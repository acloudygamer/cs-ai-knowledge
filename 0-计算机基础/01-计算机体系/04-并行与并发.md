# 并行与并发

### 解决什么问题
在多任务场景下高效利用 CPU 资源：通过并发管理多个任务（单核交替执行），通过并行真正同时执行多个任务（多核同时执行）。

### 核心概念
- **并发 (Concurrency)**：同一时间间隔内处理多个任务，通过时间片轮转切换执行上下文
- **并行 (Parallelism)**：同一时刻真正同时执行多个任务，需要多个物理执行单元
- **同步 (Synchronization)**：协调多个执行单元对共享资源的访问，防止竞态条件
- **死锁 (Deadlock)**：多个执行单元互相等待对方持有的资源，形成循环等待
- **阿姆达尔定律 (Amdahl's Law)**：并行化加速比受串行部分比例限制

### 怎么用

```python
import threading
import queue

# 生产者-消费者模式
def producer(q, count):
    for i in range(count):
        q.put(i)
    q.put(None)  # 结束信号

def consumer(q):
    while True:
        item = q.get()
        if item is None:
            break
        print(f"Processed: {item}")

q = queue.Queue()
threading.Thread(target=producer, args=(q, 10)).start()
threading.Thread(target=consumer, args=(q,)).start()
```

```python
import threading

# 屏障同步 - 等待所有线程到达某点后同时继续
barrier = threading.Barrier(3)

def worker(name):
    print(f"{name} waiting at barrier")
    barrier.wait()
    print(f"{name} passed barrier")

for i in range(3):
    threading.Thread(target=worker, args=(f"Worker-{i}",)).start()
```

## 概念

**并发 (Concurrency)** 和 **并行 (Parallelism)** 是两个相关但不同的概念：
- 并发：同一时间间隔内处理多个任务，通过时间片轮转切换
- 并行：同一时刻真正同时执行多个任务，需要硬件支持

```
并发 (单核 CPU):
  时间 → →
  T1 ████........T2 ████........T1 ████........
     ↑ CPU切换

并行 (多核 CPU):
  核心1: T1 ████████████
  核心2: T2 ████████████  (同时执行)
```

## 关系

**关键连接**：
- 并发 → **进程/线程**：并发是任务组织方式，进程/线程是实现载体
- 并行 → **多核/CPU**：真正的并行需要多个执行单元
- 同步 → **竞态条件**：多线程访问共享资源需要同步
- 死锁 → **资源竞争**：不当的同步可能导致死锁

**并行与并发的层次**：
```
指令级并行 (ILP)    → 单核 CPU 流水线，超标量
线程级并行 (TLP)    → 多线程，多核 CPU
数据级并行 (DLP)    → SIMD，GPU
任务级并行          → 多进程，多机器
```

## 并行计算模式

### 生产者-消费者

```python
import queue
import threading

def producer(q):
    for i in range(10):
        q.put(i)
    q.put(None)  # 结束信号

def consumer(q):
    while True:
        item = q.get()
        if item is None:
            break
        print(item)

q = queue.Queue()
threading.Thread(target=producer, args=(q,)).start()
threading.Thread(target=consumer, args=(q,)).start()
```

### 屏障 (Barrier)

```python
import threading

def worker(barrier, name):
    print(f"{name} waiting at barrier")
    barrier.wait()
    print(f"{name} passed barrier")

barrier = threading.Barrier(3)
for i in range(3):
    threading.Thread(target=worker, args=(barrier, f"Worker-{i}")).start()
```

## 阿姆达尔定律 (Amdahl's Law)

并行化 speedup 取决于可并行化的比例：

```
Speedup = 1 / (S + (1-S)/N)

S = 串行部分比例
N = 并行核心数
```

```python
def amdahl_speedup(serial_fraction, n_cores):
    """计算并行化加速比"""
    parallel_fraction = 1 - serial_fraction
    return 1 / (serial_fraction + parallel_fraction / n_cores)

# 示例：10% 串行，90% 可并行化
print(amdahl_speedup(0.1, 4))   # ≈ 3.08
print(amdahl_speedup(0.1, 8))   # ≈ 4.71
print(amdahl_speedup(0.1, 16))  # ≈ 6.4
```

**含义**：即使无限多核心，最大加速比也受串行部分限制

## 常见并发问题

### 竞态条件 (Race Condition)

多个线程同时访问共享资源，结果取决于访问顺序：

```
线程A: 读取 counter=0 → counter=1 (写回)
线程B: 读取 counter=0 → counter=1 (写回)
期望: counter=2，实际: counter=1
```

**解决方案**：使用原子操作或锁保护

### 活锁 (Livelock)

两个线程持续响应对方，动作互相抵消：

```
线程A: 尝试获取 lock1，失败后释放 lock2，重试
线程B: 尝试获取 lock2，失败后释放 lock1，重试
结果: 永远在忙等，但谁都无法前进
```

### 饥饿 (Starvation)

线程无法获得所需资源，一直等待：

```
高优先级线程持续抢占，低优先级线程永远没机会
```

### 死锁 (Deadlock)

互相等待对方持有的锁：

```
线程A: 持有 lock1，等待 lock2
线程B: 持有 lock2，等待 lock1
结果: 互相阻塞，程序卡住
```

**预防**：按固定顺序获取锁，或使用 try_lock

## 并发控制原语

| 原语 | 用途 | 特点 |
|------|------|------|
| mutex | 互斥访问 | 同一时刻只有一个线程能持有 |
| rwlock | 读写锁 | 读多写少场景，允许多读单写 |
| semaphore | 资源计数 | 控制同时访问的资源数量 |
| barrier | 同步点 | 等待所有线程到达后同时继续 |
| condition | 事件等待 | 线程等待特定条件满足 |

```python
import threading

# 互斥锁示例
counter = 0
counter_lock = threading.Lock()

def increment():
    global counter
    with counter_lock:  # 自动获取和释放锁
        counter += 1

# 读写锁示例
rwlock = threading.RWLock()

def read_data():
    with rwlock.read_lock():
        # 多个线程可以同时读取
        return data

def write_data(value):
    with rwlock.write_lock():
        # 独占写入
        global data
        data = value
```

## 多进程 vs 多线程

| 特性 | 多线程 | 多进程 |
|------|--------|--------|
| 内存共享 | 共享进程内存 | 独立内存空间 |
| 创建开销 | 小 | 大 |
| 通信 | 直接共享变量 | 需要 IPC |
| 稳定性 | 一个线程崩溃影响整个进程 | 进程隔离，更稳定 |
| 适用场景 | IO 密集型 | CPU 密集型 |

```python
# Python 多进程示例
from multiprocessing import Process, Queue

def worker(q):
    q.put("result")

if __name__ == "__main__":
    q = Queue()
    p = Process(target=worker, args=(q,))
    p.start()
    p.join()
    print(q.get())
```
