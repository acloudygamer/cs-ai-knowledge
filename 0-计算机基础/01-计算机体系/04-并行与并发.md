# 并行与并发

## 概念

**并发 (Concurrency)** 和 **并行 (Parallelism)** 是两个相关但不同的概念：
- 并发：同一时间间隔内处理多个任务，通过时间片轮转切换
- 并行：同一时刻真正同时执行多个任务，需要硬件支持

```
并发 (单核 CPU):
  时间 → →
  T1 ████........T2 ████........T1 ████........
     ↑ CPU切换

并行 (多核 CPU):
  核心1: T1 ████████████
  核心2: T2 ████████████  (同时执行)
```

## 关系

**关键连接**：
- 并发 → **进程/线程**：并发是任务组织方式，进程/线程是实现载体
- 并行 → **多核/CPU**：真正的并行需要多个执行单元
- 同步 → **竞态条件**：多线程访问共享资源需要同步
- 死锁 → **资源竞争**：不当的同步可能导致死锁

**并行与并发的层次**：
```
指令级并行 (ILP)    → 单核 CPU 流水线，超标量
线程级并行 (TLP)    → 多线程，多核 CPU
数据级并行 (DLP)    → SIMD，GPU
任务级并行          → 多进程，多机器
```

## 进程与线程

### 进程 (Process)

进程是资源分配的基本单位：

```python
import os
import multiprocessing

# 创建进程
def worker(name):
    print(f"Worker {name} running in process {os.getpid()}")

if __name__ == "__main__":
    p = multiprocessing.Process(target=worker, args=("Task",))
    p.start()
    p.join()  # 等待结束
```

**进程特点**：
- 独立的虚拟地址空间
- 进程间通信需要 IPC 机制
- 创建/销毁开销较大
- 隔离性好，一个进程崩溃不影响其他

### 线程 (Thread)

线程是 CPU 调度的基本单位：

```python
import threading

def worker(name):
    print(f"Worker {name} running in thread {threading.current_thread().name}")

t = threading.Thread(target=worker, args=("Task",))
t.start()
t.join()
```

**线程特点**：
- 共享进程的地址空间
- 线程间通信直接共享数据
- 创建/销毁开销较小
- 一个线程崩溃可能导致整个进程崩溃

**进程 vs 线程**：

| 特性 | 进程 | 线程 |
|------|------|------|
| 资源分配 | 独立虚拟地址空间 | 共享进程资源 |
| 创建开销 | 大 | 小 |
| 通信 | IPC (管道/消息队列/共享内存) | 直接共享变量 |
| 隔离性 | 强 | 弱 |
| 切换开销 | 大 (切换页表/文件描述符) | 小 (只切换寄存器和栈) |

## 同步原语

多线程访问共享资源时需要同步：

### 互斥锁 (Mutex)

```python
import threading

class Counter:
    def __init__(self):
        self.lock = threading.Lock()
        self.count = 0
    
    def increment(self):
        with self.lock:  # 获取锁
            self.count += 1
```

### 信号量 (Semaphore)

```python
import threading

# 控制同时访问的线程数
semaphore = threading.Semaphore(3)  # 最多3个线程同时访问

def worker():
    with semaphore:
        # 临界区
        pass
```

### 条件变量 (Condition)

```python
import threading

condition = threading.Condition()
ready = False

def producer():
    global ready
    with condition:
        ready = True
        condition.notify()  # 通知等待的消费者

def consumer():
    global ready
    with condition:
        while not ready:
            condition.wait()  # 等待直到 ready 为 True
```

### 读写锁 (Read-Write Lock)

```python
import threading

class RWLock:
    """读写锁实现，支持写者优先防止写者饥饿"""
    def __init__(self):
        self._read_ready = threading.Condition(threading.Lock())
        self._readers = 0
        self._writers = 0  # 等待中的写者数量
        self._write_lock = threading.Lock()  # 写操作独占锁
    
    def read_acquire(self):
        with self._read_ready:
            # 有写者等待时，读者需等待以防写者饥饿
            while self._writers > 0:
                self._read_ready.wait()
            self._readers += 1
    
    def read_release(self):
        with self._read_ready:
            self._readers -= 1
            if self._readers == 0:
                self._read_ready.notify_all()  # 唤醒等待的写者
    
    def write_acquire(self):
        with self._read_ready:
            self._writers += 1
            # 等待所有读者释放
            while self._readers > 0:
                self._read_ready.wait()
        self._write_lock.acquire()
    
    def write_release(self):
        with self._read_ready:
            self._writers -= 1
            self._write_lock.release()
            self._read_ready.notify_all()  # 唤醒所有等待的读者和写者
```

### 事件 (Event)

import threading

## 死锁

死锁是多个进程/线程相互等待对方持有的资源：

### 死锁必要条件 (Coffman 条件)

| 条件 | 说明 |
|------|------|
| 互斥 | 资源一次只能被一个线程持有 |
| 占有并等待 | 线程持有资源同时等待其他资源 |
| 非抢占 | 资源不能被强制夺取 |
| 循环等待 | 形成资源循环等待链 |

### 死锁示例

```python
import threading

lock1 = threading.Lock()
lock2 = threading.Lock()

def thread1():
    with lock1:
        with lock2:  # 可能死锁
            print("Thread 1")

def thread2():
    with lock2:
        with lock1:  # 可能死锁
            print("Thread 2")

# 线程1持有lock1，线程2持有lock2，互相等待
```

### 死锁预防

1. **破坏互斥**：使用资源池
2. **破坏占有并等待**：一次性获取所有资源
3. **破坏非抢占**：允许抢占资源
4. **破坏循环等待**：按固定顺序获取锁

```python
# 按固定顺序获取锁 - 避免死锁
def thread1():
    with lock1:
        with lock2:  # 不会死锁，因为顺序固定
            print("Thread 1")

def thread2():
    with lock1:  # 同样先获取 lock1
        with lock2:
            print("Thread 2")
```

## 线程池

线程池避免频繁创建/销毁线程的开销：

```python
from concurrent.futures import ThreadPoolExecutor

with ThreadPoolExecutor(max_workers=4) as executor:
    future = executor.submit(worker, "task")
    result = future.result()  # 获取结果
```

### 进程池

```python
from concurrent.futures import ProcessPoolExecutor

def cpu_intensive_task(n):
    return sum(i * i for i in range(n))

with ProcessPoolExecutor(max_workers=4) as executor:
    results = list(executor.map(cpu_intensive_task, [1000000] * 8))
```

## 协程 (Coroutine)

协程是用户态的轻量级并发：

```python
# Python asyncio 示例
import asyncio
import aiohttp

async def fetch(url):
    async with aiohttp.ClientSession() as session:
        async with session.get(url) as response:
            return await response.text()

async def main():
    tasks = [fetch(url) for url in urls]
    pages = await asyncio.gather(*tasks)  # 并发执行

asyncio.run(main())
```

**协程 vs 线程**：

| 特性 | 协程 | 线程 |
|------|------|------|
| 调度 | 用户态 ( cooperative ) | 内核态 ( preemptive ) |
| 开销 | 极低 | 较高 |
| 阻塞 | 主动让出 | 内核切换 |
| 适用 | I/O 密集 | CPU 密集 |

## 并行计算模式

### 生产者-消费者

```python
import queue
import threading

def producer(q):
    for i in range(10):
        q.put(i)
    q.put(None)  # 结束信号

def consumer(q):
    while True:
        item = q.get()
        if item is None:
            break
        print(item)

q = queue.Queue()
threading.Thread(target=producer, args=(q,)).start()
threading.Thread(target=consumer, args=(q,)).start()
```

### 屏障 (Barrier)

```python
import threading

def worker(barrier, name):
    print(f"{name} waiting at barrier")
    barrier.wait()
    print(f"{name} passed barrier")

barrier = threading.Barrier(3)
for i in range(3):
    threading.Thread(target=worker, args=(barrier, f"Worker-{i}")).start()
```

## 阿姆达尔定律 (Amdahl's Law)

并行化 speedup 取决于可并行化的比例：

```
Speedup = 1 / (S + (1-S)/N)

S = 串行部分比例
N = 并行核心数
```

```python
def amdahl_speedup(serial_fraction, n_cores):
    """计算并行化加速比"""
    parallel_fraction = 1 - serial_fraction
    return 1 / (serial_fraction + parallel_fraction / n_cores)

# 示例：10% 串行，90% 可并行化
print(amdahl_speedup(0.1, 4))   # ≈ 3.08
print(amdahl_speedup(0.1, 8))   # ≈ 4.71
print(amdahl_speedup(0.1, 16))  # ≈ 6.4
```

**含义**：即使无限多核心，最大加速比也受串行部分限制

## Go vs Python 并发模型

### Go Goroutine

```go
package main

import "fmt"

func worker(name string) {
    fmt.Println(name)
}

func main() {
    // 创建 goroutine (比线程更轻量)
    go worker("Task 1")
    go worker("Task 2")
    
    // 等待 goroutine 完成
    // 使用 sync.WaitGroup 或 channel
}
```

### Python GIL 问题

Python 的 GIL (全局解释器锁) 限制了真正的并行：

```python
import threading

def cpu_task():
    # 由于 GIL，这个不会真正并行
    total = sum(range(10_000_000))

# 对于 CPU 密集型任务，使用 ProcessPoolExecutor
from concurrent.futures import ProcessPoolExecutor
with ProcessPoolExecutor() as executor:
    executor.map(cpu_task, range(4))
```

**注意**：
- I/O 密集型：threading + asyncio
- CPU 密集型：multiprocessing + ProcessPoolExecutor
