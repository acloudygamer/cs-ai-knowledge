# 并行与并发

## 定义

并行是同一时刻物理上同时执行多个执行流，并发是同一时间间隔内交替执行多个执行流。

## 数学模型

阿姆达尔定律（加速比上限）：

$$
S_{max} = \frac{1}{S + \frac{1-S}{N}} \xrightarrow{S \to 0} N, \quad \xrightarrow{S \to 1} 1
$$

其中 $S$ 为串行比例，$N$ 为核心数。

Gustafson 定律（规模加速比）：

$$
S_{weak} = \alpha + N(1-\alpha)
$$

## 数据流

```
并发（单核）：
T1 ████....T2 ████....T1 ████....
    ↑ CPU 时间片切换

并行（多核）：
核心1: T1 ████████████████████
核心2: T2 ████████████
核心3: T3 ████████████████
```

## 机制

**同步原语**：保护共享资源访问。

| 原语 | 约束 | 违规后果 |
|------|------|----------|
| mutex | 同一时刻仅一线程持有 | 竞态条件 |
| rwlock | 写者排他，读者并行 | 写饥饿 |
| semaphore | 计数上限 | 资源泄漏 |
| barrier | 所有线程到达才能继续 | 死锁 |

**死锁必要条件**（同时满足）：
1. 互斥持有
2. 占有等待
3. 不可抢占
4. 循环等待

**Python GIL**：CPython 多线程无法并行执行 CPU 密集型字节码。

约束：
- 同一时刻仅一线程执行 Python 字节码
- IO 等待时线程让出 GIL

违规后果：
- CPU 密集型多线程反而更慢
- 解决方案：multiprocessing / ProcessPoolExecutor
