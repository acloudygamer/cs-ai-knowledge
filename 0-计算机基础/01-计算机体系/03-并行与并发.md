# 并行与并发

单核CPU一次只能执行一条指令，但需要同时处理多个任务（IO等待、用户交互、网络请求）。并行与并发让程序在资源有限的情况下实现"同时"处理多个任务，提升吞吐率和响应速度。

## 核心概念

- **并发**：同一时间间隔内处理多个任务，通过时间片轮转切换（单核即可实现）
- **并行**：同一时刻真正同时执行多个任务，需要多核CPU硬件支持
- **同步**：多线程访问共享资源时需要协调，避免竞态条件
- **阿姆达尔定律**：加速比取决于可并行化的比例（S = 串行部分占比），最大加速比 = 1 / (S + (1-S)/N)

**并行层次**：
```
指令级并行 (ILP)    → 单核 CPU 流水线，超标量
线程级并行 (TLP)    → 多线程，多核 CPU
数据级并行 (DLP)    → SIMD，GPU
任务级并行          → 多进程，多机器
```

## 并发 vs 并行

```
并发 (单核 CPU):
  时间 → →
  T1 ████........T2 ████........T1 ████........
     ↑ CPU切换

并行 (多核 CPU):
  核心1: T1 ████████████
  核心2: T2 ████████████  (同时执行)
```

**关键区别**：并发是时间分片交替执行，并行是物理上同时执行。

### 参考样例

```python
import queue
import threading

def producer(q):
    for i in range(10):
        q.put(i)
    q.put(None)  # 结束信号

def consumer(q):
    while True:
        item = q.get()
        if item is None:
            break
        print(item)

q = queue.Queue()
threading.Thread(target=producer, args=(q,)).start()
threading.Thread(target=consumer, args=(q,)).start()
```

## 同步原语

多线程访问共享资源时需要同步机制：

| 原语 | 用途 | 特点 |
|------|------|------|
| mutex | 互斥访问 | 同一时刻只有一个线程能持有 |
| rwlock | 读写锁 | 读多写少场景，允许多读单写 |
| semaphore | 资源计数 | 控制同时访问的资源数量 |
| barrier | 同步点 | 等待所有线程到达后同时继续 |

### 参考样例

```python
import threading

# 互斥锁示例
counter = 0
counter_lock = threading.Lock()

def increment():
    global counter
    with counter_lock:  # 自动获取和释放锁
        counter += 1

# 读写锁示例
rwlock = threading.RWLock()

def read_data():
    with rwlock.read_lock():
        return data

def write_data(value):
    with rwlock.write_lock():
        global data
        data = value
```

## 常见并发问题

| 问题 | 现象 | 解决方案 |
|------|------|----------|
| 竞态条件 | 结果取决于线程访问顺序 | 原子操作或锁保护 |
| 死锁 | 互相等待对方持有的锁 | 按固定顺序获取锁 |
| 活锁 | 线程持续响应对方，动作抵消 | 随机退让 |
| 饥饿 | 线程无法获得所需资源 | 公平锁/优先级调整 |

## 多进程 vs 多线程

| 特性 | 多线程 | 多进程 |
|------|--------|--------|
| 内存共享 | 共享进程内存 | 独立内存空间 |
| 创建开销 | 小 | 大 |
| 通信 | 直接共享变量 | 需要 IPC |
| 稳定性 | 一个线程崩溃影响整个进程 | 进程隔离，更稳定 |
| 适用场景 | IO 密集型 | CPU 密集型 |

> **机制演进说明**
> - **Python GIL**：CPython的多线程因GIL无法并行执行CPU密集型Python字节码，IO密集型任务因等待IO而释放GIL，可受益于多线程

### 参考样例

```python
# Python 多进程示例
from multiprocessing import Process, Queue

def worker(q):
    q.put("result")

if __name__ == "__main__":
    q = Queue()
    p = Process(target=worker, args=(q,))
    p.start()
    p.join()
    print(q.get())
```

## 阿姆达尔定律

加速比取决于可并行化的比例：

```python
def amdahl_speedup(serial_fraction, n_cores):
    """计算并行化加速比"""
    parallel_fraction = 1 - serial_fraction
    return 1 / (serial_fraction + parallel_fraction / n_cores)

# 示例：10% 串行，90% 可并行化
print(amdahl_speedup(0.1, 4))   # ≈ 3.08
print(amdahl_speedup(0.1, 8))   # ≈ 4.71
# 含义：即使无限多核心，最大加速比也受串行部分限制
```
