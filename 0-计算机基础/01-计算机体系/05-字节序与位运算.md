# 字节序与位运算

## 定义

字节序定义多字节数据在内存中的字节排列顺序，位运算是对整数二进制位的逐位操作。

## 数学模型

字节序转换（以 0x12345678 为例）：

$$
\text{小端} = 0x78 \times 2^{24} + 0x56 \times 2^{16} + 0x34 \times 2^8 + 0x12
$$

位掩码提取特定位：

$$
\text{提取第 } n \text{ 位} = \frac{v \gg n}{1} \AND 1
$$

## 数据流

```
大端序 (0x12345678):
地址:  0x00   0x01   0x02   0x03
数据:   0x12  0x34   0x56   0x78
        ↑高位字节在低地址

小端序 (0x12345678):
地址:  0x00   0x01   0x02   0x03
数据:   0x78  0x56   0x34   0x12
        ↑低位字节在低地址
```

## 机制

**大端序**：符合人类阅读习惯，网络协议标准（TCP/IP）。

约束：
- 字符串比较可直接按内存顺序
- 网络字节序统一为大端

违规后果：
- x86 系统间通信未转换导致数据解析错误

**小端序**：低位字节在低地址，利于低位优先计算。

约束：
- x86/x64、ARM 大多数实现默认小端
- 整数算术从低位向高位进位

违规后果：
- 跨平台网络编程必须转换字节序

**位运算安全规则**：

| 规则 | 说明 |
|------|------|
| 移位宽度 < 类型宽度 | 移位超过类型宽度是 UB |
| 有符号数右移 | 实现定义，优先用无符号 |
| 有符号溢出 | UB，编译器可能优化掉 |
