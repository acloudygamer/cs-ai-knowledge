# 字节序与位运算

## 概念

**字节序（Endianness）** 定义了多字节数据在内存中的存储顺序，是网络编程、系统编程和跨平台开发的基础概念。

**位运算**是对整数的二进制位进行操作，是高效算法、低级系统编程和性能优化的核心工具。


## 字节序

### 定义与类型

**大端序（Big Endian）**：高位字节存储在低地址
- 符合人类阅读习惯（左边是高位）
- 网络协议标准采用（TCP/IP协议栈）

**小端序（Little Endian）**：低位字节存储在低地址
- x86/x64、ARM（大多数）等主流CPU采用
- 便于CPU进行算术运算

```c
// 以整数 0x12345678 为例（4字节）
// 地址假设为 0x00, 0x01, 0x02, 0x03

大端序存储:
地址:  0x00   0x01   0x02   0x03
数据:   0x12  0x34   0x56   0x78
        ↑高位字节在前

小端序存储:
地址:  0x00   0x01   0x02   0x03
数据:   0x78  0x56   0x34   0x12
        ↑低位字节在前
```

### 常见平台字节序

| 平台/架构 | 字节序 | 场景 |
|-----------|--------|------|
| x86/x64 | 小端 | 桌面PC、服务器 |
| ARM | 小端（可配置） | 移动设备、嵌入式 |
| MIPS | 大端 | 某些网络设备 |
| 网络协议 | 大端 | TCP/IP, UDP |

```python
# Python 检测字节序
import sys

def get_endianness():
    return sys.byteorder  # 'little' 或 'big'

# 或者通过 struct 检测
import struct
def detect_endian():
    packed = struct.pack('=I', 1)  # 打包数字1
    if packed[0] == 1:
        return '小端序'
    else:
        return '大端序'
```

### 字节序转换

**主机字节序 ↔ 网络字节序**：
- 网络协议统一使用大端序
- 发送前需转换为主机序
- 接收后需转换回网络序

检测字节序的经典方法使用union避免指针类型转换带来的对齐问题。字节序转换的通用方法通过位运算拆分合并各个字节。

```c
#include <arpa/inet.h>

// 主机字节序 → 网络字节序
uint32_t htonl(uint32_t hostlong);  // 32位长整型
uint16_t htons(uint16_t hostshort); // 16位短整型

// 网络字节序 → 主机字节序
uint32_t ntohl(uint32_t netlong);
uint16_t ntohs(uint16_t netshort);

// 示例
struct sockaddr_in server;
server.sin_addr.s_addr = inet_addr("192.168.1.1");      // 字符串转网络字节序
server.sin_addr.s_addr = inet_pton(AF_INET, "192.168.1.1", &server.sin_addr); // 推荐方式

char *ip = inet_ntoa(server.sin_addr);  // 网络字节序转字符串
```

## 位运算

### 基础位运算符

| 运算符 | 名称 | 说明 |
|--------|------|------|
| `&` | 按位与 | 两位都为1时结果为1 |
| `\|` | 按位或 | 任一位为1时结果为1 |
| `^` | 按位异或 | 两位相异时结果为1 |
| `~` | 按位取反 | 所有位翻转 |
| `<<` | 左移 | 二进制位向左移动 |
| `>>` | 右移 | 二进制位向右移动 |

### 常用位运算技巧

#### 1. 判断奇偶性

检查最低位：奇数返回1，偶数返回0。

```c
bool is_odd(int x) { return x & 1; }      // 奇数返回1
bool is_even(int x) { return (x & 1) == 0; }  // 偶数返回true
```

#### 2. 获取特定位

将值右移n位后与1取与。

```c
bool get_bit(uint32_t value, int n) { return (value >> n) & 1; }
```

#### 3. 设置特定位为1

将1左移n位后与原值取或。

```c
uint32_t set_bit(uint32_t value, int n) { return value | (1 << n); }
```

#### 4. 清除特定位

将1左移n位后取反，再与原值取与。

```c
uint32_t clear_bit(uint32_t value, int n) { return value & ~(1 << n); }
```

#### 5. 切换特定位

将1左移n位后与原值取异或。

```c
uint32_t toggle_bit(uint32_t value, int n) { return value ^ (1 << n); }
```

### 高级位运算模式

#### 1. 最低有效位（LSB）提取

利用`value & -value`可以提取最低位的1。利用`value & (value - 1)`可以判断是否为2的幂。

#### 2. 位计数（Popcount）

Brian Kernighan算法通过每次清除最低位的1来计数。GCC/Clang提供内置函数。

#### 3. 循环移位

循环移位将移出的位放到另一端。

#### 4. 字节交换

字节交换用于调整字节序。

```c
// 权限标志定义
#define READ    (1 << 0)   // 0b0001
#define WRITE   (1 << 1)   // 0b0010
#define EXECUTE (1 << 2)   // 0b0100

// 检查权限
bool has_permission(uint8_t permissions, uint8_t requested) {
    return (permissions & requested) == requested;
}

// 添加权限
uint8_t add_permission(uint8_t permissions, uint8_t new_perm) {
    return permissions | new_perm;
}
```

```c

#define TCP_FIN  0x01
#define TCP_SYN  0x02
#define TCP_RST  0x04
#define TCP_PSH  0x08
#define TCP_ACK  0x10

// 设置多个标志
uint8_t flags = TCP_SYN | TCP_ACK;

```

```c
// 颜色值打包 (RGB565格式)
uint16_t pack_rgb565(uint8_t r, uint8_t g, uint8_t b) {
    return ((r >> 3) << 11) | ((g >> 2) << 5) | (b >> 3);
}

// 解压颜色值
void unpack_rgb565(uint16_t color, uint8_t *r, uint8_t *g, uint8_t *b) {
    *r = (color >> 11) & 0x1F;
    *g = (color >> 5) & 0x3F;
    *b = color & 0x1F;
}
```

```c
// 快速乘以2^n
int fast_multiply(int x, int n) {
    return x << n;  // 等价于 x * 2^n
}

// 快速除以2^n
int fast_divide(int x, int n) {
    return x >> n;  // 等价于 x / 2^n
}

// 判断是否为偶数
bool is_even(int x) {
    return (x & 1) == 0;  // 比 x % 2 更快
```

### 跨平台注意事项

```c
// 1. 整数溢出行为是未定义的
// 不要依赖有符号整数的位运算溢出

// 2. 移位超过类型宽度是未定义的
uint32_t x = 1;
uint32_t result = x << 32;  // 未定义行为！

// 3. 有符号数右移是实现定义的
// 算术右移（补1）vs 逻辑右移（补0）

// 安全的做法：使用无符号类型
uint32_t safe_shift(uint32_t value, int shift) {
    if (shift >= 32) return 0;
    return value << shift;
}
```

## 字节序与位运算结合

### 序列化中的应用

```c
// 将多字节数据序列化为网络字节序
void serialize_uint32(uint32_t value, uint8_t *buffer) {
    buffer[0] = (value >> 24) & 0xFF;  // 大端在前
    buffer[1] = (value >> 16) & 0xFF;
    buffer[2] = (value >> 8) & 0xFF;
    buffer[3] = value & 0xFF;
}

// 反序列化
uint32_t deserialize_uint32(uint8_t *buffer) {
    return ((uint32_t)buffer[0] << 24) |
           ((uint32_t)buffer[1] << 16) |
           ((uint32_t)buffer[2] << 8)  |
           buffer[3];
}
```

### 协议解析示例

```c
// 解析IPv4首部
struct IPv4Header {
    uint8_t  version_ihl;     // 版本(4位) + 首部长度(4位)
    uint8_t  tos;              // 服务类型
    uint16_t total_length;
    uint16_t identification;
    uint16_t flags_fragment;   // 标志(3位) + 片偏移(13位)
    uint8_t  ttl;
    uint8_t  protocol;
    uint16_t checksum;
    uint32_t src_ip;
    uint32_t dst_ip;
};

// 提取版本
uint8_t get_version(struct IPv4Header *hdr) {
    return hdr->version_ihl >> 4;
}

// 提取首部长度（单位：4字节）
uint8_t get_header_length(struct IPv4Header *hdr) {
    return (hdr->version_ihl & 0x0F) * 4;
}
```

## 常见错误

1. **字节序混淆**：网络协议使用大端序，但x86是小端序，转换函数必不可少
2. **有符号右移**：在某些平台上会产生不同的结果，使用无符号类型更安全
3. **移位溢出**：移动超过类型宽度的位数是未定义行为
4. **大小端检测**：使用union而非指针类型转换（避免对齐问题）

## 关系

**关键连接**：
- 字节序 ↔ **网络协议**：网络编程必须处理字节序转换
- 位运算 ↔ **权限系统**：Unix权限使用位标志
- 字节序 ↔ **二进制格式**：文件格式、协议格式都涉及字节序
- 位运算 ↔ **性能优化**：位操作是最快的运算之一
