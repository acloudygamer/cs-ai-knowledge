# 计算机体系

> **版本基准**: universal

本部分涵盖计算机硬件层的基础知识，包括 CPU、内存、存储、指令执行等核心概念。

## 目录

### [01-硬件组成](./01-硬件组成.md)

### [02-缓存与存储层次](./02-缓存与存储层次.md)
介质三角与局部性、AMAT 双视角账本、地址切分与 VIPT 位标尺、访存事务环、包容/排他与嗅探过滤、MESI 状态机、TLB 性能面、DRAM 以下存储层级

### [03-指令执行](./03-指令执行.md)
指令的获取、译码、执行流程，CPU 工作原理

### [04-GPU与异构计算](./04-GPU与异构计算.md)

### [06-并行与并发](./06-并行与并发.md)

## 学习路径

1. **先硬件组成**：理解执行引擎、地址翻译与内存墙的基本结构
2. **再缓存与存储层次**：掌握缓存结构、一致性与存储层级
3. **再指令执行**：理解 CPU 如何执行指令
4. **后 GPU 与异构计算**：了解 GPU 架构与 CUDA
5. **再字节序与位运算**：掌握大端小端与位操作
6. **最后并行与并发**：多线程、锁、协程、异步 IO
