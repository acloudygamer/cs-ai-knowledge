## 学习路径

1. **先硬件组成**：理解执行引擎、地址翻译与内存墙的基本结构
2. **再缓存与存储层次**：掌握缓存结构、一致性与存储层级
3. **再指令执行**：理解 CPU 如何执行指令
4. **再指令集架构与 SIMD**：理解软硬件契约与向量并行
5. **再数据表示与字节序**：掌握二进制数据在硬件中的形态
6. **后 GPU 与异构计算**：了解吞吐优先的另一种执行引擎
7. **最后并行与并发**：多核竞争、同步原语与并发模型
