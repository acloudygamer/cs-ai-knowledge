# 计算机体系

> **版本基准**: universal

本部分涵盖计算机硬件层的基础知识，包括 CPU、内存、存储、指令执行等核心概念。

全章按依赖拓扑排序，后篇消费前篇的机制如下：

| 篇目 | 消费的前置机制 |
|------|----------------|
| 02 缓存与存储层次 | 01 的虚拟地址全链路、DRAM 通道交织与内存墙账本 |
| 03 指令执行 | 02 的 AMAT 过滤账本、64B 行与 MSHR 闸门 |
| 04 指令集架构与 SIMD | 03 的执行端口与向量引擎位宽 |
| 05 数据表示与字节序 | 04 §4.1 的 ISA/微架构分界、§4.4 的 GPR 与向量寄存器位宽家谱；02 §二 的 64B 行边界 |
| 06 GPU 与异构计算 | 05 §2 的 IEEE 754 字段与 §6 的宽度转换；02 §一 的延迟档位与 §三 的在途请求；01 §三 的 25.6 GB/s 单服务台上限 |
| 07 并行与并发 | 02 §五 的 MESI 与 §五.3 的迁移账单；03 §五.2 的 Store Buffer 与 §五.4 的 TSO/弱序；05 §4 的对齐与 §5 的位标记 |

下游卷对本章的消费：02-操作系统 消费 01/02 的页表与 TLB、05 的端序与 ABI 布局、07 的 SMT 与拓扑；04-编程运行环境 消费 05 的目标文件端序与结构体布局；05-计算机网络 消费 05 的网络序。

## 学习路径

1. **先硬件组成**：理解执行引擎、地址翻译、内存墙与 NUMA 封装的基本结构
2. **再缓存与存储层次**：掌握 AMAT 账本、地址切分、MESI 与迁移账单
3. **再指令执行**：理解乱序窗口、Store Buffer 与 TSO 的硬件成因
4. **再指令集架构与 SIMD**：理解软硬件契约、向量寄存器家谱与谓词掩码
5. **再数据表示与字节序**：消费 04 的位宽与 02 的行边界，掌握补码、浮点字段、端序与布局
6. **后 GPU 与异构计算**：消费 05 的字段切分与 02 的带宽/延迟档位，看吞吐优先的另一极
7. **最后并行与并发**：消费 02/03/05 的一致性、乱序与对齐结论，落到同步原语与并发模型
