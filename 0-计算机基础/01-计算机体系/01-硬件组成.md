# 硬件组成

计算机需要四大核心组件（CPU、内存、存储、I/O）协同工作。理解硬件组成有助于选择云实例规格、排查性能瓶颈、设计高效程序。

## CPU：指令执行的物理载体

CPU是计算机的核心执行单元，其内部结构决定了指令处理能力。**控制单元**负责指令的获取、译码和执行流程控制，包含指令寄存器（IR）存储当前指令、程序计数器（PC）指向下一条指令、指令译码器解析操作码和操作数。**运算单元（ALU）**执行算术运算（加/减/乘/除）和逻辑运算（与/或/非/异或）。**寄存器**分为通用寄存器（AX/BX/CX/DX、R8-R15等）和专用寄存器（SP/BP/IP/FLAGS），用于高速暂存操作数和控制状态。**缓存（L1/L2/L3）**缓解内存访问延迟，容量递增但速度递减。

关键性能指标：主频（GHz）决定时钟周期速度，核心数决定并行执行能力，线程数（超线程）提高流水线利用率，缓存大小影响数据访问命中率。

## 内存层级与访问速度

内存层级结构是CPU访问局部性原理的物理实现。

| 层级 | 访问延迟 | 典型容量 | 成本/性能 |
|------|----------|----------|-----------|
| 寄存器 | 0周期 | 极小 | 最快 |
| L1缓存 | 4周期 | 32KB-64KB | 高 |
| L2缓存 | 12周期 | 256KB-1MB | 中 |
| L3缓存 | 40周期 | 4MB-64MB | 低 |
| 内存 | 100+周期 | GB级 | 最低 |

**局部性原理**：时间局部性（同一数据近期可能被再次访问）和空间局部性（相邻数据可能被一起访问）决定了缓存的有效性。

## 存储层次与介质特性

存储介质在速度、容量和成本之间取得不同平衡。

| 存储类型 | 原理 | 顺序读取 | 容量 | 寿命限制 |
|----------|------|----------|------|----------|
| HDD | 机械旋转+磁头寻道 | ~100MB/s | TB级 | 机械磨损 |
| SSD | NAND Flash | ~500MB/s | TB级 | 写入次数（P/E Cycle） |
| NVMe SSD | PCIe直连 | GB/s级 | TB级 | 写入次数限制 |

> **机制演进说明**
> - **HDD 机制**：机械物理寻道是瓶颈，吞吐量受限于盘片转速和磁头定位速度
> - **SSD/NVMe 变革**：无机械部件，PCIe直连消除SATA协议开销，但写入寿命（TBW）是实际约束

## 冯·诺依曼架构

程序和数据共存于同一内存，CPU通过总线与内存/I/O设备交互。这一架构的核心约束是**内存访问带宽**成为性能瓶颈（冯·诺依曼瓶颈）。

```
         ┌──────────────┐
         │    CPU       │
         │  ┌────────┐  │
         │  │控制单元│  │◄─────► 指令
         │  ├────────┤  │
         │  │运算单元│  │◄─────► 数据
         │  ├────────┤  │
         │  │ 寄存器 │  │
         │  └────────┘  │
         └──────┬───────┘
                │
    ┌────────────┼────────────┐
    │            │            │
    ▼            ▼            ▼
┌───────┐   ┌───────┐   ┌────────┐
│ 内存   │   │ I/O   │   │ 存储   │
│(RAM)  │   │设备   │   │(磁盘)  │
└───────┘   └───────┘   └────────┘
                │
         总线（数据/地址/控制）
```

C语言内存布局包含：`.data`段（全局/静态变量）、`.bss`段（未初始化变量）、栈（局部变量）、堆（动态分配）。

```bash
# Linux 查看CPU信息
cat /proc/cpuinfo | grep "model name"
arch  # 或 uname -m

# Linux 查看磁盘信息
lsblk
df -h

# Windows
wmic diskdrive get status,size,model
wmic cpu get name
```
