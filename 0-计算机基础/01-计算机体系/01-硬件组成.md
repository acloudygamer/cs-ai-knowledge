# 硬件组成

## 定义

计算机是存储程序式电子计算机，其本质是通过指令序列对二进制数据进行变换的机器。

## 数学模型

冯·诺依曼瓶颈的定量描述：

$$
B_{瓶颈} = \frac{数据访问次数}{时间} \times 数据宽度
$$

局部性原理的缓存命中率模型：

$$
H = \frac{命中次数}{命中次数 + 未命中次数}
$$

## 数据流

```
用户程序
    ↓ 编译链接
可执行文件（指令+数据）
    ↓ 加载
内存（指令区/数据区）
    ↓ 取指
CPU 控制单元 → 指令寄存器 IR
    ↓ 译码
CPU 运算单元 ← 寄存器文件
    ↓ 执行
结果 → 写回寄存器/内存
    ↓
I/O 设备 ← 总线
```

## 机制

**冯·诺依曼架构**：程序与数据共存于同一内存，CPU 通过总线访问。

约束：
- 内存访问带宽决定整机性能上限
- 总线争用导致 CPU 与 I/O 竞争

违规后果：
- 多核时代缓存一致性协议复杂化
- DMA 设备与 CPU 并发访问内存需协调

**内存层级**：容量与速度的物理折中。

约束：
- L1/L2/L3 延迟逐级递增（4/12/40 周期典型值）
- 容量逐级递增（32KB/1MB/64MB 典型值）

违规后果：
- 数据局部性差导致缓存未命中
- 内存带宽不足时 CPU 空等

**存储层次**：速度/容量/成本三角权衡。

约束：
- HDD 机械寻道限制吞吐量（~100MB/s）
- SSD 无机械部件但写入寿命有限（TBW）
- NVMe PCIe 直连消除协议开销（5-7 GB/s）

违规后果：
- 数据库等随机访问场景用 HDD 导致性能灾难
- 写入密集型应用忽略 TBW 导致固态衰减

## 参考存根

```bash
# Linux 查看 CPU 信息（WSL/Linux）
cat /proc/cpuinfo | grep "model name"
uname -m

# Linux 查看内存
cat /proc/meminfo | head -5
```

```powershell
# Windows 查看 CPU
Get-CimInstance Win32_Processor | Select-Object Name

# Windows 查看系统架构
[System.Environment]::GetEnvironmentVariable("PROCESSOR_ARCHITECTURE")
```
