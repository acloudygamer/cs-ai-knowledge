# 硬件组成

## 解决什么问题

计算机需要四大核心组件（CPU、内存、存储、I/O）协同工作。理解硬件组成有助于选择云实例规格、排查性能瓶颈、设计高效程序。

## 核心概念

- **CPU**：执行指令的大脑，包含控制单元、运算单元(ALU)、寄存器
- **内存**：临时存储运行时数据，CPU直接访问，速度快但容量有限
- **存储**：永久保存数据（磁盘/SSD），速度慢但容量大
- **总线**：组件间数据传输通道，分数据总线、地址总线、控制总线
- **冯·诺依曼架构**：程序和数据存储在同一内存，CPU逐条执行

## 怎么用

### CPU 内部结构

```
┌─────────────────────────────────────┐
│              CPU                    │
│  ┌─────────────────────────────────┐│
│  │       控制单元 (Control Unit)    ││
│  │  - 指令寄存器 (IR)               ││
│  │  - 程序计数器 (PC)              ││
│  │  - 指令译码器                   ││
│  └─────────────────────────────────┘│
│  ┌─────────────────────────────────┐│
│  │       运算单元 (ALU)            ││
│  │  - 算术运算 (加/减/乘/除)       ││
│  │  - 逻辑运算 (与/或/非/异或)     ││
│  └─────────────────────────────────┘│
│  ┌─────────────────────────────────┐│
│  │       寄存器 (Registers)        ││
│  │  - 通用寄存器 (AX/BX/CX/DX)     ││
│  │  - 专用寄存器 (SP/BP/IP/FLAGS) ││
│  └─────────────────────────────────┘│
│  ┌─────────────────────────────────┐│
│  │       缓存 (L1/L2/L3)           ││
│  └─────────────────────────────────┘│
└─────────────────────────────────────┘
```

**关键指标**：主频（GHz）、核心数、线程数、缓存大小

### 内存层级与访问速度

| 层级 | 速度 | 容量 | 成本 |
|------|------|------|------|
| 寄存器 | 0周期 | 极小 | 最高 |
| L1缓存 | 4周期 | 32KB-64KB | 高 |
| L2缓存 | 12周期 | 256KB-1MB | 中 |
| L3缓存 | 40周期 | 4MB-64MB | 低 |
| 内存 | 100+周期 | GB级 | 最低 |

### 存储类型对比

| 存储类型 | 原理 | 速度 | 容量 | 寿命 |
|----------|------|------|------|------|
| HDD | 机械旋转+磁头 | 慢 (100MB/s) | TB级 | 机械损耗 |
| SSD | Flash闪存 | 快 (500MB/s) | TB级 | 写入次数限制 |
| NVMe SSD | PCIe接口 | 极快 (GB/s) | TB级 | 写入次数限制 |

### 冯·诺依曼架构

```
         ┌──────────────┐
         │    CPU       │
         │  ┌────────┐  │
         │  │控制单元│  │◄─────► 指令
         │  ├────────┤  │
         │  │运算单元│  │◄─────► 数据
         │  ├────────┤  │
         │  │ 寄存器 │  │
         │  └────────┘  │
         └──────┬───────┘
                │
    ┌────────────┼────────────┐
    │            │            │
    ▼            ▼            ▼
┌───────┐   ┌───────┐   ┌────────┐
│ 内存   │   │ I/O   │   │ 存储   │
│(RAM)  │   │设备   │   │(磁盘)  │
└───────┘   └───────┘   └────────┘
                │
         总线（数据/地址/控制）
```

### 内存布局示例

```c
int global_var = 10;        // .data 段（全局/静态）
static int static_var = 20; // .data 段

int main() {
    int local_var = 30;     // 栈上（局部变量）
    int* heap_ptr = malloc(sizeof(int));  // 堆上（动态分配）
    free(heap_ptr);
    return 0;
}
```

### 硬件信息查看

```bash
# Linux 查看CPU信息
cat /proc/cpuinfo | grep "model name"
arch  # 或 uname -m

# Linux 查看磁盘信息
lsblk
df -h

# Windows
wmic diskdrive get status,size,model
wmic cpu get name
```
