# GPU 与异构计算

## 定义

异构计算是使用不同类型处理器（CPU+GPU）协同完成计算，通过各自擅长的任务类型实现优势互补。

## 数学模型

GPU 理论吞吐：

$$
TP_{GPU} = SM_{数量} \times Warp_{大小} \times 频率 \times 每周期指令数
$$

内存带宽利用率：

$$
U_{bw} = \frac{实际带宽}{理论带宽} \times 100\%
$$

## 数据流

```
CPU（主机）                       GPU（设备）
─────────                        ─────────
控制逻辑                         数据并行
复杂分支                         规则数据操作
    │                                │
    │   PCIe/NVLink                  │
    └───────────────────────────────►│
         数据传输（h2d）                │
                                     ▼
                              全局内存 → SM → Warp → CUDA Core
                                     │
◄────────────────────────────────────┘
         数据传输（d2h）结果
```

## 机制

**GPU 架构**：大量小核心设计，追求高吞吐而非低延迟。

约束：
- Warp（32 线程）是最小调度单元
- 共享内存同一 block 线程可见
- 全局内存访问需要合并（Coalescing）

违规后果：
- 银行冲突（Bank Conflict）导致共享内存访问串行化
- 非合并访问带宽利用率骤降

**CPU-GPU 互联**：PCIe 带宽限制数据传输。

| 互联 | 带宽 | 场景 |
|------|------|------|
| PCIe 4.0 x16 | 32 GB/s | 单 GPU |
| NVLink | 300-900 GB/s | 多 GPU/直连 |

**Tensor Core**：矩阵乘累加专用单元。

约束：
- 混合精度（FP16 输入，FP32 累加）
- 用于深度学习矩阵运算
