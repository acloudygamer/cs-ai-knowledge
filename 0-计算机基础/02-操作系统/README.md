# 操作系统

> **版本基准**: universal（Windows 11 / Ubuntu 24.04）

本章建立在 01-计算机体系 之上：消费其页表 / TLB / 特权级与中断硬件，回答"硬件之上第一层软件如何隔离与复用资源"。全程 Windows 11 与 Ubuntu 24.04 双平台对照。

## 目录

### [01-操作系统概述](./01-操作系统概述.md)
特权隔离与资源复用的约束、内核态/用户态分界、NT 与 Linux 两大谱系

### [02-系统调用与中断](./02-系统调用与中断.md)
用户态→内核态通道、syscall 路径双平台对照、中断向量与上下文切换账本

### [03-进程与线程](./03-进程与线程.md)
进程=资源容器、线程=调度实体、创建/销毁/调度、IPC 总览

### [04-虚拟内存管理](./04-虚拟内存管理.md)
虚拟地址空间、缺页调页、内存映射、交换与回收

### [05-文件系统](./05-文件系统.md)
VFS 抽象、ext4 与 NTFS、inode 与目录树、挂载与路径解析

### [06-IO与设备管理](./06-IO与设备管理.md)
驱动与内核模块、块/字符设备、页缓存、同步与异步 IO

### [07-系统启动](./07-系统启动.md)
上电→UEFI→引导加载器→内核→systemd→登录会话，Shell 的诞生

### [08-移动操作系统](./08-移动操作系统.md)
Android（Linux+ART）、iOS（XNU）、移动沙箱与权限模型

## 学习路径

1. **先概述**：建立内核态/用户态分界与双平台谱系
2. **再系统调用与中断**：理解用户态进入内核的唯一通道
3. **再进程与线程**：理解 OS 调度与隔离的基本单位
4. **再虚拟内存**：承接 01-计算机体系 的地址翻译，理解 OS 一侧的管理
5. **再文件系统与 IO**：理解持久化与设备抽象
6. **后系统启动**：把全章串成一条从上电到 Shell 的时序因果链
7. **最后移动操作系统**：看同套机制在移动端的裁剪
