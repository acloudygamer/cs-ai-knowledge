# 操作系统

> **版本基准**: universal（Windows 11 / Ubuntu 24.04 双平台对照）

本章建立在 01-计算机体系 之上：硬件已经把「地址怎么翻译、特权怎么分档、中断怎么汇流」定死，本章回答**内核如何在这套硬件上兑现隔离与复用**——用户态进内核只剩三条竖井，进程与线程是两套记账，虚拟内存是页表树的所有者，文件系统是持久字节的名字层，IO 是设备与页缓存的搬运层，而启动篇把以上全部串成一条从复位向量到登录 Shell 的时序链。

### [05-文件系统](./05-文件系统.md)

### [06-IO与设备管理](./06-IO与设备管理.md)

### [07-系统启动](./07-系统启动.md)

### [08-移动操作系统](./08-移动操作系统.md)

## 两条归属硬规则

- **页缓存**：`页↔映射`（VMA、缺页、COW、回收）归 04 篇；`页↔设备`（脏页回写、块层、驱动队列）归 06 篇。两篇各用一句话引用另一篇，不重复展开。
- **虚拟化与权限**：容器 namespace/cgroups 归 06 章 05 篇，安全模型归 06 章 09 篇；本章只在 01 §4 与 06 各留一句结论引用，不新增篇目。

## 学习路径

1. **先概述**：建立两个平面与唯一竖井，看清 `U/S` 位吞掉中间档的原因。
2. **再系统调用与中断**：用户态进内核只有一条通道，账本全在这条路上结算。
3. **再进程与线程**：调度实体与资源容器分开记账，同步成本落在缓存行与屏障上。
4. **再虚拟内存**：承接 01 章的地址翻译，换成 OS 一侧的所有者视角。
5. **再文件系统与 IO**：持久字节的名字层，以及它和页缓存、块层的三条边。
6. **后系统启动**：把以上全部压进一条从复位向量到 Shell 的时序链。
7. **最后移动操作系统**：看同一套机制在电量、热、不可信应用三重约束下被削成什么样。
