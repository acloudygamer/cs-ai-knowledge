# 编程运行环境

本部分涵盖编程语言运行时的基础知识，包括编译器、解释器、运行时、虚拟机等核心概念。

## 目录

### [01-编译型与解释型语言](./01-编译型与解释型语言.md)
编译原理、GCC/LLVM 架构、解释执行机制、REPL、字节码解释

### [02-运行时与虚拟机](./02-运行时与虚拟机.md)
程序加载、符号解析、库加载过程、JVM、进程虚拟机与系统虚拟机

### [03-Node.js运行时](./03-Node.js运行时.md)
V8 引擎、事件循环、libuv

### [04-垃圾回收](./04-垃圾回收.md)
GC 算法、内存管理、泄漏检测

## 学习路径

1. **先编译型与解释型语言**：理解源代码如何被翻译和执行
2. **再运行时与虚拟机**：了解程序运行时的加载和链接
3. **后Node.js运行时**：深入理解 V8 引擎和事件循环
4. **最后垃圾回收**：掌握内存管理核心概念
