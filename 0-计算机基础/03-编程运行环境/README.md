# 编程运行环境

> **版本基准**: universal

## 定义

编程运行环境是程序从源码到可执行、再到 CPU 指令流的完整支撑体系，包括编译器/解释器的翻译层、加载器/链接器的加载层、以及内存管理与线程调度的运行时层。

## 目录

### [01-编译型与解释型语言](./01-编译型与解释型语言.md)
编译原理、GCC/LLVM 架构、解释执行机制、REPL、字节码解释

### [02-运行时与虚拟机](./02-运行时与虚拟机.md)
程序加载、符号解析、库加载过程、进程虚拟机与系统虚拟机、垃圾回收

### [03-Node.js运行时](./03-Node.js运行时.md)
V8 引擎、事件循环、libuv

## 学习路径

1. **先编译型与解释型语言**：理解源代码如何被翻译和执行
2. **再运行时与虚拟机**：了解程序运行时的加载、链接和内存管理
3. **后Node.js运行时**：深入理解 V8 引擎和事件循环
