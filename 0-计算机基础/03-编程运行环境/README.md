# 编程运行环境

本部分涵盖编程语言运行时的基础知识，包括编译器、解释器、运行时、虚拟机等核心概念。

## 目录

### [01-编译器](./01-编译器.md)
编译原理、GCC/LLVM 架构、静态链接与动态链接

### [02-解释器](./02-解释器.md)
解释执行机制、REPL、字节码解释

### [03-运行时](./03-运行时.md)
程序加载、符号解析、库加载过程

### [04-虚拟机](./04-虚拟机.md)
JVM、进程虚拟机与系统虚拟机

### [05-Node.js运行时](./05-Node.js运行时.md)
V8 引擎、事件循环、libuv

### [06-垃圾回收](./06-垃圾回收.md)
GC 算法、内存管理、泄漏检测

## 学习路径

1. **先编译器**：理解源代码如何被翻译
2. **再解释器**：掌握解释执行机制
3. **后运行时**：了解程序运行时的加载和链接
4. **最后扩展**：虚拟机、Node.js 运行时、垃圾回收
