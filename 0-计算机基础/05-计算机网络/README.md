# 计算机网络

> **版本基准**: universal

本章建立在 02-操作系统 之上：消费其 IO 模型与进程机制，回答"进程如何跨机器通信"。按 TCP/IP 分层自底向上推进，最后回到编程接口。

全章按依赖拓扑排序，后篇消费前篇的机制如下：

| 篇目 | 消费的前置机制 |
|------|----------------|
| 01 网络分层模型 | 01-计算机体系 05 的网络序；02-操作系统 的 fd 与协议栈进内核位置 |
| 02 IP与路由 | 01 的 IP 头位标尺与分层视角 |
| 03 TCP与UDP | 01 的逐跳投递与端口复用；02-操作系统 的进程与 socket 缓冲区 |
| 04 DNS域名系统 | 03 的 UDP 可靠性取舍、02 的层级路由 |
| 05 HTTP协议 | 03 的字节流投递、04 的域名解析 |
| 06 HTTPS与TLS | 05 的报文语义、03 的 TCP 字节流 |
| 07 Socket编程 | 02-操作系统 的 fd 表与 IO 模型；本卷 02/03/04 的寻址与协议语义 |

下游卷对本章的消费：06-软件工程概念 消费 03/05/06 的协议语义（微服务通信、API 契约、传输安全）与 07 的 IO 多路复用底座。

## 学习路径

1. **先分层模型**：建立封装与切分的全局视角
2. **再 IP 与路由**：理解分组如何跨网到达
3. **再 TCP 与 UDP**：理解端到端可靠性的来源与代价
4. **再 DNS 与 HTTP/TLS**：理解应用层如何消费传输层
5. **最后 Socket 编程**：回到内核接口，把全章落到代码
