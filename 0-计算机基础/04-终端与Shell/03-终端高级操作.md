# 终端高级操作

## 定义

**终端多路复用器在单个终端进程内管理多个独立会话(Session)，会话可后台运行，断连不丢失状态。**

## 数学模型

tmux/screen维护三级层级结构：

```
Session ──► Window ──► Pane
  │            │
  │            └── 多个Pane (垂直/水平分割)
  └── 独立Shell进程树
```

会话状态持久化：会话内容写入磁盘分区(detach时)，恢复时重新attach。

## 数据流

<pre>
用户终端 → tmux server (后台进程)
              │
              ├── Window 0: pts/N (bash)
              │       └── Pane 0: bash
              │       └── Pane 1: vim
              └── Window 1: pts/M (ssh)
                      └── Pane 0: ssh session
</pre>

**数据形态变换**：

| 阶段 | 数据形态 |
|------|----------|
| tmux客户端 | 终端字节流(ANSI转义序列) |
| tmux server | 结构化Pane内容 |
| 持久化文件 | 二进制会话快照 |

## 机制

### 会话生命周期

```
tmux new -s name    创建会话 → fork bash
Ctrl+b d            断开会话(后台运行)
tmux detach        同上
tmux attach -t name 重新连接
tmux kill-session   销毁会话
```

**约束**：tmux server常驻后台，kill-server销毁所有会话。

**违规后果**：断连后若不detach，会话仍运行但无法交互。

### 窗口与面板

| 操作 | tmux | screen |
|------|------|--------|
| 创建窗口 | Ctrl+b c | Ctrl+a c |
| 切换窗口 | Ctrl+b n/p | Ctrl+a n/p |
| 垂直分割 | Ctrl+b % | Ctrl+a \| |
| 水平分割 | Ctrl+b " | Ctrl+a S |
| 切换Pane | Ctrl+b o | Ctrl+a tab |

**约束**：关闭Pane仅关闭该区域进程，不影响Window其他Pane。

### 复制模式

tmux/scrollback buffer内容通过复制模式访问：

```
Ctrl+b [         进入复制模式 (tmux)
Ctrl+a [         进入复制模式 (screen)
  PgUp/PgDn      滚动
  q              退出
```

**约束**：复制模式内只能读不能交互，需退出后才能操作终端。

### 配置加载

tmux读取~/.tmux.conf，screen读取~/.screenrc，均在启动时加载：

```bash
# tmux 配置 ~/.tmux.conf
set -g prefix C-a        # 改前缀键
set -g base-index 1       # 窗口从1编号
set -g mouse on           # 鼠标操作(tmux ≤2.8)

# screen 配置 ~/.screenrc
defutf8 on               # 默认UTF-8
shell -$SHELL            # 使用当前Shell
```

### 同步面板

同一Window内所有Pane执行相同命令，用于多主机并行操作：

```
Ctrl+b :set synchronize-panes on   # tmux开启同步
Ctrl+a :set synchronise on        # screen开启同步
```

**约束**：同步开启后所有Pane输入相同，仅当需要多终端执行同一命令时使用。

## 参考存根

```bash
tmux new -s session -d     # 后台创建会话
tmux lsc                   # 列出所有会话
tmux splitw -h -t 0        # 水平分割Window 0
screen -S name             # 创建命名会话
screen -r name             # 恢复断开会话
```
