tmux 3.4-1build1, screen 4.9.1-1ubuntu1, fish 3.7.0-1（Ubuntu 24.04 LTS 仓库版本；bash 为系统默认Shell）。Windows Terminal (Windows 11) 内置多标签支持但非多路复用器。

## 解决什么问题

远程SSH会话断开会导致工作丢失。终端多路复用器在单个终端中管理多个会话、窗口和面板，断开连接不丢失状态，适合远程工作和多任务并行。

## 核心概念

- 会话(Session)：独立的工作环境，可后台运行
- 窗口(Window)：一个会话内的多个终端页面
- 面板(Pane)：一个窗口内的多区域分割
- 前缀键：tmux用`Ctrl+b`，screen用`Ctrl+a`

## 怎么用

### tmux 基础

```bash
tmux new -s mysession     # 创建会话
Ctrl+b d                  # 断开会话
tmux attach -t mysession # 重新连接
```

### screen 基础

```bash
screen -S mysession      # 创建会话
Ctrl+a d                  # 断开会话
screen -r mysession      # 重新连接
```

## tmux 详细操作

### 会话管理

```bash
tmux ls                  # 列出所有会话
tmux kill-session -t mysession  # 杀死会话
tmux rename-session -t 0 newname  # 重命名
```

### 窗口操作

```bash
Ctrl+b c          # 创建新窗口
Ctrl+b ,          # 重命名当前窗口
Ctrl+b n/p        # 下一个/上一个窗口
Ctrl+b 0-9        # 切换到指定窗口
```

### 面板操作

```bash
Ctrl+b %          # 垂直分割
Ctrl+b "          # 水平分割
Ctrl+b o          # 切换面板
Ctrl+b x          # 关闭面板
Ctrl+b 方向键     # 按方向切换
```

### 配置示例

```bash
# ~/.tmux.conf
set -g prefix C-a        # 改前缀为Ctrl+a
unbind C-b
bind C-a send-prefix
set -g mouse on          # 鼠标支持 (tmux 2.1+; 旧版用 set -g mode-mouse on)
set -g base-index 1      # 窗口从1开始编号
set -g default-terminal "tmux-256color"  # 确保终端支持256色
```

### 复制模式

```bash
Ctrl+b [              # 进入复制模式
PgUp/PgDown          # 滚动
q                   # 退出
# 建议配合 setw -g mode-keys vi 使用vi风格
```

### 同步面板

```bash
Ctrl+b :set synchronize-panes on  # 同时在所有面板执行相同命令
```

## screen 详细操作

```bash
Ctrl+a S              # 水平分割
Ctrl+a |              # 垂直分割（部分Linux发行版默认不支持，需配置）
Ctrl+a tab            # 切换区域
Ctrl+a X              # 关闭当前区域
```

## tmux vs screen

| 特性 | tmux | screen |
|------|------|--------|
| 状态栏 | 内置 | 需配置 |
| 配置 | .tmux.conf | .screenrc |
| 开发活跃度 | 活跃 | 低活跃度（维护模式） |
| 鼠标支持 | 较好 | 一般 |

## 终端定制

### PS1 提示符

```bash
# 常用转义序列
\u    # 用户名
\h    # 主机名
\w    # 当前目录
\$    # 提示符(#为root)
\t    # 时间

# 彩色提示符
# \e[32m 绿色 \e[34m 蓝色 \e[0m 重置颜色
export PS1='\[\e[32m\]\u@\h\[\e[0m\]:\[\e[34m\]\w\[\e[0m\]\$ '
```

### 配置文件加载顺序

```bash
# bash
~/.bash_profile  # 登录shell
~/.bashrc         # 非登录shell
```

## 终端录制

### asciinema

```bash
asciinema rec           # 录制
asciinema rec file.json # 保存到文件
asciinema play file.json # 播放
```

### script

```bash
script -t timing.log -a session.log  # 录制
scriptreplay timing.log session.log  # 回放
```

## 实用技巧

### 后台保持连接

```bash
# tmux自动启动
if command -v tmux &>/dev/null && [ -z "$TMUX" ]; then
    tmux attach || tmux new-session
fi

# nohup后台运行
nohup ./script.sh &
```
