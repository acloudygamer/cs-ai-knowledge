# 终端高级操作

## 概念

**终端多路复用器**（Terminal Multiplexer）是在单个终端中管理多个会话、窗口和面板的工具。常用工具包括 tmux 和 screen。

## 关系

**关键连接**：
- 多路复用器 → **会话**：创建持久会话，断开连接不丢失状态
- 多路复用器 → **窗口**：在单一终端中创建多个窗口
- 多路复用器 → **面板**：将窗口分割为多个可交互区域
- 远程连接 → **多路复用器**：保持远程会话持续运行

## tmux

### 基础概念

```bash
# 安装
sudo apt install tmux      # Debian/Ubuntu
brew install tmux          # macOS

# 启动会话
tmux                       # 新建默认会话
tmux new -s mysession      # 新建命名会话
tmux attach -t mysession   # 接入已存在会话
tmux switch -t mysession   # 切换会话
```

### 会话管理

```bash
# 列出所有会话
tmux list-sessions
tmux ls

# 断开会话（后台运行）
# 按 Ctrl+b d

# 重命名会话
tmux rename-session -t 0 websession

# 杀死会话
tmux kill-session -t mysession

# 在会话内执行命令
tmux send-keys -t mysession "ls" C-m
```

### 窗口管理

```bash
# 按 Ctrl+b c  创建新窗口
# 按 Ctrl+b ,  重命名当前窗口
# 按 Ctrl+b &  关闭当前窗口

# 切换窗口
Ctrl+b n      # next window
Ctrl+b p      # previous window
Ctrl+b 0-9    # 切换到指定编号窗口
Ctrl+b l      # last window
```

### 面板操作

```bash
# 按 Ctrl+b %  垂直分割
# 按 Ctrl+b "  水平分割
# 按 Ctrl+b x  关闭当前面板

# 切换面板
Ctrl+b o                # 切换到下一个面板
Ctrl+b 方向键           # 按方向切换
Ctrl+b ;                # 切换到上次使用的面板

# 调整面板大小
Ctrl+b Alt+方向键       # 每次调整一行
Ctrl+b Ctrl+方向键      # 每次调整五行

# 交换面板位置
Ctrl+b {                # 当前面板与上一个交换
Ctrl+b }                # 当前面板与下一个交换
```

### tmux 配置

```bash
# 配置文件位置
~/.tmux.conf

# 常用配置示例
cat > ~/.tmux.conf << 'EOF'
# 设置前缀为 Ctrl+a（更符合习惯）
set -g prefix C-a
unbind C-b
bind C-a send-prefix

# 开启鼠标支持
set -g mouse on

# 设置面板从1开始编号（更直观）
set -g base-index 1
setw -g pane-base-index 1

# 支持鼠标选择和复制
set -g mouse on
bind -n WheelUpPane if-shell -F -t = "#{mouse_any_flag}" "send-keys -M" "if -Ft= '#{pane_in_mode}' 'send-keys -M' 'copy-mode -e'"

# 快速重新加载配置
bind r source-file ~/.tmux.conf \; display "Config reloaded!"

# 启用256色
set -g default-terminal "screen-256color"

# 设置状态栏颜色
set -g status-bg colour235
set -g status-fg colour255

# 窗口列表颜色
setw -g window-status-current-bg colour39
setw -g window-status-current-fg colour0

# 面板边框颜色
set -g pane-border-bg default
set -g pane-border-fg colour39

# 活跃面板边框颜色
set -g pane-active-border-bg colour39
set -g pane-active-border-fg colour39
EOF

# 重新加载配置
tmux source-file ~/.tmux.conf
```

### 复制模式

```bash
# 进入复制模式
Ctrl+b [

# 操作
PgUp/PgDown    # 上下滚动
/              # 向前搜索
?              # 向后搜索
n              # 下一个匹配
N              # 上一个匹配
q              # 退出复制模式

# vi 风格导航
setw -g mode-keys vi
# h j k l 移动
# w/b 按单词移动
# ^/$ 移动到行首/行尾
# gg/G 跳到开头/结尾
```

### 同步面板

```bash
# 在所有面板中同时执行相同命令
Ctrl+b :
set synchronize-panes on

# 关闭同步
set synchronize-panes off

# 实用场景：同时在多台服务器执行相同操作
```

## screen

### 基础命令

```bash
# 安装
sudo apt install screen

# 启动screen
screen                          # 创建默认会话
screen -S mysession             # 创建命名会话
screen -ls                      # 列出所有会话
screen -r mysession             # 恢复会话
screen -d mysession             # 分离会话
screen -d -r mysession          # 远程分离后恢复
```

### 常用快捷键

```bash
# Ctrl+a d  分离会话
# Ctrl+a c  创建新窗口
# Ctrl+a n  下一个窗口
# Ctrl+a p  上一个窗口
# Ctrl+a "  列出并选择窗口
# Ctrl+a k  关闭当前窗口
# Ctrl+a \  关闭所有窗口并终止screen

# 窗口内部分屏
Ctrl+a S     # 水平分割
Ctrl+a |     # 垂直分割
Ctrl+a tab   # 切换区域
Ctrl+a X     # 关闭当前区域
```

## 终端定制

### PS1 定制

```bash
# 查看当前提示符
echo $PS1

# 常用转义序列
\d    # 当前日期（星期月日）
\t    # 当前时间（HH:MM:SS）
\w    # 当前工作目录（完整路径）
\W    # 当前工作目录（仅目录名）
\u    # 用户名
\h    # 主机名（不含域名）
\H    # 完整主机名
\$    # 提示符（#为root，$为普通用户）
\n    # 换行
\\    # 反斜杠

# 颜色设置
# 格式：\[\e[颜色码m\]
# 颜色：30-37（前景色），40-47（背景色）

# 常用颜色
# 30=黑 31=红 32=绿 33=黄 34=蓝 35=紫 36=青 37=白

# 示例：带颜色的提示符
export PS1='\[\e[32m\]\u@\h\[\e[0m\]:\[\e[34m\]\w\[\e[0m\]\$ '

# 更完整的彩色提示符
export PS1='\[\e[01;32m\]\u@\h\[\e[0m\] \[\e[01;34m\]\w\[\e[0m\] \[\e[01;33m\]\t\[\e[0m\]\$ '

# git 分支支持（需要 git-completion 或 oh-my-zsh）
parse_git_branch() {
    git branch 2>/dev/null | grep '*' | sed 's/* //'
}

export PS1='\[\e[01;32m\]\u@\h\[\e[0m\]:\[\e[01;34m\]\w\[\e[0m\]\[\e[01;36m\]$(parse_git_branch)\[\e[0m\]\$ '
```

### 终端配置文件

```bash
# ~/.bashrc - 每次打开新shell时执行（非登录shell）
# ~/.bash_profile - 登录shell执行
# ~/.bash_login - 如果.bash_profile不存在则执行
# ~/.profile - 如果以上都不存在则执行

# macOS: 终端.app 默认执行 ~/.bashrc（需配置）
# Linux: 桌面环境通常执行 ~/.profile

# 常用配置项
export PATH="$HOME/bin:$PATH"           # 添加PATH
export EDITOR=vim                        # 默认编辑器
export VISUAL=vim                        # 视觉编辑器
alias ll='ls -lahF'                      # 命令别名
alias ..='cd ..'                         # 快捷目录切换
```

### 环境变量

```bash
# 查看所有环境变量
env
printenv

# 查看特定变量
echo $PATH
printenv HOME

# 设置临时变量（当前会话）
export VAR_NAME="value"

# 设置永久变量（需添加到配置文件）
echo 'export VAR_NAME="value"' >> ~/.bashrc
source ~/.bashrc

# 多值变量
export PATH="/usr/local/bin:$PATH"
export LD_LIBRARY_PATH="/usr/local/lib:$LD_LIBRARY_PATH"
export MANPATH="/usr/local/share/man:$MANPATH"
```

## 终端录制与回放

### asciinema（终端录制）

```bash
# 安装
sudo apt install asciinema        # Debian/Ubuntu
brew install asciinema            # macOS
pip install asciinema            # pip

# 录制终端会话
asciinema rec                    # 开始录制（Ctrl+Shift+d 结束）
asciinema rec demo.json          # 保存为文件

# 上传到 asciinema.org
asciinema rec                    # 录制后自动上传
asciinema upload demo.json       # 上传已有文件

# 本地播放
asciinema play demo.json

# 嵌入网页
# <script src="https://asciinema.org/a/XXXXX.js" id="asciinema-XXXXX" async></script>
```

### script 命令

```bash
# 录制完整终端会话（包括-timing文件）
script -t 2 timing.log session.log

# 回放会话
scriptreplay timing.log session.log

# 仅录制命令（不包含输出延迟）
script -q session.log

# 录制并追加
script -a session.log

# 常见用法：记录安装过程
script -c "sudo apt install nginx" install.log
```

### termtosvg

```bash
# 安装
pip install termtosvg

# 录制并导出为SVG
termtosvg recording.svg

# 录制命令
termtosvg -c "ls -la" recording.svg

# 停止录制
exit
```

### 实用场景

```bash
# 场景1：记录bug复现过程
script -t bug_reproduction.log bug_session.log
# 执行重现步骤
exit
# 发送给开发者

# 场景2：制作教程
asciinema rec tutorial.json
# 执行教学步骤
exit
# 上传到 asciinema.org 并嵌入文档

# 场景3：审计操作
script -t audit_$(date +%Y%m%d_%H%M%S).log
# 执行需要审计的操作
exit
```

## 实用技巧

### 终端复用进阶

```bash
# tmux 保持连接（防止断开）
# 编辑 ~/.tmux.conf 添加
set -g remain-size on exit 0

# 自动启动 tmux（登录时自动进入）
# 添加到 ~/.bash_profile
if command -v tmux &>/dev/null && [ -z "$TMUX" ]; then
    tmux attach || tmux new-session
fi

# screen 同名会话（防止重复创建）
screen -S mysession -X quit 2>/dev/null
screen -S mysession
```

### 作业控制

```bash
# Ctrl+z  挂起当前作业
# jobs    列出所有作业
# fg      恢复前台作业
# bg      后台恢复挂起作业
# nohup   忽略挂断信号运行命令

# 示例：后台运行并保持
nohup ./long_running_script.sh &
disown

# 或者使用 tmux/screen
tmux new -d -s myscript './long_running_script.sh'
```

### 终端复用器对比

| 特性 | tmux | screen |
|------|------|--------|
| 状态栏 | 内置 | 需配置 |
| 窗口分割 | 支持 | 支持 |
| 复制模式 | vi风格 | Emacs风格 |
| 配置方式 | .tmux.conf | .screenrc |
| 活跃开发 | 是 | 有限 |
| 跨平台 | 良好 | 良好 |
| 鼠标支持 | 较好 | 一般 |

## 故障排除

```bash
# tmux 显示乱码
# 确认终端编码为 UTF-8
export LC_ALL=en_US.UTF-8
export LANG=en_US.UTF-8

# tmux 状态栏显示异常
set -g default-terminal "screen-256color"

# screen 无法创建新窗口
# 检查是否有足够的pty
ls -la /dev/pts/

# tmux/screen 快捷键不响应
# 确认前缀键是否按下
# tmux 默认前缀：Ctrl+b
# screen 默认前缀：Ctrl+a
```
