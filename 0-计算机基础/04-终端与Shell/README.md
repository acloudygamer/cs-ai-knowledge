# 终端与 Shell

> **版本基准**: universal

本部分讲用户与系统交互的最外层：从指尖敲键到命令执行。核心是把两个常被混为一谈的角色拆开——**终端是字节流通道，shell 是通道那端的普通进程**。

## 目录

### [01-终端与伪终端](./01-终端与伪终端.md)
通道本身：电传打字机（TTY）的历史遗物、pty 对（master/slave）、终端模拟器/ssh/tmux 同一抽象、行规的规范模式与原始模式、Ctrl-C 由 tty 驱动转发 SIGINT 的真相、转义序列与 isatty

### [02-Shell工作机制](./02-Shell工作机制.md)
通道那端的进程：REPL 循环、fork+exec 执行链、shebang 的内核机制、展开的精确顺序与引号语义、管道/重定向的 fd 手术（dup2）、内建命令的约束、进程组与作业控制、退出码

### [03-Shell编程](./03-Shell编程.md)
用层：变量与环境继承、退出码驱动的控制流、grep/sed/awk 管道组合模式、`set -euo pipefail` 防御三件套、高频陷阱的机制根源、何时换 Python

## 阅读顺序

按编号即依赖顺序：01 建通道（tty/pty 是内核设施）→ 02 讲通道那端的程序如何执行命令（机制）→ 03 讲如何用这套机制写程序（用）。前置依赖是 02-系统软件层：进程、信号、文件描述符、系统调用都在那里定义。
