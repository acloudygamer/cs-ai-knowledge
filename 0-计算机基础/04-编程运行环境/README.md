# 编程运行环境

> **版本基准**: universal（Windows 11 / Ubuntu 24.04）

本章建立在 02-操作系统 与 03-终端与Shell 之上：消费其虚拟内存、进程与工具链机制，回答"源代码如何变成正在运行的进程"。

## 目录

### [01-编译与解释](./01-编译与解释.md)
编译流水线、解释执行与字节码、JIT 与 AOT 光谱

### [02-链接与装载](./02-链接与装载.md)
ELF vs PE、符号解析、动态链接 PLT/GOT、装载即内存映射

### [03-运行时与虚拟机](./03-运行时与虚拟机.md)
运行时=进程内的操作系统、JVM/CLR、CPython/V8、GC 的内存主权

## 学习路径

1. **先编译与解释**：理解源代码到目标代码的变换
2. **再链接与装载**：理解目标代码如何拼成进程映像
3. **后运行时与虚拟机**：理解托管与解释型语言在进程内再建一层的原因
