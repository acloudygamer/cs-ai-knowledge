# 操作系统概述

## 解决什么问题

程序不能直接访问硬件，需要操作系统作为中间层：管理CPU时间片分配、内存地址空间、文件读写、设备交互。操作系统让多个程序共享硬件却互不干扰，并提供统一的系统调用接口。

## 核心概念

- **内核**：操作系统的核心，运行在特权模式，直接管理硬件
- **系统调用**：用户程序请求内核服务的接口（如 read、write、fork）
- **进程**：程序的运行实例，拥有独立的内存空间
- **虚拟内存**：每个进程看到连续的地址空间，实际映射到物理内存
- **内核类型**：宏内核（Linux）、微内核（Minix）、混合内核（Windows/macOS）

```
┌─────────────────────────────────────┐
│           用户应用程序               │
├─────────────────────────────────────┤
│            操作系统                  │
│  ┌───────────────────────────────┐  │
│  │  用户界面(Shell/GUI)          │  │

│  │  内核(进程/内存/文件/设备)    │  │

├─────────────────────────────────────┤

└─────────────────────────────────────┘
```

## 怎么用

### 操作系统职能

| 职能 | 说明 | 相关概念 |
|------|------|----------|
| 进程管理 | 创建、调度、终止进程 | 进程、线程、调度器 |
| 内存管理 | 分配/回收内存，虚拟内存 | 页面置换、内存分配器 |
| 文件系统 | 管理文件的存储和访问 | inode、目录、权限 |
| 设备管理 | 驱动程序，与硬件通信 | 中断、I/O、DMA |
| 安全与权限 | 用户认证、访问控制 | 用户、组、ACL |

### 内核类型对比

| 类型 | 特点 | 示例 |
|------|------|------|
| **宏内核** | 所有功能在内核中，通信快 | Linux, Unix |
| **微内核** | 只保留核心功能，其他在用户空间 | Minix, QNX |
| **混合内核** | 宏内核+微内核折中 | Windows NT, macOS XNU |

### 系统调用示例

```c
// Linux 系统调用示例
#include <unistd.h>

int main() {
    // write 是系统调用
    const char* msg = "Hello, OS!\n";
    write(STDOUT_FILENO, msg, 13);  // sys_write

    // read 是系统调用
    char buf[100];
    read(STDIN_FILENO, buf, 100);   // sys_read

    _exit(0);                        // sys_exit
}
```

**系统调用 vs 函数调用**：

| 调用类型 | 执行位置 | 特权级别 |
|----------|----------|----------|
| 普通函数调用 | 用户空间 | 用户态 |
| 系统调用 | 内核空间 | 内核态 |

### OS 启动流程

```
BIOS/UEFI → 引导扇区 → 内核加载 → init/systemd → 用户空间
    ↓           ↓           ↓           ↓              ↓
  硬件自检    MBR/GPT    内存初始化   启动系统服务    登录界面
```

```bash
# Linux 查看启动日志
dmesg                    # 内核环缓冲区消息
journalctl -b            # systemd本次启动日志
systemctl list-units     # 查看所有系统服务单元
```

### 常见操作系统

| OS | 内核 | 特点 | 应用场景 |
|----|------|------|----------|
| Linux | Linux | 开源、多平台 | 服务器、嵌入式、Android |
| Windows | Windows NT | 闭源、生态好 | PC、企业 |
| macOS | XNU (Mach+BSD) | Unix兼容 | Apple设备 |
| Android | Linux | 移动端霸主 | 手机、平板 |
| iOS | XNU | 闭源、严格权限 | iPhone/iPad |
