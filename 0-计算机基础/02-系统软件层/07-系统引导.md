# 系统引导

## 定义

系统引导是从上电到操作系统内核完全加载并执行第一个用户进程的过程。

## 数学模型

BIOS/UEFI 跳转向量：

$$
\text{CS:IP} = 0xFFFF0 \quad \text{(BIOS)} \quad \text{或} \quad \text{UEFI} \xrightarrow{\text{PE/COFF}} \text{EFI入口}
$$

## 数据流

<pre>
上电 (PWR)
    │
    ▼
┌─────────────┐
│  CPU 复位   │  寄存器初始化，CS:IP = 0xFFFF0
└──────┬──────┘
       │
       ▼
┌─────────────┐
│   BIOS/     │  POST 自检，查找启动设备
│   UEFI      │  BIOS: 读取 MBR
└──────┬──────┘  UEFI: 读取 GPT + EFI 分区
       │
       ▼
┌─────────────┐
│  Bootloader │  GRUB/systemd-boot/rEFInd
│  (Stage 1/2)│  加载内核 + initramfs
└──────┬──────┘
       │
       ▼
┌─────────────┐
│   initramfs │  临时根文件系统
│   执行 /init │  挂载真正根文件系统
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ start_kernel│  Linux 内核入口
│ → init进程  │  PID 1，init/systemd
└─────────────┘
</pre>

数据形态变换：
- 磁盘引导扇区 → 内存（引导加载器）
- 内核镜像（压缩） → 解压到内存
- initramfs → pivot_root 切换根文件系统

## 机制

### MBR vs GPT

| 特性 | MBR | GPT |
|------|-----|-----|
| 磁盘容量限制 | 2TB | 16EB |
| 分区表位置 | LBA 0 | LBA 1 + LBA 2-33 |
| 分区数限制 | 4 主分区 | 128 分区 |
| 校验 | 0x55AA | CRC32 + 备份 |

**约束条件**：
- BIOS 只能从 MBR 启动
- UEFI 需要 GPT + EFI 分区

**违规后果**：
- MBR 损坏 → 系统无法启动
- GPT 分区表损坏 → 数据丢失风险

### UEFI Secure Boot

$$
\text{固件 DB} \xrightarrow{\text{验证签名}} \text{Bootloader} \xrightarrow{\text{验证签名}} \text{内核}
$$

未签名或签名不在 DB/DBX 中的引导程序将被拒绝执行。

**约束条件**：
- 密钥需在固件中注册
- 第三方 OS 可能需要关闭 Secure Boot
