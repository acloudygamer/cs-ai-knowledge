# 文件系统

## 定义

文件系统是将存储设备上的物理块组织为命名文件的逻辑抽象，提供按名访问和持久化存储。

## 数学模型

inode 直接块寻址（ext4，每块4KB）：

$$
\text{最大文件大小} = 12 \times 4\text{KB} + 256 \times 4\text{KB} + 65536 \times 4\text{KB} + 16777216 \times 4\text{KB} \approx 16\text{TB}
$$

虚拟文件系统（VFS）统一接口：

$$
\text{file\_operations} = \{open, read, write, release, \ldots\}
$$

应用程序

            │

    ▼               ▼

    │               │
    ▼               ▼

</pre>

数据形态变换：
- 字节流（应用） → 块号（VFS） → 扇区（设备驱动） → 闪存页/磁盘扇区（物理）

## 机制

### inode 结构

inode 存储文件的元数据（不含文件名）：

| 字段 | 说明 |
|------|------|
| mode | 文件类型 + 权限 |
| uid/gid | 所有者 |
| size | 文件大小 |
| atime/mtime/ctime | 时间戳 |
| block[15] | 直接/间接块指针 |

**约束条件**：
- inode 编号在文件系统中唯一
- 硬链接共享同一 inode

**违规后果**：
- 删除正在打开的文件 → 目录项移除，数据块保留直至文件句柄关闭

### 日志文件系统

ext4 日志保证一致性：

$$
\text{write} \xrightarrow{\text{记录}} \text{日志块} \xrightarrow{\text{提交}} \text{数据块} \xrightarrow{\text{标记}} \text{完成}
$$

崩溃恢复时：重放日志或回滚未提交事务。
