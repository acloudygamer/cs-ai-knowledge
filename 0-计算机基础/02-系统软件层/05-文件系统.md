# 文件系统

## 概念

**文件系统**是操作系统管理存储设备上的文件和目录的方法，提供了持久化存储的抽象。

```
┌─────────────────────────────────────────────────┐
│                   应用程序                        │
└────────────────────┬────────────────────────────┘
                     │ open/read/write
┌────────────────────▼────────────────────────────┐
│              VFS (虚拟文件系统)                    │
│   提供统一接口，屏蔽底层文件系统差异               │
└────────────────────┬────────────────────────────┘
                     │
    ┌────────────────┼────────────────┐
    │                │                │
┌───▼────┐      ┌────▼────┐      ┌───▼────┐
│  ext4  │      │  NTFS   │      │  APFS  │
│ Linux  │      │ Windows │      │  macOS │
└────────┘      └─────────┘      └────────┘
```

## 关系

**关键连接**：
- 文件系统 → **块设备**：文件系统读写存储设备上的数据块
- VFS → **具体文件系统**：ext4/xfs/btrfs 等实现统一接口
- inode → **磁盘块**：inode 存储文件数据块的指针
- 权限 → **用户/进程**：决定谁可以读写文件

## 文件系统类型

### Linux 文件系统

| 文件系统 | 特点 | 使用场景 |
|----------|------|----------|
| ext4 | 日志文件系统，向后兼容 | 主流 Linux 默认 |
| xfs | 高性能，大文件支持 | 企业级服务器 |
| btrfs | 写时复制，快照支持 | 需要高级特性 |
| tmpfs | 内存文件系统 | 临时文件，tmp目录 |

```bash
# 查看文件系统类型
df -T
# Filesystem  Type  1K-blocks     Used Available Use% Mounted on
# /dev/sda1   ext4  50000000  15000000  32000000  32% /

# 查看 inode 信息
df -i
```

### Windows 文件系统

| 文件系统 | 特点 | 限制 |
|----------|------|------|
| NTFS | 权限控制，日志，压缩 | 最大卷 256TB（与簇大小相关，实际取决于具体配置） |
| exFAT | 大文件支持，闪存优化 | 无日志，无权限 |
| FAT32 | 兼容性最好 | 最大文件 4GB |

### macOS 文件系统

| 文件系统 | 特点 |
|----------|------|
| APFS | 快照，加密，空间共享 |

## inode 与文件表示

**inode (索引节点)** 是文件系统的核心数据结构，存储文件的元数据：

```bash
# 查看文件 inode
ls -li file.txt
# 1310802 -rw-r--r-- 1 user group 4096 Apr 13 10:00 file.txt
# inode号  权限   链接数 owner group 大小    日期时间      文件名
```

**inode 包含的信息**：
```
┌─────────────────────────────────┐
│ inode 数据结构                   │
├─────────────────────────────────┤
│ inode 编号                      │
│ 文件类型 (普通文件/目录/链接)    │
│ 权限 (rwx for owner/group/other)│
│ 硬链接 计数                     │
│ 用户 ID (uid)                   │
│ 组 ID (gid)                     │
│ 文件大小                        │
│ 访问时间 (atime)                │
│ 修改时间 (mtime)                │
│ 状态改变时间 (ctime)            │
│ 数据块指针 (block[15])          │
└─────────────────────────────────┘
```

**文件数据块寻址**（ext4）：
- 直接块：block[0-11] 直接指向数据块（12个块，每个块大小如4KB）
- 一级间接块：block[12] 指向一个间接块，该间接块存储数据块指针（一级指针块）
- 二级间接块：block[13] 指向二级间接块，二级间接块中每个指针指向一个一级间接块
- 三级间接块：block[14] 指向三级间接块，三级间接块中每个指针指向一个二级间接块（用于超大文件寻址）

```bash
# 查看文件块分布
stat file.txt
# File: file.txt
# Size: 4096        Blocks: 8          IO Block: 4096   regular file
# Device: 08:01     Inode: 1310802     Links: 1
```

## 权限模型

### Unix 权限

```bash
# 权限表示
-rwxr-xr-- 1 owner group 4096 Apr 13 10:00 file.txt
# ↑ 权限位
# [0]  文件类型 (-=普通文件, d=目录, l=符号链接)
# [1-3] 所有者权限 (rwx)
# [4-6] 组权限 (r-x)
# [7-9] 其他用户权限 (r--)
```

| 权限位 | 数值 | 含义 |
|--------|------|------|
| r | 4 | 读 |
| w | 2 | 写 |
| x | 1 | 执行 |

```bash
# 修改权限
chmod 755 script.sh          # 八进制方式
chmod u+x script.sh          # 用户添加执行权限
chmod go-rwx secret.txt      # 移除组和其他的读写执行

# 修改所有者
chown user:group file.txt    # 改变文件所有者和组
```

### ACL (访问控制列表)

比传统 Unix 权限更细粒度：

```bash
# 查看 ACL
getfacl file.txt

# 设置 ACL
setfacl -m u:alice:rw file.txt      # 给 alice 读写权限
setfacl -m g:developers:rx /project  # 给组读执行权限
setfacl -x u:bob file.txt           # 移除 bob 的 ACL 条目
```

### 特殊权限

```bash
# SUID (运行时不改变身份)
-rwsr-xr-x 1 root root 16384 Apr 13 /usr/bin/passwd
#              ↑ s = SUID

# SGID (继承组属性)
drwxrwsr-x 2 root root 4096 Apr 13 /shared/project
#              ↑ s = SGID

# Sticky Bit (目录中只能删除自己的文件)
drwxrwxrwt 2 root root 4096 Apr 13 /tmp
#              ↑ t = Sticky Bit
```

## VFS (虚拟文件系统)

VFS 是 Linux 内核的抽象层，让用户程序无需关心底层文件系统差异：

```
应用程序
    ↓
系统调用 (open/read/write)
    ↓
VFS 层
    ↓
┌─────────────────────────────────────────┐
│  super_block    │   inode   │  dentry  │
│  (文件系统元数据) │ (文件元数据) │ (目录项) │
└─────────────────────────────────────────┘
    ↓
具体文件系统 (ext4/xfs/btrfs/NFS...)
```

**VFS 核心对象**：
- **super_block**：整个文件系统的元信息（总大小、块大小、挂载选项）
- **inode**：单个文件的元信息
- **dentry**：目录项，关联文件名和 inode
- **file**：打开的文件描述符

```bash
# 查看已挂载的文件系统
mount
# /dev/sda1 on / type ext4
# tmpfs on /tmp type tmpfs
# proc on /proc type proc

# 查看 VFS 缓存状态
cat /proc/sys/vm/drop_caches
```

## 目录结构

### Linux 目录树

```
/
├── /bin      # 基本命令
├── /boot     # 内核和启动文件
├── /dev      # 设备文件
├── /etc      # 系统配置文件
├── /home     # 用户主目录
├── /lib      # 共享库
├── /media    # 可移动媒体
├── /mnt      # 临时挂载点
├── /opt      # 可选应用
├── /proc     # 虚拟文件系统 (内核状态)
├── /root     # root 用户主目录
├── /sbin     # 系统管理命令
├── /tmp      # 临时文件
├── /usr      # 用户程序
└── /var      # 变量数据 (日志、缓存)
```

### Windows 盘符

```
C:\
├── \Users    # 用户目录
├── \Windows  # 系统目录
├── \Program Files    # 程序安装
└── \Program Files (x86)
```

## 日志文件系统

日志文件系统通过日志机制保证文件系统一致性：

```
┌─────────────────────────────────────┐
│ 日志文件系统工作流程                  │
├─────────────────────────────────────┤
│ 1. 写入操作记录到日志区              │
│ 2. 执行实际写操作                    │
│ 3. 标记日志条目为已完成              │
└─────────────────────────────────────┘
```

**ext4 日志模式**：
- `journal`：完整记录数据+元数据
- `ordered`：只记录元数据，数据写入在日志提交后
- `writeback`：只记录元数据，最快但不保证一致性

```bash
# 创建 ext4 文件系统
mkfs.ext4 -j /dev/sdb1

# 查看文件系统日志
tune2fs -l /dev/sda1 | grep -i journal
```

## 符号链接与硬链接

```bash
# 符号链接 (软链接) - 类似快捷方式
ln -s /path/to/target symlink
# -rw-r--r-- 1 user group 10 Apr 13 symlink -> /path/to/target

# 硬链接 - 同一个 inode 的多个目录项
ln /path/to/target hardlink
# 两个文件共享同一个 inode
```

| 特性 | 硬链接 | 符号链接 |
|------|--------|----------|
| 跨文件系统 | 否 | 是 |
| 链接目录 | 否 | 是 |
| 删除原文件 | 仍有引用 | 链接失效 |
| 存储方式 | 同一 inode | 目标路径 |

## 磁盘配额

```bash
# 启用配额
mount -o usrquota,grpquota /home

# 设置用户配额
edquota -u username
# Disk quotas for user username:
#   Filesystem  blocks  soft  hard  inodes  soft  hard
#   /dev/sda1    1000   5000  10000    100    200    300

# 查看配额使用
quota -u username
repquota -a
```

## 文件系统挂载

```bash
# 挂载设备

# 卸载设备
umount /mnt/usb

# 查看UUID

# /dev/sda1: UUID="abc123" TYPE="ext4"

# fstab 示例 (自动挂载)
# <file system>           <mount point>   <type>  <options>       <dump>  <pass>

```

## 性能优化

```bash
# 查看 I/O 统计
iostat -x 1
# %util 接近 100% 表示 I/O 瓶颈

# 查看文件碎片
filefrag -v file.txt

# 碎片整理 (ext4)
e4defrag /dev/sda1
e4defrag file.txt
```

## 常见问题

```bash
# 修复文件系统
fsck /dev/sda1

# 修复 ext4 日志
e2fsck -fy /dev/sda1

# 增大文件系统
resize2fs /dev/sda1

# 减小文件系统
resize2fs -M /dev/sda1
```
