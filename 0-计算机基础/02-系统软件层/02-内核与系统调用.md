# 内核与系统调用

## 定义

内核是操作系统中唯一运行在特权模式的组件，系统调用是用户态进程进入内核态的唯一入口。

## 数学模型

系统调用号作为索引查找内核函数表：

$$
\text{内核函数} = \text{sys\_call\_table}[\text{syscall\_number}]
$$

参数传递约定（x86_64）：
- RDI = 第1参数，RSI = 第2参数，RDX = 第3参数，R10 = 第4参数

## 数据流

<pre>
用户进程                    内核空间
┌─────────────┐         ┌────────────────────┐
│ syscall N   │ ──────► │ sys_call_table[N] │
│ args in     │         │                   │
│ registers   │         │ 处理: 文件/进程/   │
└─────────────┘         │ 内存/网络等        │
                        └────────────────────┘
                              │
                              ▼
                        返回值写入 RAX
                              │
                        ◄─────┘
```

数据形态变换：用户态指针（虚拟地址）→ 内核验证后 → 实际物理操作

## 机制

### 特权级别（Ring）

| Ring | 级别 | 用途 |
|------|------|------|
| Ring 0 | 特权 | 内核态，可执行任意指令 |
| Ring 3 | 用户 | 用户态，禁止敏感指令 |

**约束条件**：
- 用户态执行 `cli`（关中断）→ 保护异常
- 用户态访问内核内存区域 → 段错误

**违规后果**：CPU触发异常，内核可选择杀死进程或发送信号

### 中断/异常向量

| 向量 | 来源 | 触发条件 |
|------|------|---------|
| 0x80 (int 0x80) | 软件 | Linux 32位系统调用（旧） |
| 0x80 (syscall) | 软件 | Linux 64位系统调用 |
| 0x0D (#GP) | 硬件 | 权限检查失败 |
| 0x0E (#PF) | 硬件 | 页错误 |
