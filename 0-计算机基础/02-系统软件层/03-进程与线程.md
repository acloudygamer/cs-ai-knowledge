# 进程与线程

## 定义

进程是资源分配的基本单位，线程是CPU调度的基本单位；同一进程的线程共享地址空间，进程间地址空间隔离。

## 数学模型

进程虚拟地址空间布局：

$$
\text{进程虚拟空间} = \{\text{内核空间}\} \cup \{\text{用户空间}\}
$$

其中用户空间 = 栈 + 堆 + BSS + 数据段 + 代码段

线程调度优先级（Linux CFS）：

$$
\text{vruntime}_{\text{next}} = \text{vruntime}_{\text{curr}} + \frac{\text{period}}{\text{weight}}
$$

## 数据流

<pre>
进程A                              进程B
┌──────────────────┐            ┌──────────────────┐
│ 线程1: SP, PC, R │            │ 线程3: SP, PC, R │
├──────────────────┤            ├──────────────────┤
│ 线程2: SP, PC, R │            │                  │
├──────────────────┤            │ (独立虚拟空间)   │
│ 共享: 堆/代码/全局 │            │                  │
│ 文件描述符/信号    │            │                  │
└──────────────────┘            └──────────────────┘
        │                              │
        ▼                              ▼
    内核调度器 ◄─────────────────► 调度器
        │
        ▼
    CPU核心 (每次只执行一个线程)
</pre>

数据形态变换：
- fork() → 复制进程描述符 + 独立页表
- clone() → 共享部分地址空间（线程）

## 机制

### 进程状态机

```
        ┌─────────────────────────────────────────┐
        │                                         │
        ▼                                         │
    创建(new) ──► 就绪(ready) ◄────────────────┐  │
                              ▲                 │  │
                    调度器选择 │                 │  │
                              │                 │  │
                    就绪 ───► 运行(running) ──┘  │  │
                              │                   │  │
                    I/O阻塞/ │                   │  │
                    sleep/   │                   │  │
                    锁等待    │                   │  │
                              ▼                   │  │
                         阻塞(blocked) ──────────┘  │
                              │                   │
                              └───────────────────┘
                                        (wake up → ready)
```

**约束条件**：
- 同一进程的多个线程不可同时进入临界区
- 进程退出时需回收子进程（wait），否则僵尸

**违规后果**：
- 死锁 → 线程永久等待
- 僵尸进程 → 内核进程表项泄漏

### 线程同步原语

| 原语 | 用途 | 原子性 |
|------|------|--------|
| mutex | 互斥 | 是（硬件支持） |
| semaphore | 计数资源 | 是 |
| condition variable | 等待事件 | 需配合 mutex |
| spinlock | 自旋等待 | 是（关中断） |
