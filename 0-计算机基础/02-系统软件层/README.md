# 系统软件层

> **版本基准**: universal

本部分讲操作系统层：内核是什么、控制流如何进出内核、内核卖给应用的三大抽象（进程、地址空间、文件）、设备与 I/O，最后是时序起点（引导）与主线机制在移动端的变体。

组织逻辑：**约束 → 机制 → 变体**。先讲清每样东西为什么是这个形状（约束），再讲它如何工作（机制），移动端（08）只是同一批机制在新约束下的重新推导。

## 目录

### [01-操作系统概述](./01-操作系统概述.md)
OS 的定义与存在理由（多程序共享硬件 vs 硬件无保护）、内核态/用户态特权级、内核四大职能、宏/微/混合内核形态、虚拟化

### [02-系统调用与中断](./02-系统调用与中断.md)
进出内核的三扇门：系统调用（主动同步）、异常（被动同步：缺页、SIGSEGV 的来历）、中断（被动异步：顶/底半部、定时器心跳）、syscall 开销账与 vDSO/KPTI

### [03-进程与线程](./03-进程与线程.md)
第一抽象：资源容器 + 执行流。task_struct、fork/execve/COW、进程状态机、Linux 无线程对象、CFS/EEVDF 调度记账、上下文切换的账、futex 与内核锁

### [04-内存管理](./04-内存管理.md)
第二抽象：私有地址空间。VMA 布局、按需分页缺页链、伙伴系统与 slab、页面回收（LRU/kswapd/swap）、OOM killer

### [05-文件系统](./05-文件系统.md)
第三抽象：字节流与名字。VFS 四对象（superblock/inode/dentry/file）、ext4 extent、日志崩溃一致性、页面缓存与回写

### [06-IO与设备管理](./06-IO与设备管理.md)
第四职能：驱动模型与设备文件、DMA 协作协议、块层与 blk-mq、epoll/io_uring 的等待组织、零拷贝

### [07-系统引导](./07-系统引导.md)
时序起点：加电 → 固件（BIOS/UEFI、Secure Boot）→ Bootloader → 内核自举 → initramfs → PID 1。鸡与蛋约束的逐层解套

### [08-移动OS架构](./08-移动OS架构.md)
变体：Android（Binder、Zygote、ART、lmkd、UID 沙盒）与 iOS（XNU 混合内核、代码签名信任链）如何用移动端约束重新塑形主线机制

## 阅读顺序

按编号顺序即连接顺序：01 定位（OS 是什么）→ 02 入口（怎么进内核）→ 03/04/05 三大抽象（内核的产品）→ 06 数据进出 → 07 时序起点（要用前六篇的概念）→ 08 变体。
