# 系统软件层

本部分涵盖操作系统层的基础知识，包括内核、系统调用、进程线程、文件系统等核心概念。

## 目录

操作系统的职能、内核类型、常见操作系统

### [02-内核与系统调用](./02-内核与系统调用.md)
内核架构、系统调用接口、特权级别

### [03-进程与线程](./03-进程与线程.md)
进程管理、线程调度、同步原语

### [04-移动OS架构](./04-移动OS架构.md)

### [05-文件系统](./05-文件系统.md)

### [06-系统引导](./06-系统引导.md)

### [07-内存管理](./07-内存管理.md)

## 学习路径

1. **先概述**（01）：了解操作系统整体架构
2. **再内核**（02）：理解内核与系统调用机制
3. **后进程线程**（03）：掌握进程线程管理和同步
4. **再文件系统**（05）：理解持久化存储抽象
5. **再移动OS**（04）：了解移动端定制化操作系统
6. **再系统引导**（06）：理解从加电到内核启动的完整流程
7. **最后内存管理**（07）：掌握虚拟内存与页面置换
