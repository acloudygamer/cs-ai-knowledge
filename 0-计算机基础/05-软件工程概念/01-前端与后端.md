# 前端与后端

## 解决什么问题

用户直接看到的是前端（界面），但数据和处理逻辑在后端。前后端分离让开发团队可以并行工作，前端专注用户体验，后端专注业务逻辑和数据管理。

## 核心概念

- **前端**：用户直接交互的部分（HTML/CSS/JS、React/Vue）
- **后端**：服务器端处理数据和业务逻辑（Python/Go/Java + 数据库）
- **API**：前后端通信的契约，定义请求格式、响应结构
- **全栈**：一个开发者掌握前后端两端技术

## 怎么用

### 前后端交互架构

```
┌─────────────────────────────────────────────────┐
│                   用户                          │
└────────────────────┬──────────────────────────┘
                     │ 浏览器/App
┌────────────────────▼──────────────────────────┐
│              前端 (Frontend)                    │
│   HTML/CSS/JS 或 React/Vue/Flutter            │
└────────────────────┬──────────────────────────┘
                     │ HTTP/REST/gRPC
┌────────────────────▼──────────────────────────┐
│              后端 (Backend)                    │
│   Python/Go/Java/Node.js + 数据库            │
└────────────────────┬──────────────────────────┘
                     │
              ┌──────▼──────┐
              │   数据库     │
              │ MySQL/Redis  │
              └─────────────┘
```

### REST API 调用

```bash
# GET 请求
curl http://api.example.com/users

# POST 请求
curl -X POST http://api.example.com/users \
  -H "Content-Type: application/json" \
  -d '{"name":"Alice","email":"alice@example.com"}'

# 带认证
curl -H "Authorization: Bearer <token>" \
  http://api.example.com/protected
```

### Redis 缓存示例

```javascript
async function getUserWithCache(userId) {
    const cacheKey = `user:${userId}`;

    // 先查缓存
    const cached = await client.get(cacheKey);
    if (cached) {
        return JSON.parse(cached);
    }

    // 缓存未命中，查数据库
    const user = await db.users.findById(userId);

    // 写入缓存，过期时间 5 分钟
    await client.setEx(cacheKey, 300, JSON.stringify(user));

    return user;
}
```

### 前后端分离项目结构

```
my-app/
├── frontend/           # React/Vue 前端
│   ├── src/
│   │   ├── components/
│   │   ├── pages/
│   │   └── api/
│   ├── package.json
│
├── backend/             # Node.js/Python 后端
│   ├── src/
│   │   ├── routes/      # API 路由
│   │   ├── controllers/ # 业务逻辑
│   │   ├── models/      # 数据模型
│   │   └── middleware/  # 认证、日志
│   └── package.json
│
└── docker-compose.yml   # 统一部署
```

### 前后端分离优势

1. **独立开发**：前后端可并行开发
2. **独立部署**：前端静态资源可放CDN
3. **技术灵活**：前端用React，后端用Go
4. **移动支持**：同一API供App使用
