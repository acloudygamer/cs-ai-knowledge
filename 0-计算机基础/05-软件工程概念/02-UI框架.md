# UI框架

## 定义

UI框架是构建用户界面的组件化工具集，通过声明式语法描述视图，由框架运行时将描述转换为实际像素。

## 数学模型

UI渲染性能取决于帧率和单帧工作量：

$$
FPS = \frac{1}{T_{layout} + T_{paint} + T_{composite}}
$$

React/Vue 的虚拟DOM通过批量更新减少真实DOM操作次数，复杂度从 $O(n^3)$ 降至 $O(n)$。

## 数据流

<pre>
组件声明                  框架运行时                  渲染引擎                  屏幕像素
    │                        │                        │                        │
    │── JSX/Template ──────►│                        │                        │
    │   (声明式描述)          │                        │                        │
    │                        │── 虚拟DOM ───────────►│                        │
    │                        │   (内存结构)           │                        │
    │                        │                        │── 绘制命令 ────────────►│
    │                        │                        │   (光栅化指令)          │
    │                        │                        │                        │── 像素更新
</pre>

数据形态变换：`声明式语法(JSX/Template)` → `虚拟DOM(对象树)` → `差异计算` → `真实DOM操作` → `屏幕渲染`

## 机制

### 核心约束

1. **组件封闭性**：组件状态私有，外部通过Props传递数据
2. **单向数据流**：状态变化通过Action → Dispatch → Reducer → NewState 环更新视图
3. **声明式优先**：描述"什么"而非"如何"，框架负责实现细节

### 违规后果

- 外部直接修改组件内部状态导致不可预测渲染
- 双向绑定过度使用导致数据流混乱、调试困难
- 频繁状态变更未批处理导致过多重渲染

### 渲染模式对比

| 框架 | 渲染方式 | 更新粒度 | 性能特点 |
|------|----------|----------|----------|
| React | 虚拟DOM | 组件级 | 中等，需手动优化 |
| Vue | 虚拟DOM | 响应式追踪 | 较高，自动优化 |
| Svelte | 编译时优化 | 语句级 | 较高，无运行时 |
| Solid | 编译时生成 | 语句级 | 最高，无虚拟DOM |
