# 设计模式

## 概念

设计模式是软件设计中常见问题的可重用解决方案，是经过验证的最佳实践。

```
┌─────────────────────────────────────────────────────────┐
│                    设计模式分类                           │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐    │
│  │   创建型     │  │   结构型     │  │   行为型     │    │
│  │  Creational  │  │  Structural │  │  Behavioral │    │
│  └─────────────┘  └─────────────┘  └─────────────┘    │
│         │                │                │            │
│    单例/工厂          适配器/装饰器      观察者/策略     │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

## 关系

**关键连接**：
- 创建型 → **对象创建**：封装具体类的创建过程
- 结构型 → **对象组合**：通过组合形成更大结构
- 行为型 → **对象交互**：对象间的职责和算法分配

## 创建型模式

### 单例模式 (Singleton)

确保一个类只有一个实例，并提供全局访问点。

```python
# 懒汉式单例（线程不安全）
class Singleton:
    _instance = None

    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
        return cls._instance

# 饿汉式单例（线程安全，通过导入时创建保证）
class Singleton:
    _instance = None

    @staticmethod
    def get_instance():
        return _SingletonHolder.instance

class _SingletonHolder:
    _instance = None
    import threading
    _lock = threading.Lock()

    @classmethod
    def __init__(cls):
        if cls._instance is None:
            with cls._lock:
                if cls._instance is None:
                    cls._instance = cls.__new__(cls)
                    cls._instance._initialized = False

    def __init__(self):
        if not self._initialized:
            self._initialized = True
```

```go
// Go 单例（sync.Once 保证线程安全）
type singleton struct{}

var instance *singleton
var once sync.Once

func GetInstance() *singleton {
    once.Do(func() {
        instance = &singleton{}
    })
    return instance
}
```

**适用场景**：数据库连接、配置管理器、日志记录器

### 工厂方法模式 (Factory Method)

定义创建对象的接口，让子类决定实例化哪个类。

```python
from abc import ABC, abstractmethod

# 产品接口
class Button(ABC):
    @abstractmethod
    def render(self):
        pass

# 具体产品
class WindowsButton(Button):
    def render(self):
        return "Windows Button"

class MacButton(Button):
    def render(self):
        return "Mac Button"

# 工厂接口
class Dialog(ABC):
    @abstractmethod
    def create_button(self) -> Button:
        pass

    def render(self):
        button = self.create_button()
        return button.render()

# 具体工厂
class WindowsDialog(Dialog):
    def create_button(self) -> Button:
        return WindowsButton()

class MacDialog(Dialog):
    def create_button(self) -> Button:
        return MacButton()
```

**适用场景**：UI组件创建、数据库驱动连接

### 抽象工厂模式 (Abstract Factory)

创建一系列相关对象的工厂，无需指定具体类。

```python
# 抽象工厂
class GUIFactory(ABC):
    @abstractmethod
    def create_button(self):
        pass

    @abstractmethod
    def create_checkbox(self):
        pass

# 具体工厂
class WindowsFactory(GUIFactory):
    def create_button(self):
        return WindowsButton()

    def create_checkbox(self):
        return WindowsCheckbox()

class MacFactory(GUIFactory):
    def create_button(self):
        return MacButton()

    def create_checkbox(self):
        return MacCheckbox()

# 客户端代码
def create_ui(factory: GUIFactory):
    button = factory.create_button()
    checkbox = factory.create_checkbox()
```

### 建造者模式 (Builder)

分步骤创建复杂对象，允许不同表示。

```python
class User:
    def __init__(self):
        self.name = None
        self.email = None
        self.age = None
        self.address = None

class UserBuilder:
    def __init__(self):
        self._user = User()

    def with_name(self, name):
        self._user.name = name
        return self

    def with_email(self, email):
        self._user.email = email
        return self

    def with_age(self, age):
        self._user.age = age
        return self

    def with_address(self, address):
        self._user.address = address
        return self

    def build(self):
        return self._user

# 使用链式调用
user = UserBuilder() \
    .with_name("Alice") \
    .with_email("alice@example.com") \
    .with_age(30) \
    .build()
```

### 原型模式 (Prototype)

通过复制现有对象创建新对象。

```python
import copy

class Prototype:
    def clone(self):
        return copy.deepcopy(self)

class User(Prototype):
    def __init__(self, name, profile):
        self.name = name
        self.profile = profile  # 嵌套对象也会被深拷贝

user1 = User("Alice", {"role": "admin"})
user2 = user1.clone()
user2.name = "Bob"
```

## 结构型模式

### 适配器模式 (Adapter)

将不兼容接口转换为可兼容接口。

```python
# 目标接口
class Target:
    def request(self):
        return "Target: default behavior"

# 被适配者
class Adaptee:
    def specific_request(self):
        return ".eetpadA eht fo roivaheb laicepS"

# 适配器
class Adapter(Target):
    def __init__(self, adaptee):
        self._adaptee = adaptee

    def request(self):
        # 转换接口
        return self._adaptee.specific_request()[::-1]
```

```go
// Go 适配器示例
type Logger interface {
    Log(message string)
}

type StdLogger struct{}

func (l *StdLogger) Log(message string) {
    fmt.Println(message)
}

// 第三方库，不兼容 Logger 接口
type ThirdPartyLib struct{}

func (t *ThirdPartyLib) LogToFile(message string) {
    // 写入文件
}

// 适配器
type LoggerAdapter struct {
    thirdParty *ThirdPartyLib
}

func (a *LoggerAdapter) Log(message string) {
    a.thirdParty.LogToFile(message)
}
```

### 装饰器模式 (Decorator)

动态给对象添加额外职责。

```python
# 组件接口
class Coffee(ABC):
    @abstractmethod
    def cost(self):
        pass

    @abstractmethod
    def description(self):
        pass

# 基本组件
class SimpleCoffee(Coffee):
    def cost(self):
        return 10

    def description(self):
        return "Simple Coffee"

# 装饰器基类
class CoffeeDecorator(Coffee):
    def __init__(self, coffee: Coffee):
        self._coffee = coffee

    def cost(self):
        return self._coffee.cost()

    def description(self):
        return self._coffee.description()

# 具体装饰器
class MilkDecorator(CoffeeDecorator):
    def cost(self):
        return self._coffee.cost() + 2

    def description(self):
        return self._coffee.description() + ", Milk"

class SugarDecorator(CoffeeDecorator):
    def cost(self):
        return self._coffee.cost() + 1

    def description(self):
        return self._coffee.description() + ", Sugar"

# 使用
coffee = SimpleCoffee()
coffee = MilkDecorator(coffee)
coffee = SugarDecorator(coffee)
# description: "Simple Coffee, Milk, Sugar"
# cost: 13
```

### 代理模式 (Proxy)

为对象提供替身或占位符以控制访问。

```python
# 主题接口
class Subject(ABC):
    @abstractmethod
    def request(self):
        pass

# 真实主题
class RealSubject(Subject):
    def request(self):
        return "RealSubject: handling request."

# 代理
class Proxy(Subject):
    def __init__(self):
        self._real_subject = None

    def request(self):
        if self._check_access():
            if self._real_subject is None:
                self._real_subject = RealSubject()
            return self._real_subject.request()
        return None

    def _check_access(self):
        # 访问控制逻辑
        return True
```

```go
// Go 代理模式（实现保护代理）
type User struct {
    IsAuthenticated bool
}

type ResourceService interface {
    GetResource(id string) string
}

type RealService struct{}

func (s *RealService) GetResource(id string) string {
    return "Resource: " + id
}

type ProxyService struct {
    realService *RealService
    user        *User
}

func (p *ProxyService) GetResource(id string) string {
    if !p.user.IsAuthenticated {
        return "Access denied"
    }
    return p.realService.GetResource(id)
}
```

### 组合模式 (Composite)

将对象组合成树形结构以表示"部分-整体"层次。

```python
class Component(ABC):
    @abstractmethod
    def operation(self):
        pass

class Leaf(Component):
    def __init__(self, name):
        self.name = name

    def operation(self):
        return f"Leaf({self.name})"

class Composite(Component):
    def __init__(self, name):
        self.name = name
        self._children = []

    def add(self, component):
        self._children.append(component)
        return self

    def remove(self, component):
        self._children.remove(component)

    def operation(self):
        results = []
        for child in self._children:
            results.append(child.operation())
        return f"Composite({self.name}): [{', '.join(results)}]"

# 使用
tree = Composite("root")
branch1 = Composite("branch1")
branch1.add(Leaf("leaf1"))
branch1.add(Leaf("leaf2"))
tree.add(branch1)
tree.add(Leaf("leaf3"))
```

### 桥接模式 (Bridge)

将抽象部分与实现部分分离，使它们可以独立变化。

```python
# 实现部分
class Device(ABC):
    @abstractmethod
    def is_enabled(self):
        pass

    @abstractmethod
    def enable(self):
        pass

    @abstractmethod
    def get_volume(self):
        pass

# 抽象部分
class RemoteControl:
    def __init__(self, device: Device):
        self.device = device

    def toggle_power(self):
        if self.device.is_enabled():
            self.device.disable()
        else:
            self.device.enable()

    def set_volume(self, volume):
        self.device.set_volume(volume)

# 使用
tv = TV()
remote = RemoteControl(tv)
```

## 行为型模式

### 观察者模式 (Observer)

定义对象间的一对多依赖关系。

```python
from abc import ABC, abstractmethod

class Observer(ABC):
    @abstractmethod
    def update(self, message):
        pass

class Subject:
    def __init__(self):
        self._observers = []

    def attach(self, observer):
        self._observers.append(observer)

    def detach(self, observer):
        self._observers.remove(observer)

    def notify(self, message):
        for observer in self._observers:
            observer.update(message)

class NewsAgency(Subject):
    def __init__(self):
        super().__init__()
        self._news = ""

    def set_news(self, news):
        self._news = news
        self.notify(news)

class NewsChannel(Observer):
    def __init__(self, name):
        self.name = name

    def update(self, message):
        print(f"{self.name} received: {message}")

# 使用
agency = NewsAgency()
channel1 = NewsChannel("CNN")
channel2 = NewsChannel("BBC")

agency.attach(channel1)
agency.attach(channel2)
agency.set_news("Breaking news!")
```

### 策略模式 (Strategy)

定义一系列算法，使它们可以互换。

```python
from abc import ABC, abstractmethod

class SortStrategy(ABC):
    @abstractmethod
    def sort(self, data):
        pass

class QuickSort(SortStrategy):
    def sort(self, data):
        # 快速排序实现
        return sorted(data)

class MergeSort(SortStrategy):
    def sort(self, data):
        # 归并排序实现
        return sorted(data)

class Context:
    def __init__(self, strategy: SortStrategy):
        self._strategy = strategy

    def set_strategy(self, strategy):
        self._strategy = strategy

    def execute_sort(self, data):
        return self._strategy.sort(data)
```

### 命令模式 (Command)

将请求封装为对象。

```python
class Command(ABC):
    @abstractmethod
    def execute(self):
        pass

class Light:
    def turn_on(self):
        return "Light is ON"

    def turn_off(self):
        return "Light is OFF"

class LightOnCommand(Command):
    def __init__(self, light):
        self._light = light

    def execute(self):
        return self._light.turn_on()

class LightOffCommand(Command):
    def __init__(self, light):
        self._light = light

    def execute(self):
        return self._light.turn_off()

class RemoteControl:
    def __init__(self):
        self._commands = {}

    def set_command(self, slot, command):
        self._commands[slot] = command

    def press_button(self, slot):
        if slot in self._commands:
            return self._commands[slot].execute()
```

### 模板方法模式 (Template Method)

定义算法骨架，子类重写特定步骤。

```python
from abc import ABC, abstractmethod

class DataMiner(ABC):
    """模板方法：定义数据挖掘流程"""

    def mine(self, path):
        self.open_file(path)
        self.extract_data()
        self.parse_data()
        self.analyze_data()
        self.send_report()
        self.close_file()

    @abstractmethod
    def open_file(self, path):
        pass

    @abstractmethod
    def extract_data(self):
        pass

    @abstractmethod
    def close_file(self):
        pass

    def parse_data(self):
        """通用实现，可被子类重写"""
        print("Parsing data...")

    def analyze_data(self):
        """通用实现，可被子类重写"""
        print("Analyzing data...")

    def send_report(self):
        """通用实现"""
        print("Sending report...")

class PDFDataMiner(DataMiner):
    def open_file(self, path):
        print(f"Opening PDF: {path}")

    def extract_data(self):
        print("Extracting PDF data...")

    def close_file(self):
        print("Closing PDF...")
```

### 迭代器模式 (Iterator)

提供顺序访问集合元素的方法。

```python
from abc import ABC, abstractmethod

class Iterator(ABC):
    @abstractmethod
    def has_next(self):
        pass

    @abstractmethod
    def next(self):
        pass

class Container(ABC):
    @abstractmethod
    def get_iterator(self):
        pass

class NameRepository(Container):
    def __init__(self):
        self._names = ["Alice", "Bob", "Charlie"]

    def get_iterator(self):
        return NameIterator(self)

class NameIterator(Iterator):
    def __init__(self, repository):
        self._repository = repository
        self._index = 0

    def has_next(self):
        return self._index < len(self._repository._names)

    def next(self):
        if self.has_next():
            name = self._repository._names[self._index]
            self._index += 1
            return name
        return None

# 使用
repo = NameRepository()
iterator = repo.get_iterator()
while iterator.has_next():
    print(iterator.next())
```

### 责任链模式 (Chain of Responsibility)

将请求沿着处理者链传递。

```python
from abc import ABC, abstractmethod

class Handler(ABC):
    def __init__(self):
        self._next_handler = None

    def set_next(self, handler):
        self._next_handler = handler
        return handler

    def handle(self, request):
        if self._next_handler:
            return self._next_handler.handle(request)
        return None

class AuthHandler(Handler):
    def handle(self, request):
        if not request.get("authenticated"):
            return "Authentication failed"
        return super().handle(request)

class PermissionHandler(Handler):
    def handle(self, request):
        if not request.get("has_permission"):
            return "Permission denied"
        return super().handle(request)

# 使用
auth = AuthHandler()
perm = PermissionHandler()
auth.set_next(perm)

result = auth.handle({"authenticated": True, "has_permission": False})
```

### 状态模式 (State)

允许对象在内部状态改变时改变行为。

```python
from abc import ABC, abstractmethod

class State(ABC):
    @abstractmethod
    def handle(self, context):
        pass

class ConcreteStateA(State):
    def handle(self, context):
        context.state = ConcreteStateB()
        return "State A -> State B"

class ConcreteStateB(State):
    def handle(self, context):
        context.state = ConcreteStateA()
        return "State B -> State A"

class Context:
    def __init__(self):
        self.state = ConcreteStateA()

    def request(self):
        return self.state.handle(self)
```

## 模式对比

| 模式 | 意图 | 适用场景 |
|------|------|----------|
| 单例 | 确保唯一实例 | 配置、连接池 |
| 工厂 | 封装对象创建 | 解耦创建逻辑 |
| 适配器 | 接口转换 | 集成第三方库 |
| 装饰器 | 动态添加职责 | 日志、缓存 |
| 代理 | 访问控制 | 远程调用、安全 |
| 观察者 | 一对多通知 | 事件系统 |
| 策略 | 算法互换 | 排序、支付 |
| 命令 | 请求封装 | 撤销、重做 |

## 反模式

### 常见反模式

| 反模式 | 问题 | 解决方案 |
|--------|------|----------|
| God Object | 类承担过多职责 | 拆分为多个类 |
| Circular Dependency | 循环引用 | 依赖注入、重构 |
| Magic Numbers | 硬编码数字 | 命名常量 |
| Premature Optimization | 过早优化 | YAGNI原则 |
| Cargo Cult Programming | 盲目复制代码 | 理解原理 |

### YAGNI 原则

"You Aren't Gonna Need It" - 不要编写非必需的代码。

```python
# 反模式：过度设计
class UserManager:
    def create_user(self):
        pass

    def delete_user(self):
        pass

    def backup_user(self):  # 可能永远用不到
        pass

    def export_user_csv(self):  # 可能永远用不到
        pass

# 正确做法：先实现当前需要的
class UserManager:
    def create_user(self):
        pass

    def delete_user(self):
        pass
```

## SOLID 原则

| 原则 | 全称 | 说明 |
|------|------|------|
| S | Single Responsibility | 单一职责 |
| O | Open/Closed | 开闭原则 |
| L | Liskov Substitution | 里氏替换 |
| I | Interface Segregation | 接口隔离 |
| D | Dependency Inversion | 依赖反转 |

```python
# 违反 SRP：UserService 承担太多职责
class UserService:
    def create_user(self):
        pass

    def send_email(self):  # 邮件职责应该分离
        pass

    def generate_report(self):  # 报表职责应该分离
        pass

# 符合 SRP：职责分离
class UserService:
    def create_user(self):
        pass

class EmailService:
    def send_email(self):
        pass

class ReportService:
    def generate_report(self):
        pass
```
