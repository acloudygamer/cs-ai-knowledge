## 学习路径

1. **先前端后端**：理解软件开发的基本架构
2. **再测试与数据库**：掌握数据管理和质量保障
3. **后工程实践**：API 设计、CI/CD、安全
4. **最后架构**：设计模式、微服务、系统设计
