## 学习路径

1. **先 Git**：版本控制是一切协作的底座
2. **再测试与设计模式**：理解代码质量的内外两面
3. **再 CI/CD 与容器化**：理解代码如何自动变成可部署制品
4. **后架构分层、数据库、微服务**：理解系统级组织方式
5. **最后安全基础**：用威胁模型回看全章
