## 邮件传输协议

### SMTP (Simple Mail Transfer Protocol)

邮件发送协议，使用端口 25/587/465。

```
┌─────────────────────────────────────────────────────────┐
│                    SMTP 工作流程                          │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  邮件客户端                                              │
│       │                                                │
│       ├──► EHLO client.example.com                     │
│       │◄── 250-server Hello                            │
│       ├──► AUTH LOGIN                                  │
│       │◄── 334 VXNlcm5hbWU6                           │
│       ├──► base64(username)                            │
│       │◄── 334 UGFzc3dvcmQ6                           │
│       ├──► base64(password)                            │
│       │◄── 235 Authentication successful              │
│       ├──► MAIL FROM:<alice@example.com>             │
│       │◄── 250 OK                                     │
│       ├──► RCPT TO:<bob@example.com>                  │
│       │◄── 250 OK                                     │
│       ├──► DATA                                       │
│       │◄── 354 Start mail input                      │
│       ├──► Subject: Hello                             │
│       │    From: alice@example.com                    │
│       │    To: bob@example.com                        │
│       │                                             │
│       │    Mail body...                               │
│       ├──► .                                          │
│       │◄── 250 OK Message accepted                   │
│       ├──► QUIT                                       │
│       │◄── 221 Bye                                    │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

#### Python SMTP 示例

```python
import smtplib
from email.mime.text import MIMEText
from email.mime.multipart import MIMEMultipart

def send_email():
    # 创建邮件
    msg = MIMEMultipart()
    msg['From'] = 'alice@example.com'
    msg['To'] = 'bob@example.com'
    msg['Subject'] = 'Test Email'

    # 添加正文
    body = MIMEText('This is a test email.', 'plain')
    msg.attach(body)

    # 添加附件
    with open('document.pdf', 'rb') as f:
        attachment = MIMEText(f.read(), 'base64', 'utf-8')
        attachment['Content-Type'] = 'application/pdf'
        attachment['Content-Disposition'] = 'attachment; filename="document.pdf"'
        msg.attach(attachment)

    # 发送邮件
    with smtplib.SMTP('smtp.example.com', 587) as server:
        server.starttls()  # 启用 TLS
        server.login('alice@example.com', 'password')
        server.send_message(msg)

# Gmail 使用专用应用密码
with smtplib.SMTP('smtp.gmail.com', 587) as server:
    server.starttls()
    server.login('your-email@gmail.com', 'your-app-password')
    server.send_message(msg)
```

#### Go SMTP 示例

```go
package main

import (
    "crypto/tls"
    "fmt"
    "net/smtp"
)

func main() {
    // 邮件内容
    from := "alice@example.com"
    to := []string{"bob@example.com"}
    subject := "Subject: Test Email\r\n"
    body := "This is a test email."

    msg := fmt.Sprintf("From: %s\r\nTo: %s\r\n%s\r\n\r\n%s",
        from, to[0], subject, body)

    // SMTP 服务器配置
    host := "smtp.example.com"
    port := 587

    // 认证
    auth := smtp.PlainAuth("", "username", "password", host)

    // 发送邮件
    err := smtp.SendMail(
        fmt.Sprintf("%s:%d", host, port),
        auth,
        from,
        to,
        []byte(msg),
    )
    if err != nil {
        fmt.Println("Error:", err)
    }
}
```

```

│                                                         │
│  邮件客户端                                              │
│       │                                                │
│       ├──► USER alice                                 │
│       │◄── +OK                                        │
│       ├──► PASS password                              │
│       │◄── +OK                                        │
│       ├──► STAT                                      │
│       │◄── +OK 3 15234                               │
│       ├──► LIST                                      │
│       │◄── +OK 3 messages                            │
│       │    1 5120                                    │
│       │    2 4532                                    │
│       │    3 5582                                    │
│       │    .                                          │
│       ├──► RETR 1                                    │
│       │◄── +OK 5120 octets                           │
│       │    邮件内容...                                │
│       │    .                                          │
│       ├──► DELE 1                                    │

│                                                         │

```

#### Python POP3 示例

```python
import poplib
from email.parser import Parser

def fetch_emails():
    # 连接 POP3 服务器 (使用 SSL)
    pop = poplib.POP3_SSL('pop.gmail.com', 995)

    # 登录
    pop.user('your-email@gmail.com')
    pop.pass_('your-app-password')

    # 获取邮件统计
    num_messages = len(pop.list()[1])
    print(f"Total messages: {num_messages}")

    # 获取最新邮件
    if num_messages > 0:
        # RETR 返回邮件完整内容
        response, lines, octets = pop.retr(num_messages)
        msg_content = b'\r\n'.join(lines).decode('utf-8')

        # 解析邮件
        msg = Parser().parsestr(msg_content)
        print(f"From: {msg['From']}")
        print(f"Subject: {msg['Subject']}")

    # 删除邮件
    # pop.dele(message_num)

    pop.quit()
```

### IMAP (Internet Message Access Protocol)

邮件访问协议，支持在服务器上管理邮件，使用端口 143/993 (SSL)。

```
┌─────────────────────────────────────────────────────────┐
│                    IMAP vs POP3                         │
├─────────────────────────────────────────────────────────┤
│                                                         │
│   IMAP                    POP3                          │
│   ─────────               ─────────                     │
│   服务器存储邮件           下载后删除服务器邮件           │
│   多设备同步              单一设备使用                   │
│   按需获取邮件部分        下载完整邮件                   │
│   支持文件夹管理          不支持文件夹                   │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

#### IMAP 命令流程

```
C: A142 LOGIN alice password
S: * OK [CAPABILITY IMAP4rev1] ...

C: A143 SELECT INBOX
S: * 3 EXISTS
S: * 2 RECENT
S: * FLAGS (\Answered \Flagged \Deleted \Draft \Seen)
S: A143 OK [READ-WRITE] SELECT completed

C: A144 FETCH 1 BODY[TEXT]
S: * 1 FETCH (BODY[TEXT] {512}
S: 邮件内容...
S: A144 OK FETCH completed

C: A145 LOGOUT
S: * BYE IMAP4rev1 server logging out
S: A145 OK LOGOUT completed
```

#### Python IMAP 示例

```python
import imaplib
import email
from email.header import decode_header

def fetch_imap_emails():
    # 连接
    mail = imaplib.IMAP4_SSL('imap.gmail.com', 993)

    # 登录
    mail.login('your-email@gmail.com', 'your-app-password')

    # 列出邮箱
    status, folders = mail.list()
    print("Folders:", folders)

    # 选择收件箱
    mail.select('INBOX')

    # 搜索邮件
    status, messages = mail.search(None, 'UNSEEN', 'FROM', 'newsletter@example.com')

    # 获取邮件
    for num in messages[0].split():
        status, msg_data = mail.fetch(num, '(RFC822)')
        msg = email.message_from_bytes(msg_data[0][1])

        # 解码主题
        subject, encoding = decode_header(msg['Subject'])[0]
        if isinstance(subject, bytes):
            subject = subject.decode(encoding or 'utf-8')

        print(f"From: {msg['From']}, Subject: {subject}")

    mail.logout()
```

## 文件传输协议

### FTP (File Transfer Protocol)

使用客户端-服务器模式，端口 21 (控制) + 动态端口 (数据)。

```
┌─────────────────────────────────────────────────────────┐
│                    FTP 工作模式                           │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  主动模式 (PORT)                                        │
│  ┌──────────┐            ┌──────────┐                  │
│  │  Client  │◄───21──────│   FTP    │                  │
│  │  随机端口 │───20──────►│  Server  │                  │
│  └──────────┘   数据连接  └──────────┘                  │
│                                                         │
│  被动模式 (PASV)                                       │
│  ┌──────────┐            ┌──────────┐                  │
│  │  Client  │◄───21──────│   FTP    │                  │
│  │  随机端口 │◄───随机────│  Server  │                  │
│  └──────────┘   数据连接  └──────────┘                  │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

#### FTP 命令

| 命令 | 说明 | 示例 |
|------|------|------|
| USER | 用户名 | USER alice |
| PASS | 密码 | PASS password |
| LIST | 列出目录 | LIST /files |
| RETR | 下载文件 | RETR readme.txt |
| STOR | 上传文件 | STOR report.pdf |
| DELE | 删除文件 | DELE old.txt |
| MKD | 创建目录 | MKD newdir |
| RMD | 删除目录 | RMD olddir |
| CWD | 切换目录 | CWD /public |
| PWD | 当前目录 | PWD |
| TYPE | 传输类型 | TYPE I (二进制) |
| QUIT | 退出 | QUIT |

#### Python FTP 示例

```python
from ftplib import FTP

def ftp_operations():
    ftp = FTP('ftp.example.com')
    ftp.login('username', 'password')

    # 切换目录
    ftp.cwd('/public')

    # 列出文件
    files = ftp.nlst()
    print("Files:", files)

    # 下载文件
    with open('readme.txt', 'wb') as f:
        ftp.retrbinary('RETR readme.txt', f.write)

    # 上传文件
    with open('report.pdf', 'rb') as f:
        ftp.storbinary('STOR report.pdf', f)

    # 创建目录
    ftp.mkd('new_folder')

    ftp.quit()
```

### SFTP (SSH File Transfer Protocol)

基于 SSH 的安全文件传输协议，端口 22。

```
┌─────────────────────────────────────────────────────────┐
│                    FTP vs SFTP                          │
├─────────────────────────────────────────────────────────┤
│                                                         │
│   FTP                     SFTP                          │
│   ─────────               ─────────                     │
│   明文传输 (可加密)        始终加密                      │
│   端口 21                  端口 22                        │
│   支持目录列表             基于 SSH 命令                 │
│   支持断点续传             内置断点续传                   │
│   多种传输模式             单一二进制模式                 │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

#### Python SFTP 示例 (paramiko)

```python
import paramiko

def sftp_operations():
    # 创建 SSH 客户端
    ssh = paramiko.SSHClient()
    ssh.set_missing_host_key_policy(paramiko.AutoAddPolicy())
    ssh.connect('hostname', username='user', password='pass')

    # 打开 SFTP 会话
    sftp = ssh.open_sftp()

    # 下载文件
    sftp.get('/remote/file.txt', 'local/file.txt')

    # 上传文件
    sftp.put('local/report.pdf', '/remote/report.pdf')

    # 列出目录
    for item in sftp.listdir('/remote'):
        print(item)

    # 获取文件信息
    stat = sftp.stat('/remote/file.txt')
    print(f"Size: {stat.st_size}, Modified: {stat.st_mtime}")

    # 创建目录
    sftp.mkdir('/remote/newdir')

    # 删除文件
    sftp.remove('/remote/old.txt')

    sftp.close()
    ssh.close()
```

#### SSH 密钥生成与使用

```bash
# 生成密钥对
```


#### Python SSH 示例 (paramiko)

```python
import paramiko

def ssh_operations():
    ssh = paramiko.SSHClient()
    ssh.set_missing_host_key_policy(paramiko.AutoAddPolicy())
    ssh.connect('hostname', username='user', password='pass')

    # 执行命令
    stdin, stdout, stderr = ssh.exec_command('ls -la /home')
    print(stdout.read().decode())

    # 执行命令并获取退出状态
    stdin, stdout, stderr = ssh.exec_command('tail -f /var/log/app.log')
    exit_status = stdout.channel.recv_exit_status()

    # 交互式 shell
    channel = ssh.invoke_shell()
    channel.send('ls -la\n')
    while not channel.recv_ready():
        import time
        time.sleep(0.1)
    print(channel.recv(1024).decode())

    ssh.close()
```

#### Python WebSocket 示例

```python
# 服务器 (websockets 库)
import asyncio
import websockets

async def echo(websocket, path):
    async for message in websocket:
        print(f"Received: {message}")
        await websocket.send(f"Echo: {message}")

start_server = websockets.serve(echo, "localhost", 8765)
asyncio.get_event_loop().run_until_complete(start_server)
asyncio.get_event_loop().run_forever()

# 客户端
import asyncio
import websockets

async def client():
    async with websockets.connect("ws://localhost:8765") as ws:
        await ws.send("Hello")
        response = await ws.recv()
        print(response)

asyncio.run(client())
```

#### Go WebSocket 示例

```go
package main

import (
    "fmt"
    "github.com/gorilla/websocket"
    "net/http"
)

var upgrader = websocket.Upgrader{}

func wsHandler(w http.ResponseWriter, r *http.Request) {
    conn, _ := upgrader.Upgrade(w, r, nil)
    defer conn.Close()

    for {
        // 读取消息
        _, msg, err := conn.ReadMessage()
        if err != nil {
            break
        }

        fmt.Printf("Received: %s\n", msg)

        // 发送消息
        err = conn.WriteMessage(websocket.TextMessage, []byte("Echo: "+string(msg)))
        if err != nil {
            break
        }
    }
}

func main() {
    http.HandleFunc("/ws", wsHandler)
    http.ListenAndServe(":8080", nil)
}
```

### SSE (Server-Sent Events)

服务器向浏览器推送事件的技术。

```
┌─────────────────────────────────────────────────────────┐
│                    SSE vs WebSocket                      │
├─────────────────────────────────────────────────────────┤
│                                                         │
│   SSE                        WebSocket                  │
│   ─────────                  ─────────                  │
│   单向 (Server→Client)        全双工                     │
│   基于 HTTP                   独立协议                    │
│   自动重连                    需手动重连                   │
│   简单轻量                    稍复杂                       │
│   适合通知/推送               适合实时交互                │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

#### SSE 服务器实现

```go
// Go SSE 实现
func sseHandler(w http.ResponseWriter, r *http.Request) {
    // 设置响应头
    w.Header().Set("Content-Type", "text/event-stream")
    w.Header().Set("Cache-Control", "no-cache")
    w.Header().Set("Connection", "keep-alive")

    flusher, ok := w.(http.Flusher)
    if !ok {
        http.Error(w, "SSE not supported", http.StatusInternalServerError)
        return
    }

    for {
        // 发送事件
        fmt.Fprintf(w, "data: %s\n\n", time.Now().Format("15:04:05"))
        flusher.Flush()

        time.Sleep(1 * time.Second)
    }
}
```

#### SSE 浏览器客户端


## 协议对比

| 协议 | 端口 | 安全性 | 用途 |
|------|------|--------|------|
| SMTP | 25/587/465 | 可加密 | 邮件发送 |
| POP3 | 110/995 | 可加密 | 邮件收取 |
| IMAP | 143/993 | 可加密 | 邮件同步 |
| FTP | 21 | 明文 | 文件传输 |
| SFTP | 22 | 加密 | 安全文件传输 |
| SCP | 22 | 加密 | 安全拷贝 |
| SSH | 22 | 加密 | 远程登录 |
| Telnet | 23 | 明文 | 远程登录（不推荐） |

| SSE | 80/443 | 可加密 | 服务器推送 |

## 安全最佳实践
