# 计算机网络

> **版本基准**: universal

本部分涵盖计算机网络的核心概念，从物理连接到应用层协议。

## 学习路径

1. **先分层模型**：理解网络分层架构
2. **再传输层**：掌握TCP/UDP区别和连接管理
3. **后应用层**：理解HTTP/DNS/Socket等协议
4. **最后扩展**：HTTPS安全、TLS加密、其他协议
