# 网络分层模型

## 解决什么问题

网络通信极其复杂（物理介质、信号传输、路由、协议、数据格式）。分层模型将网络通信拆分为多个层次，每层只关心自己的职责，层间通过接口通信，大幅降低复杂度。

## 核心概念

- **OSI七层模型**：理论框架（应用→表示→会话→传输→网络→数据链路→物理）
- **TCP/IP四层模型**：实际标准（应用→传输→网络→网络接口）
- **封装**：每层添加自己的头部信息
- **解封装**：接收时逐层剥离头部，还原原始数据
- **PDU**：协议数据单元（消息→段→包→帧→比特）

**对应关系**：
```
OSI七层                    TCP/IP四层
┌─────────────────────────┐  ┌───────────────────────┐
│ 7 应用层 (HTTP/DNS/FTP) │  │  应用层               │
├─────────────────────────┤  ├───────────────────────┤
│ 6 表示层                │  │                       │
├─────────────────────────┤  ├───────────────────────┤
│ 5 会话层                │  │  传输层 (TCP/UDP)     │
├─────────────────────────┤  ├───────────────────────┤
│ 4 传输层                │  ├───────────────────────┤
├─────────────────────────┤  │  网络层 (IP)          │
│ 3 网络层                │  ├───────────────────────┤
├─────────────────────────┤  │  网络接口层            │
│ 2 数据链路层            │  │  (Ethernet/Wi-Fi)     │
├─────────────────────────┤  └───────────────────────┘
│ 1 物理层                │
└─────────────────────────┘
```

## 怎么用

### 数据封装过程

```
发送过程（封装）：
┌─────────────────────────────────┐
│  应用层：HTTP请求               │  ← 原始数据
├─────────────────────────────────┤
│  传输层：TCP头 + HTTP数据        │  ← TCP段
├─────────────────────────────────┤
│  网络层：IP头 + TCP段            │  ← IP包
├─────────────────────────────────┤
│  数据链路层：Ethernet头 + IP包   │  ← 以太网帧
├─────────────────────────────────┤
│  物理层：转换为电/光信号         │
└─────────────────────────────────┘
```

### TCP vs UDP

| 特性 | TCP | UDP |
|------|-----|-----|
| 连接性 | 面向连接（三次握手建立） | 无连接（无需握手） |
| 可靠性 | 可靠（重传、排序） | 不可靠 |
| 拥塞控制 | 有 | 无 |
| 传输速度 | 较慢 | 快 |
| 数据边界 | 字节流，无边界 | 数据报，有边界 |
| 适用场景 | HTTP、邮件、文件传输 | DNS、视频、语音 |

### TCP 三次握手

```
客户端                              服务端
   │                                  │
   │─────── SYN (seq=x) ────────────▶│  1. 客户端发送SYN
   │                                  │
   │◀────── SYN-ACK (seq=y, ack=x+1) ─│  2. 服务器返回SYN-ACK
   │                                  │
   │─────── ACK (ack=y+1) ──────────▶│  3. 客户端发送ACK
   │                                  │
   │         建立完成                  │
```

### 常用端口

| 端口 | 协议 | 用途 |
|------|------|------|
| 22 | SSH | 远程登录 |
| 53 | DNS | 域名解析 |
| 80 | HTTP | Web流量 |
| 443 | HTTPS | 加密Web流量 |
| 3306 | MySQL | 数据库连接 |
| 5432 | PostgreSQL | 数据库连接 |
| 6379 | Redis | 缓存服务 |

### 网络诊断命令

```bash
# 连通性测试
ping baidu.com

# 路由追踪
traceroute baidu.com              # Linux
tracert baidu.com                 # Windows

# DNS查询
nslookup baidu.com
dig baidu.com

# Linux (Ubuntu 24.04) 查看端口占用
ss -tulnp
```
