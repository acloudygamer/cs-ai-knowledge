# 计算机基础

> **版本基准**: universal（Windows 11 / Ubuntu 24.04 / WSL 3.0.3 / PowerShell 7.6.7 / Git Bash 5.3.15 / GNU Bash 5.2.21（WSL））

本部分不是工具手册，而是**概念关系图谱**——帮你理解计算机各层如何连接。全卷按依赖拓扑排序：讲任何一层之前，它依赖的机制必须已在前文建立。

## 概念层次

```
┌─────────────────────────────────────────────────────────────┐
│  软件工程: Git/测试/CI-CD/容器/架构/微服务/安全             │
├─────────────────────────────────────────────────────────────┤
│  网络: TCP/IP 协议栈、DNS、HTTP、TLS → Socket               │
├─────────────────────────────────────────────────────────────┤
│  编程运行环境: 编译/链接/装载 → 运行时/虚拟机               │
├─────────────────────────────────────────────────────────────┤
│  终端与 Shell: PTY → Shell 进程 → 三壳生态/WSL              │
├─────────────────────────────────────────────────────────────┤
│  操作系统: 内核 + 系统调用 + 进程/内存/文件/IO              │
│    (Linux 与 Windows 在此建立)                              │
├─────────────────────────────────────────────────────────────┤
│  硬件: CPU/缓存/内存/存储、ISA 与指令执行                   │
└─────────────────────────────────────────────────────────────┘
```

## 关键连接关系

| 关系 | 说明 |
|------|------|
| **硬件 → 操作系统** | 页表/TLB/特权级是内核机制的硬件底座 |
| **操作系统 → 终端与 Shell** | Shell 是消费进程/fd/PTY 的普通用户态进程 |
| **操作系统 → 编程运行环境** | 装载即内存映射，运行时寄生在进程内 |
| **操作系统 → 网络** | socket 是内核暴露给进程的网络端点 |
| **全卷 → 软件工程** | Git 消费 Shell、容器消费 namespace/cgroups、微服务消费网络 |

## 学习路径

1. **先计算机体系**：理解硬件执行引擎与存储结构
2. **再操作系统**：理解 OS 如何隔离与复用硬件（Linux 在此建立）
3. **再终端与 Shell**：理解人如何驱动 OS
4. **再编程运行环境**：理解代码如何变成进程
5. **再计算机网络**：理解进程如何跨机器通信
6. **最后软件工程概念**：理解多人如何可持续地构建软件

建议按顺序学习，但各部分之间有交叉引用，可随时跳转。
