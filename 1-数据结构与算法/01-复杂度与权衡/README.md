# 复杂度与权衡

> **版本基准**: universal

本域主约束所在。数据结构的存在理由是时间与空间的置换：每种结构都是在硬件约束（连续内存 vs 指针跳转、缓存行、外存页）下，让某些操作变快、另一些操作变慢的布局选择。复杂度分析是描述这场置换的度量语言。

组织逻辑：**先学会度量，再谈论结构**。不理解 $O$ 记号忽略了什么（常数、缓存、分支预测），就无法理解后面每个结构为什么是这个形状。
