# 复杂度与权衡

> **版本基准**: universal

本章回答一个问题：两个算法谁快，凭什么在没运行之前就敢下结论。第一条链是记账：把一次执行数成基本操作计数 $T(n)$，用渐进记号压成量级，按极限判据排成全序，递归定义再靠递归树或 Master 定理展开。第二条链是报价：摊还解决"多少次"，代价模型解决"每次多贵"，两者合起来才是一次操作的真实开销。

| 篇目 | 主链与消费的前置结论 |
| --- | --- |
| 01 复杂度分析 | 基本操作计数 → 单位代价假设 → 三个口径 → 渐进记号的量词定义 → 极限判据与等级全序 → 交叉点 → 递归树与 Master 定理 → 访存、分布与空间对常数的改写 |
| 02 摊还与代价模型 | 消费 01 的量级结论 → 单次最坏与序列总额分离 → 聚合、记账、势能三法 → 摊还界落在哪个操作 → 摊还失效的三种情形 → 单步代价的档位与分配拷贝 → 空间开销与负载因子的换算率 |
