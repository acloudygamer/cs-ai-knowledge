# 基础数据结构

> **版本基准**: universal

基础数据结构是计算机科学中最核心的线性与非线性结构，涵盖连续内存（数组）、指针链接（链表）、受限访问（栈/队列）、键值映射（哈希表）以及文本处理（模式匹配）五大体系。
