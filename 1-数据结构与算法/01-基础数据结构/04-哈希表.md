## 哈希表

### 解决什么问题
实现 O(1) 平均时间复杂度的键值查找，适用于快速查找、去重、缓存实现等场景。

### 核心概念
- **哈希函数**：将键映射到桶索引
- **冲突处理**：链地址法（拉链）、开放地址法（线性探测、二次探测）
- **负载因子**：填充比例，影响哈希表性能
- **布隆过滤器**：空间效率高的概率数据结构，支持快速判断存在性（有假阳性无假阴性）

### 常用技巧

两数之和、字母异位词分组等经典问题利用哈希表实现 O(n) 解决方案。

### 参考样例

```python
def two_sum(nums, target):
    seen = {}
    for i, num in enumerate(nums):
        complement = target - num
        if complement in seen:
            return [seen[complement], i]
        seen[num] = i
    return []

def group_anagrams(strs):
    groups = {}
    for s in strs:
        key = ''.join(sorted(s))
        groups.setdefault(key, []).append(s)
    return list(groups.values())
```

### LRU 缓存

哈希表 + 有序字典实现 O(1) 的 get 和 put。

### 参考样例

```python
class LRUCache:
    def __init__(self, capacity: int):
        self.cache = {}
        self.capacity = capacity

    def get(self, key: int) -> int:
        if key not in self.cache:
            return -1
        self.cache.move_to_end(key)
        return self.cache[key]

    def put(self, key: int, value: int) -> None:
        if key in self.cache:
            self.cache.move_to_end(key)
        self.cache[key] = value
        if len(self.cache) > self.capacity:
            self.cache.popitem(last=False)
```

## 布隆过滤器（Bloom Filter）

概率型数据结构，用于快速判断元素是否可能存在。

### 核心原理

- 使用 k 个哈希函数，将元素映射到长度为 m 的位数组
- 添加元素：将 k 个位置设为 1
- 查询元素：检查 k 个位置是否都为 1（都为 1 则可能存在，有假阳性）

### 假阳性率推导

设位数组大小为 m，插入 n 个元素，使用 k 个哈希函数。

**单次哈希，某一位为 0 的概率**：
$$P(某一位为0) = (1 - \frac{1}{m})^{kn}$$

**k 个哈希函数后，某一位仍为 0 的概率**：
$$P(某一位仍为0) = (1 - \frac{1}{m})^{kn} \approx e^{-\frac{kn}{m}}$$

**假阳性率（k 位全为 1 的概率）**：
$$p = (1 - e^{-\frac{kn}{m}})^k$$

### 最优参数

$$k_{opt} = \frac{m}{n} \ln 2 \approx 0.7 \frac{m}{n}$$

$$m_{opt} = -\frac{n \ln p}{(\ln 2)^2}$$

### 参数选择表

| 预期元素数 n | 假阳性率 p | 位数组大小 m | 哈希函数数 k |
|-------------|-----------|-------------|-------------|
| 10,000 | 1% | 95,784 bits (~12 KB) | 7 |
| 10,000 | 0.1% | 143,776 bits (~18 KB) | 10 |
| 100,000 | 1% | 958,176 bits (~117 KB) | 7 |
| 100,000 | 0.1% | 1,437,775 bits (~176 KB) | 10 |
| 1,000,000 | 1% | 9,581,575 bits (~1.17 MB) | 7 |

### 参考样例

```python
import hashlib
import math

class BloomFilter:
    def __init__(self, n=100000, fp_rate=0.01):
        self.n = n
        self.fp_rate = fp_rate
        self.m = int(-n * math.log(fp_rate) / (math.log(2) ** 2))
        self.k = int(self.m / n * math.log(2))
        self.bit_array = [0] * self.m

    def _hashes(self, item):
        item_bytes = str(item).encode()
        hash1 = int(hashlib.md5(item_bytes).hexdigest(), 16)
        hash2 = int(hashlib.sha256(item_bytes).hexdigest(), 16)
        for i in range(self.k):
            yield abs((hash1 + i * hash2) % self.m)

    def add(self, item):
        for idx in self._hashes(item):
            self.bit_array[idx] = 1

    def might_contain(self, item):
        for idx in self._hashes(item):
            if self.bit_array[idx] == 0:
                return False
        return True
```

### 布隆过滤器变体

#### 可计数的布隆过滤器 (Counting Bloom Filter)

用计数器数组代替位数组，支持删除操作。

### 参考样例

```python
class CountingBloomFilter:
    def __init__(self, n, fp_rate):
        import math
        self.m = int(-n * math.log(fp_rate) / (math.log(2) ** 2))
        self.k = int(self.m / n * math.log(2))
        self.counters = [0] * self.m

    def _hashes(self, item):
        item_bytes = str(item).encode()
        hash1 = int(hashlib.md5(item_bytes).hexdigest(), 16)
        hash2 = int(hashlib.sha256(item_bytes).hexdigest(), 16)
        for i in range(self.k):
            yield abs((hash1 + i * hash2) % self.m)

    def add(self, item):
        for idx in self._hashes(item):
            self.counters[idx] += 1

    def remove(self, item):
        for idx in self._hashes(item):
            if self.counters[idx] > 0:
                self.counters[idx] -= 1

    def might_contain(self, item):
        for idx in self._hashes(item):
            if self.counters[idx] == 0:
                return False
        return True
```

### 典型应用

| 应用场景 | 说明 |
|---------|------|
| 恶意 URL 检测 | 先用布隆过滤器快速判断，大概率拒绝 |
| 缓存穿透防护 | Redis + 布隆过滤器，防止无效查询击穿缓存 |
| 垃圾邮件过滤 | 快速判断邮件是否在黑名单 |
| 重复 URL 检测 | URL 去重，减少数据库压力 |
| 区块链 | Bitcoin 使用布隆过滤器做 SPV 节点 |

### 优点与局限

| 优点 | 局限 |
|------|------|
| 空间效率高 | 有假阳性（无假阴性） |
| 查询速度快 O(k) | 删除操作困难（原版） |
| 扩展性好 | 不适合精确计数 |
| 简单易实现 | 参数选择影响准确性 |
