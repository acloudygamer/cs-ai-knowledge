# 哈希表

> **版本基准**：universal —— 代码示例同时使用 Python 3.12 与 C++20

## 本质

哈希表用哈希函数 $h:\text{Key}\to[0,m-1]$ 把键压进固定大小的桶数组，在均匀分布假设下实现平均 $O(1)$ 的查找/插入/删除。它是"直接寻址数组"在键空间太大时的改良——不分配键空间那么大的数组，而是用哈希把键压到 $m$ 个桶，再用冲突策略处理挤在同一桶里的键。

核心张力：哈希把大空间压到小空间，冲突不可避免；靠**均匀哈希 + 控制负载因子 + 扩容**把冲突概率压到可接受。

## 数学模型

### 均匀性假设与负载因子

设 $h$ 把键空间均匀映射到 $m$ 桶，对任意桶 $i$、键 $k$：

$$P(h(k)=i) = \frac{1}{m}$$

负载因子 $\alpha = n/m$ （$n$ 个元素、 $m$ 桶）是冲突的核心指标。

### 冲突概率

插入 $n$ 个键后，特定桶为空的概率：

$$P(\text{空}) = \left(1-\frac{1}{m}\right)^n \approx e^{-\alpha}$$

特定桶恰有 $k$ 个元素（二项分布）：

$$P(k) = \binom{n}{k}\left(\frac{1}{m}\right)^k\left(1-\frac{1}{m}\right)^{n-k}$$

链地址法成功查找的期望比较次数约 $1+\alpha/2$。

### 扩容的均摊代价

负载因子超阈值 $\tau$ （常取 0.75）即扩容， $m_{new}=m\cdot k$ （常 $k=2$）， $\alpha$ 降为 $\alpha/k$。设初始 $m_0=1$ 每次翻倍，插 $n$ 个元素的总代价：

$$T(n) = \sum_{i=0}^{\lfloor\log_2 n\rfloor} \frac{n}{2^i} = 2n = O(n)$$

均摊每次插入 $O(1)$。

### 开放地址法探测序列

$$\text{线性探测:}\ h(k,i)=(h(k)+i)\bmod m$$

$$\text{二次探测:}\ h(k,i)=(h(k)+c_1 i+c_2 i^2)\bmod m$$

$$\text{双重哈希:}\ h(k,i)=(h_1(k)+i\cdot h_2(k))\bmod m$$

双重哈希要求 $h_2(k)$ 与 $m$ 互素，否则探测序列提前循环、部分桶永远到不了。

### 布隆过滤器假阳性率

位数组 $m$、 $n$ 个元素、 $k$ 个独立哈希。某位插入后仍为 0 的概率 $P(0)\approx e^{-kn/m}$；不在集合中的元素其 $k$ 位全为 1（假阳性）：

$$p = \left(1-e^{-kn/m}\right)^k$$

最优哈希数 $k_{opt}=\frac{m}{n}\ln 2\approx 0.7\frac{m}{n}$；给定目标 $p$ 所需位数 $m_{opt}=-\frac{n\ln p}{(\ln 2)^2}$。

> **洞察**：哈希表的操作代价 = 哈希计算 $O(1)$ + 冲突解决（链地址 $O(1+\alpha)$、开放地址 $O(1/(1-\alpha))$）。只要把 $\alpha$ 控制住，均摊就是 $O(1)$ ——扩容是维持这个前提的代价。

## 数据流

### 链地址法

<pre>
"hello" → h=2 ┐                    "world" → h=2 ┐
              ├─ 桶2 冲突 ─→ 桶2: [("hello",v1)] → ("world",v2)
              ┘                                  └─ 查找时遍历链表精确比键

形态: 键 → 哈希值 → 桶索引 → 链表遍历 → 精确键比较
</pre>

### 开放地址法

<pre>
插 "hello": h=2 → 桶2占 → 线性探测3 → 空 → 插
插 "world": h=2 → 桶2占 → 探测3占 → 探测4 → 空 → 插
查 "world": h=2 → 不匹配 → 探测3不匹配 → 探测4匹配 → 返回

形态: 键 → 哈希值 → 探测序列 → 依次探桶 → 命中/遇空桶
</pre>

### 扩容迁移

<pre>
容量4(α=0.75超阈值) → 翻倍至8
  1. 分配 8 个空桶
  2. 遍历旧桶链表
  3. 每个元素重算 h(key) % 8
  4. 插入新桶
旧数组释放；所有权从旧数组转新数组
</pre>

### 布隆过滤器

<pre>
add "example": h1,h2,h3 → 位置 2,5,7 置1 → 位数组 [0,0,1,0,0,1,0,1]
query "example": 算 h1,h2,h3 → 查对应位
  全 1 → "可能存在"(真阳性或假阳性)
  任一 0 → "必定不存在"(真阴性，保证 100%)

位只能 0→1 不能回退 → 无法删除(回退会误伤其他元素)
</pre>

## 对比参照

| 特性 | 链地址法 | 开放地址法 |
|------|----------|------------|
| 查找复杂度 | $O(1+\alpha)$ | $O(1/(1-\alpha))$ （近似） |
| 删除 | $O(1)$ 摘链节点 | 需墓碑标记 + 定期重建 |
| 缓存友好 | 差（指针跳转） | 好（连续内存） |
| 聚集效应 | 无 | 一次聚集（线性）/二次聚集（二次） |
| 负载因子上限 | 可 $>1$ | 通常 $<0.75$ |

## 机制

### 哈希函数的设计原则

- **均匀性**：哈希值均匀铺在桶上，否则部分桶过长退化为 $O(n)$ 链表。
- **雪崩效应**：输入微变导致哈希大幅变化，防特定模式键聚集。形式化：相邻输入 $k,k+1$ 的 $|h(k)-h(k+1)|$ 分布近似均匀。
- **计算成本**：加密哈希分布好但每次操作贵，需在性能与均匀性间权衡。

### 负载因子与扩容时机

$\alpha$ 过大冲突加剧：链地址 $\alpha>1$ 时链表均长 $>1$；开放地址 $\alpha>0.7$ 探测序列显著增长。扩容 $O(n)$ 重哈希不可避免，但指数扩容（翻倍）让均摊 $O(1)$。

### 链地址 vs 开放地址

- **链地址**：桶内链表或红黑树存冲突元素。删除简单、聚集不传播；指针间接、缓存不友好。
- **开放地址**：冲突按探测序列找空桶。连续内存缓存友好；删除复杂（墓碑）、有聚集效应、探测序列增长。

### 布隆过滤器的语义保证

允许假阳性（"可能存在"可能其实不在），**不允许假阴性**（"必定不存在"则必定不在）。源于位只能 $0\to1$ 单调置位、不能回退——所以无法删除。

形式化：报告"不存在"→ $\neg\exists x\in\text{集合}, x=\text{查询键}$ （真阴性，100% 保证）；报告"存在"→ $\Pr(x\in\text{集合}\mid\text{报告存在})=p_{true}/p$ （假阳性率 $p$）。

### 违反约束的后果

| 违规 | 后果 | 严重度 |
|------|------|--------|
| 哈希不均匀 | $\alpha$ 正常但查找退化 $O(n)$ | 高 |
| 开放地址删除不当 | 墓碑堆积，探测膨胀至 $O(n)$ | 高 |
| 布隆位数组过小 | 假阳性飙升，校验失效 | 中 |
| 扩容未重哈希 | 键映射到旧索引，查找"丢键" | 极高 |
| 双重哈希 $h_2$ 与 $m$ 不互素 | 探测序列提前循环，部分桶永不可达 | 高 |

## 代码示例

**Python 3.12**：

```python
# 链地址法哈希表：扩容维持 O(1) 均摊
class HashMap:
    def __init__(self, capacity=4, load_factor=0.75):
        self.capacity = capacity
        self.load_factor = load_factor
        self.size = 0
        self.buckets = [[] for _ in range(capacity)]

    def _hash(self, key):
        return hash(key) % self.capacity

    def _resize(self):                       # 翻倍扩容，重哈希所有元素
        old = self.buckets
        self.capacity *= 2
        self.buckets = [[] for _ in range(self.capacity)]
        self.size = 0
        for bucket in old:
            for k, v in bucket:
                self.put(k, v)

    def put(self, key, value):
        if self.size / self.capacity > self.load_factor:
            self._resize()
        idx = self._hash(key)
        bucket = self.buckets[idx]
        for i, (k, _) in enumerate(bucket):
            if k == key:                     # 键已存在：覆盖
                bucket[i] = (key, value)
                return
        bucket.append((key, value))
        self.size += 1

    def get(self, key):
        for k, v in self.buckets[self._hash(key)]:
            if k == key:
                return v
        return None

# 布隆过滤器：位只能 0→1，无假阴性
class BloomFilter:
    def __init__(self, n, p):
        import math
        self.m = int(-n * math.log(p) / math.log(2)**2)   # 最优位数
        self.k = int(self.m / n * math.log(2))            # 最优哈希数
        self.bits = [0] * self.m

    def _hashes(self, item):
        import hashlib
        h = int(hashlib.md5(str(item).encode()).hexdigest(), 16)
        return [(h + i * (h | 1)) % self.m for i in range(self.k)]  # 双重哈希派生 k 个

    def add(self, item):
        for idx in self._hashes(item):
            self.bits[idx] = 1

    def might_contain(self, item):
        return all(self.bits[idx] for idx in self._hashes(item))

# —— 简易输入输出 ——
m = HashMap()
for i in range(10): m.put(f"k{i}", i)
print(m.get("k3"), m.get("nope"))          # 3 None

bf = BloomFilter(100, 0.01)
bf.add("hello"); bf.add("world")
print(bf.might_contain("hello"))           # True
print(bf.might_contain("missing"))         # False（必定不存在）
```

**C++20**：

```cpp
#include <iostream>
#include <vector>
#include <list>
#include <utility>      // pair
#include <optional>
#include <cmath>
#include <string>
#include <functional>   // hash

// 链地址法哈希表
class HashMap {
    std::vector<std::list<std::pair<std::string,int>>> buckets;
    size_t cap, sz = 0;
    double load = 0.75;
    size_t idx(const std::string& k) const { return std::hash<std::string>{}(k) % cap; }
    void resize() {                                    // 翻倍重哈希
        auto old = std::move(buckets);
        cap *= 2; sz = 0;
        buckets.assign(cap, {});
        for (auto& lst : old) for (auto& [k,v] : lst) put(k, v);
    }
public:
    explicit HashMap(size_t c = 4) : buckets(c), cap(c) {}
    void put(const std::string& key, int value) {
        if ((double)sz / cap > load) resize();
        auto& lst = buckets[idx(key)];
        for (auto& [k,v] : lst) if (k == key) { v = value; return; }
        lst.emplace_back(key, value); ++sz;
    }
    std::optional<int> get(const std::string& key) const {
        for (auto& [k,v] : buckets[idx(key)]) if (k == key) return v;
        return std::nullopt;
    }
};

// 布隆过滤器
class BloomFilter {
    std::vector<bool> bits;
    size_t m, k;
    size_t hash_at(const std::string& item, size_t i) const {
        auto h = std::hash<std::string>{}(item);
        return (h + i * (h | 1)) % m;                  // 双重哈希派生 k 个
    }
public:
    BloomFilter(size_t n, double p) {
        m = (size_t)std::ceil(-double(n) * std::log(p) / (std::log(2)*std::log(2)));
        k = (size_t)std::ceil(double(m) / n * std::log(2));
        bits.assign(m, false);
    }
    void add(const std::string& item) { for (size_t i=0;i<k;++i) bits[hash_at(item,i)] = true; }
    bool might_contain(const std::string& item) const {
        for (size_t i=0;i<k;++i) if (!bits[hash_at(item,i)]) return false;
        return true;
    }
};

// —— 简易输入输出 ——
int main() {
    HashMap m;
    for (int i=0;i<10;++i) m.put("k"+std::to_string(i), i);
    std::cout << m.get("k3").value_or(-1) << ' ' << m.get("nope").value_or(-1) << '\n'; // 3 -1

    BloomFilter bf(100, 0.01);
    bf.add("hello"); bf.add("world");
    std::cout << std::boolalpha << bf.might_contain("hello") << ' '      // true
              << bf.might_contain("missing") << '\n';                    // false
}
```
