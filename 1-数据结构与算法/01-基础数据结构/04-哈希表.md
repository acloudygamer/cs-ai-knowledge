# 哈希表

## 核心要点

- 键值对映射，O(1)平均插入/查找/删除
- 哈希函数将键映射到桶索引
- 冲突处理：链地址法、开放地址法

## 常用技巧

```python
# 两数之和（哈希优化）
def two_sum(nums, target):
    seen = {}
    for i, num in enumerate(nums):
        complement = target - num
        if complement in seen:
            return [seen[complement], i]
        seen[num] = i

# 字母异位词分组
def group_anagrams(strs):
    groups = {}
    for s in strs:
        key = ''.join(sorted(s))
        groups.setdefault(key, []).append(s)
    return list(groups.values())

# LRU缓存（使用OrderedDict实现O(1)复杂度）
from collections import OrderedDict

class LRUCache:
    def __init__(self, capacity: int):
        self.cache = OrderedDict()
        self.capacity = capacity

    def get(self, key: int) -> int:
        if key not in self.cache:
            return -1
        self.cache.move_to_end(key)  # 最近访问
        return self.cache[key]

    def put(self, key: int, value: int) -> None:
        if key in self.cache:
            self.cache.move_to_end(key)
        self.cache[key] = value
        if len(self.cache) > self.capacity:
            self.cache.popitem(last=False)  # 删除最旧的
```

## 布隆过滤器（Bloom Filter）

概率型数据结构，用于快速判断元素是否可能存在。

### 核心原理

- 使用 k 个哈希函数，将元素映射到长度为 m 的位数组
- 添加元素：将 k 个位置设为 1
- 查询元素：检查 k 个位置是否都为 1（都为1则可能存在，有假阳性）

```python
import hashlib

class BloomFilter:
    """
    布隆过滤器
    - n: 预期元素数量
    - fp_rate: 期望的假阳性率
    """

    def __init__(self, n=100000, fp_rate=0.01):
        self.n = n
        self.fp_rate = fp_rate

        # 计算位数组大小和哈希函数数量
        # m = -n * ln(fp_rate) / (ln(2)^2)
        import math
        self.m = int(-n * math.log(fp_rate) / (math.log(2) ** 2))
        self.k = int(self.m / n * math.log(2))  # k = (m/n) * ln(2)

        self.bit_array = [0] * self.m

    def _hashes(self, item):
        """生成 k 个哈希值"""
        item_bytes = str(item).encode()
        hash1 = int(hashlib.md5(item_bytes).hexdigest(), 16)
        hash2 = int(hashlib.sha256(item_bytes).hexdigest(), 16)

        for i in range(self.k):
            yield abs((hash1 + i * hash2) % self.m)

    def add(self, item):
        """添加元素"""
        for idx in self._hashes(item):
            self.bit_array[idx] = 1

    def might_contain(self, item):
        """检查元素是否存在（可能有假阳性）"""
        for idx in self._hashes(item):
            if self.bit_array[idx] == 0:
                return False
        return True


# 使用示例
bf = BloomFilter(n=100000, fp_rate=0.01)
bf.add("hello")
bf.add("world")
print(bf.might_contain("hello"))  # True
print(bf.might_contain("python"))  # False（确定）
```

### 布隆过滤器参数选择

| 参数 | 公式 | 说明 |
|------|------|------|
| 位数组大小 m | -n * ln(p) / (ln(2)^2) | p 为假阳性率 |
| 哈希函数数量 k | (m/n) * ln(2) | 最优数量 |

### 典型应用

- 恶意 URL 检测
- 缓存穿透防护
- 垃圾邮件过滤
- 重复 URL 检测

### 优点与局限

| 优点 | 局限 |
|------|------|
| 空间效率高 | 有假阳性（无假阴性） |
| 查询速度快 | 删除操作困难 |
| 扩展性好 | 不适合精确计数 |
