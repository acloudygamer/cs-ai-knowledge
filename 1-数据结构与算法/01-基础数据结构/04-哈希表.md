# 哈希表

## 定义

> **版本基准**: universal

哈希表是键值对存储结构，通过哈希函数 $h: \text{Key} \rightarrow [0, m-1]$ 将键映射为桶索引，在均匀分布假设下实现平均 O(1) 的查找、插入、删除。冲突不可避免，但可通过扩容和冲突解决策略将冲突概率控制在可接受范围内。 将键映射为桶索引，在均匀分布假设下实现平均 O(1) 的查找、插入、删除。冲突不可避免，但可通过扩容和冲突解决策略将冲突概率控制在可接受范围内。

**本质**：哈希表是**直接寻址的改良**——当键空间太大无法直接分配数组时，用哈希函数将键压缩到固定大小的索引空间，同时保持 O(1) 平均查找代价。

## 机制

### 哈希函数的设计原则

**均匀性**：哈希值应均匀分布在桶数组上。若分布不均（聚集），部分桶过长，退化为链表查找 O(n)。

**雪崩效应**：输入微小变化应导致哈希值大幅变化，防止特定模式键聚集到少数桶。形式化：对任意相邻输入 $k, k+1$ ， $|h(k) - h(k+1)|$ 的分布应接近均匀。 ， $|h(k) - h(k+1)|$ 的分布应接近均匀。 的分布应接近均匀。

**计算成本**：复杂哈希函数（如加密哈希）虽分布好，但每次操作均有代价。在性能和均匀性间取平衡是工程决策。

### 冲突解决：链地址法 vs 开放地址法

**链地址法**：桶内用链表（ $O(\alpha)$ 查找）或红黑树（ $O(\log \alpha)$ 查找）存储冲突元素。优点：删除简单，聚集不传播。缺点：指针间接访问，缓存不友好。 查找）或红黑树（ $O(\log \alpha)$ 查找）存储冲突元素。优点：删除简单，聚集不传播。缺点：指针间接访问，缓存不友好。 查找）存储冲突元素。优点：删除简单，聚集不传播。缺点：指针间接访问，缓存不友好。

**开放地址法**：冲突时按探测序列寻找空桶。优点：连续内存，缓存友好。缺点：删除复杂（墓碑标记），聚集效应（一次聚集：线性探测；二次聚集：二次探测），探测序列增长。

### 布隆过滤器的语义保证

允许假阳性：查询返回"可能存在"时，该元素可能实际不在集合中。
不允许假阴性：查询返回"必定不存在"时，该元素必定不在集合中。

这源于位数组的位只能从 0 置 1、从不能从 1 置 0 的单调性。删除操作无法实现（将位从 1 改回 0 会影响其他元素）。

**形式化语义**：
- 若布隆过滤器报告"不存在"： $\neg \exists x \in \text{集合}, x = \text{查询键}$ （真阴性，保证 100%） （真阴性，保证 100%）
- 若布隆过滤器报告"存在"： $\Pr(x \in \text{集合} \mid \text{报告存在}) = \frac{p_{\text{true}}}{p}$ （假阳性率  $p$） （假阳性率  $p$ ））

### 违反约束的后果

| 违规行为 | 后果 | 严重程度 |
|---------|------|---------|
| 哈希函数不均匀 | 负载因子正常但查找退化至 O(n) | 高 |
| 开放地址法删除不当 | 墓碑过多导致探测序列膨胀，查找性能退化至 O(n) | 高 |

class HashMap:
    def __init__(self, capacity=4, load_factor=0.75):
        self.capacity = capacity
        self.load_factor = load_factor
        self.size = 0
        self.buckets = [[] for _ in range(capacity)]

    def _hash(self, key):
        return hash(key) % self.capacity

    def _resize(self):
        old_buckets = self.buckets
        self.capacity *= 2
        self.buckets = [[] for _ in range(self.capacity)]
        self.size = 0
        for bucket in old_buckets:
            for k, v in bucket:
                self.put(k, v)

    def put(self, key, value):
        if self.size / self.capacity > self.load_factor:
            self._resize()
        idx = self._hash(key)
        bucket = self.buckets[idx]
        for i, (k, _) in enumerate(bucket):
            if k == key:
                bucket[i] = (key, value)
                return
        bucket.append((key, value))
        self.size += 1

    def get(self, key):
        idx = self._hash(key)
        for k, v in self.buckets[idx]:
            if k == key:
                return v
        return None

class BloomFilter:
    def __init__(self, n, p):
        import math
        m = int(-n * math.log(p) / math.log(2)**2)
        k = int(m / n * math.log(2))
        self.bits = [0] * m
        self.m, self.k = m, k

    def _hashes(self, item):
        import hashlib
        h = int(hashlib.md5(str(item).encode()).hexdigest(), 16)
        return [(h + i * h) % self.m for i in range(self.k)]

    def add(self, item):
        for idx in self._hashes(item):
            self.bits[idx] = 1

    def might_contain(self, item):
        return all(self.bits[idx] for idx in self._hashes(item))
