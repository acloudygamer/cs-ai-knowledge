# 哈希表

### 解决什么问题
实现 O(1) 平均时间复杂度的键值查找，适用于快速查找、去重、缓存实现等场景，是面试和工程中最高效的数据结构之一。

### 核心概念
- 哈希函数：将键映射到桶索引
- 冲突处理：链地址法（拉链）、开放地址法（线性探测、二次探测）
- 负载因子：填充比例，影响哈希表性能
- 布隆过滤器：空间效率高的概率数据结构，支持快速判断存在性（有假阳性无假阴性）

### 怎么用

## 核心要点

- 键值对映射，O(1)平均插入/查找/删除
- 哈希函数将键映射到桶索引
- 冲突处理：链地址法、开放地址法

```python
# 两数之和（哈希优化）
def two_sum(nums, target):
    seen = {}
    for i, num in enumerate(nums):
        complement = target - num
        if complement in seen:
            return [seen[complement], i]
        seen[num] = i

# 字母异位词分组
def group_anagrams(strs):
    groups = {}
    for s in strs:
        key = ''.join(sorted(s))
        groups.setdefault(key, []).append(s)
    return list(groups.values())

# LRU缓存（使用OrderedDict实现O(1)复杂度）
from collections import OrderedDict

class LRUCache:
    def __init__(self, capacity: int):
        self.cache = OrderedDict()
        self.capacity = capacity

    def get(self, key: int) -> int:
        if key not in self.cache:
            return -1
        self.cache.move_to_end(key)  # 最近访问
        return self.cache[key]

    def put(self, key: int, value: int) -> None:
        if key in self.cache:
            self.cache.move_to_end(key)
        self.cache[key] = value
        if len(self.cache) > self.capacity:
            self.cache.popitem(last=False)  # 删除最旧的
```

## 布隆过滤器（Bloom Filter）

概率型数据结构，用于快速判断元素是否可能存在。

### 核心原理

- 使用 k 个哈希函数，将元素映射到长度为 m 的位数组
- 添加元素：将 k 个位置设为 1
- 查询元素：检查 k 个位置是否都为 1（都为1则可能存在，有假阳性）

```python
import hashlib

class BloomFilter:
    """
    布隆过滤器
    - n: 预期元素数量
    - fp_rate: 期望的假阳性率
    """

    def __init__(self, n=100000, fp_rate=0.01):
        self.n = n
        self.fp_rate = fp_rate

        # 计算位数组大小和哈希函数数量
        # m = -n * ln(fp_rate) / (ln(2)^2)
        import math
        self.m = int(-n * math.log(fp_rate) / (math.log(2) ** 2))
        self.k = int(self.m / n * math.log(2))  # k = (m/n) * ln(2)

        self.bit_array = [0] * self.m

    def _hashes(self, item):
        """生成 k 个哈希值"""
        item_bytes = str(item).encode()
        hash1 = int(hashlib.md5(item_bytes).hexdigest(), 16)
        hash2 = int(hashlib.sha256(item_bytes).hexdigest(), 16)

        for i in range(self.k):
            yield abs((hash1 + i * hash2) % self.m)

    def add(self, item):
        """添加元素"""
        for idx in self._hashes(item):
            self.bit_array[idx] = 1

    def might_contain(self, item):
        """检查元素是否存在（可能有假阳性）"""
        for idx in self._hashes(item):
            if self.bit_array[idx] == 0:
                return False
        return True


# 使用示例
bf = BloomFilter(n=100000, fp_rate=0.01)
bf.add("hello")
bf.add("world")
print(bf.might_contain("hello"))  # True
print(bf.might_contain("python"))  # False（确定）
```

### 布隆过滤器参数公式

#### 假阳性率推导

设位数组大小为 m，插入 n 个元素，使用 k 个哈希函数。

**单次哈希，某一位为 0 的概率**：
$$P(某一位为0) = (1 - \frac{1}{m})^{kn}$$

**k 个哈希函数后，某一位仍为 0 的概率**：
$$P(某一位仍为0) = (1 - \frac{1}{m})^{kn} \approx e^{-\frac{kn}{m}}$$

**假阳性率（k 位全为 1 的概率）**：
$$p = (1 - P(某一位仍为0))^k = (1 - e^{-\frac{kn}{m}})^k$$

#### 最优参数求解

对 p 关于 k 求导，令导数为 0：

$$k_{opt} = \frac{m}{n} \ln 2 \approx 0.7 \frac{m}{n}$$

#### 最优位数组大小

将 $k_{opt}$ 代入 p 的公式：

$$p_{opt} = (1 - e^{-\frac{m}{n} \ln 2 \cdot \frac{n}{m}})^{k_{opt}} = (1 - e^{-\ln 2})^{k_{opt}} = (\frac{1}{2})^{k_{opt}}$$

由 $k_{opt} = \frac{m}{n} \ln 2$ 和 $p_{opt}$ 反推：

$$m_{opt} = -\frac{n \ln p}{(\ln 2)^2}$$

### 哈希函数设计

理想情况下使用 k 个独立哈希函数，但实际中常用以下方法生成多个哈希值：

```python
class DoubleHashBloomFilter:
    """双哈希函数法：使用 h1 和 h2 生成 k 个哈希值"""

    def __init__(self, size, hash_funcs=3):
        self.size = size
        self.k = hash_funcs
        self.bit_array = [0] * size

    def _double_hash(self, item):
        """双哈希：h(i) = h1 + i * h2"""
        h1 = hash(item) % self.size
        h2 = hash(str(item)[::-1]) % (self.size - 1) + 1

        for i in range(self.k):
            yield (h1 + i * h2) % self.size
```

### 布隆过滤器变体

#### 1. 可计数的布隆过滤器 (Counting Bloom Filter)

用计数器数组代替位数组，支持删除操作。

```python
class CountingBloomFilter:
    """可计数的布隆过滤器"""

    def __init__(self, n, fp_rate):
        import math
        self.m = int(-n * math.log(fp_rate) / (math.log(2) ** 2))
        self.k = int(self.m / n * math.log(2))
        self.counters = [0] * self.m

    def add(self, item):
        for idx in self._hashes(item):
            self.counters[idx] += 1

    def remove(self, item):
        for idx in self._hashes(item):
            if self.counters[idx] > 0:
                self.counters[idx] -= 1

    def might_contain(self, item):
        for idx in self._hashes(item):
            if self.counters[idx] == 0:
                return False
        return True
```

#### 2. 扩容布隆过滤器 (Scalable Bloom Filter)

当空间不足时，创建新的布隆过滤器并逐步迁移。

```python
class ScalableBloomFilter:
    """可扩容的布隆过滤器"""

    def __init__(self, initial_size, fp_rate):
        self.filters = []
        self.initial_size = initial_size
        self.fp_rate = fp_rate
        self._add_filter()

    def _add_filter(self):
        current_size = self.initial_size * len(self.filters)
        self.filters.append(BloomFilter(current_size, self.fp_rate))

    def add(self, item):
        if not self.filters[-1].might_contain(item):
            self.filters[-1].add(item)
            # 如果当前过滤器快满了，添加新过滤器
            if self._is_full():
                self._add_filter()

    def might_contain(self, item):
        return any(f.might_contain(item) for f in self.filters)
```

### 典型应用

| 应用场景 | 说明 |
|---------|------|
| 恶意 URL 检测 | 先用布隆过滤器快速判断，大概率拒绝 |
| 缓存穿透防护 | Redis + 布隆过滤器，防止无效查询击穿缓存 |
| 垃圾邮件过滤 | 快速判断邮件是否在黑名单 |
| 重复 URL 检测 | URL 去重，减少数据库压力 |
| 区块链 | Bitcoin 使用布隆过滤器做 SPV 节点 |

### 优点与局限

| 优点 | 局限 |
|------|------|
| 空间效率高 | 有假阳性（无假阴性） |
| 查询速度快 O(k) | 删除操作困难（原版） |
| 扩展性好 | 不适合精确计数 |
| 简单易实现 | 参数选择影响准确性 |
