# 数组与字符串

### 解决什么问题
数组提供 O(1) 随机访问，适用于频繁查询、顺序遍历的场景；字符串操作处理文本模式匹配、子串查找等问题。

### 核心概念
- 数组：连续内存存储，O(1) 随机访问，插入/删除平均 O(n)
- 前缀和：区间查询从 O(n) 降至 O(1)
- 差分数组：区间批量更新从 O(n) 降至 O(1)
- 二维前缀和：子矩阵查询 O(1)
- 字符串不可变，频繁修改用 list

```python
# 区域和检索
class PrefixSum:
    def __init__(self, nums):
        self.prefix = [0]
        for num in nums:
            self.prefix.append(self.prefix[-1] + num)

    def sum_range(self, left, right):
        return self.prefix[right + 1] - self.prefix[left]
```

### 差分数组

区间更新优化，将O(n)的区间更新变为O(1)。

```python
class DifferenceArray:
    """
    差分数组：支持区间加法，最后还原原数组
    区间更新: O(1)，还原: O(n)
    """

    def __init__(self, arr):
        self.n = len(arr)
        self.diff = [0] * (self.n + 1)
        # 构建差分数组
        self.diff[0] = arr[0]
        for i in range(1, self.n):
            self.diff[i] = arr[i] - arr[i - 1]

    def range_add(self, left, right, val):
        """
        对区间 [left, right] 的所有元素加 val
        时间复杂度: O(1)
        """
        self.diff[left] += val
        if right + 1 < self.n:
            self.diff[right + 1] -= val

    def restore(self):
        """
        从差分数组还原原数组
        时间复杂度: O(n)
        """
        result = [0] * self.n
        result[0] = self.diff[0]
        for i in range(1, self.n):
            result[i] = result[i - 1] + self.diff[i]
        return result


# 航班预订问题（LeetCode 1109）
def corp_flight_bookings(bookings, n):
    """
    bookings: [[first, last, seats], ...]
    n: 航班数
    使用差分数组 O(n + len(bookings))
    """
    diff = [0] * (n + 1)

    for first, last, seats in bookings:
        diff[first - 1] += seats  # 起点加
        if last < n:
            diff[last] -= seats   # 终点后一位减
        # last == n 时不用减，因为数组长度是 n

    result = [0] * n
    result[0] = diff[0]
    for i in range(1, n):
        result[i] = result[i - 1] + diff[i]

    return result
```

### 二维前缀和

```python
class PrefixSum2D:
    """
    二维前缀和：快速计算子矩阵元素和
    """

    def __init__(self, matrix):
        if not matrix or not matrix[0]:
            self.m, self.n = 0, 0
            self.prefix = []
            return

        self.m, self.n = len(matrix), len(matrix[0])
        self.prefix = [[0] * (self.n + 1) for _ in range(self.m + 1)]

        for i in range(self.m):
            row_sum = 0
            for j in range(self.n):
                row_sum += matrix[i][j]
                self.prefix[i + 1][j + 1] = self.prefix[i][j + 1] + row_sum

    def sum_region(self, row1, col1, row2, col2):
        """
        计算左上角 (row1, col1) 到右下角 (row2, col2) 的子矩阵和
        时间复杂度: O(1)
        """
        return (
            self.prefix[row2 + 1][col2 + 1]
            - self.prefix[row1][col2 + 1]
            - self.prefix[row2 + 1][col1]
            + self.prefix[row1][col1]
        )
```

```python
# 有效的字母异位词
def is_anagram(s, t):
    if len(s) != len(t):
        return False
    count = [0] * 256
    for c in s:
        count[ord(c)] += 1
    for c in t:
        count[ord(c)] -= 1
        if count[ord(c)] < 0:
            return False
    return True
```

## 二维数组操作

### 螺旋矩阵遍历

```python
def spiral_order(matrix):
    """
    按顺时针螺旋顺序遍历矩阵
    时间复杂度: O(m*n)
    """
    if not matrix:
        return []

    result = []
    top, bottom, left, right = 0, len(matrix) - 1, 0, len(matrix[0]) - 1

    while top <= bottom and left <= right:
        # 左→右
        for col in range(left, right + 1):
            result.append(matrix[top][col])
        top += 1

        # 上→下
        for row in range(top, bottom + 1):
            result.append(matrix[row][right])
        right -= 1

        # 右→左（避免重复遍历）
        if top <= bottom:
            for col in range(right, left - 1, -1):
                result.append(matrix[bottom][col])
            bottom -= 1

        # 下→上（避免重复遍历）
        if left <= right:
            for row in range(bottom, top - 1, -1):
                result.append(matrix[row][left])
            left += 1

    return result
```

### 旋转矩阵

```python
def rotate_matrix(matrix):
    """
    原地旋转 n*n 矩阵 90 度
    先转置，再翻转每行
    """
    n = len(matrix)
    # 转置
    for i in range(n):
        for j in range(i + 1, n):
            matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
    # 翻转每行
    for row in matrix:
        row.reverse()

def rotate_matrix_anticlockwise(matrix):
    """
    逆时针旋转 90 度
    先转置，再翻转每列
    """
    n = len(matrix)
    for i in range(n):
        for j in range(i + 1, n):
            matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
    for j in range(n):
        top, bottom = 0, n - 1
        while top < bottom:
            matrix[top][j], matrix[bottom][j] = matrix[bottom][j], matrix[top][j]
            top += 1
            bottom -= 1
```

### Z 字形变换

```python
def convert(s, num_rows):
    """
    Z 字形变换（LeetCode 6）
    将字符串按 Z 字形排列，按行读取
    时间复杂度: O(n)
    """
    if num_rows == 1 or num_rows >= len(s):
        return s

    rows = [''] * num_rows
    current_row = 0
    going_down = False

    for c in s:
        rows[current_row] += c
        # 到达转折点时改变方向
        if current_row == 0 or current_row == num_rows - 1:
            going_down = not going_down
        current_row += 1 if going_down else -1

    return ''.join(rows)
```

## 数组技巧总结

| 技巧 | 适用场景 | 复杂度 |
|------|----------|--------|
| 前缀和 | 区间求和 | 查询 O(1) |
| 差分数组 | 区间批量更新 | 更新 O(1) |
| 二维前缀和 | 矩阵区域和 | 查询 O(1) |
| 双指针 | 两数之和、三数之和 | O(n) |
| 滑动窗口 | 子串/子数组问题 | O(n) |
| 哈希表 | 快速查找、去重 | 平均 O(1) |
