# 数组与字符串

## 定义

数组是连续内存中同构元素的空间排列，支持 O(1) 随机访问；字符串是不可变的字符序列，操作它需要创建新副本。

## 数学模型

**一维前缀和**

区间 $[l, r]$ 的和：

$$
S(l, r) = prefix[r+1] - prefix[l]
$$

其中 $prefix[i] = \sum_{j=0}^{i-1} arr[j]$

**二维前缀和**

子矩阵 $(r_1, c_1)$ 到 $(r_2, c_2)$ 的和：

$$
S = prefix[r_2+1][c_2+1] - prefix[r_1][c_2+1] - prefix[r_2+1][c_1] + prefix[r_1][c_1]
$$

**差分数组**

区间 $[l, r]$ 加 $\Delta$：

$$
diff[l] += \Delta,\quad diff[r+1] -= \Delta
$$

还原时对 diff 做前缀和。

## 数据流

**前缀和构建**

<pre>
[1, 2, 3, 4, 5]
  ↓ 累加
[0, 1, 3, 6, 10, 15]  ← prefix[0]=0 作为哨兵
</pre>

**二维前缀和构建**

<pre>
原矩阵 (2x3)      prefix矩阵 (3x4)
[a00, a01, a02]   [0,  0,  0,  0 ]
[a10, a11, a12]   [0, a00,a00+a01,a00+a01+a02]
                   [0, a00+a10, ...        ]
</pre>

**字符串不可变**

<pre>
原始: "hello"
操作: s + "world"
结果: 新建 "helloworld"（原 "hello" 不变）
</pre>

## 机制

**连续内存赋予 O(1) 随机访问**

数组元素地址：`addr(i) = base_addr + i × element_size`

CPU 缓存利用空间局部性，连续内存支持缓存行批量加载，实践中比理论 O(1) 更快。

**字符串不可变简化共享**

多线程读取同一字符串无需同步；字符串字面量可驻留池中复用；哈希计算可缓存结果。

**违规后果**

- 插入/删除需移动后续所有元素：最坏 O(n)
- 字符串拼接创建新副本：O(n) 空间与时间
- 大小超出预分配需重新分配并复制：摊销 O(n)

```python
class PrefixSum:
    def __init__(self, nums):
        self.prefix = [0]
        for num in nums:
            self.prefix.append(self.prefix[-1] + num)

    def range_sum(self, left, right):
        return self.prefix[right + 1] - self.prefix[left]
```

```python
def rotate_matrix(matrix):
    n = len(matrix)
    for i in range(n):
        for j in range(i + 1, n):
            matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
    for row in matrix:
        row.reverse()
```

```python
def is_palindrome(s):
    l, r = 0, len(s) - 1
    while l < r:
        while l < r and not s[l].isalnum():
            l += 1
        while l < r and not s[r].isalnum():
            r -= 1
        if s[l].lower() != s[r].lower():
            return False
        l += 1
        r -= 1
    return True
```
