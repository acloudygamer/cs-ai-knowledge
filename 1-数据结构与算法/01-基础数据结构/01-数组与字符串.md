## 数组与字符串

### 解决什么问题
数组提供 O(1) 随机访问，适用于频繁查询、顺序遍历的场景；字符串操作处理文本模式匹配、子串查找等问题。

### 核心概念
- **数组**：连续内存存储，O(1) 随机访问，插入/删除平均 O(n)
- **前缀和**：区间查询从 O(n) 降至 O(1)
- **差分数组**：区间批量更新从 O(n) 降至 O(1)
- **二维前缀和**：子矩阵查询 O(1)
- **字符串不可变**，频繁修改用 list

### 前缀和

区间查询优化，将 O(n) 的区间求和降至 O(1)。

**机制解释**：前缀和数组 `prefix[i]` 表示原数组前 i 个元素的和。区间 [left, right] 的和等于 `prefix[right+1] - prefix[left]`。

### 参考样例

```python
class PrefixSum:
    def __init__(self, nums):
        self.prefix = [0]
        for num in nums:
            self.prefix.append(self.prefix[-1] + num)

    def sum_range(self, left, right):
        return self.prefix[right + 1] - self.prefix[left]
```

### 差分数组

区间批量更新优化，将 O(n) 的区间更新降至 O(1)。

**机制解释**：差分数组 `diff[i]` 表示原数组第 i 个元素与第 i-1 个元素的差值。对区间 [left, right] 加 val，只需修改 `diff[left] += val` 和 `diff[right+1] -= val`，最后通过前缀和还原。

### 参考样例

```python
class DifferenceArray:
    def __init__(self, arr):
        self.n = len(arr)
        self.diff = [0] * (self.n + 1)
        self.diff[0] = arr[0]
        for i in range(1, self.n):
            self.diff[i] = arr[i] - arr[i - 1]

    def range_add(self, left, right, val):
        self.diff[left] += val
        if right + 1 < self.n:
            self.diff[right + 1] -= val

    def restore(self):
        result = [0] * self.n
        result[0] = self.diff[0]
        for i in range(1, self.n):
            result[i] = result[i - 1] + self.diff[i]
        return result
```

### 二维前缀和

子矩阵元素和查询 O(1)。

**机制解释**：构建二维前缀和数组 `prefix[i+1][j+1]` 表示 matrix[0:i][0:j] 的元素和。子矩阵 (row1, col1) 到 (row2, col2) 的和通过容斥原理计算。

### 参考样例

```python
class PrefixSum2D:
    def __init__(self, matrix):
        if not matrix or not matrix[0]:
            self.m, self.n = 0, 0
            self.prefix = []
            return
        self.m, self.n = len(matrix), len(matrix[0])
        self.prefix = [[0] * (self.n + 1) for _ in range(self.m + 1)]
        for i in range(self.m):
            row_sum = 0
            for j in range(self.n):
                row_sum += matrix[i][j]
                self.prefix[i + 1][j + 1] = self.prefix[i][j + 1] + row_sum

    def sum_region(self, row1, col1, row2, col2):
        return (
            self.prefix[row2 + 1][col2 + 1]
            - self.prefix[row1][col2 + 1]
            - self.prefix[row2 + 1][col1]
            + self.prefix[row1][col1]
        )
```

### 字符串操作技巧

- 字符串不可变，频繁修改用 list 或 StringBuilder
- 回文判断：双指针或反转比较
- 字母异位词：排序或计数比较

### 参考样例

```python
def is_anagram(s, t):
    if len(s) != len(t):
        return False
    count = [0] * 256
    for c in s:
        count[ord(c)] += 1
    for c in t:
        count[ord(c)] -= 1
        if count[ord(c)] < 0:
            return False
    return True
```

### 螺旋矩阵遍历

按顺时针螺旋顺序遍历矩阵。

**机制解释**：维护四个边界 (top, bottom, left, right)，每次遍历一行/列后收缩边界，直到边界相遇。

### 参考样例

```python
def spiral_order(matrix):
    if not matrix:
        return []
    result = []
    top, bottom, left, right = 0, len(matrix) - 1, 0, len(matrix[0]) - 1
    while top <= bottom and left <= right:
        for col in range(left, right + 1):
            result.append(matrix[top][col])
        top += 1
        for row in range(top, bottom + 1):
            result.append(matrix[row][right])
        right -= 1
        if top <= bottom:
            for col in range(right, left - 1, -1):
                result.append(matrix[bottom][col])
            bottom -= 1
        if left <= right:
            for row in range(bottom, top - 1, -1):
                result.append(matrix[row][left])
            left += 1
    return result
```

### 旋转矩阵

原地旋转 n*n 矩阵 90 度。

**机制解释**：先转置（交换 matrix[i][j] 和 matrix[j][i]），再翻转每行。

### 参考样例

```python
def rotate_matrix(matrix):
    n = len(matrix)
    for i in range(n):
        for j in range(i + 1, n):
            matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
    for row in matrix:
        row.reverse()

def rotate_matrix_anticlockwise(matrix):
    n = len(matrix)
    for i in range(n):
        for j in range(i + 1, n):
            matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
    for j in range(n):
        top, bottom = 0, n - 1
        while top < bottom:
            matrix[top][j], matrix[bottom][j] = matrix[bottom][j], matrix[top][j]
            top += 1
            bottom -= 1
```

### Z 字形变换

将字符串按 Z 字形排列，按行读取。

**机制解释**：维护 num_rows 个字符串行，用 direction 变量控制当前是向下走还是向上走。到达转折点（第一行或最后一行）时反转方向。

### 参考样例

```python
def convert(s, num_rows):
    if num_rows == 1 or num_rows >= len(s):
        return s
    rows = [''] * num_rows
    current_row = 0
    going_down = False
    for c in s:
        rows[current_row] += c
        if current_row == 0 or current_row == num_rows - 1:
            going_down = not going_down
        current_row += 1 if going_down else -1
    return ''.join(rows)
```

### 数组技巧总结

| 技巧 | 适用场景 | 复杂度 |
|------|----------|--------|
| 前缀和 | 区间求和 | 查询 O(1) |
| 差分数组 | 区间批量更新 | 更新 O(1) |
| 二维前缀和 | 矩阵区域和 | 查询 O(1) |
| 双指针 | 两数之和、三数之和 | O(n) |
| 滑动窗口 | 子串/子数组问题 | O(n) |
| 哈希表 | 快速查找、去重 | 平均 O(1) |
