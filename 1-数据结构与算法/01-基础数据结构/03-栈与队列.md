# 栈与队列

## 核心要点

- 栈：LIFO，后进先出
- 队列：FIFO，先进先出
- 常用于递归转迭代、括号匹配、层次遍历

## 括号匹配

```python
def is_valid(s):
    stack = []
    mapping = {')': '(', ']': '[', '}': '{'}
    for c in s:
        if c in mapping:
            if not stack or stack.pop() != mapping[c]:
                return False
        else:
            stack.append(c)
    return not stack
```

## 队列实现栈 / 栈实现队列

```python
# 用两个队列实现栈
# 注意：list.pop(0) 是 O(n)，生产环境建议使用 collections.deque
from collections import deque

class MyStack:
    def __init__(self):
        self.q1, self.q2 = deque(), deque()

    def push(self, x):
        self.q1.append(x)

    def pop(self):
        while len(self.q1) > 1:
            self.q2.append(self.q1.popleft())  # deque.popleft() 是 O(1)
        result = self.q1.popleft()
        self.q1, self.q2 = self.q2, self.q1
        return result

# 用一个栈实现队列
class MyQueue:
    def __init__(self):
        self.stack = []

    def push(self, x):
        # 入队元素直接加入
        self.stack.append(x)

    def pop(self):
        # 出队需要反转顺序，使用另一个栈
        if not self.stack:
            return None
        # 移动到辅助栈
        temp = []
        while self.stack:
            temp.append(self.stack.pop())
        result = temp.pop()
        # 移回原栈
        while temp:
            self.stack.append(temp.pop())
        return result
```

## 单调队列

单调队列是一种特殊队列，队内元素保持单调递增或递减。常用于滑动窗口求最值。

### 核心原理

- 入队时移除所有破坏单调性的元素
- 出队时移除过期元素（超出窗口范围）
- 队首始终是当前窗口的最大/最小值

### 实现

```python
from collections import deque

class MonotonicQueue:
    """单调递减队列，队首存储最大值"""
    def __init__(self):
        self.queue = deque()

    def push(self, val):
        """入队：移除所有小于 val 的元素（它们不可能是最大值）"""
        while self.queue and self.queue[-1] < val:
            self.queue.pop()
        self.queue.append(val)

    def pop(self, val):
        """出队：如果移除的是最大值，则从队首移除"""
        if self.queue and self.queue[0] == val:
            self.queue.popleft()

    def max(self):
        """获取最大值：队首即最大值"""
        return self.queue[0] if self.queue else None
```

### 滑动窗口最大值（LeetCode 239）

```python
def max_sliding_window(nums, k):
    """
    单调递减队列
    时间复杂度: O(n)，空间复杂度: O(k)
    """
    queue = deque()  # 存储元素索引
    result = []

    for i in range(len(nums)):
        # 入队：移除队列中所有小于当前元素的索引
        while queue and nums[queue[-1]] < nums[i]:
            queue.pop()
        queue.append(i)

        # 出队：移除超出窗口范围的索引
        while queue[0] <= i - k:
            queue.popleft()

        # 记录结果
        if i >= k - 1:
            result.append(nums[queue[0]])

    return result
```

## 优先队列（堆）

Python 的 `heapq` 是小顶堆，实现 priority queue。

```python

# 合并 K 个有序链表（最小堆）
def merge_k_lists(lists):
    heap = []
    for i, lst in enumerate(lists):
        if lst:
            heapq.heappush(heap, (lst.val, i, lst))

    curr = dummy

            heapq.heappush(heap, (node.next.val, i, node.next))

# Top K 问题
def top_k(nums, k):
    """找前 k 大的数"""
    return heapq.nlargest(k, nums)

def kth_largest(nums, k):
    """找第 k 大的数（1-indexed）"""
    return heapq.nlargest(k, nums)[-1]
```

## 典型应用场景

| 场景 | 数据结构 | 说明 |
|------|----------|------|
| 函数调用栈 | 栈 | 递归转迭代 |
| 括号匹配 | 栈 | 有效括号判断 |
| 层次遍历 | 队列 | BFS |
| 滑动窗口最值 | 单调队列 | O(1) 获取窗口最大/最小 |
| 任务调度 | 优先队列 | 按优先级排序 |
