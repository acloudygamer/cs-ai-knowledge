## 栈与队列

### 解决什么问题
栈（LIFO）适用于递归转迭代、括号匹配、单调栈等场景；队列（FIFO）适用于 BFS 层次遍历、任务调度等场景。

### 核心概念
- **栈**：后进先出，插入删除 O(1)
- **队列**：先进先出，插入删除 O(1)
- **双端队列（Deque）**：两端插入删除都是 O(1)
- **优先队列**：元素按优先级出队（堆实现）

### 典型应用场景

| 场景 | 数据结构 | 说明 |
|------|----------|------|
| 函数调用栈 | 栈 | 递归转迭代 |
| 括号匹配 | 栈 | 有效括号判断 |
| 单调栈 | 栈 | Next Greater/Smaller Element |
| 层次遍历 | 队列 | BFS |
| 任务调度 | 优先队列 | 按优先级排序 |
| 滑动窗口最值 | 双端队列 | 单调队列 |
| 循环队列 | 环形缓冲区 | 资源池管理 |

### 栈与队列实现

Python 中栈用 list 的 append/pop，队列用 collections.deque。

### 参考样例

```python
from collections import deque

# 栈：用 list 的 append/pop
stack = []
stack.append(1)
stack.pop()

# 队列：用 deque（注意：list.pop(0) 是 O(n)，不可用）
queue = deque()
queue.append(1)
queue.popleft()

# deque 支持两端操作
dq = deque()
dq.appendleft(x)
dq.append(x)
dq.pop()
dq.popleft()
```

### 括号匹配

栈的经典应用，遍历字符串，左括号入栈，右括号匹配出栈。

### 参考样例

```python
def is_valid(s):
    stack = []
    mapping = {')': '(', ']': '[', '}': '{'}
    for c in s:
        if c in mapping:
            if not stack or stack.pop() != mapping[c]:
                return False
        else:
            stack.append(c)
    return not stack
```

### 队列实现栈 / 栈实现队列

用两个队列实现栈，或用一个栈实现队列。

### 参考样例

```python
from collections import deque

class MyStack:
    def __init__(self):
        self.q1, self.q2 = deque(), deque()

    def push(self, x):
        self.q1.append(x)

    def pop(self):
        while len(self.q1) > 1:
            self.q2.append(self.q1.popleft())
        result = self.q1.popleft()
        self.q1, self.q2 = self.q2, self.q1
        return result

class MyQueue:
    def __init__(self):
        self.stack = []

    def push(self, x):
        self.stack.append(x)

    def pop(self):
        if not self.stack:
            return None
        temp = []
        while self.stack:
            temp.append(self.stack.pop())
        result = temp.pop()
        while temp:
            self.stack.append(temp.pop())
        return result
```
