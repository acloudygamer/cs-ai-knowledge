# 栈与队列

## 定义

栈（Stack）是单端存取的线性结构，遵循后进先出（LIFO, Last-In-First-Out）原则：所有操作集中在结构的一端（栈顶）进行插入（push）和删除（pop）。

队列（Queue）是双端存取的线性结构，遵循先进先出（FIFO, First-In-First-Out）原则：插入（enqueue）在队尾进行，删除（dequeue）在队头进行。

**本质操作**：栈的本质是**嵌套作用域的状态保存与恢复**；队列的本质是**资源竞争的先来先服务仲裁**。两者都是限制访问自由度的结构——栈通过禁止中间访问强制嵌套顺序，队列通过禁止插队强制公平顺序。

## 数学模型

### 栈的容量约束

设栈的最大容量为 $k$（若动态扩容则 $k$ 随容量变化），栈高度 $h$ 始终满足：
$$0 \leq h \leq k$$

**状态机描述**：栈的状态转移是高度的有界递增/递减：
$$h \xrightarrow{push(x)} h+1 \quad \text{当 } h < k$$
$$h \xrightarrow{pop()} h-1 \quad \text{当 } h > 0$$

**归约终点**：栈的状态空间可归约为二元组 $(h, S)$，其中 $h$ 为栈高度，$S$ 为栈顶以下元素的有序序列。操作语义归结为高度的有界增减和栈顶元素的替换。

### 单调栈（Monotonic Stack）

单调递减栈用于求解 Next Greater Element（NGE）：对每个位置 $i$，找到右侧第一个大于 $nums[i]$ 的元素。

设栈中存储下标，满足**栈底到栈顶对应值单调递减**：
$$nums[stack[0]] > nums[stack[1]] > \dots > nums[stack[top]]$$

算法状态转移：
$$\text{while } stack \land nums[i] > nums[stack.top()] \implies next[stack.pop()] = nums[i]$$

正确性基于：若 $nums[i]$ 大于栈顶，则栈顶的 NGE 必为 $nums[i]$（因为栈顶右侧、$i$ 左侧不存在更大元素）。

**复杂度**：每个元素最多入栈出栈各一次，总时间 $O(n)$，空间 $O(k)$。

### 优先队列出队顺序

优先队列通常用完全二叉堆实现，出队代价：
$$T(n) = T(n/2) + O(1) = O(\log n)$$

堆的数组表示（1-indexed）：父节点 $parent(i) = \lfloor i/2 \rfloor$，左子 $left(i) = 2i$，右子 $right(i) = 2i+1$。

**归约终点**：堆的 $O(\log n)$ 出队代价归结为完全二叉树的高度 $\lfloor \log_2 n \rfloor$，每次 sift-down 最坏沿一条路径向下比较。

### 循环队列满/空判断

设容量为 $k$（实际存储 $k$ 个元素），用 `head` 和 `tail` 指针追踪：
$$\text{empty} \Leftrightarrow head == tail$$
$$\text{full} \Leftrightarrow (tail + 1) \bmod k == head$$

这是**牺牲一个存储单元**换取判断一致性的经典权衡：满状态和空状态都满足 `head == tail`，无法直接区分，必须通过额外状态位或上述空位约定。

## 数据流

### 栈操作数据流

<pre>
push(x):
  [a, b, c]  ──push(x)──>  [a, b, c, x]
  栈顶指针 +1，x 成为新栈顶

pop():
  [a, b, c, x]  ──pop()──>  [a, b, c], 返回 x
  栈顶指针 -1，c 成为新栈顶

所有权转移：push 时数据所有权归栈结构；pop 时栈顶数据所有权返回调用者，栈放弃管理权
</pre>

### 队列操作数据流

<pre>
enqueue(x):
  [head][a][b][c][tail]  ──enqueue(x)──>  [head][a][b][c][x][tail]
  tail 后移，x 进入队尾

dequeue():
  [head][a][b][c]  ──dequeue()──>  [head][b][c], 返回 a
  head 后移，a 所有权返回调用者
</pre>

### 循环队列数据流

<pre>
状态转移（k=5, 实际存4个元素）:

初始: [h][ ][ ][ ][ ][t]     h=t=0, 空
入队4个: [h][1][2][3][4][t]  h=0, t=4, (4+1)%5=0=h, 满

出队1个:  [h][ ][2][3][4][t] h=1, t=4, 队首元素1被移除
再入队5:   [h][5][2][3][4][t] t=0, 覆盖已出队位置（物理环，逻辑线性）
</pre>

**数据形态变换**：循环队列的物理环结构将逻辑线性序列映射到固定大小的数组，通过模运算实现首尾指针的环回。

### 单调栈（Next Greater）执行流

<pre>
输入: nums = [2, 1, 5, 6, 2, 3]

初始: stack = [] (存放下标)
i=0, val=2: stack=[] → 入栈 [0]
i=1, val=1: 1 < nums[0]=2 → 入栈 [0,1]
i=2, val=5: 5 > nums[1]=1 → pop 1, next[1]=5; 5 > nums[0]=2 → pop 0, next[0]=5 → 入栈 [2]
i=3, val=6: 6 > nums[2]=5 → pop 2, next[2]=6 → 入栈 [3]
i=4, val=2: 2 < nums[3]=6 → 入栈 [3,4]
i=5, val=3: 3 > nums[4]=2 → pop 4, next[4]=3; 3 < nums[3]=6 → 入栈 [3,5]

结果: {2:5, 1:5, 5:6, 6:null, 2:3}  （下标对应值）

数据形态变换：list[int] → 单调递减栈（下标链） → next数组（右侧更大元素映射）
</pre>

## 机制

### 栈的 LIFO 特性与函数调用

函数调用栈是栈结构最自然的体现：**每个函数调用对应一个栈帧（frame）**，包含返回地址、局部变量、参数。调用时 push 新帧，返回时 pop 帧。

**为什么函数调用天然是栈**：
- 嵌套调用：A 调用 B，B 调用 C，C 返回时必须回到 B，而非直接回到 A（LIFO）
- 作用域嵌套：内层作用域可见外层变量，但外层作用域不可见内层变量——这与栈的 push/pop 语义完全对应

**括号匹配的机制**：利用栈的"记忆 + 逆序匹配"特性。左括号入栈，右括号时弹出比对。正确匹配要求弹出顺序与括号开闭顺序逆序对应。

### 队列的 FIFO 特性与公平调度

FIFO 保证**时间戳最早的任务最先被服务**。在资源竞争场景下（FIFO 调度、打印机队列、消息队列），这是最简单的公平策略。

**与栈的本质区别**：栈强制逆序处理，队列强制顺序处理。栈适合"嵌套展开"（函数调用、表达式求值），队列适合"公平排队"（任务调度、广度优先遍历）。

### 双端队列（Deque）与滑动窗口

Deque 兼顾头尾操作，可同时模拟栈和队列。其在滑动窗口最大值问题中的应用：

**单调递减 deque 维护最大值**：
- 窗口右移时，新元素从右入 deque
- 从右弹出所有 $\leq$ 新元素的旧元素（它们永不可能成为最大值）
- 从左弹出已移出窗口的下标
- deque 左侧始终是当前窗口最大值的下标

**为什么单调递减而非递增**：我们维护的是**候选最大值集合**，递减保证左侧是最大。递增则维护候选最小值集合。

### 循环队列的物理环与逻辑线性

循环队列用物理环（数组 + 首尾指针）实现逻辑线性队列。关键设计：

**环的结构**：
- `head` 指向队首元素
- `tail` 指向**下一个可写入位置**（即队尾+1）
- 物理相邻在逻辑上可能是首尾相邻：`(tail + 1) % k == head` 表示物理上 `tail` 的下一个位置是 `head`

**判满/判空的不可能三角**：
- 若不允许牺牲存储单元：必须维护额外 size 变量，$O(1)$ 空间
- 若牺牲一个单元：可用 `head == tail` 区分空/满（如本模型）
- 若不允许牺牲也不维护 size：空/满无法区分（数学上不可能）

### 优先队列与堆的不完全对称

堆的 pop 操作：移除堆顶后，将最后一个元素移到堆顶，然后 sift-down 与子节点比较交换。

**为什么不原地排序后 pop**：因为 pop 需要快速找到最大/最小元素并移除，堆的 $O(1)$ 堆顶访问 + $O(\log n)$ 维护是最优权衡。直接维护有序数组会在插入时 $O(n)$ 线性查找插入位置。

### 约束违反后果

| 约束 | 违反后果 |
|------|---------|
| 栈满时 push | 上溢（overflow），数据丢失或异常 |
| 栈空时 pop | 下溢（underflow），返回未定义值或异常 |
| 队列满时 enqueue | 上溢，阻塞或拒绝写入 |
| 队列空时 dequeue | 下溢，返回未定义值或阻塞 |
| 循环队列模运算遗漏 | 指针越界访问或逻辑错误 |
| 单调栈维护顺序错误 | NGE 结果完全错误 |
| 堆的 sift-down 方向错误 | 堆属性破坏，优先队列失效 |

## 对比参照

| 特性 | 栈 | 队列 | 优先队列 |
|------|-----|------|---------|
| 访问限制 | 仅栈顶 | 仅队首/队尾 | 仅堆顶 |
| 操作复杂度 | $O(1)$ push/pop | $O(1)$ enqueue/dequeue | $O(1)$ 访问堆顶，$O(\log n)$ 出队/入队 |
| 调度语义 | LIFO（逆序） | FIFO（顺序） | 优先级顺序 |
| 典型应用 | 函数调用、括号匹配、表达式求值 | 任务调度、BFS | Dijkstra、Heap Sort、Top-K |

```python
def is_valid(s: str) -> bool:
    """括号匹配：利用栈的 LIFO 特性验证字符串中的括号是否配对"""
    stack, mp = [], {')': '(', ']': '[', '}': '{'}
    for c in s:
        if c in mp:                      # 右括号：检查栈顶是否匹配
            if not stack or stack.pop() != mp[c]:
                return False
        else:                            # 左括号：入栈等待匹配
            stack.append(c)
    return not stack                     # 空栈说明全部匹配
```

```python
from collections import deque
from typing import Iterator

def sliding_max(arr: list[int], k: int) -> Iterator[int]:
    """滑动窗口最大值：单调递减 deque 维护当前窗口最大候选"""
    dq: deque[int] = deque()              # 存放下标，保持对应值单调递减
    for i, x in enumerate(arr):
        while dq and arr[dq[-1]] <= x:   # 弹出不可能成为最大值的下标
            dq.pop()
        dq.append(i)
        if dq[0] <= i - k:               # 移除已移出窗口的下标
            dq.popleft()
        if i >= k - 1:                   # 窗口成型后产出最大值
            yield arr[dq[0]]
```

```python
class CircularQueue:
    """循环队列：物理环结构实现逻辑线性队列，牺牲一个存储单元区分空/满"""
    def __init__(self, k: int):
        self.k = k
        self.data = [0] * k
        self.head = self.tail = 0

    def enqueue(self, x: int) -> bool:
        if (self.tail + 1) % self.k == self.head:  # 判满
            return False
        self.data[self.tail] = x
        self.tail = (self.tail + 1) % self.k
        return True

    def dequeue(self) -> int | None:
        if self.head == self.tail:               # 判空
            return None
        x = self.data[self.head]
        self.head = (self.head + 1) % self.k
        return x
```
