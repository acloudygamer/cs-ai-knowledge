# 栈与队列

## 核心要点

- 栈：LIFO，后进先出
- 队列：FIFO，先进先出
- 常用于递归转迭代、括号匹配、层次遍历

## 单调栈

解决-next-greater-element类问题。

```python
# 每日温度（下一个更大元素）
def daily_temperatures(temps):
    stack = []  # 存索引
    res = [0] * len(temps)
    for i, t in enumerate(temps):
        while stack and temps[stack[-1]] < t:
            prev = stack.pop()
            res[prev] = i - prev
        stack.append(i)
    return res
```

## 括号匹配

```python
def is_valid(s):
    stack = []
    mapping = {')': '(', ']': '[', '}': '{'}
    for c in s:
        if c in mapping:
            if not stack or stack.pop() != mapping[c]:
                return False
        else:
            stack.append(c)
    return not stack
```

## 单调队列

解决滑动窗口最大值问题，保持队列单调性。

```python
from collections import deque

def max_sliding_window(nums, k):
    """
    滑动窗口最大值
    LeetCode 239
    时间复杂度: O(n)，每个元素最多入队出队各一次
    """
    if not nums or k == 0:
        return []

    dq = deque()  # 存索引，保证队列单调递减
    result = []

    for i in range(len(nums)):
        # 移除不在窗口内的元素
        while dq and dq[0] < i - k + 1:
            dq.popleft()

        # 保持单调递减：新元素比队列中的都大就出队
        while dq and nums[dq[-1]] < nums[i]:
            dq.pop()

        dq.append(i)

        # 窗口形成后记录最大值
        if i >= k - 1:
            result.append(nums[dq[0]])

    return result


# 最小值版本（单调递增队列）
def min_sliding_window(nums, k):
    dq = deque()
    result = []

    for i in range(len(nums)):
        while dq and dq[0] < i - k + 1:
            dq.popleft()
        while dq and nums[dq[-1]] > nums[i]:
            dq.pop()
        dq.append(i)
        if i >= k - 1:
            result.append(nums[dq[0]])

    return result
```

- 滑动窗口最值
- 流量控制

## 单调栈进阶应用

### 1. 柱状图中的最大矩形

```python
def largest_rectangle_area(heights):
    """
    柱状图中最大的矩形面积
    LeetCode 84
    单调栈：维护递增高度，遇到更低的就弹出计算面积
    时间复杂度: O(n)
    """
    heights = heights + [0]  # 末尾添加0，确保全部弹出
    stack = [-1]  # 存索引
    max_area = 0

    for i, h in enumerate(heights):
        while stack and heights[stack[-1]] > h:
            height = heights[stack.pop()]
            width = i - stack[-1] - 1
            max_area = max(max_area, height * width)
        stack.append(i)

    return max_area
```

### 3. 下一个更大元素 II（循环数组）

```python
def next_greater_elements(nums):
    """
    循环数组中的下一个更大元素
    LeetCode 503
    方法：遍历两遍数组（通过取模实现）
    """
    n = len(nums)
    res = [-1] * n
    stack = []  # 存索引

    for i in range(2 * n):
        idx = i % n
        while stack and nums[idx] > nums[stack[-1]]:
            prev = stack.pop()
            res[prev] = nums[idx]

        # 只在前半遍入栈，避免重复入栈
        if i < n:
            stack.append(idx)

    return res
```

### 4. 接雨水

```python
def trap(heights):
    """
    接雨水问题
    LeetCode 42
    方法：单调栈（递减）or 双指针
    """
    n = len(heights)
    if n == 0:
        return 0

    stack = []  # 存索引，递减
    water = 0

    for i in range(n):
        while stack and heights[stack[-1]] < heights[i]:
            bottom = heights[stack.pop()]
            if not stack:
                break
            left = stack[-1]
            width = i - left - 1
            height = min(heights[left], heights[i]) - bottom
            water += width * height
        stack.append(i)

    return water
```

### 5. 去除重复字母（单调栈 + 计数）

```python
def remove_duplicate_letters(s):
    """
    LeetCode 316
    去除重复字母，要求结果字典序最小
    单调栈 + 计数
    """
    from collections import Counter
    count = Counter(s)
    stack = []
    in_stack = set()

    for c in s:
        count[c] -= 1

        if c in in_stack:
            continue

        while stack and c < stack[-1] and count[stack[-1]] > 0:
            in_stack.remove(stack.pop())
        stack.append(c)
        in_stack.add(c)

    return ''.join(stack)
```

### 单调栈总结

| 问题类型 | 栈特性 | 处理方式 |
|----------|--------|----------|
| 下一个更大元素 | 递增栈 | 弹出更小的，入栈当前 |
| 柱状图最大矩形 | 递增栈 | 弹出计算面积 |
| 接雨水 | 递减栈 | 形成凹陷时计算 |
| 去除重复字母 | 递增栈 + 计数 | 弹出可能再次出现的更小元素 |

## 队列实现栈 / 栈实现队列

```python
# 用两个队列实现栈
# 注意：list.pop(0) 是 O(n)，生产环境建议使用 collections.deque
from collections import deque

class MyStack:
    def __init__(self):
        self.q1, self.q2 = deque(), deque()

    def push(self, x):
        self.q1.append(x)

    def pop(self):
        while len(self.q1) > 1:
            self.q2.append(self.q1.popleft())  # deque.popleft() 是 O(1)
        result = self.q1.popleft()
        self.q1, self.q2 = self.q2, self.q1
        return result
```
