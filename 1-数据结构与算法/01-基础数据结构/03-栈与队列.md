# 栈与队列

## 核心要点

- 栈：LIFO，后进先出
- 队列：FIFO，先进先出
- 常用于递归转迭代、括号匹配、层次遍历

## 括号匹配

```python
def is_valid(s):
    stack = []
    mapping = {')': '(', ']': '[', '}': '{'}
    for c in s:
        if c in mapping:
            if not stack or stack.pop() != mapping[c]:
                return False
        else:
            stack.append(c)
    return not stack
```

## 队列实现栈 / 栈实现队列

```python
# 用两个队列实现栈
# 注意：list.pop(0) 是 O(n)，生产环境建议使用 collections.deque
from collections import deque

class MyStack:
    def __init__(self):
        self.q1, self.q2 = deque(), deque()

    def push(self, x):
        self.q1.append(x)

    def pop(self):
        while len(self.q1) > 1:
            self.q2.append(self.q1.popleft())  # deque.popleft() 是 O(1)
        result = self.q1.popleft()
        self.q1, self.q2 = self.q2, self.q1
        return result

# 用一个栈实现队列
class MyQueue:
    def __init__(self):
        self.stack = []

    def push(self, x):
        # 入队元素直接加入
        self.stack.append(x)

    def pop(self):
        # 出队需要反转顺序，使用另一个栈
        if not self.stack:
            return None
        # 移动到辅助栈
        temp = []
        while self.stack:
            temp.append(self.stack.pop())
        result = temp.pop()
        # 移回原栈
        while temp:
            self.stack.append(temp.pop())
        return result
```

## 优先队列（堆）

Python 的 `heapq` 是小顶堆，实现 priority queue。

```python
import heapq

# 合并 K 个有序链表（最小堆）
def merge_k_lists(lists):
    heap = []
    for i, lst in enumerate(lists):
        if lst:
            heapq.heappush(heap, (lst.val, i, lst))

    dummy = ListNode()
    curr = dummy

    while heap:
        val, i, node = heapq.heappop(heap)
        curr.next = node
        curr = curr.next
        if node.next:
            heapq.heappush(heap, (node.next.val, i, node.next))

    return dummy.next

# Top K 问题
def top_k(nums, k):
    """找前 k 大的数"""
    return heapq.nlargest(k, nums)

def kth_largest(nums, k):
    """找第 k 大的数（1-indexed）"""
    return heapq.nlargest(k, nums)[-1]
```

## 典型应用场景

| 场景 | 数据结构 | 说明 |
|------|----------|------|
| 函数调用栈 | 栈 | 递归转迭代 |
| 括号匹配 | 栈 | 有效括号判断 |
| 层次遍历 | 队列 | BFS |
| 任务调度 | 优先队列 | 按优先级排序 |
