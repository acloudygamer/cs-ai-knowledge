# 栈与队列

### 解决什么问题
栈（LIFO）适用于递归转迭代、括号匹配、单调栈等场景；队列（FIFO）适用于 BFS 层次遍历、任务调度等场景。

### 核心概念
- 栈：后进先出，插入删除 O(1)
- 队列：先进先出，插入删除 O(1)
- 双端队列（Deque）：两端都可插入删除
- 优先队列：元素按优先级出队（堆实现）

### 怎么用

## 括号匹配

```python
def is_valid(s):
    stack = []
    mapping = {')': '(', ']': '[', '}': '{'}
    for c in s:
        if c in mapping:
            if not stack or stack.pop() != mapping[c]:
                return False
        else:
            stack.append(c)
    return not stack
```

## 队列实现栈 / 栈实现队列

```python
# 用两个队列实现栈
# 注意：list.pop(0) 是 O(n)，生产环境建议使用 collections.deque
from collections import deque

class MyStack:
    def __init__(self):
        self.q1, self.q2 = deque(), deque()

    def push(self, x):
        self.q1.append(x)

    def pop(self):
        while len(self.q1) > 1:
            self.q2.append(self.q1.popleft())  # deque.popleft() 是 O(1)
        result = self.q1.popleft()
        self.q1, self.q2 = self.q2, self.q1
        return result

# 用一个栈实现队列
class MyQueue:
    def __init__(self):
        self.stack = []

    def push(self, x):
        # 入队元素直接加入
        self.stack.append(x)

    def pop(self):
        # 出队需要反转顺序，使用另一个栈
        if not self.stack:
            return None
        # 移动到辅助栈
        temp = []
        while self.stack:
            temp.append(self.stack.pop())
        result = temp.pop()
        # 移回原栈
        while temp:
            self.stack.append(temp.pop())
        return result
```

## 典型应用场景

| 场景 | 数据结构 | 说明 |
|------|----------|------|
| 函数调用栈 | 栈 | 递归转迭代 |
| 括号匹配 | 栈 | 有效括号判断 |
| 层次遍历 | 队列 | BFS |
| 任务调度 | 优先队列 | 按优先级排序 |
