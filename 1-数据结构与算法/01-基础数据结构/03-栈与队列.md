# 栈与队列

> **版本基准**：universal —— 代码示例同时使用 Python 3.12 与 C++20

## 本质

栈和队列都是"只允许在特定端操作"的线性结构，本质是用**访问限制**换**语义保证**：

- **栈**是单端（栈顶）存取，后进先出（LIFO）。它强制嵌套顺序——最后压入的最先弹出，天然对应"调用返回""括号闭合"这类必须逆序回退的场景。
- **队列**是双端存取（队尾进、队头出），先进先出（FIFO）。它强制公平顺序——先到先服务，天然对应任务排队、广度遍历。

一句话：栈保"嵌套回退"，队列保"先来先服务"。

## 数学模型

### 循环队列的空/满判断

容量 $k$ 的循环数组，`head`/`tail` 指针。牺牲一个存储单元（实际存 $k-1$ 个）后：

$$empty \iff head = tail,\qquad full \iff (tail+1)\bmod k = head$$

为什么必须牺牲或记账：不牺牲单元时，空和满都满足 `head==tail`，无法区分。三条路必选其一：

- 牺牲一个单元 → 用上面的两个式子区分（本模型）；
- 不牺牲 → 额外维护 size 变量；
- 既不牺牲也不记账 → 空/满在数学上不可区分。

### 优先队列出队代价

用完全二叉堆实现，出队代价 $T(n)=T(n/2)+O(1)=O(\log n)$ ——归结为树高 $\lfloor\log_2 n\rfloor$：每次 sift-down 最坏沿一条根到叶路径比较。数组表示（1-indexed）：父 $parent(i)=\lfloor i/2\rfloor$，左子 $2i$，右子 $2i+1$。

## 数据流

### 栈/队列操作

<pre>
栈 push(x):  [a, b, c] ──push(x)──> [a, b, c, x]   栈顶→x
栈 pop():    [a, b, c, x] ──pop()──> [a, b, c], 返回 x

队 enqueue:  [head]a b c[tail] ──enqueue(x)──> [head]a b c x[tail]
队 dequeue:  [head]a b c[tail] ──dequeue()──> [head]b c[tail], 返回 a
</pre>

### 循环队列（k=5，存 4 个）

<pre>
初始空:     [h][ ][ ][ ][ ][t]   h=t=0
入队4个:    [h][1][2][3][4][t]   h=0,t=4, (4+1)%5=0=h → 满
出队1个:    [ ][h][2][3][4][t]  h=1
再入队5:    [5][h][2][3][4][t]  t=0，覆盖旧位置（物理环，逻辑线性）
</pre>

物理环结构用模运算把逻辑线性序列映射进固定数组，首尾指针环回。

### 单调栈执行流（Next Greater Element）

求每个位置右侧第一个更大的元素。栈存下标、对应值保持单调递减；新元素把栈里所有更小的弹出去并顺手给它们登记答案：

<pre>
输入 nums = [2, 1, 5, 6, 2, 3]，栈存下标

i=0 v=2: 入 [0]
i=1 v=1: 1<2  入 [0,1]
i=2 v=5: 5>1 pop1→next[1]=5; 5>2 pop0→next[0]=5; 入 [2]
i=3 v=6: 6>5 pop2→next[2]=6; 入 [3]
i=4 v=2: 2<6 入 [3,4]
i=5 v=3: 3>2 pop4→next[4]=3; 3<6 入 [3,5]

结果 next = [5, 5, 6, -, 3, -]   (- 表示无更大者)
</pre>

每个元素最多入栈、出栈各一次，总 $O(n)$。更深入见 `03-算法思想/08-单调栈.md`。

## 机制

### 栈的 LIFO 与函数调用

每次函数调用压一个栈帧（返回地址+局部变量+参数），返回时弹出。**天然是栈**因为调用嵌套：A→B→C 返回时必须 C→B→A 逆序回退；作用域嵌套同理：内层可见外层、外层不可见内层，正对应 push/pop。

**括号匹配**用栈的"记忆+逆序匹配"：左括号入栈，右括号弹出比对，要求弹出顺序与开闭顺序逆序对应。

### 队列的 FIFO 与公平调度

FIFO 保证时间戳最早的任务最先服务——FIFO 调度、打印机队列、消息队列的最简公平策略。

**与栈的区别**：栈强制逆序处理（嵌套展开：函数调用、表达式求值），队列强制顺序处理（公平排队：任务调度、BFS）。

### 双端队列与滑动窗口

Deque 头尾都能 $O(1)$ 操作，可同时模拟栈和队列。滑动窗口最大值用它维护单调递减的候选下标：新元素从右入、从右弹出所有更小的旧下标（它们永不可能成为最大值——**单调剪枝**），从左弹出已移出窗口的下标，左侧恒是当前最大值。窗口最大值查询从 $O(k)$ 降到均摊 $O(1)$。

**为什么递减**：维护的是候选**最大值**集合，递减保证左侧最大；要最小值则用递增。

### 优先队列为何用堆而非有序数组

堆给 $O(1)$ 堆顶访问 + $O(\log n)$ 插入/弹出。维护有序数组虽 pop $O(1)$，但插入要 $O(n)$ 线性找位。堆是"访问快、维护便宜"的最优权衡。

### 约束违反后果

| 约束 | 违反后果 | 检测 |
|------|---------|------|
| 栈满 push | 上溢，数据丢失/异常 | $h<k$ |
| 栈空 pop | 下溢，返回未定义值 | $h>0$ |
| 队满 enqueue | 上溢，阻塞/拒绝 | `(tail+1) % k != head` |
| 队空 dequeue | 下溢，未定义/阻塞 | $head\ne tail$ |
| 循环队列漏模运算 | 指针越界 | 始终用 `%k` |
| 单调栈维护顺序错 | NGE 结果全错 | 验证出栈条件 |
| 堆 sift-down 方向错 | 堆属性破坏 | 检查父子比较方向 |

## 对比参照

| 特性 | 栈 | 队列 | 优先队列 |
|------|-----|------|---------|
| 访问限制 | 仅栈顶 | 队首/队尾 | 仅堆顶 |
| 操作复杂度 | $O(1)$ push/pop | $O(1)$ en/dequeue | $O(1)$ 取顶， $O(\log n)$ 入/出 |
| 调度语义 | LIFO（逆序） | FIFO（顺序） | 优先级顺序 |
| 典型应用 | 函数调用、括号匹配、表达式求值 | 任务调度、BFS | Dijkstra、堆排、Top-K |
| 实现 | 数组/链表 | 数组（循环）/链表 | 完全二叉堆 |

## 代码示例

**Python 3.12**：

```python
# 括号匹配：用栈的 LIFO 验证括号配对
def is_valid(s: str) -> bool:
    stack, mp = [], {')': '(', ']': '[', '}': '{'}
    for c in s:
        if c in mp:                       # 右括号：核对栈顶
            if not stack or stack.pop() != mp[c]:
                return False
        else:                             # 左括号：入栈等待
            stack.append(c)
    return not stack                      # 空栈=全匹配

from collections import deque

# 滑动窗口最大值：单调递减 deque
def sliding_max(arr: list[int], k: int) -> list[int]:
    dq: deque[int] = deque()              # 存下标，对应值单调递减
    res = []
    for i, x in enumerate(arr):
        while dq and arr[dq[-1]] <= x:    # 弹出不可能成为最大值的下标
            dq.pop()
        dq.append(i)
        if dq[0] <= i - k:                # 移除已移出窗口的下标
            dq.popleft()
        if i >= k - 1:                    # 窗口成型后产出最大值
            res.append(arr[dq[0]])
    return res

# 循环队列：牺牲一个单元区分空/满
class CircularQueue:
    def __init__(self, k: int):
        self.k = k
        self.data = [0] * k
        self.head = self.tail = 0

    def enqueue(self, x: int) -> bool:
        if (self.tail + 1) % self.k == self.head:   # 判满
            return False
        self.data[self.tail] = x
        self.tail = (self.tail + 1) % self.k
        return True

    def dequeue(self) -> int | None:
        if self.head == self.tail:                 # 判空
            return None
        x = self.data[self.head]
        self.head = (self.head + 1) % self.k
        return x

# —— 简易输入输出 ——
print(is_valid("()[]{}"))            # True
print(is_valid("([)]"))              # False
print(sliding_max([1,3,-1,-3,5,3,6,7], 3))  # [3,3,5,5,6,7]
q = CircularQueue(3)
print(q.enqueue(1), q.enqueue(2), q.enqueue(3), q.enqueue(4))  # True True False False
print(q.dequeue())                  # 1
```

**C++20**：

```cpp
#include <iostream>
#include <vector>
#include <deque>
#include <optional>
#include <string_view>

// 括号匹配
bool is_valid(std::string_view s) {
    std::vector<char> st;
    for (char c : s) {
        char want = (c == ')') ? '(' : (c == ']') ? '[' : (c == '}') ? '{' : 0;
        if (want) {                      // 右括号：核对栈顶
            if (st.empty() || st.back() != want) return false;
            st.pop_back();
        } else {                         // 左括号：入栈
            st.push_back(c);
        }
    }
    return st.empty();
}

// 滑动窗口最大值：单调递减 deque
std::vector<int> sliding_max(const std::vector<int>& arr, int k) {
    std::deque<int> dq;                  // 存下标，对应值单调递减
    std::vector<int> res;
    for (int i = 0; i < (int)arr.size(); ++i) {
        while (!dq.empty() && arr[dq.back()] <= arr[i]) dq.pop_back();
        dq.push_back(i);
        if (dq.front() <= i - k) dq.pop_front();
        if (i >= k - 1) res.push_back(arr[dq.front()]);
    }
    return res;
}

// 循环队列：牺牲一个单元区分空/满
struct CircularQueue {
    int k; std::vector<int> data; int head = 0, tail = 0;
    explicit CircularQueue(int n) : k(n), data(n) {}
    bool enqueue(int x) {
        if ((tail + 1) % k == head) return false;        // 满
        data[tail] = x;
        tail = (tail + 1) % k;
        return true;
    }
    std::optional<int> dequeue() {
        if (head == tail) return std::nullopt;           // 空
        int x = data[head];
        head = (head + 1) % k;
        return x;
    }
};

// —— 简易输入输出 ——
int main() {
    std::cout << std::boolalpha;
    std::cout << is_valid("()[]{}") << ' ' << is_valid("([)]") << '\n';  // true false
    for (int v : sliding_max({1,3,-1,-3,5,3,6,7}, 3)) std::cout << v << ' ';  // 3 3 5 5 6 7
    std::cout << '\n';
    CircularQueue q(3);
    std::cout << q.enqueue(1) << q.enqueue(2) << q.enqueue(3) << q.enqueue(4) << '\n'; // truetruefalsefalse
    std::cout << *q.dequeue() << '\n';                                     // 1
}
```
