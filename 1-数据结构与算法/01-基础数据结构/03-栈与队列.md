# 栈与队列

## 定义

栈是单端操作的 LIFO 结构，只允许一端插入删除；队列是双端操作的 FIFO 结构，允许尾插头删。

## 数学模型

**单调栈 Next Greater Element**

对每个元素找右侧第一个更大的元素，维护递减栈：

$$
\text{while } stack \land nums[i] > nums[stack.top()]:\quad next[stack.pop()] = nums[i]
$$

**优先队列出队顺序**

堆顶元素优先级最高，出队后堆化：

$$
T(n) = T(n/2) + O(1) = O(\log n)
$$

**循环队列满/空判断**

设容量为 $k$：

$$
\text{full} \Leftrightarrow (tail + 1) \bmod k == head
$$

## 数据流

**栈操作**

<pre>
push(x):    [x] ──栈顶
pop():      移除栈顶，返回它
应用：函数调用栈、括号匹配
</pre>

**队列操作**

<pre>
enqueue(x): ──>[x] ──> 尾
dequeue(): <──[x] <── 头（先入先出）
应用：BFS 层次遍历
</pre>

**单调栈（Next Greater）**

<pre>
输入: [2, 1, 5, 6, 2, 3]
步骤1: 2 入栈 []
步骤2: 1 < 2，2 的 greater 是 1，[2]
步骤3: 5 > 1 pop，[2]; 5 > 2 pop，2 的 greater 是 5，[5]
步骤4: 6 > 5 pop，5 的 greater 是 6，[6]
步骤5: 2 < 6，入栈 [6, 2]
步骤6: 3 > 2 pop，2 的 greater 是 3，[6, 3]
结果: {2:1, 5:6, 6:null, 2:3}
</pre>

## 机制

**LIFO 适合嵌套/递归展开**

函数调用栈天然匹配栈结构；括号匹配利用栈的"记忆"能力，先开的括号后关。

**FIFO 适合公平排队**

任务调度、打印队列、消息队列需要先来先服务。

**双端队列兼顾头尾操作**

Deque 可同时实现栈和队列的功能，滑动窗口最大值用单调 deque 在 O(n) 内维护。

**优先队列用堆实现**

完全二叉堆的数组表示：父节点在 $\lfloor i/2 \rfloor$，子节点在 $2i$ 和 $2i+1$。

**违规后果**

- 栈空 pop / 队空 dequeue：数据错误
- 循环队列忘记模运算：指针越界
- 单调栈维护顺序错误：结果错误

## 参考存根

```python
def is_valid(s):
    stack, mp = [], {')': '(', ']': '[', '}': '{'}
    for c in s:
        if c in mp:
            if not stack or stack.pop() != mp[c]:
                return False
        else:
            stack.append(c)
    return not stack
```

```python
def sliding_max(arr, k):
    from collections import deque
    dq = deque()
    for i, x in enumerate(arr):
        while dq and arr[dq[-1]] <= x:
            dq.pop()
        dq.append(i)
        if dq[0] <= i - k:
            dq.popleft()
        if i >= k - 1:
            yield arr[dq[0]]
```
