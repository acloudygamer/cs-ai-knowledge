# 栈与队列

## 核心要点

- 栈：LIFO，后进先出
- 队列：FIFO，先进先出
- 常用于递归转迭代、括号匹配、层次遍历

## 括号匹配

```python
def is_valid(s):
    stack = []
    mapping = {')': '(', ']': '[', '}': '{'}
    for c in s:
        if c in mapping:
            if not stack or stack.pop() != mapping[c]:
                return False
        else:
            stack.append(c)
    return not stack
```

## 队列实现栈 / 栈实现队列

```python
# 用两个队列实现栈
# 注意：list.pop(0) 是 O(n)，生产环境建议使用 collections.deque
from collections import deque

class MyStack:
    def __init__(self):
        self.q1, self.q2 = deque(), deque()

    def push(self, x):
        self.q1.append(x)

    def pop(self):
        while len(self.q1) > 1:
            self.q2.append(self.q1.popleft())  # deque.popleft() 是 O(1)
        result = self.q1.popleft()
        self.q1, self.q2 = self.q2, self.q1
        return result
```
