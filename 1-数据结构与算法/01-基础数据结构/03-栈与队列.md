# 栈与队列

## 核心要点

- 栈：LIFO，后进先出
- 队列：FIFO，先进先出
- 常用于递归转迭代、括号匹配、层次遍历

## 单调栈

解决-next-greater-element类问题。

```python
# 每日温度（下一个更大元素）
def daily_temperatures(temps):
    stack = []  # 存索引
    res = [0] * len(temps)
    for i, t in enumerate(temps):
        while stack and temps[stack[-1]] < t:
            prev = stack.pop()
            res[prev] = i - prev
        stack.append(i)
    return res
```

## 括号匹配

```python
def is_valid(s):
    stack = []
    mapping = {')': '(', ']': '[', '}': '{'}
    for c in s:
        if c in mapping:
            if not stack or stack.pop() != mapping[c]:
                return False
        else:
            stack.append(c)
    return not stack
```

## 单调队列

解决滑动窗口最大值问题，保持队列单调性。

```python
from collections import deque

def max_sliding_window(nums, k):
    """
    滑动窗口最大值
    LeetCode 239
    时间复杂度: O(n)，每个元素最多入队出队各一次
    """
    if not nums or k == 0:
        return []

    dq = deque()  # 存索引，保证队列单调递减
    result = []

    for i in range(len(nums)):
        # 移除不在窗口内的元素
        while dq and dq[0] < i - k + 1:
            dq.popleft()

        # 保持单调递减：新元素比队列中的都大就出队
        while dq and nums[dq[-1]] < nums[i]:
            dq.pop()

        dq.append(i)

        # 窗口形成后记录最大值
        if i >= k - 1:
            result.append(nums[dq[0]])

    return result


# 最小值版本（单调递增队列）
def min_sliding_window(nums, k):
    dq = deque()
    result = []

    for i in range(len(nums)):
        while dq and dq[0] < i - k + 1:
            dq.popleft()
        while dq and nums[dq[-1]] > nums[i]:
            dq.pop()
        dq.append(i)
        if i >= k - 1:
            result.append(nums[dq[0]])

    return result
```

### 应用场景

- 滑动窗口最值
- 流量控制
- 股票价格区间最大收益

## 队列实现栈 / 栈实现队列

```python
# 用两个队列实现栈
# 注意：list.pop(0) 是 O(n)，生产环境建议使用 collections.deque
from collections import deque

class MyStack:
    def __init__(self):
        self.q1, self.q2 = deque(), deque()

    def push(self, x):
        self.q1.append(x)

    def pop(self):
        while len(self.q1) > 1:
            self.q2.append(self.q1.popleft())  # deque.popleft() 是 O(1)
        result = self.q1.popleft()
        self.q1, self.q2 = self.q2, self.q1
        return result
```
