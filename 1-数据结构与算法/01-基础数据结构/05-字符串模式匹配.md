# 字符串模式匹配

## 定义

> **版本基准**: universal

字符串模式匹配是在文本串 T[0..n-1] 中定位模式串 P[0..m-1] 首次或所有出现位置的过程。核心挑战在于：避免回溯文本指针（指针 i 不能退），将匹配从朴素的 O(nm) 降至 O(n+m)。四种经典算法分别从不同角度解决这个问题：KMP 利用已匹配前缀信息、Rabin-Karp 用哈希空间换时间、Manacher 专用回文、AC 自动机扩展到多模式。

**本质**：模式匹配是将**字符串比较问题归约为状态转移问题**——通过预处理模式串构建自动机，匹配时只需沿状态转移前进，无需回退。

## 机制

### KMP 的核心不变量

文本指针 i 只增不减。匹配成功时 i 和 j 同时前移；失配时 j 回退到 π[j-1]，i 不动。这一性质保证了 O(n+m) 的时间界。

**不变式形式化**：在任意时刻， $T[i-j..i-1] = P[0..j-1]$ （已匹配文本等于已匹配模式前缀）。此不变式在每次转移后保持。 （已匹配文本等于已匹配模式前缀）。此不变式在每次转移后保持。

### Rabin-Karp 的约束

哈希函数是概率均匀的，碰撞不可避免。模数 M 的选择影响碰撞频率——M 过小（如 M=2）导致碰撞率 50%，性能退化为 O(nm)；M 取大素数（如 101, 10^9+7）碰撞率降至可接受范围。**验证步骤不可省略**。

**碰撞的后果**：哈希碰撞会导致假阳性匹配，即哈希相同但字符串实际不同。若跳过验证，会产生错误的匹配结果。

### Manacher 的分隔符选择

必须选择文本中不出现的字符（如 '$'），否则分隔符可能与原字符碰撞产生虚假回文。对于 t 中的奇数位置（对应原串字符），原串回文长度直接等于 p[i]。

**分隔符的数学作用**：分隔符  ' $ 保证 $ t[i-j] \neq t[i+j]$ 当 $j$ 跨越原字符边界时，从而将奇偶回文统一处理。t[i-j] \neq t[i+j] $ 当 $ j$ 跨越原字符边界时，从而将奇偶回文统一处理。j$ 跨越原字符边界时，从而将奇偶回文统一处理。

### AC 自动机失败链接的正确性

failure[v] 必须指向当前已匹配序列的最长真后缀对应的节点。构建时按 BFS 序确保子树处理完毕后再处理父节点，否则 failure 链可能指向尚未构建的节点。每当匹配到一个节点，沿着 failure 链向上收集所有 out（输出模式），保证不漏掉所有已匹配模式。

def kmp(text, pat):
    n, m = len(text), len(pat)
    pi = [0] * m
    for i in range(1, m):
        j = pi[i - 1]
        while j and pat[i] != pat[j]:

# Manacher - 返回最长回文子串
def manacher(s):
    t = ' + '.join(s) + '
    n = len(t)
    p = [0] * n
    c = r = 0  # center, right boundary
    for i in range(n):
        if i < r:
            p[i] = min(r - i, p[2 * c - i])
        while i - p[i] - 1 >= 0 and i + p[i] + 1 < n:
            if t[i - p[i] - 1] == t[i + p[i] + 1]:
                p[i] += 1
            else:
                break
        if i + p[i] > r:
            c, r = i, i + p[i]
    # 找到最长回文
    max_len, center = max((v, i) for i, v in enumerate(p))
    start = (center - max_len) // 2
    return s[start:start + max_len]

def rabin_karp(text, pat, B=256, M=101):
    n, m = len(text), len(pat)
    if m > n:
        return -1
    pow_b_m = pow(B, m - 1, M)
    h_p = sum((ord(pat[i]) * pow(B, m - 1 - i)) for i in range(m)) % M
    h_t = sum((ord(text[i]) * pow(B, m - 1 - i)) for i in range(m)) % M
    for i in range(n - m + 1):
        if h_t == h_p and text[i:i + m] == pat:
            return i

    return -1

from collections import deque

def ac_build(patterns):
    n = [{'next': {}, 'fail': 0, 'out': []}]
    for p in patterns:
        node = 0
        for ch in p:
            if ch not in n[node]['next']:
                n[node]['next'][ch] = len(n)
                n.append({'next': {}, 'fail': 0, 'out': []})
            node = n[node]['next'][ch]
        n[node]['out'].append(p)
    q = deque()
    for ch, nd in n[0]['next'].items():
        q.append(nd)
    while q:
        r = q.popleft()
        for ch, nd in n[r]['next'].items():
            q.append(nd)
            f = n[r]['fail']
            while f and ch not in n[f]['next']:
                f = n[f]['fail']
            n[nd]['fail'] = n[f]['next'].get(ch, 0)
            n[nd]['out'].extend(n[n[nd]['fail']]['out'])
    return n

    state = 0

        while state and ch not in state_trie[state]['next']:
            state = state_trie[state]['fail']
        state = state_trie[state]['next'].get(ch, 0)
        for pat in state_trie[state]['out']:
            yield pat, i - len(pat) + 1
