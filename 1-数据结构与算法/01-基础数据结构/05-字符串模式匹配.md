## 字符串模式匹配

### 解决什么问题
在文本串中查找模式串的出现位置，是字符串处理的核心问题。典型应用：搜索引擎、DNA序列比对、日志处理、敏感词过滤等。

### 核心概念
- **朴素匹配**：O(nm)，暴力遍历
- **KMP**：O(n+m)，利用已匹配信息避免回溯
- **Rabin-Karp**：O(n+m) 平均，使用哈希加速
- **AC自动机**：多模式匹配，O(n+m)

### 字符串匹配算法总结

| 算法 | 时间复杂度 | 空间复杂度 | 适用场景 |
|------|-----------|-----------|----------|
| 朴素匹配 | O(nm) | O(1) | 小数据量 |
| KMP | O(n+m) | O(m) | 单模式匹配 |
| Rabin-Karp | O(n+m) 平均 | O(1) | 多模式、哈希验证 |
| Manacher | O(n) | O(n) | 最长回文 |
| AC 自动机 | O(n+m+z) | O(mσ) | 多模式匹配 |

## KMP 算法

### 前缀函数（Failure Function）

对于模式串 p，前缀函数 pi[i] 表示 p[0..i] 中最长相等前后缀长度。

利用前缀函数可以在匹配失败时快速跳过已匹配的部分，避免回溯文本指针。

### 参考样例

```python
def build_prefix_function(p):
    n = len(p)
    pi = [0] * n
    for i in range(1, n):
        j = pi[i - 1]
        while j > 0 and p[i] != p[j]:
            j = pi[j - 1]
        if p[i] == p[j]:
            j += 1
        pi[i] = j
    return pi

def kmp_search(text, pattern):
    if not pattern:
        return 0
    if not text:
        return -1
    n, m = len(text), len(pattern)
    pi = build_prefix_function(pattern)
    j = 0
    for i in range(n):
        while j > 0 and text[i] != pattern[j]:
            j = pi[j - 1]
        if text[i] == pattern[j]:
            j += 1
        if j == m:
            return i - m + 1
    return -1
```

### 查找所有匹配位置

### 参考样例

```python
def kmp_find_all(text, pattern):
    if not pattern:
        return list(range(len(text) + 1))
    if not text:
        return []
    n, m = len(text), len(pattern)
    pi = build_prefix_function(pattern)
    j = 0
    result = []
    for i in range(n):
        while j > 0 and text[i] != pattern[j]:
            j = pi[j - 1]
        if text[i] == pattern[j]:
            j += 1
        if j == m:
            result.append(i - m + 1)
            j = pi[j - 1]
    return result
```

### KMP 应用：重复子串检测

利用前缀函数：如果 n % (n - pi[n-1]) == 0，则子串 text[0:n-pi[n-1]] 重复出现。

### 参考样例

```python
def find_repeated_substring(text):
    n = len(text)
    pi = build_prefix_function(text)
    k = n - pi[-1]
    if n % k == 0 and n // k > 1:
        repeat_times = n // k
        substring = text[:k]
        return substring
    return None
```

## Rabin-Karp 算法

### 滚动哈希

使用多项式哈希，将字符串映射为整数，利用滚动哈希实现 O(1) 窗口滑动。

### 参考样例

```python
def rabin_karp(text, pattern, base=256, mod=101):
    if not pattern:
        return 0
    if not text:
        return -1
    n, m = len(text), len(pattern)
    pattern_hash = 0
    text_hash = 0
    h = 1
    for _ in range(m - 1):
        h = (h * base) % mod
    for i in range(m):
        pattern_hash = (pattern_hash * base + ord(pattern[i])) % mod
        text_hash = (text_hash * base + ord(text[i])) % mod
    for i in range(n - m + 1):
        if pattern_hash == text_hash:
            if text[i:i + m] == pattern:
                return i
        if i < n - m:
            text_hash = ((text_hash - ord(text[i]) * h) * base + ord(text[i + m])) % mod
            if text_hash < 0:
                text_hash += mod
    return -1
```

### KMP vs Rabin-Karp

| 特性 | KMP | Rabin-Karp |
|------|-----|------------|
| 时间复杂度 | O(n+m) | O(n+m) 平均，O(nm) 最坏 |
| 空间复杂度 | O(m) | O(1) |
| 预处理时间 | O(m) | O(m) |
| 适用场景 | 精确匹配 | 多模式匹配、哈希验证 |

## Manacher 算法

O(n) 时间复杂度求最长回文子串。

### 核心思想

- 奇回文和偶回文统一处理：插入分隔符
- 维护右边界最靠右的回文中心及其半径
- 利用已计算信息加速后续计算

### 参考样例

```python
def manacher(s):
    if not s:
        return "", -1, 0
    t = '#' + '#'.join(s) + '#'
    n = len(t)
    p = [0] * n
    c = r = 0
    for i in range(n):
        if i < r:
            mirror = 2 * c - i
            p[i] = min(r - i, p[mirror])
        while i - p[i] - 1 >= 0 and i + p[i] + 1 < n:
            if t[i - p[i] - 1] == t[i + p[i] + 1]:
                p[i] += 1
            else:
                break
        if i + p[i] > r:
            c = i
            r = i + p[i]
    max_len = max(p)
    center_idx = p.index(max_len)
    start = (center_idx - max_len) // 2
    return s[start:start + max_len], start, max_len
```

### Manacher vs 其他方法

| 方法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 中心扩展 | O(n^2) | O(1) | 简单直观 |
| 动态规划 | O(n^2) | O(n^2) | 可预处理 |
| Manacher | O(n) | O(n) | 最优但稍复杂 |

## Aho-Corasick 自动机 (AC 自动机)

### 核心概念

AC 自动机是一种多模式字符串匹配算法，在 O(n + m + z) 时间内找出所有模式串在文本中的出现位置。

核心思想：将所有模式串构建为 Trie，然后在 Trie 上构建失败指针（类似 KMP 的前缀函数）。

### 构建过程

1. 插入所有模式串到 Trie
2. 构建失败指针（Failure Link）：根节点的失败指针指向自己，其他节点的失败指针沿父节点的失败指针向上
3. 构建输出指针（Output Link）：指向最近的可输出匹配的模式节点

### 参考样例

```python
from collections import deque

def build_ac_automaton(patterns):
    nodes = [{'children': {}, 'fail': 0, 'output': []}]
    for pid, pattern in enumerate(patterns):
        node = 0
        for ch in pattern:
            if ch not in nodes[node]['children']:
                nodes[node]['children'][ch] = len(nodes)
                nodes.append({'children': {}, 'fail': 0, 'output': []})
            node = nodes[node]['children'][ch]
        nodes[node]['output'].append(pid)
    queue = deque()
    for ch, next_node in nodes[0]['children'].items():
        nodes[next_node]['fail'] = 0
        queue.append(next_node)
    while queue:
        current = queue.popleft()
        for ch, next_node in nodes[current]['children'].items():
            queue.append(next_node)
            fail = nodes[current]['fail']
            while fail > 0 and ch not in nodes[fail]['children']:
                fail = nodes[fail]['fail']
            nodes[next_node]['fail'] = nodes[fail]['children'].get(ch, 0)
            if nodes[nodes[next_node]['fail']]['output']:
                nodes[next_node]['output'].extend(nodes[nodes[next_node]['fail']]['output'])
    return nodes

def ac_search(text, patterns):
    nodes = build_ac_automaton(patterns)
    result = []
    state = 0
    for i, ch in enumerate(text):
        while state > 0 and ch not in nodes[state]['children']:
            state = nodes[state]['fail']
        state = nodes[state]['children'].get(ch, 0)
        for pattern_id in nodes[state]['output']:
            result.append((pattern_id, i - len(patterns[pattern_id]) + 1))
    return result
```

|------|------|
| 关键词过滤 | 敏感词检测、多模式匹配 |
| DNA 序列匹配 | 生物信息学中的模式搜索 |
| 日志分析 | 恶意请求检测 |
