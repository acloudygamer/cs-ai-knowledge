# 字符串模式匹配

> **版本基准**：universal —— 代码示例同时使用 Python 3.12 与 C++20

## 本质

在文本 $T[0..n-1]$ 里定位模式 $P[0..m-1]$。朴素法每次失配都把文本指针往回挪一位重新比， $O(nm)$。所有高效算法的共同思路：**把字符串比较归约成状态转移**——预处理模式构建自动机，匹配时只沿状态前进、不回退文本指针，把 $O(nm)$ 压到 $O(n+m)$。

四个经典算法从不同角度切入：KMP 用已匹配前缀信息、Rabin-Karp 用哈希把串比变成数比、Manacher 专攻回文、AC 自动机扩展到多模式。

## 数学模型

### KMP 前缀函数

$\pi[i]$ = $P[0..i]$ 中最长相等真前后缀的长度（"真"指长度 $<i+1$）。递推：

$$j=\pi[i-1];\quad \text{while } j>0 \land P[i]\ne P[j]:\ j=\pi[j-1];\quad \pi[i]=\begin{cases}j+1 & P[i]=P[j]\\ j & \text{otherwise}\end{cases}$$

匹配时在文本位 $i$、模式位 $j$ 失配，模式直接跳到 $\pi[j-1]$，文本指针 $i$ 不回退。

**正确性**：已匹配前缀 $P[0..j-1]=T[i-j..i-1]$，失配于 $T[i]\ne P[j]$。令 $k=\pi[j-1]$，则 $P[0..k-1]=P[j-k..j-1]$ （前后缀相等）。结合已匹配段得 $T[i-k..i-1]=P[0..k-1]$，故下一轮直接从 $P[k]$ 比，无需重扫文本。

> **洞察**：KMP 是一台 $m+1$ 态自动机， $\pi$ 数组就是状态转移表——失配时状态沿 $\pi$ 回跳，而非回到初始，从而保住已匹配前缀的成果。

### Rabin-Karp 滚动哈希

多项式哈希 $H(i)=\left(\sum_{k=0}^{m-1}P[k]\cdot B^{m-1-k}\right)\bmod M$。文本子串哈希滚动更新（去掉最高位、补最低位）：

$$H(i+1)=\left(B\cdot(H(i)-T[i]\cdot B^{m-1})+T[i+m]\right)\bmod M$$

哈希相同 $H(i)=H_P$ 时**必须再逐字符验证**，防碰撞假阳性。

> **洞察**：Rabin-Karp 把"串比较"归约为"数比较"， $O(1)$ 滚动更新让窗口滑动常数时间；但碰撞概率不为零（$M=2^{64}$ 自然溢出时约 $n/M$，生日悖论），验证不可省。

### Manacher 半径数组

把长 $n$ 的 $s$ 变换为 $t$ = `#` + s[0] + `#` + s[1] + ... + s[n-1] + `#`（长 $2n+1$），让奇偶回文统一成奇回文。 $p[i]$ = 以 $i$ 为中心的最大回文半径（含中心）。对 $t$ 中奇数位置 $i$ （对应原串字符），原串回文长度 $=p[i]$。

> **洞察**：分隔符（代码用 `#`）必须选原串不出现的字符，保证回文扩展跨越原字符边界时左右必不匹配，从而把"奇/偶回文"两种情况统一成一种，免去分情况处理；实现时再加 `^`/`$` 哨兵防扩展越界。

### AC 自动机失败链接

多模式匹配。在 Trie 上建类似 KMP 的失败链接 $\text{fail}[v]$：指向"当前已匹配前缀的最长真后缀在 Trie 中对应的节点"。按 BFS 序构建，沿 fail 链回溯：

$$\text{fail}[v.\text{next}[c]] = \text{fail}[\text{fail}[v]].\text{next}[c]$$

匹配到一个节点时，沿 fail 链向上收集所有 out（输出模式），保证不漏。

> **洞察**：AC 自动机是多模式的 KMP——Trie 把多个模式的状态合并成一台自动机，fail 链让失配时跳到"最长可复用后缀"而非回到根，总复杂度 $O(n+m+z)$ （$z$ 为命中数）。

## 数据流

### KMP 匹配状态机

<pre>
文本 T = "a a b a a c"，模式 P = "a a b"，π = [0,1,0]

i=0 j=0: a==a → i=1 j=1
i=1 j=1: a==a → i=2 j=2
i=2 j=2: b==b → i=3 j=3=m → 命中，位置 i-m=0

——失配示例：T="aaxaab"，P="aab"——
i=2 j=2: x≠b → j=π[1]=1（i 不动）
i=2 j=1: x≠a → j=π[0]=0
i=2 j=0: x≠a → j 归 0，i=3（仅 i 前进）
i=3 j=0: a==a → ... 直到 i=5 j=3=m → 命中位置 3
</pre>

文本指针 $i$ 单调递增不回头， $j$ 沿 $\pi$ 跳跃不重扫已匹配文本。

### Manacher 变换与半径

<pre>
s="aba" → t="#a#b#a#"（长7，索引0..6）

以 t[3]='b' 为中心扩展:
  t[2]=t[4]='#' 匹配 → p=1
  t[1]=t[5]='a'  匹配 → p=2
  t[0]=t[6]='#'  匹配 → p=3
  越界停 → p[3]=3 → 原串回文 "aba"（长3）✓

形态: 原串 → 插分隔符变换串 → 半径数组 → 提取回文
</pre>

### Rabin-Karp 哈希滚动

<pre>
T="aabaac"，P="aab"，B=256，M=101
H_P = (256²·'a' + 256·'a' + 'b') mod 101

窗口滑动:
  H(i+1) = (256·(H(i) - T[i]·256²) + T[i+m]) mod 101
         减最高位字符贡献，乘进制，加新低位字符

H(i)==H_P 时逐字符验证 T[i..i+m-1] 是否等于 P（防碰撞）
</pre>

### AC 自动机失败链接

<pre>
模式集 ["he","she","his","is"]，建 Trie + fail 链(BFS序):

root
 ├─h─e (out: "he")
 │    └─s─h─e (out: "she"，经 fail 继承 "he")
 └─s─h─e (out: "she")
      └─i─s (out: "his","is")

匹配到某节点 → 沿 fail 链向上收集所有 out（不漏模式）
</pre>

## 对比参照

| 算法 | 时间 | 空间 | 特点 |
|------|------|------|------|
| KMP | $O(n+m)$ | $O(m)$ | 预处理 $m$，线性匹配，不回退文本指针 |
| Rabin-Karp | $O(n+m)$ 均摊 | $O(1)$ | 哈希空间换时间，需二次验证 |
| Manacher | $O(n)$ | $O(n)$ | 专用回文，变换串统一奇偶 |
| AC 自动机 | $O(n+m+z)$ | $O(mz)$ | 多模式匹配， $z$ 为输出数 |

## 机制

### KMP 的核心不变量

文本指针 $i$ 只增不减；失配时 $j$ 回退到 $\pi[j-1]$， $i$ 不动。不变式：任意时刻 $T[i-j..i-1]=P[0..j-1]$ （已匹配文本等于已匹配模式前缀），每次转移后保持。

**违反**： $\pi$ 计算错（如漏 `j>0` 边界）→ $j$ 回退到错位或无法回退，结果错或死循环。

### Rabin-Karp 的约束

碰撞不可避免。模数 $M$ 太小（如 $M=2$）碰撞率 50% 退化 $O(nm)$；取大素数（$10^9+7$）碰撞可接受。**验证步骤不可省**——跳过验证会因哈希碰撞产生假阳性匹配。

### Manacher 的分隔符选择

分隔符必须选原串不出现的字符（如 `#`），否则与原字符碰撞产生虚假回文。它统一奇偶回文：跨越原字符边界时 $t[i-j]\ne t[i+j]$ 必然成立，奇偶用同一套半径逻辑。

### AC 自动机失败链接的正确性

$\text{fail}[v]$ 必须指向"当前已匹配序列的最长真后缀在 Trie 中的节点"。按 BFS 序构建保证子树处理完再处理父，否则 fail 链可能指向未建好的节点。每次命中沿 fail 链收集所有 out，保证不漏已匹配模式。

**违反**：BFS 序错 → fail 链指向未构建节点，匹配失败；忘记沿 fail 收集 out → 漏匹配模式。

### 违规后果

| 违规 | 后果 | 严重度 |
|------|------|--------|
| KMP $\pi$ 计算错 | 匹配错或死循环 | 极高 |
| Rabin-Karp 省验证 | 碰撞假阳性匹配 | 高 |
| Manacher 分隔符与原串冲突 | 虚假回文 | 高 |
| AC 自动机 BFS 序错 | fail 链指向未建节点 | 高 |
| AC 忘沿 fail 收集 out | 漏匹配模式 | 高 |

## 代码示例

**Python 3.12**：

```python
# KMP：前缀函数 + 匹配，文本指针不回退
def kmp(text, pat):
    n, m = len(text), len(pat)
    pi = [0] * m
    for i in range(1, m):                  # 预处理 π
        j = pi[i - 1]
        while j and pat[i] != pat[j]:
            j = pi[j - 1]
        pi[i] = j + 1 if pat[i] == pat[j] else j
    j = 0
    for i in range(n):                     # 匹配
        while j and text[i] != pat[j]:
            j = pi[j - 1]                  # 失配跳 π，i 不动
        if text[i] == pat[j]:
            j += 1
        if j == m:
            return i - m + 1
    return -1

# Manacher：最长回文子串
def manacher(s):
    t = '^#' + '#'.join(s) + '#$'          # ^/$ 哨兵防越界，# 统一奇偶
    n = len(t)
    p = [0] * n
    c = r = 0                              # 当前中心、右边界
    for i in range(1, n - 1):
        if i < r:
            p[i] = min(r - i, p[2 * c - i])  # 利用对称复用
        while t[i - p[i] - 1] == t[i + p[i] + 1]:
            p[i] += 1
        if i + p[i] > r:
            c, r = i, i + p[i]
    mx, ct = max((v, i) for i, v in enumerate(p))
    return s[(ct - mx) // 2 : (ct - mx) // 2 + mx]

# Rabin-Karp：滚动哈希 + 二次验证
def rabin_karp(text, pat, B=256, M=10**9 + 7):
    n, m = len(text), len(pat)
    if m > n: return -1
    pow_b = pow(B, m - 1, M)
    hp = ht = 0
    for i in range(m):                    # 初始窗口哈希
        hp = (hp * B + ord(pat[i])) % M
        ht = (ht * B + ord(text[i])) % M
    for i in range(n - m + 1):
        if ht == hp and text[i:i + m] == pat:   # 哈希命中再逐字验证
            return i
        if i < n - m:                      # 滚动：去高位加低位
            ht = (B * (ht - ord(text[i]) * pow_b) + ord(text[i + m])) % M
    return -1

# —— 简易输入输出 ——
print(kmp("aabaac", "aab"))         # 0
print(manacher("babad"))            # bab（或 aba）
print(rabin_karp("aabaac", "aab"))  # 0
```

**C++20**：

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <string_view>

// KMP
int kmp(std::string_view text, std::string_view pat) {
    int n = text.size(), m = pat.size();
    std::vector<int> pi(m, 0);
    for (int i = 1; i < m; ++i) {                 // 预处理 π
        int j = pi[i - 1];
        while (j && pat[i] != pat[j]) j = pi[j - 1];
        pi[i] = (pat[i] == pat[j]) ? j + 1 : j;
    }
    for (int i = 0, j = 0; i < n; ++i) {          // 匹配
        while (j && text[i] != pat[j]) j = pi[j - 1];
        if (text[i] == pat[j]) ++j;
        if (j == m) return i - m + 1;
    }
    return -1;
}

// Manacher：最长回文子串
std::string manacher(std::string_view s) {
    std::string t = "^#";
    for (char c : s) { t += c; t += '#'; }
    t += '$';
    int n = t.size();
    std::vector<int> p(n, 0);
    for (int i = 1, c = 0, r = 0; i < n - 1; ++i) {
        if (i < r) p[i] = std::min(r - i, p[2 * c - i]);  // 对称复用
        while (t[i - p[i] - 1] == t[i + p[i] + 1]) ++p[i];
        if (i + p[i] > r) { c = i; r = i + p[i]; }
    }
    int mx = 0, ct = 0;
    for (int i = 1; i < n - 1; ++i) if (p[i] > mx) { mx = p[i]; ct = i; }
    int start = (ct - mx) / 2;
    return std::string(s.substr(start, mx));
}

// Rabin-Karp
int rabin_karp(std::string_view text, std::string_view pat,
               long long B = 256, long long M = 1000000007) {
    int n = text.size(), m = pat.size();
    if (m > n) return -1;
    long long pow_b = 1; for (int i = 0; i < m - 1; ++i) pow_b = pow_b * B % M;
    long long hp = 0, ht = 0;
    for (int i = 0; i < m; ++i) { hp = (hp * B + pat[i]) % M; ht = (ht * B + text[i]) % M; }
    for (int i = 0; i <= n - m; ++i) {
        if (ht == hp && text.substr(i, m) == pat) return i;   // 二次验证
        if (i < n - m) {
            ht = (B * (ht - text[i] * pow_b % M + M) + text[i + m]) % M;  // 滚动
        }
    }
    return -1;
}

// —— 简易输入输出 ——
int main() {
    std::cout << kmp("aabaac", "aab") << '\n';        // 0
    std::cout << manacher("babad") << '\n';          // bab
    std::cout << rabin_karp("aabaac", "aab") << '\n';// 0
}
```
