# 字符串模式匹配

## 定义

字符串模式匹配是在文本串中定位模式串首次或所有出现位置，核心挑战是避免回溯文本指针，将匹配降至 O(n+m)。

## 数学模型

**KMP 前缀函数**

$\pi[i]$ = $p[0..i]$ 中最长相等前后缀长度

递推：

$$
j = \pi[i-1],\quad \text{while } j > 0 \land p[i] \neq p[j]:\ j = \pi[j-1]
$$

$$
\pi[i] = j + 1\ \text{if}\ p[i] == p[j]\ \text{else}\ j
$$

**Rabin-Karp 滚动哈希**

$$
H(i) = (c_1 \cdot B^{m-1} + c_2 \cdot B^{m-2} + \cdots + c_m \cdot B^0) \bmod M
$$

滚动更新：

$$
H(i+1) = (B \cdot (H(i) - c_{i+1} \cdot B^{m-1}) + c_{i+m+1}) \bmod M
$$

**Manacher 半径数组**

$t = \$ + s[0] + \$ + s[1] + \cdots + s[n-1] + \$$（插入分隔符）

半径 $p[i]$ = 以 $i$ 为中心的回文半径。

## 数据流

**KMP 匹配流程**

<pre>
文本:   a a b a a c
模式:   a a b
前缀:   0 1 2

i=0,1 匹配；i=2 失配
j=π[1]=1，从模式位置1继续
i=2 与 j=1 比较：匹配
完全匹配！
</pre>

**Manacher 变换**

<pre>
原始: "abba" → "a b b a"
添加分隔符: "$a$b$b$a$"
</pre>

**AC 自动机 Trie 构建**

<pre>
模式: ["he", "she", "his", "is"]
构建:
root
 ├─h─e (he, she)
 └─s─h─e (she)
      └─i─s (his, is)
</pre>

## 机制

**KMP 利用已匹配信息**

当失配时，已匹配部分包含模式前缀信息，无需回溯文本指针。

**Rabin-Karp 用哈希加速比较**

哈希相同再用字符串比较验证（防止哈希碰撞），避免逐字符比较。

**Manacher 统一奇偶回文**

通过插入分隔符，奇回文和偶回文都变成奇回文处理，简化边界条件。

**AC 自动机构建失败链接**

类似 KMP 前缀函数，但扩展到多模式 Trie 树上，实现同时匹配所有模式。

**违规后果**

- KMP 前缀函数计算错误：匹配结果错误
- Rabin-Karp 模数过小：哈希碰撞频繁，性能退化 O(nm)
- AC 自动机失败指针构建错误：漏匹配

```python
def kmp(text, pat):
    n, m = len(text), len(pat)
    pi = [0] * m
    for i in range(1, m):
        j = pi[i-1]
        while j and pat[i] != pat[j]: j = pi[j-1]
        if pat[i] == pat[j]: j += 1
        pi[i] = j
    j = 0
    for i in range(n):
        while j and text[i] != pat[j]: j = pi[j-1]
        if text[i] == pat[j]: j += 1
        if j == m: return i - m + 1
    return -1
```

```python
def manacher(s):
    t = '#' + '#'.join(s) + '#'
    n, p = len(t), [0] * n
    c = r = 0
    for i in range(n):
        if i < r: p[i] = min(r-i, p[2*c-i])
        while i-p[i]-1 >= 0 and i+p[i]+1 < n:
            if t[i-p[i]-1] == t[i+p[i]+1]: p[i] += 1
            else: break
        if i + p[i] > r: c, r = i, i + p[i]
    mx = max(p)
    return s[(p.index(mx)-mx)//2 : (p.index(mx)+mx)//2]
```

```python
from collections import deque
def ac_build(patterns):
    n = [{'next': {}, 'fail': 0, 'out': []}]
    for p in patterns:
        node = 0
        for ch in p:
            if ch not in n[node]['next']:
                n[node]['next'][ch] = len(n); n.append({'next': {}, 'fail': 0, 'out': []})
            node = n[node]['next'][ch]
        n[node]['out'].append(p)
    q = deque(n[0]['next'].values())
    while q:
        r = q.popleft()
        for ch, nd in n[r]['next'].items():
            q.append(nd); f = n[r]['fail']
            while f and ch not in n[f]['next']: f = n[f]['fail']
            n[nd]['fail'] = n[f]['next'].get(ch, 0)
            n[nd]['out'].extend(n[n[nd]['fail']]['out'])
    return n
```

```python
def ac_search(text, patterns):
    n = ac_build(patterns)
    state = 0
    for i, ch in enumerate(text):
        while state and ch not in n[state]['next']:
            state = n[state]['fail']
        state = n[state]['next'].get(ch, 0)
        for pat in n[state]['out']:
            yield pat, i - len(pat) + 1
```
