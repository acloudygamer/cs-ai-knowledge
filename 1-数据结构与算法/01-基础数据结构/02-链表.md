# 链表

## 定义

链表是离散的节点通过指针串联的链式结构，节点在内存中不必连续；插入删除 O(1) 但访问任意位置 O(n)。

## 数学模型

**Floyd 环检测**

设环长为 $L$，起点到环入口距离为 $F$。

快慢指针第一次相遇时：
- 慢指针走的距离：$F + a$
- 快指针走的距离：$F + a + kL$（$k \geq 1$）

因为快指针速度是慢指针的 2 倍：

$$
2(F + a) = F + a + kL \Rightarrow F + a = kL
$$

重置一指针到起点，同速前进，再次相遇点即为环入口。

**约瑟夫问题递推**

$f(1) = 0,\quad f(i) = (f(i-1) + k) \bmod i$

## 数据流

**单链表反转**

<pre>
初始: 1 -> 2 -> 3 -> None
       prev  curr  next
翻转中: None <- 1 <- 2 <- 3
结果: 3 -> 2 -> 1 -> None
</pre>

**快慢指针找中点**

<pre>
1 -> 2 -> 3 -> 4 -> 5 -> None
s     s     s     s
f           f           f
快指针到尾部时，慢指针在中点
</pre>

**LIFO 缓存（哈希表 + 双向链表）**

<pre>
get(key):
  [node] ──移动到尾部──> [node]（最新）

put(key, val):
  [新node] ──添加到尾部
  如果超容：移除头部（最旧）
</pre>

## 机制

**指针链接实现 O(1) 插入删除**

只需改变相邻节点的指针，无需移动其他节点。

**O(n) 访问是遍历的代价**

节点离散存储，无法通过公式计算地址，必须从头逐个跳转。

**哨兵节点消除边界判断**

哨兵作为虚拟头/尾节点，插入删除操作格式统一，无需单独处理空链表或单节点。

**违规后果**

- 忘记释放已删除节点的内存：内存泄漏
- 环检测中快指针步长错误：永远不相交
- 多线程并发修改链表未加锁：数据竞争

## 参考存根

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

def reverse_list(head):
    prev, curr = None, head
    while curr:
        curr.next, prev, curr = prev, curr, curr.next
    return prev
```

```python
def has_cycle(head):
    slow = fast = head
    while fast and fast.next:
        slow, fast = slow.next, fast.next.next
        if slow is fast:
            return True
    return False
```

```python
def merge_lists(l1, l2):
    dummy = ListNode()
    curr = dummy
    while l1 and l2:
        if l1.val <= l2.val:
            curr.next, l1 = l1, l1.next
        else:
            curr.next, l2 = l2, l2.next
        curr = curr.next
    curr.next = l1 or l2
    return dummy.next
```
