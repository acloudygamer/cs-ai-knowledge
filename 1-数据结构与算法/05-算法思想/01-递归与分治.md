# 递归与分治

> **版本基准**：universal —— 代码示例同时使用 Python 3.12 与 C++20

## 本质

**递归**是函数自调用，把问题化为结构相同、规模更小的子问题；**分治**是递归的一种特定形态——把问题拆成**彼此独立**的子问题分别求解，再合并结果。两者的分界就在"子问题是否重叠"：分治要求子问题独立（无重叠），否则朴素递归会指数级重复计算，得改用动态规划的记忆化。

工程上递归的正确性等价于数学归纳法：终止条件是基例、递归调用是归纳步。复杂度由 Master 定理给出，核心是三个参数——子问题数 $a$、规模缩减比 $b$、合并代价 $f(n)$。

## 数学模型

### Master 定理

设 $T(n) = aT(n/b) + f(n)$， $a \geq 1, b > 1$，令 $c = \log_b a$：

| 条件 | 解 | 含义 |
|------|----|------|
| $f(n) = O(n^{c-\epsilon})$ | $T(n) = \Theta(n^c)$ | 叶子层主导，合并代价可忽略 |
| $f(n) = \Theta(n^c \log^k n),\ k\geq 0$ | $T(n) = \Theta(n^c \log^{k+1} n)$ | 各层代价相当，临界 |
| $f(n) = \Omega(n^{c+\epsilon})$ 且正则 $a f(n/b) \leq c' f(n)$ | $T(n) = \Theta(f(n))$ | 根层合并主导 |

正则条件要求合并代价随规模增长得够快、不被子问题数放大反超。

### 递归树视角

把递归展开成树：第 $i$ 层有 $a^i$ 个子问题、每个规模 $n/b^i$、该层代价 $a^i f(n/b^i)$，树高 $\log_b n$。总代价是各层之和，三情况分别对应"叶子层/各层均匀/根层"三者谁主导。

### 典型复杂度

| 算法 | 递归式 | $a$ | $b$ | $f(n)$ | $\log_b a$ | 复杂度 |
|------|--------|-----|-----|--------|-----------|--------|
| 二分搜索 | $T(n/2)+O(1)$ | 1 | 2 | $1$ | $0$ | $O(\log n)$ |
| 归并排序 | $2T(n/2)+O(n)$ | 2 | 2 | $n$ | $1$ | $O(n\log n)$ |
| 二叉树遍历 | $2T(n/2)+O(1)$ | 2 | 2 | $1$ | $1$ | $O(n)$ |
| Strassen 矩阵乘 | $7T(n/2)+O(n^2)$ | 7 | 2 | $n^2$ | $\log_2 7\approx2.81$ | $O(n^{2.81})$ |

> **洞察**： $a$ 是"分几路"、 $b$ 是"每路缩到几分之一"、 $f(n)$ 是"合一次的代价"。归并排序 $a=b=2$ 且 $f(n)=n$ 恰处临界，故多出那个 $\log n$；Strassen 靠把 $a$ 从 8 降到 7（少做一次乘法）把指数从 3 压到 2.81。

## 数据流

### 归并排序：分到原子再线性合并

<pre>
输入: [8,3,1,7,4,2,6,5]

分（半分到单元素）:
  [8,3,1,7]          [4,2,6,5]
   [8,3] [1,7]        [4,2] [6,5]
    [8][3] [1][7]      [4][2] [6][5]   原子，单元素天然有序

治（两两合并，双指针）:
    [3,8] [1,7]        [2,4] [5,6]
   [1,3,7,8]          [2,4,5,6]
        [1,2,3,4,5,6,7,8]

栈深度 = O(log n)（树形分治），每层合并总代价 O(n)，共 log n 层 → O(n log n)
</pre>

**所有权变换**：父数组切分出子区间引用（逻辑视图，归并时才物理拷贝），子问题各自排序后由 `merge` 合并写入新数组。子问题独立是关键——左右两半的排序互不依赖，天然可并行。

### 快速排序：原地分区 + 两段递归

<pre>
输入: [3,7,8,5,2,1,4,6], pivot=6 (Lomuto)

分区: 单指针 i, 把 <= pivot 的换到左端
  [3,7,8,5,2,1,4,6] 扫描后 ≤6 的依次前置
  → [3,5,2,1,4, 6, 8,7]   pivot 归位到下标5
  左段[3,5,2,1,4] 全 ≤6, 右段[8,7] 全 >6

两段独立递归 → 左段再分区, 右段再分区 → 拼接即整体有序
</pre>

### 递归栈的物理布局

<pre>
merge_sort([8,3,1,7,4,2,6,5])
├─ left:  merge_sort([8,3,1,7])
│  ├─ left:  merge_sort([8,3]) → ... → merge→[3,8]
│  └─ right: merge_sort([1,7]) → ... → merge→[1,7]
│  └─ merge([3,8],[1,7]) → [1,3,7,8]
└─ right: merge_sort([4,2,6,5]) → ... → [2,4,5,6]
└─ merge([1,3,7,8],[2,4,5,6]) → 有序

栈帧随递归下探而增、返回而减；同深度帧不同时存活 → 栈深 = 树高 = O(log n)
</pre>

## 对比参照

| 特征 | 递归 | 分治 |
|------|------|------|
| 子问题独立性 | 不要求 | 要求 |
| 合并步骤 | 不要求 | 要求 |
| 典型骨架 | 函数自调用 | 分 → 求解 → 合 |
| 子问题重叠 | 允许（朴素递归会爆炸） | 不允许（重叠该用 DP） |
| 栈空间 | $O(n)$ （线性）或 $O(\log n)$ （树形） | $O(\log n)$ |

## 机制

### 递归三要素

1. **终止条件**：无子问题时不再自调用。必须保证递归收敛，否则栈溢出。
2. **递归调用**：参数必须向终止条件靠拢——规模递减（ $n-1$）或结构分解（ $n/2$）。不收敛即死递归。
3. **结果合并**（分治特有）：分治必须有合并步；纯递归（如遍历）可能不需要。

### 分治 vs 动态规划

| 特征 | 分治 | 动态规划 |
|------|------|---------|
| 子问题 | 独立、不重叠 | 重叠、重复计算 |
| 记忆化 | 不需要 | 必须 |
| 合并 | 必须有 | 可无 |
| 典型 | 归并排序、Strassen | 斐波那契、矩阵链乘 |

**子问题不独立却强行分治**会出错：矩阵链乘法朴素递归会产生大量重叠子问题， $O(2^n)$ 退化，必须记忆化成 DP。

### 递归与栈空间

| 模式 | 时间 | 栈空间 |
|------|------|--------|
| 树形分治（归并） | $O(n\log n)$ | $O(\log n)$ |
| 线性递归（链表找中点） | $O(n)$ | $O(n)$ |
| 尾递归优化（TCO） | $O(n)$ | $O(1)$ |

**尾递归**：递归调用是函数最后一条语句、返回后无后续操作，支持 TCO 的编译器可将其转为循环、复用同一栈帧。归并排序的 `merge` 在递归返回后执行，**不是**尾递归，无法优化；快速排序只有**第二个**递归调用是尾调用（可消为循环），第一个仍需栈。

### 合并操作的代数要求

分治合并须满足**结合律**（不同合并顺序结果一致）；交换律则保证结果与子问题求解顺序无关。归并的 `merge` 满足两者，故任意顺序合并都得同一结果。BST 中序遍历恒有序靠的是 BST 性质（左 $<$ 根 $<$ 右）叠加固定的"左-根-右"访问序，与树形无关，而非合并律。

### 并行化潜力

子问题独立 = 天然可并行。归并排序两半可并行求解： $T_1=\Theta(n\log n)$、 $T_\infty=\Theta(\log^3 n)$（配并行合并），并行度约 $n/\log^2 n$；快排的分区是串行瓶颈，并行度受限。

### 违规后果

| 失败场景 | 原因 | 后果 |
|---------|------|------|
| 终止条件永假 | 参数不收敛 | 栈溢出 |
| 子问题不独立却分治 | 独立假设不成立 | 结果错（逻辑错，非性能） |
| 合并无结合律 | 不同合并方式结果不同 | 结果不确定 |
| 非尾递归指望 TCO | 返回后有序仍需合并 | 栈无法优化，深度依旧 |

## 代码示例

**Python 3.12**：

```python
# 归并排序：树形分治, O(n log n), 空间 O(n)
def merge_sort(arr):
    if len(arr) <= 1: return arr                # 终止
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])                 # 分·独立求解左
    right = merge_sort(arr[mid:])                # 分·独立求解右
    return _merge(left, right)                   # 合

def _merge(a, b):
    c, i, j = [], 0, 0
    while i < len(a) and j < len(b):
        if a[i] <= b[j]: c.append(a[i]); i += 1
        else:            c.append(b[j]); j += 1
    c.extend(a[i:]); c.extend(b[j:])
    return c

# 快速排序: 原地 Lomuto 分区, 平均 O(n log n)
def quick_sort(arr, lo=0, hi=None):
    if hi is None: hi = len(arr) - 1
    if lo >= hi: return
    pivot = arr[hi]; store = lo                  # Lomuto: 末元素为 pivot
    for i in range(lo, hi):
        if arr[i] < pivot:
            arr[store], arr[i] = arr[i], arr[store]; store += 1
    arr[store], arr[hi] = arr[hi], arr[store]    # pivot 归位
    quick_sort(arr, lo, store - 1)
    quick_sort(arr, store + 1, hi)

# 斐波那契: 朴素递归会指数爆炸, 记忆化后 O(n)
def fib(n, memo=None):
    if memo is None: memo = {}
    if n in memo: return memo[n]
    if n <= 1: return n
    memo[n] = fib(n-1, memo) + fib(n-2, memo)     # 子问题重叠 → 记忆化
    return memo[n]

# —— 简易输入输出 ——
print(merge_sort([8,3,1,7,4,2,6,5]))   # [1,2,3,4,5,6,7,8]
a = [3,7,8,5,2,1,4,6]; quick_sort(a); print(a)   # [1,2,3,4,5,6,7,8]
print(fib(10))                         # 55
```

**C++20**：

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

// 归并排序: [lo, hi)
void mergeSort(std::vector<int>& a, int lo, int hi) {
    if (hi - lo <= 1) return;
    int mid = (lo + hi) / 2;
    mergeSort(a, lo, mid);
    mergeSort(a, mid, hi);
    std::vector<int> tmp(a.begin() + lo, a.begin() + hi);
    int i = 0, j = mid - lo, k = lo, n1 = mid - lo, n2 = hi - lo;
    while (i < n1 && j < n2)
        a[k++] = (tmp[i] <= tmp[j]) ? tmp[i++] : tmp[j++];
    while (i < n1) a[k++] = tmp[i++];
    while (j < n2) a[k++] = tmp[j++];
}

// 快速排序: Lomuto 原地分区
void quickSort(std::vector<int>& a, int lo, int hi) {
    if (lo >= hi) return;                        // [lo, hi]
    int pivot = a[hi], store = lo;
    for (int i = lo; i < hi; ++i)
        if (a[i] < pivot) std::swap(a[store++], a[i]);
    std::swap(a[store], a[hi]);
    quickSort(a, lo, store - 1);
    quickSort(a, store + 1, hi);
}

// 斐波那契: 记忆化递归
long long fib(int n, std::vector<long long>& memo) {
    if (memo[n] != -1) return memo[n];
    return memo[n] = fib(n - 1, memo) + fib(n - 2, memo);
}

int main() {
    std::vector<int> a = {8,3,1,7,4,2,6,5};
    mergeSort(a, 0, (int)a.size());
    for (int x : a) std::cout << x << ' ';       // 1 2 3 4 5 6 7 8
    std::cout << '\n';

    std::vector<int> b = {3,7,8,5,2,1,4,6};
    quickSort(b, 0, (int)b.size() - 1);
    for (int x : b) std::cout << x << ' ';       // 1 2 3 4 5 6 7 8
    std::cout << '\n';

    std::vector<long long> memo(11, -1);
    memo[0] = 0; memo[1] = 1;
    std::cout << fib(10, memo) << '\n';          // 55
}
```
