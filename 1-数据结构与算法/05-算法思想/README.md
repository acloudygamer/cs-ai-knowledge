# 算法思想

> **版本基准**: universal

前四章按"数据怎么摆"分族，本章按"消减了哪类无用功"分族。六种思想各对付一种浪费：分治消减重复的子问题规模，排序压到比较次数的下界，二分每次砍掉一半候选，动态规划消减重复计算，贪心消减不必要的比较，回溯与分支限界消减搜索空间。位运算单列，它消减的是表示层——把状态压进机器字。

| 篇目 | 主链与消费的前置结论 |
| --- | --- |
| 01 递归与分治 | 递归的栈帧与深度账 → 分治三段 → 合并代价决定总代价（消费 01 章 Master）→ 可结合与可并行 → 显式栈与快速幂 → 子问题重叠时转向 DP |
| 02 排序 | 决策树给出 $\Omega(n\log n)$ 下界 → 归并、快排、堆排的机制与常数 → 稳定性对多键排序的意义 → 非比较排序的前提 → introsort 与 timsort 的保险设计 |
| 03 二分搜索 | 单调性砍半候选 → 闭区间与左闭右开两套不变量 → 左右边界与插入点 → `mid` 溢出与死循环 → 旋转数组 → 二分答案 → 30 次随机访存的代价 |
| 04 动态规划 | 重叠子问题 → 记忆化 → 状态自包含（无后效性）→ 递推即拓扑序 → 滚动数组 → 背包与序列两族范式 → 状态爆炸的降维 |
| 05 贪心 | 只选一次不回退 → 两条成立条件 → 交换论证与切分性质 → 区间调度 → 哈夫曼 → 反例与 DP 的分界 |
| 06 回溯与分支限界 | 解空间树 → 深度优先与撤销的对称 → 剪枝必须是充分条件 → 限界函数与可采纳性 → 优先队列与 A* → 与 DP 的分界 |
| 07 位运算 | 机器字的 64 路并行 → 集合运算与位运算同构 → 补码与 lowbit → 位掩码作集合与子集枚举 → popcount 与移位语义 → 溢出边界 |
