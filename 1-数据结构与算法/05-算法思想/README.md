# 算法思想

> **版本基准**: universal

算法不是技巧清单，而是消减无用功的几种思想：分治消减规模、二分消减一半候选、动态规划消减重复子问题、贪心消减回溯、回溯与分支限界消减搜索空间、位运算消减表示层（直接操作机器字）。

组织逻辑：**每种思想回答"它消减了什么"**。技巧性的扫描模式（双指针、滑动窗口、单调栈）依附于具体结构，已分发到 02-线性结构 的对应篇章。
