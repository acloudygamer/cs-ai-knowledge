# 动态规划

> **版本基准**：universal —— 代码示例同时使用 Python 3.12 与 C++20

## 本质

动态规划（Dynamic Programming，DP）求解一类**含重叠子问题**的优化问题：把原问题拆成子问题，按拓扑序逐个求解并**记下每个子问题的答案**，后续遇到同一子问题直接查表，避免指数级重复枚举。它成立的两根支柱是**最优子结构**（全局最优解必由子问题的最优解拼成）与**无后效性**（当前状态一旦确定，未来决策不再依赖到达该状态的路径）。

> **洞察**：DP = 在状态 DAG 上按拓扑序求最短/最长路径。状态是顶点，转移是带代价的边，状态转移方程就是 Bellman 最短路方程在 DAG 上的特例——拓扑序保证了"算到某个状态时，它所有前驱都已就绪"。

## 数学模型

### 状态转移方程的一般形式

设 `dp[i]` 为到达状态 $i$ 的最优值（或方案数）， $S(i)$ 为 $i$ 的前驱状态集， $\text{cost}(j, i)$ 为 $j \to i$ 的转移代价：

$$dp[i] = \operatorname*{opt}_{j \in S(i)} \big( dp[j] + \text{cost}(j, i) \big)$$

$\text{opt}$ 为 $\max$ 或 $\min$。每个状态算一次、查表复用，是把指数枚举压成多项式的关键。

### 复杂度

设状态总数 $n$、每状态转移候选数 $t$。无后效性保证转移图是 DAG，拓扑序即计算序，排序成本 $O(n)$：

$$T(n) = O(n \cdot t)$$

空间：默认 $O(n)$ 存全表；若转移只依赖最近 $k$ 个连续历史状态（如斐波那契 $k=2$），用滚动数组降到 $O(k)$。

### 最优子结构的数学表达

设 $OPT(n)$ 为规模 $n$ 的最优解， $k$ 为某个分解点：

$$OPT(n) = \operatorname*{opt}_{k} \big( \text{solution}(k) \oplus OPT(n-k) \big)$$

$\oplus$ 是子解的拼接操作。**拼接必须满足结合律且子解独立**——这是区间 DP 能枚举分割点 $k$ 的前提：

$$dp[i][j] = \min_{i < k < j} \big( dp[i][k] + dp[k][j] + \text{cost}(i,k,j) \big)$$

> **洞察**：最优子结构 = "全局最优的子路径也必须最优"。最短路满足它（反证：若 $A \to C$ 子路径非最优，替换成更优者，整条 $A \to B$ 还能更短，矛盾）；最长简单路径不满足（两段最长子路径拼起来可能成环、不再简单）——这就是最长路不能用 DP 的根因。

## 数据流

### 爬楼梯：线性 DP 的拓扑序计算

<pre>
问题: 每次爬 1 或 2 步，爬 n=5 级的走法数

base case:
  dp[0]=1  (0 步：一种"不动"走法)
  dp[1]=1

拓扑序（自然序）逐项计算:
  dp[2] = dp[1] + dp[0] = 1 + 1 = 2
  dp[3] = dp[2] + dp[1] = 2 + 1 = 3
  dp[4] = dp[3] + dp[2] = 3 + 2 = 5
  dp[5] = dp[4] + dp[3] = 5 + 3 = 8

状态依赖（DAG，自然序即拓扑序）:
  dp[0] dp[1] → dp[2] → dp[3] → dp[4] → dp[5]
        ↑________________↑        (dp[2] 同时是 dp[4] 前驱)
</pre>

**所有权变换**：朴素递归重复展开子树（ $F(3)$ 算两次、 $F(2)$ 算三次，指数爆炸）；DP 把每个子结果落进一维表 `dp[0..n]`，后续直接读表，从"重复计算"转为"一次计算多次读取"。

### 滚动数组压缩： $O(n) \to O(k)$

<pre>
斐波那契只依赖最近 2 项 → 只留 2 个变量
  i=2: (prev2=1, prev1=1) → cur=2, 滚动为 (1,2)
  i=3: (1,2) → cur=3, 滚动为 (2,3)
  i=4: (2,3) → cur=5, 滚动为 (3,5)
  i=5: (3,5) → cur=8

每步只留必要 k=2 个状态 → O(1) 额外空间
</pre>

### 编辑距离：二维区间 DP

<pre>
word1="ab", word2="ac"   dp[i][j] = w1前i字符 → w2前j字符 的最少编辑

      ""  a   c        base: dp[0][j]=j (全插入), dp[i][0]=i (全删除)
  ""    0  1   2
  a     1  0   1       w1[0]==w2[0]=='a' → dp[1][1]=dp[0][0]=0
  b     2  1   1       w1[1]='b'≠w2[1]='c' → 1+min(上,左,对角)=1

  转移: 字符相等 dp[i-1][j-1]
        否则     1 + min(删 dp[i-1][j], 插 dp[i][j-1], 换 dp[i-1][j-1])
</pre>

每格只依赖上、左、左上三格——二维但仍是 DAG，行序+列序即拓扑序。

## 对比参照

| 维度 | 记忆化搜索（自顶向下） | 递推 DP（自底向上） |
|------|----------------------|---------------------|
| 计算序 | 按需递归，命中即查表 | 严格按拓扑序填表 |
| 空间 | $O(n)$ + 递归栈 | $O(n)$，可滚动压缩 |
| 适合 | 状态稀疏、转移不规则 | 状态稠密、转移规整 |
| 常数 | 递归调用开销大 | 循环填表，缓存友好 |

## 机制

### 记忆化为何有效：重叠子问题

朴素递归算 $F(5)$： $F(3)$ 算 2 次、 $F(2)$ 算 3 次，子问题重复指数增长。记忆化把每个子结果存入表，首次算后直接查，复杂度从 $O(2^n)$ 降到 $O(n)$。**关键不在"递归变迭代"，而在"每个子问题只算一次"**——这正是 DP 与普通分治（子问题不重叠）的分界。

### 无后效性：状态必须"自包含"

一旦 `dp[i]` 确定，后续任何决策都不应回头改它。若当前决策会改变未来可选策略集（如棋类博弈：落子改变对手的可行位置），简单状态不足以描述——需 Minimax + 剪枝，而非裸 DP。**违反无后效性的信号**：你发现状态里还缺一个"之前路径留下的约束"才能算出转移。

### 最优子结构：反例与正例

- **正例·最短路**： $A \to B$ 最短路必过某中间点 $C$，且 $A \to C$、 $C \to B$ 子路径也各自最短。可 DP。
- **反例·最长简单路径**： $A \to C$、 $C \to B$ 两段最长子路径拼起来可能成环，不再简单，子最优拼不成全局最优。不可裸 DP。

### 拓扑序敏感性

DP 正确性依赖"算到某状态时，其所有前驱已就绪"。无后效性保证转移图是 DAG、存在拓扑序。若图有环则无拓扑序，DP 不适用——含负权边（无负环）需 Bellman-Ford 迭代松弛；存在负权回路时最短路本身无定义，Bellman-Ford 也只能检测并报出。**违反后果**：在未算完前驱时就用其值，会读到"幽灵值"，结果错乱。

### 状态爆炸与降维手段

当状态空间 $n$ 极大（如 $10^9$）无法逐个枚举：**数位 DP**（只枚举数位，状态 $O(\log n)$）、**状态压缩 DP**（集合用位掩码，状态 $O(2^n)$ 但 $n$ 取小值，如旅行商）、**斜率优化/单调队列/凸包优化**（加速特定形式的转移，降 $t$）。

### 违规后果

| 违规 | 后果 |
|------|------|
| 无后效性不成立却硬 DP | 状态信息不足，结果错 |
| 无最优子结构却套 DP | 子最优拼不成全局最优，结果错 |
| 不按拓扑序填表 | 读到未计算的幽灵值 |
| 转移无结合律却用区间 DP | 枚举分割点无意义，结果错 |
| 滚动数组漏留依赖状态 | 读到被覆盖的旧值，结果错 |

## 代码示例

**Python 3.12**：

```python
# 爬楼梯：线性 DP + 滚动数组压缩到 O(1)
def climb_stairs(n):
    if n <= 2: return n
    prev2, prev1 = 1, 2          # 只留最近 2 个状态
    for _ in range(3, n + 1):
        prev2, prev1 = prev1, prev2 + prev1   # 滚动
    return prev1

# 编辑距离：二维区间 DP，dp[i][j] = w1前i → w2前j 的最少编辑
def edit_distance(w1, w2):
    m, n = len(w1), len(w2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(m + 1): dp[i][0] = i       # base: 全删除
    for j in range(n + 1): dp[0][j] = j       # base: 全插入
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if w1[i-1] == w2[j-1]:
                dp[i][j] = dp[i-1][j-1]       # 字符相等，免编辑
            else:
                dp[i][j] = 1 + min(dp[i-1][j],    # 删
                                   dp[i][j-1],    # 插
                                   dp[i-1][j-1])  # 换
    return dp[m][n]

# 最长递增子序列：O(n^2) DP（可优化到 O(n log n)，见二分搜索）
def lis(nums):
    if not nums: return 0
    dp = [1] * len(nums)         # dp[i] = 以 nums[i] 结尾的 LIS 长度
    for i in range(len(nums)):
        for j in range(i):
            if nums[j] < nums[i]:
                dp[i] = max(dp[i], dp[j] + 1)
    return max(dp)

# —— 简易输入输出 ——
print(climb_stairs(5))                  # 8
print(edit_distance("ab", "ac"))        # 1
print(lis([10, 9, 2, 5, 3, 7, 101, 18]))  # 4  (2,3,7,101 或 2,5,7,101)
```

**C++20**：

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

// 爬楼梯：滚动数组 O(1) 空间
int climbStairs(int n) {
    if (n <= 2) return n;
    long long prev2 = 1, prev1 = 2;
    for (int i = 3; i <= n; ++i) {
        long long cur = prev2 + prev1;
        prev2 = prev1; prev1 = cur;
    }
    return (int)prev1;
}

// 编辑距离：二维 DP
int editDistance(const std::string& w1, const std::string& w2) {
    int m = (int)w1.size(), n = (int)w2.size();
    std::vector<std::vector<int>> dp(m + 1, std::vector<int>(n + 1, 0));
    for (int i = 0; i <= m; ++i) dp[i][0] = i;
    for (int j = 0; j <= n; ++j) dp[0][j] = j;
    for (int i = 1; i <= m; ++i)
        for (int j = 1; j <= n; ++j)
            if (w1[i-1] == w2[j-1]) dp[i][j] = dp[i-1][j-1];
            else dp[i][j] = 1 + std::min({dp[i-1][j], dp[i][j-1], dp[i-1][j-1]});
    return dp[m][n];
}

// 最长递增子序列：O(n^2) DP
int lis(const std::vector<int>& a) {
    if (a.empty()) return 0;
    std::vector<int> dp(a.size(), 1);
    for (int i = 0; i < (int)a.size(); ++i)
        for (int j = 0; j < i; ++j)
            if (a[j] < a[i]) dp[i] = std::max(dp[i], dp[j] + 1);
    return *std::max_element(dp.begin(), dp.end());
}

int main() {
    std::cout << climbStairs(5) << '\n';                          // 8
    std::cout << editDistance("ab", "ac") << '\n';                // 1
    std::cout << lis({10,9,2,5,3,7,101,18}) << '\n';            // 4
}
```
