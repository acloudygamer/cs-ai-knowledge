# 回溯与分支限界

> 前置：[05-贪心](./05-贪心.md) · 后续：[07-位运算](./07-位运算.md)

> **版本基准**：universal —— 代码示例同时使用 Python 3.12 与 C++20

## 本质

回溯是对**状态空间树**做深度优先遍历、系统性枚举所有合法解的框架：在每层递归里依次尝试所有可选的选择，选一个下探、递归、回到本层后**撤销刚才的选择**再试下一个。配合**剪枝**——在部分赋值已违反约束时整棵子树都不再展开——把指数级蛮力压到可解规模。回溯不是某个具体算法，而是"递归 + 选择 + 撤销"的搜索骨架。

当目标从"枚举合法解"换成"找最优解"，同一棵状态空间树换一副走法就是**分支限界**（Branch and Bound, B&B）：遍历从 DFS 换成最佳优先（优先队列扩展最有希望的分支），剪枝判据从"约束违反"换成"限界函数"——估计每个分支可达的最优值界，把不可能优于已知最优的分支整棵剪掉。A*（启发式最短路径搜索）是它在路径搜索上的特例。

工程上回溯的核心动作只有两个：**选/撤销的对称对**（`used[i]=True; path.append(...)` 必须配 `path.pop(); used[i]=False`），以及**剪枝的充分性**（剪枝条件必须是"此子树必无解"的充分判据，否则要么漏解要么等于没剪）。

## 数学模型

### 状态空间树规模

设解的深度为 $d$ （选择序列长度），第 $i$ 层分支因子为 $b_i$，叶节点数（完整解数上界）：

$$N_{leaf} = \prod_{i=1}^{d} b_i = O(b^d),\qquad b = \max_i b_i$$

总节点数 $\approx \frac{b}{b-1}N_{leaf}$，同为 $O(b^d)$ 量级。

无剪枝时必须访问绝大部分节点。剪枝后实际访问 $N'$，代价 $T = O(N')$， $N' \ll b^d$ 当剪枝足够紧。

### 经典解空间

- **全排列**： $N = n!$ （ $n$ 层、每层可选数递减）。
- **子集枚举**： $N = 2^n$ （每元素选/不选，二叉）。
- **N 皇后**： $N = n^n$ （每行 $n$ 列），剪枝后实际访问节点数比 $n^n$ 低多个量级（如 $n=4$ 时仅约 $20$ 个节点，对比 $4^4=256$）。

### 约束满足（CSP）视角

每个节点是一个部分赋值 $(x_1=v_1,\dots,x_k=v_k)$。剪枝=**约束传播**：一旦当前部分赋值违反某约束，以该节点为根的整棵子树必无合法解，直接砍掉。N 皇后里每放一个皇后，就禁止后续所有行在同列、同两条对角线落子。

> **洞察**：回溯 = 枚举 + 提前止损。不剪枝的回溯和暴力没区别；剪枝的威力来自"在尽量浅的层、尽早识别无解子树"——越早砍，省掉的子树以 $b^{\text{剩余深度}}$ 指数放大。

### 限界函数与可采纳性

分支限界的剪枝判据是**限界函数**：对最大化问题估计该分支可达的上界、对最小化估计下界，界不优于已知最优的分支剪掉。界必须**可采纳**——最小化的下界不高估、最大化的上界不低估该分支内的真实最优，否则会把含最优解的分支误剪掉；界越紧剪得越多，但算界本身有成本——弱界先行、必要时换紧界是常见折中。

A* 的限界写成：

$$f(n) = g(n) + h(n)$$

$g(n)$ 是起点到 $n$ 的已知实际代价， $h(n)$ 是到目标的启发估计。若恒有 $h(n)\le h^{\ast}(n)$（可采纳，永不高估），则最优路径上的节点 $f(n)\le C^{\ast}$，A* 按 $f$ 升序扩展，必在劣于 $C^{\ast}$ 的目标之前先碰到最优目标——可采纳的 A* 返回最优解。更强的一致性条件 $h(u)\le c(u,v)+h(v)$ 保证扩展的 $f$ 值单调非递减，节点不会被重复打开。

界从哪里来？取一个比原问题弱、但可快速求解的**松弛问题**，其最优值就是界——松弛掉多少约束，界就松多少。三个经典设计：

| 问题 | 松弛 | 界 |
|------|------|-----|
| TSP（最小化） | 去掉"单回路"约束 | 已付代价 + 未访问顶点的最小生成树（1-树）下界 |
| 0/1 背包（最大化） | 允许切分物品 | 已选价值 + 剩余容量按 $v/w$ 密度的分数背包上界 |
| 整数规划 | 丢掉整数约束 | LP 松弛的连续最优值 |

## 数据流

### 全排列：选/撤销的对称对

<pre>
nums = [1,2,3]   path 累积选择, used 标记已用

root path=[]
  选 1 → path=[1] used={1}
    选 2 → path=[1,2] used={1,2}
      选 3 → path=[1,2,3] ✓ 记录, 回溯: pop3, used[3]=False
    撤销 2: pop2, used[2]=False
    选 3 → path=[1,3] → 选 2 → [1,3,2] ✓ 记录
  撤销 1: pop1, used[1]=False
  选 2 → ... (同理得 [2,1,3],[2,3,1])
  选 3 → ... (同理得 [3,1,2],[3,2,1])

铁律: 递归返回后必须把 used[i] 与 path 同步还原，
      否则兄弟分支读到"残留已选"，解要么重复元素要么漏元素
</pre>

**所有权变换**：算法维护一个共享的 `path` 与 `used`，递归下探时增、返回时减——同一份容器被各条递归路径复用，避免每条路径各拷一份。撤销是这种复用得以正确的前提。

### N 皇后：约束剪枝

<pre>
n=4, 按行放置，queens[r]=c

行0: 放 (0,0)
行1: c=0 同列禁; c=1 对角禁 (|1-0|==|1-0|); c=2, c=3 可放 → 放 (1,2)
行2: c=0 与(0,0)同列禁
     c=1 与(1,2)对角禁 (|2-1|==|1-2|)
     c=2 与(1,2)同列禁
     c=3 与(1,2)对角禁 (|2-1|==|3-2|)
     → 无可选 → 回溯, 行1 改试 (1,3) 继续
</pre>

剪枝用 `|r-r'| == |c-c'|`（主/副对角线统一为绝对差相等）与 `c == c'`（同列）两条判据；同行天然不冲突（每行只放一个）。

### 子集枚举：选/不选的二叉

<pre>
nums=[1,2,3]   每个节点记录一个子集
root [] 
  选1 → [1] → 选2 → [1,2] → 选3 → [1,2,3]
                        撤销3 → [1,2]
              撤销2 → [1] → 跳2 → 选3 → [1,3]
  撤销1 → [] → 选2 → [2] → ...
共 2^3=8 个子集
</pre>

### 0/1 背包的限界与剪枝

<pre>
容量 W=10, 物品 [(v=60,w=5),(v=100,w=8),(v=120,w=15)]
解空间树: 每层对一件物品 "选/不选"
限界: 当前价值 + 剩余物品的分数背包上界(按 v/w 密度贪心放松)

节点(已选物品0, 价值60, 重5):
  剩余容量 5, 剩余物品 [(100,8),(120,15)]
  分数上界 = 60 + min(5,8)*100/8 = 122.5
  若此上界 ≤ 已知最优 → 剪; 否则继续分支

剪枝两条件:
  1) 重量超容 → 该分支不可行, 剪
  2) 上界 ≤ 当前最优 → 不可能更优, 剪
</pre>

## 对比参照

| 维度 | 回溯 | 分支限界 | A* |
|------|------|----------|-----|
| 遍历 | DFS（递归栈） | 最佳优先（优先队列） | 最佳优先（优先队列） |
| 目标 | 找所有解 / 任一解 | 找最优解 | 最短路径 |
| 剪枝 | 约束判无解 | 限界函数判上下界 | $f=g+h$ 估计 |
| 空间 | $O(d)$ 递归栈 | $O(b^d)$ 最坏 | $O(b^d)$，IDA* 降为 $O(bd)$ |

## 机制

### 为什么必须撤销选择

DFS 路径共享中间节点：同一次 `backtrack` 调用里循环走多个兄弟分支，它们共用同一份 `path`/`used`。若递归返回后不还原 `used[i]`，下一个分支会看到"残留的已选标记"，要么重复用同一元素（解非法）、要么跳过本可用元素（解不全）。撤销与选择必须严格对称——选了什么、返回时就还掉什么。

### 剪枝条件必须是"无解"的充分条件

剪枝返回"跳过"时，必须保证该子树**确实**无合法解。过紧（把有解子树也砍了）会漏解；过松（永远不触发）等于没剪，退化为蛮力。N 皇后的 `is_valid` 就是充分判据：当前部分布局已冲突，再加皇后不可能修复，故可砍。

### 递归深度与栈溢出

递归深度 = 解长度 $d$。 $d$ 很大（如 $10^5$）时系统栈会溢出。对策：用显式栈模拟递归（迭代回溯），把"系统栈"换成"堆上由程序员管理的状态栈"——本质是用堆空间换栈空间。

### A* 的退化与内存对策

| $h$ 设计 | 结果 |
|----------|------|
| $h=0$ | 退化为 Dijkstra（最优但无启发引导） |
| $h=h^{\ast}$（完美） | 沿最优路径直走 |
| $h>h^{\ast}$（不可采纳） | 可能跳过最优、返回次优 |

A* 须存 open + closed 两集，状态空间大时内存爆炸（15 数码约 $10^{13}$ 个状态）；IDA*（迭代加深 A*）用 $f$ 阈值替代 open 集，每轮 DFS 只走 $f\le$ 阈值的分支，空间降到 $O(bd)$。

### 与 DP 的关系

B&B 自顶向下、只展开限界选中的子问题，用启发换时间；DP 自底向上、展开全部子问题，用空间换时间。两者省的是不同的功：B&B 用限界剪掉注定次优的子树、避免展开，DP 用查表消除重叠子问题的重算；B&B 是"按需展开 + 剪枝"，DP 是"全展开 + 记忆"。

### 违规后果

| 违规 | 后果 |
|------|------|
| 递归返回后未撤销选择 | 兄弟分支读到残留状态，解重复/漏元素 |
| 剪枝条件非充分（误砍） | 漏掉合法解甚至最优解 |
| 无剪枝处理大规模问题 | 指数爆炸，超时 |
| 递归深度过大未改迭代 | 栈溢出段错误 |
| 界不可采纳（下界高估 / 上界低估分支真实最优） | 误剪最优分支，返回次优 |
| 无 closed 去重 | 同状态反复扩展，指数膨胀 |

## 代码示例

**Python 3.12**：

```python
import heapq

# 全排列：选/撤销对称
def permute(nums):
    res, used = [], [False] * len(nums)
    def bt(path):
        if len(path) == len(nums):
            res.append(path[:]); return            # 拷贝当前解
        for i in range(len(nums)):
            if used[i]: continue
            used[i] = True; path.append(nums[i])    # 选
            bt(path)
            path.pop(); used[i] = False             # 撤销（对称）
    bt([]); return res

# 子集枚举：每个节点都是一个子集
def subsets(nums):
    res = []
    def bt(start, path):
        res.append(path[:])                        # 收集当前路径
        for i in range(start, len(nums)):
            path.append(nums[i]); bt(i + 1, path); path.pop()
    bt(0, []); return res

# N 皇后：|Δr|==|Δc| 判对角冲突
def solve_n_queens(n):
    res, queens = [], [-1] * n                     # queens[r]=c
    def valid(r, c):
        for rr in range(r):
            cc = queens[rr]
            if cc == c or abs(r-rr) == abs(c-cc):  # 同列或同对角
                return False
        return True
    def bt(r):
        if r == n:
            res.append(queens[:]); return
        for c in range(n):
            if valid(r, c):
                queens[r] = c; bt(r + 1); queens[r] = -1   # 撤销
    bt(0); return res

# A* 通用骨架: h 须可采纳(不高估真实代价)
def astar(start, goal, h, neighbors):
    counter = 0                              # 打破 f 平局, 避免比较 state
    open_set = [(h(start), 0, counter, start)]
    g_score = {start: 0}
    came_from = {start: None}
    while open_set:
        f, g, _, cur = heapq.heappop(open_set)
        if g > g_score.get(cur, float('inf')):    # 过时条目跳过
            continue
        if goal(cur):
            path = []
            while cur is not None:
                path.append(cur); cur = came_from[cur]
            return path[::-1]
        for nxt, cost in neighbors(cur):
            ng = g + cost
            if ng < g_score.get(nxt, float('inf')):
                g_score[nxt] = ng; came_from[nxt] = cur
                counter += 1
                heapq.heappush(open_set, (ng + h(nxt), ng, counter, nxt))
    return None

# 八数码: h = 不在位方块数(可采纳)
GOAL = (1,2,3,4,5,6,7,8,0)
def h_misplaced(s): return sum(1 for i in range(9) if s[i] and s[i] != GOAL[i])
def neighbors(s):
    z = s.index(0); r, c = divmod(z, 3); out = []
    for dr, dc in ((1,0),(-1,0),(0,1),(0,-1)):
        nr, nc = r+dr, c+dc
        if 0 <= nr < 3 and 0 <= nc < 3:
            lst = list(s); nz = nr*3 + nc
            lst[z], lst[nz] = lst[nz], lst[z]
            out.append((tuple(lst), 1))
    return out

# —— 简易输入输出 ——
print(permute([1,2,3]))        # 6 个排列
print(len(subsets([1,2,3])))   # 8
print(len(solve_n_queens(4)))  # 2  ([1,3,0,2] 与 [2,0,3,1])
print(len(solve_n_queens(8)))  # 92
path = astar((1,2,3,4,0,6,7,5,8), lambda s: s == GOAL, h_misplaced, neighbors)
print(len(path) - 1)           # 2 (八数码: 0 与 5、8 各换一次)
```

**C++20**：

```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <queue>
#include <algorithm>

// 全排列
void permute(std::vector<int>& nums, std::vector<bool>& used,
             std::vector<int>& path, std::vector<std::vector<int>>& res) {
    if ((int)path.size() == (int)nums.size()) { res.push_back(path); return; }
    for (int i = 0; i < (int)nums.size(); ++i) {
        if (used[i]) continue;
        used[i] = true; path.push_back(nums[i]);      // 选
        permute(nums, used, path, res);
        path.pop_back(); used[i] = false;             // 撤销
    }
}

// N 皇后：返回解的个数
int nQueens(int n) {
    std::vector<int> q(n, -1);
    int res = 0;
    auto valid = [&](int r, int c) -> bool {
        for (int rr = 0; rr < r; ++rr) {
            int cc = q[rr];
            if (cc == c || std::abs(r - rr) == std::abs(c - cc)) return false;
        }
        return true;
    };
    auto bt = [&](auto& self, int r) -> void {
        if (r == n) { ++res; return; }
        for (int c = 0; c < n; ++c)
            if (valid(r, c)) { q[r] = c; self(self, r + 1); q[r] = -1; }
    };
    bt(bt, 0);
    return res;
}

// 0/1 背包分支限界(最大化): 限界 = 已选价值 + 分数背包上界
struct Item { double v, w; };

double bound(int i, double v, double cap, const std::vector<Item>& it) {
    double tot = v;
    for (int k = i; k < (int)it.size() && cap > 0; ++k) {
        double take = std::min(it[k].w, cap);
        tot += take * (it[k].v / it[k].w);
        cap -= take;
    }
    return tot;
}

double knapsack(std::vector<Item> it, double W) {
    std::sort(it.begin(), it.end(),
              [](auto& a, auto& b){ return a.v/a.w > b.v/b.w; });  // 按密度降序, 界更紧
    struct Node { int i; double v, w; };
    std::queue<Node> q;
    q.push({0, 0, 0});
    double best = 0;
    while (!q.empty()) {
        auto [i, v, w] = q.front(); q.pop();
        if (i == (int)it.size()) continue;
        if (w + it[i].w <= W) {                          // 选物品 i
            best = std::max(best, v + it[i].v);
            q.push({i+1, v + it[i].v, w + it[i].w});
        }
        if (bound(i+1, v, W - w, it) > best)             // 不选 i 且上界仍有希望
            q.push({i+1, v, w});
    }
    return best;
}

int main() {
    std::vector<int> nums = {1, 2, 3};
    std::vector<bool> used(3, false);
    std::vector<int> path;
    std::vector<std::vector<int>> res;
    permute(nums, used, path, res);
    std::cout << res.size() << '\n';        // 6
    std::cout << nQueens(4) << '\n';        // 2
    std::cout << nQueens(8) << '\n';        // 92
    std::cout << knapsack({{60,5},{100,8},{120,15}}, 16) << '\n';  // 160 (物品0+1)
}
```
