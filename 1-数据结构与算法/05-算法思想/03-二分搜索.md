# 二分搜索

> **版本基准**：universal —— 代码示例同时使用 Python 3.12 与 C++20

## 本质

二分搜索在**有序序列**上每步把搜索空间折半，用一次 $O(1)$ 比较决定目标落在左半还是右半，总比较次数 $\lceil \log_2 n \rceil$。它把"有序"这层信息直接换成搜索效率：线性查找是算术式递减 $n \to n-1 \to \dots$，二分是几何式递减 $n \to n/2 \to n/4 \to \dots$ ——后者每步都榨干了"有序"能给出的全部信息增益。

工程上二分的关键不在写出能跑的循环，而在**区间定义的统一**与**边界收缩的正确**：开闭区间风格一旦定下就不能混用，`left`/`right` 在命中目标时是"立即返回"还是"继续收缩"决定了你找的是任意位置、左边界还是右边界。

## 数学模型

### 决策树高度与下界

每步把规模为 $n$ 的问题归约为 $n/2$：

$$T(n) = T(n/2) + O(1) = T(n/2^k) + k$$

令 $n/2^k \leq 1$ 得 $k \geq \log_2 n$，故 $T(n) = O(\log n)$。

下界： $n$ 个元素的搜索问题，基于比较的算法决策树至少要有 $n$ 个叶节点（每个叶对应一个可能的目标位置），高度 $\geq \lceil \log_2 n \rceil$。二分搜索恰好达到这根下界，因此**比较意义上最优**。

> **洞察**： $n!$ 是排序要区分的状态数（所以排序下界是 $\log(n!)=n\log n$），而搜索只要区分 $n$ 个位置，故下界是 $\log n$。同样是决策树，叶节点数决定了高度。

### 旋转数组：先定有序半边再二分

有序数组 $[a_0, \dots, a_{n-1}]$ 旋转 $p$ 位得 $[a_p, \dots, a_{n-1}, a_0, \dots, a_{p-1}]$。它由两段有序子数组拼接，用 `arr[mid]` 与 `arr[left]` 比较即可判断哪半边是有序的，再判断目标是否落在有序半边内，丢弃另一半。每步仍折半，保持 $O(\log n)$。

注意边界退化：当 `arr[mid] == arr[left]`（如含重复元素）时无法判定哪边有序，需退化为线性收缩（左移 `left`）才能保证正确，此时最坏退化为 $O(n)$。无重复时仍是严格 $O(\log n)$。

## 数据流

### 标准二分（闭区间 $[l, r]$）

<pre>
target=6, 序列: [1, 3, 5, 6, 7, 9]
  l=0, r=5, mid=2, arr[2]=5 < 6 → 目标在右 → l=3
  l=3, r=5, mid=4, arr[4]=7 > 6 → 目标在左 → r=3
  l=3, r=3, mid=3, arr[3]=6 == 6 → 命中 return 3

搜索空间: [0,5] → [3,5] → [3,3]   每步折半
</pre>

### 左边界二分（找第一个 $\geq$ target）

<pre>
target=5, 序列: [1, 3, 5, 5, 5, 9]   左闭右开 [l, r)

  l=0, r=6, mid=3, arr[3]=5 >= 5 → 收缩右端 r=mid=3
  l=0, r=3, mid=1, arr[1]=3 < 5  → 扩张左端 l=mid+1=2
  l=2, r=3, mid=2, arr[2]=5 >= 5 → 收缩右端 r=mid=2
  l=2, r=2 → 循环结束，l==r==2 即第一个 >= 5 的位置

关键: arr[mid] >= target 时 right=mid（不返回），向左压到最左可行点
</pre>

**所有权变换**：算法不搬动数据，只移动两个整型指针 `l`、`r`；输入数组的所有权与值均不变，最终用 $O(1)$ 指针状态编码出答案位置。

### 旋转数组搜索

<pre>
target=0, 旋转数组: [4, 5, 6, 7, 0, 1, 2]

  l=0, r=6, mid=3, arr[3]=7
    arr[mid]=7 >= arr[l]=4 → 左半 [4,5,6,7] 有序
    0 不在 [4,7) 内 → 丢左半, l=mid+1=4
  l=4, r=6, mid=5, arr[5]=1
    arr[mid]=1 >= arr[l]=0 → 左半 [arr[4], arr[5]] = [0,1] 有序
    0 在 [0,1) 内 → 丢右半, r=mid-1=4
  l=4, r=4, mid=4, arr[4]=0 == 0 → 命中 return 4
</pre>

每步先判有序半边，再判目标是否落其中，二选一丢弃另一半，空间不变。

## 对比参照

| 变种 | 命中时行为 | 区间 | 适用 |
|------|-----------|------|------|
| 标准 | 立即返回 | $[l, r]$ | 仅需存在性 |
| 左边界 | `r=mid` 继续收缩 | $[l, r)$ | 第一个 $\geq$ target |
| 右边界 | `l=mid+1` 继续扩张 | $[l, r)$ | 最后一个 $\leq$ target |
| 旋转数组 | 判有序半边再二分 | $[l, r]$ | 旋转有序序列 |

## 机制

### 区间定义的两种风格不能混用

- **闭区间** $[l, r]$：循环条件 `l <= r`，收缩为 `l=mid+1` / `r=mid-1`，停止于 `l > r`。
- **左闭右开** $[l, r)$：循环条件 `l < r`，收缩为 `l=mid+1` / `r=mid`，停止于 `l == r`。

混用必错：闭区间配 `l < r` 会漏查单元素区间；左闭右开配 `l <= r` 会死循环（`l==r` 时 `mid` 卡死，`r=mid` 不前进）。

### `mid` 的计算与溢出

`mid = (l + r) // 2` 在 `l`、`r` 为 $2^{31}$ 量级时 `l + r` 溢出。改写：

$$\text{mid} = l + \lfloor (r - l) / 2 \rfloor$$

Python 整数任意精度无此问题；C/C++/Java 必须用此写法。当收缩写为 `l = mid`（如闭区间求右边界）时还需防 `mid` 卡在 `l`：$r=l+1$ 时向下取整得 $mid=l$， `l=mid` 不前进、死循环。应写 `mid = l + (r - l + 1) // 2`（向上取整）。

### 浮点二分：用固定迭代次数代替收敛判断

浮点区间收敛慢，且精度误差下 `l < r` 永真会死循环。工程做法：固定迭代 $100$ 次（区间缩到 $2^{-100}$，远小于浮点精度），或用 `abs(r - l) > eps` 配合明确上限。

### 违规后果

| 违规 | 后果 |
|------|------|
| 序列未排序 | 结果错乱（二分依赖有序前提） |
| 开闭区间混用 | 死循环或漏查边界元素 |
| `mid` 向下取整用于右边界 | `mid` 卡 `l`，死循环 |
| 旋转数组判方向错误 | 丢弃含目标的半边，永远找不到 |
| 浮点二分无迭代上限 | 精度误差下死循环 |

## 代码示例

**Python 3.12**：

```python
# 标准二分：闭区间 [l, r]，命中即返回
def binary_search(nums, target):
    l, r = 0, len(nums) - 1
    while l <= r:
        mid = l + (r - l) // 2          # 防溢出写法
        if nums[mid] == target: return mid
        if nums[mid] < target:  l = mid + 1
        else:                   r = mid - 1
    return -1

# 左边界二分：左闭右开 [l, r)，找第一个 >= target（等价 bisect_left）
def lower_bound(nums, target):
    l, r = 0, len(nums)
    while l < r:
        mid = l + (r - l) // 2
        if nums[mid] < target: l = mid + 1
        else:                  r = mid    # >= target，向左压
    return l                          # l == r == 第一个 >= target

# 旋转数组搜索：先判有序半边再二分
def search_rotated(nums, target):
    l, r = 0, len(nums) - 1
    while l <= r:
        mid = l + (r - l) // 2
        if nums[mid] == target: return mid
        if nums[mid] >= nums[l]:           # 左半有序
            if nums[l] <= target < nums[mid]: r = mid - 1
            else:                              l = mid + 1
        else:                               # 右半有序
            if nums[mid] < target <= nums[r]: l = mid + 1
            else:                              r = mid - 1
    return -1

# —— 简易输入输出 ——
print(binary_search([1, 3, 5, 6, 7, 9], 6))      # 3
print(lower_bound([1, 3, 5, 5, 5, 9], 5))        # 2
print(search_rotated([4, 5, 6, 7, 0, 1, 2], 0))  # 4
```

**C++20**：

```cpp
#include <iostream>
#include <vector>

// 标准二分：闭区间 [l, r]
int binarySearch(const std::vector<int>& a, int target) {
    int l = 0, r = (int)a.size() - 1;
    while (l <= r) {
        int mid = l + (r - l) / 2;          // 防溢出
        if (a[mid] == target) return mid;
        if (a[mid] < target) l = mid + 1;
        else                 r = mid - 1;
    }
    return -1;
}

// 左边界二分：左闭右开 [l, r)，第一个 >= target
int lowerBound(const std::vector<int>& a, int target) {
    int l = 0, r = (int)a.size();
    while (l < r) {
        int mid = l + (r - l) / 2;
        if (a[mid] < target) l = mid + 1;
        else                 r = mid;
    }
    return l;
}

// 旋转数组搜索
int searchRotated(const std::vector<int>& a, int target) {
    int l = 0, r = (int)a.size() - 1;
    while (l <= r) {
        int mid = l + (r - l) / 2;
        if (a[mid] == target) return mid;
        if (a[mid] >= a[l]) {                // 左半有序
            if (a[l] <= target && target < a[mid]) r = mid - 1;
            else                                   l = mid + 1;
        } else {                            // 右半有序
            if (a[mid] < target && target <= a[r]) l = mid + 1;
            else                                   r = mid - 1;
        }
    }
    return -1;
}

int main() {
    std::cout << binarySearch({1, 3, 5, 6, 7, 9}, 6) << '\n';        // 3
    std::cout << lowerBound({1, 3, 5, 5, 5, 9}, 5) << '\n';          // 2
    std::cout << searchRotated({4, 5, 6, 7, 0, 1, 2}, 0) << '\n';   // 4
}
```
