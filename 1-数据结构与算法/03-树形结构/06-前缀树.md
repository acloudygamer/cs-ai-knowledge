# 前缀树

> 前置：[05-堆与优先队列](./05-堆与优先队列.md) · 后续：[07-线段树与树状数组](./07-线段树与树状数组.md)

> **版本基准**：universal —— 代码示例同时使用 Python 3.12 与 C++20

## 本质

前缀树（Trie，来自 "re**trie**val"）是存储字符串集合的有序树：根到某节点的路径对应一个字符串前缀，每个节点标记"从根到这里是否构成完整词"。核心操作是**前缀查询**——给定 $p$ 找出所有以 $p$ 为前缀的词。

通过**前缀共享**，前缀树做 $O(|p|)$ 的前缀匹配，插入和查询都与字符串长度成正比、与词库大小无关。代价是内存（节点+边数）；无公共前缀时空间优势消失。

## 数学模型

### 结构约定

- 每条边带一个字符标签，根到节点的路径拼出一个前缀；
- 同节点的出边字符不重复 ⇒ 每个字符串在树中路径唯一；
- 每个节点带 `isEnd` 标记：是否某完整词的终点。

### 空间复杂度

最坏（无公共前缀） $|V|=\sum_i|s_i|$。两种实现权衡：

- **字典实现**（边存字符指针，如 dict）：空间 $O(|V|)$，访问 $O(1)$ 需哈希计算。
- **数组实现**（固定字符集，每节点一个大小 $\sigma$ 的子指针数组， $\sigma$ 为字母表大小）：空间 $O(|V|\cdot\sigma)$，访问 $O(1)$ 无哈希开销。

**压缩前缀树（Patricia Trie / Radix Tree）**：把单子节点链压成一条边、节点存多字符，省空间但实现复杂。

### 时间复杂度

| 操作 | 时间 | 说明 |
|------|------|------|
| insert(s) | $O(\|s\|)$ | 沿路径逐字符创建或前进 |
| search(s) | $O(\|s\|)$ | 沿路径匹配，判 isEnd |
| prefix(p) | $O(\|p\|+output)$ | 定位前缀节点后遍历子树 |

> **洞察**：前缀查询时间取决于**输出规模**而非输入规模——这是前缀树相对哈希表的本质优势：哈希表 $O(1)$ 查整词，但前缀查询只能穷举，而 Trie 天然按前缀聚合。

## 数据流

### insert("cat")

<pre>
root → 'c' → node_c → 'a' → node_a → 't' → node_t(isEnd=True)

每步: 当前节点无该字符子边则新建，前进到子节点，末节点置 isEnd
内存: 每节点 {children: {char: node}, is_end: bool}
</pre>

### search("car") 失败

<pre>
root→'c'(有)→'a'(有)→'r'(无) → 失败返回 False
即使前缀 "ca" 在树中，完整词 "car" 不在。
</pre>

### prefix("ca")

<pre>
root→'c'→'a' 到 node_a（"ca" 前缀终点，isEnd=False）
从 node_a DFS 子树: →'t'→ node_t(isEnd) 输出 "cat"
收集所有 isEnd=True 节点对应串 → ["cat"]
</pre>

### Trie vs 哈希表

<pre>
            插入/查询      前缀查询          内存
Trie       O(|s|)        O(|p|+k)         O(Σ|s_i|)
哈希表     O(|s|)均摊    O(总词数)穷举     O(Σ|s_i|)

k = 以 p 为前缀的词数
</pre>

## 机制

### 公共前缀的空间复用

"car" 和 "cat" 共享 'c'→'a' 段只存一份——对朴素存储（每词独立存串）的根本优势。最坏（词库 ["a".."z"] 无公共前缀）节点数=字符总数，空间与哈希表相当，但数组实现每节点有 $\sigma$ 槽位。

### 字符集过大时的空间爆炸

$\sigma$ 达 Unicode 量级时每节点子字典大却多空。数组实现空槽率 $1-k/\sigma$ （ $k$ 平均子数， $k\ll\sigma$）， $\sigma$ 大则浪费严重。对策：压缩 Trie（合并单子链）、双数组 Trie（两数组表示转移函数、 $O(1)$ 转移无空槽）、FSA 紧凑表示。

### isEnd 标记的语义

只标记"该节点是某完整词终点"，非路径独占。"a"和"ab"共存时，'a' 节点 isEnd=True、'b' 节点（经 'a'）isEnd=True。

**常见错误**：只查目标节点 isEnd 而忽略前缀本身可能是完整词；查 "a" 而树中只有 "ab" 应返回 False。

### 与前缀匹配相关的扩展

AC 自动机 = 前缀树 + 每条失配边预计算的失败指针（KMP 思想移植到树上），把单模式匹配扩展为多模式（见 02-线性结构 的字符串匹配）。

### 前缀搜索的完整性

以 $v$ 为根的子树含所有以 $s(v)$ 为前缀的词。前缀搜索必须遍历整棵子树——无法剪枝，因所有分支都可能含有效词。大规模词库可按子树大小或词频做启发式。

### 前缀计数与自动补全

前缀计数：给每节点加一个 cnt（子树中的词数，新词插入时沿途 +1，重复插入同词只加词频），count_prefix( $p$ ) = walk 到 $p$ 的终点读 cnt， $O(\|p\|)$ 。自动补全：词终点再记 freq（词频），定位前缀节点后 DFS 收集子树全部词、按 freq 降序取前 $k$ 个——代价 $O(\|p\|+\text{output})$，与前缀查询同结构。工程上（输入法、搜索建议）常把子树 Top-K 词表直接缓存在节点上，把 DFS 摊到插入期。

### 约束与违反后果

| 违规 | 后果 |
|------|------|
| 字符集过大且词少 | 空间/时间可能劣于哈希表 |
| isEnd 标记错（完整词未设） | search 漏输出；prefix 可能误含祖先 isEnd |
| 单射约束破坏（同父多子同字符） | 路径不唯一，search 不确定 |

## 代码示例

**Python 3.12**：

```python
class TrieNode:
    __slots__ = ('children', 'is_end', 'cnt', 'freq')
    def __init__(self):
        self.children = {}              # char -> TrieNode
        self.is_end = False             # 是否某完整词终点
        self.cnt = 0                    # 子树中的词数（前缀计数）
        self.freq = 0                   # 本节点为词终点时的词频

class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word, freq=1):
        node, path = self.root, []
        for ch in word:                 # 逐字符深入，无则建
            if ch not in node.children:
                node.children[ch] = TrieNode()
            node = node.children[ch]
            path.append(node)
        if not node.is_end:             # 新词：沿途 cnt+1（重复插入只加词频）
            for nd in path: nd.cnt += 1
        node.is_end = True
        node.freq += freq

    def search(self, word):             # 完整词：找到节点且 is_end
        node = self._walk(word)
        return node is not None and node.is_end

    def starts_with(self, prefix):     # 前缀存在：走到即可
        return self._walk(prefix) is not None

    def count_prefix(self, prefix):    # 以 prefix 开头的词数：walk 后读 cnt
        node = self._walk(prefix)
        return node.cnt if node else 0

    def autocomplete(self, prefix, k):  # 自动补全：子树词按词频降序取前 k
        words = self.collect_prefix_words(prefix)
        return sorted(words, key=lambda w: -self._walk(w).freq)[:k]

    def _walk(self, s):                 # 沿 s 走，断链返回 None
        node = self.root
        for ch in s:
            if ch not in node.children: return None
            node = node.children[ch]
        return node

    def collect_prefix_words(self, prefix):   # 收集所有以 prefix 为前缀的词
        node = self._walk(prefix)
        if node is None: return []
        out = []
        self._dfs(node, prefix, out)
        return out

    def _dfs(self, node, path, out):
        if node.is_end: out.append(path)
        for ch, child in node.children.items():
            self._dfs(child, path + ch, out)

# —— 简易输入输出 ——
t = Trie()
for w in ["cat", "car", "card", "dog"]:
    t.insert(w)
print(t.search("cat"))            # True
print(t.search("ca"))             # False（前缀存在但非完整词）
print(t.starts_with("ca"))        # True
print(sorted(t.collect_prefix_words("ca")))  # ['car', 'card', 'cat']

t2 = Trie()
for w, f in [("cat", 5), ("car", 3), ("card", 1), ("dog", 2)]:
    t2.insert(w, f)
print(t2.count_prefix("ca"))      # 3（cat/car/card）
print(t2.autocomplete("ca", 2))   # ['cat', 'car']（按词频）
```

**C++20**：

```cpp
#include <iostream>
#include <unordered_map>
#include <vector>
#include <string>
#include <string_view>
#include <algorithm>

struct TrieNode {
    std::unordered_map<char, TrieNode*> children;
    bool is_end = false;
    int cnt = 0;                        // 子树中的词数（前缀计数）
    int freq = 0;                       // 本节点为词终点时的词频
};

class Trie {
    TrieNode root;
    TrieNode* walk(std::string_view s) {        // 沿 s 走，断链返回 nullptr
        TrieNode* n = &root;
        for (char c : s) {
            auto it = n->children.find(c);
            if (it == n->children.end()) return nullptr;
            n = it->second;
        }
        return n;
    }
    void dfs(TrieNode* n, std::string& path, std::vector<std::string>& out) {
        if (n->is_end) out.push_back(path);
        for (auto& [c, child] : n->children) {
            path.push_back(c);
            dfs(child, path, out);
            path.pop_back();
        }
    }
public:
    void insert(std::string_view word, int freq = 1) {
        TrieNode* n = &root;
        std::vector<TrieNode*> path;
        for (char c : word) {
            auto [it, inserted] = n->children.emplace(c, nullptr);
            if (!it->second) it->second = new TrieNode();
            n = it->second;
            path.push_back(n);
        }
        if (!n->is_end) for (auto* nd : path) ++nd->cnt;   // 新词：沿途计数
        n->is_end = true;
        n->freq += freq;
    }
    bool search(std::string_view word) {
        TrieNode* n = walk(word);
        return n && n->is_end;
    }
    bool starts_with(std::string_view prefix) { return walk(prefix) != nullptr; }
    int count_prefix(std::string_view prefix) {         // 以 prefix 开头的词数
        TrieNode* n = walk(prefix);
        return n ? n->cnt : 0;
    }
    std::vector<std::string> autocomplete(std::string_view prefix, int k) {  // 按词频取前 k
        auto words = collect_prefix_words(prefix);
        std::sort(words.begin(), words.end(),
                  [&](auto& a, auto& b){ return walk(a)->freq > walk(b)->freq; });
        if ((int)words.size() > k) words.resize(k);
        return words;
    }
    std::vector<std::string> collect_prefix_words(std::string_view prefix) {
        TrieNode* n = walk(prefix);
        if (!n) return {};
        std::vector<std::string> out;
        std::string p{prefix};
        dfs(n, p, out);
        return out;
    }
};

// —— 简易输入输出 ——
int main() {
    Trie t;
    for (auto w : {"cat", "car", "card", "dog"}) t.insert(w);
    std::cout << std::boolalpha
              << t.search("cat") << ' '       // true
              << t.search("ca") << ' '        // false
              << t.starts_with("ca") << '\n'; // true
    auto words = t.collect_prefix_words("ca");
    std::sort(words.begin(), words.end());
    for (auto& w : words) std::cout << w << ' ';   // car card cat
    std::cout << '\n';
    Trie t2;
    t2.insert("cat", 5); t2.insert("car", 3); t2.insert("card", 1); t2.insert("dog", 2);
    std::cout << t2.count_prefix("ca") << '\n';                    // 3
    for (auto& w : t2.autocomplete("ca", 2)) std::cout << w << ' ';  // cat car（按词频）
}
```
