# 树与二叉树

> **版本基准**：universal —— 代码示例同时使用 Python 3.12 与 C++20

## 本质

树是节点间的层次关系——从图论看是**连通无环图**：根唯一，从任一节点沿父向边能到根、从根能到所有节点，边数恒为 $n-1$。等价的递归定义：空树，或一个根加若干不相交子树。二叉树是每节点最多两子的树，是树结构的基础模型：任何有根有序树都可唯一二叉化。

树结构消耗两类资源——内存（节点指针+值）和计算时间（沿路径的查找/遍历）。**所有平衡机制的本质都是在控制树高**，从而控制这两类消耗。遍历（先序/中序/后序/层序）则是把层级结构线性化压平成一维序列；中序遍历 BST 产出升序序列，是 BST 查找性质的直接推论。

## 数学模型

### BST 的查找界

含 $n$ 节点的二叉树高度 $h$：

$$\lfloor\log_2 n\rfloor \le h \le n-1$$

- **下界**：完全二叉树 $n\le 2^{h+1}-1$ ⇒ $h\ge\lfloor\log_2 n\rfloor$。
- **上界**：退化为链表（升/降序插入总落在最左/最右）⇒ $h=n-1$。

> **洞察**：BST 查找是 $O(h)$。退化让 $O(\log n)$ 变 $O(n)$ ——平衡树的全部意义就是把 $h$ 钉在 $O(\log n)$。

### 各树的核心约束

| 树 | 约束 | 目的 |
|----|------|------|
| 二叉树 | $\deg(v)\le 2$ | 保二叉结构等价性 |
| BST 有序 | 左子 $<x<$ 右子 | 搜索单调 |
| AVL | $\|h_L-h_R\|\le 1$ | 严格高度平衡 |
| 红黑树 | 根黑叶黑、红子必黑、黑高相同 | 黑高平衡（最长 $\le 2\times$ 最短） |
| B 树($m$ 阶) | 节点子指针 $\in[\lceil m/2\rceil, m]$ | 多路平衡，控树高 |
| Treap | key 有序 + priority 堆序 | 随机化期望平衡 |

## 数据流

### 四种遍历

<pre>
先序(根→左→右): 读根 → 递归左 → 递归右        根最先消费
中序(左→根→右): 最左深入压栈 → 弹栈读值 → 转右   BST 即升序
后序(左→右→根): 两子处理完才读根                适合释放资源
层序(BFS):       队列入根 → 出队访问 → 入队左右   按深度分层
</pre>

### BST 中序的排序性

<pre>
依次插 [7,2,9,1,5] 建 BST:
        7
       / \
      2   9
     / \
    1   5

中序遍历: 1 → 2 → 5 → 7 → 9   (升序)

原理: 对任意节点 x，左子树全 < x.val < 右子树全
      中序先输出完左子树再输出 x 再输出右子树 ⇒ 单调递增
</pre>

## 机制

### 退化的必然与出路

BST 的 $O(h)$ 把全部操作代价押在树高上，而输入顺序能轻易让它退化成链表（升序插入 $h=n-1$）。出路是给 BST 再加一条平衡约束、并用重平衡算法维护它——确定性约束（AVL、红黑树）与随机化约束（Treap）见 02-平衡树；把节点加宽到一整页以适配外存，同一思想引出 04-B树与外存索引。

## 代码示例

**Python 3.12**：

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val, self.left, self.right = val, left, right

# BST 插入（递归）
def bst_insert(root, val):
    if not root:
        return TreeNode(val)
    if val < root.val:
        root.left = bst_insert(root.left, val)
    else:
        root.right = bst_insert(root.right, val)
    return root

# BST 查找（迭代，O(h)）
def bst_search(root, target):
    while root:
        if target == root.val:
            return True
        root = root.left if target < root.val else root.right
    return False

# 中序遍历：BST 产出升序
def inorder(root):
    return inorder(root.left) + [root.val] + inorder(root.right) if root else []

# —— 简易输入输出 ——
root = None
for v in [7, 2, 9, 1, 5]:
    root = bst_insert(root, v)
print(inorder(root))          # [1, 2, 5, 7, 9]
print(bst_search(root, 5), bst_search(root, 3))   # True False
```

**C++20**：

```cpp
#include <iostream>
#include <vector>
#include <memory>

struct TreeNode {
    int val{};
    TreeNode* left{};
    TreeNode* right{};
    TreeNode(int x = 0) : val(x) {}
};

// BST 插入（递归）
TreeNode* bst_insert(TreeNode* root, int val) {
    if (!root) return new TreeNode(val);
    if (val < root->val) root->left = bst_insert(root->left, val);
    else                 root->right = bst_insert(root->right, val);
    return root;
}

// BST 查找（迭代，O(h)）
bool bst_search(TreeNode* root, int target) {
    while (root) {
        if (target == root->val) return true;
        root = (target < root->val) ? root->left : root->right;
    }
    return false;
}

// 中序遍历：BST 产出升序
void inorder(TreeNode* root, std::vector<int>& out) {
    if (!root) return;
    inorder(root->left, out);
    out.push_back(root->val);
    inorder(root->right, out);
}

// —— 简易输入输出 ——
int main() {
    TreeNode* root = nullptr;
    for (int v : {7, 2, 9, 1, 5}) root = bst_insert(root, v);
    std::vector<int> ord; inorder(root, ord);
    for (int v : ord) std::cout << v << ' ';        // 1 2 5 7 9
    std::cout << '\n' << std::boolalpha
              << bst_search(root, 5) << ' ' << bst_search(root, 3) << '\n'; // true false
}
```
