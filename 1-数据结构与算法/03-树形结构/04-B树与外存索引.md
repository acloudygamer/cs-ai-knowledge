# B树与外存索引

> 前置：[03-跳表](./03-跳表.md) · 后续：[05-堆与优先队列](./05-堆与优先队列.md)

> **版本基准**：universal —— 代码示例同时使用 Python 3.12 与 C++20

## 本质

内存里的平衡树把树高压到 $O(\log_2 n)$ 就够了，因为内存访问便宜。外存的规则不同：读写以**页**为最小单位（一次 IO 搬运整页），且一次随机 IO 的延迟与内存访问差数个量级（7200 rpm HDD 随机 IO 约 5–10 ms，DRAM 约 100 ns，差约 5 个数量级；NVMe SSD 随机读约 100 µs，仍差 3 个——访存延迟的硬件出处见 [01-硬件组成](../../0-计算机基础/01-计算机体系/01-硬件组成.md)）。此时瓶颈不是比较次数，而是**页访问次数**，树必须又宽又矮。

B 树（B-Tree）就是把 BST 的节点放大到一整页：每个节点装数百个 key、同样多的子指针，树高从 $\log_2 n$ 压到以数百为底的对数，一次查找只触发几次页 IO。B+ 树再把数据全部聚到叶子、叶子用链表串联，让范围查询沿链顺序扫描——这是数据库索引的事实标准。

## 数学模型

### B 树的磁盘 IO 模型

磁盘页 $B$ 字节、每 key $k$ 字节 ⇒ 每内部节点容 $\lfloor B/k\rfloor$ 个 key。 $n$ 个 key 的树高：

$$h\approx\lceil\log_{\lfloor B/k\rfloor} n\rceil$$

若 $B/k=100$， $h\approx\log_{100} n=\log_2 n\\,/\\,\log_2 100\approx\log_2 n\\,/\\,6.6$ ——每降一层省一次磁盘页加载。

> **洞察**：B 树是为磁盘而生的树——磁盘 IO 比内存访问贵数个量级，所以用多路分支把树高压到极低，让一次查找只触发少数几页 IO。

### 阶的约束：分裂平衡

$m$ 阶 B 树每节点子指针数 $\in[\lceil m/2\rceil, m]$（根除外）。过满分裂（中位 key 上提）、过疏向兄弟借或与兄弟合并。平衡不靠旋转，靠节点的拆分与合并——所有叶子永远同深，树高只在根分裂时加一。

## 数据流

### 节点分裂（ $m=3$，每节点至多 2 个 key）

<pre>
依次插入 10, 20, 5, 15, 25

插 10,20:   [10, 20]
插 5:       [5, 10, 20] 超满 → 分裂: 中位 10 上提
                [10]
               /    \
            [5]    [20]
插 15:          [10]
               /    \
            [5]  [15, 20]
插 25:      右叶 [15,20,25] 超满 → 分裂: 20 上提
               [10, 20]
              /    |    \
           [5]  [15]  [25]

规则: 节点 key 数超 m-1 → 中位上提, 左右分裂; 根分裂则树高 +1
</pre>

## 机制

### B+ 树为何统治数据库索引

- **内部节点纯 key**：不带数据指针，一页装下更多 key，树更矮。
- **叶子链表**：范围查询 $[l,r]$ 定位 $l$ 后沿叶链顺序扫，避免逐层随机 IO。
- **锚点**：InnoDB（MySQL 5.7+）默认页 16 KB，按每 key+指针约 16 字节计，单页约千个分支，三层即可索引十亿行量级（ $1000^3$）。

### 写优化的对照：LSM 树

B+ 树的写入是原地更新页（随机写）。LSM 树（RocksDB、LevelDB）走另一头：写先落内存跳表、满则整批顺序刷盘，后台多层合并——用读放大（一次逻辑读要查多层，实际读盘次数被放大）与写放大（同一条数据在合并中被反复重写，实际写盘字节数被放大）换顺序写的吞吐。同一外存约束下的另一种时间↔空间置换。

### 违反约束的后果

| 违规 | 后果 |
|------|------|
| 阶数与页大小不匹配 | 一页装不下一个节点，每次访问多页 IO，树高优势白费 |
| 页填充率过低（删多不合并） | 树变高变瘦，页 IO 次数回升 |
| 范围查询走 B 树中序 | 跨层随机 IO，失去 B+ 叶链的顺序红利 |

## 对比参照

| 维度 | B 树 | B+ 树 |
|------|------|-------|
| 数据位置 | 内部节点与叶子均可存 | 仅叶子 |
| 叶子链接 | 无 | 有（链表串联） |
| 范围查询 | 中序遍历（跨层跳） | 定位后沿叶链顺序扫 |
| 单页有效分支 | 少（key 带数据指针） | 多（内部节点纯 key） |
| 典型用途 | 早期文件系统与数据库 | 现代数据库索引（InnoDB、PostgreSQL nbtree） |

## 代码示例

**Python 3.12**：

```python
# B 树(最小度 T=2: 每节点 key 数 ∈ [1, 3]): 节点即页, 过满分裂上提
class BNode:
    __slots__ = ('keys', 'kids', 'leaf')
    def __init__(self, leaf=True):
        self.keys, self.kids, self.leaf = [], [], leaf

class BTree:
    T = 2
    def __init__(self): self.root = BNode()

    def search(self, node, k):               # 页内定位, 未中则下钻一页
        i = 0
        while i < len(node.keys) and k > node.keys[i]: i += 1
        if i < len(node.keys) and k == node.keys[i]: return True
        return False if node.leaf else self.search(node.kids[i], k)

    def _split(self, parent, i):             # kids[i] 已满(2T-1), 中位上提
        full = parent.kids[i]
        right = BNode(full.leaf)
        mid = full.keys[self.T - 1]
        right.keys, full.keys = full.keys[self.T:], full.keys[:self.T - 1]
        if not full.leaf:
            right.kids, full.kids = full.kids[self.T:], full.kids[:self.T]
        parent.keys.insert(i, mid)
        parent.kids.insert(i + 1, right)

    def insert(self, k):
        if len(self.root.keys) == 2 * self.T - 1:   # 根满先裂, 树高 +1
            old = self.root
            self.root = BNode(leaf=False)
            self.root.kids = [old]
            self._split(self.root, 0)
        node = self.root
        while not node.leaf:                        # 下降途中预分裂满子节点
            i = 0
            while i < len(node.keys) and k > node.keys[i]: i += 1
            if len(node.kids[i].keys) == 2 * self.T - 1:
                self._split(node, i)
                if k > node.keys[i]: i += 1
            node = node.kids[i]
        i = len(node.keys)                          # 叶内有序插入
        node.keys.append(k)
        while i > 0 and node.keys[i - 1] > k:
            node.keys[i] = node.keys[i - 1]; i -= 1
        node.keys[i] = k

# —— 简易输入输出 ——
t = BTree()
for v in [10, 20, 5, 15, 25, 3, 8]:
    t.insert(v)
print(t.root.keys)                               # [10] (根分裂后中位上提)
print(t.search(t.root, 15), t.search(t.root, 99))  # True False
```

**C++20**：

```cpp
#include <iostream>
#include <vector>

// B 树(最小度 T=2): 节点即页, 过满分裂上提
struct BNode {
    bool leaf;
    std::vector<int> keys;
    std::vector<BNode*> kids;
    explicit BNode(bool lf = true) : leaf(lf) {}
};

struct BTree {
    static constexpr int T = 2;              // 每节点 key 数 ∈ [T-1, 2T-1]
    BNode* root = new BNode();

    bool search(BNode* n, int k) const {
        int i = 0;
        while (i < (int)n->keys.size() && k > n->keys[i]) ++i;
        if (i < (int)n->keys.size() && k == n->keys[i]) return true;
        return n->leaf ? false : search(n->kids[i], k);
    }

    void split(BNode* parent, int i) {       // kids[i] 已满, 中位上提
        BNode* full = parent->kids[i];
        BNode* right = new BNode(full->leaf);
        int mid = full->keys[T - 1];
        right->keys.assign(full->keys.begin() + T, full->keys.end());
        full->keys.resize(T - 1);
        if (!full->leaf) {
            right->kids.assign(full->kids.begin() + T, full->kids.end());
            full->kids.resize(T);
        }
        parent->keys.insert(parent->keys.begin() + i, mid);
        parent->kids.insert(parent->kids.begin() + i + 1, right);
    }

    void insert(int k) {
        if ((int)root->keys.size() == 2 * T - 1) {   // 根满先裂, 树高 +1
            BNode* s = new BNode(false);
            s->kids.push_back(root);
            split(s, 0);
            root = s;
        }
        BNode* n = root;
        while (!n->leaf) {                     // 下降途中预分裂满子节点
            int i = 0;
            while (i < (int)n->keys.size() && k > n->keys[i]) ++i;
            if ((int)n->kids[i]->keys.size() == 2 * T - 1) {
                split(n, i);
                if (k > n->keys[i]) ++i;
            }
            n = n->kids[i];
        }
        int i = (int)n->keys.size();           // 叶内有序插入
        n->keys.push_back(k);
        while (i > 0 && n->keys[i - 1] > k) { n->keys[i] = n->keys[i - 1]; --i; }
        n->keys[i] = k;
    }
};

// —— 简易输入输出 ——
int main() {
    BTree t;
    for (int v : {10, 20, 5, 15, 25, 3, 8}) t.insert(v);
    std::cout << t.root->keys[0] << '\n';            // 10
    std::cout << std::boolalpha
              << t.search(t.root, 15) << ' '
              << t.search(t.root, 99) << '\n';       // true false
}
```
