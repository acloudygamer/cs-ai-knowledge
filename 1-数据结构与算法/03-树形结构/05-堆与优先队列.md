# 堆与优先队列

> **版本基准**：universal —— 代码示例同时使用 Python 3.12 与 C++20

## 本质

堆是一棵**完全二叉树**，满足堆序性（大顶堆父 $\ge$ 子、小顶堆父 $\le$ 子），用数组按层序存储——父子下标有算术关系，无需指针。优先队列是堆的 ADT 包装，对外提供 push/pop，把"优先级"这个偏序引入队列，让高优先级元素先出队，而非先进先出。

堆是**偏序集合的快速极值结构**： $O(1)$ 取极值（堆顶）， $O(\log n)$ 维护插入/删除后的堆序性。它把"排序"从全局重排降为只需维护局部有序——同层兄弟间无约束，所以不是全序。

## 数学模型

### 下标关系（0-indexed）

$$\text{parent}(i)=\left\lfloor\frac{i-1}{2}\right\rfloor,\quad \text{left}(i)=2i+1,\quad \text{right}(i)=2i+2$$

完全二叉树除最后一层外每层满、最后一层靠左，故父子关系可用算术描述、无需指针。第 $k$ 层节点下标范围 $[2^k-1,\ 2^{k+1}-2]$，节点 $i$ 的左子 $2i+1$ 恰落下一层同范围——这保证了公式的成立。

### 堆序性

大顶堆： $\forall i,\ \text{heap}[i]\ge\text{heap}[2i+1]\ (\text{若存在})\ \land\ \text{heap}[i]\ge\text{heap}[2i+2]\ (\text{若存在})$。从堆顶到任一叶的路径上键值非递增。

> **洞察**：堆序性是"父 $\ge$ 子"的层次化偏序，**同层兄弟间无约束**——所以堆顶是全局极值，但中序遍历并非有序（区别于 BST）。

### 操作复杂度

树高 $h=\lfloor\log_2 n\rfloor$：

- **sift_up**（插入后从叶上浮）： $O(h)=O(\log n)$
- **sift_down**（删堆顶后从根下沉）： $O(h)=O(\log n)$
- **push** = 末尾加 + sift_up： $O(\log n)$
- **pop** = 末尾替堆顶 + sift_down： $O(\log n)$

**sift_down 决策**：两子时必须与较大者（大顶堆）/较小者（小顶堆）比较——只比一个可能把错的子节点提上来。

### 建堆是 $O(n)$ 而非 $O(n\log n)$

从最后一个非叶节点 $\lfloor(n-2)/2\rfloor$ 向前对每个节点 sift_down。设高 $h$，第 $k$ 层有 $2^k$ 节点、每个到叶距离 $h-k$：

$$T(n)=\sum_{k=0}^{h} 2^k(h-k)=2^{h+1}-h-2=O(n)$$

> **洞察**：浅层节点少（但 sift 距离长）、深层节点多（但 sift 距离短），加权求和抵消成 $O(n)$。所以"先 $O(n)$ 建堆再 $O(n\log n)$ 逐个 pop"得堆排，建堆这步几乎免费。

### Top-K： $O(n\log K)$

维护大小 $K$ 的小顶堆遍历所有元素：堆未满直接入；已满且新元素 $>$ 堆顶则替换堆顶。 $K\ll n$ 时远优于 $O(n\log n)$ 全局排序。

> **洞察**：小顶堆维护的是"最大的 $K$ 个"，堆顶即其中最小者 = 第 $K$ 大。正确性靠归纳：处理 $i$ 个后堆含最大 $\min(i,K)$ 个；新元素若 $>$ 堆顶则它属于最大 $K$ 个，替换后堆顶更新为新的第 $K$ 大。

## 数据流

### sift_up（插入上浮）

<pre>
插 15 到末尾，与父比、大则交换，直到根或不再大:

     10              10              15
    /  \            /  \            /  \
   8    7   →     8   15   →     8    7
  / \  /          / \  / \       / \  / \
 5  6 [15]       5  6 7  -      5  6 7  -

15>7 换 → 15>10 换到根。最多 ⌊log₂n⌋ 次比较交换。
</pre>

### sift_down（删堆顶下沉）

<pre>
删堆顶 15，末尾 5 替堆顶，与较大子比、小则下沉:

     5              8              8
    / \            / \            / \
   8   7   →     5   7   →     5   7
  / \ /          / \ /          / \ /
 [5] 6 -        -  6 -         -  6 -

5<8 与左子换 → 5<7 与右子换 → 停。新堆顶 8。
</pre>

### Top-K（K=3，求 [3,1,5,2,4] 第 3 大）

<pre>
维护大小 3 的小顶堆:
  push 3 → [3]
  push 1 → [1,3]
  push 5 → [1,3,5]      (满)
  push 2 → 2>堆顶1? 否,忽略
  push 4 → 4>堆顶1, heapreplace: 弹1压4 → [3,4,5]

堆顶 3 = 第 3 大 ✓
</pre>

## 对比参照

| 实现 | push | pop(极值) | 适用 |
|------|------|-----------|------|
| 数组(无序) | $O(1)$ | $O(n)$ | 写多读少 |
| 数组(有序) | $O(n)$ | $O(1)$ | 读多写少 |
| 二叉堆 | $O(\log n)$ | $O(\log n)$ | 读写均衡 |
| 斐波那契堆 | $O(1)$ 均摊 | $O(\log n)$ 均摊 | 极致 push |

## 机制

### 为什么完全二叉树 + 数组让堆操作 $O(\log n)$

1. **树高固定** $O(\log n)$，不随插入顺序变。
2. **父子跳转纯算术**：下标公式直接算，无遍历。
3. **数组连续**：无指针 chasing，缓存友好——sift 路径地址近似连续，预取器有效。

若非完全二叉树，父子关系无简单公式、需指针、树高可能 $O(n)$。

### sift_up / sift_down 的约束

- sift_up：父须存在（$i>0$ 时 parent 有效）。
- sift_down：子须存在（$2i+1<n$ 左子在、 $2i+2<n$ 右子在）；一子只比该子，两子比大顶堆较大者/小顶堆较小者。

> **洞察**：sift_down 选"更可能破坏堆序性"的方向——大顶堆选较大子，因为较大子都不大于当前节点则较小子必然也不大于，可安全停。

### Python heapq 约定

`heapq` 是小顶堆。要大顶堆：存 `-x` 取用时取负。`heapreplace` 是 pop 后 push 的原子版（空堆抛 IndexError）。

### 堆 vs 优先队列

堆是数据结构，优先队列是 ADT。堆可用数组/斐波那契堆等实现；优先队列也可用有序数组（push $O(n)$、pop $O(1)$）实现。二叉堆在 push/pop 上均衡，是通用首选。

### 多路归并

$k$ 个有序文件，各取首元素入堆，每次弹全局最小并从对应文件补下一个。初始 $O(k\log k)$，每步 $O(\log k)$，总计 $O(N\log k)$ （$N$ 总元素数）。堆在此是**动态多路归并**，把"全读入内存"变成流式处理。

### 违规后果

| 违规 | 后果 |
|------|------|
| 堆性质破坏未修复 | 堆顶非极值，优先级错乱 |
| sift_down 只比一个子 | 可能提升错的子节点，破坏堆序 |
| 空堆 pop | 未定义/IndexError |
| 下标越界未停 | 数组越界访问 |

## 代码示例

**Python 3.12**：

```python
import heapq

# Top-K：维护大小 k 的小顶堆，返回第 k 大
def top_k(nums, k):
    h = []
    for x in nums:
        heapq.heappush(h, x)        # O(log k)
        if len(h) > k:
            heapq.heappop(h)        # O(log k)，弹最小
    return h[0]                      # 堆顶 = 第 k 大

# 手写小顶堆（数组实现，演示 sift）
class MinHeap:
    def __init__(self): self.a = []
    def push(self, x):
        self.a.append(x); self._sift_up(len(self.a) - 1)
    def pop(self):
        top, last = self.a[0], self.a.pop()
        if self.a:
            self.a[0] = last; self._sift_down(0)
        return top
    def _sift_up(self, i):           # 与父比、小则上浮
        while i > 0:
            p = (i - 1) // 2
            if self.a[i] < self.a[p]:
                self.a[i], self.a[p] = self.a[p], self.a[i]; i = p
            else: break
    def _sift_down(self, i):         # 与较小子比、大则下沉
        n = len(self.a)
        while 2*i + 1 < n:
            c = 2*i + 1
            if c + 1 < n and self.a[c+1] < self.a[c]: c += 1  # 选较小子
            if self.a[i] > self.a[c]:
                self.a[i], self.a[c] = self.a[c], self.a[i]; i = c
            else: break

# —— 简易输入输出 ——
print(top_k([3, 1, 5, 2, 4], 3))    # 3（第 3 大）
h = MinHeap()
for v in [5, 3, 8, 1, 4]: h.push(v)
print([h.pop() for _ in range(5)])  # [1, 3, 4, 5, 8]（升序）
```

**C++20**：

```cpp
#include <iostream>
#include <vector>
#include <queue>        // priority_queue

// Top-K：priority_queue 默认大顶堆，要第 k 大用大顶堆弹 k-1 次，或用小顶堆维护 k 个
int top_k(const std::vector<int>& nums, int k) {
    std::priority_queue<int, std::vector<int>, std::greater<>> minh; // 小顶堆
    for (int x : nums) {
        minh.push(x);
        if ((int)minh.size() > k) minh.pop();   // 弹最小
    }
    return minh.top();                          // 堆顶 = 第 k 大
}

// 手写小顶堆（数组 + sift）
struct MinHeap {
    std::vector<int> a;
    void push(int x) { a.push_back(x); sift_up(a.size() - 1); }
    int pop() {
        int top = a[0]; a[0] = a.back(); a.pop_back();
        if (!a.empty()) sift_down(0);
        return top;
    }
    void sift_up(size_t i) {                     // 与父比、小则上浮
        while (i > 0) {
            size_t p = (i - 1) / 2;
            if (a[i] < a[p]) { std::swap(a[i], a[p]); i = p; } else break;
        }
    }
    void sift_down(size_t i) {                   // 与较小子比、大则下沉
        size_t n = a.size();
        for (size_t c = 2*i+1; c < n; c = 2*i+1) {
            if (c + 1 < n && a[c+1] < a[c]) ++c; // 选较小子
            if (a[i] > a[c]) { std::swap(a[i], a[c]); i = c; } else break;
        }
    }
};

// —— 简易输入输出 ——
int main() {
    std::cout << top_k({3,1,5,2,4}, 3) << '\n';  // 3
    MinHeap h;
    for (int v : {5,3,8,1,4}) h.push(v);
    for (int i = 0; i < 5; ++i) std::cout << h.pop() << ' ';  // 1 3 4 5 8
}
```
