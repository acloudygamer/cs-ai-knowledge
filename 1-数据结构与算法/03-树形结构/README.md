# 树形结构

> **版本基准**: universal

用层次链接换取 $O(\log n)$ 量级操作的结构家族。主线是**有序字典问题**的三代解法：BST 给出形状，平衡树用旋转维持形状，跳表用概率替代旋转；B 树把同一思想搬到外存页。其余成员各服膺于一个特殊约束：堆只维护极值、前缀树共享公共前缀、线段树维护区间聚合、并查集维护等价类。

组织逻辑：**约束 → 形状**。每种树先讲它服膺的约束（有序？极值？前缀？区间？等价？），再讲形状如何由约束推出。
