# 树形结构

> **版本基准**: universal

本章回答一个问题：怎样把定位路径从线性压到对数。答案只有一个机制——让每一层同时排除一批候选，层数就是路径长度。八个成员的区别只在"每层留几个分支"和"什么不变量保证层数不失控"：比较型字典靠旋转、着色或随机优先级；外存索引靠加宽节点；堆只维持极值；前缀树按字符分叉；线段树与树状数组按区间二分；并收集只维护等价类。

| 篇目 | 主链与消费的前置结论 |
| --- | --- |
| 01 树与二叉树 | 树的三条计数性质 → 链式与数组两种表示 → 四种遍历及其栈空间账 → BST 的界 = 树高 → 有序插入退化成链 → 引出"必须维持形状" |
| 02 平衡树 | 消费 01 的"树高就是路径长度" → 旋转是中序不变的最小重排 → AVL 的高度差 → 红黑树的黑高 → Treap 的随机优先级 → 用哪种不变量换哪段路径 |
| 03 跳表 | 多层索引跳过节点 → 几何分布层高 → 期望路径与期望空间 → 与平衡树的期望/最坏对比 → Redis 的 $p=0.25$、32 层上限与 listpack 切换 |
| 04 B 树与外存索引 | 消费 01 的树高与 0-计算机基础 的页读量级 → 单步代价从比较变成页读 → 扇出与树高的换算 → 分裂与填充率 → B+ 叶子链 → LSM 的写路径对照 |
| 05 堆与优先队列 | 极值问题不需要全序 → 完全二叉树的数组表示 → 堆序性 → 上浮与下沉 → 建堆 $O(n)$ 的逐层求和 → Top-K 的 $O(n\log K)$ |
| 06 前缀树 | 键的字符拆成路径 → 公共前缀共享 → 字符集决定节点宽度 → 前缀查询 = 下降加子树遍历 → 与哈希表的取舍 → 压缩边与双数组 |
| 07 线段树与树状数组 | 区间查询的代价由预处理与更新共同决定 → lowbit 分解前缀 → 区间二分与懒标记 → 稀疏表的幂等前提 → 四代方案的判据 |
| 08 并查集 | 等价类只需回答"同不同组" → 父指针森林 → 朴素合并退化成链 → 按秩合并 → 路径压缩 → 反 Ackermann 界 → Kruskal 的两个接口 |
