# 平衡树

> 前置：[01-树与二叉树](./01-树与二叉树.md) · 后续：[03-跳表](./03-跳表.md)

> **版本基准**：universal —— 代码示例同时使用 Python 3.12 与 C++20

## 本质

BST 的查找、插入、删除都是 $O(h)$，输入顺序稍有不慎就退化成链表（见 01-树与二叉树）。平衡树的存在理由就是把树高钉死在 $O(\log n)$：**BST 偏序约束 + 一条平衡约束 + 维护该约束的重平衡算法**，三者构成全部平衡树。

平衡约束有两种哲学：

- **确定性**：AVL 用严格高度差换最优查找；红黑树用松弛的黑高换更便宜的写。约束越严，查找越优、维护越贵。
- **随机化**：Treap 给每个节点配一个随机优先级并维持堆序，用概率替代确定性的情形修复——期望高度同阶，实现量少数倍，且不存在最坏输入（期望由自带随机数保证，与数据分布无关）。

## 数学模型

### 三种平衡的高度界

- **AVL**：约束 $|h_L-h_R|\le 1$。高度 $h$ 的树最少节点数 $N(h)=N(h-1)+N(h-2)+1$（斐波那契递推），解得 $h<1.44\log_2 n$。
- **红黑树**：约束根黑、红节点的子必黑、各路径黑高相同 ⇒ 最长路径 $\le 2\times$ 最短， $h\le 2\log_2(n+1)$。
- **Treap**：随机优先级使树形同构于随机 BST，期望高度 $\approx 4.311\ln n\approx 3\log_2 n$（Devroye 1986）。

> **洞察**：三个常数（1.44 / 2 / 3）不改阶，真正的区别在于维护代价——约束越严格，重平衡越频繁。Treap 的高度常数最差，卖点是实现极简且免疫最坏输入。

### 两套维护原语：旋转与 split/merge

确定性阵营用**旋转**：在保持 BST 中序序列不变的前提下，把较深子树上提、较浅子树下压。单次旋转 $O(1)$、只改常数个指针，但改变子树高度，失衡沿路径向上传播。

Treap 阵营用 **split/merge**：`split(root, key)` 按键把树切成 L（ $<$ key）与 R（ $\ge$ key）；`merge(L, R)` 在 L 全小于 R 的前提下按优先级决定父节点。插入 = split + merge 新节点；删除 = split 出待删 + merge 跳过它——无需显式旋转。

## 数据流

### 旋转（中序不变）

<pre>
        x                右旋            y
       / \              ───→           / \
      y   T3                           T1  x
     / \                                   / \
    T1  T2                                T2  T3

中序不变: T1 y T2 x T3   (旋转前后完全一致)
局部: 只改常数个指针，O(1)；但改变子树高度，失衡沿路径上传
</pre>

失衡按路径分四种：LL/RR 一次单旋恢复；LR/RL 需双旋（先把拐点所在子树旋直，再旋根）。

### Treap 的 split 与 merge

<pre>
split(root, key) → (L, R): L<key, R≥key

case key ≤ root.key:   (root.key ≥ key → root 归 R)
  split(root.left, key) → (L, root.left')
  root.left = root.left'   (R 部分接左子)
  返回 (L, root)           (root 成为 R 的根)

case key > root.key:
  split(root.right, key) → (root.right', R)
  root.right = root.right' (L 部分接右子)
  返回 (root, R)

不变量: BST 有序性 + 堆性质在重连中自动保持
</pre>

<pre>
merge(L, R) → 根 (前提: L 全 key < R 全 key)

case L.pri > R.pri:
  L.right = merge(L.right, R); 返回 L  (高者优先为父)
case L.pri ≤ R.pri:
  R.left  = merge(L, R.left);  返回 R

终止: L 或 R 空 → 返回非空者
</pre>

## 机制

### AVL：严格高度差

约束 $|h_L-h_R|\le 1$。插入沿路径回溯最多两次旋转恢复；**删除可能要 $O(\log n)$ 次旋转**向上修复（每次旋转若降低子树高就继续上传）——这是 AVL 的主要弱点。严格平衡 ⇒ 查找最优、删除贵，适合读密集。

### 红黑树：松弛的黑高平衡

约束：根黑、叶黑、红子必黑、各路径黑高相同。最长路径 $\le 2\times$ 最短，不如 AVL 严格。插入最多两次旋转、删除最多三次。

> **洞察**：红黑树的设计动机正是治 AVL 删除的病——AVL 严格平衡要 $O(\log n)$ 次旋转，红黑树允许路径长度在 2:1 内波动，把删除旋转压到常数次（最多 3），换更稳定的写性能。适合写密集与通用场景（`std::map`、Java `TreeMap` 均为红黑树）。

### Treap：随机化平衡

优先级用均匀随机数生成（相等时按 `(priority, key)` 字典序定确定性），树形因此同构于随机 BST——无论输入顺序如何，期望高度都是 $O(\log n)$。退化存在但概率随 $n$ 指数衰减：树形退化成链，要求优先级排列的根取当前 key 区间的最值、递归同理，此类排列共 $2^{n-1}$ 种，概率 $2^{n-1}/n!$ 。

若以旋转实现插入删除，期望旋转次数 $<2$（Seidel-Aragon 1996）；split/merge 实现则无显式旋转，沿查找路径单次递归重写指针，期望 $O(\log n)$。

### 统一视角

平衡树 = BST 偏序约束 + 某种平衡约束 + 维护该约束的重平衡算法。AVL 用严格高度差换查找最优、删除贵；红黑树用黑高换写性能；Treap 用随机数换实现简洁与免疫最坏输入。把节点加宽到一整页以适配外存页，同一思想引出 B 树（见 04-B树与外存索引）。

## 对比参照

| 维度 | AVL | 红黑树 | Treap |
|------|-----|--------|-------|
| 平衡约束 | 高度差 $\le 1$（严格） | 黑高相同（松弛） | 随机优先级堆序 |
| 高度界 | $<1.44\log_2 n$（最坏） | $\le 2\log_2 n$（最坏） | $\approx 3\log_2 n$（期望） |
| 插入重平衡 | 旋转 $\le 2$ | 旋转 $\le 2$ | split/merge，期望 $O(\log n)$ |
| 删除重平衡 | 旋转 $O(\log n)$（弱点） | 旋转 $\le 3$ | split/merge，期望 $O(\log n)$ |
| 实现 | 中等 | 复杂（情形多） | 极简（split/merge 各约 15 行） |
| 退化风险 | 无 | 无 | 概率随 $n$ 指数衰减 |
| 每节点附加 | 平衡因子 | 一个颜色位 | 一个随机数 |
| 适用 | 读密集 | 写密集、通用 | 需 split/merge 的场景 |

## 代码示例

**Python 3.12**：

```python
import random

# —— 旋转: 确定性阵营的维护原语(中序不变, O(1)) ——
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val, self.left, self.right = val, left, right

def rotate_right(y):          # y 的左子 x 上提为父, y 变 x 的右子
    x, T2 = y.left, y.left.right
    x.right, y.left = y, T2
    return x

def rotate_left(x):           # x 的右子 y 上提为父, x 变 y 的左子
    y, T2 = x.right, x.right.left
    y.left, x.right = x, T2
    return y

def inorder(x):
    return inorder(x.left) + [x.val] + inorder(x.right) if x else []

# —— Treap: split/merge 阵营 ——
class Node:
    __slots__ = ('key', 'pri', 'left', 'right', 'size')
    def __init__(self, key):
        self.key, self.pri = key, random.randint(1, 1 << 30)
        self.left = self.right = None
        self.size = 1

def sz(n): return n.size if n else 0
def upd(n):
    if n: n.size = 1 + sz(n.left) + sz(n.right)

def split(n, key):
    # 返回 (L, R): L 中键 < key, R 中键 ≥ key
    if not n: return (None, None)
    if key <= n.key:                          # n 属于 R
        L, R = split(n.left, key)
        n.left = R; upd(n); return (L, n)
    else:                                     # n 属于 L
        L, R = split(n.right, key)
        n.right = L; upd(n); return (n, R)

def merge(L, R):
    # 前提: L 全 key < R 全 key; 按 priority 决定父
    if not L or not R: return L or R
    if L.pri > R.pri:
        L.right = merge(L.right, R); upd(L); return L
    else:
        R.left = merge(L, R.left); upd(R); return R

def insert(root, key):
    L, R = split(root, key)                   # 按 key 分
    return merge(merge(L, Node(key)), R)      # L + 新节点 + R

def erase(root, key):
    L, R = split(root, key)                   # L: <key, R: ≥key
    R1, R2 = split(R, key + 1)                # R1: ==key(待删), R2: >key
    return merge(L, R2)                       # 跳过 R1

def kth(root, k):                             # 第 k 小(1-indexed)
    if not root: return None
    ls = sz(root.left)
    if k <= ls: return kth(root.left, k)
    elif k == ls + 1: return root.key
    else: return kth(root.right, k - ls - 1)

# —— 简易输入输出 ——
r = TreeNode(2, TreeNode(1), TreeNode(3))
print(inorder(rotate_left(r)))                     # [1, 2, 3] (旋转后中序不变)

root = None
for v in [5, 3, 8, 1, 4, 7, 9, 2, 6]:
    root = insert(root, v)
print(kth(root, 1), kth(root, 5), kth(root, 9))    # 1 5 9
root = erase(root, 5)
print(kth(root, 5))                                # 6
```

**C++20**：

```cpp
#include <iostream>
#include <random>
#include <utility>

// —— 旋转: 中序不变, O(1) ——
struct TreeNode {
    int val; TreeNode *left, *right;
    explicit TreeNode(int v) : val(v), left(nullptr), right(nullptr) {}
};

TreeNode* rotate_right(TreeNode* y) {
    TreeNode* x = y->left;
    y->left = x->right; x->right = y;
    return x;
}

// —— Treap ——
struct Node {
    int key, pri, size = 1;
    Node *left = nullptr, *right = nullptr;
    Node(int k, int p) : key(k), pri(p) {}
};

int sz(Node* n) { return n ? n->size : 0; }
void upd(Node* n) { if (n) n->size = 1 + sz(n->left) + sz(n->right); }

std::mt19937 rng{std::random_device{}()};

// split: L 中键 < key, R 中键 ≥ key
std::pair<Node*, Node*> split(Node* n, int key) {
    if (!n) return {nullptr, nullptr};
    if (key <= n->key) {                        // n 属于 R
        auto [L, R] = split(n->left, key);
        n->left = R; upd(n); return {L, n};
    } else {                                    // n 属于 L
        auto [L, R] = split(n->right, key);
        n->right = L; upd(n); return {n, R};
    }
}

// merge: L 全 key < R 全 key
Node* merge(Node* L, Node* R) {
    if (!L || !R) return L ? L : R;
    if (L->pri > R->pri) { L->right = merge(L->right, R); upd(L); return L; }
    else                 { R->left  = merge(L, R->left);  upd(R); return R; }
}

Node* insert(Node* root, int key) {
    auto [L, R] = split(root, key);
    return merge(merge(L, new Node(key, (int)rng())), R);
}

Node* erase(Node* root, int key) {
    auto [L, R]  = split(root, key);         // L: <key, R: ≥key
    auto [R1, R2] = split(R, key + 1);       // R1: ==key(待删), R2: >key
    delete R1;                               // 跳过 R1
    return merge(L, R2);
}

int kth(Node* n, int k) {                    // 第 k 小
    if (!n) return -1;
    int ls = sz(n->left);
    if (k <= ls) return kth(n->left, k);
    if (k == ls + 1) return n->key;
    return kth(n->right, k - ls - 1);
}

// —— 简易输入输出 ——
int main() {
    TreeNode* r = new TreeNode(2);
    r->left = new TreeNode(1); r->right = new TreeNode(3);
    r = rotate_right(r);                     // 旋转后中序不变(仍 1 2 3)
    std::cout << r->val << '\n';             // 1

    Node* root = nullptr;
    for (int v : {5,3,8,1,4,7,9,2,6}) root = insert(root, v);
    std::cout << kth(root,1) << ' ' << kth(root,5) << ' ' << kth(root,9) << '\n'; // 1 5 9
    root = erase(root, 5);
    std::cout << kth(root,5) << '\n';                                              // 6
}
```
