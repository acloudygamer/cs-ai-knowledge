# 单调栈

> **版本基准**：universal —— 代码示例同时使用 Python 3.12 与 C++20

## 本质

单调栈在普通栈上加一条"栈内元素（按值看）保持单调"的约束，专门 $O(n)$ 求解"下一个更大/更小元素"类问题。每个元素至多入栈一次、出栈一次，整趟遍历总操作 $2n$，所以线性。机制是利用 LIFO：新元素到来时，把栈里所有"被它遮挡"的旧元素弹掉，弹出的瞬间就为那个旧元素确定了答案——当前这个新元素。

工程上单单调栈只有两件易错事：**栈存下标而非值**（要给答案数组按索引赋值、要能算距离、要能区分相等元素），以及**严格 vs 非严格单调**的取舍（求"严格更大"用 `<` 严格递增，相等元素不弹）。

## 数学模型

### 均摊复杂度

$n$ 个元素，每元素 push 一次、pop 至多一次：

$$\sum \text{push} = n,\quad \sum \text{pop} \leq n \;\Rightarrow\; \text{总操作} = O(n)$$

虽然内层是 `while` 循环，但均摊到 $n$ 次遍历上每元素常数次操作，整体线性。空间最坏 $O(n)$ （输入本身单调、全员压栈）。

### 单调性约束

栈存下标，但按下标对应的值看保持单调。求"下一个更大"用**单调递减栈**（栈顶到栈底递减，新值更大时弹栈顶）：

$$\text{val}[s_0] > \text{val}[s_1] > \dots > \text{val}[s_k]\quad(\text{栈顶 }s_k\text{ 最小})$$

弹栈触发条件：当前值 `nums[i]` 严格大于栈顶值——栈顶的"下一个更大"就是 `nums[i]`，记录后弹出。

> **洞察**：单调栈维护的是"还没找到答案的候选序列"。新元素一来，弹掉所有比它小的候选（它们被当前元素遮挡、当前元素就是它们的答案），再把自己入栈成为新候选。弹的瞬间 = 答案确定的瞬间。

## 数据流

### 下一个更大元素（NGE）

<pre>
nums = [2, 1, 2, 4, 3], 求每个元素的右侧第一个更大值, 递减栈

i=0 val=2: 栈空 → push0,        stack=[0]      (值 2)
i=1 val=1: 栈顶2 > 1, 不弹 → push1, stack=[0,1]   (值 2,1)
i=2 val=2: 栈顶1 < 2 → pop1, next[1]=2; 栈顶2 == 2 不弹 → push2, stack=[0,2]
i=3 val=4: 栈顶2 < 4 → pop2, next[2]=4; 栈顶2 < 4 → pop0, next[0]=4; 栈空 → push3, stack=[3]
i=4 val=3: 栈顶4 > 3, 不弹 → push4, stack=[3,4]

遍历结束, 栈内残留 [3,4] 无右侧更大 → next[3]=next[4]=-1
输出: next = [4, 2, 4, -1, -1]
</pre>

**所有权变换**：`nums` 只读；栈存的是下标（引用，非拷贝）；答案数组 `next` 在每次 pop 瞬间被写入——元素所有权从"答案未确定"转为"已确定"。

### 遮挡效应的几何直觉

<pre>
把元素想成高度, 从右往左看, 高的遮挡矮的:

        4
       ╱╲
      ╱  ╲
   2 ╱    ╲ 3
    ╱  2   ╲
   1────────2  (下标, 已弹出的可见性被新高峰取代)

新高峰 4 入栈时, 把比它矮的 2、2、1 全弹掉——它们都被 4 遮挡, 4 即是它们的"下一个更大"
</pre>

### 柱状图最大矩形

<pre>
heights = [2,1,5,6,2,3], 求最大矩形面积
对每根柱, 找其左右第一个更矮的柱, 宽度即两者之间

加哨兵 0 首尾, 递增栈(按高度):
  在每个柱位置 i, 弹掉所有比 heights[i] 高的栈顶
  弹出柱 h 的高 × (i - 新栈顶 - 1) 即以该柱为高的矩形面积
  → max area = 10 (柱 5,6 各高 5, 宽 2)
</pre>

## 对比参照

| 问题 | 栈方向 | 弹栈条件 | 答案来源 |
|------|--------|---------|---------|
| 下一个更大 | 递减（栈顶最小） | 当前 > 栈顶值 | 当前元素 |
| 下一个更小 | 递增（栈顶最大） | 当前 < 栈顶值 | 当前元素 |
| 柱状图最大矩形 | 递增（按高度） | 当前 < 栈顶高 | 弹出柱 × 宽 |
| 移除 K 位数字 | 递增 | 当前 < 栈顶（破坏递增） | 剩余栈序列 |
| 每日温度 | 递减 | 当前 > 栈顶温度 | 当前下标 - 栈顶下标 |

## 机制

### 正确性核心引理

**引理**：递减栈中，当 `nums[i]` 入栈时，栈里所有比 `nums[i]` 小的元素 $y$，其"下一个更大元素"恰为 `nums[i]`。

**证明**（反证）： $y$ 在 $i$ 左侧且 $y < \text{nums}[i]$。设 $y$ 与 $i$ 之间存在 $z > y$，则遍历到 $z$ 时 $y$ 就会被弹出（递减栈弹栈条件），不可能活到 $i$ 时刻——矛盾。故 $y$ 与 $i$ 之间没有比 $y$ 大的元素， $i$ 即 $y$ 右侧第一个更大者。 $\square$

### 为什么存下标不存值

存值无法区分相等元素、无法算距离、无法给答案数组按位置赋值。存下标把"位置信息"保留，值通过 `nums[idx]` 随时取，是单调栈实现的标准做法。

### 严格单调的选择

求"严格更大"用严格不等号 `<` 弹栈：相等元素不弹，保持各自独立。若误用 `<=`，相等元素会被提前弹掉、答案错指向后续等值元素。求"非严格更大"（ $\geq$）则反之。

### 循环数组

把序列首尾相接视为环形。处理法：遍历 $2n$ 次（按下标 $\bmod n$），第一遍正常 push，第二遍只 pop 不 push——避免同一元素重复入栈被多次处理。每个元素的答案只在它首次被弹出时确定，不能二次赋值。

### 违规后果

| 违规 | 后果 |
|------|------|
| 栈存值而非下标 | 相等元素歧义、无法算距离、无法给答案赋值 |
| 求严格更大却用 `<=` 弹栈 | 相等元素被误弹，答案错指 |
| 循环数组第二遍仍 push | 元素重复入栈，答案被覆盖错误 |
| 遍历结束未处理栈残留 | 残留元素答案保持初值 -1，需确认初始化正确 |

## 代码示例

**Python 3.12**：

```python
# 下一个更大元素: 递减栈, O(n)
def next_greater(nums):
    n = len(nums)
    res = [-1] * n
    stack = []                                  # 存下标
    for i in range(n):
        while stack and nums[stack[-1]] < nums[i]:   # 栈顶 < 当前 → 弹
            res[stack.pop()] = nums[i]
        stack.append(i)
    return res                                  # 栈内残留元素保持 -1

# 循环数组的下一个更大: 遍历 2n, 第二遍只 pop 不 push
def next_greater_circular(nums):
    n = len(nums)
    res = [-1] * n
    stack = []
    for i in range(2 * n):
        idx = i % n
        while stack and nums[stack[-1]] < nums[idx]:
            res[stack.pop()] = nums[idx]
        if i < n:                               # 仅第一遍 push
            stack.append(i)
    return res

# 柱状图最大矩形: 加哨兵 0, 递增栈按高度
def largest_rectangle(heights):
    h = [0] + heights + [0]                     # 首尾哨兵统一边界
    stack = [0]
    best = 0
    for i in range(1, len(h)):
        while h[stack[-1]] > h[i]:               # 比当前高 → 弹
            height = h[stack.pop()]
            width = i - stack[-1] - 1            # 新栈顶到 i 之间
            best = max(best, height * width)
        stack.append(i)
    return best

# —— 简易输入输出 ——
print(next_greater([2,1,2,4,3]))              # [4, 2, 4, -1, -1]
print(next_greater_circular([2,1,2,4,3]))     # [4, 2, 4, -1, 4] (下标4的3循环一周后遇到4)
print(largest_rectangle([2,1,5,6,2,3]))       # 10
```

**C++20**：

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

// 下一个更大元素: 递减栈
std::vector<int> nextGreater(const std::vector<int>& nums) {
    int n = (int)nums.size();
    std::vector<int> res(n, -1), st;
    for (int i = 0; i < n; ++i) {
        while (!st.empty() && nums[st.back()] < nums[i]) {
            res[st.back()] = nums[i];
            st.pop_back();
        }
        st.push_back(i);
    }
    return res;
}

// 柱状图最大矩形
int largestRectangle(std::vector<int> h) {
    h.insert(h.begin(), 0);
    h.push_back(0);
    std::vector<int> st = {0};
    int best = 0;
    for (int i = 1; i < (int)h.size(); ++i) {
        while (h[st.back()] > h[i]) {
            int height = h[st.back()]; st.pop_back();
            int width = i - st.back() - 1;
            best = std::max(best, height * width);
        }
        st.push_back(i);
    }
    return best;
}

int main() {
    auto r = nextGreater({2,1,2,4,3});
    for (int x : r) std::cout << x << ' ';        // 4 2 4 -1 -1
    std::cout << '\n';
    std::cout << largestRectangle({2,1,5,6,2,3}) << '\n';   // 10
}
```
