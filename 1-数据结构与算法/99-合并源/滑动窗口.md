# 滑动窗口

> **版本基准**：universal —— 代码示例同时使用 Python 3.12 与 C++20

## 本质

滑动窗口用双指针 `left`/`right` 维护一个连续子数组/子串区间，把"枚举所有子区间"的 $O(n^2)$ 嵌套循环压成 $O(n)$：`right` 只向右扩张、`left` 只向右收缩，两指针合起来至多移动 $2n$ 次。它的成立完全靠**指针单调**——一旦允许 `right` 回退，复杂度立刻退化回 $O(n^2)$。

窗口分两类：**固定窗口**（大小恒为 $k$，`right` 每扩一格 `left` 跟着收一格）和**可变窗口**（大小随约束变化，约束被破坏时收 `left` 直到恢复）。何时收缩由一个**窗口合法性谓词** $C(W)$ 决定。

## 数学模型

### 复杂度：指针单调性

设窗口 $W(l,r)$。可变窗口里 `right` 单调不减（只扩）、`left` 单调不减（只收），故：

$$\text{right 移动} \leq n,\quad \text{left 移动} \leq n \;\Rightarrow\; \text{总移动} \leq 2n = O(n)$$

固定窗口同理：`right` 走 $n$ 步，`left` 在 `right` 到达 $k$ 后跟随，总 $O(n)$。每步窗口状态转移 $O(1)$ （增删一个元素），整体线性。

### 窗口状态转移

$$W(l,r) \xrightarrow{\text{扩}} W(l,r+1) \quad(\text{约束仍满足})$$

$$W(l,r) \xrightarrow{\text{收}} W(l+1,r) \quad(\text{约束被破坏，左收至恢复})$$

收缩仅在 $C(W)=\text{false}$ 时发生、且 `left` 只增——这两条共同保证了总收缩次数 $\leq n$。

> **洞察**：滑动窗口把"对所有 $l$ 找最优 $r$"的二重枚举，换成" $r$ 扫一遍、 $l$ 被动跟上"。之所以不漏解，是因为当 `right` 固定时 `left` 越大窗口越短、约束越易满足——最优窗口的 `left` 必落在"恰好满足约束"的临界点上，单调收缩刚好停在那里。

## 数据流

### 无重复字符最长子串

<pre>
s = "abcabcbb", 可变窗口, 约束: 窗口内无重复字符

right=0 'a': {a}            len1 max1
right=1 'b': {a,b}          len2 max2
right=2 'c': {a,b,c}        len3 max3
right=3 'a': 重复 → left 0→1, 窗口 {b,c,a}  len3
right=4 'b': 重复 → left 1→2, 窗口 {c,a,b}  len3
right=5 'c': 重复 → left 2→3, 窗口 {a,b,c}  len3
right=6 'b': 重复(last[b]=4≥left=3) → left 3→5, 窗口 {c,b} len2
right=7 'b': 重复(last[b]=6≥left=5) → left 5→7, 窗口 {b}   len1

max_len = 3
</pre>

**所有权变换**：`s` 只读；窗口用一个计数字典（或字符→最新下标映射）动态维护，`right` 入窗增计数、`left` 出窗减计数；`max_len` 是标量，每步取 max。窗口状态 $O(1)$ 增量更新是线性的前提。

### 固定窗口最大值（单调队列）

<pre>
nums = [1,3,-1,-3,5,3,6,7], k=3, 求每个窗口最大值

递减双端队列(存下标), 队首即窗口最大:
  i=0 val=1: 队[0]
  i=1 val=3: 弹队尾0(1<3) → 队[1]
  i=2 val=-1: 队[1,2]        窗口[0..2] max=nums[1]=3
  i=3 val=-3: 队[1,2,3], 队首1未越界 → 窗口[1..3] max=3
  i=4 val=5:  弹队尾全部(值<5, 含下标1) → 队[4] → 窗口[2..4] max=5
  ...
输出: [3,3,5,5,6,7]
</pre>

## 对比参照

| 类型 | 窗口大小 | 收缩触发 | 典型问题 |
|------|---------|---------|---------|
| 固定窗口 | 恒为 $k$ | `right` 每扩一格 `left` 收一格 | 窗口最大值/平均、定长排列 |
| 可变窗口 | 动态 | 约束被破坏 | 无重复最长子串、最小覆盖子串 |

| 应用 | 窗口类型 | 约束 | 答案 |
|------|---------|------|------|
| 无重复最长子串 | 可变 | 窗口无重复 | max 长度 |
| 最小覆盖子串 | 可变 | 窗口含 $t$ 全部字符 | 最短窗口 |
| 定长子数组和 | 固定 | 大小 $=k$ | max 和 |
| 字符串排列 | 固定 | 计数匹配 $t$ | 是否匹配 |

## 机制

### 为什么是 $O(n)$：指针不可回退

暴力里 `right` 每次扩张后可能因 `left` 右移而要"重新扫"，产生 $O(n^2)$。滑动窗口强约束 `left` 只增不减：每元素至多被 `right` 访问一次（入窗）、被 `left` 访问一次（出窗），总 $2n$。**这是滑动窗口的命根**——任何让指针回退的写法都毁了线性。

### 窗口合法性的可逆检测

收缩依赖"窗口是否满足约束"的 $O(1)$ 检测：无重复用字符计数/最新下标哈希、最小覆盖用"已匹配字符种类数"。检测必须增量可维护——加一个元素更新一次、删一个元素回滚一次。若检测需 $O(k)$ 全扫，窗口线性就崩了。

### 单调队列优化窗口最值

固定窗口求最值，朴素每次 $O(k)$ 扫最值、整体 $O(nk)$。单调队列（递减双端队列，队首为最大）把每次查询降到 $O(1)$：

1. 新元素入队前，从队尾弹掉所有比它小的（它们被新元素遮挡，永不再成最大）。
2. 队首下标若已离开窗口（`< i-k+1`），弹出队首。
3. 队首即当前窗口最大值。

每元素入队出队各一次，总 $O(n)$，每查询 $O(1)$ ——本质和单调栈同一套"遮挡弹出"机制，只是加了窗口左界的过期淘汰。

### 违规后果

| 违规 | 后果 |
|------|------|
| `left` 回退 | 复杂度退化 $O(n^2)$ |
| 收缩条件过松 | 窗口含非法元素，结果错 |
| 收缩条件过紧 | 漏掉更优窗口，结果次优 |
| 单调队列漏判队首越界 | 过期元素被误报为窗口最值 |
| 约束检测需全扫 | 增量更新失效，整体超线性 |

## 代码示例

**Python 3.12**：

```python
# 无重复字符最长子串: 可变窗口 + 字符最新下标
def length_of_longest_substring(s):
    last = {}                                  # ch → 最近下标
    left = best = 0
    for right, ch in enumerate(s):
        if ch in last and last[ch] >= left:    # 重复且在窗口内
            left = last[ch] + 1                # 跳到重复字符之后
        last[ch] = right
        best = max(best, right - left + 1)
    return best

# 最小覆盖子串: 可变窗口 + 计数匹配
from collections import Counter
def min_window(s, t):
    need = Counter(t)
    window = Counter()
    have, need_cnt = 0, len(need)              # need_cnt = t 中不同字符数
    left, best = 0, None
    for right, ch in enumerate(s):
        if ch in need:
            window[ch] += 1
            if window[ch] == need[ch]:         # 某字符恰好凑齐
                have += 1
        while have == need_cnt:                # 窗口已覆盖 t
            if best is None or right-left+1 < len(best):
                best = s[left:right+1]
            if s[left] in need:
                if window[s[left]] == need[s[left]]:
                    have -= 1                  # 该字符将不足
                window[s[left]] -= 1
            left += 1
    return best or ""

# 滑动窗口最大值: 递减单调队列
from collections import deque
def max_sliding_window(nums, k):
    dq = deque()                               # 存下标, 对应值递减
    res = []
    for i, x in enumerate(nums):
        while dq and nums[dq[-1]] <= x:        # 队尾 <= 新值 → 弹
            dq.pop()
        dq.append(i)
        if dq[0] <= i - k:                     # 队首离开窗口 → 弹
            dq.popleft()
        if i >= k - 1:
            res.append(nums[dq[0]])             # 队首即最大
    return res

# —— 简易输入输出 ——
print(length_of_longest_substring("abcabcbb"))   # 3
print(min_window("ADOBECODEBANC", "ABC"))        # "BANC"
print(max_sliding_window([1,3,-1,-3,5,3,6,7], 3))  # [3,3,5,5,6,7]
```

**C++20**：

```cpp
#include <iostream>
#include <vector>
#include <deque>
#include <unordered_map>
#include <algorithm>

// 无重复字符最长子串
int lengthOfLongestSubstring(const std::string& s) {
    std::unordered_map<char,int> last;
    int left = 0, best = 0;
    for (int right = 0; right < (int)s.size(); ++right) {
        char ch = s[right];
        if (last.count(ch) && last[ch] >= left) left = last[ch] + 1;
        last[ch] = right;
        best = std::max(best, right - left + 1);
    }
    return best;
}

// 滑动窗口最大值: 递减单调队列
std::vector<int> maxSlidingWindow(const std::vector<int>& nums, int k) {
    std::deque<int> dq;                        // 存下标
    std::vector<int> res;
    for (int i = 0; i < (int)nums.size(); ++i) {
        while (!dq.empty() && nums[dq.back()] <= nums[i]) dq.pop_back();
        dq.push_back(i);
        if (dq.front() <= i - k) dq.pop_front();
        if (i >= k - 1) res.push_back(nums[dq.front()]);
    }
    return res;
}

int main() {
    std::cout << lengthOfLongestSubstring("abcabcbb") << '\n';    // 3
    auto r = maxSlidingWindow({1,3,-1,-3,5,3,6,7}, 3);
    for (int x : r) std::cout << x << ' ';                        // 3 3 5 5 6 7
    std::cout << '\n';
}
```
