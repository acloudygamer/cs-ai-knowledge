# 数据结构与算法

> **版本基准**: universal（代码片段基于 Python 3.12；C++20 只在标准库行为处作对照）

没有一种结构能同时让查找、插入、删除和顺序遍历都便宜。每种数据结构都是在"数据怎么摆"上做一次置换，把某几个操作变快、另一些变慢；每种算法思想都是在"哪些计算白做了"上做一次消减。

全卷按一条链组织：**一次按键访问的代价 = 定位路径的长度 × 每一步的代价，再加一份维持形状的费用**。数组把路径压成一次地址算术，链表把路径摊成 $n$ 次跳转，哈希用函数把路径折叠成一次探测，树用层次把路径压到 $\log n$，B 树把单步代价换成一次页读再靠加宽节点把路径压短。三个因子此消彼长，没有一种结构能同时压低三者。

## 学习路径

1. **先读 01-复杂度与权衡**：拿到记账的两把尺子——量级与摊还，后面的每一篇都在用它们算账。
2. **再读 02-线性结构**：从最便宜的布局出发，看清"连续"带来的红利与约束。
3. **再读 03-树形结构**：同一笔置换向层次推进，八个成员按"维持什么不变量"分族。
4. **再读 04-图**：结构从"摆放元素"转向"组织关系"，路径本身成为优化对象。
5. **最后读 05-算法思想**：把前四章的收录全部打开，按"消减了什么"重新分类。

前四章按数据布局推进，可以跳读；第五章的六种思想与前面各章的机制互为参照，建议在读过对应结构之后再读。
