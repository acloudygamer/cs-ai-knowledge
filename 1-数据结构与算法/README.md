# 数据结构与算法

> **版本基准**: universal

> **版本说明**: 代码示例基于 Python 3.12 与 C++20

本域回答一个问题：**数据怎么摆放，操作就有多快**。每种数据结构都是在硬件约束（连续内存 vs 指针跳转、缓存行、外存页）下，时间与空间的一场置换；每种算法思想都是消减某一类无用功的方法。

组织逻辑：**主约束先行，结构按布局分族，算法按思想分族**。01 给出度量置换的语言（复杂度分析）；02~04 是按物理布局分族的结构（线性 → 树形 → 图）；05 是按"消减了什么"分族的算法思想。

## 各部分入口
