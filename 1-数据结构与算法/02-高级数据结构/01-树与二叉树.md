## 树与二叉树

### 解决什么问题
树结构用于表示层次关系，适用于文件系统、组织结构、XML/HTML DOM 等场景；二叉树是每个节点最多两个子节点的树，是许多高级数据结构的基础。

### 核心概念
- **二叉树遍历**：前序（根-左-右）、中序（左-根-右）、后序（左-右-根）、层序（BFS）
- **BST**：左子树小于根，右子树大于根，中序遍历有序
- **自平衡树**：AVL、红黑树通过旋转保持平衡，保证 O(log n) 操作
- **B树/B+树**：多路搜索树，适用于数据库索引、文件系统

### 节点定义

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right
```

## 二叉树遍历

### 前序遍历（根-左-右）

先访问根节点，再递归遍历左右子树。

### 参考样例

```python
def preorder(root):
    if not root:
        return []
    return [root.val] + preorder(root.left) + preorder(root.right)

def preorder_iter(root):
    if not root:
        return []
    stack, res = [root], []
    while stack:
        node = stack.pop()
        res.append(node.val)
        if node.right:
            stack.append(node.right)
        if node.left:
            stack.append(node.left)
    return res
```

### 中序遍历（左-根-右）

左子树 → 根 → 右子树。二叉搜索树的中序遍历得到有序序列。

### 参考样例

```python
def inorder(root):
    if not root:
        return []
    return inorder(root.left) + [root.val] + inorder(root.right)
```

### 后序遍历（左-右-根）

左右子树都遍历完再访问根节点。

### 参考样例

```python
def postorder(root):
    if not root:
        return []
    return postorder(root.left) + postorder(root.right) + [root.val]
```

## 最近公共祖先（LCA）

若节点 p、q 分别在 root 的左右子树，则 root 即为 LCA。

### 参考样例

```python
def lowest_common_ancestor(root, p, q):
    if not root or root == p or root == q:
        return root
    left = lowest_common_ancestor(root.left, p, q)
    right = lowest_common_ancestor(root.right, p, q)
    if not left:
        return right
    if not right:
        return left
    return root
```

## 二叉搜索树（BST）

左子树 < 根 < 右子树，中序遍历得到有序序列，查找/插入/删除平均 O(log n)。

### BST 查找

### 参考样例

```python
def bst_search(root, target):
    while root:
        if target == root.val:
            return root
        elif target < root.val:
            root = root.left
        else:
            root = root.right
    return None
```

### BST 插入

### 参考样例

```python
def bst_insert(root, val):
    if not root:
        return TreeNode(val)
    if val < root.val:
        root.left = bst_insert(root.left, val)
    else:
        root.right = bst_insert(root.right, val)
    return root
```

### BST 删除

删除操作需要考虑三种情况：
- **叶子节点**：直接删除
- **度为1**：用子节点替代
- **度为2**：用后继节点（右子树最左节点）或前驱节点（左子树最右节点）替代

### 参考样例

```python
def bst_delete(root, val):
    if not root:
        return None
    if val < root.val:
        root.left = bst_delete(root.left, val)
    elif val > root.val:
        root.right = bst_delete(root.right, val)
    else:
        if not root.left and not root.right:
            return None
        if not root.left:
            return root.right
        if not root.right:
            return root.left
        successor = root.right
        while successor.left:
            successor = successor.left
        root.val = successor.val
        root.right = bst_delete(root.right, successor.val)
    return root
```

### 复杂度分析

| 操作 | 平均 | 最坏 |
|------|------|------|
| 查找 | O(log n) | O(n) |
| 插入 | O(log n) | O(n) |
| 删除 | O(log n) | O(n) |

最坏情况发生在树退化为链表时（已排序插入/删除）。

## 平衡二叉搜索树（AVL）

一种自平衡二叉搜索树，任何节点的左右子树高度差不超过 1。

### 核心概念
- **平衡因子** = 左子树高度 - 右子树高度，取值 {-1, 0, 1}
- **四种旋转**：左左（单右旋）、右右（单左旋）、左右（先左旋后右旋）、右左（先右旋后左旋）

### 参考样例

```python
def rotate_right(y):
    x = y.left
    y.left = x.right
    x.right = y
    return x

def rotate_left(x):
    y = x.right
    x.right = y.left
    y.left = x
    return y
```

### 复杂度

| 操作 | 时间复杂度 |
|------|-----------|
| 查找 | O(log n) |
| 插入 | O(log n) |
| 删除 | O(log n) |

## 红黑树

自平衡二叉搜索树，通过节点颜色和旋转操作保持近似平衡。

### 红黑树性质

1. 每个节点非红即黑
2. 根节点是黑色
3. 叶节点（NIL）是黑色
4. 红节点的子节点必须是黑色
5. 从任一节点到其每个叶子的路径上，黑节点数量相同

### 复杂度保证

- 查找/插入/删除：O(log n)
- 适用于需要有序且频繁插入删除的场景（如 C++ STL 的 map/set、Java 的 TreeMap/TreeSet）

### 参考样例

```python
def rb_rotate_right(tree, y):
    x = y.left
    y.left = x.right
    x.right = y
    return x

def rb_rotate_left(tree, x):
    y = x.right
    x.right = y.left
    y.left = x
    return y
```

### AVL vs 红黑树

| 特性 | AVL | 红黑树 |
|------|-----|--------|
| 平衡度 | 严格（高度差≤1） | 宽松（近似平衡） |
| 查找性能 | 更好 | 稍差 |
| 插入删除性能 | 需更多旋转 | 旋转更少 |
| 应用 | 数据库索引 | STL map/set |

## B树与B+树

外存友好的多路搜索树，常用于数据库和文件系统索引。

### B树（B-Tree）

一种自平衡多路搜索树，所有叶子节点在同一层。

### 参考样例

```python
class BTreeNode:
    def __init__(self, leaf=False):
        self.leaf = leaf
        self.keys = []
        self.children = []
        self.t = 2

class BTree:
    def __init__(self, t=2):
        self.t = t
        self.root = BTreeNode(leaf=True)

    def insert(self, k):
        root = self.root
        if len(root.keys) == 2 * self.t - 1:
            new_root = BTreeNode()
            new_root.children.append(self.root)
            self._split_child(new_root, 0)
            self.root = new_root
        self._insert_nonfull(self.root, k)

    def _split_child(self, parent, i):
        t = self.t
        child = parent.children[i]
        new_child = BTreeNode(leaf=child.leaf)
        new_child.keys = child.keys[t:]
        child.keys = child.keys[:t - 1]
        if not child.leaf:
            new_child.children = child.children[t:]
            child.children = child.children[:t]
        parent.keys.insert(i, child.keys.pop())
        parent.children.insert(i + 1, new_child)
```

### B+树（B+ Tree）

B树的变体，所有数据存在叶子节点，非叶子节点只存储索引，便于范围查询。

### 参考样例

```python
class BPlusTreeNode:
    def __init__(self, leaf=False):
        self.leaf = leaf
        self.keys = []
        self.children = []
        self.next = None

class BPlusTree:
    def __init__(self, t=2):
        self.t = t
        self.root = BPlusTreeNode(leaf=True)

    def _insert_nonfull(self, node, k):
        i = len(node.keys) - 1
        if node.leaf:
            node.keys.append(None)
            while i >= 0 and k < node.keys[i]:
                node.keys[i + 1] = node.keys[i]
                i -= 1
            node.keys[i + 1] = k
        else:
            while i >= 0 and k < node.keys[i]:
                i -= 1
            i += 1
            if len(node.children[i].keys) == 2 * self.t - 1:
                self._split_child(node, i)
                if k > node.keys[i]:
                    i += 1
            self._insert_nonfull(node.children[i], k)
```

### B树 vs B+树

| 特性 | B树 | B+树 |
|------|-----|------|
| 数据存储 | 所有节点 | 仅叶子节点 |
| 查询稳定性 | O(log n) ~ O(n) | O(log n)（稳定） |
| 范围查询 | 需要遍历树 | 叶子链表便于范围查询 |
| 空间利用率 | 较低 | 较高（节点满） |
| 应用场景 | 文件系统 | 数据库索引 |

## 层次遍历（BFS）

使用队列按层遍历二叉树。

### 参考样例

```python
from collections import deque

def level_order(root):
    if not root:
        return []
    queue, result = deque([root]), []
    while queue:
        level = []
        for _ in range(len(queue)):
            node = queue.popleft()
            level.append(node.val)
            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)
        result.append(level)
    return result
```
