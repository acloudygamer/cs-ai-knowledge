# 树与二叉树

### 解决什么问题
树结构用于表示层次关系，适用于文件系统、组织结构、XML/HTML DOM等场景；二叉树是每个节点最多两个子节点的树，是许多高级数据结构的基础。

### 核心概念
- 二叉树遍历：前序（根-左-右）、中序（左-根-右）、后序（左-右-根）、层序（BFS）
- BST：左子树小于根，右子树大于根，中序遍历有序
- 自平衡树：AVL、红黑树通过旋转保持平衡，保证 O(log n) 操作
- B树/B+树：多路搜索树，适用于数据库索引、文件系统

### 怎么用

## 二叉树遍历

```python
# 前序遍历（根-左-右）
def preorder(root):
    if not root:
        return []
    return [root.val] + preorder(root.left) + preorder(root.right)

# 中序遍历（左-根-右）
def inorder(root):
    if not root:
        return []
    return inorder(root.left) + [root.val] + inorder(root.right)

# 后序遍历（左-右-根）
def postorder(root):
    if not root:
        return []
    return postorder(root.left) + postorder(root.right) + [root.val]

# 迭代版前序
def preorder_iter(root):
    if not root:
        return []
    stack, res = [root], []
    while stack:
        node = stack.pop()
        res.append(node.val)
        if node.right:
            stack.append(node.right)
        if node.left:
            stack.append(node.left)
    return res
```

## 最近公共祖先（LCA）

```python
def lowest_common_ancestor(root, p, q):
    if not root or root == p or root == q:
        return root
    left = lowest_common_ancestor(root.left, p, q)
    right = lowest_common_ancestor(root.right, p, q)
    if not left:
        return right
    if not right:
        return left
    return root
```

## 二叉搜索树（BST）

- 左子树 < 根 < 右子树
- 中序遍历得到有序序列
- 查找/插入/删除平均O(log n)

## 平衡二叉搜索树（AVL）

一种自平衡二叉搜索树，任何节点的左右子树高度差不超过1。

```python
class AVLNode:
    def __init__(self, val):
        self.val = val
        self.left = None
        self.right = None
        self.height = 1

class AVLTree:
    def get_height(self, node):
        return node.height if node else 0

    def get_balance(self, node):
        return self.get_height(node.left) - self.get_height(node.right) if node else 0

    def rotate_right(self, y):
        x = y.left
        T2 = x.right
        x.right = y
        y.left = T2
        y.height = 1 + max(self.get_height(y.left), self.get_height(y.right))
        x.height = 1 + max(self.get_height(x.left), self.get_height(x.right))
        return x

    def rotate_left(self, x):
        y = x.right
        T2 = y.left
        y.left = x
        x.right = T2
        x.height = 1 + max(self.get_height(x.left), self.get_height(x.right))
        y.height = 1 + max(self.get_height(y.left), self.get_height(y.right))
        return y

    def insert(self, node, val):
        if not node:
            return AVLNode(val)

        if val < node.val:
            node.left = self.insert(node.left, val)
        else:
            node.right = self.insert(node.right, val)

        node.height = 1 + max(self.get_height(node.left), self.get_height(node.right))
        balance = self.get_balance(node)

        # 四种旋转情况
        if balance > 1 and val < node.left.val:  # 左左
            return self.rotate_right(node)
        if balance < -1 and val > node.right.val:  # 右右
            return self.rotate_left(node)
        if balance > 1 and val > node.left.val:  # 左右
            node.left = self.rotate_left(node.left)
            return self.rotate_right(node)
        if balance < -1 and val < node.right.val:  # 右左
            node.right = self.rotate_right(node.right)
            return self.rotate_left(node)

        return node
```

## 红黑树

自平衡二叉搜索树，通过节点颜色和旋转操作保持近似平衡。

### 红黑树性质

1. 每个节点非红即黑
2. 根节点是黑色
3. 叶节点（NIL）是黑色
4. 红节点的子节点必须是黑色
5. 从任一节点到其每个叶子的路径上，黑节点数量相同

### 复杂度保证

- 查找/插入/删除：O(log n)
- 适用于需要有序且频繁插入删除的场景（如 C++ STL 的 map/set、Java 的 TreeMap/TreeSet）

```python
class RBNode:
    def __init__(self, val, color='red'):
        self.val = val
        self.color = color  # 'red' or 'black'
        self.left = None
        self.right = None
        self.parent = None

class RedBlackTree:
    BLACK = 'black'
    RED = 'red'

    def __init__(self):
        self.NIL = RBNode(val=None, color=self.BLACK)
        self.root = self.NIL

    def left_rotate(self, x):
        y = x.right
        x.right = y.left
        if y.left != self.NIL:
            y.left.parent = x
        y.parent = x.parent
        if x.parent == self.NIL:
            self.root = y
        elif x == x.parent.left:
            x.parent.left = y
        else:
            x.parent.right = y
        y.left = x
        x.parent = y

    def right_rotate(self, y):
        x = y.left
        y.left = x.right
        if x.right != self.NIL:
            x.right.parent = y
        x.parent = y.parent
        if y.parent == self.NIL:
            self.root = x
        elif y == y.parent.right:
            y.parent.right = x
        else:
            y.parent.left = x
        x.right = y
        y.parent = x

    def insert(self, val):
        new_node = RBNode(val, self.RED)
        new_node.left = self.NIL
        new_node.right = self.NIL

        parent = self.NIL
        current = self.root

        while current != self.NIL:
            parent = current
            if new_node.val < current.val:
                current = current.left
            else:
                current = current.right

        new_node.parent = parent
        if parent == self.NIL:
            self.root = new_node
        elif new_node.val < parent.val:
            parent.left = new_node
        else:
            parent.right = new_node

        self._insert_fixup(new_node)

    def _insert_fixup(self, node):
        while node.parent.color == self.RED:
            if node.parent == node.parent.parent.left:
                uncle = node.parent.parent.right
                if uncle.color == self.RED:
                    node.parent.color = self.BLACK
                    uncle.color = self.BLACK
                    node.parent.parent.color = self.RED
                    node = node.parent.parent
                else:
                    if node == node.parent.right:
                        node = node.parent
                        self.left_rotate(node)
                    node.parent.color = self.BLACK
                    node.parent.parent.color = self.RED
                    self.right_rotate(node.parent.parent)
            else:
                uncle = node.parent.parent.left
                if uncle.color == self.RED:
                    node.parent.color = self.BLACK
                    uncle.color = self.BLACK
                    node.parent.parent.color = self.RED
                    node = node.parent.parent
                else:
                    if node == node.parent.left:
                        node = node.parent
                        self.right_rotate(node)
                    node.parent.color = self.BLACK
                    node.parent.parent.color = self.RED
                    self.left_rotate(node.parent.parent)
        self.root.color = self.BLACK
```

## B树与B+树

外存友好的多路搜索树，常用于数据库和文件系统索引。

### B树（B-Tree）

一种自平衡多路搜索树，所有叶子节点在同一层。

```python
class BTreeNode:
    def __init__(self, leaf=False):
        self.leaf = leaf
        self.keys = []  # 存储键
        self.children = []  # 存储子节点指针
        self.t = 2  # 最小度数（t-1 <= keys <= 2t-1）

class BTree:
    def __init__(self, t=2):
        self.t = t
        self.root = BTreeNode(leaf=True)

    def insert(self, k):
        root = self.root
        if len(root.keys) == 2 * self.t - 1:
            new_root = BTreeNode()
            new_root.children.append(self.root)
            self._split_child(new_root, 0)
            self.root = new_root
        self._insert_nonfull(self.root, k)

    def _split_child(self, parent, i):
        t = self.t
        child = parent.children[i]
        new_child = BTreeNode(leaf=child.leaf)

        # 将满节点分裂
        new_child.keys = child.keys[t:]
        child.keys = child.keys[:t - 1]

        if not child.leaf:
            new_child.children = child.children[t:]
            child.children = child.children[:t]

        # 将中间键提升到父节点
        parent.keys.insert(i, child.keys.pop())

        # 设置新子节点
        parent.children.insert(i + 1, new_child)
```

### B+树（B+ Tree）

B树的变体，所有数据存在叶子节点，非叶子节点只存储索引。

```python
class BPlusTreeNode:
    def __init__(self, leaf=False):
        self.leaf = leaf
        self.keys = []
        self.children = []
        self.next = None  # 叶子节点链表指针

class BPlusTree:
    def __init__(self, t=2):
        self.t = t
        self.root = BPlusTreeNode(leaf=True)

    def _insert_nonfull(self, node, k):
        i = len(node.keys) - 1
        if node.leaf:
            # 叶子节点：找到位置插入
            node.keys.append(None)
            while i >= 0 and k < node.keys[i]:
                node.keys[i + 1] = node.keys[i]
                i -= 1
            node.keys[i + 1] = k
        else:
            # 非叶子节点：找到合适的子节点
            while i >= 0 and k < node.keys[i]:
                i -= 1
            i += 1
            if len(node.children[i].keys) == 2 * self.t - 1:
                self._split_child(node, i)
                if k > node.keys[i]:
                    i += 1
            self._insert_nonfull(node.children[i], k)
```

### B树 vs B+树

| 特性 | B树 | B+树 |
|------|-----|------|
| 数据存储 | 所有节点 | 仅叶子节点 |
| 查询稳定性 | O(log n) ~ O(n) | O(log n)（稳定） |
| 范围查询 | 需要遍历树 | 叶子链表便于范围查询 |
| 空间利用率 | 较低 | 较高（节点满） |
| 应用场景 | 文件系统 | 数据库索引 |

def bst_search(root, target):
    while root:
        if target == root.val:
            return root
        elif target < root.val:
            root = root.left

## BST 删除操作

BST 删除操作需要考虑三种情况：

### 情况分析

| 情况 | 说明 | 处理方式 |
|------|------|----------|
| 度为0（叶子节点） | 无子节点 | 直接删除 |
| 度为1 | 只有一个子节点 | 用子节点替代 |
| 度为2 | 有两个子节点 | 找后继或前驱节点替代 |

**关键思想**：度为2的节点，删除后可以用其**后继节点**（右子树最左节点）或**前驱节点**（左子树最右节点）替代。

### 实现（后继节点方式）

```python
def bst_delete(root, val):
    """
    BST 删除操作
    返回删除后的根节点
    """
    if not root:
        return None

    if val < root.val:
        root.left = bst_delete(root.left, val)
    elif val > root.val:
        root.right = bst_delete(root.right, val)
    else:
        # 找到要删除的节点

        # 情况1：叶子节点（度为0）
        if not root.left and not root.right:
            return None

        # 情况2：只有右子树（度为1）
        if not root.left:
            return root.right

        # 情况3：只有左子树（度为1）
        if not root.right:
            return root.left

        # 情况4：度为2 - 找后继节点（右子树最左节点）
        successor = root.right
        while successor.left:
            successor = successor.left

        root.val = successor.val  # 用后继节点的值替代
        # 删除后继节点（后继节点一定没有左子树）
        root.right = bst_delete(root.right, successor.val)

    return root


def bst_delete_iterative(root, key):
    """
    BST 删除（迭代版本，更清晰）
    """
    parent = None
    current = root

    # 找到要删除的节点
    while current and current.val != key:
        parent = current
        if key < current.val:
            current = current.left
        else:
            current = current.right

    if not current:
        return root  # 未找到

    # 情况1：叶子节点
    if not current.left and not current.right:
        if current == root:
            return None
        if parent.left == current:
            parent.left = None
        else:
            parent.right = None

    # 情况2：只有左子树
    elif current.left and not current.right:
        if current == root:
            return current.left
        if parent.left == current:
            parent.left = current.left
        else:
            parent.right = current.left

    # 情况3：只有右子树
    elif not current.left and current.right:
        if current == root:
            return current.right
        if parent.left == current:
            parent.left = current.right
        else:
            parent.right = current.right

    # 情况4：度为2
    else:
        # 找后继（右子树最左节点）
        successor_parent = current
        successor = current.right
        while successor.left:
            successor_parent = successor
            successor = successor.left

        # 用后继值替代
        current.val = successor.val

        # 删除后继节点
        if successor_parent == current:
            # 后继是当前节点的直接右子节点
            successor_parent.right = successor.right
        else:
            successor_parent.left = successor.right

    return root
```

## 层次遍历（BFS）

```python
def level_order(root):
    if not root:
        return []
    from collections import deque
    queue, result = deque([root]), []
    while queue:
        level = []
        for _ in range(len(queue)):
            node = queue.popleft()  # 使用 popleft() O(1)，避免 O(n) 的 pop(0)
            level.append(node.val)
            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)
        result.append(level)
    return result
```
