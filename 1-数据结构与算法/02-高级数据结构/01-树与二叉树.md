# 树与二叉树

> **版本基准**：universal —— 代码示例同时使用 Python 3.12 与 C++20

## 本质

树是节点间的层次关系——从图论看是**连通无环图**：根唯一，从任一节点沿父向边能到根、从根能到所有节点，边数恒为 $n-1$。等价的递归定义：空树，或一个根加若干不相交子树。二叉树是每节点最多两子的树，是树结构的基础模型：任何有根有序树都可唯一二叉化。

树结构消耗两类资源——内存（节点指针+值）和计算时间（沿路径的查找/遍历）。**所有平衡机制的本质都是在控制树高**，从而控制这两类消耗。遍历（先序/中序/后序/层序）则是把层级结构线性化压平成一维序列；中序遍历 BST 产出升序序列，是 BST 查找性质的直接推论。

## 数学模型

### BST 的查找界

含 $n$ 节点的二叉树高度 $h$：

$$\lfloor\log_2 n\rfloor \le h \le n-1$$

- **下界**：完全二叉树 $n\le 2^{h+1}-1$ ⇒ $h\ge\lfloor\log_2 n\rfloor$。
- **上界**：退化为链表（升/降序插入总落在最左/最右）⇒ $h=n-1$。

> **洞察**：BST 查找是 $O(h)$。退化让 $O(\log n)$ 变 $O(n)$ ——平衡树的全部意义就是把 $h$ 钉在 $O(\log n)$。

### 各树的核心约束

| 树 | 约束 | 目的 |
|----|------|------|
| 二叉树 | $\deg(v)\le 2$ | 保二叉结构等价性 |
| BST 有序 | 左子 $<x<$ 右子 | 搜索单调 |
| AVL | $\|h_L-h_R\|\le 1$ | 严格高度平衡 |
| 红黑树 | 根黑叶黑、红子必黑、黑高相同 | 黑高平衡（最长 $\le 2\times$ 最短） |
| B 树($m$ 阶) | 节点子指针 $\in[\lceil m/2\rceil, m]$ | 多路平衡，控树高 |

### B 树的磁盘 IO 模型

磁盘页 $B$ 字节、每 key $k$ 字节 ⇒ 每内部节点容 $\lfloor B/k\rfloor$ 个 key。 $n$ 个 key 的树高：

$$h\approx\lceil\log_{\lfloor B/k\rfloor} n\rceil$$

若 $B/k=100$， $h\approx\log_{100} n$，比二叉的 $\log_2 n$ 小约 6 倍——每降一层省一次磁盘页加载。

> **洞察**：B 树是为磁盘而生的树——磁盘 IO 比内存访问贵数个量级，所以用多路分支把树高压到极低，让一次查找只触发少数几页 IO；B+ 树再把数据全聚到叶子层并用链表串联，让范围查询沿链扫描、避免随机 IO。

## 数据流

### 四种遍历

<pre>
先序(根→左→右): 读根 → 递归左 → 递归右        根最先消费
中序(左→根→右): 最左深入压栈 → 弹栈读值 → 转右   BST 即升序
后序(左→右→根): 两子处理完才读根                适合释放资源
层序(BFS):       队列入根 → 出队访问 → 入队左右   按深度分层
</pre>

### BST 中序的排序性

<pre>
依次插 [7,2,9,1,5] 建 BST:
        7
       / \
      2   9
     / \
    1   5

中序遍历: 1 → 2 → 5 → 7 → 9   (升序)

原理: 对任意节点 x，左子树全 < x.val < 右子树全
      中序先输出完左子树再输出 x 再输出右子树 ⇒ 单调递增
</pre>

### 旋转（重平衡的原子操作）

<pre>
        x                右旋            y
       / \              ───→           / \
      y   T3                           T1  x
     / \                                   / \
    T1  T2                                T2  T3

中序不变: T1 y T2 x T3   (旋转前后完全一致)
局部: 只改常数个指针，O(1)；但改变子树高度，失衡沿路径上传
</pre>

## 对比参照

| 属性 | BST | AVL | 红黑树 | B/B+ 树 |
|------|-----|-----|--------|---------|
| 平衡标准 | 无（自然高度） | 高度差 $\le 1$ | 黑高平衡 | 多路平衡 |
| 查找 | $O(h)$ | $O(\log n)$ | $O(\log n)$ | $O(\log_m n)$ |
| 插入旋转 | — | $\le 2$ | $\le 2$ | 分裂/合并 |
| 删除旋转 | — | $O(\log n)$ | $\le 3$ | $O(\log_m n)$ |
| 适用 | 内存小数据 | 读密集 | 写密集 | 磁盘/外存 |

## 机制

### AVL：严格高度差

约束 $|h_L-h_R|\le 1$。插入沿路径回溯最多两次旋转恢复；**删除可能要 $O(\log n)$ 次旋转**向上修复（每次旋转若降低子树高就继续上传）——这是 AVL 的主要弱点。严格平衡 ⇒ 查找最优、删除贵，适合读密集。

### 红黑树：松弛的黑高平衡

约束：根黑、叶黑、红子必黑、各路径黑高相同。最长路径 $\le 2\times$ 最短，不如 AVL 严格。插入最多两次旋转、删除最多三次。

> **洞察**：红黑树的设计动机正是治 AVL 删除的病——AVL 严格平衡要 $O(\log n)$ 次旋转，红黑树允许路径长度在 2:1 内波动，把删除旋转压到常数次（最多 3），换更稳定的写性能。适合写密集。

### B/B+ 树：多路分支为磁盘

$m$ 阶 B 树每节点最多 $m$ 子、至少 $\lceil m/2\rceil$ 子。过满分裂、过疏合并或向兄弟借。B+ 树把数据全聚到叶子、叶子链表串联，范围查询沿链扫描免随机 IO；内部节点只存 key 不存 data 指针，一页装更多 key、树高更低。

### 旋转的机制

左旋/右旋在**保持 BST 中序序列不变**的前提下，把较深子树"上提"、较浅的"下压"。LL/RR 失衡单旋即可，LR/RL 需双旋（两次单旋）。旋转本身 $O(1)$、只改常数指针，但改了子树高度，失衡沿路径向上传播。

### 统一视角

平衡树 = BST 偏序约束 + 某种高度/平衡约束 + 维护该约束的重平衡算法。AVL 用严格高度差换查找最优、删除贵；红黑用黑高换写性能；B 树用多路分支换低树高以适配磁盘——都是"在偏序约束下控树高"的不同工程折中。

## 代码示例

**Python 3.12**：

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val, self.left, self.right = val, left, right

# BST 插入（递归）
def bst_insert(root, val):
    if not root:
        return TreeNode(val)
    if val < root.val:
        root.left = bst_insert(root.left, val)
    else:
        root.right = bst_insert(root.right, val)
    return root

# BST 查找（迭代，O(h)）
def bst_search(root, target):
    while root:
        if target == root.val:
            return True
        root = root.left if target < root.val else root.right
    return False

# 中序遍历：BST 产出升序
def inorder(root):
    return inorder(root.left) + [root.val] + inorder(root.right) if root else []

# 右旋：y 的左子 x 上提为父，y 变 x 的右子（中序不变）
def rotate_right(y):
    x, T2 = y.left, y.left.right
    x.right, y.left = y, T2
    return x

# 左旋：x 的右子 y 上提为父，x 变 y 的左子
def rotate_left(x):
    y, T2 = x.right, x.right.left
    y.left, x.right = x, T2
    return y

# —— 简易输入输出 ——
root = None
for v in [7, 2, 9, 1, 5]:
    root = bst_insert(root, v)
print(inorder(root))          # [1, 2, 5, 7, 9]
print(bst_search(root, 5), bst_search(root, 3))   # True False
```

**C++20**：

```cpp
#include <iostream>
#include <vector>
#include <memory>

struct TreeNode {
    int val{};
    TreeNode* left{};
    TreeNode* right{};
    TreeNode(int x = 0) : val(x) {}
};

// BST 插入（递归）
TreeNode* bst_insert(TreeNode* root, int val) {
    if (!root) return new TreeNode(val);
    if (val < root->val) root->left = bst_insert(root->left, val);
    else                 root->right = bst_insert(root->right, val);
    return root;
}

// BST 查找（迭代，O(h)）
bool bst_search(TreeNode* root, int target) {
    while (root) {
        if (target == root->val) return true;
        root = (target < root->val) ? root->left : root->right;
    }
    return false;
}

// 中序遍历：BST 产出升序
void inorder(TreeNode* root, std::vector<int>& out) {
    if (!root) return;
    inorder(root->left, out);
    out.push_back(root->val);
    inorder(root->right, out);
}

// 右旋：中序不变，O(1)
TreeNode* rotate_right(TreeNode* y) {
    TreeNode* x = y->left;
    TreeNode* T2 = x->right;
    x->right = y;  y->left = T2;
    return x;
}
// 左旋
TreeNode* rotate_left(TreeNode* x) {
    TreeNode* y = x->right;
    TreeNode* T2 = y->left;
    y->left = x;   x->right = T2;
    return y;
}

// —— 简易输入输出 ——
int main() {
    TreeNode* root = nullptr;
    for (int v : {7, 2, 9, 1, 5}) root = bst_insert(root, v);
    std::vector<int> ord; inorder(root, ord);
    for (int v : ord) std::cout << v << ' ';        // 1 2 5 7 9
    std::cout << '\n' << std::boolalpha
              << bst_search(root, 5) << ' ' << bst_search(root, 3) << '\n'; // true false
}
```
