## 树与二叉树

### 定义

树是节点间具有层次关系的数据结构，根节点唯一，从任一节点沿父向边可达根，从根可达所有节点。

**数学模型**

$$
T = (V, E, r),\quad V = \{v_1, v_2, \ldots, v_n\},\quad |V| = n,\quad |E| = n-1
$$

- 二叉树约束：$\forall v \in V,\ \deg(v) \leq 2$
- BST 约束：$\forall (u,v) \in \text{left}(x),\ u < x;\ \forall (u,v) \in \text{right}(x),\ u > x$
- AVL 平衡约束：$\forall v,\ |h(\text{left}(v)) - h(\text{right}(v))| \leq 1$

**数据流**

<pre>
先序 (根→左→右):  A B D E C F G
中序 (左→根→右):  D B E A F C G
后序 (左→右→根):  D E B F G C A
层序 (BFS):       A B C D E F G
</pre>

<pre>
BST 中序遍历数据形态变换：
[7,2,9,1,5]  →  遍历路径：2→7→9 → 输出升序：[1,2,5,7,9]
</pre>

**机制**

树的层次结构天然适配递归分解：遍历是深度优先的后序组合，并查集路径压缩将查找路径上的节点直接挂到根上。

BST 的查找下界由树高决定，退化为链表时 $O(n)$。AVL 强制平衡因子约束，插入最多两次旋转、删除最多 $O(\log n)$ 次旋转，查找始终 $O(\log n)$。红黑树以颜色约束代替高度约束，插入最多两次旋转，允许最长路径不超过最短路径的两倍，换取更低的删除成本。

B/B+ 树的多路分支将树高压到 $O(\log_m n)$，适合磁盘 IO；B+ 树所有数据聚在叶子并用链表串连，范围查询只需扫描叶子链。

**参考存根**

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val, self.left, self.right = val, left, right

def bst_insert(root, val):
    if not root: return TreeNode(val)
    if val < root.val: root.left = bst_insert(root.left, val)
    else: root.right = bst_insert(root.right, val)
    return root
```
