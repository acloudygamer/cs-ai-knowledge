## 并查集

### 定义

并查集（Union-Find）是不相交集合的数据结构，支持 Find（查代表元）与 Union（合并）两种核心操作。

**数学模型**

$$
\text{Find}(x) = \begin{cases} x & \text{parent}[x] = x \\ \text{Find}(\text{parent}[x]) & \text{otherwise} \end{cases}
$$

路径压缩：$\text{parent}[x] \leftarrow \text{Find}(\text{parent}[x])$ 使查找路径上所有节点直接指向根。

按秩合并：设 $\text{rank}[x]$ 为树高的上界，合并时令大秩根为新根。

复杂度：$T(n) = O(\alpha(n))$，其中 $\alpha(n)$ 为 Ackermann 函数反函数，实际值 $< 5$。

**数据流**

```
Find(4):
  4→3→1→0 (压缩前)
  4→0, 3→0 (压缩后)

Kruskal:
  边按权重升序 → if Find(u) ≠ Find(v): 选择该边并Union
```

**机制**

Kruskal 最小生成树依赖并查集的环检测：某边两端点已在同一集合则该边必在已有 MST 中，舍去。每合并一次集合数减一，$|V|-1$ 次合并后 MST 完成。岛屿数量问题中，将相邻陆地合并，统计独立集合数。

**参考存根**

```python
class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x

    def union(self, x, y):
        rx, ry = self.find(x), self.find(y)
        if rx == ry: return False
        if self.rank[rx] < self.rank[ry]: rx, ry = ry, rx
        self.parent[ry] = rx
        if self.rank[rx] == self.rank[ry]: self.rank[rx] += 1
        return True
```
