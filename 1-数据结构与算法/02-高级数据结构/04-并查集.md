## 并查集 (Union-Find)

### 解决什么问题
处理不相交集合的合并与查询，核心操作 Find（查根）与 Union（合并），适用于连通性判断、朋友圈问题、岛屿数量、集合合并等动态连通性场景。

### 核心概念
- **Find**：查找元素所属集合的根节点
- **Union**：合并两个不相交的集合
- **路径压缩**：查询时将路径上节点直接指向根
- **按秩合并**：小秩合并到大秩，保持树的扁平化
- **复杂度**：近乎 O(1)，实际是 O(α(n))

### 并查集 vs DFS

| 场景 | 并查集 | DFS/BFS |
|------|--------|---------|
| 动态连通性 | 更适合 | 需要重建访问状态 |
| 频繁查询两点是否连通 | O(1) | O(V+E) |
| 需要获知所有连通分量成员 | 需额外存储 | 直接可得 |
| 图结构固定不变 | 并查集略优 | 等效 |

### 复杂度分析

| 操作 | 朴素版 | 路径压缩 | 路径压缩 + 按秩合并 |
|------|--------|----------|-------------------|
| Find | O(n) | O(α(n)) | O(α(n)) |
| Union | O(n) | O(α(n)) | O(α(n)) |

其中 α(n) 是 Ackermann 函数的反函数，近似为常数。

## 基本实现

### 参考样例

```python
class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, x, y):
        root_x, root_y = self.find(x), self.find(y)
        if root_x == root_y:
            return False
        if self.rank[root_x] < self.rank[root_y]:
            root_x, root_y = root_y, root_x
        self.parent[root_y] = root_x
        if self.rank[root_x] == self.rank[root_y]:
            self.rank[root_x] += 1
        return True
```

## 经典问题

### 省份数量（连通分量）

**LeetCode 547**。

### 参考样例

```python
def find_circle_num(is_connected):
    n = len(is_connected)
    uf = UnionFind(n)
    for i in range(n):
        for j in range(i + 1, n):
            if is_connected[i][j]:
                uf.union(i, j)
    return sum(1 for i in range(n) if uf.find(i) == i)
```

### 岛屿数量

**LeetCode 200**。

### 参考样例

```python
def num_islands(grid):
    if not grid:
        return 0
    m, n = len(grid), len(grid[0])
    uf = UnionFind(m * n)
    directions = [(1, 0), (0, 1)]
    for i in range(m):
        for j in range(n):
            if grid[i][j] == '1':
                idx = i * n + j
                for di, dj in directions:
                    ni, nj = i + di, j + dj
                    if 0 <= ni < m and 0 <= nj < n and grid[ni][nj] == '1':
                        uf.union(idx, ni * n + nj)
    islands = set()
    for i in range(m):
        for j in range(n):
            if grid[i][j] == '1':
                islands.add(uf.find(i * n + j))
    return len(islands)
```

### 等式方程可满足性

**LeetCode 990**。

### 参考样例

```python
def equations_possible(equations):
    uf = UnionFind(26)
    for eq in equations:
        if eq[1] == '=':
            uf.union(ord(eq[0]) - 97, ord(eq[3]) - 97)
    for eq in equations:
        if eq[1] == '!':
            if uf.find(ord(eq[0]) - 97) == uf.find(ord(eq[3]) - 97):
                return False
    return True
```

## Kruskal 最小生成树

按边权重排序，依次选择不形成环的最小边。

### 参考样例

```python
def kruskal(n, edges):
    edges.sort(key=lambda x: x[2])
    uf = UnionFind(n)
    mst_weight = 0
    for u, v, weight in edges:
        if uf.union(u, v):
            mst_weight += weight
    return mst_weight
```
