# 并查集

## 定义

> **版本基准**: universal

并查集（Union-Find）是一种不相交集合（Disjoint Sets）数据结构，支持两种原子操作：
- **Find(x)**：确定元素 $x$ 所在集合的代表性元素（根）
- **Union(x, y)**：合并两个集合为一个集合

在带路径压缩和按秩合并的优化下，两种操作均摊时间为 $O(\alpha(n))$，其中 $\alpha$ 是 Ackermann 函数的反函数，实际值恒小于 5，可视为常数。

**本质**：并查集维护的是等价关系。Find 判断两个元素是否在同一等价类，Union 声明两个元素的等价性。

## 数学模型

### 集合表示：父指针森林

并查集使用父指针树表示集合。每棵树代表一个集合，树的根节点是集合的代表性元素。

对于元素 $x$，定义父指针 $parent[x]$：
- 若 $x$ 是根，则 $parent[x] = x$
- 否则 $parent[x]$ 是 $x$ 的父节点

**Find 操作的递归定义**

$$\text{Find}(x) = \begin{cases} x & \text{若 } parent[x] = x \\ \text{Find}(parent[x]) & \text{否则} \end{cases}$$

### 路径压缩

在 Find 返回根的过程中，将路径上所有节点的父指针直接指向根：
$$parent[x] \leftarrow \text{Find}(parent[x])$$

这使树高趋近于 1，后续 Find 操作直接 O(1)。

**路径压缩的几何直观**：将查找路径上的所有节点直接连接到根节点，使树变平。

### Union 操作的按秩合并

定义秩 $rank[x]$ 为树高的上界（近似 $\lfloor \log_2 n \rfloor$）。合并时：
- 若 $rank[root_x] < rank[root_y]$：令 $parent[root_x] = root_y$
- 若 $rank[root_x] > rank[root_y]$：令 $parent[root_y] = root_x$
- 若相等：任意一方为父，父的秩 +1

按秩合并保证树高 $h \leq \lfloor \log_2 n \rfloor$，因为只有当两棵树秩相同时树高才会增加。

**秩的物理含义**：秩不是真实的树高，而是树高的上界估计。使用上界而非真实高度，是因为真实高度需要在合并时计算（额外开销），而上界可以在不知道真实高度的情况下维护。

### 均摊复杂度：逆 Ackermann 函数

未优化的并查集最坏情况树高为 $n$，操作时间为 $O(n)$。

优化后（路径压缩 + 按秩合并），任意 $m$ 次操作序列的均摊时间为 $O(m \cdot \alpha(n))$。

Ackermann 函数 $A(n)$ 增长极快：
$$A(1) = 2, \quad A(2) = 4, \quad A(3) = 8, \quad A(4) = 2^{65536}$$

其反函数 $\alpha(n)$ 增长极慢：
$$\alpha(1) = 1, \quad \alpha(10^6) = 4, \quad \alpha(10^{80}) = 5$$

因此 $O(\alpha(n))$ 实际可视为 $O(1)$。

### 归约终点

并查集本质是维护等价关系的传递闭包。Find 判断两个元素是否在同一等价类，Union 声明两个元素的等价性。树结构是实现细节，可归约为集合论中的不相交集合合并问题。

**进一步归约**：等价关系是自反、对称、传递的关系。Union-Find 动态维护这个关系的传递闭包，支持增量合并和等价查询。

## 数据流

初始状态（5个独立元素）:
parent: [0, 1, 2, 3, 4]
rank:  [0, 0, 0, 0, 0]

Union(0, 1):
  Find(0)=0, Find(1)=1, rank[0]=rank[1]=0
  parent[1]=0, rank[0]=1
parent: [0, 0, 2, 3, 4]
rank:  [1, 0, 0, 0, 0]

Union(2, 3):
  Find(2)=2, Find(3)=3
  parent[3]=2, rank[2]=1
parent: [0, 0, 2, 2, 4]
rank:  [1, 0, 1, 0, 0]

Union(0, 2):
  Find(0)=0, Find(2)=2
  rank[0]=1, rank[2]=1, 相等
  parent[2]=0, rank[0]=2
parent: [0, 0, 0, 2, 4]
rank:  [2, 0, 1, 0, 0]

Find(3):
  parent[3]=2, parent[2]=0, parent[0]=0
  路径压缩: parent[3]=0
  返回 0
</pre>

**等价关系传递闭包**：

<pre>
操作序列: Union(0,1), Union(1,2), Union(3,4)
含义: 0~1, 1~2 ⇒ 0~2（传递）
     3~4（独立）

集合划分: {0,1,2}, {3,4}
Find(0)=0, Find(2)=0 → 同一集合
Find(3)=3, Find(4)=3 → 同一集合
Find(0)≠Find(3) → 不同集合
</pre>

## 机制

### 路径压缩与按秩合并的协同效应

两者结合的均摊分析是复杂的，但直观上：
- **路径压缩**：使查找路径上的节点直接连接到根，平摊树高
- **按秩合并**：控制树的生长方式，避免形成深树

**两者可独立实现且互补**：路径压缩改变树的形状但不影响秩，按秩合并控制树高但不改变已有路径的形状。

### 按秩合并为何有效

直觉：如果总是将大树接到小树下，树高可能变成 $O(n)$；按秩合并保证树高为 $O(\log n)$。

**形式化**：只有当两棵树秩相同时，合并后的秩才会增加。由于秩最多增加 $\lfloor \log_2 n \rfloor$ 次，树高必然不超过 $\lfloor \log_2 n \rfloor$。

### Kruskal 最小生成树算法中的应用

最小生成树（MST）的 Kruskal 算法：
1. 将所有边按权重升序排列
2. 依次遍历每条边 $(u, v)$
3. 若 $\text{Find}(u) \neq \text{Find}(v)$：选择该边，$\text{Union}(u, v)$

正确性：已选择的边不会形成环。每当 Find(u) ≠ Find(v) 时，$u$ 和 $v$ 在当前森林的不同树中，连接它们不会产生环，且是剩余边中权重最小的跨集合边。

**环检测**：若 $\text{Find}(u) = \text{Find}(v)$，边 $(u, v)$ 两端点已在同一集合，添加该边会在 MST 中形成环，应舍去。

### 连通分量计数

并查集的集合数量初始化为 $n$（每个元素独立）。每次成功的 Union 合并两个集合，集合数减一。当所有 Union 执行完毕后，集合数即为连通分量数。

**应用**：岛屿数量问题（LeetCode 200）中，遍历 grid，将遇到的每个 '1' 与其邻居 Union，最终的集合数就是岛屿数。

### 约束条件与违反后果

- **Union 操作必须保证传递性**：若 Union(A,B) 和 Union(B,C) 后 Find(A) = Find(C)。违反则传递闭包不成立，算法失效。
- **路径压缩必须在 Find 过程中实时执行**，否则树高不退化，均摊复杂度退化。
- **按秩合并必须使用真实的树高估计（秩）**，否则合并可能加剧树高增长。
- **Find 不能无限递归**：必须有终止条件（到达根节点），否则栈溢出。

## 参考存根

```python
class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, x):
        # 迭代版本（避免递归栈溢出）
        root = x
        while self.parent[root] != root:
            root = self.parent[root]
        # 路径压缩：将查找路径上的所有节点直接连接到根
        while self.parent[x] != root:
            next_x = self.parent[x]
            self.parent[x] = root
            x = next_x
        return root

    def union(self, x, y):
        rx, ry = self.find(x), self.find(y)
        if rx == ry:
            return False
        # 按秩合并：将秩小的接到秩大的下面
        if self.rank[rx] < self.rank[ry]:
            rx, ry = ry, rx
        self.parent[ry] = rx
        if self.rank[rx] == self.rank[ry]:
            self.rank[rx] += 1
        return True

# Kruskal 最小生成树
def kruskal(n, edges):
    edges.sort(key=lambda e: e[2])
    uf = UnionFind(n)
    mst = []
    for u, v, w in edges:
        if uf.union(u, v):
            mst.append((u, v, w))
            if len(mst) == n - 1:
                break
    return mst
```
