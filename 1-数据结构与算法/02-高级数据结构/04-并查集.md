# 并查集

> **版本基准**：universal —— 代码示例同时使用 Python 3.12 与 C++20

## 本质

并查集（Union-Find）维护**等价关系**：Find 判断两元素是否同一等价类，Union 声明两元素等价。用父指针森林表示——每棵树一个集合，根是代表元。带路径压缩 + 按秩合并时，两操作均摊 $O(\alpha(n))$ （$\alpha$ 是 Ackermann 反函数，实际恒 $<5$，视为常数）。

核心资源是**查找路径长度**——路径压缩和按秩合并都服务于把它压到极小。

## 数学模型

### 父指针森林与 Find

元素 $x$ 的父指针 $parent[x]$：根时 $parent[x]=x$，否则指向父节点。

$$\text{Find}(x)=\begin{cases}x & parent[x]=x \\ \text{Find}(parent[x]) & \text{否则}\end{cases}$$

### 路径压缩

Find 返回根时，把路径上所有节点父指针直接指向根： $parent[x]\leftarrow\text{Find}(parent[x])$。树高趋近 1，后续 Find 近 $O(1)$。几何直观：把查找路径整条"拉平"贴到根。

### 按秩合并

秩 $rank[x]$ 是树高上界（非真实高，因真实高合并时要重算、开销大）。合并两根 $root_x, root_y$：

- 秩小者接到秩大者下
- 秩相等：任一方为父，父的秩 $+1$

> **洞察**：只有两树秩相等时合并后秩才增加；而每次秩增加意味着等秩两树合并、节点数至少翻倍。故秩最多增 $\log_2 n$ 次，树高 $\le\lfloor\log_2 n\rfloor$。若总把大树接小树下，树高会变 $O(n)$——按秩合并正是堵这条路。

### 均摊复杂度：逆 Ackermann

未优化最坏树高 $n$、操作 $O(n)$。路径压缩 + 按秩合并后， $m$ 次操作均摊 $O(m\cdot\alpha(n))$。Ackermann 增长极快（$A(4)=2^{65536}$），反函数极慢： $\alpha(10^6)=4$， $\alpha(10^{80})=5$，故 $O(\alpha(n))$ 实际 $O(1)$。

> **洞察**：路径压缩平摊已有路径的树高，按秩合并控制新合并不长深树——一者治旧、一者防新，协同使操作代价几乎与 $n$ 无关。两者可独立实现、互补：压缩改形状不影响秩，按秩控高不改已有路径。

### 等价关系的传递闭包

并查集是**等价类划分**的数据结构实现：Union 合并划分，Find 查询划分。等价关系自反/对称/传递，Union-Find 动态维护其传递闭包，支持增量合并与等价查询。

## 数据流

<pre>
5 元素初始: parent=[0,1,2,3,4]  rank=[0,0,0,0,0]

Union(0,1): rank 相等 → parent[1]=0, rank[0]=1
Union(2,3): parent[3]=2, rank[2]=1
Union(0,2): rank[0]=rank[2]=1 相等 → parent[2]=0, rank[0]=2
  parent=[0,0,0,2,4]  rank=[2,0,1,0,0]

Find(3): 3→2→0，路径压缩 parent[3]=0，返回 0
  集合划分: {0,1,2,3}, {4}
</pre>

## 机制

### 路径压缩 + 按秩合并的协同

压缩治旧路径（拉平）、按秩防新合并（不长深树），协同把均摊压到 $\alpha(n)$。两者独立且互补。

### Kruskal 中的应用

边按权排序，依次取 $(u,v)$：若 $\text{Find}(u)\ne\text{Find}(v)$ 则选此边并 Union。Find 不等 ⇒ $u,v$ 在森林不同树 ⇒ 连接不形成环，且是剩余最小跨集合边（割性质保证最优）。Find 相等 ⇒ 两端已同集 ⇒ 加此边成环，舍去。

### 连通分量计数

集合数初始 $n$，每次成功 Union 减一，结束时即连通分量数。应用：岛屿数量（grid 遍历，'1' 与邻居 Union，最终集合数=岛屿数）。

### 约束与违反后果

| 约束 | 违反后果 |
|------|---------|
| Union 须保传递性 | 传递闭包不成立，算法失效 |
| 路径压缩须 Find 时实时做 | 树高不退化，均摊退化 |
| 按秩须用真实树高估计（秩） | 合并加剧树高增长 |
| Find 须有终止（到根） | 无限递归栈溢出 |

## 代码示例

**Python 3.12**：

```python
class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, x):
        # 迭代找根，避免递归栈溢出
        root = x
        while self.parent[root] != root:
            root = self.parent[root]
        # 路径压缩：路径上节点全指向根
        while self.parent[x] != root:
            self.parent[x], x = root, self.parent[x]
        return root

    def union(self, x, y):              # 已同集返回 False
        rx, ry = self.find(x), self.find(y)
        if rx == ry: return False
        if self.rank[rx] < self.rank[ry]: rx, ry = ry, rx   # 小接大
        self.parent[ry] = rx
        if self.rank[rx] == self.rank[ry]: self.rank[rx] += 1
        return True

# Kruskal MST
def kruskal(n, edges):
    edges.sort(key=lambda e: e[2])
    uf = UnionFind(n); mst = []
    for u, v, w in edges:
        if uf.union(u, v):
            mst.append((u, v, w))
            if len(mst) == n - 1: break
    return mst

# —— 简易输入输出 ——
uf = UnionFind(5)
uf.union(0, 1); uf.union(2, 3); uf.union(0, 2)
print(uf.find(1) == uf.find(3))   # True（同集 {0,1,2,3}）
print(uf.find(1) == uf.find(4))   # False
print(kruskal(4, [(0,1,1),(2,3,2),(1,3,3),(0,3,4)]))  # [(0,1,1),(2,3,2),(1,3,3)]
```

**C++20**：

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

struct UnionFind {
    std::vector<int> p, r;
    explicit UnionFind(int n) : p(n), r(n, 0) { for (int i=0;i<n;++i) p[i]=i; }
    int find(int x) {                          // 路径压缩（递归）
        return p[x]==x ? x : p[x]=find(p[x]);
    }
    bool unite(int x, int y) {                 // 已同集返回 false
        int rx=find(x), ry=find(y);
        if (rx==ry) return false;
        if (r[rx] < r[ry]) std::swap(rx, ry);   // 小接大
        p[ry] = rx;
        if (r[rx]==r[ry]) ++r[rx];
        return true;
    }
};

// Kruskal MST
std::vector<std::tuple<int,int,int>> kruskal(int n, std::vector<std::tuple<int,int,int>> edges) {
    std::sort(edges.begin(), edges.end(), [](auto& a, auto& b){ return std::get<2>(a) < std::get<2>(b); });
    UnionFind uf(n); std::vector<std::tuple<int,int,int>> mst;
    for (auto [u,v,w] : edges) if (uf.unite(u, v)) { mst.push_back({u,v,w}); if ((int)mst.size()==n-1) break; }
    return mst;
}

// —— 简易输入输出 ——
int main() {
    UnionFind uf(5);
    uf.unite(0,1); uf.unite(2,3); uf.unite(0,2);
    std::cout << std::boolalpha << (uf.find(1)==uf.find(3)) << ' '   // true
              << (uf.find(1)==uf.find(4)) << '\n';                    // false
    for (auto [u,v,w] : kruskal(4, {{0,1,1},{2,3,2},{1,3,3},{0,3,4}}))
        std::cout << u<<'-'<<v<<':'<<w<<' ';                         // 0-1:1 2-3:2 1-3:3
}
```
