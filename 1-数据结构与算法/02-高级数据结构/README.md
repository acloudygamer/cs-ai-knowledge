## 核心概念速查

### 区间查询数据结构

| 结构 | 查询 | 更新 | 空间 | 适用场景 |
|------|------|------|------|---------|
| 树状数组 | O(log n) | O(log n) | O(n) | 前缀和、单点更新 |
| 线段树 | O(log n) | O(log n) | O(4n) | 区间和、最大值、懒标记 |
| 稀疏表 | O(1) | O(n log n) | O(n log n) | 静态RMQ |
| 跳表 | O(log n) | O(log n) | O(n log n) | 有序序列、范围查询 |

### 平衡树对比

| 结构 | 平衡方式 | 实现难度 | 查询 | 插入/删除 |
|------|---------|---------|------|---------|
| AVL | 高度差≤1 | 中等 | O(log n) | O(log n) |
| 红黑树 | 颜色约束 | 复杂 | O(log n) | O(log n) |
| Treap | 随机优先级 | 简单 | O(log n) | O(log n) |
| 跳表 | 随机层高 | 简单 | O(log n) | O(log n) |

### 字符串索引

| 结构 | 构建时间 | 查询时间 | 空间 | 用途 |
|------|---------|---------|------|------|
| 后缀数组 | O(n log n) | O(m log n) | O(n) | 有序后缀、LCP |
| 后缀自动机 | O(n) | O(m) | O(n) | 子串查询、出现次数 |
| 前缀树 | O(nm) | O(m) | O(nm) | 前缀匹配 |
