# 图

> **版本基准**：universal —— 代码示例同时使用 Python 3.12 与 C++20

## 本质

图 $G=(V,E)$ 是顶点集加边集。有向边 $(u,v)$ 规定单向关系，无向边 $\{u,v\}$ 规定双向等价关系。图的核心操作是**路径查询**（连通？最短路？极值路？）和**结构探测**（连通分量、环、拓扑序）——本质是在离散结构上做组合优化。算法消耗的核心资源是**边遍历次数**（决定时间）和**邻接表/矩阵空间**。

## 数学模型

### 连通分量

$C\subseteq V$ 是极大连通子图，当 $\forall u,v\in C$ 存在 $u\leadsto v$ 路径。定义 $u\sim v \iff$ 存在 $u\leadsto v$，这是自反/对称/传递的等价关系，连通分量即其等价类。设分量数 $k$，则 $|E|\ge|V|-k$ （每分量至少一棵树）；等号时每分量都是无环连通的树。

### 最短路径（Dijkstra）

$$dist[v]=\min_{p\in P(s,v)}\sum_{e\in p}w(e)$$

**贪心不变量**：每步从优先队列弹出的节点 $u$，其 $dist[u]$ 已达全局最优。因为未弹出节点当前距离 $\ge dist[u]$，而边权非负保证没有更短路能绕过 $u$。

**正确性（反证）**：设弹出 $u$ 时存在更短的未定路径，该路径第一个未弹出节点 $x$ 的前驱 $y$ 已弹出，则 $dist[x]\ge dist[y]+w(y,x)>dist[u]$ （$dist[u]$ 最小），矛盾。

> **洞察**：Dijkstra 的非负边权是**贪心不变量的命门**——有负权边，已弹出节点可能被更短路径再次到达，"弹出即定"失效。负权得用 Bellman-Ford。

### 最小生成树（Kruskal）

生成树 $T\subseteq E$， $w(T)=\sum_{e\in T}w(e)$。Kruskal 贪心选不构成环的最小边。

- **割性质**：对任意割 $(S,V\setminus S)$，横跨该割的最小权边必属于某棵 MST。
- **环性质**：环中最大权边必不在任何 MST（删它换环上另一边代价不增）。

> **洞察**：Kruskal 每步选当前最小横跨边 + 并查集保不成环，割性质保证这个"局部最优"恰是"全局最优"。

### 拓扑排序（DAG）

拓扑序是 $V$ 的线性排列，使所有有向边 $(u,v)$ 满足 $u$ 在 $v$ 前。入度模型：不断取 $in(v)=0$ 的顶点。

**环检测**：若结束时处理顶点数 $<|V|$，则图含环——环上每点入度 $\ge 1$ 永不进队。本质是给 DAG 偏序找全序扩展（拓扑序可能不唯一）。

### Bellman-Ford（允许负权）

$$dist_{i+1}[v]=\min_{u\in pred(v)}(dist_i[u]+w(u,v))$$

迭代 $|V|-1$ 轮，第 $k$ 轮后 $dist[v]$ 是至多 $k$ 条边的最短路。若第 $|V|$ 轮仍有更新 → 存在可无限减距的负权环。

## 数据流

### BFS（层次遍历 = 无权最短路）

<pre>
邻接表: start→[a,b]  a→[c,d]  b→[d]  c→[goal]  d→[goal]  goal→[]

Level0: [start]         dist={start:0}
Level1: [a,b]           dist={a:1,b:1}
Level2: [c,d]           dist={c:2,d:2}
Level3: [goal]          dist={goal:3}

形态: 顶点 → 队列(层级快照) → dist 表
</pre>

FIFO 保证同层全先于下层处理，所以无权图第一次到达某点即最短路径。

### DFS（深度优先 + 回溯）

<pre>
visit(start): 标记 → for 邻居: 未访问则 visit(邻居)
执行: start→a→c→goal←c←a→b→d→goal←d←b←start
回溯靠递归栈帧保存(节点,邻居迭代位置)，栈深=递归深，空间 O(|V|)
</pre>

**BFS vs DFS**：BFS 横向（层）找无权最短路；DFS 纵向（深）找连通性/环/强连通分量。BFS 用队列存待访问，DFS 用调用栈。

### Dijkstra 执行流

<pre>
graph: s→[(a,4),(b,1)]  a→[(c,1)]  b→[(c,5)]  c→[]

dist={s:0}, pq=[(0,s)]
pop(0,s): relax a→4, b→1     push (4,a),(1,b)
pop(1,b): relax c→1+5=6       push (6,c)
pop(4,a): relax c→min(6,4+1)=5 update (5,c)
pop(5,c): 定

dist={s:0,b:1,a:4,c:5}
</pre>

松弛 relax：若经 $u$ 到 $v$ 更短则更新 $dist[v]$，每次 relax 保 $dist$ 是已发现路径的最小上界。

### Kruskal MST

<pre>
边排序: (1-2,1)(2-3,2)(1-3,3)(3-4,4)(2-4,6)
(1-2,1) find≠find → union, T=[1-2]
(2-3,2) find≠find → union, T=[1-2,2-3]
(1-3,3) find==find → 环,跳过
(3-4,4) find≠find → union, T=[1-2,2-3,3-4]
|T|=3=|V|-1 → 完成, 总代价 1+2+4=7
</pre>

### 拓扑排序（Kahn）

<pre>
边: 0→1,0→2,1→3,2→3,3→4   入度: in=[0,1,1,2,1]
取0 → in[1]=0,in[2]=0 → 队列[1,2], 输出[0]
取1 → in[3]=1           → 队列[2],   输出[0,1]
取2 → in[3]=0           → 队列[3],   输出[0,1,2]
取3 → in[4]=0           → 队列[4],   输出[0,1,2,3]
取4 →                              输出[0,1,2,3,4]
处理5=|V| → 无环
</pre>

## 对比参照

| 表示 | 空间 | 适用 |
|------|------|------|
| 邻接表 | $O(\|V\|+\|E\|)$ | 稀疏图、遍历 |
| 邻接矩阵 | $O(\|V\|^2)$ | 稠密图、 $O(1)$ 边查询 |

邻接表遍历邻居局部性好（连续访问）；邻接矩阵判相邻 $O(1)$ 但空间浪费大。

## 机制

### BFS 为什么第一次到达即最短

设 $s$ 到 $v$ 最短路 $k$ 跳。若有 $m>k$ 跳路径先到 $v$，则 $v$ 在第 $m$ 层才被发现，与 $k<m$ 矛盾——FIFO 的层次保证使然。

### Dijkstra 的失效与负权处理

非负边权是必要条件：负权边让已弹出节点可能被更短路再次到达，破坏"弹出即定"。负权用 Bellman-Ford（$|V|-1$ 轮松弛保无负环时最优）或 SPFA（队列动态更新，减不必要松弛）。

### Kruskal 的割/环性质

每次选最小横跨边 + 并查集保不环，二者结合恰构造 MST。MST 唯一性：边权全互异则唯一，否则可能多个。

### 拓扑排序的入度队列

入度 0 的点是"无前驱起始点"。环上每点入度 $\ge 1$ 永不进队，故结束时未处理完即有环。

### 违规后果

| 违规 | 后果 |
|------|------|
| Dijkstra 用于负权图 | 错误最短路或死循环（负环） |
| 拓扑排序漏判环 | DAG 假设破坏，结果无意义 |
| 邻接矩阵用于稀疏图 | $O(\|V\|^2)$ 空间/遍历浪费 |
| Kruskal 不排序边 | 贪心失效，非 MST |

## 代码示例

**Python 3.12**：

```python
import heapq
from collections import deque

# Dijkstra：优先队列 + 贪心松弛，跳过过期条目
def dijkstra(graph: dict, start) -> dict:
    dist = {start: 0}
    pq = [(0, start)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist.get(u, float('inf')):     # 过期条目跳过
            continue
        for v, w in graph.get(u, []):
            nd = d + w
            if nd < dist.get(v, float('inf')):
                dist[v] = nd
                heapq.heappush(pq, (nd, v))
    return dist

# BFS 层次遍历（无权图即最短路）
def bfs(graph: dict, start) -> list:
    visited = {start}
    q = deque([start])
    order = []
    while q:
        u = q.popleft(); order.append(u)
        for v in graph.get(u, []):
            if v not in visited:
                visited.add(v); q.append(v)
    return order

# Kahn 拓扑排序 + 环检测
def topo_sort(graph: dict) -> list | None:
    indeg = {v: 0 for v in graph}
    for u in graph:
        for v in graph[u]:
            indeg[v] += 1
    q = deque([v for v, d in indeg.items() if d == 0])
    order = []
    while q:
        u = q.popleft(); order.append(u)
        for v in graph[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)
    return order if len(order) == len(graph) else None   # None=有环

# 并查集（路径压缩 + 按秩合并）
class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n)); self.rank = [0] * n
    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])   # 路径压缩
        return self.parent[x]
    def union(self, x, y):                               # 已连通返回 False
        px, py = self.find(x), self.find(y)
        if px == py: return False
        if self.rank[px] < self.rank[py]: px, py = py, px
        self.parent[py] = px
        if self.rank[px] == self.rank[py]: self.rank[px] += 1
        return True

# Kruskal MST：边排序 + 并查集环检测
def kruskal(n, edges):
    edges.sort(key=lambda e: e[2])
    uf = UnionFind(n); mst = []
    for u, v, w in edges:
        if uf.union(u, v):
            mst.append((u, v, w))
            if len(mst) == n - 1: break
    return mst

# —— 简易输入输出 ——
g = {'s': [('a',4),('b',1)], 'a': [('c',1)], 'b': [('c',5)], 'c': []}
print(dijkstra(g, 's'))                       # {'s':0,'a':4,'b':1,'c':5}
print(bfs({'0':['1','2'],'1':['3'],'2':['3'],'3':[]}, '0'))  # ['0','1','2','3']
dag = {'0':['1','2'],'1':['3'],'2':['3'],'3':['4'],'4':[]}
print(topo_sort(dag))                         # ['0','1','2','3','4']
print(kruskal(4, [(0,1,1),(2,3,2),(1,3,3),(0,3,4),(1,2,6)]))  # [(0,1,1),(2,3,2),(1,3,3)]
```

**C++20**：

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <algorithm>

// Dijkstra（邻接表: {v,w}）
std::vector<long long> dijkstra(const std::vector<std::vector<std::pair<int,int>>>& g, int s) {
    const long long INF = 1e18;
    std::vector<long long> dist(g.size(), INF);
    std::priority_queue<std::pair<long long,int>, std::vector<std::pair<long long,int>>, std::greater<>> pq;
    dist[s] = 0; pq.push({0, s});
    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if (d > dist[u]) continue;                       // 过期跳过
        for (auto [v, w] : g[u]) if (d + w < dist[v]) { dist[v] = d + w; pq.push({dist[v], v}); }
    }
    return dist;
}

// BFS
std::vector<int> bfs(const std::vector<std::vector<int>>& g, int s) {
    std::vector<int> ord, vis(g.size(), 0);
    std::queue<int> q; q.push(s); vis[s] = 1;
    while (!q.empty()) {
        int u = q.front(); q.pop(); ord.push_back(u);
        for (int v : g[u]) if (!vis[v]) { vis[v] = 1; q.push(v); }
    }
    return ord;
}

// Kahn 拓扑排序，返回空表示有环
std::vector<int> topo_sort(const std::vector<std::vector<int>>& g, std::vector<int>& indeg) {
    std::queue<int> q;
    for (size_t i = 0; i < indeg.size(); ++i) if (indeg[i] == 0) q.push(i);
    std::vector<int> ord;
    while (!q.empty()) {
        int u = q.front(); q.pop(); ord.push_back(u);
        for (int v : g[u]) if (--indeg[v] == 0) q.push(v);
    }
    return ord.size() == g.size() ? ord : std::vector<int>{};
}

// 并查集
struct UnionFind {
    std::vector<int> p, r;
    UnionFind(int n) : p(n), r(n, 0) { for (int i=0;i<n;++i) p[i]=i; }
    int find(int x) { return p[x]==x ? x : p[x]=find(p[x]); }
    bool unite(int x, int y) {
        int px=find(x), py=find(y);
        if (px==py) return false;
        if (r[px] < r[py]) std::swap(px, py);
        p[py] = px; if (r[px]==r[py]) ++r[px];
        return true;
    }
};

// Kruskal
std::vector<std::tuple<int,int,int>> kruskal(int n, std::vector<std::tuple<int,int,int>> edges) {
    std::sort(edges.begin(), edges.end(), [](auto& a, auto& b){ return std::get<2>(a) < std::get<2>(b); });
    UnionFind uf(n); std::vector<std::tuple<int,int,int>> mst;
    for (auto [u,v,w] : edges) if (uf.unite(u, v)) { mst.push_back({u,v,w}); if ((int)mst.size()==n-1) break; }
    return mst;
}

// —— 简易输入输出 ——
int main() {
    std::vector<std::vector<std::pair<int,int>>> g = {{{1,4},{2,1}},{{3,1}},{{3,5}},{}};
    for (auto d : dijkstra(g, 0)) std::cout << d << ' ';   // 0 4 1 5
    std::cout << '\n';
    std::vector<std::vector<int>> bg = {{1,2},{3},{3},{}};
    for (int v : bfs(bg, 0)) std::cout << v << ' ';        // 0 1 2 3
    std::cout << '\n';
    auto mst = kruskal(4, {{0,1,1},{2,3,2},{1,3,3},{0,3,4},{1,2,6}});
    for (auto [u,v,w] : mst) std::cout << u<<'-'<<v<<':'<<w<<' ';  // 0-1:1 2-3:2 1-3:3
}
```
