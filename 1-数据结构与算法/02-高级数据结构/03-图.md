# 图

## 定义

> **版本基准**: universal

图 $G = (V, E)$ 是由顶点集合 $V$ 和边集合 $E$ 组成的有序对。有向边 $(u, v) \in E$ 规定从 $u$ 到 $v$ 的单向关系；无向边 $\{u, v\} \in E$ 规定 $u$ 与 $v$ 之间的双向等价关系。

**本质操作**：图的核心操作是**路径查询**（两点间是否存在路径、最短路径、极值路径）和**结构探测**（连通分量、环检测、拓扑序）。图算法本质上是在离散结构上做组合优化。

**有权图 vs 无权图**：权值将"路径长度"从跳数泛化为带权求和。最短路径问题从 BFS 的"最少跳数"变为"最小加权和"。

## 数学模型

### 连通分量（Connected Component）

设 $C \subseteq V$ 是 $V$ 的非空子集。若 $\forall u, v \in C$，存在 $u \leadsto v$ 路径，则 $C$ 是极大连通子图（连通分量）。无向图的连通分量划分将 $V$ 划分为不相交的等价类。

**等价关系视角**：定义关系 $u \sim v$ 当且仅当存在 $u \leadsto v$ 路径。这是自反、对称、传递的等价关系，连通分量即该等价关系的等价类。

### 最短路径（Dijkstra 算法）

设 $dist[v]$ 为从源点 $s$ 到顶点 $v$ 的最短路径长度。Dijkstra 贪心正确性的核心：

$$dist[v] = \min_{p \in P(s,v)} \sum_{e \in p} w(e)$$

其中 $P(s,v)$ 是 $s$ 到 $v$ 所有路径的集合。

**贪心不变量**：每步从优先队列弹出的节点 $u$ 满足 $dist[u]$ 已达到全局最小值。因为所有未弹出节点的当前距离 $\geq dist[u]$（优先队列按距离排序），而边权非负保证没有更短的路径能绕过 $u$ 到达 $u$。

**形式化证明框架**：
1. 初始化：$dist[s] = 0$，其他为 $\infty$ —— 不变量成立
2. 归纳：假设弹出 $u$ 前，不变量成立。$u$ 是未弹出节点中 $dist$ 最小的
3. 矛盾假设：存在另一条通过未弹出节点的路径比 $dist[u]$ 短
4. 该路径的第一个未弹出节点 $x$，其前驱 $y$ 已弹出，则 $dist[x] \geq dist[y] + w(y,x) > dist[u]$（因为 $dist[u]$ 最小）
5. 矛盾，所以 $dist[u]$ 已最优

### 最小生成树（Kruskal 算法）

设 $T \subseteq E$ 为生成树，$w(T) = \sum_{e \in T} w(e)$。Kruskal 贪心选择不构成环的最小边：

**割性质**：对任意割 $(S, V \setminus S)$，横跨该割的最小权边必属于某棵 MST。

**环性质**：环中权值最大的边必不在任何 MST 中（因为若它在 MST 中，删除它后环上另一条边可替换而代价不增）。

**正确性**：Kruskal 选择的边集是某棵 MST 的子集。设 $T$ 是最终选择的边集，$T_{opt}$ 是 MST。若某条边 $e \in T \setminus T_{opt}$，根据 MST 的割性质，$e$ 必是某割的最小边，因此可替换 $T_{opt}$ 中代价不小于 $e$ 的边而不增加总权重。

### 拓扑排序

设图 $G = (V, E)$ 是有向无环图（DAG）。拓扑序是 $V$ 的线性排列，使得所有有向边 $(u, v)$ 满足 $u$ 在 $v$ 之前。

**入度模型**：设 $in(v)$ 为顶点 $v$ 的入度。拓扑排序通过不断取出 $in(v) = 0$ 的顶点实现。

**环检测**：拓扑排序完成后，若处理顶点数 $|V'| < |V|$，则原图存在环（环内所有顶点入度 $> 0$，永远无法被取出）。

### Bellman-Ford 算法

允许负权边但无负权环的有向图最短路径：

$$dist_{i+1}[v] = \min_{u \in \text{pred}(v)} (dist_i[u] + w(u,v))$$

进行 $|V|-1$ 轮迭代。第 $k$ 轮后，$dist[v]$ 为至多 $k$ 条边的最短路径。

**负权环检测**：若第 $|V|$ 轮仍有更新，则存在可被无限减小距离的负权环。

## 数据流

### BFS 路径探索

<pre>
图结构（邻接表）:  start: [a, b]  →  a: [c, d]  →  b: [d]  →  ...
                    c: [goal]  →  d: [goal]  →  goal: []

BFS 队列执行:
Level 0: [start]           dist={start:0}
Level 1: [a, b]            dist={a:1, b:1}
Level 2: [c, d]            dist={c:2, d:2}
Level 3: [goal]            dist={goal:3}

数据形态变换:
顶点对象 → 队列状态（层级快照）→ dist 映射表
每步操作：队首出队 → 邻居入队 → 更新 dist
</pre>

**BFS 的队列语义**：FIFO 保证同一层的所有顶点在下一层顶点之前被处理，因此第一次到达某顶点的路径就是最短路径（无权图）。

### DFS 递归探索

<pre>
递归调用栈模拟 DFS:
visit(start):
    mark start
    for neighbor in adj[start]:
        if not visited:
            visit(neighbor)

执行流（深度优先）:
start → a → c → goal ← c ← a → b → d → goal ← d ← b ← start

回溯机制：递归栈展开返回父节点，继续探索未访问分支
栈深度 = 递归深度，空间 O(|V|)
</pre>

**DFS 的栈帧保存状态**：包括当前节点和邻居迭代位置，使得回溯后能恢复执行。这是 DFS 与 BFS 的本质区别——BFS 用队列保存待访问节点，DFS 用调用栈。

### Dijkstra 执行流

<pre>
输入: graph = {s: [(a,4), (b,1)], a: [(c,1)], b: [(c,5)], c: []}
      start = s

初始: dist = {s:0}, pq = [(0, s)]

Step 1: pop (0, s) → u=s, dist[s]=0 最小
        relax(s,a): dist[a]=min(∞,0+4)=4, push (4,a)
        relax(s,b): dist[b]=min(∞,0+1)=1, push (1,b)

Step 2: pop (1, b) → u=b, dist[b]=1
        relax(b,c): dist[c]=min(∞,1+5)=6, push (6,c)

Step 3: pop (4, a) → u=a, dist[a]=4
        relax(a,c): dist[c]=min(6,4+1)=5, update (5,c)

Step 4: pop (5, c) → u=c, dist[c]=5

结果: dist = {s:0, b:1, a:4, c:5}

数据形态: 顶点 → 优先队列（距离排序）→ dist 表（最短距离累积）
</pre>

### Kruskal MST 执行流

<pre>
边按权重排序: [(1,2,1), (2,3,2), (1,3,3), (3,4,4), (2,4,6)]

Step 1: edge(1,2,1) → find(1)≠find(2) → union → T=[(1,2)]
Step 2: edge(2,3,2) → find(2)≠find(3) → union → T=[(1,2),(2,3)]
Step 3: edge(1,3,3) → find(1)==find(3) → 环，跳过
Step 4: edge(3,4,4) → find(3)≠find(4) → union → T=[(1,2),(2,3),(3,4)]
Step 5: |T|=3=|V|-1 → 完成

并查集状态: {1,2,3} ∪ {4}  →  {1,2,3,4}
MST 总代价: 1+2+4=7
</pre>

### 拓扑排序执行流

<pre>
输入: DAG，边: (0,1), (0,2), (1,3), (2,3), (3,4)
入度: in[0]=0, in[1]=1, in[2]=1, in[3]=2, in[4]=1

Step 1: in[0]=0 → 队列 [0]，输出 []
Step 2: 取出 0，删除边 → in[1]=0, in[2]=0 → 队列 [1,2]，输出 [0]
Step 3: 取出 1，删除边 → in[3]=1 → 队列 [2]，输出 [0,1]
Step 4: 取出 2，删除边 → in[3]=0 → 队列 [3]，输出 [0,1,2]
Step 5: 取出 3，删除边 → in[4]=0 → 队列 [4]，输出 [0,1,2,3]
Step 6: 取出 4，输出 [0,1,2,3,4]

处理顶点数 = 5 = |V| → 无环，拓扑序唯一（如 [0,1,2,3,4]）
</pre>

## 机制

### BFS 的层次特性与最短路径

BFS 按"距离源点的跳数"分层遍历。对于无权图，从源点到任意顶点的第一条路径必是最短路径——因为任何其他到达该顶点的路径必定经过相同或更多的边。

**队列的 FIFO 语义保证层次顺序**：同一层的所有顶点先于下一层入队，先入队的先被处理，确保层内遍历的公平性。

### DFS 的深度优先与回溯

DFS 递归深入直到遇到终止条件（叶子节点或已访问节点），然后"回溯"到上一个分叉点继续探索。栈帧保存当前状态（节点、邻居迭代位置），使得回溯后能恢复执行。

**与 BFS 的本质区别**：BFS 横向探索（层），DFS 纵向探索（深度）。BFS 找最短路径（无权），DFS 找任一路径或检测连通性/环。

**DFS 的应用场景**：
- 连通分量检测
- 环检测（无向图用岛屿计数，有向图用拓扑排序）
- 强连通分量（Kosaraju、Tarjan 算法）
- 生成排列组合

### Dijkstra 的贪心条件与失效场景

**非负边权是必要条件**：若存在负权边，则已弹出的节点可能通过负权边被再次到达并更新更短距离，破坏"弹出时距离已确定"的贪心不变量。

**失效后果**：若边权为负，算法可能返回错误的最短路径或进入无限循环（若存在负权环则可无限减小距离）。

**负权处理**：使用 Bellman-Ford 或 SPFA（队列优化的 Bellman-Ford）。

### Kruskal 的割性质与环性质

**割性质**：对任意割 $(S, V \setminus S)$，横跨该割的最小权边必属于某棵 MST。

**环性质**：环中权值最大的边必不在任何 MST 中（因为若它在 MST 中，删除它后环上另一条边可替换而代价不增）。

Kruskal 每次选择的是当前最小权横跨边，同时维护不形成环的约束——两者结合恰好构造 MST。

### 拓扑排序的入度队列机制

入度为 0 的顶点是没有前驱的"起始点"。不断移除它们（删除出边，更新邻居入度）直到队列空。

**为什么这样能检测环**：环上的顶点入度至少为 1（环内每个顶点至少有一条入边来自环内），因此永远无法进入队列。拓扑排序完成后若还有顶点未被处理，图必含环。

### 邻接表 vs 邻接矩阵

| 表示 | 空间 | 适用场景 |
|------|------|---------|
| 邻接表 | $O(|V| + |E|)$ | 稀疏图，BFS/DFS |
| 邻接矩阵 | $O(|V|^2)$ | 稠密图，$O(1)$ 边查询 |

**数据局部性**：邻接表在遍历某顶点邻居时局部性更好（连续访问邻居）；邻接矩阵在判断两顶点是否相邻时 $O(1)$ 但空间浪费大。

```python
import heapq
from collections import deque

def dijkstra(graph: dict, start: str) -> dict:
    """Dijkstra 最短路径：优先队列 + 贪心 relax"""
    dist = {start: 0}
    pq = [(0, start)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist.get(u, float('inf')):      # 跳过过期条目
            continue
        for v, w in graph.get(u, []):
            nd = d + w
            if nd < dist.get(v, float('inf')):
                dist[v] = nd
                heapq.heappush(pq, (nd, v))
    return dist

def bfs(graph: dict, start: str) -> list:
    """BFS 层次遍历：队列保证 FIFO 层次顺序"""
    visited = {start}
    queue = deque([start])
    order = []
    while queue:
        u = queue.popleft()
        order.append(u)
        for v in graph.get(u, []):
            if v not in visited:
                visited.add(v)
                queue.append(v)
    return order

def topological_sort(graph: dict) -> list | None:
    """Kahn 算法拓扑排序：入度队列 + 环检测"""
    in_degree = {v: 0 for v in graph}
    for u in graph:
        for v in graph[u]:
            in_degree[v] += 1
    queue = deque([v for v, d in in_degree.items() if d == 0])
    order = []
    while queue:
        u = queue.popleft()
        order.append(u)
        for v in graph[u]:
            in_degree[v] -= 1
            if in_degree[v] == 0:
                queue.append(v)
    return order if len(order) == len(graph) else None  # None 表示有环
```

```python
class UnionFind:
    """并查集：Kruskal 的环检测数据结构"""
    def __init__(self, n: int):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, x: int) -> int:
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])  # 路径压缩
        return self.parent[x]

    def union(self, x: int, y: int) -> bool:
        """若 x 和 y 已连通返回 False，否则合并返回 True"""
        px, py = self.find(x), self.find(y)
        if px == py:
            return False
        if self.rank[px] < self.rank[py]:
            px, py = py, px
        self.parent[py] = px
        if self.rank[px] == self.rank[py]:
            self.rank[px] += 1
        return True

def kruskal(vertices: list, edges: list) -> list:
    """Kruskal MST：边排序 + 并查集环检测"""
    edges.sort(key=lambda x: x[2])  # 按权排序
    uf = UnionFind(len(vertices))
    mst = []
    for u, v, w in edges:
        if uf.union(u, v):
            mst.append((u, v, w))
            if len(mst) == len(vertices) - 1:
                break
    return mst
```
