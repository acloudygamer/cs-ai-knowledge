## 图

### 定义

图 $G = (V, E)$ 是顶点集合与边集合的有序对；有向边 $(u,v) \in E$ 规定方向，无向边 $\{u,v\}$ 无方向。

**数学模型**

- 连通分量：极大连通子图 $C \subseteq V$，$\forall u,v \in C$，存在 $u \leadsto v$ 路径
- 最短路径（Dijkstra）：$dist[v] = \min_{p \in P(s,v)} \sum_{e \in p} w(e)$，$P(s,v)$ 为 $s$ 到 $v$ 所有路径集合
- MST（Kruskal）：$w(T) = \sum_{e \in T} w(e)$ 最小，且 $|T| = |V|-1$、无环

**数据流**

```
BFS:     start → 层1邻居 → 层2邻居 → ... (队列入，层次出)
DFS:     start → 递归深入 → 回溯 → (栈入，递归出)

Dijkstra:
  dist[s]=0, 其余 ∞
  while pq 非空:
    弹出最小 dist 的 u
    对每条 (u,v,w): dist[v] = min(dist[v], dist[u]+w)
```

**机制**

Kruskal 按边权重升序处理，贪心选择不构成环的最小边——用并查集检测环，连通分量数降至 1 时完成。Dijkstra 依赖边的非负权重保证贪心正确性：每步弹出的最小 dist 节点必为全局最短路径的终点。拓扑排序用入度为 0 队列，队列空时若处理顶点数 < n 则存在环。

**参考存根**

```python
import heapq

def dijkstra(graph, start):
    dist = {start: 0}
    pq = [(0, start)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist.get(u, float('inf')): continue
        for v, w in graph.get(u, []):
            nd = d + w
            if nd < dist.get(v, float('inf')):
                dist[v] = nd
                heapq.heappush(pq, (nd, v))
    return dist
```
