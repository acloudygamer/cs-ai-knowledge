## 线段树与树状数组

### 定义

树状数组（Fenwick Tree）是以二进制分解为核心实现 $O(\log n)$ 前缀和与单点更新的数据结构；线段树以区间递归划分为核心，支持任意区间聚合与区间更新。

**数学模型**

树状数组核心运算——lowbit：

$$
\text{lowbit}(i) = i \ \& \ (-i)
$$

树状数组更新：向前缀方向累加 $\text{lowbit}(i)$；查询：向后缀方向累减 $\text{lowbit}(i)$

$$
\text{prefix\_sum}(i) = \sum_{k} A[k],\quad k \text{ 为 } i \text{ 二进制展开的 2 的幂分量}
$$

线段树区间和：$\text{sum}(l,r) = \text{sum}(l,\text{mid}) + \text{sum}(\text{mid}+1,r)$

**数据流**

<pre>
树状数组更新_add(5, delta):
  idx=5 → tree[5]+=delta → idx+=lowbit(5)=6
  idx=6 → tree[6]+=delta → idx+=lowbit(6)=8
  idx=8 → tree[8]+=delta → idx+=lowbit(8)=16 > n 结束

前缀和查询_prefix_sum(5):
  idx=5 → result+=tree[5] → idx-=lowbit(5)=4
  idx=4 → result+=tree[4] → idx-=lowbit(4)=0 结束
</pre>

**机制**

树状数组利用 $i = \sum 2^k$ 的二进制分解，将前缀和分解为 $O(\log n)$ 个树节点。线段树更通用：每个节点管辖一段区间，支持任意聚合（和/最大/最小）、区间更新、懒标记。树状数组常数更小但功能受限；线段树支持 $O(\log n)$ 区间更新（加差分后仍是 BIT 范围）。

**参考存根**

```python
class Fenwick:
    def __init__(self, n):
        self.n, self.tree = n, [0] * (n + 1)

    def add(self, idx, delta):
        while idx <= self.n:
            self.tree[idx] += delta
            idx += idx & -idx

    def sum(self, idx):
        s = 0
        while idx > 0:
            s += self.tree[idx]
            idx -= idx & -idx
        return s
```
