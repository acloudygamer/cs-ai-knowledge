# 跳表（Skip List）

### 解决什么问题
以 O(log n) 期望时间实现有序数组的查找、插入、删除，同时支持范围查询。实现比红黑树简单，适用于 Redis Sorted Set 等需要高效有序操作的场景。

### 核心概念
- 多层链表结构，每层是有序链表
- 随机层高决定节点在哪些层出现
- 查找时从高层开始，逐步缩小范围
- 期望查找/插入/删除：O(log n)

### 怎么用

## 基本结构

```
Level 2:  HEAD -> [1] ---------> [5] ---------> [9] -> NIL
Level 1:  HEAD -> [1] -> [3] -> [5] -> [7] -> [9] -> NIL
Level 0:  HEAD -> [1] -> [2] -> [3] -> [4] -> [5] -> [6] -> [7] -> [8] -> [9] -> NIL
```

每层都是有序链表，最底层包含所有元素，高层是快速通道。

## Python 实现

```python
import random

class SkipListNode:
    def __init__(self, val, max_level=16):
        self.val = val
        self.forward = [None] * max_level  # 每层的后继指针


class SkipList:
    """
    跳表实现
    - 查找: O(log n)
    - 插入: O(log n)
    - 删除: O(log n)
    - 空间: O(n)
    """

    def __init__(self, max_level=16):
        self.max_level = max_level
        self.header = SkipListNode(float('-inf'), max_level)
        self.level = 0  # 当前层数

    def _random_level(self):
        """随机生成层高，层数越高概率越小"""
        level = 1
        while random.random() < 0.5 and level < self.max_level:
            level += 1
        return level

    def _find(self, val):
        """查找元素，返回是否存在"""
        path = [None] * self.max_level  # 记录每层的前驱
        current = self.header

        # 从最高层开始查找
        for i in range(self.level - 1, -1, -1):
            while current.forward[i] and current.forward[i].val < val:
                current = current.forward[i]
            path[i] = current

        # 检查最底层
        if current.forward[0] and current.forward[0].val == val:
            return True, path, current.forward[0]
        return False, path, None

    def search(self, val):
        """查找元素"""
        found, _, node = self._find(val)
        return node if found else None

    def insert(self, val):
        """插入元素"""
        new_level = self._random_level()

        # 如果新节点层高大于当前层高，更新 header
        if new_level > self.level:
            for i in range(self.level, new_level):
                self.header.forward[i] = None
            self.level = new_level

        new_node = SkipListNode(val, new_level)

        _, path, _ = self._find(val)

        for i in range(new_level):
            new_node.forward[i] = path[i].forward[i]
            path[i].forward[i] = new_node

    def delete(self, val):
        """删除元素"""
        found, path, target = self._find(val)
        if not found:
            return False

        # 从所有层移除节点
        for i in range(self.level):
            if path[i].forward[i] == target:
                path[i].forward[i] = target.forward[i]

        # 调整层高
        while self.level > 1 and self.header.forward[self.level - 1] is None:
            self.level -= 1

        return True

    def range_query(self, left, right):
        """范围查询，返回 [left, right] 区间内的所有元素"""
        result = []
        _, _, start = self._find(left)

        if start is None:
            # 找到大于等于 left 的第一个元素
            current = self.header.forward[0]
            while current and current.val < left:
                current = current.forward[0]
        else:
            current = start

        while current and current.val <= right:
            result.append(current.val)
            current = current.forward[0]

        return result

    def __str__(self):
        """打印跳表结构"""
        result = []
        for i in range(self.level - 1, -1, -1):
            level_nodes = []
            current = self.header.forward[i]
            while current:
                level_nodes.append(str(current.val))
                current = current.forward[i]
            result.append(f"Level {i}: {' -> '.join(level_nodes)}")
        return '\n'.join(result)
```

## 与红黑树的对比

| 特性 | 跳表 | 红黑树 |
|------|------|--------|
| 实现复杂度 | 简单 | 复杂 |
| 查找复杂度 | O(log n) | O(log n) |
| 插入/删除 | O(log n) | O(log n) |
| 范围查询 | 容易 | 容易 |
| 空间复杂度 | O(n log n) | O(n) |
| 迭代顺序 | 自然有序 | 自然有序 |
| 并发性能 | 更好（锁粒度小） | 较差 |

## 典型应用

- Redis Sorted Set（ZADD, ZRANGE 等）
- LevelDB/MemTable 的 MemTable
- 替代红黑树作为有序数据结构

## 实战例题

### LeetCode 1206: 设计跳表

```python
class Skiplist:

    def __init__(self):
        self.MAX_LEVEL = 16
        self.header = SkipListNode(float('-inf'), self.MAX_LEVEL)
        self.level = 1

    def search(self, target: int) -> bool:
        current = self.header
        for i in range(self.MAX_LEVEL - 1, -1, -1):
            while current.forward[i] and current.forward[i].val < target:
                current = current.forward[i]
            if current.forward[i] and current.forward[i].val == target:
                return True
        return False

    def add(self, num: int) -> None:
        current = self.header
        update = [None] * self.MAX_LEVEL

        for i in range(self.MAX_LEVEL - 1, -1, -1):
            while current.forward[i] and current.forward[i].val < num:
                current = current.forward[i]
            update[i] = current

        level = 1
        while random.random() < 0.5 and level < self.MAX_LEVEL:
            level += 1

        new_node = SkipListNode(num, level)
        for i in range(level):
            new_node.forward[i] = update[i].forward[i]
            update[i].forward[i] = new_node

        self.level = max(self.level, level)

    def erase(self, num: int) -> bool:
        update = [None] * self.MAX_LEVEL
        current = self.header

        for i in range(self.MAX_LEVEL - 1, -1, -1):
            while current.forward[i] and current.forward[i].val < num:
                current = current.forward[i]
            update[i] = current

        if current.forward[0] is None or current.forward[0].val != num:
            return False

        target = current.forward[0]
        for i in range(self.MAX_LEVEL):
            if update[i].forward[i] == target:
                update[i].forward[i] = target.forward[i]

        return True
```
