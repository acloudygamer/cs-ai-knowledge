# 跳表

> **版本基准**：universal —— 代码示例同时使用 Python 3.12 与 C++20

## 本质

跳表是概率型有序结构：以有序链表为底层，上层以概率 $p$ 建立指向更远节点的快速通道，把搜索从 $O(n)$ 降到期望 $O(\log n)$。核心洞察是用**随机层高**模拟平衡树的平衡效果，却无需旋转维护——随机性替代确定性平衡，是空间换时间的经典工程折中。

与平衡树的本质区别：平衡树靠旋转维护**确定性**平衡（树高有最坏保证），跳表靠概率分布维护**期望**平衡（树高期望 $O(\log n)$ 但有极低退化概率）。

## 数学模型

### 随机层高（几何分布）

每新节点的层高 $h_i$ 服从几何分布（最大层高 $h_{\max}$ 常数上限，如 16/32）：

$$P(h_i=k)=p^{k-1}(1-p),\quad k=1,2,\ldots,h_{\max}$$

通常 $p=0.5$。物理含义：每"抛硬币"决定是否上扩一层，直到失败或达上限。期望层高 $E[h_i]=\frac{1}{1-p}$。

**第 $k$ 层节点数期望** $E[N_k]=n\cdot p^{k-1}$ （每节点独立有 $p^{k-1}$ 概率达第 $k$ 层）。

### 最大层高的集中性

层高随 $n$ 对数增长且高度集中：超过 $\lceil\log_{1/p} n\rceil + c$ 的概率随 $c$ 指数衰减——所以实现只需设一个常数层高上限（如 16/32）即可。

> **洞察**：几何分布让每升一层概率指数衰减，自然限住最大层高。若改用均匀分布（每节点等概率选 1..h 层），高层节点数期望不衰减，就退化为带冗余副本的普通链表。几何分布的指数衰减是跳表 $O(\log n)$ 的根基。

### 期望查找路径长度

从最高层起，每层期望遍历 $\frac{1}{p}$ 个节点（层内期望 $n\cdot p^{k-1}$，下降时减为 $p$ 倍）：

$$E[\text{查找长度}]=\sum_{k=1}^{h_{\max}}\frac{1}{p}=\frac{h_{\max}}{p}=O\!\left(\frac{\log n}{p}\right)=O(\log n)$$

> **洞察**：每向下一层节点数期望缩为 $p$ 倍，故每层只需遍历常数个节点（$p=0.5$ 时约 2 个），总长 $O(\log n)$。

## 数据流

### 多层结构与查找

<pre>
L3: HEAD ─────────────────────────────→ NIL
L2: HEAD ──→ [1] ────────→ [5] ──────→ NIL
L1: HEAD → [1] → [3] → [5] → [7] → [9] → NIL
L0: HEAD →[1]→[2]→[3]→[4]→[5]→[6]→[7]→[8]→[9]→NIL

查 7 (★标记遍历):
  L3: HEAD→★[1]→★NIL  (7>1, NIL>7, 下降)
  L2: ★[1]→★[5]       (7>5, 前进; 7<下一个, 下降)
  L1: ★[5]→★[7]       (命中)

每层先沿 forward 前进到目标右侧,再下降一层; 高层大步跳,底层精确
</pre>

### 插入

<pre>
插 8.5 (随机层高=2):
  1. 自顶向下找每层前驱 prev[0..2]
  2. 建新节点 [8.5], 层高 2
  3. 每层 prev[k].forward[k] ↔ new_node.forward[k] 接入

  prev[0]=7 → new 接在 7 与 8 之间
  prev[1]=5 → new 在 L1 接在 5 与 7 之间
</pre>

## 机制

### 为什么跳表比红黑树更适合并发

- **局部修改**：插入/删除只影响 $O(\log n)$ 个节点，每节点最多改 2 个指针（forward/backward）。红黑树旋转涉及父、祖父、叔多节点联动。
- **锁粒度**：多线程可对单节点加锁（乐观并发），删除只锁目标及前驱；红黑树要锁多祖先。
- **Redis 的选择**：Sorted Set 用跳表而非红黑树——实现更简单（无旋转）、代码量与 ziplist 相当、天然支持范围操作（ZRANGEBYSCORE）。

### 删除为何需要 backward 指针

跳表常实现为双向链表。删除时自底向上找前驱，每层让前驱 forward 绕过目标，并更新 backward。单向则无法快速改前驱 forward，须自顶重查或底层逐层锁定。

### 约束与违反后果

| 约束/违规 | 后果 |
|----------|------|
| 层高上限须固定 | 否则内存分配不可预测 |
| $p$ 影响时空权衡 | $p$ 大则层高期望大、空间增、查找可能更快； $p=0.5$ 典型 |
| $p=1$ （层高无限增长） | 退化为底层链表 + 多层冗余副本，空间爆炸 |
| 期望非最坏 | $O(\log n)$ 期望，极低概率退化（与红黑树最坏保证不同） |

### 跳表 vs 平衡树

| 维度 | 跳表 | 红黑树 |
|------|------|--------|
| 最坏查找 | $O(n)$ | $O(\log n)$ |
| 期望查找 | $O(\log n)$ | $O(\log n)$ |
| 插入/删除 | $O(\log n)$ 期望 | $O(\log n)$ 最坏 |
| 实现复杂度 | 低（无旋转） | 高（旋转+染色） |
| 并发友好 | 高（局部修改） | 低（跨节点锁） |
| 内存 | $O(n\cdot E[h_i])$ | $O(n)$ （指针开销小） |

## 代码示例

**Python 3.12**：

```python
import random

class SkipNode:
    def __init__(self, val, level):
        self.val = val
        self.forward = [None] * (level + 1)   # 每层后继指针

class SkipList:
    def __init__(self, max_level=16, p=0.5):
        self.max_level, self.p = max_level, p
        self.head = SkipNode(float('-inf'), max_level)
        self.level = 0

    def _random_level(self):                  # 几何分布层高
        lvl = 1
        while random.random() < self.p and lvl < self.max_level:
            lvl += 1
        return lvl

    def _find(self, val):                      # 返回每层前驱 + 命中节点
        prev = [None] * (self.max_level + 1)
        cur = self.head
        for i in range(self.level, -1, -1):
            while cur.forward[i] and cur.forward[i].val < val:
                cur = cur.forward[i]
            prev[i] = cur
        return prev, cur.forward[0]

    def search(self, val):
        _, node = self._find(val)
        return node is not None and node.val == val

    def insert(self, val):
        prev, _ = self._find(val)
        lvl = self._random_level()
        if lvl > self.level:                   # 更新最高层
            for i in range(self.level + 1, lvl + 1): prev[i] = self.head
            self.level = lvl
        node = SkipNode(val, lvl)
        for i in range(lvl + 1):               # 每层接入
            node.forward[i] = prev[i].forward[i]
            prev[i].forward[i] = node

# —— 简易输入输出 ——
sl = SkipList()
for v in [1, 3, 5, 7, 9, 2, 4, 6, 8]:
    sl.insert(v)
print(sl.search(7))   # True
print(sl.search(10))  # False
# 按序遍历底层
cur, out = sl.head.forward[0], []
while cur:
    out.append(cur.val); cur = cur.forward[0]
print(out)            # [1, 2, 3, 4, 5, 6, 7, 8, 9]
```

**C++20**：

```cpp
#include <iostream>
#include <vector>
#include <random>
#include <limits>

struct SkipNode {
    int val;
    std::vector<SkipNode*> forward;
    SkipNode(int v, int level) : val(v), forward(level + 1, nullptr) {}
};

class SkipList {
    int max_level, level = 0;
    double p;
    SkipNode head;
    std::mt19937 rng{std::random_device{}()};
    std::uniform_real_distribution<double> uni{0.0, 1.0};

    int random_level() {                      // 几何分布层高
        int lvl = 1;
        while (uni(rng) < p && lvl < max_level) ++lvl;
        return lvl;
    }
    std::vector<SkipNode*> find(int val, SkipNode*& after) {
        std::vector<SkipNode*> prev(max_level + 1, nullptr);
        SkipNode* cur = &head;
        for (int i = level; i >= 0; --i) {
            while (cur->forward[i] && cur->forward[i]->val < val) cur = cur->forward[i];
            prev[i] = cur;
        }
        after = cur->forward[0];
        return prev;
    }
public:
    SkipList(int ml = 16, double prob = 0.5) : max_level(ml), p(prob), head(std::numeric_limits<int>::min(), ml) {}

    bool search(int val) {
        SkipNode* after; find(val, after);
        return after && after->val == val;
    }
    void insert(int val) {
        SkipNode* after;
        auto prev = find(val, after);
        int lvl = random_level();
        if (lvl > level) { for (int i = level + 1; i <= lvl; ++i) prev[i] = &head; level = lvl; }
        SkipNode* node = new SkipNode(val, lvl);
        for (int i = 0; i <= lvl; ++i) { node->forward[i] = prev[i]->forward[i]; prev[i]->forward[i] = node; }
    }
    std::vector<int> to_sorted() {            // 底层遍历得升序
        std::vector<int> out; SkipNode* cur = head.forward[0];
        while (cur) { out.push_back(cur->val); cur = cur->forward[0]; }
        return out;
    }
};

// —— 简易输入输出 ——
int main() {
    SkipList sl;
    for (int v : {1,3,5,7,9,2,4,6,8}) sl.insert(v);
    std::cout << std::boolalpha << sl.search(7) << ' ' << sl.search(10) << '\n';  // true false
    for (int v : sl.to_sorted()) std::cout << v << ' ';                           // 1 2 3 4 5 6 7 8 9
}
```
