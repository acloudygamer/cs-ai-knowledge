## 跳表

### 定义

跳表是按层组织的有序链表，每层是下层的快速通道，查找从最高层出发逐步降至最底层，期望 $O(\log n)$ 完成。

**数学模型**

设层高为随机变量，每次升至下一层概率为 $p$（通常 $p = 0.5$），最大层高 $h_{\max} = \lceil \log_{1/p} n \rceil$。

第 $k$ 层节点数期望：$n \cdot p^k$

期望查找路径长度：$O(1/p) \cdot \log_{1/p} n = O(\log n)$

**数据流**

<pre>
Level 2:  HEAD ──→ [1] ────────→ [5] ────────→ [9] → NIL
Level 1:  HEAD → [1] → [3] → [5] → [7] → [9] → NIL
Level 0:  HEAD → [1] → [2] → [3] → [4] → [5] → [6] → [7] → [8] → [9] → NIL

查找 7:
  L2: 1 → 9 (7 < 9, 停留在 1)
  L1: 1 → 3 → 5 → 7 (找到)
</pre>

**机制**

跳表以随机层高代替平衡旋转，比红黑树实现简单。Redis Sorted Set 用跳表实现，支持 ZADD（插入）、ZRANGE（范围查询）$O(\log n)$。并发场景下跳表优于红黑树：修改操作只影响局部节点，锁粒度小。

**参考存根**

```python
import random

class SkipList:
    def __init__(self, max_level=16):
        self.hdr = [None] * max_level
        self.level = 1

    def search(self, target):
        cur = self.hdr
        for i in range(self.level - 1, -1, -1):
            while cur[i] and cur[i].val < target:
                cur = cur[i]
        return cur[0] and cur[0].val == target
```
