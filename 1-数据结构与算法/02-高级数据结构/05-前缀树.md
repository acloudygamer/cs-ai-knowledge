# 前缀树

> **版本基准**：universal —— 代码示例同时使用 Python 3.12 与 C++20

## 本质

前缀树（Trie，来自 "re**trie**val"）是存储字符串集合的有序树：根到某节点的路径对应一个字符串前缀，每个节点标记"从根到这里是否构成完整词"。核心操作是**前缀查询**——给定 $p$ 找出所有以 $p$ 为前缀的词。

通过**前缀共享**，前缀树做 $O(|p|)$ 的前缀匹配，插入和查询都与字符串长度成正比、与词库大小无关。代价是内存（节点+边数）；无公共前缀时空间优势消失。

## 数学模型

### 形式定义

$$T=(V, E, \Sigma, r)$$

- $V$ 节点集，根到 $v$ 的路径对应字符串 $s(v)$
- $\Sigma$ 字符集（大小 $\sigma$）
- $E\subseteq V\times\Sigma\times V$ 有标签边，每条边标签是单字符
- $r\in V$ 根， $s(r)=\epsilon$
- $\text{children}(v)\subseteq\Sigma\times V$，**单射**（同节点出边字符不重复）⇒ 每字符串在树中路径唯一
- $\text{isEnd}(v)\in\{\top,\bot\}$ 标记 $v$ 是否某完整词终点

### 空间复杂度

最坏（无公共前缀） $|V|=\sum_i|s_i|$。两种实现权衡：

- **字典实现**（边存字符指针，如 dict）：空间 $O(|V|)$，访问 $O(1)$ 需哈希计算。
- **数组实现**（固定字符集，每节点大小 $\sigma$ 数组存子指针）：空间 $O(|V|\cdot\sigma)$，访问 $O(1)$ 无哈希开销。

**压缩前缀树（Patricia Trie / Radix Tree）**：把单子节点链压成一条边、节点存多字符，省空间但实现复杂。

### 时间复杂度

| 操作 | 时间 | 说明 |
|------|------|------|
| insert(s) | $O(\|s\|)$ | 沿路径逐字符创建或前进 |
| search(s) | $O(\|s\|)$ | 沿路径匹配，判 isEnd |
| prefix(p) | $O(\|p\|+output)$ | 定位前缀节点后遍历子树 |

> **洞察**：前缀查询时间取决于**输出规模**而非输入规模——这是前缀树相对哈希表的本质优势：哈希表 $O(1)$ 查整词，但前缀查询只能穷举，而 Trie 天然按前缀聚合。

## 数据流

### insert("cat")

<pre>
root → 'c' → node_c → 'a' → node_a → 't' → node_t(isEnd=True)

每步: 当前节点无该字符子边则新建，前进到子节点，末节点置 isEnd
内存: 每节点 {children: {char: node}, is_end: bool}
</pre>

### search("car") 失败

<pre>
root→'c'(有)→'a'(有)→'r'(无) → 失败返回 False
即使前缀 "ca" 在树中，完整词 "car" 不在。
</pre>

### prefix("ca")

<pre>
root→'c'→'a' 到 node_a（"ca" 前缀终点，isEnd=False）
从 node_a DFS 子树: →'t'→ node_t(isEnd) 输出 "cat"
收集所有 isEnd=True 节点对应串 → ["cat"]
</pre>

### Trie vs 哈希表

<pre>
            插入/查询      前缀查询          内存
Trie       O(|s|)        O(|p|+k)         O(Σ|s_i|)
哈希表     O(|s|)均摊    O(总词数)穷举     O(Σ|s_i|)

k = 以 p 为前缀的词数
</pre>

## 机制

### 公共前缀的空间复用

"car" 和 "cat" 共享 'c'→'a' 段只存一份——对朴素存储（每词独立存串）的根本优势。最坏（词库 ["a".."z"] 无公共前缀）节点数=字符总数，空间与哈希表相当，但数组实现每节点有 $\sigma$ 槽位。

### 字符集过大时的空间爆炸

$\Sigma$ 为 Unicode 时每节点子字典大却多空。数组实现空槽率 $1-k/\sigma$ （$k$ 平均子数， $k\ll\sigma$）， $\sigma$ 大则浪费严重。对策：压缩 Trie（合并单子链）、双数组 Trie（两数组表示转移函数、 $O(1)$ 转移无空槽）、FSA 紧凑表示。

### isEnd 标记的语义

只标记"该节点是某完整词终点"，非路径独占。"a"和"ab"共存时，'a' 节点 isEnd=True、'b' 节点（经 'a'）isEnd=True。

**常见错误**：只查目标节点 isEnd 而忽略前缀本身可能是完整词；查 "a" 而树中只有 "ab" 应返回 False。

### 前缀搜索的完整性

以 $v$ 为根的子树含所有以 $s(v)$ 为前缀的词。前缀搜索必须遍历整棵子树——无法剪枝，因所有分支都可能含有效词。大规模词库可按子树大小或词频做启发式。

### 约束与违反后果

| 违规 | 后果 |
|------|------|
| 字符集过大且词少 | 空间/时间可能劣于哈希表 |
| isEnd 标记错（完整词未设） | search 漏输出；prefix 可能误含祖先 isEnd |
| 单射约束破坏（同父多子同字符） | 路径不唯一，search 不确定 |

## 代码示例

**Python 3.12**：

```python
class TrieNode:
    __slots__ = ('children', 'is_end')
    def __init__(self):
        self.children = {}              # char -> TrieNode
        self.is_end = False             # 是否某完整词终点

class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word):
        node = self.root
        for ch in word:                 # 逐字符深入，无则建
            if ch not in node.children:
                node.children[ch] = TrieNode()
            node = node.children[ch]
        node.is_end = True

    def search(self, word):             # 完整词：找到节点且 is_end
        node = self._walk(word)
        return node is not None and node.is_end

    def starts_with(self, prefix):     # 前缀存在：走到即可
        return self._walk(prefix) is not None

    def _walk(self, s):                 # 沿 s 走，断链返回 None
        node = self.root
        for ch in s:
            if ch not in node.children: return None
            node = node.children[ch]
        return node

    def collect_prefix_words(self, prefix):   # 收集所有以 prefix 为前缀的词
        node = self._walk(prefix)
        if node is None: return []
        out = []
        self._dfs(node, prefix, out)
        return out

    def _dfs(self, node, path, out):
        if node.is_end: out.append(path)
        for ch, child in node.children.items():
            self._dfs(child, path + ch, out)

# —— 简易输入输出 ——
t = Trie()
for w in ["cat", "car", "card", "dog"]:
    t.insert(w)
print(t.search("cat"))            # True
print(t.search("ca"))             # False（前缀存在但非完整词）
print(t.starts_with("ca"))        # True
print(sorted(t.collect_prefix_words("ca")))  # ['car', 'card', 'cat']
```

**C++20**：

```cpp
#include <iostream>
#include <unordered_map>
#include <vector>
#include <string>
#include <string_view>
#include <algorithm>

struct TrieNode {
    std::unordered_map<char, TrieNode*> children;
    bool is_end = false;
};

class Trie {
    TrieNode root;
    TrieNode* walk(std::string_view s) {        // 沿 s 走，断链返回 nullptr
        TrieNode* n = &root;
        for (char c : s) {
            auto it = n->children.find(c);
            if (it == n->children.end()) return nullptr;
            n = it->second;
        }
        return n;
    }
    void dfs(TrieNode* n, std::string& path, std::vector<std::string>& out) {
        if (n->is_end) out.push_back(path);
        for (auto& [c, child] : n->children) {
            path.push_back(c);
            dfs(child, path, out);
            path.pop_back();
        }
    }
public:
    void insert(std::string_view word) {
        TrieNode* n = &root;
        for (char c : word) {
            auto& [it, _] = n->children.emplace(c, nullptr);
            if (!it->second) it->second = new TrieNode();
            n = it->second;
        }
        n->is_end = true;
    }
    bool search(std::string_view word) {
        TrieNode* n = walk(word);
        return n && n->is_end;
    }
    bool starts_with(std::string_view prefix) { return walk(prefix) != nullptr; }
    std::vector<std::string> collect_prefix_words(std::string_view prefix) {
        TrieNode* n = walk(prefix);
        if (!n) return {};
        std::vector<std::string> out;
        std::string p{prefix};
        dfs(n, p, out);
        return out;
    }
};

// —— 简易输入输出 ——
int main() {
    Trie t;
    for (auto w : {"cat", "car", "card", "dog"}) t.insert(w);
    std::cout << std::boolalpha
              << t.search("cat") << ' '       // true
              << t.search("ca") << ' '        // false
              << t.starts_with("ca") << '\n'; // true
    auto words = t.collect_prefix_words("ca");
    std::sort(words.begin(), words.end());
    for (auto& w : words) std::cout << w << ' ';   // car card cat
}
```
