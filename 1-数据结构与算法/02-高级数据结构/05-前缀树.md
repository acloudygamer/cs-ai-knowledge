## 前缀树

### 定义

前缀树（Trie）是存储字符串集合的有序树，从根到某节点的路径对应一个字符串前缀，所有节点按字符键组织。

**数学模型**

$$
T = (V, E, \Sigma, r)
$$

- $V$：节点集合，$|V| = O(\sum |s_i|)$
- $\Sigma$：字符集
- $\text{children}(v) \subseteq \Sigma \times V$：单射
- $\text{isEnd}(v) \in \{\text{T},\text{F}\}$

操作复杂度：$\text{insert}(s) = O(|s|)$，$\text{search}(s) = O(|s|)$，$\text{prefix}(p) = O(|p|)$

**数据流**

<pre>
insert("cat"):
  c→a→t (创建三个节点，t.isEnd = true)

search("car"):
  c→a→r (r.isEnd = false → 不存在)

starts_with("ca"):
  c→a (存在 → true)
</pre>

**机制**

公共前缀只存储一次，空间复用。isEnd 标记单词边界，可附加计数实现 MapSum。设计约束：字符集过大会导致空间爆炸；稀疏字符集适合哈希表而非 Trie。

**参考存根**

```python
class TrieNode:
    def __init__(self):
        self.children = {}
        self.is_end = False

class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word):
        node = self.root
        for c in word:
            if c not in node.children:
                node.children[c] = TrieNode()
            node = node.children[c]
        node.is_end = True
```
