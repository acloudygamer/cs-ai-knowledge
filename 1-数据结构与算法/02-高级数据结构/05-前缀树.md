# 前缀树 (Trie)

### 解决什么问题
高效处理字符串前缀查询，适用于自动补全、词典搜索、IP路由最长前缀匹配等场景，查找/插入复杂度为 O(m)，m 为字符串长度。

### 核心概念
- 节点存储字符和子节点指针，根节点不存储字符
- 公共前缀只存储一次，空间效率高
- 每个节点可标记是否为单词结尾
- 可存储额外信息（如计数、前缀数量）

### 怎么用

## 基本实现

```python
class TrieNode:
    """前缀树节点"""
    def __init__(self):
        self.children = {}          # 字符 -> 子节点
        self.is_end = False         # 是否为单词结尾
        self.word_count = 0          # 以此节点结尾的单词数量


class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word):
        """插入一个单词"""
        node = self.root
        for char in word:
            if char not in node.children:
                node.children[char] = TrieNode()
            node = node.children[char]
        node.is_end = True
        node.word_count += 1

    def search(self, word):
        """精确查找一个单词"""
        node = self._find_node(word)
        return node is not None and node.is_end

    def starts_with(self, prefix):
        """查找是否有以 prefix 为前缀的单词"""
        return self._find_node(prefix) is not None

    def _find_node(self, prefix):
        """找到 prefix 对应的节点，不存在返回 None"""
        node = self.root
        for char in prefix:
            if char not in node.children:
                return None
            node = node.children[char]
        return node

    def delete(self, word):
        """删除一个单词"""
        def _delete(node, word, depth):
            if depth == len(word):
                if not node.is_end:
                    return False
                node.is_end = False
                node.word_count -= 1
                # 如果没有子节点，可以删除（可选优化）
                return len(node.children) == 0

            char = word[depth]
            if char not in node.children:
                return False

            child = node.children[char]
            should_delete_child = _delete(child, word, depth + 1)

            if should_delete_child:
                del node.children[char]
                return len(node.children) == 0 and not node.is_end

            return False

        if not self.search(word):
            return  # 单词不存在
        _delete(self.root, word, 0)
```

## 统计前缀

```python
class TrieWithPrefixCount(Trie):
    """带前缀计数的前缀树"""

    def __init__(self):
        super().__init__()
        # 根节点的 prefix_count 表示所有单词的总数
        self.root.prefix_count = 0

    def insert(self, word):
        node = self.root
        node.prefix_count += 1
        for char in word:
            if char not in node.children:
                node.children[char] = TrieNode()
            node = node.children[char]
            node.prefix_count += 1
        node.is_end = True
        node.word_count += 1

    def count_prefix(self, prefix):
        """返回以 prefix 为前缀的单词数量"""
        node = self._find_node(prefix)
        return node.prefix_count if node else 0

    def count_words_equal(self, word):
        """返回完全等于 word 的单词数量"""
        node = self._find_node(word)
        return node.word_count if node else 0
```

## 实战例题

### 1. 单词替换（LeetCode 648）

```python
def replace_words(dict, sentence):
    """
    将句子中的单词用最短词根替换
    dict = ["cat","bat","rat"]
    sentence = "the cattle was rattled by the battery"
    输出: "the cat was rat by the bat"
    """
    trie = Trie()

    # 插入所有词根
    for root in dict:
        trie.insert(root)

    def find_shortest_root(word):
        """找到单词的最短词根"""
        node = trie.root
        path = []
        for char in word:
            if char not in node.children:
                break
            node = node.children[char]
            path.append(char)
            if node.is_end:  # 找到词根
                return ''.join(path)
        return word  # 没找到，返回原词

    # 处理句子
    words = sentence.split()
    result = [find_shortest_root(w) for w in words]
    return ' '.join(result)
```

### 2. 键值映射（LeetCode 677）

```python
class MapSum:
    """
    实现一个 MapSum 类，支持：
    - insert(key, val)：插入键值对
    - sum(prefix)：返回所有以 prefix 开头的键的值之和
    """

    def __init__(self):
        self.root = TrieNode()
        self.root.val = 0

    def insert(self, key, val):
        node = self.root
        for char in key:
            if char not in node.children:
                node.children[char] = TrieNode()
            node = node.children[char]
        node.val = val

    def sum(self, prefix):
        node = self.root
        for char in prefix:
            if char not in node.children:
                return 0
            node = node.children[char]
        # DFS 累加所有以 prefix 为根的子树的值
        return self._dfs_sum(node)

    def _dfs_sum(self, node):
        total = node.val
        for child in node.children.values():
            total += self._dfs_sum(child)
        return total
```

### 4. 向前缀树插入数字（LeetCode 677 变体）

```python
class MapSumNode:
    """MapSum专用节点"""
    def __init__(self):
        self.children = {}
        self.is_end = False
        self.val = 0
        self.sum = 0  # 该节点为根的子树所有值的和


class MapSum:
    def __init__(self):
        self.root = MapSumNode()

    def insert(self, key, val):
        node = self.root
        for char in key:
            if char not in node.children:
                node.children[char] = MapSumNode()
            node = node.children[char]
            node.sum += val  # 更新子树和
        node.is_end = True
        node.val = val

    def sum(self, prefix):
        node = self.root
        for char in prefix:
            if char not in node.children:
                return 0
            node = node.children[char]
        return node.sum
```

## Trie vs 哈希表

| 特性 | Trie | 哈希表 |
|------|------|--------|
| 查找 | O(m) | O(1) 平均 |
| 空间 | O(Σm) | O(n) |
| 前缀查询 | O(1) 支持 | 需要扫描 |
| 排序 | 按字典序 | 不支持 |
| 内存 | 较大（稀疏） | 较小 |
| 适用 | 前缀问题、自动补全 | 精确查找 |

## 复杂度分析

| 操作 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 插入 | O(m) | O(m) 最坏 |
| 查找 | O(m) | O(1) |
| 前缀匹配 | O(m) | O(1) |
| 删除 | O(m) | O(1)（如释放节点） |

m 为字符串/前缀长度，n 为字符串数量。
