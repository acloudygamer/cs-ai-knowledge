# 前缀树

## 定义

> **版本基准**: universal

前缀树（Trie，来自 "re**trie**val"）是存储字符串集合的有序树形结构。树的根到某节点的路径对应一个字符串前缀，所有节点按字符键组织，每个节点记录从根到该节点的字符串是否是一个完整单词。前缀树的核心操作是**前缀查询**：给定字符串 $p$ ，找出所有以 $p$ 为前缀的词。 ，找出所有以 $p$ 为前缀的词。 为前缀的词。

**本质操作**：前缀树通过前缀共享实现 $O(|p|)$ 的前缀匹配，其中 $|p|$ 是前缀长度。插入和查询都与字符串长度成正比，与词库大小无关。 的前缀匹配，其中 $|p|$ 是前缀长度。插入和查询都与字符串长度成正比，与词库大小无关。 是前缀长度。插入和查询都与字符串长度成正比，与词库大小无关。

**资源视角**：前缀树消耗的核心资源是**内存**（节点数和边数）。前缀共享减少了冗余存储，但当字符串无公共前缀时，空间优势消失。

## 数据流

### insert("cat") 节点创建过程

<pre>
初始状态: root (isEnd=False, 无子节点)

Step 1: 插入 'c'
  root --'c'--> node_c (新建, isEnd=False)
  t[0] = node_c

Step 2: 插入 'a'
  node_c --'a'--> node_a (新建, isEnd=False)
  t[1] = node_a

Step 3: 插入 't'
  node_a --'t'--> node_t (新建, isEnd=True)
  t[2] = node_t

内存布局:
root: {isEnd: False, children: {'c': node_c}}
node_c: {isEnd: False, children: {'a': node_a}}
node_a: {isEnd: False, children: {'t': node_t}}
node_t: {isEnd: True, children: {}}

所有权转移: 字符串 "cat" 的字符所有权按序被树边吸收，节点持有字符引用
</pre>

### search("car") 失败路径

<pre>
Step 1: 从 root 沿 'c' 边到 node_c (存在)
Step 2: 从 node_c 沿 'a' 边到 node_a (存在)
Step 3: 从 node_a 沿 'r' 边 → children['r'] 不存在！
  → search 失败，返回 False

即使路径 "car" 的前缀 "ca" 存在于树中，完整词不存在。
</pre>

### prefix("ca") 成功 + 子树遍历

<pre>
Step 1: 从 root 沿 'c','a' 到 node_a
Step 2: node_a.isEnd = False，但它是 "ca" 前缀的终点
Step 3: 从 node_a 出发 DFS/BFS 遍历所有可达节点
  node_a --'t'--> node_t (isEnd=True, 输出 "cat")
  收集所有 isEnd=True 的节点对应字符串 → ["cat"]
</pre>

## 机制

### 公共前缀的空间复用

相同前缀的词共享树路径，插入 "car" 和 "cat" 时，'c'→'a' 段只存储一份。这是对朴素存储（每词独立存字符串）的根本优势，但当字符串无公共前缀时，空间优势消失。

**最坏情况**：词库为 ["a", "b", "c", ..., "z"]（无公共前缀），则节点数等于字符总数，空间与哈希表相当，但每个节点有 $\sigma$ 个潜在槽位（若是数组实现）。 个潜在槽位（若是数组实现）。

### isEnd 标记的语义

仅标记该节点是否是某完整词的终点，而非路径独占。例如 "a" 和 "ab" 共存时，节点 'a' 的 isEnd=True，节点 'b'（经 'a'）的 isEnd=True。

**常见错误**：只检查目标节点的 isEnd 而忽略前缀本身可能是完整词。例如查询 "a" 而树中只有 "ab" 时，应返回 False。

### 前缀搜索的完整性

以节点 $v$ 为根的子树包含所有以 $s(v)$ 为前缀的词。前缀搜索必须遍历整棵子树——无法利用任何剪枝，因为所有分支都可能包含有效词。 为根的子树包含所有以 $s(v)$ 为前缀的词。前缀搜索必须遍历整棵子树——无法利用任何剪枝，因为所有分支都可能包含有效词。 为前缀的词。前缀搜索必须遍历整棵子树——无法利用任何剪枝，因为所有分支都可能包含有效词。

**优化方向**：对于大规模词库，可对子树大小做剪枝，或使用启发式搜索（如按词频排序）。

### 约束与违反后果

- **字符集过大（Unicode）且词数少时**：空间/时间效率可能劣于哈希表
- **isEnd 标记错误**：某完整词未设 isEnd → search 不会输出该词，但 prefix 可能误包含（若某祖先 isEnd=True）
- **单射约束被破坏**：若允许同一父节点的多个子节点有相同字符 → 字符串路径不唯一，search 结果不确定

## 参考存根

```python
class TrieNode:
    __slots__ = ('children', 'is_end')
    def __init__(self):
        self.children = {}   # char -> TrieNode
        self.is_end = False  # 该节点是否为某完整词的终点

class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word):
        node = self.root
        for ch in word:
            if ch not in node.children:
                node.children[ch] = TrieNode()
            node = node.children[ch]
        node.is_end = True

    def search(self, word):
        node = self._find_node(word)
        return node is not None and node.is_end

    def starts_with(self, prefix):
        return self._find_node(prefix) is not None

    def _find_node(self, prefix):
        node = self.root
        for ch in prefix:
            if ch not in node.children:
                return None
            node = node.children[ch]
        return node

    def collect_prefix_words(self, prefix):
        """收集所有以 prefix 为前缀的词"""
        node = self._find_node(prefix)
        if node is None:
            return []
        results = []
        self._dfs(node, prefix, results)
        return results

    def _dfs(self, node, path, results):
        if node.is_end:
            results.append(path)
        for ch, child in node.children.items():
            self._dfs(child, path + ch, results)
```
