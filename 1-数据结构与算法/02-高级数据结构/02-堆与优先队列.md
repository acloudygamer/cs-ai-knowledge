## 堆与优先队列

### 定义

堆是完全二叉树的数组实现，父节点与子节点满足堆序性：大顶堆 $Parent \geq Children$，小顶堆 $Parent \leq Children$。

**数学模型**

下标关系（0-indexed）：

$$
\text{parent}(i) = \lfloor(i-1)/2\rfloor,\quad \text{left}(i) = 2i+1,\quad \text{right}(i) = 2i+2
$$

堆性质：$\forall i,\ \text{heap}[i] \geq \text{heap}[2i+1],\ \text{heap}[i] \geq \text{heap}[2i+2]$

建堆复杂度：$T(n) = O(n)$（从最后一个非叶子节点向上 sift_down）

**数据流**

```
sift_up (插入):      末尾 → 父 → 祖父 → ... → 根 (O(log n))
sift_down (删除):     根 → 左/右子 → ... → 叶子 (O(log n))
heapify:              从 i=(n-2)//2 递减调用 sift_down
```

```
Top-K 数据流：
stream → 维护大小为 K 的小顶堆 → 堆顶 = 第 K 大
[3,1,5,2,4], K=3
push 3 → [3]
push 1 → [1,3]       push 5 → [1,3,5] → pop 5 → [1,3]
push 2 → [1,2,3]     push 4 → [1,2,3] → pop 4 → [1,2,3]
result = 堆顶 = 1 (第3大)
```

**机制**

完全二叉树的数组存储将树高固定为 $\lfloor\log_2 n\rfloor$，使父子跳转只需算术运算而无指针开销。sift_up 保证插入后堆性质，sift_down 保证删除根后重建堆性质。Python 的 `heapq` 是小顶堆，取负数实现大顶堆。

合并有序文件：将每个有序文件的迭代器作为元素入堆，每次弹出最小值并推进该文件，复杂度 $O(N \log k)$。

**参考存根**

```python
import heapq

def top_k(nums, k):
    h = []
    for x in nums:
        heapq.heappush(h, x)
        if len(h) > k: heapq.heappop(h)
    return h[0]
```
