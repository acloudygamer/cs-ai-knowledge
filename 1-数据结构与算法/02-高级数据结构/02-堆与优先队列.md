## 堆与优先队列

### 解决什么问题
堆是完全二叉树的数组实现，根节点为最值，O(1) 获取极值、O(log n) 插入删除，适用于 Top K、优先队列、堆排序、合并有序文件等场景。

### 核心概念
- **完全二叉树**：数组存储，父节点 i，左子 2i+1，右子 2i+2
- **大顶堆**：父节点 >= 子节点；小顶堆：父节点 <= 子节点
- **优先队列**：堆实现的队列，优先级高者先出
- **堆化**：O(n) 将任意数组调整为堆（从最后一个非叶子节点向上 sift_down）

### 堆的复杂度

| 操作 | 时间复杂度 | 说明 |
|------|----------|------|
| 构建堆 | O(n) | heapify |
| 插入 | O(log n) | sift_up |
| 删除根 | O(log n) | sift_down |
| 获取最值 | O(1) | 数组首元素 |
| 堆排序 | O(n log n) | 构建 + n 次删除 |

### 堆 vs 其他数据结构

| 数据结构 | 获取最值 | 插入 | 删除 | 适用场景 |
|---------|---------|------|------|---------|
| 数组（无序） | O(n) | O(1) | O(1) | 插入为主 |
| 数组（有序） | O(1) | O(n) | O(1) | 查询为主 |
| 链表 | O(n) | O(1) | O(1) | 插入为主 |
| 二叉搜索树 | O(log n) | O(log n) | O(log n) | 范围查询 |
| 堆 | O(1) | O(log n) | O(log n) | Top K、优先队列 |

## Python heapq 模块

Python 的 heapq 是最小堆，存入负数可实现最大堆。

### 参考样例

```python
import heapq

# 最小堆
heap = []
heapq.heappush(heap, 5)
heapq.heappush(heap, 2)
heapq.heappush(heap, 8)
heapq.heappop(heap)

# heapify：O(n) 将列表转为堆
arr = [5, 2, 8, 1, 9]
heapq.heapify(arr)

# nlargest / nsmallest
heapq.nlargest(3, arr)
heapq.nsmallest(3, arr)

# 最大堆：存入负数
max_heap = []
heapq.heappush(max_heap, -5)
heapq.heappush(max_heap, -2)
heapq.heappush(max_heap, -8)
```

## 手写堆（理解原理）

### 参考样例

```python
class MinHeap:
    def __init__(self):
        self.heap = []

    def parent(self, i):
        return (i - 1) // 2

    def left(self, i):
        return 2 * i + 1

    def right(self, i):
        return 2 * i + 2

    def swap(self, i, j):
        self.heap[i], self.heap[j] = self.heap[j], self.heap[i]

    def insert(self, val):
        self.heap.append(val)
        self._sift_up(len(self.heap) - 1)

    def _sift_up(self, i):
        while i > 0 and self.heap[self.parent(i)] > self.heap[i]:
            self.swap(i, self.parent(i))
            i = self.parent(i)

    def extract_min(self):
        if not self.heap:
            return None
        min_val = self.heap[0]
        last = self.heap.pop()
        if self.heap:
            self.heap[0] = last
            self._sift_down(0)
        return min_val

    def _sift_down(self, i):
        while self.left(i) < len(self.heap):
            smallest = self.left(i)
            if self.right(i) < len(self.heap) and self.heap[self.right(i)] < self.heap[smallest]:
                smallest = self.right(i)
            if self.heap[i] <= self.heap[smallest]:
                break
            self.swap(i, smallest)
            i = smallest
```

## Top K 问题

### 参考样例

```python
def find_kth_largest(nums, k):
    heap = []
    for num in nums:
        heapq.heappush(heap, num)
        if len(heap) > k:
            heapq.heappop(heap)
    return heap[0]

def find_kth_largest_v2(nums, k):
    return heapq.nlargest(k, nums)[-1]
```

## 合并有序文件

将 k 个有序数组合并为一个有序数组，时间复杂度 O(N log k)。

### 参考样例

```python
def merge_sorted_files(files):
    heap = []
    iterators = [iter(f) for f in files]
    for i, it in enumerate(iterators):
        first = next(it, None)
        if first is not None:
            heapq.heappush(heap, (first, i, it))
    result = []
    while heap:
        val, i, it = heapq.heappop(heap)
        result.append(val)
        nxt = next(it, None)
        if nxt is not None:
            heapq.heappush(heap, (nxt, i, it))
    return result
```
