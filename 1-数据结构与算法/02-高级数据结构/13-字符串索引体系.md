## 字符串索引体系

### 定义

后缀数组（Suffix Array）是所有后缀按字典序排列的有序索引；后缀自动机（SAM）是最小化确定性有限状态自动机，识别字符串的所有子串。

**数学模型**

后缀数组：$sa[i]$ = 排名第 $i$ 小的后缀起始位置

名次数组：$rank[pos]$ = 起始位置为 $pos$ 的后缀排名

LCP 数组：$lcp[i]$ = $sa[i-1]$ 与 $sa[i]$ 的最长公共前缀长度

SAM 状态数上界：$2n - 1$，转移数上界：$3n - 4$

不同子串数量：$\sum_{v} (\text{len}(v) - \text{len}(\text{link}(v)))$

**数据流**

<pre>
字符串 "banana$"

后缀列表:
  0: banana$
  1: anana$
  2: nana$
  3: ana$
  4: na$
  5: a$
  6: $

字典序排序 → sa = [6, 0, 5, 3, 1, 4, 2]
  rank[0]=1, rank[1]=4, rank[2]=6, ...

LCP 构建 (Kasai):
  $ < a < ana < anana < banana < na < nana
  lcp = [0, 1, 3, 0, 0, 1]
</pre>

**机制**

SAM 构建：每个新字符创建 cur 状态，若无对应转移则链向 p 并创建；遇到已存在转移 q 时，若 $\text{len}(p)+1 = \text{len}(q)$ 则直接链接，否则克隆 q 为 clone 并调整链接。SAM 的每个状态对应一组结束位置相同的子串。

**参考存根**

```python
class SAMNode:
    def __init__(self):
        self.next, self.link, self.len = {}, -1, 0

class SuffixAutomaton:
    def __init__(self):
        self.nodes, self.last = [SAMNode()], 0

    def extend(self, c):
        p, cur = self.last, len(self.nodes)
        self.nodes.append(SAMNode())
        self.nodes[cur].len = self.nodes[p].len + 1
        while p >= 0 and c not in self.nodes[p].next:
            self.nodes[p].next[c] = cur; p = self.nodes[p].link
        if p == -1: self.nodes[cur].link = 0
        else:
            q = self.nodes[p].next[c]
            if self.nodes[p].len + 1 == self.nodes[q].len: self.nodes[cur].link = q
            else:
                clone = len(self.nodes); self.nodes.append(SAMNode())
                self.nodes[clone].len = self.nodes[p].len + 1
                self.nodes[clone].next = self.nodes[q].next.copy()
                self.nodes[clone].link = self.nodes[q].link
                while p >= 0 and self.nodes[p].next.get(c) == q:
                    self.nodes[p].next[c] = clone; p = self.nodes[p].link
                self.nodes[q].link = self.nodes[cur].link = clone
        self.last = cur
```
