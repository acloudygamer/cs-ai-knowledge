# 字符串索引体系

> **版本基准**：universal —— 代码示例同时使用 Python 3.12 与 C++20

## 本质

字符串索引体系处理"在字符串集合中快速查找"。核心两个结构：**后缀数组（SA）** 把所有后缀排序成有序索引；**后缀自动机（SAM）** 是识别字符串所有子串的最小化 DFA。两者都把"所有子串"组织成可查索引——SA 靠排序，SAM 靠状态机。后缀树（所有后缀压缩进一棵压缩 Trie）省略，本文聚焦 SA 与 SAM。

## 数学模型

### 后缀数组

- $sa[i]$：排名第 $i$ 小的后缀的起始位置
- $rank[pos]$：起始位置 $pos$ 的后缀排名（$rank$ 是 $sa$ 的逆）
- $lcp[i]=\text{LCP}(T[sa[i-1]..],\ T[sa[i]..])$：相邻排名后缀的最长公共前缀长度

**LCP 定理**：任意两后缀 $T[i..],T[j..]$ 的 LCP = LCP 数组上 $[rank[i],rank[j]]$ 的区间最小值：

$$\text{LCP}(i,j)=\min_{k=rank[i]+1}^{rank[j]}lcp[k]\quad(rank[i]<rank[j])$$

构造：朴素 $O(n\log^2 n)$ （每比较两后缀）、倍增 $O(n\log n)$ （实践最常用）、SA-IS/DC3 $O(n)$ （线性但复杂）。

### 后缀自动机

每个状态 $v$ 代表一个 **endpos 等价类**——所有在原串中作为子串结束位置相同的子串集合。状态 $v$ 对应子串长度构成连续区间 $[\text{len}(\text{link}(v))+1,\ \text{len}(v)]$。

- 状态数上界 $2n-1$，转移数上界 $3n-4$（均线性）
- 不同子串数 $=\sum_v(\text{len}(v)-\text{len}(\text{link}(v)))$

> **洞察**：SAM 是"所有子串的最小化 DFA"——用 $O(n)$ 状态+转移表示了原本 $O(n^2)$ 的子串空间。压缩靠 endpos 等价类：结束位置相同的子串共用一个状态，按长度区间分层。

S="banana $" ($ 终止符,小于所有字符)

所有后缀按字典序排:

  [5] na$      排名4
  [3] nana$    排名5
  [0] banana$  排名6

sa   = [6,4,2,1,5,3,0]
rank = [6,3,2,5,1,4,0]   (rank[sa[i]]=i)
</pre>

### SAM 的 extend 与 clone

<pre>
S="ababa" 逐步扩展:
  extend('a'): 新状态1, 0-a→1, link[1]=0
  extend('b'): 新状态2, 1-b→2, link[2]=0
  extend('a'): 新状态3, 2-a→3, link[3]=0
  extend('b'): 新状态4, 3-b→4, link[4]=0
  extend('a'): p=4 有 a 转移到 q=1, 但 len(p)+1=5 ≠ len(q)=1
    → clone 状态5: len=5, next=copy(q.next), link=link[q]
    把 p 链上指向 q 的 a 转移改指 clone
    link[q]=link[cur]=clone
</pre>

## 机制

### LCP 数组为何是 SA 的核心配套

LCP 长 $n$、记录相邻后缀公共前缀。**没有 LCP 的 SA 只能排序，无法高效比子串**。有了 LCP，任意两后缀 LCP 可 $O(1)$ 查（RMQ on LCP），无需逐字符 $O(n)$ 比。

### SAM clone 为何必须

**触发条件**：extend 遇状态 $q$ （已有转移 $p\xrightarrow{c}q$）但 $\text{len}(p)+1\neq\text{len}(q)$。

**直观**： $q$ 原对应一组 endpos，加入新字符后该集合被分割——部分仍是旧长度子串、部分（加新字符后）构成更长子串。clone 保持"每状态对应连续长度区间"的性质。

**clone 的约束**：
- $\text{len}(\text{clone})=\text{len}(p)+1$ （填补断层）
- $\text{link}(\text{clone})=\text{link}(q)$ （继承链接）
- $\text{next}(\text{clone})=\text{next}(q)$ （**复制**所有转移）

**为何复制而非共享**：clone 代表更长子串，后续字符集合应与 $q$ 完全相同。共享转移会互相干扰——改 $q$ 影响 clone、反之亦然。clone 后 $q$ 的 link 指向 clone，长度区间被截断。

### SAM vs 后缀数组

| 维度 | 后缀数组 | SAM |
|------|----------|-----|
| 构造 | $O(n\log n)$ 或 $O(n)$ | $O(n)$ |
| 空间 | $O(n)$ （+LCP $O(n)$） | $O(n)$ （状态+转移） |
| 子串查询 | 二分 | 直接转移 |
| 重复子串 | 自然处理 | 自动合并 |
| LCP 查询 | $O(1)$ （RMQ on LCP） | 需额外结构 |
| 适用 | 静态串排序/范围查询 | 动态串子串存在性 |

### 子串查询应用

- **SA**：在 $sa$ 上二分找模式 $P$ 的排名区间 $[L,R]$， $R-L+1$ 即出现次数。
- **SAM**：从初始状态沿 $P$ 字符转移，失败则不存在、走完则 $P$ 是子串。 $O(|P|)$、与 $T$ 长度无关。

### 违规后果

| 违规 | 后果 |
|------|------|
| SA 不带终止符 $ | 后缀长度不等，排序比较越界 |
| SA 无 LCP 配套 | 无法 $O(1)$ 查任意两后缀 LCP |
| SAM clone 漏复制转移 | 状态后续可达性丢失，子串识别错 |
| SAM clone 条件判错（$\text{len}(p)+1=\text{len}(q)$ 时误 clone） | 状态冗余，破坏最小化 |

## 代码示例

**Python 3.12**：

```python
# 后缀数组（倍增法 O(n log² n)）+ LCP（Kasai 算法 O(n)）
def build_sa(s):
    s = s + '$'; n = len(s)
    sa = list(range(n))
    rank = [ord(c) for c in s]
    tmp = [0] * n
    k = 1
    while True:
        # 按双关键字排序: (rank[i], rank[i+k] 或 -1)
        sa.sort(key=lambda i: (rank[i], rank[i+k] if i+k < n else -1))
        tmp[sa[0]] = 0
        for i in range(1, n):
            prev, cur = sa[i-1], sa[i]
            prev_key = (rank[prev], rank[prev+k] if prev+k < n else -1)
            cur_key  = (rank[cur],  rank[cur+k]  if cur+k  < n else -1)
            tmp[cur] = tmp[prev] + (1 if cur_key != prev_key else 0)
        rank = tmp[:]
        if rank[sa[-1]] == n - 1: break     # 全不同,完成
        k <<= 1
    return sa, s

def build_lcp(s, sa):
    n = len(s); rank = [0]*n
    for i, p in enumerate(sa): rank[p] = i
    lcp = [0]*n; h = 0
    for i in range(n):                      # Kasai: 利用 rank 求相邻 LCP
        if rank[i] > 0:
            j = sa[rank[i]-1]
            while i+h < n and j+h < n and s[i+h] == s[j+h]: h += 1
            lcp[rank[i]] = h
            if h: h -= 1                    # 利用 h-1 不变性
    return lcp

# SAM: O(n) 识别所有子串
class SAM:
    def __init__(self):
        self.nxt = [{}]; self.link = [-1]; self.length = [0]; self.last = 0
    def extend(self, c):
        cur = len(self.nxt); self.nxt.append({}); self.link.append(0); self.length.append(0)
        self.length[cur] = self.length[self.last] + 1
        p = self.last
        while p != -1 and c not in self.nxt[p]:
            self.nxt[p][c] = cur; p = self.link[p]
        if p == -1:
            self.link[cur] = 0
        else:
            q = self.nxt[p][c]
            if self.length[p] + 1 == self.length[q]:
                self.link[cur] = q
            else:                           # clone
                clone = len(self.nxt)
                self.nxt.append(self.nxt[q].copy()); self.link.append(self.link[q]); self.length.append(self.length[p]+1)
                while p != -1 and self.nxt[p].get(c) == q:
                    self.nxt[p][c] = clone; p = self.link[p]
                self.link[q] = self.link[cur] = clone
        self.last = cur
    def contains(self, p):                  # p 是否子串
        v = 0
        for c in p:
            if c not in self.nxt[v]: return False
            v = self.nxt[v][c]
        return True
    def distinct_substrings(self):          # 不同子串数
        return sum(self.length[i] - self.length[self.link[i]] for i in range(1, len(self.nxt)))

# —— 简易输入输出 ——
sa, s = build_sa("banana")
print(sa)                    # [6, 5, 3, 1, 0, 4, 2] (banana$ 的 sa, 含 $)
lcp = build_lcp(s, sa)
print(lcp)                   # 相邻 lcp

sam = SAM()
for c in "banana": sam.extend(c)
print(sam.contains("ana"))   # True
print(sam.contains("xyz"))   # False
print(sam.distinct_substrings())  # banana 的不同子串数 = 21
```

**C++20**：

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <unordered_map>

// 后缀数组（倍增）+ rank
std::vector<int> build_sa(std::string s) {
    s += '$'; int n = s.size();
    std::vector<int> sa(n), rank(n), tmp(n);
    for (int i = 0; i < n; ++i) { sa[i] = i; rank[i] = (unsigned char)s[i]; }
    for (int k = 1; ; k <<= 1) {
        auto key = [&](int i){ return std::make_pair(rank[i], i+k<n ? rank[i+k] : -1); };
        std::sort(sa.begin(), sa.end(), [&](int a, int b){ return key(a) < key(b); });
        tmp[sa[0]] = 0;
        for (int i = 1; i < n; ++i) tmp[sa[i]] = tmp[sa[i-1]] + (key(sa[i]) != key(sa[i-1]));
        rank = tmp;
        if (rank[sa.back()] == n-1) break;
    }
    return sa;
}

// SAM
struct SAM {
    std::vector<std::unordered_map<char,int>> nxt;
    std::vector<int> link, len; int last = 0;
    SAM() { nxt.push_back({}); link.push_back(-1); len.push_back(0); }
    void extend(char c) {
        int cur = nxt.size();
        nxt.push_back({}); link.push_back(0); len.push_back(len[last]+1);
        int p = last;
        for (; p != -1 && !nxt[p].count(c); p = link[p]) nxt[p][c] = cur;
        if (p == -1) link[cur] = 0;
        else {
            int q = nxt[p][c];
            if (len[p]+1 == len[q]) link[cur] = q;
            else {
                int clone = nxt.size();
                nxt.push_back(nxt[q]); link.push_back(link[q]); len.push_back(len[p]+1);
                for (; p != -1 && nxt[p][c] == q; p = link[p]) nxt[p][c] = clone;
                link[q] = link[cur] = clone;
            }
        }
        last = cur;
    }
    bool contains(const std::string& p) {
        int v = 0;
        for (char c : p) { if (!nxt[v].count(c)) return false; v = nxt[v][c]; }
        return true;
    }
    long long distinct() {
        long long s = 0;
        for (size_t i = 1; i < nxt.size(); ++i) s += len[i] - len[link[i]];
        return s;
    }
};

// —— 简易输入输出 ——
int main() {
    auto sa = build_sa("banana");
    for (int x : sa) std::cout << x << ' '; std::cout << '\n';   // 6 5 3 1 0 4 2

    SAM sam;
    for (char c : std::string("banana")) sam.extend(c);
    std::cout << std::boolalpha << sam.contains("ana") << ' ' << sam.contains("xyz") << '\n'; // true false
    std::cout << sam.distinct() << '\n';                          // 21
}
```
