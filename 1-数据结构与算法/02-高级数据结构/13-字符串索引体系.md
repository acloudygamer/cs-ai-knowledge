## 字符串索引体系

### 解决什么问题
高效处理字符串的匹配、搜索、子串查询等问题。适用于全文搜索、DNA序列比对、编译器词法分析等需要字符串处理的核心场景。

### 核心概念
- 后缀数组：将所有后缀排序，O(n log n) 构建
- 后缀自动机（SAM）：最小化确定有限状态自动机，支持 O(1) 子串查询
- 后缀树：所有后缀的 Trie 压缩（构建较复杂）

---

## 后缀数组 (Suffix Array)

### 后缀数组核心概念

后缀数组 sa[i] 表示排名第 i 小的后缀的起始位置。

**后缀**：从位置 i 开始到字符串末尾的子串。

### 构建方法

#### 倍增算法 (Doubling)

时间复杂度 O(n log n)，适用于 n ≤ 10^5。

### 参考样例

```python
def build_suffix_array(s):
    s = s + '$'
    n = len(s)

    k = 1
    sa = list(range(n))
    rank = [ord(c) for c in s]
    tmp = [0] * n

    while k < n:
        sa.sort(key=lambda x: (rank[x], rank[x + k] if x + k < n else -1))

        tmp[sa[0]] = 0
        for i in range(1, n):
            prev, cur = sa[i - 1], sa[i]
            tmp[cur] = tmp[prev] + (
                (rank[prev], rank[prev + k] if prev + k < n else -1) <
                (rank[cur], rank[cur + k] if cur + k < n else -1)
            )

        rank, tmp = tmp, rank
        if rank[sa[-1]] == n - 1:
            break
        k <<= 1

    return sa[1:]


def lcp_array(s, sa):
    n = len(s)
    rank = [0] * n
    for i in range(n):
        rank[sa[i]] = i

    lcp = [0] * n
    h = 0
    for i in range(n):
        r = rank[i]
        if r > 0:
            j = sa[r - 1]
            while i + h < n and j + h < n and s[i + h] == s[j + h]:
                h += 1
            lcp[r] = h
            if h > 0:
                h -= 1
    return lcp
```

### 最长重复子串

### 参考样例

```python
def longest_repeated_substring(s):
    sa = build_suffix_array(s)
    lcp = lcp_array(s, sa)

    max_len = max(lcp)
    max_idx = lcp.index(max_len)
    start = sa[max_idx]

    return s[start:start + max_len]
```

### 最长回文子串（结合字符串反转）

### 参考样例

```python
def longest_palindromic_substring(s):
    rev = s[::-1]
    combined = s + '#' + rev

    sa = build_suffix_array(combined)
    lcp = lcp_array(combined, sa)

    n = len(s)
    max_len = 0
    result = ""

    for i in range(1, len(sa)):
        pos1 = sa[i - 1]
        pos2 = sa[i]
        if (pos1 < n) != (pos2 < n):
            cur_lcp = lcp[i]
            if pos1 < pos2:
                center = pos1 + (pos2 - pos1) // 2
            else:
                center = pos2 + (pos1 - pos2) // 2
            if cur_lcp > max_len:
                max_len = cur_lcp
                start = center - max_len // 2
                result = s[start:start + max_len]

    return result
```

## 后缀自动机 (SAM)

### SAM 核心概念

后缀自动机是一个最小化确定有限状态自动机，能识别一个字符串的所有后缀。

**状态**：每个状态代表所有结束位置相同的子串的等价类。

### 重要性质

1. 每个状态对应一组结束位置相同的子串
2. 从初始状态到任意状态的路径构成原串的子串
3. 状态数 ≤ 2n - 1
4. 转移数 ≤ 3n - 4

### 实现

### 参考样例

```python
class SAMNode:
    def __init__(self):
        self.next = {}
        self.link = -1
        self.len = 0


class SuffixAutomaton:
    def __init__(self):
        self.nodes = [SAMNode()]
        self.last = 0
        self.endpos_size = [0] * 1

    def extend(self, c):
        p = self.last
        cur = len(self.nodes)
        self.nodes.append(SAMNode())
        self.nodes[cur].len = self.nodes[p].len + 1
        self.endpos_size.append(1)

        while p >= 0 and c not in self.nodes[p].next:
            self.nodes[p].next[c] = cur
            p = self.nodes[p].link

        if p == -1:
            self.nodes[cur].link = 0
        else:
            q = self.nodes[p].next[c]
            if self.nodes[p].len + 1 == self.nodes[q].len:
                self.nodes[cur].link = q
            else:
                clone = len(self.nodes)
                self.nodes.append(SAMNode())
                self.nodes[clone].len = self.nodes[p].len + 1
                self.nodes[clone].next = self.nodes[q].next.copy()
                self.nodes[clone].link = self.nodes[q].link
                self.endpos_size.append(0)

                while p >= 0 and self.nodes[p].next.get(c) == q:
                    self.nodes[p].next[c] = clone
                    p = self.nodes[p].link

                self.nodes[q].link = self.nodes[cur].link = clone

        self.last = cur

    def build(self, s):
        for c in s:
            self.extend(c)
        self._compute_endpos_sizes()

    def _compute_endpos_sizes(self):
        max_len = max(node.len for node in self.nodes)
        cnt = [0] * (max_len + 1)
        for node in self.nodes:
            cnt[node.len] += 1
        for i in range(1, max_len + 1):
            cnt[i] += cnt[i - 1]
        order = [0] * len(self.nodes)
        for i, node in enumerate(self.nodes):
            order[cnt[node.len] - 1] = i

        for i in range(len(self.nodes) - 1, 0, -1):
            v = order[i]
            if self.nodes[v].link != -1:
                self.endpos_size[self.nodes[v].link] += self.endpos_size[v]

    def contains(self, pattern):
        p = 0
        for c in pattern:
            if c not in self.nodes[p].next:
                return False
            p = self.nodes[p].next[c]
        return True

    def count_occurrences(self, pattern):
        p = 0
        for c in pattern:
            if c not in self.nodes[p].next:
                return 0
            p = self.nodes[p].next[c]
        return self.endpos_size[p]

    def longest_common_substring(self, t):
        v = 0
        l = 0
        best = 0
        best_pos = 0

        for i, c in enumerate(t):
            if c in self.nodes[v].next:
                v = self.nodes[v].next[c]
                l += 1
            else:
                while v >= 0 and c not in self.nodes[v].next:
                    v = self.nodes[v].link
                if v < 0:
                    v = 0
                    l = 0
                else:
                    l = self.nodes[v].len + 1
                    v = self.nodes[v].next[c]

            if l > best:
                best = l
                best_pos = i - l + 1

        return t[best_pos:best_pos + best], best
```

## SAM vs 后缀数组对比

| 特性 | SAM | SA |
|------|-----|-----|
| 构建时间 | O(n) | O(n log n) |
| 空间 | O(n) | O(n) |
| 子串查询 | O(m) | O(m log n) |
| 出现次数 | O(m) | O(n) |
| 适用场景 | 多模式匹配 | 有序遍历 |

## SAM 应用

### 不同子串数量

### 参考样例

```python
def distinct_substrings(s):
    sam = SuffixAutomaton()
    sam.build(s)

    total = 0
    for i in range(1, len(sam.nodes)):
        total += sam.nodes[i].len - sam.nodes[sam.nodes[i].link].len
    return total
```

## 后缀树 (Suffix Tree)

后缀树的线性构建较为复杂，实际应用中 SAM 通常可以替代。

```
banana$
banana$ 的后缀树：
root
 ├── a$
 │    ├── na$
 │    └── $
 ├── banana$
 └── na$
      └── na$
```

## 三种索引对比

| 特性 | 后缀数组 | 后缀自动机 | 后缀树 |
|------|----------|------------|--------|

## 实战例题

### 重复子串（LeetCode 1062）

### 参考样例

```python
def longest_repeated_substring(s):
    sa = build_suffix_array(s)
    lcp = lcp_array(s, sa)

    max_len = max(lcp)
    if max_len == 0:
        return ""
    idx = lcp.index(max_len)
    return s[sa[idx]:sa[idx] + max_len]
```

### 多个字符串的最长公共子串

### 参考样例

```python
def longest_common_substring_multiple(strings):
    sam = SuffixAutomaton()
    sam.build(strings[0])

    result = ""
    for s in strings[1:]:
        lcs, length = sam.longest_common_substring(s)
        if not result or length < len(result):
            result = lcs

    return result
```
