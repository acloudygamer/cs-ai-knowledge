## 字符串索引体系

### 解决什么问题
高效处理字符串的匹配、搜索、子串查询等问题。适用于全文搜索、DNA序列比对、编译器词法分析等需要字符串处理的核心场景。

### 核心概念
- 后缀数组：将所有后缀排序，O(n log n) 构建
- 后缀自动机（SAM）：最小化确定有限状态自动机，支持 O(1) 子串查询
- 后缀树：所有后缀的 Trie 压缩（构建较复杂）

### 怎么用

```python
# 后缀数组（Suffix Array）- 倍增算法 O(n log n)
def build_suffix_array(s):
    n = len(s)
    sa = list(range(n))
    rank = [ord(c) for c in s]
    k = 1
    while k < n:
        sa.sort(key=lambda i: (rank[i], rank[i + k] if i + k < n else -1))
        tmp = [0] * n
        for i in range(1, n):
            tmp[i] = tmp[i - 1] + (sa[i], sa[i-1], rank[sa[i]], rank[sa[i-1]]) != \
                           (sa[i-1], sa[i], rank[sa[i-1]], rank[sa[i]])
        rank = tmp
        if rank[sa[-1]] == n - 1:
            break
        k <<= 1
    return sa
```

## 概述

字符串索引是处理字符串高效匹配和搜索的核心数据结构，主要包括：

- **后缀数组 (Suffix Array)**：将所有后缀排序
- **后缀自动机 (Suffix Automaton, SAM)**：最小化确定有限状态自动机
- **后缀树 (Suffix Tree)**：所有后缀的 Trie 压缩

## 后缀数组 (Suffix Array)

### 后缀数组核心概念

后缀数组 sa[i] 表示排名第 i 小的后缀的起始位置。

**后缀**：从位置 i 开始到字符串末尾的子串。

### 构建方法

#### 1. 倍增算法 (Doubling)

时间复杂度 O(n log n)，适用于 n ≤ 10^5。

```python
def build_suffix_array(s):
    """
    构建后缀数组（倍增算法）
    s: 输入字符串
    返回: sa - 后缀数组
    """
    s = s + '$'  # 添加结束符
    n = len(s)

    # 初始：每个字符的排名
    k = 1
    sa = list(range(n))  # 初始 sa[i] = i
    rank = [ord(c) for c in s]  # 初始排名
    tmp = [0] * n

    while k < n:
        # 按 (rank[i], rank[i+k]) 排序
        sa.sort(key=lambda x: (rank[x], rank[x + k] if x + k < n else -1))

        tmp[sa[0]] = 0
        for i in range(1, n):
            prev, cur = sa[i - 1], sa[i]
            tmp[cur] = tmp[prev] + (
                (rank[prev], rank[prev + k] if prev + k < n else -1) <
                (rank[cur], rank[cur + k] if cur + k < n else -1)
            )

        rank, tmp = tmp, rank
        if rank[sa[-1]] == n - 1:
            break
        k <<= 1

    return sa[1:]  # 去掉结束符的位置


def lcp_array(s, sa):
    """
    构建 LCP（最长公共前缀）数组
    lcp[i] = sa[i] 和 sa[i-1] 的最长公共前缀长度
    """
    n = len(s)
    rank = [0] * n
    for i in range(n):
        rank[sa[i]] = i

    lcp = [0] * n
    h = 0
    for i in range(n):
        r = rank[i]
        if r > 0:
            j = sa[r - 1]
            while i + h < n and j + h < n and s[i + h] == s[j + h]:
                h += 1
            lcp[r] = h
            if h > 0:
                h -= 1
    return lcp
```

#### 2. SA-IS 算法

线性时间复杂度 O(n)，但实现复杂。

### 应用

#### 最长重复子串

```python
def longest_repeated_substring(s):
    """
    找出字符串中的最长重复子串
    利用 LCP 数组：重复子串 = 相邻后缀的 LCP
    """
    sa = build_suffix_array(s)
    lcp = lcp_array(s, sa)

    max_len = max(lcp)
    max_idx = lcp.index(max_len)
    start = sa[max_idx]

    return s[start:start + max_len]
```

#### 最长回文子串（结合字符串反转）

```python
def longest_palindromic_substring(s):
    """
    通过后缀数组找最长回文子串
    方法：将原串与其反转串拼接，用特殊字符分隔
    """
    rev = s[::-1]
    combined = s + '#' + rev

    sa = build_suffix_array(combined)
    lcp = lcp_array(combined, sa)

    n = len(s)
    max_len = 0
    result = ""

    for i in range(1, len(sa)):
        pos1 = sa[i - 1]
        pos2 = sa[i]
        # 判断两个后缀是否分布在原串和反转串
        if (pos1 < n) != (pos2 < n):
            cur_lcp = lcp[i]
            # 确定回文中心
            if pos1 < pos2:
                center = pos1 + (pos2 - pos1) // 2
            else:
                center = pos2 + (pos1 - pos2) // 2
            if cur_lcp > max_len:
                max_len = cur_lcp
                start = center - max_len // 2
                result = s[start:start + max_len]

    return result
```

## 后缀自动机 (SAM)

### SAM 核心概念

后缀自动机是一个最小化确定有限状态自动机，能识别一个字符串的所有后缀。

**状态**：每个状态代表所有结束位置相同的子串的等价类。

### 重要性质

1. 每个状态对应一组结束位置相同的子串
2. 从初始状态到任意状态的路径构成原串的子串
3. 状态数 ≤ 2n - 1
4. 转移数 ≤ 3n - 4

### 实现

```python
class SAMNode:
    def __init__(self):
        self.next = {}        # 转移：字符 -> 状态
        self.link = -1       # 后缀链接
        self.len = 0         # 状态对应的最长串长度


class SuffixAutomaton:
    def __init__(self):
        self.nodes = [SAMNode()]  # 初始状态 0
        self.last = 0             # 最后添加的状态
        self.endpos_size = [0] * 1  # endpos 大小，用于 count_occurrences

    def extend(self, c):
        """添加字符 c 到自动机"""
        p = self.last
        cur = len(self.nodes)
        self.nodes.append(SAMNode())
        self.nodes[cur].len = self.nodes[p].len + 1
        self.endpos_size.append(1)  # 新状态的 endpos 大小为 1

        # 转移：找第一个有 c 转移的状态
        while p >= 0 and c not in self.nodes[p].next:
            self.nodes[p].next[c] = cur
            p = self.nodes[p].link

        if p == -1:
            # 第一个状态，后缀链接指向 0
            self.nodes[cur].link = 0
        else:
            q = self.nodes[p].next[c]
            if self.nodes[p].len + 1 == self.nodes[q].len:
                self.nodes[cur].link = q
            else:
                # 需要克隆状态
                clone = len(self.nodes)
                self.nodes.append(SAMNode())
                self.nodes[clone].len = self.nodes[p].len + 1
                self.nodes[clone].next = self.nodes[q].next.copy()
                self.nodes[clone].link = self.nodes[q].link
                self.endpos_size.append(0)  # 克隆状态的 endpos 大小稍后通过拓扑排序计算

                while p >= 0 and self.nodes[p].next.get(c) == q:
                    self.nodes[p].next[c] = clone
                    p = self.nodes[p].link

                self.nodes[q].link = self.nodes[cur].link = clone

        self.last = cur

    def build(self, s):
        """从字符串构建 SAM"""
        for c in s:
            self.extend(c)
        self._compute_endpos_sizes()

    def _compute_endpos_sizes(self):
        """计算每个状态的 endpos 大小（按 len 降序拓扑排序）"""
        # 按 len 计数排序
        max_len = max(node.len for node in self.nodes)
        cnt = [0] * (max_len + 1)
        for node in self.nodes:
            cnt[node.len] += 1
        for i in range(1, max_len + 1):
            cnt[i] += cnt[i - 1]
        order = [0] * len(self.nodes)
        for i, node in enumerate(self.nodes):
            order[cnt[node.len] - 1] = i

        # 按 len 降序传播 endpos 大小
        for i in range(len(self.nodes) - 1, 0, -1):
            v = order[i]
            if self.nodes[v].link != -1:
                self.endpos_size[self.nodes[v].link] += self.endpos_size[v]

    def contains(self, pattern):
        """判断 pattern 是否是原串的子串"""
        p = 0
        for c in pattern:
            if c not in self.nodes[p].next:
                return False
            p = self.nodes[p].next[c]
        return True

    def count_occurrences(self, pattern):
        """计算 pattern 出现次数"""
        p = 0
        for c in pattern:
            if c not in self.nodes[p].next:
                return 0
            p = self.nodes[p].next[c]

        # 状态 p 对应的所有子串都结束于 p
        # 统计 endpos 大小（需要额外维护）
        return self.endpos_size[p]

    def longest_common_substring(self, t):
        """
        找出与构建 SAM 的字符串的最长公共子串
        """
        v = 0
        l = 0
        best = 0
        best_pos = 0

        for i, c in enumerate(t):
            if c in self.nodes[v].next:
                v = self.nodes[v].next[c]
                l += 1
            else:
                while v >= 0 and c not in self.nodes[v].next:
                    v = self.nodes[v].link
                if v < 0:
                    v = 0
                    l = 0
                else:
                    l = self.nodes[v].len + 1
                    v = self.nodes[v].next[c]

            if l > best:
                best = l
                best_pos = i - l + 1

        return t[best_pos:best_pos + best], best
```

### SAM 与后缀数组对比

| 特性 | SAM | SA |
|------|-----|-----|
| 构建时间 | O(n) | O(n log n) |
| 空间 | O(n) | O(n) |
| 子串查询 | O(m) | O(m log n) |
| 出现次数 | O(m) | O(n) |
| 适用场景 | 多模式匹配 | 有序遍历 |

```python
def distinct_substrings(s):
    """SAM：计算不同子串数量"""
    sam = SuffixAutomaton()
    sam.build(s)

    total = 0
    for i in range(1, len(sam.nodes)):
        total += sam.nodes[i].len - sam.nodes[sam.nodes[i].link].len
    return total
```

## 后缀树 (Suffix Tree)

后缀树的线性构建较为复杂，实际应用中 SAM 通常可以替代。

```
banana$
banana$ 的后缀树：
root
 ├── a$
 │    ├── na$
 │    └── $
 ├── banana$
 └── na$
      └── na$
```

## 三种索引对比

| 特性 | 后缀数组 | 后缀自动机 | 后缀树 |
|------|----------|------------|--------|
| 构建时间 | O(n log n) | O(n) | O(n) |
| 空间 | O(n) | O(n) | O(n) |
| 子串查询 | O(m log n) | O(m) | O(m) |
| LCP 查询 | O(1) | O(n) | O(1) |
| 实现难度 | 中等 | 较难 | 难 |

```python
def longest_repeated_substring(s):
    """
    最长重复子串（可重叠）
    """
    sa = build_suffix_array(s)
    lcp = lcp_array(s, sa)

    max_len = max(lcp)
    if max_len == 0:
        return ""
    idx = lcp.index(max_len)
    return s[sa[idx]:sa[idx] + max_len]
```

```python
def longest_common_substring_multiple(strings):
    """
    找多个字符串的最长公共子串
    方法：将第一个字符串构建 SAM，其他字符串依次匹配
    """
    sam = SuffixAutomaton()
    sam.build(strings[0])

    result = ""
    for s in strings[1:]:
        lcs, length = sam.longest_common_substring(s)
        if not result or length < len(result):
            result = lcs

    return result
```
