# 字符串索引体系

## 定义

> **版本基准**: universal

字符串索引体系是处理"在字符串集合中快速查找"问题的数据结构总称。后缀数组（Suffix Array）通过对所有后缀排序构建有序索引；后缀自动机（SAM）是最小化确定性有限状态自动机，以线性空间识别字符串的所有子串；后缀树则是把所有后缀压缩进一棵压缩前缀树（Trie）。

本条目重点讨论后缀数组和后缀自动机，它们是字符串处理领域最核心的两个索引结构。

**本质**：两者都是将字符串的**所有子串**组织为可查询的索引结构，但组织方式不同——后缀数组通过排序，后缀自动机通过状态机。

**资源视角**：字符串索引消耗的核心资源是**构建时间/空间**和**查询时间**。后缀数组构建相对简单，后缀自动机构建更复杂但查询更快。

## 数学模型

### 后缀数组

**定义**：
- $sa[i]$：排名第 $i$ 小的后缀的起始位置
- $rank[pos]$：起始位置为 $pos$ 的后缀的排名（$rank$ 是 $sa$ 的逆函数）

**LCP 数组**：$lcp[i] = \text{LCP}(T[sa[i-1]..],\ T[sa[i]..])$，即排名第 $i-1$ 和第 $i$ 的后缀的最长公共前缀长度。

**LCP 定理**：任意两个后缀 $T[i..]$ 和 $T[j..]$ 的 LCP，等于 RMQ（$rank[i], rank[j]$）在 LCP 数组上的区间最小值：

$$
\text{LCP}(i, j) = \min_{k=rank[i]+1}^{rank[j]} lcp[k]\quad (\text{设 } rank[i] < rank[j])
$$

**后缀数组构造**：$O(n \log^2 n)$ 的朴素方法（每次比较两个后缀），或 $O(n)$ 的 SA-IS/DC3 算法。

**不同构造算法的权衡**：
- 朴素方法：$O(n \log^2 n)$，实现简单，但不适合大字符串
- SA-IS：$O(n)$，线性时间但实现复杂
- Doubling：$O(n \log n)$，是实践中最常用的方法

### 后缀自动机

**状态定义**：每个状态 $v$ 代表字符串 $S$ 的一组结束位置集合，所有以 $v$ 为结束位置的前缀长度构成连续区间 $[\text{len}(\text{link}(v))+1,\ \text{len}(v)]$。

**状态数上界**：$2n - 1$（线性）
**转移数上界**：$3n - 4$

**不同子串数量**：

$$
\sum_{v} (\text{len}(v) - \text{len}(\text{link}(v)))
$$

每个状态贡献的子串数等于其长度区间大小。

**归约终点**：SAM 是**所有子串的最小化确定有限自动机**，可归约为前缀树的有序压缩——它识别的是该字符串所有子串的集合，用 $O(n)$ 状态和 $O(n)$ 转移表示了原本需要 $O(n^2)$ 的子串空间。

## 机制

### 后缀数组为何必须 $O(n)$ 空间存储 LCP？

LCP 数组长度 $n$ 记录相邻后缀的公共前缀长度，是后缀数组的核心配套结构。**没有 LCP 的后缀数组只能做排序，无法高效回答子串比较**。

LCP 数组的存在使得：比较任意两个后缀 $T[i..]$ 和 $T[j..]$ 的 LCP，可以 $O(1)$ 查询（RMQ on LCP），而不需要逐字符比较 $O(n)$。

### SAM 的 clone 机制——为什么必须 clone？

**问题来源**：当 extend 操作遇到状态 $q$（已有转移），但 $q$ 的长度不连续时。

具体条件：当前扩展字符 $c$，$p$ 有转移 $p \xrightarrow{c} q$，但 $\text{len}(p) + 1 \neq \text{len}(q)$。

**直观理解**：$q$ 状态原本对应一组结束位置集合，加入新字符后，该集合被分割——一部分结束位置仍构成旧长度的子串，另一部分（加入新字符后）构成更长子串。clone 的目的是**保持"每个状态对应连续长度区间"的性质**。

**clone 的数学约束**：
- $\text{len}(\text{clone}) = \text{len}(p) + 1$（刚好填补断层）
- $\text{link}(\text{clone}) = \text{link}(q)$（继承原链接）
- $\text{next}(\text{clone}) = \text{next}(q)$（复制所有转移——这是关键）

**为什么 clone 的转移是复制的而非共享的**？clone 代表"更长的子串"，它的后续字符集合应该与 $q$ 完全相同（因为加入新字符后，原 $q$ 的所有可能后继依然可达）。若共享转移，则 $q$ 和 $\text{clone}$ 会相互干扰——对 $q$ 的修改会影响 $\text{clone}$，反之亦然。

**clone 后 $q$ 的长度区间被截断**：$\text{len}(q)$ 缩小为 $\text{len}(\text{link}(q))$，$q$ 的 $\text{link}$ 指向 $\text{clone}$。

### SAM 与后缀数组的对比

| 维度 | 后缀数组 | 后缀自动机 |
|------|----------|-----------|
| 构造复杂度 | $O(n \log n)$ 或 $O(n)$ | $O(n)$ |
| 空间 | $O(n)$（+ LCP $O(n)$） | $O(n)$（状态 + 转移） |
| 子串查询 | 需要二分 | 直接转移 |
| 重复子串 | 自然处理 | 自动合并 |
| 扩展能力 | 有限 | 可修改/删除（需额外接口） |
| LCP 查询 | $O(1)$（RMQ on LCP） | 需要额外结构 |
| 适用场景 | 静态字符串排序、范围查询 | 动态字符串的子串存在性 |

### 子串查询的应用

**后缀数组**：找出字符串 $P$ 在 $T$ 中的所有出现位置
1. 在 $sa$ 上二分，找到 $P$ 的排名区间 $[L, R]$
2. $R - L + 1$ 即出现次数

**SAM**：直接从初始状态出发，沿 $P$ 的字符转移，若转移失败则不存在；若成功完成，则 $P$ 是 $T$ 的子串。

SAM 的查询过程实际上是识别 $P$ 是否属于该自动机识别的语言（即 $T$ 的子串集合）。时间复杂度 $O(|P|)$，与 $T$ 长度无关。

### SAM 的 endpos 等价类

SAM 的每个状态 $v$ 对应一个 **endpos 等价类**——所有在原串中作为子串结束的位置集合。

**关键性质**：所有以状态 $v$ 为结束位置的子串长度构成连续区间 $[\text{len}(\text{link}(v))+1, \text{len}(v)]$。

**实例**：字符串 "ababa" 中，状态 1（第一个 'a' 后）对应结束位置 {1, 3}，其 len = 1，link = 0（len = 0），因此代表子串 "a"。

## 参考存根

### 后缀数组的 Kasai 算法

```python
def build_sa(s):
    s = s + '$'
    n = len(s)
    sa = list(range(n))
    rank = [ord(c) for c in s]
    k = 1
    while k < n:
        sa.sort(key=lambda i: (rank[i], rank.get(i + k, -1)))
        tmp = [0] * n
        for i in range(1, n):
            tmp[i] = tmp[i-1] + (sa[i-1], sa[i]) < (sa[i], sa[i-1])
        for i in range(n):
            rank[sa[i]] = tmp[i]
        if rank[sa[-1]] == n - 1:
            break
        k <<= 1
    return sa[:-1]  # 去掉末尾 '$'
```

### SAM 的 extend 操作

```python
class SAMNode:
    def __init__(self):
        self.next = {}
        self.link = -1
        self.len = 0

class SuffixAutomaton:
    def __init__(self):
        self.nodes = [SAMNode()]
        self.last = 0

    def extend(self, c):
        p = self.last
        cur = len(self.nodes)
        self.nodes.append(SAMNode())
        self.nodes[cur].len = self.nodes[p].len + 1
        while p >= 0 and c not in self.nodes[p].next:
            self.nodes[p].next[c] = cur
            p = self.nodes[p].link
        if p == -1:
            self.nodes[cur].link = 0
        else:
            q = self.nodes[p].next[c]
            if self.nodes[p].len + 1 == self.nodes[q].len:
                self.nodes[cur].link = q
            else:
                clone = len(self.nodes)
                self.nodes.append(SAMNode())
                self.nodes[clone].len = self.nodes[p].len + 1
                self.nodes[clone].next = self.nodes[q].next.copy()
                self.nodes[clone].link = self.nodes[q].link
                while p >= 0 and self.nodes[p].next.get(c) == q:
                    self.nodes[p].next[c] = clone
                    p = self.nodes[p].link
                self.nodes[q].link = self.nodes[cur].link = clone
        self.last = cur
```
