# 数组与字符串

> 前置：[01-复杂度分析](../01-复杂度与权衡/01-复杂度分析.md) · 后续：[02-链表](./02-链表.md)

> **版本基准**：universal —— 代码示例同时使用 Python 3.12 与 C++20

## 本质

数组是连续内存中等大小元素的排列。逻辑下标 $i$ 到物理地址是线性映射 $\text{addr}(i) = B + i \times s$ ——一次乘法加一次加法直接定位，这就是 $O(1)$ 随机访问的来源。链表做不到：节点不连续，地址无公式可循，只能沿指针逐个跳。

字符串物理上与数组同源（连续字符内存），但语言层加了**不可变**约束：任何修改都是"分配新内存 + 复制 + 丢弃旧的"。不可变换来并发安全、驻留复用、哈希可缓存（见机制），代价是每次修改都重建。

连续布局还有个副产品：**缓存友好**。访问 `arr[i]` 时整条[缓存行](../../0-计算机基础/01-计算机体系/01-硬件组成.md)（64 字节，约 8 个 int）被拉进 L1，后续几个元素的访问几乎全命中。

## 数学模型

前缀和与差分是数组上最核心的两个区间技巧：一个把区间查询变 $O(1)$，一个把区间修改变 $O(1)$。

### 一维前缀和

构造 $prefix[0..n]$，令 $prefix[0]=0$ 为哨兵：

$$prefix[i+1] = prefix[i] + arr[i],\quad i \in [0, n-1]$$

区间 $[l, r]$ （含端点）的和：

$$S(l, r) = prefix[r+1] - prefix[l]$$

**正确性**： $prefix[r+1] = \sum_{i=0}^{r} arr[i]$， $prefix[l] = \sum_{i=0}^{l-1} arr[i]$，相减即 $\sum_{i=l}^{r} arr[i]$。查询 $O(1)$，构建 $O(n)$； $Q$ 次查询总代价 $O(n+Q)$。

> **洞察**：前缀和把"每次查询都重算"的代价前置到一次性构建——用 $O(n)$ 空间换 $Q$ 次 $O(n)\to O(1)$。

### 二维前缀和

$$prefix[i+1][j+1] = A[i][j] + prefix[i][j+1] + prefix[i+1][j] - prefix[i][j]$$

子矩阵 $(r_1,c_1)$ 到 $(r_2,c_2)$ （含端点）的和：

$$S = prefix[r_2\\!+\\!1][c_2\\!+\\!1] - prefix[r_1][c_2\\!+\\!1] - prefix[r_2\\!+\\!1][c_1] + prefix[r_1][c_1]$$

> **洞察**：包含-排除原理在离散网格上的直接应用——大矩形减去左、上两块，加回被重复减去的左上角。

### 差分数组

构造 $diff$：

$$diff[i] = \begin{cases} arr[0] & i = 0 \\ arr[i] - arr[i-1] & i > 0 \end{cases}$$

区间 $[l, r]$ 整体加 $\Delta$ 的等价操作：

$$diff[l] \mathrel{+}= \Delta,\quad diff[r+1] \mathrel{-}= \Delta$$

还原 $arr[i] = \sum_{j=0}^{i} diff[j]$ （即前缀和）。

> **洞察**：差分与还原互为逆操作，正如微分与积分。区间更新从 $O(r-l)$ 降到 $O(1)$，但单点查询变 $O(n)$，与朴素数组正好对偶。

## 数据流

### 数组物理布局与缓存行

<pre>
内存地址  B      B+s     B+2s    B+3s           B+(n-1)s
          ┌────────┬────────┬────────┬────────┬───┬────────┐
数组 arr  │ arr[0] │ arr[1] │ arr[2] │ arr[3] │...│ arr[n-1]│
          └────────┴────────┴────────┴────────┴───┴────────┘
          └─ 元素大小 s 字节，连续无间隔 ─┘

读 arr[i]: 物理地址 = B + i*s ──→ 一次访存
          └─→ 整条缓存行(64B)被拉进 L1，arr[i+1..i+7] 顺带命中
</pre>

连续布局给两个红利：地址可算（ $O(1)$ 访问）+ 空间局部性（顺序访问缓存命中）。

### 字符串拼接的数据流

<pre>
s = "hello"  (不可变对象 @0x1000, refcount=N)

执行 s += "world":
  1. 堆上分配新对象 @0x2000
  2. 复制 "hello"+"world" → "helloworld" 写入 0x2000
  3. s 改指向 0x2000；原 0x1000 的 refcount-1（归零则回收）
</pre>

不可变的核心保证：拼接不改原对象，任何持有旧引用的变量看到的仍是 "hello"。

### 数据形态变换

| 操作 | 输入 | 中间 | 输出 |
|------|------|------|------|
| `arr[i]` 读 | 下标 i | 地址 $B+i\cdot s$ | 元素值 |
| `arr[i]=x` 写 | 值 x | 地址 $B+i\cdot s$ | 覆盖原值 |
| `s1+s2` 拼接 | 两个不可变串 | 分配新堆对象 | 新字符串 |

## 对比参照

| 属性 | 数组（可变） | 链表 | 字符串（不可变） |
|------|-------------|------|------------------|
| 内存模型 | 连续物理地址 | 离散节点+指针 | 连续 + 只读约束 |
| 随机访问 | $O(1)$ 地址公式 | $O(n)$ 遍历 | $O(1)$ |
| 插入/删除 | $O(n)$ 搬移 | $O(1)$ 改指针 | $O(n)$ 重建副本 |
| 缓存友好 | 高（连续） | 低（分散） | 高，但写产生新副本 |

## 机制

### 缓存行、空间局部性与越界

缓存行 64 字节（x86-64/ARM64 主流平台）。顺序访问 $n$ 个元素，未命中约 $\lceil n/C \rceil$ 次（ $C$ = 每行装的元素数）；步长 ≥ 缓存行的跳跃访问则每次访问都未命中——拉进一整行只用到 1 个元素，缓存行利用率降到 $1/C$（命中率 ≈ 0）。链表遍历慢正是这个原理的极端版：节点分散、地址无规律，每次跳转都未命中。

**越界写入**：下标 $i \notin [0, n-1]$ 会被地址公式照样外推到数组外，覆盖相邻内存——缓冲区溢出，C/C++ 最常见漏洞根因。

### 字符串不可变的设计动机

不可变不是偶然，是刻意的：

1. **并发安全**：多线程读同一字符串无需同步，无数据竞争。
2. **驻留复用**：相同字面量共享同一对象（Python 字符串池、Java `intern()`），省内存、加速相等比较。
3. **哈希缓存**：内容永不变，哈希可安全预计算并缓存。
4. **安全边界**：权限检查后传引用，无需担心调用方在检查与使用间篡改（TOCTOU）。

**违反不可变的后果**（C 的 `char*`）：多指针指向同一缓冲，一方释放后他人悬空（use-after-free）；并发写无锁导致数据竞争；哈希后、使用前被改导致安全检查失效。

### 前缀和 vs 差分的适用边界

- **前缀和**：静态数据、写少读多。频繁更新会让每次更新 $O(n)$ 重算，失去优势——此时换树状数组/线段树， $O(\log n)$ 点更新+区间查询。
- **差分数组**：区间更新多、单点查询少。查询与更新各半时，差分均摊 $O(n)$ 与朴素持平，优势消失。

## 应用：双指针与滑动窗口

数组上最经典的降阶模式：用两个下标的协同扫描替代嵌套枚举。它们不是独立结构，而是数组连续布局的直接应用——正因为下标可加减、可随机访问，"移动指针排除候选"才成立；同样的思想搬到链表上就是快慢指针（见 02-链表 的 Floyd 判环）。

### 双指针：每步排除一批候选

两个下标按单调性或不变量移动，每移动一次排除一批候选对，把 $O(n^2)$ 枚举压到 $O(n)$。

**碰撞指针**（要求有序）：有序数组找两数之和为 `target`，设 $S=a[l]+a[r]$。 $S<\text{target}$ 时固定 $r$：所有 $l'\leq l$ 只会更小，整列排除，只能 $l$ 右移； $S>\text{target}$ 对称，只能 $r$ 左移。每步排除一行或一列，总步数 $\leq 2n$。排除的合法性来自单调性；无序数组要先排序（ $O(n\log n)$ ），而排序丢失原始下标——要求返回下标时此法不适用。

**三路指针**（荷兰国旗）：把数组划成四段并维护不变量：

$$[0,p_0)=0,\quad [p_0,i)=1,\quad [i,p_2)=\text{待处理},\quad [p_2,n)=2$$

遇 0 与 $p_0$ 交换后两者各进一；遇 1 直接 $i{+}{+}$；遇 2 与 $p_2$ 前一位交换但 $i$ 不动——换来的元素尚未处理，这是不变量不破的关键。 $i$ 与 $p_2$ 各至多移动 $n$ 步，总 $O(n)$。

### 滑动窗口：指针不可回退

`right` 只扩、`left` 只收，每个元素至多入窗一次、出窗一次，总移动 $\leq 2n=O(n)$。**命根是单调**：任何让 `left` 回退的写法都退化回 $O(n^2)$。收缩由窗口合法性谓词触发，且检测必须 $O(1)$ 增量可维护（计数字典/最新下标），否则线性同样崩溃。不漏解的原因：`right` 固定时 `left` 越大窗口越短、约束越易满足，最优窗口的 `left` 必落在"恰好满足约束"的临界点，单调收缩刚好停在那里。

窗口分两类：**固定窗口**大小恒为 $k$，`right` 每扩一格 `left` 跟收一格；**可变窗口**随约束收缩。可变窗口代表例——无重复字符最长子串：

<pre>
s = "abcabcbb", 可变窗口, 约束: 窗口内无重复字符

right=0 'a': {a}            len1 max1
right=1 'b': {a,b}          len2 max2
right=2 'c': {a,b,c}        len3 max3
right=3 'a': 重复 → left 0→1, 窗口 {b,c,a}  len3
right=4 'b': 重复 → left 1→2, 窗口 {c,a,b}  len3
right=5 'c': 重复 → left 2→3, 窗口 {a,b,c}  len3
right=6 'b': 重复(last[b]=4≥left=3) → left 3→5, 窗口 {c,b} len2
right=7 'b': 重复(last[b]=6≥left=5) → left 5→7, 窗口 {b}   len1

max_len = 3
</pre>

固定窗口求最值用单调队列（递减双端队列）：队尾弹掉被新元素遮挡的（它们永不再成最大），队首弹掉离开窗口的，每元素进出各一次，查询 $O(1)$。机制与单调栈同源，见 03-栈与队列。

## 代码示例

**Python 3.12**：

```python
# 前缀和：静态数组区间查询 O(1)，构建 O(n)
class PrefixSum:
    def __init__(self, nums):
        self.prefix = [0]              # prefix[0]=0 哨兵
        for num in nums:
            self.prefix.append(self.prefix[-1] + num)

    def range_sum(self, left, right):  # 区间 [left, right] 含端点
        return self.prefix[right + 1] - self.prefix[left]

# 差分数组：区间加 O(1)，还原 O(n)
def diff_range_add(diff, left, right, delta):
    diff[left] += delta
    if right + 1 < len(diff):          # 越界保护
        diff[right + 1] -= delta

def diff_recover(diff):
    arr = [0] * len(diff)
    arr[0] = diff[0]
    for i in range(1, len(diff)):      # 前缀和还原
        arr[i] = arr[i-1] + diff[i]
    return arr


# 碰撞指针: 有序两数之和, 返回 0-indexed 对
def two_sum_sorted(numbers, target):
    l, r = 0, len(numbers) - 1
    while l < r:
        s = numbers[l] + numbers[r]
        if s == target: return [l, r]
        if s < target:  l += 1
        else:           r -= 1
    return []

# 滑动窗口: 无重复字符最长子串, 可变窗口 + 字符最新下标
def length_of_longest_substring(s):
    last = {}                                # ch -> 最近下标
    left = best = 0
    for right, ch in enumerate(s):
        if ch in last and last[ch] >= left:  # 重复且在窗口内
            left = last[ch] + 1
        last[ch] = right
        best = max(best, right - left + 1)
    return best

# —— 简易输入输出 ——
ps = PrefixSum([1, 2, 3, 4, 5])
print(ps.range_sum(1, 3))              # 2+3+4 = 9

diff = [0] * 5
diff_range_add(diff, 1, 3, 10)         # 区间 [1,3] 各加 10
diff_range_add(diff, 0, 2, 5)          # 区间 [0,2] 各加 5
print(diff_recover(diff))              # [5, 15, 15, 10, 0]
print(two_sum_sorted([1, 2, 4, 6], 10))    # [2, 3]
print(length_of_longest_substring("abcabcbb"))  # 3
```

**C++20**：

```cpp
#include <iostream>
#include <vector>
#include <numeric>
#include <string>
#include <unordered_map>

// 前缀和：构建 O(n)，区间查询 O(1)
class PrefixSum {
    std::vector<long long> prefix{0};   // prefix[0]=0 哨兵
public:
    explicit PrefixSum(const std::vector<int>& nums) {
        prefix.reserve(nums.size() + 1);
        for (int x : nums) prefix.push_back(prefix.back() + x);
    }
    // 区间 [l, r] 含端点
    long long range_sum(int l, int r) const { return prefix[r + 1] - prefix[l]; }
};

// 差分：区间加 O(1)，还原用前缀和 O(n)
void diff_range_add(std::vector<long long>& diff, int l, int r, long long delta) {
    diff[l] += delta;
    if (r + 1 < (int)diff.size()) diff[r + 1] -= delta;  // 越界保护
}
std::vector<long long> diff_recover(const std::vector<long long>& diff) {
    std::vector<long long> arr(diff.size());
    arr[0] = diff[0];
    for (size_t i = 1; i < diff.size(); ++i) arr[i] = arr[i - 1] + diff[i];
    return arr;
}


// 碰撞指针: 有序两数之和, 返回 0-indexed 对
std::vector<int> twoSumSorted(const std::vector<int>& a, int target) {
    int l = 0, r = (int)a.size() - 1;
    while (l < r) {
        int s = a[l] + a[r];
        if (s == target) return {l, r};
        if (s < target) ++l; else --r;
    }
    return {};
}

// 滑动窗口: 无重复字符最长子串
int lengthOfLongestSubstring(const std::string& s) {
    std::unordered_map<char,int> last;
    int left = 0, best = 0;
    for (int right = 0; right < (int)s.size(); ++right) {
        char ch = s[right];
        if (last.count(ch) && last[ch] >= left) left = last[ch] + 1;
        last[ch] = right;
        best = std::max(best, right - left + 1);
    }
    return best;
}

// —— 简易输入输出 ——
int main() {
    PrefixSum ps({1, 2, 3, 4, 5});
    std::cout << ps.range_sum(1, 3) << '\n';             // 9

    std::vector<long long> diff(5, 0);
    diff_range_add(diff, 1, 3, 10);
    diff_range_add(diff, 0, 2, 5);
    for (auto v : diff_recover(diff)) std::cout << v << ' ';  // 5 15 15 10 0
    auto p = twoSumSorted({1,2,4,6}, 10);
    std::cout << '\n' << p[0] << ',' << p[1] << '\n';            // 2,3
    std::cout << lengthOfLongestSubstring("abcabcbb") << '\n';    // 3
}
```
