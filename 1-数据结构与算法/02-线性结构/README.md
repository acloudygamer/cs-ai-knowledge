# 线性结构

> **版本基准**: universal

本章回答一个问题：把"第 $i$ 个元素"折算成一次地址算术，是能拿到的最便宜的定位路径；同一条算式也冻结了"中间插入要搬移"。其余成员都在这套连续布局上加限制或换换算方式——链表取消连续性，位置改由指针给出；栈与队列不动布局，只限制出入口；哈希表用函数把键折算成桶位；字符串匹配则在字符数组上找模式。

五篇因此共用一本账：定位要几次访存、代价落在哪一层、什么时候失效。篇序按"从连续布局往外拆"排列，每一篇只回答定位路径怎么走、代价落在哪、什么条件下不再成立。

| 篇目 | 主链一句话 |
| --- | --- |
| 01 数组与字符串 | 地址公式 $B+i\times s$ 给出 $O(1)$ 定位，缓存行把一次取回放大成 16 个元素，中间插入要搬走后缀；前缀和与差分各换掉一半重复扫描，双指针与滑动窗口每步排除一批候选 |
| 02 链表 | 位置不可算、只能沿 `next` 走，于是定位 $O(n)$ 而改链 $O(1)$；哨兵消除边界判断，双向链表要先把邻居地址取出，快慢指针在环上做整除，LRU 淘汰靠哈希定位加双链改序 |
| 03 栈与队列 | 限制出入口就把次序固定成 LIFO 或 FIFO；循环队列用牺牲一格或额外计数区分空满，单调栈在弹出时结算答案，单调队列让窗口两端都能删 |
| 04 哈希表 | 键经哈希折算成桶号，均匀、快、抗构造三条约束压住哈希函数；冲突两族把代价分别放到链上比较与连续探测；负载因子越过阈值就扩容，摊还 $O(1)$；布隆过滤器用位数组换一个确定的"不在" |
| 05 字符串匹配 | 朴素法重复比较已被丢弃的窗口内容；KMP 用前缀函数让失配只退模式，Rabin-Karp 用滚动哈希把整窗比较换成一次乘加，AC 自动机把失败链搬到前缀树上做多模式一遍扫描 |
