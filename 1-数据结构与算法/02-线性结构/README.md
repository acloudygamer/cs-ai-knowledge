# 线性结构

> **版本基准**: universal

连续内存布局及其变体。数组给出 $O(1)$ 随机访问与缓存行红利；链表用指针跳转换掉连续约束，换来插入删除自由；栈与队列是在序列上限制出入口的访问纪律；哈希表是数组加哈希函数的随机化扩展；字符串匹配是字符数组上的模式查找问题。

组织逻辑：**布局决定代价**。每种结构先回答"元素在内存里怎么摆"，再推导每个操作的代价。
