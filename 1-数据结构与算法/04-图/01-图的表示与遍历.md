# 图的表示与遍历

此前几章的结构都在组织"元素怎么摆"：数组按下标、链表按指针、哈希表按摘要、树按父子。图组织的是"元素之间的连接"本身。关系成为数据之后，被优化的对象从"定位一次访问"变成"走通一条路径"。

一张 $10^5$ 个顶点、平均度 $20$ 的图，两种表示差三个量级。按无向图计，边数 $m=10^6$。邻接表存 $2m$ 个邻接项，每项 $8 \mathrm{B}$，加 $10^5$ 个表头共约 $16.8 \mathrm{MB}$。邻接矩阵按每格 $4 \mathrm{B}$ 是 $10^{10}$ 格，合 $40 \mathrm{GB}$。这道算例假设邻接项为顶点号与权重各 $4 \mathrm{B}$。

图上的问题分两类。结构探测问连通、环、拓扑序，路径查询问最短、最长。两类的算法都落在同一个动作上：从一个顶点沿边走到它的邻居。所以先定表示的账，再定遍历的次序。

## 一、顶点、边与度数：三个计数定下全章的账

### 1. 一张图只有三个数

图记作 $G=(V,E)$， $n$ 是顶点数， $m$ 是边数。有向边 $(u,v)$ 规定单向关系，无向边用两端的无序顶点对表示，规定双向对称关系。

顶点的度数是与它关联的边数，记为 $\deg(v)$。有向图把它拆成入度与出度：入边数与出边数。

两条恒等式撑起后面所有复杂度。无向图满足 $\sum_v \deg(v) = 2m$，即握手引理。有向图的出度之和与入度之和都等于 $m$。

度数之和与边数的关系是双向的。给定 $n$ 和 $m$，平均度就是 $2m/n$；给定 $n$ 与平均度 $d$，边数是 $nd/2$。这两个换算决定后面每一次复杂度折算。

### 2. 存一条无向边要登记两次

邻接表把无向边存成 $(u,v)$ 与 $(v,u)$ 两项，有向边只存一项。邻接矩阵里无向图对称填两格，有向图只填一格。

口径不统一， $m$ 就差一个因子 $2$。写下 $O(n+m)$ 时， $m$ 指邻接项数；无向图的邻接项是边数的两倍。

邻接项数还决定了枚举邻居的总代价。全部顶点的邻接项加起来正好是 $n+2m$，所以"把每个顶点的邻居都看一遍"是 $O(n+m)$，与顶点怎么编号无关。

## 二、两种表示： $O(n^2)$ 与 $O(n+m)$ 的置换

### 1. 邻接矩阵用 $n^2$ 个槽位买 $O(1)$ 判邻接

矩阵 $A$ 有 $n^2$ 格， $A[u][v]$ 存边权，无边记 $\infty$。判两点是否相邻读一格，代价 $O(1)$。枚举 $u$ 的邻居要扫一整行，代价 $O(n)$。空间只与 $n$ 有关，与 $m$ 无关。

无权图可以把每格压到 $1$ 位。 $10^4$ 个顶点的位矩阵是 $10^8$ 位，合 $12.5 \mathrm{MB}$。

矩阵的第二个用处是代数运算。可达性靠布尔矩阵乘、路径计数靠整数矩阵乘，这类问题在矩阵表示上是 $O(n^3)$ 的乘法，换到邻接表上写不出来。

### 2. 邻接表把空间压到 $O(n+m)$，判邻接退回 $O(\deg(u))$

每个顶点挂一条出边序列，总项数 $n+2m$（无向）。枚举 $u$ 的邻居与它的出边数成正比，全部顶点枚举一遍是 $O(n+m)$。判 $(u,v)$ 是否存在要沿 $u$ 的表扫过 $\deg(u)$ 项。

邻接表不要求边按任何次序存放，头插即可 $O(1)$ 加边。代价是同一顶点的邻居散落在内存各处，遍历时缓存命中率低于矩阵的整行扫描。

### 3. 判据是 $m$ 与 $n^2$ 的比值

两种表示的空间都写成式子。记邻接表空间为 $S_L$、矩阵空间为 $S_M$，每个邻接项 $b_L$ 字节，每格 $b_M$ 字节，每个表头 $b_H$ 字节：

$$S_L = n b_H + 2 m b_L,\quad S_M = n^2 b_M$$

邻接表更省的条件是 $2 m b_L + n b_H < n^2 b_M$。取 $b_M=4$、 $b_L=8$、 $b_H=8$，忽略 $n b_H$ 这一项，交叉点落在 $m^\ast \approx n^2/4$。换成平均度 $d=2m/n$，就是 $d \approx n/2$。

这个数说明"稀疏"是相对 $n^2$ 说的，不是相对某个固定边数说的。平均度几十的图，邻接表省两个量级以上；只有平均度接近 $n/2$，矩阵才在空间上追平。

| 代价或操作 | 邻接矩阵 | 邻接表 |
| --- | --- | --- |
| 空间 | $n^2$ 格，与 $m$ 无关 | $n+2m$ 项，与 $m$ 同阶 |
| 判两点相邻 | $O(1)$ | $O(\deg(u))$ |
| 枚举 $u$ 的邻居 | $O(n)$ | $O(\deg(u))$ |
| 遍历全图 | $O(n^2)$ | $O(n+m)$ |
| 加一条边 | $O(1)$，改一格 | $O(1)$，头插一项 |
| 适用工况 | 平均度接近 $n/2$ 的稠密图 | 平均度远小于 $n$ 的稀疏图 |

## 三、BFS：队列把顶点按距离分层

### 1. 队列里同时排着两层

广度优先搜索（Breadth-First Search，BFS）从源点 $s$ 出发，用先进先出队列保存待展开的顶点。

出队一个顶点，把它所有未访问的邻居置距离并入队。标记发生在入队时，而不是出队时：只标出队的顶点，同一顶点会被多个前驱重复入队，队列长度会涨到边数。

```text
邻接表：s→[a,b]  a→[c,d]  b→[d]  c→[g]  d→[g]  g→[]

队列（左出右入）   出队   动作                  距离
[s]                —      起点入队              s=0
[a,b]              s      a、b 入队             a=1 b=1
[b,c,d]            a      c、d 入队             c=2 d=2
[c,d]              b      d 已在队，跳过        不变
[d,g]              c      g 入队                g=3
[g]                d      g 已在队，跳过        不变
[]                 g      无出边                不变
```

队列里最多同时有两层：距离 $k$ 的顶点全排在距离 $k+1$ 的顶点之前。这条性质来自入队时机——新顶点只由当前层产生，而当前层还没出完。

### 2. 第一次到达就是最短路

无权图里， $s$ 到 $v$ 的最短距离就是路径经过的边数。

设 $v$ 首次被访问时在第 $d$ 层。任何一条 $s$ 到 $v$ 的路径，每走一条边最多让层号加一，所以边数不少于 $d$。另一方面 BFS 已经用 $d$ 条边走到了 $v$。两个方向合起来， $d$ 就是最短距离。

层号也给出路径本身：沿每个顶点的入队前驱回溯到 $s$，得到的边数正好是 $d$。

```python
from collections import deque

def bfs(adj: list[list[int]], s: int) -> list[int]:
    dist = [-1] * len(adj)          # -1 表示未访问
    dist[s] = 0
    q = deque([s])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if dist[v] == -1:       # 入队时定距，避免重复入队
                dist[v] = dist[u] + 1
                q.append(v)
    return dist
```

### 3. 每条边检查两次， $O(n+m)$ 是记账的结果

每个顶点入队一次、出队一次，共 $O(n)$ 次队列操作。每次出队扫该顶点的整条邻接表，所有扫描加起来是 $2m$ 项（无向）或 $m$ 项（有向）。

两项相加得 $O(n+m)$。矩阵实现没有这张表可扫，每次出队要扫一整行 $n$ 格，总计 $O(n^2)$。

这个界也是下界。连通图上每条边都要检查， $\Omega(m)$ 无法绕过，所以 $O(n+m)$ 已经是无权遍历的最优量级。

## 四、DFS：栈帧记住"下一条边试到哪"

### 1. 递归栈帧里存的不只是顶点

深度优先搜索（Depth-First Search，DFS）沿一条边一路走到底，走不动再退回上一个还有未试邻边的顶点。退回去的那个位置就是回溯点。

回溯点由两样东西确定：哪个顶点，以及它的邻接表查到第几项。只记顶点会丢掉第二样——显式栈只压顶点时，弹出后只能从邻接表第一项重扫，已访问的邻居全被跳过一次，总代价升到 $O(n \cdot m)$。

```text
递归版栈帧       (u, i)：u 是当前顶点，i 是下一个待查邻接项的下标
只压 u 的显式栈   弹出后从 adj[u][0] 重扫 → 每个顶点可能被扫多次 → O(n·m)
压 (u, i) 的栈    弹出后从 adj[u][i] 接着查 → 每条边只查一次 → O(n+m)
```

```python
def dfs(adj: list[list[int]], s: int) -> list[int]:
    seen, order = [False] * len(adj), [s]
    seen[s] = True
    stack = [(s, 0)]                 # (顶点, 下一个待查邻接项下标)
    while stack:
        u, i = stack[-1]
        if i == len(adj[u]):
            stack.pop()              # 邻边查完，回溯
            continue
        stack[-1] = (u, i + 1)       # 先推进下标，再压子顶点
        v = adj[u][i]
        if not seen[v]:
            seen[v] = True
            order.append(v)
            stack.append((v, 0))
    return order
```

栈深度最坏是 $n$，即链状的图。递归实现在这条链上要 $n$ 层调用帧， $10^6$ 个顶点的链足以压穿默认的 8 MB 线程栈，显式栈把同一笔空间放到堆上。

### 2. 两个时间戳分出树边与后向边

DFS 给每个顶点记两个时刻：发现时刻 $d(u)$ 与完成时刻 $f(u)$。顶点在两者之间处于"在栈上"的状态。

一条边若指向仍在栈上的顶点，称为后向边。它意味着存在一条从该顶点回到祖先的路径，与树边一起构成环。

```text
图：0→1、1→2、2→0、1→3，从 0 起 DFS

DFS(0)  d=1
├─ 0→1  DFS(1)  d=2
│   ├─ 1→2  DFS(2)  d=3
│   │   └─ 2→0  0 仍在栈上 → 后向边，图上存在环
│   │       完成 2  f=4
│   ├─ 1→3  DFS(3)  d=5
│   │       完成 3  f=6
│   └─ 完成 1  f=7
└─ 完成 0  f=8
```

后代关系对应区间包含： $v$ 是 $u$ 的后代，当且仅当 $d(u)<d(v)<f(v)<f(u)$。这条括号性质把所有边分成两类——落在某个区间内部的是树边或前向边，落在区间之间的另一端是横跨边。

判环判据直接落在后向边上：有向图有环，当且仅当某次 DFS 出现后向边。无向图同理，但要把回到父顶点的那条边排除。

### 3. 与 BFS 同阶，产出不同

| 维度 | BFS | DFS |
| --- | --- | --- |
| 保存待展开顶点 | 队列 | 栈，递归帧或显式栈 |
| 空间 | $O(n)$，最坏同时存一层以上 | $O(n)$，最坏是栈深 $n$ |
| 时间（邻接表） | $O(n+m)$ | $O(n+m)$ |
| 产出 | 层号即无权最短距离 | 发现与完成时刻、后向边 |
| 典型用途 | 无权最短路、最少跳数 | 判环、求分量、给拓扑序 |

两者都不检查同一条边两次以上，所以量级相同。差别全在次序带来的副产物上：BFS 的次序就是距离，DFS 的次序给出区间结构。

## 五、连通分量与强连通分量：一次 DFS 走干一块

### 1. 无向图的分量由外层循环数出来

从任一未访问顶点起 DFS，能走到的顶点恰好构成一个连通分量。外层循环对每个未访问顶点再起一次 DFS，起几次就有几个分量。

代价仍是 $O(n+m)$：每个顶点只进入一次，每条边只检查一次。

分量数 $k$ 与边数有一个下界： $k$ 个分量的图至少有 $n-k$ 条边，因为每个分量要连通，至少需要顶点数减一条边。等号成立时图是森林，每个分量是一棵树。

### 2. 有向图要两遍 DFS

强连通分量（Strongly Connected Component，SCC）是有向图中两两互达的极大顶点集。缩点把每个 SCC 压成一个顶点，得到的图是有向无环图（Directed Acyclic Graph，DAG）。

这一步是后面所有结论的基础：分量之间只有单向可达，不会绕回来，因此分量之间可以排序。

Kosaraju 算法用两遍 DFS 求出所有分量：

```text
① 在 G 上 DFS，记下每个顶点的完成时刻 f
② 把每条边反向，得到反图
③ 按 f 从大到小取未访问顶点，在反图上 DFS
④ 每棵 DFS 树就是一个 SCC
```

成立的理由在完成时刻上。第一遍结束时， $f$ 最大的顶点所在分量在缩点图里没有入边——若有分量指向它，那个分量的顶点会先被访问、后完成， $f$ 更大。

反图把这个方向倒过来：源分量在反图里没有出边。所以从它出发的 DFS 走不出去，恰好走干一个分量。取走这个分量后，剩余部分重复同一论证。

```text
G：0→1→2→0，2→3，3→4，4→3
第一遍 f：0=10，1=9，2=8，3=7，4=6
在反图上按 0、1、2、3、4 的顺序 DFS：
  从 0 出发：0→2→1，1 的邻居 0 已访问 → 分量 {0,1,2}
  从 3 出发：3→4，4 的邻居 3 已访问 → 分量 {3,4}
```

两遍都是 $O(n+m)$，总代价同阶。Tarjan 算法用一遍 DFS 加 low-link 值给出同一结果，省掉反图与第二遍遍历。

### 3. 缩点后的 DAG 是拓扑排序的输入

缩点消掉环，使"先做谁、后做谁"成为可回答的问题。每个分量内部互相可达，分量之间是单向依赖。

同一个顶点集，未缩点时没有拓扑序；缩点后一定有。这两句话是同一个事实的两面。

## 六、拓扑排序：入度为零的顶点先出队

### 1. Kahn 法：出队顺序就是拓扑序

拓扑序是顶点的线性排列，使每条有向边 $(u,v)$ 的 $u$ 都排在 $v$ 之前。只有 DAG 才有拓扑序。

Kahn 法维护每个顶点的入度，把入度为零的顶点放进队列。出队一个顶点，就把它所有出边的目标入度减一；减到零的目标入队。

```text
边：0→1、0→2、1→3、2→3、3→4，初始入度 in = [0,1,1,2,1]

队列       出队   入度更新              输出
[0]        0      1→0、2→0              [0]
[1,2]      1      3：2→1                [0,1]
[2]        2      3：1→0                [0,1,2]
[3]        3      4：1→0                [0,1,2,3]
[4]        4      无出边                [0,1,2,3,4]
```

正确性只看一件事：顶点出队时，它的所有前驱都已出队并把它的入度减掉了。所以出队顺序满足每条边的方向。

### 2. 处理数少于 $n$ 就是有环

环上每个顶点至少有一条来自环内的入边，入度永远减不到零，因此永远不会入队。

所以结束时计数小于 $n$，图就有环；等于 $n$ 时得到一个完整拓扑序。

这条判据与 DFS 的后向边判据观测的是同一个事实。Kahn 数计数，DFS 看时间戳。前者顺带给出序，后者不需要额外的入度数组。

### 3. 队列换成优先队列，得到字典序最小的序

入度为零的顶点常有多个，任取一个都得到合法拓扑序。要固定次序，例如每次取编号最小的顶点，把队列换成小顶堆，代价从 $O(n+m)$ 升到 $O((n+m)\log n)$。

同卷《堆与优先队列》「操作复杂度」给出 push 与 pop 各 $O(\log n)$；这里拿它给"每次取最小编号"定价。

唯一性判据：每一步入度为零的顶点恰好一个，拓扑序才唯一。某步出现两个入度为零的顶点时，交换它们的相对位置仍满足所有边，序就不唯一。
