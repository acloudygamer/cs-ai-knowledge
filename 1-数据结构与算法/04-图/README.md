# 图

> **版本基准**: universal

前面几章的结构都在组织"元素怎么摆"，图组织的是"元素之间的连接"本身。一旦关系成为数据，定位路径要让位给路径：问题从"这个键在哪"变成"从这点到那点的最便宜走法是什么"。

两篇构成一条链：第一篇给出图的两种表示与两种遍历，说明"从一点能到哪些点"怎样在 $O(V+E)$ 内回答；第二篇把"能到"升级成"最省"，最短路与生成树的分支全部由边的权与图的有环性决定。

| 篇目 | 主链与消费的前置结论 |
| --- | --- |
| 01 图的表示与遍历 | 顶点、边、度数 → 邻接矩阵与邻接表的空间-时间置换 → BFS 的层次即无权最短路 → DFS 的时间戳与回溯点 → 连通分量与强连通分量 → 拓扑排序与环检测 |
| 02 最短路与生成树 | 消费 01 的表示与队列 → 松弛是共同动作 → BFS、Dijkstra、Bellman-Ford 按权的符号分界 → 取最小结构决定复杂度 → 切分性质与 Prim/Kruskal → DAG 最长路与关键路径 |
