# 复杂度分析

## 定义

> **版本基准**: universal

复杂度分析是用**渐进记号**描述算法性能随输入规模增长的尺度定律，是算法选择与优化的理论基础。核心关注的是**增长趋势**而非具体数值——当 $n \to \infty$ 时，最高阶项主导。

复杂度分析之所以必要，是因为具体运行时间依赖硬件、编译器、编程语言，而增长趋势只依赖算法本身，在不同环境下保持稳定。

## 数学模型

### 渐进记号的严格定义

设 $f(n)$ 和 $g(n)$ 为定义在自然数集上的函数。

**紧确界 $\Theta(g(n))$**：

$$
\Theta(g(n)) = \{ f(n) : \exists c_1, c_2, n_0 > 0,\ \forall n \geq n_0,\ 0 \leq c_1 g(n) \leq f(n) \leq c_2 g(n) \}
$$

存在正常数倍数使 $f$ 被 $g$ 从上下界夹逼。

**上界 $O(g(n))$**：

$$
O(g(n)) = \{ f(n) : \exists c, n_0 > 0,\ \forall n \geq n_0,\ 0 \leq f(n) \leq c g(n) \}
$$

$f$ 不超过 $g$ 的常数倍。

**下界 $\Omega(g(n))$**：

$$
\Omega(g(n)) = \{ f(n) : \exists c, n_0 > 0,\ \forall n \geq n_0,\ 0 \leq c g(n) \leq f(n) \}
$$

$f$ 至少是 $g$ 的常数倍。

**非紧确上界 $o(g(n))$**：

$$
o(g(n)) = \{ f(n) : \forall c > 0,\ \exists n_0,\ \forall n \geq n_0,\ f(n) < c g(n) \}
$$

比 $O$ 更强：$f$ 必须严格小于 $g$（常数倍数下界为 0）。

### 复杂度等级的全序关系

$$
O(1) < O(\log n) < O(n) < O(n \log n) < O(n^2) < O(n^3) < O(2^n) < O(n!)
$$

**增长速率的可视化理解**：在双对数坐标纸上，$n^a$ 是斜率为 $a$ 的直线，指数 $2^n$ 在 $n$ 较大时急剧上扬。

### Master 定理（递归复杂度分析）

对于形如 $T(n) = aT(n/b) + f(n)$ 的递归式，$a \geq 1,\ b > 1$：

| 条件 | 结论 |
|------|------|
| $f(n) = O(n^{\log_b a - \varepsilon}),\ \varepsilon > 0$ | $T(n) = \Theta(n^{\log_b a})$ |
| $f(n) = \Theta(n^{\log_b a} \log^k n),\ k \geq 0$ | $T(n) = \Theta(n^{\log_b a} \log^{k+1} n)$ |
| $f(n) = \Omega(n^{\log_b a + \varepsilon}),\ \varepsilon > 0$ 且正则条件 | $T(n) = \Theta(f(n))$ |

**正则条件**：$a f(n/b) \leq c f(n)$ 对某个 $c < 1$ 成立，确保合并代价不被递归代价主导。

### 摊还分析

**聚合分析**：$n$ 次操作总代价 $T(n)$，摊还代价 $\hat{c} = T(n)/n$。关键：摊还分析不考虑单次操作的最坏情况，而是考虑整体序列的平均。

**势能方法**：设 $\Phi$ 为数据结构的势能函数，第 $i$ 次操作的摊还代价：

$$
\hat{c}_i = c_i + \Phi(D_i) - \Phi(D_{i-1})
$$

其中 $c_i$ 是实际代价，$\Phi$ 是势能差。典型例子：栈的 multipop 操作。

**核算法**：预先收取费用覆盖未来实际代价。典型例子：二进制计数器递增。

**归约终点**：摊还分析将"最坏情况单次代价"与"最坏情况序列总代价"区分开来。本质上，摊还分析是**势能守恒定律**在算法分析中的应用——某些操作的"浪费"被储存为势能，供后续操作"释放"使用。

### 递归树展开示例

$T(n) = 2T(n/2) + n$ 的递归树展开：

<pre>
第 1 层：  1 个节点，每个代价 n/1     →  n
第 2 层：  2 个节点，每个代价 n/2     →  n
第 3 层：  4 个节点，每个代价 n/4     →  n
...
第 log₂n 层：2^{log₂n} = n 个节点，每个代价 n/n = 1 → n
树高 = log₂n，每层总代价 = n
总代价 = n · log₂n = Θ(n log n)
</pre>

### 势能方法示例：栈的 multipop

<pre>
栈操作序列: push, push, pop×3 (multipop 一次弹出所有)

实际代价:
  push: c_i = 1
  multipop(k): c_i = k (弹出 k 个)

势能函数 Φ = 栈中元素个数

第 1 次 push: 实际代价 1，Φ 增 1
  摊还代价 = 1 + (1-0) = 2

第 2 次 push: 实际代价 1，Φ 增 1
  摊还代价 = 1 + (2-1) = 2

第 3 次 pop×3: 实际代价 3，Φ 减 3
  摊还代价 = 3 + (0-2) = 1

总摊还代价: 2 + 2 + 1 = 5
实际总代价: 1 + 1 + 3 = 5  ✓

摊还 O(1) = 总代价 O(n) / n 次操作
</pre>

## 机制

### 渐进记号为何忽略常数和低阶项？

**设计目的**：比较不同算法的增长趋势。当 $n$ 足够大时：
- $1000n$ 始终小于 $n^2$（存在 $n_0 = 1001$）
- $0.0001n^2$ 始终小于 $1000n \log n$（存在交点）

常数因子和低阶项在足够大的输入下被最高阶项淹没。

**约束**：$n_0$ 必须存在且足够大，使得渐近关系成立。在小规模输入下，$n_0$ 可能超过实际输入，导致低阶算法反而更慢。

**违反后果**：若忽略 $n_0$ 的存在，在实际可能的输入范围内可能选错算法。

### Master 定理的适用边界

**不适用情况**：
1. 子问题规模不对等（不是 $n/b$ 而是 $n-1$ 或 $n/2 + 1$）
2. 第三种情况不满足正则条件
3. 非多项式分裂（如 $T(n) = 2T(n/2) + n \log n$）

**不满足条件时**：使用递归树展开或代入法（substitution method）。

### 摊还分析与概率分析的根本区别

**摊还分析**：对**最坏情况序列**做均摊，不依赖输入分布。分析保证：任何长度为 $n$ 的操作序列，总代价不超过某个上界。

**概率分析**（随机算法）：对**输入分布**做期望，分析保证：输入服从某分布时，期望代价是多少。

两者都可能得到"均摊 O(1)"的结论，但保证的层面不同。

### 空间复杂度的递归栈深度

递归算法除输入数据外，还消耗调用栈空间。每次递归调用需保存返回地址、局部变量等，通常为 $O(1)$。

若递归深度为 $d$，则空间复杂度为 $O(d)$。例如：
- 二分查找递归深度：$O(\log n)$
- 归并排序递归深度：$O(\log n)$，但需额外 $O(n)$ 归并数组
- 斐波那契递归（无 memo）深度：$O(n)$，但时间复杂度 $O(2^n)$

## 参考存根

```python
def fib(n):
    if n <= 1:
        return n
    return fib(n-1) + fib(n-2)
# T(n) = T(n-1) + T(n-2) + O(1) ⇒ T(n) = O(2^n)
# 递归树高度 = n，空间复杂度 = O(n)

def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])   # T(n/2)
    right = merge_sort(arr[mid:])   # T(n/2)
    return merge(left, right)       # O(n)
# T(n) = 2T(n/2) + O(n) ⇒ Master 定理第二种情况: Θ(n log n)
```
