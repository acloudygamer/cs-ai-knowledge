# 复杂度分析

## 时间复杂度

### 渐进记号

| 记号 | 定义 | 含义 |
|-----|------|------|
| Θ(g(n)) | Θ(g(n)) = {f(n): ∃c₁,c₂,n₀ > 0, ∀n≥n₀, 0 ≤ c₁g(n) ≤ f(n) ≤ c₂g(n)} | 紧确界 |
| O(g(n)) | O(g(n)) = {f(n): ∃c,n₀ > 0, ∀n≥n₀, 0 ≤ f(n) ≤ cg(n)} | 上界 |
| Ω(g(n)) | Ω(g(n)) = {f(n): ∃c,n₀ > 0, ∀n≥n₀, 0 ≤ cg(n) ≤ f(n)} | 下界 |
| o(g(n)) | o(g(n)) = {f(n): ∀c>0, ∃n₀, ∀n≥n₀, 0 ≤ f(n) < cg(n)} | 非紧上界 |
| ω(g(n)) | ω(g(n)) = {f(n): ∀c>0, ∃n₀, ∀n≥n₀, 0 ≤ cg(n) < f(n)} | 非紧下界 |

### 常见复杂度等级

| 复杂度 | 名称 | 示例 |
|--------|------|------|
| O(1) | 常数 | 哈希查找 |
| O(log n) | 对数 | 二分查找 |
| O(n) | 线性 | 数组遍历 |
| O(n log n) | 线性对数 | 归并排序 |
| O(n²) | 平方 | 冒泡排序 |
| O(n³) | 立方 | 矩阵乘法 |
| O(2ⁿ) | 指数 | 递归斐波那契 |
| O(n!) | 阶乘 | 全排列 |

### 复杂度排序（从低到高）

```
O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(n³) < O(2ⁿ) < O(n!)
```

## 递归复杂度分析

### Master 定理（主定理）

**形式**: T(n) = aT(n/b) + f(n)，其中 a ≥ 1, b > 1

| 条件 | 结论 |
|-----|------|
| f(n) = O(n^{log_b(a-ε)})，ε > 0 | T(n) = Θ(n^{log_b(a)}) |
| f(n) = Θ(n^{log_b(a)} * log^k(n))，k ≥ 0 | T(n) = Θ(n^{log_b(a)} * log^{k+1}(n)) |
| f(n) = Ω(n^{log_b(a+ε)})，ε > 0，且满足 regularity condition | T(n) = Θ(f(n)) |

**regularity condition**: af(n/b) ≤ cf(n)，对某个 c < 1 和足够大的 n 成立

### Master 定理实例

| 递归式 | a | b | n^{log_b(a)} | f(n) | 结果 |
|--------|---|---|-------------|------|------|
| T(n) = 2T(n/2) + n | 2 | 2 | n | n | Θ(n log n) |
| T(n) = 2T(n/2) + n² | 2 | 2 | n | n² | Θ(n²) |
| T(n) = T(n/2) + O(1) | 1 | 2 | n⁰ = 1 | 1 | Θ(log n) |
| T(n) = 8T(n/2) + n³ | 8 | 2 | n³ | n³ | Θ(n³ log n) |

### 递归树法

将递归式展开为树形结构，每层代价之和即为总代价。

```python
# 递归树分析示例：T(n) = 2T(n/2) + n
# 第1层: n
# 第2层: 2 * (n/2) = n
# 第3层: 4 * (n/4) = n
# ...
# 树高: log n
# 总代价: n * log n = Θ(n log n)
```

### 代入法（Substitution Method）

猜测解的形式，用数学归纳法证明。

```python
# 证明 T(n) = O(n log n) for T(n) = 2T(n/2) + n
# 假设 T(k) ≤ c * k log k for all k < n
# T(n) = 2T(n/2) + n
#      ≤ 2 * c * (n/2) * log(n/2) + n
#      = c * n * (log n - log 2) + n
#      = c * n * log n - c * n + n
#      ≤ c * n * log n  (when c ≥ 1)
```

## 摊还分析

摊还分析求数据结构操作的平均代价，不涉及概率。

### 聚合分析（Aggregate Analysis）

总代价 T(n) 除以操作数 n 得到平均代价。

```python
# 示例：栈的 push/pop 和 multi-pop
# n 次操作，push O(1)
# 最多 n 次 push，所以 multi-pop 最多 n 次
# 总代价 O(n)，摊还代价 O(1)
```

### 势能方法（Potential Method）

定义势函数 Φ，摊还代价 = 实际代价 + ΔΦ

```python
# 栈的势函数：Φ = 栈中元素数量
# push: 实际代价 1，Φ 增加 1，摊还代价 = 2
# pop: 实际代价 1，Φ 减少 1，摊还代价 = 0
# multipop(k): 实际代价 min(k, s)，Φ 减少 min(k, s)，摊还代价 = 0
```

### 核算法（Accounting Method）

不同操作收取不同费用，余额用于支付未来操作。

```python
# 栈操作：
# push: 收费 2（1 支付自身，1 预存）
# pop: 收费 0（用预存余额支付）
# multipop: 收费 0（用预存余额支付）
```

## 空间复杂度

### 常见空间类型

- 原始数据类型：O(1)
- 数组/矩阵：O(n) / O(n²)
- 递归栈空间：O(递归深度)
- 动态规划表：O(n) / O(n²)

### 递归空间

```python
# 递归深度 = 树的高度
def fib_recursive(n):
    if n <= 1:
        return n
    return fib_recursive(n - 1) + fib_recursive(n - 2)
# 空间复杂度: O(n)（考虑递归栈）
```

### 空间优化

- 状态压缩：用一行代替整个DP数组
- 滚动数组：只保留必要的几行

```python
# 斐波那契空间优化
def fib_optimized(n):
    if n <= 1:
        return n
    prev, curr = 0, 1
    for _ in range(2, n + 1):
        prev, curr = curr, prev + curr
    return curr
# 空间: O(1)，原实现: O(n)
```

## 主定理详细推导

### 证明框架

递归树第 j 层有 a^j 个子问题，每个大小 n/b^j，代价为 a^j * f(n/b^j)

```
T(n) = Σ(j=0 to log_b(n)) a^j * f(n/b^j)
```

### 三种情况的几何意义

1. **情况一**: 叶节点主导（f(n) 增长慢于 n^{log_b(a)}) → 代价在叶节点
2. **情况二**: 各层代价平衡（f(n) 与 n^{log_b(a)} 同阶）→ log n 层，每层 Θ(n^{log_b(a)})
3. **情况三**: 根节点主导（f(n) 增长快于 n^{log_b(a)}) → 代价在根节点
