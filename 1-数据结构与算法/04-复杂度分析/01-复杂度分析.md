## 复杂度分析

### 定义

> 复杂度分析是用渐进记号描述算法性能随输入规模增长的尺度定律，是算法选择与优化的理论基础。

---

## 数学模型

### 渐进记号（Asymptotic Notation）

设 $f(n)$ 和 $g(n)$ 为定义在自然数集上的函数。

**紧确界 $\Theta(g(n))$**：
$$
\Theta(g(n)) = \{ f(n) : \exists c_1, c_2, n_0 > 0,\ \forall n \geq n_0,\ 0 \leq c_1 g(n) \leq f(n) \leq c_2 g(n) \}
$$

**上界 $O(g(n))$**：
$$
O(g(n)) = \{ f(n) : \exists c, n_0 > 0,\ \forall n \geq n_0,\ 0 \leq f(n) \leq c g(n) \}
$$

**下界 $\Omega(g(n))$**：
$$
\Omega(g(n)) = \{ f(n) : \exists c, n_0 > 0,\ \forall n \geq n_0,\ 0 \leq c g(n) \leq f(n) \}
$$

### 复杂度等级全序

$$
O(1) < O(\log n) < O(n) < O(n \log n) < O(n^2) < O(n^3) < O(2^n) < O(n!)
$$

### Master 定理（递归式复杂度）

对于形如 $T(n) = aT(n/b) + f(n)$ 的递归式，其中 $a \geq 1,\ b > 1$：

| 条件 | 结论 |
|------|------|
| $f(n) = O(n^{\log_b a - \varepsilon}),\ \varepsilon > 0$ | $T(n) = \Theta(n^{\log_b a})$ |
| $f(n) = \Theta(n^{\log_b a} \log^k n),\ k \geq 0$ | $T(n) = \Theta(n^{\log_b a} \log^{k+1} n)$ |
| $f(n) = \Omega(n^{\log_b a + \varepsilon}),\ \varepsilon > 0$ 且正则条件 | $T(n) = \Theta(f(n))$ |

### 摊还分析

聚合分析：$T(n) / n$；势能方法：$\hat{c}_i = c_i + \Delta \Phi$；核算法：预先收取费用以覆盖未来实际代价。

## 机制

### 渐进记号的设计目的

渐进记号忽略常数因子和低阶项，只保留增长趋势。这使得：
- **不同硬件环境下的算法比较成为可能**：常数因子随机器变化，但增长率不变
- **输入规模足够大时算法行为可预测**：当 $n \to \infty$，最高阶项主导

**约束**：常数 $c$ 必须为正；$n_0$ 为渐进成立的起点。

**违规后果**：若忽略常数因子，在小规模输入下可能选错算法（如 $1000n$ 在 $n < 100$ 时优于 $n^2$）。

### Master 定理的约束

- 子问题必须等规模划分（$n/b$ 而非 $n-1$）
- 第三种情况需满足正则条件：$a f(n/b) \leq c f(n)$ 对某个 $c < 1$ 成立

**违规后果**：不满足条件时 Master 定理不适用，需用递归树或代入法。

### 摊还分析与概率分析的区别

摊还分析的"平均"是**最坏情况序列的均摊**，不涉及输入分布的概率假设：
- 栈的 push/pop/multipop：$n$ 次操作总代价 $O(n)$，摊还 $O(1)$
- 动态数组扩容：均摊 $O(1)$，最坏单次 $O(n)$

**约束**：摊还上界不是每个操作的平均最坏情况。

## 参考存根

### 递归斐波那契的复杂度验证

```python
def fib(n):
    if n <= 1:
        return n
    return fib(n-1) + fib(n-2)
```
$T(n) = T(n-1) + T(n-2) + O(1) \Rightarrow T(n) = O(2^n)$

### Master 定理应用

```python
def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    return merge(left, right)
```
$a=2,\ b=2,\ f(n)=n \Rightarrow \Theta(n \log n)$（第二种情况）
