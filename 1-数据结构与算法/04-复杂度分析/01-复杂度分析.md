## 复杂度分析

### 解决什么问题
评估算法性能，指导算法选择与优化。通过分析时间/空间复杂度，在面试和工程中证明解法的优劣，指导代码实现决策。

### 核心概念
- **渐进记号**：O（上限）、Ω（下限）、Θ（紧确界）
- **复杂度等级**：O(1) < O(log n) < O(n) < O(n log n) < O(n^2) < O(2^n) < O(n!)
- **Master定理**：分析递归式复杂度
- **摊还分析**：求数据结构操作的平均代价

---

## 时间复杂度

### 渐进记号

| 记号 | 定义 | 含义 |
|-----|------|------|
| Θ(g(n)) | 紧确界 | f(n) 在 c1g(n) 和 c2g(n) 之间 |
| O(g(n)) | 上界 | f(n) 不超过 cg(n) |
| Ω(g(n)) | 下界 | f(n) 至少是 cg(n) |

### 常见复杂度等级

| 复杂度 | 名称 | 示例 |
|--------|------|------|
| O(1) | 常数 | 哈希查找 |
| O(log n) | 对数 | 二分查找 |
| O(n) | 线性 | 数组遍历 |
| O(n log n) | 线性对数 | 归并排序 |
| O(n^2) | 平方 | 冒泡排序 |
| O(2^n) | 指数 | 递归斐波那契 |
| O(n!) | 阶乘 | 全排列 |

### 复杂度排序（从低到高）

```
O(1) < O(log n) < O(n) < O(n log n) < O(n^2) < O(n^3) < O(2^n) < O(n!)
```

## 递归复杂度分析

### Master 定理（主定理）

**形式**: T(n) = aT(n/b) + f(n)，其中 a ≥ 1, b > 1

| 条件 | 结论 |
|-----|------|
| f(n) = O(n^{log_b(a-ε)})，ε > 0 | T(n) = Θ(n^{log_b(a)}) |
| f(n) = Θ(n^{log_b(a)} * log^k(n))，k ≥ 0 | T(n) = Θ(n^{log_b(a)} * log^{k+1}(n)) |
| f(n) = Ω(n^{log_b(a+ε)})，ε > 0 | T(n) = Θ(f(n)) |

### Master 定理实例

| 递归式 | 结果 |
|--------|------|
| T(n) = 2T(n/2) + n | Θ(n log n) |
| T(n) = 2T(n/2) + n^2 | Θ(n^2) |
| T(n) = T(n/2) + O(1) | Θ(log n) |
| T(n) = 8T(n/2) + n^3 | Θ(n^3 log n) |

### 递归树法

将递归式展开为树形结构，每层代价之和即为总代价。

```
T(n) = 2T(n/2) + n
第1层: n
第2层: 2 * (n/2) = n
第3层: 4 * (n/4) = n
...
树高: log n
总代价: n * log n = Θ(n log n)
```

## 摊还分析

摊还分析求数据结构操作的平均代价，不涉及概率。

### 三种方法

- **聚合分析**：总代价 T(n) 除以操作数 n
- **势能方法**：摊还代价 = 实际代价 + ΔΦ
- **核算法**：不同操作收取不同费用，余额用于支付未来操作

### 示例：栈的 push/pop 和 multi-pop

- n 次操作，最多 n 次 push
- multi-pop 最多 n 次
- 总代价 O(n)，摊还代价 O(1)

## 空间复杂度

### 常见空间类型

- 原始数据类型：O(1)
- 数组/矩阵：O(n) / O(n^2)
- 递归栈空间：O(递归深度)
- 动态规划表：O(n) / O(n^2)

### 递归空间

```python
def fib_recursive(n):
    if n <= 1:
        return n
    return fib_recursive(n - 1) + fib_recursive(n - 2)
# 空间复杂度: O(n)（考虑递归栈）
```

### 空间优化

- 状态压缩：用一行代替整个 DP 数组
- 滚动数组：只保留必要的几行
