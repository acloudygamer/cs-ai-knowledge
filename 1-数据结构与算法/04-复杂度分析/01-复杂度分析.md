# 复杂度分析

> **版本基准**：universal —— 代码示例同时使用 Python 3.12 与 C++20

## 本质

复杂度分析用**渐进记号**描述算法性能随输入规模 $n$ 增长的尺度定律，刻意忽略硬件/编译器/语言相关的常数因子，把算法抽象成 $n$ 的函数 $T(n)$ 以便数学上比较增长趋势。它的价值是不依赖运行环境—— $O(n\log n)$ 的归并对足够大的 $n$ 必胜 $O(n^2)$ 的冒泡，这个判断来自极限的阶的比较，而非实测。

工程上要记住它的边界：渐进只保证 $n\to\infty$ 的趋势，**忽略常数与低阶项**意味着存在交叉点 $n^*$，在 $n<n^*$ 时高常数低阶算法可能更快。复杂度分析给的是渐近保证，不含缓存命中、分支预测等实测因素——选型时它是必要而非充分依据。

## 数学模型

### 四种渐进记号

设 $f,g$ 为非负函数。渐进记号本质是**存在性量词约束的不等式**：

$$\Theta(g)=\{f:\exists c_1,c_2,n_0>0,\ \forall n\geq n_0,\ 0\le c_1 g\le f\le c_2 g\}\quad(\text{双向夹逼, 紧确界})$$

$$O(g)=\{f:\exists c,n_0>0,\ \forall n\ge n_0,\ 0\le f\le c g\}\quad(\text{上界})$$

$$\Omega(g)=\{f:\exists c,n_0>0,\ \forall n\ge n_0,\ 0\le c g\le f\}\quad(\text{下界})$$

$$o(g)=\{f:\forall c>0,\exists n_0,\ \forall n\ge n_0,\ f<c g\}\quad(\text{非紧上界, 严格小于})$$

关键区别： $O$ 是**存在**量词（ $\exists c$）， $o$ 是**全称**量词（ $\forall c$）。 $f=O(n^2)$ 说"存在常数使 $f$ 被 $n^2$ 控制"， $f=o(n^2)$ 说"任意小常数 $c$， $n$ 够大时 $f<cn^2$"——后者更强。

### 复杂度等级全序

$$O(1) < O(\log n) < O(n) < O(n\log n) < O(n^2) < O(n^3) < O(2^n) < O(n!)$$

对两不同等级 $a,b$， $\lim_{n\to\infty}a(n)/b(n)=0 \Leftrightarrow a=o(b)$。 $n$ 够大时低等级必胜高等级。

> **洞察**： $n! \gg 2^n \gg n^k$ 的根源是**增长率的本质差异**——多项式是"乘常数"，指数是"乘底数"，阶乘是"乘递增因子"。每跨一个量级， $n$ 翻倍带来的代价增长模式根本不同，这正是 $O$ 记号能跨硬件比较的根基。

### Master 定理

递归式 $T(n)=aT(n/b)+f(n)$， $a\geq1,b>1$，令 $c=\log_b a$：

| 条件 | 结论 | 物理图像 |
|------|------|---------|
| $f=O(n^{c-\epsilon})$ | $\Theta(n^c)$ | 叶子层主导，重量在树底 |
| $f=\Theta(n^c\log^k n),\ k\geq0$ | $\Theta(n^c\log^{k+1}n)$ | 各层同阶，每层都重要 |
| $f=\Omega(n^{c+\epsilon})$ 且正则 $af(n/b)\leq c'f(n)$ | $\Theta(f)$ | 根层主导，重量在树顶 |

不适用：子问题规模不对等、 $b$ 非常数、 $f$ 不满足任一条件——需用递归树或代入法。

### 摊还分析的势能模型

跨操作序列的代价守恒：某操作"过度消耗"预先以势能存储，供后续"免费"使用。设 $\Phi(D_i)$ 为第 $i$ 次操作后结构的势能，摊还代价：

$$\hat{c}_i = c_i + \Phi(D_i) - \Phi(D_{i-1}) = c_i + \Delta\Phi_i$$

$\Phi$ 须满足非负、 $\Phi(D_0)=0$，则 $\sum\hat{c}_i \geq \sum c_i$ ——总实际代价不超过总摊还代价。

## 数据流

### 递归树展开： $T(n)=2T(n/2)+n$

<pre>
层 i      节点数      每节点代价     该层总代价
─────────────────────────────────────────────────
0         1           n              n
1         2           n/2            n
2         4           n/4            n
...
L=log n   n           1              n
─────────────────────────────────────────────────
总代价 = n · (log n + 1) = Θ(n log n)
</pre>

每下沉一层，子问题规模减半（ $n\to n/2$）同时节点数翻倍（ $1\to2$），乘积守恒为 $n$ ——这是分治能否达到线性对数阶的关键：规模衰减与节点增长的精确平衡。

### 势能法：栈 multipop

<pre>
Φ(栈) = 栈中元素数

操作          实际 c  ΔΦ   摊还 ĉ=c+ΔΦ
push(x1)      1      +1   2
push(x2)      1      +1   2
push(x3)      1      +1   2
multipop(3)   3      -3   0     ← 高代价被前 3 次 push 的势能覆盖
─────────────────────────────────
总实际 6   总摊还 6   每操作摊还 O(1)
</pre>

**所有权变换**：势能 $\Phi$ 是数据结构状态的"虚拟账本"，不占真实存储；实际代价 $c_i$ 是真实消耗，摊还代价 $\hat{c}_i$ 把单次尖峰摊平到序列。

### 时间与空间的不对称（递归栈）

<pre>
递归树(时间):           栈深(空间):
     f(n)                  f(n)
    /    \                  |
  f(n/2) f(n/2)            f(n/2)      ← 同深度帧才共存
  ...                       ...
叶子 O(2^d) 个          深度 d 帧 O(d)

时间 = 树总节点数(指数级)    空间 = 树最大深度(线性/对数)
</pre>

无 memo 斐波那契：时间 $O(2^n)$ （指数级节点数），空间 $O(n)$ （最左路径深度）——同一算法两者量级不同。

## 对比参照

| 记号 | 方向 | 量词 | 用途 |
|------|------|------|------|
| $O$ | 上界 | $\exists c$ | 最坏/渐进上界 |
| $\Omega$ | 下界 | $\exists c$ | 问题下界、最优情况 |
| $\Theta$ | 双向 | $\exists c_1,c_2$ | 紧确界 |
| $o$ | 严格小于 | $\forall c$ | 等级分隔 |

| 分析类型 | 定义 | 是否依赖输入分布 |
|---------|------|----------------|
| 最坏 | $\max_x T(x)$ | 否 |
| 平均 | $\mathbb{E}_x[T(x)]$ | 是 |
| 最好 | $\min_x T(x)$ | 否 |
| 摊还 | 序列总代价/操作数 | 否（确定性） |

## 机制

### 为何能忽略常数与低阶项

$$\lim_{n\to\infty}\frac{1000n+3}{n^2}=0 \;\Rightarrow\; 1000n+3=o(n^2)$$

无论常数 1000 多大， $n>1000$ 时 $1000n<n^2$。渐近优势只在 $n\to\infty$ 成立；工程中存在交叉点 $n^*$， $n<n^*$ 时高阶算法可能更快。**违规后果**：对小数据盲目套渐近分析，可能选错算法——如小 $n$ 时 $O(n^2)$ 的插入排序实测常胜 $O(n\log n)$ 的归并/快排，`std::sort`（introsort）因此在小区间切到插入排序。

### 为何要分 worst/average/best

同算法对不同输入表现差异巨大。最坏 $T_{\text{worst}}=\max_x T(x)$ 给上界承诺（无需分布假设，选型标准）；平均 $T_{\text{avg}}=\mathbb{E}[T]$ 依赖分布假设；最好 $T_{\text{best}}=\min_x T(x)$ 描述最优输入。例：快排最坏 $\Theta(n^2)$ （已排序输入）、平均 $\Theta(n\log n)$；随机化快排打乱输入使最坏在实践中几乎不出现。

### 摊还 vs 概率分析

两者都给"平均"意义，但保证性质不同：**摊还**对任意输入序列确定性地有上界（不依赖分布）；**概率分析**对随机抽取输入给期望（依赖分布模型，偏离则失效）。一算法可同时"摊还 $O(1)$"且"单次最坏 $O(n)$"——摊还 $O(1)$ 指序列总代价被常数控制，不意味每操作都 $O(1)$。

### 递归栈的空间约束

空间由**最大递归深度**决定，非总调用次数。二分查找深 $O(\log n)$ 总空间 $O(\log n)$；归并深 $O(\log n)$ 但需 $O(n)$ 归并缓冲、总 $O(n)$；无 memo 斐波那契深 $O(n)$、总 $O(n)$。尾递归优化可把 $O(n)$ 深度降到 $O(1)$ （编译器支持时），但改变了算法结构。**违规后果**：递归深超系统栈（Linux 默认约 8MB、百万级）触发栈溢出。

### 违规后果

| 违规 | 后果 |
|------|------|
| 对小数据盲用渐近分析 | 选到常数极差的高阶算法，实测更慢 |
| 把 $O$ 当 $\Theta$ | 误以为紧确界，下界判断错 |
| 摊还 $\Phi$ 无下界 | $\sum\hat{c}$ 可能 $<\sum c$，摊还上界失效 |
| 递归深超栈大小 | 栈溢出段错误 |
| Master 用于 $b$ 非常数 | 结论不成立，需递归树 |

## 代码示例

**Python 3.12**：

```python
# 斐波那契: 无 memo 时间 O(2^n), 空间 O(n) (最左路径深度)
def fib(n):
    if n <= 1: return n
    return fib(n-1) + fib(n-2)
# T(n)=T(n-1)+T(n-2)+O(1) → O(2^n); 最大栈深 = n

# 归并排序: T(n)=2T(n/2)+O(n) → Master 情况2 → Θ(n log n); 空间 O(n)
def merge_sort(arr):
    if len(arr) <= 1: return arr
    mid = len(arr) // 2
    return _merge(merge_sort(arr[:mid]), merge_sort(arr[mid:]))
def _merge(a, b):
    c, i, j = [], 0, 0
    while i < len(a) and j < len(b):
        if a[i] <= b[j]: c.append(a[i]); i += 1
        else:            c.append(b[j]); j += 1
    c.extend(a[i:]); c.extend(b[j:]); return c

# 摊还示例: 二进制计数器递增, 摊还 O(1)
def increment(counter):           # k 位二进制数组
    i = 0
    while i < len(counter) and counter[i] == 1:
        counter[i] = 0            # 1→0 由信用支付
        i += 1
    if i < len(counter):
        counter[i] = 1            # 0→1 预付信用
# 最坏单次 k, 但 n 次总 O(n+k) → 每次摊还 O(1)

# —— 简易输入输出 ——
print(fib(10))                    # 55
print(merge_sort([5,2,4,7,1,3]))  # [1,2,3,4,5,7]
c = [1,1,1,0,0]; increment(c); print(c)  # [0,0,0,1,0]
```

**C++20**：

```cpp
#include <iostream>
#include <vector>

// 斐波那契: 无 memo, O(2^n) 时间, O(n) 栈深
long long fib(int n) {
    if (n <= 1) return n;
    return fib(n - 1) + fib(n - 2);
}

// 归并排序: Θ(n log n), 空间 O(n)
void mergeSort(std::vector<int>& a, int lo, int hi) {
    if (hi - lo <= 1) return;
    int mid = (lo + hi) / 2;
    mergeSort(a, lo, mid);
    mergeSort(a, mid, hi);
    std::vector<int> t(a.begin() + lo, a.begin() + hi);
    int i = 0, j = mid - lo, k = lo, n1 = mid - lo, n2 = hi - lo;
    while (i < n1 && j < n2)
        a[k++] = (t[i] <= t[j]) ? t[i++] : t[j++];
    while (i < n1) a[k++] = t[i++];
    while (j < n2) a[k++] = t[j++];
}

// 二进制计数器递增: 摊还 O(1)
void increment(std::vector<int>& c) {
    int i = 0;
    while (i < (int)c.size() && c[i] == 1) { c[i] = 0; ++i; }
    if (i < (int)c.size()) c[i] = 1;
}

int main() {
    std::cout << fib(10) << '\n';                 // 55
    std::vector<int> a = {5,2,4,7,1,3};
    mergeSort(a, 0, (int)a.size());
    for (int x : a) std::cout << x << ' ';        // 1 2 3 4 5 7
    std::cout << '\n';
    std::vector<int> c = {1,1,1,0,0};
    increment(c);
    for (int x : c) std::cout << x;               // 00010
    std::cout << '\n';
}
```
