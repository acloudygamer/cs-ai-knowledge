# 位运算

## 定义

位运算是对整数二进制表示的原子操作，利用硬件级 $O(1)$ 并行性，将集合操作、状态压缩等问题从线性降为常数时间。

## 数学模型

异或性质：
$$a \oplus a = 0, \quad a \oplus 0 = a, \quad a \oplus b \oplus b = a$$

lowbit 与消除：
$$\text{lowbit}(x) = x \& (-x), \quad x \& (x-1) \text{ 消除最低位 1}$$

奇偶判断：
$$n \text{ 为偶} \iff (n \& 1) = 0$$

## 数据流

<pre>
数字 12 (1100) 的 lowbit:
lowbit = 12 & (-12) = 1100 & 0100 = 0100 = 4

消除最低位1:
12 & (12-1) = 1100 & 1011 = 1000 = 8
8 & (8-1) = 1000 & 0111 = 0000 = 0
共消除2次 → 12二进制有2个1
</pre>

<pre>
数据形态变换:
int → bitstring (str) → bitwise operations → int
状态压缩: list[bool] → bitmask(int) → test/set bit → list[bool]
</pre>

## 机制

**为什么 $O(1)$ 空间**：位运算是硬件指令，在单个 CPU 周期内完成，不涉及额外数据结构。状态压缩将 $n$ 维布尔向量编码为 $\lceil n/wordsize \rceil$ 个整数。

**lowbit 的代数原理**：$-x = \sim x + 1$（补码定义），$x \& (-x)$ 保留从最低位1向右的所有位。

**状态压缩约束**：只能表示固定维度问题；维度过大会导致位掩码溢出或移位越界。

**常见误用**：带符号右移 `>>` 在负数上符号扩展，应使用无符号右移 `>>>`（Python 不存在此问题，整数无限精度且逻辑右移）。

## 参考存根

```python
def count_ones(n):
    count = 0
    while n:
        n &= n - 1
        count += 1
    return count

def single_number(nums):
    res = 0
    for n in nums: res ^= n
    return res
```
