# 位运算

## 定义

> **版本基准**: universal

位运算是对整数二进制表示进行原子级操作的技巧，利用硬件指令的 O(1) 并行性（ALU 在单时钟周期内处理整个字宽的所有位），将集合操作、状态压缩、算术优化等问题从线性或平方复杂度降至常数时间。位运算的核心优势不是"跑得更快"，而是"用更少的状态编码更多的信息"——n 个布尔值压缩为 $\lceil n/w \rceil$ 个机器字（w = 字宽，通常 32 或 64）。

## 数学模型

### 异或的群论视角

异或（XOR, $\oplus$ ）在 $\{0,1\}^n$ （视为 $n$ 维二元向量空间）上构成阿贝尔群：

$a \oplus a = 0,\quad a \oplus 0 = a,\quad a \oplus b \oplus b = a$

**证明（自反性）**：对任意 $a \in \{0,1\}$ ， $a \oplus a$ 的每一位：  $0\oplus 0 = 0$，  $1\oplus 1 = 0$（相同为 0）。故  $a \oplus a = 0$。

**单值出现问题的解**：若数组中除一个数出现一次外，其余数均出现两次，则：
$\text{result} = \bigoplus_{i=1}^{n} \text{nums}[i]$

相同数两次异或抵消为 0，最终结果即为唯一数。

### lowbit 与补码代数

**代数定义**：

$\text{lowbit}(x) = x\ \&\ (-x)$

**证明**：设 $x$ 的二进制中最低的 1 在第 $k$ 位（从 0 开始）：
$x = \underbrace{b_{n-1}\ldots b_{k+1}}_{\text{第 }k\text{ 位以前}} 1 \underbrace{0\ldots 0}_{k\text{ 个 0}}$

在补码表示下， $-x = \sim x + 1$ 。由于 $x$ 在第 $k$ 位为 1 且低 $k$ 位全为 0， $\sim x$ 在第 $k$ 位为 0、低 $k$ 位全为 1。 $\sim x + 1$ 产生进位逐位传播，仅在第 $k$ 位保留 1。因此：

$x\ \&\ (-x) = 2^k$

**消除最低位 1**：

$x\ \&\ (x-1)$

$x-1$ 将 $x$ 的最低位 1 变为 0，该位右侧全部变为 1。两者按位与后，第 $k$ 位变 0，低于 $k$ 的位全变成 0。每次循环消除一个最低位的 1，消除次数 = popcount(x)。

### Two's Complement 表示范围

$w$ 位有符号整数范围： $[-2^{w-1},\ 2^{w-1}-1]$ 。负数 $-x$ 的表示为  $2^w - x$（模  $2^w$）。

| 运算 | 有符号溢出 | 无符号溢出 |
|------|-----------|-----------|
| 语义 | 截断为 $[-2^{w-1}, 2^{w-1}-1]$ | 模 $2^w$ 归约 |
| 典型语言 | C/Java（有 UB / 补码截断） | C/Java |
| Python | 任意精度，永不溢出 | N/A |

**归约终点**：位运算是**有限域 $\mathbb{F}_2$ 上的线性代数**。异或对应向量加法，与/或对应向量空间中的投影。状态压缩将布尔向量编码为有限域元素，算术运算可在单机器字内并行完成。

## 数据流

### 状态压缩：集合 → 位掩码

<pre>
n=9 棋盘状态压缩（9 个位置 → 1 个整数）:
  bit index:  8 7 6
              5 4 3
              2 1 0

初始: mask = 0 (无棋子)

放棋子到位置 4 (中心):
  mask' = mask | (1 << 4) = 0 | 0b100000000 = 0b100000000

检测位置 4 是否有棋子:
  (mask >> 4) & 1 = 1 → 有

移除位置 4:
  mask' = mask & ~(1 << 4) = 0b100000000 & ~0b100000000 = 0

数据形态变换:
  list[bool](9个布尔) ←→ bitmask(int) ←→ set/test/clear operations
  一个整数替代了 9 个独立布尔变量，状态转移在 O(1) 内完成
</pre>

### 子集枚举（状态压缩 DP）

<pre>
原集合 S = {0, 1, 2, 3}，掩码范围 0..2^4-1

遍历所有子集:
for mask in range(1 << 4):
    submask = mask
    while submask:
        process(submask)
        submask = (submask - 1) & mask  # 枚举 mask 的所有非空子集
    process(0)  # 空子集

mask = 3 (0b0011) 时的子集枚举:
  submask = 3 → process → submask = (3-1)&3 = 2 → process
  → submask = (2-1)&3 = 1 → process → submask = (1-1)&3 = 0 → 结束
  结果: 3, 2, 1 (以及隐含的 0)

数学依据: (submask - 1) & mask 消除 submask 最低位的 1，
         连续消除直到 0，保证枚举了 mask 的所有非空子集且不重复
</pre>

### lowbit 逐位分解

<pre>
x = 12 = 0b1100

第1次循环:
  lowbit = 12 & (-12) = 0b1100 & 0b0100 = 0b0100 = 4
  x = x & (x-1) = 0b1100 & 0b1011 = 0b1000 = 8

第2次循环:
  lowbit = 8 & (-8) = 0b1000 & 0b1000 = 0b1000 = 8
  x = x & (x-1) = 0b1000 & 0b0111 = 0b0000 = 0

结束: 执行 2 次 → popcount(12) = 2

popcount 实际应用: 汉明距离（两数不同位的个数）= popcount(x ^ y)
</pre>

## 机制

### 为什么位运算是 O(1) 空间？

空间复杂度描述的是**额外数据结构**。位运算在 CPU 寄存器中完成，不涉及堆分配或数组索引，因此 O(1) 额外空间。状态压缩将 n 维布尔向量编码为 O(1) 个机器字，而非 O(n) 个布尔数组——这是编码效率的提升，不是空间复杂度的降低。

### 有符号右移 vs. 无符号右移

| 操作 | 行为 | 适用场景 |
|------|------|---------|
| `>>`（算术右移） | 低位丢弃，符号位复制填充高位 | 有符号负数除以 2（向下取整） |
| `>>>`（逻辑右移） | 低位丢弃，零填充高位 | 无符号数右移，位字段提取 |

Java/C 中 `>>` 是算术右移，`>>>` 是逻辑右移。对负数使用算术右移会符号扩展，保持负数数值（除以 2 向下取整）；逻辑右移则将负数视为大正数。

Python 中整数是无限精度的无限长补码序列（实际是符号扩展的无限 1 序列），右移是逻辑右移：`(-1) >> 1 == -1` 因为高位无限填充 1。

### 位运算溢出边界

在固定字宽语言（C/Java）中，当移位量 `k >= w` 时行为未定义（C）或被截取低 5/6 位（Java）。Python 无此问题。

| 场景 | C/Java | Python |
|------|--------|--------|
| 1 << 31 (32位) | 若为 int 则溢出 | 正确结果 2147483648 |
| 移位量 >= 字宽 | 未定义或截取低位 | 正确计算 |
| 无符号乘法溢出 | 模 $2^w$ 截断 | 任意精度 |

### 常见位运算模式

| 目的 | 表达式 | 说明 |
|------|--------|------|
| 取第 $k$ 位 | `(n >> k) & 1` | 右移后取最低位 |
| 置第 $k$ 位为 1 | `n | (1 << k)` | 或运算 |
| 清除第 $k$ 位 | `n & ~(1 << k)` | 取反后按位与 |
| 翻转第 $k$ 位 | `n ^ (1 << k)` | 异或 |
| 判断 2 的幂 | `n > 0 and (n & (n-1)) == 0` | 只有最高位为 1 |
| 绝对值（无分支） | `(n ^ (n >> 31)) - (n >> 31)` | 32 位有符号；负数取反+1 |
| 交换两数 | `a ^= b; b ^= a; a ^= b` | 需保证 a != b（同一内存会变0） |
| 统计不同位 | `popcount(a ^ b)` | 汉明距离 |

### 布隆过滤器的位数组

使用 $m$ 位数组和 $k$ 个独立哈希函数 $h_1, \ldots, h_k$ 。插入 $x$ 时，将 $h_i(x)$ 映射的 $k$ 个位置设为 1。查询时检查所有 $k$ 个位置是否均为 1。

**假阳性概率**：设插入 $n$ 个元素，位数组未被填充的比例为 $(1 - 1/m)^{kn} \approx e^{-kn/m}$ 。某位为 0 的概率为 $e^{-kn/m}$ ，所有 $k$ 位为 1 的概率为 $(1 - e^{-kn/m})^k$ 。

**约束**：无法删除元素（可能有其他元素也映射到该位）；假阳性率随 $n$ 增长而上升。

### 位运算在状态机中的应用

位掩码在状态机中用于高效编码状态转换。设状态数为 $2^n$ ，可用 $n$ 位掩码表示：

- **状态转移矩阵**：每个状态（掩码）可编码转换到其他状态的动作
- **可达性分析**：BFS/DFS 中用掩码标记已访问状态，避免重复访问
- **骑士巡逻/八皇后等搜索问题**：棋盘格子用位编码，约束检查用位运算完成

**性能优势**：位运算的并行性（单指令操作 $w$ 位）使得检查合法性的复杂度从 $O(n)$ 降至 $O(1)$ 。

## 参考存根

```python
def count_ones(n):
    """Brian Kernighan 算法：统计 1 的个数"""
    count = 0
    while n:
        n &= n - 1  # 消除最低位的 1
        count += 1
    return count

def single_number(nums):
    """除一个数外其他均出现两次，求该数"""
    res = 0
    for n in nums:
        res ^= n
    return res

def is_power_of_two(n):
    """判断是否为 2 的幂"""
    return n > 0 and (n & (n - 1)) == 0

def bitwise_swap(a, b):
    """无临时变量交换（需 a != b）"""
    a ^= b
    b ^= a  # b = (a ^ b) ^ b = a
    a ^= b  # a = (a ^ b) ^ a = b
    return a, b

def get_bit(n, k):
    return (n >> k) & 1

def set_bit(n, k):
    return n | (1 << k)

def clear_bit(n, k):
    return n & ~(1 << k)

def lowest_bit_position(n):
    """返回最低位 1 的位置（0-indexed），n > 0"""
    return (n & -n).bit_length() - 1

def subsets(nums):
    """通过位掩码枚举所有子集"""
    n = len(nums)
    res = []
    for mask in range(1 << n):
        subset = [nums[i] for i in range(n) if mask & (1 << i)]
        res.append(subset)
    return res

def hamming_distance(x, y):
    """两数不同位的个数"""
    return count_ones(x ^ y)
```
