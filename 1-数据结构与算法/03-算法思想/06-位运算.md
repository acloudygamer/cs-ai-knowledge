## 位运算

### 解决什么问题
用 O(1) 额外空间实现算法，适用于状态压缩、集合表示、布隆过滤器哈希函数、棋盘状态等问题。

### 核心概念
- **异或性质**：a^a=0，a^0=a，满足交换律和结合律
- **位掩码**：用整数的位表示集合状态
- **lowbit**：最低位1的值，x & (-x)
- **状态压缩**：将复杂状态压缩为整数位

### 常用操作

| 操作 | 表达式 |
|------|--------|
| 获取第 i 位 | `(n >> i) & 1` |
| 将第 i 位置 1 | `n \| (1 << i)` |
| 将第 i 位置 0 | `n & ~(1 << i)` |
| 最低位的 1 | `n & (-n)` |
| 清除最低位的 1 | `n & (n - 1)` |
| 判断奇偶 | `n & 1` |
| 2 的幂判断 | `n > 0 and (n & (n - 1)) == 0` |

## 基本位运算技巧

### 异或交换与求反

### 参考样例

```python
def swap(a, b):
    a = a ^ b
    b = a ^ b
    a = a ^ b
    return a, b

def negate(a):
    return ~a + 1
```

### 统计1的个数

Brian & Kernighan 算法：每次消除最低位的1。

### 参考样例

```python
def count_ones(n):
    count = 0
    while n:
        n &= (n - 1)
        count += 1
    return count
```

### 只出现一次的数字

**LeetCode 136**：除一个元素外其他都出现两次，利用异或性质。

### 参考样例

```python
def single_number(nums):
    result = 0
    for num in nums:
        result ^= num
    return result
```

### 只出现一次的数字 II

除一个元素外其他都出现三次，利用位运算统计每一位。

### 参考样例

```python
def single_number_ii(nums):
    result = 0
    for i in range(32):
        bit_sum = 0
        for num in nums:
            bit_sum += (num >> i) & 1
        if bit_sum % 3:
            result |= (1 << i)
    return result
```

### 只出现一次的数字 III

两个元素只出现一次，其他出现两次。分组异或。

### 参考样例

```python
def single_number_iii(nums):
    xor = 0
    for num in nums:
        xor ^= num
    diff = xor & (-xor)
    result = 0
    for num in nums:
        if num & diff:
            result ^= num
    return [result, xor ^ result]
```

## 比特位计数

**LeetCode 338**：动态规划，i & (i-1) 的结果 +1。

### 参考样例

```python
def count_bits(n):
    dp = [0] * (n + 1)
    for i in range(1, n + 1):
        dp[i] = dp[i & (i - 1)] + 1
    return dp
```

## 数字范围按位与

**LeetCode 201**：找到公共前缀，右移直到相等。

### 参考样例

```python
def range_bitwise_and(left, right):
    shift = 0
    while left < right:
        left >>= 1
        right >>= 1
        shift += 1
    return left << shift
```

## 颠倒二进制位

**LeetCode 190**：分治交换，两两交换，四四交换。

### 参考样例

```python
def reverse_bits(n):
    n = (n >> 16) | ((n & 0xFFFF) << 16)
    n = ((n & 0xFF00FF00) >> 8) | ((n & 0x00FF00FF) << 8)
    n = ((n & 0xF0F0F0F0) >> 4) | ((n & 0x0F0F0F0F) << 4)
    n = ((n & 0xCCCCCCCC) >> 2) | ((n & 0x33333333) << 2)
    n = ((n & 0xAAAAAAAA) >> 1) | ((n & 0x55555555) << 1)
    return n
```

## 位运算实现加减乘除

### 参考样例

```python
def add(a, b):
    while b:
        carry = a & b
        a = a ^ b
        b = carry << 1
    return a

def subtract(a, b):
    return add(a, add(~b, 1))

def multiply(a, b):
    result = 0
    while b:
        if b & 1:
            result = add(result, a)
        a <<= 1
        b >>= 1
    return result
```

## O(1) 时间获取随机数

用 rand7() 实现 rand10()，拒绝采样。

### 参考样例

```python
import random

class RandomBit:
    def rand7(self):
        return random.randint(1, 7)

    def rand10(self):
        while True:
            num = (self.rand7() - 1) * 7 + (self.rand7() - 1)
            if num < 40:
                return (num % 10) + 1
```

## 复杂度总结

| 操作 | 时间 | 空间 |
|------|------|------|
| 基本位运算 | O(1) | O(1) |
| 统计 1 的个数 | O(k)，k 为 1 的个数 | O(1) |
| 查找只出现一次的数 | O(n) | O(1) |
| 数字范围按位与 | O(log n) | O(1) |
