# 位运算

> **版本基准**：universal —— 代码示例同时使用 Python 3.12 与 C++20

## 本质

位运算在整数的二进制位上做原子级操作。它的真正优势不是"跑得快"——而是 ALU 在单时钟周期内对整个机器字（32/64 位）的所有位**并行**处理，于是 $n$ 个布尔的状态可以压进 $\lceil n/w \rceil$ 个机器字里，集合的交/并/差/包含判断都退化成一条位指令。一句话：用更少的状态编码更多的信息，把原本 $O(n)$ 的逐元素操作压成 $O(1)$ 的字级并行。

工程上要警惕两件事：**有符号 vs 无符号**的右移语义不同（算术右移符号扩展、逻辑右移零填充），以及**移位量 $\geq$ 字宽**在 C/Java 里是未定义或截断行为（Python 无此问题，整数任意精度）。

## 数学模型

### 异或的群结构

异或 $\oplus$ 在 $\{0,1\}^n$ （ $n$ 维二元向量空间）上构成阿贝尔群，恒等元为 $0$、每个元素自逆：

$$a \oplus a = 0,\quad a \oplus 0 = a,\quad a \oplus b \oplus b = a$$

逐位看即"相同为 0、不同为 1"，故 $a \oplus a$ 每位归零。这正是"单值出现"问题的解：除一个数外其余均出现两次时，

$$\text{result} = \bigoplus_{i=1}^{n} \text{nums}[i]$$

成对数自相抵消为 0，剩下唯一那个出现一次的数。

> **洞察**：异或是 $\mathbb{F}_2$ 上的向量加法，与/或对应投影。位运算的本质是把布尔向量当作 $\mathbb{F}_2$ 上的元素，让加法/乘法在单机器字内并行完成。

### lowbit 与补码代数

$\text{lowbit}(x) = x\ \&\ (-x)$，取出 $x$ 最低位的 1 及其以下的全 0，结果恰为 $2^k$ （ $k$ 为最低 1 的位置）。

**证明**：补码下 $-x = \sim x + 1$。设 $x$ 第 $k$ 位为 1、低 $k$ 位全 0，则 $\sim x$ 第 $k$ 位为 0、低 $k$ 位全 1； $\sim x + 1$ 的低 $k$ 个 1 加 1 后逐位进位归零、仅在第 $k$ 位留下 1。与 $x$ 按位与后高于 $k$ 的位全 0（因 $-x$ 高位被取反），结果为 $2^k$。

**消最低位 1**： $x\ \&\ (x-1)$。 $x-1$ 把最低位 1 置 0、其右全置 1，与 $x$ 相与后该位清零、低位也归零，循环执行次数即 `popcount(x)`——这是 Brian Kernighan 计数法的根。

### 补码表示范围

$w$ 位有符号整数范围 $[-2^{w-1},\ 2^{w-1}-1]$，负数 $-x$ 表示为 $2^w - x$ （模 $2^w$）。绝对值无分支技巧就源自此：

$$|n| = (n \oplus (n \gg 31)) - (n \gg 31)$$

$n \geq 0$ 时 $n \gg 31 = 0$，结果即 $n$； $n < 0$ 时 $n \gg 31 = -1$ （全 1）， $n \oplus (-1) = \sim n$， $\sim n - (-1) = \sim n + 1 = -n$。

## 数据流

### 状态压缩：集合 → 位掩码

<pre>
9 格棋盘 → 1 个整数, bit i 表示位置 i 是否落子

放子到位置 4:  mask | (1 << 4)
查位置 4:       (mask >> 4) & 1   → 0/1
移除位置 4:     mask & ~(1 << 4)
翻转位置 4:     mask ^ (1 << 4)

一个整数替代 9 个布尔变量，增删查改各一条指令，O(1)
</pre>

**所有权变换**：原本散落的 $n$ 个布尔被收编进一个整数的各 bit 位，集合运算从"逐元素循环"压缩为"单次字级按位指令"。

### 子集枚举：`(sub - 1) & mask` 遍历子掩码

<pre>
mask = 3 (0b0011), 枚举其所有非空子集:
  sub = 3          → 处理
  sub = (3-1)&3 = 2 → 处理
  sub = (2-1)&3 = 1 → 处理
  sub = (1-1)&3 = 0 → 结束
枚举顺序: 3, 2, 1 (子集递减), 不重不漏

依据: (sub-1) 把 sub 最低位 1 清零、其右全置 1，
      与 mask 相与保证只在 mask 的 1 位范围内变化
</pre>

子集枚举总复杂度 $O(3^n)$ （所有掩码的子掩码数之和），是状压 DP 的常用骨架。

### lowbit 逐位分解

<pre>
x = 12 = 0b1100

循环1: lowbit = 12 & -12 = 4 (0b0100), x &= x-1 → 0b1100 & 0b1011 = 8
循环2: lowbit = 8  & -8  = 8 (0b1000), x &= x-1 → 0b1000 & 0b0111 = 0
结束: 2 次 → popcount(12) = 2

应用: 汉明距离 = popcount(x ^ y)
</pre>

## 对比参照

| 维度 | 算术右移 `>>` | 逻辑右移 `>>>` |
|------|--------------|----------------|
| 高位填充 | 符号扩展 | 零填充 |
| 负数行为 | 保持负值（÷2 向下取整） | 变成大正数 |
| 语言 | C/Java 有符号 | Java/C 无符号 |
| Python | 无限补码，`(-1)>>1 == -1` | 无原生 `>>>` |

## 机制

### 为什么位运算是 $O(1)$ 空间

空间复杂度计量**额外数据结构**。位运算在寄存器内完成、无堆分配，故 $O(1)$。状压把 $n$ 维布尔向量编进 $O(1)$ 个机器字，是**编码效率**的提升，不是"空间复杂度降维"——它省掉的是逐元素数组与循环，不是渐近空间。

### 移位与字宽边界

固定字宽语言里移位量 $k \geq w$ 在 C 中是**未定义行为**、在 Java 中截取低 5/6 位。Python 整数任意精度，`1 << 100` 合法。跨语言移植位运算代码时这是隐藏地雷：在 Python 验证正确、搬到 C 却因溢出或截断出错。

### 常见位运算模式

| 目的 | 表达式 | 说明 |
|------|--------|------|
| 取第 $k$ 位 | `(n >> k) & 1` | 右移后取最低位 |
| 置第 $k$ 位 | `n \| (1 << k)` | 或 |
| 清第 $k$ 位 | `n & ~(1 << k)` | 取反后按位与 |
| 翻转第 $k$ 位 | `n ^ (1 << k)` | 异或 |
| 判 2 的幂 | `n > 0 && !(n & (n-1))` | 仅最高位为 1 |
| 消最低位 1 | `n & (n-1)` | popcount 循环 |
| 取最低位 1 | `n & -n` | lowbit |
| 无分支绝对值 | `(n ^ (n>>31)) - (n>>31)` | 32 位有符号 |
| 汉明距离 | `popcount(a ^ b)` | 不同位计数 |

### 布隆过滤器的位数组

$m$ 位数组 + $k$ 个独立哈希函数。插入 $x$ 把 $h_i(x)$ 对应的 $k$ 位都置 1；查询时这 $k$ 位全 1 才"可能存在"。插入 $n$ 个元素后某位仍为 0 的概率 $\approx e^{-kn/m}$，假阳性率：

$$\left(1 - e^{-kn/m}\right)^k$$

**约束**：不可删除（一位可能被多个元素共享）；假阳性随 $n$ 升高。位运算让"置 1 / 查 1"成为单指令操作，是布隆过滤器能高吞吐的根因。

### 违规后果

| 违规 | 后果 |
|------|------|
| 移位量 $\geq$ 字宽（C 中） | 未定义行为，结果不可预测 |
| 对负数用逻辑右移想除以 2 | 变成大正数，逻辑错 |
| 异或交换同地址两变量 | `a ^= a` 后归零，数据丢失 |
| 状压掩码未初始化/越界访问位 | 读到未定义状态，结果错 |
| 用 `n & (n-1) == 0` 判 2 的幂忘 `n>0` | $n=0$ 误判为 2 的幂 |

## 代码示例

**Python 3.12**：

```python
# popcount: Brian Kernighan, 每次消最低位 1
def count_ones(n):
    c = 0
    while n:
        n &= n - 1            # 消最低位 1
        c += 1
    return c

# 单值出现: 全员异或, 成对抵消
def single_number(nums):
    res = 0
    for x in nums: res ^= x
    return res

# 位操作原语
def get_bit(n, k): return (n >> k) & 1
def set_bit(n, k): return n | (1 << k)
def clear_bit(n, k): return n & ~(1 << k)
def toggle_bit(n, k): return n ^ (1 << k)
def is_power_of_two(n): return n > 0 and (n & (n - 1)) == 0
def lowbit_pos(n): return (n & -n).bit_length() - 1   # 最低位 1 的位置

# 汉明距离
def hamming(x, y): return count_ones(x ^ y)

# 子集枚举: 位掩码
def subsets(nums):
    n = len(nums)
    return [[nums[i] for i in range(n) if mask & (1 << i)]
            for mask in range(1 << n)]

# —— 简易输入输出 ——
print(count_ones(12))                 # 2
print(single_number([4,1,2,1,2]))     # 4
print(is_power_of_two(64))            # True
print(hamming(0b1010, 0b0110))        # 1
print(subsets([1,2]))                 # [[], [1], [2], [1,2]]
```

**C++20**：

```cpp
#include <iostream>
#include <vector>
#include <cstdint>

// popcount: Brian Kernighan
int countOnes(uint32_t n) {
    int c = 0;
    while (n) { n &= n - 1; ++c; }
    return c;
}
// C++20 也可直接用 <bit> 的 std::popcount

// 单值出现
int singleNumber(const std::vector<int>& nums) {
    int res = 0;
    for (int x : nums) res ^= x;
    return res;
}

// 位操作原语
constexpr bool getBit(uint32_t n, int k) { return (n >> k) & 1; }
constexpr uint32_t setBit(uint32_t n, int k) { return n | (1u << k); }
constexpr uint32_t clearBit(uint32_t n, int k) { return n & ~(1u << k); }
constexpr bool isPowerOfTwo(uint32_t n) { return n && !(n & (n - 1)); }

// 汉明距离
int hamming(uint32_t a, uint32_t b) { return countOnes(a ^ b); }

// 子集枚举: 位掩码
std::vector<std::vector<int>> subsets(const std::vector<int>& nums) {
    int n = (int)nums.size();
    std::vector<std::vector<int>> res;
    for (uint32_t mask = 0; mask < (1u << n); ++mask) {
        std::vector<int> s;
        for (int i = 0; i < n; ++i) if (mask & (1u << i)) s.push_back(nums[i]);
        res.push_back(std::move(s));
    }
    return res;
}

int main() {
    std::cout << countOnes(12) << '\n';                 // 2
    std::cout << singleNumber({4,1,2,1,2}) << '\n';     // 4
    std::cout << isPowerOfTwo(64) << '\n';              // 1
    std::cout << hamming(0b1010, 0b0110) << '\n';       // 1
    auto s = subsets({1, 2});
    std::cout << s.size() << '\n';                      // 4
}
```
