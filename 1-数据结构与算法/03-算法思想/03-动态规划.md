# 动态规划

## 定义

动态规划通过记忆化将重叠子问题的指数级枚举降为多项式时间求解，其核心是 无后效性的最优子结构。

## 数学模型

状态转移方程：

$$dp[i] = \text{opt}_{j < i}(dp[j] + \text{cost}(j, i))$$

时间复杂度：$O(n \cdot \text{subproblems})\cdot O(\text{transition})$

空间优化：若转移仅依赖 $dp[i-k..i-1]$，可滚动压缩至 $O(k)$。

## 数据流

<pre>
输入: 爬楼梯 n=5
dp[0]=1, dp[1]=1          (base case)
dp[2]=dp[1]+dp[0]=2      (list[int], 2 states)
dp[3]=dp[2]+dp[1]=3      (list[int], 3 states)
dp[4]=dp[3]+dp[2]=5      (list[int], 4 states)
dp[5]=dp[4]+dp[3]=8      (list[int], 5 states)
输出: 8
</pre>

<pre>
状态依赖拓扑序:
dp[0],dp[1] → dp[2] → dp[3] → ... → dp[n]
无环，确保按序计算即可
</pre>

## 机制

**为什么记忆化有效**：同一子问题被多个上层问题引用（重叠子问题），保存结果避免重复计算。若子问题独立无重叠，退化为普通分治。

**无后效性约束**：当前状态只通过转移方程与之前状态相关；未来决策不能回头修改已定状态。违反则DP失效，须用搜索（博弈/状态机搜索）。

**最优子结构约束**：全局最优解的每个子部分必须是该子空间的局部最优。反例：最长路径问题（无最优子结构，须用 Floyd 而非 DP）。

**空间优化条件**：转移仅依赖连续 $k$ 个历史状态时，可用环形缓冲；否则须保留完整状态表。

## 参考存根

```python
def climb_stairs(n):
    if n <= 2: return n
    dp = [0] * (n + 1)
    dp[1], dp[2] = 1, 2
    for i in range(3, n + 1):
        dp[i] = dp[i-1] + dp[i-2]
    return dp[n]
```
