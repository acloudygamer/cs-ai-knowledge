## 动态规划

### 解决什么问题
具有重叠子问题与最优子结构的问题，通过记忆化避免指数级枚举，实现多项式复杂度求解。典型场景：计数问题、最值问题、存在性问题。

### 核心概念
- **重叠子问题**：子问题被多次计算，需要保存结果
- **最优子结构**：最优解可由子问题的最优解构造
- **无后效性**：当前状态只与之前状态有关，不影响未来决策
- **状态转移方程**：描述问题结构的递推关系
- **空间优化**：利用滚动数组或只保留必要状态降维

### DP 框架

1. **定义状态** - dp[i] 表示什么？
2. **推导状态转移方程** - dp[i] = f(dp[j], ...)
3. **确定初始值** - dp[0], dp[1] 等
4. **确定遍历顺序** - 升序/降序/按依赖顺序

### 空间优化技巧

降维优化原则：只保留需要的先前状态。一维 DP 通常可只保留前 1-2 个状态。

## 经典问题

### 爬楼梯

最简单的 DP 问题。dp[i] = dp[i-1] + dp[i-2]，空间可优化到 O(1)。

### 参考样例

```python
def climb_stairs(n):
    if n <= 2:
        return n
    dp = [0] * (n + 1)
    dp[1], dp[2] = 1, 2
    for i in range(3, n + 1):
        dp[i] = dp[i - 1] + dp[i - 2]
    return dp[n]

def climb_stairs_optimized(n):
    if n <= 2:
        return n
    prev, curr = 1, 2
    for _ in range(3, n + 1):
        prev, curr = curr, prev + curr
    return curr
```

### 打家劫舍

相邻房屋不能同时偷。dp[i] = max(dp[i-1], dp[i-2] + nums[i])。

### 参考样例

```python
def rob(nums):
    if not nums:
        return 0
    if len(nums) == 1:
        return nums[0]
    dp = [0] * len(nums)
    dp[0] = nums[0]
    dp[1] = max(nums[0], nums[1])
    for i in range(2, len(nums)):
        dp[i] = max(dp[i - 1], dp[i - 2] + nums[i])
    return dp[-1]
```

### 最长公共子序列

二维 DP，dp[i][j] 表示 text1[0:i] 和 text2[0:j] 的 LCS 长度。

### 参考样例

```python
def lcs(text1, text2):
    m, n = len(text1), len(text2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if text1[i - 1] == text2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
    return dp[m][n]
```

### 编辑距离

word1 转换为 word2 的最少操作数。操作：插入、删除、替换。

### 参考样例

```python
def min_distance(word1, word2):
    m, n = len(word1), len(word2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(m + 1):
        dp[i][0] = i
    for j in range(n + 1):
        dp[0][j] = j
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if word1[i - 1] == word2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1]
            else:
                dp[i][j] = min(dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1]) + 1
    return dp[m][n]
```

### 背包问题

0-1 背包：每种物品只能选一次，空间优化后逆序遍历。完全背包：每种物品可选无限次，顺序遍历。

### 参考样例

```python
def knapsack_01(weights, values, capacity):
    n = len(weights)
    dp = [0] * (capacity + 1)
    for i in range(n):
        for j in range(capacity, weights[i] - 1, -1):
            dp[j] = max(dp[j], dp[j - weights[i]] + values[i])
    return dp[capacity]

def complete_knapsack(weights, values, capacity):
    dp = [0] * (capacity + 1)
    for i in range(len(weights)):
        for j in range(weights[i], capacity + 1):
            dp[j] = max(dp[j], dp[j - weights[i]] + values[i])
    return dp[capacity]
```

### 股票买卖最佳时机

通用框架（最多 k 次交易）。状态编码：奇数索引=持有，偶数索引=不持有。

### 参考样例

```python
def maxProfit(k, prices):
    if not prices or k == 0:
        return 0
    n = len(prices)
    if k >= n // 2:
        profit = 0
        for i in range(1, n):
            profit += max(0, prices[i] - prices[i - 1])
        return profit
    profit = [[0] * (2 * k + 1) for _ in range(n)]
    for j in range(1, 2 * k + 1, 2):
        profit[0][j] = -prices[0]
    for i in range(1, n):
        for j in range(1, 2 * k + 1):
            if j % 2 == 1:
                profit[i][j] = max(profit[i - 1][j], profit[i - 1][j - 1] - prices[i])
            else:
                profit[i][j] = max(profit[i - 1][j], profit[i - 1][j - 1] + prices[i])
    return profit[n - 1][2 * k]
```

### 最长递增子序列（LIS）

二分优化版 O(n log n)：维护 tails 数组，tails[i] 表示长度为 i+1 的递增子序列的最小尾元素。

### 参考样例

```python
import bisect

def length_of_lis(nums):
    tails = []
    for num in nums:
        pos = bisect.bisect_left(tails, num)
        if pos == len(tails):
            tails.append(num)
        else:
            tails[pos] = num
    return len(tails)
```

### 路径问题

不同路径：机器人从左上角到右下角，只能向下或向右移动。dp[j] 原地更新。

### 参考样例

```python
def unique_paths(m, n):
    dp = [1] * n
    for _ in range(1, m):
        for j in range(1, n):
            dp[j] += dp[j - 1]
    return dp[n - 1]

def unique_paths_with_obstacles(grid):
    m, n = len(grid), len(grid[0])
    dp = [0] * n
    dp[0] = 1 if grid[0][0] == 0 else 0
    for i in range(m):
        for j in range(n):
            if grid[i][j] == 1:
                dp[j] = 0
            elif j > 0:
                dp[j] += dp[j - 1]
    return dp[n - 1]

def min_path_sum(grid):
    m, n = len(grid), len(grid[0])
    dp = [[0] * n for _ in range(m)]
    dp[0][0] = grid[0][0]
    for j in range(1, n):
        dp[0][j] = dp[0][j - 1] + grid[0][j]
    for i in range(1, m):
        dp[i][0] = dp[i - 1][0] + grid[i][0]
    for i in range(1, m):
        for j in range(1, n):
            dp[i][j] = min(dp[i - 1][j], dp[i][j - 1]) + grid[i][j]
    return dp[m - 1][n - 1]
```

### 字符串分割

单词拆分：完全背包问题，dp[i] 表示 s[0:i] 能否被拆分。

### 参考样例

```python
def word_break(s, word_dict):
    word_set = set(word_dict)
    n = len(s)
    dp = [False] * (n + 1)
    dp[0] = True
    for i in range(1, n + 1):
        for j in range(i):
            if dp[j] and s[j:i] in word_set:
                dp[i] = True
                break
    return dp[n]
```

### 状态压缩 DP

旅行商问题（TSP）：状态 mask 表示已访问城市集合，dp[mask][u] 表示最后访问城市 u。

### 参考样例

```python
def solve_tsp(dist):
    n = len(dist)
    dp = [[float('inf')] * n for _ in range(1 << n)]
    dp[1][0] = 0
    for mask in range(1 << n):
        for u in range(n):
            if not (mask & (1 << u)):
                continue
            for v in range(n):
                if mask & (1 << v):
                    continue
                next_mask = mask | (1 << v)
                dp[next_mask][v] = min(dp[next_mask][v], dp[mask][u] + dist[u][v])
    full_mask = (1 << n) - 1
    return min(dp[full_mask][u] + dist[u][0] for u in range(1, n))

def super_egg_drop(K, N):
    dp = [0] * (K + 1)
    m = 0
    while dp[K] < N:
        m += 1
        for k in range(K, 0, -1):
            dp[k] = dp[k] + dp[k - 1] + 1
    return m
```

### 区间 DP

戳气球：区间 (left, right) 的最大分数等于在中间选一个位置戳破。

合并石子：相邻石子合并，代价为石子之和。

### 参考样例

```python
def min_balloons(nums):
    nums = [1] + nums + [1]
    n = len(nums)
    dp = [[0] * n for _ in range(n)]
    for length in range(2, n):
        for left in range(n - length):
            right = left + length
            for mid in range(left + 1, right):
                dp[left][right] = max(
                    dp[left][right],
                    dp[left][mid] + dp[mid][right] + nums[left] * nums[mid] * nums[right]
                )
    return dp[0][n - 1]

def min_stones(stones):
    n = len(stones)
    prefix = [0] * (n + 1)
    for i in range(n):
        prefix[i + 1] = prefix[i] + stones[i]
    dp = [[0] * n for _ in range(n)]
    for length in range(2, n + 1):
        for left in range(n - length + 1):
            right = left + length - 1
            dp[left][right] = float('inf')
            for mid in range(left, right):
                cost = dp[left][mid] + dp[mid + 1][right] + prefix[right + 1] - prefix[left]
                dp[left][right] = min(dp[left][right], cost)
    return dp[0][n - 1]
```

### DP 分类总结

| 类型 | 状态定义 | 遍历顺序 | 经典问题 |
|------|----------|----------|----------|
| 线性DP | dp[i] | 从左到右 | 爬楼梯、 LIS |
| 矩阵DP | dp[i][j] | 行优先 | 路径问题、编辑距离 |
| 背包DP | dp[i][j] | 物品/容量双循环 | 0-1背包、完全背包 |
| 区间DP | dp[l][r] | 长度递增 | 戳气球、合并石子 |
| 状态压缩DP | dp[mask] | mask递增 | TSP、鸡蛋掉落 |
| 树形DP | dp[u] | DFS后序 | 树上选点 |
