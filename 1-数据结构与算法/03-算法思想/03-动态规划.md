# 动态规划

## 定义

> **版本基准**: universal

动态规划（Dynamic Programming，DP）是将带重复子问题的问题分治求解的算法思想，通过记忆化消除重复计算，将指数级枚举降为多项式时间求解。其核心是**最优子结构**（Optimal Substructure）和**无后效性**（No Aftereffect）。

- **最优子结构**：全局最优解的子解也是子空间的最优解。
- **无后效性**：当前状态一旦确定，后续决策不受之前路径影响。
- **重叠子问题**：子问题被多次求解，记忆化可避免重复。

## 数学模型

### 状态转移方程的一般形式

设 $dp[i]$ 表示到达状态 $i$ 的最优值（或方案数），则：
$$dp[i] = \text{opt}_{j \in S(i)} \left( dp[j] + \text{cost}(j, i) \right)$$

其中 $S(i)$ 是状态 $i$ 的前驱状态集，$\text{cost}(j, i)$ 是从状态 $j$ 转移到 $i$ 的代价。

### 时间复杂度

令 $n$ 为状态总数，$t$ 为每个状态的转移候选数，则：
$$T(n) = O(n \cdot t + \text{topological\_sort})$$

若转移图是 DAG（无后效性保证），拓扑排序为 $O(n)$。

### 空间复杂度优化

若转移仅依赖 $dp[i-k]$ 到 $dp[i-1]$（连续 $k$ 个历史状态），可用 $O(k)$ 环形缓冲：
$$dp[\text{cur}] \rightarrow dp[\text{cur} \bmod k]$$

若转移依赖任意历史状态（如 $dp[j]$ for all $j < i$），则需 $O(n)$ 空间存储所有状态。

### 最优子结构的数学表达

令 $OPT(n)$ 为规模为 $n$ 的问题的最优解。则：
$$OPT(n) = \text{opt}_{k} \left( \text{solution}(k) + OPT(n-k) \right)$$

其中 $\text{solution}(k)$ 是在某个分解点 $k$ 处已经确定的部分解。

**归约终点**：动态规划是图论中的最短路径问题在 DAG 上的特例。状态是顶点，转移是边，状态转移方程是最短路径的 Bellman 方程在拓扑序上的特殊形式。

## 数据流

<pre>
问题：爬楼梯（每次爬1或2步），n=5

状态空间:
dp[0]=1 (base case: 0步有一种走法)
dp[1]=1 (1步有一种走法)

拓扑序计算:
dp[2] = dp[1] + dp[0] = 1 + 1 = 2
dp[3] = dp[2] + dp[1] = 2 + 1 = 3
dp[4] = dp[3] + dp[2] = 3 + 2 = 5
dp[5] = dp[4] + dp[3] = 5 + 3 = 8

数据形态变换:
原始问题 (n) → 分解为子问题 (n-1, n-2) → 合并子问题解 (加法) → dp[n]
                                      ↑
                               这里 dp[1], dp[0] 是已计算结果
</pre>

<pre>
状态依赖关系（DAG）:
dp[0] dp[1]  ←────── base cases
   ↓   ↓
dp[2] ───────→ dp[3] → dp[4] → dp[5]
   ↑               ↑
   └───────────────┘
         (dp[2] 同时是 dp[4] 的前驱)

每个 dp[i] 只依赖更小索引的状态 → 拓扑序即自然序
</pre>

<pre>
空间优化（滚动数组）:
原始: dp = [1,1,2,3,5,8]  → O(n) 空间

滚动: 只保留最近2个状态
i=2: dp[0],dp[1] → dp[2]=2      [1,1,2,...]
i=3: dp[1],dp[2] → dp[3]=3      [1,2,3,...]
i=4: dp[2],dp[3] → dp[4]=5      [2,3,5,...]
i=5: dp[3],dp[4] → dp[5]=8      [3,5,8]

每步只保留必要的2个状态 → O(1) 额外空间（若 k=2）
</pre>

## 机制

### 为什么记忆化有效：重叠子问题

考虑斐波那契数列 $F(n) = F(n-1) + F(n-2)$。朴素递归计算 $F(5)$ 时：
$$F(5) \rightarrow F(4), F(3)$$
$$F(4) \rightarrow F(3), F(2)$$
$$F(3) \rightarrow F(2), F(1)$$

$F(3)$ 被计算了 2 次，$F(2)$ 被计算了 3 次。子问题指数级重复。

记忆化将每个子问题的结果存储，首次计算后直接查表，整体复杂度从 $O(2^n)$ 降为 $O(n)$。

### 无后效性约束

无后效性要求：状态的定义消除了对未来决策的依赖。一旦 $dp[i]$ 确定，后续计算不会再改变 $dp[i]$。

违反无后效性的例子：博弈问题中当前决策影响未来可选策略（需用 Minimax + 剪枝，而非 DP）。

典型无后效性场景：线性DP、区间DP（只在子区间内决策）、数位DP（前缀已定）。

### 最优子结构约束

全局最优解由局部最优解构成，但"局部最优"的定义依赖于子问题划分。

反例：最长路径问题（无优化子结构）：
- 问题：找到图中从 A 到 B 的最长简单路径
- 子问题：从 A 到中间节点 C 的最长路径
- 障碍：连接两个局部最长路径可能形成环，导致路径非简单

反例：最短路径问题（有最优子结构）：
- 问题：找到从 A 到 B 的最短路径
- 子问题：从 A 到中间节点 C 的最短路径
- 正确性：A→B 的最短路径必经过某个 C，且 A→C 和 C→B 的子路径也必须是最短的

### 空间优化条件

转移若只依赖连续 $k$ 个历史状态，可用 $O(k)$ 环形缓冲：
- $k=1$：仅依赖 $dp[i-1]$，如 $dp[i] = dp[i-1] + constant$
- $k=2$：如斐波那契 $dp[i] = dp[i-1] + dp[i-2]$
- $k=任意$：如 $dp[i] = \max_{j < i}(dp[j] + 1)$，需保留所有历史状态

空间换时间：存储更多状态换取更快的转移。

### 状态爆炸与优化方向

当状态数 $n$ 极大时（如 $n = 10^9$），无法枚举所有状态：
- 数位 DP：只枚举数位状态（$O(\log n)$ 状态）
- 状态压缩 DP：状态用位掩码表示（$O(2^n)$ 状态）
- 斜率优化/单调队列：特定形式的状态转移可加速

## 参考存根

```python
def climb_stairs(n):
    if n <= 2:
        return n
    dp = [0] * (n + 1)
    dp[1], dp[2] = 1, 2
    for i in range(3, n + 1):
        dp[i] = dp[i-1] + dp[i-2]
    return dp[n]

# 空间优化版本
def climb_stairs_optimized(n):
    if n <= 2:
        return n
    prev2, prev1 = 1, 2
    for _ in range(3, n + 1):
        prev2, prev1 = prev1, prev2 + prev1
    return prev1

# 编辑距离（区间 DP）
def edit_distance(word1, word2):
    m, n = len(word1), len(word2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(m + 1):
        dp[i][0] = i
    for j in range(n + 1):
        dp[0][j] = j
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if word1[i-1] == word2[j-1]:
                dp[i][j] = dp[i-1][j-1]
            else:
                dp[i][j] = 1 + min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1])
    return dp[m][n]
```
