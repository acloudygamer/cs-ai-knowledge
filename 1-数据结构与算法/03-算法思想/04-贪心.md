# 贪心

## 定义

贪心在每一步选择当前局部最优，期望该选择序列构成全局最优，要求问题具有贪心选择性质与最优子结构。

## 数学模型

设选择序列 $S = \{g_1, g_2, ..., g_n\}$，最优解满足：

$$\exists \text{最优解 } S^* : g_1 \in S^* \text{ 且 } S^* - \{g_1\} \text{ 是子问题的最优解}$$

即：存在最优解可由贪心第一步直接导出。

## 数据流

<pre>
区间调度问题:
输入: intervals = [(1,4), (2,3), (3,5), (4,6)]
       │
按结束时间排序: [(2,3), (1,4), (3,5), (4,6)]
       │
贪心选择:
  选(2,3), end=3
  跳过(1,4) → 冲突
  选(3,5), end=5
  选(4,6)  → 不冲突(4≥3)
输出: 3 个区间 (最多)
</pre>

## 机制

**为什么局部最优能导出全局最优**：当问题的最优子结构与贪心选择性质同时成立时，贪心选择的约束空间不排除任何最优解。交换论证（exchange argument）：若某最优解不以贪心选择开头，可将其替换为贪心选择而不降低解质量。

**贪心选择性质约束**：局部最优选择必须属于某一最优解。验证方法：假设存在最优解不包含当前贪心选择，通过交换使其包含，观察是否破坏最优性。

**与 DP 的本质区别**：DP 考虑所有子问题的最优解再选，贪心只考虑当前；问题无重叠子结构时贪心必然失败。

**适用场景**：区间调度（选最早结束）、哈夫曼编码（小根堆合并）、活动选择（最优加括号）。

## 参考存根

```python
def interval_scheduling(intervals):
    intervals.sort(key=lambda x: x[1])
    count, end = 0, float('-inf')
    for s, e in intervals:
        if s >= end:
            count += 1; end = e
    return count
```
