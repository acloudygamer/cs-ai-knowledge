# 贪心

> **版本基准**：universal —— 代码示例同时使用 Python 3.12 与 C++20

## 本质

贪心在每一步选**当前局部最优**的那个选择，且不回溯、不考虑此选择对未来的影响。它成立需要两件事同时为真：**贪心选择性质**（存在一个最优解以贪心的第一步开头）与**最优子结构**（剩下的子问题仍保持原问题结构，可继续贪心）。两者都满足时，贪心比 DP 更省——不必枚举所有子问题，一条道走到黑就是最优。

工程上贪心的价值是**常数小、实现短、通常 $O(n \log n)$ **：排序一次 + 线性扫描即可。代价是必须**证明**它对具体问题成立，否则会给出看似合理却非最优的近似解。

## 数学模型

### 贪心选择性质

设原问题最优解为 $S^*$，贪心第一步选 $g_1$。贪心选择性质要求：

$$\exists\, S^* : g_1 \in S^* \text{ 且 } S^* \setminus \{g_1\} \text{ 是剩余子问题的最优解}$$

即某个最优解就是从贪心第一步开始走的——贪心选择没有"排除掉所有最优解"。

### 交换论证（Exchange Argument）

证明贪心最优的标准武器。设 $S_{OPT}$ 为任意最优解、 $g_1$ 为贪心首步、 $o_1$ 为 $S_{OPT}$ 首步：

1. 由贪心排序键定义， $C(g_1) \leq C(o_1)$ （贪心首步不劣于任意首步）。
2. 把 $o_1$ 换成 $g_1$，构造 $S' = (S_{OPT} \setminus \{o_1\}) \cup \{g_1\}$，代价不增。
3. $S'$ 仍是某最优解，且以 $g_1$ 开头；剩余子问题与原问题同构。
4. 对子问题递归同样论证，最终整条贪心解 $\leq S_{OPT}$，故相等。

> **洞察**：交换论证的本质是"贪心解与最优解的差，可以一步步无损替换掉"。若某步替换会增大代价（ $C(g_1) > C(o_1)$），贪心选择性质就不成立——这是判断贪心能否用的试金石。

### 切分性质（MST 的贪心依据）

对任意非空顶点集 $S \subset V$，设 $e$ 是横跨切分 $(S, V \setminus S)$ 的最小权边，则**存在**一个最小生成树包含 $e$。

**证明**：取任一 MST $T$。若 $T$ 已含 $e$，证毕。否则把 $e$ 加入 $T$ 形成环，该环必另有一条横跨同一切分的边 $e'$。由 $e$ 的最小性 $w(e) \leq w(e')$，用 $e$ 替换 $e'$ 得 $T'$，权值不超过 $T$，故 $T'$ 也是 MST 且含 $e$。 $\square$

这就是 Kruskal 按权升序选边的理论根基：每次新边横跨的是"已选森林 vs 剩余顶点"的切分，最小横跨边必属于某 MST。

## 数据流

### 区间调度：按结束时间贪心

<pre>
输入: [(1,4), (2,3), (3,5), (4,6)]   目标: 选最多互不重叠区间

策略: 每次选当前结束最早且不冲突的区间

1. 按结束时间排序: [(2,3), (1,4), (3,5), (4,6)]
   选 (2,3), end=3
2. (1,4): start=1 < 3 冲突 → 跳过
3. (3,5): start=3 >= 3 不冲突 → 选, end=5
4. (4,6): start=4 < 5 冲突 → 跳过... (注: 4<5 冲突, 此例选 2 个)

输出: [(2,3), (3,5)]   ← 选最早结束为后续留出最多空间
</pre>

**所有权变换**：算法只读区间、维护一个 `end` 游标与计数器，不修改输入。排序建立"结束时间"这个全序后，贪心退化为一次线性扫描。

### 哈夫曼编码：小根堆不断合并最小两棵

<pre>
频率: {a:45, b:13, c:12, d:16, e:9, f:5}

初始堆(按频率): [5(f), 9(e), 12(c), 13(b), 16(d), 45(a)]
  弹 f(5)+e(9) → 合并 14, 推回
  弹 12+13 → 合并 25, 推回
  弹 14+16 → 合并 30, 推回
  弹 25+30 → 合并 55, 推回
  弹 45+55 → 合并 100 (根)

每步合并代价 = 两子树频率和，累加成总编码代价（加权路径长度）。
</pre>

频率最低的两字符在最优前缀码中必为兄弟叶（否则交换到更深处不增代价），合并后子问题同构——这是贪心选择性质的体现。

### Kruskal MST：按权升序选边、并查集查环

<pre>
边按权升序排列，维护已选森林(并查集):
  对每条边 (u,v,w):
    find(u) != find(v) → 两端不同连通分量, 选之, union
    find(u) == find(v) → 会成环, 跳过

每步状态: 森林连通分量数从 n 逐步减到 1, 恰选 n-1 条边
</pre>

## 对比参照

| 维度 | 贪心 | 动态规划 |
|------|------|----------|
| 决策 | 只看当前一步，不回溯 | 枚举所有子问题再选最优 |
| 前提 | 贪心选择性质 + 最优子结构 | 最优子结构 + 无后效性 |
| 时间 | 常为 $O(n \log n)$ （排序+扫描） | 常 $O(n^2)$ 或更高 |
| 空间 | $O(1)$~$O(n)$ | $O(n)$，可滚动 |
| 最优性 | 须按问题证明 | 表格化枚举天然保证 |
| 典型 | 区间调度、哈夫曼、Kruskal/Dijkstra | 背包、编辑距离、LIS |

## 机制

### 贪心为何会失败：最优子结构缺失

**0/1 背包**（物品不可分）是经典反例：贪心按"单位价值比"先拿最高比的物品 A，可能因容量耗尽而错过更优的 B+C 组合——选 A 这一步排除了 B、C 的组合空间，局部最优排除了全局最优。

**分数背包**（物品可分）却可用贪心：选 A 的一部分不排除再选 B、C 的一部分，容量满即停。差别就在"选择是否会排除未来组合"。

### 贪心 vs DP 的本质分界

DP 枚举所有子问题最优解后再做选择，**信息全**所以总能最优；贪心只看当前一步，**信息省**所以快，但必须靠问题结构保证"省掉的不会害你"。能用贪心就别用 DP——常数差一个量级；不能证明贪心就老实用 DP。

### 适用场景

- **区间调度**：按结束时间排序选，最早结束为后续留最多空间。
- **哈夫曼编码**：合并频率最小的两棵子树，交换论证保证最优。
- **Kruskal/PriM（MST）**：切分性质保证按权贪心选边最优。
- **Dijkstra（正权单源最短路）**：每次取当前最近未定节点，贪心选择性质由"最短路的子路也是最短路"保证。**负权失效**：负边会破坏"已定节点的最短路不会更优"这一前提。

### 违规后果

| 违规 | 后果 |
|------|------|
| 0/1 背包用分数贪心 | 排除更优组合，返回近似解而非最优 |
| 未证贪心选择性质就用贪心 | 结果可能非最优，且无报警 |
| Dijkstra 用于含负权图 | 已定节点最短路被负边推翻，结果错 |
| 哈夫曼不取频率最小的两棵 | 加权路径长度非最小，编码次优 |

## 代码示例

**Python 3.12**：

```python
# 区间调度：按结束时间贪心，选最多互不重叠区间
def interval_scheduling(intervals):
    if not intervals: return []
    intervals.sort(key=lambda x: x[1])     # 按结束时间排序
    ans, end = [], float('-inf')
    for s, e in intervals:
        if s >= end:                        # 不冲突则选
            ans.append((s, e)); end = e
    return ans

# 哈夫曼编码：小根堆合并最小两棵子树，合并时给左右子树编码前缀加 0/1
import heapq
def huffman(freq):
    # 堆元素: [频率, 计数器, 字符或None, 左, 右]；计数器用于打破频率相同时的比较
    counter = 0
    heap = [[w, counter, ch, None, None] for ch, w in freq.items()]
    heapq.heapify(heap)
    while len(heap) > 1:
        a = heapq.heappop(heap); b = heapq.heappop(heap)
        counter += 1
        node = [a[0] + b[0], counter, None, a, b]   # a 为左(0)、b 为右(1)
        heapq.heappush(heap, node)
    root = heap[0]
    codes = {}
    def walk(n, code):
        if n[2] is not None:                  # 叶节点
            codes[n[2]] = code or '0'; return
        walk(n[3], code + '0'); walk(n[4], code + '1')
    walk(root, '')
    return codes

# Kruskal MST：按权升序选边 + 并查集查环
def kruskal(vertices, edges):
    edges.sort(key=lambda x: x[2])          # (u, v, w)
    parent = {v: v for v in vertices}
    def find(v):
        while parent[v] != v:
            parent[v] = parent[parent[v]]   # 路径压缩
            v = parent[v]
        return v
    mst = []
    for u, v, w in edges:
        ru, rv = find(u), find(v)
        if ru != rv:                        # 不同分量，选之
            parent[ru] = rv
            mst.append((u, v, w))
    return mst

# —— 简易输入输出 ——
print(interval_scheduling([(1,4),(2,3),(3,5),(3,6)]))  # [(2,3),(3,5)]
print(huffman({'a':45,'b':13,'c':12,'d':16,'e':9,'f':5}))
# {'a':'0','c':'100','b':'101','f':'1100','e':'1101','d':'111'}（编码不唯一，位长 a=1,b/c=3,d/e/f 变化）
print(kruskal(['A','B','C','D'],
              [('A','B',1),('B','C',2),('A','C',3),('C','D',4)]))
# [('A','B',1),('B','C',2),('C','D',4)]
```

**C++20**：

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <climits>

// 区间调度：按结束时间贪心
int intervalScheduling(std::vector<std::pair<int,int>> iv) {
    if (iv.empty()) return 0;
    std::sort(iv.begin(), iv.end(),
              [](auto& a, auto& b){ return a.second < b.second; });
    int cnt = 0, end = INT_MIN;
    for (auto& [s, e] : iv)            // C++17 结构化绑定
        if (s >= end) { ++cnt; end = e; }
    return cnt;
}

// Kruskal：并查集 + 按权排序
struct DSU {
    std::vector<int> p;
    DSU(int n): p(n) { for (int i=0;i<n;++i) p[i]=i; }
    int find(int x){ return p[x]==x ? x : p[x]=find(p[x]); }
};
int kruskal(int n, std::vector<std::tuple<int,int,int>>& edges) {
    std::sort(edges.begin(), edges.end(),
              [](auto& a, auto& b){ return std::get<2>(a) < std::get<2>(b); });
    DSU dsu(n);
    int total = 0, used = 0;
    for (auto& [u, v, w] : edges) {
        int ru = dsu.find(u), rv = dsu.find(v);
        if (ru != rv) { dsu.p[ru] = rv; total += w; if (++used == n-1) break; }
    }
    return total;
}

int main() {
    std::cout << intervalScheduling({{1,4},{2,3},{3,5},{3,6}}) << '\n';   // 2
    std::vector<std::tuple<int,int,int>> edges = {
        {0,1,1},{1,2,2},{0,2,3},{2,3,4}};
    std::cout << kruskal(4, edges) << '\n';                              // 7
}
```
