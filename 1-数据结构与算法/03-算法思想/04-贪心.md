## 贪心

### 解决什么问题
每步选择局部最优解，期望获得全局最优。适用于具有贪心选择性质的问题（局部最优能导出全局最优），比动态规划更简单高效。典型场景：区间调度、资源分配、哈夫曼编码。

### 核心概念
- **贪心选择性质**：存在最优解包含当前的贪心选择
- **最优子结构**：问题具有最优子结构性质
- **正确性证明**：交换论证法、反证法、归纳法
- **与DP区别**：贪心只考虑当前，DP保存所有子问题结果

### 贪心算法分类

| 问题 | 贪心策略 | 正确性条件 |
|------|----------|------------|
| 区间调度 | 选择最早结束 | 无重叠 |
| 加油站 | 从可支撑点重新开始 | 总油量>=总消耗 |
| 饼干分配 | 最小饼干满足最小需求 | 任意匹配 |
| 船救人 | 最重+最轻配对 | 体重限制=2 |
| 找零钱 | 优先用大面额 | 货币系统正规 |
| Huffman编码 | 小堆合并 | 前缀码 |

### 贪心 vs DP vs 回溯

| 问题类型 | 贪心 | 动态规划 | 回溯 |
|----------|------|----------|------|
| 最优子结构 | 有 | 有 | 可能有 |
| 子问题重叠 | 否 | 是 | 是 |
| 局部最优=全局最优 | 是 | 否 | 否 |
| 复杂度 | 通常O(n) | O(n^2)+ | 指数级 |
| 适用场景 | 分配、区间 | 计数、最值 | 枚举、组合 |

## 区间调度

选择最多不重叠的区间。按结束时间排序，选择最早结束且与已选区间不冲突的区间。

### 参考样例

```python
def interval_scheduling(intervals):
    if not intervals:
        return 0
    intervals.sort(key=lambda x: x[1])
    end_time = intervals[0][1]
    count = 1
    for start, end in intervals[1:]:
        if start >= end_time:
            count += 1
            end_time = end
    return count

def erase_overlap_intervals(intervals):
    if not intervals:
        return 0
    intervals.sort(key=lambda x: x[1])
    end = intervals[0][1]
    count = 0
    for i in range(1, len(intervals)):
        if intervals[i][0] < end:
            count += 1
        else:
            end = intervals[i][1]
    return count
```

## 跳跃游戏

### 参考样例

```python
def can_jump(nums):
    furthest = 0
    for i in range(len(nums)):
        if i > furthest:
            return False
        furthest = max(furthest, i + nums[i])
    return True
```

## 哈夫曼编码思路

每次合并两个最小的文件，代价为两者之和。

### 参考样例

```python
import heapq

def huffman_merge(lengths):
    heap = lengths[:]
    heapq.heapify(heap)
    cost = 0
    while len(heap) > 1:
        a = heapq.heappop(heap)
        b = heapq.heappop(heap)
        cost += a + b
        heapq.heappush(heap, a + b)
    return cost
```

## 饼干分配

最小饼干满足最小需求。

### 参考样例

```python
def find_content_children(g, s):
    g.sort()
    s.sort()
    gi = si = 0
    while gi < len(g) and si < len(s):
        if s[si] >= g[gi]:
            gi += 1
        si += 1
    return gi
```

## 船救人问题

最重+最轻配对，每船最多2人。

### 参考样例

```python
def num_rescue_boats(people, limit):
    people.sort()
    left, right = 0, len(people) - 1
    boats = 0
    while left <= right:
        if people[left] + people[right] <= limit:
            left += 1
        right -= 1
        boats += 1
    return boats
```

## 加油站问题

环形路线加油站，若从i到j油量变为负，则中间任何点都不可能到达j。

### 参考样例

```python
def can_complete_circuit(gas, cost):
    total_tank = 0
    curr_tank = 0
    start = 0
    for i in range(len(gas)):
        diff = gas[i] - cost[i]
        total_tank += diff
        curr_tank += diff
        if curr_tank < 0:
            start = i + 1
            curr_tank = 0
    return start if total_tank >= 0 else -1
```

## 柠檬水找零

### 参考样例

```python
def lemonade_change(bills):
    five, ten = 0, 0
    for bill in bills:
        if bill == 5:
            five += 1
        elif bill == 10:
            if five == 0:
                return False
            five -= 1
            ten += 1
        else:
            if ten > 0 and five > 0:
                ten -= 1
                five -= 1
            elif five >= 3:
                five -= 3
            else:
                return False
    return True
```

## 单调递增数字

找到小于等于N的最大单调递增数。

### 参考样例

```python
def monotone_increasing_digits(N):
    digits = list(str(N))
    marker = len(digits)
    for i in range(len(digits) - 1, 0, -1):
        if digits[i - 1] > digits[i]:
            marker = i
            digits[i - 1] = str(int(digits[i - 1]) - 1)
    for i in range(marker, len(digits)):
        digits[i] = '9'
    return int(''.join(digits))
```
