# 滑动窗口

## 定义

滑动窗口是维护连续子数组/子串的可伸缩区间结构，通过双指针（left, right）将嵌套循环 $O(n^2)$ 优化为 $O(n)$ 单次遍历。右指针扩展窗口、左指针收缩窗口，保证窗口始终满足约束条件。

## 数学模型

### 固定窗口时间复杂度

设序列长度为 $n$，窗口大小为 $k$。右指针从 0 移动到 $n-1$，左指针在右指针到达 $k-1$ 后开始跟随：
$$T(n) = O(n) + O(n-k) = O(n)$$

每次指针移动 $O(1)$，总移动次数为 $O(n)$。

### 可变窗口时间复杂度

右指针单调不减（只向右扩展），左指针单调不减（只向右收缩）。每个指针最多移动 $n$ 步，总计 $2n = O(n)$ 次指针移动。

### 窗口状态转移

令 $W(l, r)$ 表示以 $l$ 为左边界、$r$ 为右边界的窗口。每次扩展或收缩都是对 $W$ 的状态转移：
$$W(l, r) \xrightarrow{\text{右移 right}} W(l, r+1) \quad \text{若约束仍满足}$$
$$W(l, r) \xrightarrow{\text{右移 left}} W(l+1, r) \quad \text{若约束不再满足}$$

### 单调性保证 O(n)

指针的单调性是关键。每次 while 循环收缩 left 时，left 只会增加，不会回退。因此总指针移动次数有上界 $2n$。

若窗口扩张后可能回退（如暴力解中 right 回退），总操作数为 $O(n^2)$。

**归约终点**：滑动窗口是**带约束的在线问题求解算法**。本质是维护一个"最近合法区间"的区间收缩/扩张状态机，在线算法中无法预知未来（右指针只能右移），但可通过左指针收缩满足约束。

## 机制

### 为何 O(n)：指针单调性的约束保证

暴力解中 right 指针每次扩展后可能回退（当 left 右移时），导致 $O(n^2)$。

滑动窗口要求：left 只能右移（左边界只能扩大，不能缩小）。这通过约束条件的设计实现：只有当窗口不再满足约束时，才收缩 left。

因此每个元素最多被 right 访问一次（入窗口），最多被 left 访问一次（出窗口），总 $2n = O(n)$。

### 窗口合法性约束

收缩条件必须正确设计。若收缩过慢：
- 窗口包含非法元素（如重复字符）
- 结果不正确（漏掉合法解的最优窗口）

若收缩过快：
- 可能过早收缩，漏掉更优解
- 但通常收缩条件是确定性的，不会漏解

### 固定窗口 vs 可变窗口

固定窗口（窗口大小 $k$ 恒定）：
- 用于：子数组最大值、子数组平均值
- 特点：right 扩张到 $k$ 后，left 跟随 right 保持窗口大小

可变窗口（窗口大小动态变化）：
- 用于：最短子串、最长子串
- 特点：right 不断右扩，left 在约束破坏时收缩

### 单调队列优化最值查询

朴素滑动窗口中，求窗口最大值需要 $O(k)$ 扫描。使用单调队列可在 $O(1)$ 求窗口最值：

维护递减双端队列（队首为当前窗口最大值）：
1. 新元素入队：从队尾弹出所有小于新元素的元素（它们永不成最大值）
2. 队首元素若已离开窗口（左边界超过），弹出队首
3. 队首即为当前窗口最大值

正确性：递减队列中，队首是最大元素；被弹出的元素右侧有更大元素，故永不成最大值。

### 典型应用场景

1. **无重复字符最长子串**：收缩条件为"当前字符已在窗口中"
2. **最小覆盖子串**：固定左边界，扩展右边界找覆盖
3. **子数组最大和（长度 ≥ k）**：固定窗口
4. **字符串排列**：固定大小窗口，维护字符计数
5. **最大平均子数组**：固定窗口

### 约束条件与违反后果

- left 指针不可左移：若 left 回退，总复杂度退化为 $O(n^2)$
- 窗口约束必须可逆检测：如"无重复"可通过 hash set 检测收缩
- 单调队列中，若入队元素值比较符号写反（应为 ≤ 而非 <），会导致相等元素处理错误

def length_of_longest_substring(s):
    char_idx = {}
    left = max_len = 0
    for right, ch in enumerate(s):
        if ch in char_idx and char_idx[ch] >= left:
            left = char_idx[ch] + 1
        char_idx[ch] = right
        max_len = max(max_len, right - left + 1)
    return max_len

def min_window_substring(s, t):
    from collections import Counter
    need = Counter(t)
    window = Counter()
    left = 0
    result = ""
    matched = 0
    for right, ch in enumerate(s):
        if ch in need:
            window[ch] += 1
            if window[ch] <= need[ch]:
                matched += 1
        while matched == len(t):
            if not result or right - left + 1 < len(result):
                result = s[left:right+1]
            if s[left] in need:
                window[s[left]] -= 1
                if window[s[left]] < need[s[left]]:
                    matched -= 1
            left += 1
    return result

def max_sliding_window(nums, k):
    from collections import deque
    dq = deque()
    result = []
    for i in range(len(nums)):
        while dq and nums[dq[-1]] <= nums[i]:
            dq.pop()
        dq.append(i)
        if dq[0] <= i - k:
            dq.popleft()
        if i >= k - 1:
            result.append(nums[dq[0]])
    return result
