# 滑动窗口

## 定义

滑动窗口通过维护连续子数组/子串的两个指针，将嵌套循环 $O(n^2)$ 优化为 $O(n)$ 的单层线性扫描，右指针扩展、左指针收缩保证窗口合法性。

## 数学模型

固定窗口移动代价：
$$T(n) = O(n) + O(1) \cdot (n-k) = O(n)$$

可变窗口最坏情况：右指针单调不减，左指针单调不减，每个指针最多移动 $n$ 步，总计 $O(n)$。

## 数据流

<pre>
无重复字符最长子串 "abcabcbb":
初始: left=0, right=0, window=empty
right→: "a" → window={a}, len=1
right→: "ab" → window={a,b}, len=2
right→: "abc" → window={a,b,c}, len=3
right→: "abca" → 重复a, left收缩→1, window={b,c,a}, len=3
right→: "abcab" → 重复a,b, left收缩→3, window={c,a,b}, len=3
继续... 最大窗口长度=3

数据形态:
str → window (dict or set) → 收缩/扩展 → 更新max_len
</pre>

## 机制

**为什么 $O(n)$**：右指针只向右移动，左指针也只向右移动，每个元素最多被访问两次（入窗口、出窗口），总指针移动 $2n = O(n)$。

**窗口合法性约束**：收缩条件（何时右移 left）必须在遍历过程中及时触发；若收缩过慢，窗口状态不反映真实约束；若收缩过快，可能漏掉合法解。

**固定 vs 可变**：固定窗口适合最大值/平均值问题（窗口大小恒定）；可变窗口适合最短子串/最长子串问题（窗口大小动态）。

**单调队列优化**：窗口最值查询 $O(1)$ 通过维护递减（最大值）或递增（最小值）双端队列实现，队首为当前窗口极值。

## 参考存根

```python
def length_of_longest_substring(s):
    char_idx = {}
    left = max_len = 0
    for right, ch in enumerate(s):
        if ch in char_idx and char_idx[ch] >= left:
            left = char_idx[ch] + 1
        char_idx[ch] = right
        max_len = max(max_len, right - left + 1)
    return max_len
```
