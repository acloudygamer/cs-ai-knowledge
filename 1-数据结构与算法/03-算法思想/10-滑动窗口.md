# 滑动窗口

## 核心思想

滑动窗口是一种高效遍历数组/字符串的技巧，通过维护一个"窗口"（连续子数组/子串），在遍历过程中动态调整窗口边界，将嵌套循环优化为单层循环。

**核心公式**：
- 窗口扩大：`right++`，加入新元素
- 窗口收缩：`left++`，移除旧元素
- 结果更新：在窗口变化时或收缩后更新

**时间复杂度**: O(n)，每个元素最多被左右指针访问一次
**空间复杂度**: O(1) 到 O(k)，取决于窗口内需要存储的数据结构

## 固定窗口模板

窗口大小固定的滑动窗口，适用于求最大值/平均值等。

```python
def fixed_window_template(nums, k):
    """
    固定大小为 k 的窗口模板
    时间复杂度: O(n)
    """
    window_sum = sum(nums[:k])  # 初始化窗口
    max_sum = window_sum

    for i in range(k, len(nums)):
        # 滑动：减去左边，加入右边
        window_sum += nums[i] - nums[i - k]
        max_sum = max(max_sum, window_sum)

    return max_sum
```

## 可变窗口模板

窗口大小动态变化的滑动窗口，适用于子串/子数组问题。

```python
def variable_window_template(s):
    """
    可变窗口模板 - 以最小覆盖子串为例
    时间复杂度: O(n)
    """
    from collections import Counter

    need = Counter(s)  # 需要的字符
    window = {}
    left, right = 0, 0
    valid = 0  # 满足条件的字符数

    while right < len(s):
        c = s[right]
        right += 1
        # 扩大窗口
        window[c] = window.get(c, 0) + 1
        if need[c] > 0 and window[c] == need[c]:
            valid += 1

        # 收缩窗口
        while valid == len(need):
            # 更新最小覆盖子串
            result = s[left:right]

            d = s[left]
            left += 1
            # 收缩窗口
            if need[d] > 0 and window[d] == need[d]:
                valid -= 1
            window[d] -= 1

    return result
```

### 1. 无重复字符的最长子串

**LeetCode 3**: 找出一个字符串中不包含重复字符的最长子串长度。

**思路**：使用哈希集合维护窗口内字符，扩张右边界时检查重复，遇到重复字符收缩左边界。

**时间复杂度**: O(n)
**空间复杂度**: O(min(m, charset))，charset 为字符集大小

```python
def length_of_longest_substring(s):
    """
    滑动窗口 + 哈希集合
    关键点：
    - 使用 set 存储窗口内字符
    - 遇到重复字符时收缩左边界直到移除重复字符
    """
    char_set = set()
    left = 0
    max_length = 0

    for right in range(len(s)):
        # 收缩左边界直到没有重复
        while s[right] in char_set:
            char_set.remove(s[left])
            left += 1

        char_set.add(s[right])
        max_length = max(max_length, right - left + 1)

    return max_length


def length_of_longest_substring_sliding(s):
    """
    优化版本：记录字符最新位置
    时间复杂度: O(n)
    空间复杂度: O(min(m, charset))
    """
    char_index = {}  # 存储字符最新出现位置
    left = 0
    max_length = 0

    for right in range(len(s)):
        if s[right] in char_index:
            # 左边界跳到重复字符的下一个位置（更高效的收缩）
            left = max(left, char_index[s[right]] + 1)

        char_index[s[right]] = right
        max_length = max(max_length, right - left + 1)

    return max_length
```

**图解**：
```
s = "abcabcbb"
         left
          ↓
  窗口: [a b c a b c b b]
                ↑
               right

当遇到第二个 'a' (index=3) 时：
- char_index['a'] = 0
- left = max(0, 0+1) = 1
- 窗口变为 "bca"
```

### 2. 字符串的排列

**LeetCode 567**: 检查 s2 是否包含 s1 的排列作为子串。

**思路**：固定窗口大小为 len(s1)，维护字符计数窗口。

```python
def check_inclusion(s1, s2):
    """
    滑动窗口 + 字符计数比较
    时间复杂度: O(n)
    空间复杂度: O(1)，字符集固定为26个小写字母
    """
    from collections import Counter

    if len(s1) > len(s2):
        return False

    s1_count = Counter(s1)
    s2_count = Counter(s2[:len(s1)])  # 初始化窗口

    matches = 0
    for i in range(26):
        if s1_count[chr(ord('a') + i)] == s2_count[chr(ord('a') + i)]:
            matches += 1

    left = 0
    for right in range(len(s1), len(s2)):
        if matches == 26:
            return True

        # 扩张窗口
        char_r = s2[right]
        s2_count[char_r] += 1
        if s1_count[char_r] == s2_count[char_r]:
            matches += 1
        elif s1_count[char_r] + 1 == s2_count[char_r]:
            matches -= 1

        # 收缩窗口
        char_l = s2[left]
        if s1_count[char_l] == s2_count[char_l]:
            matches -= 1
        elif s1_count[char_l] - 1 == s2_count[char_l]:
            matches += 1
        s2_count[char_l] -= 1
        left += 1

    return matches == 26
```

### 3. 找到字符串中所有字母异位词

**LeetCode 438**: 在 s 中找到所有 p 的字母异位词的起始索引。

```python
def find_anagrams(s, p):
    """
    滑动窗口 + 字符计数
    时间复杂度: O(n)
    空间复杂度: O(1)
    """
    from collections import Counter

    need = Counter(p)
    window = Counter()
    left = 0
    valid = 0
    result = []

    for right in range(len(s)):
        char_r = s[right]
        window[char_r] += 1
        if window[char_r] == need.get(char_r, 0):
            valid += 1

        # 收缩窗口到固定大小
        if right >= len(p):
            char_l = s[left]
            if window[char_l] == need.get(char_l, 0):
                valid -= 1
            window[char_l] -= 1
            left += 1

        # 检查是否匹配
        if valid == len(need):
            result.append(left)

    return result
```

### 4. 最小覆盖子串

**LeetCode 76**: 在 s 中找到包含 t 所有字符的最小子串。

```python
def min_window(s, t):
    """
    滑动窗口 + 哈希表
    时间复杂度: O(n)
    空间复杂度: O(1)
    """
    from collections import Counter

    need = Counter(t)
    window = {}
    left = 0
    valid = 0
    start = 0
    min_len = float('inf')

    for right in range(len(s)):
        char_r = s[right]
        window[char_r] = window.get(char_r, 0) + 1
        if char_r in need and window[char_r] == need[char_r]:
            valid += 1

        # 收缩窗口
        while valid == len(need):
            # 更新最小窗口
            if right - left + 1 < min_len:
                start = left
                min_len = right - left + 1

            char_l = s[left]
            if char_l in need and window[char_l] == need[char_l]:
                valid -= 1
            window[char_l] -= 1
            left += 1

    return s[start:start + min_len] if min_len != float('inf') else ""
```

### 5. 最大连续1的个数 III

**LeetCode 1004**: 最多翻转 k 个 0 后的最长连续 1 数组。

```python
def longest_ones(nums, k):
    """
    可变窗口：翻转不超过 k 个 0
    时间复杂度: O(n)
    空间复杂度: O(1)
    """
    left = 0
    zero_count = 0
    max_length = 0

    for right in range(len(nums)):
        if nums[right] == 0:
            zero_count += 1

        # 收缩窗口直到翻转不超过 k 个 0
        while zero_count > k:
            if nums[left] == 0:
                zero_count -= 1
            left += 1

        max_length = max(max_length, right - left + 1)

    return max_length
```

### 6. 水果成篮

**LeetCode 904**: 最多选择两种水果，求最长连续子数组。

```python
def total_fruit(fruits):
    """
    滑动窗口 + 哈希表存储最后出现位置
    时间复杂度: O(n)
    空间复杂度: O(1)
    """
    last_seen = {}  # 存储每种水果的最后出现位置
    left = 0
    max_length = 0

    for right in range(len(fruits)):
        fruit = fruits[right]
        last_seen[fruit] = right

        # 收缩窗口直到只有两种水果
        if len(last_seen) > 2:
            # 找到最旧的水果并移除
            oldest_fruit = min(last_seen, key=last_seen.get)
            left = last_seen[oldest_fruit] + 1
            del last_seen[oldest_fruit]

        max_length = max(max_length, right - left + 1)

    return max_length
```

## 单调队列优化

滑动窗口求最值时，每次窗口滑动都需要 O(k) 比较。使用单调队列可将比较降至 O(1)。

### 单调队列原理

```python
from collections import deque


class MonotonicQueue:
    """
    单调队列：队首存储最大值，队尾存储候选值
    入队时移除比新元素小的所有元素（它们不可能成为最大值）
    出队时移除过期元素
    """

    def __init__(self):
        self.queue = deque()

    def push(self, val):
        """入队：移除队列中所有小于 val 的元素"""
        while self.queue and self.queue[-1] < val:
            self.queue.pop()
        self.queue.append(val)

    def pop(self, val):
        """出队：如果移除的是最大值，则从队首移除"""
        if self.queue and self.queue[0] == val:
            self.queue.popleft()

    def max(self):
        """获取最大值：队首即最大值"""
        return self.queue[0] if self.queue else None
```

### 滑动窗口最大值

**LeetCode 239**: 求每个窗口大小为 k 的最大值数组。

**时间复杂度**: O(n)
**空间复杂度**: O(k)

```python
def max_sliding_window(nums, k):
    """
    单调递减队列
    队首始终是当前窗口的最大值
    """
    from collections import deque

    queue = deque()  # 存储元素索引
    result = []

    for i in range(len(nums)):
        # 1. 入队：移除队列中所有小于当前元素的索引（它们不可能是最大值）
        while queue and nums[queue[-1]] < nums[i]:
            queue.pop()
        queue.append(i)

        # 2. 出队：移除超出窗口范围的索引
        while queue[0] <= i - k:
            queue.popleft()

        # 3. 记录结果
        if i >= k - 1:
            result.append(nums[queue[0]])

    return result


def max_sliding_window_brute(nums, k):
    """
    暴力方法（对照）
    时间复杂度: O(n*k)
    """
    result = []
    for i in range(len(nums) - k + 1):
        result.append(max(nums[i:i + k]))
    return result
```

**单调队列图解**：
```
nums = [1, 3, -1, -3, 5, 3, 6, 7], k = 3

Step 0: queue = []          → []
Step 1: push 1  → [0]       → [1]
Step 2: push 3  → pop 1, [1]→ [3]
Step 3: push -1 → [-1]     → [3, -1]  (保留顺序因为 -1 < 3)
Step 4: push -3 → [-1, -3] → [3, -1, -3]
Step 5: window at [3,-1,-3], max = 3  → output [3]
        push 5  → pop all, [5]         → [5]
...
```

def min_sliding_window(nums, k):

## 子数组问题模板

滑动窗口常用于求解满足特定条件的子数组问题。

```python
def subarray_template(nums, target):
    """
    求满足条件的最短/最长子数组
    时间复杂度: O(n)
    """
    left = 0
    current_sum = 0
    min_length = float('inf')

    for right in range(len(nums)):
        current_sum += nums[right]

        # 收缩窗口直到满足条件
        while current_sum >= target:
            min_length = min(min_length, right - left + 1)
            current_sum -= nums[left]
            left += 1

    return min_length if min_length != float('inf') else 0
```

### 和大于等于 target 的最短子数组

**LeetCode 862**: 求和大于等于 target 的最短子数组长度。

```python
def shortest_subarray(nums, target):
    """
    前缀和 + 单调队列
    时间复杂度: O(n)
    空间复杂度: O(n)
    """
    from collections import deque

    n = len(nums)
    prefix_sum = [0] * (n + 1)
    for i in range(n):
        prefix_sum[i + 1] = prefix_sum[i] + nums[i]

    queue = deque()  # 存储候选前缀和索引
    queue.append(0)
    result = float('inf')

    for i in range(1, n + 1):
        # 找到满足条件的最近前缀和
        while queue and prefix_sum[i] - prefix_sum[queue[0]] >= target:
            result = min(result, i - queue.popleft())

        # 维护单调递增队列（更小的前缀和更有价值）
        while queue and prefix_sum[i] <= prefix_sum[queue[-1]]:
            queue.pop()
        queue.append(i)

    return result if result != float('inf') else -1
```

## 模板总结

```python
# 固定窗口
for right in range(len(nums)):
    add nums[right]
    if right >= k - 1:
        update answer
        remove nums[right - k + 1]

# 可变窗口（最小覆盖子串）
for right in range(len(s)):
    add s[right] to window
    while valid:
        update answer
        remove s[left] from window
        left += 1

# 单调队列（窗口最值）
while queue and nums[queue[-1]] < nums[right]:
    queue.pop()
queue.append(right)
while queue[0] <= right - k:
    queue.popleft()
```
