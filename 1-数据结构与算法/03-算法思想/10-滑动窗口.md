## 滑动窗口

### 解决什么问题
高效遍历数组/字符串，通过维护连续子数组/子串的窗口，将嵌套循环优化为单层循环。适用于子串/子数组问题，如无重复字符最长子串、最小覆盖子串等。

### 核心概念
- **窗口扩大**：右指针右移加入新元素
- **窗口收缩**：左指针右移移除旧元素
- **固定窗口**：窗口大小不变，如求最大值/平均值
- **可变窗口**：窗口大小动态变化，如最小覆盖子串
- **单调队列优化**：窗口最值查询从 O(k) 降至 O(1)

## 固定窗口

窗口大小固定的滑动窗口，适用于求最大值/平均值等。

### 参考样例

```python
def fixed_window_template(nums, k):
    window_sum = sum(nums[:k])
    max_sum = window_sum
    for i in range(k, len(nums)):
        window_sum += nums[i] - nums[i - k]
        max_sum = max(max_sum, window_sum)
    return max_sum
```

## 可变窗口

窗口大小动态变化的滑动窗口，适用于子串/子数组问题。

### 参考样例

```python
def variable_window_template(s):
    from collections import Counter
    need = Counter(s)
    window = {}
    left, right = 0, 0
    valid = 0
    while right < len(s):
        c = s[right]
        right += 1
        window[c] = window.get(c, 0) + 1
        if need[c] > 0 and window[c] == need[c]:
            valid += 1
        while valid == len(need):
            result = s[left:right]
            d = s[left]
            left += 1
            if need[d] > 0 and window[d] == need[d]:
                valid -= 1
            window[d] -= 1
    return result
```

## 无重复字符的最长子串

**LeetCode 3**：找出一个字符串中不包含重复字符的最长子串长度。

### 参考样例

```python
def length_of_longest_substring(s):
    char_index = {}
    left = 0
    max_length = 0
    for right in range(len(s)):
        if s[right] in char_index and char_index[s[right]] >= left:
            left = char_index[s[right]] + 1
        char_index[s[right]] = right
        max_length = max(max_length, right - left + 1)
    return max_length
```

## 最小覆盖子串

**LeetCode 76**：在 s 中找到包含 t 所有字符的最小子串。

### 参考样例

```python
def min_window(s, t):
    from collections import Counter
    need = Counter(t)
    window = {}
    left = 0
    valid = 0
    start = 0
    min_len = float('inf')
    for right in range(len(s)):
        char_r = s[right]
        window[char_r] = window.get(char_r, 0) + 1
        if char_r in need and window[char_r] == need[char_r]:
            valid += 1
        while valid == len(need):
            if right - left + 1 < min_len:
                start = left
                min_len = right - left + 1
            char_l = s[left]
            if char_l in need and window[char_l] == need[char_l]:
                valid -= 1
            window[char_l] -= 1
            left += 1
    return s[start:start + min_len] if min_len != float('inf') else ""
```

## 滑动窗口最大值

**LeetCode 239**：求每个窗口大小为 k 的最大值数组。使用单调递减队列，队首始终是当前窗口的最大值。

### 参考样例

```python
from collections import deque

def max_sliding_window(nums, k):
    queue = deque()
    result = []
    for i in range(len(nums)):
        while queue and nums[queue[-1]] < nums[i]:
            queue.pop()
        queue.append(i)
        while queue[0] <= i - k:
            queue.popleft()
        if i >= k - 1:
            result.append(nums[queue[0]])
    return result
```

## 最大连续1的个数 III

**LeetCode 1004**：最多翻转 k 个 0 后的最长连续 1 数组。

### 参考样例

```python
def longest_ones(nums, k):
    left = 0
    zero_count = 0
    max_length = 0
    for right in range(len(nums)):
        if nums[right] == 0:
            zero_count += 1
        while zero_count > k:
            if nums[left] == 0:
                zero_count -= 1
            left += 1
        max_length = max(max_length, right - left + 1)
    return max_length
```

## 和至少为 K 的最短子数组

**LeetCode 862**：前缀和 + 单调队列。

### 参考样例

```python
def shortest_subarray(nums, target):
    from collections import deque
    n = len(nums)
    prefix_sum = [0] * (n + 1)
    for i in range(n):
        prefix_sum[i + 1] = prefix_sum[i] + nums[i]
    queue = deque([0])
    result = float('inf')
    for i in range(1, n + 1):
        while queue and prefix_sum[i] - prefix_sum[queue[0]] >= target:
            result = min(result, i - queue.popleft())
        while queue and prefix_sum[i] <= prefix_sum[queue[-1]]:
            queue.pop()
        queue.append(i)
    return result if result != float('inf') else -1
```
