# 分支限界

## 定义

分支限界通过优先队列按估计下界排序扩展节点，以限界函数剪去无法产生更优解的分支，在解空间树中系统搜索最优解。

## 数学模型

A* 算法的估计函数：
$$f(n) = g(n) + h(n)$$

- $g(n)$：起点到 $n$ 的实际代价
- $h(n)$：$n$ 到目标的启发估计
- $f(n)$：经过 $n$ 的最优路径总代价上界

可采纳性：$h(n)$ 从不高估真实代价 $\implies$ A* 找到最优解。

## 数据流

<pre>
八数码问题搜索树:
        [初始状态]
           │
    按 f 值扩展 (优先队列)
           │
    [状态A: f=6] ← 优先扩展
           │
    ┌──────┴──────┐
 [状态B]    [状态C]   ← f 值更小的先扩展
   f=7         f=8
    │            │
  (弹栈)      继续扩展...
数据形态: state (tuple) → f_score (int) → 优先队列出队
</pre>

## 机制

**与回溯的本质区别**：回溯找所有解或一个解（深度优先），分支限界找最优解（通常 BFS/最佳优先）。分支限界用优先队列按限界值排序，回溯用栈按深度优先。

**限界函数约束**：
- 下界估计必须不大于真实最优代价，否则剪掉本可最优的分支
- 上界估计越大剪枝效率越低，但过于激进会导致错失最优解

**A* 的可采纳性要求**：$h(n) \leq h^*(n)$（真实最小代价）。若违反，A* 可能返回次优解。

**随机化分支限界**（快速选择）：基于随机 pivot 的划分，第 $k$ 大期望 $O(n)$，最坏 $O(n^2)$（随机化保证期望最优）。

## 参考存根

```python
import heapq

def astar(start, goal, h, neighbors):
    open_set = [(h(start), 0, start)]
    g_score = {start: 0}
    while open_set:
        _, g, cur = heapq.heappop(open_set)
        if cur == goal: return g
        for nxt, cost in neighbors(cur):
            if g + cost < g_score.get(nxt, float('inf')):
                g_score[nxt] = g + cost
                heapq.heappush(open_set, (g_score[nxt] + h(nxt), g_score[nxt], nxt))
    return -1
```
