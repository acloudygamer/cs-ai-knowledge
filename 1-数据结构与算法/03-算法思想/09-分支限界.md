# 分支限界

> **版本基准**：universal —— 代码示例同时使用 Python 3.12 与 C++20

## 本质

分支限界（Branch and Bound, B&B）在解空间树上系统搜索**最优解**，靠**限界函数**估计每个分支的最优值上下界，剪掉"不可能比当前已知最优更好"的分支。与回溯的深度优先不同，它通常**最佳优先**——用优先队列按估计值扩展最有希望的节点。A* 是它在路径搜索上的特例，限界函数写成 $f(n)=g(n)+h(n)$。

工程上分支限界只关心两件事：**限界紧不紧**（越紧剪得越多，但算界本身有成本），以及**界是否可采纳**（对最小化问题，界必须是不高估真实代价的下界，否则会误剪最优）。这两个权衡直接决定它退化成"贪心近似"还是"指数穷举"。

## 数学模型

### A* 的估计函数与可采纳性

$$f(n) = g(n) + h(n)$$

$g(n)$ 是起点到 $n$ 的已知实际代价， $h(n)$ 是 $n$ 到目标的启发估计， $f(n)$ 是经 $n$ 的最优路径总代价的**上界估计**（对最小化问题）。

**可采纳性**：若对所有 $n$， $h(n) \leq h^*(n)$ （ $h^*$ 为真实最小代价），则 $h$ 可采纳。可采纳的 $h$ 永不高估，故 $f(n) \leq g(n) + h^*(n) = C^*$ （最优总代价）——A* 不会把最优路径上的节点误判为"已无希望"而剪掉。

**一致性**（更强的条件）：对每条边 $(u,v)$， $h(u) \leq c(u,v) + h(v)$。一致 $\Rightarrow$ 可采纳，且 A* 扩展节点的 $f$ 值单调非递减（不会回头重开已闭合节点）。

### 最优性证明

**定理**：若 $h$ 可采纳，A* 返回最优解。

**证明**（反证）：设最优路径代价 $C^*$，A* 返回次优解 $S$ （代价 $> C^*$）。考虑最优路径 $S^*$ 上第一个被 A* 跳过、未放入闭合集的节点 $n$。 $n$ 的父节点 $p$ 被扩展过，故 $n$ 曾入 open 队列，入队时：

$$f(n) = g_{S^*}(n) + h(n) \leq g_{S^*}(n) + h^*(n) = C^*$$

A* 弹出节点按 $f$ 升序。若 $n$ 一直未被弹出而目标先被返回，说明被弹出的目标节点 $f < C^*$。但目标节点 $h=0$，故 $g(S)=f(S) < C^*$，与 $C^*$ 是最优代价矛盾。故 A* 不可能返回次优解。 $\square$

**洞察**：可采纳性 = $f$ 是真实代价的"乐观下界"。A* 按 $f$ 升序展开，相当于"永远优先展开乐观估计最小的"，而最优路径的估计永远 $\leq C^*$，所以它必在劣于 $C^*$ 的目标之前先碰到最优目标——除非启发不可采纳，把乐观估计抬到了真实代价之上。

## 数据流

### 八数码 A* 搜索

<pre>
初始 [1 2 3 / 4 0 6 / 7 5 8], 目标 [1 2 3 / 4 5 6 / 7 8 0]
h = 不在位的方块数 (可采纳)

open 队列按 f = g + h 排序, 每节点携带 (g, parent)

弹出 f 最小者 → 扩展 0 的四邻居(交换) → 新状态入队
  每个新状态: g' = g+1, f' = g' + h(新状态)
closed 集: 已扩展状态不再重复扩展 (哈希去重)

路径重建: 命中目标后沿 parent 回溯 → 反转得解路径
</pre>

**所有权变换**：状态作为不可变元组（可哈希、可作字典键），`g_score` 字典持有"到此状态的最小代价"所有权，`came_from` 持父指针供回溯。父指针把零散状态缝成一条解路径。

### 0/1 背包的限界与剪枝

<pre>
容量 W=10, 物品 [(v=60,w=5),(v=100,w=8),(v=120,w=15)]
解空间树: 每层对一件物品 "选/不选"
限界: 当前价值 + 剩余物品的分数背包上界(按 v/w 密度贪心)

节点(已选物品0, 价值60, 重5):
  剩余容量 5, 剩余物品 [(100,8),(120,15)]
  分数上界 = 60 + min(5,8)*100/8 = 60 + 62.5 = 122.5
  若此上界 ≤ 已知最优 → 剪; 否则继续分支

剪枝两条件:
  1) 重量超容 → 该分支不可行, 剪
  2) 上界 ≤ 当前最优 → 不可能更优, 剪
</pre>

## 对比参照

| 维度 | 回溯 | 分支限界 | A* |
|------|------|----------|-----|
| 遍历 | DFS（栈） | 最佳优先（优先队列） | 最佳优先（优先队列） |
| 目标 | 所有/任一解 | 最优解 | 最短路径 |
| 剪枝 | 约束判无解 | 限界判上下界 | $f=g+h$ 估计 |
| 空间 | $O(d)$ | $O(b^d)$ 最坏 | $O(b^d)$，可用 IDA* 降 |

## 机制

### 分支 vs 限界

- **分支**：把问题拆成子问题的方式（如 0/1 背包按"选/不选"分叉）。决定树的形状。
- **限界**：估子问题最优值的界。界越紧剪得越多，但算界有成本。

权衡：简单弱的限界（剪枝少但每次便宜）vs 复杂紧的限界（剪枝多但每次贵）。实际常先用弱限界、必要时再上紧的。

### A* 退化的三种情形

| $h$ 设计 | 结果 |
|----------|------|
| $h=0$ | 退化为 Dijkstra（最优但无启发引导，等同无信息 BFS） |
| $h=h^*$ （完美） | 沿最优路径直走，指数 $\to$ 线性 |
| $h>h^*$ （不可采纳） | 可能跳过最优、返回次优 |

### 内存爆炸与对策

A* 须存 open + closed 两集，状态空间大时内存爆炸（15 数码 $\sim 10^{13}$）。对策：

- **IDA\***（迭代加深 A*）：用 $f$ 阈值替代 open/closed，每次 DFS 内只走 $f\leq$ 阈值的边，超阈值则记下最小超限值作下一轮阈值。空间 $O(bd)$。
- **RBFS**：只存当前路径与兄弟的 $f$，空间 $O(d)$。
- **SMA\***：内存满时删最差叶、保留其 $f$ 以便回填。

### 界函数的常见设计

| 问题 | 下界（最小化） | 上界（最大化） |
|------|--------------|--------------|
| TSP | 最小生成树/1-树 | 贪心插入构造 |
| 0/1 背包 | 已选价值 | 已选 + 分数背包密度上界 |
| 整数规划 | LP 松弛 | 贪心整数解 |

### 违规后果

| 违规 | 后果 |
|------|------|
| 界过松（剪不动） | 搜索接近指数穷举 |
| 界不可采纳（高估真实代价） | 误剪最优分支，返回次优 |
| 算界成本过高 | 抵消剪枝收益，反而更慢 |
| 无 closed 去重 | 同状态反复扩展，指数膨胀 |

### 与 DP 的关系

B&B 自顶向下、只展开"限界选中"的子问题，用启发换时间；DP 自底向上、展开全部子问题，用空间换时间。两者都为避免重复计算，但 B&B 是"按需展开 + 剪枝"，DP 是"全展开 + 记忆"。

## 代码示例

**Python 3.12**（A* 通用骨架 + 八数码）：

```python
import heapq

# A* 通用: h 须可采纳
def astar(start, goal, h, neighbors):
    counter = 0                              # 打破 f 平局, 避免比较 state
    open_set = [(h(start), 0, counter, start)]
    g_score = {start: 0}
    came_from = {start: None}
    while open_set:
        f, g, _, cur = heapq.heappop(open_set)
        if g > g_score.get(cur, float('inf')):    # 过时条目, 跳过
            continue
        if goal(cur):
            path = []
            while cur is not None:
                path.append(cur); cur = came_from[cur]
            return path[::-1]
        for nxt, cost in neighbors(cur):
            ng = g + cost
            if ng < g_score.get(nxt, float('inf')):
                g_score[nxt] = ng; came_from[nxt] = cur
                counter += 1
                heapq.heappush(open_set, (ng + h(nxt), ng, counter, nxt))
    return None

# 八数码: h = 不在位方块数 (可采纳)
GOAL = (1,2,3,4,5,6,7,8,0)
def h_misplaced(s): return sum(1 for i in range(9) if s[i] and s[i] != GOAL[i])
def neighbors(s):
    z = s.index(0); r, c = divmod(z, 3); out = []
    for dr, dc in ((1,0),(-1,0),(0,1),(0,-1)):
        nr, nc = r+dr, c+dc
        if 0 <= nr < 3 and 0 <= nc < 3:
            lst = list(s); nz = nr*3 + nc
            lst[z], lst[nz] = lst[nz], lst[z]
            out.append((tuple(lst), 1))
    return out

# —— 简易输入输出 ——
start = (1,2,3,4,0,6,7,5,8)
path = astar(start, lambda s: s == GOAL, h_misplaced, neighbors)
print(len(path) - 1 if path else None, "步")   # 2 步 (0 与 5、8 交换)
```

**C++20**（0/1 背包分支限界）：

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <queue>

struct Item { double v, w; };

// 限界: 已选价值 + 剩余物品分数背包上界
double bound(int i, double v, double cap, const std::vector<Item>& it) {
    double tot = v;
    for (int k = i; k < (int)it.size() && cap > 0; ++k) {
        double take = std::min(it[k].w, cap);
        tot += take * (it[k].v / it[k].w);
        cap -= take;
    }
    return tot;
}

// 0/1 背包分支限界(最大化), 返回最大价值
double knapsack(std::vector<Item> it, double W) {
    // 按单位价值降序, 让上界更紧
    std::sort(it.begin(), it.end(),
              [](auto& a, auto& b){ return a.v/a.w > b.v/b.w; });
    struct Node { int i; double v, w; };
    std::queue<Node> q;
    q.push({0, 0, 0});
    double best = 0;
    while (!q.empty()) {
        auto [i, v, w] = q.front(); q.pop();
        if (i == (int)it.size()) continue;
        // 选物品 i
        if (w + it[i].w <= W) {
            best = std::max(best, v + it[i].v);
            q.push({i+1, v + it[i].v, w + it[i].w});
        }
        // 不选物品 i (仅当上界仍可能超过当前最优才入队)
        if (bound(i+1, v, W - w, it) > best)
            q.push({i+1, v, w});
    }
    return best;
}

int main() {
    std::cout << knapsack({{60,5},{100,8},{120,15}}, 16) << '\n';   // 160 (选物品0+1: 60+100)
}
```
