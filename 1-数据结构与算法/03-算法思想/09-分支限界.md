## 分支限界法

### 解决什么问题
通过剪枝和限界函数寻找最优解，适用于组合优化问题（如旅行商问题、装载问题、背包问题），与回溯法相比更注重最优解搜索。

### 核心概念
- **广度优先或最佳优先搜索**
- **限界函数**：估计下界/上界，剪掉无法产生更优解的分支
- **与回溯区别**：回溯找所有/一个解，分支限界找最优解
- **优先队列按限界值排序**，优先扩展最优解

## A* 算法

**A* = BFS + 启发式搜索**

核心公式：f(n) = g(n) + h(n)
- g(n)：从起点到当前节点的实际代价
- h(n)：从当前节点到目标的估计代价（启发函数）
- f(n)：总代价估计

性质：若 h(n) 是可采纳的（永远不会高估），则 A* 能找到最优解。

### 参考样例

```python
import heapq

def astar(start, goal, h_func, neighbors_func):
    open_set = [(h_func(start), 0, start)]
    came_from = {}
    g_score = {start: 0}
    while open_set:
        _, _, current = heapq.heappop(open_set)
        if current == goal:
            return g_score[goal]
        for neighbor, cost in neighbors_func(current):
            tentative_g = g_score[current] + cost
            if tentative_g < g_score.get(neighbor, float('inf')):
                came_from[neighbor] = current
                g_score[neighbor] = tentative_g
                f_score = tentative_g + h_func(neighbor)
                heapq.heappush(open_set, (f_score, tentative_g, neighbor))
    return -1
```

## 随机化算法

### 快速选择

**LeetCode 215**：找到第 k 大的元素，平均 O(n)。

### 参考样例

```python
import random

def find_kth_largest(nums, k):
    def partition(low, high):
        pivot_idx = random.randint(low, high)
        nums[pivot_idx], nums[high] = nums[high], nums[pivot_idx]
        pivot = nums[high]
        i = low - 1
        for j in range(low, high):
            if nums[j] > pivot:
                i += 1
                nums[i], nums[j] = nums[j], nums[i]
        nums[i + 1], nums[high] = nums[high], nums[i + 1]
        return i + 1
    def select(low, high, k):
        if low == high:
            return nums[low]
        pi = partition(low, high)
        if k == pi:
            return nums[pi]
        elif k < pi:
            return select(low, pi - 1, k)
        else:
            return select(pi + 1, high, k)
    return select(0, len(nums) - 1, k - 1)
```

## 经典应用

### 八数码问题（滑动拼图）

使用 A* 算法解决。

### 参考样例

```python
def manhattan(state, goal):
    distance = 0
    for i, tile in enumerate(state):
        if tile != 0:
            target_idx = goal.index(tile)
            x1, y1 = i // 3, i % 3
            x2, y2 = target_idx // 3, target_idx % 3
            distance += abs(x1 - x2) + abs(y1 - y2)
    return distance

def solve_puzzle(start, goal):
    start = tuple(start)
    goal = tuple(goal)
    heap = [(manhattan(start, goal), 0, start)]
    visited = {start: 0}
    parent = {start: None}
    while heap:
        f, g, state = heapq.heappop(heap)
        if state == goal:
            path = []
            while state:
                path.append(state)
                state = parent[state]
            return path[::-1]
        zero_idx = state.index(0)
        x, y = zero_idx // 3, zero_idx % 3
        for dx, dy in [(0, 1), (0, -1), (1, 0), (-1, 0)]:
            nx, ny = x + dx, y + dy
            if 0 <= nx < 3 and 0 <= ny < 3:
                new_idx = nx * 3 + ny
                new_state = list(state)
                new_state[zero_idx], new_state[new_idx] = new_state[new_idx], new_state[zero_idx]
                new_state = tuple(new_state)
                new_g = g + 1
                if new_state not in visited or new_g < visited[new_state]:
                    visited[new_state] = new_g
                    f = new_g + manhattan(new_state, goal)
                    heapq.heappush(heap, (f, new_g, new_state))
                    parent[new_state] = state
    return None
```

## 随机洗牌算法

Fisher-Yates 洗牌算法，时间复杂度 O(n)。

### 参考样例

```python
import random

def shuffle(arr):
    result = arr[:]
    for i in range(len(result) - 1, 0, -1):
        j = random.randint(0, i)
        result[i], result[j] = result[j], result[i]
    return result
```
