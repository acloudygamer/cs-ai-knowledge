# 分支限界

## 定义

> **版本基准**: universal

分支限界（Branch and Bound）是对解空间树进行系统搜索的算法范式，通过**限界函数**（bound function）估计每个分支的最优解上界或下界，剪去无法产生更优解的分支，从而在指数级解空间中高效搜索最优解。与回溯的深度优先不同，分支限界通常采用最佳优先（best-first），用优先队列按估计值扩展最有希望的节点。

## 数学模型

### A\* 算法的估计函数

A\* 是分支限界的特例，其限界函数为：
$$f(n) = g(n) + h(n)$$

- $g(n)$：从起始节点到节点 $n$ 的实际代价（已知的累积成本）
- $h(n)$：从节点 $n$ 到目标节点的启发估计（需人为设计）
- $f(n)$：经过节点 $n$ 的最优路径总代价的上界估计

### 可采纳性（Admissibility）

若对所有节点 $n$，$h(n) \leq h^*(n)$（$h^*$ 为真实最小代价），则称 $h$ 是可采纳的。可采纳性保证 A\* 不会错过最优解。

**意义**：可采纳的启发函数永不高估真实代价，因此 $f(n) = g(n) + h(n) \leq g(n) + h^*(n) = C^*$（最优路径代价）。当优先队列中所有节点的 $f$ 值都 $\geq C^*$ 时，搜索必在最优解处终止。

### 一致性（Consistency / 单调性）

若对所有边 $(u, v)$ 有 $h(u) \leq c(u, v) + h(v)$（其中 $c(u,v)$ 为边代价），则称 $h$ 一致。

**一致性引理**：一致的性能保证启发函数在每条边上都是"不下坡"的。推论：若 $h$ 一致，则 A\* 扩展节点 $n$ 时，$f(n)$ 值单调非递减。

**证明**：设节点 $n$ 被扩展，$n'$ 为其后继。$f(n') = g(n') + h(n') = g(n) + c(n,n') + h(n') \geq g(n) + h(n) = f(n)$。

### 最优性证明

**定理（最优性）**：若 $h$ 可采纳，则 A\* 算法返回最优解路径。

**证明**（反证法）：
设 $S^*$ 为最优解路径（代价 $C^*$），$S$ 为 A\* 输出的解路径。设 $n$ 为 $S^*$ 上第一个被 A\* 跳过的节点（不在 closed 集中被扩展）。

由于 $n$ 的父节点 $p$ 被扩展但 $n$ 未被扩展，说明优先队列中所有节点的 $f$ 值小于 $C^*$ 时，$n$ 不在队列中。

考虑 $n$ 被放入优先队列的时刻：此时 $f(n) = g_S^*(n) + h(n)$，其中 $g_S^*(n)$ 为 $S^*$ 上到达 $n$ 的代价。

由于 $h(n) \leq h^*(n)$（可采纳性），有：
$$f(n) \leq g_S^*(n) + h^*(n) = C^*$$

但优先队列弹出节点的 $f$ 值严格小于 $C^*$，且 $n$ 最终未被弹出扩展——这意味着存在某路径 $S$ 的目标节点，其 $f$ 值 $< C^*$ 被返回。但 $h \geq 0$，故 $g(S) \leq f(S) < C^*$，与 $C^*$ 是最优代价矛盾。

**归约终点**：分支限界是**在指数级解空间树中的最优路径搜索问题**。限界函数提供剪枝依据，可采纳启发函数保证最优性。问题可归约为"在约束条件下最小化/最大化目标函数"的优化问题。

## 数据流

### 八数码问题（8-Puzzle）的 A\* 搜索树

<pre>
初始状态:
[1 2 3]    目标: [1 2 3]
[4 0 6]    h(n) = 不在位的数字个数 = 4
[7 5 8]

优先队列 (open set) 按 f = g + h 排序:
状态节点: (f值, g值, 状态, 父节点)

Step 1: 初始节点入队
  open = [(4, 0, 初始状态, None)]  # f=0+4=4

Step 2: 弹出 f=4，扩展4个邻居（0 与上下左右交换）
  邻居 A (h=3, g=1, f=4) → open
  邻居 B (h=5, g=1, f=6) → open
  邻居 C (h=4, g=1, f=5) → open
  邻居 D (h=3, g=1, f=4) → open
  open 按 f 排序: [(4,A), (4,D), (5,C), (6,B), ...]

Step 3: 弹出 f=4 的 A（按插入顺序或 FIFO tie-break）
  ... 继续扩展 ...

closed 集合记录已扩展节点（避免重复扩展）

数据形态变换:
  状态元组 (tuple) → 计算 f 值 → 入优先队列 → 弹出扩展 → 生成新状态元组 → ...
  每个状态节点携带: g_score(实际代价), parent(父指针用于路径重建)

所有权转移:
  状态对象只读（作为字典键需可哈希）
  g_score 累积记录所有权（路径代价）
  parent 指针用于重建路径（所有权：最终路径属于调用者）
</pre>

### 分支限界中的限界与剪枝（以 0/1 背包为例）

<pre>
问题: 容量=10，物品=[(价值:60,重量:5), (价值:100,重量:10), (价值:120,重量:20)]
       贪心上界: 取物品1 (价值60) + 容量剩余5取物品0的一部分 (60+30=90)

解空间树 (每个节点表示对物品的选择状态):
        [root: 未选任何物品, 价值=0, 重量=0]
              │
       ┌──────┴──────┐
  [选物品0]      [不选物品0]
  v=0,w=0         v=0,w=0
      │                │
  ┌───┴───┐       ┌───┴───┐
[选物品1][不选1] [选物品1][不选1]
v=60,w=5  ...     v=100,w=10 ...

剪枝规则:
  若当前重量 > 容量 → 该分支不可行，剪掉
  若当前价值 + 剩余物品价值上界 ≤ 已知最优解 → 剪掉（无法超越）
  上界用分数背包计算: 价值 + Σ(剩余物品价值/重量 * 剩余容量)

例如: 在节点(选物品0,重量=5,价值=60)处
  剩余容量=5，剩余物品=[(100,10),(120,20)]
  上界 = 60 + min(5,10)*100/10 = 60 + 50 = 110 > 当前最优(0)，继续
</pre>

## 机制

### 分支限界的核心思想

解空间树中，大多数分支不可能产生比当前已知最优解更好的解。限界函数提供该分支最优解的上界估计（对最大化问题）或下界估计（对最小化问题）。若上界 ≤ 当前最优可行解，则剪去该分支。

**本质**：搜索策略是最小化"必须访问的节点数"。限界越紧，剪枝越多，但计算限界本身有成本（时间-空间权衡）。

### 分支策略 vs. 限界策略

- **分支**：如何将一个问题分解为子问题（分叉方式）。常用策略有按变量分支（如 0/1 背包的选/不选）、按约束分支。
- **限界**：如何估计子问题最优解的界。界越紧，剪枝越多；但计算界本身有成本。

**最优平衡**：若限界函数计算成本过高，可能抵消剪枝带来的搜索量减少。实际中需权衡：简单但弱的限界 vs. 复杂但紧的限界。

### A\* 何时退化为穷举搜索

| 情况 | $h$ 设计 | 结果 |
|------|----------|------|
| $h(n) = 0$ | 零启发 | A\* 退化为 Dijkstra（最优但无启发引导） |
| $h(n) = h^*(n)$ | 完美启发 | A\* 直接沿最优路径扩展（指数→线性） |
| $h(n) > h^*(n)$ | 不可采纳 | 可能跳过最优解，返回次优 |

### A\* 的内存问题与解决方案

A\* 需存储所有扩展过的节点（closed 集）和所有已知但未扩展的节点（open 集）。在最坏情况下，节点数指数增长。

| 问题规模 | 节点复杂度 | 内存压力 |
|----------|-----------|---------|
| 8-puzzle | 9! / 2 ≈ 181,440 | 可控 |
| 15-puzzle | ~10^13 | 不可控 |

**解决方案**：
- **IDA\*（迭代加深 A\*）**：用 $f$ 阈值替代 open/closed 集，空间 $O(bd)$
- **RBFS（递归最佳优先搜索）**：只存储当前路径和兄弟节点的 $f$ 值，空间 $O(d)$
- **SMA\*（简化记忆 A\*）**：当内存满时删除最差叶节点，保留其 $f$ 值以便后续恢复

### 分支限界的上界/下界函数设计

| 问题 | 下界估计 | 上界估计 |
|------|----------|----------|
| TSP（最小化） | 最便宜插入 | 贪心路径构造 |
| 0/1 背包（最大化） | 已选物品价值 | 已选 + 分数背包（取剩余物品的价值密度上界） |
| 作业调度 | 已排程作业成本 | 贪心调度剩余作业 |
| 整数规划 | LP 松弛 | 贪心构造整数解 |

### 违反约束的后果

| 违反 | 后果 |
|------|------|
| 上界估计过大（过宽松） | 剪枝效率低，搜索节点数接近指数级 |
| 上界估计过小（过激进） | 可能剪掉实际最优解的分支（仅当估计不可采纳时会发生） |
| 计算界函数成本过高 | 可能抵消剪枝带来的搜索量减少 |
| $h(n) > h^*(n)$（不可采纳） | 不保证最优性 |

### 分支限界与动态规划的关系

分支限界的解空间树搜索可视为 DP 的"智能展开"：
- DP 的自底向上计算：所有子问题的解都计算并存储
- 分支限界自顶向下搜索：只计算"必要"的子问题（被限界函数选中的路径）

**共同本质**：避免重复计算。但 DP 用空间换时间（存储所有子问题），分支限界用启发换时间（剪去不可能更优的分支）。

import heapq

def astar(start, goal, h, neighbors):
    """
    A* 算法通用实现
    start: 起始状态
    goal: 目标检测函数 (state -> bool)
    h: 启发函数 (state -> float), 须可采纳
    neighbors: (state -> list[(next_state, cost)])
    """
    open_set = [(h(start), 0, start)]
    g_score = {start: 0}
    came_from = {start: None}
    while open_set:
        _, g, cur = heapq.heappop(open_set)
        if goal(cur):
            # 重建路径
            path = []
            while cur is not None:
                path.append(cur)
                cur = came_from[cur]
            return path[::-1]
        for nxt, cost in neighbors(cur):
            tentative_g = g + cost
            if tentative_g < g_score.get(nxt, float('inf')):
                came_from[nxt] = cur
                g_score[nxt] = tentative_g
                f = tentative_g + h(nxt)
                heapq.heappush(open_set, (f, tentative_g, nxt))
    return None  # 无解
