## 二分搜索

### 解决什么问题
在有序数据中快速查找目标元素，将 O(n) 的线性查找优化为 O(log n)，适用于有序数组的查找、边界定位、二分答案等问题。

### 核心概念
- 每次将搜索范围缩小一半，通过中点比较排除一半元素
- 需要数据有序的前提条件
- 模板选择：标准二分、左边界、右边界，根据需求选择
- 二分答案：将优化问题转化为判定问题，通过二分搜索最优解

### 常见错误与边界条件

| 错误类型 | 正确做法 |
|---------|---------|
| `left + right` 溢出（C/C++） | 改为 `left + (right - left) // 2`（Python 不需要） |
| `left < right` vs `left <= right` | 查找元素用 `<=`；查找边界用 `<` |
| 循环结束条件 | 左边界模板返回 left；右边界模板返回 right |
| 重复元素区间 | 无法判断时收缩边界（如搜索旋转排序数组 II） |

## 标准二分搜索

### 参考样例

```python
def binary_search(nums, target):
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = (left + right) // 2
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1

def left_bound(nums, target):
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = (left + right) // 2
        if nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return left

def right_bound(nums, target):
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = (left + right) // 2
        if nums[mid] <= target:
            left = mid + 1
        else:
            right = mid - 1
    return right
```

## 搜索旋转排序数组

**LeetCode 33**：数组从某点旋转后整体分为两段有序区间，利用局部单调性判断 target 所在区间。

### 参考样例

```python
def search_rotated(nums, target):
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = (left + right) // 2
        if nums[mid] == target:
            return mid
        if nums[left] <= nums[mid]:
            if nums[left] <= target < nums[mid]:
                right = mid - 1
            else:
                left = mid + 1
        else:
            if nums[mid] < target <= nums[right]:
                left = mid + 1
            else:
                right = mid - 1
    return -1
```

### 搜索旋转排序数组 II（可能包含重复元素）

**LeetCode 81**：当 `nums[left] == nums[mid] == nums[right]` 时无法判断区间，收缩边界。

### 参考样例

```python
def search_rotated_ii(nums, target):
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = (left + right) // 2
        if nums[mid] == target:
            return True
        if nums[left] == nums[mid] == nums[right]:
            left += 1
            right -= 1
        elif nums[left] <= nums[mid]:
            if nums[left] <= target < nums[mid]:
                right = mid - 1
            else:
                left = mid + 1
        else:
            if nums[mid] < target <= nums[right]:
                left = mid + 1
            else:
                right = mid - 1
    return False
```

### 寻找旋转排序数组中的最小值

**LeetCode 153**：找 pivot 点，当 `nums[mid] > nums[right]` 时最小值在右半边。

### 参考样例

```python
def find_min(nums):
    left, right = 0, len(nums) - 1
    while left < right:
        mid = (left + right) // 2
        if nums[mid] > nums[right]:
            left = mid + 1
        else:
            right = mid
    return nums[left]
```

## 寻找峰值元素

**LeetCode 162**：峰值是比相邻元素都大的元素。如果 `nums[mid] < nums[mid+1]`，峰值在右半边。

### 参考样例

```python
def find_peak_element(nums):
    left, right = 0, len(nums) - 1
    while left < right:
        mid = (left + right) // 2
        if nums[mid] < nums[mid + 1]:
            left = mid + 1
        else:
            right = mid
    return left
```

## 搜索二维矩阵

### 每行升序，每行第一个元素大于上一行最后一个元素

**LeetCode 74**：将二维坐标映射为一维，利用二分搜索。

### 参考样例

```python
def search_matrix(matrix, target):
    if not matrix:
        return False
    m, n = len(matrix), len(matrix[0])
    left, right = 0, m * n - 1
    while left <= right:
        mid = (left + right) // 2
        row, col = mid // n, mid % n
        if matrix[row][col] == target:
            return True
        elif matrix[row][col] < target:
            left = mid + 1
        else:
            right = mid - 1
    return False
```

### 每行每列均升序

**LeetCode 240**：利用有序性从右上角或左下角开始搜索，大了往左，小了往下。

### 参考样例

```python
def search_matrix_ii(matrix, target):
    if not matrix:
        return False
    m, n = len(matrix), len(matrix[0])
    row, col = 0, n - 1
    while row < m and col >= 0:
        if matrix[row][col] == target:
            return True
        elif matrix[row][col] > target:
            col -= 1
        else:
            row += 1
    return False
```

## 在排序数组中查找元素第一次和最后一次出现位置

**LeetCode 34**：标准左边界 + 右边界模板。

### 参考样例

```python
def search_range(nums, target):
    def lower_bound(nums, target):
        left, right = 0, len(nums) - 1
        while left <= right:
            mid = (left + right) // 2
            if nums[mid] < target:
                left = mid + 1
            else:
                right = mid - 1
        return left

    def upper_bound(nums, target):
        left, right = 0, len(nums) - 1
        while left <= right:
            mid = (left + right) // 2
            if nums[mid] <= target:
                left = mid + 1
            else:
                right = mid - 1
        return right

    if not nums:
        return [-1, -1]
    left = lower_bound(nums, target)
    if left >= len(nums) or nums[left] != target:
        return [-1, -1]
    right = upper_bound(nums, target)
    return [left, right]
```

## 二分答案

将问题转化为"判定性问题"，通过二分搜索最优解。

### 最小化最大值（最小运输耗时）

**LeetCode 875**：判定函数 can_finish(k) 检查速度 k 是否能在 h 小时内吃完。

### 参考样例

```python
def min_eating_speed(piles, h):
    def can_finish(k):
        return sum((pile + k - 1) // k for pile in piles) <= h

    left, right = 1, max(piles)
    while left < right:
        mid = (left + right) // 2
        if can_finish(mid):
            right = mid
        else:
            left = mid + 1
    return left
```

### 最大化最小值（分割数组的最大值）

**LeetCode 410**：将数组分成 m 个连续子数组，最小化子数组和的最大值。

### 参考样例

```python
def split_array(nums, m):
    def can_split(max_sum):
        count = 1
        current = 0
        for num in nums:
            if current + num > max_sum:
                count += 1
                current = num
            else:
                current += num
        return count <= m

    left, right = max(nums), sum(nums)
    while left < right:
        mid = (left + right) // 2
        if can_split(mid):
            right = mid
        else:
            left = mid + 1
    return left
```
