# 二分搜索

### 解决什么问题
在有序数据中快速查找目标元素，将 O(n) 的线性查找优化为 O(log n)，适用于有序数组的查找、边界定位、二分答案等问题。

### 核心概念
- 每次将搜索范围缩小一半，通过中点比较排除一半元素
- 需要数据有序的前提条件
- 模板选择：标准二分、左边界、右边界，根据需求选择
- 二分答案：将优化问题转化为判定问题，通过二分搜索最优解

### 怎么用

## 二分搜索

**时间复杂度**: O(log n)
**空间复杂度**: O(1) 迭代 / O(log n) 递归栈

```python
# 标准二分
def binary_search(nums, target):
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = (left + right) // 2
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1

# 找左边界
def left_bound(nums, target):
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = (left + right) // 2
        if nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return left

# 找右边界
def right_bound(nums, target):
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = (left + right) // 2
        if nums[mid] <= target:
            left = mid + 1
        else:
            right = mid - 1
    return right

# 二分答案（搜索最小值/最大值）
def min_max_search(check, lo, hi):
    # 找到满足条件的最小值
    while lo < hi:
        mid = (lo + hi) // 2
        if check(mid):
            hi = mid
        else:
            lo = mid + 1
    return lo
```

## 二分搜索模板

### 模板一：标准二分
```python
def binary_search(nums, target):
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = left + (right - left) // 2  # 防止溢出
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1
```

### 模板二：左边界（第一个 >= target）
```python
def lower_bound(nums, target):
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = left + (right - left) // 2
        if nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return left  # 即为第一个 >= target 的位置
```

### 模板三：右边界（最后一个 <= target）
```python
def upper_bound(nums, target):
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = left + (right - left) // 2
        if nums[mid] <= target:
            left = mid + 1
        else:
            right = mid - 1
    return right  # 即为最后一个 <= target 的位置
```

- 二分答案（最小化最大值、最大化最小值）

## 搜索旋转排序数组

**LeetCode 33**: 假设按照升序排序的数组在某个点上被旋转，搜索目标值。

**思路**：
- 数组从某点旋转后，整体分为两段有序区间
- 判断 mid 落在哪个有序区间，根据 target 与边界的关系缩小范围

**时间复杂度**: O(log n)

```python
# 搜索旋转排序数组
def search_rotated(nums, target):
    """
    思路：利用局部单调性判断 target 所在区间
    - 若 nums[left] <= nums[mid]，左半边有序
    - 否则右半边有序
    """
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = (left + right) // 2
        if nums[mid] == target:
            return mid
        # 左半边有序
        if nums[left] <= nums[mid]:
            if nums[left] <= target < nums[mid]:
                right = mid - 1
            else:
                left = mid + 1
        # 右半边有序
        else:
            if nums[mid] < target <= nums[right]:
                left = mid + 1
            else:
                right = mid - 1
    return -1
```

### 搜索旋转排序数组 II（可能包含重复元素）

**LeetCode 81**: 数组可能包含重复元素，需要返回是否包含 target。

**思路**：
- 与上一题相同，但当 `nums[left] == nums[mid] == nums[right]` 时无法判断区间，收缩边界

**时间复杂度**: O(n) 最坏情况

```python
def search_rotated_ii(nums, target):
    """
    思路：与无重复版本相同，但当无法判断区间时收缩左右边界
    """
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = (left + right) // 2
        if nums[mid] == target:
            return True
        # 无法判断哪个区间有序
        if nums[left] == nums[mid] == nums[right]:
            left += 1
            right -= 1
        elif nums[left] <= nums[mid]:  # 左半边有序
            if nums[left] <= target < nums[mid]:
                right = mid - 1
            else:
                left = mid + 1
        else:  # 右半边有序
            if nums[mid] < target <= nums[right]:
                left = mid + 1
            else:
                right = mid - 1
    return False
```

### 寻找旋转排序数组中的最小值

**LeetCode 153**: 数组是升序旋转，找最小元素。

**思路**：
- 找 pivot 点，即最小元素位置
- 当 `nums[mid] > nums[right]` 时，最小值在右半边

```python
def find_min(nums):
    """
    思路：比较 mid 与 right，找到最小值所在区间
    """
    left, right = 0, len(nums) - 1
    while left < right:
        mid = (left + right) // 2
        if nums[mid] > nums[right]:
            left = mid + 1
        else:
            right = mid
    return nums[left]
```

### 寻找旋转排序数组中的最小值 II（可能重复）

**LeetCode 154**: 包含重复元素的旋转数组找最小值。

```python
def find_min_ii(nums):
    left, right = 0, len(nums) - 1
    while left < right:
        mid = (left + right) // 2
        if nums[mid] > nums[right]:
            left = mid + 1
        elif nums[mid] < nums[right]:
            right = mid
        else:  # nums[mid] == nums[right]，收缩右边界
            right -= 1
    return nums[left]
```

## 寻找峰值元素

**LeetCode 162**: 峰值是比相邻元素都大的元素，返回任意峰值索引。

**思路**：
- 利用坡度趋势：如果 `nums[mid] < nums[mid+1]`，峰值在右半边
- 否则峰值在左半边（含 mid）

**时间复杂度**: O(log n)

```python
def find_peak_element(nums):
    """
    思路：利用局部单调性，nums[mid] < nums[mid+1] 说明峰值在右侧
    """
    left, right = 0, len(nums) - 1
    while left < right:
        mid = (left + right) // 2
        if nums[mid] < nums[mid + 1]:
            left = mid + 1
        else:
            right = mid
    return left
```

### 寻找峰值 II

**LeetCode 1901**: 二维矩阵找峰值。

```python
def find_peak_grid(mat):
    """
    思路：从中间列找最大元素，再比较上下元素确定区间
    """
    n = len(mat)
    if n == 1:
        return [0, mat[0].index(max(mat[0]))]

    def find_in_column(col, top, bottom):
        mid = (top + bottom) // 2
        row_max = max(range(top, bottom + 1), key=lambda r: mat[r][col])
        max_val = mat[row_max][col]

        if col + 1 < n and mat[row_max][col] < mat[row_max][col + 1]:
            return find_in_column(col + 1, top, bottom)
        if col - 1 >= 0 and mat[row_max][col] < mat[row_max][col - 1]:
            return find_in_column(col - 1, top, bottom)
        return [row_max, col]

    return find_in_column(0, 0, n - 1)
```

## 搜索二维矩阵

**LeetCode 74**: 每行升序，每行第一个元素大于上一行最后一个元素。

```python
def search_matrix(matrix, target):
    """
    思路：将二维坐标映射为一维，利用二分搜索
    """
    if not matrix:
        return False
    m, n = len(matrix), len(matrix[0])
    left, right = 0, m * n - 1
    while left <= right:
        mid = (left + right) // 2
        row, col = mid // n, mid % n
        if matrix[row][col] == target:
            return True
        elif matrix[row][col] < target:
            left = mid + 1
        else:
            right = mid - 1
    return False
```

### 搜索二维矩阵 II（每行每列均升序）

**LeetCode 240**: 利用有序性从右上角或左下角开始搜索。

```python
def search_matrix_ii(matrix, target):
    """
    思路：从右上角出发，大了往左，小了往下
    时间复杂度: O(m + n)
    """
    if not matrix:
        return False
    m, n = len(matrix), len(matrix[0])
    row, col = 0, n - 1
    while row < m and col >= 0:
        if matrix[row][col] == target:
            return True
        elif matrix[row][col] > target:
            col -= 1
        else:
            row += 1
    return False
```

## 在排序数组中查找元素第一次和最后一次出现位置

**LeetCode 34**: 标准左边界 + 右边界模板。

```python
def search_range(nums, target):
    """
    时间复杂度: O(log n)
    """
    def lower_bound(nums, target):
        left, right = 0, len(nums) - 1
        while left <= right:
            mid = (left + right) // 2
            if nums[mid] < target:
                left = mid + 1
            else:
                right = mid - 1
        return left

    def upper_bound(nums, target):
        left, right = 0, len(nums) - 1
        while left <= right:
            mid = (left + right) // 2
            if nums[mid] <= target:
                left = mid + 1
            else:
                right = mid - 1
        return right

    if not nums:
        return [-1, -1]
    left = lower_bound(nums, target)
    if left >= len(nums) or nums[left] != target:
        return [-1, -1]
    right = upper_bound(nums, target)
    return [left, right]
```

## 二分答案

**思路**：将问题转化为"判定性问题"，通过二分搜索最优解。

### 最小化最大值（最小运输耗时）

**LeetCode 875**: Koko 吃香蕉，每小时最多吃一堆，求最小速度。

```python
def min_eating_speed(piles, h):
    """
    思路：判定函数 can_finish(k) 检查速度 k 是否能在 h 小时内吃完
    """
    def can_finish(k):
        return sum((pile + k - 1) // k for pile in piles) <= h

    left, right = 1, max(piles)
    while left < right:
        mid = (left + right) // 2
        if can_finish(mid):
            right = mid
        else:
            left = mid + 1
    return left
```

### 最大化最小值（最大化最小分配空间）

**LeetCode 410**: 将数组分成 m 个连续子数组，最小化子数组和的最大值。

```python
def split_array(nums, m):
    """
    思路：二分搜索子数组和的最大值，判定函数 can_split(max_sum)
    """
    def can_split(max_sum):
        count = 1
        current = 0
        for num in nums:
            if current + num > max_sum:
                count += 1
                current = num
            else:
                current += num
        return count <= m

    left, right = max(nums), sum(nums)
    while left < right:
        mid = (left + right) // 2
        if can_split(mid):
            right = mid
        else:
            left = mid + 1
    return left
```

### 找到 K 个最接近的元素

**LeetCode 658**: 在排序数组中找最接近 target 的 k 个元素。

```python
def find_closest_elements(arr, k, target):
    """
    思路：二分找到 target 位置，取左右扩展
    时间复杂度: O(log n + k)
    """
    left, right = 0, len(arr) - k
    while left < right:
        mid = (left + right) // 2
        if target - arr[mid] <= arr[mid + k] - target:
            right = mid
        else:
            left = mid + 1
    return arr[left:left + k]
```

## 常见错误与边界条件

| 错误类型 | 正确做法 |
|---------|---------|
| `left + right` 溢出 | 改为 `left + (right - left) // 2` |
| `left < right` vs `left <= right` | 查找元素用 `<=`；查找边界用 `<` |
| 循环结束条件 | 左边界模板返回 left；右边界模板返回 right |
| 重复元素区间 | 无法判断时收缩边界（如搜索旋转排序数组 II） |
