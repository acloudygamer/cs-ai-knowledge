# 二分搜索

## 定义

> **版本基准**: universal

二分搜索（Binary Search）是在**有序序列**中将目标定位问题通过**每次将搜索空间折半**来实现的 $O(\log n)$ 算法。它本质上是在完全二叉决策树上做自顶向下的贪心搜索。

**本质操作**：二分搜索的核心操作是**比较 + 区间收缩**。每步通过一次 $O(1)$ 比较，确定目标落在左半区间还是右半区间，将搜索空间缩小一半。

## 数学模型

### 决策树高度

设序列长度为 $n$ ，每步将搜索空间减半：
$T(n) = T(n/2) + O(1)$

展开递归：
$T(n) = T(n/2) + 1 = T(n/4) + 2 = \dots = T(n/2^k) + k$

令 $n/2^k \leq 1 \implies k \geq \log_2 n$ ：
$T(n) = O(\log n)$

**决策树高度的下界**：对于 $n$ 个元素的搜索问题，任何基于比较的算法最优情况下的决策树高度至少为 $\lceil \log_2 n \rceil$ 。二分搜索恰好达到这个下界，因此是最优的。

### 收敛边界

设搜索过程中第 $k$ 步后的剩余区间长度为 $n_k$ ：
$n_k = \left\lceil \frac{n}{2^k} \right\rceil$

收敛条件 $n_k \leq 1$ 等价于 $k \geq \log_2 n$ 。

### 旋转数组变种

设旋转数组由两个有序子数组拼接而成： $sorted = [a_0, a_1, \dots, a_{n-1}]$ ，旋转后  $rotated = [a_{p}, a_{p+1}, \dots, a_{n-1}, a_0, \dots, a_{p-1}]$。

**判断哪半边有序**：
```
若 arr[mid] > arr[left]，则左半边 [left, mid) 有序
否则右半边 [mid, right) 有序
```

每次比较后丢弃有序的那半边，在无序的那半边继续搜索。总体仍保持 $O(\log n)$ 。

**归约终点**：二分搜索是**有序集合上的决策树搜索问题的最优解**，其决策树高度下界为 $\lceil \log_2 n \rceil$ 。旋转数组搜索是三分叉而非二分叉，需要先判断有序半边再决定搜索区间。

## 数据流

### 标准二分搜索执行流

<pre>
搜索目标: target=6, 序列: [1, 3, 5, 6, 7, 9]

Step 1:
  left=0, right=5, mid=2
  arr[2]=5 < 6 → 目标在右半边
  新区间: [left=3, right=5]

Step 2:
  left=3, right=5, mid=4
  arr[4]=7 > 6 → 目标在左半边
  新区间: [left=3, right=3]

Step 3:
  left=3, right=3, mid=3
  arr[3]=6 == 6 → 命中，return 3

数据形态变换:
  list[int] + target → predicate(mid) → {GoLeft | GoRight | Found}
  搜索空间: [0,5] → [3,5] → [3,3]
</pre>

### 边界查找（左边界）执行流

<pre>
搜索目标: target=5, 序列: [1, 3, 5, 5, 5, 9]

标准二分找到的是任意一个5，而非最左/最右边界

左边界变种: 找到 target 后不返回，继续收缩右边界
Step 1: left=0, right=5, mid=2, arr[2]=5 == 5 → 收缩右边界 right=mid → [0,2]
Step 2: left=0, right=2, mid=1, arr[1]=3 < 5 → 扩张左边界 left=mid+1 → [2,2]
Step 3: left=2, right=2, mid=2, arr[2]=5 == 5 → 收缩 right=mid → [2,2]
Step 4: left=2, right=1 → 循环结束，left=2 即左边界

关键修改: arr[mid]==target 时 right=mid（不返回），最终 left/right 收敛到最左位置
</pre>

### 旋转数组搜索执行流

<pre>
搜索目标: target=6, 旋转数组: [4, 5, 6, 7, 0, 1, 2]

Step 1:
  left=0, right=6, mid=3
  arr[mid]=7 > arr[left]=4 → 左半边 [0,3) 有序
  检查6是否在 [4,5,6]内：arr[mid]=7 > target=6，但 arr[left]=4 < target，不在左半边
  → 搜索右半边: left=mid+1=4

Step 2:
  left=4, right=6, mid=5
  arr[mid]=1 < arr[left]=0 → 右半边 [5,7) 有序
  检查6是否在 [0,1,2]内：arr[mid]=1 < target=6，且 arr[left]=0 < target，在右半边
  → left=mid+1=6

Step 3:
  left=6, right=6, mid=6
  arr[mid]=2 == target=6? No, 2 < 6 → left=mid+1=7 > right → 未找到，return -1

实际 target=6 在原数组 index=2，旋转后在 [4,5,6,7,0,1,2] 中 index=2
正确执行流应找到 index=2

数据形态: 无序旋转数组 → 有序半边判断 → 单调区间内目标判断 → O(log n) 收敛
</pre>

## 机制

### 为什么 $O(\log n)$

搜索空间按指数速度衰减： $n \to n/2 \to n/4 \to \dots \to 1$ 。决策树高度为  $\lceil \log_2 n \rceil$，每层仅需一次比较。

**与线性搜索的本质区别**：线性搜索的搜索空间按算术递减 $n \to n-1 \to n-2 \to \dots$ ，总比较次数 $O(n)$ 。二分搜索利用有序信息，将信息增益最大化——每次比较将候选空间减半。

### 区间定义的两种风格

**闭合区间 $[left, right]$**：
```
while left <= right:
    mid = left + (right - left) // 2
```
停止条件：`left > right`（区间为空）

**左闭右开区间 $[left, right)$**：
```
while left < right:
    mid = left + (right - left) // 2
```
停止条件：`left == right`（空区间）

**混用会导致错误**：在 `[left, right]` 风格中用 `left < right` 做循环条件，或在 `[left, right)$ 风格中用 `left <= right` 做条件，会导致死循环或漏查边界元素。

### 整数溢出风险

在 `mid = (left + right) // 2` 中，若 `left` 和 `right` 是大整数（如 $2^{31}-1$ ），`left + right` 可能溢出。

**解决方案**：`mid = left + (right - left) // 2`。Python 的整数是 arbitrary precision，不会溢出，但 C/C++/Java 等语言必须注意。

### 左/右边界查找的语义差异

| 变种 | 找到目标时行为 | 适用场景 |
|------|--------------|---------|
| 标准二分 | 立即返回 | 只需确认存在性 |
| 左边界 | `right = mid`，继续收缩 | 找第一个 $\geq target$ 的位置 |
| 右边界 | `left = mid`，继续扩张 | 找最后一个 $\leq target$ 的位置 |

### 三分叉变体（旋转数组）

旋转数组搜索是三分叉而非二分叉：
1. 先判断哪半边有序（比较 `arr[mid]` 和 `arr[left]`）
2. 再判断目标是否在有序半边内
3. 根据判断结果选择搜索区间

**为什么不能直接二分**：因为旋转破坏了全局有序性，直接二分无法保证每次排除一半候选。

### 二分搜索的数值稳定性问题

当 `mid = left + (right - left) // 2` 用于浮点数搜索时，区间收敛较慢，且浮点精度误差可能导致死循环或跳过正确解。

**解决方案**：使用固定迭代次数而非条件循环，或在浮点比较中引入 epsilon 容忍度。

### 约束违反后果

| 约束 | 违反后果 |
|------|---------|
| 序列无序 | 二分搜索返回错误结果 |
| 区间定义错误（混用开闭） | 死循环或漏查边界 |
| 整数溢出（在大整型语言） | 索引越界或负数索引 |
| `mid` 计算错误 | 跳过正确区间，漏查 |
| 旋转数组变种判断方向错误 | 错误地排除正确半边，无法收敛 |
| 浮点二分无迭代上限 | 可能死循环或精度误差 |

## 参考存根

```python
def binary_search(nums: list[int], target: int) -> int:
    """标准二分搜索：闭区间 [left, right]，命中即返回"""
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = left + (right - left) // 2   # 防止大整数溢出
        if nums[mid] == target:
            return mid
        if nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1
```

```python
def lower_bound(nums: list[int], target: int) -> int:
    """左边界二分：找第一个 >= target 的位置（Python bisect_left 等价）"""
    left, right = 0, len(nums)
    while left < right:
        mid = left + (right - left) // 2
        if nums[mid] < target:
            left = mid + 1
        else:
            right = mid   # 不返回，继续收缩找最左
    return left   # left == right == 第一个 >= target 的位置
```

```python
def search_rotated(nums: list[int], target: int) -> int:
    """旋转数组搜索：O(log n)，判断有序半边 + 目标落区"""
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = left + (right - left) // 2
        if nums[mid] == target:
            return mid
        # 判断左半边是否有序
        if nums[mid] >= nums[left]:
            # 左半边有序，检查 target 是否在左半边
            if nums[left] <= target < nums[mid]:
                right = mid - 1
            else:
                left = mid + 1
        else:
            # 右半边有序，检查 target 是否在右半边
            if nums[mid] < target <= nums[right]:
                left = mid + 1
            else:
                right = mid - 1
    return -1
```
