# 递归与分治

## 定义

递归是函数自调用将问题化为子问题的编程范式；分治是递归地将独立子问题分别求解后合并结果的算法设计模式。

## 数学模型

Master 定理：$T(n) = aT(n/b) + f(n)$，其中 $a \geq 1, b > 1$。

$$T(n) = \begin{cases} \Theta(n^{\log_b a}) & f(n) = O(n^{\log_b a - \epsilon}) \\ \Theta(n^{\log_b a} \log n) & f(n) = \Theta(n^{\log_b a}) \\ \Theta(f(n)) & f(n) = \Omega(n^{\log_b a + \epsilon}) \end{cases}$$

## 机制

**递归三要素**：
1. 终止条件：无子问题时不调用自身；缺失则无限递归栈溢出
2. 递归调用：参数必须向终止条件收敛；不收敛则死递归
3. 结果合并：分治必须合并，单纯递归可能不需要

**与 DP 的本质区别**：分治的子问题独立（无重复计算），DP 的子问题重叠（需记忆化）。若子问题不独立而强行分治，结果错误。

**递归复杂度**：递归调用栈深度 $O(\log n)$（树形分治）或 $O(n)$（线性递归），栈空间受限；尾递归在支持 TCO 的语言可优化为 $O(1)$ 空间。

**分治正确性**：递归路径上的合并操作必须满足交换律/结合律，或在特定点（如中序遍历）有唯一语义。

## 参考存根

```python
def merge_sort(arr):
    if len(arr) <= 1: return arr
    m = len(arr) // 2
    return merge(merge_sort(arr[:m]), merge_sort(arr[m:]))

def merge(a, b):
    c = []
    while a and b:
        c.append(a.pop(0) if a[0] <= b[0] else b.pop(0))
    return c + a + b
```
