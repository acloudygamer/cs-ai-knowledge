## 递归与分治

### 解决什么问题
将大问题分解为同类子问题，通过解决子问题来解决原问题。适用于问题本身具有递归结构（树、图、分形）或可自然分解（排序、查找）的场景。

### 核心概念
- **递归三要素**：终止条件、递归调用、返回值合并
- **分治**：分解为独立子问题，分别求解后合并结果
- **与DP区别**：分治的子问题独立，DP的子问题重叠
- **递归复杂度**：可用 Master 定理分析

### 分治 vs 动态规划

| 特性 | 分治 | 动态规划 |
|------|------|----------|
| 子问题关系 | 独立 | 重叠 |
| 重复计算 | 有 | 无（记忆化） |
| 最优子结构 | 不一定 | 必须 |
| 典型应用 | 归并排序、最近点对 | 爬楼梯、背包 |
| 实现方式 | 递归 | 递归或迭代 |

## 经典递归问题

### 汉诺塔

将 n 个盘子从 source 移动到 target，使用 auxiliary 作为辅助。移动次数: 2^n - 1。

### 参考样例

```python
def hanoi(n, source='A', target='C', auxiliary='B'):
    if n == 1:
        print(f"Move disk 1 from {source} to {target}")
        return
    hanoi(n - 1, source, auxiliary, target)
    print(f"Move disk {n} from {source} to {target}")
    hanoi(n - 1, auxiliary, target, source)
```

### 大整数乘法（Karatsuba）

Karatsuba 大整数乘法，时间复杂度 O(n^log3) ≈ O(n^1.585)。

### 参考样例

```python
def karatsuba(x, y):
    if x < 10 or y < 10:
        return x * y
    n = max(len(str(x)), len(str(y)))
    m = n // 2
    high1, low1 = divmod(x, 10**m)
    high2, low2 = divmod(y, 10**m)
    z0 = karatsuba(low1, low2)
    z1 = karatsuba((low1 + high1), (low2 + high2))
    z2 = karatsuba(high1, high2)
    return z2 * 10**(2*m) + (z1 - z2 - z0) * 10**m + z0
```

## 递归优化技巧

### 记忆化（Memoization）

避免重复计算，将已计算的结果缓存。

### 参考样例

```python
from functools import lru_cache

@lru_cache(maxsize=None)
def fib_cache(n):
    if n < 2:
        return n
    return fib_cache(n - 1) + fib_cache(n - 2)
```

### 尾递归优化

尾递归版本（Python 不支持尾递归优化，但思路重要）。

### 参考样例

```python
def factorial_tail(n, acc=1):
    if n == 0:
        return acc
    return factorial_tail(n - 1, n * acc)
```

### 递归转迭代

使用栈模拟递归过程。

### 参考样例

```python
def inorder_iterative(root):
    result = []
    stack = []
    current = root
    while current or stack:
        while current:
            stack.append(current)
            current = current.left
        current = stack.pop()
        result.append(current.val)
        current = current.right
    return result
```

## 重建二叉树

**LeetCode 105**：根据前序和中序遍历结果重建二叉树。

前序：[根, 左子树, 右子树]
中序：[左子树, 根, 右子树]

### 参考样例

```python
def build_tree(preorder, inorder):
    if not preorder or not inorder:
        return None
    root_val = preorder[0]
    root = TreeNode(root_val)
    root_idx = inorder.index(root_val)
    left_size = root_idx
    root.left = build_tree(preorder[1:1 + left_size], inorder[:root_idx])
    root.right = build_tree(preorder[1 + left_size:], inorder[root_idx + 1:])
    return root
```

## 求众数 II

**LeetCode 229**：找出所有出现次数超过 n/3 的元素。出现超过 n/3 的元素最多有 2 个。

### 参考样例

```python
def majority_element(nums):
    if not nums:
        return []
    def divide_conquer(left, right):
        if left == right:
            return {nums[left]}
        mid = (left + right) // 2
        left_set = divide_conquer(left, mid)
        right_set = divide_conquer(mid + 1, right)
        result = set()
        for num in left_set | right_set:
            count = sum(1 for i in range(left, right + 1) if nums[i] == num)
            if count > (right - left + 1) // 3:
                result.add(num)
        return result
    return list(divide_conquer(0, len(nums) - 1))
```

## 递归常见错误

1. **忘记终止条件**：导致无限递归
2. **终止条件不正确**：结果错误
3. **子问题不独立**：导致重复计算
4. **栈溢出**：递归深度过大
