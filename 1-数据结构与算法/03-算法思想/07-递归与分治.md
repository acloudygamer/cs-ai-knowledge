# 递归与分治

## 定义

**递归（Recursion）**是函数自调用将问题化为子问题的编程范式。递归函数必须满足：（1）有明确的终止条件；（2）子问题与原问题结构相同且规模更小；（3）子问题结果可合并为原问题结果。

**分治（Divide and Conquer）**是递归地将独立子问题分别求解后合并结果的算法设计模式。分治是递归算法的一种特殊形式，强调"分"（分解）与"合"（合并）两步。

**本质区别**：分治的子问题**必须独立**（无重叠计算），否则应使用动态规划。递归则不强制子问题独立——纯粹递归（如计算斐波那契）允许子问题重叠，导致指数级重复计算。

## 数学模型

### Master 定理

设递归关系 $T(n) = aT(n/b) + f(n)$，其中 $a \geq 1, b > 1$：

| 条件 | 解 |
|------|-----|
| $f(n) = O(n^{\log_b a - \epsilon})$，$\epsilon > 0$ | $T(n) = \Theta(n^{\log_b a})$ |
| $f(n) = \Theta(n^{\log_b a} \log^k n)$，$k \geq 0$ | $T(n) = \Theta(n^{\log_b a} \log^{k+1} n)$ |
| $f(n) = \Omega(n^{\log_b a + \epsilon})$，$\epsilon > 0$ 且满足正则条件 | $T(n) = \Theta(f(n))$ |

**正则条件**：$a f(n/b) \leq c f(n)$ 对某个常数 $c < 1$ 和足够大的 $n$ 成立。

### 递归树视角

将递归关系展开为递归树：
- 第 $i$ 层有 $a^i$ 个子问题，每个规模为 $n/b^i$
- 第 $i$ 层总代价为 $a^i \cdot f(n/b^i)$
- 树高度 $h = \log_b n$
- 总代价 = 第 0 层代价 + 第 1 层代价 + ... + 第 $h$ 层代价 + 叶子层代价

Master 定理的三种情况分别对应：叶子层主导、每层代价相似、根层（合并代价）主导。

### 典型复杂度分析

| 算法 | 递归关系 | $a$ | $b$ | $f(n)$ | $\log_b a$ | 复杂度 |
|------|---------|-----|-----|--------|-----------|--------|
| 二分搜索 | $T(n) = T(n/2) + O(1)$ | 1 | 2 | $n^0$ | 0 | $O(\log n)$ |
| 归并排序 | $T(n) = 2T(n/2) + O(n)$ | 2 | 2 | $n^1$ | 1 | $O(n \log n)$ |
| 二叉树遍历 | $T(n) = 2T(n/2) + O(1)$ | 2 | 2 | $n^0$ | 1 | $O(n)$ |
| Strassen 矩阵乘法 | $T(n) = 7T(n/2) + O(n^2)$ | 7 | 2 | $n^2$ | $\log_2 7 \approx 2.81$ | $O(n^{2.81})$ |

### 快速排序分区执行流

<pre>
输入: [3, 7, 8, 5, 2, 1, 4, 6]，选 pivot=6

分区过程（原地交换）:
初始: [3, 7, 8, 5, 2, 1, 4, 6]
i=0: 3 < 6，交换(0,0)，i++ → [3, 7, 8, 5, 2, 1, 4, 6]
i=1: 7 > 6，跳过
i=2: 8 > 6，跳过

i=4: 2 < 6，交换(2,4)，i++ → [3, 5, 2, 7, 8, 1, 4, 6]
i=5: 1 < 6，交换(3,5)，i++ → [3, 5, 2, 1, 8, 7, 4, 6]
i=6: 4 < 6，交换(4,6)，i++ → [3, 5, 2, 1, 4, 7, 8, 6]

## 机制

### 递归三要素

1. **终止条件**：无子问题时不调用自身。终止条件必须保证递归必定收敛，否则导致无限递归（栈溢出）。

2. **递归调用**：参数必须向终止条件收敛。收敛方式可以是规模递减（$n-1$）或结构分解（$n/2$）。不收敛则死递归。

3. **结果合并**（分治特有）：分治必须包含合并步骤，单纯递归（如遍历）可能不需要合并。

### 分治与动态规划的本质区别

| 特征 | 分治 | 动态规划 |
|------|------|---------|
| 子问题关系 | 独立，无重叠 | 重叠，存在重复计算 |
| 重复计算 | 无 | 有（需记忆化） |
| 合并操作 | 必须有 | 可能不需要 |
| 典型例子 | 归并排序 | 斐波那契数列 |

**若子问题不独立而强行分治**：会导致错误结果，因为独立假设不成立。以矩阵链乘法为例，递归分解会产生重叠子问题，必须用 DP 记忆化。

### 递归复杂度与栈空间

| 分治模式 | 时间复杂度 | 栈空间 |
|---------|----------|-------|
| 树形分治（如归并排序） | $T(n) = aT(n/b) + O(n)$ | $O(\log n)$ |
| 线性递归（如链表中点查找） | $T(n) = T(n-1) + O(1)$ | $O(n)$ |
| 尾递归优化（TCO） | $O(n)$ | $O(1)$ |

**尾递归优化**：若递归调用是函数最后一条语句（尾调用），支持 TCO 的编译器可将递归转化为循环，不占用栈空间。归并排序的递归不是尾递归（merge 在递归返回后执行），无法优化。

### 分治正确性的合并语义要求

分治算法的合并操作必须满足**交换律和结合律**，或在中序遍历点有唯一语义，否则不同分治顺序会产生不同结果。

**交换律/结合律**：归并排序的 merge 操作满足这两个律，因此无论以何种顺序合并子数组，结果一致。

**中序遍历特例**：二叉搜索树的中序遍历无论以何种顺序递归，结果都是有序序列，因为 BST 的中序语义本身保证顺序。

### 分治的并行化潜力

分治算法具有天然的并行化潜力，因为子问题独立可同时求解。归并排序的半分操作完全可并行（并行复杂度 $O(n \log n / p + n)$），而快速排序的分区操作限制了并行性。

## 对比参照

| 特征 | 递归 | 分治 |
|------|------|------|
| 子问题独立性 | 不要求 | 要求 |
| 合并步骤 | 不要求 | 要求 |
| 典型结构 | 函数自调用 | 分解 → 求解 → 合并 |
| 记忆化需求 | 子问题重叠时需要 | 通常不需要（子问题独立） |
| 栈空间 | $O(n)$（线性）或 $O(\log n)$（树形） | $O(\log n)$ |

## 参考存根

```python
def merge_sort(arr: list[int]) -> list[int]:
    """归并排序：树形分治，O(n log n)，空间 O(n)（合并结果存储）"""
    if len(arr) <= 1:                     # 终止条件
        return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])           # 分治：递归求解左半
    right = merge_sort(arr[mid:])         # 分治：递归求解右半
    return merge(left, right)              # 分治：合并有序子序列

def merge(a: list[int], b: list[int]) -> list[int]:
    """合并两个有序数组：双指针，时间 O(n)，空间 O(n)"""
    result = []
    i = j = 0
    while i < len(a) and j < len(b):
        if a[i] <= b[j]:
            result.append(a[i])
            i += 1
        else:
            result.append(b[j])
            j += 1
    result.extend(a[i:])
    result.extend(b[j:])
    return result
```

```python
def quicksort(arr: list[int], left: int, right: int) -> None:
    """快速排序：原地分区，O(n log n) 平均，O(n²) 最坏，空间 O(log n)"""
    if left >= right:                      # 终止条件
        return
    pivot_index = partition(arr, left, right)
    quicksort(arr, left, pivot_index - 1) # 左半排序
    quicksort(arr, pivot_index + 1, right) # 右半排序

def partition(arr: list[int], left: int, right: int) -> int:
    """ Lomuto 分区：选最后一个元素为 pivot"""
    pivot = arr[right]
    i = left                               # i 左边（不含i）都 <= pivot
    for j in range(left, right):
        if arr[j] <= pivot:
            arr[i], arr[j] = arr[j], arr[i]
            i += 1
    arr[i], arr[right] = arr[right], arr[i]  # pivot 归位
    return i
```

```python
def fibonacci(n: int, memo: dict | None = None) -> int:
    """带记忆化的递归（分治思想 + DP 记忆化）：O(n) 时间，O(n) 栈空间"""
    if memo is None:
        memo = {}
    if n in memo:
        return memo[n]
    if n <= 1:                             # 终止条件
        return n
    memo[n] = fibonacci(n - 1, memo) + fibonacci(n - 2, memo)
    return memo[n]
```
