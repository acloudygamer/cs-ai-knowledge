## 排序

### 解决什么问题
将无序数据调整为有序序列，适用于数据预处理、查找优化（有序数据可二分查找）、优先级队列等场景。

### 核心概念
- **基于比较的排序**：归并、快排、堆排，最优复杂度下界 O(n log n)
- **线性排序**：计数排序、桶排序、基数排序，在特定条件下可达 O(n)
- **稳定性**：相等等元素的相对顺序是否保持，是则为稳定排序
- **原地排序**：额外空间 O(1)，如堆排、快排（原地版本）

### 常用排序对比

| 算法 | 平均 | 最坏 | 空间 | 稳定 |
|------|------|------|------|------|
| 冒泡 | O(n²) | O(n²) | O(1) | 稳定 |
| 选择 | O(n²) | O(n²) | O(1) | 不稳定 |
| 插入 | O(n²) | O(n²) | O(1) | 稳定 |
| 归并 | O(n log n) | O(n log n) | O(n) | 稳定 |
| 快排 | O(n log n) | O(n²) | O(log n) | 不稳定 |
| 堆排 | O(n log n) | O(n log n) | O(1) | 不稳定 |
| 计数排序 | O(n + k) | O(n + k) | O(k) | 稳定 |
| 桶排序 | O(n + k) | O(n²) | O(n + k) | 稳定 |
| 基数排序 | O(nk) | O(nk) | O(n + k) | 稳定 |

### 内置排序

Python 的 list.sort() 使用 TimSort，混合了归并排序和插入排序。

### 参考样例

```python
arr = [3, 1, 4, 1, 5, 9, 2, 6]
arr.sort()
print(arr)

arr.sort(reverse=True)

arr.sort(key=abs)
```

## 线性时间排序（不基于比较）

### 计数排序

适用于范围较小的整数排序。通过统计每个值出现的次数，利用前缀和确定每个元素的最终位置，保证稳定性。

### 参考样例

```python
def counting_sort(arr):
    if not arr:
        return arr
    min_val, max_val = min(arr), max(arr)
    k = max_val - min_val + 1
    count = [0] * k
    for num in arr:
        count[num - min_val] += 1
    for i in range(1, k):
        count[i] += count[i - 1]
    result = [0] * len(arr)
    for num in reversed(arr):
        idx = count[num - min_val]
        result[idx - 1] = num
        count[num - min_val] -= 1
    return result
```

### 桶排序

将元素分散到有限数量的桶中，每个桶内单独排序。适用于数据均匀分布的场景。

### 参考样例

```python
def bucket_sort(arr, num_buckets=5):
    if not arr:
        return arr
    min_val, max_val = min(arr), max(arr)
    if min_val == max_val:
        return arr
    bucket_size = (max_val - min_val) // num_buckets + 1
    buckets = [[] for _ in range(num_buckets)]
    for num in arr:
        idx = int((num - min_val) / bucket_size)
        buckets[idx].append(num)
    result = []
    for bucket in buckets:
        bucket.sort()
        result.extend(bucket)
    return result
```

### 基数排序

按位排序，从最低有效位到最高有效位。每位使用计数排序。

### 参考样例

```python
def radix_sort(arr):
    if not arr:
        return arr
    max_val = max(arr)
    exp = 1
    while max_val // exp > 0:
        buckets = [[] for _ in range(10)]
        for num in arr:
            digit = (num // exp) % 10
            buckets[digit].append(num)
        arr = []
        for bucket in buckets:
            arr.extend(bucket)
        exp *= 10
    return arr
```

### 线性排序适用场景

| 算法 | 适用场景 |
|------|----------|
| 计数排序 | 整数范围较小（年龄、成绩等） |
| 桶排序 | 数据均匀分布 |
| 基数排序 | 整数或字符串排序 |

## 归并排序

分治策略，将数组分为两半分别排序，再合并。稳定排序，适合链表 O(n log n) 排序。

### 参考样例

```python
def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    return merge(left, right)

def merge(left, right):
    result = []
    i = j = 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1
    result.extend(left[i:])
    result.extend(right[j:])
    return result
```

## 快速排序

分治策略，选择 pivot 将数组分为小于 pivot 和大于 pivot 的两部分，递归排序。

### 参考样例

```python
def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quick_sort(left) + middle + quick_sort(right)

def partition(arr, low, high):
    pivot = arr[high]
    i = low - 1
    for j in range(low, high):
        if arr[j] <= pivot:
            i += 1
            arr[i], arr[j] = arr[j], arr[i]
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    return i + 1

def quick_sort_inplace(arr, low=0, high=None):
    if high is None:
        high = len(arr) - 1
    if low < high:
        p = partition(arr, low, high)
        quick_sort_inplace(arr, low, p - 1)
        quick_sort_inplace(arr, p + 1, high)
```
