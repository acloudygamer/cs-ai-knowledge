# 排序

> **版本基准**：universal —— 代码示例同时使用 Python 3.12 与 C++20

## 本质

排序是把 $n$ 个可比较元素按全序关系重排为非递减序列的过程。它的本质是**信息压缩**： $n$ 个元素的初始状态有 $n!$ 种可能排列，算法通过一次次比较（或直接寻址）逐步排除不可能的排列，最终收敛到唯一有序状态。比较类排序因此被一根信息论下界钉在 $\Omega(n \log n)$；非比较排序（计数、基数、桶）绕开比较、改用元素本身的位/值信息直接定位，才能突破这根下界。

工程上选排序算法，看的不只是 $O$ 记号里的渐近项，还有三件事：**是否稳定**（相等元素相对顺序是否保持）、**是否原地**（额外空间多少）、**是否缓存友好**（顺序访问还是大跨距跳转）。这三项往往比平均复杂度更决定实测速度。

## 数学模型

### 比较排序的信息论下界

把比较排序抽象成**决策树**：每个内部节点是一次比较，两分支对应 $\leq$ 与 $>$ 两种结果，每个叶节点对应一种最终排列。 $n$ 个元素有 $n!$ 种排列，决策树必须至少有 $n!$ 个叶节点才能区分所有输入；而高度为 $h$ 的二叉树至多 $2^h$ 个叶节点，故：

$$2^h \geq n! \;\Rightarrow\; h \geq \log_2(n!)$$

由 Stirling 近似 $\log_2(n!) = \Theta(n \log n)$，所以 $T_{\text{compare}}(n) = \Omega(n \log n)$。这是**任何**基于比较的排序在最坏情况下的硬下界。

> **洞察**：每次比较最多把可能排列数砍半（决策树一分为二），要把 $n!$ 砍到 $1$，至少要砍 $\log_2(n!)$ 刀——这就是 $n \log n$ 的物理来源。

### 快速排序的期望比较次数

快排每次选 pivot 把数组分成左右两段，每对元素在整个递归过程中**至多比较一次**（一旦被某个 pivot 分到不同侧，就再也不会相遇比较）。设 $I_{ij}$ 为元素 $i$ 与 $j$ 是否被比较的指示变量，比较总次数 $X = \sum I_{ij}$。

关键概率：元素 $i$ 与 $j$ （设为第 $i$ 小、第 $j$ 小， $i < j$）被比较，当且仅当 $\{i, i+1, \dots, j\}$ 这 $j-i+1$ 个元素中**第一个被选为 pivot 的是 $i$ 或 $j$ **。在等概率假设下此概率为 $\frac{2}{j-i+1}$，于是：

$$E[X] = \sum_{i=1}^{n-1}\sum_{j=i+1}^{n} \frac{2}{j-i+1} = 2\sum_{d=1}^{n-1}\frac{n-d}{d+1} = O(n \ln n) = \Theta(n \log n)$$

最坏情况（每次选到最值作 pivot，划分极度倾斜）退化为 $\Theta(n^2)$。

### 非比较排序的约束边界

- **计数排序**：值域 $k$ 必须 $k = O(n)$。计数数组大小为 $k$，当 $k \gg n$ 时空间与时间都退化，得不偿失。
- **桶排序**：数据需大致均匀分布到 $k$ 个桶，否则所有元素挤进一个桶，桶内再排序退化为 $O(n^2)$。
- **基数排序**：按位用稳定排序（通常是计数排序）处理，共 $d$ 位，需 $d \cdot (n+k) < n \log n$ 才优于比较排序。适用于定长整数、字符串。

> **洞察**：非比较排序用"元素值直接告诉你它该放哪"换掉了"比较告诉你谁大谁小"。代价是你必须事先知道值域/位数/分布——信息从比较中挪到了对输入的先验假设里。

## 数据流

### 归并排序：分治到原子再线性合并

<pre>
输入: [3, 1, 4, 1, 5, 9, 2, 6]
         │
    ┌────┴────┐
  [3,1,4,1]   [5,9,2,6]        半分
    │           │
  ┌─┴─┐       ┌─┴─┐
 [3,1] [4,1] [5,9] [2,6]      继续半分
   │     │     │     │
  [3][1] [4][1] [5][9] [2][6] 原子：单元素天然有序
   │     │     │     │
  [1,3]   [1,4]   [5,9]   [2,6]   治：两两归并
         │           │
    [1,1,3,4]      [2,5,6,9]      治：四四归并
         │
输出: [1,1,2,3,4,5,6,9]
</pre>

**所有权变换**：分阶段只切分区间引用（无数据拷贝），治阶段把两个有序区间合并写入新数组。核心操作"合并两个有序区间"是线性 $O(n)$，分治层深 $\log n$，总计 $O(n \log n)$。

### 快速排序：原地分区 + 递归两段

<pre>
选 pivot = 5:
[3, 1, 4, 1, 5, 9, 2, 6]
  双指针扫描，≤5 左移、>5 右移
→ [3, 1, 4, 1, 2]  5  [9, 6]
      左半(≤5)        右半(>5)
         │                │
     递归处理           递归处理
</pre>

Lomuto 分区：单指针从左扫到右，把每个 ≤ pivot 的元素与前边界交换，最后把 pivot 放到分界点。空间 $O(1)$ （原地），但最坏划分时退化为 $O(n^2)$。

### 计数排序：计数 → 前缀和 → 反向放置

<pre>
输入: [2, 5, 3, 0, 2, 3]   k = 6 (值域 0..5)

1. 计数:
   index: 0  1  2  3  4  5
   count: 1  0  2  2  0  1

2. 前缀和（值 v 的最末落点）:
   index: 0  1  2  3  4  5
   pos:   1  1  3  5  5  6

3. 从后往前放置（保证稳定）:
   读 3 → 放 pos[3]=5 处, pos[3]→4
   读 2 → 放 pos[2]=3 处, pos[2]→2
   读 0 → 放 pos[0]=1 处, pos[0]→0
   ... (从后往前是稳定性关键)

输出: [0, 2, 2, 3, 3, 5]
</pre>

前缀和数组的第 $i$ 项表示"值 $\leq i$ 的元素总数"，即值 $i$ 在输出中的末位下标。**从后往前扫描**输入、每放一个就把对应位置减一，相等元素的相对顺序就被原样保留——这是稳定性的来源。

## 对比参照

| 算法 | 平均 | 最坏 | 空间 | 稳定 | 缓存友好 |
|------|------|------|------|------|----------|
| 归并排序 | $n \log n$ | $n \log n$ | $n$ | 是 | 优（顺序合并） |
| 快速排序 | $n \log n$ | $n^2$ | $\log n$ | 否 | 良（分区局部） |
| 堆排序 | $n \log n$ | $n \log n$ | $1$ | 否 | 差（父子大跨距） |
| 插入排序 | $n^2$ | $n^2$ | $1$ | 是 | 优（极小 $n$ 最快） |
| 计数排序 | $n+k$ | $n+k$ | $k$ | 是 | 优（顺序扫描） |
| 基数排序 | $d(n+k)$ | $d(n+k)$ | $n+k$ | 是 | 优（按位顺序） |

$k$ 为值域大小， $d$ 为位数。

## 机制

### 为什么比较排序突破不了 $n \log n$

每次比较是二元判断，最多把剩余可能排列数砍半。要从 $n!$ 砍到 $1$，至少 $\log_2(n!)$ 次比较，Stirling 给出这就是 $\Theta(n \log n)$。**任何**号称 $o(n \log n)$ 的"比较排序"都违反信息论，不可能正确。

### 稳定性的语义价值

稳定排序保证相等元素的相对顺序不变。它支撑两类场景：**多级排序**（先按次键排、再按主键稳定排，主键相等处次键序自然保留）、**基数排序的底层**（按位用稳定排序叠加成全局有序）。归并排序合并时"相等取左半"天然稳定；快排原地分区会让相等元素跨 pivot 移动而失稳。

### 工程选型的真实砝码：缓存

$O$ 记号相同的算法，实测速度差可达数倍，主因是缓存命中率：

- **归并排序**：合并时双指针顺序扫两段数组，硬件预取器识别出顺序模式，提前拉缓存行，命中率高。
- **堆排序**：`sift-down` 沿父子下标跳转（父 $i$ → 子 $2i, 2i+1$），步长随树深翻倍，是典型的**大跨距随机访问**，预取器失效、cache miss 频繁。这就是堆排序常数因子大、实测常比快排慢的根因——不是比较次数多，而是每次比较常常伴随一次 cache miss。
- **插入排序**： $O(n^2)$ 但在小 $n$ （约 $n \leq 16$）时反而最快，因为 inner loop 几乎全在寄存器/L1 里跑，没有函数调用与跨距跳转的开销。这也是 `std::sort`、`introsort` 在小区间切到插入排序的原因。

> **洞察**： $n \log n$ 是比较次数的下界，但真实运行时间 = 比较次数 × 每次比较的内存代价。堆排序输给快排的不是前者，是后者——大跨距访问把每次比较的代价从"几纳秒"抬到"几十纳秒"。

### 快排最坏情况与对策

最坏发生在划分极度倾斜（逆序输入总选首元素为 pivot，每次只分出 1 个元素）。对策：**随机化 pivot**（期望均匀，概率上避开最坏）、**三数取中**（首中尾取中位数）、**小区间切插入排序**（兼顾常数与缓存）、**introsort**（递归深度超 $2\log n$ 时切堆排序，保住 $O(n \log n)$ 最坏界，这是 `std::sort` 的实现策略）。

### 违规后果

| 违规 | 后果 |
|------|------|
| 声称比较排序 $o(n \log n)$ | 违反信息论下界，算法必错 |
| 不稳定排序用于多级排序 | 次键序被破坏，结果错乱 |
| 对 $k \gg n$ 用计数排序 | 空间爆炸，反而远慢于 $n \log n$ 比较 |
| 快排不随机化 + 接近有序输入 | 退化 $n^2$，递归深度 $n$ 可能栈溢出 |

## 代码示例

**Python 3.12**：

```python
# 归并排序：分治，稳定，O(n log n)；合并时相等取左半保证稳定
def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    return _merge(merge_sort(arr[:mid]), merge_sort(arr[mid:]))

def _merge(a, b):
    c, i, j = [], 0, 0
    while i < len(a) and j < len(b):
        if a[i] <= b[j]:          # <= 保证稳定：相等取左半
            c.append(a[i]); i += 1
        else:
            c.append(b[j]); j += 1
    c.extend(a[i:]); c.extend(b[j:])
    return c

# 快速排序（Lomuto 原地分区，随机化 pivot 规避最坏）
import random
def quick_sort(arr, lo=0, hi=None):
    if hi is None: hi = len(arr) - 1
    if lo >= hi: return
    piv = random.randint(lo, hi)
    arr[piv], arr[hi] = arr[hi], arr[piv]   # pivot 暂存到末尾
    store, pivot = lo, arr[hi]
    for i in range(lo, hi):
        if arr[i] < pivot:
            arr[store], arr[i] = arr[i], arr[store]; store += 1
    arr[store], arr[hi] = arr[hi], arr[store]  # pivot 归位
    quick_sort(arr, lo, store - 1)
    quick_sort(arr, store + 1, hi)

# 计数排序：值域有限时 O(n+k)，稳定（前缀和 + 反向放置）
def counting_sort(arr, max_val):
    count = [0] * (max_val + 1)
    for x in arr: count[x] += 1
    for i in range(1, len(count)): count[i] += count[i - 1]   # 前缀和
    out = [0] * len(arr)
    for x in reversed(arr):              # 反向扫描保稳定
        count[x] -= 1
        out[count[x]] = x
    return out

# —— 简易输入输出 ——
a = [3, 1, 4, 1, 5, 9, 2, 6]
print(merge_sort(a))              # [1, 1, 2, 3, 4, 5, 6, 9]
quick_sort(a); print(a)           # [1, 1, 2, 3, 4, 5, 6, 9]
print(counting_sort([2,5,3,0,2,3], 5))   # [0, 2, 2, 3, 3, 5]
```

**C++20**：

```cpp
#include <iostream>
#include <vector>
#include <random>
#include <algorithm>

// 归并排序：稳定，O(n log n)
void mergeSort(std::vector<int>& a, int lo, int hi) {
    if (hi - lo <= 1) return;                 // [lo, hi)
    int mid = (lo + hi) / 2;
    mergeSort(a, lo, mid);
    mergeSort(a, mid, hi);
    std::vector<int> tmp(a.begin() + lo, a.begin() + hi);
    int i = 0, j = mid - lo, k = lo, n1 = mid - lo;
    while (i < n1 && j < hi - lo)
        a[k++] = (tmp[i] <= tmp[j]) ? tmp[i++] : tmp[j++];   // <= 保稳定
    while (i < n1) a[k++] = tmp[i++];
    while (j < hi - lo) a[k++] = tmp[j++];
}

// 快速排序：Lomuto 原地分区 + 随机化 pivot
void quickSort(std::vector<int>& a, int lo, int hi, std::mt19937& rng) {
    if (lo >= hi) return;                     // [lo, hi]
    std::uniform_int_distribution<int> dist(lo, hi);
    int p = dist(rng);
    std::swap(a[p], a[hi]);
    int pivot = a[hi], store = lo;
    for (int i = lo; i < hi; ++i)
        if (a[i] < pivot) std::swap(a[store++], a[i]);
    std::swap(a[store], a[hi]);
    quickSort(a, lo, store - 1, rng);
    quickSort(a, store + 1, hi, rng);
}

// 计数排序：值域 [0, maxVal]，稳定
std::vector<int> countingSort(const std::vector<int>& a, int maxVal) {
    std::vector<int> count(maxVal + 1, 0), out(a.size());
    for (int x : a) ++count[x];
    for (int i = 1; i <= maxVal; ++i) count[i] += count[i - 1];   // 前缀和
    for (int i = (int)a.size() - 1; i >= 0; --i) {                // 反向保稳定
        out[--count[a[i]]] = a[i];
    }
    return out;
}

int main() {
    std::vector<int> a = {3, 1, 4, 1, 5, 9, 2, 6};
    mergeSort(a, 0, (int)a.size());
    for (int x : a) std::cout << x << ' ';       // 1 1 2 3 4 5 6 9
    std::cout << '\n';

    std::vector<int> b = {3, 1, 4, 1, 5, 9, 2, 6};
    std::mt19937 rng(42);
    quickSort(b, 0, (int)b.size() - 1, rng);
    for (int x : b) std::cout << x << ' ';       // 1 1 2 3 4 5 6 9
    std::cout << '\n';

    for (int x : countingSort({2, 5, 3, 0, 2, 3}, 5))
        std::cout << x << ' ';                   // 0 2 2 3 3 5
    std::cout << '\n';
}
```
