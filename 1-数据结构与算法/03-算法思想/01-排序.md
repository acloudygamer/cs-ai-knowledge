# 排序

## 定义

排序是将有限元素集合按确定的全序关系调整为有序序列的过程。

## 数学模型

比较排序下界：决策树高度 $h \geq \log_2(n!)$，由 Stirling 近似得 $h = \Omega(n \log n)$。

$$T_{\text{compare}}(n) = \Omega(n \log n)$$

| 算法 | $T_{\text{avg}}$ | $T_{\text{worst}}$ | 空间 | 稳定 |
|------|-----------------|-------------------|------|------|
| 归并 | $n\log n$ | $n\log n$ | $n$ | 是 |
| 快排 | $n\log n$ | $n^2$ | $\log n$ | 否 |
| 堆排 | $n\log n$ | $n\log n$ | $1$ | 否 |
| 计数 | $n+k$ | $n+k$ | $k$ | 是 |

## 数据流

<pre>
输入: [3, 1, 4, 1, 5, 9, 2, 6]  (list[int])
         │
    ┌────┴────┐
  [3,1,4,1]  [5,9,2,6]        (list[int], 半分)
    │           │
  [3,1] [4,1] [5,9] [2,6]     (list[int], 再分)
    │      │      │      │
  [3] [1] [4] [1] [5] [9] [2] [6]  (list[int], 原子)
    │      │      │      │
  [1,3]   [1,4]   [5,9]   [2,6]     (list[int], 局部有序)
         │           │
    [1,1,3,4]      [2,5,6,9]       (list[int], 归并)
         │
输出: [1,1,2,3,4,5,6,9]  (list[int], sorted)
</pre>

## 机制

**为什么需要 $O(n \log n)$ 下界**：$n$ 个元素的排列有 $n!$ 种，决策树每叶对应一种排列，高为 $h$ 的二叉树至多 $2^h$ 叶，故 $2^h \geq n!$，$h \geq \log_2 n! = \Omega(n \log n)$。

**约束条件**：
- 比较排序必须定义全序关系；元素间不可比时算法失效
- 违反下界：算法退化为 $O(n^2)$ 或更高，或需借助非比较手段
- 稳定排序要求相等等价类保持相对顺序，避免下游计算语义混乱

**非比较排序约束**：计数排序要求 $k = O(n)$（值域与规模线性）；桶排序要求数据均匀分布；基数排序要求可用计数排序按位比较。

## 参考存根

```python
def sort(arr):
    if len(arr) <= 1: return arr
    mid = len(arr) // 2
    return merge(sort(arr[:mid]), sort(arr[mid:]))

def merge(a, b):
    c = []
    i = j = 0
    while i < len(a) and j < len(b):
        c.append(a[i] if a[i] <= b[j] else b[j])
        i += 1 if a[i] <= b[j] else 0
        j += 1 if a[i] > b[j] else 0
    c.extend(a[i:]); c.extend(b[j:])
    return c
```
