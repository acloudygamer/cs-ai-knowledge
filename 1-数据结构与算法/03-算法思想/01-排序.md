## 排序

### 解决什么问题
将无序数据调整为有序序列，适用于数据预处理、查找优化（有序数据可二分查找）、优先级队列等场景。

### 核心概念
- 基于比较的排序：归并、快排、堆排，最优复杂度下界 O(n log n)
- 线性排序：计数排序、桶排序、基数排序，在特定条件下可达 O(n)
- 稳定性：相等等元素的相对顺序是否保持，是则为稳定排序
- 原地排序：额外空间 O(1)，如堆排、快排（原地版本）

### 怎么用

```python
# 内置排序
arr = [3, 1, 4, 1, 5, 9, 2, 6]
arr.sort()  # 原地排序 O(n log n)
print(arr)  # [1, 1, 2, 3, 4, 5, 6, 9]

# 降序
arr.sort(reverse=True)
print(arr)  # [9, 6, 5, 4, 3, 2, 1, 1]

# 自定义排序（按绝对值）
arr = [-1, 3, -2, 8, -4]
arr.sort(key=abs)
print(arr)  # [-1, -2, -3, -4, 8] 如果有 3, 8
```

| 算法 | 平均 | 最坏 | 空间 | 稳定 |
|------|------|------|------|------|
| 冒泡 | O(n²) | O(n²) | O(1) | 稳定 |
| 选择 | O(n²) | O(n²) | O(1) | 不稳定 |

| 归并 | O(n log n) | O(n log n) | O(n) | 稳定 |

## 线性时间排序（不基于比较）

### 计数排序

适用于范围较小的整数排序。

```python
def counting_sort(arr):
    """
    计数排序：统计每个值出现的次数
    时间复杂度: O(n + k)，k为数值范围
    空间复杂度: O(k)
    稳定排序
    """
    if not arr:
        return arr

    min_val, max_val = min(arr), max(arr)
    k = max_val - min_val + 1
    count = [0] * k

    # 统计每个元素出现次数
    for num in arr:
        count[num - min_val] += 1

    # 前缀和，确定每个元素的最终位置
    for i in range(1, k):
        count[i] += count[i - 1]

    # 从后向前遍历，保证稳定性
    result = [0] * len(arr)
    for num in reversed(arr):
        idx = count[num - min_val]
        result[idx - 1] = num  # idx是1-indexed前缀和，result是0-indexed
        count[num - min_val] -= 1

    return result
```

### 桶排序

将元素分散到有限数量的桶中，每个桶内单独排序。

```python
def bucket_sort(arr, num_buckets=5):
    """
    桶排序
    时间复杂度: O(n + k)，k为桶数
    空间复杂度: O(n + k)
    稳定排序
    """
    if not arr:
        return arr

    min_val, max_val = min(arr), max(arr)
    if min_val == max_val:
        return arr

    # 创建桶
    bucket_size = (max_val - min_val) // num_buckets + 1
    buckets = [[] for _ in range(num_buckets)]

    # 分配元素到桶
    for num in arr:
        idx = int((num - min_val) / bucket_size)
        buckets[idx].append(num)

    # 对每个桶排序并合并
    result = []
    for bucket in buckets:
        bucket.sort()
        result.extend(bucket)

    return result
```

### 基数排序

按位排序，从最低有效位到最高有效位。

```python
def radix_sort(arr):
    """
    基数排序（LSD - 最低位优先）
    时间复杂度: O(nk)，k为最大数字的位数
    空间复杂度: O(n + k)
    稳定排序
    """
    if not arr:
        return arr

    # 获取最大数字的位数
    max_val = max(arr)
    exp = 1

    while max_val // exp > 0:
        # 按当前位将元素分配到0-9的桶中
        buckets = [[] for _ in range(10)]
        for num in arr:
            digit = (num // exp) % 10
            buckets[digit].append(num)

        # 从桶中取出元素
        arr = []
        for bucket in buckets:
            arr.extend(bucket)

        exp *= 10

    return arr


# 更节省空间的版本（原地桶排序）
def radix_sort_inplace(arr):
    if not arr:
        return arr

    max_val = max(arr)
    exp = 1

    while max_val // exp > 0:
        # 计数排序按当前位排序
        k = 10
        count = [0] * k
        temp = [0] * len(arr)

        # 统计每位数字出现次数
        for num in arr:
            digit = (num // exp) % 10
            count[digit] += 1

        # 前缀和
        for i in range(1, k):
            count[i] += count[i - 1]

        # 从后向前保证稳定性
        for i in range(len(arr) - 1, -1, -1):
            digit = (arr[i] // exp) % 10
            count[digit] -= 1
            temp[count[digit]] = arr[i]

        arr[:] = temp
        exp *= 10

    return arr
```

## 归并排序

```python
def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    return merge(left, right)

def merge(left, right):
    result = []
    i = j = 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1
    result.extend(left[i:])
    result.extend(right[j:])
    return result
```

## 快速排序

```python
def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quick_sort(left) + middle + quick_sort(right)

# 原地快排
def partition(arr, low, high):
    pivot = arr[high]
    i = low - 1
    for j in range(low, high):
        if arr[j] <= pivot:
            i += 1
            arr[i], arr[j] = arr[j], arr[i]
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    return i + 1

def quick_sort_inplace(arr, low=0, high=None):
    if high is None:
        high = len(arr) - 1
    if low < high:
        p = partition(arr, low, high)
        quick_sort_inplace(arr, low, p - 1)
        quick_sort_inplace(arr, p + 1, high)
