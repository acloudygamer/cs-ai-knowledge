# 回溯

### 解决什么问题
通过枚举所有可能性找到满足约束条件的解，适用于排列、组合、子集、括号生成、N皇后等组合优化问题。通过剪枝避免无效搜索。

### 核心概念
- 状态树遍历：每个选择构成树的节点，解是根到叶的路径
- 选择与撤销：做选择后递归，递归返回后撤销选择（回溯）
- 剪枝条件：跳过无效选择，减少搜索空间
- 时间复杂度：通常 O(n!) 或 O(2^n)，剪枝可显著降低

### 怎么用

## 核心思想

- 枚举所有可能性
- 状态树遍历
- 剪枝优化

**时间复杂度**: 通常 O(n!) 或 O(2^n)，剪枝可显著降低

## 框架

```python
def backtrack(路径, 选择列表):
    if 满足结束条件:
        结果.add(路径)
        return
    for 选择 in 选择列表:
        if 满足剪枝条件:
            做选择
            backtrack(路径, 新的选择列表)
            撤销选择
```

## 回溯三要素

1. **结束条件**: 何时收集结果、何时返回
2. **选择列表**: 当前可以做出的选择
3. **剪枝条件**: 跳过无效选择（如已使用、超过边界等）

## 经典问题

### 全排列

**LeetCode 46**: 无重复元素的全排列。

```python
def permute(nums):
    """
    思路：used 数组标记已使用元素
    时间复杂度: O(n! * n)
    """
    result = []
    def backtrack(path, used):
        if len(path) == len(nums):
            result.append(path[:])
            return
        for i in range(len(nums)):
            if used[i]:
                continue
            used[i] = True
            path.append(nums[i])
            backtrack(path, used)
            path.pop()
            used[i] = False
    backtrack([], [False] * len(nums))
    return result
```

### 全排列 II（含重复元素）

**LeetCode 47**: 包含重复元素的全排列，需要去重。

**思路**：先排序，相同元素相邻，剪枝条件为 `i > 0 && nums[i] == nums[i-1] && !used[i-1]`

```python
def permute_unique(nums):
    """
    思路：排序后剪枝，相同元素只使用第一个未使用的
    时间复杂度: O(n! * n)
    """
    nums.sort()
    result = []
    def backtrack(path, used):
        if len(path) == len(nums):
            result.append(path[:])
            return
        for i in range(len(nums)):
            if used[i]:
                continue
            # 剪枝：相同元素，前一个未使用则跳过
            if i > 0 and nums[i] == nums[i-1] and not used[i-1]:
                continue
            used[i] = True
            path.append(nums[i])
            backtrack(path, used)
            path.pop()
            used[i] = False
    backtrack([], [False] * len(nums))
    return result
```

### 子集

**LeetCode 78**: 无重复元素的子集。

```python
def subsets(nums):
    """
    思路：每个元素选或不选，收集所有路径
    时间复杂度: O(2^n * n)
    """
    result = []
    def backtrack(start, path):
        result.append(path[:])
        for i in range(start, len(nums)):
            path.append(nums[i])
            backtrack(i + 1, path)
            path.pop()
    backtrack(0, [])
    return result
```

### 组合总和

**LeetCode 39**: 无重复元素，可无限次选取，和为 target。

```python
def combination_sum(candidates, target):
    """
    思路：可重复选取，start 保持不变
    时间复杂度: O(n * 2^n) 最坏
    """
    result = []
    def backtrack(start, path, remaining):
        if remaining == 0:
            result.append(path[:])
            return
        if remaining < 0:
            return
        for i in range(start, len(candidates)):
            path.append(candidates[i])
            backtrack(i, path, remaining - candidates[i])  # i 不变，可重复选
            path.pop()
    backtrack(0, [], target)
    return result
```

### 组合总和 II（含重复元素，每个元素只能用一次）

**LeetCode 40**: 每个数字只能用一次，可能有重复元素。

```python
def combination_sum2(candidates, target):
    """
    思路：排序后去重，start + 1 避免重复使用
    时间复杂度: O(2^n * n)
    """
    candidates.sort()
    result = []
    def backtrack(start, path, remaining):
        if remaining == 0:
            result.append(path[:])
            return
        if remaining < 0:
            return
        for i in range(start, len(candidates)):
            # 去重：相同元素只选第一个
            if i > start and candidates[i] == candidates[i-1]:
                continue
            path.append(candidates[i])
            backtrack(i + 1, path, remaining - candidates[i])
            path.pop()
    backtrack(0, [], target)
    return result
```

### 电话号码的字母组合

**LeetCode 17**: 2-9 数字映射到字母，求所有组合。

**思路**：数字到字母映射，DFS 遍历每个数字的所有字母

```python
def letter_combinations(digits):
    """
    思路：构建数字到字母映射，递归组合
    时间复杂度: O(4^n * n) 最多4个字母
    """
    if not digits:
        return []
    phone = {
        '2': 'abc', '3': 'def', '4': 'ghi', '5': 'jkl',
        '6': 'mno', '7': 'pqrs', '8': 'tuv', '9': 'wxyz'
    }
    result = []
    def backtrack(index, path):
        if index == len(digits):
            result.append(''.join(path))
            return
        for letter in phone[digits[index]]:
            path.append(letter)
            backtrack(index + 1, path)
            path.pop()
    backtrack(0, [])
    return result
```

### 括号生成

**LeetCode 22**: 生成 n 对括号的所有有效组合。

**思路**：回溯法，左右括号计数，选左或选右需满足约束

```python
def generate_parenthesis(n):
    """
    思路：左右括号计数，有效条件 left < right
    时间复杂度: O(4^n / sqrt(n)) 卡特兰数
    """
    result = []
    def backtrack(left, right, path):
        if left == right == n:
            result.append(path[:])
            return
        # 可以加左括号
        if left < n:
            path.append('(')
            backtrack(left + 1, right, path)
            path.pop()
        # 可以加右括号
        if right < left:
            path.append(')')
            backtrack(left, right + 1, path)
            path.pop()
    backtrack(0, 0, [])
    return result
```

### 复原 IP 地址

**LeetCode 93**: 将字符串复原为有效的 IP 地址。

**思路**：分段回溯，每段 1-3 位，需满足 0-255 且无前导零

```python
def restore_ip_addresses(s):
    """
    思路：递归分段，验证每段有效性
    时间复杂度: O(3^4 * n) 最多4段
    """
    result = []
    def is_valid(segment):
        # 无前导零（除 "0" 本身）
        if len(segment) > 1 and segment[0] == '0':
            return False
        return 0 <= int(segment) <= 255

    def backtrack(start, segments):
        if len(segments) == 4:
            if start == len(s):
                result.append('.'.join(segments))
            return
        # 剪枝：剩余字符过多或过少
        if len(s) - start > (4 - len(segments)) * 3:
            return
        if len(s) - start < (4 - len(segments)):
            return
        # 取 1-3 个字符
        for length in range(1, 4):
            if start + length > len(s):
                break
            segment = s[start:start + length]
            if is_valid(segment):
                segments.append(segment)
                backtrack(start + length, segments)
                segments.pop()
    backtrack(0, [])
    return result
```

### N皇后

**LeetCode 51**: N 皇后问题，求所有解。

```python
def solve_n_queens(n):
    """
    思路：用集合记录已占用的列和两个对角线
    时间复杂度: O(n! * n)
    """
    result = []
    cols = set()
    diag1 = set()  # row + col
    diag2 = set()  # row - col

    def backtrack(row, path):
        if row == n:
            result.append(path[:])
            return
        for col in range(n):
            if col in cols or (row - col) in diag2 or (row + col) in diag1:
                continue
            cols.add(col)
            diag1.add(row + col)
            diag2.add(row - col)
            path.append('.' * col + 'Q' + '.' * (n - col - 1))
            backtrack(row + 1, path)
            path.pop()
            cols.remove(col)
            diag1.remove(row + col)
            diag2.remove(row - col)
    backtrack(0, [])
    return result
```

### N皇后 II（只求数量）

```python
def total_n_queens(n):
    """
    思路：位运算优化
    时间复杂度: O(n!)
    """
    def backtrack(row, cols, diags1, diags2):
        if row == n:
            return 1
        count = 0
        # 可用位置
        available_positions = (~(cols | diags1 | diags2)) & ((1 << n) - 1)
        while available_positions:
            position = available_positions & (-available_positions)  # 取最低位的1
            available_positions -= position
            count += backtrack(
                row + 1,
                cols | position,
                (diags1 | position) << 1,
                (diags2 | position) >> 1
            )
        return count
    return backtrack(0, 0, 0, 0)
```

### 单词搜索

**LeetCode 79**: 在二维网格中搜索单词。

**思路**：DFS + 回溯，同一单元格不能重复使用

```python
def exist(board, word):
    """
    思路：遍历起点，DFS 匹配单词
    时间复杂度: O(m * n * 4^L) L 为单词长度
    """
    if not board:
        return False
    m, n = len(board), len(board[0])

    def dfs(r, c, index):
        if index == len(word):
            return True
        if r < 0 or r >= m or c < 0 or c >= n or board[r][c] != word[index]:
            return False
        # 标记已访问
        temp = board[r][c]
        board[r][c] = '#'
        found = (dfs(r+1, c, index+1) or dfs(r-1, c, index+1) or
                dfs(r, c+1, index+1) or dfs(r, c-1, index+1))
        board[r][c] = temp  # 回溯
        return found

    for i in range(m):
        for j in range(n):
            if board[i][j] == word[0] and dfs(i, j, 0):
                return True
    return False
```

### 分割回文串

**LeetCode 131**: 将字符串分割成回文子串。

```python
def partition(s):
    """
    思路：DFS 枚举分割点，验证是否为回文
    时间复杂度: O(n * 2^n)
    """
    result = []
    def is_palindrome(sub):
        return sub == sub[::-1]

    def backtrack(start, path):
        if start == len(s):
            result.append(path[:])
            return
        for end in range(start + 1, len(s) + 1):
            if is_palindrome(s[start:end]):
                path.append(s[start:end])
                backtrack(end, path)
                path.pop()
    backtrack(0, [])
    return result
```

### 组合

**LeetCode 77**: 从 1-n 中选 k 个数的所有组合。

```python
def combine(n, k):
    """
    思路：回溯start到n，收集k个元素的组合
    时间复杂度: O(C(n,k) * k)
    """
    result = []
    def backtrack(start, path):
        if len(path) == k:
            result.append(path[:])
            return
        for i in range(start, n + 1):
            path.append(i)
            backtrack(i + 1, path)
            path.pop()
    backtrack(1, [])
    return result
```

## 回溯剪枝技巧

| 技巧 | 场景 |
|-----|------|
| 已使用标记 | 全排列、子集（元素不重复使用） |
| 排序 + 去重 | 含重复元素时跳过相同元素的重复分支 |
| 边界判断 | 组合总和 target < 0 时返回 |
| 可行性剪枝 | N皇后列/对角线冲突检测 |
| 前序/后序位置 | 分割回文串的子串有效性验证 |
