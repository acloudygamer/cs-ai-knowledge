# 回溯

## 定义

回溯是通过状态空间树的深度优先遍历（DFS）系统地枚举所有合法解的算法范式。在每层递归中，算法尝试所有可能的选择，进入下一层递归；当递归返回时，撤销刚才的选择（回溯），尝试下一个选择。配合剪枝（pruning）跳过已被约束证明无效的子树，将搜索从蛮力指数级压缩至接近最优解所在的区域。回溯不是一种具体算法，而是一种通过递归实现的状态空间搜索框架。

## 数学模型

### 状态空间树

设问题的选择序列长度为 $d$（解的规模），每层决策的分支因子为 $b_i$（第 $i$ 层可选项数），则状态空间树的最大节点数为：
$$N_{total} = \prod_{i=1}^{d} b_i = O(b^d)$$

其中 $b = \max_i b_i$ 为最大分支因子。

### 剪枝效率

设剪枝后实际访问节点数为 $N'$，则搜索代价 $T = O(N')$。若剪枝能排除绝大部分搜索空间，则 $N' \ll b^d$。剪枝效率取决于剪枝条件的精确性——剪枝条件越紧，排除的无效子树越多。

### 约束满足问题（CSP）形式化

将回溯应用于约束满足问题时，每个节点代表一个部分赋值 $(x_1=v_1, x_2=v_2, \ldots, x_k=v_k)$。剪枝通过约束传播（constraint propagation）实现：若当前部分赋值已违反某约束，则以该节点为根的整个子树均可剪掉。

### 解的计数

- 全排列：$N_{total} = n!$，无剪枝时需访问所有 $n!$ 个叶节点
- 子集枚举：$N_{total} = 2^n$，每个节点对应一个子集选择
- N 皇后：$N_{total} = n^n$（每行可选 $n$ 列），剪枝后可降至约 $10^n$ 数量级

**归约终点**：回溯是**状态空间树的穷举搜索问题**。在无剪枝情况下，时间复杂度指数级 $O(b^d)$；剪枝通过约束条件将搜索空间压缩到实际可求解的规模。

## 数据流

### 全排列的状态空间树遍历

<pre>
输入: nums = [1, 2, 3]

树遍历过程（每个节点 = (path, used)）:

Level 0: ([ ], used={})
           │
    ┌──────┴──────┐
    ▼              ▼
([1], {1})    ([2], {2})    ([3], {3})
    │              │              │
 ▼  ▼           ▼  ▼           ▼  ▼
...            ...            ...

展开 [1] 分支:
  ([1], {1}) → 选择 2 → ([1,2], {1,2})
    → 选择 3 → ([1,2,3], {1,2,3}) → 记录结果 [1,2,3]，回溯
    → 撤销 3, used[3]=False, 尝试其他选择（无）
  回溯到 ([1], {1})
  → 选择 3 → ([1,3], {1,3})
    → 选择 2 → ([1,3,2], {1,3,2}) → 记录 [1,3,2]
  回溯到 root

数据形态变换:
  path: list[int] — 当前选择序列（累积的解的部分构造）
  used: list[bool] — 各元素是否已被使用（选择状态标记）
  递归时: used[i]=True → path.append(nums[i]) → 递归
  回溯时: path.pop() → used[i]=False

关键: used 数组在回溯时必须还原（撤销操作），否则同一次递归调用返回后，
      后续分支会看到错误的 used 状态
</pre>

### N 皇后问题的约束传播与剪枝

<pre>
输入: n=4

Level 0 (row=0): 无约束，所有列可选
  尝试 col=0 → queen[0]=0

Level 1 (row=1): 约束来自 queen[0]=0
  列不能为 0 (同列)
  列不能为 1 (主对角线: row-col=1-0=1)
  列不能为 3 (副对角线: row+col=1+0=1)
  → 仅 col=2 可行 → queen[1]=2

Level 2 (row=2): 约束来自 queen[0]=0, queen[1]=2
  可选列: {0,1,3} \ {0,1,2,3} (分别检查同列和两条对角线)
  检查 col=0: 同列冲突(queen[0]=0)
  检查 col=1: 主对角线 row-col=2-1=1 冲突(queen[1]=2, 1-2=-1≠1)
            副对角线 row+col=2+1=3 冲突(queen[0]=0, 0+0=0≠3)
            实际上 col=1 不与任何已放皇后冲突... 继续递归
  ...

约束传播: 每个新放的皇后产生三个禁止列集合（同行已在其他行选择时才有）
         实际实现中只需检查新位置是否与所有已放皇后冲突

数据形态:
  queens: list[int] — queens[row] = col（第 row 行的皇后放在第 col 列）
  约束检查: 对每个已放皇后 (r, c)，检查 |row-r| == |col-c|（对角线冲突）
</pre>

### 八皇后问题的完整搜索树（部分）

<pre>
n=4 搜索树:

root (row=0)
 ├─ col=0 → row=1 可选列: {1,2,3} 但 {1,3} 对角线冲突
 │    ├─ col=1 → row=2 可选列: {3}
 │    │    └─ col=3 → row=3 无可选列 → 回溯
 │    └─ col=2 → row=2 无可选列 → 回溯
 └─ col=1 → row=1 可选列: {3}
      ├─ col=3 → row=2 可选列: {1}
      │    └─ col=1 → row=3 无可选列 → 回溯
      └─ (无其他选择) → 回溯
 ...

最终解: [1,3,0,2] 和 [2,0,3,1] (两种解)
</pre>

## 机制

### 为什么必须撤销选择

状态空间树的 DFS 路径共享中间节点。若在递归返回时不将 `used[i]` 还原为 `False`，则同一次 `backtrack` 调用返回后的后续循环迭代会看到错误的已选状态——将已选元素视为未选，导致：
- 重复使用同一元素（解不合法）
- 或者跳过本可使用的元素（解不完整）

这与图的 DFS 遍历中访问标记需在返回时清除完全类似——状态空间树是特殊的递归状图。

### 剪枝条件的充分性

剪枝条件必须是对"无解"的**充分条件**：若剪枝返回 True（即决定跳过），则该子树中一定不存在任何合法解。若剪枝条件过弱（不是真正的无解判定），可能跳过最优解；若剪枝条件过松（判定永远为 False），剪枝失效，搜索退化为蛮力。

### 回溯 vs. 分支限界

| 维度 | 回溯 | 分支限界 |
|------|------|----------|
| 搜索策略 | 深度优先（栈/递归） | 最佳优先（优先队列） |
| 目标 | 找所有解或一个解 | 找最优解 |
| 剪枝依据 | 约束条件（无解判定） | 限界函数（解质量上界） |
| 解空间 | 所有合法解 | 最小/最大代价的解 |

### 约束传播（Constraint Propagation）

在 CSP 问题中，单个选择的约束可传播给下游选择。例如 N 皇后中，一行的选择禁止同列和两对角线上所有后续行的皇后放置。AC-3 算法通过弧一致性维护进一步传播域约简，但基础回溯中的约束检查只做局部验证（前向检查）。

### 递归深度与栈溢出

回溯的递归深度等于解的长度 $d$。若 $d$ 很大（如 $d=10^5$），递归可能导致栈溢出。解决方案：使用显式栈模拟递归（迭代回溯），或尾递归优化（编译器支持时）。

### 时间复杂度分析

无剪枝时：
- 全排列：$O(n!)$（所有 $n!$ 个叶节点均访问）
- 子集枚举：$O(2^n)$
- N 皇后：$O(n^n)$

强剪枝时（如 N 皇后），剪枝后搜索节点数远小于 $n^n$，精确分析困难，实际接近指数级但远小于蛮力。

## 参考存根

```python
# 全排列
def permute(nums):
    res = []
    used = [False] * len(nums)

    def backtrack(path):
        if len(path) == len(nums):
            res.append(path[:])
            return
        for i in range(len(nums)):
            if used[i]:
                continue
            used[i] = True
            path.append(nums[i])
            backtrack(path)
            path.pop()
            used[i] = False

    backtrack([])
    return res

# 子集枚举
def subsets(nums):
    res = []

    def backtrack(start, path):
        res.append(path[:])  # 每个节点都是一个子集
        for i in range(start, len(nums)):
            path.append(nums[i])
            backtrack(i + 1, path)
            path.pop()

    backtrack(0, [])
    return res

# N 皇后（约束传播）
def solve_n_queens(n):
    res = []
    queens = [-1] * n  # queens[row] = col

    def is_valid(row, col):
        for r in range(row):
            c = queens[r]
            if c == col or abs(row - r) == abs(col - c):
                return False
        return True

    def backtrack(row):
        if row == n:
            board = ['.' * n for _ in range(n)]
            for r, c in enumerate(queens):
                board[r] = board[r][:c] + 'Q' + board[r][c+1:]
            res.append(board)
            return
        for col in range(n):
            if is_valid(row, col):
                queens[row] = col
                backtrack(row + 1)
                queens[row] = -1

    backtrack(0)
    return res

# 组合总和（可重复选/不可重复选）
def combination_sum(candidates, target):
    res = []

    def backtrack(start, path, remaining):
        if remaining == 0:
            res.append(path[:])
            return
        for i in range(start, len(candidates)):
            if candidates[i] > remaining:
                continue
            path.append(candidates[i])
            backtrack(i, path, remaining - candidates[i])  # i 可重复, start+1 不可重复
            path.pop()

    backtrack(0, [], target)
    return res
```
