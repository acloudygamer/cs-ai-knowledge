# 回溯

## 定义

回溯通过状态空间树的深度优先遍历枚举所有合法解，每层做选择后递归，递归返回时撤销选择（回溯），配合剪枝跳过无效子树。

## 数学模型

状态空间树大小为 $O(b^d)$，其中 $b$ 是分支因子，$d$ 是深度。剪枝将搜索规模从 $b^d$ 降至接近最优解所在区域。

剪枝效率：设剪枝后访问节点数为 $N'$，则搜索代价 $T = O(N')$。

## 数据流

<pre>
全排列 [1,2,3]:
树遍历:
[ ] 
 ├─[1] → [1,2] → [1,2,3] → record, pop
 │       └─[1,3] → [1,3,2] → record, pop
 └─[2] → [2,1] → [2,1,3] → record, pop
         └─[2,3] → [2,3,1] → record, pop
   ...
数据形态:
path: list[int] (当前路径)
used: list[bool] (已选状态标记)
</pre>

## 机制

**为什么需要撤销选择**：DFS 路径共享子节点，若不还原已选标记，同一节点会被多条路径错误复用，导致重复或遗漏。

**剪枝条件约束**：剪枝必须是充分条件——若剪枝条件为假（误剪），最优解被跳过；若剪枝条件过松，搜索效率降低但不错失解。

**三大要素**：
1. 结束条件：路径长度 == 目标规模，收集结果
2. 选择列表：通过 `used` 或边界计算可得
3. 剪枝条件：已选/越界/不满足约束

**时间复杂度**：无剪枝时 $O(n!)$（全排列）或 $O(2^n)$（子集）；强剪枝可指数级降低。

## 参考存根

```python
def permute(nums):
    res, used = [], [False] * len(nums)
    def backtrack(path):
        if len(path) == len(nums):
            res.append(path[:])
            return
        for i in range(len(nums)):
            if used[i]: continue
            used[i] = True
            path.append(nums[i])
            backtrack(path)
            path.pop()
            used[i] = False
    backtrack([])
    return res
```
