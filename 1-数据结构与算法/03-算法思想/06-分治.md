# 分治算法

## 核心思想

- **分解**：将原问题划分为若干个规模较小的相同子问题
- **解决**：递归求解子问题
- **合并**：将子问题的解合并为原问题的解

分治与递归密切相关，常用递归实现。核心条件：
1. 子问题之间相互独立
2. 子问题的解可以合并为原问题的解

## 经典应用

### 1. 归并排序（分治排序）

```python
def merge_sort(arr):
    """
    分治排序：分解 + 递归 + 合并
    时间：O(n log n)
    空间：O(n)
    """
    if len(arr) <= 1:
        return arr

    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])

    return merge(left, right)


def merge(left, right):
    """合并两个有序数组"""
    result = []
    i = j = 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1
    result.extend(left[i:])
    result.extend(right[j:])
    return result
```

### 2. 归并排序求逆序对

```python
def reverse_pairs_count(nums):
    """
    统计逆序对数量：i < j 且 nums[i] > nums[j]
    利用归并排序，在合并过程中统计
    """
    if len(nums) <= 1:
        return nums, 0

    mid = len(nums) // 2
    left, left_count = reverse_pairs_count(nums[:mid])
    right, right_count = reverse_pairs_count(nums[mid:])
    merged, cross_count = merge_and_count(left, right)

    return merged, left_count + right_count + cross_count


def merge_and_count(left, right):
    """合并两个有序数组，同时统计跨区域逆序对"""
    result = []
    count = 0
    i = j = 0

    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1
        else:
            # left[i] > right[j]，构成逆序对
            # left[i..] 都大于 right[j]，共 len(left) - i 个
            count += len(left) - i
            result.append(right[j])
            j += 1

    result.extend(left[i:])
    result.extend(right[j:])
    return result, count
```

### 3. 最近点对（Closest Pair）

```python
import math


def closest_pair(points):
    """
    二维平面上 n 个点中距离最近的两个点
    分治法：O(n log n)
    """
    if len(points) <= 3:
        return brute_force_closest(points)

    # 按 x 坐标排序
    points = sorted(points, key=lambda p: p[0])
    mid = len(points) // 2
    mid_x = points[mid][0]

    # 分治
    left = points[:mid]
    right = points[mid:]

    dl, pl = closest_pair(left)
    dr, pr = closest_pair(right)

    d, p = (dl, pl) if dl < dr else (dr, pr)

    # 合并：在 d 范围内的跨区域点
    strip = [p for p in points if abs(p[0] - mid_x) < d]
    ds, ps = closest_in_strip(strip, d)

    if ds < d:
        return ds, ps
    return d, p


def brute_force_closest(points):
    """暴力法（n <= 3）"""
    if len(points) < 2:
        return float('inf'), None
    if len(points) == 2:
        d = dist(points[0], points[1])
        return d, (points[0], points[1])

    d = float('inf')
    pair = None
    for i in range(len(points)):
        for j in range(i + 1, len(points)):
            dij = dist(points[i], points[j])
            if dij < d:
                d = dij
                pair = (points[i], points[j])
    return d, pair


def closest_in_strip(strip, d):
    """在 strip 中找距离小于 d 的最近点对（已按 y 排序）"""
    if len(strip) < 2:
        return d, None

    # strip 已按 y 坐标排序
    min_d = d
    min_pair = None

    for i in range(len(strip)):
        for j in range(i + 1, min(i + 7, len(strip))):
            # 只需检查相邻的至多 7 个点（几何性质）
            dij = dist(strip[i], strip[j])
            if dij < min_d:
                min_d = dij
                min_pair = (strip[i], strip[j])

    return min_d, min_pair


def dist(p1, p2):
    return math.sqrt((p1[0] - p2[0])**2 + (p1[1] - p2[1])**2)
```

### 4. 快速幂

```python
def fast_power(base, exponent):
    """
    快速幂：计算 base^exponent
    分治：O(log n)
    """
    if exponent == 0:
        return 1
    if exponent < 0:
        return 1 / fast_power(base, -exponent)

    half = fast_power(base, exponent // 2)
    if exponent % 2 == 0:
        return half * half
    else:
        return half * half * base


def matrix_power(matrix, exponent):
    """矩阵快速幂"""
    n = len(matrix)
    if exponent == 0:
        return [[int(i == j) for j in range(n)] for i in range(n)]  # 单位矩阵

    if exponent == 1:
        return matrix

    if exponent % 2 == 0:
        half = matrix_power(matrix, exponent // 2)
        return matrix_multiply(half, half)
    else:
        half = matrix_power(matrix, exponent // 2)
        return matrix_multiply(matrix_multiply(half, half), matrix)


def matrix_multiply(A, B):
    """矩阵乘法"""
    n = len(A)
    result = [[0] * n for _ in range(n)]
    for i in range(n):
        for j in range(n):
            for k in range(n):
                result[i][j] += A[i][k] * B[k][j]
    return result
```

### 5. 求众数 II（LeetCode 229）

```python
def majority_element(nums):
    """
    找出所有出现次数超过 n/3 的元素
    思路：分治
    出现超过 n/3 的元素最多有 2 个
    """
    if not nums:
        return []

    def divide_conquer(left, right):
        if left == right:
            return {nums[left]}

        mid = (left + right) // 2
        left_set = divide_conquer(left, mid)
        right_set = divide_conquer(mid + 1, right)

        result = set()
        for num in left_set | right_set:
            count = sum(1 for i in range(left, right + 1) if nums[i] == num)
            if count > (right - left + 1) // 3:
                result.add(num)
        return result

    return list(divide_conquer(0, len(nums) - 1))
```

### 6. 重建二叉树（LeetCode 105）

```python
def build_tree(preorder, inorder):
    """
    根据前序和中序遍历结果重建二叉树
    前序：[根, 左子树, 右子树]
    中序：[左子树, 根, 右子树]
    """
    if not preorder or not inorder:
        return None

    root_val = preorder[0]
    root = TreeNode(root_val)

    # 在中序遍历中找根
    root_idx = inorder.index(root_val)

    # 递归重建
    left_size = root_idx
    root.left = build_tree(
        preorder[1:1 + left_size],
        inorder[:root_idx]
    )
    root.right = build_tree(
        preorder[1 + left_size:],
        inorder[root_idx + 1:]
    )

    return root
```

## 分治 vs 动态规划

| 特性 | 分治 | 动态规划 |
|------|------|----------|
| 子问题关系 | 独立 | 重叠 |
| 重复计算 | 有 | 无（记忆化） |
| 最优子结构 | 不一定 | 必须 |
| 典型应用 | 归并排序、最近点对 | 爬楼梯、背包 |
| 实现方式 | 递归 | 递归或迭代 |

## 分治复杂度分析

常用主定理（Master Theorem）：
```
T(n) = aT(n/b) + f(n)

若 f(n) = O(n^log_b(a-ε))，则 T(n) = Θ(n^log_b(a))
若 f(n) = Θ(n^log_b(a) * log^k(n))，则 T(n) = Θ(n^log_b(a) * log^(k+1)(n))
若 f(n) = Ω(n^log_b(a+ε))，且满足正则条件，则 T(n) = Θ(f(n))
```

常见分治算法复杂度：
- 归并排序：T(n) = 2T(n/2) + O(n) → Θ(n log n)
- 最近点对：T(n) = 2T(n/2) + O(n) → Θ(n log n)
- 二分查找：T(n) = T(n/2) + O(1) → Θ(log n)
- 矩阵乘法（Strassen）：T(n) = 7T(n/2) + O(n²) → Θ(n^2.81)
