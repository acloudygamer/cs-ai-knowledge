# 双指针

> **版本基准**：universal —— 代码示例同时使用 Python 3.12 与 C++20

## 本质

双指针用两个指针协同遍历数组/链表/字符串，靠数据的**有序性或对称结构**让每步排除一批候选，把 $O(n^2)$ 的暴力枚举降到 $O(n)$ （或 $O(n\log n)$，含排序）。它不增加额外空间（ $O(1)$），代价是要求数据满足特定约束（有序、可成环、可三分等）。

常见三类：**碰撞指针**（有序数组两端向中间逼近，用单调性排除）、**快慢指针**（同向不同速，用速度差检测环/找中点）、**三路指针**（荷兰国旗，三分区间在线维护）。

## 数学模型

### 碰撞指针：单调性排除

有序数组找两数之和为 `target`。设 $S_{l,r}=a[l]+a[r]$， $l$ 从左、 $r$ 从右：

- $S < \text{target}$：固定 $r$、所有 $l' \leq l$ 的组合都更小（因 $a[l']\leq a[l]$），故只能 $l{+}{+}$。
- $S > \text{target}$：固定 $l$、所有 $r' \geq r$ 的组合都更大，故只能 $r{-}{-}$。

每步至少移动一个指针，总步数 $\leq 2n$。**正确性**：目标对 $(l^*,r^*)$ 存在时，中间状态 $(l,r)$ 若 $l\leq l^*, r\geq r^*$ 则 $S\geq\text{target}$ 必 $r{-}{-}$、若 $l\geq l^*, r\leq r^*$ 则 $S\leq\text{target}$ 必 $l{+}{+}$，逐步收敛到 $(l^*,r^*)$。

### 快慢指针：Floyd 环检测

慢指针走 1 步、快指针走 2 步。设环前长 $\mu$、环长 $\lambda$，首次相遇时慢走 $t=\mu+a$ （ $a$ 为相遇点在环内距入口的步数），快走 $2t=\mu+b\lambda+a$：

$$2t - t = b\lambda \;\Rightarrow\; t = b\lambda \;\Rightarrow\; \mu + a = b\lambda$$

相遇后把一个指针重置到头、两者都每次走 1 步，再次相遇处即环入口：从头走 $\mu$ 步到入口，从相遇点走 $\mu$ 步则 $a+\mu = a + b\lambda - a = b\lambda$ （模 $\lambda$ 回到入口）。

> **洞察**：快指针相对慢指针每步多走 1 格，环长 $\lambda$ 有限，故慢进环后至多 $\lambda$ 步必被追上——这是"速度差 + 有限环"的必然。步长必须使 $\gcd(\Delta v,\lambda)=1$ 才保证不跨过；步长 2 满足 $\gcd(1,\lambda)=1$ 总成立，故选 2。

### 三路指针：荷兰国旗不变量

把数组划成四段并维护不变量：

$$[0,p_0)=0,\quad [p_0,i)=1,\quad [i,p_2)=\text{待处理},\quad [p_2,n)=2$$

$i$ 每遇 0 与 $p_0$ 交换后两者各进一、遇 1 直接 $i{+}{+}$、遇 2 与 $p_2{-}{-}$ 交换但 $i$ 不动（换来的元素尚未处理）。 $i$ 与 $p_2$ 各至多移动 $n$ 步，总 $O(n)$。

## 数据流

### 碰撞指针：有序两数之和

<pre>
numbers = [1,2,4,6], target=10

l=0,r=3: 1+6=7  < 10 → l++
l=1,r=3: 2+6=8  < 10 → l++
l=2,r=3: 4+6=10 == target → 命中, 返回 [3,4] (1-indexed)

每步排除: 和太小则左端那个值对所有右候选都偏小, 整列砍掉
</pre>

**所有权变换**：数组只读，两指针仅是索引引用，无数据搬移。

### 快慢指针：链表环检测 + 找入口

<pre>
1 → 2 → 3 → 4 → 5 → 回指 3   (环入口在 3, μ=2, λ=3)

相遇阶段(slow 1步, fast 2步):
  slow:1 fast:1 → slow:2 fast:3 → slow:3 fast:5 → slow:4 fast:3(相遇)

找入口(slow 重置到头, 两者均 1 步):
  slow:1 fast:3 → slow:2 fast:4 → slow:3 fast:3(相遇, 即入口 3)
</pre>

### 三路指针：荷兰国旗

<pre>
nums = [2,0,2,1,1,0], 不变量 [0,p0)=0 [p0,i)=1 [i,p2)=待 [p2,n)=2

i=0 val2: 换 nums[0]↔nums[--p2=5] → [0,0,2,1,1,2], i 不动
i=0 val0: 换 nums[0]↔nums[p0++=0] → [0,0,2,1,1,2], i=1
i=1 val0: 换 nums[1]↔nums[p0++=1] → [0,0,2,1,1,2], i=2
i=2 val2: 换 nums[2]↔nums[--p2=4] → [0,0,1,1,2,2], i 不动
i=2 val1: i++ → i=3
i=3 val1: i++ → i=4 == p2 → 结束
结果: [0,0,1,1,2,2]
</pre>

## 对比参照

| 类型 | 指针方向 | 依赖结构 | 典型问题 |
|------|---------|---------|---------|
| 碰撞指针 | 两端向中间 | 数组有序 | 两数之和、容器盛水 |
| 快慢指针 | 同向不同速 | 链表/数组可成环 | 环检测、找中点、删倒数第N |
| 三路指针 | 三分区间 | 取值三类 | 荷兰国旗、三色排序 |
| 同向双指针 | 都从左向右 | 滑动窗口式约束 | 去重、划分 |

## 机制

### 碰撞指针必须有序

单调性来自 $a[l']\leq a[l]<a[r]\leq a[r']$ （ $l'<l<r<r'$）。和随 $l$ 增而增、随 $r$ 减而减，每步排除才"安全"——被排除的必不是解。无序数组要先排序（ $O(n\log n)$），但排序会丢失原始下标，若题目要下标则此法不适用。

### 快慢指针的步长选择

快指针相对慢指针每步追近 $\Delta v$ 格。环内要保证不"跨过"慢指针，需 $\gcd(\Delta v, \lambda)=1$。步长 2 时 $\Delta v=1$，与任意 $\lambda$ 都互素，总相遇；步长 3 时 $\Delta v=2$，若 $\lambda$ 为偶数则可能永远跳过——故默认选 2。无环时快指针先到 `NULL`。

### 三路指针的交换与指针推进

| `nums[i]` | 动作 | $p_0$ | $i$ | $p_2$ |
|-----------|------|-------|-----|-------|
| 0 | 换 `i`↔`p0`， $p_0{+}{+}$， $i{+}{+}$ | +1 | +1 | 不变 |
| 1 | $i{+}{+}$ | 不变 | +1 | 不变 |
| 2 | 换 `i`↔`p2-1`， $p_2{-}{-}$ | 不变 | 不变 | -1 |

遇 2 换来的元素未处理，故 $i$ 不动——这是不变量不破的关键。

### 违规后果

| 违规 | 后果 |
|------|------|
| 碰撞指针用于无序数组 | 单调性不成立，排除逻辑错，漏解或死循环 |
| 快慢指针步长非 2 且 $\lambda$ 不互素 | 跳过慢指针，永远不相遇 |
| 三路指针遇 2 后误推 $i$ | 换来的元素漏处理，结果错 |
| 链表快指针只检查 `fast` 不查 `fast.next` | 偶数长度越界访问空指针 |

## 代码示例

**Python 3.12**：

```python
# 碰撞指针: 有序两数之和, 返回 1-indexed
def two_sum_sorted(numbers, target):
    l, r = 0, len(numbers) - 1
    while l < r:
        s = numbers[l] + numbers[r]
        if s == target: return [l + 1, r + 1]
        if s < target:  l += 1
        else:           r -= 1
    return []

# 快慢指针: 环检测 + 找环入口
class ListNode:
    def __init__(self, val=0, nxt=None): self.val, self.next = val, nxt

def detect_cycle(head):
    slow = fast = head
    while fast and fast.next:
        slow, fast = slow.next, fast.next.next
        if slow is fast:                      # 相遇
            p = head
            while p is not slow:              # 同步走至环入口
                p, slow = p.next, slow.next
            return p
    return None

# 三路指针: 荷兰国旗, p2 取 n (exclusive)
def sort_colors(nums):
    p0 = i = 0; p2 = len(nums)
    while i < p2:
        if nums[i] == 0:
            nums[p0], nums[i] = nums[i], nums[p0]; p0 += 1; i += 1
        elif nums[i] == 2:
            p2 -= 1
            nums[i], nums[p2] = nums[p2], nums[i]   # i 不动
        else:
            i += 1
    return nums

# —— 简易输入输出 ——
print(two_sum_sorted([1,2,4,6], 10))     # [3, 4]
print(sort_colors([2,0,2,1,1,0]))       # [0,0,1,1,2,2]
```

**C++20**：

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

// 碰撞指针: 有序两数之和
std::vector<int> twoSumSorted(const std::vector<int>& a, int target) {
    int l = 0, r = (int)a.size() - 1;
    while (l < r) {
        int s = a[l] + a[r];
        if (s == target) return {l + 1, r + 1};
        if (s < target) ++l; else --r;
    }
    return {};
}

// 三路指针: 荷兰国旗 (p2 exclusive)
void sortColors(std::vector<int>& nums) {
    int p0 = 0, i = 0, p2 = (int)nums.size();
    while (i < p2) {
        if (nums[i] == 0) std::swap(nums[p0++], nums[i++]);
        else if (nums[i] == 2) std::swap(nums[i], nums[--p2]);   // i 不动
        else ++i;
    }
}

int main() {
    auto r = twoSumSorted({1,2,4,6}, 10);
    std::cout << r[0] << ',' << r[1] << '\n';        // 3,4
    std::vector<int> c = {2,0,2,1,1,0};
    sortColors(c);
    for (int x : c) std::cout << x << ' ';          // 0 0 1 1 2 2
    std::cout << '\n';
}
```
