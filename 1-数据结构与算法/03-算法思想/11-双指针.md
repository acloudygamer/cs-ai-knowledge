# 双指针

## 核心思想

双指针是一种通过两个指针协同遍历数组/链表来解决问题的技巧。两个指针可以在同向或反向移动，从而将暴力 O(n²) 优化为 O(n)。

**常见模式**：
- **碰撞指针**：左右指针从两端向中间移动（有序数组）
- **快慢指针**：快慢指针同向移动（链表环检测、删重）
- **滑动窗口**：两个指针维护一个窗口（见滑动窗口专题）

**时间复杂度**: O(n)
**空间复杂度**: O(1)

## 碰撞指针

碰撞指针要求数组有序，左右指针从两端向中间逼近。

### 两数之和 II - 输入有序数组

**LeetCode 167**: 在有序数组中找到两数之和等于 target 的两个索引。

**时间复杂度**: O(n)
**空间复杂度**: O(1)

```python
def two_sum_sorted(numbers, target):
    """
    碰撞指针：
    - 左指针指向最小值，右指针指向最大值
    - 如果和大于 target，右指针左移
    - 如果和小于 target，左指针右移
    """
    left, right = 0, len(numbers) - 1

    while left < right:
        current_sum = numbers[left] + numbers[right]

        if current_sum == target:
            return [left + 1, right + 1]  # 1-indexed
        elif current_sum < target:
            left += 1
        else:
            right -= 1

    return []  # No solution
```

**图解**：
```
numbers = [2, 7, 11, 15], target = 9

Step 1: left=0, right=3 → 2+15=17 > 9 → right--
Step 2: left=0, right=2 → 2+11=13 > 9 → right--
Step 3: left=0, right=1 → 2+7=9 == target → return [1, 2]
```

### 验证回文串

**LeetCode 125**: 验证是否为回文串（忽略非字母数字字符，大小写不敏感）。

```python
def is_palindrome(s):
    """
    碰撞指针：左右指针向中间移动
    时间复杂度: O(n)
    空间复杂度: O(1)
    """
    left, right = 0, len(s) - 1

    while left < right:
        # 跳过非字母数字字符
        while left < right and not s[left].isalnum():
            left += 1
        while left < right and not s[right].isalnum():
            right -= 1

        if s[left].lower() != s[right].lower():
            return False

        left += 1
        right -= 1

    return True
```

### 翻转元音字母

**LeetCode 345**: 翻转字符串中的元音字母。

```python
def reverse_vowels(s):
    """
    碰撞指针 + 元音判断
    时间复杂度: O(n)
    空间复杂度: O(n) for result string
    """
    vowels = set('aeiouAEIOU')
    chars = list(s)
    left, right = 0, len(chars) - 1

    while left < right:
        while left < right and chars[left] not in vowels:
            left += 1
        while left < right and chars[right] not in vowels:
            right -= 1

        chars[left], chars[right] = chars[right], chars[left]
        left += 1
        right -= 1

    return ''.join(chars)
```

### 三数之和

**LeetCode 15**: 在数组中找到所有和为 0 的不重复三元组。

**思路**：排序 + 碰撞指针 + 去重

```python
def three_sum(nums):
    """
    排序后使用碰撞指针
    时间复杂度: O(n²)
    空间复杂度: O(1) (不计结果存储)
    """
    nums.sort()
    result = []

    for i in range(len(nums) - 2):
        # 跳过重复的第一个元素
        if i > 0 and nums[i] == nums[i - 1]:
            continue

        left, right = i + 1, len(nums) - 1
        target = -nums[i]

        while left < right:
            current_sum = nums[left] + nums[right]

            if current_sum == target:
                result.append([nums[i], nums[left], nums[right]])

                # 跳过重复的第二个和第三个元素
                while left < right and nums[left] == nums[left + 1]:
                    left += 1
                while left < right and nums[right] == nums[right - 1]:
                    right -= 1

                left += 1
                right -= 1
            elif current_sum < target:
                left += 1
            else:
                right -= 1

    return result
```

### 四数之和

**LeetCode 18**: 在数组中找到所有和为 target 的不重复四元组。

```python
def four_sum(nums, target):
    """
    排序 + 双碰撞指针
    时间复杂度: O(n³)
    空间复杂度: O(1)
    """
    nums.sort()
    n = len(nums)
    result = []

    for i in range(n - 3):
        if i > 0 and nums[i] == nums[i - 1]:
            continue
        # 剪枝：小数和大，退出
        if nums[i] + nums[i + 1] + nums[i + 2] + nums[i + 3] > target:
            break
        if nums[i] + nums[n - 1] + nums[n - 2] + nums[n - 3] < target:
            continue

        for j in range(i + 1, n - 2):
            if j > i + 1 and nums[j] == nums[j - 1]:
                continue
            # 剪枝
            if nums[i] + nums[j] + nums[j + 1] + nums[j + 2] > target:
                break
            if nums[i] + nums[j] + nums[n - 1] + nums[n - 2] < target:
                continue

            left, right = j + 1, n - 1
            while left < right:
                current_sum = nums[i] + nums[j] + nums[left] + nums[right]

                if current_sum == target:
                    result.append([nums[i], nums[j], nums[left], nums[right]])
                    left += 1
                    right -= 1
                    while left < right and nums[left] == nums[left - 1]:
                        left += 1
                    while left < right and nums[right] == nums[right + 1]:
                        right -= 1
                elif current_sum < target:
                    left += 1
                else:
                    right -= 1

    return result
```

## 快慢指针

快慢指针同向移动，常用于链表问题。

### 链表环检测

**LeetCode 141**: 检测链表是否有环。

**时间复杂度**: O(n)
**空间复杂度**: O(1)

```python
def has_cycle(head):
    """
    快指针每次走两步，慢指针每次走一步
    如果有环，它们最终会相遇
    """
    slow = fast = head

    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow == fast:
            return True

    return False
```

### 环形链表 II

**LeetCode 142**: 找到环形链表的入环点。

```python
def detect_cycle(head):
    """
    数学推导：
    - 设入环前距离为 a，快慢指针相遇点距入环点为 b
    - 慢指针路程 = a + b
    - 快指针路程 = a + b + n(环长) = 2(a + b)
    - 所以 a + b = n(环长)，即 a = n(环长) - b

    相遇后，让一个指针从 head 出发，另一个从相遇点出发，
    它们会在入环点相遇
    """
    slow = fast = head

    # 第一次相遇
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow == fast:
            break

    if not fast or not fast.next:
        return None  # No cycle

    # 第二次相遇：找入环点
    slow = head
    while slow != fast:
        slow = slow.next
        fast = fast.next

    return slow
```

**图解**：
```
链表: 1 → 2 → 3 → 4 → 5
            ↑       ↓
            7 ← 6 ←─┘

设环长 = 4 (节点 2-5-7-6)
入环点 = 节点 2

步骤：
1. slow 和 fast 从 head(1) 出发
2. slow 走到节点 2，fast 走到节点 4
3. 继续，slow 走到节点 3，fast 走到节点 6
4. 继续，slow 走到节点 2，fast 走到节点 2（相遇）

现在 slow 从 head 出发，fast 从节点 2 出发，一次走一步：
- slow: 1 → 2 (入环点)
- fast: 2 → 3 → 4 → 5 → 6 → 7 → 2 (回到入环点)
相遇点即为入环点
```

### 删除链表的倒数第 N 个节点

**LeetCode 19**: 删除链表的倒数第 N 个节点。

```python
def remove_nth_from_end(head, n):
    """
    快慢指针：先让快指针走 n 步，然后一起走
    时间复杂度: O(n)
    空间复杂度: O(1)
    """
    dummy = ListNode(0, head)
    slow = fast = dummy

    # 快指针先走 n+1 步
    for _ in range(n + 1):
        fast = fast.next

    # 一起走，直到快指针到达末尾
    while fast:
        slow = slow.next
        fast = fast.next

    # slow 指向待删除节点的前一个
    slow.next = slow.next.next

    return dummy.next
```

### 移除重复元素（有序链表）

**LeetCode 82**: 删除有序链表中重复的元素（保留不重复的）。

```python
def delete_duplicates(head):
    """
    快慢指针
    时间复杂度: O(n)
    空间复杂度: O(1)
    """
    dummy = ListNode(0, head)
    slow = dummy

    while head:
        # 检测重复
        if head.next and head.val == head.next.val:
            # 跳过所有重复节点
            while head.next and head.val == head.next.val:
                head = head.next
            # slow 指向不重复的下一个
            slow.next = head.next
        else:
            slow = slow.next
        head = head.next

    return dummy.next
```

def delete_all_duplicates(head):

## 对撞型双指针

### 反转字符串

**LeetCode 344**: 反转字符串。

```python
def reverse_string(s):
    """
    碰撞指针原地反转
    时间复杂度: O(n)
    空间复杂度: O(n) for char list
    """
    chars = list(s)
    left, right = 0, len(chars) - 1

    while left < right:
        chars[left], chars[right] = chars[right], chars[left]
        left += 1
        right -= 1

    return "".join(chars)
```

### 回文链表

**LeetCode 234**: 验证是否为回文链表。

**思路**：找中点 → 反转后半部分 → 比较

```python
def is_palindrome_list(head):
    """
    步骤：
    1. 快慢指针找中点
    2. 反转后半部分
    3. 比较前后两部分
    4. 恢复链表（可选）

    时间复杂度: O(n)
    空间复杂度: O(1)
    """
    if not head or not head.next:
        return True

    # 1. 找中点
    slow = fast = head
    while fast.next and fast.next.next:
        slow = slow.next
        fast = fast.next.next

    # 2. 反转后半部分
    second_half = reverse_list(slow.next)

    # 3. 比较
    p1, p2 = head, second_half
    result = True
    while p2:
        if p1.val != p2.val:
            result = False
            break
        p1 = p1.next
        p2 = p2.next

    # 4. 恢复链表（可选）
    slow.next = reverse_list(second_half)

    return result


def reverse_list(head):
    """反转链表辅助函数"""
    prev = None
    curr = head
    while curr:
        next_temp = curr.next
        curr.next = prev
        prev = curr
        curr = next_temp
    return prev
```

### 合并两个有序数组

**LeetCode 88**: 将 nums2 合并到 nums1 中（原地）。

```python
def merge(nums1, m, nums2, n):
    """
    从后向前双指针，避免覆盖
    时间复杂度: O(m + n)
    空间复杂度: O(1)
    """
    p1 = m - 1  # nums1 的有效元素末尾
    p2 = n - 1  # nums2 的末尾
    p = m + n - 1  # 合并后的末尾

    while p1 >= 0 and p2 >= 0:
        if nums1[p1] > nums2[p2]:
            nums1[p] = nums1[p1]
            p1 -= 1
        else:
            nums1[p] = nums2[p2]
            p2 -= 1
        p -= 1

    # 如果 nums2 还有剩余，直接复制
    while p2 >= 0:
        nums1[p] = nums2[p2]
        p2 -= 1
        p -= 1
```

### 颜色分类（荷兰国旗问题）

**LeetCode 75**: 将 0、1、2 三种颜色排序。

```python
def sort_colors(nums):
    """
    三路指针：维护 [0, zero] 是 0，(zero, i) 是 1，[two, n-1] 是 2
    时间复杂度: O(n)
    空间复杂度: O(1)
    """
    zero = 0  # 0 的右边界
    i = 0     # 当前遍历位置
    two = len(nums) - 1  # 2 的左边界

    while i <= two:
        if nums[i] == 0:
            nums[zero], nums[i] = nums[i], nums[zero]
            zero += 1
            i += 1
        elif nums[i] == 2:
            nums[two], nums[i] = nums[i], nums[two]
            two -= 1
            # 注意：i 不变，因为交换过来的元素还需要检查
        else:  # nums[i] == 1
            i += 1
```

**图解**：
```
初始: [2, 0, 2, 1, 1, 0]
       ↑
      zero=0, i=0, two=5

Step: i=0, nums[i]=2 → 交换 nums[0] 和 nums[5]
      [0, 0, 2, 1, 1, 2]
             ↑
            two=4
      i 不变，继续检查 nums[0]

Step: i=0, nums[i]=0 → 交换 nums[0] 和 nums[0]
      [0, 0, 2, 1, 1, 2]
       ↑    ↑
      zero=1, i=1

Step: i=1, nums[i]=0 → 交换 nums[1] 和 nums[1]
      [0, 0, 2, 1, 1, 2]
          ↑    ↑
         zero=2, i=2

...继续直到 i > two
```

### 有效山脉数组

**LeetCode 941**: 验证是否为有效山脉数组。

```python
def valid_mountain_array(arr):
    """
    双指针：从两端向中间找峰值
    时间复杂度: O(n)
    空间复杂度: O(1)
    """
    n = len(arr)
    if n < 3:
        return False

    left, right = 0, n - 1

    # 从左边上山
    while left + 1 < n - 1 and arr[left] < arr[left + 1]:
        left += 1

    # 从右边上山
    while right - 1 > 0 and arr[right] < arr[right - 1]:
        right -= 1

    # 两个指针必须相遇在同一点，且不是起点或终点
    return left == right and left != 0 and right != n - 1
```

### 合并区间

**LeetCode 56**: 合并重叠的区间。

```python
def merge(intervals):
    """
    排序 + 双指针
    时间复杂度: O(n log n)
    空间复杂度: O(1) (不计结果存储)
    """
    if not intervals:
        return []

    intervals.sort()
    result = [intervals[0]]

    for i in range(1, len(intervals)):
        current = intervals[i]
        last = result[-1]

        if current[0] <= last[1]:  # 重叠
            last[1] = max(last[1], current[1])
        else:
            result.append(current)

    return result
```

## 双指针技巧总结

| 场景 | 指针类型 | 关键点 |
|-----|---------|--------|
| 两数之和（有序） | 碰撞指针 | left 从小，right 从大 |
| 链表中点/环 | 快慢指针 | fast 走两步，slow 走一步 |
| 删除倒数第 N 个 | 快慢指针 | fast 先走 n+1 步 |
| 反转字符串 | 碰撞指针 | 交换 left 和 right |
| 合并有序数组 | 对撞指针 | 从后往前避免覆盖 |
| 三数/四数之和 | 排序 + 碰撞 | 去重是关键 |
| 颜色分类 | 三路指针 | 维护三个分区 |
