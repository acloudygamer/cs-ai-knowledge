## 双指针

### 解决什么问题
通过两个指针协同遍历数组/链表，将暴力 O(n^2) 优化为 O(n)，适用于有序数组的两数之和、三数之和、链表环检测等问题。

### 核心概念
- **碰撞指针**：左右指针从两端向中间移动，适用于有序数组
- **快慢指针**：快慢指针同向移动，适用于链表
- **滑动窗口**：双指针维护窗口，可看作特殊的双指针
- **三路指针**：维护三个分区，如荷兰国旗问题

### 双指针技巧总结

| 场景 | 指针类型 | 关键点 |
|-----|---------|--------|
| 两数之和（有序） | 碰撞指针 | left 从小，right 从大 |
| 反转字符串 | 碰撞指针 | 交换 left 和 right |
| 合并有序数组 | 对撞指针 | 从后往前避免覆盖 |
| 三数/四数之和 | 排序 + 碰撞 | 去重是关键 |
| 颜色分类 | 三路指针 | 维护三个分区 |

## 碰撞指针

碰撞指针要求数组有序，左右指针从两端向中间逼近。

### 两数之和 II

**LeetCode 167**：在有序数组中找到两数之和等于 target 的两个索引（1-indexed）。

### 参考样例

```python
def two_sum_sorted(numbers, target):
    left, right = 0, len(numbers) - 1
    while left < right:
        current_sum = numbers[left] + numbers[right]
        if current_sum == target:
            return [left + 1, right + 1]
        elif current_sum < target:
            left += 1
        else:
            right -= 1
    return []
```

### 验证回文串

**LeetCode 125**：验证是否为回文串（忽略非字母数字字符）。

### 参考样例

```python
def is_palindrome(s):
    left, right = 0, len(s) - 1
    while left < right:
        while left < right and not s[left].isalnum():
            left += 1
        while left < right and not s[right].isalnum():
            right -= 1
        if s[left].lower() != s[right].lower():
            return False
        left += 1
        right -= 1
    return True
```

## 三数之和

**LeetCode 15**：在数组中找到所有和为 0 的不重复三元组。排序后使用碰撞指针 + 去重。

### 参考样例

```python
def three_sum(nums):
    nums.sort()
    result = []
    for i in range(len(nums) - 2):
        if i > 0 and nums[i] == nums[i - 1]:
            continue
        left, right = i + 1, len(nums) - 1
        target = -nums[i]
        while left < right:
            current_sum = nums[left] + nums[right]
            if current_sum == target:
                result.append([nums[i], nums[left], nums[right]])
                while left < right and nums[left] == nums[left + 1]:
                    left += 1
                while left < right and nums[right] == nums[right - 1]:
                    right -= 1
                left += 1
                right -= 1
            elif current_sum < target:
                left += 1
            else:
                right -= 1
    return result
```

## 四数之和

**LeetCode 18**：在数组中找到所有和为 target 的不重复四元组。

### 参考样例

```python
def four_sum(nums, target):
    nums.sort()
    n = len(nums)
    result = []
    for i in range(n - 3):
        if i > 0 and nums[i] == nums[i - 1]:
            continue
        for j in range(i + 1, n - 2):
            if j > i + 1 and nums[j] == nums[j - 1]:
                continue
            left, right = j + 1, n - 1
            while left < right:
                current_sum = nums[i] + nums[j] + nums[left] + nums[right]
                if current_sum == target:
                    result.append([nums[i], nums[j], nums[left], nums[right]])
                    while left < right and nums[left] == nums[left - 1]:
                        left += 1
                    while left < right and nums[right] == nums[right + 1]:
                        right -= 1
                    left += 1
                    right -= 1
                elif current_sum < target:
                    left += 1
                else:
                    right -= 1
    return result
```

## 颜色分类（荷兰国旗问题）

**LeetCode 75**：将 0、1、2 三种颜色排序。三路指针维护 [0, zero] 是 0，(zero, i) 是 1，[two, n-1] 是 2。

### 参考样例

```python
def sort_colors(nums):
    zero = 0
    i = 0
    two = len(nums) - 1
    while i <= two:
        if nums[i] == 0:
            nums[zero], nums[i] = nums[i], nums[zero]
            zero += 1
            i += 1
        elif nums[i] == 2:
            nums[two], nums[i] = nums[i], nums[two]
            two -= 1
        else:
            i += 1
```

## 合并两个有序数组

**LeetCode 88**：从后向前双指针，避免覆盖。

### 参考样例

```python
def merge(nums1, m, nums2, n):
    p1 = m - 1
    p2 = n - 1
    p = m + n - 1
    while p1 >= 0 and p2 >= 0:
        if nums1[p1] > nums2[p2]:
            nums1[p] = nums1[p1]
            p1 -= 1
        else:
            nums1[p] = nums2[p2]
            p2 -= 1
        p -= 1
    while p2 >= 0:
        nums1[p] = nums2[p2]
        p2 -= 1
        p -= 1
```

## 合并区间

**LeetCode 56**：合并重叠的区间。排序后遍历。

### 参考样例

```python
def merge(intervals):
    if not intervals:
        return []
    intervals.sort()
    result = [intervals[0]]
    for i in range(1, len(intervals)):
        current = intervals[i]
        last = result[-1]
        if current[0] <= last[1]:
            last[1] = max(last[1], current[1])
        else:
            result.append(current)
    return result
```

## 有效山脉数组

**LeetCode 941**：验证是否为有效山脉数组。

### 参考样例

```python
def valid_mountain_array(arr):
    n = len(arr)
    if n < 3:
        return False
    left, right = 0, n - 1
    while left + 1 < n - 1 and arr[left] < arr[left + 1]:
        left += 1
    while right - 1 > 0 and arr[right] < arr[right - 1]:
        right -= 1
    return left == right and left != 0 and right != n - 1
```
