# 双指针

## 定义

双指针通过两个指针在数组/链表上协同遍历，将 $O(n^2)$ 暴力枚举降为 $O(n)$，利用有序性或对称结构剪掉无效枚举。

## 数学模型

碰撞指针时间复杂度：
$$\text{每步至少一指针移动，总步数} \leq 2n = O(n)$$

快慢指针链表环检测：
$$\text{相遇时间} = O(\mu \cdot \lambda) = O(n), \quad \mu=\text{环前长度}, \lambda=\text{环长}$$

## 数据流

<pre>
两数之和 II (有序数组):
输入: numbers=[1,2,4,6], target=10
初始: left=0, right=3, sum=1+6=7 < 10 → left++
left=1, right=3, sum=2+6=8 < 10 → left++
left=2, right=3, sum=4+6=10 == 10 → return [3,4]
索引为 1-indexed → [left+1, right+1] = [3,4]

数据形态:
list[int] + two pointers → sum comparison → pointer movement
</pre>

<pre>
快慢指针检测链表环:
slow → 每次移动1步, fast → 每次移动2步
若有环必相遇
</pre>

## 机制

**碰撞指针原理**：有序数组两端元素之和随 left↑ 增大、right↓ 减小，单调性保证每步都能排除至少一个候选。

**快慢指针原理**：链表有环时，快指针必在环内追上慢指针（相对速度1）；无环时快指针先到尾部。

**三路指针**（荷兰国旗）：维护三个分区 $[0..zero]$ (0)、$(zero..i)$ (1)、$[two..n-1]$ (2)，i 前进、zero 和 two 交换，$O(n)$ 一次遍历完成三色排序。

**约束条件**：
- 碰撞指针要求数组有序；无序数组必须先排序（破坏原顺序感）
- 快慢指针需确保快指针边界不越位（链表操作需判空）

```python
def two_sum_sorted(nums, target):
    l, r = 0, len(nums) - 1
    while l < r:
        s = nums[l] + nums[r]
        if s == target: return [l + 1, r + 1]
        l += 1 if s < target else 0
        r -= 1 if s > target else 0
    return []

def sort_colors(nums):
    zero = i = 0; two = len(nums) - 1
    while i <= two:
        if nums[i] == 0:
            nums[zero], nums[i] = nums[i], nums[zero]
            zero += 1; i += 1
        elif nums[i] == 2:
            nums[i], nums[two] = nums[two], nums[i]
            two -= 1
        else: i += 1
```
