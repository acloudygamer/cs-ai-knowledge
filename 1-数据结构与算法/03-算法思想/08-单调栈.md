# 单调栈

## 定义

单调栈在 $O(n)$ 时间内维护一个单调递增或递减的下标序列，每个元素最多入栈出栈各一次，用于求解 Next Greater/Smaller Element 等区间极值问题。

## 数学模型

每个元素入栈一次、出栈一次，总操作数 $2n$，故时间 $O(n)$、空间最坏 $O(n)$。

栈操作均摊分析：
$$\sum \text{push} = n, \quad \sum \text{pop} \leq n$$
$$\text{总操作} = O(n)$$

## 数据流

<pre>
nums = [2,1,2,4,3], 找下一个更大元素
遍历:
i=0, val=2: stack=[] → push(0)
i=1, val=1: stack=[0], nums[0]=2 > 1 → 不pop, push(1)
i=2, val=2: stack=[0,1], nums[1]=1 < 2 → pop(1), next[1]=2
                 stack=[0], nums[0]=2 == 2 → 不pop, push(2)
i=3, val=4: stack=[0,2], nums[2]=2 < 4 → pop(2), next[2]=4
                 stack=[0], nums[0]=2 < 4 → pop(0), next[0]=4
                 stack=[], push(3)
i=4, val=3: stack=[3], nums[3]=4 > 3 → 不pop, push(4)
栈剩余: next[4]=-1

输出: next = [4,2,4,-1,-1]
</pre>

## 机制

**为什么单调性保证正确性**：栈底到栈顶单调，当新元素 $x$ 压栈时，所有比 $x$ 小的栈内元素不会再成为任何后续元素的 Next Greater——它们已被 $x$ "遮挡"。弹出时记录 $x$ 为其答案。

**约束条件**：
- 栈内存储下标而非值，确保能计算距离
- 循环数组须遍历两遍（$2n$），第二遍不入新元素只弹栈

**适用问题**：柱状图最大矩形（枚举高度作为最低柱）、每日温度（下一个更大距离）、移去 K 位数字（保持递增删除逆序）。

## 参考存根

```python
def next_greater(nums):
    n = len(nums)
    res = [-1] * n
    stack = []
    for i in range(n):
        while stack and nums[stack[-1]] < nums[i]:
            res[stack.pop()] = nums[i]
        stack.append(i)
    return res
```
