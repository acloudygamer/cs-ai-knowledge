## 单调栈

### 解决什么问题
在 O(n) 时间复杂度内解决 Next Greater/Smaller Element 问题，适用于柱状图最大矩形、每日温度等应用单调性简化的问题。

### 核心概念
- 栈内元素保持单调递增或递减
- 每个元素最多入栈出栈各一次，总时间 O(n)
- 记录下标而非值，便于计算距离
- 循环数组问题：遍历两遍模拟环形结构

### 单调栈模板

```python
# 单调递增栈（找下一个更小元素）
stack = []
for i in range(n):
    while stack and nums[stack[-1]] > nums[i]:
        idx = stack.pop()
        # nums[idx] 的下一个更小是 nums[i]
    stack.append(i)

# 单调递减栈（找下一个更大元素）
stack = []
for i in range(n):
    while stack and nums[stack[-1]] < nums[i]:
        idx = stack.pop()
        # nums[idx] 的下一个更大是 nums[i]
    stack.append(i)
```

## Next Greater Element

### 下一个更大元素 I

**LeetCode 496**：nums1 是 nums2 的子集，对 nums1 中每个元素找在 nums2 中的下一个更大元素。

### 参考样例

```python
def next_greater_element(nums1, nums2):
    stack = []
    next_greater = {}
    for num in nums2:
        while stack and stack[-1] < num:
            next_greater[stack.pop()] = num
        stack.append(num)
    for num in stack:
        next_greater[num] = -1
    return [next_greater[num] for num in nums1]
```

### 下一个更大元素 II（循环数组）

**LeetCode 503**：数组是环形的，需要遍历两遍。

### 参考样例

```python
def next_greater_element_ii(nums):
    n = len(nums)
    result = [-1] * n
    stack = []
    for i in range(2 * n):
        idx = i % n
        while stack and nums[stack[-1]] < nums[idx]:
            result[stack.pop()] = nums[idx]
        if i < n:
            stack.append(idx)
    return result
```

### 每日温度

**LeetCode 739**：返回需要等待多少天才能等到更高温度。

### 参考样例

```python
def daily_temperatures(temps):
    n = len(temps)
    result = [0] * n
    stack = []
    for i in range(n):
        while stack and temps[stack[-1]] < temps[i]:
            prev = stack.pop()
            result[prev] = i - prev
        stack.append(i)
    return result
```

## 柱状图中最大的矩形

**LeetCode 84**：计算柱状图中最大矩形面积。

枚举每个柱形为最低高度，向左右扩展。使用单调递增栈。

### 参考样例

```python
def largest_rectangle_area(heights):
    heights = [0] + heights + [0]
    stack = [0]
    max_area = 0
    for i in range(1, len(heights)):
        while heights[i] < heights[stack[-1]]:
            h = heights[stack.pop()]
            w = i - stack[-1] - 1
            max_area = max(max_area, h * w)
        stack.append(i)
    return max_area
```

## 移去 K 位数字

**LeetCode 402**：移除 k 位数字使结果最小。保持单调递增，移除比后续数字大的数字。

### 参考样例

```python
def remove_k_digits(num, k):
    stack = []
    for digit in num:
        while k and stack and stack[-1] > digit:
            stack.pop()
            k -= 1
        stack.append(digit)
    while k:
        stack.pop()
        k -= 1
    result = ''.join(stack).lstrip('0')
    return result if result else '0'
```

## 最短无序连续子数组

**LeetCode 581**：找出最短的无序子数组长度，排序后整个数组有序。

### 参考样例

```python
def find_unsorted_subarray(nums):
    n = len(nums)
    stack = []
    left = n
    for i in range(n):
        while stack and nums[stack[-1]] > nums[i]:
            left = min(left, stack.pop())
        stack.append(i)
    if left == n:
        return 0
    right = 0
    stack = []
    for i in range(n - 1, -1, -1):
        while stack and nums[stack[-1]] < nums[i]:
            right = max(right, stack.pop())
        stack.append(i)
    return right - left + 1
```
