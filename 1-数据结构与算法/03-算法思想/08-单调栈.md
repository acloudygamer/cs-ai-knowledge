# 单调栈

### 解决什么问题
在 O(n) 时间复杂度内解决 Next Greater/Smaller Element 问题，适用于柱状图最大矩形、每日温度等应用单调性简化的问题。

### 核心概念
- 栈内元素保持单调递增或递减
- 每个元素最多入栈出栈各一次，总时间 O(n)
- 记录下标而非值，便于计算距离
- 循环数组问题：遍历两遍模拟环形结构

### 怎么用

## 单调栈模板

```python
def monotonic_stack(nums, mode='increasing'):
    """
    mode: 'increasing' 保持递增，'decreasing' 保持递减
    返回每个元素对应的 Next Greater Element
    """
    stack = []  # 存放下标
    result = [-1] * len(nums)

    for i in range(len(nums)):
        # 保持单调性
        while stack and (mode == 'increasing' and nums[stack[-1]] < nums[i]
                        or mode == 'decreasing' and nums[stack[-1]] > nums[i]):
            index = stack.pop()
            result[index] = nums[i]
        stack.append(i)

    return result
```

## Next Greater Element

### 下一个更大元素 I

**LeetCode 496**: nums1 是 nums2 的子集，对 nums1 中每个元素找在 nums2 中的下一个更大元素。

```python
def next_greater_element(nums1, nums2):
    """
    思路：单调递减栈，栈中存元素，遇到更大则匹配
    时间复杂度: O(m + n)
    """
    stack = []
    next_greater = {}
    for num in nums2:
        while stack and stack[-1] < num:
            next_greater[stack.pop()] = num
        stack.append(num)
    # 栈中剩余元素无更大元素
    for num in stack:
        next_greater[num] = -1
    return [next_greater[num] for num in nums1]
```

### 下一个更大元素 II（循环数组）

**LeetCode 503**: 数组是环形的，需要遍历两遍。

```python
def next_greater_element_ii(nums):
    """
    思路：遍历两遍，模拟环形数组
    时间复杂度: O(n)
    """
    n = len(nums)
    result = [-1] * n
    stack = []  # 存放下标

    for i in range(2 * n):
        idx = i % n
        while stack and nums[stack[-1]] < nums[idx]:
            result[stack.pop()] = nums[idx]
        if i < n:  # 只在第一遍时入栈
            stack.append(idx)
    return result
```

### 每日温度（下一个更大元素的距离）

**LeetCode 739**: 返回需要等待多少天才能等到更高温度。

```python
def daily_temperatures(temps):
    """
    思路：栈中存放下标，遇到更高温度则计算距离
    时间复杂度: O(n)
    """
    n = len(temps)
    result = [0] * n
    stack = []  # 存放下标

    for i in range(n):
        while stack and temps[stack[-1]] < temps[i]:
            prev = stack.pop()
            result[prev] = i - prev
        stack.append(i)
    return result
```

## 柱状图中最大的矩形

**LeetCode 84**: 计算柱状图中最大矩形面积。

**思路**：枚举每个柱形为最低高度，向左右扩展。使用单调递增栈。

**时间复杂度**: O(n)

```python
def largest_rectangle_area(heights):
    """
    思路：单调递增栈，栈中元素代表还未找到右边更小柱子的索引
    - 入栈时：当前柱比栈顶高，继续扩展
    - 出栈时：当前柱比栈顶低，栈顶作为最低柱子的矩形可以确定
    """
    heights = [0] + heights + [0]  # 哨兵，左右各加一个0
    stack = [0]  # 栈中存放下标
    max_area = 0

    for i in range(1, len(heights)):
        while heights[i] < heights[stack[-1]]:
            h = heights[stack.pop()]  # 弹出柱子的高度
            w = i - stack[-1] - 1     # 宽度
            max_area = max(max_area, h * w)
        stack.append(i)
    return max_area
```

**图解**：
```
 heights:    [2,1,5,6,2,3]
             ↓
 栈变化:     [0]
             ↓
 遇到 1:     pop 0 (h=2, w=0) → area=0
             [1]
             ↓
 遇到 5,6:   [1,2,3]
             ↓
 遇到 2:     pop 3 (h=6, w=1) → area=6
             pop 2 (h=5, w=3) → area=15
             [1,4]
             ↓
 遇到 3:     [1,4,5]
 结果: max_area = 15
```

## 移去 K 位数字

**LeetCode 402**: 移除 k 位数字使结果最小。

**思路**：保持单调递增，移除比后续数字大的数字

```python
def remove_k_digits(num, k):
    """
    思路：单调递增栈，移除比后续大的数字
    时间复杂度: O(n)
    """
    stack = []
    for digit in num:
        while k and stack and stack[-1] > digit:
            stack.pop()
            k -= 1
        stack.append(digit)

    # 如果还没移除够k个，从末尾移除
    while k:
        stack.pop()
        k -= 1

    # 去除前导零
    result = ''.join(stack).lstrip('0')
    return result if result else '0'
```

## 最短无序连续子数组

**LeetCode 581**: 找出最短的无序子数组长度，排序后整个数组有序。

```python
def find_unsorted_subarray(nums):
    """
    思路：
    1. 从左到右找最后一个破坏递增的索引 right
    2. 从右到左找第一个破坏递减的索引 left
    3. 收缩区间确保覆盖所有需要排序的元素
    时间复杂度: O(n)
    """
    n = len(nums)
    stack = []

    # 从左到右找右边界
    left = n
    for i in range(n):
        while stack and nums[stack[-1]] > nums[i]:
            left = min(left, stack.pop())
        stack.append(i)

    if left == n:  # 已经有序
        return 0

    # 从右到左找左边界
    right = 0
    stack = []
    for i in range(n - 1, -1, -1):
        while stack and nums[stack[-1]] < nums[i]:
            right = max(right, stack.pop())
        stack.append(i)

    return right - left + 1
```

### 饥饿的兔子（社交距离）

```python
def min_intervals(intervals):
    """
    合并区间，找最小间隔
    """
    intervals.sort()
    stack = [intervals[0]]

    for interval in intervals[1:]:
        if interval[0] <= stack[-1][1]:
            stack[-1][1] = max(stack[-1][1], interval[1])
        else:
            stack.append(interval)

    # 使用单调栈找最小间隔
    min_gap = float('inf')
    for i in range(1, len(stack)):
        min_gap = min(min_gap, stack[i][0] - stack[i-1][1])
    return min_gap if min_gap != float('inf') else -1
```
