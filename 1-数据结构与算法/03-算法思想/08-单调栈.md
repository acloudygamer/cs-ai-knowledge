# 单调栈

## 定义

单调栈是维护序列单调性的栈结构，每个元素最多入栈一次、出栈一次，在 $O(n)$ 时间内解决"下一个更大/更小元素"问题。其本质是利用栈的 LIFO（后进先出）特性，在一次遍历中完成所有元素的答案计算。

## 数学模型

### 时间复杂度分析

令 $n$ 为序列长度。每个元素最多执行一次 push 和一次 pop，总操作数为 $2n$，故时间复杂度为 $O(n)$。

均摊分析：
$$\sum \text{push} = n, \quad \sum \text{pop} \leq n$$
$$\text{总操作} = O(n)$$

### 空间复杂度

最坏情况：序列单调（递增或递减），所有元素压在栈中，空间为 $O(n)$。

最优情况：每次 push 后立即 pop，空间为 $O(1)$。

### 单调性的形式化定义

对于递增栈 $S = [s_0, s_1, ..., s_k]$（$s_0$ 为栈底，$s_k$ 为栈顶）：
$$s_0 < s_1 < ... < s_k \quad \text{或} \quad s_0 > s_1 > ... > s_k \text{（递减栈）}$$

栈内保存的是**下标**，但隐含了值的单调性约束。

**归约终点**：单调栈是**状态机的一种特例**。栈的状态表示"当前未找到答案的元素序列"，新元素的到来触发状态转移（pop/push），弹出瞬间即为该元素找到答案。

## 数据流

<pre>
问题：求下一个更大元素 (Next Greater Element)
nums = [2, 1, 2, 4, 3]

遍历过程:
i=0, val=2:  stack=[]         → push(0),    stack=[0]
i=1, val=1:  nums[0]=2 > 1    → 不pop      → push(1),   stack=[0,1]
i=2, val=2:  nums[1]=1 < 2    → pop(1),    next[1]=2  → stack=[0]
              nums[0]=2 == 2   → 不pop      → push(2),   stack=[0,2]
i=3, val=4:  nums[2]=2 < 4    → pop(2),    next[2]=4  → stack=[0]
              nums[0]=2 < 4    → pop(0),    next[0]=4  → stack=[]
              push(3),                     stack=[3]
i=4, val=3:  nums[3]=4 > 3    → 不pop      → push(4),   stack=[3,4]

栈剩余元素（无更大右侧元素）:
next[3]=-1, next[4]=-1

输出: next = [4, 2, 4, -1, -1]

数据形态变换:
nums[i] (输入值) → 与栈顶元素比较 (比较) → pop触发时记录答案 (更新) → push下标 (入栈)
</pre>

循环数组（下一个更大元素，遍历两遍）:
nums = [2,1,2,4,3], 求每个元素的下一个更大元素（含循环）

第一遍：同普通遍历
第二遍：从栈中弹出剩余元素（此时 i 已越界，只pop不push）

第一遍结束时 stack=[3,4]
第二遍: i=0→4 已处理完，栈中元素弹出:
  pop(4): next[4] = -1 (因为循环查找后无更大)
  pop(3): next[3] = -1

## 机制

### 单调性保证正确性的核心引理

引理：对于递增栈，当元素 $x$ 入栈时，栈中所有比 $x$ 小的元素 $y$ 的"下一个更大元素"已确定为 $x$。

证明：$y$ 在 $x$ 左侧，且 $y < x$。由于栈的递增性，在 $y$ 和 $x$ 之间不存在其他比 $y$ 大的未处理元素（否则栈不会保持递增）。因此 $x$ 是 $y$ 的右侧第一个比 $y$ 大的元素。

### 遮挡效应（Masking Effect）

当 $x$ 入栈后，所有比 $x$ 小的栈内元素被 $x$ "遮挡"——它们不会再成为任何后续元素的"下一个更大"，因为 $x$ 更近且更大。

这意味着：
1. 每个元素最多 pop 一次（不可能被 pop 两次）
2. pop 发生时，当前遍历的元素就是被 pop 元素的答案

### 栈内存储下标的必要性

栈内存储值会导致"相等元素"的答案计算出现歧义。若存储下标：
- 可以区分元素的先后位置
- 可以计算"距离"（答案与原元素的索引差）

存储下标的另一个原因：答案数组需要用索引赋值，而非值。

### 循环数组的处理

循环数组是线性序列的首尾相邻扩展。处理方法：
1. 遍历 $2n$ 次（将序列复制拼接）
2. 或遍历 $n$ 次，使用 $(i+1) \bmod n$ 探测右侧
3. 第二遍遍历只弹栈不 push（避免重复入栈）

关键约束：循环数组中，每个元素只能作为"下一个更大"被查找一次，不能在第二遍被重复处理。

### 典型应用场景

1. **柱状图最大矩形**：枚举每个柱作为最低高度，向左向右扩展找到第一个更低的柱。单调栈可在 $O(n)$ 内找到每个柱的左右边界。

2. **每日温度**（LeetCode 739）：将"更低温度出现的天数差"作为答案，递减栈存储温度偏低的日子。

3. **移去 K 位数字**（LeetCode 402）：维持递增栈，移除破坏递增性的数字，确保结果字典序最小。

4. **去除重复字母**（LeetCode 316）：类似思路，但需额外计数数组确保每个字符都被保留。

### 约束条件与违反后果

- 栈内单调性必须严格：若出现 $s_k \leq x$ 而非 $s_k < x$，会导致相等元素的答案错误（对于"严格更大"问题）。
- 循环数组第二遍不可 push：若第二遍仍 push，会导致元素被重复处理，答案覆盖错误。
- 必须处理栈残留：遍历结束后，栈内剩余元素无答案（设为 -1 或特殊值）。

def next_greater(nums):
    n = len(nums)
    res = [-1] * n
    stack = []
    for i in range(n):
        while stack and nums[stack[-1]] < nums[i]:
            res[stack.pop()] = nums[i]
        stack.append(i)
    return res

def next_greater_circular(nums):
    n = len(nums)
    res = [-1] * n
    stack = []
    for i in range(2 * n):
        idx = i % n
        while stack and nums[stack[-1]] < nums[idx]:
            if stack[-1] < n:
                res[stack.pop()] = nums[idx]
            else:
                stack.pop()
        if i < n:
            stack.append(i)
    return res

def largest_rectangle_in_histogram(heights):
    heights = [0] + heights + [0]
    stack = [0]
    max_area = 0
    for i in range(1, len(heights)):
        while stack and heights[stack[-1]] > heights[i]:
            h = heights[stack.pop()]
            w = i - stack[-1] - 1
            max_area = max(max_area, h * w)
        stack.append(i)
    return max_area
