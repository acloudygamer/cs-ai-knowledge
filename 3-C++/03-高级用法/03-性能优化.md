# 性能优化

> **版本关系**：C++11（基础）→ C++17（C++20 无直接相关）→ C++23/26

## 定义

**性能优化是在硬件约束下最小化数据移动和指令执行的代价。** 现代 CPU 的性能瓶颈从计算转向内存访问和分支预测，性能优化本质上是**让程序的行为符合硬件假设**。

三个核心维度：
- **计算密度**：每字节内存传输完成的运算次数
- **内存层次利用率**：缓存命中率与内存带宽利用率
- **指令级并行**：流水线占用率和 SIMD 利用率

## 数学模型

### Roofline 模型

Roofline 模型给出理论性能上界：

$$\text{Performance}( \text{FLOPS}) = \min \left( \text{Peak}_{\text{FLOPS}},\ \text{Bandwidth} \times \text{AI} \right)$$

其中 $\text{AI} = \frac{\text{FLOPs}}{\text{Bytes}}$ 是算术强度（Arithmetic Intensity）。

```
        FLOPS
         ^
   Peak  |'''''''''''
        |            '''. 内存带宽限制区
        |                  '''
  R     |                      '''
 O      |                          '''
 O      |                              '''
 F      |                                  '''
 L      |                                      '''
 I      |                                          '''
 N      |                                              '''
 E      |                                                  '''
        +------------------------------------------------->
             AI (FLOPs/Byte)
```

**访问模式分类**：
- **计算限制**（左侧）：AI 足够高，接近峰值 FLOPS
- **内存限制**（右侧）：AI 不足，带宽成为瓶颈

### 缓存未命中代价

分层缓存的未命中代价：

$$T_{access} = T_{hit} + \sum_{i} M_i \times P_i$$

其中 $M_i$ 是第 $i$ 层缓存的未命中次数，$P_i$ 是第 $i$ 层的惩罚周期数。

典型的缓存层次：
| 层级 | 大小 | 访问延迟 | 未命中惩罚 |
|------|------|----------|------------|
| L1   | 32KB | 4 cycles | ~10 cycles |
| L2   | 256KB | 12 cycles | ~40 cycles |
| L3   | 8MB | ~40 cycles | ~100+ cycles |
| 主存 | 数十 GB | ~200 cycles | — |

### SIMD 加速比

设向量长度为 $N$，SIMD 宽度为 $W$（如 AVX-512 的 $W=16$ 单精度浮点）：

$$S_{SIMD} = \frac{\text{串行执行时间}}{\text{SIMD 执行时间}} = \frac{N}{N/W} = W$$

实际加速比受限于：
- **数据依赖**：循环携带的依赖链阻止完全并行化
- **对齐要求**：未对齐内存访问触发微码降低效率
- **分散加载**：gather/scatter 远慢于连续加载

### 缓存友好的数据布局

**AoS（Array of Structure）**：
```cpp
struct Point { float x, y, z; };
Point points[N];
// 访问 points[i].x 时，x 和 y、z 同时加载（空间局部性差）
```

**SoA（Structure of Array）**：
```cpp
struct Points {
    float xs[N], ys[N], zs[N];
};
// 访问 xs[i] 时，只加载 xs 数组（空间局部性好）
```

内存传输量对比（设缓存行 64 字节，float 4 字节）：
- AoS：访问一个分量加载 64/sizeof(Point) = 16 个 Point，但只用一个字段
- SoA：访问一个分量加载 N 个 float，N 由缓存容量决定

## 机制

### 分支预测与流水线

CPU 流水线中，分支指令导致**控制流冒险**。分支预测器尝试在不知道目标时预测方向：

- **静态预测**：总是预测分支不跳转（x86 默认），或基于方向（向前跳预测不跳，向后跳预测跳）
- **动态预测**：记录分支历史表（BHT）、全局分支历史（GHR）、两级自适应等

分支未命中的代价：

$$\text{Penalty}_{mispredict} = \text{流水线深度} - \text{取指位置} \approx 15\!-\!20\ \text{cycles}$$

典型优化：
- **likely/unlikely 属性**：告知编译器分支方向，引导布局
- **条件mov**（cmov）：消除分支，数据流替代控制流
- **函数表跳转**：多路分支转换为索引跳转（O(1) 无分支）

### 内存带宽与访问模式

**内存带宽峰值**（典型值，桌面 CPU）：
- DDR4-3200 双通道：$\approx 50\ \text{GB/s}$
- L1 带宽：$\approx 1000\ \text{GB/s}$（内部）

**优化原则**：
1. **减少内存访问量**：压缩表示、移除冗余数据
2. **提高访问局部性**：分块、排序使相邻访问指向同一缓存行
3. **预取（Prefetch）**：在需要前主动加载数据到缓存

```cpp
// 手动预取：提前 3 个缓存行
for (int i = 0; i < N; ++i) {
    __builtin_prefetch(&a[i + 3], 0, 3);  // 预取读，预取级别 3
    // 处理 a[i]
}
```

### 编译期优化

**LTO（Link-Time Optimization）**：
- 传统编译：每个编译单元独立优化，跨单元函数调用形成边界
- LTO：链接时合并 LLVM bitcode，跨编译单元内联、死代码消除、常量传播

$$\text{优化收益} \propto \text{可见代码量}$$

**PGO（Profile-Guided Optimization）**：
- 第一阶段：插桩编译，运行获取真实分支/冷热路径
- 第二阶段：用真实数据重新优化

关键指标：
- **分支命中率**：`likely/unlikely` 与真实分布吻合时有效
- **函数内联收益**：叶函数优先内联，减少调用开销
- **循环展开**：减少分支频率，但增加代码体积

### 伪共享（False Sharing）

多线程修改**同一缓存行上的不同变量**导致性能退化：

```cpp
struct Counter { std::atomic<int> c; };  // 两个 atomic 相邻
Counter counters[4];  // 在同一缓存行

// 线程 0 修改 counters[0].c
// 线程 1 修改 counters[1].c
// 触发缓存行无效化震荡（cache line ping-pong）
```

解决：**填充（padding）** 使每个变量独占缓存行，或使用 `std::hardware_destructive_interference_size`（C++20）。

## 对比参照

| 属性 | AoS 布局 | SoA 布局 |
|------|----------|----------|
| 内存访问量（单分量访问） | 多（加载整个结构体） | 少（只加载目标数组） |
| 空间局部性 | 差（分量分散） | 好（同类数据连续） |
| 代码简洁度 | 高（自然语义） | 低（需独立数组） |
| 适用场景 | 少量对象、批量处理 | 大量对象、分量遍历 |

## 参考存根

```cpp
// SoA 布局优化的矩阵乘法
void matmul_soa(int N, const float* a, const float* b, float* c) {
    // b 是行优先，c 是行优先
    for (int i = 0; i < N; ++i) {
        for (int k = 0; k < N; ++k) {
            float aik = a[i*N + k];
            for (int j = 0; j < N; ++j) {
                c[i*N + j] += aik * b[k*N + j];
            }
        }
    }
}

// 对齐 + 手动 SIMD（AVX-512）
alignas(64) float a[1024], b[1024], c[1024];
for (int i = 0; i < 1024; i += 16) {
    __m512 va = _mm512_load_ps(&a[i]);
    __m512 vb = _mm512_load_ps(&b[i]);
    __m512 vc = _mm512_fmadd_ps(va, vb, _mm512_load_ps(&c[i]));
    _mm512_store_ps(&c[i], vc);
}
```
