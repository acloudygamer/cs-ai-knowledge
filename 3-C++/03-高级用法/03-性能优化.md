# 性能优化

> **版本关系**：C++11（基础）→ C++17（C++20 无直接相关）→ C++23/26

**性能优化是在缓存局部性、向量化、编译时优化三个维度上减少数据移动和指令开销。**

## 数学模型

缓存未命中惩罚公式：

$$
T_{miss} = T_{hit} + \frac{M}{B} \times L
$$

其中 $M$ 是工作集大小，$B$ 是缓存行大小，$L$ 是miss penalty。

SIMD 加速比：

$$
S_{SIMD} = \frac{N}{N/lanes} = lanes
$$

AVX-512 可达 16 FLOPS/cycle（float）。

   │                          │                          │

   │                          │                          │

</pre>

## 机制

**缓存友好的本质**：数据访问模式应符合空间局部性（访问地址N后倾向于访问N+1）和时间局部性（同一数据在短期内被多次访问）。AoS（Array of Structures）访问时加载无关字段，SoA（Structure of Arrays）只加载需要的字段。

**SIMD 向量化条件**：循环必须迭代次数已知、无控制流依赖、数据对齐。编译器对简单循环自动向量化，复杂情况需手动 intristics 或库。

**LTO 为什么有效**：传统编译单元隔离导致函数调用边界阻止跨函数优化（内联、死代码消除）。LTO 在链接时合并中间表示，编译器可看到完整程序。

**PGO 的核心价值**：编译器假设分支预测和冷热路径基于启发式，PGO 用真实运行数据替换假设，让编译器做出更准确的优化决策。

## 参考存根

```cpp
alignas(64) float a[1024], b[1024], c[1024];
for (int i = 0; i < 1024; i += 8) {
    __m256 va = _mm256_load_ps(&a[i]);
    _mm256_store_ps(&c[i], _mm256_add_ps(va, _mm256_load_ps(&b[i])));
}
```
