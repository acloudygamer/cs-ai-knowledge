# C++26 新特性

> **版本关系**：C++26（latest）

**C++26 是即将发布的新标准，核心特性是 std::execution 发送方-接收方接口和 Contracts 契约编程。**

## 定义

| 特性 | 一句话断言 |
|------|-----------|
| std::execution | 标准化的发送方-接收方并发接口，用管道操作符组合异步任务 |
| Contracts | 可执行的规格说明，前置/后置条件断言 |
| std::meta | 编译期反射能力（实验性） |

## 数据流

<pre>
std::execution 模型：
Sender ────→ Receiver
   │              │
   ├─ just(1)   ├─ then([](int x) { })
   ├─ when_all  ├─ let_error
   ├─ then      └─ sync_wait
   │
   └─ Scheduler（决定在哪里执行）
       ├─ inline_scheduler
       ├─ thread_pool_scheduler
       └─ system_scheduler
</pre>

## 机制

**std::execution 为什么重要**：C++20 协程和 Concurrency TS 的异步模型互不兼容，第三方库（ASIO、Folly）各自实现难以统一。std::execution 提供标准化的发送方-接收方接口，让所有异步/并行代码可以互操作。

**Contracts 的设计目标**：契约编程将运行时检查编译进代码，提供可执行的规格说明。`[[expects]]`/`[[ensures]]` 替代 assert 更精确，`[[assert]]` 用于代码内部检查。

**std::meta 反射的价值**：当前 C++ 反射只能通过宏或外部工具实现。std::meta 让编译器在编译期提供类型信息，支持代码生成、序列化框架等元编程场景。

## 参考存根

```cpp
auto r = std::execution::just(1) | std::execution::then([](int x) { return x * 2; });

int divide(int a, int b) [[expects b != 0]] { return a / b; }
```

|------|-----|-------|------|
| std::execution | 15+ | 19+ | 实现中 |

| Contracts | 14+ | 19+ | 实现中 |
