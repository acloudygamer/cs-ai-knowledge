# C++26 新特性 (<latest> 版本新增)

## std::execution：发送方-接收方接口（C++26）

C++20 协程和 Concurrency TS 提供的异步编程模型互不兼容，第三方库各有实现难以统一。std::execution 提供标准的发送方-接收方接口，统一所有异步和并行编程场景。

发送方（Sender）产生值或错误，接收方（Receiver）消费值或处理错误，调度器（Scheduler）决定任务在哪里执行。

> **注意**：C++26 标准库提供的是 sender/receiver 概念和算法，具体的调度器（如 inline_scheduler、thread_pool_scheduler）由实现库提供。

### 参考样例

```cpp
#include <execution>

// 发送方工厂
auto sender = std::execution::just(1, 2, 3, 4, 5);

// 管道操作组合
auto processed = sender
    | std::execution::then([](int x) { return x * 2; })
    | std::execution::then([](int x) { return x + 1; });

// when_all 组合多个发送方
auto combined = std::execution::when_all(
    std::execution::just(1),
    std::execution::just(2),
    std::execution::just(3)
);

// let_error 错误处理
auto with_error_handling = std::execution::just(1, 2, 3)
    | std::execution::let_error([](auto) {
        return std::execution::just(0);
    });
```

## Contracts

在函数调用前后验证前置条件和后置条件，在代码中嵌入可执行的规格说明。`[[expects]]` 声明前置条件，`[[ensures]]` 声明后置条件，`[[assert]]` 声明断言语句。

### 参考样例

```cpp
// 前置条件
int divide(int a, int b) [[expects b != 0]] {
    return a / b;
}

// 后置条件
int allocate(int size) [[ensures result: result > 0]] {
    int* p = new int(size);
    return size;
}

// 断言
void critical_operation() [[assert: some_condition]] {
    // ...
}
```

## std::meta：反射（实验性）

C++26 引入编译期反射能力，通过 `std::meta::info` 查询类型信息，支持编译期元编程。

> **注意**：`std::meta` 是实验性功能，GCC 不支持，Clang 19+ 有实验性支持。

### 参考样例

```cpp
#include <meta>

struct Point {
    int x;
    int y;
};

int main() {
    constexpr auto info = std::meta::info_of<Point>();
    constexpr auto members = std::meta::members_of(info);
    static_assert(members.size() == 2);

    constexpr auto type_name = std::meta::name_of(std::meta::info_of<Point>);
    static_assert(std::meta::name_of(std::meta::info_of<Point>) == "Point");
}
```

## 改进的 constexpr 支持（C++26）

constexpr new/delete 改进，现在支持在 constexpr 上下文中使用 new/delete 并 return 堆分配的值。

### 参考样例

```cpp
constexpr int* allocate_and_init() {
    int* p = new int(42);
    int val = *p;
    delete p;
    return val;
}
constexpr int x = allocate_and_init();  // 编译时执行
```

## 字符串拼接改进（C++26）

`std::basic_string` 与 `std::basic_string_view` 拼接，现在支持 `string + string_view`。

### 参考样例

```cpp
std::string s = "Hello";
std::string_view sv = " World";
std::string result = s + sv;  // C++26 支持
```

## 版本关系

| 特性 | C++23 | C++26 |
|------|-------|-------|
| std::expected | 基础版 | + monadic 操作 |
| std::generator | 非标准提案 | 标准化 |
| std::execution | 提案 | 合并标准 |
| Contracts | 无 | 新增 |
