# C++26 新特性

> **C++ 标准版本标记**：本文涵盖 C++26 新增特性，兼容 C++23 基础。代码示例均标注最低支持标准。
>

> - GCC 14+：部分支持
> - Clang 19+：部分支持

## std::execution：发送方-接收方接口（C++26）

`std::execution` 是 C++26 最重大的库增强，提供了统一的异步编程模型，取代了之前的 Concurrency TS。

### 核心概念

```cpp
#include <execution>

// 发送方（Sender）：产生值或错误
// 接收方（Receiver）：消费值或处理错误
// 调度器（Scheduler）：决定任务在哪里执行
```

### 发送方/接收方模式

```cpp
#include <execution>
#include <iostream>

// 发送方：产生值
auto ints = std::execution::just(1, 2, 3, 4, 5);

// 接收方：消费值
struct Consumer {
    std::execution::receiver_adaptor<
        std::execution::set_value_t(int, int, int, int, int),
        std::execution::set_error_t(std::exception_ptr),
        std::execution::set_stopped_t()
    > impl;

    friend void std::execution::set_value(Consumer&& c, int a, int b, int c_, int d, int e) {
        std::cout << "Got: " << a << " " << b << " " << c_ << " " << d << " " << e << "\n";
    }
};
```

### 调度器类型

```cpp
#include <execution>
#include <thread>

// inline_scheduler：同步执行
struct inline_scheduler {
    friend auto std::execution::schedule(inline_scheduler) {
        return std::execution::just();
    }
};

// thread_pool_scheduler：线程池执行
struct thread_pool_scheduler {
    friend auto std::execution::schedule(thread_pool_scheduler) {
        // 返回在线程池执行的发送方
    }
};
```

### 发送方算法组合

```cpp
#include <execution>
#include <vector>

// then：转换值
auto doubled = std::execution::just(42)
    | std::execution::then([](int x) { return x * 2; });

// when_all：组合多个发送方
auto combined = std::execution::when_all(
    std::execution::just(1),
    std::execution::just(2),
    std::execution::just(3)
);

// let_error：错误处理
auto with_error_handling = std::execution::just(1, 2, 3)
    | std::execution::let_error([](auto) {
        return std::execution::just(0);  // 出错时返回默认值
    });
```

### 实际应用：并行计算

```cpp
#include <execution>
#include <vector>
#include <numeric>

std::vector<int> data(1000);
std::iota(data.begin(), data.end(), 1);

// 并行求和
auto sum_sender = std::execution::just(data)
    | std::execution::transform([](const std::vector<int>& v) {
        return std::reduce(std::execution::par, v.begin(), v.end());
    });

auto [result] = std::this_thread::sync_wait(sum_sender).value();
```

### 与 C++20/C++23 对比

| 特性 | std::async | C++23 协程 | std::execution |
|------|------------|------------|----------------|
| 组合性 | 差 | 好 | 最好 |
| 错误处理 | future.get() | co_await | sender/receiver |
| 调度控制 | 有限 | 自定义 | 完全可控 |
| 标准支持 | C++11 | C++20 | C++26 |

## std::meta：反射（实验性）

C++26 引入了编译期反射能力，可以通过 `std::meta::info` 查询类型信息，支持编译期元编程。

### 基础反射查询

```cpp
#include <meta>
#include <iostream>

struct Point {
    int x;
    int y;
};

int main() {
    // 反射获取类型信息
    constexpr auto info = std::meta::info_of<Point>();

    // 获取成员变量
    constexpr auto members = std::meta::members_of(info);

    std::cout << "Point has " << members.size() << " members\n";
}
```

### 类型名称反射

```cpp
#include <meta>
#include <iostream>

struct MyStruct {
    int value;
    double data;
};

int main() {
    // 获取类型的名字
    constexpr auto type_name = std::meta::name_of(std::meta::info_of<MyStruct>());

    // 在编译期验证类型名称
    static_assert(std::meta::name_of(std::meta::info_of<MyStruct>) == "MyStruct");
}
```

### 成员信息查询

```cpp
#include <meta>

struct User {
    std::string name;
    int age;
    double salary;
};

int main() {
    constexpr auto user_info = std::meta::info_of<User>();
    constexpr auto members = std::meta::members_of(user_info);

    // 遍历成员变量
    []<size_t... Is>(std::index_sequence<Is...>) {
        ((std::cout << std::meta::name_of(members[Is]) << "\n"), ...);
    }(std::make_index_sequence<members.size()>{});
}
```

### 编译期代码生成模式

```cpp
#include <meta>
#include <array>

// 编译期生成序列化代码
template<typename T>
constexpr auto get_member_names() {
    constexpr auto members = std::meta::members_of(std::meta::info_of<T>);
    std::array<std::string_view, members.size()> names;
    []<size_t... Is>(auto& arr, auto& mems, std::index_sequence<Is...>) {
        ((arr[Is] = std::meta::name_of(mems[Is])), ...);
    }(arr, members, std::make_index_sequence<members.size()>{});
    return arr;
}

// 编译期生成 JSON 序列化
template<typename T>
std::string serialize(const T& obj) {
    // 使用反射获取成员...
}
```

### 实际应用：自动比较运算符

```cpp
#include <meta>

// 使用反射自动生成 operator==
template<typename T>
bool auto_equal(const T& a, const T& b) {
    constexpr auto members = std::meta::members_of(std::meta::info_of<T>);
    return []<size_t... Is>(const T& a, const T& b, auto& mems, std::index_sequence<Is...>) {
        return ((a.*mems[Is].ptr == b.*mems[Is].ptr) && ...);
    }(a, b, members, std::make_index_sequence<members.size()>{});
}
```

### 限制与注意事项

```cpp
// 反射的当前限制：
// 1. 无法通过反射修改原始类型定义
// 2. 私有成员访问受限
// 3. 函数指针和静态成员需要特殊处理

// 推荐使用场景：
// - 自动化代码生成（序列化、日志）
// - 调试和诊断工具
// - 领域特定语言（DSL）实现
```

## 改进的 constexpr 支持

### constexpr new/delete（C++26）

C++26 改进了 constexpr 上下文中使用 new/delete 的能力：

```cpp
constexpr int* allocate_and_init() {
    int* p = new int(42);
    int val = *p;
    delete p;
    return val;  // 可以 return 堆分配的值
}

constexpr int x = allocate_and_init();  // 编译时执行
```

### constexpr std::vector（C++23 已支持）

constexpr std::vector 在 C++23 中已可用，C++26 继续改进：

```cpp
constexpr auto create_and_use_vector() {
    std::vector<int> v;
    v.push_back(1);
    v.push_back(2);
    v.push_back(3);

    // 可以在编译期迭代
    int sum = 0;
    for (int x : v) {
        sum += x;
    }
    return sum;
}

constexpr int result = create_and_use_vector();  // 编译时求值（C++23）
```

## std::not_fn 改进（C++26）

`std::not_fn` 现在支持静态调用运算符：

```cpp
#include <functional>
#include <iostream>

struct Pred {
    bool operator()(int x) const { return x > 0; }
};

int main() {
    auto not_pred = std::not_fn(Pred{});

    std::cout << std::boolalpha;
    std::cout << not_pred(5) << "\n";   // false
    std::cout << not_pred(-5) << "\n";  // true
}
```

### std::hash for std::chrono::weekday（C++26）

```cpp
#include <chrono>
#include <functional>
#include <unordered_set>

int main() {
    std::unordered_set<std::chrono::weekday> holidays;

    holidays.insert(std::chrono::Sunday);
    holidays.insert(std::chrono::Saturday);

    // 现在可以正常工作了
    std::hash<std::chrono::weekday> hasher;
    std::size_t h = hasher(std::chrono::Monday);
}
```

## 与 C++23 的关系

C++26 在 C++23 基础上继续发展：

| 特性 | C++23 | C++26 |
|------|-------|-------|
| std::expected | 基础版 | + monadic 操作 |
| std::generator | 实验性 | 标准化 |
| std::print | 支持 | 改进 |
| std::execution | 提案 | 合并标准 |

```cpp
// C++23 std::expected
std::expected<int, Error> parse_int(const std::string& s);

// C++26 可以这样链式调用
auto result = parse_int(s)
    .transform([](int x) { return x * 2; })
    .and_then([](int x) { return process(x); });
```

## 迁移指南

### 从 C++23 迁移到 C++26

1. **异步代码**：考虑使用 `std::execution` 替代自定义协程框架
2. **反射**：使用 `std::meta` 替代手动的类型注册系统
3. **编译期计算**：C++26 改进了 constexpr new/delete 等特性

```cpp
// C++26 改进了 constexpr new/delete
constexpr int* allocate_and_init() {
    int* p = new int(42);  // C++26 改进
    int val = *p;
    delete p;              // C++26 改进
    return val;
}
```
