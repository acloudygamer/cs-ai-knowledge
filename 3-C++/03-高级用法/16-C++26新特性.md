# C++26 新特性

C++26 是 C++ 标准化的重要里程碑，引入了反射、改进的异步编程模型和核心语言增强。

> **编译器支持注意**：C++26 特性正在由主流编译器实现中，部分功能可能尚未完全支持。
> - GCC 14+：部分支持
> - Clang 19+：部分支持
> - MSVC 19.29+：部分支持
> 如需生产环境使用，请查阅 [cppreference.com](https://en.cppreference.com/w/cpp/compiler_support) 获取最新支持情况。

## std::execution：发送方-接收方接口（C++26）

`std::execution` 是 C++26 最重大的库增强，提供了统一的异步编程模型。

### 核心概念

```cpp
#include <execution>

// 发送方（Sender）：产生值或错误
// 接收方（Receiver）：消费值或处理错误
// 调度器（Scheduler）：决定任务在哪里执行
```

### 调度器示例

```cpp
#include <execution>
#include <iostream>
#include <thread>

// 使用 run_loop 作为调度器
class single_thread_context {
    std::execution::run_loop loop_;
    std::jthread thread_;

public:
    single_thread_context() : thread_([this] { loop_.run(); }) {}
    ~single_thread_context() { loop_.finish(); }

    auto get_scheduler() noexcept {
        return loop_.get_scheduler();
    }
};

int main() {
    single_thread_context ctx;

    // 提交异步任务
    auto snd = std::execution::schedule(ctx.get_scheduler())
        | std::execution::then([] {
            std::cout << "Task executed\n";
            return 42;
        });

    auto [result] = std::this_thread::sync_wait(snd).value();
    std::cout << "Result: " << result << "\n";
}
```

### 发送方算法

```cpp
#include <execution>
#include <vector>

// 并行算法 - 使用 bulk sender adaptor
std::vector<int> data = {1, 2, 3, 4, 5};

auto result = std::execution::just() |
    std::execution::bulk(data.size(), [&data](auto idx) {
        data[idx] *= 2;
    });
```

## std::meta：反射（实验性）

C++26 引入了编译期反射能力，可以通过 `std::meta::info` 查询类型信息。

### 基础反射查询

```cpp
#include <meta>
#include <iostream>

struct Point {
    int x;
    int y;
};

int main() {
    // 反射获取类型信息
    constexpr auto info = std::meta::info_of<Point>();

    // 获取成员变量
    constexpr auto members = std::meta::members_of(info);

    std::cout << "Point has " << members.size() << " members\n";
}
```

### 类型名称反射

```cpp
#include <meta>
#include <iostream>

struct MyStruct {
    int value;
    double data;
};

int main() {
    // 获取类型的名字
    constexpr auto type_name = std::meta::name_of<std::meta::info_of<MyStruct>>();

    // 在编译期打印（通过 requires）
    static_assert(std::meta::name_of(std::meta::info_of<MyStruct>) == "MyStruct");
}
```

## 改进的 constexpr 支持

### constexpr new/delete（C++26）

C++26 改进了 constexpr 上下文中使用 new/delete 的能力：

```cpp
constexpr int* allocate_and_init() {
    int* p = new int(42);
    int val = *p;
    delete p;
    return val;  // 可以 return 堆分配的值
}

constexpr int x = allocate_and_init();  // 编译时执行
```

### constexpr std::vector（C++23 已支持）

constexpr std::vector 在 C++23 中已可用，C++26 继续改进：

```cpp
constexpr auto create_and_use_vector() {
    std::vector<int> v;
    v.push_back(1);
    v.push_back(2);
    v.push_back(3);

    // 可以在编译期迭代
    int sum = 0;
    for (int x : v) {
        sum += x;
    }
    return sum;
}

constexpr int result = create_and_use_vector();  // 编译时求值（C++23）
```

## std::not_fn 改进（C++26）

`std::not_fn` 现在支持静态调用运算符：

```cpp
#include <functional>
#include <iostream>

struct Pred {
    bool operator()(int x) const { return x > 0; }
};

int main() {
    auto not_pred = std::not_fn(Pred{});

    std::cout << std::boolalpha;
    std::cout << not_pred(5) << "\n";   // false
    std::cout << not_pred(-5) << "\n";  // true
}
```

## std::chrono 改进

### std::hash for std::chrono::weekday（C++26）

```cpp
#include <chrono>
#include <functional>
#include <unordered_set>

int main() {
    std::unordered_set<std::chrono::weekday> holidays;

    holidays.insert(std::chrono::Sunday);
    holidays.insert(std::chrono::Saturday);

    // 现在可以正常工作了
    std::hash<std::chrono::weekday> hasher;
    std::size_t h = hasher(std::chrono::Monday);
}
```

```cpp
int main() {
```

## 核心语言增强

### 属性改进

```cpp
// [[no_unique_address]] 改进（C++26）
// 现在可以更方便地用于空类型

struct Empty {};

struct Packed {
    [[no_unique_address]] Empty e;
    int value;
};

static_assert(sizeof(Packed) == sizeof(int));

// [[likely]] / [[unlikely]] 扩展（C++26）
// 现在可以用于 if 和 switch

if (condition) [[likely]] {
    // 预期执行路径
}
```

### decltype(auto) 改进

```cpp
// C++26 对 decltype(auto) 有更好的推断

template<typename T>
auto&& helper(T&& t) {
    return static_cast<decltype(auto)>(t);
}
```


## 与 C++23 的关系

C++26 在 C++23 基础上继续发展：

| 特性 | C++23 | C++26 |
|------|-------|-------|
| std::expected | 基础版 | + monadic 操作 |
| std::generator | 实验性 | 标准化 |
| std::print | 支持 | 改进 |
| std::execution | 提案 | 合并标准 |

```cpp
// C++23 std::expected
std::expected<int, Error> parse_int(const std::string& s);

// C++26 可以这样链式调用
auto result = parse_int(s)
    .transform([](int x) { return x * 2; })
    .and_then([](int x) { return process(x); });
```

## 迁移指南

### 从 C++23 迁移到 C++26

1. **异步代码**：考虑使用 `std::execution` 替代自定义协程框架
2. **反射**：使用 `std::meta` 替代手动的类型注册系统
3. **编译期计算**：C++26 改进了 constexpr new/delete 等特性

```cpp
// C++26 改进了 constexpr new/delete
constexpr int* allocate_and_init() {
    int* p = new int(42);  // C++26 改进
    int val = *p;
    delete p;              // C++26 改进
    return val;
}
```
