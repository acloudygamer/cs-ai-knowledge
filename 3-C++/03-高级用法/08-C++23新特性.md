# C++23 新特性

> **版本关系**：C++23（latest）→ C++26（std::execution）

**C++23 是对 C++20 的大幅补充：std::expected 函数式错误处理、mdspan 多维数组视图、std::flat_map 缓存友好容器、constexpr 全面增强。**

## 定义

C++23 新特性是一组在编译期或运行期为特定领域（错误处理、科学计算、容器设计）提供更精确抽象的机制。每种机制都解决一个已有实践中被反复验证的痛点：异常的性能不确定性、数组索引的手工计算、容器遍历的缓存失效。

| 特性 | 本质操作 | 核心约束 |
|------|----------|----------|
| std::expected | 错误值的代数类型构造 | 必须被调用者检查，否则未定义行为 |
| std::flat_map | 用两块平行向量替代树节点指针 | 查找 O(log n)，插入 O(n)，但缓存命中率高 |
| std::mdspan | 多维索引的空间映射 | 底层数据布局必须与访问模式匹配 |
| std::print | 格式化字符串的直接输出 | 线程安全（内部使用锁或原子操作） |
| std::ranges::to | 惰性视图的物化 | 不能用于无限范围 |

## 数学模型

### std::expected 的语义代数

expected<T, E> 本质上是 **Tagged Union**（标签联合）：在任意时刻，对象要么持有 T 类型的值（OK 状态），要么持有 E 类型的错误（Error 状态），二者互斥。

$\text{expected}_{T,E} \cong \text{OK}: T \mid \text{Error}: E$

Check 操作构成一个 **Kleene 三明治**：

$$
\text{and\_then}_f(v) = \begin{cases}
\text{Some}(f(v)) & \text{if } v \in \text{Some} \\
\text{None}(e) & \text{if } v \in \text{Error}(e)
\end{cases}
$$

这保证了错误状态的短路求值（short-circuit evaluation），等价于 Monad 的 bind 操作。

### std::flat_map 的缓存局部性

设 flat_map 存储 $n$ 个键值对，内存布局为：

$$
\text{keys}: \underbrace{k_0, k_1, \dots, k_{n-1}}_{\text{连续内存}} \quad
\text{values}: \underbrace{v_0, v_1, \dots, v_{n-1}}_{\text{连续内存}}
$$

二分查找的比较次数为 $\lceil \log_2 n \rceil$ 。但由于 keys 连续分布，每次比较后加载下一个 cache line 的概率 $p \to 1$ （空间局部性）。相比红黑树（节点分散，随机访问导致 cache miss 率 $\approx 1$ ），flat_map 的有效比较时间常数更小。

### std::mdspan 的索引映射

对于 $d$ 维 mdspan，索引元组 $(i_0, i_1, \dots, i_{d-1})$ 到线性地址的映射取决于 **layout policy**：

- **layout_left**（列优先，Fortran 风格）： $\text{addr} = \sum_{k=0}^{d-1} i_k \prod_{j=0}^{k-1} \text{extents}_j$
- **layout_right**（行优先，C 风格）： $\text{addr} = \sum_{k=0}^{d-1} i_k \prod_{j=k+1}^{d-1} \text{extents}_j$
- **layout_stride**（任意步长）： $\text{addr} = \sum_{k=0}^{d-1} i_k \cdot \text{stride}_k$

NumPy 默认 row-major（C 风格），即 layout_right。mdspan 让 C++ 可以直接使用与 Fortran/MATLAB 相同的数据结构而不需要手动计算偏移。

**所有权流转（以 expected 为例）**：

1. 调用 `parse()` → 返回 expected 对象（值或错误语义）
2. 调用者用 `.and_then()` 链式处理 → 若 OK，执行回调，返回新 expected；若 Error，短路跳过
3. 最终调用 `.value()` 或 `.error()` 提取语义

## 机制

### std::expected 为什么重要

C++ 错误处理三足鼎立：
- **异常**：性能不确定（栈展开、析构函数执行），且易被调用者忽略
- **错误码（int/enum）**：调用者必须显式检查，但嵌套检查导致金字塔地狱
- **std::error_code**：需要额外的错误域定义，系统调用专用

expected<T, E> 提供第四种：强制检查的函数式组合子。等价于 Rust 的 `Result<T, E>`，Haskell 的 `Either e t`。

**约束条件**：
- `.value()` 在 Error 状态调用时抛出 `std::bad_expected_access<E>`
- `.error()` 在 OK 状态调用时行为未定义
- 未定义行为不等于崩溃——但调试困难，应避免

### std::flat_map 的取舍

flat_map 的本质是 **以时间换空间（缓存命中率）**：

| 操作 | std::map (红黑树) | std::flat_map (两向量) |
|------|-------------------|------------------------|
| 查找 | O(log n)，指针跳转 | O(log n)，二分 |
| 插入 | O(log n)，指针更新 | O(n)，元素移动 |
| 删除 | O(log n)，指针更新 | O(n)，元素移动 |
| 缓存 | 差（节点分散） | 好（连续） |

插入/删除 O(n) 但缓存命中率高，对于 **读多写少** 或 **需要 scan all** 的场景更优。

### std::mdspan 与 BLAS 互操作性

科学计算中，矩阵乘法（GEMM）是 BLAS 的核心操作，接口约定：
- 矩阵按列存储（Fortran）
- 步长（lda/ldb/ldc）指定每行跨度

mdspan 可以直接建模这个接口：

```cpp
std::mdspan<double, std::extents<size_t, std::dynamic_extent, std::dynamic_extent>,
                       std::layout_left>
    A(a_ptr, m, k);  // m×k 列优先矩阵
```

这使得 C++23 可以直接与 cuBLAS、MKL 等高性能线性代数库互操作，无需数据拷贝。

### std::print 的同步机制

std::print 在多线程环境下必须保证输出不交织。实现通常采用：
- 每个输出流关联一个 mutex（传统 iostream 的做法，性能差）
- 或者使用 `print_lock` 全局锁
- 未来可能演进为 lock-free 环形缓冲区

## 对比参照

| 特性 | C++20 替代方案 | C++23 改进 | 适用场景 |
|------|---------------|------------|----------|
| std::expected | `std::optional`（只能表示"无值"） | 函数式错误组合子（and_then/or_else/transform） | 需要携带错误信息的失败场景 |
| std::flat_map | `std::map`（树节点指针跳转） | 连续内存布局，二分查找 | 读多写少、缓存敏感 |
| std::mdspan | 手写 stride 计算 | 类型级 layout policy | 科学计算、矩阵操作 |
| std::ranges::to | `std::vector(v.begin(), v.end())` | 一行物化，支持集合类型构造 | 视图转容器 |
| std::print | `printf`/`std::cout` | 类型安全 + 格式化简洁 | 所有输出场景 |

## 参考存根

```cpp
#include <expected>
#include <print>
#include <mdspan>
#include <flat_map>

std::expected<int, std::string> parse(int x) {
    if (x >= 0) [[likely]] return x;
    return std::unexpected("negative value: " + std::to_string(x));
}

// 链式组合子
auto result = parse(-5)
    .and_then([](int v) { return std::expected<int, std::string>(v * 2); })
    .or_else([](auto) { return std::expected<int, std::string>(0); });

// mdspan 多维视图
std::array<int, 15> a{/*...*/};
std::mdspan<int, std::extents<size_t, 5, 3>> matrix(a.data());
int val = matrix[2, 1];  // 直观访问

// std::print 格式化输出
std::print("{:05.2f}\n", 3.14);
```

---

**归约终点**：C++23 的各特性可归约为：
- expected → 代数数据类型（Tagged Union + Monad）
- flat_map → 向量二分搜索 + 元素搬移
- mdspan → 索引映射函数（仿射变换）
- print → 格式化字符串的线程安全输出
