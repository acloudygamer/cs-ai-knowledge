# C++23 新特性

> **版本关系**：C++23（latest）→ C++26（std::execution）

**C++23 是对 C++20 的大幅补充：std::expected 函数式错误处理、mdspan 多维数组视图、std::flat_map 缓存友好容器、constexpr 全面增强。**

## 定义

| 特性 | 一句话断言 |
|------|-----------|
| std::expected | 表达"可能失败的结果"的函数式错误处理类型 |
| std::flat_map | 用连续内存实现 map 接口，缓存友好 |
| std::mdspan | 多维数组的轻量非拥有型视图 |
| std::print | 直接输出格式化字符串到 stdout（无需 format 返回） |
| std::ranges::to | 一行代码将惰性视图转换为容器 |

## 数据流

<pre>
C++23 特性              解决的问题                    核心价值
    │                        │                          │
    ├─ expected       →    ├─ 异常的性能开销          ├─ 强制检查
    │                   ├─ 错误码的繁琐嵌套           ├─ 链式组合
    │                        │                          │
    ├─ flat_map       →    ├─ 树节点分散导致缓存未命中  ├─ 连续内存
    │                        │                          │
    ├─ mdspan         →    ├─ 手写多维索引计算         ├─ 直观的 [,] 访问
    │                        │                          │
    └─ ranges::to     →    └─ 视图转容器需要多行代码   └─ 一行搞定
</pre>

## 机制

**std::expected 的设计动机**：C++ 的错误处理有三种方式——异常（性能开销大且易被忽略）、错误码（嵌套检查繁琐）、std::error_code（需要额外的错误域定义）。expected 提供第四种选择：强制调用者检查，链式操作优雅处理成功/失败路径。

**flat_map vs map 的取舍**：flat_map 用两个平行 vector 分别存储键和值，查找仍是 O(log n)（二分），但插入/删除是 O(n)（需要移动元素）。优势在于内存连续，缓存命中率高，适合读多写少或需要频繁遍历的场景。

**mdspan 的设计**：Fortran、MATLAB、NumPy 等科学计算生态中多维数组是一等公民。mdspan 让 C++ 可以直接使用 `matrix[i, j]` 语法访问多维数组，无需手动计算 `data[i * stride_i + j * stride_j]`。

**为什么需要 std::ranges::to**：Ranges 视图是惰性的，组合多个视图不会立即执行。但最终需要具体容器（如 `std::vector`）来保存结果。`ranges::to<Container>()` 解决了这个问题。

## 参考存根

```cpp
std::expected<int, std::string> parse(int x) {
    if (x >= 0) return x;
    return std::unexpected("negative");
}

std::flat_map<std::string, int> m;
m["key"] = 42;

std::array<int, 15> a;
std::mdspan<int, std::extents<size_t, 5, 3>> matrix(a.data());

std::vector<int> v = std::views::iota(1, 10) | std::ranges::to<std::vector>();
```
