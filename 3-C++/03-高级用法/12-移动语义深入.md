# 移动语义深入

移动语义是 C++11 引入的核心特性，它解决了不必要的拷贝开销问题，通过"窃取"临时对象的资源来提升性能。本章深入讲解移动语义的原理、实现和最佳实践。

## 左值与右值

### 概念区分

```cpp
int x = 10;        // x 是左值（有名称，可取地址）
int* ptr = &x;     // 可以对左值取地址

42;                 // 字面量是右值（不能取地址）
x + 1;              // 表达式结果是右值
std::string("hello");  // 临时对象是右值

// 左值引用（绑定到左值）
int& ref = x;          // OK
// int& ref2 = 42;     // 错误：右值不能绑定到左值引用

// 常量左值引用（可绑定到右值）
const int& cref = 42;  // OK，C++11 起可用

// 右值引用（C++11 起，绑定到右值）
int&& rref = 42;       // OK，右值引用绑定到右值
// int&& rref2 = x;    // 错误：左值不能绑定到右值引用

// 函数返回左值引用返回左值，返回值返回右值
```

### 将亡值与纯右值

```cpp
// 纯右值（prvalue）：字面量、临时对象、lambda 等
42;
x + 1;
std::string("temp");

// 将亡值（xvalue）：即将被移动的对象
std::move(x);              // 转为将亡值
std::vector<int>(100);     // 临时 vector 即将销毁
// 将亡值可以绑定到右值引用

// 左值（lvalue）：有名称的对象
int y = 5;
y = 10;

// glvalue = lvalue + xvalue（泛左值）
// prvalue = 纯右值
// xvalue = 将亡值
```

## 右值引用

### 右值引用基础

```cpp
#include <iostream>
#include <utility>

void process(int& x) {
    std::cout << "左值引用: " << x << std::endl;
}

void process(int&& x) {
    std::cout << "右值引用: " << x << std::endl;
}

int main() {
    int a = 10;
    process(a);         // 调用左值版本
    process(42);        // 调用右值版本
    process(std::move(a));  // 调用右值版本
}
```

### 移动语义的核心

```cpp
class Resource {
    int* data_;
    size_t size_;
public:
    explicit Resource(size_t size) : size_(size) {
        data_ = new int[size];
        std::cout << "构造 size=" << size_ << std::endl;
    }

    // 拷贝构造函数（深拷贝）
    Resource(const Resource& other) : size_(other.size_) {
        data_ = new int[size_];
        std::copy(other.data_, other.data_ + size_, data_);
        std::cout << "拷贝构造 size=" << size_ << std::endl;
    }

    // 移动构造函数（窃取资源）
    Resource(Resource&& other) noexcept : data_(other.data_), size_(other.size_) {
        other.data_ = nullptr;   // 关键：将原对象置为空
        other.size_ = 0;
        std::cout << "移动构造 size=" << size_ << std::endl;
    }

    // 拷贝赋值运算符
    Resource& operator=(const Resource& other) {
        if (this != &other) {
            delete[] data_;
            size_ = other.size_;
            data_ = new int[size_];
            std::copy(other.data_, other.data_ + size_, data_);
            std::cout << "拷贝赋值 size=" << size_ << std::endl;
        }
        return *this;
    }

    // 移动赋值运算符
    Resource& operator=(Resource&& other) noexcept {
        if (this != &other) {
            delete[] data_;
            data_ = other.data_;
            size_ = other.size_;
            other.data_ = nullptr;
            other.size_ = 0;
            std::cout << "移动赋值 size=" << size_ << std::endl;
        }
        return *this;
    }

    ~Resource() {
        delete[] data_;
        if (size_ > 0) std::cout << "析构 size=" << size_ << std::endl;
    }

    bool empty() const { return size_ == 0; }
};

Resource create_resource() {
    return Resource(100);  // 临时对象
}

int main() {
    // 移动语义在返回时的应用
    Resource r1 = create_resource();  // 可能触发移动

    // 显式移动
    Resource r2 = std::move(r1);  // 移动构造，r1 变为空

    // 移动赋值
    Resource r3(50);
    r3 = std::move(r2);  // 移动赋值，r3 释放旧资源，接收 r2 的资源

    // r1, r2 已为空
    std::cout << "r1 empty: " << r1.empty() << std::endl;  // 1
    std::cout << "r2 empty: " << r2.empty() << std::endl;  // 1
    std::cout << "r3 empty: " << r3.empty() << std::endl;  // 0
}
```

## std::move 实现原理

### 本质是类型转换

```cpp
// std::move 的实现本质上是一个 static_cast
template<typename T>
constexpr std::remove_reference_t<T>&& move(T&& arg) noexcept {
    return static_cast<std::remove_reference_t<T>&&>(arg);
}

// 实际使用
int x = 10;
std::move(x);           // 推导为 int&& (因为 x 是左值)
std::move(42);          // 推导为 int&& (字面量本身就是右值)

std::string s1 = "hello";
std::string s2 = std::move(s1);  // s1 转为 std::string&&

// 注意：std::move 本身不移动任何东西，只是类型转换
// 真正的移动发生在移动构造函数/赋值运算符中
```

### std::move 的误用

```cpp
class Buffer {
    std::vector<char> data_;
public:
    // 错误示范：返回 std::move 局部变量
    // 在 C++11/14 中，返回局部对象的右值引用不会移动
    // 在 C++17 的 copy elision 规则下更不需要

    // 正确做法：直接返回
    Buffer get_buffer() {
        return data_;  // 编译器优化，可能不拷贝不移动
    }

    // 错误：对成员使用 std::move
    void process_member() {
        // 永远不要对成员变量使用 std::move
        // std::vector<int> v = std::move(data_);  // 危险！
    }

    // 正确：在赋值时使用 std::move
    void set_data(std::vector<char>&& new_data) {
        data_ = std::move(new_data);  // OK，右值引用参数
    }
};
```

## 完美转发

### 转发引用的困惑

```cpp
template<typename T>
void wrapper(T&& arg) {
    // T&& 是"转发引用"（既可以绑定左值也可以绑定右值）
    // 它的推导规则特殊：
    // - 传入左值：T 推导为 T&，arg 类型为 T&
    // - 传入右值：T 推导为 T，arg 类型为 T&&
}

// 转发引用与类型推导
void process(int&) { std::cout << "int&\n"; }
void process(int&&) { std::cout << "int&&\n"; }

int x = 10;
wrapper(x);      // wrapper<int&>(x)，内部 arg 是 int&
wrapper(42);     // wrapper<int>(42)，内部 arg 是 int&&
wrapper(std::move(x));  // wrapper<int&&>(std::move(x))
```

### std::forward 详解

```cpp
template<typename T>
void wrapper(T&& arg) {
    // 关键：只有当 T 不是引用类型时才转发为右值
    // T 是 int（传入右值）→ forward<int> 转为 int&&
    // T 是 int&（传入左值）→ forward<int&> 转为 int&（保持左值）
    process(std::forward<T>(arg));
}

int x = 10;
wrapper(x);      // forward<int&>(arg) → int&
wrapper(42);     // forward<int>(arg) → int&&
```

### 完美转发工厂函数

```cpp
#include <memory>
#include <utility>

class Widget {
public:
    Widget(int a, double b, std::string c) {
        std::cout << "构造 Widget: " << a << ", " << b << ", " << c << std::endl;
    }
};

// 完美转发工厂函数
template<typename T, typename... Args>
std::unique_ptr<T> make_unique_optimal(Args&&... args) {
    return std::unique_ptr<T>(
        new T(std::forward<Args>(args)...)
    );
}

int main() {
    int a = 42;
    double b = 3.14;
    std::string c = "hello";

    // 完美转发：保持参数的值类别
    auto p1 = make_unique_optimal<Widget>(a, b, c);      // 左值
    auto p2 = make_unique_optimal<Widget>(1, 2.0, "temp"); // 右值
    auto p3 = make_unique_optimal<Widget>(a, std::move(b), std::move(c)); // 混合
}
```

### 转发引用陷阱

```cpp
// 陷阱1：局部变量转发
template<typename T>
T&& create(T&& t) {
    // 错误！局部对象不能返回引用
    // return std::forward<T>(t);
}

// 陷阱2：auto&& 推导
auto&& x = 10;  // int&&，不是转发引用！
// 转发引用只存在于模板参数中

// 陷阱3：成员函数中的转发
class Widget {
    std::vector<int> data_;
public:
    template<typename T>
    void set_data(T&& value) {
        data_ = std::forward<T>(value);  // OK
    }

    template<typename T>
    T&& get_data() {
        return std::forward<T>(data_);  // 危险！返回成员引用
    }
};
```

## 移动语义与容器

### vector 的移动行为

```cpp
#include <vector>
#include <string>

int main() {
    std::vector<std::string> v;

    // 当容器需要重新分配时，会移动所有元素
    for (int i = 0; i < 1000; i++) {
        std::string s = "item_" + std::to_string(i);
        v.push_back(std::move(s));  // 移动而非拷贝
        // 注意：s 被移动后处于有效但未定义状态，不应再使用
    }

    // reserve 可以避免重新分配
    std::vector<std::string> v2;
    v2.reserve(1000);
    for (int i = 0; i < 1000; i++) {
        v2.emplace_back("item_" + std::to_string(i));  // 就地构造
    }

    // emplace_back 就地构造，效率最高
    std::vector<std::string> v3;
    v3.emplace_back("hello");  // 直接在 vector 内部构造
    v3.emplace_back(10, 'c');   // 构造 "cccccccccc"
}
```

### 移动语义与字符串

```cpp
#include <string>

int main() {
    std::string s1 = "hello world";
    std::string s2 = std::move(s1);

    // s1 变为空
    // s2 获得 s1 的内部缓冲区（指针拷贝）

    // SSO（短字符串优化）
    std::string short_s = "short";
    std::string s3 = std::move(short_s);
    // 短字符串可能不会移动，而是拷贝
    // 因为 SSO 会把字符串存储在对象内部

    // 大字符串移动
    std::string long_s(10000, 'x');  // 超过 SSO 阈值
    std::string s4 = std::move(long_s);
    // long_s 变为空，s4 获得堆内存所有权
}
```

### emplace vs push

```cpp
#include <vector>
#include <string>

struct Point {
    int x, y;
    Point(int x, int y) : x(x), y(y) {}
    Point(const Point&) = default;
    Point(Point&&) = default;
};

int main() {
    std::vector<Point> v;

    // push_back：先构造临时对象，再移动/拷贝
    v.push_back(Point(1, 2));  // 构造 + 移动
    v.push_back({3, 4});       // 构造 + 移动

    // emplace_back：直接在容器中构造
    v.emplace_back(5, 6);      // 直接构造，无移动
    v.emplace_back(Point(7, 8));  // 这个还是会移动

    // 对于简单类型，差别不大
    // 对于复杂类型，emplace_back 效率更高
}
```

## 移动语义与异常安全

### noexcept 的重要性

```cpp
#include <vector>
#include <exception>
#include <iostream>

class CriticalData {
    std::vector<int> data_;
public:
    CriticalData(size_t size) : data_(size, 0) {}

    // 移动操作必须声明 noexcept
    CriticalData(CriticalData&& other) noexcept
        : data_(std::move(other.data_)) {}

    CriticalData& operator=(CriticalData&& other) noexcept {
        data_ = std::move(other.data_);
        return *this;
    }

    // 如果移动操作可能抛异常，必须声明
    // 否则 std::vector 在重新分配时会拒绝移动
};

int main() {
    std::vector<CriticalData> v;

    v.reserve(10);
    v.emplace_back(100);
    v.emplace_back(200);
    v.emplace_back(300);

    // 当 vector 容量不足时
    v.emplace_back(400);  // 如果移动操作不抛异常，使用移动
                           // 如果可能抛异常，vector 选择拷贝（效率低）
}
```

### 强异常安全保证

```cpp
class SafeVector {
    int* data_;
    size_t size_;
    size_t capacity_;
public:
    void swap(SafeVector& other) noexcept {
        std::swap(data_, other.data_);
        std::swap(size_, other.size_);
        std::swap(capacity_, other.capacity_);
    }

    // 移动赋值使用 copy-and-swap 实现强异常安全
    SafeVector& operator=(SafeVector&& other) noexcept {
        if (this != &other) {
            SafeVector temp(std::move(other));  // 可能抛异常
            swap(temp);  // noexcept
        }
        return *this;
    }
};
```

### 移动操作的noexcept规范

```cpp
class Widget {
    std::vector<int> data_;
public:
    // 默认移动构造函数
    Widget(Widget&&) = default;  // 继承 vector 的 noexcept

    // 手动实现时注意
    Widget(Widget&& other) noexcept(std::is_nothrow_move_constructible_v<std::vector<int>>)
        : data_(std::move(other.data_)) {}

    // 可以使用 std::move_if_noexcept
    Widget copy_and_move() const {
        Widget temp;
        if constexpr (std::is_nothrow_move_constructible_v<Widget>) {
            temp = Widget(*this);  // 移动
        } else {
            temp = *this;  // 拷贝
        }
        return temp;
    }
};
```

## 移动语义与模板

### 模板中的移动语义

```cpp
#include <utility>
#include <vector>
#include <iostream>

// 模板函数中的移动语义
template<typename Container>
void process_container(Container&& c) {
    // 使用 std::forward 保持原始类型
    using T = std::decay_t<Container>;

    if constexpr (std::is_lvalue_reference_v<Container>) {
        std::cout << "左值引用\n";
    } else {
        std::cout << "右值引用\n";
    }

    // 访问元素
    for (auto& item : c) {
        std::cout << item << " ";
    }
    std::cout << std::endl;
}

// 完美转发接受任意参数
template<typename T, typename... Args>
std::pair<T, Args...> make_pair_perfect(Args&&... args) {
    return {std::forward<Args>(args)...};
}

int main() {
    std::vector<int> v{1, 2, 3};

    // 传入左值
    process_container(v);

    // 传入右值
    process_container(std::vector<int>{4, 5, 6});

    // 混合
    auto p = make_pair_perfect<int>(42, "hello", 3.14);
}
```

### 类型推导与移动

```cpp
#include <type_traits>

template<typename T>
void deduce(T arg) {
    // T 是值类型
    // 如果传入左值 int&，T = int
    // 如果传入右值 int&&，T = int
}

template<typename T>
void deduce_ref(T& arg) {
    // T 是引用类型
    // 如果传入左值 int&，T = int
    // 如果传入右值 int&&，T = int（仍然是引用）
}

template<typename T>
void deduce_forward(T&& arg) {
    // 转发引用
    // 如果传入左值 int&，T = int&，arg = int&
    // 如果传入右值 int&&，T = int，arg = int&&
}

// decltype 与移动
int x = 10;
decltype(x)& lr = x;     // int&
decltype(std::move(x))&& rr = std::move(x);  // int&&

// std::move 返回类型是 remove_reference_t<T>&&
```

## Pimpl 惯用法与移动语义

### 经典 Pimpl 实现

```cpp
// widget.h
class Widget {
public:
    Widget();
    ~Widget();

    Widget(Widget&&);             // 移动构造
    Widget& operator=(Widget&&);  // 移动赋值

    // 拷贝（如果需要）
    Widget(const Widget&);
    Widget& operator=(const Widget&);

    void do_something();

private:
    struct Impl;
    std::unique_ptr<Impl> pImpl_;  // 指向实现的唯一指针
};

// widget.cpp
struct Widget::Impl {
    int data_;
    std::vector<int> vec_;

    Impl() : data_(0), vec_(100) {}
    Impl(int d) : data_(d), vec_(100) {}
};

Widget::Widget() : pImpl_(std::make_unique<Impl>()) {}

Widget::~Widget() = default;  // unique_ptr 需要完整类型

Widget::Widget(Widget&& other) = default;  // unique_ptr 可移动

Widget& Widget::operator=(Widget&& other) = default;

Widget::Widget(const Widget& other)
    : pImpl_(std::make_unique<Impl>(*other.pImpl_)) {}

Widget& Widget::operator=(const Widget& other) {
    *pImpl_ = *other.pImpl_;  // 拷贝赋值
    return *this;
}

void Widget::do_something() {
    pImpl_->data_ = 42;
}
```

## 常见陷阱

### 1. 移动后使用对象

```cpp
std::string s1 = "hello";
std::string s2 = std::move(s1);

// 错误：s1 已被移动，不应再使用
// std::cout << s1 << std::endl;  // 未定义行为！

// 移动后，对象处于"有效但未定义"状态
// 可以重新赋值或销毁，但不能读取原值
s1 = "world";  // OK，可以重新赋值
```

### 2. 自移动

```cpp
class Widget {
    std::vector<int> data_;
public:
    Widget& operator=(Widget&& other) {
        if (this != &other) {
            // 常见错误：忘记检查自移动
            data_ = std::move(other.data_);
            // 其他成员也要处理
        }
        return *this;
    }
};

Widget w;
w = std::move(w);  // 自移动！可能丢失数据
```

### 3. 移动 non-copyable 资源

```cpp
#include <fstream>

class FileHandler {
    std::fstream file_;
public:
    explicit FileHandler(const char* path)
        : file_(path, std::ios::in) {}

    // 移动语义
    FileHandler(FileHandler&& other) noexcept
        : file_(std::move(other.file_)) {}

    FileHandler& operator=(FileHandler&& other) noexcept {
        if (this != &other) {
            file_ = std::move(other.file_);
        }
        return *this;
    }

    // 禁用拷贝
    FileHandler(const FileHandler&) = delete;
    FileHandler& operator=(const FileHandler&) = delete;
};

// 正确使用
FileHandler f1("test.txt");
FileHandler f2 = std::move(f1);  // OK
```

### 4. 移动线程不安全的对象

```cpp
class ThreadUnsafe {
    std::vector<int> data_;
public:
    ThreadUnsafe(ThreadUnsafe&& other) {
        // 不是线程安全的！
        data_ = std::move(other.data_);
    }
};

ThreadUnsafe obj1;
std::thread t1([&]() {
    ThreadUnsafe obj2 = std::move(obj1);  // 危险！obj1 被同时访问
});
t1.join();
```

## 最佳实践总结

1. **移动构造函数和移动赋值运算符应标记 `noexcept`**
   - 否则容器可能选择拷贝而非移动

2. **在移动操作中将原对象置于有效状态**
   - 指针成员应设为 `nullptr`
   - 尺寸成员应设为 `0`

3. **不要对已移动对象进行读取操作**
   - 只能重新赋值或销毁

4. **使用 `std::move` 时确保目标需要资源**
   - 避免不必要的移动开销

5. **优先使用 `emplace` 而非 `push`**
   - 减少临时对象的创建和移动

6. **模板函数中使用 `std::forward` 保持值类别**
   - 不要混淆 `std::move` 和 `std::forward`
