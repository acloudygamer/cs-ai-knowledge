# 并发与异步

> **版本关系**：C++20（基础）→ C++23 → C++26（std::execution）

**并发是多线程同时执行，异步是调用立即返回而实际执行在别处。**

## std::jthread：自动管理的线程（C++20）

**std::jthread 是能在析构时自动 join 的线程对象，解决了普通 thread 忘记 join 导致悬挂线程的问题。**

```cpp
std::jthread t([](std::stop_token token, int id) {
    while (!token.stop_requested()) { }
}, 1);
```

## 内存顺序与原子操作

**内存顺序是线程间对共享变量操作可见性的契约，它解决了 CPU 缓存与编译器重排导致的可见性问题。**

六种内存顺序：

| 顺序 | 公式语义 |
|------|----------|
| `seq_cst` | $\text{可见性} = \text{全局时序}$ |
| `acquire` | $\text{后续读写} \prec \text{当前操作}$ |
| `release` | $\text{当前操作} \prec \text{前置读写}$ |
| `acq_rel` | $\text{读写} \prec \text{当前操作} \prec \text{读写}$ |
| `relaxed` | $\text{仅原子性}$ |
| `consume` | $\text{已废弃}$ |

```cpp
std::atomic<int*> ptr;
std::atomic<int> data;
```

```pre
Writer                          Reader
  │                               │
  ├─ data.store(val, relaxed)    │
  │                               │
  ├─ ptr.store(p, release) ──────┼─ ptr.load(acquire)
  │                               │  └─ data.load(relaxed) 可见
```

## std::atomic 深入

**atomic_flag 是最简单的锁，atomic_wait/notify（C++20）提供了阻塞等待机制。**

```cpp
std::atomic<int> counter(0);
counter.wait(0);
counter.store(1);
counter.notify_one();
```

## std::latch 与 std::barrier（C++20）

**latch 是一次性栅栏（计数只减），barrier 是可复用栅栏（可重置）。**

```cpp
std::latch l(3);
l.count_down();
l.wait();

std::barrier b(3);
b.arrive_and_wait();
```

## 线程局部存储

**thread_local 为每线程提供独立变量副本，消除线程间隐式共享。**

```cpp
thread_local int id = 0;
```

## 同步原语与死锁避免

**死锁四条件：互斥、持有等待、非抢占、循环等待。破坏任一即可避免。**

```pre
线程A: lock(m1) → lock(m2)    线程B: lock(m2) → lock(m1)
           ↓                            ↓
        持有m1                         持有m2
        等待m2                         等待m1
           ↓                            ↓
         死锁!                        死锁!
```

避免策略：固定顺序、std::lock、scoped_lock（C++17）。

## std::async 与 std::future

**std::async 将计算任务投入线程池返回 future，future.get() 阻塞获取结果。**

```cpp
std::future<int> f = std::async(std::launch::async, [] { return 42; });
f.get();
```

## 条件变量深入

**条件变量用于线程间同步，虚假唤醒迫使 wait 必须用谓词。**

```cpp
std::condition_variable cv;
std::mutex mtx;
std::unique_lock lock(mtx);
cv.wait(lock, []{ return ready; });
```

## std::execution（C++26）

**std::execution 是标准化的发送方-接收方接口，用管道操作符组合异步任务。**

```cpp
auto r = std::execution::just(1) | std::execution::then([](int x) { return x * 2; });
```
