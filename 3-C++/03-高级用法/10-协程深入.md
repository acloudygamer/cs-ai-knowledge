# C++ 协程深入

### 解决什么问题
传统异步编程模型不统一，第三方库各有实现难以统一。协程是 C++20 引入的轻量级并发抽象，适合异步 I/O 和流式处理场景。

### 核心概念
- 协程可以挂起和恢复执行，不同于普通函数的调用→执行→返回
- `promise_type` 定义协程行为：初始挂起点、最终挂起点、返回值、异常处理
- `co_await` 挂起协程等待异步操作完成
- `std::generator`（C++26）提供标准生成器，替代手写 promise_type

### 怎么用

## 协程基础回顾

### 协程与普通函数对比

```cpp
// 普通函数：调用 → 执行 → 返回
int ordinary_function() {
    return 42;
}

// 协程：调用 → 挂起 → 恢复 → 返回
// 注：std::future 不直接支持 co_await，需用自定义 awaitable 或库提供的扩展
std::future<int> async_function() {
    co_await std::suspend_always{};  // 简单示例：挂起后手动恢复
    co_return 42;
}
```

### 协程的三个关键点

```cpp
struct Task {
    struct promise_type {
        // 1. 创建协程返回值
        Task get_return_object() {
            return Task{std::coroutine_handle<promise_type>::from_promise(*this)};
        }

        // 2. 初始挂起点（是否立即挂起）
        std::suspend_always initial_suspend() { return {}; }

        // 3. 最终挂起点（是否在最后挂起）
        std::suspend_always final_suspend() noexcept { return {}; }

        // 4. 返回值
        void return_value(int v) { value_ = v; }

        // 5. 异常处理
        void unhandled_exception() { std::terminate(); }

        int value_;
    };

    std::coroutine_handle<promise_type> handle_;

    // 从协程获取结果
    int get() {
        handle_.resume();  // 恢复执行
        return handle_.promise().value_;
    }
};
```

## promise_type 详解

### 不同的挂起策略

```cpp
// 立即开始（不挂起）
struct ImmediateStart {
    promise_type* p_;
    ImmediateStart(promise_type* p) : p_(p) {}

    // 不挂起，继续执行
    bool await_ready() const noexcept { return true; }
    void await_suspend(std::coroutine_handle<>) const {}
    void await_resume() const {}
};

// 永远挂起（需要显式恢复）
struct NeverAutoStart {
    std::suspend_always initial_suspend() { return {}; }
};

// 条件挂起
struct ConditionalStart {
    bool ready_;
    ConditionalStart(bool ready) : ready_(ready) {}

    bool await_ready() const noexcept { return ready_; }
    template<typename Handle>
    void await_suspend(Handle h) const {
        // 可以在这里安排调度
    }
    void await_resume() const {}
};
```

## co_await 详解

### await_ready

```cpp
struct TryLock {
    std::mutex& mtx_;
    bool* acquired_;

    explicit TryLock(std::mutex& mtx, bool* acquired = nullptr)
        : mtx_(mtx), acquired_(acquired) {}

    bool await_ready() const {
        return false;  // 默认总是挂起
    }

    template<typename Handle>
    void await_suspend(Handle h) {
        // 尝试获取锁
        if (mtx_.try_lock()) {
            if (acquired_) *acquired_ = true;
            h.destroy();  // 立即销毁，不继续
        } else {
            // 锁被占用，保存 handle 以便后续唤醒
            if (acquired_) *acquired_ = false;
            // 通常需要其他机制来唤醒
        }
    }

    void await_resume() {
        // 锁已获取
    }
};
```

### co_await 的执行流程

```cpp
// co_await expr 的执行顺序：
// 1. 调用 expr.await_ready()
//    - true: 跳过 suspend，直接执行 await_resume()，然后继续
//    - false: 继续下一步

// 2. 挂起协程，调用 expr.await_suspend(handle)
//    - void: 协程保持挂起
//    - true: 恢复协程
//    - false: 恢复协程继续执行
//    - coroutine_handle: 暂停当前，切换到指定 handle

// 3. 恢复后调用 expr.await_resume()，其返回值就是 co_await 的值
```

### 多个协程组合

```cpp
#include <coroutine>
#include <future>

// 顺序执行
Task sequential() {
    std::cout << "1\n";
    co_await std::suspend_always{};
    std::cout << "2\n";
    co_await std::suspend_always{};
    std::cout << "3\n";
}

// 并发执行
Task concurrent_a() {
    co_await std::suspend_always{};
    std::cout << "A done\n";
}

Task concurrent_b() {
    co_await std::suspend_always{};
    std::cout << "B done\n";
}

void run_concurrent() {
    auto task_a = concurrent_a();
    auto task_b = concurrent_b();

    // 恢复两个协程
    task_a.handle_.resume();
    task_b.handle_.resume();
}
```

## 异步 I/O 示例

### 异步文件读取

```cpp
#include <coroutine>
#include <future>
#include <fstream>

class AsyncFileReader {
public:
    struct ReadOperation {
        std::ifstream stream_;
        std::vector<char> buffer_;
        std::coroutine_handle<> continuation_;

        bool await_ready() { return false; }

        void await_suspend(std::coroutine_handle<> h) {
            continuation_ = h;

            // 在后台线程执行读取
            std::thread([this]() {
                stream_.read(buffer_.data(), buffer_.size());
                auto bytes_read = stream_.gcount();

                // 恢复协程
                continuation_();
            }).detach();
        }

        auto await_resume() {
            return std::string(buffer_.data(), stream_.gcount());
        }
    };

    ReadOperation read(const std::string& path, size_t size) {
        ReadOperation op;
        op.stream_.open(path, std::ios::binary);
        op.buffer_.resize(size);
        return op;
    }
};

AsyncFileReader reader;

Task load_file_task() {
    auto content = co_await reader.read("data.bin", 1024);
    std::cout << "Read " << content.size() << " bytes\n";
}
```

## 协程与 std::future

### 使用 std::async 风格的协程

```cpp
#include <coroutine>
#include <future>

template<typename T>
struct Lazy {
    struct promise_type {
        std::variant<std::monostate, T, std::exception_ptr> value_;
        std::coroutine_handle<> continuation_;

        Lazy get_return_object() {
            return Lazy{std::coroutine_handle<promise_type>::from_promise(*this)};
        }

        std::suspend_always initial_suspend() { return {}; }
        std::suspend_always final_suspend() noexcept { return {}; }

        void return_value(T val) {
            value_.template emplace<1>(std::move(val));
            continuation_();  // 通知等待者
        }

        void unhandled_exception() {
            value_.template emplace<2>(std::current_exception());
            continuation_();
        }

        T get() {
            if (std::holds_alternative<std::exception_ptr>(value_)) {
                std::rethrow_exception(std::get<std::exception_ptr>(value_));
            }
            return std::get<T>(value_);
        }
    };

    std::coroutine_handle<promise_type> handle_;

    explicit Lazy(std::coroutine_handle<promise_type> h) : handle_(h) {}
    ~Lazy() { if (handle_) handle_.destroy(); }

    T get() { return handle_.promise().get(); }
};

Lazy<int> compute() {
    co_return 42;
}

int main() {
    Lazy<int> lazy = compute();
    std::cout << lazy.get() << std::endl;  // 输出 42
}
```

## 协程池

### 固定数量的工作线程

```cpp
#include <coroutine>
#include <vector>
#include <queue>
#include <mutex>
#include <thread>
#include <condition_variable>

class CoroutinePool {
    std::vector<std::thread> workers_;
    std::queue<std::coroutine_handle<>> tasks_;
    std::mutex mutex_;
    std::condition_variable cv_;
    bool stop_ = false;

public:
    explicit CoroutinePool(size_t threads) {
        for (size_t i = 0; i < threads; ++i) {
            workers_.emplace_back([this] {
                while (true) {
                    std::coroutine_handle<> task;
                    {
                        std::unique_lock lock(mutex_);
                        cv_.wait(lock, [this] { return stop_ || !tasks_.empty(); });

                        if (stop_ && tasks_.empty()) return;
                        task = tasks_.front();
                        tasks_.pop();
                    }
                    task.resume();
                }
            });
        }
    }

    ~CoroutinePool() {
        {
            std::lock_guard lock(mutex_);
            stop_ = true;
        }
        cv_.notify_all();
        for (auto& t : workers_) t.join();
    }

    template<typename Promise>
    void submit(std::coroutine_handle<Promise> task) {
        {
            std::lock_guard lock(mutex_);
            tasks_.push(task);
        }
        cv_.notify_one();
    }
};

CoroutinePool pool(4);
```

### 自定义调度器

```cpp
#include <coroutine>
#include <thread>

struct InlineScheduler {
    bool await_ready() const { return true; }
    template<typename Handle>
    void await_suspend(Handle h) const {
        // 不挂起，在当前线程继续
    }
    void await_resume() const {}
};

struct ThreadPoolScheduler {
    std::vector<std::thread>& threads_;

    explicit ThreadPoolScheduler(std::vector<std::thread>& t) : threads_(t) {}

    bool await_ready() const { return false; }

    template<typename Handle>
    void await_suspend(Handle h) {
        threads_.emplace_back([h] { h.resume(); });
    }

    void await_resume() const {}
};

// 使用调度器
Task scheduled_work(InlineScheduler& sched) {
    std::cout << "Runs inline\n";
    co_await sched;
    std::cout << "After suspend\n";
}
```

## 异常处理与协程

### 异常传播

```cpp
#include <coroutine>

struct ErrorAwareTask {
    struct promise_type {
        std::exception_ptr exception_;

        ErrorAwareTask get_return_object() {
            return ErrorAwareTask{
                std::coroutine_handle<promise_type>::from_promise(*this)
            };
        }

        void unhandled_exception() {
            exception_ = std::current_exception();
        }

        std::suspend_always initial_suspend() { return {}; }
        std::suspend_always final_suspend() noexcept { return {}; }

        void return_void() {}
    };

    std::coroutine_handle<promise_type> handle_;

    ErrorAwareTask(std::coroutine_handle<promise_type> h) : handle_(h) {}
    ~ErrorAwareTask() { if (handle_) handle_.destroy(); }

    void resume() { handle_.resume(); }
    bool done() const { return handle_.done(); }
};

ErrorAwareTask risky() {
    throw std::runtime_error("Something went wrong");
    co_return;
}

int main() {
    auto task = risky();
    task.resume();

    if (task.handle_.promise().exception_) {
        try {
            std::rethrow_exception(task.handle_.promise().exception_);
        } catch (const std::exception& e) {
            std::cerr << "Caught: " << e.what() << std::endl;
        }
    }
}
```

## 性能考虑

### 避免不必要的分配

```cpp
// 默认情况下，每个协程需要动态分配：
// - 协程帧（保存局部变量）
// - promise 对象
// - std::coroutine_handle

// 使用 return value optimization 优化
struct OptimizedTask {
    struct promise_type {
        // 在协程帧中内联存储，而不是动态分配
        int value_;

        OptimizedTask get_return_object() {
            // 直接构造，避免额外的分配
            return OptimizedTask{
                std::coroutine_handle<promise_type>::from_promise(*this)
            };
        }

        // 使用 suspend_never 避免挂起时的额外开销
        std::suspend_never initial_suspend() { return {}; }
        std::suspend_always final_suspend() noexcept { return {}; }

        void return_value(int v) { value_ = v; }
        void unhandled_exception() { std::terminate(); }
    };

    std::coroutine_handle<promise_type> handle_;
    int get() { return handle_.promise().value_; }
};
```

### 栈帧大小

```cpp
// 协程的局部变量存储在堆分配的协程帧中
// 过大的局部变量可能导致问题

Task bad_example() {
    // 这个 1MB 的 buffer 会在堆上分配
    std::vector<char> large_buffer(1024 * 1024);
    co_return;
}

// 更好的做法：使用动态分配或引用
Task better_example() {
    auto large_buffer = std::make_shared<std::vector<char>>(1024 * 1024);
    co_return;
}
```

## 实际使用建议

### 推荐做法

```cpp
// 1. 使用库提供的协程类型，而不是自己实现
// - cppcoro (第三方)
// - std::generator (C++26)
// - 自定义需要仔细测试

// 2. 协程适用于
// - 异步 I/O
// - 流式处理（生成器）
// - 事件驱动架构

// 3. 不要用于
// - CPU 密集型任务（用 std::thread 或线程池）
// - 需要真正并行的场景
```

### 避免的陷阱

```cpp
// 1. 不要忘记销毁 handle
void bad_example() {
    auto task = some_async_task();
    // task.handle_ 在函数结束时没有被清理
}  // 内存泄漏！

// 正确做法
void good_example() {
    auto task = some_async_task();
    // ... 使用 task
    task.handle_.destroy();  // 或使用 RAII 包装
}

// 2. 不要在析构函数中调用 co_await
class BadClass {
    Task cleanup() {
        co_await close_connection();  // 危险！析构函数不能是 async
    }
};

// 3. 协程不能使用 try-catch 捕获所有异常
Task risky() {
    try {
        co_await might_throw();
    } catch (...) {
        // 可以捕获
    }
    co_return;
}
```

## 相关标准库组件

| 组件 | 头文件 | 版本 | 说明 |
|------|--------|------|------|
| std::coroutine_handle | <coroutine> | C++20 | 协程控制句柄 |
| std::suspend_always | <coroutine> | C++20 | 总是挂起的 promise |
| std::suspend_never | <coroutine> | C++20 | 从不挂起的 promise |
| std::generator | <generator> | **C++26**（C++26 新标准）| 标准生成器类型 |
| std::execution | <execution> | **C++26** | 发送方-接收方并发框架 |

> **版本说明**：
> - `std::generator`：**C++26 新标准**，C++23 期间仅为提案（Concurrency TS），从未纳入 C++23 标准
> - `std::execution`（发送方/接收方）：**C++26 新标准**，统一异步编程模型，取代 Concurrency TS
> 详见 [C++23 新特性](./09-C++23新特性.md) 和 [C++26 新特性](./16-C++26新特性.md)
