# 运算符重载

> **版本关系**：C++98（基础）→ C++11（移动语义）→ C++20（三路比较）→ C++23/26

**运算符重载是让自定义类型使用值语义语法的语法糖，本质是函数调用伪装成运算符形式。**

## 定义

| 运算符类型 | 一句话断言 |
|-----------|-----------|
| 成员运算符 | 左侧操作数必须是自身（`a + b` 可写成 `a.operator+(b)`） |
| 友元运算符 | 访问私有成员，无隐式 this（`a * 2` 需 `operator*(a, 2)`） |
| `operator bool` | 隐式转换为布尔值，必须 `explicit` 防止意外转换 |
| `operator auto` | C++20 隐式类型转换，由编译器推断目标类型 |

## 数据流

<pre>
表达式                  解析                   调用
   │                      │                      │
   ├─ a + b      →      ├─ a.operator+(b)       │
   │                      │                      │
   ├─ 2 * a      →      ├─ operator*(2, a)     │
   │                      │                      │
   ├─ a == b     →      ├─ a.operator==(b)      │
   │                      │                      │
   └─ if(a)      →      └─ a.operator bool()   ┌─ explicit bool
                                               │
                                               └─ 控制流中使用
</pre>

## 机制

**为什么需要友元重载**：成员运算符的左操作数必须是自身，但 `2 * Vector` 中 2 是内置类型无法添加成员函数。友元函数让两个操作数都是公开参数。

**operator bool 的危险**：任何能转换为 bool 的类型都可隐式进入 `if`、`while`、`!`、`&&`、`||`。一个错误的 `operator int()` 比 `operator bool()` 更危险，因为整数可参与更多运算。

**三路比较（`<=>`）的优势**：传统 `==`、`<`、`<=`、`>=`、`>` 需分别实现且易不一致。`operator<=>` 生成所有比较运算符，保证数学一致性：C++20 `= default` 自动生成。

## 参考存根

```cpp
struct Vec2 {
    double x, y;
    auto operator<=>(const Vec2&) const = default;
};
```

## 不可重载的运算符

`::` `.*` `.` `?:` `sizeof` `typeid` `dynamic_cast` `static_cast` `reinterpret_cast` `const_cast`
