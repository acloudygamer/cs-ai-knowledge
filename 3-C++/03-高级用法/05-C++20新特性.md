# C++20 新特性

> **版本关系**：C++20（基础）→ C++23 → C++26

C++20 是现代 C++ 的重要里程碑，引入了概念（Concepts）、协程、模块、范围库等核心特性。作为基础版本，C++20 涵盖现代 C++ 开发的核心概念。

## 概念（Concepts）

概念是对模板参数约束的显式声明，让编译错误信息更清晰。`requires` 子句约束模板参数，`requires` 表达式定义更复杂的需求。标准库在 `<concepts>` 中提供了常用概念。

`std::integral`、`std::floating_point`、`std::same_as`、`std::derived_from` 等概念可用于约束模板类型。`requires` 表达式可检查类型是否支持特定操作。

### 参考样例

```cpp
#include <concepts>

// 定义概念
template <typename T>
concept Numeric = std::integral<T> || std::floating_point<T>;

template <typename T>
concept Addable = requires(T a, T b) {
    a + b;
    a - b;
};

// 使用概念约束模板
template <Numeric T>
T add(T a, T b) { return a + b; }

// 简写形式
template <std::integral T>
T square(T x) { return x * x; }

// requires 子句
template <typename T>
    requires std::integral<T>
T divide(T a, T b) {
    if (b == 0) throw std::invalid_argument("Division by zero");
    return a / b;
}

// requires 表达式
template <typename T>
concept Hashable = requires(T a) {
    std::hash<T>{}(a);
    a == a;
};

// 标准概念
std::integral<int>;      // true
std::floating_point<double>;  // true
std::same_as<int, int>;  // true
std::derived_from<Derived, Base>;
std::invocable<std::function<void()>>;
std::totally_ordered<int>;
```

## 范围库（Ranges）

范围库支持惰性求值和组合，让算法链式调用更直观。视图（View）是惰性求值的序列操作，可通过管道操作组合。范围工厂（如 `iota`）生成序列。

### 参考样例

```cpp
#include <ranges>
#include <vector>

std::vector<int> vec = {1, 2, 3, 4, 5};

// 范围工厂
auto range = std::views::iota(1, 10);  // 1, 2, 3, ..., 9
auto range2 = std::views::iota(1) | std::views::take(10);  // 无限，但取前 10

// 视图操作
auto evens = vec | std::views::filter([](int n) { return n % 2 == 0; });
auto doubled = vec | std::views::transform([](int n) { return n * 2; });

// 链式操作
auto result = vec
    | std::views::filter([](int n) { return n > 2; })
    | std::views::transform([](int n) { return n * 2; })
    | std::views::take(3);
```

### 常用视图

`iota` 生成序列，`take/drop` 取/跳过前 N 个，`filter` 过滤，`transform` 转换，`reverse` 反转，`unique` 去除相邻重复，`split/lazy_split`（C++23）分割。

### 参考样例

```cpp
#include <ranges>

// iota：生成序列
auto seq = std::views::iota(1, 100);

// take / drop
auto first_10 = std::views::iota(1) | std::views::take(10);
auto skip_10 = seq | std::views::drop(10);

// filter：过滤
auto odd = std::views::iota(1, 20) | std::views::filter([](int n) { return n % 2; });

// transform：转换
auto squares = std::views::iota(1, 10) | std::views::transform([](int n) { return n * n; });

// split（C++23）
std::string s = "hello,world";
for (auto word : s | std::views::split(',')) { /* ... */ }
```

### 范围算法

范围算法支持三路比较运算符，可直接对容器操作。

### 参考样例

```cpp
#include <ranges>

std::vector<int> vec = {5, 2, 8, 1, 9, 3};

// 范围版本（惰性求值）
auto result = vec | std::views::filter([](int n) { return n > 3; });

// 排序
std::vector<int> sorted(vec | std::views::all);
std::ranges::sort(sorted);

// 查找
auto it = std::ranges::find(vec, 8);
auto it2 = std::ranges::find_if(vec, [](int n) { return n > 5; });

// all_of / any_of / none_of
bool all_pos = std::ranges::all_of(vec, [](int n) { return n > 0; });
```

## 模块（Modules）

模块解决了头文件依赖导致的编译性能差、命名冲突、宏污染问题。模块接口文件（`.ixx`）导出公共 API，`export module` 声明模块名，`import` 导入模块。模块分区（Partition）组织大型模块。

### 参考样例

```cpp
// module.ixx（接口文件）
module;  // 模块单元开始

export module my_module;  // 声明模块名

import std.core;  // C++23 标准库模块

export int add(int a, int b) { return a + b; }

export class Point {
public:
    int x, y;
    Point(int x, int y) : x(x), y(y) {}
};

// main.cpp
import my_module;
import std.vector;  // C++23 标准库模块

int main() {
    int result = add(3, 4);
    Point p(1, 2);
}
```

## 三路比较运算符（Spaceship Operator）

`<=>` 运算符返回三态比较结果：`std::partial_ordering`、`std::strong_ordering` 或 `std::weak_ordering`。`operator<=>` = `default` 自动生成所有比较运算符。链式比较如 `a < b < c` 等价于 `(a < b) && (b < c)`。

### 参考样例

```cpp
#include <compare>

int a = 5, b = 10;
auto result = a <=> b;

if (result < 0) { /* a < b */ }
else if (result > 0) { /* a > b */ }
else { /* a == b */ }

// 链式比较
int x = 1, y = 2, z = 3;
if (x < y < z) { /* 等价于 (x < y) && (y < z) */ }

// 自动生成比较运算符
class Point {
    int x_, y_;
public:
    auto operator<=>(const Point&) const = default;  // 编译器生成所有比较
};
```

## consteval 与 constexpr

`consteval`（C++20）强制函数在编译期求值，运行时调用会导致编译错误。constexpr 扩展（C++20）支持 `std::vector` 等动态容器和 `new`/`delete`。`std::bit_cast`（C++20）位模式重解释，需相同大小。

### 参考样例

```cpp
// consteval 强制编译期求值
consteval int sqr(int n) { return n * n; }
constexpr int x = sqr(5);   // 编译时计算
int y = sqr(6);             // 编译时计算
// int z; std::cin >> z; int bad = sqr(z);  // 错误：z 不是常量

// constexpr 动态分配（C++20）
constexpr std::vector<int> create_vec() {
    std::vector<int> v;
    v.push_back(1);
    v.push_back(2);
    return v;
}
constexpr auto v = create_vec();

// std::bit_cast
float f = 3.14159f;
uint32_t bits = std::bit_cast<uint32_t>(f);
```
