# C++20 新特性

> **C++ 标准版本标记**：本文介绍 C++20 标准特性，是现代 C++ 的重要里程碑。
>
> **版本关系**：C++20（基础）→ C++23 → C++26

> **本文定位**：作为 C++ 基础版本文档，涵盖 C++20 核心概念。C++23 和 C++26 在此基础上增强，详见各自文档。

## 概念（Concepts）

### 解决什么问题
模板参数约束不明确，编译错误信息难以理解。概念（Concept）提供了模板参数约束的显式声明，让错误信息更清晰。

### 核心概念
- 概念是对模板参数约束的显式声明
- `requires` 子句用于约束模板参数
- `requires` 表达式用于定义更复杂的需求
- 标准库提供了常用概念（`<concepts>`）

### 怎么用

```cpp
#include <concepts>

// 定义概念
template <typename T>
concept Numeric = std::integral<T> || std::floating_point<T>;

template <typename T>
concept Addable = requires(T a, T b) {
    a + b;  // 必须支持 + 运算
    a - b;  // 必须支持 - 运算
};

// 使用概念约束模板
template <Numeric T>
T add(T a, T b) {
    return a + b;
}

// 简化写法：using 声明（C++20）
template <std::integral T>
T square(T x) {
    return x * x;
}
```

### requires 子句

```cpp
// 模板参数约束
template <typename T>
    requires std::integral<T>
T divide(T a, T b) {
    if (b == 0) throw std::invalid_argument("Division by zero");
    return a / b;
}

// 简写形式
template <std::integral T>
T divide(T a, T b) { return a / b; }

// 尾部返回类型约束
template <std::integral T>
T mod(T a, T b) requires (b != 0) { return a % b; }
```

### requires 表达式

```cpp
// 定义更复杂的需求
template <typename T>
concept Hashable = requires(T a) {
    std::hash<T>{}(a);  // 必须能构造 hash 对象并调用
    a == a;             // 必须支持相等比较
};

template <typename T>
concept Container = requires(T c) {
    c.begin();
    c.end();
    std::ranges::size(c);
};

// 组合概念
template <typename T>
concept NumberContainer = Container<T> && Hashable<typename T::value_type>;
```

### 标准概念（<concepts>）

```cpp
#include <concepts>

// 基本类型概念
std::integral<int>      // true
std::floating_point<double>  // true
std::same_as<int, int>  // true
std::derived_from<Derived, Base>  // 继承关系

// 可调用概念
std::invocable<std::function<void()>>  // 可调用
std::predicate<bool(*)(int)>  // 谓词

// 比较概念
std::totally_ordered<int>  // 支持 <, <=, >, >=
std::equality_comparable<int>  // 支持 ==, !=
```

## 协程（Coroutines）

### 解决什么问题
传统异步编程模型不统一，C++20 协程提供轻量级的用户态线程，适合异步 I/O 和生成器场景。

### 核心概念
- 协程可以挂起和恢复执行，不同于普通函数的调用→执行→返回
- `co_await` 挂起协程等待异步操作完成
- `co_yield` 产生值用于生成器
- `co_return` 返回值并结束协程

### 怎么用

```cpp
#include <coroutine>
#include <iostream>

// 简单的协程返回类型
struct Task {
    struct promise_type {
        Task get_return_object() { return Task{}; }
        std::suspend_never initial_suspend() { return {}; }
        std::suspend_always final_suspend() noexcept { return {}; }
        void return_void() {}
        void unhandled_exception() {}
    };
};

// co_await 挂起协程
Task async_operation() {
    std::cout << "Before suspend\n";
    co_await std::suspend_always{};
    std::cout << "After resume\n";
}

// co_yield 产生值
Task generate_values() {
    co_yield 1;
    co_yield 2;
    co_yield 3;
    co_return;
}
```

## 范围库（Ranges）

### 解决什么问题
STL 算法难以组合，链式调用需要大量中间变量。范围库（Ranges）支持惰性求值和组合，让算法链式调用更直观。

### 核心概念
- 视图（View）是惰性求值的序列操作
- 视图可以管道操作组合：`vec | views::filter | views::transform`
- 范围工厂（如 `iota`）生成序列
- 范围算法支持三路比较运算符

### 怎么用

```cpp
#include <ranges>
#include <vector>
#include <iostream>

std::vector<int> vec = {1, 2, 3, 4, 5};

// 范围工厂
auto range = std::views::iota(1, 10);  // 1, 2, 3, ..., 9
auto range2 = std::views::iota(1) | std::views::take(10);  // 无限，但取前 10

// 视图操作
auto evens = vec | std::views::filter([](int n) { return n % 2 == 0; });
auto doubled = vec | std::views::transform([](int n) { return n * 2; });
auto first_three = vec | std::views::take(3);

// 链式操作
auto result = vec
    | std::views::filter([](int n) { return n > 2; })
    | std::views::transform([](int n) { return n * 2; })
    | std::views::take(3);
```

### 常用视图

```cpp
#include <ranges>

// iota：生成序列
auto seq = std::views::iota(1, 100);  // 1 到 99

// take / drop：取/跳过前 N 个
auto first_10 = std::views::iota(1) | std::views::take(10);
auto skip_10 = seq | std::views::drop(10);

// filter：过滤
auto odd = std::views::iota(1, 20) | std::views::filter([](int n) { return n % 2; });

// transform：转换
auto squares = std::views::iota(1, 10) | std::views::transform([](int n) { return n * n; });

// reverse：反转
auto rev = vec | std::views::reverse;

// unique：去除相邻重复（需要先转换为 common range）
auto uniq = vec | std::views::unique | std::views::common;

// split / lazy_split（C++23）：分割
std::string s = "hello,world";
for (auto word : s | std::views::split(',')) {
    // word 是子字符串的视图
}
```

### 范围算法（代替传统算法）

```cpp
#include <ranges>

std::vector<int> vec = {5, 2, 8, 1, 9, 3};

// 范围版本（惰性求值）
auto result = vec | std::views::filter([](int n) { return n > 3; });

// 排序（需要 to 容器）
std::vector<int> sorted(vec | std::views::all);  // C++23 可以直接用 ranges
std::ranges::sort(sorted);

// 查找
auto it = std::ranges::find(vec, 8);
auto it2 = std::ranges::find_if(vec, [](int n) { return n > 5; });

// 二分查找（容器必须已排序）
std::ranges::binary_search(sorted, 5);

// all_of / any_of / none_of
bool all_pos = std::ranges::all_of(vec, [](int n) { return n > 0; });
```

## 模块（Modules）

### 解决什么问题
头文件依赖导致编译性能差、命名冲突、宏污染。模块（Modules）提供更好的封装和编译性能。

### 核心概念
- 模块接口文件（`.ixx`）导出公共 API
- `export module` 声明模块名
- `import` 导入模块，与 `#include` 类似但更高效
- 模块分区（Partition）组织大型模块

### 怎么用

```cpp
// module.ixx（接口文件）
module;  // 模块单元开始

export module my_module;  // 声明模块名

import std.core;  // 导入标准库

export int add(int a, int b) {
    return a + b;
}

export class Point {
public:
    int x, y;
    Point(int x, int y) : x(x), y(y) {}
};

// 内部细节（不导出）
namespace {
    int helper() { return 42; }
}
```

### 使用模块

```cpp
// main.cpp
import my_module;  // 导入模块
import std.vector;  // C++23 标准库模块

int main() {
    int result = add(3, 4);  // 直接使用，无需 include
    Point p(1, 2);
}
```

### 模块分区

```cpp
// my_module_impl.ixx
module my_module;  // 属于 my_module 的实现分区

int helper_function() {
    return 100;
}

// my_module.ixx
export module my_module;
export import :impl;  // 导出实现分区

export int use_helper() {
    return helper_function();  // 可以调用
}
```

## 三路比较运算符（Spaceship Operator）

### 解决什么问题
重载比较运算符繁琐且容易出错，需要为 `==`、`!=`、`<`、`<=`、`>`、`>=` 分别实现。`<=>` 运算符自动生成所有比较运算符。

### 核心概念
- `<=>` 返回三态比较结果：`std::partial_ordering`、`std::strong_ordering` 或 `std::weak_ordering`
- `operator<=>` = `default` 自动生成所有比较运算符
- 支持链式比较：`a < b < c` 等价于 `(a < b) && (b < c)`

### 怎么用

```cpp
#include <compare>
#include <iostream>

int main() {
    int a = 5, b = 10;

    auto result = a <=> b;

    if (result < 0) {
        std::cout << "a < b\n";  // 输出
    } else if (result > 0) {
        std::cout << "a > b\n";
    } else {
        std::cout << "a == b\n";
    }

    // 支持链式比较（C++20）
    int x = 1, y = 2, z = 3;
    if (x < y < z) {  // 等价于 (x < y) && (y < z)
        std::cout << "x < y < z\n";
    }
}
```

### 自动生成比较运算符

```cpp
class Point {
    int x_, y_;

public:
    auto operator<=>(const Point&) const = default;  // 编译器自动生成所有比较
    // 自动生成: ==, !=, <, <=, >, >=
};

Point p1{1, 2}, p2{1, 2};
if (p1 == p2) { /* true */ }

// 仅生成部分比较
class Person {
    std::string name_;
    int age_;
public:
    auto operator<=>(const Person&) const = default;
    // 生成所有 6 个比较运算符
};
```

## consteval 与 constexpr

### 解决什么问题
需要确保某些计算在编译期完成以提升性能或用于模板元编程。`consteval` 强制编译期求值，`constexpr` 扩展支持动态内存分配。

### 核心概念
- `consteval`（C++20）：强制函数在编译期求值，运行时调用会导致编译错误
- `constexpr` 扩展（C++20）：支持 `std::vector` 等动态容器和 `new`/`delete`
- `std::bit_cast`（C++20）：位模式重解释，需相同大小

### 怎么用

```cpp
// consteval 强制编译期求值
consteval int sqr(int n) {
    return n * n;
}

constexpr int x = sqr(5);   // 编译时计算，x = 25
int y = sqr(6);             // 编译时计算，y = 36

// 以下会编译错误
int z;
std::cin >> z;
int bad = sqr(z);  // 错误：z 不是常量

// constexpr 动态分配（C++20）
constexpr std::vector<int> create_vec() {
    std::vector<int> v;
    v.push_back(1);  // 现在可以在 constexpr 中使用
    v.push_back(2);
    return v;
}

constexpr auto v = create_vec();  // 编译时求值

// std::bit_cast
float f = 3.14159f;
uint32_t bits = std::bit_cast<uint32_t>(f);  // 重新解释为整数的位模式
```

## 立即函数（immediate functions）

### 解决什么问题
需要确保函数在编译期求值用于模板元编程，但 `constexpr` 函数也允许运行时调用。

### 核心概念
- `consteval` 关键字强制函数只能在编译期求值
- 编译期计算的结果可用于数组大小、模板参数等

### 怎么用

```cpp
consteval double sqrt(double x) {
    if (x < 0) throw std::domain_error("negative");
    // 二分查找平方根
    double lo = 0, hi = x;
    while (hi - lo > 1e-9) {
        double mid = (lo + hi) / 2;
        if (mid * mid <= x) lo = mid;
        else hi = mid;
    }
    return lo;
}
```

### std::bit_cast（C++20）

位模式重解释（需相同大小）：

```cpp
#include <bit>
#include <cstdint>

float f = 3.14159f;
uint32_t bits = std::bit_cast<uint32_t>(f);  // 重新解释为整数的位模式
uint32_t bits2 = std::bit_cast<uint32_t>(std::bit_cast<float>(bits));  // 还原
```
