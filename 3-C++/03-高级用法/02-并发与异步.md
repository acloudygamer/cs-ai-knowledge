# 并发与异步

C++11 开始提供完善的并发支持，C++20 和 C++23 继续增强。本章深入讲解现代 C++ 的并发编程，包括线程管理、内存模型、同步原语、并发设计模式和异步编程。

## std::jthread：自动管理的线程（C++20）

`std::jthread` 是 C++20 引入的智能线程，会在析构时自动 join，避免忘记调用 `join()` 导致的悬挂线程。

### 基础用法

```cpp
#include <thread>
#include <iostream>

void worker(int id) {
    std::cout << "Worker " << id << " running\n";
}

int main() {
    // 普通 thread：需要手动 join 或 detach
    std::thread t1(worker, 1);
    t1.join();  // 必须记得调用

    // jthread：自动 join
    std::jthread t2(worker, 2);
    // 无需手动 join，析构时自动调用

    std::cout << "Main continues\n";
    // t2 在离开作用域时自动 join
}
```

### 请求停止

`std::jthread` 支持协作式停止，通过 `std::stop_token` 实现：

```cpp
#include <thread>
#include <iostream>
#include <chrono>

void infinite_loop(std::stop_token token) {
    int count = 0;
    // 检查停止请求
    while (!token.stop_requested()) {
        std::cout << "Working... " << ++count << "\n";
        std::this_thread::sleep_for(std::chrono::seconds(1));
    }
    std::cout << "Stopped\n";
}

int main() {
    std::jthread worker(infinite_loop);

    // 主线程做一些其他事情
    std::this_thread::sleep_for(std::chrono::seconds(3));

    // 请求停止
    worker.request_stop();  // worker 会在当前循环迭代结束后检查并退出

    // 也可以在 jthread 析构时自动请求停止
}
```

### jthread 与 stop_token

```cpp
#include <thread>
#include <iostream>
#include <vector>

void parallel_work(std::stop_token token, int id) {
    while (!token.stop_requested()) {
        // 处理工作
        std::cout << "Task " << id << " running\n";
        std::this_thread::sleep_for(std::chrono::milliseconds(100));
    }
}

int main() {
    std::vector<std::jthread> workers;

    // 创建多个工作线程
    for (int i = 0; i < 4; ++i) {
        workers.emplace_back(parallel_work, i);
    }

    // 主线程
    std::this_thread::sleep_for(std::chrono::seconds(2));

    // 一次性停止所有线程
    // workers 析构时会自动调用 request_stop() 并 join
}
```

## 内存顺序与原子操作

### 内存顺序基础

C++ 的内存模型定义了六种内存顺序，用于控制多线程间的可见性和排序：

| 内存顺序 | 说明 | 使用场景 |
|----------|------|----------|
| `std::memory_order_seq_cst` | 顺序一致（默认） | 严格要求顺序 |
| `std::memory_order_acquire` | 获取 | 读操作，后续读写不能重排 |
| `std::memory_order_release` | 释放 | 写操作，之前读写不能重排 |
| `std::memory_order_acq_rel` | 获取-释放 | 读-改-写操作 |
| `std::memory_order_relaxed` | 松弛 | 仅保证原子性，无顺序保证 |
| `std::memory_order_consume` | 消费（已废弃） | 数据依赖的读 |

### 顺序一致（seq_cst）

```cpp
#include <atomic>
#include <thread>
#include <iostream>

std::atomic<int> x(0);
std::atomic<int> y(0);

// 顺序一致：所有线程看到相同的操作顺序
void seq_cst_writer() {
    x.store(1, std::memory_order_seq_cst);
    y.store(1, std::memory_order_seq_cst);
}

void seq_cst_reader() {
    // 确保看到 x 和 y 的正确顺序
    while (y.load(std::memory_order_seq_cst) == 0) {}
    // 此时 x 一定已经被写入
    std::cout << "x = " << x.load(std::memory_order_seq_cst) << "\n";
}
```

### 获取-释放（acquire-release）

```cpp
#include <atomic>
#include <thread>
#include <vector>

std::atomic<int*> ptr(nullptr);
std::atomic<int> data(0);

// 生产者
void producer() {
    int local_data = 42;
    int* new_ptr = new int(local_data);

    // Release：之前的读写不能重排到此操作之后
    // 同时保证 new_ptr 的写入对消费者可见
    data.store(local_data, std::memory_order_relaxed);
    ptr.store(new_ptr, std::memory_order_release);
}

// 消费者
void consumer() {
    int* expected_ptr = nullptr;

    // Acquire：如果看到非空指针，则之前的写入都可见
    // compare_exchange_* 默认使用 seq_cst，但可以指定
    while (!ptr.compare_exchange_strong(expected_ptr, nullptr,
                                        std::memory_order_acquire,
                                        std::memory_order_relaxed)) {
        expected_ptr = nullptr;
    }

    // 此时 ptr 指向非空，data 也已经被写入
    std::cout << "data = " << data.load(std::memory_order_relaxed) << "\n";
    delete expected_ptr;
}
```

### 松弛操作（relaxed）

```cpp
#include <atomic>
#include <thread>

std::atomic<int> counter(0);

// 松弛：只保证原子性，不保证顺序
// 适用于计数器等不依赖顺序的场景
void increment() {
    // fetch_add 返回旧值，但顺序不确定
    counter.fetch_add(1, std::memory_order_relaxed);
}

int main() {
    std::thread t1(increment);
    std::thread t2(increment);

    t1.join();
    t2.join();

    // 最终 counter == 2，但中间过程不可预测
    std::cout << "counter = " << counter.load() << "\n";
}
```

### 内存栅栏（Fence）

```cpp
#include <atomic>
#include <thread>

std::atomic<int> x(0);
std::atomic<int> y(0);

// 全局栅栏
void with_fence() {
    x.store(1, std::memory_order_relaxed);

    // 栅栏：强制刷新所有写操作
    std::atomic_thread_fence(std::memory_order_release);

    y.store(1, std::memory_order_relaxed);
}

void with_fence_reader() {
    // 读取 y
    while (y.load(std::memory_order_relaxed) == 0) {}

    // 栅栏：强制所有读操作在之后执行
    std::atomic_thread_fence(std::memory_order_acquire);

    // 此时 x 一定已经被写入
    std::cout << "x = " << x.load(std::memory_order_relaxed) << "\n";
}
```

## 深入 std::atomic

### 指针原子操作

```cpp
#include <atomic>
#include <thread>

struct Node {
    int value;
    Node* next;
};

std::atomic<Node*> head(nullptr);

// 无锁链表插入
void push(int val) {
    Node* new_node = new Node{val, head.load()};

    // 直到 head 仍指向 new_node->next，才更新 head
    // 失败时重试
    while (!head.compare_exchange_weak(new_node->next, new_node,
                                       std::memory_order_release,
                                       std::memory_order_relaxed)) {
        // new_node->next 已被更新为当前 head
    }
}

bool pop(int& val) {
    Node* old_head = head.load(std::memory_order_acquire);

    while (old_head != nullptr) {
        if (head.compare_exchange_weak(old_head, old_head->next,
                                       std::memory_order_acq_rel,
                                       std::memory_order_acquire)) {
            val = old_head->value;
            delete old_head;
            return true;
        }
    }
    return false;
}
```

### atomic_flag

```cpp
#include <atomic>
#include <thread>
#include <vector>

// 最简单的锁实现
class SpinLock {
    std::atomic_flag flag = ATOMIC_FLAG_INIT;
public:
    void lock() {
        // test_and_set：原子地将 flag 设为 true，返回旧值
        // false 表示之前未被设置（获得锁）
        // true 表示之前已被设置（等待）
        while (flag.test_and_set(std::memory_order_acquire)) {
            // 自旋等待
            std::this_thread::yield();
        }
    }

    void unlock() {
        flag.clear(std::memory_order_release);
    }
};

SpinLock spin;

// 使用
void critical_section(int id) {
    spin.lock();
    std::cout << "Task " << id << " in critical section\n";
    spin.unlock();
}
```

## 线程池实现

### 简单线程池

```cpp
#include <thread>
#include <vector>
#include <queue>
#include <mutex>
#include <condition_variable>
#include <functional>
#include <future>
#include <iostream>

class ThreadPool {
    std::vector<std::thread> workers_;
    std::queue<std::function<void()>> tasks_;
    std::mutex mutex_;
    std::condition_variable cv_;
    bool stop_ = false;

public:
    explicit ThreadPool(size_t threads) {
        for (size_t i = 0; i < threads; ++i) {
            workers_.emplace_back([this] {
                while (true) {
                    std::function<void()> task;
                    {
                        std::unique_lock lock(mutex_);
                        cv_.wait(lock, [this] {
                            return stop_ || !tasks_.empty();
                        });

                        if (stop_ && tasks_.empty()) {
                            return;
                        }

                        task = std::move(tasks_.front());
                        tasks_.pop();
                    }
                    task();
                }
            });
        }
    }

    ~ThreadPool() {
        {
            std::lock_guard lock(mutex_);
            stop_ = true;
        }
        cv_.notify_all();
        for (auto& worker : workers_) {
            worker.join();
        }
    }

    template<typename F, typename... Args>
    auto submit(F&& f, Args&&... args) -> std::future<std::invoke_result_t<F, Args...>> {
        using ReturnType = std::invoke_result_t<F, Args...>;

        auto task = std::make_shared<std::packaged_task<ReturnType()>>(
            [f = std::forward<F>(f), args...]() mutable {
                return std::invoke(f, args...);
            }
        );

        {
            std::lock_guard lock(mutex_);
            tasks_.emplace([task]() { (*task)(); });
        }

        cv_.notify_one();
        return task->get_future();
    }
};

// 使用
int main() {
    ThreadPool pool(4);

    auto f1 = pool.submit([]() {
        return 42;
    });

    auto f2 = pool.submit([](int x, int y) {
        return x + y;
    }, 10, 20);

    std::cout << "f1: " << f1.get() << "\n";
    std::cout << "f2: " << f2.get() << "\n";
}
```

### std::when_all 与 std::when_any

> **注意**：`std::when_all` 和 `std::when_any` 并非 C++ 标准库的一部分。它们是第三方库（如 PPL、TBB）或 C++26 `std::execution` 提案中的功能。

标准库的替代方案是使用 `std::future` 手动等待：

```cpp
#include <future>
#include <iostream>
#include <chrono>
#include <vector>

int main() {
    // 启动多个异步任务
    std::future<int> f1 = std::async([]() {
        std::this_thread::sleep_for(std::chrono::milliseconds(100));
        return 1;
    });

    std::future<int> f2 = std::async([]() {
        std::this_thread::sleep_for(std::chrono::milliseconds(50));
        return 2;
    });

    std::future<int> f3 = std::async([]() {
        std::this_thread::sleep_for(std::chrono::milliseconds(150));
        return 3;
    });

    // 手动收集并等待所有 future
    std::vector<std::future<int>> futures = {std::move(f1), std::move(f2), std::move(f3)};

    for (auto& f : futures) {
        std::cout << f.get() << "\n";
    }
}
```

**C++26 建议**：C++26 引入了 `std::execution` 库，提供了统一的发送方-接收方模型和 `when_all` 等算法，详见 [C++26 新特性](./16-C++26新特性.md)。

## 同步原语深入

### std::latch（C++20）

`std::latch` 是一次性屏障，计数只能减不能增：

```cpp
#include <latch>
#include <thread>
#include <vector>
#include <iostream>

int main() {
    const size_t num_workers = 3;
    std::latch start_latch(num_workers);

    std::vector<std::thread> workers;

    for (size_t i = 0; i < num_workers; ++i) {
        workers.emplace_back([&, id = i]() {
            std::cout << "Worker " << id << " preparing...\n";
            // 做准备工作
            std::this_thread::sleep_for(std::chrono::milliseconds(100));

            // 到达屏障
            start_latch.count_down();
            std::cout << "Worker " << id << " started\n";
        });
    }

    // 等待所有 worker 就绪
    start_latch.wait();
    std::cout << "All workers ready, starting main work\n";

    for (auto& w : workers) {
        w.join();
    }
}
```

### std::barrier（C++20）

`std::barrier` 是可重置的屏障，可以重复使用：

```cpp
#include <barrier>
#include <thread>
#include <vector>
#include <iostream>

int main() {
    const size_t num_phases = 3;
    std::barrier phase_barrier(num_phases);

    std::vector<std::thread> workers;

    for (size_t i = 0; i < num_phases; ++i) {
        workers.emplace_back([&, id = i]() {
            for (size_t phase = 0; phase < 3; ++phase) {
                std::cout << "Worker " << id << " doing phase " << phase << "\n";

                // 模拟工作
                std::this_thread::sleep_for(std::chrono::milliseconds(50));

                // 等待其他 worker 完成此阶段
                phase_barrier.arrive_and_wait();
            }
        });
    }

    for (auto& w : workers) {
        w.join();
    }
}
```

### std::barrier 改进（C++23）

C++23 对 `std::barrier` 进行了改进：

```cpp
#include <barrier>
#include <thread>

void barrier_example() {
    std::barrier<> barrier(3);

    std::thread t1([&]() {
        barrier.arrive();  // C++23: arrive() 现为 noexcept
    });

    std::thread t2([&]() {
        barrier.arrive_and_wait();  // 计数并等待
    });
}
```

C++23 将 `arrive()` 声明为 `noexcept`，提升性能并允许更高效的实现。

`thread_local` 关键字为每个线程提供独立的变量副本：

## 并发设计模式

### 生产者-消费者模式

```cpp
#include <thread>
#include <queue>
#include <mutex>
#include <condition_variable>
#include <atomic>
#include <chrono>
#include <iostream>

template<typename T>
class ThreadSafeQueue {
    std::queue<T> queue_;
    std::mutex mutex_;
    std::condition_variable cv_;
    std::atomic<bool> stop_{false};

public:
    void push(T value) {
        {
            std::lock_guard lock(mutex_);
            if (stop_.load()) return;
            queue_.push(std::move(value));
        }
        cv_.notify_one();
    }

    bool pop(T& value) {
        std::unique_lock lock(mutex_);
        cv_.wait(lock, [this] { return !queue_.empty() || stop_.load(); });

        if (queue_.empty()) return false;

        value = std::move(queue_.front());
        queue_.pop();
        return true;
    }

    void stop() {
        {
            std::lock_guard lock(mutex_);
            stop_.store(true);
        }
        cv_.notify_all();
    }
};

ThreadSafeQueue<int> g_queue;
std::atomic<int> g_item_count(0);

void producer(int id, int count) {
    for (int i = 0; i < count; ++i) {
        g_queue.push(id * 1000 + i);
        std::this_thread::sleep_for(std::chrono::milliseconds(10));
    }
}

void consumer(int id) {
    while (true) {
        int value;
        if (!g_queue.pop(value)) {
            break;
        }
        std::cout << "Consumer " << id << " got: " << value << "\n";
        g_item_count.fetch_add(1);
    }
}

int main() {
    std::vector<std::thread> producers;
    std::vector<std::thread> consumers;

    // 启动生产者
    for (int i = 0; i < 2; ++i) {
        producers.emplace_back(producer, i, 5);
    }

    // 启动消费者
    for (int i = 0; i < 3; ++i) {
        consumers.emplace_back(consumer, i);
    }

    // 等待生产者完成
    for (auto& p : producers) {
        p.join();
    }

    // 停止消费者
    g_queue.stop();
    for (auto& c : consumers) {
        c.join();
    }

    std::cout << "Total items processed: " << g_item_count.load() << "\n";
}
```

### 读写锁模式

```cpp
#include <shared_mutex>
#include <thread>
#include <map>
#include <string>
#include <chrono>
#include <iostream>

class ThreadSafeMap {
    std::map<std::string, std::string> data_;
    mutable std::shared_mutex mutex_;

public:
    // 读操作：多个线程可以同时读
    std::string get(const std::string& key) const {
        std::shared_lock lock(mutex_);
        auto it = data_.find(key);
        return it != data_.end() ? it->second : "";
    }

    bool contains(const std::string& key) const {
        std::shared_lock lock(mutex_);
        return data_.find(key) != data_.end();
    }

    // 写操作：独占访问
    void set(const std::string& key, const std::string& value) {
        std::unique_lock lock(mutex_);
        data_[key] = value;
    }

    // 批量读（快照）
    std::map<std::string, std::string> snapshot() const {
        std::shared_lock lock(mutex_);
        return data_;  // 拷贝整个 map
    }
};

ThreadSafeMap g_cache;

void reader(int id) {
    for (int i = 0; i < 100; ++i) {
        std::string value = g_cache.get("key");
        std::cout << "Reader " << id << " got: " << value << "\n";
        std::this_thread::sleep_for(std::chrono::microseconds(10));
    }
}

void writer(int id) {
    for (int i = 0; i < 10; ++i) {
        g_cache.set("key", "value_from_writer_" + std::to_string(id));
        std::cout << "Writer " << id << " wrote\n";
        std::this_thread::sleep_for(std::chrono::milliseconds(5));
    }
}
```

### 线程安全的单例模式

```cpp
#include <mutex>
#include <memory>

class Singleton {
    static std::atomic<Singleton*> instance_;
    static std::mutex mutex_;

    Singleton() = default;
    Singleton(const Singleton&) = delete;
    Singleton& operator=(const Singleton&) = delete;

public:
    ~Singleton() = default;

    static Singleton* get_instance() {
        Singleton* tmp = instance_.load(std::memory_order_acquire);
        if (tmp == nullptr) {
            std::lock_guard lock(mutex_);
            tmp = instance_.load(std::memory_order_relaxed);
            if (tmp == nullptr) {
                tmp = new Singleton();
                instance_.store(tmp, std::memory_order_release);
            }
        }
        return tmp;
    }
};

// 静态成员初始化
std::atomic<Singleton*> Singleton::instance_{nullptr};
std::mutex Singleton::mutex_;
```

### 更简洁的单例：C++11 完美方案

```cpp
class Singleton {
    Singleton() = default;

public:
    static Singleton& get_instance() {
        // 静态局部变量保证线程安全（C++11）
        static Singleton instance;
        return instance;
    }

    // 删除拷贝和移动
    Singleton(const Singleton&) = delete;
    Singleton& operator=(const Singleton&) = delete;
    Singleton(Singleton&&) = delete;
    Singleton& operator=(Singleton&&) = delete;
};
```

## 死锁避免

### 死锁的四个必要条件

1. **互斥**：资源一次只能被一个线程持有
2. **持有并等待**：线程持有资源同时等待其他资源
3. **非抢占**：资源不能被强制夺走
4. **循环等待**：形成线程间的循环等待链

### 避免死锁的策略

```cpp
#include <mutex>
#include <thread>
#include <iostream>
#include <chrono>

// 策略1：固定加锁顺序
class FixedOrderLock {
    std::mutex mutex_a_;
    std::mutex mutex_b_;

public:
    void operation_ab() {
        // 始终先锁 a 再锁 b
        std::lock_guard lock_a(mutex_a_);
        std::this_thread::sleep_for(std::chrono::milliseconds(10));  // 模拟延迟
        std::lock_guard lock_b(mutex_b_);

        std::cout << "Operation AB by " << std::this_thread::get_id() << "\n";
    }

    void operation_ba() {
        // 始终先锁 a 再锁 b（与 operation_ab 一致）
        std::lock_guard lock_a(mutex_a_);
        std::this_thread::sleep_for(std::chrono::milliseconds(10));
        std::lock_guard lock_b(mutex_b_);

        std::cout << "Operation BA by " << std::this_thread::get_id() << "\n";
    }
};

// 策略2：使用 std::lock 同时锁定多个互斥量
class MultiLock {
    std::mutex mutex_a_;
    std::mutex mutex_b_;

public:
    void operation_ab() {
        // std::lock 会使用死锁避免算法
        std::lock(mutex_a_, mutex_b_);
        std::lock_guard lock_a(mutex_a_, std::adopt_lock);
        std::lock_guard lock_b(mutex_b_, std::adopt_lock);

        std::cout << "Operation AB by " << std::this_thread::get_id() << "\n";
    }

    void operation_ba() {
        std::lock(mutex_b_, mutex_a_);  // 参数顺序不影响
        std::lock_guard lock_b(mutex_b_, std::adopt_lock);
        std::lock_guard lock_a(mutex_a_, std::adopt_lock);

        std::cout << "Operation BA by " << std::this_thread::get_id() << "\n";
    }
};

// 策略3：scoped_lock（C++17）
#include <mutex>

class ScopedLockExample {
    std::mutex mutex_a_;
    std::mutex mutex_b_;

public:
    void operation() {
        // std::scoped_lock 自动推导需要锁定的互斥量
        std::scoped_lock lock(mutex_a_, mutex_b_);

        std::cout << "Protected operation by " << std::this_thread::get_id() << "\n";
    }
};
```

```cpp

    int balance_;
    mutable std::mutex mutex_;

        std::scoped_lock lock(mutex_, from.mutex_);

        std::lock_guard lock(mutex_);
        return balance_;
    }
};
```

## 条件变量深入

### 虚假唤醒防护

```cpp
#include <condition_variable>
#include <mutex>
#include <thread>
#include <iostream>
#include <queue>

template<typename T>
class ThreadSafeQueue {
    std::queue<T> queue_;
    mutable std::mutex mutex_;
    std::condition_variable cv_;

public:
    void push(T value) {
        {
            std::lock_guard lock(mutex_);
            queue_.push(std::move(value));
        }
        cv_.notify_one();
    }

    bool pop(T& value) {
        std::unique_lock lock(mutex_);

        // 使用带谓词的 wait：必须满足条件才返回
        // 虚假唤醒时会重新检查条件
        cv_.wait(lock, [this] { return !queue_.empty(); });

        value = std::move(queue_.front());
        queue_.pop();
        return true;
    }

    // 带超时的 pop
    bool pop_with_timeout(T& value, std::chrono::milliseconds timeout) {
        std::unique_lock lock(mutex_);

        if (!cv_.wait_for(lock, timeout, [this] { return !queue_.empty(); })) {
            return false;  // 超时
        }

        value = std::move(queue_.front());
        queue_.pop();
        return true;
    }
};
```

### 生产者-消费者与广播

```cpp
#include <condition_variable>
#include <mutex>
#include <thread>
#include <vector>
#include <iostream>

class WorkQueue {
    std::queue<int> tasks_;
    std::mutex mutex_;
    std::condition_variable cv_;
    bool stop_ = false;

public:
    void produce(int task) {
        {
            std::lock_guard lock(mutex_);
            if (stop_) return;
            tasks_.push(task);
        }
        cv_.notify_one();  // 只唤醒一个消费者
    }

    void produce_batch(std::vector<int> new_tasks) {
        {
            std::lock_guard lock(mutex_);
            if (stop_) return;
            for (int task : new_tasks) {
                tasks_.push(task);
            }
        }
        cv_.notify_all();  // 唤醒所有消费者
    }

    bool consume(int& task) {
        std::unique_lock lock(mutex_);
        cv_.wait(lock, [this] { return !tasks_.empty() || stop_; });

        if (tasks_.empty()) return false;

        task = tasks_.front();
        tasks_.pop();
        return true;
    }

    void shutdown() {
        {
            std::lock_guard lock(mutex_);
            stop_ = true;
        }
        cv_.notify_all();
    }
};
```

```cpp
    std::shared_future<int> sf = f.share();

        });
    }

    // 设置值，所有等待的线程都会收到
    p.set_value(100);

        t.join();
    }
}
```

## 线程取消与停止

### 协作式取消模式

```cpp
#include <thread>
#include <atomic>
#include <vector>
#include <iostream>

class CancellationToken {
    std::atomic<bool> cancelled_{false};

public:
    void cancel() { cancelled_.store(true); }
    bool is_cancelled() const { return cancelled_.load(); }
};

void long_running_task(CancellationToken& token) {
    int count = 0;
    while (!token.is_cancelled()) {
        std::cout << "Working... " << ++count << "\n";
        std::this_thread::sleep_for(std::chrono::milliseconds(100));

        // 定期检查取消请求
        if (count % 10 == 0) {
            // 可以做清理工作
        }
    }
    std::cout << "Task cancelled at count " << count << "\n";
}

int main() {
    CancellationToken token;
    std::thread worker(long_running_task, std::ref(token));

    std::this_thread::sleep_for(std::chrono::seconds(1));
    token.cancel();

    worker.join();
}
```

## 常见并发问题

### 数据竞争


### 死锁

```cpp
#include <mutex>
#include <thread>

// 错误：可能死锁
class BrokenAccount {
    std::mutex mutex_;
    int balance_ = 100;

public:
    void transfer_to(BrokenAccount& other, int amount) {
        // 如果两个线程同时调用 A.transfer_to(B) 和 B.transfer_to(A)
        // 可能死锁
        std::lock_guard lock(mutex_);
        std::this_thread::sleep_for(std::chrono::milliseconds(1));
        std::lock_guard lock_other(other.mutex_);  // 可能死锁！

        balance_ -= amount;
        other.balance_ += amount;
    }
};

// 正确：使用 std::lock
class SafeAccount {
    std::mutex mutex_a_;
    std::mutex mutex_b_;
    int balance_ = 100;

public:
    void transfer_to(SafeAccount& other, int amount) {
        // std::lock 避免死锁
        std::lock(mutex_a_, other.mutex_b_);
        std::lock_guard lock_a(mutex_a_, std::adopt_lock);
        std::lock_guard lock_other(other.mutex_b_, std::adopt_lock);

        balance_ -= amount;
        other.balance_ += amount;
    }
};
```

### 竞态条件

```cpp
#include <atomic>
#include <thread>

// 错误：检查然后操作不是原子
bool flag = false;
int data = 0;

void writer() {
    data = 42;
    flag = true;  // 可能编译器优化导致 flag 在 data 之前被写入
}

void reader() {
    if (flag) {  // 可能在 data 被写入前就看到 flag
        // data 可能还是 0
        std::cout << data << "\n";  // 未定义行为
    }
}

// 正确：使用内存顺序
std::atomic<bool> safe_flag(false);
std::atomic<int> safe_data(0);

void safe_writer() {
    safe_data.store(42, std::memory_order_relaxed);
    safe_flag.store(true, std::memory_order_release);  // 屏障
}

void safe_reader() {
    if (safe_flag.load(std::memory_order_acquire)) {
        // 此时 safe_data 一定已经被写入
        std::cout << safe_data.load(std::memory_order_relaxed) << "\n";
    }
}
```

## 性能考虑

### 何时使用多线程

```cpp
// 适合多线程：
// - I/O 密集型任务（等待网络、磁盘）
// - 可以并行化的独立计算
// - 响应性要求高的 UI 任务

// 不适合多线程：
// - 简单小任务（线程开销可能大于任务本身）
// - 高度依赖共享数据的任务
// - 实时系统（线程调度不确定）
```

### 减少锁竞争

```cpp
#include <mutex>
#include <thread>
#include <vector>
#include <atomic>

// 策略1：减小临界区
void bad_reduce_counter(std::atomic<int>& counter, int times) {
    for (int i = 0; i < times; ++i) {
        // 锁在循环内部，每次迭代都要加锁
        counter.fetch_add(1);
    }
}

// 策略2：使用线程局部计数，最后合并
void good_reduce_counter(std::atomic<int>& total, int times) {
    thread_local int local_count = 0;

    for (int i = 0; i < times; ++i) {
        local_count++;  // 无锁
    }

    total.fetch_add(local_count);  // 最后只加锁一次
}
```

### false sharing 避免

```cpp
#include <atomic>
#include <thread>
#include <array>

// 错误：false sharing
struct BadCounter {
    std::atomic<int> counter[4];
};

void bad_increment(BadCounter& c, int idx) {
    for (int i = 0; i < 1000000; ++i) {
        c.counter[idx].fetch_add(1);  // 相邻的 counter 可能在同一缓存行
    }
}

// 正确：使用 padding 分隔
struct GoodCounter {
    struct PaddedCounter {
        std::atomic<int> value;
        char padding[64 - sizeof(std::atomic<int>)];  // 填满缓存行
    };
    PaddedCounter counter[4];
};

void good_increment(GoodCounter& c, int idx) {
    for (int i = 0; i < 1000000; ++i) {
        c.counter[idx].value.fetch_add(1);
    }
}
```

### 并行计算框架

```cpp
#include <future>
#include <vector>
#include <functional>
#include <thread>
#include <iostream>

template<typename T>
class ParallelExecutor {
    size_t num_threads_;

public:
    explicit ParallelExecutor(size_t num_threads = std::thread::hardware_concurrency())
        : num_threads_(num_threads) {}

    template<typename F, typename... Args>
    std::vector<std::future<std::invoke_result_t<F, Args...>>>
    map(F&& func, std::vector<std::invoke_result_t<F, Args...>>& inputs) {
        std::vector<std::future<std::invoke_result_t<F, Args...>>> futures;
        futures.reserve(inputs.size());

        for (auto& input : inputs) {
            futures.push_back(std::async(std::launch::async, func, input));
        }

        return futures;
    }
};

int main() {
    ParallelExecutor<int> executor;

    std::vector<int> inputs = {1, 2, 3, 4, 5, 6, 7, 8};
    auto results = executor.map([](int x) { return x * x; }, inputs);

    for (auto& f : results) {
        std::cout << f.get() << " ";
    }
    std::cout << "\n";
}
```
