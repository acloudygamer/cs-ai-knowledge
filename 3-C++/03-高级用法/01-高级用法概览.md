## 学习路径建议

### 路线一：并发与系统编程
```
并发与异步 → 内存管理 → 性能优化 → 链接与ABI基础
```

### 路线二：泛型与元编程
```
TypeTraits完整指南 → Lambda高级用法 → 移动语义深入 → C++20新特性
```

### 路线三：现代 C++ 开发者
```
C++20新特性 → C++23新特性 → C++26新特性 → 协程深入
```

## 版本说明

- **C++20**：基础版本，引入 Concepts、Ranges、模块、协程
- **C++23**：增强版本，std::expected、constexpr 扩展
- **C++26**：前沿版本，std::execution、反射

建议按顺序学习，但 C++20 新特性可独立深入。
