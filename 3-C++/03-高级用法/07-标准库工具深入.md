# 标准库工具深入

> **版本关系**：C++17（string_view、optional）→ C++20（span、format）→ C++23（expected）→ C++26

## 定义

**非拥有型视图（string_view、span）通过指针+长度消除拷贝，承诺"借用"而非"拥有"。expected 用类型系统将错误处理提升为值等价物。**

**核心不变量**：非拥有型视图所引用的数据**必须保持有效**，这是使用者的责任，而非视图的责任。

## 数学模型

### string_view 的字符串空间

设 $S$ 为字符串集合，$s \in S$ 是连续的字符序列：

$$\text{string\_view}(s) = (p, \text{len})$$

其中 $p$ 是指向 $s$ 首字符的指针，$\text{len} = |s|$。$p$ 可以指向任意位置，包括 $s$ 的子串：

$$\text{string\_view}(s[i:j]) = (p+i, j-i)$$

**切片操作不拷贝**，这是 `string_view` 的本质价值。

### expected 的和类型语义

`expected<T, E>` 是 **sum type**：

$$\text{expected} \equiv \text{Either}\ T\ E$$

$$\text{expected} = \text{Value}(T) \mid \text{Error}(E)$$

对应 Haskell 的 `Either a b`，Rust 的 `Result<T, E>`。

**链式操作（`.and_then()`）** 对应函数式编程的 bind 操作符（$\text{>>=}$）：

$$\text{.and_then}(f)(v) = \begin{cases} f(v) & \text{if } v \text{ is Value} \\ \text{Error}(e) & \text{if } v \text{ is Error} \end{cases}$$

### span 的静态 vs 动态 extent

```cpp
span<int, 10>   // 静态 extent：大小编译期已知
span<int>        // 动态 extent：大小运行时确定
```

**类型级大小信息**（静态 extent）使编译器可以进行边界检查优化：

$$\text{sizeof}(\text{span}<T, N>) = \text{sizeof}(T*) + \underbrace{0}_{\text{不需要 size\_t}} = 8\ \text{bytes}$$

$$\text{sizeof}(\text{span}<T, \text{dynamic}>) = \text{sizeof}(T*) + \text{sizeof}(\text{size\_t}) = 16\ \text{bytes}$$

### std::format 的解析状态机

格式化字符串是一个**上下文无关文法**：

```
FormatString ::= (Literal | ReplacementField)*
ReplacementField ::= '{' [ArgumentIndex] [':' FormatSpec] '}'
```

解析器状态机：
```
START ──► LITERAL ──► REPLACEMENT ──► FORMAT_SPEC ──► END
            │              │              │
            └──── chars ────┘──── chars ────┘
```

## 机制

### string_view 的使用不变量

**必须满足**：

```cpp
string_view sv(p, len);
// 1. p 必须非空（或 len == 0）
// 2. [p, p+len) 必须是有序字符序列
// 3. 该内存范围在 sv 存活期内必须保持有效
```

**违反后果**：
- 指向已析构的 `std::string`：未定义行为，use-after-free
- 指向 `const char*` 但字符串中间有 `\0`：大多数操作不受影响（`string_view` 不依赖 `\0`），但 `sv.data()` 会包含 `\0`
- `substr()` 返回的新 `string_view`：若原 `string_view` 违反不变量，新视图也违反

**常见陷阱**：

```cpp
std::string get_name() { return "Alice"; }
std::string_view sv = get_name();
// 灾难：sv 引用的临时 string 在语句结束时析构
// string_view 不延长临时对象生命周期！
```

### span 的边界语义

**`span::at()` vs `span::operator[]`**：

- `operator[]`：**不检查**边界，返回引用；越界是未定义行为
- `at()`：**检查**边界，越界抛出 `std::out_of_range`

```cpp
span<int> s(arr, 10);
s[10];   // 未定义行为
s.at(10); // 抛出 out_of_range
```

**子视图**：

```cpp
span<int, 10> s(arr, 10);
auto sub = s.subspan(2, 4);   // span<int, 4>
auto tail = s.last<3>();       // span<int, 3>
```

### std::format 的类型安全原理

**printf 的不安全来源**：

```cpp
printf("%s", 42);  // 灾难：int 被解释为指针
// 未定义行为：访问无效内存地址
```

**format 的编译期检查**：

```cpp
std::format("{} {}", 1, 2);    // OK：类型匹配
std::format("{:s}", 42);       // 编译错误：int 不是字符串类型
// 格式化器在编译期检查格式说明符与参数类型的一致性
```

**格式说明符的上下文无关语法**：

$$\text{FormatSpec} ::= [\text{fill_and_align}][\text{sign}][\text{'#'}][\text{'0'}][\text{width}][\text{'.' precision}][\text{type}]$$

### expected 的 monadic 链

```cpp
std::expected<int, std::error_code> parse_number(std::string_view sv);

// 链式错误处理
auto r = parse_number(sv)
    .and_then([](int n) {
        if (n < 0) return std::expected<int, Error>{std::unexpect, Error::NegativeNotAllowed};
        return std::expected<int, Error>(n);
    })
    .transform([](int n) { return n * 2; })  // 值存在时应用
    .transform_error([](Error e) { return log_error(e); });  // 错误时应用
```

**与异常的对比**：

| 特性 | 异常 | expected |
|------|------|----------|
| 检查时机 | 运行时 | 编译期（通过类型系统） |
| 遗忘风险 | 高（未捕获会栈展开） | 低（必须解包） |
| 性能（无错误时） | 略低（栈展开机制） | 零成本 |
| 性能（错误时） | 栈展开成本 | 同返回值 |

### std::optional 的语义

`std::optional<T>` 表示**可能有、可能无**的值：

$$\text{optional} \ T = \text{Nothing} \mid \text{Just}(T)$$

```cpp
std::optional<int> find(const std::vector<int>& v, int target) {
    for (size_t i = 0; i < v.size(); ++i)
        if (v[i] == target) return i;  // 自动包装为 optional
    return std::nullopt;
}
```

**与指针的区别**：
- `optional<T&>` 允许引用（`T*` 不允许空引用）
- `optional` 语义更清晰："值可能不存在"而非"指针可能为空"

## 参考存根

```cpp
// string_view 的安全使用
std::string_view extract_extension(std::string_view path) {
    auto pos = path.find_last_of("./\\");
    if (pos == std::string_view::npos || path[pos] != '.')
        return {};
    return path.substr(pos);
}

// span 的类型级大小
void process_matrix(span<int, 784> data);  // 固定大小，编译期检查
void process_dynamic(span<int> data);        // 动态大小，运行时检查

// expected 的函数式组合
std::expected<int, std::string> safe_divide(int a, int b) {
    if (b == 0) return std::unexpected("division by zero");
    return a / b;
}

auto result = safe_divide(10, 2)
    .and_then([](int q) { return safe_divide(q, 2); })
    .transform([](int q) { return q * 2; });

if (result)
    std::println("{}", *result);
else
    std::println("Error: {}", result.error());

// std::format 的自定义类型
template<>
struct std::formatter<Point> {
    constexpr auto parse(auto& ctx) { return ctx.begin(); }
    auto format(const Point& p, auto& ctx) const {
        return std::format_to(ctx.out(), "({}, {})", p.x, p.y);
    }
};
```
