# 协程深入

> **版本关系**：C++20（基础）→ C++26（std::generator）

**协程是函数可以在挂起点暂停并在后续恢复执行的抽象，适合异步 I/O 和流式处理。**

## 定义

| 概念 | 一句话断言 |
|------|-----------|
| coroutine_handle | 控制协程生命周期（创建、恢复、销毁）的句柄 |
| promise_type | 定义协程行为：初始挂起点、最终挂起点、返回值、异常处理 |
| co_await | 挂起协程等待异步操作完成 |
| co_return | 从协程返回值（隐式调用 promise.return_value） |
| std::generator | C++26 标准生成器，替代手写 promise_type |

## 数据流

<pre>
调用协程               协程执行                恢复执行
   │                     │                       │
   ├─ 创建协程帧        ├─ initial_suspend()     │
   │                     │                       │
   │                     ├─ 执行直到 co_await    ├─ await_resume()
   │                     │       │               │
   │                     │       ▼               │
   │                     ├─ await_suspend() ────┼─ 保存 handle
   │                     │                       │
   │                     ├─ 执行直到 co_return   │
   │                     │                       │
   │                     ├─ final_suspend()     │
   │                     │                       │
   └─ 返回协程句柄       └─ 协程帧仍存在         └─ handle.resume()
                                                     │
                                                     └─ 协程帧销毁
</pre>

## 机制

**协程与普通函数的本质区别**：普通函数调用→执行→返回，调用者等待函数完全执行完毕。协程可以在执行过程中挂起（suspend），让出控制权给其他任务，之后再恢复（resume）。

**promise_type 四个关键点**：1. `get_return_object()` 创建协程的返回值对象；2. `initial_suspend()` 决定协程体是否立即开始执行（C++20 通常 `suspend_always` 让调用者先拿到句柄）；3. `return_value(v)` 或 `return_void()` 定义 `co_return` 的行为；4. `final_suspend()` 决定协程结束时是否挂起（通常 `suspend_always` 让调用者先处理返回值）。

**co_await 的执行流程**：1. 调用 `awaitable.await_ready()`（若返回 true 则跳过挂起）；2. 挂起协程，调用 `awaitable.await_suspend(handle)`；3. 恢复后调用 `awaitable.await_resume()`，其返回值就是 `co_await expr` 的值。

**协程的性能陷阱**：每个协程默认在堆上分配协程帧（保存局部变量和 promise）。如果协程体很小或调用很频繁，分配开销可能超过异步带来的好处。使用 `std::suspend_never` 或在调用者栈上分配可以优化。

## 参考存根

```cpp
struct Task {
    struct promise_type {
        Task get_return_object() { return Task{std::coroutine_handle<promise_type>::from_promise(*this)}; }
        std::suspend_always initial_suspend() { return {}; }
        std::suspend_always final_suspend() noexcept { return {}; }
        void return_value(int v) { value_ = v; }
        int value_;
    };
    std::coroutine_handle<promise_type> h_;
    int get() { h_.resume(); return h_.promise().value_; }
};

Task compute() { co_return 42; }
```
