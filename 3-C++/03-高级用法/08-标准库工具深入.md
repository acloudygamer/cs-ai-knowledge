# 标准库工具深入

深入介绍 C++ 标准库中常用的非拥有型视图和格式化工具。

## std::string_view（C++17）

string_view 是字符串的轻量非拥有型视图，避免不必要的拷贝。

### 基础用法

```cpp
#include <string_view>
#include <iostream>

void print_length(std::string_view sv) {
    std::cout << "Length: " << sv.length() << "\n";
}

int main() {
    // 从 const char* 创建
    std::string_view sv1 = "hello";

    // 从 std::string 创建
    std::string s = "world";
    std::string_view sv2 = s;

    // 从部分字符串
    std::string_view sv3(s.data() + 1, 3);  // "orl"

    print_length("temporary");  // 直接传 C 字符串
    print_length(s);           // 自动转换为 string_view
}
```

### 字符串操作

```cpp
#include <string_view>
#include <iostream>

int main() {
    std::string_view sv = "  hello world  ";

    // 移除空白
    sv.remove_prefix(2);   // "hello world  "
    sv.remove_suffix(2);   // "hello world"

    // 查找
    std::string_view sub = "world";
    size_t pos = sv.find(sub);         // 找到返回位置
    size_t npos = sv.find("foo");      // 未找到返回 npos

    // 其他查找函数
    sv.find_first_of("aeiou");          // 首个元音
    sv.find_last_of("aeiou");           // 末个元音
    sv.find_first_not_of(" ");          // 首个非空格
    sv.substr(0, 5);                    // "hello"
    sv.compare("hello");                // 0 表示相等
}
```

### string_view 与函数参数

```cpp
#include <string_view>

// 推荐：使用 string_view 而非 const std::string&
// 原因：避免不必要的拷贝，同时接受 string 和 const char*
void process(std::string_view sv) {
    // 不需要知道输入是 string 还是 char[]
    size_t len = sv.length();
    // ...
}

// 调用
std::string s = "hello";
process(s);           // 隐式转换
process("literal");   // 直接使用
process({s.data(), 3}); // 部分字符串
```

### 注意事项

```cpp
// 重要：string_view 不拥有数据，原始字符串必须保持有效
std::string_view get_view() {
    std::string s = "hello";
    return s;  // 危险！s 在函数结束时销毁
}

// 正确做法
std::string_view get_view(const std::string& s) {
    return s;  // 调用者确保 s 生命周期
}

// 避免返回临时对象的 view
const char* get_cstr();
std::string_view sv = get_cstr();  // 危险！
```

## std::span（C++20）

span 是连续序列的轻量非拥有型视图。

### 基础用法

```cpp
#include <span>
#include <vector>
#include <array>
#include <iostream>

void print_span(std::span<int> s) {
    for (int x : s) {
        std::cout << x << " ";
    }
    std::cout << "\n";
}

int main() {
    std::vector<int> vec = {1, 2, 3, 4, 5};
    std::array<int, 5> arr = {1, 2, 3, 4, 5};
    int raw[] = {1, 2, 3, 4, 5};

    print_span(vec);          // 从 vector
    print_span(arr);          // 从 array
    print_span(raw);          // 从原始数组
    print_span({vec.data(), 3});  // 从指针+大小
}
```

### 动态与静态 extent

```cpp
#include <span>

// 动态大小（编译时未知）
std::span<int> dynamic_span(vec);

// 静态大小（编译时已知）
std::span<int, 5> static_span(arr);

// 首元素视图
std::span<int, 1> first = static_span.first<1>();

// 子视图
std::span<int, 3> sub = static_span.subspan<1, 3>();
```

### 作为函数参数

```cpp
#include <span>
#include <vector>

// 处理任意长度的数组
double average(std::span<const double> data) {
    if (data.empty()) return 0.0;
    double sum = 0;
    for (double x : data) sum += x;
    return sum / data.size();
}

// 修改元素（非常量 span）
void scale(std::span<double> data, double factor) {
    for (double& x : data) {
        x *= factor;
    }
}

int main() {
    std::vector<double> v = {1, 2, 3, 4, 5};
    scale(v, 2.0);  // v 变为 {2, 4, 6, 8, 10}
}
```

## std::format（C++20）

安全的字符串格式化，Python f-string 风格。

### 基础格式

```cpp
#include <format>
#include <iostream>
#include <string>

int main() {
    // 基本占位符
    std::string s = std::format("{} + {} = {}", 1, 2, 3);
    std::cout << s << "\n";  // "1 + 2 = 3"

    // 位置参数
    std::format("{1} {0} {2}", "a", "b", "c");  // "b a c"

    std::format("Name: {}, Age: {}", "Alice", 30);
}
```

### 数值格式

```cpp
#include <format>
#include <iostream>

int main() {
    int x = 255;

    // 进制转换
    std::format("{:d}", x);   // "255"    十进制
    std::format("{:x}", x);   // "ff"     十六进制（小写）
    std::format("{:X}", x);   // "FF"     十六进制（大写）
    std::format("{:b}", x);   // "11111111" 二进制
    std::format("{:o}", x);   // "377"    八进制

    // 进制前缀
    std::format("{:#x}", x);  // "0xff"
    std::format("{:#b}", x);  // "0b11111111"

    double pi = 3.14159;

    // 浮点精度
    std::format("{:.2f}", pi);    // "3.14"
    std::format("{:.3f}", pi);    // "3.142"
    std::format("{:+.2f}", pi);   // "+3.14"  带符号

    // 科学计数法
    std::format("{:e}", pi);      // "3.141590e+00"
    std::format("{:E}", pi);      // "3.141590E+00"

    // 通用格式（自动选择）
    std::format("{:g}", pi);      // "3.14159"
    std::format("{:g}", 0.0001);  // "0.0001"
    std::format("{:g}", 0.00001); // "1e-05"
}
```

### 对齐与填充

```cpp
#include <format>

int main() {
    // 对齐
    std::format("{:>10}", "right");   // "     right"  右对齐
    std::format("{:<10}", "left");    // "left      "  左对齐
    std::format("{:^10}", "center");  // "  center  "  居中

    // 填充
    std::format("{:0>10}", 42);       // "0000000042"
    std::format("{:*>10}", 42);       // "*******42"
    std::format("{:^10}", "pad");     // "   pad    "

    // 组合使用
    std::format("{:+>10.2f}", 3.14);  // "++++++3.14"
}
```

### 其他类型

```cpp
#include <format>
#include <memory>

int main() {
    // 布尔
    std::format("{:}", true);         // "true"
    std::format("{:d}", true);        // "1"
    std::format("{:s}", false);       // "false"

    // 指针
    int x = 42;
    std::format("{:p}", &x);          // 指针地址

    // 字符串
    std::format("{:>10}", "hi");      // "        hi"
    std::format("{:.*s}", 4, "hello"); // "hell"
}
```

### 自定义格式化

```cpp
#include <format>
#include <chrono>

// 为自定义类型定义 formatter
template<>
struct std::formatter<std::chrono::minutes : std::formatter<int> {
    template<typename FormatContext>
    auto format(std::chrono::minutes m, FormatContext& ctx) {
        return std::format_to(ctx.out(), "{} min", m.count());
    }
};

int main() {
    auto dur = std::chrono::minutes(30);
    std::format("Duration: {}", dur);  // "Duration: 30 min"
}
```

## 组合使用示例

```cpp
#include <span>
#include <string_view>
#include <format>
#include <iostream>

struct Config {
    std::string_view name;
    std::span<const int> values;
};

void print_config(const Config& cfg) {
    std::cout << std::format("Config: {}\n", cfg.name);
    std::cout << "Values: ";
    for (int v : cfg.values) {
        std::cout << std::format("{:d} ", v);
    }
    std::cout << "\n";
}

int main() {
    std::vector<int> data = {1, 2, 3, 4, 5};
    Config cfg{"MyConfig", data};
    print_config(cfg);
}
```
