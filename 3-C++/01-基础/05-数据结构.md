# 数据结构

## STL 容器

```cpp
#include <vector>
#include <map>
#include <set>
#include <unordered_map>
#include <string>

std::vector<int> vec = {1, 2, 3};
vec.push_back(4);
int first = vec[0];

std::map<std::string, int> dict;
dict["one"] = 1;
dict["two"] = 2;

std::set<int> unique_set = {3, 1, 4, 1, 5, 9};

std::unordered_map<std::string, int> hash_map;
hash_map["key"] = 100;  // O(1) 查找
```

## std::array — 固定大小数组

`std::array` 是固定大小的顺序容器，存储在栈上，无动态内存分配。

```cpp
#include <array>
#include <algorithm>

std::array<int, 5> arr = {1, 2, 3, 4, 5};

// 访问元素
arr[0];        // 不边界检查
arr.at(1);     // 边界检查，越界抛 std::out_of_range
arr.front();   // 第一个元素
arr.back();    // 最后一个元素
arr.data();    // 返回原始指针

// 大小
arr.size();    // 5
arr.empty();   // false

// 遍历
for (int x : arr) std::cout << x << " ";
std::for_each(arr.begin(), arr.end(), [](int x){ std::cout << x << " "; });

// 排序（需要可变副本，因为 array 元素不能移动）
std::array<int, 5> sorted = arr;
std::sort(sorted.begin(), sorted.end());
```

### 与原始数组对比

| 特性 | std::array | 原始数组 |
|------|-----------|----------|
| 大小 | 编译期常量 | 编译期常量 |
| 内存 | 栈上 | 栈上 |
| 边界检查 | at() 提供 | 无 |
| 可拷贝 | 是 | 否 |
| 迭代器 | 有 | 无 |

## std::deque — 双端队列

`std::deque` 是双端队列，支持两端 O(1) 插入/删除，内部由多个固定大小缓冲区组成。

```cpp
#include <deque>

std::deque<int> dq = {1, 2, 3};

// 双端操作
dq.push_back(4);    // 尾插 O(1)
dq.push_front(0);   // 头插 O(1)
dq.pop_back();      // 尾删 O(1)
dq.pop_front();     // 头删 O(1)

// 访问
dq[0];              // 不边界检查
dq.at(0);           // 边界检查
dq.front();         // 第一个元素
dq.back();          // 最后一个元素

// 插入
dq.insert(dq.begin() + 2, 10);  // 在任意位置插入

// 特点：无连续内存，但支持随机访问
```

### deque vs vector

| 特性 | deque | vector |
|------|-------|--------|
| 内存布局 | 多段缓冲区 | 连续内存 |
| 头插 | O(1) | O(n) |
| 内存增长 | 多次小块分配 | 指数倍增长 |
| 迭代器稳定性 | 插入/删除可能失效 | 插入/删除必定失效 |

## std::list — 双向链表

`std::list` 是双向链表，适合频繁的插入/删除操作。

```cpp
#include <list>

std::list<int> lst = {1, 2, 3, 4, 5};

// 插入与删除
lst.push_back(6);       // 尾插 O(1)
lst.push_front(0);      // 头插 O(1)
lst.insert(std::next(lst.begin(), 2), 10);  // 在位置2插入

lst.remove(3);          // 删除所有值为3的元素 O(n)
lst.remove_if([](int x){ return x > 4; });  // 条件删除

// 移动节点（O(1)，无需拷贝）
lst.splice(lst.begin(), lst, std::next(lst.begin(), 2));  // 移动元素

// 遍历
for (int x : lst) std::cout << x << " ";

// 排序（list 自带的 sort 更高效）
lst.sort();            // O(n log n)
lst.sort(std::greater<int>());  // 降序

// 去重
lst.unique();          // 删除相邻重复元素

// 合并有序链表
std::list<int> other = {10, 20, 30};
lst.merge(other);       // other 变为空
```

### list vs vector

| 特性 | list | vector |
|------|------|--------|
| 插入/删除 | O(1) 在已知位置 | O(n) 可能需要移动 |
| 随机访问 | O(n) | O(1) |
| 内存开销 | 每节点额外指针 | 无额外开销 |
| 缓存友好性 | 差 | 好 |

## std::stack — 栈

`std::stack` 是 LIFO 容器适配器，默认基于 `std::deque`。

```cpp
#include <stack>

std::stack<int> s;

// 入栈
s.push(1);
s.push(2);
s.push(3);

// 访问
s.top();   // 查看栈顶，不弹出

// 出栈
s.pop();   // 弹出栈顶，无返回值

// 大小与空
s.size();  // 3
s.empty(); // false

// 底层容器可指定
std::stack<int, std::vector<int>> s2;  // 用 vector 作为底层
```

### 典型应用：括号匹配

```cpp
bool isValid(const std::string& s) {
    std::stack<char> st;
    for (char c : s) {
        if (c == '(' || c == '[' || c == '{')
            st.push(c);
        else {
            if (st.empty()) return false;
            char top = st.top(); st.pop();
            if ((c == ')' && top != '(') ||
                (c == ']' && top != '[') ||
                (c == '}' && top != '{'))
                return false;
        }
    }
    return st.empty();
}
```

## std::queue — 队列

`std::queue` 是 FIFO 容器适配器，默认基于 `std::deque`。

```cpp
#include <queue>

std::queue<int> q;

// 入队
q.push(1);
q.push(2);
q.push(3);

// 访问
q.front();  // 队首
q.back();   // 队尾

// 出队
q.pop();    // 弹出队首，无返回值

// 大小与空
q.size();   // 3
q.empty();  // false

// 底层容器可指定
std::queue<int, std::list<int>> q2;  // 用 list 作为底层
```

### 典型应用：BFS 遍历

```cpp
std::vector<int> bfs(const std::vector<std::vector<int>>& graph, int start) {
    std::vector<int> result;
    std::queue<int> q;
    std::vector<bool> visited(graph.size(), false);

    q.push(start);
    visited[start] = true;

    while (!q.empty()) {
        int node = q.front(); q.pop();
        result.push_back(node);
        for (int neighbor : graph[node]) {
            if (!visited[neighbor]) {
                visited[neighbor] = true;
                q.push(neighbor);
            }
        }
    }
    return result;
}
```

## std::priority_queue — 优先队列

`std::priority_queue` 是最大堆（默认），支持 O(log n) 插入和删除。

```cpp
#include <queue>

// 默认最大堆
std::priority_queue<int> pq;
pq.push(30);
pq.push(10);
pq.push(50);
pq.push(20);
while (!pq.empty()) {
    std::cout << pq.top() << " ";  // 50 30 20 10
    pq.pop();
}

// 最小堆
std::priority_queue<int, std::vector<int>, std::greater<int>> min_pq;
min_pq.push(30);
min_pq.push(10);
min_pq.push(50);
while (!min_pq.empty()) {
    std::cout << min_pq.top() << " ";  // 10 20 30 50
    min_pq.pop();
}

// 自定义比较器（存储 pair，按 second 降序）
std::priority_queue<std::pair<int,int>,
    std::vector<std::pair<int,int>>,
    [](const auto& a, const auto& b) {
        return a.second < b.second;
    }> custom_pq;
```

### 典型应用：Top-K 问题

```cpp
// 找第 K 大的数（LeetCode 215）
int findKthLargest(std::vector<int>& nums, int k) {
    std::priority_queue<int> pq(nums.begin(), nums.end());
    for (int i = 0; i < k - 1; ++i) pq.pop();
    return pq.top();
}

// 合并 K 个有序链表
ListNode* mergeKLists(std::vector<ListNode*>& lists) {
    std::priority_queue<std::pair<int, ListNode*>,
        std::vector<std::pair<int, ListNode*>>,
        std::greater<std::pair<int, ListNode*>>> pq;

    for (ListNode* node : lists)
        if (node) pq.push({node->val, node});

    ListNode dummy(0);
    ListNode* cur = &dummy;

    while (!pq.empty()) {
        auto [val, node] = pq.top(); pq.pop();
        cur->next = node;
        cur = cur->next;
        if (node->next) pq.push({node->next->val, node->next});
    }
    return dummy.next;
}
```

## 容器选择指南

| 场景 | 推荐容器 |
|------|---------|
| 需要随机访问 | `vector`, `array` |
| 频繁头插/尾插 | `deque`, `vector` |
| 频繁在中间插入/删除 | `list` |
| LIFO 栈操作 | `stack` |
| FIFO 队列操作 | `queue` |
| 找最大/最小 Top-K | `priority_queue` |
| 键值对，顺序遍历 | `map` |
| 键值对，无序查找 | `unordered_map` |
| 唯一元素集合 | `set`, `unordered_set` |
