# 数据结构

**数据结构是在内存中组织数据的方式，其本质是访问模式（随机 vs 顺序）与插入/删除代价的权衡——没有万能结构，只有在特定访问模式下的最优选择。**

## 连续内存 vs 节点链式

**选择连续内存（vector/array）还是节点链式（list）的核心取舍是：缓存局部性（cache locality）vs 节点移动代价。**

<pre>
内存布局对比：

vector（连续）:
[ elem0 ][ elem1 ][ elem2 ][ elem3 ][ elem4 ]
  ↓         ↓         ↓
CPU prefetch: 访问 elem0 时自动加载 elem1-elem3

list（节点链式）:
[node0] → [node1] → [node2] → [node3]
   ↓
[node1] 的地址在运行时才知道
CPU 无法 prefetch，必须跟随指针
</pre>

**缓存行（cache line）通常 64 字节**。连续内存访问能让一个缓存行加载多个元素，节点链式每次跳转都可能触发缓存未命中（cache miss）。

## std::vector — 动态数组

**`vector` 是在堆上分配连续内存的动态数组，其增长策略是容量翻倍（amortized O(1) 尾部插入），设计动机是摊还分析下使每次插入的均摊成本为常数。**

$$
T(n) = \underbrace{n}_{\text{最后一步拷贝}} + \underbrace{\frac{n}{2} + \frac{n}{4} + \cdots + 2}_{\text{每次容量翻倍时的拷贝}} = 2n = O(n)
$$

$$
\text{均摊成本} = \frac{T(n)}{n} = O(1)
$$

**删除元素不会自动收缩容量**。需要手动 `shrink_to_fit()` 回收多余空间，否则 vector 会保持"已删除但未释放"的内存。

<pre>
std::vector<int> vec = {1, 2, 3, 4, 5};
vec.push_back(6);    // amortized O(1)，容量翻倍时 O(n) 拷贝
vec.erase(vec.begin() + 2);  // O(n)，后续元素前移
</pre>

## std::array — 固定大小数组

**`array` 的本质是栈上分配的固定大小数组（编译期大小已知），与原始数组的区别是提供了迭代器接口和 `at()` 边界检查，同时保持零开销（无动态分配）。**

<pre>
std::array<int, 5> arr = {1, 2, 3, 4, 5};
arr.at(0);   // 边界检查，越界抛 std::out_of_range
arr[0];       // 无边界检查，裸指针速度
arr.data();   // 返回原始指针，用于 C API
</pre>

## std::deque — 双端队列

**`deque` 的本质是多个固定大小缓冲区的连续性抽象（分段连续），设计动机是在 O(1) 头尾插入的同时保持随机访问能力，代价是迭代器实现复杂化。**

<pre>
deque 内部结构：

Buffer 0: [ A ][ B ][ C ][ D ]   ← 头端
Buffer 1: [ E ][ F ][ G ][ H ]
Buffer 2: [ I ][ J ][ K ][ L ]   ← 尾端
  ↓
逻辑连续：E F G H I J K L
物理分散：跨缓冲区需要跳转
</pre>

## std::list — 双向链表

**`list` 的本质是节点通过前后指针串联的链式结构，插入/删除仅修改相邻节点的指针，O(1) 已知位置操作。代价是无法随机访问，且每个节点有额外两个指针的内存开销。**

<pre>
list 节点：
┌──────┬──────┬──────┐
│ prev │ data │ next │
└──────┴──────┴──────┘

插入 O(1)（已知位置）：
node->next = position;
node->prev = position->prev;
position->prev->next = node;
position->prev = node;
</pre>

## std::stack / std::queue — 适配器

**适配器的本质是用已有容器实现新的抽象接口。`stack` 要求：push_back/pop_back/back；`queue` 要求：push_back/pop_front/front。`deque` 满足两者，故为默认底层容器。**

<pre>
std::stack<int, std::vector<int>> s;  // 用 vector 实现 stack
std::queue<int, std::list<int>> q;    // 用 list 实现 queue
</pre>

## std::priority_queue — 堆

**`priority_queue` 的本质是一个完全二叉堆（complete binary heap），用数组实现。堆性质：父节点 ≥ 子节点（最大堆）。插入和删除都是 O(log n)，因为只需维护从根到叶子的路径。**

$$
\text{高度} = \lfloor \log_2 n \rfloor
$$

$$
\text{插入/删除代价} = O(\log n)
$$

<pre>
完全二叉堆（数组索引从 0 开始）：
          0
        /   \
       1     2        parent = (i-1)/2
      / \   / \
     3   4 5   6      left = 2*i+1, right = 2*i+2

push: 末尾插入，上浮（bubble up）维护堆序
pop:  移除根，末尾放到根，下沉（bubble down）维护堆序
</pre>
