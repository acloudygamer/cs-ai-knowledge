# 数据结构

STL 提供丰富的容器类型，选择合适的容器取决于访问模式、插入/删除模式和对缓存局部性的需求。

## std::vector — 动态数组

`std::vector` 是动态数组，在堆上分配连续内存。随机访问 O(1)，尾部插入 O(1)，中间插入 O(n)。缓存友好，适合顺序访问和需要频繁随机访问的场景。

## std::array — 固定大小数组

`std::array` 是固定大小的顺序容器，存储在栈上，无动态内存分配。编译期确定大小，支持 `at()` 边界检查，可拷贝。

| 特性 | std::array | 原始数组 |
|------|-----------|----------|
| 大小 | 编译期常量 | 编译期常量 |
| 内存 | 栈上 | 栈上 |
| 边界检查 | at() 提供 | 无 |
| 可拷贝 | 是 | 否 |
| 迭代器 | 有 | 无 |

### 参考样例

```cpp
#include <array>
#include <algorithm>

std::array<int, 5> arr = {1, 2, 3, 4, 5};

// 访问元素
arr[0];        // 不边界检查
arr.at(1);     // 边界检查，越界抛 std::out_of_range
arr.front();   // 第一个元素
arr.back();    // 最后一个元素
arr.data();    // 返回原始指针

// 遍历
for (int x : arr) std::cout << x << " ";
std::for_each(arr.begin(), arr.end(), [](int x){ std::cout << x << " "; });

// 排序（需要可变副本）
std::array<int, 5> sorted = arr;
std::sort(sorted.begin(), sorted.end());
```

## std::deque — 双端队列

`std::deque` 是双端队列，支持两端 O(1) 插入/删除，内部由多个固定大小缓冲区组成。无连续内存，但支持随机访问。

| 特性 | deque | vector |
|------|-------|--------|
| 内存布局 | 多段缓冲区 | 连续内存 |
| 头插 | O(1) | O(n) |
| 内存增长 | 多次小块分配 | 指数倍增长 |
| 迭代器稳定性 | 插入/删除可能失效 | 插入/删除必定失效 |

### 参考样例

```cpp
#include <deque>

std::deque<int> dq = {1, 2, 3};

// 双端操作
dq.push_back(4);    // 尾插 O(1)
dq.push_front(0);   // 头插 O(1)
dq.pop_back();      // 尾删 O(1)
dq.pop_front();     // 头删 O(1)

// 访问
dq[0];              // 不边界检查
dq.at(0);           // 边界检查
dq.front();         // 第一个元素
dq.back();          // 最后一个元素
```

## std::list — 双向链表

`std::list` 是双向链表，插入/删除 O(1)（已知位置）。不支持随机访问，缓存不友好，但节点移动 O(1)。

| 特性 | list | vector |
|------|------|--------|
| 插入/删除 | O(1) 在已知位置 | O(n) 可能需要移动 |
| 随机访问 | O(n) | O(1) |
| 内存开销 | 每节点额外指针 | 无额外开销 |
| 缓存友好性 | 差 | 好 |

### 参考样例

```cpp
#include <list>

std::list<int> lst = {1, 2, 3, 4, 5};

// 插入与删除
lst.push_back(6);       // 尾插 O(1)
lst.push_front(0);      // 头插 O(1)
lst.insert(std::next(lst.begin(), 2), 10);  // 在位置2插入

lst.remove(3);          // 删除所有值为3的元素 O(n)
lst.remove_if([](int x){ return x > 4; });  // 条件删除

// splice：O(1) 移动节点
lst.splice(lst.begin(), lst, std::next(lst.begin(), 2));

// 排序
lst.sort();            // O(n log n)
lst.sort(std::greater<int>());  // 降序

// 合并有序链表
std::list<int> other = {10, 20, 30};
lst.merge(other);       // other 变为空
```

## std::stack — 栈

`std::stack` 是 LIFO 容器适配器，默认基于 `std::deque`。

### 参考样例

```cpp
#include <stack>

std::stack<int> s;
s.push(1);
s.push(2);
s.push(3);
s.top();   // 查看栈顶，不弹出
s.pop();   // 弹出栈顶，无返回值

// 底层容器可指定
std::stack<int, std::vector<int>> s2;  // 用 vector 作为底层
```

## std::queue — 队列

`std::queue` 是 FIFO 容器适配器，默认基于 `std::deque`。

### 参考样例

```cpp
#include <queue>

std::queue<int> q;
q.push(1);
q.push(2);
q.push(3);
q.front();  // 队首
q.back();   // 队尾
q.pop();    // 弹出队首，无返回值
```

## std::priority_queue — 优先队列

`std::priority_queue` 是最大堆（默认），支持 O(log n) 插入和删除。适用于 Top-K 问题、合并 K 个有序链表等场景。

### 参考样例

```cpp
#include <queue>

// 默认最大堆
std::priority_queue<int> pq;
pq.push(30);
pq.push(10);
pq.push(50);
while (!pq.empty()) {
    std::cout << pq.top() << " ";  // 50 30 20 10
    pq.pop();
}

// 最小堆
std::priority_queue<int, std::vector<int>, std::greater<int>> min_pq;

// 自定义比较器
std::priority_queue<std::pair<int,int>,
    std::vector<std::pair<int,int>>,
    [](const auto& a, const auto& b) { return a.second < b.second; }> custom_pq;
```

## 容器选择指南

| 场景 | 推荐容器 |
|------|---------|
| 需要随机访问 | `vector`, `array` |
| 频繁头插/尾插 | `deque`, `vector` |
| 频繁在中间插入/删除 | `list` |
| LIFO 栈操作 | `stack` |
| FIFO 队列操作 | `queue` |
| 找最大/最小 Top-K | `priority_queue` |
| 键值对，顺序遍历 | `map` |
| 键值对，无序查找 | `unordered_map` |
| 唯一元素集合 | `set`, `unordered_set` |
