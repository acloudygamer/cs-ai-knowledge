# 安装与环境

本文详细介绍 C++ 开发环境的搭建过程，涵盖三大主流平台的编译器安装、IDE 配置以及构建工具的使用。

## 编译器选择与安装

C++ 代码需要通过**编译器**转换为机器可执行文件。根据不同平台和需求，有以下选择：

| 编译器 | 平台 | 说明 |
|--------|------|------|
| g++ | Linux/macOS/Windows (WSL) | GNU 项目开源编译器，事实标准 |
| clang | macOS/Linux | 苹果主推，错误提示友好 |
| MSVC | Windows | 微软 Visual Studio 内置 |

### Windows 安装

#### 方案一：Visual Studio Community（推荐）

1. 访问 [visualstudio.microsoft.com](https://visualstudio.microsoft.com/)
2. 下载 Visual Studio Community（免费）
3. 运行安装程序，选择 **"使用 C++ 桌面开发"** 工作负载
4. 安装完成后，启动 Visual Studio
5. 创建新项目：文件 → 新建 → 项目 → 空项目 → 添加 .cpp 文件

验证安装：
```cmd
# 打开 "x64 Native Tools Command Prompt"
cl
# 应显示 Microsoft (R) C/C++ 编译器版本信息
```

#### 方案二：MinGW-w64 + VS Code

1. 下载 MinGW-w64：[https://www.mingw-w64.org/](https://www.mingw-w64.org/)
   - 选择 `x86_64-posix-seh` 版本
2. 解压到 `C:\mingw64`
3. 添加到系统 PATH：`C:\mingw64\bin`
4. 重启终端，验证：

```cmd
g++ --version
# 应显示 g++ 版本，如：g++ (x86_64-posix-seh, Built by MinGW-W64 project) 13.2.0
```

#### 方案三：WSL + g++（Linux 原生体验）

如果使用 Windows 10/11，可启用 Linux 子系统：

```powershell
# 以管理员身份打开 PowerShell
wsl --install

# 重启后进入 Ubuntu，安装 g++
sudo apt update
sudo apt install build-essential

# 验证
g++ --version
```

### macOS 安装

macOS 已预装 clang（实为 apple-clang）：

```bash
# 验证编译器
g++ --version
# Apple clang version 15.0.0

# 如果提示未安装 Xcode Command Line Tools
xcode-select --install
```

使用 Homebrew 安装最新版 GCC：

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
brew install gcc

# 验证（brew 安装的版本通常名为 gcc-13 或类似）
g++-13 --version
```

### Linux 安装

大多数发行版已预装 g++。如需安装：

```bash
# Ubuntu/Debian
sudo apt update
sudo apt install build-essential

# Fedora/RHEL
sudo dnf install gcc-c++

# Arch Linux
sudo pacman -S base-devel

# 验证
g++ --version
```

## 环境变量配置

### Windows (MSVC)

使用 Visual Studio Developer Command Prompt 自动配置，或手动设置：

```batch
:: 在 "x64 Native Tools Command Prompt" 中运行
:: 或添加到系统环境变量
set INCLUDE=C:\Program Files\Microsoft Visual Studio\2022\Community\VC\Tools\MSVC\14.36.32532\include
set LIB=C:\Program Files\Microsoft Visual Studio\2022\Community\VC\Tools\MSVC\14.36.32532\lib\x64
```

### Linux/macOS

通常无需额外配置。如有自定义安装：

```bash
# ~/.bashrc 或 ~/.zshrc 添加
export PATH="/usr/local/bin:$PATH"
export CPATH="/usr/local/include"
export LIBRARY_PATH="/usr/local/lib"
```

## 第一个项目

### 创建项目目录

```bash
mkdir -p ~/cpp-projects/hello
cd ~/cpp-projects/hello
```

### 编写代码

创建 `main.cpp`：

```cpp
#include <iostream>

int main() {
    std::cout << "Hello, C++!" << std::endl;
    return 0;
}
```

### 编译运行

**直接编译：**

```bash
g++ -std=c++17 -O2 -o hello main.cpp
./hello
# 输出：Hello, C++!
```

**常用编译选项：**

| 选项 | 说明 |
|------|------|
| `-std=c++17` | 使用 C++17 标准 |
| `-std=c++20` | 使用 C++20 标准 |
| `-Wall` | 启用所有警告 |
| `-Wextra` | 额外警告 |
| `-O2` | 优化级别 |
| `-g` | 生成调试信息 |
| `-o <file>` | 指定输出文件名 |

## CMake 构建系统

CMake 是跨平台构建系统，通过 `CMakeLists.txt` 描述构建过程。

### 最小项目

```
hello-cmake/
├── CMakeLists.txt
├── src/
│   └── main.cpp
└── build/      # 在此目录运行 cmake
```

`CMakeLists.txt`：

```cmake
cmake_minimum_required(VERSION 3.16)
project(MyApp VERSION 1.0 LANGUAGES CXX)

# 设置 C++ 标准
set(CMAKE_CXX_STANDARD 17)
set(CMAKE_CXX_STANDARD_REQUIRED ON)

# 查找源文件
aux_source_directory(src SRCS)

# 生成可执行文件
add_executable(myapp ${SRCS})
```

构建步骤：

```bash
mkdir build && cd build
cmake ..
cmake --build .
# 或 make（在 Unix 系统上）
./myapp
```

### CMake 常用命令

| 命令 | 说明 |
|------|------|
| `cmake_minimum_required()` | 最低 CMake 版本 |
| `project()` | 项目名称和语言 |
| `add_executable()` | 添加可执行目标 |
| `add_library()` | 添加库目标 |
| `target_include_directories()` | 包含目录 |
| `target_link_libraries()` | 链接库 |

## 常见问题

### Q: g++ 找不到？

```bash
# 确认 PATH 配置
echo $PATH          # Linux/macOS
echo %PATH%         # Windows

# 查找 g++ 位置
which g++           # Unix
where g++           # Windows
```

### Q: 编译报错 "undefined reference"？

通常是链接库问题：

```bash
# 添加链接库
g++ main.cpp -o program -lpthread
# 或使用 CMake
target_link_libraries(myapp PRIVATE pthread)
```

### Q: 中文乱码？

源文件编码问题：

```bash
# 使用 UTF-8 编码保存源文件
# Windows 下使用 -finput-charset=UTF-8 -fexec-charset=GBK
g++ -finput-charset=UTF-8 -fexec-charset=UTF-8 main.cpp -o app
```

### Q: 头文件找不到？

```bash
# 添加 include 路径
g++ -I/usr/local/include main.cpp -o app
# CMake 中
target_include_directories(myapp PRIVATE /usr/local/include)
```

## 验证环境

运行以下代码验证环境配置正确：

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <memory>

int main() {
    // 智能指针
    auto ptr = std::make_unique<int>(42);
    std::cout << "Value: " << *ptr << std::endl;

    // STL 容器
    std::vector<std::string> names = {"C++", "Python", "Rust"};
    for (const auto& name : names) {
        std::cout << name << " ";
    }
    std::cout << std::endl;

    // Lambda
    auto sum = [](auto a, auto b) { return a + b; };
    std::cout << "Sum: " << sum(1, 2) << std::endl;

    std::cout << "Environment OK!" << std::endl;
    return 0;
}
```

编译运行：

```bash
g++ -std=c++17 -o test test.cpp && ./test
```

输出类似：
```
Value: 42
C++ Python Rust
Sum: 3
Environment OK!
```
