# 函数

**函数的本质是代码块的命名抽象，其核心机制是将调用-返回契约编码为栈帧布局——调用方压参，被调用方通过帧指针偏移访问参数和局部变量，返回时通过 `ret` 指令回到调用点。**

## 调用机制的数据流

<pre>
调用方栈帧                    被调用方栈帧
┌─────────────┐            ┌─────────────┐
│ 实参 1       │ ←──────── │ 形参 1       │
│ 实参 2       │ ←──────── │ 形参 2       │
│ 返回地址     │ ←──────── │ 返回地址      │
│ 旧 RBP       │ ←──────── │ 旧 RBP       │
│ 局部变量     │           │ 局部变量      │
└─────────────┘            └─────────────┘
     ↓                           ↓
  caller                      callee
</pre>

**参数传递方式决定调用契约**：
- 值传递：实参拷贝压栈（栈复制开销）
- 引用传递：指针压栈（仅一个指针宽度）
- 移动语义：窃取源对象资源，将拷贝变为移动

## 默认参数与函数重载

**默认参数的本质是调用方省略实参时由编译器自动填入的占位值，其约束是默认参数必须放在形参列表末尾，以消除二义性。**

<pre>
void greet(std::string name = "World") {
    // 编译器重写：greet() → greet("World")
}
</pre>

**函数重载的本质是名字修饰（name mangling）——编译器在符号表中将函数名 + 参数类型列表编码为唯一符号，使链接器能区分同名函数。重载解析发生在编译期。**

<pre>
int add(int a, int b) { return a + b; }
double add(double a, double b) { return a + b; }
// 编译器内部符号：
// _Z3addii（int, int）
// _Z3adddd（double, double）
</pre>

**内联的本质是建议编译器将函数体在调用点展开，代价是代码膨胀（code bloat），收益是消除函数调用开销（栈帧创建、参数压栈、跳转、返回）。**

<pre>
inline int max(int a, int b) { return a > b ? a : b; }
int x = max(1, 2);  // 编译器可能展开为：int x = (1 > 2 ? 1 : 2);
</pre>

## Lambda 表达式（C++11）

**Lambda 的本质是一个匿名函数对象（closure），编译器生成一个匿名类，其 `operator()` 是 lambda 体。捕获列表决定了这个闭包对象如何持有外部变量。**

<pre>
auto is_even = [](int n] { return n % 2 == 0; };
// 编译器生成近似：
// class __Lambda1 {
// public:
//     bool operator()(int n) const { return n % 2 == 0; }
// };
// __Lambda1 is_even;
</pre>

**捕获机制决定外部变量的生命周期绑定方式**：
- `[=]` 值捕获：拷贝一份，lambda 持有一份独立副本
- `[&]` 引用捕获：不拷贝，lambda 持有外部变量的引用（危险：外部变量销毁后 dangling）
- `[x]` 按值捕获特定变量
- `[&x]` 按引用捕获特定变量

<pre>
int x = 10;
auto f1 = [=] { return x; };  // x 的拷贝
auto f2 = [&] { return x; };  // x 的引用
</pre>

## 移动语义与函数返回值

**移动构造的本质是将"资源所有权"从一个对象转移到另一个对象，而非重新分配内存。返回局部对象的优化（RVO/NRVO）使得返回时直接构造到调用方的目标内存，省去拷贝。**

<pre>
Buffer create_buffer() {
    Buffer buf(1000);
    return buf;  // NRVO：直接构造到调用方的返回值内存
}
Buffer b1(100);
Buffer b2 = std::move(b1);  // b1 的资源被"窃取"，b1 变为空
</pre>

**`std::move` 本身不移动任何东西，其本质是一个强制类型转换到右值引用，通知编译器可以劫持原对象的资源。**

<pre>
Buffer b1(100);
Buffer b2 = std::move(b1);  // 实际调用 Buffer(Buffer&&)
// std::move(b1) 返回 Buffer&&
</pre>
