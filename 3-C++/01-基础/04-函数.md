# 函数

## 默认参数

```cpp
void greet(std::string name = "World") {
    std::cout << "Hello, " << name << "!" << std::endl;
}

greet();           // Hello, World!
greet("Alice");    // Hello, Alice!
```

## 函数重载

```cpp
// 同名函数，不同参数
int add(int a, int b) { return a + b; }
double add(double a, double b) { return a + b; }
std::string add(std::string a, std::string b) { return a + b; }
```

## 内联函数

```cpp
inline int max(int a, int b) {
    return (a > b) ? a : b;
}
// 编译器可能将函数体直接展开，避免函数调用开销
```

## Lambda 表达式（C++11）

```cpp
#include <algorithm>

std::vector<int> nums = {5, 2, 8, 1, 9};

// 完整 lambda
auto is_even = [](int n) -> bool {
    return n % 2 == 0;
};

// 省略返回类型推导
auto square = [](int n) { return n * n; };

// 带捕获的 lambda
int threshold = 5;
auto greater_than = [threshold](int n) {
    return n > threshold;
};

// 使用 std::function
std::function<int(int, int)> add = [](int a, int b) { return a + b; };

// 在算法中使用
std::sort(nums.begin(), nums.end(), [](int a, int b) {
    return a > b;  // 降序
});

auto it = std::find_if(nums.begin(), nums.end(), is_even);
```

### Lambda 捕获模式

```cpp
int x = 10;
int y = 20;

// 按值捕获：复制当前值
[x, y]() { return x + y; }();

// 按引用捕获：保持与外部变量同步
[&x, &y]() { x = 100; return x + y; }();

// 混合捕获：x按值，y按引用
[x, &y]() { return x + y; }();

// 默认捕获模式
[=]() { return x + y; }();      // 默认按值捕获所有变量
[&]() { return x + y; }();      // 默认按引用捕获所有变量
[=, &x]() { return x + y; }();  // 默认按值，x按引用
[&, =x]() { return x + y; }();  // 默认按引用，x按值（C++17）

// 初始化捕获（C++14）：创建新变量
[z = x + y]() { return z; }();

// C++14 捕获表达式
auto ptr = std::make_unique<int>(42);
[wp = std::weak_ptr(ptr)]() { return wp.lock() != nullptr; };
```

### mutable Lambda

按值捕获的 lambda 默认不能修改捕获变量，使用 `mutable` 允许修改：

```cpp
int count = 0;

// 按值捕获，mutable 允许修改 count 的副本
auto counter = [count]() mutable {
    count++;
    return count;
};

counter();  // 返回 1
counter();  // 返回 2
count;     // 仍然是 0，原始变量不受影响
```

### Generic Lambda（C++14）

参数使用 `auto` 让 lambda 成为泛型：

```cpp
auto plus = [](auto a, auto b) { return a + b; };

plus(1, 2);           // int: 3
plus(1.5, 2.5);       // double: 4.0
plus(std::string("a"), std::string("b"));  // "ab"

// 与标准库算法结合
std::vector<int> nums = {1, 2, 3};
std::transform(nums.begin(), nums.end(), nums.begin(), [](auto n) {
    return n * 2;
});
```

### constexpr Lambda（C++17）

编译期计算的 lambda：

```cpp
constexpr auto add = [](auto a, auto b) constexpr {
    return a + b;
};

constexpr int result = add(3, 4);  // 编译时计算，result = 7
```

### Lambda 与 std::bind

Lambda 优于 std::bind 的场景：

```cpp
auto bound = std::bind(func, std::placeholders::_1, 100);

// 等价 lambda，更清晰
auto lambda = [](auto&& arg) { return func(arg, 100); };

// Lambda 优势：语法直观、可读性强、支持 mutable、捕获灵活
```

### IIFE（立即调用函数表达式）

```cpp
// C++14 开始支持初始化捕获结合 IIFE
int x = 10;
auto result = [x = x + 1]() { return x; }();  // result = 11

// 用于初始化复杂对象
auto [a, b] = [str = std::string("hello")]() {
    return std::pair<char, size_t>{str[0], str.size()};
}();
```

### Lambda 作为函数参数

```cpp
// 高阶函数：接收 lambda
template<typename Func>
void transform(std::vector<int>& vec, Func&& func) {
    for (auto& n : vec) {
        n = func(n);
    }
}

transform(nums, [](int n) { return n * 2; });

// 使用 std::function 指定类型
void process(std::function<bool(int)> predicate);
```

## 移动语义（C++11）

移动语义避免不必要的拷贝，通过"窃取"临时对象的资源。

### 移动构造与移动赋值

```cpp
class Buffer {
    char* data_;
    size_t size_;
public:
    Buffer(size_t size) : size_(size), data_(new char[size]) {}

    // 移动构造函数
    Buffer(Buffer&& other) noexcept : data_(other.data_), size_(other.size_) {
        other.data_ = nullptr;  // 防止析构时释放
        other.size_ = 0;
    }

    // 移动赋值运算符
    Buffer& operator=(Buffer&& other) noexcept {
        if (this != &other) {
            delete[] data_;
            data_ = other.data_;
            size_ = other.size_;
            other.data_ = nullptr;
            other.size_ = 0;
        }
        return *this;
    }

    ~Buffer() { delete[] data_; }
};

// 使用
Buffer create_buffer() {
    Buffer buf(1000);
    return buf;  // 移动构造，而非拷贝
}

int main() {
    Buffer b1(100);
    Buffer b2 = std::move(b1);  // 移动构造，b1 变为空
    b2 = std::move(b1);        // 移动赋值
}
```

### std::move 与 std::forward

```cpp
#include <utility>

// std::move：无条件转换为右值引用
template<typename T>
void wrapper(T&& arg) {
    // T&& 是转发引用，根据 arg 类型推导
    process(std::forward<T>(arg));  // 保持原始值类别
}

// 完美转发：保持左值/右值属性
template<typename T>
void perfect_forward(T&& arg) {
    // 传入左值，forward 保持左值
    // 传入右值，forward 保持右值
    process(std::forward<T>(arg));
}

int main() {
    int x = 10;
    perfect_forward(x);     // 转发为左值
    perfect_forward(42);    // 转发为右值
}
```

### 移动语义与容器

```cpp
std::vector<int> v1 = {1, 2, 3};
std::vector<int> v2 = std::move(v1);  // v1 变为空，O(1)

std::string s1 = "hello";
std::string s2 = std::move(s1);  // s1 变为空

// push_back vs emplace
std::vector<std::string> v;
std::string s = "hello";
v.push_back(s);       // 拷贝，s 保留
v.push_back(std::move(s));  // 移动，s 变为空（但行为未定义，s 被移动后应不再使用）

// emplace 就地构造
v.emplace_back("hello");  // 直接构造，不拷贝/移动
```

### 移动语义与返回值

```cpp
// NRVO（命名返回值优化）
Buffer create_buffer() {
    Buffer buf(100);
    return buf;  // 可能直接构造在返回值位置
}

// 强制移动
Buffer create_buffer() {
    Buffer buf(100);
    return std::move(buf);  // 保证移动，但可能禁用 NRVO
}

// 最佳实践：让编译器决定
Buffer create_buffer() {
    return Buffer(100);  // 直接返回临时对象
}
```

### 移动语义与异常

```cpp
class Vector {
    int* data_;
    size_t size_;
public:
    // 移动操作应为 noexcept
    // 否则 std::vector 可能选择拷贝而非移动
    Vector(Vector&& other) noexcept : data_(other.data_), size_(other.size_) {
        other.data_ = nullptr;
        other.size_ = 0;
    }

    Vector& operator=(Vector&& other) noexcept {
        if (this != &other) {
            delete[] data_;
            data_ = other.data_;
            size_ = other.size_;
            other.data_ = nullptr;
            other.size_ = 0;
        }
        return *this;
    }
};
```

### 移动语义与智能指针

```cpp
#include <memory>

std::unique_ptr<int> create_ptr() {
    return std::unique_ptr<int>(new int(42));
}

int main() {
    auto p1 = std::make_unique<int>(10);
    auto p2 = std::move(p1);  // p1 变为 nullptr

    // unique_ptr 可以移动但不能拷贝
    // shared_ptr 可以拷贝和移动
    std::shared_ptr<int> sp1 = std::make_shared<int>(20);
    std::shared_ptr<int> sp2 = sp1;  // 共享引用计数
}
```

### 移动语义与默认方法

```cpp
class Data {
    std::vector<int> v_;
    std::string s_;
public:
    // 如果手动定义移动构造函数，拷贝构造函数被删除
    // 如果手动定义移动赋值运算符，拷贝赋值运算符被删除

    Data() = default;  // 默认构造
    Data(Data&&) = default;  // 默认移动构造
    Data& operator=(Data&&) = default;  // 默认移动赋值

    // 如果手动定义析构函数，拷贝/移动构造可能不再自动生成
};
```
