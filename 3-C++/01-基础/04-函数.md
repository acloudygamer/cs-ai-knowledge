# 函数

函数是代码组织的基本单元，接受输入并产生输出，实现代码复用和模块化组织。函数将相关操作封装为独立单元，通过参数传递数据，通过返回值获取结果。

## 默认参数与函数重载

默认参数在调用时可省略相应实参。函数重载允许同名函数处理不同参数类型或个数，增强 API 表达力。内联函数建议编译器在调用处展开，避免函数调用开销。

### 参考样例

```cpp
// 默认参数
void greet(std::string name = "World") {
    std::cout << "Hello, " << name << "!" << std::endl;
}
greet();           // Hello, World!
greet("Alice");    // Hello, Alice!

// 函数重载
int add(int a, int b) { return a + b; }
double add(double a, double b) { return a + b; }

// 内联函数
inline int max(int a, int b) {
    return (a > b) ? a : b;
}

// 函数指针
int (*operation)(int, int) = add;
int result = operation(3, 4);     // 7
```

## Lambda 表达式（C++11）

Lambda 表达式是匿名函数对象，适合短小的回调场景。详见 [Lambda高级用法](../03-高级用法/13-Lambda高级用法.md)。

### 参考样例

```cpp
#include <algorithm>
#include <vector>

std::vector<int> nums = {5, 2, 8, 1, 9};

auto is_even = [](int n) { return n % 2 == 0; };

std::sort(nums.begin(), nums.end(), [](int a, int b) { return a > b; });
auto it = std::find_if(nums.begin(), nums.end(), is_even);
```

## 移动语义基础（C++11）

移动语义避免不必要的拷贝，通过"窃取"临时对象的资源。移动构造函数和移动赋值运算符实现资源所有权的转移。详见 [移动语义深入](../03-高级用法/12-移动语义深入.md)。

### 参考样例

```cpp
class Buffer {
    char* data_;
    size_t size_;
public:
    Buffer(size_t size) : size_(size), data_(new char[size]) {}

    // 移动构造函数
    Buffer(Buffer&& other) noexcept : data_(other.data_), size_(other.size_) {
        other.data_ = nullptr;
        other.size_ = 0;
    }

    // 移动赋值运算符
    Buffer& operator=(Buffer&& other) noexcept {
        if (this != &other) {
            delete[] data_;
            data_ = other.data_;
            size_ = other.size_;
            other.data_ = nullptr;
            other.size_ = 0;
        }
        return *this;
    }

    ~Buffer() { delete[] data_; }
};

// 使用
Buffer create_buffer() {
    Buffer buf(1000);
    return buf;  // 移动构造，而非拷贝
}

// std::move
Buffer b1(100);
Buffer b2 = std::move(b1);  // 移动构造，b1 变为空
```
