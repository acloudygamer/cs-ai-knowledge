# 函数

## 解决什么问题

代码复用和模块化组织，避免重复编写相同逻辑。函数将相关操作封装为独立单元，通过参数传递数据，通过返回值获取结果。

## 核心概念

- 函数是代码组织的基本单元，接受输入并产生输出
- 默认参数提供默认值，调用时可省略相应实参
- 函数重载允许同名函数处理不同参数类型或个数
- 内联函数建议编译器在调用处展开，避免函数调用开销
- Lambda 表达式是匿名函数对象，适合短小的回调场景

## 怎么用

### 默认参数

```cpp
void greet(std::string name = "World") {
    std::cout << "Hello, " << name << "!" << std::endl;
}

greet();           // Hello, World!
greet("Alice");    // Hello, Alice!
```

### 函数重载

```cpp
// 同名函数，不同参数
int add(int a, int b) { return a + b; }
double add(double a, double b) { return a + b; }
std::string add(std::string a, std::string b) { return a + b; }
```

### 内联函数

```cpp
inline int max(int a, int b) {
    return (a > b) ? a : b;
}
// 编译器可能将函数体直接展开，避免函数调用开销
```

### Lambda 表达式基础（C++11）

详见 [Lambda高级用法](../03-高级用法/14-Lambda高级用法.md)。

```cpp
#include <algorithm>
#include <vector>

std::vector<int> nums = {5, 2, 8, 1, 9};

// 简单 lambda
auto is_even = [](int n) { return n % 2 == 0; };

// 在算法中使用
std::sort(nums.begin(), nums.end(), [](int a, int b) { return a > b; });
auto it = std::find_if(nums.begin(), nums.end(), is_even);
```

### 函数指针

```cpp
int (*operation)(int, int) = add;  // 指向 add 函数
int result = operation(3, 4);     // 7
```

## 移动语义基础（C++11）

移动语义避免不必要的拷贝，通过"窃取"临时对象的资源。

### 移动构造与移动赋值

```cpp
class Buffer {
    char* data_;
    size_t size_;
public:
    Buffer(size_t size) : size_(size), data_(new char[size]) {}

    // 移动构造函数
    Buffer(Buffer&& other) noexcept : data_(other.data_), size_(other.size_) {
        other.data_ = nullptr;
        other.size_ = 0;
    }

    // 移动赋值运算符
    Buffer& operator=(Buffer&& other) noexcept {
        if (this != &other) {
            delete[] data_;
            data_ = other.data_;
            size_ = other.size_;
            other.data_ = nullptr;
            other.size_ = 0;
        }
        return *this;
    }

    ~Buffer() { delete[] data_; }
};

// 使用
Buffer create_buffer() {
    Buffer buf(1000);
    return buf;  // 移动构造，而非拷贝
}
```

### std::move

```cpp
#include <utility>

Buffer b1(100);
Buffer b2 = std::move(b1);  // 移动构造，b1 变为空
```
