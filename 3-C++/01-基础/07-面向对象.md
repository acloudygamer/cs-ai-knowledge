# 面向对象

## 定义

**类的本质是对数据和操作这些数据的函数的统一封装，其核心机制是访问控制——通过 `private`/`protected`/`public` 限定符将接口与实现分离，强制调用方只能通过公开契约访问内部状态。** 面向对象的核心抽象是**数据抽象 + 行为绑定**：对象将状态和操作捆绑在一起，状态只能通过定义好的接口访问。

从抽象代数角度看，类定义了一个**抽象数据类型（ADT）**：
 $T = \langle D, \Omega \rangle$ 

其中 $D$ 是数据域（状态空间）， $\Omega$ 是操作集（接口）。良好的类设计确保： 是数据域（状态空间）， $\Omega$ 是操作集（接口）。良好的类设计确保： 是操作集（接口）。良好的类设计确保：
- **封装性**： $D$ 的内部表示对外部不可见 的内部表示对外部不可见
- **完整性**： $\Omega$ 足以表达类型的全部行为 足以表达类型的全部行为
- **一致性**：操作的语义与状态的不变式一致

## 数学模型

### 访问控制的权限矩阵

| 限定符 | 类自身 | 派生类 | 其他类 |
|--------|-------|--------|--------|
| `private` | ✅ | ❌ | ❌ |
| `protected` | ✅ | ✅ | ❌ |
| `public` | ✅ | ✅ | ✅ |

**继承后的访问调整**：

| 基类成员 | public 继承 | protected 继承 | private 继承 |
|---------|-------------|----------------|--------------|
| public | public | protected | private |
| protected | protected | protected | private |
| private | 不可见 | 不可见 | 不可见 |

### 虚函数表的内存布局

每个含虚函数的类有一个隐藏的**虚表指针**（vptr）：
 $\text{vtable} : \text{类} \rightarrow \text{函数指针数组}$ 

对象内存布局（单继承）：
```
对象 obj（假设 Dog 继承自 Animal）:
┌────────────────────────┐
│ Animal 部分             │
│   vptr ─────────────┐  │
├────────────────────────┤  │
│ Dog 扩展部分          │  │
└────────────────────────┘  │
                             ▼
                    ┌───────────────────┐
                    │ vtable (Dog)      │
                    │ [0] Animal::~()  │  ← 析构函数
                    │ [1] Animal::eat()│
                    │ [2] Dog::bark()  │  ← 动态分派
                    │ ...               │
                    └───────────────────┘
```

**虚函数调用的开销**：
 $T_{\text{virtual}} = T_{\text{vptr 读取}} + T_{\text{vtable 偏移访问}} = O(1)$ 

仅比普通函数调用多一次内存间接寻址。

### RAII 的资源管理不变量

 $\forall \text{对象 } o : \text{Constructor}(o) \implies \text{acquired}(o.\text{resource})$ 
 $\forall \text{对象 } o : \text{Destructor}(o) \implies \text{released}(o.\text{resource})$ 

**强异常安全保证**：
 $\text{若 Constructor 抛出异常} \implies \text{无对象被构造（事务语义）}$ 

### 三-rule / 五-rule 的形式化

若类管理**资源**（非平凡析构函数），则需要：

| 规则 | 触发条件 | 必要性 |
|------|---------|-------|
| 拷贝构造 | 管理资源时 | 必须自定义或 delete |
| 拷贝赋值 | 管理资源时 | 必须自定义或 delete |
| 移动构造 | C++11+ 管理资源时 | 建议自定义 |
| 移动赋值 | C++11+ 管理资源时 | 建议自定义 |

**零-rule**：若类不管理资源（平凡析构），编译器生成所有特殊成员函数。

### 动态分派的类型查询模型

`dynamic_cast<T>(p)` 的语义：若 $p \text{ 的实际类型} \in T$ 则为 `static_cast<T>(p)`，否则为 `nullptr`。

运行时类型查询的开销：
 $T_{\text{RTTI}} = O(\text{继承链深度})$ 

## 数据流

### 构造/析构的数据流

<pre>
构造顺序（派生类对象）:
    1. 基类构造 → 2. 成员构造 → 3. 派生类构造

    class Base { };
    class Derived : public Base {
        Member m;
    };

    new Derived();
    │
    ├──► Base 构造
    ├──► Member m 构造
    ├──► Derived 构造
    │
    └──► 对象完全构造

析构顺序（与构造相反）:
    1. 派生类析构 → 2. 成员析构 → 3. 基类析构

    delete p;
    │
    ├──► Derived 析构
    ├──► ~Member() 析构
    ├──► ~Base() 析构
    │
    └──► 内存返还堆
</pre>

**所有权语义**：基类构造期间，对象还不是完整的派生类对象。虚函数分派到基类版本。

### 多态调用的动态分派

<pre>
Animal* animal = new Dog("Buddy");

animal->speak();
    │
    ├──► 读取 animal->vptr
    │
    ├──► 读取 vptr[2]（speak 的偏移）
    │
    └──► 调用函数指针 Dog::speak()

内存操作序列:
    1. MOV RAX, [animal]      ; RAX = vptr 地址
    2. MOV RAX, [RAX + 16]    ; RAX = vtable[2]（speak）
    3. CALL RAX               ; 调用 Dog::speak()
</pre>

### 移动语义的所有权转移

<pre>
Buffer b1(1000);           // b1 构造，持有资源 R
Buffer b2 = std::move(b1); // b2 窃取 b1 的资源
    │
    ├──► 调用 Buffer(Buffer&&) 移动构造函数
    ├──► b2.data = b1.data    ; 资源转移
    ├──► b1.data = nullptr    ; b1 变为空壳
    │
    └──► b1 析构时，delete[] nullptr 无操作
</pre>

### 虚继承的布局

<pre>
菱形继承（无虚继承）:
    A { int x; }
    B : A { }
    C : A { }
    D : B, C { }

D 的内存布局:
┌────────┬────────┬────────┐
│  A (B) │  B 独有 │  A (C) │
│   x    │        │   x    │  ← 两份 x
├────────┴────────┴────────┤
│           C 独有            │
├───────────────────────────┤
│           D 独有            │
└───────────────────────────┘

虚继承后:
    B : virtual A { }
    C : virtual A { }
    D : B, C { }

D 的内存布局:
┌────────────────────────────┐
│  vptr (B)                 │
├────────────────────────────┤
│  B 独有                   │
├────────────────────────────┤
│  vptr (C)                 │
├────────────────────────────┤
│  C 独有                   │
├────────────────────────────┤
│  D 独有                   │
├────────────────────────────┤
│  共享 A { x } (间接寻址)   │  ← 一份 x
└────────────────────────────┘
</pre>

## 机制

### 六大特殊成员函数

| 函数 | 默认行为 | 何时需要自定义 |
|------|---------|---------------|
| 默认构造 | `T() = default` | 类有其他构造函数时需显式定义 |
| 拷贝构造 | 逐成员拷贝 | 管理资源（指针、句柄）时需删除或自定义 |
| 移动构造 | 逐成员移动 | 管理资源且需要高效转移时 |
| 拷贝赋值 | 逐成员拷贝赋值 | 同上 |
| 移动赋值 | 逐成员移动赋值 | 同上 |
| 析构函数 | `~T() = default` | 管理资源时需自定义（通常配合移动语义） |

**C++11 后的规则**：
- 若声明了任一移动或拷贝操作，编译器不再自动生成其他操作
- 若声明了析构函数，编译器不再自动生成移动操作

### = default 与 = delete

**`= default`**：
```cpp
class Trivial {
    int x_;
public:
    Trivial() = default;  // 显式要求编译器生成默认版本
    Trivial(int x) : x_(x) {}
};
```

**`= delete`**：
```cpp
class NonCopyable {
    std::vector<int> data_;
public:
    NonCopyable() = default;
    NonCopyable(const NonCopyable&) = delete;      // 禁止拷贝构造
    NonCopyable& operator=(const NonCopyable&) = delete;  // 禁止拷贝赋值
};
```

### 菱形继承与虚继承

**菱形继承的问题**：
```
    A
   / \
  B   C
   \ /
    D

class A { int x; };
class B : public A {};
class C : public A {};
class D : public B, public C {};

D d;
d.B::x = 1;  // 必须指定路径
d.C::x = 2;  // 另一份 x
```

**虚继承的解决**：
```
class B : virtual public A {};
class C : virtual public A {};
class D : public B, public C {};

D d;
d.x = 1;     // 唯一 x，B 和 C 共享同一个 A 子对象
```

虚继承的代价：虚基类子对象通过 vptr（间接寻址）访问，增加一层间接跳转。

### override 与 final

**`override`**：编译期断言，确保函数确实重写了基类虚函数
```cpp
struct Base {
    virtual void foo() const;
};

struct Derived : Base {
    void foo() const override {}  // 编译成功
    // void foo() override {}      // 编译错误：签名不匹配
};
```

**`final`**：禁止进一步重写
```cpp
struct Base {
    virtual void foo() final {}
};

struct Derived : Base {
    // void foo() override {}    // 编译错误：foo 已 final
};
```

### 多态的运行时类型信息

**dynamic_cast 的类型查询**：
```cpp
Base* p = new Derived;
Derived* d = dynamic_cast<Derived*>(p);  // 成功，返回有效指针
Base* b = new Base;
Derived* d2 = dynamic_cast<Derived*>(b);  // 失败，返回 nullptr
```

**typeid 运算符**：
 `typeid(e)` : $\text{表达式} \rightarrow$ `std::type_info` 
 `typeid(*ptr)` ：解引用前先检查 `nullptr` $\Rightarrow$ 若 `ptr == nullptr` 则抛出 `std::bad_typeid`。 

### 友元的非传递性

```cpp
class A {
    friend class B;
    int x_;
};

class B {
    friend class C;  // C 不是 A 的友元
};
```

友元不继承，不传递：若 D 继承 B，D 不是 A 的友元。

### 构造函数的委托

```cpp
class Widget {
    int x_, y_;
public:
    Widget(int x, int y) : x_(x), y_(y) {}
    Widget() : Widget(0, 0) {}  // 委托给 (int, int)
};
```

**委托构造函数的执行顺序**：
1. 先执行被委托的构造函数（目标构造函数）
2. 再执行委托构造函数体

## 参考存根

```cpp
#include <memory>
#include <iostream>
#include <vector>
#include <typeinfo>

// RAII 演示
class Buffer {
    char* data_;
    size_t size_;
public:
    Buffer(size_t size) : data_(new char[size]), size_(size) {}
    ~Buffer() { delete[] data_; }

    // 移动构造
    Buffer(Buffer&& other) noexcept : data_(other.data_), size_(other.size_) {
        other.data_ = nullptr;
        other.size_ = 0;
    }

    Buffer(const Buffer&) = delete;
    Buffer& operator=(const Buffer&) = delete;
};

// 虚函数演示
struct Animal {
    virtual ~Animal() = default;
    virtual void speak() const = 0;
};

struct Dog : Animal {
    std::string name_;
    Dog(std::string n) : name_(n) {}
    void speak() const override { std::cout << name_ << " says Woof!\n"; }
};

struct Cat : Animal {
    std::string name_;
    Cat(std::string n) : name_(n) {}
    void speak() const override { std::cout << name_ << " says Meow!\n"; }
};

void make_speak(const Animal& a) { a.speak(); }

// dynamic_cast 演示
void demo_dynamic_cast() {
    Animal* a1 = new Dog("Buddy");
    Animal* a2 = new Cat("Whiskers");

    if (Dog* d = dynamic_cast<Dog*>(a1))
        std::cout << "a1 is a Dog\n";

    if (Dog* d = dynamic_cast<Dog*>(a2))
        std::cout << "a2 is a Dog\n";  // 不执行
    else
        std::cout << "a2 is not a Dog\n";
}

// typeid 演示
void demo_typeid() {
    Animal* a = new Dog("Rex");
    std::cout << typeid(*a).name() << "\n";  // 输出类名（实现相关）
}
```

## 约束与违反后果

| 约束 | 违反后果 |
|------|----------|
| 基类析构函数必须为 virtual | 通过基类指针删除派生类时，派生类析构函数不调用，资源泄漏 |
| 虚函数调用通过 vptr | 比普通调用多一次内存访问 |
| 移动操作必须是 noexcept | `vector` 扩容时不使用移动，退化为拷贝 |
| `= delete` 的函数禁止调用 | 编译错误 |
| 虚继承增加间接寻址开销 | 轻微性能损失（通常可忽略） |
| dynamic_cast 要求有虚函数 | 裸类型无法使用，编译错误 |
| 友元不是成员，无访问特权 | 友元函数/类访问权限等同于成员 |
| 构造/析构期间调用虚函数 | 分派到当前构造/析构阶段的类版本，非最终版本 |
| 拷贝构造/赋值需自赋值检查 | 无检查时，self-assignment 可能导致资源泄漏 |
| 委托构造和成员初始化列表不能同时使用 | 编译错误 |
