# 迭代器

迭代器是 STL 的核心概念，提供了一种统一的方式访问容器元素。迭代器封装了对容器元素的访问和遍历操作，将算法与容器解耦。

## 五种迭代器类别

迭代器按能力分为五类：输入迭代器（只读）、输出迭代器（只写）、前向迭代器（读写，支持 `++`）、双向迭代器（支持 `++` 和 `--`）、随机访问迭代器（支持 `+`、`-`、`[]`）。C++17 还定义了连续迭代器概念。

| 类别 | 支持操作 | 容器示例 |
|------|---------|---------|
| **输入迭代器** | `++`, `*` (只读) | istream |
| **输出迭代器** | `++`, `*` (只写) | ostream, inserter |
| **前向迭代器** | `++`, `*` (读写) | forward_list |
| **双向迭代器** | `++`, `--`, `*` (读写) | list, set, map |
| **随机访问迭代器** | `++`, `--`, `+`, `-`, `[]` | vector, deque, array |
| **连续迭代器**（C++17） | 指向连续内存的随机访问迭代器 | vector, array |

### 参考样例

```cpp
std::vector<int> vec = {1, 2, 3, 4, 5};

// 随机访问迭代器
auto it = vec.begin();
it + 2;      // 前进 2 位
it[3];       // 相当于 *(it + 3)
it - 1;      // 后退 1 位
it < vec.end();  // 可以比较

// 双向迭代器（list）
std::list<int> lst = {1, 2, 3, 4, 5};
auto lit = lst.begin();
++lit;   // 前进
--lit;   // 后退（支持）
// lit + 2;  // 错误！不支持算术运算
```

## 迭代器辅助函数

`std::advance` 将迭代器前进指定距离。`std::next`/`std::prev`（C++11）返回前进/后退后的新迭代器，原迭代器不变。`std::distance` 计算两个迭代器之间的距离。

### 参考样例

```cpp
#include <iterator>

std::vector<int> vec = {1, 2, 3, 4, 5};
auto it = vec.begin();

std::advance(it, 3);  // it 指向第 4 个元素

auto it2 = vec.begin();
auto it3 = std::next(it2, 2);  // it2 不变，it3 前进 2 位
auto last = std::prev(vec.end(), 1);  // 最后一个元素

ptrdiff_t d = std::distance(vec.begin(), vec.begin() + 3);  // 3
```

## 迭代器适配器

迭代器适配器将一种迭代器转换为另一种，提供特殊遍历能力。

### 反向迭代器

`rbegin`/`rend` 提供反向遍历，从容器末尾向前移动。

### 参考样例

```cpp
std::vector<int> vec = {1, 2, 3, 4, 5};

for (auto rit = vec.rbegin(); rit != vec.rend(); ++rit) {
    std::cout << *rit << " ";  // 5 4 3 2 1
}

// 反向迭代器转换为正向迭代器
auto rit = vec.rbegin();
std::vector<int>::iterator it = rit.base();  // 对应的正向迭代器
```

### 插入迭代器

`back_inserter`/`front_inserter`/`inserter` 在容器指定位置插入元素。

### 参考样例

```cpp
#include <iterator>

std::vector<int> vec = {1, 2, 3};
std::list<int> lst;

// back_inserter：尾部插入
std::copy(vec.begin(), vec.end(), std::back_inserter(lst));

// front_inserter：头部插入
std::deque<int> deq;
std::copy(vec.begin(), vec.end(), std::front_inserter(deq));

// inserter：在指定位置插入
std::set<int> s;
std::copy(vec.begin(), vec.end(), std::inserter(s, s.begin()));
```

### 流迭代器

流迭代器将流转换为迭代器，支持使用算法操作流。

### 参考样例

```cpp
#include <iterator>

// 输入流迭代器：从 cin 读取
std::vector<int> vec;
std::copy(
    std::istream_iterator<int>(std::cin),
    std::istream_iterator<int>(),
    std::back_inserter(vec)
);

// 输出流迭代器
std::vector<int> nums = {1, 2, 3, 4, 5};
std::copy(nums.begin(), nums.end(),
    std::ostream_iterator<int>(std::cout, " "));

// 使用 accumulate 求和
int sum = std::accumulate(
    std::istream_iterator<int>(std::cin),
    std::istream_iterator<int>(),
    0
);
```

### 移动迭代器（C++11）

移动迭代器将拷贝操作转换为移动操作。

### 参考样例

```cpp
std::vector<std::string> src = {"a", "b", "c"};
std::vector<std::string> dest(src.size());

// 移动而非拷贝
std::move(src.begin(), src.end(), dest.begin());

// src 中的元素现在处于"有效但未指定"状态
```

### 哨兵迭代器（C++20）

哨兵迭代器用于处理没有明确大小的范围。

### 参考样例

```cpp
#include <ranges>

std::string_view sv = "hello world";
auto view = sv | std::views::transform([](char c) { return std::toupper(c); });
```

## 迭代器失效

迭代器失效规则取决于容器类型：vector 插入可能导致所有迭代器失效，capacity 变化时全部失效；deque 插入可能使所有迭代器失效；list/map/set 仅影响被删元素的迭代器；unordered_map rehash 后所有迭代器可能失效。

### 参考样例

```cpp
std::vector<int> vec = {1, 2, 3, 4, 5};

// 删除偶数 - 正确方式
for (auto it = vec.begin(); it != vec.end(); ) {
    if (*it % 2 == 0) {
        it = vec.erase(it);  // erase 返回下一个有效迭代器
    } else {
        ++it;
    }
}

// erase-remove 惯用法
vec.erase(std::remove_if(vec.begin(), vec.end(), [](int n) {
    return n % 2 == 0;
}), vec.end());
```

## 自定义迭代器

自定义迭代器需定义 `iterator_category`、`value_type`、`difference_type`、`pointer`、`reference` 类型别名，并实现 `*`、`->`、`++`、`==`、`!=` 等运算符。

### 参考样例

```cpp
#include <iterator>

class IntRange {
    int current_;
    int end_;
public:
    class iterator {
        friend class IntRange;
        int value_;
        explicit iterator(int v) : value_(v) {}

    public:
        using iterator_category = std::forward_iterator_tag;
        using value_type = int;
        using difference_type = std::ptrdiff_t;
        using pointer = int*;
        using reference = int&;

        reference operator*() const { return value_; }
        pointer operator->() const { return &value_; }
        iterator& operator++() { ++value_; return *this; }
        iterator operator++(int) { iterator tmp = *this; ++value_; return tmp; }
        bool operator==(const iterator& other) const { return value_ == other.value_; }
        bool operator!=(const iterator& other) const { return value_ != other.value_; }
    };

    IntRange(int start, int end) : current_(start), end_(end) {}
    iterator begin() const { return iterator(current_); }
    iterator end() const { return iterator(end_); }
};

// 使用
for (int i : IntRange(1, 5)) {
    std::cout << i << " ";  // 1 2 3 4
}
```

## 范围库与迭代器（C++20）

C++20 范围库提供惰性求值的视图操作。`std::ranges::begin/end` 获取范围的迭代器，`std::views::all` 将容器转换为范围。

### 参考样例

```cpp
#include <ranges>

std::vector<int> vec = {1, 2, 3, 4, 5};

// views::all 转换为范围
auto r = std::views::all(vec);

// begin/end 方法
auto b = std::ranges::begin(vec);
auto e = std::ranges::end(vec);

// 范围概念检查
static_assert(std::ranges::range<decltype(vec)>);  // true
static_assert(std::ranges::random_access_range<decltype(vec)>);  // true
```
