# 迭代器

## 定义

**迭代器的本质是算法与容器之间的抽象接口契约——它将"如何遍历容器"这一职责从算法剥离到容器自身，使同一份算法代码可以操作不同容器的元素。**

## 数学模型

### 迭代器类别的能力分层

迭代器类别定义了**最小必需操作集合**，算法据此推断自己能在该迭代器上做什么：

| 类别 | 必需操作 | 能力 |
|------|---------|------|
| 输入迭代器 | `++`, `*`（只读） | 单遍扫描，只读 |
| 输出迭代器 | `++`, `*`（只写） | 单遍扫描，只写 |
| 前向迭代器 | `++`, `*`（读写） | 多遍扫描，读写 |
| 双向迭代器 | `++`, `--`, `*`（读写） | 支持前后移动 |
| 随机访问迭代器 | `++`, `--`, `+`, `-`, `[]` | $O(1)$ 跳转 |

**连续迭代器（C++17）** 是随机访问迭代器的子集，保证物理连续性：
$$\forall \text{连续迭代器 } it : \&*(it + n) = \&*it + n$$

### 迭代器失效的复杂度

| 容器 | 插入操作 | 删除操作 |
|------|---------|---------|
| vector | 所有迭代器失效（可能扩容） | 被删元素之后的所有迭代器失效 |
| deque | 仅首尾迭代器可能失效 | 被删元素迭代器失效 |
| list | 仅涉及节点的迭代器有效 | 仅被删元素的迭代器失效 |
| map/set | 所有迭代器保持有效 | 仅被删元素的迭代器失效 |

**数学约束**：
$$\text{失效条件} = \text{容器内部结构变化（重新分配/节点重链接）}$$

## 数据流

### 迭代器遍历的数据流

<pre>
范围 for 循环的等价变换:

源代码:
    for (auto x : container) {
        process(x);
    }

编译器重写:
    auto __begin = container.begin();
    auto __end = container.end();
    for (; __begin != __end; ++__begin) {
        auto x = *__begin;
        process(x);
    }
</pre>

### 反向迭代器的指针变换

<pre>
正向迭代器 rbegin() 的关系:
    rbegin() 指向 end() - 1
    rend() 指向 begin() - 1

++rbegin() 实际执行 --base()
    rbegin() = end() - 1
    ++rbegin() = (end() - 1) + 1 = end()

正向视图:    [ A ][ B ][ C ][ D ]
              ↑           ↑
           begin()       end()

反向视图:      rbegin()       rend()
                ↓             ↓
              [ D ][ C ][ B ][ A ]
                ↑             ↑
              end()-1       begin()-1
</pre>

### 插入迭代器的代理模式

<pre>
std::back_inserter(vec) 返回的代理对象:

back_inserter(vec) 实际上返回 std::back_insert_iterator&lt;vector&lt;int&gt;&gt;

对该迭代器赋值时:
    *it = value;
    ↓ 等价于
    vec.push_back(value);

copy 算法认为它在"写入"容器
实际执行的是"插入"操作
</pre>

## 机制

### 迭代器失效的根本原因

**vector 扩容导致所有迭代器失效**：
$$\text{当 } size == capacity \implies \text{ push\_back 触发 realloc }$$
$$\text{realloc } \Rightarrow \text{ 新内存分配 + 元素移动 + 旧内存释放}$$
$$\text{所有指向旧内存的迭代器} \Rightarrow \text{悬垂（dangling）}$$

**erase 导致后续迭代器失效**：
```cpp
vec.erase(it);  // it 失效，返回后继迭代器
// 等价于: it = vec.erase(it);
```

### 流迭代器的惰性求值

**`istream_iterator`**：
- 默认构造 = EOF 哨兵
- 解引用时触发一次 `operator>>`

**`ostream_iterator`**：
- 赋值时触发一次 `operator<<`
- 可指定分隔符

```cpp
// 惰性求值演示
std::istream_iterator&lt;int&gt; it(std::cin);  // 未读取
std::istream_iterator&lt;int&gt; end;           // EOF 哨兵

// 解引用才真正读取
if (it != end) {
    int x = *it;  // 触发 std::cin >> x
}
```

### 迭代器适配器的组合

**`reverse_iterator`**：将递增变为递减
```cpp
auto rit = std::reverse_iterator(vec.end());  // 指向 5
*rit = 10;  // 修改 vec[4]
```

**`insert_iterator`**：代理模式
```cpp
std::list&lt;int&gt; lst = {1, 2, 3};
auto it = std::inserter(lst, lst.begin());  // 指向 lst.begin()
*it = 99;  // 等价于 lst.insert(lst.begin(), 99)
```

**`move_iterator`**：解引用时返回右值引用
```cpp
std::vector&lt;Buffer&gt; src = {/*...*/};
std::vector&lt;Buffer&gt; dst;
std::copy(std::make_move_iterator(src.begin()),
           std::make_move_iterator(src.end()),
           std::back_inserter(dst));
// Buffer 被移动而非拷贝
```

## 对比参照

| 迭代器类型 | 适用场景 | 代价 |
|-----------|---------|------|
| vector::iterator | 高性能顺序遍历、随机访问 | 插入/删除代价高 |
| list::iterator | 高频插入/删除的遍历 | 无随机访问 |
| map::iterator | 有序遍历、范围查询 | 遍历代价 $O(n)$ |
| istream_iterator | 流式输入处理 | 惰性，每次解引用一次读取 |
| move_iterator | 将容器元素转移到另一容器 | 移动而非拷贝 |

## 参考存根

```cpp
#include <vector>
#include <list>
#include <map>
#include <iterator>
#include <algorithm>
#include <iostream>

// 正确删除容器中的偶数
void erase_evens(std::vector<int>& vec) {
    for (auto it = vec.begin(); it != vec.end(); ) {
        if (*it % 2 == 0) {
            it = vec.erase(it);  // erase 返回后继迭代器
        } else {
            ++it;
        }
    }
}

// 流迭代器演示
void stream_iter_demo() {
    std::vector<int> v;
    std::copy(
        std::istream_iterator<int>(std::cin),
        std::istream_iterator<int>(),
        std::back_inserter(v)
    );

    std::copy(v.begin(), v.end(),
        std::ostream_iterator<int>(std::cout, " "));
    std::cout << "\n";
}

// 移动迭代器演示
struct Buffer {
    Buffer() = default;
    Buffer(const Buffer&) = default;
    Buffer(Buffer&&) noexcept = default;
};
```

## 约束与违反后果

| 约束 | 违反后果 |
|------|----------|
| `erase(it)` 返回的迭代器才是有效的后继 | 使用原 `it` 崩溃 |
| vector 扩容后所有迭代器失效 | 使用旧迭代器，未定义行为（可能崩溃） |
| 对 rvalue 调用 `*it` 可能无效 | 取决于容器和迭代器类型 |
| `ostream_iterator` 赋值时立即输出 | 无缓冲，多次 I/O 调用 |
| 迭代器必须与容器生命周期匹配 | 容器析构后迭代器悬空 |
