# 迭代器

迭代器是 STL 的核心概念，提供了一种统一的方式访问容器元素。

## 迭代器基础

### 五种迭代器类别

| 类别 | 支持操作 | 容器示例 |
|------|---------|---------|
| **输入迭代器** | `++`, `*` (只读) | istream |
| **输出迭代器** | `++`, `*` (只写) | ostream, inserter |
| **前向迭代器** | `++`, `*` (读写) | forward_list |
| **双向迭代器** | `++`, `--`, `*` (读写) | list, set, map |
| **随机访问迭代器** | `++`, `--`, `+`, `-`, `[]`, `*` (读写) | vector, deque, array |
| **连续迭代器**（C++17） | 指向连续内存的随机访问迭代器 | vector, array |

```cpp
std::vector<int> vec = {1, 2, 3, 4, 5};

// 随机访问迭代器
auto it = vec.begin();
it + 2;      // 前进 2 位
it[3];       // 相当于 *(it + 3)
it - 1;      // 后退 1 位
it < vec.end();  // 可以比较

// 双向迭代器（list）
std::list<int> lst = {1, 2, 3, 4, 5};
auto lit = lst.begin();
++lit;   // 前进
--lit;   // 后退（支持）
// lit + 2;  // 错误！不支持算术运算
```

## 迭代器辅助函数

### std::advance

```cpp
#include <iterator>

std::vector<int> vec = {1, 2, 3, 4, 5};
auto it = vec.begin();

std::advance(it, 3);  // it 指向第 4 个元素
```

### std::next / std::prev（C++11）

```cpp
auto it = vec.begin();

auto it2 = std::next(it, 2);  // it 不变，it2 前进 2 位
auto it3 = std::prev(vec.end(), 1);  // 最后一个元素
```

### std::distance

```cpp
auto first = vec.begin();
auto last = vec.begin() + 3;

ptrdiff_t d = std::distance(first, last);  // 3
```

## 迭代器适配器

### 反向迭代器

```cpp
std::vector<int> vec = {1, 2, 3, 4, 5};

// 反向迭代器
for (auto rit = vec.rbegin(); rit != vec.rend(); ++rit) {
    std::cout << *rit << " ";  // 5 4 3 2 1
}

// 反向迭代器转换为正向迭代器
auto rit = vec.rbegin();
std::vector<int>::iterator it = rit.base();  // 对应的正向迭代器
```

### 插入迭代器

```cpp
#include <iterator>

std::vector<int> vec = {1, 2, 3};
std::list<int> lst;

// back_inserter：尾部插入
std::copy(vec.begin(), vec.end(), std::back_inserter(lst));

// front_inserter：头部插入（需要容器支持 push_front）
std::deque<int> deq;
std::copy(vec.begin(), vec.end(), std::front_inserter(deq));

// inserter：在指定位置插入
std::set<int> s;
std::copy(vec.begin(), vec.end(), std::inserter(s, s.begin()));

// 使用示例
std::vector<int> src = {1, 2, 3};
std::vector<int> dest;
dest.reserve(src.size());  // 需要预分配
std::copy(src.begin(), src.end(), std::back_inserter(dest));
```

### 流迭代器

```cpp
#include <iterator>

// 输入流迭代器：从 cin 读取
std::vector<int> vec;
std::copy(
    std::istream_iterator<int>(std::cin),  // 绑定到 cin
    std::istream_iterator<int>(),           // 结束迭代器（EOF）
    std::back_inserter(vec)
);

// 输出流迭代器：写入 cout
std::vector<int> nums = {1, 2, 3, 4, 5};
std::copy(nums.begin(), nums.end(),
    std::ostream_iterator<int>(std::cout, " "));  // 以空格分隔输出

// 使用 accumulate 配合流迭代器求和
std::cout << std::accumulate(
    std::istream_iterator<int>(std::cin),
    std::istream_iterator<int>(),
    0
) << std::endl;

// 读取文件
std::ifstream file("input.txt");
std::vector<std::string> lines;
std::copy(
    std::istream_iterator<std::string>(file),
    std::istream_iterator<std::string>(),
    std::back_inserter(lines)
);
```

### 移动迭代器（C++11）

```cpp
std::vector<std::string> src = {"a", "b", "c"};
std::vector<std::string> dest(src.size());

// 移动而非拷贝
std::move(src.begin(), src.end(), dest.begin());

// src 中的元素现在处于"有效但未指定"状态
```

### 哨兵迭代器（C++20）

用于处理没有明确大小的范围：

```cpp
#include <ranges>

std::string_view sv = "hello world";

// 使用 std::views::common 转换为有界视图
auto view = sv | std::views::transform([](char c) { return std::toupper(c); });
```

## 迭代器失效

### 迭代器失效规则

| 容器 | 插入 | 删除 |
|------|------|------|
| vector | 插入可能导致所有迭代器失效；capacity 变化时全部失效 | 删除点之后的迭代器失效 |
| deque | insert 可能使所有迭代器失效 | 删除两端元素时只有被删元素的迭代器失效 |
| list | 只影响被删元素的迭代器 | 只影响被删元素的迭代器 |
| map/set | 只影响被删元素的迭代器 | 只影响被删元素的迭代器 |
| unordered_map | 所有迭代器在 rehash 后可能失效 | 只影响被删元素的迭代器 |

### 正确的迭代方式

```cpp
std::vector<int> vec = {1, 2, 3, 4, 5};

// 删除偶数 - 正确方式
for (auto it = vec.begin(); it != vec.end(); ) {
    if (*it % 2 == 0) {
        it = vec.erase(it);  // erase 返回下一个有效迭代器
    } else {
        ++it;
    }
}

// 删除元素（使用 erase-remove 惯用法更好）
vec.erase(std::remove_if(vec.begin(), vec.end(), [](int n) {
    return n % 2 == 0;
}), vec.end());
```

## 自定义迭代器

### 基本自定义迭代器

```cpp
#include <iterator>

class IntRange {
    int current_;
    int end_;

public:
    class iterator {
        friend class IntRange;
        int value_;
        explicit iterator(int v) : value_(v) {}

    public:
        using iterator_category = std::forward_iterator_tag;
        using value_type = int;
        using difference_type = std::ptrdiff_t;
        using pointer = int*;
        using reference = int&;

        reference operator*() const { return value_; }
        pointer operator->() const { return &value_; }

        iterator& operator++() { ++value_; return *this; }
        iterator operator++(int) { iterator tmp = *this; ++value_; return tmp; }

        bool operator==(const iterator& other) const { return value_ == other.value_; }
        bool operator!=(const iterator& other) const { return value_ != other.value_; }
    };

    IntRange(int start, int end) : current_(start), end_(end) {}

    iterator begin() const { return iterator(current_); }
    iterator end() const { return iterator(end_); }
};

// 使用
for (int i : IntRange(1, 5)) {
    std::cout << i << " ";  // 1 2 3 4
}
```

### 迭代器约束（C++20）

```cpp

public:
    class iterator {
        // ...
    };

    iterator end() requires std::same_as<T, int>;
```

## 范围库与迭代器（C++20）

```cpp
#include <ranges>

std::vector<int> vec = {1, 2, 3, 4, 5};

// views::all 转换为范围
auto r = std::views::all(vec);

// begin/end 方法
auto b = std::ranges::begin(vec);
auto e = std::ranges::end(vec);

// C++20 自定义范围
class IntRange {
    int start_, end_;
public:
    int* begin() { return &start_; }      // 或返回迭代器
    int* end() { return &end_; }
    auto cbegin() const { return start_; }  // const 版本
    auto cend() const { return end_; }
};

// 范围概念检查
static_assert(std::ranges::range<decltype(vec)>);  // true
static_assert(std::ranges::random_access_range<decltype(vec)>);  // true
```

## 常用迭代器代码模式

### 遍历容器的正确方式

```cpp
std::vector<int> vec = {1, 2, 3, 4, 5};

// 1. 范围 for 循环（最推荐）
for (int x : vec) {
    std::cout << x << " ";
}

// 2. 显式迭代器
for (auto it = vec.begin(); it != vec.end(); ++it) {
    std::cout << *it << " ";
}

// 3. C++20 范围
for (int x : std::views::all(vec)) {
    std::cout << x << " ";
}

// 4. const 容器用 const_iterator
const std::vector<int>& ref = vec;
for (auto it = ref.cbegin(); it != ref.cend(); ++it) {
    std::cout << *it << " ";
}
```

### 二维数组迭代

```cpp
std::vector<std::vector<int>> matrix = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
};

// 按行遍历
for (const auto& row : matrix) {
    for (int val : row) {
        std::cout << val << " ";
    }
}

// 展平遍历
for (auto it = matrix.begin(); it != matrix.end(); ++it) {
    for (auto jt = it->begin(); jt != it->end(); ++jt) {
        std::cout << *jt << " ";
    }
}
```

### 迭代器与算法

```cpp
std::vector<int> vec = {5, 2, 8, 1, 9, 3};

// 与算法结合
auto it = std::find(vec.begin(), vec.end(), 8);
std::sort(vec.begin(), it);  // 排序到找到的元素为止

// 使用 make_reverse_iterator 反向迭代
auto rit = std::make_reverse_iterator(vec.end());
auto rit_end = std::make_reverse_iterator(vec.begin());
for (; rit != rit_end; ++rit) {
    std::cout << *rit << " ";
}
```
