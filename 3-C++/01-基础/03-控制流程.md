# 控制流程

## 条件语句

条件语句根据布尔表达式选择执行路径。C++20 允许在 `if` 语句头部声明变量，作用域限定在整个 `if-else` 块内。

`switch` 语句通过整数或枚举值进行多路分支。`case` 穿透（省略 `break`）允许多个 case 共用代码。C++20 同样支持在 `switch` 头部声明变量。

### 参考样例

```cpp
// if-else 条件
int score = 85;
if (score >= 90) {
    std::cout << "A" << std::endl;
} else if (score >= 80) {
    std::cout << "B" << std::endl;
} else {
    std::cout << "C" << std::endl;
}

// 三元运算符
std::string grade = (score >= 60) ? "pass" : "fail";

// C++20 初始化语句
if (auto it = vec.find(42); it != vec.end()) {
    std::cout << "Found: " << *it << std::endl;
} else {
    std::cout << "Not found" << std::endl;
}

// switch 多路分支
switch (day) {
    case 1: std::cout << "Monday" << std::endl; break;
    case 2: std::cout << "Tuesday" << std::endl; break;
    default: std::cout << "Unknown" << std::endl;
}

// case 穿透：90-100 分都是 A
switch (grade / 10) {
    case 10: case 9: std::cout << "A" << std::endl; break;
    case 8: std::cout << "B" << std::endl; break;
    default: std::cout << "F" << std::endl;
}

// C++20 switch 初始化
switch (auto it = m.find(key); it->second) {
    case success: /* ... */ break;
    default: /* ... */ break;
}
```

## break 与 continue

`break` 立即退出 switch 或循环语句。`continue` 跳过本次迭代剩余部分，进入下一次迭代。在嵌套循环中，`continue` 仅影响直接包含它的循环。

### 参考样例

```cpp
// break 退出循环
for (int n : nums) {
    if (n == 3) break;  // 找到 3 就退出
    std::cout << n << std::endl;  // 输出 1, 2
}

// continue 跳过偶数
for (int i = 0; i < 10; i++) {
    if (i % 2 == 0) continue;  // 跳过偶数
    std::cout << i << " ";  // 输出 1 3 5 7 9
}

// continue 仅影响内层循环
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 5; j++) {
        if (j == 2) continue;  // 只跳过 j=2
        std::cout << "(" << i << "," << j << ") ";
    }
}
```

## goto 语句

`goto` 是 C++ 中最少使用的控制流语句，用于跳出嵌套循环或错误处理。**现代 C++ 推荐使用 RAII 和 Lambda 替代 goto**。

`goto` 不能跳入另一个作用域、跳入函数内部、或从外部跳入 try/catch 块。

### 参考样例

```cpp
// goto 基本语法
int i = 0;
goto skip;
std::cout << "This will be skipped" << std::endl;
skip:
std::cout << "After goto" << std::endl;

// 跳出嵌套循环（传统方式）
for (int i = 0; i < 10; i++) {
    for (int j = 0; j < 10; j++) {
        if (condition(i, j)) goto found;
    }
}
found:
// 继续执行

// 现代替代：Lambda 封装
auto result = [&]() {
    for (int i = 0; i < 10; i++) {
        for (int j = 0; j < 10; j++) {
            if (condition(i, j)) return std::make_pair(i, j);
        }
    }
    return std::make_pair(-1, -1);
}();

// 错误处理（goto 仍有用处）
int process() {
    Resource* r1 = nullptr;
    Resource* r2 = nullptr;
    r1 = allocate_resource1();
    if (!r1) goto cleanup;
    r2 = allocate_resource2();
    if (!r2) goto cleanup;
    do_work(r1, r2);
cleanup:
    if (r1) release_resource1(r1);
    if (r2) release_resource2(r2);
    return success;
}
```

## 循环

`for` 循环包含初始化、条件、更新三部分。`while` 循环先判断条件。`do-while` 至少执行一次。C++11 引入范围 for 循环，适合遍历容器。

### 参考样例

```cpp
// 普通 for 循环
for (int i = 0; i < 5; i++) {
    std::cout << i << std::endl;
}

// 多变量循环
for (int i = 0, j = 10; i < j; i++, j--) {
    std::cout << i << " " << j << std::endl;
}

// 范围 for 循环（C++11）
std::vector<int> nums = {1, 2, 3, 4, 5};
for (int n : nums) {
    std::cout << n << std::endl;
}

// 修改元素
for (auto& n : nums) {
    n *= 2;
}

// while 循环
int count = 0;
while (count < 5) { count++; }

// do-while（至少执行一次）
int input;
do {
    std::cout << "Enter positive number: ";
    std::cin >> input;
} while (input <= 0);

// 范围 for 与容器
std::array<int, 5> arr = {1, 2, 3, 4, 5};
for (int x : arr) { /* ... */ }

std::map<std::string, int> m = {{"a", 1}, {"b", 2}};
for (const auto& [k, v] : m) {  // C++17 结构化绑定
    std::cout << k << " -> " << v << std::endl;
}
```

## 循环语句标签（C++23）

C++23 引入循环标签，允许 `break` 和 `continue` 直接携带标签，实现跨作用域的精确跳转。这是 C++23 新增的前沿特性。

### 参考样例

```cpp
outer:
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        if (condition(i, j)) {
            continue outer;  // 继续外层循环
        }
    }
}

// break outer;  // 直接退出外层循环
```

## 流程控制最佳实践

1. **优先使用范围 for**：简单清晰
2. **避免 break/continue 过多**：考虑提取为函数
3. **goto 仅用于错误处理**：清理资源场景
4. **使用算法替代循环**：`std::find`、`std::accumulate` 等
