# 控制流程

## 条件语句

```cpp
int score = 85;

if (score >= 90) {
    std::cout << "A" << std::endl;
} else if (score >= 80) {
    std::cout << "B" << std::endl;
} else {
    std::cout << "C" << std::endl;
}

// 三元运算符
std::string grade = (score >= 60) ? "pass" : "fail";
```

### 初始化语句（C++20）

```cpp
// C++20 起可以在 if 中声明变量
if (auto it = vec.find(42); it != vec.end()) {
    // it 在这个作用域内可见
    std::cout << "Found: " << *it << std::endl;
} else {
    // it 仍然可见，值为 vec.end()
    std::cout << "Not found" << std::endl;
}

// 同样适用于 switch
switch (auto val = get_value(); val) {
    case 1: /* ... */ break;
    default: /* ... */ break;
}
```

## switch 语句

### 基础语法

```cpp
int day = 3;
switch (day) {
    case 1:
        std::cout << "Monday" << std::endl;
        break;
    case 2:
        std::cout << "Tuesday" << std::endl;
        break;
    case 3:
        std::cout << "Wednesday" << std::endl;
        break;
    default:
        std::cout << "Unknown" << std::endl;
}
```

### switch 穿透（case 穿透）

```cpp
// 不使用 break，case 会穿透执行
int grade = 85;
switch (grade / 10) {
    case 10:
    case 9:
        std::cout << "A" << std::endl;  // 90-100 分都是 A
        break;
    case 8:
        std::cout << "B" << std::endl;
        break;
    case 7:
        std::cout << "C" << std::endl;
        break;
    default:
        std::cout << "F" << std::endl;
}
```

### 初始化语句（C++20）

```cpp
// 可以在 switch 头部声明变量
switch (auto it = m.find(key); it->second) {
    case success:
        std::cout << it->first << std::endl;
        break;
    default:
        std::cout << "Not found" << std::endl;
}
```

### 字符串 switch（C++17）

```cpp
// 使用 if-else 处理字符串
std::string cmd = "start";
if (cmd == "start") {
    // handle start
} else if (cmd == "stop") {
    // handle stop
}

// C++20 可以用 constexpr if 或字典
```

## break 语句

`break` 只能用于 switch 和循环语句，用于立即退出。

### 在循环中

```cpp
std::vector<int> nums = {1, 2, 3, 4, 5};
for (int n : nums) {
    if (n == 3) {
        break;  // 找到 3 就退出循环
    }
    std::cout << n << std::endl;  // 输出 1, 2
}

// while 循环中
int i = 0;
while (true) {
    if (i >= 5) {
        break;  // 退出无限循环
    }
    std::cout << i++ << std::endl;
}
```

### 在 switch 中

```cpp
int x = 2;
switch (x) {
    case 1:
        std::cout << "One" << std::endl;
        break;  // 防止穿透到 case 2
    case 2:
        std::cout << "Two" << std::endl;
        break;
    default:
        std::cout << "Other" << std::endl;
}
```

## continue 语句

`continue` 只能用于循环语句，跳过本次迭代剩余部分，直接进入下一次迭代。

### 在 for 循环中

```cpp
// 跳过偶数，只处理奇数
for (int i = 0; i < 10; i++) {
    if (i % 2 == 0) {
        continue;  // 跳过偶数
    }
    std::cout << i << " ";  // 输出 1 3 5 7 9
}
```

### 在 while 循环中

```cpp
int i = 0;
while (i < 10) {
    i++;
    if (i % 2 == 0) {
        continue;  // 跳过偶数
    }
    std::cout << i << " ";  // 输出 1 3 5 7 9
}
```

### 嵌套循环

```cpp
// continue 只影响直接包含它的循环
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 5; j++) {
        if (j == 2) {
            continue;  // 只跳过 j=2，继续 j=3,4
        }
        std::cout << "(" << i << "," << j << ") ";
    }
    std::cout << std::endl;
}
```

## goto 语句

`goto` 是 C++ 中最少使用的控制流语句，但在特定场景下有用。

### 基本语法

```cpp
goto label;
label:
// 标签语句，可以出现在函数的任何地方

// 示例
int i = 0;
goto skip;
std::cout << "This will be skipped" << std::endl;
skip:
std::cout << "After goto" << std::endl;
```

### 跳出嵌套循环

```cpp
// 不用 goto，需要使用标志位或函数拆分
for (int i = 0; i < 10; i++) {
    for (int j = 0; j < 10; j++) {
        if (condition(i, j)) {
            goto found;  // 直接跳出两层循环
        }
    }
}
found:
// 继续执行

// 替代方案：使用函数
auto result = [&]() {
    for (int i = 0; i < 10; i++) {
        for (int j = 0; j < 10; j++) {
            if (condition(i, j)) {
                return std::make_pair(i, j);
            }
        }
    }
    return std::make_pair(-1, -1);
}();
```

### 错误处理模式

```cpp
int process() {
    Resource* r1 = nullptr;
    Resource* r2 = nullptr;

    r1 = allocate_resource1();
    if (!r1) goto cleanup;

    r2 = allocate_resource2();
    if (!r2) goto cleanup;

    // 正常处理逻辑
    do_work(r1, r2);

cleanup:
    if (r1) release_resource1(r1);
    if (r2) release_resource2(r2);
    return success;
}
```

### RAII 优于 goto

```cpp
// 现代 C++ 推荐使用 RAII 而不是 goto
int process() {
    std::unique_ptr<Resource1> r1 = allocate_resource1();
    if (!r1) return error;

    std::unique_ptr<Resource2> r2 = allocate_resource2();
    if (!r2) return error;

    do_work(r1.get(), r2.get());
    return success;
}
// 资源在 unique_ptr 析构时自动释放
```

### goto 限制

```cpp
// goto 不能：
// 1. 跳入另一个作用域
// 2. 跳入函数内部
// 3. 从外部跳入 try 或 catch 块

// 有效
goto label;
{
    int x = 10;
    label:
    std::cout << x << std::endl;
}

// 错误示例（不能跳入作用域）
goto skip;
int y = 20;  // 编译器错误
skip:
```

## 循环

### 普通 for 循环

```cpp
// 基本语法：for (初始化; 条件; 更新)
for (int i = 0; i < 5; i++) {
    std::cout << i << std::endl;
}

// 多变量循环
for (int i = 0, j = 10; i < j; i++, j--) {
    std::cout << i << " " << j << std::endl;
}
```

### 范围 for 循环（C++11）

```cpp
std::vector<int> nums = {1, 2, 3, 4, 5};
for (int n : nums) {
    std::cout << n << std::endl;
}

// 使用 auto
for (auto& n : nums) {
    n *= 2;  // 修改原数组
}

// 只读遍历
for (const auto& n : nums) {
    std::cout << n << std::endl;
}
```

### while 循环

```cpp
int count = 0;
while (count < 5) {
    count++;
}

// 无限循环
while (true) {
    if (should_exit()) break;
    // ...
}
```

### do-while（至少执行一次）

```cpp
int input;
do {
    std::cout << "Enter positive number: ";
    std::cin >> input;
} while (input <= 0);
// 至少提示一次
```

### 循环控制嵌套

```cpp
// 打印 1-100 的质数
for (int n = 2; n <= 100; n++) {
    bool is_prime = true;
    for (int i = 2; i <= n/2; i++) {
        if (n % i == 0) {
            is_prime = false;
            break;  // 不是质数，跳过
        }
    }
    if (is_prime) {
        std::cout << n << " ";
    }
}
```

### 范围 for 与容器

```cpp
#include <array>
#include <map>

// std::array
std::array<int, 5> arr = {1, 2, 3, 4, 5};
for (int x : arr) { /* ... */ }

// std::map
std::map<std::string, int> m = {{"a", 1}, {"b", 2}};
for (const auto& [k, v] : m) {  // C++17 结构化绑定
    std::cout << k << " -> " << v << std::endl;
}
```

## 循环语句标签（C++23）

C++23 引入了给循环语句加标签的能力：

```cpp
outer:
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        if (condition(i, j)) {
            continue outer;  // C++23：继续外层循环
        }
    }
}

// break outer;  // C++23：可以 break 带标签的循环
```

## 流程控制最佳实践

1. **优先使用范围 for**：简单清晰
2. **避免 break/continue 过多**：考虑提取为函数
3. **goto 仅用于错误处理**：清理资源场景
4. **使用算法替代循环**：std::find, std::accumulate 等
