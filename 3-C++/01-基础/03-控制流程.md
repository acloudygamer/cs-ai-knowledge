# 控制流程

**控制流语句通过修改指令指针寄存器改变程序执行路径，其本质是 CPU 分支预测和流水线吞吐量的博弈——顺序执行 vs 跳转的代价差决定何时该避免分支。**

## 条件分支的机制

**`if/else` 的本质是条件跳转指令（x86: `je`/`jne`）。CPU 流水线遇到跳转时需要 Flush，影响性能。分支预测失败的代价是 10-20 个时钟周期。**

<pre>
if (x > 0) {
    // 分支预测：可能不执行（常见）
    // 预测失败：流水线 Flush，重填
} else {
    // 分支预测：可能执行（罕见）
    // 预测成功：流水线无缝继续
}
</pre>

**C++20 初始化语句的设计动机**：将临时变量的作用域限定在 if-else 块内，避免污染外层作用域。这使得 `if (auto it = m.find(key); it != m.end())` 成为可能。

<pre>
int score = 85;
if (auto grade = score / 10; grade >= 9) {
    // grade 仅在此作用域内可见
}
</pre>

**`switch` 的本质是跳转表（jump table）——当 case 是连续整数时，编译器生成一个函数指针数组，跳转目标直接由 case 值索引，时间复杂度 O(1)。当 case 稀疏时退化为二分查找或顺序比较。**

<pre>
switch (day) {
    case 1: /* ... */ break;
    case 2: /* ... */ break;
    // 连续整数 → 跳转表（O(1)）
}
// case 穿透（故意省略 break）
switch (grade / 10) {
    case 10: case 9: /* grade == 100 or 90-99 */ break;
    // 两个 case 共用代码，减少重复
}
</pre>

## 循环的机制

**循环的本质是条件跳转 + 循环体的反复执行。CPU 流水线的循环展开（loop unrolling）优化会将循环体复制多份，减少跳转次数。**

<pre>
for (int i = 0; i < n; i++) {
    // 每次迭代至少一次跳转：
    // 1. 跳入循环
    // 2. 跳转回条件判断
}
</pre>

**范围 for 循环（C++11）的本质**：编译器自动调用 `begin()` 和 `end()`，对返回的迭代器进行 `!=` 比较和 `++` 操作。迭代器抽象使容器遍历与容器结构解耦。

<pre>
std::vector<int> vec = {1, 2, 3};
for (int n : vec) {
    // 编译器重写为：
    // for (auto __it = vec.begin(); __it != vec.end(); ++__it)
    //     int n = *__it;
}
</pre>

## break 与 continue

**`break` 跳出最近的一层 switch 或循环体。`continue` 跳过本次循环剩余语句，进入下一次迭代。这两者都是人为干预循环执行流的手段。**

<pre>
for (int n : nums) {
    if (n == 3) break;   // 跳出循环，不再执行后续 n
    if (n % 2 == 0) continue; // 跳过偶数，继续下一个 n
}
</pre>

## goto 的机制

**`goto` 是最原始的跳转，本质是一条无条件跳转指令（x86: `jmp`）。其危险在于可跳入作用域内部，破坏栈展开顺序和 RAII 保证。**

**禁止跳入的规则**：跳入一个作用域会导致局部对象未构造，析构函数不会被调用，RAII 资源管理被破坏。

<pre>
int i = 0;
goto skip;
skip:
    // 合法：跳入标签所在位置（而非跳入作用域）
    // 但 skip 标签在声明之前，实际上跳过了 i 的初始化
</pre>

**`goto` 的合法用途**：跳出深层嵌套循环（单次跳转替代多层 break），以及错误处理时的统一清理跳转点。

<pre>
for (int i = 0; i < 10; i++) {
    for (int j = 0; j < 10; j++) {
        if (condition(i, j)) goto cleanup;  // 一次性跳出两层
    }
}
cleanup:
    // 统一清理（等价于多层 break）
</pre>

**现代替代：C++23 循环标签**——给外层循环命名，让 `break`/`continue` 直接指定目标循环层级。

<pre>
outer:
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        if (condition(i, j)) continue outer;  // 继续外层循环
    }
}
</pre>
