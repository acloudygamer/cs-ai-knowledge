# 变量与类型

## 定义

**类型是编译期对位模式的语义标注，其本质是告诉编译器如何解释一段内存以及能对它进行哪些操作。** 类型系统提供：
1. **一致性检查**：防止类型不匹配的操作
2. **布局信息**：决定数据在内存中的大小和对齐
3. **操作集合**：定义允许的一元/二元运算

类型的本质是**代数结构**：类型 $T$ 附带一组操作 $\Omega_T$。当表达式 $e$ 的类型为 $T$ 时，$e$ 只能使用 $\Omega_T$ 中的操作。

## 数学模型

### 类型推断的形式化

C++ 的 `auto` 推断本质上是 **Hindley-Milner 类型系统**的受限版本：

$$\frac{\Gamma \vdash e : \tau}{\Gamma \vdash \text{auto } x = e : \text{drop-ref-cv}(\tau)}$$

其中 drop-ref-cv 运算：
- `int&` → `int`（移除顶层引用）
- `const int&` → `int`（移除顶层 const 和引用）
- `volatile int*` → `int*`（移除顶层 volatile）

**decltype 的推断规则**：

| 表达式形式 | 推断类型 | 说明 |
|-----------|---------|------|
| `decltype(expr)` | $\tau$ | 原始类型，含引用和 cv 限定符 |
| `decltype((expr))` | $\tau$& | 双括号永远是引用，即使 expr 是纯右值 |

**设计动机**：`decltype((x))` 返回引用是为了让调用方能绑定到左值，实现"只读访问"或"转发"语义。双括号规则强制将变量视为表达式而非变量名。

**函数返回类型的推断**：
- `auto f() -> int` 等价于 `int f()`
- `auto f()` 的推断规则复杂（涉及返回值类型的推导）
- C++14 允许 `decltype(auto)` 用于精确转发

### 类型转换的语义层级

| 转换 | 形式化 | 安全性 | 典型用途 |
|------|--------|--------|----------|
| `static_cast<T>` | $: \tau_1 \rightarrow \tau_2$ | 编译期验证 | 数值类型转换、void* → T* |
| `dynamic_cast<T>` | $: \tau_1 \rightarrow \tau_2$ | 运行时 RTTI | 继承层级下行转换 |
| `const_cast<T>` | $: \tau_1 \rightarrow \tau_2$ | 编译期，无检查 | 去除 const（危险） |
| `reinterpret_cast<T>` | $: \tau_1 \rightarrow \tau_2$ | 无检查，最危险 | 位模式重解释 |

**dynamic_cast 的运行时代价**：对于继承链深度 $d$，RTTI 查询时间为 $O(d)$，因为需要沿继承链逐级查询虚表。

**转换的数学性质**：
- `static_cast`：$\tau_1$ 和 $\tau_2$ 之间必须有明确定义的转换路径
- `const_cast`：只能改变 cv 限定符，不能改变类型
- `reinterpret_cast`：不改变位模式，仅改变类型解释

### 整数类型的大小约束

C++ 标准保证的最小大小：
$$\begin{aligned}
\text{char} &= 1 \text{ 字节} = 8 \text{ 位} \\
\text{short} &\geq 2 \text{ 字节} = 16 \text{ 位} \\
\text{int} &\geq 2 \text{ 字节} = 16 \text{ 位} \\
\text{long} &\geq 4 \text{ 字节} = 32 \text{ 位} \\
\text{long long} &\geq 8 \text{ 字节} = 64 \text{ 位} \\
\end{aligned}$$

**历史原因**：`int` 在 32 位时代标准化为 4 字节，尽管最小要求是 2 字节。这是硬件寄存器宽度的历史映射。

**补码表示法**：
对于 $n$ 位有符号整数，有效范围是：
$$[-2^{n-1}, 2^{n-1} - 1]$$

### IEEE 754 浮点表示

浮点数的位布局：
$$\text{sign} \times (1 + \text{fraction}) \times 2^{\text{exponent} - \text{bias}}$$

| 类型 | 总位数 | 符号位 | 指数位 | 尾数位 | 偏差值 |
|------|--------|--------|--------|--------|--------|
| float | 32 | 1 | 8 | 23 | 127 |
| double | 64 | 1 | 11 | 52 | 1023 |
| long double | 80 | 1 | 15 | 64 | 16383 |

**特殊值的数学编码**：
- $+\infty$：指数全 1，尾数全 0
- $-\infty$：符号位 1，指数全 1，尾数全 0
- NaN：指数全 1，尾数非 0

**NaN 的数学性质**：
$$\text{NaN} \pm x = \text{NaN}$$
$$\text{NaN} \times x = \text{NaN}$$
$$\text{NaN} == \text{NaN} = \text{false}$$

这是因为 IEEE 754 定义 NaN 为"不是任何数"，因此 NaN 与自身的比较永远为假。

### 位域的内存布局

位域打包到最小对齐单位：
$$\text{struct 的大小} = \lceil \sum \text{位域宽度} / \text{单位大小} \rceil \times \text{单位大小}$$

**约束**：位域不能跨单元边界，数组不能作为位域类型。

**位域的数学模型**：
$$|\text{struct}| = \sum_{i} \lceil w_i / 8 \rceil \times 8 \text{ 字节（简化模型）}$$

实际上，编译器会合并相邻位域以节省空间，但遵循"同一次序下，第一个位域从新的分配单元开始"的规则。

## 数据流

### auto 推断的数据流

<pre>
源代码:
    auto x = expr;

编译器内部推断:
    1. 分析 expr 的类型 τ
    2. 应用 decltype(expr) 规则
    3. 移除顶层引用和 cv 限定符
    4. 生成变量声明: τ' x = expr;

示例:
    int& ref = x;
    auto a = ref;       // τ = int& → int（移除引用）
    auto& b = ref;      // τ = int& → int&（保留引用）
    auto&& c = ref;     // τ = int& → int&（引用折叠）
    auto&& d = 42;      // τ = int → int&&（右值引用折叠）
</pre>

**引用折叠规则**：
$$T\& \& \rightarrow T\& \quad T\& \&\& \rightarrow T\& \quad T\&\& \& \rightarrow T\& \quad T\&\& \&\& \rightarrow T\&\&$$

这使得 `auto&&` 成为**转发引用**，能根据实参类型推导为左值引用或右值引用。

### variant 的数据流

<pre>
std::variant&lt;int, double, std::string&gt; v = 42;

内存布局（伪代码）:
    union Storage {
        int as_int;
        double as_double;
        std::string as_string;  // 含指针+小字符串优化
    } storage;
    size_t index;  // 当前有效类型的索引

访问（std::visit）:
    1. 读取 index
    2. 分派到对应类型的处理函数
    3. 运行时开销：一次索引比较 + 函数调用
</pre>

**variant 的类型安全保证**：
$$\text{std::get&lt;T&gt;(v)} \implies \begin{cases}
\text{返回 } T & \text{若 } \text{index}(v) == \text{typeid}(T) \\
\text{抛出 } \text{bad_variant_access} & \text{否则}
\end{cases}$$

### optional 的数据流

<pre>
std::optional&lt;int&gt; opt = 42;

内存布局:
    struct optional_int {
        bool has_value;  // 是否有效
        int  value;      // 有效载荷
    };

解引用时:
    if (opt) return *opt;
    else 处理空状态
</pre>

**optional 的空状态语义**：
$$\text{opt.has\_value()} = \text{false} \implies *\text{opt} \text{ 未定义行为}$$
必须先检查 `has_value()` 才能解引用。

### string_view 的零拷贝语义

`std::string_view` 本质上是一个 `(ptr, length)` 对：
```cpp
struct string_view {
    const char* data_;
    size_t len_;
};
```

**零拷贝原理**：
$$\text{construction: } s \mapsto (s.\text{data}, s.\text{length}) \quad O(1)$$

**约束条件**：
- 不拥有所有权，原字符串生命周期结束时视图悬空
- 修改原字符串会导致视图指向新内存的旧偏移

**string_view 与 string 的区别**：
$$\text{string} = (\text{ptr}, \text{len}, \text{capacity}, \text{所有权})$$
$$\text{string\_view} = (\text{ptr}, \text{len}) \quad \text{无所有权}$$

### union 的内存共享模型

Union 的数学模型是**位共享**：
$$|\bigcup_{i=1}^{n} \text{member}_i| = \max_i |\text{member}_i|$$

所有成员共享同一段内存，修改一个成员会覆盖其他成员的位：
```cpp
union Data {
    int i;      // 4 字节
    double d;   // 8 字节
    char c;     // 1 字节
};
// Data 的大小 = max(4, 8, 1) = 8 字节
```

**违反约束**：读取非活跃成员是未定义行为，因为位模式对目标类型无效。

## 机制

### 类型别名的本质

`typedef` 和 `using` 是同义词，但 `using` 支持模板别名：
```cpp
// typedef 的等价 using 形式
typedef unsigned int uint;           // C++98
using uint = unsigned int;          // C++11

// 模板别名（using 独有）
template<typename T>
using Vec = std::vector<T, std::allocator<T>>;

Vec<int> v;  // 等价于 std::vector<int, std::allocator<int>>
```

**typedef vs using 的数学区别**：
- `typedef` 是**名字替换**：`uint` 是 `unsigned int` 的同义词
- `using` 支持**SFINAE** 和模板参数化

SFINAE 的数学形式：
$$\text{SFINAE} : \text{模板参数替换失败} \implies \text{选择其他重载而非编译错误}$$

### nullptr 的类型安全性

`nullptr` 的类型是 `std::nullptr_t`，是一个独元类型（singleton type）：
$$\text{nullptr} : \text{std::nullptr_t}$$

**设计动机**：整数 `0` 在重载解析中存在歧义：
```cpp
void f(int);
void f(char*);

f(0);    // 匹配 f(int)，而非 f(char*)——意外行为
f(nullptr); // 仅匹配 f(char*)——类型安全
```

**nullptr 的数学性质**：
$$\forall \tau : \text{nullptr} \convertsto \tau* \quad \text{（指针类型）}$$
$$\nexists \tau : \text{nullptr} \convertsto \tau \quad \text{（非指针类型）}$$

### string_view 的约束传播

**所有权与生命周期的分离**：
$$S_{\text{view}} = (p, l) \quad \text{其中 } p \text{ 指向外部内存}$$
$$\text{所有者} \in \text{外部} \implies S_{\text{view}} \text{ 是视图，不负责释放}$$

**悬空视图的危险**：
$$T_{\text{origin}} < T_{\text{view}} \implies \text{视图悬空} \implies \text{解引用未定义行为}$$

### union 的类型安全性

**活跃成员（active member）**：
$$\text{index}(u) = k \implies \text{union 的第 } k \text{ 个成员是活跃的}$$
只有活跃成员可以安全读取。

**placement 读取**：
若要读取非活跃成员，必须通过 `std::launder` 消除优化引入的 UB：
```cpp
struct A { int x; };
struct B { double y; };
union U { A a; B b; };

U u;
u.a.x = 42;
int x = std::launder(&u.a)->x;  // 必须 launder
```

### 位运算的数学语义

| 运算符 | 数学定义 | 典型应用 |
|--------|---------|---------|
| `&` | 按位与：$\forall i: (a \& b)_i = a_i \land b_i$ | 掩码提取 |
| `\|` | 按位或：$\forall i: (a \| b)_i = a_i \lor b_i$ | 标志组合 |
| `^` | 按位异或：$\forall i: (a \oplus b)_i = a_i \oplus b_i$ | 加密、交换 |
| `~` | 按位取反：$\forall i: (\sim a)_i = \neg a_i$ | 补码运算 |
| `<<` | 左移：$a << k = a \times 2^k$ | 快速乘以 $2^k$ |
| `>>` | 右移：$a >> k = \lfloor a / 2^k \rfloor$ | 快速除以 $2^k$ |

**未定义行为**：对负数进行右移是实现定义的（算术右移 vs 逻辑右移）。

### cv 限定符的约束传播

`const` 和 `volatile` 通过以下规则传播：

$$\text{指向 const 的指针} \Rightarrow \text{不能通过该指针修改对象}$$
$$\text{顶层 const} \Rightarrow \text{对象本身不可变}$$
$$\text{底层 const} \Rightarrow \text{指向 const 的指针/引用}$$

```cpp
int i = 42;
const int* p1 = &i;    // 底层 const：不能通过 p1 修改 i
int* const p2 = &i;    // 顶层 const：p2 自身不能指向别的
const int* const p3 = &i; // 两者兼备
```

**const 的哲学**：
- `const` 是**承诺**而非强制：编译器帮助发现无意的修改，但可以通过 `const_cast` 绕过
- `volatile` 是**不优化**：告诉编译器每次访问都必须从内存读取，不能缓存

## 参考存根

```cpp
#include <variant>
#include <string>
#include <iostream>
#include <optional>
#include <bitset>

// decltype(auto) 的正确用法
int x = 10;
int& get_ref() { return x; }

auto r1 = get_ref();              // int（引用被丢弃）
decltype(auto) r2 = get_ref();   // int&（引用被保留）

// variant 演示
std::variant<int, double, std::string> v = 42;
std::visit([](auto&& arg) {
    using T = std::decay_t<decltype(arg)&>;
    if constexpr (std::is_same_v<T, int>)
        std::cout << "int: " << arg << "\n";
    else if constexpr (std::is_same_v<T, double>)
        std::cout << "double: " << arg << "\n";
    else if constexpr (std::is_same_v<T, std::string>)
        std::cout << "string: " << arg << "\n";
}, v);

// optional 演示
std::optional<std::string> find_name(int id) {
    if (id > 0) return "User_" + std::to_string(id);
    return std::nullopt;
}

// string_view 演示
std::string s = "hello world";
std::string_view sv = s;           // 零拷贝
std::string_view sub = sv.substr(0, 5);  // 仍是零拷贝

// 位运算演示
constexpr int READ_FLAG = 0b001;   // 1
constexpr int WRITE_FLAG = 0b010;  // 2
constexpr int EXEC_FLAG = 0b100;   // 4

int permissions = READ_FLAG | WRITE_FLAG;  // 3
bool can_read = permissions & READ_FLAG;  // true
bool can_exec = permissions & EXEC_FLAG;  // false
```

## 约束与违反后果

| 约束 | 违反后果 |
|------|----------|
| `auto` 推断基于初始化表达式 | `auto x;` 编译错误——无初始值 |
| `variant` 访问时类型必须匹配 | `std::get<double>(v)` 若当前是 int，则抛出 `std::bad_variant_access` |
| `string_view` 原字符串必须存活 | 原字符串析构后，视图悬空，解引用未定义 |
| `const_cast` 去除 const 后不能写 | 写入了严格化的对象是未定义行为 |
| 有符号整数溢出 | 未定义行为（可被编译器重优化为任意结果） |
| 对齐要求必须满足 | 硬件错误或性能下降，跨平台不可预期 |
| 位域不能跨单元边界 | 编译器强制打包，行为依赖实现 |
| union 读取非活跃成员 | 未定义行为 |
| `volatile` 不提供原子性保证 | 多线程下仍需同步原语 |
