# 变量与类型

C++ 是静态类型语言，编译时确定类型。类型书写繁琐且容易出错，`auto` 和类型推导让代码更简洁。

## 静态类型与类型推导

C++ 是静态类型语言，编译时确定类型。`auto` 关键字自动推导类型，移除引用和 cv 限定符；`decltype` 推导类型但不求值，保留引用和 cv 限定符；`decltype(auto)` 保留表达式的原始类型。

`std::variant` 提供类型安全的联合体替代。

### 参考样例

```cpp
// auto 自动推导类型
auto x = 42;          // int
auto y = 3.14;        // double
auto name = "hello";  // const char*
auto vec = std::vector<int>{1, 2, 3};  // std::vector<int>

// auto 移除引用和 cv 限定符
int x = 10;
int& ref = x;
auto y = ref;         // int，不是 int&

// auto& 保留引用
auto& z = ref;        // int&

// auto&& 保留值类别（左值引用或右值引用）
auto&& r1 = x;        // int&
auto&& r2 = 10;       // int&&
```

## decltype 类型推导

`decltype` 推导但不求值，返回类型。双括号 `decltype((expr))` 推导为引用。

### 参考样例

```cpp
int x = 10;
int& ref = x;
int* ptr = &x;

decltype(x) a = 5;    // int
decltype(ref) b = x;  // int&，必须初始化为左值
decltype(ptr) c = &x; // int*

// decltype((expr)) 双括号推导为引用
int i = 10;
decltype((i)) r1 = i;  // int&（表达式结果是引用）
decltype(i) r2 = i;    // int

// 用于函数返回类型
template<typename T, typename U>
auto add(T a, U b) -> decltype(a + b) {
    return a + b;
}
```

## decltype(auto)（C++14）

`decltype(auto)` 保留表达式的原始类型（包括引用和 cv 限定符），与 `auto` 不同。

### 参考样例

```cpp
int x = 10;
int& get_ref() { return x; }

decltype(auto) r1 = get_ref();  // int&，保留返回类型
decltype(auto) r2 = x;          // int，不会推导为 int&

// 对比：auto 会丢失引用
// auto r3 = get_ref();  // int，不是 int&
```

## decltype vs auto 对比

`auto` 移除引用和 const，`decltype` 保留原始类型。

### 参考样例

```cpp
int x = 10;
const int cx = x;
int& rx = x;

auto a = rx;          // int，移除引用
auto b = cx;          // int，移除 const
decltype(rx) c = rx;  // int&，保留引用
decltype(cx) d = cx;  // const int，保留 const
```

## 基本类型

C++ 提供丰富的基本类型：整数（`int`、`long long`）、浮点（`double`、`float`）、字符（`char`）、布尔（`bool`）。类型大小通常为：int 4 字节、long long 8 字节、double 8 字节、float 4 字节、char 1 字节、bool 1 字节。

## 类型转换

C++ 提供四种类型转换：`static_cast` 编译时转换、`dynamic_cast` 运行时检查、`const_cast` 移除 const、`reinterpret_cast` 底层位重解释。

`static_cast` 用于明确定义的编译时转换，如数值类型转换、枚举转整数、void* 转具体指针。`dynamic_cast` 用于安全的向下转型，失败时指针返回 nullptr，引用抛 `bad_cast` 异常。`const_cast` 移除或添加 const/volatile 限定符。`reinterpret_cast` 进行低层位重解释，不进行任何检查。

### 参考样例

```cpp
// static_cast：编译时转换
double d = 3.14;
int i = static_cast<int>(d);  // 3，截断小数

void* p = &d;
double* dp = static_cast<double*>(p);  // 从 void* 转回

enum Color { Red, Green, Blue };
int c = static_cast<int>(Red);  // 枚举到整数

// dynamic_cast：运行时类型检查
class Base { virtual ~Base() {} };
class Derived : public Base { void special() {} };

Base* base_ptr = new Derived();
Derived* derived_ptr = dynamic_cast<Derived*>(base_ptr);
if (derived_ptr) {
    derived_ptr->special();  // 安全使用
}

// const_cast：移除或添加 const
const int ci = 10;
int* p = const_cast<int*>(&ci);  // 移除 const（不推荐修改 const 对象）

// reinterpret_cast：底层位重解释
int* ip = new int(42);
char* cp = reinterpret_cast<char*>(ip);  // 同一地址的不同类型解释
long long addr = reinterpret_cast<long long>(ip);  // 获取地址值
```

## 类型别名

类型别名有两种创建方式：`typedef`（C++98）和 `using`（C++11，后者更清晰）。C++14 支持模板别名。

### 参考样例

```cpp
// typedef（C++98）
typedef unsigned int uint;
typedef std::vector<int> IntVec;
typedef int (*FuncPtr)(int, int);

// using 别名（C++11，更清晰）
using uint = unsigned int;
using IntVec = std::vector<int>;
using FuncPtr = int(*)(int, int);

// 模板别名（C++14）
template<typename T>
using Vec = std::vector<T>;
Vec<int> int_vec;
Vec<std::string> str_vec;
```

## 类型类别判断

`<type_traits>` 提供编译时类型判断：`std::is_same`、`std::is_pointer`、`std::is_class`、`std::is_integral`、`std::is_floating_point` 等。`std::conditional` 支持编译时条件选择。

### 参考样例

```cpp
#include <type_traits>

static_assert(std::is_same<int, int>::value, "int == int");
static_assert(!std::is_pointer<int>::value, "int is not pointer");
static_assert(std::is_class<std::string>::value, "string is class");
static_assert(std::is_integral<int>::value, "int is integral");

// 编译时条件选择
template<typename T>
typename std::conditional<std::is_integral<T>::value, T, double>::type
sum(T a, T b) {
    return a + b;
}
```

## 字符串

`std::string` 提供字符串操作：`size()` 获取长度、`substr()` 提取子串、`find()` 查找子串。C++17 的 `std::string_view` 提供非拷贝的字符串视图。

### 参考样例

```cpp
std::string s1 = "hello";
std::string s2 = " world";
std::string s3 = s1 + s2;  // "hello world"

s1.size();      // 5
s1.substr(0, 3);  // "hel"
s1.find("ll");    // 2

// C++17 字符串视图（不拷贝）
std::string_view sv1 = "hello world";
std::string_view sv2 = sv1.substr(0, 5);  // "hello"，无拷贝
```

## 联合体与结构体

联合体（`union`）所有成员共享同一内存。结构体（`struct`）默认公开成员，用于 POD 数据。

### 参考样例

```cpp
// 联合体：所有成员共享同一内存
union Data {
    int i;
    double d;
    char c;
};

Data data;
data.d = 3.14;      // 设置 d
double val = data.d; // 读取 d
data.i = 42;        // 覆写 d 的位

// 匿名联合体
struct Variant {
    enum Type { INT, DOUBLE };
    Type type;
    union { int i; double d; };
};

// 结构体默认公开成员
struct Point { int x; int y; };
Point p{10, 20};  // 聚合初始化
```

## nullptr（C++11）

`nullptr` 是类型安全的空指针，类型为 `std::nullptr_t`。与 `NULL`（定义为整数 0）或 `0` 不同，`nullptr` 在函数重载时会精确匹配指针类型。

### 参考样例

```cpp
int* p1 = nullptr;    // 推荐：类型安全的空指针
int* p2 = NULL;      // C++11 中实际定义为 0，可能产生重载歧义
int* p3 = 0;         // 整数 0，与 NULL 等价

void foo(int);
void foo(char*);

foo(nullptr);  // 调用 foo(char*)，不会与整数混淆
```

## std::variant（C++17）

`std::variant` 是类型安全的联合体替代，提供编译时类型检查。可通过 `std::get_if` 或 `std::visit` 访问。

### 参考样例

```cpp
#include <variant>
#include <string>

std::variant<int, double, std::string> v = 42;
v = 3.14;
v = "hello";

if (auto p = std::get_if<int>(&v)) {
    std::cout << "int: " << *p << std::endl;
}

// std::visit 统一处理
std::visit([](auto&& arg) {
    std::cout << arg << std::endl;
}, v);
```
