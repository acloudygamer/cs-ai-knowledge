# 面向对象

## 定义

**类的本质是对数据和操作这些数据的函数的统一封装，其核心机制是访问控制——通过 `private`/`protected`/`public` 限定符将接口与实现分离，强制调用方只能通过公开契约访问内部状态。**

## 数学模型

### 访问控制的权限矩阵

| 限定符 | 类自身 | 派生类 | 其他类 |
|--------|-------|--------|--------|
| `private` | ✅ | ❌ | ❌ |
| `protected` | ✅ | ✅ | ❌ |
| `public` | ✅ | ✅ | ✅ |

**继承后的访问调整**：

| 基类成员 | public 继承 | protected 继承 | private 继承 |
|---------|-------------|----------------|--------------|
| public | public | protected | private |
| protected | protected | protected | private |
| private | 不可见 | 不可见 | 不可见 |

### 虚函数表的内存布局

每个含虚函数的类有一个隐藏的**虚表指针**（vptr）：
$$\text{vtable} : \text{类} \rightarrow \text{函数指针数组}$$

对象内存布局（单继承）：
```
对象 obj（假设 Dog 继承自 Animal）:
┌────────────────────────┐
│ Animal 部分             │
│   vptr ─────────────┐  │
├────────────────────────┤  │
│ Dog 扩展部分          │  │
└────────────────────────┘  │
                             │
                             ▼
                    ┌───────────────────┐
                    │ vtable (Dog)      │
                    │ [0] Animal::~()   │  ← 析构函数
                    │ [1] Animal::eat() │
                    │ [2] Dog::bark()   │  ← 动态分派
                    │ ...               │
                    └───────────────────┘
```

**虚函数调用的开销**：
$$T_{\text{virtual}} = T_{\text{vptr 读取}} + T_{\text{vtable 偏移访问}} = O(1)$$

仅比普通函数调用多一次内存间接寻址。

### RAII 的资源管理不变量

$$\forall \text{对象 } o : \text{Constructor}(o) \implies \text{acquired}(o.\text{resource})$$
$$\forall \text{对象 } o : \text{Destructor}(o) \implies \text{released}(o.\text{resource})$$

**强异常安全保证**：
$$\text{若 Constructor 抛出异常} \implies \text{无对象被构造（事务语义）}$$

## 数据流

### 构造/析构的数据流

<pre>
构造顺序（派生类对象）:
    1. 基类构造 → 2. 成员构造 → 3. 派生类构造

    class Base { };
    class Derived : public Base {
        Member m;
    };

    new Derived();
    │
    ├──► Base 构造
    ├──► Member m 构造
    ├──► Derived 构造
    │
    └──► 对象完全构造

析构顺序（与构造相反）:
    1. 派生类析构 → 2. 成员析构 → 3. 基类析构

    delete p;
    │
    ├──► Derived 析构
    ├──► ~Member() 析构
    ├──► ~Base() 析构
    │
    └──► 内存返还堆
</pre>

### 多态调用的动态分派

<pre>
Animal* animal = new Dog("Buddy");

animal-&gt;speak();
    │
    ├──► 读取 animal-&gt;vptr
    │
    ├──► 读取 vptr[2]（speak 的偏移）
    │
    └──► 调用函数指针 Dog::speak()

内存操作序列:
    1. MOV RAX, [animal]      ; RAX = vptr 地址
    2. MOV RAX, [RAX + 16]    ; RAX = vtable[2]（speak）
    3. CALL RAX               ; 调用 Dog::speak()
</pre>

### 移动语义的所有权转移

<pre>
Buffer b1(1000);           // b1 构造，持有资源 R
Buffer b2 = std::move(b1); // b2 窃取 b1 的资源
    │
    ├──► 调用 Buffer(Buffer&amp;&amp;) 移动构造函数
    ├──► b2.data = b1.data    ; 资源转移
    ├──► b1.data = nullptr    ; b1 变为空壳
    │
    └──► b1 析构时，delete[] nullptr 无操作
</pre>

## 机制

### 六大特殊成员函数

| 函数 | 默认行为 | 何时需要自定义 |
|------|---------|---------------|
| 默认构造 | `T() = default` | 类有其他构造函数时需显式定义 |
| 拷贝构造 | 逐成员拷贝 | 管理资源（指针、句柄）时需删除或自定义 |
| 移动构造 | 逐成员移动 | 管理资源且需要高效转移时 |
| 拷贝赋值 | 逐成员拷贝赋值 | 同上 |
| 移动赋值 | 逐成员移动赋值 | 同上 |
| 析构函数 | `~T() = default` | 管理资源时需自定义（通常配合移动语义） |

**C++11 后的规则**：
- 若声明了任一移动或拷贝操作，编译器不再自动生成其他操作
- 若声明了析构函数，编译器不再自动生成移动操作

### = default 与 = delete

**`= default`**：
```cpp
class Trivial {
    int x_;
public:
    Trivial() = default;  // 显式要求编译器生成默认版本
    Trivial(int x) : x_(x) {}
};
```

**`= delete`**：
```cpp
class NonCopyable {
    std::vector&lt;int&gt; data_;
public:
    NonCopyable() = default;
    NonCopyable(const NonCopyable&amp;) = delete;      // 禁止拷贝构造
    NonCopyable&amp; operator=(const NonCopyable&amp;) = delete;  // 禁止拷贝赋值
};
```

### 菱形继承与虚继承

**菱形继承的问题**：
```
    A
   / \
  B   C
   \ /
    D

class A { int x; };
class B : public A {};
class C : public A {};
class D : public B, public C {};

D d;
d.B::x = 1;  // 必须指定路径
d.C::x = 2;  // 另一份 x
```

**虚继承的解决**：
```
class B : virtual public A {};
class C : virtual public A {};
class D : public B, public C {};

D d;
d.x = 1;     // 唯一 x，B 和 C 共享同一个 A 子对象
```

虚继承的代价：虚基类子对象通过 vptr（间接寻址）访问，增加一层间接跳转。

### override 与 final

**`override`**：编译期断言，确保函数确实重写了基类虚函数
```cpp
struct Base {
    virtual void foo() const;
};

struct Derived : Base {
    void foo() const override {}  // 编译成功
    // void foo() override {}      // 编译错误：签名不匹配
};
```

**`final`**：禁止进一步重写
```cpp
struct Base {
    virtual void foo() final {}
};

struct Derived : Base {
    // void foo() override {}    // 编译错误：foo 已 final
};
```

## 参考存根

```cpp
#include &lt;memory&gt;
#include &lt;iostream&gt;
#include &lt;vector&gt;

// RAII 演示
class Buffer {
    char* data_;
    size_t size_;
public:
    Buffer(size_t size) : data_(new char[size]), size_(size) {}
    ~Buffer() { delete[] data_; }

    // 移动构造
    Buffer(Buffer&amp;&amp; other) noexcept : data_(other.data_), size_(other.size_) {
        other.data_ = nullptr;
        other.size_ = 0;
    }

    Buffer(const Buffer&amp;) = delete;
    Buffer&amp; operator=(const Buffer&amp;) = delete;
};

// 虚函数演示
struct Animal {
    virtual ~Animal() = default;
    virtual void speak() const = 0;
};

struct Dog : Animal {
    std::string name_;
    Dog(std::string n) : name_(n) {}
    void speak() const override { std::cout &lt;&lt; name_ &lt;&lt; " says Woof!\n"; }
};

struct Cat : Animal {
    std::string name_;
    Cat(std::string n) : name_(n) {}
    void speak() const override { std::cout &lt;&lt; name_ &lt;&lt; " says Meow!\n"; }
};

void make_speak(const Animal&amp; a) { a.speak(); }
```

## 约束与违反后果

| 约束 | 违反后果 |
|------|----------|
| 基类析构函数必须为 virtual | 通过基类指针删除派生类时，派生类析构函数不调用，资源泄漏 |
| 虚函数调用通过 vptr | 比普通调用多一次内存访问 |
| 移动操作必须是 noexcept | `vector` 扩容时不使用移动，退化为拷贝 |
| `= delete` 的函数禁止调用 | 编译错误 |
| 虚继承增加间接寻址开销 | 轻微性能损失（通常可忽略） |
