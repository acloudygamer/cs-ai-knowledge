# 面向对象

## 类与对象

类定义了一组属性和方法的抽象数据类型，对象是类的实例。C++ 中类的默认成员访问级别是 `private`，结构体默认是 `public`。

### 构造函数与特殊成员函数

构造函数在对象创建时调用，用于初始化。C++11 提供六大默认特殊成员函数：默认构造函数、拷贝构造函数、移动构造函数、拷贝赋值运算符、移动赋值运算符、析构函数。使用 `= default` 显式要求编译器生成默认实现，`= delete` 禁止特定函数。

### 参考样例

```cpp
class Rectangle {
    double width_;
    double height_;
public:
    Rectangle() : width_(0), height_(0) {}
    Rectangle(double w, double h) : width_(w), height_(h) {}

    double area() const { return width_ * height_; }
    double perimeter() const { return 2 * (width_ + height_); }
};

// 六大默认特殊成员函数
class MyClass {
    // 编译器会自动生成：
    // 1. 默认构造函数
    // 2. 拷贝构造函数
    // 3. 拷贝赋值运算符
    // 4. 移动构造函数
    // 5. 移动赋值运算符
    // 6. 析构函数
};

// = default 与 = delete
class NonCopyable {
    std::vector<int> data_;
public:
    NonCopyable() = default;
    NonCopyable(const NonCopyable&) = delete;  // 禁止拷贝
    NonCopyable& operator=(const NonCopyable&) = delete;
    NonCopyable(NonCopyable&&) = default;
    NonCopyable& operator=(NonCopyable&&) = default;
};

// 统一初始化（C++11）
Person p1;                       // 默认构造
Person p2{"Alice", 30};         // 参数化构造
Person p3 = Person{"Bob", 25};  // 显式构造
Person p4{p3};                   // 拷贝构造
Person p5 = std::move(p2);      // 移动构造
```

## 继承

继承允许创建基于现有类的层次结构。派生类继承基类的成员，可添加自己的成员或重写虚函数。

### 继承方式与访问控制

继承方式（`public`/`protected`/`private`）决定基类成员的访问级别。`protected` 成员在派生类中可见，外部不可见。

### 参考样例

```cpp
// 基类
class Animal {
protected:
    std::string name_;
public:
    Animal(const std::string& name) : name_(name) {}
    virtual ~Animal() {}
    virtual void speak() const {
        std::cout << name_ << " makes a sound" << std::endl;
    }
};

// 派生类
class Dog : public Animal {
    std::string breed_;
public:
    Dog(const std::string& name, const std::string& breed)
        : Animal(name), breed_(breed) {}

    void speak() const override {
        std::cout << name_ << " barks: Woof!" << std::endl;
    }
};

Animal* animal = new Dog("Buddy", "Golden Retriever");
animal->speak();  // 动态绑定，调用 Dog::speak()

// 多继承与虚继承（解决菱形继承）
class Flyable { public: virtual void fly() const = 0; };

class Bird : public Animal { public: Bird(const std::string& name) : Animal(name) {} };

class Sparrow : public Bird, public Flyable {
public:
    Sparrow(const std::string& name) : Bird(name) {}
    void fly() const override { std::cout << " flies" << std::endl; }
};

// 虚继承解决菱形继承问题
class Base { public: int value_; };
class A : virtual public Base {};
class B : virtual public Base {};
class C : public A, public B {};  // C 只有一个 Base 子对象
```

## 多态

多态允许通过基类指针或引用操作派生类对象。虚函数实现动态绑定，纯虚函数定义抽象接口。

### 虚函数与动态绑定

基类析构函数应设为 `virtual`，否则通过基类指针删除派生类对象时，派生类析构函数不会被调用。`override` 关键字显式标识重写，`final` 关键字禁止进一步重写或继承。

### 参考样例

```cpp
class Shape {
public:
    virtual double area() const = 0;  // 纯虚函数
    virtual ~Shape() {}
};

class Circle : public Shape {
    double radius_;
public:
    Circle(double r) : radius_(r) {}
    double area() const override {
        return 3.14159 * radius_ * radius_;
    }
};

// override 与 final（C++11）
class Base {
public:
    virtual void foo() const {}
    virtual void bar() {}
};

class Derived : public Base {
public:
    void foo() const override {}  // 确保基类有可重写的 foo()
    void bar() override {}         // 基类没有 virtual void bar()，编译错误
};

// final：禁止重写或继承
class NoOverride final {
    virtual void process() final {}  // 禁止派生类重写
};
class NoInherit : public Base {};  // 禁止继承
```

## 访问控制与友元

类成员默认 `private`，只能通过成员函数或友元访问。`public` 成员可在类外部访问。`protected` 成员在派生类中可见。友元（`friend`）可以访问类的所有 private 成员。

### 参考样例

```cpp
class Person {
    std::string name_;
    int age_;
public:
    Person(const std::string& name, int age)
        : name_(name), age_(age) {}

    // 声明友元函数
    friend void print_person(const Person& p);
    friend class PersonPrinter;
};

// 友元函数可以访问 private 成员
void print_person(const Person& p) {
    std::cout << p.name_ << ", " << p.age_ << std::endl;
}

// 前向声明
class Person;  // 不完整类型
void greet(const Person& p);  // 可以声明但不能定义
class Person {
    std::string name_;
public:
    Person(const std::string& name) : name_(name) {}
};
```

## 嵌套类与结构体

嵌套类在另一个类的内部定义，遵循相同的访问控制规则。结构体与类几乎相同，默认成员访问级别不同（struct 为 `public`，class 为 `private`）。

### 参考样例

```cpp
class Outer {
    int outer_value_;
public:
    class Inner {
        int inner_value_;
    public:
        explicit Inner(int v) : inner_value_(v) {}
        void process(const Outer& o) {
            // 可以访问 o.outer_value_ 如果是 public
        }
    };
    Inner create_inner(int v) { return Inner(v); }
};

// 结构体默认 public
struct PointStruct {
    int x;  // 默认 public
    int y;
    PointStruct(int x, int y) : x(x), y(y) {}
};

// 类默认 private
class PointClass {
    int x;  // 默认 private
    int y;
public:
    PointClass(int x, int y) : x(x), y(y) {}
};
```
