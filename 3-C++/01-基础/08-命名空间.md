# 命名空间

命名空间（Namespace）是 C++ 防止命名冲突的重要机制。

## 基本用法

```cpp
namespace MyLibrary {
    class String { /* ... */ };
    void process();
    const int MAX_SIZE = 100;
}

// 使用限定符访问
MyLibrary::String s;
MyLibrary::process();
int x = MyLibrary::MAX_SIZE;
```

## using 声明与 using 指示

```cpp
namespace MyLib {
    void func();
    class Helper {};
}

// using 声明：引入单个名称
using MyLib::func;
func();  // 直接调用，无需限定符

// using 指示：将整个命名空间引入作用域
using namespace MyLib;
Helper h;  // 直接使用
func();
```

### 注意事项

```cpp
// 命名空间冲突示例
namespace A { int x = 1; }
namespace B { int x = 2; }

using namespace A;
using namespace B;

// cout << x << endl;  // 错误：x 歧义
cout << A::x << endl;  // 明确指定
```

## 嵌套命名空间

```cpp
namespace outer {
    namespace inner {
        void func() {}
    }
}

// C++17 嵌套命名空间简化
namespace outer::inner {
    void func() {}
}

// 使用
outer::inner::func();
```

## inline 命名空间（C++11）

inline 命名空间中的名称自动作为外层命名空间的成员出现。

```cpp
namespace MyLib {
    inline namespace v1 {
        void func() { std::cout << "v1\n"; }
    }
}

// 现在 func 可以不加版本前缀直接访问
MyLib::func();  // 调用 v1::func

// 切换版本时只需改变 inline
namespace MyLib {
    inline namespace v2 {
        void func() { std::cout << "v2\n"; }
    }
}

MyLib::func();  // 现在调用 v2::func
```

## 匿名命名空间

匿名命名空间内的名称只在当前翻译单元可见，相当于给名称加了 static。

```cpp
namespace {
    int helper_function() { return 1; }
    class HelperClass {};
}

// 等价于：
namespace _unique_name {
    int helper_function() { return 1; }
}
using _unique_name::helper_function;
```

### 用途

```cpp
// 替代 static（ C 风格）
static int counter = 0;  // C 风格，不推荐

namespace {
    int counter = 0;  // C++ 风格，更清晰
}

// 定义仅当前文件使用的实体
namespace {
    class InternalOnly {};
    void internal_helper();
}
```

## 命名空间别名

```cpp
namespace very_long_namespace_name {
    void func() {}
}

// 定义短别名
namespace short_ns = very_long_namespace_name;
short_ns::func();

// 嵌套命名空间简化（C++17）
namespace A::B::C {
    void func() {}
}
```

## 命名空间与模板

```cpp
namespace math {
    template<typename T>
    T add(T a, T b) { return a + b; }
}

// 特化模板命名空间
namespace math {
    template<>
    int add(int a, int b) { return a + b; }
}
```

## ADL（参数依赖查找）

Argument-Dependent Lookup，简称 ADL，当调用无限定函数时，编译器会在参数的命名空间中查找函数。

```cpp
namespace Vec {
    class Vector { double x, y; };
    
    // 这个函数虽然无限定，但 ADL 会找到它
    Vector operator+(const Vector& a, const Vector& b);
}

Vector a, b;
auto c = a + b;  // ADL 找到 Vec::operator+
```

### ADL 与 using

```cpp
namespace MyNS {
    struct Widget {};
    void process(Widget&) {}
}

void external_process(Widget&) {}  // 通常不应该这样写

Widget w;
process(w);  // ADL 找到 MyNS::process

using MyNS::process;
process(w);  // using 声明后，隐藏 ADL，只找 MyNS::process
```

## 命名空间最佳实践

### 1. 项目命名空间

```cpp
// myproject/core/utils.h
#ifndef MYPROJECT_CORE_UTILS_H
#define MYPROJECT_CORE_UTILS_H

namespace myproject {
    namespace core {
        namespace utils {
            // 实现
        }
    }
}

#endif
```

### 2. 头文件中的 using

```cpp
// good.h
#ifndef GOOD_H
#define GOOD_H

namespace good {
    void func();
}

// 在头文件中尽量避免 using namespace
// 如需使用，在.cpp而非.h中

#endif
```

### 3. 避免污染

```cpp
// 在小范围内使用 using
void some_function() {
    using namespace std;  // 只在这个函数内有效
    cout << "hello" << endl;
}
```

### 4. 统一使用命名空间

```cpp
// 避免在全局作用域定义名称
namespace myapp {
    class Config {};
    void init() {}
}
```

## std 命名空间

```cpp
// 正确做法：不要 using namespace std
#include <vector>
#include <string>

std::vector<std::string> names;

// 可以 using 具体名称
using std::vector;
vector<int> nums;
```

## 命名空间与动态库

```cpp
// 动态库导出的符号通常带命名空间前缀
extern "C" {
    // C 风格导出，无命名空间
    MYLIBRARY_API void process();
}

namespace mylib {
    MYLIBRARY_API void process();
}
```
