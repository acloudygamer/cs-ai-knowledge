# 命名空间

命名空间（Namespace）是 C++ 防止命名冲突的重要机制，将代码组织成逻辑分组。

## 基本用法与 using 声明

`namespace` 定义命名空间，`::` 限定符访问其中成员。`using` 声明引入单个名称，`using namespace` 指示将整个命名空间引入作用域。使用命名空间时需注意潜在的名称冲突。

### 参考样例

```cpp
namespace MyLibrary {
    class String { /* ... */ };
    void process();
    const int MAX_SIZE = 100;
}

// 使用限定符访问
MyLibrary::String s;
MyLibrary::process();

// using 声明：引入单个名称
using MyLib::func;
func();  // 直接调用

// using 指示：将整个命名空间引入作用域
using namespace MyLib;
Helper h;  // 直接使用

// 命名空间冲突示例
namespace A { int x = 1; }
namespace B { int x = 2; }
using namespace A;
using namespace B;
cout << A::x << endl;  // 明确指定
```

## 嵌套命名空间与 inline（C++17）

C++17 支持 `namespace A::B::C {}` 简化嵌套命名空间。`inline namespace` 中的名称自动作为外层命名空间的成员出现，便于版本切换。

### 参考样例

```cpp
// 嵌套命名空间
namespace outer {
    namespace inner {
        void func() {}
    }
}

// C++17 简化
namespace outer::inner {
    void func() {}
}

// inline 命名空间（版本切换）
namespace MyLib {
    inline namespace v1 {
        void func() { std::cout << "v1\n"; }
    }
}
MyLib::func();  // 调用 v1::func

// 切换版本
namespace MyLib {
    inline namespace v2 {
        void func() { std::cout << "v2\n"; }
    }
}
MyLib::func();  // 现在调用 v2::func
```

## 匿名命名空间

匿名命名空间内的名称只在当前翻译单元可见，相当于给名称加了 `static`。用于定义仅当前文件使用的实体。

### 参考样例

```cpp
namespace {
    int helper_function() { return 1; }
    class HelperClass {};
}

// 等价于
namespace _unique_name {
    int helper_function() { return 1; }
}
using _unique_name::helper_function;

// 替代 static（C 风格）
static int counter = 0;  // C 风格
namespace {
    int counter = 0;  // C++ 风格，更清晰
}
```

## 命名空间别名与 ADL

命名空间别名简化长名称访问。ADL（参数依赖查找）在调用无限定函数时，会在参数的命名空间中查找函数。

### 参考样例

```cpp
// 命名空间别名
namespace very_long_namespace_name { void func() {} }
namespace short_ns = very_long_namespace_name;
short_ns::func();

// ADL 示例
namespace Vec {
    class Vector { /* ... */ };
    Vector operator+(const Vector& a, const Vector& b);  // ADL 会找到它
}
Vector a, b;
auto c = a + b;  // ADL 找到 Vec::operator+

// ADL 与 using
namespace MyNS {
    struct Widget {};
    void process(Widget&) {}
}
Widget w;
process(w);  // ADL 找到 MyNS::process
using MyNS::process;
process(w);  // using 声明后，隐藏 ADL
```

## std 命名空间最佳实践

不要使用 `using namespace std`，推荐使用具体名称或限定符。

### 参考样例

```cpp
// 正确做法
#include <vector>
#include <string>

std::vector<std::string> names;

// 可以 using 具体名称
using std::vector;
vector<int> nums;

// 小范围内使用 using
void some_function() {
    using namespace std;  // 只在这个函数内有效
    cout << "hello" << endl;
}
```

## 命名空间与动态库

动态库导出的符号通常带命名空间前缀。`extern "C"` 用于 C 风格导出，无命名空间。

### 参考样例

```cpp
// 动态库导出的符号
extern "C" {
    MYLIBRARY_API void process();  // C 风格导出
}

namespace mylib {
    MYLIBRARY_API void process();  // C++ 风格导出
}
```
