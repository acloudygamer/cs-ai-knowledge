# C++ 单元测试

## 解决什么问题

代码需要验证正确性、防止回归、记录预期行为。C++ 单元测试框架（GoogleTest、Catch2）提供了结构化的测试组织、丰富的断言、夹具管理和测试发现机制。

## 核心概念

- 测试框架提供断言宏验证预期值与实际值的匹配
- 测试夹具（Fixtures）管理测试共享的资源和清理逻辑
- 参数化测试用少量代码覆盖多组测试数据
- 测试发现机制自动收集并运行所有测试用例

## 怎么用

### GoogleTest

GoogleTest 是 Google 开发的跨平台测试框架。

```cpp
#include <gtest/gtest.h>

// 测试套件
TEST(MathTest, Addition) {
    EXPECT_EQ(2 + 2, 4);
    EXPECT_NE(2 + 2, 5);
}

int main(int argc, char** argv) {
    testing::InitGoogleTest(&argc, argv);
    return RUN_ALL_TESTS();
}
```

### Catch2

Catch2 以单头文件著称，语法更自然。

```cpp
#define CATCH_CONFIG_MAIN
#include <catch2/catch_test_macros.hpp>

TEST_CASE("Math operations", "[math]") {
    REQUIRE(2 + 2 == 4);
    CHECK(3 * 3 == 9);
}
```

### 断言类型

```cpp
// 致命断言（ASSERT_*）- 失败时终止当前测试
ASSERT_EQ(a, b);
ASSERT_TRUE(condition);
ASSERT_FLOAT_EQ(a, b);

// 非致命断言（EXPECT_*）- 失败时继续执行
EXPECT_EQ(a, b);
EXPECT_LT(a, b);      // less than
EXPECT_GT(a, b);      // greater than
```

### 测试夹具（Fixtures）

```cpp
class DatabaseTest : public testing::Test {
protected:
    void SetUp() override {
        db_ = new Database("test.db");
        db_->connect();
    }

    void TearDown() override {
        db_->disconnect();
        delete db_;
    }

    Database* db_;
};

TEST_F(DatabaseTest, Insert) {
    EXPECT_TRUE(db_->insert("key", "value"));
}
```

### 参数化测试

```cpp
class AddTest : public testing::TestWithParam<std::tuple<int, int, int>> {};

TEST_P(AddTest, Values) {
    auto [a, b, expected] = GetParam();
    EXPECT_EQ(add(a, b), expected);
}

INSTANTIATE_TEST_CASE_P(
    AddTests, AddTest,
    testing::Values(
        std::make_tuple(1, 2, 3),
        std::make_tuple(0, 0, 0),
        std::make_tuple(-1, 1, 0)
    )
);
```

### CMake 集成

```cmake
cmake_minimum_required(VERSION 3.16)
project(MyProject)
enable_testing()

include(FetchContent)
FetchContent_Declare(
    googletest
    GIT_REPOSITORY https://github.com/google/googletest.git
    GIT_TAG v1.14.0
)
FetchContent_MakeAvailable(googletest)

add_executable(tests test_main.cpp utils_test.cpp)
target_link_libraries(tests PRIVATE GTest::gtest GTest::gtest_main)

include(GoogleTest)
gtest_discover_tests(tests)
```

### 测试最佳实践

```cpp
// AAA 模式（Arrange-Act-Assert）
TEST_CASE("Process pending orders", "[order]") {
    // Arrange
    OrderProcessor processor;
    Order order{"id-123", 100.0, OrderStatus::Pending};

    // Act
    processor.add_order(order);
    processor.process_pending();

    // Assert
    auto result = processor.get_order("id-123");
    REQUIRE(result.status == OrderStatus::Processed);
}

// Mock 对象示例
class MockUserRepository : public IUserRepository {
public:
    MOCK_METHOD(User, find_by_id, (int id), (override));
};

TEST_CASE("UserService with mock") {
    MockUserRepository mock_repo;
    EXPECT_CALL(mock_repo, find_by_id(1))
        .WillOnce(Return(User{"Alice", 25}));

    UserService service(&mock_repo);
    auto user = service.get_user(1);
    CHECK(user.name == "Alice");
}
```
