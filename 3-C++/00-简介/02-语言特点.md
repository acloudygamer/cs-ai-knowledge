# C++ 语言特点

C++ 是一门独特而强大的编程语言，它融合了高性能、底层控制和现代抽象能力。理解 C++ 的核心特点，是掌握这门语言的关键。

## 极致性能

C++ 最大的优势在于**性能**。它编译后直接生成机器码，没有虚拟机或解释器的额外开销。

### 零成本抽象

C++ 的设计哲学是"你只为使用的东西付费"：

```cpp
#include <vector>
#include <algorithm>

// 高级抽象，但性能接近手写循环
std::vector<int> v = {3, 1, 4, 1, 5, 9};
auto result = std::find_if(v.begin(), v.end(), [](int x) { return x > 3; });

// 编译器通常能将上述代码优化为等价的指针运算
// 不会有额外的函数对象调用开销（如果可以内联）
```

### 内存布局控制

```cpp
// 指定结构体内存布局
struct Packet {
    uint32_t header;    // 4 字节
    uint16_t payload_size;
    uint8_t  flags;
    uint8_t  version;
    char     data[1024];
};

// 确保没有填充（#pragma pack 或 attribute）
struct PackedPacket {
    uint32_t header;
    uint16_t payload_size;
    uint8_t  flags;
    uint8_t  version;
    char     data[1024];
} __attribute__((packed));
```

### 内联与编译器优化

```cpp
// constexpr 函数在编译期求值
constexpr int square(int x) {
    return x * x;
}

int arr[square(5)];  // arr 是 int[25]，编译时确定

// 内联提示
inline int critical_function() {
    return 42;  // 编译器决定是否内联
}
```

## 直接控制硬件

### 指针操作

```cpp
// 直接内存地址操作
int value = 42;
int* ptr = &value;
*ptr = 100;  // 修改原始值

// 指针运算

// 类型转换

*dptr = 3.14;
```

### 引用计数与资源管理

```cpp
#include <memory>

// 裸指针的危险
class RawResource {
    int* data_;
public:
    RawResource(size_t size) : data_(new int[size]) {}
    ~RawResource() { delete[] data_; }  // 必须记住释放
};

// 智能指针自动释放
class SmartResource {
    std::unique_ptr<int[]> data_;
public:
    SmartResource(size_t size)
        : data_(std::make_unique<int[]>(size)) {}
    // 无需手动析构，unique_ptr 自动释放
};
```

## 多范式编程

C++ 支持多种编程范式，你可以根据问题特点选择最合适的风格。

### 过程式编程

```cpp
// 直接编写函数序列
void processData(int* data, size_t size) {
    for (size_t i = 0; i < size; ++i) {
        data[i] *= 2;
    }
}
```

### 面向对象

```cpp
class Shape {
public:
    virtual double area() const = 0;  // 纯虚函数
    virtual ~Shape() = default;
};

class Rectangle : public Shape {
    double width_, height_;
public:
    Rectangle(double w, double h) : width_(w), height_(h) {}
    double area() const override { return width_ * height_; }
};

class Circle : public Shape {
    double radius_;
public:
    explicit Circle(double r) : radius_(r) {}
    double area() const override { return 3.14159 * radius_ * radius_; }
};

// 多态调用
void print_area(const Shape& shape) {
    std::cout << "Area: " << shape.area() << "\n";
}
```

### 泛型编程

```cpp
#include <vector>
#include <algorithm>

// 函数模板
template<typename T>
T max(T a, T b) {
    return a > b ? a : b;
}

// 类模板
template<typename T>
class Stack {
    std::vector<T> data_;
public:
    void push(const T& item) { data_.push_back(item); }
    T pop() {
        T item = data_.back();
        data_.pop_back();
        return item;
    }
};

// 模板特化
template<>
class Stack<bool> {  // 针对 bool 的特殊实现
    // 使用位压缩
};
```

### 函数式编程

```cpp
#include <functional>

// Lambda 表达式
auto add = [](int a, int b) { return a + b; };
```

## RAII：资源获取即初始化

RAII 是 C++ 最独特也是最重要的编程 idiom。

### 核心概念

```cpp
#include <stdexcept>

class FileHandle {
    FILE* file_;
public:
    explicit FileHandle(const char* path)
        : file_(fopen(path, "r")) {
        if (!file_) throw std::runtime_error("Cannot open file");
    }

    ~FileHandle() {
        if (file_) fclose(file_);
    }

    // 禁用拷贝
    FileHandle(const FileHandle&) = delete;
    FileHandle& operator=(const FileHandle&) = delete;

    // 允许移动
    FileHandle(FileHandle&& other) noexcept : file_(other.file_) {
        other.file_ = nullptr;
    }
};

// 使用：作用域结束时自动关闭
void process() {
    FileHandle file("data.txt");
    // 使用 file...
}  // 文件自动关闭，即使抛出异常也会关闭
```

### RAII 与异常安全

```cpp
class MutexGuard {
    std::mutex& mutex_;
public:
    explicit MutexGuard(std::mutex& m) : mutex_(m) { mutex_.lock(); }
    ~MutexGuard() { mutex_.unlock(); }
};

void critical_operation() {
    MutexGuard guard(some_mutex);  // 获取锁
    // 可能抛出异常的操作
    do_something_that_may_throw();
}  // 锁自动释放，即使抛出异常
```

### 标准库中的 RAII

```cpp
#include <fstream>
#include <lock_guard>
#include <unique_lock>

// 文件流自动关闭
{
    std::ofstream file("output.txt");
    file << "Hello\n";
}  // 文件自动关闭

// 锁守卫
std::mutex mtx;
void safe_operation() {
    std::lock_guard lock(mtx);  // 离开作用域自动解锁
    // 线程安全的操作
}
```

## 模板元编程

模板是 C++ 最强大的特性之一，支持编译期计算和类型操作。

### 模板参数

```cpp
// 类型模板参数
template<typename T>
class Container {};

// 非类型模板参数
template<int Size>
class Array {};

// 默认模板参数
template<typename T = int>
class DefaultContainer {};

// 模板模板参数
template<template<typename> class Container, typename T>
class Adaptor {};
```

### 编译期计算

```cpp
#include <array>

// 递归模板计算阶乘
template<int N>
struct Factorial {
    static constexpr int value = N * Factorial<N - 1>::value;
};

template<>
struct Factorial<0> {
    static constexpr int value = 1;
};

static_assert(Factorial<5>::value == 120, "");  // 编译时断言

// 使用
std::array<int, Factorial<5>::value> arr;  // 大小为 120
```

### SFINAE 与 concepts

```cpp
#include <type_traits>

// SFINAE：替换失败不是错误
template<typename T,
         typename = std::enable_if_t<std::is_integral_v<T>>>
void process(T value) {
    // 只处理整数类型
}

// C++20 concepts
template<typename T>
concept Numeric = std::integral<T> || std::floating_point<T>;

template<Numeric T>
T add(T a, T b) { return a + b; }
```

## 作用域与生命周期

### 作用域规则

```cpp

    void func() {

    }

```

### 生命周期

```cpp
// 静态生命周期
static int persistent = 1;  // 程序结束才销毁

// 自动生命周期
void func() {
    int local = 1;  // 函数结束时销毁
}

// 动态生命周期
void allocate() {
    int* dynamic = new int(42);  // 手动管理
    delete dynamic;  // 必须显式释放

    // 或者使用智能指针
    auto managed = std::make_unique<int>(42);  // 自动释放
}
```

## 特殊成员函数

C++ 为类自动生成六个特殊成员函数，但你可以自定义。

### 规则

| 函数 | 默认行为 | 自定义 |
|------|----------|--------|
| 默认构造函数 | `T(){}` | `T(int){}` |
| 析构函数 | `~T(){}` | `~T(){}` |
| 拷贝构造函数 | 逐成员拷贝 | `T(const T&)` |
| 移动构造函数 | 逐成员移动 | `T(T&&)` |
| 拷贝赋值运算符 | 逐成员拷贝赋值 | `T& operator=(const T&)` |
| 移动赋值运算符 | 逐成员移动赋值 | `T& operator=(T&&)` |

### = default 与 = delete

```cpp
class Immovable {
public:
    Immovable() = default;  // 使用默认实现
    Immovable(const Immovable&) = delete;  // 禁止拷贝
    Immovable(Immovable&&) = delete;  // 禁止移动
};

class OnlyMovable {
public:
    OnlyMovable() = default;
    OnlyMovable(const OnlyMovable&) = delete;
    OnlyMovable& operator=(const OnlyMovable&) = delete;

    OnlyMovable(OnlyMovable&&) = default;  // 允许移动
    OnlyMovable& operator=(OnlyMovable&&) = default;
};
```

## const 与 constexpr

### const

```cpp
// const 变量
const int MAX_SIZE = 100;

// const 成员函数（不修改对象）
class Circle {
    double radius_;
public:
    double area() const { return 3.14 * radius_ * radius_; }
};

// const 引用（不能通过它修改对象）
void print_vector(const std::vector<int>& v) {
    // v 不能被修改
    for (int x : v) std::cout << x << " ";
}
```

### constexpr（C++11/14/20/23 演进）

```cpp
// C++11：编译期常量表达式
constexpr int square(int x) {
    return x * x;
}

// C++14：允许更多语句
constexpr int factorial(int n) {
    int result = 1;
    for (int i = 2; i <= n; ++i) {
        result *= i;
    }
    return result;
}

// C++17：constexpr lambda
constexpr auto add = [](auto a, auto b) { return a + b; };

// C++20：constexpr 动态分配
constexpr std::vector<int> create_vector() {
    std::vector<int> v;
    v.push_back(1);
    v.push_back(2);
    return v;
}
```

## 可变参数模板

```cpp
#include <cstdarg>

// 递归终止
void print() {}

// 递归打印
template<typename T, typename... Args>
void print(T first, Args... rest) {
    std::cout << first << " ";
    print(rest...);
}

print(1, 2.5, "hello", 'c');  // 1 2.5 hello c

// 参数包展开
template<typename... Ts>
std::tuple<Ts...> make_tuple_from_args(Ts... args) {
    return std::make_tuple(args...);
}
```

## 总结：C++ 的核心哲学

1. **性能优先**：你永远不需要为没有使用的功能付出代价
2. **零成本抽象**：高级抽象不损失性能
3. **显式优于隐式**：代码行为清晰可见
4. **资源管理自动化**：RAII 减少资源泄漏
5. **静态类型安全**：编译期检查减少运行时错误
6. **多范式支持**：根据问题选择最佳方法

C++ 的设计目标是让你写出高效且安全的代码，同时保持对底层的完全控制。
