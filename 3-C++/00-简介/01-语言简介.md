# C++ 语言简介

## 历史背景

C++ 由丹麦计算机科学家 **Bjarne Stroustrup** 于 1979 年在贝尔实验室工作时创造。最初这门语言叫 "C with Classes"（带类的C），在 1983 年正式更名为 C++。

Bjarne Stroustrup 设计的初衷是在C语言的基础上，添加面向对象的特性来解决大型软件开发中的复杂性问题。

## 与C语言的关系

C++ 与 C 语言有着密不可分的关系：
- **兼容继承**：几乎所有有效的 C 程序都是有效的 C++ 程序
- **共同血脉**：都提供对硬件的直接控制，语法风格相近
- **不同哲学**：C 是过程式编程，C++ 在此基础上支持面向对象、泛型编程等多范式

## 名称由来

C++ 中的 "++" 是 C 语言的自增运算符（将变量值加1）。所以 C++ 可以理解为 "C 语言的下一个阶段"，也暗示它在 C 语言基础上的增强和进化。

## C++ 的演进

| 年份 | 标准 | 重要特性 |
|------|------|----------|
| 1983 | C++ 诞生 | 类、虚函数、引用 |
| 1998 | C++98 | 第一个国际标准，STL |
| 2003 | C++03 | 缺陷修复 |
| 2011 | C++11 | 现代 C++ 元年，智能指针、lambda、nullptr |
| 2014 | C++14 | 泛型 lambda、变量模板 |
| 2017 | C++17 | 结构化绑定、if constexpr、optional/variant |
| 2020 | C++20 | 概念（Concepts）、协程、模块、ranges |
| 2023 | C++23 | std::expected、更多 constexpr |
| 2026 | C++26 | 反射、std::execution、改进的 constexpr |

## C++ 的优缺点

### 优点

1. **高性能**: 编译型语言，直接编译为机器码，执行效率接近 C 语言。

2. **面向对象**: 支持类、继承、多态、封装等 OOP 特性。

3. **泛型编程**: 模板机制支持通用算法和数据结构。

4. **STL 标准库**: 提供丰富的数据结构和算法（vector、map、algorithm 等）。

5. **底层控制**: 可以直接操作内存地址、位运算，适合系统编程。

6. **跨平台**: 支持 Windows、Linux、macOS 等多种平台。

7. **丰富的特性**: 支持过程式、面向对象、函数式、泛型等多种编程范式。

### 缺点

1. **学习曲线陡峭**: 语法复杂，概念繁多（指针、智能指针、模板、RAII 等）。

2. **容易出错**: 手动内存管理容易导致泄漏、野指针等 bug。

3. **编译时间长**: 模板元编程会增加编译时间。

4. **代码冗长**: 相比 Python 等动态语言，代码量较大。

5. **不安全**: 直接操作内存可以写出效率极高的代码，但也容易写出不安全的代码。

## 适用场景

### 非常适合的场景

1. **游戏开发**: Unreal Engine、CryEngine 等游戏引擎核心使用 C++。

2. **系统编程**: 操作系统、设备驱动、编译器。

3. **嵌入式系统**: 资源受限环境下的实时系统。

4. **高性能服务器**: 高频交易、实时通信。

5. **图形图像处理**: Photoshop、3D 建模软件、Video editing。

6. **数据库引擎**: MySQL、PostgreSQL 核心。

7. **VR/AR 应用**: 对性能要求极高的实时渲染。

### 不太适合的场景

1. **快速原型开发**: Python/JavaScript 更适合。

2. **Web 后端开发**: Java/C#/Go 更常见。

3. **数据分析**: Python/R 更方便。

4. **移动应用开发**: Swift/Kotlin/Java。

## 著名项目和应用

使用 C++ 开发的一些著名项目：

- **操作系统**: Windows、Linux 内核部分、macOS

## C++ 现代特性（C++11 及以后）

### 智能指针

```cpp
#include <memory>

// 独占所有权
std::unique_ptr<int> p1 = std::make_unique<int>(42);

// 共享所有权
std::shared_ptr<int> p2 = std::make_shared<int>(42);

// 弱引用（不增加引用计数）
std::weak_ptr<int> p3 = p2;
```

### Lambda 表达式

```cpp
#include <algorithm>
#include <vector>

std::vector<int> nums = {1, 2, 3, 4, 5};
int target = 10;

auto it = std::find_if(nums.begin(), nums.end(),
    [target](int n) { return n > target; });
```

### auto 关键字

```cpp
auto i = 42;           // int
auto d = 3.14;         // double
auto s = "hello";      // const char*
auto v = std::vector<int>{1, 2, 3};
```

### 范围for循环

```cpp
std::vector<int> nums = {1, 2, 3};

for (int n : nums) {
    std::cout << n << " ";
}

// 修改值
for (auto& n : nums) {
    n *= 2;
}
```

### nullptr

```cpp
int* p = nullptr;  // 替代 NULL
```
