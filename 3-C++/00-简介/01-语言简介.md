# C++ 语言简介

## 历史背景

C++ 由丹麦计算机科学家 **Bjarne Stroustrup** 于 1979 年在贝尔实验室工作时创造。最初叫 "C with Classes"（带类的 C），1983 年正式更名为 C++。设计初衷是在 C 语言基础上添加面向对象特性，解决大型软件开发中的复杂性问题。

"C++" 中的 "++" 是 C 语言的自增运算符，C++ 可理解为 "C 语言的下一个阶段"。

## C++ 演进

| 年份 | 标准 | 重要特性 |
|------|------|----------|
| 1983 | C++ 诞生 | 类、虚函数、引用 |
| 1998 | C++98 | 第一个国际标准，STL |
| 2003 | C++03 | 缺陷修复 |
| 2011 | C++11 | 现代 C++ 元年，智能指针、lambda、nullptr |
| 2014 | C++14 | 泛型 lambda、变量模板 |
| 2017 | C++17 | 结构化绑定、if constexpr、optional/variant |
| 2020 | C++20 | 概念（Concepts）、协程、模块、ranges |
| 2023 | C++23 | std::expected、更多 constexpr |
| 2026 | C++26 | 反射、std::execution、改进的 constexpr |

## 与 C 语言的关系

C++ 与 C 语言有着密不可分的关系：几乎所有有效的 C 程序都是有效的 C++ 程序。但两者有不同哲学：C 是过程式编程，C++ 支持面向对象、泛型编程等多范式。

## C++ 的优缺点

### 优点

- **高性能**：编译型语言，直接编译为机器码，执行效率接近 C 语言
- **面向对象**：支持类、继承、多态、封装等 OOP 特性
- **泛型编程**：模板机制支持通用算法和数据结构
- **STL 标准库**：提供丰富的数据结构和算法
- **底层控制**：可以直接操作内存地址、位运算，适合系统编程
- **多范式**：支持过程式、面向对象、函数式、泛型等多种编程范式

### 缺点

- **学习曲线陡峭**：语法复杂，概念繁多
- **容易出错**：手动内存管理容易导致泄漏、野指针等 bug
- **编译时间长**：模板元编程会增加编译时间
- **代码冗长**：相比 Python 等动态语言，代码量较大

## 适用场景

### 非常适合的场景

- **游戏开发**：Unreal Engine、CryEngine 等游戏引擎核心使用 C++
- **系统编程**：操作系统、设备驱动、编译器
- **嵌入式系统**：资源受限环境下的实时系统
- **高性能服务器**：高频交易、实时通信
- **图形图像处理**：Photoshop、3D 建模软件
- **数据库引擎**：MySQL、PostgreSQL 核心
- **VR/AR 应用**：对性能要求极高的实时渲染

### 不太适合的场景

- 快速原型开发（Python/JavaScript 更适合）
- Web 后端开发（Java/C#/Go 更常见）
- 数据分析（Python/R 更方便）
- 移动应用开发（Swift/Kotlin/Java）

## 著名项目

## C++ 现代特性（C++11 及以后）

### 智能指针

C++11 引入了三种智能指针：`std::unique_ptr`（独占所有权）、`std::shared_ptr`（共享所有权）、`std::weak_ptr`（不增加引用计数的弱引用）。

```cpp
#include <memory>

// 独占所有权
std::unique_ptr<int> p1 = std::make_unique<int>(42);

// 共享所有权
std::shared_ptr<int> p2 = std::make_shared<int>(42);

// 弱引用（不增加引用计数）
std::weak_ptr<int> p3 = p2;
```

### Lambda 表达式

Lambda 表达式是匿名函数对象，适合短小的回调场景。

```cpp
#include <algorithm>
#include <vector>

std::vector<int> nums = {1, 2, 3, 4, 5};
int target = 10;

auto it = std::find_if(nums.begin(), nums.end(),
    [target](int n) { return n > target; });
```

### auto 与类型推导

`auto` 自动推导类型，`decltype` 推导类型保留引用和 cv 限定符。

```cpp
auto i = 42;           // int
auto d = 3.14;         // double
auto s = "hello";      // const char*
auto v = std::vector<int>{1, 2, 3};
```

### 范围 for 循环

```cpp
std::vector<int> nums = {1, 2, 3};

for (int n : nums) {
    std::cout << n << " ";
}

// 修改值
for (auto& n : nums) {
    n *= 2;
}
```

### nullptr

`nullptr` 是类型安全的空指针，推荐使用。

```cpp
int* p = nullptr;  // 替代 NULL
```
