# 09-预处理与宏

> 前置：[08-命名空间与模块](08-命名空间与模块.md) · 后续：[02-标准库](../02-标准库/README.md)

> **版本基准**：C++20；C++23/26 特性行内标注。示例实测环境：GCC 14.2（MinGW-w64，Windows）。

预处理是编译链的第一段（四段链见 [01-语言定位与编译模型](../00-概览/01-语言定位与编译模型.md)）：语法分析之前的纯文本改写。本篇给出它的能力清单、宏的危险机制，以及每种历史用途的现代替代。

## 本质

预处理是**纯文本改写器**：输入 Token 流、输出 Token 流，不理解 C++ 的语法、类型与作用域。它干四件事：

1. **包含**：`#include` 把目标文件内容原样粘贴进来（递归展开）；
2. **宏展开**：`#define` 登记替换规则，遇到宏名做文本替换（可带参数）；
3. **条件编译**：`#if`/`#ifdef`/`#elif`/`#endif` 按编译期常量裁剪 Token 流；
4. **杂项指令**：`#pragma`（编译器私有开关）、`#error`、`#line` 等。

"不理解 C++" 是全部危险的根源：宏**没有作用域**——从定义点起生效到 `#undef` 或文件尾，穿透一切大括号与命名空间；**没有类型**——参数是 Token 序列，不检查、不求值，原样粘贴。

## 机制

### 宏的三类经典事故

1. **多次求值**：`SQUARE(a++)` 展开为 `((a++) * (a++))`——同一标量对象两次无顺序副作用，未定义行为（GCC 14.2 实测输出 30，并给出 `-Wsequence-point` 警告；数值不可依赖）。
2. **优先级泄漏**：`#define ADD(a, b) a + b` 在 `ADD(1, 2) * 3` 中展开为 `1 + 2 * 3`。防御写法是给每个参数与整体都套括号——括号救得了优先级，救不了多次求值。
3. **跨域污染**：宏不认识命名空间。Windows 头文件定义的 `min`/`max` 宏会在语法分析之前换掉用户代码里的 `std::min`。解法：`-DNOMINMAX` 或 `#undef`。

另有一条写法纪律：多语句宏用 `do { ... } while (0)` 包成单条语句，否则嵌进 `if/else` 会因悬挂 else 或多余分号改变语法结构。

### 现代替代表

宏的每一种历史用途，几乎都有类型安全的上位替代：

| 宏的旧用途 | 现代替代 | 替代赢在哪 |
|---|---|---|
| 常量宏 `#define N 4096` | `constexpr int kN = 4096;` | 有类型、有作用域、进调试符号表 |
| 函数宏 | `inline` 函数 / 函数模板（能 `constexpr` 更佳） | 参数只求值一次、有类型检查 |
| 类型宏 `#define Vec vector<int>` | `using Vec = std::vector<int>;` | 参与类型系统，诊断可读 |
| 编译期检查宏 | `static_assert`（C++11） | 语义分析后求值，错误消息自含 |
| `#include` 组织代码 | 模块 `import`（C++20） | 见 [08-命名空间与模块](08-命名空间与模块.md)；编译器支持尚不齐 |

### 宏仅剩的正当地盘

- **条件编译**：平台与版本裁剪（`#if defined(_WIN32)`、`__cplusplus >= 202002L`）。被裁掉的分支可以含有对本平台根本非法的代码——`if constexpr` 做不到，它要求两个分支都语法合法。
- **位置信息**：`__FILE__`/`__LINE__` 只有宏能在调用点捕获（C++20 起 `std::source_location` 提供了非宏替代）。
- **Token 拼装**：`#`（字符串化）与 `##`（拼接）操作的是标识符本身，语言层无对应物。其正当形态是 **X-Macro**：把同一张清单（枚举成员表、错误码表）写成接受宏参数的列表，在不同上下文喂入不同的 X 定义——一处增删、多处同步，枚举与名字表由机制保证不脱节。
- **头文件卫哨**：`#pragma once` / include guard——模块普及之前仍是必需品。

## 示例

危险案例、现代替代、条件编译、X-Macro 一次跑完（GCC 14.2，`-std=c++20 -Wall` 实测）：

```cpp
#include <cstdio>

// 危险案例：宏参数是文本粘贴，会被多次求值
#define SQUARE(x) ((x) * (x))

// 现代替代
constexpr int kBlockSize = 4096;                    // 换常量宏：有类型、有作用域

template <typename T>                               // 换函数宏：类型检查，参数只求值一次
constexpr T square(T x) { return x * x; }

static_assert(sizeof(void*) == 8, "64-bit only");   // 换编译期检查宏

// 条件编译：宏仅剩的主场之一
#if defined(_WIN32)
constexpr const char* kPlatform = "windows";
#elif defined(__linux__)
constexpr const char* kPlatform = "linux";
#else
constexpr const char* kPlatform = "other";
#endif

// X-Macro：一张表驱动多处生成
#define COLOR_LIST(X) X(Red) X(Green) X(Blue)

enum class Color {
#define ENUM_ENTRY(name) name,
    COLOR_LIST(ENUM_ENTRY)
#undef ENUM_ENTRY
};

const char* name_of(Color c) {
    switch (c) {
#define CASE_ENTRY(name) case Color::name: return #name;
        COLOR_LIST(CASE_ENTRY)
#undef CASE_ENTRY
    }
    return "?";
}

int main() {
    int a = 5;
    int bad = SQUARE(a++);   // 展开为 ((a++)*(a++))：同一标量两次无顺序副作用，未定义行为
    std::printf("SQUARE(a++) = %d, a = %d\n", bad, a);   // 实测 30, 7——数值不可依赖

    std::printf("square(6) = %d, block = %d\n", square(6), kBlockSize);  // 36, 4096
    std::printf("platform = %s\n", kPlatform);                           // windows
    std::printf("color %d = %s\n", (int)Color::Green, name_of(Color::Green));  // 1 = Green
}
```

编译期警告（UB 的证据）：`warning: operation on 'a' may be undefined [-Wsequence-point]`。
