# 07-错误处理

> 前置：[06-模板与Concepts](06-模板与Concepts.md) · 后续：[08-命名空间与模块](08-命名空间与模块.md)

> **版本基准**：C++20；C++23/26 特性行内标注。示例实测环境：GCC 14.2（MinGW-w64，Windows）。

C++ 同时提供三条错误通道：异常、`std::error_code`、`std::expected`（C++23 增量）。本篇先讲清异常的机制与代价，再给三者的选择判据。

## 本质

异常（exception）是**跨函数边界的控制流转移机制**：`throw` 构造一个异常对象，控制流沿调用链逐层回退（栈展开，stack unwinding），直到遇上类型匹配的 `catch`；沿途每个退出的栈帧先析构自己的局部对象。它与错误码的本质差异在传播方式：中间层对错误完全无感，不必每层手写 `if (err) return err;`——错误从抛出点直达处理点。

RAII（见 [04-类与资源管理](04-类与资源管理.md)）是异常安全的前提：资源绑在局部对象的析构上，栈展开必然触发析构，锁、句柄、内存才不会随控制流跳走而泄漏。没有确定性析构的语言要靠 finally/with 手工补这一步。

## 机制

### throw 到 catch 的完整链路

1. `throw expr`：把 expr 拷贝或移动到编译器管理的存储区（不挂在即将展开的栈帧上，因此异常对象活过整个展开过程）。
2. 栈展开：从 throw 点逐层退出函数，每层按构造逆序析构本帧已构造完毕的局部对象。
3. 匹配：按书写顺序逐个试 `catch`，第一个类型匹配的获胜——派生类异常可被基类类型的 `catch` 接住，因此顺序必须**先派生后基类**，`catch(...)` 兜底放最后。
4. 无人接住：调用 `std::terminate()`，程序终止。

### noexcept 的双重角色

- **契约**：声明"本函数不抛异常"。违反契约直接 `std::terminate()`，不做展开。析构函数默认 `noexcept`——展开途中析构再抛会让两个异常同时存活，语言无法裁决，只能终止。
- **优化开关**：`std::vector` 扩容搬迁元素时，元素移动构造是 `noexcept` 才走移动，否则退回拷贝——移动中途抛异常则旧存储已拆、新存储未满，"失败即回滚"守不住；拷贝失败则原件完好。这就是"移动构造能标 `noexcept` 就标"的机制根源（移动语义本身见 [05-移动语义与拷贝控制](05-移动语义与拷贝控制.md)）。

### 三条通道的选择判据

| 判据 | 异常 | `std::error_code` | `std::expected`（C++23 增量） |
|---|---|---|---|
| 适用失败 | 罕见、真正的"异常" | 常见失败（IO、解析） | 常见失败 |
| 签名可见性 | 不可见（`noexcept` 只答"是否抛"） | 可见 | 可见，类型即契约 |
| 无错误时代价 | 零（表驱动展开，Itanium ABI 口径） | 零 | 零 |
| 出错时代价 | 栈展开，昂贵但罕见 | 一次整数比较 | 一次分支 |
| 中间层负担 | 无感 | 每层手写转发 | 手写转发或 `and_then` 链式组合 |
| 构造函数报错 | 唯一选择 | 不可行 | 不可行 |

一条硬推论：**构造函数只能用异常报错**——它没有返回值，又必须交付一个完全构造的对象；构造失败时异常是唯一能把"半成品不存在"精确编码进语言的通道（异常抛出时该对象视为从未存在，已构造的成员按逆序析构）。

### std::error_code 与 std::expected

`std::error_code`（`<system_error>`，C++11）= 整数错误码 + 错误类别（category）指针：类别决定 `message()` 的翻译，并区分同值异义（不同域里的"错误 2"含义不同）。它就是两个字段的平凡结构体，拷贝与比较零开销，适合"失败是常态"的底层 API。

`std::expected<T, E>`（C++23 增量）把"要么值、要么错"编码进返回类型，编译器强迫调用方先分支再用值；`and_then`/`transform`/`or_else` 支持链式组合。GCC 12 起可用（本机 GCC 14.2 `-std=c++23` 实测）。

## 示例

栈展开顺序、`noexcept` 开关、`error_code` 通道（GCC 14.2，`-std=c++20 -Wall` 实测）：

```cpp
#include <iostream>
#include <stdexcept>
#include <system_error>
#include <type_traits>

struct Guard {
    const char* name;
    explicit Guard(const char* n) : name(n) { std::cout << "+ " << name << '\n'; }
    ~Guard() { std::cout << "- " << name << '\n'; }
};

void level2() {
    Guard g2("level2");
    throw std::runtime_error("disk full");   // 展开 level2、level1 与 try 块的栈帧
}
void level1() {
    Guard g1("level1");
    level2();
}

// noexcept 是 vector 搬迁策略的开关
struct MayThrow { MayThrow() = default; MayThrow(const MayThrow&) {} MayThrow(MayThrow&&) {} };
struct NoThrow  { NoThrow() = default;  NoThrow(const NoThrow&) {}  NoThrow(NoThrow&&) noexcept {} };

// error_code：轻量错误通道
std::error_code divide(int a, int b, int& out) {
    if (b == 0) return std::make_error_code(std::errc::invalid_argument);
    out = a / b;
    return {};
}

int main() {
    try {
        Guard gm("main");
        level1();
    } catch (const std::runtime_error& e) {   // 按类型匹配
        std::cout << "caught: " << e.what() << '\n';
    }

    std::cout << std::boolalpha
              << std::is_nothrow_move_constructible_v<MayThrow> << ' '
              << std::is_nothrow_move_constructible_v<NoThrow> << '\n';  // false true

    int r = 0;
    if (auto ec = divide(10, 0, r))
        std::cout << "error: " << ec.message() << '\n';   // error: Invalid argument
    if (!divide(10, 3, r))
        std::cout << "10/3 = " << r << '\n';              // 10/3 = 3
}
```

实测输出（注意 `- main` 在 `caught` 之前：try 块的局部对象也在展开路径上）：

```
+ main
+ level1
+ level2
- level2
- level1
- main
caught: disk full
false true
error: Invalid argument
10/3 = 3
```

`std::expected`（C++23 增量，GCC 14.2 `-std=c++23` 实测）：

```cpp
#include <expected>
#include <iostream>
#include <string>

std::expected<int, std::string> parse_nonneg(const std::string& s) {
    try {
        int v = std::stoi(s);
        if (v < 0) return std::unexpected("negative");
        return v;
    } catch (...) {
        return std::unexpected("not a number");
    }
}

int main() {
    for (const char* s : {"42", "-1", "abc"}) {
        auto r = parse_nonneg(s);
        if (r) std::cout << s << " -> " << *r << '\n';
        else   std::cout << s << " -> error: " << r.error() << '\n';
    }
    // 42 -> 42
    // -1 -> error: negative
    // abc -> error: not a number
}
```
