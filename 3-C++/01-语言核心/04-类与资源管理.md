# 04-类与资源管理

> 前置：[03-函数与Lambda](03-函数与Lambda.md) · 后续：[05-移动语义与拷贝控制](05-移动语义与拷贝控制.md)、[06-模板与Concepts](06-模板与Concepts.md)

> **版本基准**：C++20；C++23/26 特性行内标注

类把数据和操作绑成一个类型。但 C++ 的类真正独特的地方不在封装，在于**析构函数的时机是词法确定的**——离开作用域立即析构，这条性质（继承自"确定性析构"的立论，见 [01-语言定位与编译模型](../00-概览/01-语言定位与编译模型.md)）让对象成为资源的托管人。本篇围绕这条性质展开：构造/析构的次序、RAII、拷贝五法则、智能指针，以及让自定义类型融入语法的运算符重载。

## 本质

**类 = 布局 + 不变量 + 接口**：布局决定对象占多少字节、成员在什么偏移；不变量是成员之间必须恒成立的关系（如 `size_` 必须与 `data_` 指向的缓冲一致）；接口（public 成员函数）是唯一允许的操作面，访问控制（`private`/`public`）把"能碰布局的代码"收缩到类内，不变量因此只需在接口的出入口被维护。

**资源管理是 C++ 类的主战场**。内存、文件句柄、互斥锁、套接字的共性是"获取—使用—必须归还"，而 `new`/`delete` 裸写的死穴是控制流中途折返（异常、提前 return）时归还路径被跳过。RAII 把归还挂到析构函数上：析构时机由作用域决定、异常栈展开也会走，归还因此不可跳过。

## 机制

### 构造/析构次序：一条钉死的链

对象的构造按固定次序，与初始化列表的书写顺序**无关**：

1. 虚基类（如有）→ 2. 直接基类（按继承声明序）→ 3. 成员（**按类内声明序**）→ 4. 自身构造体。

析构严格逆序：自身析构体 → 成员（逆声明序）→ 基类。次序钉死的理由是依赖方向：基类子对象与成员必须在构造体执行前就绪（构造体里要用它们）；析构反过来，先拆外层。推论一条：基类构造/析构期间，对象还"不是"派生类——此时调用虚函数分派到基类版本，不会触达派生类的覆写。

### RAII：获取即初始化

**RAII（Resource Acquisition Is Initialization，资源获取即初始化）**：构造函数获取资源、析构函数归还资源，资源生命周期 = 对象生命周期。判据两条：资源从构造成功起即处于可用状态；析构函数无条件归还，且**不抛异常**（栈展开中析构再抛会直接 `std::terminate`）。

满足判据的类对异常天然免疫：栈展开沿调用链逐个析构已构造的局部对象（机制见 [07-错误处理](07-错误处理.md)），资源随对象一起被带走，不需要任何 catch 里补 `delete`。

### 拷贝三/五法则：一个信号带出一组义务

管理资源的类一旦需要自定义析构函数，就意味着编译器的"逐成员拷贝"默认实现是错的（两份对象指向同一资源 → 双重释放）。信号与义务：

| 你声明了 | 编译器推断 | 你欠下的义务 |
|---|---|---|
| 析构函数 | 类管资源 | 拷贝构造、拷贝赋值（三法则，C++98 起） |
| 上述任一 | 同上 | 另加移动构造、移动赋值（五法则，C++11 起）——声明拷贝/析构任一会**抑制移动操作的自动生成** |
| 什么都没声明 | 类只管值 | 零法则：什么都不写，全部交给成员的实现 |

`= default` 显式请回编译器默认版，`= delete` 显式禁止（如 `unique_ptr` 禁拷贝）。移动操作的语义展开见 [05-移动语义与拷贝控制](05-移动语义与拷贝控制.md)。

### 智能指针：所有权的类型化表达

智能指针是 RAII 在堆内存上的三个现成实现，按所有权语义选型：

| | `unique_ptr` | `shared_ptr` | `weak_ptr` |
|---|---|---|---|
| 所有权 | 独占，只能移动不能拷贝 | 共享，控制块里原子引用计数 | 不参与所有权，观察 shared 管的对象 |
| 体积/代价 | 一个裸指针（8 字节，64 位 GCC 14.2 实测），零开销——`sizeof` 与 `T*` 相同 | 两个指针（对象 + 控制块）；每次拷贝/析构各一次原子增减 | 拷一份控制块指针 |
| 典型用途 | 默认首选：工厂返回值、容器元素、PImpl | 对象图里多方共持、寿命不可静态预测 | 破 shared 循环引用；缓存/观察者 |

控制块里有两个计数：强计数归零析构对象，弱计数归零才释放控制块本身。`weak_ptr` 把"观察者不该延长对象寿命"这个语义编码进类型——`lock()` 拿到临时 `shared_ptr` 或空，对象是否还在一目了然。循环引用（A 持 B、B 持 A 都是 `shared_ptr`）的死结：两个强计数永远不归零，把其中一条边降级为 `weak_ptr` 即破。

### 运算符重载：让值语义类型融入语法

`a + b` 之于 `add(a, b)` 没有新语义——运算符重载是**具名函数调用借了运算符的记号**。存在理由：值语义类型（向量、复数、大整数）的行为模型和内置算术类型同构，用户读 `v1 + v2` 的心智成本远低于 `v1.plus(v2)`。语言为此付出的代价是纪律全在程序员：优先级、结合性、目数不可改，语义则由实现随便写。

纪律（约束出自"可读性来自记号与语义同构"）：

- **只重载语义直觉成立的**。`+` 就该像加法（可结合、不改操作数、返回新值）；把 `+` 重载成"追加日志"是用语法撒谎。
- `<<`/`>>` 留给流插入/提取：写成非成员、返回流引用以支持链式。
- 比较用 C++20 三向比较 `operator<=>`：`= default` 一行让编译器逐成员生成，自动补齐 `==` `!=` `<` `<=` `>` `>=` 六个运算符且保证互相一致——手写六个易互相矛盾的历史包袱就此了结。
- 对称运算（`a + b` 与 `b + a` 应同义）写非成员函数，让两边操作数平等地参与隐式转换；修改左操作数的（`+=`）写成员。

### explicit 与隐式转换洞

单参数构造函数默认是**隐式转换通道**：`void f(Buf); f(42);` 若 `Buf(int)` 不带 `explicit`，42 会被静默包成临时 `Buf`。这条通道的存在理由是历史兼容，现实后果是重载决议选中你没打算选的函数、临时对象在你看不见的地方生灭。纪律：**单参数构造函数默认加 `explicit`**，只在确实希望类型被当作另一类型的自然表示时（如 `string_view` 之于字符串字面量）才放开。

## 示例

（GCC 14.2 MinGW 实测，`-std=c++20`）

```cpp
#include <iostream>
#include <memory>

struct Base { Base() { std::cout << "B+ "; } ~Base() { std::cout << "B- "; } };
struct M1 { M1() { std::cout << "M1+ "; } ~M1() { std::cout << "M1- "; } };
struct M2 { M2() { std::cout << "M2+ "; } ~M2() { std::cout << "M2- "; } };
struct D : Base { M1 a; M2 b;
    D() { std::cout << "D+ "; } ~D() { std::cout << "D- "; } };

class Buf {                          // RAII + 五法则全套
    int* p_;
public:
    explicit Buf(int n) : p_(new int[n]{}) {}   // explicit 堵住隐式转换
    ~Buf() { delete[] p_; }
    Buf(const Buf& o) : p_(new int[1]{*o.p_}) {}        // 拷贝构造：深拷贝
    Buf& operator=(const Buf& o) {                      // 拷贝赋值
        if (this != &o) *p_ = *o.p_;
        return *this;
    }
    Buf(Buf&& o) noexcept : p_(o.p_) { o.p_ = nullptr; }       // 移动构造：窃取
    Buf& operator=(Buf&& o) noexcept {                         // 移动赋值
        if (this != &o) { delete[] p_; p_ = o.p_; o.p_ = nullptr; }
        return *this;
    }
};

struct Vec2 {
    double x, y;
    Vec2 operator+(const Vec2& o) const { return {x + o.x, y + o.y}; }
    auto operator<=>(const Vec2&) const = default;  // C++20：一行生成六个比较
};
std::ostream& operator<<(std::ostream& os, const Vec2& v) {
    return os << '(' << v.x << ',' << v.y << ')';
}

int main() {
    { D d; } std::cout << '\n';        // B+ M1+ M2+ D+ D- M2- M1- B-（构造正序、析构逆序）

    Buf a(4), b(8);
    b = std::move(a);                  // 移动赋值

    Vec2 u{1,2}, v{3,4};
    std::cout << u + v << ' ' << (u < v) << '\n';   // (4,6) 1

    auto up = std::make_unique<Vec2>(Vec2{5, 6});
    std::cout << sizeof(up) << '\n';   // 8：零开销，就是一个指针
    auto sp1 = std::make_shared<Vec2>(Vec2{7, 8});
    std::cout << sp1.use_count() << ' ';
    { auto sp2 = sp1; std::cout << sp1.use_count() << ' '; }
    std::weak_ptr<Vec2> wp = sp1;
    std::cout << sp1.use_count() << ' ' << wp.expired() << '\n';  // 1 2 1 0：weak 不计数
}
```
