# 01-类型系统与值类别

> 前置：[01-语言定位与编译模型](../00-概览/01-语言定位与编译模型.md)（静态类型 + AOT 编译是这里一切规则的背景） · 后续：[02-控制流程](02-控制流程.md)、[05-移动语义与拷贝控制](05-移动语义与拷贝控制.md)

> **版本基准**：C++20；C++23/26 特性行内标注

上一篇说 C++ 是静态类型语言，本篇把"类型"这个概念拆开：它如何解释内存、编译器如何推演它、四种强制转换各自能走多远、运行时又如何找回它。值类别（值是左值还是右值）只在此建立坐标系，展开归 [05-移动语义与拷贝控制](05-移动语义与拷贝控制.md)。

## 本质

**类型（type）是编译期对位模式的解释规则**：一段内存本身是纯位串，类型决定三件事——占多少字节（尺寸与对齐）、位模式怎么读（整数/浮点/指针）、允许哪些运算。同 4 字节位模式 `0x00000041`，解释为 `int` 是 65，解释为 `float` 是 $9.1 \times 10^{-44}$（64 位 GCC 14.2 实测）。类型不属于数据，属于编译器；程序编译完成后，类型信息在机器码里几乎全部消失（例外是 RTTI，见下文）。

**对象（object） = 存储期 + 类型 + 值**：一块被某种类型解释的存储。变量只是有名字的对象；`new` 出来的堆块是匿名的对象。类型检查发生在编译期，这正是"编译期/运行时分账"的第一笔账（见 [01-语言定位与编译模型](../00-概览/01-语言定位与编译模型.md)）。

## 机制

### 基础类型的尺寸：标准只给下限，平台给实数

标准只承诺相对次序与下限（`char` 恰为 1 字节，`short ≤ int ≤ long ≤ long long`），具体尺寸由平台的 ABI（应用二进制接口：编译器与操作系统约定的数据布局与调用规则）定死。64 位 GCC 14.2（MinGW，Windows）实测：

| 类型 | 字节 | | 类型 | 字节 |
|---|---|---|---|---|
| `bool`、`char` | 1 | | `float` | 4 |
| `short` | 2 | | `double` | 8 |
| `int` | 4 | | `long double` | 16（80 位扩展精度对齐填充） |
| `long` | 4（Windows LLP64 惯例） | | 指针（任意 `T*`） | 8 |
| `long long` | 8 | | | |

注意 `long`：同一份代码在 64 位 Linux（LP64 惯例）上 `long` 是 8 字节——跨平台代码要指定位宽就用 `<cstdint>` 的 `int32_t`、`int64_t`。有符号整数的表示范围是 $[-2^{n-1},\ 2^{n-1}-1]$（ $n$ 为位数，补码表示）；**有符号溢出是未定义行为**，编译器可据此激进优化（如假设 `i + 1 > i` 恒真）。

### auto 与 decltype：编译期类型推演

`auto` 从初始化式推演类型，规则一句话：**剥掉顶层引用和顶层 cv（const/volatile）**。要保留它们就显式写 `auto&`、`const auto&`。

`decltype(实体)` 走的是另一套规则：**实体给声明类型，表达式给"类型 + 值类别"**——`decltype((x))` 的双括号把变量名变成左值表达式，于是结果是 `T&`。判据表：

| 写法 | 结果类型 | 规则 |
|---|---|---|
| `decltype(x)`，`x` 是变量名 | 声明类型（含 cv，不含引用剥除） | 实体 → 声明类型 |
| `decltype((x))` | `T&` | 双括号是表达式，左值 → `T&` |
| `decltype(x + 1)` | `T` | 纯右值表达式 → `T` |
| `decltype(f())`，`f` 返回 `int&` | `int&` | 表达式是左值 → `T&` |
| `auto a = r;`，`r` 是 `int&` | `int` | auto 剥引用与顶层 cv |
| `decltype(auto) b = f();` | 精确保留 `f` 的返回类型（C++14） | 按 decltype 规则推演 |

陷阱：`decltype((x))` 是引用类型，写 `decltype((x)) y = x;` 后改 `y` 就是在改 `x`；而 `auto` 推演的变量是独立副本。

### 四种强制转换：按"能走多危险"分级

约束先立：**裸 C 风格强转 `(T)e` 会静默退到它认为够得着的最强转换**——可能在不知情下剥掉 const 或重解释位模式。四个命名转换把意图写进代码，让编译器按各自的能力边界检查：

| 转换 | 检查时机 | 能做什么 | 判据（什么时候选它） |
|---|---|---|---|
| `static_cast` | 编译期 | 数值互转、继承层级上行、已知安全的下行 | 有明确定义的转换路径，且你（而非运行时）担保正确 |
| `dynamic_cast` | 运行期 | 多态层级的安全下行/交叉转换 | 只有基类指针却要调用派生类接口，且愿意付 RTTI 代价 |
| `const_cast` | 编译期 | 增删 cv 限定 | 只此一职；对本身就是 const 的对象去 const 再写是未定义行为 |
| `reinterpret_cast` | 无检查 | 位模式重解释（指针↔整数、无关指针互转） | 只在序列化、内存池、位级 hack 等明确知道布局的场景 |

### RTTI：运行时找回类型信息的通道

编译期类型在机器码里消失，但多态类保留了通道：每个含虚函数的对象带一个**虚表指针**（vptr，机制见 [04-类与资源管理](04-类与资源管理.md)），虚表里除了虚函数地址还附带指向 `std::type_info` 的指针——这就是运行时类型信息（RTTI，Run-Time Type Information）的唯一来源。两个入口都从这里读：

- `typeid(*p)`：沿 vptr 取 type_info，一次间接寻址， $O(1)$；非多态类型没有 vptr，`typeid` 退化为编译期查静态类型。
- `dynamic_cast<Derived*>(p)`：读 type_info 后**沿继承链向上比对**，失败返回 `nullptr`（引用版本抛 `std::bad_cast`）。代价正比于继承深度，且跨共享库时涉及 type_info 的跨模块比较。

代价账：每个多态类多一份 type_info（名字字符串 + 类型关系表），每个多态对象多一个 vptr（8 字节）。GCC/Clang/MSVC 均可整体关掉（GCC/Clang 用 `-fno-rtti`），省掉这份空间，`typeid` 与 `dynamic_cast` 随之不可用。

### 值类别：两维坐标（占位）

表达式除类型外还有**值类别**（value category），由两个正交维度决定：**有没有身份**（能否取地址、能否在别处再见到它）和**能不能被移动**。两维叉出五类：左值（lvalue，有身份不可移动）、纯右值（prvalue，无身份的临时值）、将亡值（xvalue，有身份但资源可被窃取，如 `std::move(x)` 的结果）；左值与将亡值合称泛左值（glvalue），将亡值与纯右值合称右值（rvalue）。这套分类存在的唯一理由是移动语义——它决定重载决议选拷贝还是移动，完整展开（含移动构造的窃取语义）见 [05-移动语义与拷贝控制](05-移动语义与拷贝控制.md)。

## 示例

尺寸、推演与 RTTI 三合一（GCC 14.2 MinGW 实测，`-std=c++20`）：

```cpp
#include <iostream>
#include <type_traits>

struct Base { virtual ~Base() = default; };
struct Derived : Base { int x = 42; };

int main() {
    // 尺寸表（64 位 GCC 14.2 MinGW 实测）
    std::cout << sizeof(int) << ' ' << sizeof(long) << ' '
              << sizeof(long long) << ' ' << sizeof(int*) << '\n';  // 4 4 8 8

    // auto 剥引用剥顶层 const；decltype 分实体/表达式两套
    int n = 10;
    int& r = n;
    auto a = r;              // int：独立副本
    decltype(r) d = n;       // int&：n 的别名
    decltype((n)) g = n;     // int&：双括号 → 左值表达式 → T&
    d = 77;                  // n、g 跟着变
    a = 99;                  // 只改自己
    std::cout << n << ' ' << a << '\n';                    // 77 99
    static_assert(std::is_same_v<decltype((n)), int&>);    // 编译期验证双括号规则

    // RTTI：从 vptr 找回动态类型
    Base* p = new Derived;
    std::cout << (typeid(*p) == typeid(Derived)) << '\n';  // 1
    if (Derived* q = dynamic_cast<Derived*>(p))
        std::cout << q->x << '\n';                         // 42
    Base b;
    std::cout << (dynamic_cast<Derived*>(&b) == nullptr) << '\n';  // 1：失败不抛指针版
    delete p;
}
```
