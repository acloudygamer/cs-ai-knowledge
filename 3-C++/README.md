# 3-C++

> **版本基准**：C++20 stable / C++23·C++26 latest。C++23/26 特性在各篇行内以"增量"标注；编年视角的集中视图见 [07-版本演进](07-版本演进/README.md)。编译器支持度断言以 cppreference 编译器支持页为准，示例以 GCC（MinGW）实测为准。

本库不是语法手册，是一条**逻辑主线上的知识网络**：C++ 的一切复杂性来自两个根源——**零开销抽象**（抽象不许比手写机器码贵）与**编译期/运行时的严格分账**（能在编译期算完的，不许留到运行时）。后续各篇的"为什么"都能回溯到这两条。
