# 包管理工具

**C++包管理工具解决第三方库发现、下载、编译和链接的自动化问题，vcpkg和Conan是主流方案。**

## vcpkg

**vcpkg是微软开发的集中式C++包管理器，通过git子模块存储库源码，以编译后缓存实现复用。**

<pre>
vcpkg install nlohmann-json → [git submodule] → [编译] → [缓存]
                                          ↓
                              CMake find_package()
</pre>

### 基础使用

```bash
vcpkg install nlohmann-json:x64-linux
vcpkg list
```

### CMake集成

```bash
cmake -B build -S . \
    -DCMAKE_TOOLCHAIN_FILE=$VCPKG_ROOT/scripts/buildsystems/vcpkg.cmake
```

```cmake
find_package(nlohmann-json REQUIRED)
target_link_libraries(myapp PRIVATE nlohmann-json::nlohmann-json)
```

### manifest模式

```json
{
    "dependencies": ["nlohmann-json", "spdlog"]
}
```

## Conan

**Conan是去中心化的C++包管理器，通过中央仓库和自定义服务器分发，支持二进制制品管理。**

<pre>
Conan Center → [conan install] → [本地缓存]
                              ↓
                     CMake find_package()
</pre>

### 基础使用

```bash
conan install . -pr:h=default
```

### conanfile.py

```python
class MyPkg(ConanFile):
    def requirements(self):
        self.requires("nlohmann-json/[>=3.10.0]")

    def generate(self):
        tc = CMakeToolchain(self)
        tc.generate()
        deps = CMakeDeps(self)
        deps.generate()
```

## vcpkg vs Conan

| 特性 | vcpkg | Conan |
|------|-------|-------|
| 架构 | 集中式（git子模块） | 去中心化 |
| 二进制缓存 | 编译后缓存 | 独立制品库 |
| CMake集成 | 原生toolchain | 需生成器 |

## 选型建议

- 小型项目：vcpkg（快速上手）
- 大型企业/多配置：Conan（制品管理）
