# 文件操作

**文件操作是将程序数据持久化到存储介质的机制，通过流或系统调用实现字节序列化与反序列化。**

## 流式文件I/O

**std::fstream是C++流式文件I/O的抽象，通过缓冲区将程序数据转换为存储字节序列。**

<pre>
应用程序 → [流缓冲区] → 文件系统 → 存储介质
</pre>

### 参考样例

```cpp
#include <fstream>

std::ofstream out("output.txt");
out << "Hello" << std::endl;

std::ifstream in("input.txt");
std::string s;
std::getline(in, s);
```

### 二进制模式

```cpp
std::fstream file("data.bin", std::ios::binary | std::ios::in | std::ios::out);
int nums[]{1, 2, 3};
file.write(reinterpret_cast<const char*>(nums), sizeof(nums));
```

## filesystem路径操作

**std::filesystem是C++17跨平台路径抽象，将操作系统路径差异统一为可组合的操作序列。**

<pre>
"dir/subdir/file.txt" → parent_path() → "dir/subdir"
"dir/subdir/file.txt" → filename() → "file.txt"
"dir/subdir/file.txt" → stem() → "file"
"dir/subdir/file.txt" → extension() → ".txt"
</pre>

### 参考样例

```cpp
#include <filesystem>
namespace fs = std::filesystem;

fs::path p = "dir/subdir/file.txt";
p.parent_path();
p.filename();
fs::create_directories("new_dir/sub");
fs::exists("file.txt");
for (auto& e : fs::directory_iterator(".")) {}
```

## 随机访问

**文件指针通过seekg/tellg（读）和seekp/tellp（写）实现直接定位，本质是将字节偏移量映射到物理地址。**

### 参考样例

```cpp
std::fstream f("data.bin", std::ios::binary | std::ios::in | std::ios::out);
f.seekg(0, std::ios::end);
auto sz = f.tellg();
f.seekg(index * sizeof(int));
f.read(reinterpret_cast<char*>(&val), sizeof(val));
```

## 文件锁（Unix/Linux）

**flock是将文件描述符与锁状态关联的咨询锁，通过内核维护锁的持有者信息，实现多进程互斥。**

> 平台限制：此API仅适用于Unix/Linux。Windows需使用Win32 API（LockFileEx）。

### 参考样例

```cpp
#include <sys/file.h>
int fd = open(".lockfile", O_CREAT | O_RDWR, 0666);
flock(fd, LOCK_EX);
int r = flock(fd, LOCK_EX | LOCK_NB);
flock(fd, LOCK_UN);
close(fd);
```

## 内存映射（Unix/Linux）

**mmap将文件字节序列直接映射为进程虚拟地址空间的页表项，写入映射内存触发内核按需分页脏回写。**

> 平台限制：此API仅适用于Unix/Linux。Windows需使用CreateFileMapping/MapViewOfFile。

### 参考样例

```cpp
#include <sys/mman.h>
int fd = open("data.bin", O_RDWR);
struct stat sb;
fstat(fd, &sb);
void* addr = mmap(nullptr, sb.st_size, PROT_READ | PROT_WRITE,
                  MAP_SHARED, fd, 0);
static_cast<char*>(addr)[0] = 'X';
munmap(addr, sb.st_size);
```

## 原子写入

**写入临时文件再rename是利用文件系统rename的原子性，避免程序崩溃导致文件损坏。**

### 参考样例

```cpp
void atomicWrite(const fs::path& p, const std::string& c) {
    auto tmp = p.string() + ".tmp";
    std::ofstream out(tmp);
    out << c;
    out.close();
    fs::rename(tmp, p);
}
```
