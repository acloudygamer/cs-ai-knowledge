# 日期时间

**日期时间是Chrono库对现实时间的三种抽象：时长（长度）、时间点（位置）、时钟（测量工具）。**

## chrono基本概念

**时长是时间的长度，时间点是时间上的位置，时钟是测量时间点的工具。**

<pre>
steady_clock:───────→（单调递增，不受系统时钟调整影响）
system_clock:────────→（可转换为time_t，受系统时钟影响）
</pre>

### 参考样例

```cpp
using namespace std::chrono;
seconds s(30);
milliseconds ms = s;
auto mins = duration_cast<minutes>(s);
auto point = system_clock::now();
```

## 时长转换

**隐式转换在单位成倍数关系时自动发生，否则需显式duration_cast。**

### 参考样例

```cpp
minutes m(2);
seconds s = m;
auto ms = duration_cast<milliseconds>(m);
```

## 时间点

**时间点是距离纪元的时间量，可与time_t相互转换用于C库互操作。**

### 参考样例

```cpp
auto now = system_clock::now();
auto t = system_clock::to_time_t(now);
auto diff = later - earlier;
```

## C++20日历

**C++20通过字面量运算符支持年月日直接构造，通过sys_days与time_t互转。**

### 参考样例

```cpp
auto d = 2024y / 1 / 15;
auto wd = d / weekday{};
auto days10 = d + days(10);
sys_days sd{d};
year_month_day ymd{sd};
```

## C++20时区

**zoned_time将UTC时间点与时区名称结合，自动处理夏令时等转换。**

### 参考样例

```cpp
auto utc = utc_clock::now();
auto tokyo = zoned_time{"Asia/Tokyo", utc};
auto local = current_zone()->to_local(utc);
```

## 超时控制

**wait_for通过状态机检测future是否在超时前完成，避免永久阻塞。**

### 参考样例

```cpp
auto f = std::async(std::launch::async, [] { return 42; });
auto st = f.wait_for(1s);
if (st == std::future_status::ready) {}
```
