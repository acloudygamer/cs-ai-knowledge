# 日期与时间

## chrono 库（C++11 起）

`<chrono>` 库是 C++ 的时间处理库，包含三种主要类型：时长（duration）、时间点（time point）和时钟（clock）。

### 基本概念

时长表示一段时间，时间点表示一个具体的时刻，时钟分为 `system_clock`（系统实时时钟）、`steady_clock`（单调时钟）和 `high_resolution_clock`（高精度时钟）。

### 参考样例

```cpp
#include <chrono>
#include <iostream>

// 时长：一段时间
std::chrono::seconds sec(5);        // 5 秒
std::chrono::milliseconds ms(500);  // 500 毫秒
std::chrono::minutes min(2);        // 2 分钟

// 时间点：一个具体的时刻
auto now = std::chrono::system_clock::now();  // 当前时间点

// 时钟
using namespace std::chrono;

// system_clock：系统实时时钟（可转换为 time_t）
// steady_clock：单调时钟（不受系统时间调整影响，适合测量时间间隔）
// high_resolution_clock：高精度时钟（通常是 steady_clock 的别名）
```

### 时长（Duration）

时长是时间量的表示，支持多种单位之间的转换。`duration_cast` 用于显式转换时长单位，可选择截断或向上取整。

### 参考样例

```cpp
using namespace std::chrono;

// 预定义时长类型
seconds s(30);
milliseconds ms = s;                      // 30,000 ms（隐式转换）
std::chrono::duration<double> ds = s;    // 30.0 秒（浮点）

// duration_cast：显式转换时长单位
auto mins = std::chrono::duration_cast<std::chrono::minutes>(s);  // 0 分钟（截断）
auto mins_ceil = std::chrono::duration_cast<std::chrono::minutes>(std::chrono::ceil<std::chrono::minutes>(s));  // 1 分钟（向上取整）

// 时长运算
auto total = seconds(30) + std::chrono::minutes(1);  // 90 秒
auto doubled = s * 2;                                // 60 秒

// 常用时长单位
std::chrono::hours h(2);                    // 2 小时
std::chrono::minutes m(30);                 // 30 分钟
std::chrono::seconds sec(120);              // 120 秒
std::chrono::milliseconds ms(1500);         // 1500 毫秒
std::chrono::microseconds us(1000000);      // 100 万微秒
std::chrono::nanoseconds ns(1000000000);    // 10 亿纳秒

// count() 获取值
std::cout << ms.count() << " ms\n";  // 1500
```

### 时间点（Time Point）

时间点表示距离纪元（epoch）的时间量，可与 `time_t` 相互转换，支持计算时间间隔。

### 参考样例

```cpp
using namespace std::chrono;

// 获取当前时间点
auto now = std::chrono::system_clock::now();

// 转换为 time_t（可与 C 库互操作）
std::time_t now_c = std::chrono::system_clock::to_time_t(now);

// 转换为 chrono::duration（距离纪元的时长）
auto since_epoch = now.time_since_epoch();
auto seconds_since_epoch = std::chrono::duration_cast<std::chrono::seconds>(since_epoch).count();

// 从 time_t 创建时间点
std::time_t past = std::chrono::system_clock::to_time_t(std::chrono::system_clock::now()) - 3600;
auto past_point = std::chrono::system_clock::from_time_t(past);

// 计算时间间隔
auto point1 = std::chrono::system_clock::now();
auto point2 = point1 + std::chrono::hours(24);
auto diff = point2 - point1;  // duration 类型
```

### 时钟与时间测量

`steady_clock` 是测量时间间隔的首选，不受系统时间调整影响。`high_resolution_clock` 提供最高精度。

### 参考样例

```cpp
#include <chrono>
#include <iostream>

using namespace std::chrono;

// 方法 1：steady_clock（推荐用于测量时间间隔）
void measure_steady() {
    auto start = std::chrono::steady_clock::now();

    // 执行要测量的操作
    volatile int sum = 0;
    for (int i = 0; i < 1000000; ++i) sum += i;

    auto end = std::chrono::steady_clock::now();
    auto elapsed = end - start;

    std::cout << "Elapsed: "
              << std::chrono::duration<double, std::milli>(elapsed).count()
              << " ms\n";
}

// 方法 2：high_resolution_clock（最高精度）
void measure_high_res() {
    auto start = std::chrono::high_resolution_clock::now();

    // ... 操作 ...

    auto end = std::chrono::high_resolution_clock::now();
    auto ns = std::chrono::duration_cast<std::chrono::nanoseconds>(end - start).count();
    std::cout << ns << " ns\n";
}

// 测量函数执行时间
template <typename Func>
auto measure(Func&& func) {
    auto start = steady_clock::now();
    func();
    auto end = steady_clock::now();
    return end - start;
}
```

## C 风格时间 API

C 风格时间 API 通过 `<ctime>` 提供，与 chrono 库可相互转换。

### 参考样例

```cpp
#include <ctime>
#include <iostream>
#include <iomanip>

std::time_t now = std::time(nullptr);

// 转换为可读格式（本地时间）
std::tm* local = std::localtime(&now);

// 转换为可读格式（UTC）
std::tm* utc = std::gmtime(&now);

// 格式化输出
std::cout << std::put_time(local, "%Y-%m-%d %H:%M:%S") << "\n";
// 输出类似：2024-01-15 14:30:45

// strftime 格式化
char buf[100];
std::strftime(buf, sizeof(buf), "%Y-%m-%d %H:%M:%S", local);
std::cout << buf << "\n";

// 解析字符串为 time_t
std::string date_str = "2024-01-15 14:30:45";
std::tm tm = {};
std::istringstream ss(date_str);
ss >> std::get_time(&tm, "%Y-%m-%d %H:%M:%S");
std::time_t t = std::mktime(&tm);  // 转换为 time_t
```

### 格式化符号

| 符号 | 含义 | 示例 |
|------|------|------|
| `%Y` | 年（4 位） | 2024 |
| `%m` | 月（2 位） | 01-12 |
| `%d` | 日（2 位） | 01-31 |
| `%H` | 时（24 小时） | 00-23 |
| `%M` | 分 | 00-59 |
| `%S` | 秒 | 00-59 |
| `%A` | 星期（全名） | Monday |
| `%B` | 月份（全名） | January |
| `%y` | 年（2 位） | 24 |

## date.h（C++20 扩展）

C++20 引入了 `<chrono>` 的日历和时区扩展，提供日期字面量、年月日分解和时区转换功能。

### 参考样例

```cpp
#include <chrono>
#include <iostream>

// C++20 需要编译器支持（如 GCC 10+）

using namespace std::chrono;

// 日期字面量（C++20）
auto date = 2024y / 1 / 15;  // 2024 年 1 月 15 日

// 年月日分解
auto year = date.year();
auto month = date.month();
auto day = date.day();

// 星期几
auto weekday = date.year() / date.month() / date.day();
std::cout << weekday << "\n";  // Monday

// 日历运算
auto tomorrow = date + days(1);
auto last_month = date - months(1);

// 时间点与日历日期互转（C++20）
auto sys_days = std::chrono::sys_days{date};
std::chrono::year_month_day ymd = std::chrono::sys_days{date};
```

### 时区（C++20）

C++20 提供 `zoned_time` 支持时区转换，`current_zone()` 获取本地时区。

### 参考样例

```cpp
#include <chrono>
#include <iostream>

using namespace std::chrono;

// UTC 时间
auto utc_now = std::chrono::system_clock::now();
auto utc_time = std::chrono::utc_clock::now();  // C++20

// 转换为本地时间
std::chrono::local_t local_now = std::chrono::current_zone()->to_local(utc_now);

// 特定时区
auto tokyo = std::chrono::zoned_time{"Asia/Tokyo", utc_now};
std::cout << tokyo << "\n";  // 自动格式化

// 时区转换
auto ny = std::chrono::zoned_time{"America/New_York", utc_now};
std::cout << "NY time: " << ny << "\n";
std::cout << "Tokyo time: " << tokyo << "\n";
```

## 实用代码片段

### 定时器类

定时器类使用 `steady_clock` 测量时间，支持回调函数触发。

### 参考样例

```cpp
#include <chrono>
#include <functional>
#include <iostream>

class Timer {
    using clock = std::chrono::steady_clock;
    clock::time_point start_;
    std::chrono::milliseconds interval_;
    std::function<void()> callback_;
    bool running_ = false;

public:
    template <typename Func>
    void start(Func&& callback, int interval_ms) {
        callback_ = std::forward<Func>(callback);
        interval_ = std::chrono::milliseconds(interval_ms);
        start_ = clock::now();
        running_ = true;
    }

    void stop() { running_ = false; }

    bool check_and_fire() {
        if (!running_) return false;

        auto now = clock::now();
        if (now - start_ >= interval_) {
            callback_();
            start_ = now;
            return true;
        }
        return false;
    }
};

// 使用
Timer timer;
timer.start([]{ std::cout << "Timer fired!\n"; }, 1000);
```

### 超时控制

`std::future::wait_for` 支持超时控制，用于异步任务超时检测。

### 参考样例

```cpp
#include <chrono>
#include <future>
#include <iostream>

int long_running_task() {
    std::this_thread::sleep_for(std::chrono::seconds(5));
    return 42;
}

int main() {
    auto future = std::async(std::launch::async, long_running_task);

    // 等待最多 1 秒
    auto status = future.wait_for(std::chrono::seconds(1));

    if (status == std::future_status::ready) {
        std::cout << "Result: " << future.get() << "\n";
    } else if (status == std::future_status::timeout) {
        std::cout << "Timeout! Task still running.\n";
    }
}
```

### 速率限制器（Token Bucket）

令牌桶算法实现请求速率限制，支持令牌补充和获取控制。

### 参考样例

```cpp
#include <chrono>

class RateLimiter {
    int max_tokens_;
    int tokens_;
    std::chrono::steady_clock::time_point last_update_;
    double refill_rate_;  // tokens per second

public:
    RateLimiter(int max, double refill_per_sec)
        : max_tokens_(max), tokens_(max),
          last_update_(std::chrono::steady_clock::now()),
          refill_rate_(refill_per_sec) {}

    bool try_acquire(int count = 1) {
        refill();

        if (tokens_ >= count) {
            tokens_ -= count;
            return true;
        }
        return false;
    }

private:
    void refill() {
        auto now = std::chrono::steady_clock::now();
        auto elapsed = now - last_update_;
        double seconds = std::chrono::duration<double>(elapsed).count();

        tokens_ = std::min(max_tokens_,
            static_cast<int>(tokens_ + seconds * refill_rate_));
        last_update_ = now;
    }
};

// 使用：每秒最多 10 次请求
RateLimiter limiter(10, 10.0);

if (limiter.try_acquire()) {
    // 执行请求
} else {
    // 限流
}
```

### 性能计数器

性能计数器记录函数执行时间统计，支持命名和作用域计时。

### 参考样例

```cpp
#include <chrono>
#include <string>
#include <unordered_map>

class PerformanceCounter {
public:
    struct Stats {
        int count = 0;
        std::chrono::nanoseconds total{0};
        std::chrono::nanoseconds min{std::numeric_limits<long long>::max()};
        std::chrono::nanoseconds max{0};
    };

    class ScopedTimer {
        PerformanceCounter& counter_;
        std::string name_;
        std::chrono::steady_clock::time_point start_;

    public:
        ScopedTimer(PerformanceCounter& counter, const std::string& name)
            : counter_(counter), name_(name),
              start_(std::chrono::steady_clock::now()) {}

        ~ScopedTimer() {
            auto elapsed = std::chrono::steady_clock::now() - start_;
            counter_.record(name_, elapsed);
        }
    };

    void record(const std::string& name, std::chrono::nanoseconds elapsed) {
        auto& stats = data_[name];
        stats.count++;
        stats.total += elapsed;
        stats.min = std::min(stats.min, elapsed);
        stats.max = std::max(stats.max, elapsed);
    }

    void print() const {
        for (const auto& [name, stats] : data_) {
            std::cout << name << ":\n";
            std::cout << "  count: " << stats.count << "\n";
            std::cout << "  avg: "
                << std::chrono::duration<double, std::micro>(stats.total).count() / stats.count
                << " us\n";
            std::cout << "  min: "
                << std::chrono::duration<double, std::micro>(stats.min).count()
                << " us\n";
            std::cout << "  max: "
                << std::chrono::duration<double, std::micro>(stats.max).count()
                << " us\n";
        }
    }

private:
    std::unordered_map<std::string, Stats> data_;
};

// 使用
PerformanceCounter counter;
{
    PerformanceCounter::ScopedTimer timer(counter, "sort");
    std::vector<int> v = {5, 2, 8, 1, 9};
    std::sort(v.begin(), v.end());
}
counter.print();
```
