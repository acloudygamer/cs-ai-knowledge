# 日期时间

## 定义

日期时间是 Chrono 库对**连续时间轴**的离散化抽象：C++ 将时间建模为**时长（Duration）**的累加，将时刻建模为**时间点（Time Point）**距离特定**纪元（Epoch）**的时长。Chrono 的核心设计原则是**类型安全**：不同时间单位是不同类型，隐式转换仅在单位成倍数关系时允许，防止错误的单位参与运算。

## 数学模型

### Duration 的数学结构

时长是**带单位的整数或浮点值**，数学上是一个**阿基米德域**（Archimedean field）：

$$
\text{duration} = \text{rep} \times \text{period}
$$

其中 `rep` 是数值类型（`int64_t`、`double` 等），`period` 是 `std::ratio<Num, Den>`，表示单位（如 `milliseconds = ratio<1, 1000>` 秒）。

**时长之间的运算**：

| 运算 | 结果类型 | 条件 |
|------|----------|------|
| `dur1 + dur2` | `common_type` | 单位可转换 |
| `dur1 - dur2` | `common_type` | 单位可转换 |
| `dur1 * rep` | `duration` | 缩放 |
| `dur1 / dur2` | `rep`（无量纲） | 仅在比值有意义时 |

**隐式转换规则**：仅当转换后的值是整数（无精度损失）时才允许隐式转换。`seconds` → `minutes` 需 `duration_cast`（显式转换），因为 $60$ 不是所有秒数都能整除。 不是所有秒数都能整除。

### Time Point 与纪元

时间点是 "**纪元 + 时长**" 的二元组：

$$
TP = (\text{Epoch}, \text{Duration since epoch})
$$

- `std::chrono::system_clock::time_point` 的纪元是 Unix Epoch（1970-01-01 00:00:00 UTC）。
- `std::chrono::steady_clock::time_point` 的纪元是未规范化的"某个未指定时刻"（只能用于测量时间差，不可与其他时钟互转）。

**时间点的算术**：

$$
TP_2 - TP_1 = \text{duration} \quad (\text{时间差，与纪元无关})
$$

$$
TP_1 + \text{duration} = TP_2 \quad (\text{时间平移})
$$

### 时区转换的数学模型

时区转换本质上是**UTC 与地方时（Local Time）之间的仿射变换**：

$$
\text{LT} = \text{UTC} + \text{offset} + \text{DST\_adjustment}
$$

其中 `offset` 是固定时差（如 `+08:00`），`DST_adjustment` 是夏令时期间额外的一小时偏移。

**IANA 时区数据库** 将时区规则编码为历史分段时间线，每个转换点记录 `UTC offset` 和 `DST flag`。给定 UTC 时间，转换算法：
1. 在时区规则时间线中二分查找对应区间。
2. 应用该区间的 offset 和 DST adjustment。

### C++20 日历的日期数学

Gregorian 历法日期是**儒略日（Julian Day Number）**的线性映射。设年份为 $Y$ ，月份为 $M$ ，日期为 $D$ （Gregorian 历），对应的 Julian Day Number： ，月份为 $M$ ，日期为 $D$ （Gregorian 历），对应的 Julian Day Number： ，日期为 $D$ （Gregorian 历），对应的 Julian Day Number： （Gregorian 历），对应的 Julian Day Number：

$$
\text{JDN} = (1461(Y + 4800 + (M-14)/12))/4 + (367(M-2-12((M-14)/12)))/12 \\
- (3((Y+4900+(M-14)/12)/100))/4 + D - 32075
$$

此公式将任意 Gregorian 日期映射为唯一的整数（JDN），使日期的加减运算转化为整数的加减。

## 数据流

### Duration 转换的数据流

<pre>
seconds(120)              minutes(2)                 hours(0.0333...)
   │                          │                          │
   │ 隐式转换（整数除法）       │ 显式 duration_cast        │ 浮点转换
   ▼                          ▼                          ▼
  rep = 120               rep = 2                    rep = 0.0333...
  period = s              period = min               period = h
</pre>

**隐式转换条件**：`std::chrono::seconds` → `std::chrono::minutes` 需要 `duration_cast<minutes>`，因为 $120 / 60 = 2$ （整数），但反向转换（minutes → seconds）也是显式的，因为不是所有秒数都能整除分钟。 （整数），但反向转换（minutes → seconds）也是显式的，因为不是所有秒数都能整除分钟。

### C++20 日历系统的类型层次

<pre>
Calendar Date (year/month/day)      weekday / year_month_weekday
           │                                    │
           ▼                                    ▼
      sys_days (时间点，UTC天数)          local_days (地方时天数)
           │                                    │
           ▼                                    ▼
      system_clock::time_point               zoned_time
           │                                    │
           ▼                                    ▼
      to_time_t() → Unix time_t            时区转换 → 人类可读时间字符串
</pre>

**数据流约束**：`sys_days` 是天数的 `time_point`，可直接与 `system_clock::time_point` 相互转换。转换涉及天→秒的乘法和纪元偏移的加法。

### future::wait_for 的状态机

<pre>
async 调用发起
       │
       ▼
┌─────────────────────────────────┐
│          future 状态机            │
├─────────────────────────────────┤
│  deferred（未启动）→ 启动后 → ready │
│  ready ←（超时或就绪）             │
└─────────────────────────────────┘
       │

wait_for(timeout) 返回：
  future_status::deferred ← 操作尚未开始
  future_status::ready ← 超时前完成

</pre>

## 机制

### 闰秒（Leap Second）的处理

UTC 时间通过**闰秒**保持与地球自转同步（不规则性）。闰秒在 6 月 30 日或 12 月 31 日的 23:59:59 UTC 之后插入，使该分钟变成 59 或 61 秒。

**Chrono 的处理**：
- `system_clock` 基于 POSIX Time（忽略闰秒），因此 `system_clock::now()` 与 UTC 之间存在已知偏移（当前为 37 秒）。
- `steady_clock` 完全忽略日历时间，只测量物理时间流逝。
- C++ 标准库不直接支持闰秒插入的时间点，tz database 通过时区规则间接处理。

### Duration 的溢出行为

`duration` 的算术运算在编译期和运行时都可能溢出：

```cpp
hours h(1);
minutes m = h;  // 编译错误：hours → minutes 需要显式 cast
minutes m = duration_cast<minutes>(h);  // OK: 60
minutes m(INT_MAX);  // 运行时可能溢出（取决于 rep 类型）
```

**溢出时的行为**：
- 有符号整数溢出：未定义行为（UB）。
- `duration_cast`：如果结果超出目标类型范围，编译错误（常量表达式）或未定义行为（运行时）。
- `std::chrono::**time_point**` 的加减：溢出时未定义行为。

**预防**：使用 `duration_count` 的 `abs_duration`（C++20）或检查溢出边界。

### C++20 `std::format` 的日期格式化

`std::format` 支持 Chrono 类型的格式化：

```cpp
std::format("{:%%Y-%%m-%%d}", sys_days{d});  // 2024-01-15
std::format("{:%%H:%%M:%%S}", local_seconds{s});  // 14:30:00
```

格式化字符串中 `%%` 转义为 `%`，后跟时间符号：`%Y` 年、`%m` 月、`%d` 日、`%H` 时、`%M` 分、`%S` 秒。

### zoned_time 的惰性求值

`zoned_time` 在构造时不执行时区转换，只记录 UTC 时间点和时区标识。转换到地方时在以下时机**惰性求值**：

1. 转换为字符串（`to_local()`）。
2. 访问 `.get_local_time()`。
3. `std::format` 格式化输出。

这避免了重复计算，同时确保时区规则在构造时就被固定（即使后续规则改变，已构造的 `zoned_time` 仍保持原有转换结果）。

### future_status 的超时语义

`wait_for` 的语义是"等待**至少**指定时长"，而非"等待**恰好**指定时长"。这意味着：

- 若操作在超时前完成，返回 `ready`（不等待到超时到期）。
- 若超时到期时操作未完成，返回 `timeout`（操作可能仍在后台运行）。
- `wait_until` 指定绝对时间点，避免了时钟漂移问题。

**时钟选择**：若使用 `steady_clock` 进行超时控制，则超时是单调递增的，不受系统时钟调整影响。若使用 `system_clock`，系统时钟调整可能导致超时提前（时钟回拨）或延迟（时钟快进）。

### C++20 std::format 的格式化框架

**[C++20]** `std::format` 是 C++20 引入的格式化框架，提供了 Python `str.format()` 风格的安全性：

$$
\text{format}(fmt, args...) \rightarrow \text{string}
$$

**格式规范的数学语法**：

$$
\text{fmt} = \underbrace{[clearance]}_{\text{填充字符}} \underbrace{[alignment]}_{\text{对齐方式}} \underbrace{[sign]}_{\text{符号}} \underbrace{[\#]}_{\text{替代形式}} \underbrace{[0]}_{\text{前导零}} \underbrace{[\text{width}]}_{\text{宽度}} \underbrace{[grouping]}_{\text{千分位}} \underbrace{[.precision]}_{\text{精度}} \underbrace{[\text{type}]}_{\text{类型}}
$$

**类型说明符的语义**：

| 类型 | 含义 | 示例输出 |
|------|------|----------|
| `d` | 十进制整数 | `42` |
| `x` / `X` | 十六进制 | `2a` / `2A` |
| `f` / `F` | 定点浮点 | `3.140000` |
| `e` / `E` | 科学计数 | `3.14e+00` |
| `g` / `G` | 通用格式 | `3.14` |
| `%` | 百分数 | `31.4%` |
| `s` | 字符串 | `hello` |

**惰性求值与工厂函数**：

`std::format` 的参数是**按值传递**的，这可能导致不必要的拷贝。`std::format_arg` 提供了惰性求值：

```cpp
// 每次调用都拷贝 vector
std::print("{}", std::vector{1, 2, 3});  // 拷贝开销

// 工厂函数避免拷贝（延迟求值）
auto arg = std::make_format_arg(std::vector{1, 2, 3});
// 仅在实际格式化时读取
```

**与 printf 的对比**：

| 维度 | printf | std::format |
|------|--------|-------------|
| 类型安全 | `%s` 等类型擦除 | 编译期格式校验 |
| 扩展性 | 需重载 | ADL 查找 |
| 本地化 | `%'d` (非标准) | `std::locale` 支持 |
| 性能 | 解析 + 输出 | 解析（缓存）+ 输出 |

## 参考存根

```cpp
// C++20 日历：计算两个日期之间的天数差
using namespace std::chrono;

auto d1 = 2024y / 1 / 15;
auto d2 = 2024y / 7 / 1;

sys_days sd1{d1};
sys_days sd2{d2};

auto diff = sd2 - sd1;  // 返回 days 类型
cout << diff.count() << " days";  // 168 天

// 星期计算
auto wd = d1 / weekday{};  // 2024-01-15 是星期几
cout << wd.text();  // "Monday" 或当地语言
```

```cpp
// future 超时控制
auto f = std::async(std::launch::async, [] {
    std::this_thread::sleep_for(3s);
    return 42;
});

auto st = f.wait_for(1s);  // 等待 1 秒
if (st == std::future_status::timeout) {
    // 未完成，继续等待或放弃
    st = f.wait_for(3s);
}
if (st == std::future_status::ready) {
    int result = f.get();  // 42
}
```
