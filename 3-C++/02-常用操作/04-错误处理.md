# 错误处理

## noexcept 说明符（C++11）

`noexcept` 声明函数不会抛出异常，编译器可据此优化。

### 基本用法

```cpp
// 声明不抛异常的函数
void process() noexcept {
    // 不会抛出异常
}

// 等价于
void process() noexcept(true) {}

// 可能抛出
void risky() noexcept(false) {}

// 隐式 noexcept（C++11 起，以下情况自动推导）
// - 析构函数（默认）
// - 默认构造函数、拷贝构造函数、移动构造函数
// - 拷贝赋值运算符、移动赋值运算符
```

### noexcept 与移动语义

```cpp
class Buffer {
    char* data_;
    size_t size_;
public:
    // 移动构造函数应为 noexcept
    // 这样 std::vector::push_back 才会选择移动而非拷贝
    Buffer(Buffer&& other) noexcept : data_(other.data_), size_(other.size_) {
        other.data_ = nullptr;
        other.size_ = 0;
    }

    Buffer& operator=(Buffer&& other) noexcept {
        if (this != &other) {
            delete[] data_;
            data_ = other.data_;
            size_ = other.size_;
            other.data_ = nullptr;
            other.size_ = 0;
        }
        return *this;
    }
};

std::vector<Buffer> v;
v.push_back(Buffer());  // 调用 noexcept 移动构造
```

### noexcept 运算符

运行时检查表达式是否可能抛异常：

```cpp
constexpr bool can_throw = noexcept(int(1));  // false
constexpr bool may_throw = noexcept(throw 1);  // true

template<typename T>
void smart_move(T& a, T& b) noexcept(noexcept(T(std::move(a)))) {
    T tmp(std::move(a));
    a = std::move(b);
    b = std::move(tmp);
}
```

## Stack Unwinding（栈展开）

异常抛出时，栈上的局部对象会被销毁（栈展开）。

### 析构函数与异常

```cpp
class Cleanup {
public:
    ~Cleanup() {
        // 如果这里也抛异常，terminate() 被调用
        std::cout << "Cleanup\n";
    }
};

void risky() {
    Cleanup c;
    throw std::runtime_error("error");  // c 的析构被调用
}

int main() {
    try {
        risky();
    } catch (...) {
        // 如果析构函数抛异常，std::terminate 被调用
    }
}
```

### 异常安全保证

```cpp
class Resource {
public:
    // 基本异常安全：操作失败，对象保持有效状态
    void basic_exception_safety() noexcept {
        // 失败时对象状态仍有效
    }

    // 强异常安全：操作要么成功，要么状态不变
    void strong_exception_safety() noexcept {
        auto backup = state_;  // 复制
        try {
            perform_action();
            state_ = new_state;
        } catch (...) {
            state_ = backup;  // 恢复原状态
            throw;
        }
    }

    // 无抛异常保证：操作不抛异常
    void no_throw() noexcept {
        // 保证不抛异常
    }
};
```

### RAII 与异常

```cpp
class FileGuard {
    FILE* file_;
public:
    explicit FileGuard(const char* path) : file_(fopen(path, "r")) {}

    ~FileGuard() {
        if (file_) fclose(file_);
    }

    // 移动语义
    FileGuard(FileGuard&& other) noexcept : file_(other.file_) {
        other.file_ = nullptr;
    }

    FileGuard& operator=(FileGuard&& other) noexcept {
        if (this != &other) {
            if (file_) fclose(file_);
            file_ = other.file_;
            other.file_ = nullptr;
        }
        return *this;
    }
};

void process_file() {
    FileGuard guard("data.txt");
    // 文件在 guard 析构时保证关闭
    // 即使中间抛异常，析构也会执行
}
```

## 异常机制

```cpp
#include <stdexcept>

double divide(double a, double b) {
    if (b == 0.0) {
        throw std::invalid_argument("Division by zero");
    }
    return a / b;
}

try {
    double result = divide(10.0, 0.0);
} catch (const std::invalid_argument& e) {
    std::cerr << "Error: " << e.what() << std::endl;
} catch (const std::exception& e) {
    std::cerr << "Unexpected error: " << e.what() << std::endl;
}

// 自定义异常
class MyException : public std::exception {
public:
    explicit MyException(const std::string& msg) : message(msg) {}
    const char* what() const noexcept override { return message.c_str(); }
private:
    std::string message;
};
```

## 错误码方式

```cpp
enum class ErrorCode {
    Success = 0,
    NotFound = 1,
    InvalidInput = 2,
    NetworkError = 3
};

ErrorCode process(int input, std::string& result) {
    if (input < 0) {
        return ErrorCode::InvalidInput;
    }
    result = "processed: " + std::to_string(input);
    return ErrorCode::Success;
}

// 使用
std::string output;
ErrorCode err = process(-1, output);
if (err != ErrorCode::Success) {
    // 处理错误
}
```

## C 风格错误处理

```cpp
#include <cerrno>
#include <cstring>

FILE* f = fopen("nonexistent.txt", "r");
if (f == nullptr) {
    std::cerr << "Error opening file: " << strerror(errno) << std::endl;
}
```
