# 错误处理

**错误处理是程序对异常状态的响应机制，核心是异常展开栈与RAII资源回收的配合，或错误码的显式传播。**

## noexcept

**noexcept声明函数不抛异常，使编译器跳过栈展开代码生成，是C++优化异常成本的关键手段。**

<pre>
函数调用 → [noexcept?] → [是:跳过栈展开] / [否:执行栈展开]
</pre>

### 参考样例

```cpp
void foo() noexcept {}
void bar() noexcept(false) {}

constexpr bool canThrow = noexcept(int(1));
constexpr bool mayThrow = noexcept(throw 1);

template<typename T>
void move_only(T& a, T& b) noexcept(noexcept(T(std::move(a)))) {
    T tmp(std::move(a));
    a = std::move(b);
    b = std::move(tmp);
}
```

## noexcept与移动语义

**std::vector在push_back时若移动构造函数是noexcept则优先移动，否则拷贝。**

### 参考样例

```cpp
class Buf {
    char* d_;
public:
    Buf(Buf&& o) noexcept : d_(o.d_) { o.d_ = nullptr; }
    Buf& operator=(Buf&& o) noexcept {
        delete[] d_; d_ = o.d_; o.d_ = nullptr; return *this;
    }
};

std::vector<Buf> v;
v.push_back(Buf{});
```

## 异常安全保证

**基本保证：失败后对象有效；强保证：失败则状态不变；nothrow保证：操作不抛异常。**

### 参考样例

```cpp
void strong() noexcept {
    auto bak = state_;
    try {
        action();
        state_ = new_state;
    } catch (...) {
        state_ = bak;
        throw;
    }
}
```

## RAII与异常

**RAII通过析构函数保证资源释放，即使异常发生也能正确清理，是C++异常安全的基石。**

### 参考样例

```cpp
class FileGuard {
    FILE* f_;
public:
    explicit FileGuard(const char* p) : f_(fopen(p, "r")) {}
    ~FileGuard() { if (f_) fclose(f_); }
    FileGuard(const FileGuard&) = delete;
    FileGuard& operator=(const FileGuard&) = delete;
};

void process() {
    FileGuard g("data.txt");
}
```

## std::uncaught_exceptions

**uncaught_exceptions()区分正常析构与异常析构，防止在栈展开时执行可能引发新异常的清理。**

### 参考样例

```cpp
class Guard {
    ~Guard() {
        if (std::uncaught_exceptions() == 0) {}
    }
};
```

## 静态断言

**static_assert在编译期检查条件，不满足则编译失败，是模板元编程的调试手段。**

### 参考样例

```cpp
static_assert(std::is_pointer<int>::value == false);

template<typename T>
concept Numeric = std::integral<T> || std::floating_point<T>;

template<Numeric T>
T add(T a, T b) { return a + b; }
```
