# 错误处理

## noexcept 说明符（C++11）

`noexcept` 声明函数不会抛出异常，编译器可据此优化。C++11 起析构函数、默认构造函数、拷贝/移动构造函数、拷贝/移动赋值运算符自动推导为 `noexcept`。`noexcept(expr)` 运行时检查表达式是否可能抛异常。

### 参考样例

```cpp
// 声明不抛异常的函数
void process() noexcept {
    // 不会抛出异常
}

// 等价于
void process() noexcept(true) {}

// 可能抛出
void risky() noexcept(false) {}

// noexcept 运算符
constexpr bool can_throw = noexcept(int(1));  // false
constexpr bool may_throw = noexcept(throw 1);  // true

// 模板中使用
template<typename T>
void smart_move(T& a, T& b) noexcept(noexcept(T(std::move(a)))) {
    T tmp(std::move(a));
    a = std::move(b);
    b = std::move(tmp);
}
```

## noexcept 与移动语义

移动构造函数应设为 `noexcept`，这样 `std::vector::push_back` 才会选择移动而非拷贝。

### 参考样例

```cpp
class Buffer {
    char* data_;
    size_t size_;
public:
    // 移动构造函数应为 noexcept
    Buffer(Buffer&& other) noexcept : data_(other.data_), size_(other.size_) {
        other.data_ = nullptr;
        other.size_ = 0;
    }

    Buffer& operator=(Buffer&& other) noexcept {
        if (this != &other) {
            delete[] data_;
            data_ = other.data_;
            size_ = other.size_;
            other.data_ = nullptr;
            other.size_ = 0;
        }
        return *this;
    }
};

std::vector<Buffer> v;
v.push_back(Buffer());  // 调用 noexcept 移动构造
```

## Stack Unwinding 与异常安全

异常抛出时，栈上的局部对象会被销毁（栈展开）。异常安全保证：基本保证（操作失败对象保持有效）、强保证（操作要么成功要么状态不变）、无抛保证（操作不抛异常）。

**RAII 是现代 C++ 处理异常的核心模式。**

### 参考样例

```cpp
// 析构函数与异常
class Cleanup {
    ~Cleanup() {
        std::cout << "Cleanup\n";  // 异常时也会被调用
    }
};

void risky() {
    Cleanup c;
    throw std::runtime_error("error");  // c 的析构被调用
}

// 构造函数中的异常
class Resource {
    int* data_;
public:
    Resource(size_t size) : data_(new int[size]) {
        // 如果 new 失败，data_ 不会被构造
    }
    ~Resource() { delete[] data_; }
};

// 强异常安全
void strong_exception_safety() noexcept {
    auto backup = state_;
    try {
        perform_action();
        state_ = new_state;
    } catch (...) {
        state_ = backup;  // 恢复原状态
        throw;
    }
}

// RAII 与异常
class FileGuard {
    FILE* file_;
public:
    explicit FileGuard(const char* path) : file_(fopen(path, "r")) {}
    ~FileGuard() { if (file_) fclose(file_); }
    FileGuard(FileGuard&& other) noexcept : file_(other.file_) { other.file_ = nullptr; }
    FileGuard& operator=(FileGuard&& other) noexcept { /* ... */ }
};

void process_file() {
    FileGuard guard("data.txt");
    // 文件在 guard 析构时保证关闭
}
```

## 异常机制

`std::exception` 是异常层次基类，派生类包括 `std::logic_error`（程序错误，如无效输入）、`std::runtime_error`（运行时错误，如范围错误）、`std::bad_alloc`（内存分配失败）。

### 参考样例

```cpp
#include <stdexcept>

double divide(double a, double b) {
    if (b == 0.0) {
        throw std::invalid_argument("Division by zero");
    }
    return a / b;
}

try {
    double result = divide(10.0, 0.0);
} catch (const std::invalid_argument& e) {
    std::cerr << "Error: " << e.what() << std::endl;
} catch (const std::exception& e) {
    std::cerr << "Unexpected error: " << e.what() << std::endl;
}

// 自定义异常
class MyException : public std::exception {
    std::string message;
public:
    explicit MyException(const std::string& msg) : message(msg) {}
    const char* what() const noexcept override { return message.c_str(); }
};

// nested_exception（C++11）
void lower_level() { throw std::runtime_error("low level"); }

void mid_level() {
    try {
        lower_level();
    } catch (...) {
        std::throw_with_nested(std::runtime_error("mid level"));
    }
}
```

## 错误码方式

错误码适合可预见的失败（如找不到、参数无效），异常适合真正异常的情况。`std::error_code` 提供系统错误码封装。

### 参考样例

```cpp
// 基础错误码
enum class ErrorCode { Success = 0, NotFound = 1, InvalidInput = 2 };

ErrorCode process(int input, std::string& result) {
    if (input < 0) return ErrorCode::InvalidInput;
    result = "processed: " + std::to_string(input);
    return ErrorCode::Success;
}

// std::error_code（C++11）
#include <system_error>

std::error_code ec;
std::ifstream f("nonexistent.txt");
if (!f) {
    ec = std::error_code(errno, std::system_category());
}
```

## C++17 std::uncaught_exceptions

`std::uncaught_exceptions()` 检测是否有未捕获的异常，用于区分正常析构和异常析构。

### 参考样例

```cpp
// 检测异常析构
class Cleanup {
    ~Cleanup() {
        if (std::uncaught_exceptions() > 0) {
            // 正在栈展开，不要执行可能导致新异常的清理
        }
    }
};

// 安全回滚
class Transaction {
    bool committed_ = false;
public:
    void commit() { committed_ = true; }
    ~Transaction() {
        if (!committed_ && std::uncaught_exceptions() == 0) {
            rollback();  // 安全回滚
        }
    }
};
```

## 静态断言与类型错误

`static_assert` 用于编译期检查，配合 `<type_traits>` 实现模板约束。C++20 concepts 提供了更清晰的模板约束表达。

### 参考样例

```cpp
#include <type_traits>

// 编译期检查
static_assert(std::is_pointer<int>::value == false, "int is not a pointer");

// 模板约束（C++20 concepts）
template<typename T>
concept Numeric = std::integral<T> || std::floating_point<T>;

template<Numeric T>
T add(T a, T b) { return a + b; }

add(1, 2);     // OK
add(1.0, 2.0); // OK
// add("a", "b"); // 编译错误
```
