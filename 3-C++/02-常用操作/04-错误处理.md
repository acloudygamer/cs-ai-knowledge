# 错误处理

## noexcept 说明符（C++11）

`noexcept` 声明函数不会抛出异常，编译器可据此优化。

### 基本用法

```cpp
// 声明不抛异常的函数
void process() noexcept {
    // 不会抛出异常
}

// 等价于
void process() noexcept(true) {}

// 可能抛出
void risky() noexcept(false) {}

// 隐式 noexcept（C++11 起，以下情况自动推导）
// - 析构函数（默认）
// - 默认构造函数、拷贝构造函数、移动构造函数
// - 拷贝赋值运算符、移动赋值运算符
```

### noexcept 与移动语义

```cpp
class Buffer {
    char* data_;
    size_t size_;
public:
    // 移动构造函数应为 noexcept
    // 这样 std::vector::push_back 才会选择移动而非拷贝
    Buffer(Buffer&& other) noexcept : data_(other.data_), size_(other.size_) {
        other.data_ = nullptr;
        other.size_ = 0;
    }

    Buffer& operator=(Buffer&& other) noexcept {
        if (this != &other) {
            delete[] data_;
            data_ = other.data_;
            size_ = other.size_;
            other.data_ = nullptr;
            other.size_ = 0;
        }
        return *this;
    }
};

std::vector<Buffer> v;
v.push_back(Buffer());  // 调用 noexcept 移动构造
```

### noexcept 运算符

运行时检查表达式是否可能抛异常：

```cpp
constexpr bool can_throw = noexcept(int(1));  // false
constexpr bool may_throw = noexcept(throw 1);  // true

template<typename T>
void smart_move(T& a, T& b) noexcept(noexcept(T(std::move(a)))) {
    T tmp(std::move(a));
    a = std::move(b);
    b = std::move(tmp);
}
```

### 虚函数中的 noexcept

```cpp
class Base {
public:
    virtual void process() noexcept = 0;
    virtual ~Base() = default;
};

class Derived : public Base {
public:
    void process() noexcept override {
        // 必须保持 noexcept 协变
    }
};
```

## Stack Unwinding（栈展开）

异常抛出时，栈上的局部对象会被销毁（栈展开）。

### 析构函数与异常

```cpp
class Cleanup {
public:
    ~Cleanup() {
        // 如果这里也抛异常，terminate() 被调用
        std::cout << "Cleanup\n";
    }
};

void risky() {
    Cleanup c;
    throw std::runtime_error("error");  // c 的析构被调用
}

int main() {
    try {
        risky();
    } catch (...) {
        // 如果析构函数抛异常，std::terminate 被调用
    }
}
```

### 构造函数中的异常

```cpp
class Resource {
    int* data_;
public:
    Resource(size_t size) : data_(new int[size]) {
        // 如果 this->data_ 构造成功，异常会触发 cleanup
        // 如果 new int[size] 失败，data_ 不会被构造
    }

    ~Resource() {
        delete[] data_;  // data_ 未构造则不会调用
    }
};

// 委托构造中的异常
class Delegating {
    int value_;
public:
    Delegating(int v) : Delegating() {  // 先调用委托构造
        if (v < 0) throw std::invalid_argument("negative");
        value_ = v;
    }

    Delegating() : value_(0) {}
};
```

### 异常安全保证

```cpp
class Resource {
public:
    // 基本异常安全：操作失败，对象保持有效状态
    void basic_exception_safety() noexcept {
        // 失败时对象状态仍有效
    }

    // 强异常安全：操作要么成功，要么状态不变
    void strong_exception_safety() noexcept {
        auto backup = state_;  // 复制
        try {
            perform_action();
            state_ = new_state;
        } catch (...) {
            state_ = backup;  // 恢复原状态
            throw;
        }
    }

    // 无抛异常保证：操作不抛异常
    void no_throw() noexcept {
        // 保证不抛异常
    }
};
```

### RAII 与异常

```cpp
class FileGuard {
    FILE* file_;
public:
    explicit FileGuard(const char* path) : file_(fopen(path, "r")) {}

    ~FileGuard() {
        if (file_) fclose(file_);
    }

    // 移动语义
    FileGuard(FileGuard&& other) noexcept : file_(other.file_) {
        other.file_ = nullptr;
    }

    FileGuard& operator=(FileGuard&& other) noexcept {
        if (this != &other) {
            if (file_) fclose(file_);
            file_ = other.file_;
            other.file_ = nullptr;
        }
        return *this;
    }
};

void process_file() {
    FileGuard guard("data.txt");
    // 文件在 guard 析构时保证关闭
    // 即使中间抛异常，析构也会执行
}
```

## 异常机制

### 标准异常层次

```cpp
#include <stdexcept>

// std::exception
//   ├── std::logic_error
//   │     ├── std::invalid_argument
//   │     ├── std::domain_error
//   │     ├── std::length_error
//   │     └── std::out_of_range
//   ├── std::runtime_error
//   │     ├── std::range_error
//   │     ├── std::overflow_error
//   │     ├── std::underflow_error
//   │     └── std::regex_error
//   └── std::bad_alloc
//         └── std::bad_array_new_length
```

### 基础用法

```cpp
#include <stdexcept>

double divide(double a, double b) {
    if (b == 0.0) {
        throw std::invalid_argument("Division by zero");
    }
    return a / b;
}

try {
    double result = divide(10.0, 0.0);
} catch (const std::invalid_argument& e) {
    std::cerr << "Error: " << e.what() << std::endl;
} catch (const std::exception& e) {
    std::cerr << "Unexpected error: " << e.what() << std::endl;
}

// 自定义异常
class MyException : public std::exception {
public:
    explicit MyException(const std::string& msg) : message(msg) {}
    const char* what() const noexcept override { return message.c_str(); }
private:
    std::string message;
};
```

### 异常重新抛出

```cpp
try {
    // 可能抛出异常的代码
    throw std::runtime_error("original error");
} catch (const std::exception& e) {
    // 处理异常
    std::cerr << "Handling: " << e.what() << std::endl;
    // 重新抛出（保持类型信息）
    throw;
}
```

### 异常指针（std::exception_ptr）

```cpp
#include <exception>
#include <functional>

std::exception_ptr current_exception() noexcept;

// 捕获并重新抛出
std::function<void()> dangerous = []() {
    throw std::runtime_error("error");
};

std::exception_ptr err;
try {
    dangerous();
} catch (...) {
    err = std::current_exception();  // 捕获异常
}

// 稍后重新抛出
if (err) {
    std::rethrow_exception(err);
}
```

### noexcept 函数中的异常

```cpp
// noexcept 函数中抛异常会导致 terminate()
void terminate_func() noexcept {
    throw std::runtime_error("oops");  // terminate() 被调用
}

// nested_exception（C++11）
#include <exception>

void lower_level() {
    throw std::runtime_error("low level");
}

void mid_level() {
    try {
        lower_level();
    } catch (...) {
        std::throw_with_nested(std::runtime_error("mid level"));
    }
}

void top_level() {
    try {
        mid_level();
    } catch (const std::nested_exception& e) {
        std::cerr << e.what() << std::endl;  // mid level
        try {
            e.rethrow_nested();
        } catch (const std::runtime_error& e2) {
            std::cerr << e2.what() << std::endl;  // low level
        }
    }
}
```

## 错误码方式

### 基础错误码

```cpp
enum class ErrorCode {
    Success = 0,
    NotFound = 1,
    InvalidInput = 2,
    NetworkError = 3
};

ErrorCode process(int input, std::string& result) {
    if (input < 0) {
        return ErrorCode::InvalidInput;
    }
    result = "processed: " + std::to_string(input);
    return ErrorCode::Success;
}

// 使用
std::string output;
ErrorCode err = process(-1, output);
if (err != ErrorCode::Success) {
    // 处理错误
}
```

### std::error_code（C++11）

```cpp
#include <system_error>

// 系统错误码
std::error_code ec;
std::ifstream f("nonexistent.txt");
if (!f) {
    ec = std::error_code(errno, std::system_category());
    std::cerr << "Error: " << ec.message() << std::endl;
}

// 自定义错误码
class MyError {
public:
    enum Code { NotFound, Invalid, Timeout };
private:
    Code code_;
public:
    MyError(Code c) : code_(c) {}
    explicit operator int() const { return static_cast<int>(code_); }
};

namespace std {
    template<>
    struct is_error_code_enum<MyError::Code> : true_type {};
}

std::error_code make_error_code(MyError::Code e) {
    return std::error_code(static_cast<int>(e), std::system_category());
}
```

## 错误处理设计模式

### 错误处理策略

```cpp
// 1. 异常用于真正异常情况
void process_config() {
    // 配置缺失是异常
    throw ConfigError("missing config file");
}

// 2. 错误码用于可预见的失败
std::optional<T> find_item(int id) {
    // 找不到是正常情况，不是异常
    auto it = items.find(id);
    if (it == items.end()) return std::nullopt;
    return it->second;
}

// 3. C++23 std::expected 用于明确错误信息
std::expected<Result, Error> risky_operation() {
    // 成功或明确错误
    if (failed) return std::unexpected(Error::Reason);
    return Result{};
}
```

### 资源获取与错误

```cpp
// 构造函数中分配资源，析构函数释放
class Connection {
    ConnectionImpl* impl_;
public:
    Connection(const std::string& url) : impl_(nullptr) {
        impl_ = connect_impl(url);  // 可能抛异常
```

## C++17 std::uncaught_exceptions

```cpp
#include <exception>

// 检测是否有未捕获的异常
class Cleanup {
public:
    ~Cleanup() {
        if (std::uncaught_exceptions() > 0) {
            // 正在栈展开，不要执行清理
            // 否则可能再次抛异常
        }
    }
};

// 区分正常析构和异常析构
class Transaction {
    bool committed_ = false;
public:
    void commit() { committed_ = true; }

    ~Transaction() {
        if (!committed_ && std::uncaught_exceptions() == 0) {
            rollback();  // 安全回滚
        }
    }
};
```
