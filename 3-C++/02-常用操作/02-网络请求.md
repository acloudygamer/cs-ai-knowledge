# 网络请求

**网络请求是通过协议栈将数据从本机传输到远程主机的过程，核心是socket描述符与协议缓冲区的管理。**

## libcurl

**libcurl是Multi-protocol网络传输库，通过easy接口提供同步请求，通过multi接口提供异步请求。**

<pre>
应用 → [libcurl] → [TCP/IP] → 远程主机
</pre>

### GET请求

```cpp
#include <curl/curl.h>
#include <string>

size_t writeCallback(void* p, size_t sz, size_t n, std::string* out) {
    out->append(static_cast<char*>(p), sz * n);
    return sz * n;
}

bool get(const std::string& url, std::string& resp) {
    CURL* c = curl_easy_init();
    curl_easy_setopt(c, CURLOPT_URL, url.c_str());
    curl_easy_setopt(c, CURLOPT_WRITEFUNCTION, writeCallback);
    curl_easy_setopt(c, CURLOPT_WRITEDATA, &resp);
    bool ok = curl_easy_perform(c) == CURLE_OK;
    curl_easy_cleanup(c);
    return ok;
}
```

### POST请求

```cpp
bool post(const std::string& url, const std::string& data, std::string& resp) {
    CURL* c = curl_easy_init();
    curl_easy_setopt(c, CURLOPT_URL, url.c_str());
    curl_easy_setopt(c, CURLOPT_POSTFIELDS, data.c_str());
    curl_easy_setopt(c, CURLOPT_WRITEFUNCTION, writeCallback);
    curl_easy_setopt(c, CURLOPT_WRITEDATA, &resp);
    bool ok = curl_easy_perform(c) == CURLE_OK;
    curl_easy_cleanup(c);
    return ok;
}
```

## Boost.Asio

**Asio是基于Proactor模式的跨平台网络I/O库，通过io_context驱动异步操作，C++20 networking TS以其为核心。**

<pre>
异步操作 → [io_context] → [操作系统异步API] → 完成回调
</pre>

### 同步TCP客户端

```cpp
#include <asio.hpp>

asio::io_context ctx;
asio::ip::tcp::resolver r(ctx);
auto ep = r.resolve("example.com", "http");
asio::ip::tcp::socket s(ctx);
asio::connect(s, ep);
std::string req = "GET / HTTP/1.1\r\nHost: example.com\r\n\r\n";
asio::write(s, asio::buffer(req));
asio::streambuf buf;
asio::error_code ec;
while (asio::read(s, buf, asio::transfer_at_least(1), ec)) {}
```

### 同步TCP服务器

```cpp
#include <asio.hpp>
using asio::ip::tcp;

class Session {
    tcp::socket s_;
    std::array<char, 1024> d_;
public:
    Session(tcp::socket s) : s_(std::move(s)) {}
    void start() {
        asio::async_read_some(s_, asio::buffer(d_),
            [this](auto ec, size_t n) {
                if (!ec) asio::write(s_, asio::buffer(d_, n));
            });
    }
};

asio::io_context ctx;
tcp::acceptor a(ctx, tcp::endpoint(tcp::v4(), 8080));
for (;;) {
    Session s(ctx);
    a.accept(s.s_);
    s.start();
}
```

### UDP服务器

```cpp
#include <asio.hpp>
using asio::ip::udp;

asio::io_context ctx;
udp::socket s(ctx, udp::endpoint(udp::v4(), 8080));
std::array<char, 1024> d;
udp::endpoint ep;
s.async_receive_from(asio::buffer(d), ep,
    [&](auto ec, size_t n) {
        s.send_to(asio::buffer("ACK"), ep);
    });
```

## POSIX socket（Unix/Linux）

**socket是Unix文件描述符向网络领域的扩展，通过文件描述符统一了I/O操作接口。**

> 平台限制：此代码仅适用于Unix/Linux。Windows需使用WinSock API。

### 参考样例

```cpp
int sock = socket(AF_INET, SOCK_STREAM, 0);
struct sockaddr_in srv{};
srv.sin_family = AF_INET;
srv.sin_port = htons(80);
inet_pton(AF_INET, "93.184.216.34", &srv.sin_addr);
connect(sock, (struct sockaddr*)&srv, sizeof(srv));
send(sock, req.data(), req.size(), 0);
close(sock);
```

## Windows WinSock

**WinSock是Windows的网络API，通过WSAStartup初始化，与 POSIX socket语义相似但API不同。**

### 参考样例

```cpp
#include <winsock2.h>
WSADATA w;
WSAStartup(MAKEWORD(2,2), &w);
SOCKET s = socket(AF_INET, SOCK_STREAM, IPPROTO_TCP);
sockaddr_in a{};
a.sin_family = AF_INET;
a.sin_port = htons(80);
inet_pton(AF_INET, "93.184.216.34", &a.sin_addr);
connect(s, (sockaddr*)&a, sizeof(a));
closesocket(s);
WSACleanup();
```
