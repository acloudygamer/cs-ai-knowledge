# 数据库操作

**数据库操作是通过标准化接口将程序数据存入持久化关系结构的过程，核心是SQL语句的执行与结果游标遍历。**

## SQLite3

**SQLite3是进程内嵌的ACID数据库，文件即数据库，无独立服务进程，适合轻量级本地存储。**

<pre>
进程 → [SQLite库] → test.db (文件)
</pre>

### RAII封装

```cpp
#include <sqlite3.h>

class DB {
    sqlite3* db_ = nullptr;
public:
    DB(const std::string& path) {
        sqlite3_open(path.c_str(), &db_);
    }
    ~DB() { if (db_) sqlite3_close(db_); }
    DB(const DB&) = delete;
    DB& operator=(const DB&) = delete;

    void exec(const std::string& sql) {
        char* err = nullptr;
        if (sqlite3_exec(db_, sql.c_str(), nullptr, nullptr, &err) != SQLITE_OK) {
            std::string msg = err ? err : "unknown";
            sqlite3_free(err);
            throw std::runtime_error(msg);
        }
    }

    template<typename F>
    void transaction(F&& fn) {
        exec("BEGIN");
        try {
            fn();
            exec("COMMIT");
        } catch (...) {
            exec("ROLLBACK");
            throw;
        }
    }
};
```

### 参数化查询

```cpp
sqlite3_stmt* stmt = nullptr;
sqlite3_prepare_v2(db_, "INSERT INTO users VALUES (?, ?, ?)", -1, &stmt, nullptr);
sqlite3_bind_text(stmt, 1, "Alice", -1, SQLITE_STATIC);
sqlite3_bind_int(stmt, 2, 30);
if (sqlite3_step(stmt) == SQLITE_DONE) {}
sqlite3_finalize(stmt);
```

## SOCI

**SOCI是连接导向的数据库抽象，通过滑动窗口将SQL结果映射为C++类型，支持同步/异步两种接口。**

### 参考样例

```cpp
#include <soci/soci.h>
#include <soci/sqlite3/soci-sqlite3.h>

soci::session sql(soci::sqlite3, "test.db");
int id = 1;
std::string name;
int age;
sql << "SELECT name, age FROM users WHERE id = :id",
    soci::into(name), soci::into(age), soci::use(id);

soci::rowset<soci::row> rs = (sql.prepare << "SELECT * FROM users");
for (auto& row : rs) {}
```

### 事务处理

```cpp
soci::transaction tr(sql);
sql << "INSERT INTO users VALUES ('Bob')";
sql << "INSERT INTO users VALUES ('Carol')";
tr.commit();
```

## libpqxx

**libpqxx是PostgreSQL的C++客户端，通过结果行随机访问和参数化查询实现安全的数据读写。**

### 参考样例

```cpp
#include <pqxx/pqxx>

pqxx::connection conn("host=localhost port=5432 dbname=test user=u pass=p");
pqxx::work w(conn);
pqxx::row r = w.exec1("INSERT INTO t(name) VALUES ('Alice') RETURNING id");
int new_id = r[0].as<int>();
w.exec("INSERT INTO t(name) VALUES ($1)", pqxx::params("Bob"));
w.commit();
```

### 事务处理

```cpp
pqxx::work w(conn);
w.exec("INSERT INTO t VALUES (1)");
w.exec("INSERT INTO t VALUES (2)");
w.commit();
```

## ORM（Drogon）

**ORM将关系表映射为C++对象，通过元数据描述列与成员的绑定关系，隐藏SQL生成过程。**

### 参考样例

```cpp
class User : public drogon::orm::Model<User> {
public:
    int id;
    std::string name;
    static constexpr const char* TableName = "users";
};

orm::Mapper<User> mapper(app().getDbClient());
mapper.insert(new_user);
auto user = mapper.findByPrimaryKey(1);
mapper.deleteByPrimaryKey(1);
```

## 连接池

**连接池预分配数据库连接队列，使用时借用归还，避免频繁建立TCP连接的overhead。**

### 参考样例

```cpp
soci::connection_pool pool(4);
for (int i = 0; i < 4; ++i)
    pool.at(i).open(soci::sqlite3, "test.db");
{
    soci::session sql(pool);
    sql << "SELECT COUNT(*)";
}
```

## SQL注入防御

**参数化查询将SQL结构与数据值分离，使恶意数据无法突破SQL语法边界。**

### 参考样例

```cpp
sql << "SELECT * FROM users WHERE name = $1", pqxx::params(user_input);
```
