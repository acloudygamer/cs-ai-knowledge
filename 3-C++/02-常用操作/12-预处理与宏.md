# 预处理与宏

预处理在编译之前执行，负责文本替换、条件编译和宏展开。

## 宏基础

### 对象宏

对象宏是简单的文本替换，用于定义常量。

### 参考样例

```cpp
#define MAX_SIZE 100
#define PI 3.14159
#define VERSION "1.0.0"

// 使用
int arr[MAX_SIZE];
```

### 函数宏

函数宏类似函数调用，带参数替换。使用时需注意括号避免展开副作用问题。

### 参考样例

```cpp
#define SQUARE(x) ((x) * (x))
#define MAX(a, b) ((a) > (b) ? (a) : (b))
#define MIN(a, b) ((a) < (b) ? (a) : (b))

// 注意括号：避免展开副作用问题
int y = SQUARE(x++);  // 变成 ((x++) * (x++))，x 被增加两次
```

### 多行宏

do-while(0) 是常见的宏技巧，确保宏像函数一样使用。

### 参考样例

```cpp
#define LOG_ERROR(msg) \
    do { \
        std::cerr << "ERROR: " << msg << std::endl; \
        std::abort(); \
    } while(0)

// 使用 do-while 是常见技巧，确保宏像函数一样使用
```

## 条件编译

### #if / #elif / #else / #endif

条件编译根据条件选择性地编译代码块。

### 参考样例

```cpp
#define DEBUG 1

#if DEBUG == 1
    #define LOG(msg) std::cout << "[DEBUG] " << msg << std::endl
#else
    #define LOG(msg)
#endif

// 数值比较
#if __cplusplus >= 202302L
    // C++23 代码
#elif __cplusplus >= 202002L
    // C++20 代码
#elif __cplusplus >= 201703L
    // C++17 代码
#else
    #error "需要 C++17 或更高版本"
#endif
```

### #ifdef / #ifndef

### 参考样例

```cpp
#define FEATURE_X_ENABLED

#ifdef FEATURE_X_ENABLED
    void feature_x();
#endif

#ifndef DISABLE_LOGGING
    #define ENABLE_LOG 1
#endif
```

### #pragma

#pragma 用于向编译器发出特殊指令。

### 参考样例

```cpp
// 防止头文件重复包含
#pragma once
// 等价于：
// #ifndef HEADER_H
// #define HEADER_H
// #endif

// 警告控制
#pragma GCC diagnostic push
#pragma GCC diagnostic ignored "-Wall"
void dummy_warning_code();
#pragma GCC diagnostic pop

// 结构体对齐
#pragma pack(push, 1)
struct Packed {
    char a;
    int b;
};
#pragma pack(pop)

// 优化提示
#pragma GCC optimize("O3")
void hot_function();
#pragma GCC reset_options
```

## 预定义宏

### 标准预定义宏

### 参考样例

```cpp
__FILE__      // 当前文件名
__LINE__      // 当前行号
__DATE__      // 编译日期 "MMM DD YYYY"
__TIME__      // 编译时间 "HH:MM:SS"
__STDC__      // 是否遵循 ISO C
__STDC_VERSION__  // C 标准版本
__cplusplus   // C++ 标准版本
    // C++11:  201103L
    // C++14:  201402L
    // C++17:  201703L
    // C++20:  202002L
    // C++23:  202302L
```

### 编译器特定宏

### 参考样例

```cpp
// GCC/Clang
__GNUC__              // GCC 主版本
__GNUC_MINOR__        // GCC 次版本
__clang_major__       // Clang 主版本

// MSVC
_MSVC_LANG            // MSVC 的 C++ 标准版本
 _MSC_VER             // MSVC 版本号

// 跨平台检测
#if defined(__GNUC__) || defined(__clang__)
    #define COMPILER_GCC 1
#elif defined(_MSC_VER)
    #define COMPILER_MSVC 1
#endif
```

## 字符串化与连接

### #define 字符串化

# 运算符将宏参数转换为字符串。

### 参考样例

```cpp
#define STRINGIFY(x) #x
#define TO_STRING(x) STRINGIFY(x)

int my_var = 42;
const char* s1 = STRINGIFY(my_var);    // "my_var"
const char* s2 = TO_STRING(my_var);    // "42"
```

### ## 连接符

## 运算符连接两个标记形成新的标识符。

### 参考样例

```cpp
#define CONCAT(a, b) a ## b
#define CONCAT2(a, b) CONCAT(a, b)

int xy = 10;
int result = CONCAT(x, y);  // xy
```

## 可变参数宏（C++11）

`__VA_ARGS__` 表示可变参数，C++20 的 `__VA_OPT__` 可以在有参数时才插入逗号。

### 参考样例

```cpp
#define LOG(fmt, ...) fprintf(stderr, fmt, __VA_ARGS__)
#define LOG(fmt, args...) fprintf(stderr, fmt, ##args)

// C++20  __VA_OPT__
#define LOG(fmt, ...) fprintf(stderr, fmt __VA_OPT__(, ) __VA_ARGS__)
```

## 宏与模板对比

### 宏的优点

- 编译前执行，可用于条件编译
- 可构造无法用模板实现的代码

### 宏的缺点

- 不做类型检查
- 难以调试
- 可能产生意外展开

### 何时用宏

### 参考样例

```cpp
// 1. 条件编译
#if defined(_WIN32)
    #include <windows.h>
#endif

// 2. 编译期断言
#define STATIC_ASSERT(cond) \
    static_assert((cond), #cond)
STATIC_ASSERT(sizeof(int) == 4);

// 3. 头文件保护
#ifndef MY_HEADER_H
#define MY_HEADER_H
// ...
#endif

// 4. 平台特定代码
#if defined(_WIN32)
    #define PATH_SEP '\\'
#else
    #define PATH_SEP '/'
#endif
```

### 何时用模板

### 参考样例

```cpp
// 类型安全、可维护的代码用模板
template<typename T>
T max(T a, T b) {
    return a > b ? a : b;
}

// 编译期计算的代码用 constexpr
constexpr int factorial(int n) {
    return n <= 1 ? 1 : n * factorial(n - 1);
}
```

## 宏调试技巧

### 参考样例

```cpp
// 展开宏查看实际代码
#define SHOW_EXPANSION(x) cout << #x << " = " << (x) << endl;

int arr[10];
int i = 5;
SHOW_EXPANSION(arr[i++]);  // 输出: arr[i++] = 6（i 被增加一次）
```

## 防止宏污染

### 参考样例

```cpp
// 1. 用命名空间包裹宏（C++11）
namespace details {
    #define private_func() /* ... */
}

// 2. 短生命周期
#define DISABLE_WARNING _Pragma("GCC diagnostic push") \
    _Pragma("GCC diagnostic ignored \"-Wall\"")

DISABLE_WARNING
void code() {}

#define ENABLE_WARNING _Pragma("GCC diagnostic pop")

// 3. 优先使用 constexpr/inline
constexpr int MAX_SIZE = 100;  // 优于 #define MAX_SIZE 100
inline int square(int x) { return x * x; }  // 优于 #define SQUARE(x)
```

## _Pragma 操作符

### 参考样例

```cpp
// 等价于 #pragma，但可以用于宏中
#define PRAGMA(x) _Pragma(#x)

PRAGMA(GCC diagnostic push)
PRAGMA(GCC diagnostic ignored "-Wall")
void warning_code() {}
PRAGMA(GCC diagnostic pop)
```

## 宏与 assert

### 参考样例

```cpp
#include <cassert>

// 标准 assert
assert(ptr != nullptr);

// 自定义 assert 宏
#ifdef DEBUG
    #define ASSERT(cond, msg) \
        if (!(cond)) { \
            std::cerr << "Assertion failed: " << #cond \
                      << " in " << __FILE__ << ":" << __LINE__ \
                      << " - " << msg << std::endl; \
            std::abort(); \
        }
#else
    #define ASSERT(cond, msg)
#endif
```

## 条件编译实战

### 参考样例

```cpp
// 调试/发布模式
#ifdef NDEBUG
    #define DEBUG_LOG(msg)
#else
    #define DEBUG_LOG(msg) std::cout << __FILE__ << ":" << __LINE__ << " " << msg << std::endl
#endif

// 公共 API 导出
#if defined(_WIN32) || defined(__CYGWIN__)
    #ifdef MYLIB_EXPORTS
        #define MYLIB_API __declspec(dllexport)
    #else
        #define MYLIB_API __declspec(dllimport)
    #endif
#else
    #define MYLIB_API __attribute__((visibility("default")))
#endif

// 功能开关
#define ENABLE_FEATURE_X 1
#define ENABLE_FEATURE_Y 0

#if ENABLE_FEATURE_X
    void feature_x() {}
#endif
```
