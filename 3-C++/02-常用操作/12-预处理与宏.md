# 预处理与宏

**预处理是编译前期的文本替换阶段，宏是文本替换的符号标记，条件编译使代码块根据编译期条件选择性地参与编译。**

## 宏基础

**对象宏是简单文本替换，函数宏通过参数实现参数化替换，do-while(0)确保宏在if-else中行为与函数一致。**

<pre>
#define MAX 100 → 文本替换
#define SQUARE(x) ((x)*(x)) → 参数化替换
#define LOG() do {} while(0) → 语句形式
</pre>

### 参考样例

```cpp
#define PI 3.14159
#define SQUARE(x) ((x) * (x))

int a = SQUARE(5);
int b = SQUARE(x++);
```

## 条件编译

**#if/#elif/#else根据宏值选择分支，#ifdef检测宏是否定义，__cplusplus是C++标准版本预定义宏。**

### 参考样例

```cpp
#if __cplusplus >= 202002L
    // C++20
#elif __cplusplus >= 201703L
    // C++17
#endif

#ifdef DEBUG
    #define LOG(msg)
#endif
```

## 预定义宏

**__FILE__/__LINE__/__DATE__/__TIME__是编译器提供的元信息，用于日志和断言。**

```cpp
__FILE__
__LINE__
__DATE__
__TIME__
__cplusplus  // 201703L(C++17), 202002L(C++20)
```

## 字符串化与连接

**#将宏参数转为字符串，##连接两个标记形成新标识符。**

```cpp
#define STRINGIFY(x) #x
#define CONCAT(a, b) a ## b

STRINGIFY(test)  // "test"
CONCAT(x, y)     // xy
```

## 可变参数宏

**__VA_ARGS__表示可变参数，__VA_OPT__(, )在C++20中仅在有参数时插入逗号。**

```cpp
#define LOG(fmt, ...) fprintf(stderr, fmt, __VA_ARGS__)
#define LOG(fmt, ...) fprintf(stderr, fmt __VA_OPT__(, ) __VA_ARGS__)
```

## 何时用宏

**条件编译、平台检测、无法用模板实现的代码用宏；类型安全代码用模板和constexpr。**

| 场景 | 方案 |
|------|------|
| 条件编译 | #if/#ifdef |
| 平台检测 | 预定义宏 |
| 编译期断言 | static_assert |
| 类型安全 | template/constexpr |
