# 序列化

序列化是将数据结构或对象转换为可存储/传输格式的过程。反序列化是序列化的逆过程。

## 基础概念

序列化：对象 -> 字节流
反序列化：字节流 -> 对象

## JSON 序列化

### nlohmann/json（C++17）

nlohmann/json 提供直观的 API 进行 JSON 序列化与反序列化。

### 参考样例

```cpp
#include <nlohmann/json.hpp>
using json = nlohmann::json;

// 序列化
json j;
j["name"] = "Alice";
j["age"] = 30;
j["scores"] = {85, 92, 78};

std::string serialized = j.dump();  // JSON 字符串
std::string pretty = j.dump(2);     // 格式化

// 反序列化
json parsed = json::parse(serialized);
std::string name = parsed["name"];
int age = parsed["age"];

// 容器序列化
std::map<std::string, int> scores = parsed["scores"];
```

### 复杂对象序列化

通过定义 `to_json` 和 `from_json` 函数实现自定义类型序列化。

### 参考样例

```cpp
#include <nlohmann/json.hpp>

class Person {
public:
    std::string name;
    int age;
    std::vector<int> scores;

    // 序列化到 JSON
    void to_json(json& j) const {
        j = json{{"name", name}, {"age", age}, {"scores", scores}};
    }

    // 从 JSON 反序列化
    void from_json(const json& j) {
        name = j.at("name").get<std::string>();
        age = j.at("age").get<int>();
        scores = j.at("scores").get<std::vector<int>>();
    }
};

Person p{"Bob", 25, {90, 85, 88}};
json j = p;  // 调用 to_json
Person p2 = j.get<Person>();  // 调用 from_json
```

## 二进制序列化

### 手动序列化

手动序列化需要处理类型大小、字节序和字符串长度前缀。

### 参考样例

```cpp
#include <fstream>
#include <vector>
#include <cstdint>

class DataPacket {
public:
    uint32_t id;
    float value;
    std::string name;

    // 序列化
    std::vector<uint8_t> serialize() const {
        std::vector<uint8_t> data;
        // 写入 ID（4 字节）
        data.insert(data.end(),
            reinterpret_cast<const uint8_t*>(&id),
            reinterpret_cast<const uint8_t*>(&id) + sizeof(id));
        // 写入 value（4 字节）
        data.insert(data.end(),
            reinterpret_cast<const uint8_t*>(&value),
            reinterpret_cast<const uint8_t*>(&value) + sizeof(value));
        // 写入 name（长度前缀 + 内容）
        uint32_t name_len = name.size();
        data.insert(data.end(),
            reinterpret_cast<const uint8_t*>(&name_len),
            reinterpret_cast<const uint8_t*>(&name_len) + sizeof(name_len));
        data.insert(data.end(), name.begin(), name.end());
        return data;
    }

    // 反序列化
    void deserialize(const std::vector<uint8_t>& data) {
        size_t pos = 0;
        std::memcpy(&id, &data[pos], sizeof(id));
        pos += sizeof(id);
        std::memcpy(&value, &data[pos], sizeof(value));
        pos += sizeof(value);
        std::memcpy(&name_len, &data[pos], sizeof(name_len));
        pos += sizeof(name_len);
        name = std::string(data.begin() + pos, data.begin() + pos + name_len);
    }
};
```

### 字节序处理

跨平台序列化时需要处理字节序（大小端）问题。

### 参考样例

```cpp
#include <cstdint>
#include <arpa/inet.h>  // Linux
// #include <winsock2.h>  // Windows

uint32_t htonl(uint32_t hostlong);  // 主机序 -> 网络序
uint32_t ntohl(uint32_t netlong);  // 网络序 -> 主机序

// 跨平台序列化时需要处理字节序
class NetworkPacket {
    uint32_t id_;
    uint16_t port_;

public:
    std::vector<uint8_t> serialize() const {
        std::vector<uint8_t> data;
        uint32_t id_net = htonl(id_);
        uint16_t port_net = htons(port_);
        data.insert(data.end(),
            reinterpret_cast<uint8_t*>(&id_net),
            reinterpret_cast<uint8_t*>(&id_net) + sizeof(id_net));
        data.insert(data.end(),
            reinterpret_cast<uint8_t*>(&port_net),
            reinterpret_cast<uint8_t*>(&port_net) + sizeof(port_net));
        return data;
    }
};
```

## Protocol Buffers

Protocol Buffers 是 Google 的跨语言序列化协议，比 JSON 更紧凑，支持版本控制。

### .proto 定义

### 参考样例

```protobuf
// person.proto
syntax = "proto3";

message Person {
    string name = 1;
    int32 age = 2;
    repeated int32 scores = 3;
    EmailType email_type = 4;
}

enum EmailType {
    PERSONAL = 0;
    WORK = 1;
}
```

### C++ 使用

### 参考样例

```bash
# 安装 protoc
# 编译 proto 文件
protoc --cpp_out=. person.proto
```

```cpp
#include "person.pb.h"

// 序列化
Person person;
person.set_name("Alice");
person.set_age(30);
person.add_scores(85);
person.add_scores(92);

std::string bytes = person.SerializeAsString();

// 反序列化
Person parsed;
parsed.ParseFromString(bytes);

std::cout << parsed.name() << std::endl;  // Alice
```

## Boost Serialization

Boost Serialization 支持多种归档格式，包括文本、二进制和 XML。

### 参考样例

```cpp
#include <boost/archive/text_oarchive.hpp>
#include <boost/archive/text_iarchive.hpp>
#include <boost/serialization/vector.hpp>
#include <fstream>

class Data {
    friend class boost::serialization::access;

    template<class Archive>
    void serialize(Archive& ar, const unsigned int version) {
        ar & id & name & values;
    }

public:
    int id;
    std::string name;
    std::vector<double> values;
};

// 序列化
{
    std::ofstream ofs("data.txt");
    boost::archive::text_oarchive oa(ofs);
    Data d{1, "test", {1.0, 2.0, 3.0}};
    oa << d;
}

// 反序列化
{
    std::ifstream ifs("data.txt");
    boost::archive::text_iarchive ia(ifs);
    Data d;
    ia >> d;
}
```

## C++17 文件操作

### 简单二进制序列化

### 参考样例

```cpp
#include <fstream>
#include <vector>

class Serializer {
public:
    template<typename T>
    static void write(std::ostream& os, const T& value) {
        os.write(reinterpret_cast<const char*>(&value), sizeof(T));
    }

    static void write_string(std::ostream& os, const std::string& s) {
        uint32_t len = s.size();
        write(os, len);
        os.write(s.data(), len);
    }

    template<typename T>
    static T read(std::istream& is) {
        T value;
        is.read(reinterpret_cast<char*>(&value), sizeof(T));
        return value;
    }

    static std::string read_string(std::istream& is) {
        uint32_t len = read<uint32_t>(is);
        std::string s(len, '\0');
        is.read(s.data(), len);
        return s;
    }
};

// 使用
std::ofstream of("data.bin", std::ios::binary);
Serializer::write(of, 42);
Serializer::write_string(of, "hello");
of.close();

std::ifstream is("data.bin", std::ios::binary);
int x = Serializer::read<int>(is);
std::string s = Serializer::read_string(is);
```

## 版本控制

序列化时写入版本号，反序列化时根据版本处理兼容性问题。

### 参考样例

```cpp
class VersionedData {
    int version_ = 1;  // 当前版本
public:
    int id;
    int legacy_field;  // v1 字段

    // v2 新增字段
    std::string new_field;

    // 序列化时写入版本
    void serialize(std::ostream& os) const {
        write_string(os, "V1");  // 魔数
        write(os, version_);
        write(os, id);
        write(os, legacy_field);
        write_string(os, new_field);
    }

    // 反序列化时根据版本处理
    void deserialize(std::istream& is) {
        std::string magic = read_string(is);
        if (magic != "V1") throw std::runtime_error("Invalid format");

        int ver = read<int>(is);
        id = read<int>(is);
        legacy_field = read<int>(is);

        if (ver >= 2) {
            new_field = read_string(is);
        }
    }
};
```

## 错误处理

### 参考样例

```cpp
class SerializationError : public std::runtime_error {
public:
    enum class Code { InvalidFormat, VersionMismatch, IOError };
    SerializationError(Code code, const std::string& msg)
        : std::runtime_error(msg), code_(code) {}
    Code code() const { return code_; }
private:
    Code code_;
};

void safe_load(const std::string& path) {
    std::ifstream is(path, std::ios::binary);
    if (!is) {
        throw SerializationError(
            SerializationError::Code::IOError,
            "Cannot open file: " + path);
    }

    try {
        Data d;
        d.deserialize(is);
    } catch (const SerializationError& e) {
        // 处理序列化特定错误
        std::cerr << "Serialization error: " << e.what() << std::endl;
    }
}
```

## 序列化库对比

| 库 | 格式 | 优点 | 缺点 |
|----|------|------|------|
| nlohmann/json | JSON | 人类可读、C++17 | 体积较大 |
| protobuf | 二进制 | 跨语言、版本控制 | 需要编译 |
| boost::serialization | 多格式 | 功能全面 | 依赖 boost |
| msgpack | 二进制 | 小巧快速 | 需要定义 |
| cap'nproto | 二进制 | 零拷贝 | 生态较小 |

## 选择建议

- 配置文件：JSON（人类可读）
- 网络通信：Protocol Buffers 或 MessagePack（跨语言、紧凑）
- 持久化存储：二进制序列化（高性能）
- 调试：Boost 文本归档（可读）
