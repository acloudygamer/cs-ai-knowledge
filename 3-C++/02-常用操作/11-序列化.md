# 序列化

**序列化是将C++对象转换为可存储/传输字节流的过程，反序列化是其逆过程，核心问题是类型描述与字节序的跨平台一致性。**

## 核心概念

**序列化本质是对象结构到线性字节序列的映射，反序列化是字节序列到对象结构的重建。**

<pre>
C++对象 → [序列化] → 字节序列 → [存储/传输]
字节序列 → [反序列化] → C++对象
</pre>

## JSON序列化

**JSON序列化将C++对象转换为文本格式，人类可读但体积较大，适合配置文件。**

### 参考样例

```cpp
#include <nlohmann/json.hpp>
using json = nlohmann::json;

json j;
j["name"] = "Alice";
j["age"] = 30;
std::string s = j.dump();
json p = json::parse(s);
```

## 二进制序列化

**二进制序列化通过固定偏移或长度前缀描述结构，体积小但跨平台需处理字节序。**

### 字节序处理

```cpp
uint32_t htonl(uint32_t x);
uint32_t ntohl(uint32_t x);
uint16_t htons(uint16_t x);
```

### 参考样例

```cpp
std::vector<uint8_t> serialize(const Person& p) {
    std::vector<uint8_t> v;
    uint32_t id_net = htonl(p.id);
    v.insert(v.end(), (uint8_t*)&id_net, (uint8_t*)&id_net + 4);
    uint32_t len = p.name.size();
    v.insert(v.end(), (uint8_t*)&len, (uint8_t*)&len + 4);
    v.insert(v.end(), p.name.begin(), p.name.end());
    return v;
}
```

## Protocol Buffers

**Protobuf是Google的跨语言二进制序列化协议，通过.proto定义消息结构，编译器生成序列化代码，支持版本向前兼容。**

### 参考样例

```protobuf
message Person {
    string name = 1;
    int32 age = 2;
}
```

```cpp
Person p;
p.set_name("Alice");
p.set_age(30);
std::string bytes = p.SerializeAsString();
Person p2;
p2.ParseFromString(bytes);
```

## 版本控制

**序列化时写入版本号，反序列化时根据版本选择解析路径，是向前兼容的核心机制。**

```cpp
void serialize(std::ostream& os) const {
    write(os, version_);
    write(os, id);
    if (version_ >= 2) write(os, new_field);
}
```

## 库对比

| 库 | 格式 | 适用场景 |
|----|------|---------|
| nlohmann/json | 文本 | 配置文件 |
| protobuf | 二进制 | 跨语言通信 |
| boost::serialization | 多格式 | Boost生态 |
| msgpack | 二进制 | 高性能 |
