# 03-字符串与格式化

> 前置：[01-容器](01-容器.md)（`string` 是连续族的特化） · 后续：[04-时间与日期](04-时间与日期.md)、[01-文件操作](../03-IO与外部世界/01-文件操作.md)（格式化输出落进 IO 流）

> **版本基准**：C++20；C++23/26 特性行内标注。示例实测环境：GCC 14.2（MinGW-w64），`-std=c++20`。

字符串处理在 C++ 里被拆成两个角色：**拥有者**（`std::string`，一块会增长的字符内存）与**观察者**（`std::string_view`，指针+长度的只读借用）。格式化则是第三个角色：把值渲染成文本，从类型不安全的 `printf` 演进到编译期检查格式串的 `std::format`（C++20）。本篇按这三件东西的所有权边界与职责边界展开。

## 本质

- `std::string` 是连续字符容器（内存布局同 `vector<char>`，见 [01-容器](01-容器.md)），拥有并管理字符内存，支持增删改。
- `std::string_view` 是 `(const char*, size_t)` 的二元组，**非拥有**：不分配、不释放、不拷贝，只是把一段已存在的字符内存描述出来。它的存在理由是一笔资源账：纯读取的字符串处理（切分、查找、前后缀判断）按 `const std::string&` 传参也能零拷贝，但 `string_view` 还能指向字面量、数组、子串，而不强求来源必须是 `string`。
- `std::format`（C++20）把格式化从"运行期解析 `%` 占位符、按调用约定裸读参数栈"（printf 的未定义行为温床）改写为"编译期解析 `{}` 占位符、类型检查每个参数"。

## 机制

### string 与 SSO：小字符串优化

`string` 的对象内放三样东西：指向字符的指针、size、以及一个 union——要么是 capacity，要么是一块**内嵌字符缓冲区**。短字符串直接驻进对象内部，不碰堆；超阈值才分配堆内存。这就是 SSO（Small String Optimization，小字符串优化），其存在理由是分配账：短字符串极高频，而一次堆分配的代价（百纳秒级）远超 16 字节的内嵌空间。

实测锚点（GCC 14.2 libstdc++，x86-64）：`sizeof(std::string) == 32`；**容量 15 字符以内驻对象，16 字符起落堆**（内嵌缓冲区 16 字节，末尾留给 `\0`）。MSVC 口径为 32 字节对象、阈值同为 15；libc++（Clang）为 24 字节、阈值 22。阈值是实现细节，不是标准承诺——纪律是**别依赖具体阈值**，把它当纯优化。

### string_view：零拷贝视图与悬垂陷阱

`string_view` 的全部机制是切片：`substr(pos, n)` 返回 `(ptr+pos, n)`， $O(1)$，不拷贝一个字符。函数签名用它做参数，等于声明"我只读、不持有"。

非拥有的对价是**生命周期责任归调用者**。典型陷阱：

```cpp
std::string_view bad = std::string("tmp");   // 临时 string 语句结束即析构，bad 悬垂
```

`string_view` 不延长临时对象的生命周期（C++ 的临时生命周期延长只认直接绑定到引用）。返回 `string_view` 的函数同样危险：视图指向的内存一死，视图就是野指针的薄包装。规则与迭代器失效同源：视图有效性跟随底层数据，底层变了、死了，凭证作废。

### std::format（C++20）：编译期检查的格式化

格式语法：`std::format("{:>8}|{:.2f}|{:#x}", 42, 3.14159, 255)` → `"      42|3.14|0xff"`。`{}` 内是替换域，冒号后依次为填充对齐、符号、宽度、精度、类型说明符（`d`/`x`/`f`/`e`/`s` 等），`{{` 转义字面花括号。

与 `printf` 的分野在检查时机：`std::format` 的格式串参数类型是 `consteval` 构造的 `basic_format_string`，**字面量格式串在编译期解析并逐参数做类型匹配**——`std::format("{:d}", "x")` 直接编译失败（GCC 14.2 实测），而 `printf("%d", "x")` 是静默的未定义行为。运行期格式串走 `std::runtime_format`（C++26 正式名，GCC 14 已提供），退回到运行期抛 `format_error`。

自定义类型可特化 `std::formatter`（实现 `parse` + `format` 两个成员）接入同一套语法。

（C++23 增量）`std::print` / `std::println` 把 `format` 直接接到 stdout，省去 `std::cout <<` 的中转。平台注意：GCC 14.2 MinGW 下 `<print>` 可编译，但默认链接缺终端支持符号（`std::__open_terminal`），需追加 `-lstdc++exp` 方可运行（已实测）；MSVC/Clang 主流通行版无此坑。

### to_string/stoi 一族：定位是"够用就好的窄桥"

`std::to_string(42)`、`std::stoi("42")`、`stod`、`stol`……是 C 时代 `sprintf`/`atoi` 的最小安全化包装：只支持最朴素的十进制互转，`stoi` 遇非法输入抛 `invalid_argument`/`out_of_range`。定位明确：**单个数值的朴素互转用它，任何带格式（对齐、进制、精度、多值拼接）的需求上 `format`**。追求极限性能的解析（如 JSON 数字）则用 `std::from_chars`/`to_chars`（C++17，无分配、无异常、无 locale）。

## 连接

| 需求 | 选 |
|---|---|
| 拥有、修改、传递字符串 | `std::string` |
| 只读参数、切片、解析视图 | `std::string_view`（调用者担保生命周期） |
| 单值朴素互转 | `to_string` / `stoi` 一族 |
| 带格式文本生成 | `std::format`；直出终端用 `std::print`（C++23 增量） |
| 极限性能数值解析 | `from_chars` / `to_chars` |

- `string` 的连续布局与扩容账同 `vector`，见 [01-容器](01-容器.md)。
- `format` 的输出最终落进流或终端，与 IO 层的衔接见 [01-文件操作](../03-IO与外部世界/01-文件操作.md)。
- `string_view` 的生命周期纪律与悬垂的一般原理，见 [04-类与资源管理](../01-语言核心/04-类与资源管理.md)。

## 示例

（GCC 14.2 MinGW 实测，`-std=c++20`）

```cpp
#include <string>
#include <string_view>
#include <format>
#include <iostream>
#include <cstdint>

bool sso(const std::string& s) {   // 数据指针落在对象内部 → SSO 生效
    auto p = reinterpret_cast<std::uintptr_t>(s.data());
    auto b = reinterpret_cast<std::uintptr_t>(&s);
    return p >= b && p < b + sizeof(s);
}

std::string_view ext_of(std::string_view path) {   // 视图进、视图出，零拷贝
    auto pos = path.find_last_of('.');
    return pos == std::string_view::npos ? "" : path.substr(pos);
}

int main() {
    std::cout << sizeof(std::string) << '\n';        // 32（libstdc++）
    std::string a(15, 'x'), b(16, 'x');
    std::cout << sso(a) << sso(b) << '\n';           // 10：15 驻对象，16 落堆

    std::string path = "a/b/main.cpp";
    std::cout << ext_of(path) << '\n';               // .cpp
    // 反例：std::string_view bad = std::string("tmp");  // 语句结束即悬垂

    std::cout << std::format("[{:>6}|{:.2f}|{:#x}]", 42, 3.14159, 255) << '\n';
    // [    42|3.14|0xff]；格式串编译期检查，"{:d}" 配字符串直接编译失败

    int n = std::stoi("42");                          // 朴素互转一族
    std::cout << std::to_string(n + 1) << '\n';       // 43
}
```
