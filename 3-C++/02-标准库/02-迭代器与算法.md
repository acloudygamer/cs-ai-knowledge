# 02-迭代器与算法

> 前置：[01-容器](01-容器.md)（容器按内存布局分族，迭代器是它们交出的唯一接口） · 后续：[03-字符串与格式化](03-字符串与格式化.md)

> **版本基准**：C++20；C++23/26 特性行内标注。示例实测环境：GCC 14.2（MinGW-w64），`-std=c++20`；动态链接因环境 DLL 冲突加载失败（exit 127）时，加 `-static` 静态链接。

STL 的结构性决策只有一条：**容器与算法互不直接认识，全靠迭代器接头**。容器负责摆放元素（[01-容器](01-容器.md)），算法负责描述操作（排序、查找、变换），迭代器夹在中间，既暴露元素又声明能力。这条接头的回报是组合数： $M$ 种容器 × $N$ 种算法，不用写 $M \times N$ 份代码，只要容器给出的迭代器满足算法声明的能力下限。

## 本质

迭代器（iterator）是"指向元素位置的凭证"的抽象：对外提供解引用（`*`）、前进（`++`）、比较（`==`），对内封装容器的物理布局——`vector` 的迭代器包一个裸指针，`list` 的包节点指针，`map` 的包红黑树节点。**能力不是等价的**：链表的迭代器给不出 $O(1)$ 的 `+n`，哈希表给不出有序遍历。于是迭代器按能力分档，算法按所需最低档位提要求，编译器在编译期撮合两者。

## 机制

### 能力六档：算法分派的依据

| 档位 | 必备操作 | 能伺候的算法（举例） | 谁提供 |
|---|---|---|---|
| 输入 | `*`（读）、`++`、单遍 | `find`、`accumulate` | `istream_iterator` |
| 输出 | `*`（写）、`++`、单遍 | `copy` 的目的端 | `back_insert_iterator` |
| 前向 | 多读多写、可多遍 | `replace`、`binary_search` | `forward_list`、哈希族 |
| 双向 | 加 `--` | `reverse` | `list`、`map`/`set` |
| 随机访问 | 加 `+`、`-`、`[]`、距离 $O(1)$ | `sort`、`nth_element` | `vector`、`deque`、`array` |
| 连续（contiguous，C++20） | 加内存连续性：元素紧邻如数组 | 可与 C API 零拷贝对接 | `vector`、`array`、`string` |

分派在编译期完成：C++20 起算法用概念（`std::random_access_iterator` 等，机制见 [06-模板与Concepts](../01-语言核心/06-模板与Concepts.md)）约束形参，档位不够直接报"约束不满足"，替代了旧式模板错误的长串嵌套。有些算法还按档位选实现：`std::distance` 对随机访问迭代器是 $O(1)$ 的减法，对前向迭代器退化为 $O(n)$ 的逐次 `++`——同一个名字，按能力付不同的账。

### 常用算法族与复杂度账

- **查找**：`find`（线性 $O(n)$，任何档位）；有序区间上 `lower_bound`/`upper_bound`/`binary_search`（二分 $O(\log n)$，要求随机访问才有意义——`list` 上二分查找的"折半"本身就要 $O(n)$ 走路）。
- **排序**：`sort` $O(n \log n)$——实现为 introsort（内省排序）：快排主体，递归深度超 $2\lfloor\log_2 n\rfloor$ 转堆排防最坏情况，小区间转插入排序省常数。比较排序有信息论下界： $n!$ 种排列靠二元比较区分至少要 $\lceil \log_2 n! \rceil = \Omega(n \log n)$ 次比较，这个账没人能赖掉。`stable_sort` 加保序（多付内存），`nth_element` 只要第 $k$ 名就位、线性 $O(n)$。
- **变换**：`transform`、`for_each` $O(n)$；`copy_if` 配 `back_inserter`（写迭代器代理为 `push_back`）增容。
- **数值**：`accumulate`、`inner_product`、`reduce`（C++17，不保证累加顺序——为并行让路）。

### erase-remove 惯用法与 C++20 的收编

通用算法碰不到容器的内存，`remove_if` 能做的只是把"要留的"元素前移、返回新逻辑末尾， $O(n)$ 原地完成；真正的析构与缩容必须由容器自己的 `erase` 收尾：

```cpp
v.erase(std::remove_if(v.begin(), v.end(), pred), v.end());
```

两步分离的原因是算法-容器解耦的代价。C++20 把这对组合拳收编为成员级自由函数：`std::erase_if(v, pred)`（对 `vector`/`deque`/`list` 等）、`std::erase(v, value)` 一步完成，等价语义。新代码直接用后者。

### execution 并行策略（C++17）

多数算法接受第一参数 `std::execution::seq` / `par` / `par_unseq`：`par` 允许线程级并行，`par_unseq` 再加 SIMD 向量化。约束随之转移给调用者：传入的操作函数不得有数据竞争，`par_unseq` 下不得用任何同步原语（向量化交错下锁会死锁）。注意实现现实：libstdc++ 的并行后端依赖 Intel TBB，MinGW 环境未装 TBB 时 `par` **静默退化为串行**（GCC 14.2 MinGW 实测：能编译运行、结果正确，但无并行加速）——要真并行需自行链接 TBB。

### Ranges（C++20）：从迭代器对到惰性管道

Ranges 做了三件事：

1. **把 `[begin, end)` 合成一个对象**（range），算法直接吃容器：`std::ranges::sort(v)` 替代 `std::sort(v.begin(), v.end())`。
2. **视图（view）惰性组合**：`filter`/`transform`/`take` 等适配器不产中间容器，管道 `v | filter(p) | transform(f)` 只是一张"待执行计划"，迭代时才逐元素流过整条链—— $O(1)$ 额外内存。
3. **投影（projection）**：算法多收一个成员指针/变换，`std::ranges::sort(users, {}, &User::age)` 直接按成员排序，省掉手写 lambda。

视图持有的是引用不是拷贝：底层容器在视图存活期间被结构性修改，视图随之失效——与迭代器失效同一套规则（[01-容器](01-容器.md)）。（C++23 增量）`std::ranges::to<std::vector>()` 把管道结果一步落成容器；C++20 的等价写法是 `std::ranges::copy(pipe, std::back_inserter(v))`。

## 示例

（GCC 14.2 MinGW 实测，`-std=c++20`）

```cpp
#include <algorithm>
#include <ranges>
#include <vector>
#include <string>
#include <iostream>

struct User { std::string name; int age; };

int main() {
    std::vector<int> v{5, 2, 8, 1, 9, 3};

    std::ranges::sort(v);                       // introsort，O(n log n)
    for (int x : v) std::cout << x;             // 123589
    std::cout << '\n';

    // 有序区间二分：第一个不小于 4 的元素
    std::cout << *std::ranges::lower_bound(v, 4) << '\n';   // 5

    // C++20：erase_if 一步替代 erase-remove 惯用法
    std::erase_if(v, [](int x) { return x % 2 == 0; });
    for (int x : v) std::cout << x;             // 1359
    std::cout << '\n';

    // Ranges 惰性管道：无中间容器，迭代时才逐元素计算
    auto r = v | std::views::filter([](int x) { return x > 2; })
               | std::views::transform([](int x) { return x * 10; });
    for (int x : r) std::cout << x << ' ';      // 30 50 90
    std::cout << '\n';

    // projection：按成员排序，不必手写 lambda
    std::vector<User> us{{"ann", 30}, {"bob", 20}, {"cid", 25}};
    std::ranges::sort(us, {}, &User::age);
    std::cout << us[0].name << us[2].name << '\n';          // bobann
}
```
