# 04-时间与日期

> 前置：[03-字符串与格式化](03-字符串与格式化.md)（时间值的文本化走 `std::format`） · 后续：[05-并发与协程](05-并发与协程.md)（`sleep_for`/`wait_for` 的时长参数就是本篇的 duration）

> **版本基准**：C++20；C++23/26 特性行内标注。示例实测环境：GCC 14.2（MinGW-w64），`-std=c++20`；动态链接因环境 DLL 冲突加载失败（exit 127）时，加 `-static` 静态链接。

`<chrono>` 解决的是一个类型系统问题：时间单位混算是 C 时代 `time_t` 的经典事故源（秒当毫秒传），而换算本身只是乘除法——**让类型系统把单位钉死在编译期**。C++20 在其上加了日历与时区，把 chrono 从"计时工具"扩成"日期库"。

## 本质

chrono 的全部机制由三个角色构成：

- **时长（duration）**：`count × period`，一个数值（rep）配一个编译期单位（`std::ratio`，如 `milliseconds = ratio<1,1000>` 秒）。单位是类型的一部分。
- **时钟（clock）**：时长的来源，定义纪元（epoch）与 `now()`。标准是三种：`system_clock`（日历钟，纪元为 1970-01-01 UTC）、`steady_clock`（单调钟，纪元未指定，只保证不倒退）、`high_resolution_clock`（通常是前两者之一的别名）。
- **时点（time_point）**：`时钟纪元 + duration`，绑定在具体时钟上——不同时钟的 time_point 是不同类型，混用在编译期就报错。

## 机制

### 强类型换算：无损隐式，有损显式

duration 之间的换算规则一条：**不丢精度的方向隐式放行**（`seconds`→`milliseconds`），**可能丢精度的方向必须 `duration_cast`**（`milliseconds{1500}`→`seconds` 得显式截断）。运算同理：`tp2 - tp1` 得 duration，`tp + dur` 得 time_point，`dur / dur` 得无量纲比值——类型把量纲分析做完了。

`steady` 与 `system` 的分工由物理性质钉死：`system_clock` 会被对时（NTP 校时、管理员改时间）拨动，前后两次 `now()` 的差可能为负；`steady_clock` 单调不减。**量耗时用 steady，对人类报时刻用 system**——拿 system_clock 掐表，一次 NTP 跳变就能让"耗时"变成负 300 毫秒。

### C++20 日历：字段型与计数型两层

日期有两种表示，各自服务一种操作：

- **字段型** `year_month_day`（及 `2024y/1/15` 字面语法）：年、月、日三个字段，适合构造与按字段读取；
- **计数型** `sys_days`：从纪元起的天数计数（本质是天精度的 time_point），适合算术——两个日期相减得天数、加 `days{7}` 得下周。

两层之间直接互转（`sys_days{ymd}`、`year_month_day{sd}`），换算算法（Civil 历算法）摊平闰年规则。`weekday`、`month_weekday` 等类型解决"这天星期几""本月第三个周五"这类日历问题，答案都由 `sys_days` 的整数模运算得出。

### C++20 时区：tzdb 查表

`zoned_time{"Asia/Tokyo", sys_time}` = 时点 + 时区名。时区规则（固定偏移 + 夏令时历史分段）来自 IANA tzdb 数据库，换算即查表：按 UTC 时点在时区的规则时间线上定位区间，取该区间的偏移。所以时区转换的正确性依赖**数据库新鲜度**（各国夏令时政策会变），而不是算法。平台现实：GCC 14.2 MinGW 实测 `zoned_time` 与 `std::format` 时区格式化均可用；若目标平台缺 tzdb（部分老工具链），`locate_zone` 会抛异常，须按平台文档核对。

### 与 IO 的接口

chrono 类型直接接入 `std::format`：`{:...}` 内写 `strftime` 风格指令（`%Y-%m-%d %H:%M:%S`），`system_clock::time_point`、`sys_days`、`zoned_time` 都有对应 `formatter` 特化（GCC 14.2 实测）。反向解析用 `std::chrono::from_stream`（或 `parse`）。流的接线细节见 [01-文件操作](../03-IO与外部世界/01-文件操作.md)。

## 连接

- 时长是并发原语的超时参数：`sleep_for`、`cv.wait_for`、`fut.wait_until` 全部收 duration/time_point，见 [05-并发与协程](05-并发与协程.md)。
- 文本化走 [03-字符串与格式化](03-字符串与格式化.md) 的 format 体系。
- 时钟的硬件来源（TSC、HPET、OS 时钟中断）见 [0-计算机基础](../../0-计算机基础/README.md)。

## 示例

（GCC 14.2 MinGW 实测，`-std=c++20`）

```cpp
#include <chrono>
#include <format>
#include <iostream>
#include <thread>
using namespace std::chrono;

int main() {
    // duration 强类型换算：无损隐式，有损必须显式 cast
    milliseconds ms{1500};
    seconds s = duration_cast<seconds>(ms);          // 显式截断
    std::cout << s.count() << '\n';                  // 1
    std::cout << milliseconds{s}.count() << '\n';    // 1000（无损方向隐式）

    // 掐表用 steady_clock：单调，NTP 跳变伤不到它
    auto t0 = steady_clock::now();
    std::this_thread::sleep_for(2ms);
    std::cout << duration_cast<microseconds>(steady_clock::now() - t0).count()
              << "us\n";                             // 实测约 2000us 级

    // 报时刻用 system_clock，文本化走 format 的 chrono 指令
    auto now = system_clock::now();
    std::cout << std::format("{:%Y-%m-%d %H:%M:%S}", now) << '\n';

    // C++20 日历：字段型日期与计数型时点互转，日期差是整数天
    auto d1 = 2024y / 1 / 15, d2 = 2024y / 7 / 1;
    std::cout << (sys_days{d2} - sys_days{d1}).count() << " days\n";  // 168 days
    std::cout << weekday{sys_days{d1}} << '\n';                        // Mon

    // C++20 时区：tzdb 查表换算（含夏令时历史）
    std::cout << std::format("{:%H:%M}", zoned_time{"Asia/Tokyo", now}) << '\n';
}
```
