| 篇目 | 一句话 |
|---|---|
| [01-容器](01-容器.md) | 按内存布局分类：连续（vector/array）、节点（list/map/set）、哈希（unordered_*）；复杂度表即选型表 |
| [02-迭代器与算法](02-迭代器与算法.md) | 迭代器能力层级驱动算法分派；Ranges（C++20）把两段迭代器合成视图管道 |
| [03-字符串与格式化](03-字符串与格式化.md) | string/string_view 的所有权分野；std::format（C++20）与 std::print（C++23） |
| [04-时间与日期](04-时间与日期.md) | chrono 的时钟/时点/时长三件套；日历与时区（C++20） |
| [05-并发与协程](05-并发与协程.md) | 线程/互斥/条件变量、原子与内存序、future/promise、协程（C++20）骨架 |
| [06-工具组件](06-工具组件.md) | optional/variant/any 三选一判据、tuple、function 类型擦除的代价 |
