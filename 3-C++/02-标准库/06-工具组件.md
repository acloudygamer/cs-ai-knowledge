# 06-工具组件

> 前置：[05-移动语义与拷贝控制](../01-语言核心/05-移动语义与拷贝控制.md)（值语义的包装都依赖移动）、[03-函数与Lambda](../01-语言核心/03-函数与Lambda.md)（function 擦除的对象） · 后续：[07-错误处理](../01-语言核心/07-错误处理.md)（expected 的主场）

> **版本基准**：C++20；C++23/26 特性行内标注。示例实测环境：GCC 14.2（MinGW-w64），`-std=c++20`。

本篇收编标准库里一组"小而通用"的值包装组件。它们的共同主题：**用类型系统把本来靠注释和约定表达的情况变成编译期可检查的事实**——"可能没有值"（optional）、"是这几种之一"（variant）、"类型先藏起来"（any/function）、"位就是值"（bitset）。

## 本质

- `optional<T>`：值 + 一个"有没有"标志位，内联存储（不是指针、无堆分配）。表达"可能无值"。
- `variant<A,B,...>`：带标签的 union——一块能装下最大成员的存储 + 当前是哪个成员的标签。表达**封闭多态**：成员集合编译期封死。
- `any`：能装任何可拷贝类型的盒子，小对象内联、大对象落堆，读取时按类型名（typeid）核对。表达**开放多态**：装的时候不设限，取的时候才验。
- `function`：可调用对象的类型擦除包装——lambda、函数指针、bind 表达式，只要签名匹配就能装。
- `tuple`/`pair`：异构值的无名打包，编译期定长。

## 机制

### 三选一判据：optional / variant / any

| 问题 | 答案 |
|---|---|
| 一个值，可能不存在？ | `optional` |
| 值是**固定几种**类型之一，集合编译期已知？ | `variant` |
| 类型集合开放，装的时候不知道会有哪些？ | `any`（最后的退路） |

三者的安全等级随通用性递减：`optional` 的 `value()` 越界抛异常、`variant` 的 `get<T>` 类型错了抛 `bad_variant_access`、`visit` 更是**编译期**穷举所有成员（漏一个分支编译不过）；`any` 的 `any_cast<T>` 错了抛 `bad_any_cast`，编译器完全帮不上忙。选型顺着表的顺序问，能用前面的就别用后面的。

`variant` 的默认构造要求首个成员可默认构造（否则自己 `monostate` 占位）；`visit` 配重载集 lambda（`overloaded` 惯用法）是标准消费姿势。

### tuple/pair：结构化绑定的天然搭档

`pair` 是二元组，`tuple` 是任意元。C++17 结构化绑定（`auto [k, v] = ...`）让它们成为多返回值的事实标准——`map::insert` 返回 `pair<iterator, bool>`、`minmax` 返回 pair，都是"返回值通道"而非"数据结构"。当元素的**名字**承载语义时（x/y、width/height），换 struct——tuple 的字段没有名字，三个字段以上可读性崩溃。

### std::function：类型擦除的代价

`function<R(Args...)>` 把任意可调用对象抹成统一类型，机制是类型擦除：内部存一个指向擦除后对象的指针 + 一张虚函数式跳转表（调用、拷贝、析构三个入口）。代价有三笔，回指 [03-函数与Lambda](../01-语言核心/03-函数与Lambda.md) 的零开销对照：

1. **调用间接化**：一次指针跳转，阻止内联——热路径上的 `function` 回调是经典优化障碍；
2. **存储策略**：小对象进内联缓冲（SBO），大捕获落堆。实测（GCC 14.2 libstdc++）：`sizeof(std::function<void()>) == 32`，内联缓冲 16 字节——捕获超 16 字节的 lambda 每次构造 `function` 都付一次堆分配；
3. **可拷贝要求**：装进来的对象必须可拷贝。

替代路径：签名固定且类型已知时用模板参数（零开销）；只要移动语义时用 `std::move_only_function`（C++23 增量，GCC 12 起，本篇实测 `-std=c++23` 通过）——取消拷贝要求，可装 `unique_ptr` 捕获的 lambda。

### bitset：编译期定长的位数组

`bitset<N>` 把 $N$ 个位压进 $\lceil N/64 \rceil$ 个机器字，位操作（`set`/`reset`/`flip`/`count`/`test`）编译为单条或少数几条位指令。`N` 必须是编译期常量——这是它与 `vector<bool>`（运行期变长的位特化，代理引用坑多）的分界。适合标志集、权限位、布隆过滤器底座这类"位即语义"的场景。

### expected：回指错误处理篇

`std::expected<T, E>`（C++23 增量）是"值或错误"的和类型，`and_then`/`transform` 提供链式组合。它属于错误处理体系的一部分，机制与异常的对比见 [07-错误处理](../01-语言核心/07-错误处理.md)，本篇不展开。

## 连接

| 需求 | 选 |
|---|---|
| 函数可能无结果 | `optional` |
| 封闭集合的状态/消息类型 | `variant` + `visit` |
| 插件、脚本边界等开放类型袋 | `any` |
| 多返回值 | `pair`/`tuple`；有语义名就写 struct |
| 统一签名存回调 | `function`；热路径改模板，只要移动改 `move_only_function`（C++23 增量） |
| 定长标志位集 | `bitset<N>` |

- 类型擦除的对照面（模板静态多态）见 [06-模板与Concepts](../01-语言核心/06-模板与Concepts.md)。
- `variant`/`optional` 的值语义与移动行为见 [05-移动语义与拷贝控制](../01-语言核心/05-移动语义与拷贝控制.md)。

## 示例

（GCC 14.2 MinGW 实测，`-std=c++20`）

```cpp
#include <algorithm>
#include <any>
#include <array>
#include <bitset>
#include <functional>
#include <iostream>
#include <optional>
#include <tuple>
#include <variant>

std::optional<int> find_even(const int* a, std::size_t n) {
    for (std::size_t i = 0; i < n; ++i) if (a[i] % 2 == 0) return a[i];
    return std::nullopt;                              // "可能无值"由类型声明
}

using Num = std::variant<int, double>;                // 封闭多态

int main() {
    int a[]{1, 3, 4};
    std::cout << find_even(a, 3).value_or(-1) << '\n';       // 4

    Num n = 3;
    n = 2.5;
    std::cout << std::get<double>(n) << '\n';                // 2.5
    std::cout << std::visit([](auto v) { return v * 2.0; }, Num{7}) << '\n';  // 14

    std::any x = std::string("hi");                          // 开放多态
    std::cout << std::any_cast<std::string>(x) << '\n';      // hi

    auto [lo, hi] = std::minmax(3, 7);                       // pair + 结构化绑定
    std::cout << lo << hi << '\n';                           // 37

    // function 类型擦除：sizeof 32、内联缓冲 16 字节（libstdc++ 实测）
    std::cout << sizeof(std::function<void()>) << '\n';      // 32
    std::function<int()> small = [v = 1] { return v; };              // 内联
    std::function<int()> big = [buf = std::array<long long, 4>{}] {  // 超阈值 → 堆分配
        return (int)buf[0];
    };
    std::cout << small() << big() << '\n';                   // 10

    std::bitset<8> flags{0b1010};
    flags.set(0);
    std::cout << flags << '\n';                              // 00001011
}
```
