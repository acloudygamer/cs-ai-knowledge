# 04-正则表达式

> 前置：[03-序列化与JSON](03-序列化与JSON.md) · 后续：[05-数据库操作](05-数据库操作.md)

> **版本基准**：C++20；C++23/26 特性行内标注。示例实测环境：GCC 14.2（MinGW-w64，Windows）；动态链接因环境 DLL 冲突加载失败（exit 127）时，加 `-static` 静态链接。

正则表达式（regular expression）是用声明式模式描述字符串集合的记号：模式 `(\w+)=(\w+)` 描述的是"键=值"形状的全体字符串。C++11 把它收进标准库 `<regex>`，本篇讲三件事：六种语法族的由来、`match`/`search`/`replace` 三个入口的分工、以及 `std::regex` 的性能现实与何时该换库。

## 本质

正则模式编译成的执行体是有限状态自动机：匹配就是在文本上驱动自动机走状态转移。理论天花板也随之确定——正则表达能力恰与正则文法（Chomsky 3 型）同构，**匹配不了需要计数记忆的嵌套结构**（如任意深度的平衡括号），那是上下文无关文法的领域，该上解析器而非正则。

`<regex>` 支持六种语法族，默认 ECMAScript：`basic`、`extended`、`awk`、`grep`、`egrep`。这是历史遗产而非设计——Unix 工具链各时代沉淀出一套方言，标准把它们全部收纳；新代码没有理由离开默认的 ECMAScript。

## 机制

### 三个入口的分工

| 入口 | 语义 | 返回 |
|---|---|---|
| `std::regex_match` | **整个串**必须匹配模式 | bool / 填 `smatch` |
| `std::regex_search` | 找**第一个匹配的子串** | bool / 填 `smatch` |
| `std::regex_replace` | 所有匹配子串按模板替换，`$1` 反向引用捕获组 | 新 `std::string` |

配套两件套：`std::smatch` 持有匹配结果与捕获组（`m[0]` 全匹配、`m[1]` 起为各捕获组）；`std::sregex_iterator` 迭代文本中的**所有**匹配，覆盖 search 只给第一个的空档。

### 原始字符串字面量：转义只付一次

正则里反斜杠有双重身份——C++ 字符串转义一层、正则语法再转义一层。`"\d"` 在 C++ 字符串里要先写成 `"\\d"`，模式稍长就数不过来。原始字符串字面量 `R"(...)"`（C++11）关掉 C++ 这一层：`R"(\d+)"` 里看到什么正则就收到什么。纪律：**正则模式一律写 `R"(...)"`**。

### 性能现实：回溯实现的代价

libstdc++（GCC）的 `std::regex` 是回溯型实现，且性能偏差——公开基准对比中的典型口径是比 RE2、PCRE2 慢数倍至一个数量级（实现相关，非标准问题）。回溯型实现还有一个形状陷阱：嵌套量词模式如 `(a+)+$` 在失配文本上会指数级回溯（catastrophic backtracking），一次匹配卡死线程。

热路径的答案是换库：**RE2**（Google）用有限自动机模拟，保证匹配时间是文本长度的线性函数、拒绝回溯爆炸，代价是不支持反向引用与前后顾断言。判据：正则出现在热路径、或模式/输入来自外部（不可信输入 + 回溯实现 = 拒绝服务敞口），换 RE2；一次性的文本清洗、内部工具，`std::regex` 的零依赖够用。

另两条实现纪律：

- `std::regex` 对象的构造即编译（模式 → 自动机），循环内反复构造等于每次重编译——模式对象应该是 `static const` 或函数外长命对象。
- 字符类默认按当前 locale 解释，非 ASCII 文本的 `\w`、`\b` 行为随 locale 漂移；处理 Unicode 文本的标准答案是专门的 Unicode 正则库（如 ICU），`std::regex` 不承担这个责任。

## 连接

正则消费的是文本：从文件来（[01-文件操作](01-文件操作.md)）、从 JSON 字段来（[03-序列化与JSON](03-序列化与JSON.md)）；模式对象"构造一次、长期复用"的纪律与 [04-类与资源管理](../01-语言核心/04-类与资源管理.md) 的对象生命周期同源。

## 示例

（GCC 14.2 MinGW 实测，`-std=c++20`）

```cpp
#include <iostream>
#include <regex>
#include <string>

int main() {
    std::string s = "id=42, name=alice, id=7";
    const std::regex kv(R"((\w+)=(\w+))");  // 原始字符串：\w 只写一遍

    // regex_search：找第一个匹配子串，smatch 带捕获组
    std::smatch m;
    if (std::regex_search(s, m, kv))
        std::cout << m[1] << '=' << m[2] << '\n';      // id=42

    // regex_match：整串匹配，这里必然失败
    std::cout << std::boolalpha << std::regex_match(s, kv) << '\n';  // false

    // regex_replace：$2:$1 交换键值
    std::cout << std::regex_replace(s, kv, "$2:$1") << '\n';

    // sregex_iterator：迭代全部匹配
    for (std::sregex_iterator it(s.begin(), s.end(), kv), end; it != end; ++it)
        std::cout << (*it)[2] << ' ';
    std::cout << '\n';
}
```

实测输出：

```text
id=42
false
42:id, alice:name, 7:id
42 alice 7 
```
