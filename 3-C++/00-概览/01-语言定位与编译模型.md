# 01-语言定位与编译模型

> 前置：无（全库起点） · 后续：[02-构建系统与包管理](02-构建系统与包管理.md)、[01-类型系统与值类别](../01-语言核心/01-类型系统与值类别.md)

> **版本基准**：C++20 stable / C++23·C++26 latest；C++23/26 特性行内以"（C++23 增量）"标注。示例实测环境：GCC 14.2（MinGW-w64，Windows）。

本篇建立贯穿全库的两个锚点：C++ 在语言光谱上的位置，以及一段源码从文本到进程的编译链。后续各篇的"为什么"几乎都能回溯到这里——RAII（[04-类与资源管理](../01-语言核心/04-类与资源管理.md)）是"确定性析构"的展开，模板与 constexpr（[06-模板与Concepts](../01-语言核心/06-模板与Concepts.md)）是"编译期分账"的展开，ODR 与 ABI（[03-链接与ABI](../04-性能与底层/03-链接与ABI.md)）是"链接段"的展开。

## 本质

C++ 是静态类型、AOT（Ahead-of-Time，运行前整体编译为机器码）编译的多范式系统编程语言，全部设计围绕两条纪律：

- **零开销抽象**：高级机制（类、模板、异常）不许比等价的底层手写代码更贵——没用到的特性不付钱，用到的不比手写贵。
- **编译期/运行时分账**：能在编译期算完的不许留到运行时。类型检查、模板实例化、constexpr 求值全部在编译期结账，运行时只剩机器指令序列。

与 GC（垃圾回收，Garbage Collection）语言的分界线在内存管理：C++ 默认**值语义**（对象是值，赋值即拷贝，对象嵌在作用域或容器里）配**确定性析构**（离开作用域立即、按构造逆序析构），没有后台回收线程。析构时机可预测，析构函数就能托管一切资源——内存、文件句柄、锁；这就是 RAII 的根基，也是 C++ 能进实时与嵌入式领域的结构性原因。代价对称：悬垂引用、内存泄漏、双重释放都归程序员。

## 机制

### 语言光谱上的坐标

| 维度 | C++ 的选择 | 对照与后果 |
|---|---|---|
| 类型系统 | 静态 + 强类型（留有窄化转换等历史洞） | 类型错误编译期暴露；对照 Python 运行期才 `TypeError` |
| 编译 | AOT 编译为机器码，无 VM、无 JIT 热身 | 启动即全速；优化的代价付在编译时间里 |
| 内存管理 | 手动 + RAII，无 GC | 资源时机可控；悬垂与泄漏归程序员 |
| 值语义默认 | 对象是值，赋值即深拷贝 | 与 Java/Python"一切皆引用"相反；移动语义回收拷贝代价（[05-移动语义与拷贝控制](../01-语言核心/05-移动语义与拷贝控制.md)） |
| 硬件 | 裸指针、位操作、内联汇编直通硬件 | 可写内核与驱动；可移植性由程序员担保 |
| 向后兼容 | 几乎完全兼容 C | 直接调用整个 C 生态；同时继承了预处理、隐式转换等历史包袱 |

### 编译链四段：源码到进程

C++ 的编译模型是 C（1972 年）的遗产：编译以**翻译单元**（translation unit：一个 `.cpp` 经预处理后得到的完整输入）为单位独立进行，单元之间靠链接器缝合。四段各有独立产物，可用编译器选项逐段截停：

| 段 | 输入 → 输出 | 做什么 | 截停产物 |
|---|---|---|---|
| 预处理 | `.cpp` + 头文件 → 纯 C++ 文本 | 展开 `#include`/`#define`、条件编译、剥注释 | `.i`（`-E`） |
| 编译 | 预处理文本 → 汇编 | 语法/语义分析、模板实例化、优化 | `.s`（`-S`） |
| 汇编 | 汇编 → 机器码 | 逐条翻译为指令，生成符号表与重定位项 | `.o`/`.obj`（`-c`） |
| 链接 | 多个 `.o` + 库 → 可执行文件 | 解析跨单元符号引用、绑定地址 | `.exe`/`a.out` |

两条直接推论：**编译以翻译单元为单位** → 改一个 `.cpp` 只重编自己，这是增量构建的地基（见 [02-构建系统与包管理](02-构建系统与包管理.md)）；**单元之间没有编译期类型检查** → 跨单元的单一定义规则（ODR）违例要到链接期才暴露，甚至静默通过（见 [03-链接与ABI](../04-性能与底层/03-链接与ABI.md)）。

### 头文件包含的文本本质

`#include` 不是"导入"，是**文本替换**：预处理器把被包含文件的内容原样粘贴进来。本篇示例的 11 行源码预处理后展开成 47328 行（GCC 14.2 + libstdc++ 实测），绝大部分来自 `<iostream>` 与 `<vector>` 的间接包含。三条推论：

1. 同一头文件被多个 `.cpp` 包含 → 同一批声明在每个单元重复编译，编译时间随包含规模线性放大；
2. 头文件里放"定义"（非 inline 的函数、变量）会被粘贴进多个单元 → 链接期重复定义错误；
3. 可见性由包含顺序决定，宏不认识作用域，会跨文件污染。

这三条正是 C++20 模块要解决的问题；模块语法与三大编译器的支持现状见 [08-命名空间与模块](../01-语言核心/08-命名空间与模块.md)，预处理本身的机制展开见 [09-预处理与宏](../01-语言核心/09-预处理与宏.md)。

### 三大编译器与平台现实

| 编译器 | 上游 | 主场 | 注意 |
|---|---|---|---|
| GCC（g++） | GNU | Linux、MinGW-w64（Windows 移植） | 新标准跟进快，自由软件传统 |
| Clang（clang++） | LLVM | macOS/iOS 官方工具链、跨平台 | 诊断信息可读性好，常作静态分析与工具链底座 |
| MSVC（cl） | 微软 | Windows 原生、Visual Studio | 与 Windows SDK、调试器集成最深 |

平台现实有两个硬点。**ABI 互不兼容**：三家各自做名字修饰（name mangling）与对象布局，GCC 编出的目标文件不能喂给 MSVC 链接，跨编译器边界只能退到 `extern "C"`（机制见 [03-链接与ABI](../04-性能与底层/03-链接与ABI.md)）。**特性支持度不齐**：C++20 主体三家均已支持，但模块等个别特性进度不一（cppreference 编译器支持页口径：MSVC 最完整，GCC/Clang 部分支持）。

### 安装与最小验证

- Linux：发行版包管理器（Debian 系 `apt install g++`）；macOS：`xcode-select --install` 得 Clang。
- Windows 两条路：MSVC（Visual Studio 勾选"使用 C++ 的桌面开发"工作负载），或 MinGW-w64（本仓库实测环境，Git Bash 里直接用 `g++`）。
- 验证三行：`g++ --version` 看版本；`g++ -std=c++20 hello.cpp && ./a.out` 一次跑完四段链即环境就绪。逐段截停的完整演示见下方示例。

## 连接

**何时选 C++，何时别选**：

| 场景 | 判断 |
|---|---|
| 游戏引擎、高频交易、数据库/浏览器内核 | 主场：零开销抽象 + 确定性析构，延迟与吞吐都压得住 |
| 嵌入式、OS 内核、驱动 | 主场：无运行时依赖，直通硬件 |
| 长寿命大代码库、跨编译器生态 | 可行，但 ABI 与构建纪律是长期税（[04-性能与底层](../04-性能与底层/README.md)） |
| Web 业务后端、数据分析、快速原型 | 别选：编译耗时与手动内存拖慢迭代，换 Go/Java/Python（本仓库 [2-Python](../../2-Python/README.md)、[4-Java](../../4-Java/README.md)） |

**延伸**：编译链各段的硬件背景（指令、虚拟内存、缓存）见 [0-计算机基础](../../0-计算机基础/README.md)；C++ 标准的编年主线见 [07-版本演进](../07-版本演进/README.md)。

## 示例

四段链逐段截停（GCC 14.2 MinGW 实测，`hello.cpp` 见下）：

```bash
g++ -std=c++20 -E hello.cpp -o hello.i   # 预处理：纯文本展开，实测 47328 行
g++ -std=c++20 -S hello.cpp -o hello.s   # 编译：x86-64 汇编，1820 行
g++ -std=c++20 -c hello.cpp -o hello.o   # 汇编：目标文件 41 KB（机器码 + 符号表 + 重定位项）
g++ hello.o -o hello                     # 链接：可执行文件
./hello                                  # 30
```

```cpp
// hello.cpp：11 行，一个文件呼应三个上文锚点（值语义、编译期推导、文本宏）
#include <iostream>
#include <vector>

#define SQUARE(x) ((x) * (x))   // 预处理段展开的纯文本宏：括号防优先级坑

int main() {
    std::vector v{1, 2, 3, 4};  // C++17 类模板实参推导（CTAD），类型在编译期定案
    int sum = 0;
    for (int x : v) sum += SQUARE(x);
    std::cout << sum << '\n';   // 30
}
```
