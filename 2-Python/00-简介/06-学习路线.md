# 学习路线

## 推荐学习顺序

### 第一阶段：基础入门（1-2 周）

1. **语法基础** - 变量、数据类型、运算符
2. **控制流程** - if 条件、for/while 循环
3. **数据结构** - 列表、元组、字典、集合

目标是能读懂简单程序，能写 20-50 行的脚本。

#### 入门资源

```python
# 第一个程序
print("Hello, World!")

# 变量
name = "Alice"
age = 30
is_student = False

# 数据结构
numbers = [1, 2, 3, 4, 5]
person = {"name": "Alice", "age": 30}
unique_numbers = {1, 2, 3}

# 条件判断
if age >= 18:
    print("成年人")
else:
    print("未成年")

# 循环
for i in range(5):
    print(i)
```

### 第二阶段：函数与模块（1-2 周）

1. **函数定义** - 参数、返回值、作用域
2. **模块导入** - 标准库使用、第三方库安装
3. **文件操作** - 读写文本文件

这一阶段要多动手练习，尝试写一些文件处理小工具。

#### 函数练习项目

```python
# 文本文件处理工具
def count_lines(filepath: str) -> int:
    """统计文件行数"""
    with open(filepath, "r", encoding="utf-8") as f:
        return len(f.readlines())


def word_frequency(filepath: str) -> dict[str, int]:
    """统计单词频率"""
    with open(filepath, "r", encoding="utf-8") as f:
        words = f.read().lower().split()
    return {word: words.count(word) for word in set(words)}
```

### 第三阶段：面向对象（1-2 周）

1. **类与对象** - 定义、属性、方法
2. **继承与多态** - 类层次结构
3. **特殊方法** - `__init__`, `__str__` 等

### 第四阶段：项目实践（持续）

选择一个感兴趣的方向深入：

- **数据分析方向** - NumPy、Pandas、Matplotlib
- **Web 开发方向** - Flask 或 Django
- **自动化脚本** - 文件处理、Excel 操作
- **爬虫实战** - requests、BeautifulSoup

通过项目巩固知识，遇到问题再回头查文档。

### 避免常见错误

```python
# 错误1：可变默认参数
def bad_append(item, items=[]):  # 错误！
    items.append(item)
    return items

# 正确
def good_append(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items

# 错误2：混用 == 和 is
a = [1, 2, 3]
b = [1, 2, 3]
print(a == b)  # True（值相等）
print(a is b)  # False（不同对象）

# 错误3：闭包循环变量
funcs = [lambda: i for i in range(3)]
print([f() for f in funcs])  # [2, 2, 2] 而不是 [0, 1, 2]

# 正确
funcs = [lambda i=i: i for i in range(3)]
print([f() for f in funcs])  # [0, 1, 2]
```

```python
# 1. 猜数字游戏
import random

def guess_number():
    target = random.randint(1, 100)
    attempts = 0
    while True:
        guess = int(input("Guess (1-100): "))
        attempts += 1
        if guess < target:
            print("Too small!")
        elif guess > target:
            print("Too big!")
        else:
            print(f"Correct! Attempts: {attempts}")
            break

# 2. 文本文件搜索
def search_in_file(filepath, keyword):
    with open(filepath, "r") as f:
        for i, line in enumerate(f, 1):
            if keyword in line:
                print(f"{i}: {line.rstrip()}")

# 3. Todo 命令行应用
class TodoList:
    def __init__(self):
        self.tasks = []

    def add(self, task):
        self.tasks.append({"task": task, "done": False})

    def done(self, index):
        self.tasks[index]["done"] = True

    def list(self):
        for i, t in enumerate(self.tasks, 1):
            status = "[x]" if t["done"] else "[ ]"
            print(f"{i}. {status} {t['task']}")
```

## 常见问题

### Q: Python 2 还是 Python 3？

**A**: 学习 Python 3。Python 2 已于 2020 年停止支持。

### Q: 需要学多线程吗？

**A**: 先了解基本概念。Python 有 GIL 限制，多线程主要用于 I/O 密集型任务，多进程用于 CPU 密集型。

### Q: 如何提高代码质量？

**A**:
1. 使用 type hints
2. 编写测试
3. 使用 pylint/flake8 检查
4. 遵循 PEP 8
5. 重构优化

### Q: Git 需要学吗？

**A**: 必须学。版本控制是现代开发的基础。
