# 语言特点

## 动态类型

Python 是**动态类型**语言，变量无需声明类型，解释器在运行时自动推断。类型注解仅作为提示，不影响运行时行为。

### 参考样例

```python
x = 10          # 整数
x = "hello"     # 字符串，合法但可能不是本意

# 类型检查
print(type(x))  # <class 'str'>
```

动态类型优势：代码编写快速，无需等待编译；变量可随时改变类型，灵活度高。

动态类型劣势：运行时不类型错误可能导致 bug；大型项目中类型难以追踪。

## 解释型语言

Python 代码无需编译，由解释器逐行执行。开发周期短、调试方便，但运行速度相对编译型语言较慢。

### Python 实现

| 实现 | 说明 |
|------|------|
| CPython | 官方实现，用 C 编写 |
| PyPy | JIT 编译，执行更快 |
| Jython | 运行在 JVM 上 |
| IronPython | 运行在 .NET 平台上 |

### 参考样例

```python
# 直接运行
python script.py

# 交互式解释器
python
>>> print("Hello")
Hello
```

特点：交互式开发（REPL）；跨平台；执行速度较慢（每次运行都需要解释）。

## 简洁易读

Python 使用**缩进语法**表达代码块结构，避免花括号或 begin/end 的视觉噪音。同一代码块的所有语句必须保持相同缩进。

### PEP 8 规范

### 参考样例

```python
# 空格规范
x = 1  # 变量赋值
y = x + 1  # 操作符周围加空格
z = [1, 2, 3]  # 列表字面量

# 函数定义
def func(parameter1, parameter2):
    return parameter1 + parameter2

# 类定义
class MyClass:
    def method(self):
        pass
```

缩进规则：推荐使用 4 个空格；同一代码块必须使用相同缩进；IDE 通常会自动处理。

## "Batteries Included" 哲学

Python 倡导「自带电池」，标准库非常丰富。安装 Python 后即可使用 json、datetime、re、math、urllib.request、sqlite3、collections、itertools、functools 等模块。

### 参考样例

```python
# 文件和路径
import pathlib
p = pathlib.Path(".")
print(list(p.glob("*.py")))

# 数据结构
from collections import defaultdict, Counter
cnt = Counter(["a", "b", "a"])
print(cnt["a"])  # 2

# 日期时间
from datetime import datetime, timedelta
now = datetime.now()
tomorrow = now + timedelta(days=1)
```

常用标准库：json、datetime、re、math、urllib.request、sqlite3、collections、itertools、functools。

## 跨平台

Python 天然支持 Windows、macOS、Linux，一次编写多处运行。

### 参考样例

```python
import platform
import os

print(f"Platform: {platform.system()}")  # Windows / Darwin / Linux
print(f"Home: {os.path.expanduser('~')}")  # 用户主目录
```

跨平台注意事项：路径分隔符使用 `os.path.join` 自动处理平台差异；环境变量通过 `os.environ.get` 获取；Python 自动处理文本文件换行符转换。

## 一切皆对象

Python 中函数、类、模块都是对象，可以作为参数传递。

### 参考样例

```python
def apply(func, value):
    return func(value)

result = apply(lambda x: x * 2, 5)  # 10

# 装饰器
def debug(func):
    def wrapper(*args, **kwargs):
        print(f"Calling {func.__name__}")
        return func(*args, **kwargs)
    return wrapper

@debug
def greet():
    print("Hello!")
```

## 总结

Python 核心特点：动态类型（灵活但需注意类型安全）；解释执行（开发效率高但运行速度较慢）；缩进语法（代码简洁美观）；丰富标准库（开箱即用）；庞大生态（PyPI 第三方库支持）；跨平台；一切皆对象（函数、类、模块都是对象）。
