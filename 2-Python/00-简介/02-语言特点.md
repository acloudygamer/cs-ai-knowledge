# 语言特点

## 动态类型

Python 是**动态类型**语言，变量无需声明类型，解释器会在运行时自动推断。这让代码编写更快捷，但也要注意类型错误。

```python
x = 10          # 整数
x = "hello"     # 字符串，合法但可能不是你的本意

# 类型检查
print(type(x))  # <class 'str'>
```

动态类型的优势：
- 代码编写快速，无需等待编译
- 变量可以随时改变类型，灵活度高

动态类型的劣势：
- 运行时不类型错误可能导致 bug
- 大型项目中类型难以追踪

### 类型注解（PEP 484）

Python 3.5+ 支持类型注解，但仅作为提示，不影响运行时行为：

```python
def greet(name: str) -> str:
    return f"Hello, {name}"

# 类型检查器如 mypy 可以发现潜在错误
age: int = "thirty"  # 运行时合法，但 mypy 会报错
```

## 解释型语言

Python 是**解释型**语言，代码无需编译，直接由解释器逐行执行。这使得开发周期短、调试方便，但运行速度相对编译型语言（如 C、Go）较慢。

```python
# 直接运行
python script.py

# 交互式解释器
python
>>> print("Hello")
Hello
```

解释型语言的特点：
- 交互式开发（REPL）
- 跨平台（同一份代码在不同平台解释器上运行）
- 执行速度较慢（每次运行都需要解释）

## 简洁易读

Python 使用**缩进语法**表达代码块结构，避免了花括号或 begin/end 的视觉噪音。同一代码块的所有语句必须保持相同缩进。

```python
if True:
    print("缩进很重要")  # 这行属于 if 内部
    if True:
        print("嵌套的缩进")  # 更深的缩进层级
else:
    print("这行不会执行")  # 与 if 同级
```

Python 的缩进规则：
- 推荐使用 4 个空格（也可使用 Tab）
- 同一代码块必须使用相同缩进
- IDE 通常会自动处理缩进

### PEP 8 规范

Python 官方编码规范（PEP 8）：

```python
# 空格规范
x = 1  # 变量赋值
y = x + 1  # 操作符周围加空格
z = [1, 2, 3]  # 列表字面量

# 函数定义
def func(parameter1, parameter2):
    return parameter1 + parameter2

# 类定义
class MyClass:
    def method(self):
        pass
```

## 跨平台

Python 天然支持 Windows、macOS、Linux，一次编写多处运行。

```python
import platform
import os

print(f"Platform: {platform.system()}")  # Windows / Darwin / Linux
print(f"Home: {os.path.expanduser('~')}")  # 用户主目录
```

## 一切皆对象

Python 中函数、类、模块都是对象，可以作为参数传递：

```python
def apply(func, value):
    return func(value)

result = apply(lambda x: x * 2, 5)  # 10

# 装饰器
def debug(func):
    def wrapper(*args, **kwargs):
        print(f"Calling {func.__name__}")
        return func(*args, **kwargs)
    return wrapper

@debug
def greet():
    print("Hello!")
```

## 总结

Python 的核心特点：
- 动态类型：灵活但需注意类型安全
- 解释执行：开发效率高但运行速度较慢
- 缩进语法：代码简洁美观
- 丰富标准库：开箱即用
- 庞大生态：PyPI 第三方库支持
- 跨平台：Windows、macOS、Linux 兼容
- 一切皆对象：函数、类、模块都是对象

这些特点使 Python 成为快速原型开发、数据科学、Web 开发等领域的首选语言。
