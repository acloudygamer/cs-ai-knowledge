# 开发环境

## Python 安装

### Windows

1. 访问 **python.org** 下载安装包
2. 运行安装程序，**务必勾选「Add Python to PATH」**
3. 打开命令提示符，输入 `python --version` 验证

安装选项说明：
- **Add Python to PATH** - 必需勾选，否则命令行无法直接运行 python
- **Install Now** - 使用默认安装位置
- **Customize Installation** - 自定义安装位置和功能

### macOS

macOS 通常预装 Python，但版本较旧。建议使用 Homebrew 安装：

```bash
# 安装 Homebrew（如果没有）
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 安装 Python 3.14+
brew install python@3.14

# 验证安装
python3 --version
pip3 --version

# 创建别名（可选）
echo 'alias python=python3' >> ~/.zshrc
```

### Linux

大多数发行版已自带 Python。Ubuntu/Debian 可用：

```bash
# 更新包列表
sudo apt update

# 安装 Python 和 pip
sudo apt install python3 python3-pip python3-venv

# 验证安装
python3 --version
pip3 --version

# Ubuntu 22.04+ 可能需要额外安装 pip
sudo apt install python3-pip
```

### 源码编译安装

适用于需要自定义编译选项或安装最新版本：

```bash
# 安装编译依赖
sudo apt install build-essential libssl-dev zlib1g-dev libbz2-dev \
    libreadline-dev libsqlite3-dev curl libncursesw5-dev xz-utils tk-dev libxml2-dev libxmlsec1-dev libffi-dev liblzma-dev

# 下载 Python 源码
curl -O https://www.python.org/ftp/python/3.14.0/Python-3.14.0.tgz
tar -xzf Python-3.14.0.tgz
cd Python-3.14.0

# 编译安装
./configure --enable-optimizations
make -j$(nproc)
sudo make altinstall

# 验证
python3.14 --version
```

## Python Launcher (Windows)

Windows 用户建议安装 **py Launcher**，它可以方便地管理多个 Python 版本：

```bash
# 查看已安装的 Python 版本
py -0

# 运行特定版本
py -3.14    # 运行 Python 3.14
py -3.13    # 运行 Python 3.13
py -3       # 运行最新的 Python 3

# 运行脚本
py -3.14 script.py

# shebang 支持（在脚本第一行写）
#!python3.14
#!/usr/bin/env python3
```

### Linux 上的 Python 版本管理

```bash
# 使用 pyenv 管理多个版本
curl https://pyenv.run | bash

# 安装 Python 版本
pyenv install 3.14.0
pyenv install 3.13.0

# 设置全局版本
pyenv global 3.14.0

# 为项目设置本地版本
pyenv local 3.14.0
```

## 虚拟环境

### venv（Python 3.3+ 内置）

```bash
# 创建虚拟环境
python -m venv myenv

# 激活（Windows）
myenv\Scripts\activate

# 激活（Linux/macOS）
source myenv/bin/activate

# 安装包
pip install requests

# 导出依赖
pip freeze > requirements.txt

# 从依赖安装
pip install -r requirements.txt

# 停用
deactivate
```

### pipenv

```bash
# 安装 pipenv
pip install pipenv

# 创建项目环境
pipenv install requests

# 运行脚本
pipenv run python script.py

# 安装开发依赖
pipenv install --dev pytest

# 激活 shell
pipenv shell

# 生成 requirements.txt
pipenv lock -r > requirements.txt
```

### poetry

```bash
# 安装 poetry
pip install poetry

# 创建项目
poetry new myproject

# 添加依赖
poetry add requests
poetry add --dev pytest

# 安装依赖
poetry install

# 运行脚本
poetry run python script.py

# 虚拟环境位置
poetry env info
```

### uv（新兴工具）

```bash
# 安装 uv
pip install uv

# 创建项目
uv init myproject
cd myproject

# 添加依赖
uv add requests
uv add --dev pytest

# 运行
uv run python script.py
```

## 安装验证

安装完成后，打开终端/命令提示符验证：

```bash
python --version    # 应显示 Python 3.x.x
pip --version       # 应显示 pip 版本信息
```

如果遇到「不是内部命令」错误：
1. 重启终端/命令提示符
2. 检查 PATH 环境变量
3. 使用完整路径运行

Windows 检查 PATH：
```powershell
# 查看 PATH 中是否有 Python
$env:PATH -split ";"

# 添加到 PATH（如果需要）
[Environment]::SetEnvironmentVariable(
    "Path",
    $env:PATH + ";C:\Python311",
    "User"
)
```

## 包管理

### pip 基本用法

```bash
# 安装包
pip install requests
pip install requests==2.28.0       # 指定版本
pip install "requests>=2.28.0"     # 最小版本

# 升级包
pip install --upgrade requests

# 卸载包
pip uninstall requests

# 查看已安装的包
pip list
pip list --outdated    # 查看可升级的包

# 显示包信息
pip show requests

# 搜索包
pip search requests    # 需要 pip search 插件
```

### pip 国内镜像

```bash
# 临时使用
pip install requests -i https://pypi.tuna.tsinghua.edu.cn/simple

# 永久设置
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
```

常用镜像：
- 清华：https://pypi.tuna.tsinghua.edu.cn/simple
- 阿里云：https://mirrors.aliyun.com/pypi/simple
- 豆瓣：http://pypi.douban.com/simple

## 常用开发工具

### 格式化工具

```bash
# black - 代码格式化
pip install black
black .

# isort - import 排序
pip install isort
isort .

# yapf - 另一个格式化工具
pip install yapf
yapf -i script.py
```

### 静态分析工具

```bash
# mypy - 类型检查
pip install mypy
mypy script.py

# pylint - 代码检查
pip install pylint
pylint script.py

# flake8 - 代码风格检查
pip install flake8
flake8 script.py

# ruff - 快速的 Python linter（Rust 实现）
pip install ruff
ruff check .
```

### 测试工具

```bash
# pytest - 测试框架
pip install pytest
pytest tests/

# coverage - 覆盖率
pip install coverage
coverage run -m pytest
coverage report
```

## 项目结构示例

```bash
myproject/
├── src/
│   └── mypackage/
│       ├── __init__.py
│       ├── main.py
│       └── utils.py
├── tests/
│   ├── __init__.py
│   ├── test_main.py
│   └── test_utils.py
├── docs/
│   └── README.md
├── pyproject.toml      # 项目配置
├── requirements.txt    # 依赖列表
├── .gitignore
└── README.md
```

### pyproject.toml 示例

```toml
[build-system]
requires = ["setuptools>=61.0"]
build-backend = "setuptools.build_meta"

[project]
name = "mypackage"
version = "0.1.0"
description = "My package"
requires-python = ">=3.10"
dependencies = [
    "requests>=2.28.0",
]

[project.optional-dependencies]
dev = [
    "pytest>=7.0.0",
    "black>=23.0.0",
    "mypy>=1.0.0",
]

[tool.black]
line-length = 88
target-version = ['py310']

[tool.mypy]
python_version = "3.10"
strict = true
```
