# 语言简介

Python 由 **Guido van Rossum** 于 **1991年** 创立，灵感来源于 ABC 语言参与经验及 Amoeba 操作系统开发反思。

名字来自英国喜剧团 Monty Python，而非蟒蛇。Guido 希望这门语言能给开发者带来乐趣。

## 版本演进

Python 2 → 3 的迁移是历史性变革。Python 3 修正了 print 语句改为 print 函数、字符串默认 Unicode 等设计缺陷，但 breaking change 导致大量旧代码需要改写。新项目应始终使用 Python 3。

| 版本 | 发布年份 | 状态 |
|------|----------|------|
| Python 1.0 | 1991 | 已停止维护 |
| Python 2.0 | 2000 | 已停止维护（2020年终止） |
| Python 3.0 | 2008 | 首个 Python 3 版本 |
| Python 3.12 | 2023 | 稳定版本 |
| Python 3.13 | 2024 | 稳定版本 |
| Python 3.14 | 2026 | 前沿版本 |

## 设计哲学

Python 设计理念浓缩于「PEP 20 - The Zen of Python」，可用 `import this` 查看。核心原则：**简洁优于复杂**、**明了优于隐晦**、**可读性很重要**。

## 优缺点

### 优点

- **语法简洁**：一行代码实现其他语言几十行功能，接近自然语言
- **应用领域广泛**：Web 开发、数据科学、机器学习、自动化脚本、DevOps、游戏开发、网络爬虫
- **库支持丰富**：超过 200,000 个第三方包通过 pip 安装
- **社区强大**：Stack Overflow 调查长期位居最受欢迎编程语言前列
- **跨平台**：Windows、macOS、Linux 均可运行

### 缺点

- **运行速度较慢**：解释型语言，执行速度不如编译型语言
- **GIL 限制**：全局解释器锁限制多线程并行执行
- **移动端开发薄弱**：不适合移动应用开发
- **内存消耗较高**：相比 C/C++ 占用更大

## 适用场景

### 非常适合

- **数据分析**：pandas、NumPy、SciPy、Matplotlib 构成完整数据科学生态
- **机器学习和 AI**：TensorFlow、PyTorch、Keras 使 Python 成为 AI 领域首选语言
- **快速原型开发**：简洁性适合快速验证想法和构建 MVP
- **自动化脚本**：文件处理、系统管理、网络爬虫
- **Web 后端开发**：Django 和 Flask 提供成熟框架
- **教学和入门编程**：许多顶尖大学将 Python 作为编程入门语言

### 不太适合

- **移动应用开发**：推荐 Swift（iOS）或 Kotlin（Android）
- **对性能要求极高的系统**：如操作系统内核、游戏引擎核心
- **浏览器前端开发**：JavaScript 是唯一选择（WebAssembly 除外）
