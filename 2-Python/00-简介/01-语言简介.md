# 语言简介

**Python 是一门由 Guido van Rossum 于 1991 年创立的解释型、动态类型通用编程语言**，灵感来源于 ABC 语言参与经验及 Amoeba 操作系统开发反思，名字来自英国喜剧团 Monty Python。

> Guido 设计 Python 的核心目标是让编程本身成为乐趣——"让人们做事情"比"让机器理解"更重要。

## 版本演进

Python 2 → 3 的迁移是历史性变革。Python 3 修正了 print 语句改为 print 函数、字符串默认 Unicode 等设计缺陷，但 breaking change 导致大量旧代码需要改写。**新项目应始终使用 Python 3**。

<pre>
1991 ── Python 1.0 (已停止维护)
2000 ── Python 2.0 (2020 年终止维护)
2008 ── Python 3.0 (首个 Python 3，breaking change)
     ├── 3.8 (2020) ── 赋值表达式 := 、位置-only 参数
     ├── 3.11 (2022) ── 启动速度提升 25%、更好的错误回溯
     ├── 3.12 (2023) ── 稳定版本
     ├── 3.13 (2024) ── 稳定版本
     └── 3.14 (2026) ── 前沿版本
</pre>

## 设计哲学

Python 设计理念浓缩于「PEP 20 - The Zen of Python」，可用 `import this` 查看。核心原则：**简洁优于复杂**、**明了优于隐晦**、**可读性很重要**。

> 可读性原则的根源：代码被读的次数远多于被写的次数。Python 通过强制缩进将视觉格式与语义结构绑定，使协作阅读成本大幅降低。

## 优缺点

### 优点

- **语法简洁**：一行代码实现其他语言几十行功能，接近自然语言
- **应用领域广泛**：Web 开发、数据科学、机器学习、自动化脚本、DevOps、游戏开发、网络爬虫
- **库支持丰富**：PyPI 超过 40 万个第三方包
- **社区强大**：Stack Overflow 调查长期位居最受欢迎编程语言前列
- **跨平台**：Windows、macOS、Linux 均可运行

### 缺点

- **运行速度较慢**：解释型语言，执行速度不如编译型语言（设计权衡：优先人的时间而非机器的时间）
- **GIL 限制**：全局解释器锁限制多线程并行执行（CPython 的内存管理机制决定）
- **移动端开发薄弱**：不适合移动应用开发
- **内存消耗较高**：相比 C/C++ 占用更大

## 适用场景

### 非常适合

- **数据分析**：pandas、NumPy、SciPy、Matplotlib 构成完整数据科学生态
- **机器学习和 AI**：TensorFlow、PyTorch 使 Python 成为 AI 领域首选语言
- **快速原型开发**：简洁性适合快速验证想法和构建 MVP
- **自动化脚本**：文件处理、系统管理、网络爬虫
- **Web 后端开发**：Django 和 Flask 提供成熟框架
- **教学和入门编程**：许多顶尖大学将 Python 作为编程入门语言

### 不太适合

- **移动应用开发**：推荐 Swift（iOS）或 Kotlin（Android）
- **对性能要求极高的系统**：如操作系统内核、游戏引擎核心
- **浏览器前端开发**：JavaScript 是唯一选择（WebAssembly 除外）
