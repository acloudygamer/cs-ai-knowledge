# 数据分析与机器学习

## 目录

- [01-数据分析基础](01-数据分析基础.md)

## 概述

数据分析与可视化工具链形成三层架构：

| 层级 | 库 | 核心抽象 | 适用场景 |
|------|-----|----------|----------|
| **数值计算** | NumPy | ndarray 多维数组，广播运算 | 矩阵运算，数值算法 |
| **数据操作** | pandas | DataFrame 表格，索引对齐 | 数据清洗，特征工程 |
| **可视化** | matplotlib | Artist 对象树，仿射变换 | 探索性图表，出版级图形 |

## 学习路径

**推荐顺序**：NumPy（底层数组）→ pandas（表格数据）→ matplotlib（可视化）

- **NumPy**：理解连续内存布局、strides、广播机制，是所有上层库的基础
- **pandas**：掌握索引对齐、groupby 分组聚合、向量化操作
- **matplotlib**：理解 Artist 层次、坐标变换链、后端渲染系统

## 工具组合

典型数据分析流程：

```
NumPy（数据生成/预处理）
    ↓
pandas（数据清洗/分析/特征工程）
    ↓
matplotlib（可视化探索）
```
