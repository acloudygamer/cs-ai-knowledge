# 控制流程

**控制流程是 CPU 跳转指令的抽象，if/else 是分支，for/while 是循环，match 是结构化跳转表。**

## if/elif/else

### 定义

条件分支根据布尔值选择执行路径，短路求值使布尔表达式具有条件执行语义。

### 数据流

<pre>
if condition:
    # True 路径
elif condition2:
    # condition=False, condition2=True
else:
    # 全部 False
</pre>

### 参考存根（≤20行）

```python
age = 20
if age < 18: print("未成年")
elif age < 65: print("成年人")
else: print("老年人")
status = "成人" if age >= 18 else "未成年"
```

## for / while

### 定义

for 是迭代器驱动循环，while 是条件驱动循环，两者皆通过 break/continue 控制跳转。

### 数据流

<pre>
for item in iterable:
    # 每次从迭代器取一个元素
    # 迭代器耗尽时退出

while condition:
    # condition 为真则继续
    # 假则退出
</pre>

### 参考存根（≤20行）

```python
for i in range(5): print(i)
for k, v in {"a": 1}.items(): print(k, v)
count = 0
while count < 3: count += 1
```

## break / continue / pass

### 定义

break 跳出最近层循环，continue 跳到下次迭代开头，pass 是空语句占位符。

### 参考存根（≤20行）

```python
for i in range(10):
    if i == 5: break
    if i % 2 == 0: continue
    print(i)
```

## match 语句

### 定义

match 是结构化模式匹配，Python 3.10+ 支持，比 if/elif 更强的解构能力。

### 数据流

<pre>
match value:
    case pattern1: ...
    case pattern2 if guard: ...
    case _: ...  # 默认
</pre>

### 参考存根（≤20行）

```python
def http_status(n):
    match n:
        case 200: return "OK"
        case 404: return "Not Found"
        case _: return "Unknown"
```

## 推导式

### 定义

推导式是迭代器模式的内联语法，在单个表达式中完成过滤+转换。

### 参考存根（≤20行）

```python
squares = [x**2 for x in range(5)]
evens = [x for x in range(10) if x % 2 == 0]
```

## 循环 else

### 定义

循环 else 在**非 break 退出**时执行，用于搜索"未找到"场景。

### 参考存根（≤20行）

```python
for x in [1, 2, 3]:
    if x == 2: break
else:
    print("not found")
```

## itertools

### 定义

itertools 提供内存高效的无限迭代器，核心是惰性求值的生成器模式。

### 参考存根（≤20行）

```python
from itertools import count, islice
list(islice(count(1), 5))
```
