# 控制流程

## 定义

控制流程是 CPU 跳转指令的抽象。Python 的控制流语句通过字节码指令实现：
- `if`/`elif`/`else` 生成条件跳转 `POP_JUMP_IF_FALSE`
- `for` 循环使用 `GET_ITER` + `FOR_ITER`
- `while` 循环使用 `SETUP_LOOP` + 条件跳转
- `match` 语句通过序列化的模式匹配实现

## 数学模型

### 分支跳转的形式化

设条件 $c$ 的布尔值为 $B(c) \in \{\text{True}, \text{False}\}$，分支执行的字节码序列为 $B_{true}$ 和 $B_{false}$。总执行时间：

$$T_{\text{branch}}(c) = T_{\text{eval}}(c) + \begin{cases} T_{\text{exec}}(B_{true}) & \text{if } B(c) = \text{True} \\ T_{\text{exec}}(B_{false}) & \text{if } B(c) = \text{False} \end{cases}$$

### 循环不变式

循环不变式是每次迭代前保持为真的断言 $I$：

$$\text{while } c \text{ do } S \text{ od}$$

不变式 $I$ 满足：
1. **初始化**：$I$ 在循环开始前为真
2. **保持**：若 $I \land c$ 为真，执行 $S$ 后 $I$ 仍为真
3. **终止**：循环结束时，可从 $I \land \neg c$ 推导出所需结果

对于 `for i in range(n)`：

$$I_k: \text{已处理 } i_0, i_1, \dots, i_{k-1}$$

### match 语句的复杂度

Python 3.10+ 的 `match` 语句通过**模式序列依次匹配**实现。最坏情况复杂度为 $O(n)$（n 为 case 数）：

$$T_{\text{match}}(v, \text{cases}) = \sum_{i=1}^{n} O(1) \cdot \mathbb{1}_{\text{前面 i-1 个均不匹配}} = O(n)$$

## 数据流

### for 循环的迭代器协议执行

<pre>
for item in iterable:
    # body

等价的执行流：
1. iterator = iter(iterable)  # __iter__()
2. while True:
3.     try:
4.         item = next(iterator)  # __next__()
5.         # body
6.     except StopIteration:
7.         break
</pre>

### match 语句的执行流

<pre>
match value:
    case pattern1: ...
    case pattern2 if guard: ...
    case _: ...

执行流程：
1. value 与 pattern1 匹配（解构 + 类型检查）
2. 若成功，检查 guard（若有）
3. 若 guard 为真，执行对应 body，退出 match
4. 否则，继续匹配下一个 case
5. _ 是通配符，总匹配成功
</pre>

### 短路求值的数据流

<pre>
a and b
等价于：
if a:
    return b
else:
    return a

执行路径：
1. 求值 a
2. 若 a 为真，求值 b，返回 b
3. 若 a 为假，直接返回 a（不求值 b）

a or b
等价于：
if a:
    return a
else:
    return b
</pre>

## 机制

### 字节码条件跳转的实现

Python 的 `if` 语句编译为条件跳转指令：

```python
# 源码
if condition:
    # True branch
else:
    # False branch

# 伪字节码
LOAD_FAST condition      # 加载条件值
POP_JUMP_IF_FALSE L1     # 为假则跳到 L1
# True branch bytecode
JUMP_FORWARD L2          # 跳过 False branch
L1:
# False branch bytecode
L2:
```

关键指令：
- `POP_JUMP_IF_FALSE`：栈顶为假时跳转
- `JUMP_FORWARD`：无条件向前跳转（跳过代码块）

### 循环的字节码结构

`while` 循环：

```python
while condition:
    # body

# 伪字节码
L1:
LOAD_FAST condition
POP_JUMP_IF_FALSE L2    # 条件为假则退出
# body bytecode
JUMP_BACK L1             # 跳回继续判断
L2:
```

### 推导式的优化机制

列表/集合/字典推导式在 Python 中被优化为等价的 `for` 循环构建。字节码层面：

```python
[x**2 for x in range(5)]

# 优化后的等价字节码
BUILD_LIST 0             # 创建空列表
LOAD_FAST range(5)       # 加载可迭代对象
GET_ITER                 # 获取迭代器
FOR_ITER L1             # 迭代
STORE_FAST x            # x = next()
LOAD_FAST x
LOAD_CONST 2
BINARY_POWER             # x**2
LIST_APPEND             # 追加到列表
JUMP_ABSOLUTE FOR_ITER
L1:
```

### 循环 else 的语义

循环的 `else` 子句在**非 break 退出**时执行：

$$T_{\text{loop\_else}} = \neg \text{break} \implies \text{执行 else 分支}$$

这是 Python 独有的语法，用于"搜索未找到"模式：

```python
for x in items:
    if x == target:
        print("found")
        break
else:
    print("not found")  # 仅在未执行 break 时执行
```

### itertools 的惰性求值

`itertools` 的核心是**生成器函数**——不一次性构造序列，而是按需产生元素。这允许处理无限序列而不耗尽内存：

$$S = (s_0, s_1, s_2, \dots) \quad \text{其中 } s_i = f(i)$$

内存占用：$O(1)$，无论序列多长。
