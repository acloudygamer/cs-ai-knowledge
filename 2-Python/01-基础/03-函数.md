# 函数

**函数是惰性求值的代码对象，def 是语法糖，本质是创建可调用对象并绑定到名字。**

## 函数定义

### 定义

`def` 创建代码对象并绑定到名字，return 返回值（默认 None），参数是代码对象的输入槽位。

### 参考存根（≤20行）

```python
def greet(name: str) -> str: return f"Hello, {name}!"
def add(a: int, b: int) -> int: return a + b
def log(msg: str) -> None: print(msg)
```

## 参数类型

### 定义

位置参数按顺序绑定，关键字参数按名字绑定，`*args` 收集剩余位置实参，`**kwargs` 收集剩余关键字实参。

### 数据流

<pre>
def f(a, *args, b, **kwargs): ...
f(1, 2, 3, b=4, c=5, d=6)
# a=1, args=(2,3), b=4, kwargs={'c':5,'d':6}
</pre>

### 参考存根（≤20行）

```python
def f(a, /, b, *, c): return a + b + c
def sum_all(*args): return sum(args)
```

## 作用域 LEGB

### 定义

变量名查找顺序：Local → Enclosing → Global → Built-in。`global` 声明写全局槽，`nonlocal` 声明写闭包槽。

### 数据流

<pre>
x = "global"
def outer():
    x = "enclosing"
    def inner():
        x = "local"  # 写 local 槽
        print(x)     # 查 local → enclosing → global
</pre>

### 参考存根（≤20行）

```python
x = "g"
def outer():
    x = "e"
    def inner():
        x = "l"
        print(x)
outer()
```

## lambda

### 定义

lambda 是单行匿名函数对象，本质是语法压缩的 `def`，适合作为高阶函数的参数。

### 参考存根（≤20行）

```python
square = lambda x: x ** 2
list(map(lambda x: x * 2, [1, 2, 3]))
```

## 高阶函数

### 定义

函数是一等公民（可赋值、可传参、可返回值），接收或返回函数的函数称为高阶函数。

### 参考存根（≤20行）

```python
from functools import reduce
reduce(lambda x, y: x + y, [1, 2, 3])
```

## 闭包

### 定义

闭包 = 函数 + 自由变量绑定。自由变量在创建时捕获，不随外层函数返回而消失。

### 数据流

<pre>
def make_adder(n):
    def adder(x): return x + n
    return adder
# n 绑定在 adder 的 __closure__ 中
</pre>

### 参考存根（≤20行）

```python
def make_adder(n):
    def adder(x): return x + n
    return adder
add5 = make_adder(5)
add5(3)
```

## 装饰器

### 定义

装饰器是函数组合的语法糖，`@d` 等价于 `f = d(f)`，在函数定义后立即修改其行为。

### 参考存根（≤20行）

```python
def decorator(f): return f
@decorator
def target(): pass
```

## 递归

### 定义

递归是函数自调用，需有终止条件防止无限展开。Python 无尾递归优化，深度约 1000 层。

### 参考存根（≤20行）

```python
def factorial(n):
    if n <= 1: return 1
    return n * factorial(n - 1)
```
