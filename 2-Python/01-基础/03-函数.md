# 函数

函数组织代码逻辑、避免重复编写、模块化复杂任务。函数将可复用的逻辑封装为独立单元，支持参数化输入和返回值输出。

## 核心机制

`def` 定义函数，`return` 返回结果（默认返回 `None`）。参数类型包括位置参数、关键字参数、`*args`、`**kwargs`。作用域 LEGB：Local → Enclosing → Global → Built-in。`lambda` 是单行匿名函数，适合简单转换。装饰器使用 `@wrapper` 语法，本质是函数组合。

## 函数定义

### 参考样例

```python
# 基本函数
def greet(name: str) -> str:
    """问候函数"""
    return f"Hello, {name}!"

# 多参数
def add(a: int, b: int) -> int:
    return a + b

# 无返回值（返回 None）
def print_greeting(name: str) -> None:
    print(f"Hello, {name}!")
```

## lambda 表达式

### 参考样例

```python
# lambda（单行匿名函数）
square = lambda x: x ** 2
add = lambda x, y: x + y
```

## 参数类型

位置参数按顺序传递，关键字参数按名称传递。默认参数必须是不可变对象（避免可变默认参数陷阱）。`*args` 接收任意数量位置参数，`**kwargs` 接收任意数量关键字参数。Python 3.10+ 支持仅位置参数语法（`/`）和仅关键字参数语法（`*`）。

### 参考样例

```python
# 位置参数（必须参数）
def func(a, b, c):
    return a + b + c

func(1, 2, 3)  # 正确
func(1, 2)     # TypeError
func(a=1, b=2, c=3)  # 可以用关键字参数

# 默认参数
def func(a, b=10, c=20):
    return a + b + c

func(1)              # a=1, b=10, c=20
func(1, c=30)        # a=1, b=10, c=30
func(1, 5, 10)      # a=1, b=5, c=10
func(1, b=5)        # a=1, b=5, c=20

# *args（可变位置参数）
def sum_all(*args):
    return sum(args)

sum_all(1, 2, 3, 4)  # 10
sum_all()             # 0

# **kwargs（可变关键字参数）
def print_info(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")

print_info(name="Alice", age=25, city="Beijing")

# 组合使用
def func(*args, **kwargs):
    print(f"Args: {args}")
    print(f"Kwargs: {kwargs}")

func(1, 2, 3, name="test")

# 参数解包
args = (1, 2, 3)
kwargs = {"a": 4, "b": 5}
func(*args, **kwargs)

# 仅关键字参数
def func(a, *, b, c):
    """b 和 c 必须是关键字参数"""
    return a + b + c

func(1, b=2, c=3)  # 正确
func(1, 2, 3)      # TypeError

# Python 3.10+ 位置关键字
def func(a, /, b, *, c):
    """a 必须位置参数，c 必须关键字参数"""
    return a + b + c

func(1, 2, c=3)  # 正确
```

## 作用域 LEGB

变量名查找顺序：Local → Enclosing → Global → Built-in。`global` 声明使用全局变量，`nonlocal` 声明使用外层闭包变量。列表、字典等可变对象在全局和局部作用域都能修改。

### 参考样例

```python
# LEGB: Local -> Enclosing -> Global -> Built-in
x = "global"  # global

def outer():
    x = "enclosing"

    def inner():
        x = "local"      # local 作用域
        print(x)         # 打印 local

    inner()
    print(x)             # 打印 enclosing

outer()
print(x)                 # 打印 global

# global 声明使用全局变量
counter = 0

def increment():
    global counter      # 声明使用全局变量
    counter += 1

# nonlocal 声明使用外层变量
def outer():
    count = 0

    def inner():
        nonlocal count   # 声明使用外层变量
        count += 1

    inner()
    print(count)  # 1
```

## 高阶函数

函数是一等公民，可以作为参数或返回值。高阶函数接收函数参数或返回函数。闭包捕获外部变量，形成带状态的函数。

### 参考样例

```python
# map - 对每个元素应用函数
numbers = [1, 2, 3, 4, 5]
squared = list(map(lambda x: x ** 2, numbers))
print(squared)  # [1, 4, 9, 16, 25]

# filter - 过滤元素
evens = list(filter(lambda x: x % 2 == 0, numbers))
print(evens)  # [2, 4]

# reduce - 累积计算
from functools import reduce
total = reduce(lambda x, y: x + y, numbers)
print(total)  # 15

product = reduce(lambda x, y: x * y, numbers, 1)  # 带初始值
print(product)  # 120

# sorted 的 key
students = [
    {"name": "Alice", "grade": 90},
    {"name": "Bob", "grade": 85},
    {"name": "Charlie", "grade": 92}
]

sorted_students = sorted(students, key=lambda x: x["grade"])
print([s["name"] for s in sorted_students])  # ['Bob', 'Alice', 'Charlie']

# 函数工厂
def make_adder(n):
    """返回一个加 n 的函数"""
    def adder(x):
        return x + n
    return adder

add_5 = make_adder(5)
add_10 = make_adder(10)
print(add_5(3))   # 8
print(add_10(3))  # 13
```

## 偏函数

`functools.partial(func, *args, **kwargs)` 固定部分参数，常用于回调、事件处理等场景。

### 参考样例

```python
from functools import partial

def power(base, exponent):
    return base ** exponent

# 创建偏函数
square = partial(power, exponent=2)
cube = partial(power, exponent=3)

print(square(5))  # 25
print(cube(5))    # 125

# 固定第一个参数
def multiply(a, b):
    return a * b

double = partial(multiply, 2)
print(double(5))  # 10
```

## 递归

问题可分解为相同类型的子问题，且子问题规模逐渐减小时，适合用递归表达。递归需要有终止条件，防止无限递归。Python 不支持尾递归优化，但可用迭代避免栈溢出。递归深度默认限制约 1000 层。

### 参考样例

```python
# 基本递归
def factorial(n: int) -> int:
    """阶乘"""
    if n <= 1:
        return 1
    return n * factorial(n - 1)

# 斐波那契数列
def fibonacci(n: int) -> int:
    """斐波那契数列"""
    if n < 2:
        return n
    return fibonacci(n - 1) + fibonacci(n - 2)

# 迭代版本避免栈溢出
def fibonacci_iter(n: int) -> int:
    """迭代版本避免栈溢出"""
    if n < 2:
        return n
    a, b = 0, 1
    for _ in range(n - 1):
        a, b = b, a + b
    return b
```

## 常见错误

可变默认参数（如 `def func(items=[])`）会导致所有调用共享同一对象。忘记返回值导致函数返回 `None`。`*args` 和 `**kwargs` 参数顺序必须正确。

### 参考样例

```python
# 错误 - 可变默认参数
def bad_append(item, items=[]):
    items.append(item)
    return items

# 正确
def good_append(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items

# 忘记返回值
def process_data(data):
    # 处理数据但不返回
    data.append(1)

result = process_data([1, 2, 3])
print(result)  # None（应该返回结果）
```

## 闭包

闭包是函数与其引用的外部变量（自由变量）的组合。函数"记住"创建时的外部变量状态，即使外部函数已返回。这用于创建带状态的函数、函数工厂、记忆化等场景。

### 核心概念

- 闭包 = 函数 + 引用的外部变量（自由变量）
- 三个条件：嵌套函数、引用外层变量、返回嵌套函数
- `nonlocal` 允许修改闭包捕获的外层变量
- 循环中的闭包需注意变量捕获时机（使用默认参数或额外嵌套函数）

### 闭包的三个条件

1. 必须有一个嵌套函数
2. 嵌套函数引用了外部作用域的变量
3. 外部函数返回嵌套函数

### 参考样例

```python
# 示例：满足闭包条件的函数
def make_multiplier(factor):
    def multiplier(number):
        return number * factor  # 引用了外部变量 factor
    return multiplier  # 返回嵌套函数


times_3 = make_multiplier(3)
times_5 = make_multiplier(5)

print(times_3(10))  # 30
print(times_5(10))  # 50

# 闭包捕获的变量
print(times_3.__code__.co_freevars)  # ('factor',) - 自由变量
```

### 闭包 vs 普通函数

```python
# 普通函数：每次调用独立
def add_plain(x, y):
    return x + y


# 闭包：保持状态
def counter(start=0):
    def step():
        nonlocal start
        start += 1
        return start
    return step


cnt = counter(0)
print(cnt())  # 1
print(cnt())  # 2
print(cnt())  # 3

# 多个闭包独立状态
cnt2 = counter(10)
print(cnt2())  # 11
print(cnt())   # 4（cnt 保持自己的状态）
```

### nonlocal 关键字

```python
def make_accumulator():
    total = 0

    def accumulator(value):
        nonlocal total  # 允许修改外部变量
        total += value
        return total

    return accumulator


acc = make_accumulator()
print(acc(10))  # 10
print(acc(5))   # 15
print(acc(3))   # 18
```

### 闭包的实际应用

```python
# 函数工厂
def make_power_function(exponent):
    """函数工厂：创建指定指数的幂函数"""
    def power(base):
        return base ** exponent
    return power


square = make_power_function(2)
cube = make_power_function(3)
print(square(5))    # 25
print(cube(5))      # 125

# 记忆化
def memoize(func):
    """记忆化装饰器"""
    cache = {}

    def wrapper(*args):
        if args not in cache:
            cache[args] = func(*args)
        return cache[args]

    wrapper.cache = cache
    return wrapper


@memoize
def fibonacci(n):
    if n < 2:
        return n
    return fibonacci(n-1) + fibonacci(n-2)


print(fibonacci(100))  # 354224848179261915075
```

### 闭包陷阱

```python
# 错误：所有函数引用同一个变量
def create_functions_wrong():
    funcs = []
    for i in range(3):
        funcs.append(lambda: i)  # i 是可变变量
    return funcs


funcs = create_functions_wrong()
print([f() for f in funcs])  # [2, 2, 2]（都是最终值）

# 正确：使用默认参数捕获当前值
def create_functions_correct():
    funcs = []
    for i in range(3):
        funcs.append(lambda i=i: i)  # i=i 使用默认参数
    return funcs


funcs = create_functions_correct()
print([f() for f in funcs])  # [0, 1, 2]
```
