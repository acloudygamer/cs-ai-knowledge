# 函数

函数组织代码逻辑、避免重复编写、模块化复杂任务。函数将可复用的逻辑封装为独立单元，支持参数化输入和返回值输出。

## 核心机制

`def` 定义函数，`return` 返回结果（默认返回 `None`）。参数类型包括位置参数、关键字参数、`*args`、`**kwargs`。作用域 LEGB：Local → Enclosing → Global → Built-in。`lambda` 是单行匿名函数，适合简单转换。装饰器使用 `@wrapper` 语法，本质是函数组合。

## 函数定义

### 参考样例

```python
# 基本函数
def greet(name: str) -> str:
    """问候函数"""
    return f"Hello, {name}!"

# 多参数
def add(a: int, b: int) -> int:
    return a + b

# 无返回值（返回 None）
def print_greeting(name: str) -> None:
    print(f"Hello, {name}!")
```

## lambda 表达式

### 参考样例

```python
# lambda（单行匿名函数）
square = lambda x: x ** 2
add = lambda x, y: x + y

# lambda 与高阶函数
numbers = [1, 2, 3, 4, 5]
squared = list(map(lambda x: x ** 2, numbers))
filtered = list(filter(lambda x: x % 2 == 0, numbers))
```

## 参数类型

位置参数按顺序传递，关键字参数按名称传递。默认参数必须是不可变对象（避免可变默认参数陷阱）。`*args` 接收任意数量位置参数，`**kwargs` 接收任意数量关键字参数。Python 3.10+ 支持仅位置参数语法（`/`）和仅关键字参数语法（`*`）。

### 参考样例

```python
# 位置参数（必须参数）
def func(a, b, c):
    return a + b + c

func(1, 2, 3)  # 正确
func(1, 2)     # TypeError
func(a=1, b=2, c=3)  # 可以用关键字参数

# 默认参数
def func(a, b=10, c=20):
    return a + b + c

func(1)              # a=1, b=10, c=20
func(1, c=30)        # a=1, b=10, c=30
func(1, 5, 10)      # a=1, b=5, c=10
func(1, b=5)        # a=1, b=5, c=20

# *args（可变位置参数）
def sum_all(*args):
    return sum(args)

sum_all(1, 2, 3, 4)  # 10
sum_all()             # 0

# **kwargs（可变关键字参数）
def print_info(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")

print_info(name="Alice", age=25, city="Beijing")

# 组合使用
def func(*args, **kwargs):
    print(f"Args: {args}")
    print(f"Kwargs: {kwargs}")

func(1, 2, 3, name="test")

# 参数解包
args = (1, 2, 3)
kwargs = {"a": 4, "b": 5}
func(*args, **kwargs)

# 仅关键字参数
def func(a, *, b, c):
    """b 和 c 必须是关键字参数"""
    return a + b + c

func(1, b=2, c=3)  # 正确
func(1, 2, 3)      # TypeError

# Python 3.10+ 位置关键字
def func(a, /, b, *, c):
    """a 必须位置参数，c 必须关键字参数"""
    return a + b + c

func(1, 2, c=3)  # 正确
```

## 作用域 LEGB

变量名查找顺序：Local → Enclosing → Global → Built-in。`global` 声明使用全局变量，`nonlocal` 声明使用外层闭包变量。列表、字典等可变对象在全局和局部作用域都能修改。

### 参考样例

```python
# LEGB: Local -> Enclosing -> Global -> Built-in
x = "global"  # global

def outer():
    x = "enclosing"

    def inner():
        x = "local"      # local 作用域
        print(x)         # 打印 local

    inner()
    print(x)             # 打印 enclosing

outer()
print(x)                 # 打印 global

# global 声明使用全局变量
counter = 0

def increment():
    global counter      # 声明使用全局变量
    counter += 1

# nonlocal 声明使用外层变量
def outer():
    count = 0

    def inner():
        nonlocal count   # 声明使用外层变量
        count += 1

    inner()
    print(count)  # 1
```

## 高阶函数

函数是一等公民，可以作为参数或返回值。高阶函数接收函数参数或返回函数。闭包捕获外部变量，形成带状态的函数。

### 参考样例

```python
# map - 对每个元素应用函数
numbers = [1, 2, 3, 4, 5]
squared = list(map(lambda x: x ** 2, numbers))
print(squared)  # [1, 4, 9, 16, 25]

# filter - 过滤元素
evens = list(filter(lambda x: x % 2 == 0, numbers))
print(evens)  # [2, 4]

# reduce - 累积计算
from functools import reduce
total = reduce(lambda x, y: x + y, numbers)
print(total)  # 15

product = reduce(lambda x, y: x * y, numbers, 1)  # 带初始值
print(product)  # 120

# sorted 的 key
students = [
    {"name": "Alice", "grade": 90},
    {"name": "Bob", "grade": 85},
    {"name": "Charlie", "grade": 92}
]

sorted_students = sorted(students, key=lambda x: x["grade"])
print([s["name"] for s in sorted_students])  # ['Bob', 'Alice', 'Charlie']

# 函数工厂
def make_adder(n):
    """返回一个加 n 的函数"""
    def adder(x):
        return x + n
    return adder

add_5 = make_adder(5)
add_10 = make_adder(10)
print(add_5(3))   # 8
print(add_10(3))  # 13
```

## 偏函数

`functools.partial(func, *args, **kwargs)` 固定部分参数，常用于回调、事件处理等场景。

### 参考样例

```python
from functools import partial

def power(base, exponent):
    return base ** exponent

# 创建偏函数
square = partial(power, exponent=2)
cube = partial(power, exponent=3)

print(square(5))  # 25
print(cube(5))    # 125

# 固定第一个参数
def multiply(a, b):
    return a * b

double = partial(multiply, 2)
print(double(5))  # 10
```

## 递归

问题可分解为相同类型的子问题，且子问题规模逐渐减小时，适合用递归表达。递归需要有终止条件，防止无限递归。Python 不支持尾递归优化，但可用迭代避免栈溢出。递归深度默认限制约 1000 层。

### 参考样例

```python
# 基本递归
def factorial(n: int) -> int:
    """阶乘"""
    if n <= 1:
        return 1
    return n * factorial(n - 1)

# 斐波那契数列
def fibonacci(n: int) -> int:
    """斐波那契数列"""
    if n < 2:
        return n
    return fibonacci(n - 1) + fibonacci(n - 2)

# 迭代版本避免栈溢出
def fibonacci_iter(n: int) -> int:
    """迭代版本避免栈溢出"""
    if n < 2:
        return n
    a, b = 0, 1
    for _ in range(n - 1):
        a, b = b, a + b
    return b
```

## 函数注解

### 参考样例

```python
# 类型提示
def greet(name: str) -> str:
    """带类型注解的函数"""
    return f"Hello, {name}!"

# 多个参数
def add(a: int, b: int) -> int:
    return a + b

# 默认参数
def func(x: int, y: int = 10) -> int:
    return x + y

# *args 和 **kwargs
def func(*args: int, **kwargs: str) -> None:
    print(f"Args: {args}")
    print(f"Kwargs: {kwargs}")

# 使用 get_type_hints
from typing import get_type_hints

def greet(name: str) -> str:
    return f"Hello, {name}!"

hints = get_type_hints(greet)
print(hints)  # {'name': <class 'str'>, 'return': <class 'str'>}
```

## 常见错误

可变默认参数（如 `def func(items=[])`）会导致所有调用共享同一对象。忘记返回值导致函数返回 `None`。`*args` 和 `**kwargs` 参数顺序必须正确。

### 参考样例

```python
# 错误 - 可变默认参数
def bad_append(item, items=[]):
    items.append(item)
    return items

# 正确
def good_append(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items

# 忘记返回值
def process_data(data):
    # 处理数据但不返回
    data.append(1)

result = process_data([1, 2, 3])
print(result)  # None（应该返回结果）
```
