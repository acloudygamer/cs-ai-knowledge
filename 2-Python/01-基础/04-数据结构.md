# 数据结构

**数据结构是内存布局的抽象，决定了操作的复杂度上限。选错结构，算法再优也无用。**

## 核心复杂度

| 操作 | list | dict | set |
|------|------|------|-----|
| 索引访问 | $O(1)$ | $O(1)$ | N/A |
| 末尾追加 | $O(1)$ | $O(1)$ | $O(1)$ |
| 中间插入 | $O(n)$ | $O(n)$ | N/A |
| 查找 | $O(n)$ | $O(1)$ | $O(1)$ |

## list

### 定义

list 是动态数组实现——连续内存块，按索引可直接计算偏移访问。append 摊销 $O(1)$，insert 中间 $O(n)$。

### 数据流

<pre>
list 内存布局:
[elem0][elem1][elem2]...
   ↑
索引 i 的地址 = 基址 + i * item_size
</pre>

### 参考存根（≤20行）

```python
nums = [1, 2, 3]
nums.append(4)
nums.insert(0, 0)
nums.pop()
```

## dict

### 定义

dict 是哈希表实现——键哈希映射到桶，碰撞用开放地址或链表解决。查找/插入/删除平均 $O(1)$。Python 3.7+ 保持插入顺序。

### 数据流

<pre>
哈希函数: key → hash(key) % n_buckets → 桶索引
查找流程:
1. 计算 hash(key)
2. 定位桶
3. 线性探测/比较 key
</pre>

### 参考存根（≤20行）

```python
d = {"a": 1, "b": 2}
d["c"] = 3
d.get("d", 0)
```

## set

### 定义

set 是去重集合，哈希表结构（无值），支持交集/并集/差集等集合运算。

### 参考存根（≤20行）

```python
a, b = {1, 2, 3}, {2, 3, 4}
a | b
a & b
a - b
```

## tuple

### 定义

tuple 是不可变序列，因不可变故可哈希，可作 dict 键或 set 元素。

### 参考存根（≤20行）

```python
p = (1, 2)
x, y = p
```

## collections

### 定义

deque 是双端队列，两端 $O(1)$ 操作。defaultdict 是键不存在时自动创建默认值的字典。

### 参考存根（≤20行）

```python
from collections import deque, defaultdict
dq = deque([1, 2])
dq.appendleft(0)
dd = defaultdict(list)
dd["k"].append(1)
```
