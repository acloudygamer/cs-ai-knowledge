# 数据结构

## 解决什么问题

程序需要存储和操作一组数据，选择合适的数据结构能提高代码效率和可读性。

## 核心概念

- **list** - 有序可变序列，适合需要频繁增删的有序数据
- **dict** - 键值对映射，适合快速查找
- **set** - 无序不重复集合，适合去重和集合运算
- **tuple** - 有序不可变序列，适合固定数据结构
- **deque** - 双端队列，适合频繁在两端操作
- **defaultdict** - 带默认值的字典，避免 KeyError

## 机制解释

### 列表机制

list 是动态数组实现，索引访问 O(1)，在末尾添加 O(1)，但在中间插入/删除 O(n)。切片操作返回新列表。列表可包含任意类型对象。

### 字典机制

dict 基于哈希表实现，键必须是可哈希的不可变对象。查找、插入、删除平均复杂度 O(1)。Python 3.7+ 保持插入顺序。

### 集合机制

set 同样基于哈希表，但只存储键（无值）。集合元素必须可哈希。交集、并集、差集等操作有对应运算符支持。

### 元组机制

tuple 是不可变序列，创建后不能修改。可作为 dict 的键或 set 的元素，因其可哈希特性。

## 参考样例

### 列表 list

```python
# 创建
nums = [1, 2, 3]
mixed = [1, "hello", True, None]

# 添加
nums.append(4)              # 末尾添加
nums.insert(0, 0)           # 指定位置插入
nums.extend([5, 6])         # 合并列表

# 删除
nums.remove(3)              # 删除第一个匹配值
nums.pop()                  # 弹出末尾
nums.pop(0)                 # 弹出指定位置

# 查找
nums.index(2)              # 查找元素索引
nums.count(2)              # 计数

# 排序
nums.sort()                 # 原地排序
sorted(nums)                # 返回新列表
nums.reverse()              # 原地反转

# 切片
nums[1:3]                  # 切片
nums[::2]                  # 步长
nums[::-1]                 # 反转
```

### 字典 dict

```python
# 创建
person = {"Name": "Alice", "age": 25}
dict([("a", 1), ("b", 2)])
dict.fromkeys(["a", "b"], 0)

# 访问
person["name"]              # 键访问（不存在报错）
person.get("gender", "unknown")  # 安全访问

# 添加/修改
person["city"] = "Beijing"

# 删除
del person["age"]
person.pop("age")

# 遍历
person.keys()               # 键
person.values()             # 值
person.items()              # 键值对

# 字典方法
person.update({"age": 26})  # 批量更新
```

### 集合 set

```python
# 创建
s = {1, 2, 3}
s = set([1, 2, 2, 3])       # 从列表创建

# 添加
s.add(4)
s.update([5, 6])

# 删除
s.remove(3)                 # 不存在会报错
s.discard(10)               # 不存在不报错
s.pop()                     # 随机删除

# 集合运算
a = {1, 2, 3}
b = {2, 3, 4}
a | b                       # 并集
a & b                       # 交集
a - b                       # 差集
a ^ b                       # 对称差集

# 子集/超集
a.issubset(b)
a.issuperset(b)
```

### 元组 tuple

```python
# 创建
point = (10, 20)
t = tuple([1, 2, 3])

# 解包
x, y = point
first, *middle, last = [1, 2, 3, 4, 5]

# 命名元组
from collections import namedtuple
Point = namedtuple('Point', ['x', 'y'])
p = Point(10, 20)
print(p.x, p.y)
```

### deque

```python
from collections import deque
dq = deque([1, 2, 3])
dq.appendleft(0)
dq.append(4)
dq.popleft()
dq.pop()
```

### defaultdict

```python
from collections import defaultdict
dd = defaultdict(list)
dd["fruits"].append("apple")
```

### Counter

```python
from collections import Counter
c = Counter(["apple", "banana", "apple"])
print(c["apple"])           # 2
```
