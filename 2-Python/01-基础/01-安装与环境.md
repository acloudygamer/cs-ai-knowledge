# 安装与环境

## anaconda / venv / pip

**anaconda**: Python 数据科学发行版，预装大量科学计算库（numpy, pandas, scipy 等），适合数据分析/机器学习场景。

**venv**: Python 3.3+ 内置的轻量级虚拟环境，无需额外安装。

**pip**: Python 包管理工具，anaconda 环境自带 conda 也可管理包。

## 环境管理常用命令

### venv 虚拟环境

```bash
# 创建虚拟环境
python -m venv myenv              # 创建虚拟环境
python -m venv myenv --system-site-packages  # 包含系统包

# 激活（Linux/Mac）
source myenv/bin/activate

# 激活（Windows）
myenv\Scripts\activate

# 退出虚拟环境
deactivate

# 删除虚拟环境（直接删除目录）
rm -rf myenv
```

### pip 包管理

```bash
# 安装包
pip install requests               # 安装单个包
pip install requests==2.28.0       # 安装指定版本
pip install -r requirements.txt    # 从文件批量安装

# 查看已安装的包
pip list                           # 列出所有包
pip list --outdated                # 查看有更新的包

# 导出依赖
pip freeze > requirements.txt     # 导出到文件
pipreqs . --force                  # 从项目目录生成 requirements

# 查看包信息
pip show requests                  # 显示包详情
pip show -f requests               # 显示包详情和文件位置

# 卸载
pip uninstall requests             # 卸载单个包
pip uninstall -y -r requirements.txt  # 批量卸载

# 升级
pip install --upgrade pip          # 升级 pip
pip install -U package_name        # 升级包

# 缓存管理
pip cache purge                    # 清理 pip 缓存
```

### conda 环境管理

```bash
# 创建环境
conda create -n myenv python=3.14    # 创建 Python 3.14 环境
conda create -n myenv python=3.14 numpy pandas  # 创建并安装包

# 激活/退出
conda activate myenv                # 激活
conda deactivate                    # 退出

# 列出环境
conda env list                      # 列出所有环境
conda info --envs                   # 同上

# 克隆环境
conda create --name new_env --clone myenv

# 删除环境
conda env remove --name myenv

# 环境中的包管理
conda install requests              # 安装包
conda install numpy=1.24.0          # 安装指定版本
conda update numpy                  # 升级包
conda remove numpy                  # 卸载包

# 导出/导入环境
conda env export > env.yml          # 导出环境
conda env create --file env.yml     # 从文件创建环境

# 搜索包
conda search package_name
```

## Python 安装

### Windows

1. 下载: https://www.python.org/downloads/
2. 运行安装程序
3. **重要**: 勾选 "Add Python to PATH"
4. 选择 "Customize installation" 可自定义安装位置

```bash
# 验证安装
python --version
pip --version

# 如果有多个版本
py -3.14 --version
py -3.13 --version
```

### macOS

```bash
# 使用 Homebrew 安装
brew install python@3.14

# 或者使用 pyenv 管理多版本
brew install pyenv
pyenv install 3.14.0
pyenv global 3.14.0
```

### Linux (Ubuntu/Debian)

```bash
# 使用 apt 安装
sudo apt update
sudo apt install python3 python3-pip python3-venv

# 或使用 deadsnakes PPA 安装特定版本
sudo add-apt-repository ppa:deadsnakes/ppa
sudo apt install python3.14 python3.14-venv python3.14-dev
```

### 多版本共存（pyenv）

```bash
# 安装 pyenv
curl https://pyenv.run | bash

# 配置 shell（~/.bashrc 或 ~/.zshrc）
export PYENV_ROOT="$HOME/.pyenv"
export PATH="$PYENV_ROOT/bin:$PATH"
eval "$(pyenv init -)"

# 安装 Python 版本
pyenv install 3.14.0
pyenv install 3.15.0

# 设置全局/局部版本
pyenv global 3.14.0              # 全局
pyenv local 3.15.0               # 当前目录
```

## 常见问题排查

### 1. pip 安装失败

```bash
# 升级 pip
python -m pip install --upgrade pip

# 使用国内镜像
pip install package_name -i https://pypi.tuna.tsinghua.edu.cn/simple

# 永久设置镜像
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
```

### 2. 虚拟环境激活失败（Windows PowerShell）

```powershell
# 允许执行脚本
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

# 或使用
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

### 3. 解决依赖冲突

```bash
# 创建新虚拟环境
python -m venv newenv

# 或使用 pip-tools
pip install pip-tools
pip-compile requirements.in  # 生成锁定版本的依赖
pip-sync requirements.txt     # 同步到环境
```

### 4. 多版本 Python 切换

```bash
# Windows 使用 py
py -3.14 -m venv venv314
py -3.13 -m venv venv313

# Linux/Mac 使用 pyenv
pyenv local 3.14.0
```

### 5. Jupyter Notebook 切换环境

```bash
# 安装 ipykernel
pip install ipykernel

# 添加环境到 Jupyter
python -m ipykernel install --user --name=myenv --display-name "Python (myenv)"

# 移除
jupyter kernelspec uninstall myenv
```
