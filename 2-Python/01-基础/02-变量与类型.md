# 变量与类型

Python 是动态类型语言，变量无需声明类型，解释器在运行时自动推断。类型注解仅用于类型提示，不影响运行行为。

## 解决什么问题

需要理解 Python 的动态类型特性、如何使用类型注解提升代码可读性和可靠性。

## 核心概念

- 变量无需声明类型，解释器自动推断
- 类型注解仅用于类型提示，不影响运行时行为
- 支持 PEP 484 类型注解语法（Python 3.5+），现代代码更多使用内置语法
- 运行时类型检查使用 `isinstance()`，类型提示使用 `typing` 模块

## 怎么用

```python
# 动态类型
x = 10          # int
x = "hello"     # str，可以随时改变类型
x = [1, 2, 3]   # list

# 静态类型（如需）使用类型注解
name: str = "Alice"
age: int = 25
scores: list[int] = [90, 85, 88]
```

## 类型注解 typing

```python
# 基础类型注解
name: str = "Alice"
age: int = 25
scores: list[float] = [90.5, 85.0]
person: dict[str, Any] = {"name": "Bob"}

# 泛型注解
def process(items: list[int]) -> list[int]:
    return [x * 2 for x in items]

def lookup(users: dict[str, int], key: str) -> int | None:
    return users.get(key)

# 联合类型（多种可能）
ID = int | str

# 类型别名
Matrix = list[list[float]]
Vector = tuple[float, float, float]

# Callable（可调用对象）
from typing import Callable, TypeVar, Generic

T = TypeVar('T')

def apply(func: Callable[[int], int], x: int) -> int:
    return func(x)

# 复杂类型

def first(lst: list[T]) -> T | None:
    return lst[0] if lst else None
```

## 类型检查

```python
# 运行时类型检查
isinstance(42, int)         # True
isinstance("hello", str)    # True
isinstance([1, 2], list)    # True

# 类型转换
int("42")                   # 42
float("3.14")              # 3.14
str(42)                     # "42"
list("hello")               # ['h', 'e', 'l', 'l', 'o']
```
