# 函数

## 解决什么问题

组织代码逻辑、避免重复编写、模块化复杂任务。函数将可复用的逻辑封装为独立单元，支持参数化输入和返回值输出。

## 核心概念

- `def` 定义函数，`return` 返回结果（默认返回 `None`）
- 参数类型：位置参数、关键字参数、`*args`、`**kwargs`
- 作用域 LEGB：Local → Enclosing → Global → Built-in
- `lambda` 是单行匿名函数，适合简单转换
- 装饰器使用 `@wrapper` 语法，本质是函数组合

## 怎么用

## def / lambda

### 函数定义

```python
# 基本函数
def greet(name: str) -> str:
    """问候函数"""
    return f"Hello, {name}!"

# 多参数
def add(a: int, b: int) -> int:
    return a + b

# 无返回值（返回 None）
def print_greeting(name: str) -> None:
    print(f"Hello, {name}!")
```

### lambda 表达式

```python
# lambda（单行匿名函数）
square = lambda x: x ** 2
add = lambda x, y: x + y

# lambda 不支持类型注解语法，需通过变量标注或 Callable
from typing import Callable
add: Callable[[int, int], int] = lambda x, y: x + y

# lambda 与高阶函数
numbers = [1, 2, 3, 4, 5]
squared = list(map(lambda x: x ** 2, numbers))
filtered = list(filter(lambda x: x % 2 == 0, numbers))
```

## 参数类型

### 解决什么问题

函数需要灵活接收各种形式的输入：必选参数、可选默认值、不定量参数等。

### 核心概念

- 位置参数按顺序传递，关键字参数按名称传递
- 默认参数必须是不可变对象（避免可变默认参数陷阱）
- `*args` 接收任意数量位置参数，`**kwargs` 接收任意数量关键字参数
- Python 3.10+ 支持仅位置参数语法（`/`）和仅关键字参数语法（`*`）

### 怎么用

### 位置参数和关键字参数

```python
# 位置参数（必须参数）
def func(a, b, c):
    return a + b + c

func(1, 2, 3)  # 正确
func(1, 2)     # TypeError
func(a=1, b=2, c=3)  # 可以用关键字参数

# 关键字参数
func(a=1, b=2, c=3)
func(1, 2, c=3)  # 混合使用
```

### 默认参数

```python
def func(a, b=10, c=20):
    return a + b + c

func(1)              # a=1, b=10, c=20
func(1, c=30)        # a=1, b=10, c=30
func(1, 5, 10)      # a=1, b=5, c=10
func(1, b=5)        # a=1, b=5, c=20

# 重要：默认参数应该是不可变对象
# 错误示例
def bad_func(items=[]):  # 可变默认参数！
    items.append(1)
    return items

# 正确示例
def good_func(items=None):
    if items is None:
        items = []
    items.append(1)
    return items
```

### *args 和 **kwargs

```python
# *args（可变位置参数）
def sum_all(*args):
    return sum(args)

sum_all(1, 2, 3, 4)  # 10
sum_all()             # 0

# **kwargs（可变关键字参数）
def print_info(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")

print_info(name="Alice", age=25, city="Beijing")
# name: Alice
# age: 25
# city: Beijing

# 组合使用
def func(*args, **kwargs):
    print(f"Args: {args}")
    print(f"Kwargs: {kwargs}")

func(1, 2, 3, name="test")
# Args: (1, 2, 3)
# Kwargs: {'name': 'test'}

# 参数解包
args = (1, 2, 3)
kwargs = {"a": 4, "b": 5}
func(*args, **kwargs)
# Args: (1, 2, 3)
# Kwargs: {'a': 4, 'b': 5}
```

### 仅关键字参数

```python
# 使用 * 分隔强制关键字参数
def func(a, *, b, c):
    """b 和 c 必须是关键字参数"""
    return a + b + c

func(1, b=2, c=3)  # 正确
func(1, 2, 3)      # TypeError

# Python 3.10+ 支持位置关键字
def func(a, /, b, *, c):
    """a 必须位置参数，c 必须关键字参数"""
    return a + b + c

func(1, 2, c=3)  # 正确
func(1, b=2, c=3)  # 正确
```

## 作用域 LEGB

### 解决什么问题

变量名在不同作用域可能有不同含义，需要规则来明确查找顺序，避免意外修改全局变量。

### 核心概念

- LEGB 查找顺序：Local → Enclosing → Global → Built-in
- `global` 声明使用全局变量，`nonlocal` 声明使用外层闭包变量
- 列表、字典等可变对象在全局和局部作用域都能修改

### 怎么用

### 作用域规则

```python
# LEGB: Local -> Enclosing -> Global -> Built-in

x = "global"  # global

def outer():
    x = "enclosing"

    def inner():
        x = "local"      # local 作用域
        print(x)         # 打印 local

    inner()
    print(x)             # 打印 enclosing

outer()
print(x)                 # 打印 global
```

### global 和 nonlocal

```python
# global 声明使用全局变量
counter = 0

def increment():
    global counter      # 声明使用全局变量
    counter += 1

# nonlocal 声明使用外层变量
def outer():
    count = 0

    def inner():
        nonlocal count   # 声明使用外层变量
        count += 1

    inner()
    print(count)  # 1
```

### 内置作用域

```python
# 内置函数和异常
print(len("hello"))  # 5
print(max([1, 2, 3]))  # 3

# 内置作用域可以通过 builtins 模块访问
import builtins
print(builtins.len("hello"))  # 5
```

## 匿名函数进阶

### 解决什么问题

需要简短转换或过滤逻辑时，不需要单独定义函数，使用 lambda 表达式更简洁。

### 核心概念

- `lambda` 是单行匿名函数，适合简单计算
- `map(func, iterable)` 对每个元素执行函数
- `filter(predicate, iterable)` 保留满足条件的元素
- `functools.reduce(func, iterable, init)` 累积计算

### 怎么用

### map 和 filter

```python
numbers = [1, 2, 3, 4, 5]

# map - 对每个元素应用函数
squared = list(map(lambda x: x ** 2, numbers))
print(squared)  # [1, 4, 9, 16, 25]

# filter - 过滤元素
evens = list(filter(lambda x: x % 2 == 0, numbers))
print(evens)  # [2, 4]

# 结合使用
result = sum(map(lambda x: x ** 2, filter(lambda x: x % 2 == 0, numbers)))
print(result)  # 4 + 16 = 20
```

### reduce

```python
from functools import reduce

numbers = [1, 2, 3, 4, 5]

# reduce - 累积计算
total = reduce(lambda x, y: x + y, numbers)
print(total)  # 15

product = reduce(lambda x, y: x * y, numbers, 1)  # 带初始值
print(product)  # 120

# 求最大值
max_val = reduce(lambda a, b: a if a > b else b, numbers)
print(max_val)  # 5
```

### sorted 的 key

```python
students = [
    {"name": "Alice", "grade": 90},
    {"name": "Bob", "grade": 85},
    {"name": "Charlie", "grade": 92}
]

# 按成绩排序
sorted_students = sorted(students, key=lambda x: x["grade"])
print([s["name"] for s in sorted_students])  # ['Bob', 'Alice', 'Charlie']

# 降序排序
sorted_students = sorted(students, key=lambda x: x["grade"], reverse=True)
print([s["name"] for s in sorted_students])  # ['Charlie', 'Alice', 'Bob']
```

## 递归

### 解决什么问题

问题可以分解为相同类型的子问题，且子问题规模逐渐减小，适合用递归表达。

### 核心概念

- 递归需要有终止条件，防止无限递归
- Python 不支持尾递归优化，但可用迭代避免栈溢出
- 递归深度默认限制约 1000 层

### 怎么用

### 基本递归

```python
def factorial(n: int) -> int:
    """阶乘"""
    if n <= 1:
        return 1
    return n * factorial(n - 1)

# 斐波那契数列
def fibonacci(n: int) -> int:
    """斐波那契数列"""
    if n < 2:
        return n
    return fibonacci(n - 1) + fibonacci(n - 2)
```

### 尾递归优化

Python 不支持尾递归优化，但可以用改写避免栈溢出：

```python
def factorial_tail(n: int, acc: int = 1) -> int:
    """尾递归形式的阶乘"""
    if n <= 1:
        return acc
    return factorial_tail(n - 1, n * acc)

def fibonacci_iter(n: int) -> int:
    """迭代版本避免栈溢出"""
    if n < 2:
        return n
    a, b = 0, 1
    for _ in range(n - 1):
        a, b = b, a + b
    return b
```

## 偏函数

### 解决什么问题

需要固定函数的部分参数，创建一个新函数用于后续调用。

### 核心概念

- `functools.partial(func, *args, **kwargs)` 固定部分参数
- 偏函数常用于回调、事件处理等场景

### 怎么用

### functools.partial

```python
from functools import partial

def power(base, exponent):
    return base ** exponent

# 创建偏函数
square = partial(power, exponent=2)
cube = partial(power, exponent=3)

print(square(5))  # 25
print(cube(5))    # 125

# 固定第一个参数
def multiply(a, b):
    return a * b

double = partial(multiply, 2)
print(double(5))  # 10
```

## 函数作为返回值

### 解决什么问题

需要动态生成定制化函数，或在函数间传递可执行逻辑。

### 核心概念

- 函数是一等公民，可以作为参数或返回值
- 高阶函数接收函数参数或返回函数
- 闭包捕获外部变量，形成带状态的函数

### 怎么用

### 高阶函数

```python
def make_adder(n):
    """返回一个加 n 的函数"""
    def adder(x):
        return x + n
    return adder

add_5 = make_adder(5)
add_10 = make_adder(10)

print(add_5(3))   # 8
print(add_10(3))  # 13
```

## 常见错误

### 解决什么问题

函数使用中的常见陷阱，导致意外行为或难以发现的 bug。

### 核心概念

- 可变默认参数（如 `def func(items=[])`）会导致所有调用共享同一对象
- 忘记返回值导致函数返回 `None`
- `*args` 和 `**kwargs` 参数顺序必须正确

### 怎么用

### 可变默认参数

```python
# 错误
def bad_append(item, items=[]):
    items.append(item)
    return items

# 正确
def good_append(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items
```

### 忘记返回值

```python
def process_data(data):
    # 处理数据但不返回
    data.append(1)

result = process_data([1, 2, 3])
print(result)  # None（应该返回结果）
```
