# 面向对象编程

**类是对象的工厂，对象是状态+行为的封装，继承是接口复用，Protocol 是结构子类型。**

## class 基础

### 定义

class 是创建实例的模板，`__init__` 是构造器（实例级初始化），实例属性存储在 `__dict__` 中。

### 数据流

<pre>
class Dog:
    species = "Canis"      # 类属性 → 类.__dict__
    def __init__(self, name):
        self.name = name   # 实例属性 → dog.__dict__
</pre>

### 参考存根（≤20行）

```python
class Dog:
    species = "Canis"
    def __init__(self, name: str):
        self.name = name
    def bark(self) -> str: return f"{self.name} says woof!"
Dog("Buddy").bark()
```

## 继承与 MRO

### 定义

继承建立"是-a"关系，子类复用父类接口。MRO（方法解析顺序）由 C3 线性化算法决定，决定属性查找路径。

### 数据流

<pre>
class D(B, C):
    pass
# MRO: D → B → C → A → object
# d.greet() 查找顺序: D → B → C → A
</pre>

### 参考存根（≤20行）

```python
class A:
    def greet(self): return "A"
class B(A): pass
class C(A): pass
class D(B, C): pass
D().greet()
D.__mro__
```

## Protocol

### 定义

Protocol 定义结构子类型——只要对象有指定方法，即使不继承也算兼容，是静态类型检查的接口契约。

### 参考存根（≤20行）

```python
from typing import Protocol
class Closable(Protocol):
    def close(self) -> None: ...
class Resource:
    def close(self) -> None: pass
isinstance(Resource(), Closable)
```

## ABC

### 定义

ABC（抽象基类）强制子类实现抽象方法，是接口契约的运行时检查，比 Protocol 更强（不可实例化抽象类）。

### 参考存根（≤20行）

```python
from abc import ABC, abstractmethod
class Shape(ABC):
    @abstractmethod
    def area(self) -> float: ...
```

## 组合 vs 继承

### 定义

继承表达"是-a"，组合表达"有-a"。优先组合——组合更松耦合，更易测试。

### 参考存根（≤20行）

```python
class Engine: pass
class Car:
    def __init__(self):
        self.engine = Engine()
```

## property

### 定义

@property 将方法转为属性访问，本质是描述符协议，实现 getter/setter/deleter 控制读写。

### 参考存根（≤20行）

```python
class T:
    def __init__(self): self._c = 0
    @property
    def c(self): return self._c
    @c.setter
    def c(self, v): self._c = v
```

## dataclass

### 定义

@dataclass 自动生成 `__init__`/`__repr__`/`__eq__` 样板代码，适合纯数据承载类。

### 参考存根（≤20行）

```python
from dataclasses import dataclass
@dataclass
class Point:
    x: float
    y: float
```

## 魔术方法

### 定义

魔术方法（Dunder Methods）是解释器回调的钩子，`__eq__`/`__hash__` 控制相等性，`__lt__` 控制排序，`__enter__`/`__exit__` 控制上下文。

### 参考存根（≤20行）

```python
class Count:
    def __init__(self): self.n = 0
    def __call__(self): self.n += 1; return self.n
c = Count()
c()
```

## Enum

### 定义

Enum 是具名常量集合，成员值相同则为别名，通过 `EnumName.value` 访问值，通过 `EnumName.name` 访问名字。

### 参考存根（≤20行）

```python
from enum import Enum, auto
class Color(Enum):
    RED = auto()
    GREEN = auto()
Color.RED.value
```
