# 面向对象编程

## 解决什么问题

将数据和操作数据的方法组织在一起，模拟现实世界实体的行为和关系。

## 核心概念

- 类是模板，实例是根据类创建的对象
- `__init__` 初始化实例属性
- 继承实现"是-a"关系，组合实现"有-a"关系
- MRO（方法解析顺序）决定多继承时的查找顺序
- `Protocol` 定义结构子类型（类似接口）

## 怎么用

## class 基础

```python
# 定义类
class Dog:
    # 类属性（所有实例共享）
    species = "Canis familiaris"

    # 实例属性（在 __init__ 中定义）
    def __init__(self, name: str, age: int):
        self.name = name
        self.age = age

    # 实例方法
    def bark(self) -> str:
        return f"{self.name} says woof!"

    # repr 用于调试
    def __repr__(self) -> str:
        return f"Dog(name={self.name!r}, age={self.age})"

# 创建实例
my_dog = Dog("Buddy", 3)
print(my_dog.bark())  # Buddy says woof!
print(my_dog.species)  # Canis familiaris

# 类型检查
isinstance(my_dog, Dog)  # True
```

## 继承

### 解决什么问题

多个类有共同属性和方法时，避免代码重复，建立类型层次关系。

### 核心概念

- 单继承直接了当，多继承需注意 MRO 顺序
- `super()` 按 MRO 顺序调用父类方法
- 优先使用组合而非继承，除非"是-a"关系明确

### 怎么用

```python
# 单继承
class Animal:
    def __init__(self, name: str):
        self.name = name

    def speak(self) -> str:
        raise NotImplementedError


class Cat(Animal):
    def speak(self) -> str:
        return f"{self.name} says meow!"


class Dog(Animal):
    def speak(self) -> str:
        return f"{self.name} says woof!"


cat = Cat("Whiskers")
print(cat.speak())  # Whiskers says meow!

# 多继承（慎用，优先用组合）
class Pet:
    def __init__(self, name: str, owner: str):
        self.name = name
        self.owner = owner


class ShowDog(Dog, Pet):
    """多继承：同时继承 Dog 和 Pet"""

    def __init__(self, name: str, age: int, owner: str, title: str = ""):
        Dog.__init__(self, name, age)
        Pet.__init__(self, name, owner)
        self.title = title

    def bark(self) -> str:
        return f"{self.title}{self.name} competes!".upper()
```

## MRO（方法解析顺序）

```python
# Python 使用 C3 线性化算法确定方法查找顺序
class A:
    def greet(self):
        return "A"


class B(A):
    def greet(self):
        return "B"


class C(A):
    def greet(self):
        return "C"


class D(B, C):
    pass


d = D()
print(d.greet())       # B（MRO: D -> B -> C -> A）
print(D.__mro__)       # 查看完整 MRO
# (<class 'D'>, <class 'B'>, <class 'C'>, <class 'A'>, <class 'object'>)

# super() 按照 MRO 顺序调用
class Base:
    def __init__(self):
        print("Base init")


class Child(Base):
    def __init__(self):
        super().__init__()  # 调用 Base.__init__
        print("Child init")


Child()
# Base init
# Child init
```

## ABC（抽象基类）

### 解决什么问题

需要定义子类必须实现的方法，强制接口契约。

### 核心概念

- `@abstractmethod` 装饰的方法子类必须实现
- 抽象类可以提供具体方法供子类复用
- `Protocol` 更灵活，适合结构子类型

### 怎么用

```python
from abc import ABC, abstractmethod


class Shape(ABC):
    @abstractmethod
    def area(self) -> float:
        """计算面积"""
        pass

    @abstractmethod
    def perimeter(self) -> float:
        """计算周长"""
        pass

    def describe(self) -> str:
        """具体方法（可选）"""
        return f"A shape with area {self.area()}"


class Rectangle(Shape):
    def __init__(self, width: float, height: float):
        self.width = width
        self.height = height

    def area(self) -> float:
        return self.width * self.height

    def perimeter(self) -> float:
        return 2 * (self.width + self.height)


# Shape()  # TypeError: Can't instantiate abstract class Shape
rect = Rectangle(3, 4)
print(rect.area())  # 12
```

## Protocol（结构子类型）

### 解决什么问题

需要定义"有某个方法"的类型契约，而不依赖继承关系（类似 Go 的接口）。

### 核心概念

- `Protocol` 定义方法签名，子类只需实现这些方法
- `@runtime_checkable` 允许 `isinstance()` 检查
- PEP 695 语法（Python 3.12+）使用更简洁的类型参数声明

### 怎么用

```python
from typing import Protocol, runtime_checkable


# 定义 Protocol（类似接口）
@runtime_checkable
class Closable(Protocol):
    def close(self) -> None:
        ...


class Resource:
    def close(self) -> None:
        print("Closing resource")


# 静态类型检查器认可，runtime_checkable 允许 isinstance 检查
r = Resource()
isinstance(r, Closable)  # True（因为有 close 方法）


# 函数参数使用 Protocol
def close_all(things: list[Closable]) -> None:
    for thing in things:
        thing.close()


# 复杂 Protocol
class SupportsLessThan(Protocol):
    def __lt__(self, other) -> bool:
        ...
```

### 参考样例

```python
# PEP 695 语法（Python 3.12+，类型提示惰性求值在 Python 3.14 进一步改进）
def find_min[T: SupportsLessThan](items: list[T]) -> T | None:
    if not items:
        return None
    min_item = items[0]
    for item in items[1:]:
        if item < min_item:
            min_item = item
    return min_item
```

**兼容写法（Python 3.9+）**：

```python
from typing import TypeVar

T = TypeVar('T', bound=SupportsLessThan)

def find_min(items: list[T]) -> T | None:
    if not items:
        return None
    min_item = items[0]
    for item in items[1:]:
        if item < min_item:
            min_item = item
    return min_item
```

## 组合 vs 继承

### 解决什么问题

代码复用时，选择继承还是组合影响系统的灵活性和可维护性。

### 核心概念

- 继承表达"是-a"关系（猫是动物）
- 组合表达"有-a"关系（车有引擎）
- 优先使用组合，提高灵活性和可测试性

### 怎么用

```python
# 优先组合，慎用继承
class Engine:
    def start(self):
        print("Engine started")


class Wheel:
    def rotate(self):
        print("Wheel rotating")


# 组合（推荐）
class Car:
    def __init__(self):
        self.engine = Engine()  # 组合
        self.wheels = [Wheel() for _ in range(4)]

    def drive(self):
        self.engine.start()
        for wheel in self.wheels:
            wheel.rotate()


# 继承（仅当"是-a"关系明确时使用）
class ElectricCar(Car):  # 电动车是汽车
    def __init__(self):
        super().__init__()
        self.battery = 100

    def charge(self):
        print("Charging...")
```

## 属性 property

### 解决什么问题

需要控制属性的访问、修改和删除，添加验证逻辑或计算属性。

### 核心概念

- `@property` 装饰器将方法转为属性访问
- 可以定义 `@setter` 和 `@deleter` 控制写入和删除
- 计算属性每次访问时重新计算

### 怎么用

```python
# getter / setter / deleter
class Temperature:
    def __init__(self, celsius: float = 0):
        self._celsius = celsius

    @property
    def celsius(self) -> float:
        return self._celsius

    @celsius.setter
    def celsius(self, value: float):
        self._celsius = value

    @celsius.deleter
    def celsius(self):
        print("Deleting temperature")
        del self._celsius

    # 华氏温度（计算属性）
    @property
    def fahrenheit(self) -> float:
        return self._celsius * 9 / 5 + 32


t = Temperature(25)
print(t.fahrenheit)  # 77.0
t.fahrenheit = 100
print(t.celsius)     # ~37.78
```

## __slots__

### 解决什么问题

需要限制实例属性，减少内存占用，提升属性访问速度。

### 核心概念

- `__slots__` 限制实例只能拥有指定的属性
- 不能动态添加 `__slots__` 中未定义的属性
- 配合继承使用时，子类也需要定义 `__slots__`

### 怎么用

```python
# 限制实例属性，减少内存占用
class Point:
    __slots__ = ('x', 'y')

    def __init__(self, x, y):
        self.x = x
        self.y = y


# Point 实例不能再添加其他属性
p = Point(1, 2)
p.z = 3  # AttributeError

# 结合继承（父类有 __slots__，子类也要有才能优化）
class LabeledPoint(Point):
    __slots__ = ('label',)
```

## 常见陷阱

### 解决什么问题

面向对象编程中的常见错误，避免写出难以调试的代码。

### 核心概念

- 可变默认参数导致实例共享数据
- 类属性 vs 实例属性的区别
- 多继承时的菱形继承歧义
- 忘记调用 `super().__init__`

### 怎么用

```python
# 陷阱1：可变默认参数
class Node:
    def __init__(self, children=None):  # 错误！
        self.children = children or []

    def add_child(self, child):
        self.children.append(child)


# 正确做法
class Node:
    def __init__(self, children=None):
        self.children = list(children) if children else []

    def add_child(self, child):
        self.children.append(child)


# 陷阱2：类属性 vs 实例属性
class Counter:
    count = 0  # 类属性（共享）

    def __init__(self):
        self.count += 1  # 创建实例属性，遮蔽类属性


c1 = Counter()
print(c1.count)  # 1（实例属性）
print(Counter.count)  # 0（类属性未被修改）

# 正确做法
class Counter:
    count = 0

    def __init__(self):
        Counter.count += 1


# 陷阱3：忘记调用 super().__init__
class Child(Base):
    def __init__(self, extra_param):
        self.extra = extra_param
        # 忘记 super().__init__()，Base 的属性未初始化


# 陷阱4：多继承时的菱形继承歧义
class A:
    def process(self):
        print("A")


class B(A):
    pass


class C(A):
    def process(self):
        print("C")


class D(B, C):
    pass


D().process()  # C（按 MRO，B -> C -> A）
```
