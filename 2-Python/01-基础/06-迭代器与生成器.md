# 迭代器与生成器

**迭代器是惰性数据的抽象协议，生成器是惰性数据的工程实现，两者本质都是"按需计算"以节省内存。**

## 迭代器协议

### 定义

迭代器必须实现 `__iter__` 返回 self、`__next__` 返回下一元素或抛 StopIteration。可迭代对象只需实现 `__iter__`。

### 数据流

<pre>
for item in iterable:
    # 等价于:
    it = iter(iterable)
    while True:
        try: item = next(it)
        except StopIteration: break
</pre>

### 参考存根（≤20行）

```python
class Counter:
    def __init__(self, n): self.n, self.i = n, 0
    def __iter__(self): return self
    def __next__(self):
        if self.i >= self.n: raise StopIteration
        self.i += 1; return self.i
list(Counter(3))
```

## 生成器函数

### 定义

包含 yield 的函数自动成为生成器函数，调用它返回生成器对象，每次 next() 执行到下一个 yield 暂停。

### 参考存根（≤20行）

```python
def countdown(n):
    while n > 0:
        yield n
        n -= 1
list(countdown(3))
```

## 生成器表达式

### 定义

类似列表推导式但用圆括号，惰性求值，不创建中间列表，适合处理大数据或无限序列。

### 参考存根（≤20行）

```python
gen = (x**2 for x in range(5))
list(gen)
```

## yield from

### 定义

yield from 委托给子生成器，实现生成器组合，等价于手动迭代并 yield 每个元素。

### 参考存根（≤20行）

```python
def flat(lst):
    for item in lst:
        if isinstance(item, (list, tuple)):
            yield from flat(item)
        else: yield item
list(flat([1, [2, 3]]))
```

## itertools

### 定义

itertools 提供三类惰性迭代器：无限迭代器（count/cycle/repeat）、有限迭代器（chain/islice/filterfalse）、组合迭代器（product/permutations/combinations）。

### 参考存根（≤20行）

```python
from itertools import count, islice
list(islice(count(1), 5))
list(islice((x**2 for x in range(5)), 2))
```

## 生成器方法

### 定义

`send()` 向生成器注入值实现双向通信，`throw()` 注入异常，`close()` 强制终止。

### 参考存根（≤20行）

```python
def echo():
    while True:
        v = yield
        print(v)
g = echo()
next(g)
g.send(1)
```

## 生成器 vs 列表

| 特性 | 生成器 | 列表 |
|------|--------|------|
| 内存 | 按需 $O(1)$ | 预分配 $O(n)$ |
| 迭代 | 一次 | 多次 |
| 索引 | 不支持 | 支持 |
| 长度 | 未知 | 已知 |

## 核心机制

### 为什么生成器省内存

<pre>
列表: 先算完 [f(1), f(2), ..., f(1000000)] 再迭代
生成器: 每次只算一个值，用完即弃
对于 sum(f(x) for x in range(1000000)):
  列表需要存储 1000000 个对象
  生成器只需存储生成器对象本身
</pre>

### 生成器只能迭代一次的原因

生成器是状态机，迭代过程消耗状态。一旦穷尽，内部状态无法重置，只能重建生成器对象。
