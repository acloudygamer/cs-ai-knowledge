# Web 开发

Python 生态中三大主流 Web 框架，覆盖从轻量级到企业级的开发场景。

## 目录

- [01-FastAPI快速入门](01-FastAPI快速入门.md) - 现代高性能 API 框架，基于类型提示，支持异步
- [02-Django基础](02-Django基础.md) - 高级 "batteries included" 框架，MTV 架构
- [03-Flask基础](03-Flask基础.md) - 轻量级微框架，核心简单但扩展丰富

## 框架选择指南

| 框架 | 定位 | 适用场景 | 学习曲线 |
|------|------|----------|----------|
| FastAPI | 现代高性能 API | 微服务、实时 API、异步应用 | 低 |
| Django | 企业级全栈 | 大型 Web 应用、管理后台 | 中 |
| Flask | 轻量微框架 | 小型应用、原型开发、定制化需求 | 低 |
