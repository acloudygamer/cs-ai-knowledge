# 适配器模式

适配器模式是一种结构型模式，它将一个类的接口转换成客户期望的另一个接口，使原本不兼容的类可以一起工作。

## 本质

```
Client（期望的接口）
    │
    └── Adapter ──→ Adaptee（不兼容的接口）
                    └─ specific_request()
                          │
                          └── 转换逻辑（参数映射、返回值调整）
```

**为什么需要适配器**：集成第三方库或遗留代码时，其接口与当前系统不匹配；适配器在两者之间做转换，使客户端无感知差异，无需修改被适配对象。

**类适配器 vs 对象适配器**：
- 类适配器（多重继承）：通过继承获取被适配类的方法，可直接调用 `super()`；但不支持"同时适配多个对象"
- 对象适配器（组合）：持有被适配对象引用，更灵活，可适配被适配对象的所有子类

## 类适配器

多重继承让适配器同时拥有目标接口和被适配类的接口。

```python
class Target:
    def request(self) -> str:
        return "Target: Default"

class Adaptee:
    def specific_request(self) -> str:
        return ".eetpadA eht fo roivaheb laicepS"

class ClassAdapter(Adaptee, Target):
    def request(self) -> str:
        return self.specific_request()[::-1]
```

## 对象适配器

通过组合持有被适配对象，更符合合成复用原则。

```python
class ObjectAdapter(Target):
    def __init__(self, adaptee: Adaptee):
        self._adaptee = adaptee

    def request(self) -> str:
        return self._adaptee.specific_request()[::-1]
```

## 双向适配器

同时支持两个接口方向的转换，使两个不兼容接口可以互相调用。

```python
class OldAPI:
    def get_user_data(self) -> dict:
        return {"user_name": "Alice", "user_age": 30}

class NewAPI:
    def fetch_user(self) -> dict:
        return {"name": "Bob", "age": 25}

class BidirectionalAdapter:
    def __init__(self, api):
        self._api = api

    def fetch_user(self):
        data = self._api.get_user_data()
        return {"name": data.get("user_name", ""),
                "age": data.get("user_age", 0)}

    def get_user_data(self):
        data = self._api.fetch_user()
        return {"user_name": data.get("name", ""),
                "user_age": data.get("age", 0)}
```

## 类适配器 vs 对象适配器

| | 类适配器 | 对象适配器 |
|---|---|---|
| 机制 | 多重继承 | 组合 |
| 灵活性 | 无法适配多个被适配对象 | 可适配被适配对象的任意子类 |
| 覆盖行为 | 可直接覆盖被适配类方法 | 通过委托处理 |
| 耦合 | 与被适配类强耦合 | 被适配类独立 |
