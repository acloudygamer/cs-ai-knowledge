# 01-Python视角下的设计模式

> 前置：[05-函数](../01-语言核心/05-函数.md)（一等函数与装饰器）、[07-面向对象](../01-语言核心/07-面向对象.md)（协议与 dataclass） · 后续：[02-创建型模式](02-创建型模式.md)、[03-结构型模式](03-结构型模式.md)、[04-行为型模式](04-行为型模式.md)

GoF（1994）的 23 个模式诞生于 C++/Smalltalk 时代：没有一等函数、没有垃圾回收、没有运行时类型内省。Python 把这些语言级能力内建后，**一批模式隐形了、一批退化成一行语法、只有少数仍值得手写**。本篇给 23 个模式在 Python 里的"判决表"，并保留那些与语言无关、永远有效的部分——设计原则。

## 本质

- 模式是**语言缺口的补丁**（"pattern is a where language is missing a feature"）：同一问题在不同语言里是模式（Java 的 Strategy 接口族）还是语法（Python 传个函数），取决于语言给了什么。带着这副眼镜读 GoF，23 个模式在 Python 里分成四类：

| 判决 | 含义 | 数量感 | 例 |
|---|---|---|---|
| 语言已内建 | 直接用语法，别手写结构 | 约 1/4 | Iterator、Observer（回调）、Decorator（@） |
| 一行替代 | 核心机制（函数/协议）让样板消失 | 约 1/2 | Strategy=传函数、Command=可调用对象 |
| 仍需手写 | 结构复杂度是本质的，语言帮不上 | 少数 | Composite、责任链（中间件） |
| 通常不需要 | 动态性使问题本身消失 | 少数 | Abstract Factory、Memento |

- 设计**原则**不随语言过期（下节），模式**实现**随语言过期——本组四篇按此组织：原则在这篇，实现按创建/结构/行为三类各一篇。

## 机制

### 永远有效的六条原则（模式的"为什么"）

| 原则 | 一句话 | Python 对应物 |
|---|---|---|
| 组合优于继承 | "能做"委托给成员，比"是什么"继承更松 | [07-面向对象](../01-语言核心/07-面向对象.md) 的 mixin 判据 |
| 面向接口编程 | 依赖形状而非血统 | Protocol（[07-面向对象](../01-语言核心/07-面向对象.md)、[11-类型提示](../01-语言核心/11-类型提示.md)） |
| 开闭原则 | 加行为靠扩展不靠改源 | 传函数/插件注册（[10-模块与导入系统](../01-语言核心/10-模块与导入系统.md)） |
| 依赖倒置 | 高层定义接口，低层实现它 | 构造函数注入（本组各篇示例反复出现） |
| 单一职责 | 一个模块一个变化理由 | 模块划分本身（[10-模块与导入系统](../01-语言核心/10-模块与导入系统.md)） |
| 最小知识 | 只跟直接朋友说话 | Facade（[03-结构型模式](03-结构型模式.md)） |

### GoF 23 模式 Python 判决表（本组路线图）

| 类别 | 语言内建 / 一行替代 | 仍需手写 |
|---|---|---|
| 创建 | 单例（import 即单例）、工厂方法（classmethod 备选构造） | Builder（参数爆炸时） |
| 结构 | 装饰器（@ 语法）、门面（`__init__.py`）、适配器（协议+薄包装） | Composite（树形结构）、代理（惰性/远端）、责任链归行为 |
| 行为 | 策略（传函数）、命令（可调用对象）、观察者（回调注册）、迭代器（协议）、访问者（singledispatch） | 状态（状态机）、责任链（中间件）、中介者（事件总线） |

读法：左列是"知道它对应的语法即可"——写代码时**不要**再搭 GoF 骨架（Strategy 接口 + 三个实现类在 Python 里是三个函数的事）；右列是三篇分论的正文，它们有真实的复杂度要管理。

### 反模式提醒：模式癖

模式的成本是间接层（多一跳抽象）。Python 代码里"为模式而模式"的信号：只有一个实现的"策略接口"、永远不换的"工厂"、包装一个函数的"命令类"。判据倒过来用：**先写直白代码，第二次重复、第三次变化出现时再提取模式**——重构驱动，不是蓝图驱动（配套的质量反馈见 [04-测试与质量](../04-测试与质量/README.md)：安全的重构以测试为前提）。

## 示例

```python
"""同一个需求（可替换的压缩策略）的三代形态——模式隐形化的缩影"""
# GoF 形态（Java/C++ 时代的移植）
class Compressor:                      # 接口
    def compress(self, data: bytes) -> bytes: ...
class GzipCompressor(Compressor): ...
class ZstdCompressor(Compressor): ...

# Python 形态：策略 = 传函数（协议只留给类型检查）
def process(data: bytes, compress: Callable[[bytes], bytes]) -> bytes:
    return compress(data)

process(b"...", gzip.compress)          # 换策略 = 换个函数
```
