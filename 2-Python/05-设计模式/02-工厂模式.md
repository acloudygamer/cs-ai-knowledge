# 工厂模式

工厂模式是一种对象创建模式，它定义创建对象的接口，让子类决定实例化哪个类，从而将对象的创建与使用解耦。

## 本质

```
调用者 ──→ 工厂 ──→ 产品
          └─ 根据参数/类型决定创建哪个具体产品
```

**为什么需要工厂**：当创建逻辑需要条件判断、涉及复杂初始化、或可能变化时，把创建代码从业务代码中分离，使调用者不依赖具体类的构造函数。

**本质机制**：通过一个中间层（工厂）代替调用者直接执行 `new ConcreteClass()`，创建逻辑集中管理且可配置。

## 简单工厂

通过静态方法根据类型字符串创建对象，工厂外部只看到一个统一入口。

```
Factory.create("dog") ──→ Dog() 实例
Factory.create("cat") ──→ Cat() 实例
```

```python
class Animal:
    def speak(self):
        raise NotImplementedError

class Dog(Animal):
    def speak(self):
        return "Woof!"

class Cat(Animal):
    def speak(self):
        return "Meow!"

class AnimalFactory:
    @staticmethod
    def create(animal_type: str) -> Animal:
        mapping = {"dog": Dog, "cat": Cat}
        cls = mapping.get(animal_type.lower())
        if cls is None:
            raise ValueError(f"Unknown: {animal_type}")
        return cls()
```

## 工厂方法模式

将创建方法抽象为子类的责任，父类保留创建接口但不确定具体类。

```
Creator（抽象）──→ create_product() [抽象]
    │
    ├── CreatorA ──→ create_product() → ConcreteProductA
    └── CreatorB ──→ create_product() → ConcreteProductB
```

```python
from abc import ABC, abstractmethod

class Product(ABC):
    @abstractmethod
    def operation(self) -> str:
        pass

class Creator(ABC):
    @abstractmethod
    def create_product(self) -> Product:
        pass

    def do_work(self) -> str:
        return f"Created: {self.create_product().operation()}"

class ConcreteCreator(Creator):
    def create_product(self) -> Product:
        return Product()
```

## 抽象工厂模式

创建一系列相关对象（产品族），确保同一工厂产生的对象相互兼容。

```
UIFactory（抽象）
    │
    ├── WindowsUIFactory
    │     ├── create_button() → WindowsButton
    │     └── create_text_field() → WindowsTextField
    └── MacUIFactory
          ├── create_button() → MacButton
          └── create_text_field() → MacTextField
```

```python
from abc import ABC, abstractmethod

class Button(ABC):
    @abstractmethod
    def render(self) -> str:
        pass

class TextField(ABC):
    @abstractmethod
    def render(self) -> str:
        pass

class WindowsButton(Button):
    def render(self) -> str:
        return "Windows Button"

class MacButton(Button):
    def render(self) -> str:
        return "Mac Button"

class UIFactory(ABC):
    @abstractmethod
    def create_button(self) -> Button:
        pass

class WindowsUIFactory(UIFactory):
    def create_button(self) -> Button:
        return WindowsButton()

class MacUIFactory(UIFactory):
    def create_button(self) -> Button:
        return MacButton()
```

## 注册表工厂

运行时动态注册类，工厂按名字查找并实例化，支持扩展无需修改工厂代码。

```
register("dog", Dog) ──→ _registry["dog"] = Dog
create("dog") ──→ _registry["dog"]()
```

```python
class Registry:
    _registry: dict[str, type] = {}

    @classmethod
    def register(cls, name: str, animal_cls: type):
        cls._registry[name] = animal_cls

    @classmethod
    def create(cls, name: str):
        cls = cls._registry.get(name)
        if cls is None:
            raise ValueError(name)
        return cls()
```

## 工厂 vs 建造者

| | 工厂 | 建造者 |
|---|---|---|
| 创建对象 | 一次构造完整对象 | 分步构建复杂对象 |
| 产品形态 | 单一实例 | 多部件组合 |
| 关注点 | "创建哪个类" | "如何逐步构建" |
