# 单例模式

确保一个类只有一个实例，并提供全局访问点。

## 实现方式

### 1. 模块级单例（最简单）

```python
# singleton.py
class _Singleton:
    def __init__(self):
        self.value = None

    def set(self, value):
        self.value = value

    def get(self):
        return self.value

# 模块即单例
singleton = _Singleton()

# 使用
singleton.set(42)
print(singleton.get())  # 42
```

### 2. 类方法实现

```python
class Database:
    _instance = None

    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
            cls._instance._initialized = False
        return cls._instance

    def __init__(self):
        if self._initialized:
            return
        self._initialized = True
        self.connection = None

    def connect(self):
        print("Connected to database")
        self.connection = "db_connection"

# 使用
db1 = Database()
db2 = Database()
print(db1 is db2)  # True
db1.connect()
db2.connect()  # 不会重新连接
```

### 3. 装饰器实现

```python
def singleton(cls):
    instances = {}
    @functools.wraps(cls)
    def get_instance(*args, **kwargs):
        if cls not in instances:
            instances[cls] = cls(*args, **kwargs)
        return instances[cls]
    return get_instance

@singleton
class Config:
    def __init__(self):
        self.settings = {}

config1 = Config()
config2 = Config()
print(config1 is config2)  # True
```

### 4. Borg 模式（共享状态）

```python
class Borg:
    _shared_state = {}

    def __init__(self):
        self.__dict__ = self._shared_state

    def set(self, key, value):
        self._shared_state[key] = value

    def get(self, key):
        return self._shared_state.get(key)

# 所有实例共享同一状态
b1 = Borg()
b2 = Borg()
b1.set("name", "Alice")
print(b2.get("name"))  # Alice
```

## 应用场景

| 场景 | 说明 |
|------|------|
| 数据库连接 | 复用连接，避免频繁创建销毁 |
| 配置管理器 | 全局共享配置 |
| 日志记录器 | Logger 通常是单例 |
| 缓存 | 全局缓存实例 |

## 注意事项

```python
# 多线程问题
import threading

class ThreadSafeSingleton:
    _lock = threading.Lock()
    _instance = None

    def __new__(cls):
        if cls._instance is None:
            with cls._lock:
                if cls._instance is None:
                    cls._instance = super().__new__(cls)
        return cls._instance
```

## 缺点

- **隐藏依赖**：单例全局可见，难以追踪依赖
- **难以测试**：单例状态贯穿整个测试生命周期
- **违反单一职责**：单例既管理自身生命周期，又承担业务逻辑
