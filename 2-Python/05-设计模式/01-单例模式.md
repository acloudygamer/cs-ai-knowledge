# 单例模式

单例模式是一种对象创建模式，它保证一个类仅有一个实例，并提供一个全局访问点。

## 本质

```
调用者 ──→ 单例类 ──→ 唯一实例
            ▲
            └── __new__ 拦截：首次创建返回实例，后续创建返回同一实例
```

**为什么需要单例**：当系统需要一个共享实例来协调所有用户操作时（如数据库连接池），频繁创建销毁会浪费资源且无法保证状态一致性。

**本质机制**：通过 `__new__` 或闭包拦截构造过程，使同一类名的所有实例化请求都返回同一个对象。

## 模块级单例

模块在首次导入时初始化，之后所有导入都引用同一份内存副本。

```
import → sys.modules 检查 → 已加载? → 直接返回缓存的模块对象
                         └→ 未加载? → 执行模块代码 → 存入 sys.modules
```

```python
class _DB:
    def connect(self):
        return "db_connection"

db = _DB()  # 模块加载时执行，仅一次
```

## 类装饰器单例

用闭包存储实例字典，键为类本身，值 为实例对象。

```
singleton_decorator
  └─闭包: instances = {}
  └─get_instance(cls)
       ├─ cls in instances? ──→ return instances[cls]
       └─ else ──→ instances[cls] = cls(); return
```

```python
import functools

def singleton(cls):
    instances = {}
    @functools.wraps(cls)
    def get_instance(*args, **kwargs):
        if cls not in instances:
            instances[cls] = cls(*args, **kwargs)
        return instances[cls]
    return get_instance

@singleton
class Config:
    pass

c1 = Config()
c2 = Config()
assert c1 is c2
```

## Borg 模式（共享状态）

所有实例共享同一 `__dict__`，因此状态同步但身份不同。

```python
class Borg:
    _shared = {}

    def __init__(self):
        self.__dict__ = self._shared

b1 = Borg()
b2 = Borg()
b1.x = 1
assert b2.x == 1
assert b1 is not b2
```

## 多线程安全

非线程安全的单例在并发创建时可能产生多个实例。

```
                    ┌──→ 创建 instance A
  线程1 ──→ if inst is None? ──┤
                    └──→ 线程2 同时检查 → 也创建 instance B
```

```python
import threading

class SafeSingleton:
    _lock = threading.Lock()
    _instance = None

    def __new__(cls):
        if cls._instance is None:
            with cls._lock:
                if cls._instance is None:
                    cls._instance = super().__new__(cls)
        return cls._instance
```

双重检查锁避免每次加锁，只有实例未创建时才加锁创建。

## 应用场景

| 场景 | 原因 |
|------|------|
| 数据库连接 | 连接池复用，避免频繁建立/关闭连接 |
| 配置管理 | 全局共享同一份配置，任何修改立即同步 |
| 日志记录器 | 所有模块写入同一输出流 |
| 缓存 | 全局缓存实例，跨调用保持命中率 |

## 缺点

- **全局状态**：单例在程序启动时就创建，生命周期难以控制
- **隐式依赖**：调用者不需要在构造函数声明依赖，难以追踪
- **测试隔离困难**：单例状态在测试间持久化，除非手动重置
