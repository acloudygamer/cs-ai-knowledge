# 设计模式

Python 实现经典设计模式：从创建型（单例、工厂、建造者）到结构型（装饰器、适配器）再到行为型（策略、观察者），每种模式聚焦数学模型、接口契约与 Pythonic 实现。

## 目录

### 创建型模式
- [01-单例模式](01-单例模式.md) - 唯一性不变式、线程安全 DCLP、Borg 状态共享
- [02-工厂模式](02-工厂模式.md) - 注册表工厂、抽象工厂、开闭原则、工厂 vs 建造者
- [03-建造者模式](03-建造者模式.md) - 偏序构建序列、状态迁移、Director 配方、不变式验证

### 行为型模式
- [04-策略模式](04-策略模式.md) - 算法可替换性、策略分派代价、函数式策略、策略 vs 条件分支
- [05-观察者模式](05-观察者模式.md) - Pub/Sub 可靠性、推/拉模式、弱引用防护、异步广播

### 结构型模式
- [06-装饰器模式](06-装饰器模式.md) - 运行时功能组合、函数复合模型、接口同构性、装饰器链代价
- [07-适配器模式](07-适配器模式.md) - 接口同构映射、双向转换、类适配器 vs 对象适配器
