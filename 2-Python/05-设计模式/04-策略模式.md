# 策略模式

## 定义

策略模式是一种**算法可替换性抽象**：将一族算法 $A = \{a_1, a_2, \dots, a_n\}$ 各自封装为独立对象，并赋予调用方在运行时选择具体算法的能力。数学上，策略接口定义了一个**行为空间** $\mathcal{B}$，每个具体策略是 $\mathcal{B}$ 的一个实例：

$$\text{Strategy}: \mathcal{B},\quad \forall s \in A,\ s: \text{Input} \rightarrow \text{Output}$$

Context 持有策略引用但本身不实现算法，策略可随时替换而不影响 Context 的结构。

## 数学模型

**策略分派代价**：设策略集合 $\mathcal{S} = \{s_1, s_2, \dots, s_n\}$，Context 的 `execute(x)` 操作分派到策略 $s_i$ 的代价为：

$$T_{\text{dispatch}}(x) = \underbrace{T_{\text{lookup}}(s_i)}_{\text{策略查找}} + \underbrace{T_{s_i}(x)}_{\text{算法执行}}$$

其中 $T_{\text{lookup}}$ 是从当前策略引用到具体实现的跳转代价（虚函数表查表或字典查找），$T_{s_i}$ 是策略 $s_i$ 自身的算法复杂度。

**策略选择复杂度**：运行时切换策略 $s_i \rightarrow s_j$ 的代价为 $O(1)$（直接指针替换），不触发任何算法重计算。

**开放封闭原则的数学表达**：新增策略 $a_{n+1}$ 定义新映射 $s_{n+1}: \text{Input} \to \text{Output}$，无需修改 Context 代码——在 $\mathcal{B}$ 上做集合扩展：

$$\mathcal{B}' = \mathcal{B} \cup \{s_{n+1}\}$$

**归约终点**：策略模式本质是**函数作为一等公民**的面向对象伪装——每个策略对象持有一个函数（算法），Context 调用该函数。这与高阶函数 `map(algorithm, data)` 同构，只是包装进了类和对象系统。

## 机制

### 策略接口：行为契约

策略接口（通常是 ABC）定义了算法的**签名契约**，确保所有具体策略可互换：

```python
class SortStrategy(ABC):
    @abstractmethod
    def sort(self, data: list) -> list: ...
```

契约的核心是**输入输出类型**：同输入类型，同输出类型，具体算法实现自由。这使策略间可相互替换而不影响调用方。

**约束**：策略接口的变化（增删方法）会导致所有具体策略都要修改——策略接口本身应设计为稳定的。

### 函数式策略：去类化的算法封装

Python 的函数是一等公民，可以直接作为策略传递，无需包装成类：

```python
class Sorter:
    def __init__(self, fn):
        self._fn = fn

    def sort(self, data):
        return self._fn(data)
```

这与策略模式的本质完全一致，只是**省略了策略接口的显式声明**——类型注解可作为隐式接口。在简单场景下，函数式策略避免了类膨胀。

### 策略选择策略

Context 如何选择策略有三种常见模式：
- **构造时注入**：调用方在创建 Context 时决定策略，策略生命周期与 Context 相当
- **运行时切换**：`set_strategy()` 支持动态替换，允许同一 Context 在不同阶段使用不同算法
- **委托选择**：Context 内部维护策略映射表，根据输入特征自动路由到对应策略（这是策略模式与简单工厂的组合）

### 策略 vs 条件分支

| | 策略模式 | 条件分支 |
|--|---------|---------|
| 新增算法 | 新增策略类 | 修改原函数 |
| 可测试性 | 各策略独立单元测试 | 逻辑散落难以隔离 |
| 运行时切换 | 支持 | 需要变量重新赋值 |
| 开闭原则 | 扩展开放，修改封闭 | 每次改动都有修改风险 |

## 参考存根

```python
from abc import ABC, abstractmethod

class SortStrategy(ABC):
    @abstractmethod
    def sort(self, data: list) -> list: ...

class QuickSort(SortStrategy):
    def sort(self, data: list) -> list:
        if len(data) <= 1:
            return data
        pivot = data[len(data) // 2]
        return self.sort([x for x in data if x < pivot]) \
               + [x for x in data if x == pivot] \
               + self.sort([x for x in data if x > pivot])

class Sorter:
    def __init__(self, strategy: SortStrategy):
        self._strategy = strategy

    def set_strategy(self, strategy: SortStrategy):
        self._strategy = strategy

    def sort(self, data: list) -> list:
        return self._strategy.sort(data)
```
