# 策略模式

策略模式是一种对象行为模式，它定义一系列算法并封装它们，使它们可以相互替换。

## 本质

```
Context ──→ Strategy（接口）
            ├─ ConcreteStrategyA ── algorithm_a()
            ├─ ConcreteStrategyB ── algorithm_b()
            └─ ConcreteStrategyC ── algorithm_c()
```

**为什么需要策略模式**：当同一行为（如排序、支付）有多种实现且需要在运行时切换时，用 if/else 或继承会导致每次新增算法都要改原有代码，违反开闭原则。

**本质机制**：将每种算法封装为独立策略对象，持有 Context 的代码只依赖策略接口而非具体实现，新增策略无需修改已有代码。

## 策略接口 + 上下文

Strategy 定义统一算法接口，具体策略实现不同算法，上下文持有并调用策略。

```
Sorter.set_strategy(QuickSort())
Sorter.set_strategy(MergeSort())
Sorter.sort(data)  ──→ 调用当前策略的 sort()
```

```python
from abc import ABC, abstractmethod

class SortStrategy(ABC):
    @abstractmethod
    def sort(self, data: list) -> list:
        pass

class QuickSort(SortStrategy):
    def sort(self, data: list) -> list:
        if len(data) <= 1:
            return data
        pivot = data[len(data) // 2]
        left = [x for x in data if x < pivot]
        mid = [x for x in data if x == pivot]
        right = [x for x in data if x > pivot]
        return self.sort(left) + mid + self.sort(right)

class MergeSort(SortStrategy):
    def sort(self, data: list) -> list:
        if len(data) <= 1:
            return data
        mid = len(data) // 2
        left = self.sort(data[:mid])
        right = self.sort(data[mid:])
        return self._merge(left, right)

    def _merge(self, left, right):
        result = []
        i = j = 0
        while i < len(left) and j < len(right):
            if left[i] <= right[j]:
                result.append(left[i])
                i += 1
            else:
                result.append(right[j])
                j += 1
        result.extend(left[i:])
        result.extend(right[j:])
        return result

class Sorter:
    def __init__(self, strategy: SortStrategy):
        self._strategy = strategy

    def set_strategy(self, strategy: SortStrategy):
        self._strategy = strategy

    def sort(self, data: list) -> list:
        return self._strategy.sort(data)
```

## 函数式策略

简单场景下直接传入函数，省去策略类的接口声明。

```python
def sort_asc(data):
    return sorted(data)

def sort_desc(data):
    return sorted(data, reverse=True)

class Sorter:
    def __init__(self, fn):
        self._fn = fn

    def sort(self, data):
        return self._fn(data)
```

## 策略 vs 条件分支

| | 策略模式 | 条件分支 |
|---|---|---|
| 新增算法 | 新增策略类，不改现有代码 | 修改原函数 |
| 可测试性 | 策略可独立单元测试 | 逻辑散落 |
| 运行时切换 | 支持 | 需要重新赋值变量 |
| 代码量 | 多一个类 | 简洁 |
