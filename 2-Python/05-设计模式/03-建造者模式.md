# 建造者模式

## 定义

建造者模式是一种**分步对象构造协议**：将复杂对象的创建过程分解为一系列离散的、命名的步骤，主调用者通过声明式链式调用描述最终产物，而非传入位置参数。构建过程可形式化为产品状态空间 $\mathcal{S}$ 上的**偏序构建序列**。

## 数学模型

**偏序构建关系**：设部件集合 $\mathcal{P} = \{p_1, p_2, \dots, p_m\}$，构建步骤集合 $\mathcal{K} = \{k_1, k_2, \dots, k_m\}$。每个步骤 $k_i$ 定义偏序关系：

$$k_i \prec k_j \iff \text{步骤 } i \text{ 必须在步骤 } j \text{ 之前完成}$$

偏序的传递闭包 $\prec^*$ 约束 Builder 必须遵循的执行顺序。

**状态迁移函数**：设产品状态空间 $\mathcal{S}$，初始态 $s_0 \in \mathcal{S}$。每个步骤 $k_i$ 对应状态迁移函数 $f_i: \mathcal{S} \rightarrow \mathcal{S}$：

$$s_{i+1} = f_i(s_i)$$

完整构建序列的最终产物为：

$$s_n = (f_n \circ f_{n-1} \circ \cdots \circ f_1)(s_0)$$

**不变式验证**：Builder 在 `build()` 时验证产品不变式 $\phi: \mathcal{S} \rightarrow \{\text{True}, \text{False}\}$。仅当 $\phi(s_n) = \text{True}$ 时构建成功：

$$\text{build}() \triangleq \phi(s_n) ? s_n : \bot$$

其中 $\bot$ 表示构建失败（抛出异常）。

**归约终点**：链式 Builder 可归约为**流畅接口（fluent interface）** + **建造者模式**——方法链返回 `self`，使调用可读性接近自然语言陈述。

## 机制

### Director（导演类）：构建流程封装

Director 封装预定义的**构建配方**（build recipe），调用者可选择标准模板而不必关心步骤细节。Director 本身不持有产品状态，只持有 Builder 引用：

$$\text{Director.build\_luxury()} \triangleq \text{Builder.walls("stone").roof("copper").windows(8).build()}$$

这将"构建步骤顺序"与"每个步骤的参数选择"解耦——换新产品只需新建 Builder，换配方只需调 Director 方法。

### Builder 的不变式验证

复杂对象往往有内部不变式约束（如"房屋必须有门且数量≥1"）。Builder 在 `build()` 时统一验证：

```python
def build(self) -> House:
    if self._house.walls is None:
        raise BuildError("walls required")
    if self._house.windows < 1:
        raise BuildError("at least one window")
    return self._house
```

**约束**：验证时机可选择在每个 setter（即时验证）或 `build()`（延迟验证）。即时验证利于快速失败，延迟验证允许 Builder 内部临时状态合法。

### dataclasses + Builder 分离

`@dataclass` 定义数据的静态结构（字段名、类型、默认值），Builder 负责运行时填充——这将"数据schema"与"数据填充逻辑"分离：

```python
@dataclass
class Pizza:
    size: str = ""
    cheese: bool = False
    pepperoni: bool = False
```

Builder 持有 `Pizza` 实例，链式方法逐步填充，最终 `build()` 返回完全初始化的 Pizza。dataclass 保证字段访问有类型提示，Builder 保证构建过程可读。

### Builder vs 工厂

| | 建造者 | 工厂 |
|--|------|------|
| 产品形态 | 多部件组合（对象结构复杂） | 单一对象 |
| 构建过程 | 可中断（有中间态） | 不可中断（原子构造） |
| 参数风格 | 声明式，命名参数 | 命令式，通常位置参数 |
| 表示分离 | 构建逻辑与表示分离 | 创建与表示合一 |

## 参考存根

```python
class PizzaBuilder:
    def __init__(self, size: str):
        self._pizza = Pizza(size=size)

    def cheese(self) -> "PizzaBuilder":
        self._pizza.cheese = True
        return self

    def pepperoni(self) -> "PizzaBuilder":
        self._pizza.pepperoni = True
        return self

    def build(self) -> Pizza:
        return self._pizza

# 使用
pizza = PizzaBuilder("large").cheese().pepperoni().build()
```
