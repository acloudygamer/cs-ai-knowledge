# 建造者模式

建造者模式是一种对象创建模式，它将复杂对象的构建与表示分离，使同样的构建过程可以创建不同表示。

## 本质

```
调用者 ──→ Builder ──→ Product
          ├─ build_part_a()
          ├─ build_part_b()
          └─ get_result()
```

**为什么需要建造者**：当对象有多个可选部件（门、窗、花园）、创建步骤有顺序要求、或需要不同配置时，构造函数参数过多且难以阅读。

**本质机制**：将"如何组装一个复杂对象"封装在一个独立的 Builder 对象中，主调用者通过链式调用声明式地描述最终产物，而不是传入大量构造参数。

## 链式 Builder

Builder 返回 `self` 支持链式调用，调用者按需组合部件。

```python
class House:
    def __init__(self):
        self.walls = None
        self.roof = None
        self.windows = None

class HouseBuilder:
    def __init__(self):
        self._house = House()

    def walls(self, material: str):
        self._house.walls = material
        return self

    def roof(self, material: str):
        self._house.roof = material
        return self

    def windows(self, count: int):
        self._house.windows = count
        return self

    def build(self) -> House:
        return self._house

house = (HouseBuilder()
         .walls("brick")
         .roof("tile")
         .windows(4)
         .build())
```

## Director（导演类）

Director 封装预定义的构建流程，调用者可选择使用标准模板或自定义步骤。

```
HouseDirector
  └─ build_simple_house() → Builder.walls("wood").roof("shingle").build()
  └─ build_luxury_house() → Builder.walls("stone").roof("copper").build()
```

```python
class HouseDirector:
    def __init__(self, builder: HouseBuilder):
        self._builder = builder

    def simple(self) -> House:
        return (self._builder
                .walls("wood")
                .roof("shingle")
                .windows(2)
                .build())

    def luxury(self) -> House:
        return (self._builder
                .walls("stone")
                .roof("copper")
                .windows(8)
                .build())
```

## dataclasses 配合 Builder

`@dataclass` 定义产品，Builder 负责设置字段，分离数据声明与构建逻辑。

```python
from dataclasses import dataclass

@dataclass
class Pizza:
    size: str = ""
    cheese: bool = False
    pepperoni: bool = False

class PizzaBuilder:
    def __init__(self, size: str):
        self._pizza = Pizza(size=size)

    def cheese(self) -> "PizzaBuilder":
        self._pizza.cheese = True
        return self

    def pepperoni(self) -> "PizzaBuilder":
        self._pizza.pepperoni = True
        return self

    def build(self) -> Pizza:
        return self._pizza

pizza = PizzaBuilder("large").cheese().pepperoni().build()
```

## Builder vs 工厂

| | 建造者 | 工厂 |
|---|---|---|
| 构建过程 | 分步、链式 | 一次完成 |
| 产品结构 | 多部件组合 | 单一对象 |
| 参数风格 | 声明式、按名设置 | 命令式、位置参数 |
