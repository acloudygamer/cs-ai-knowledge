# 观察者模式

观察者模式是一种对象行为模式，它定义对象间的一对多依赖关系，当主题状态改变时，所有观察者收到通知。

## 本质

```
Subject ──→ _observers: [Observer, Observer, ...]
             │
             └── notify(message)
                  └─→ observer.update(message) × N

主题状态变化
    │
    └─→ 自动遍历观察者列表，逐个通知
```

**为什么需要观察者**：当一个对象状态变化需要同步通知多个其他对象时，若在变化处直接调用所有目标，目标和观察者之间形成强耦合；观察者模式让主题只负责"通知"，观察者负责"响应"，两者解耦。

**推送 vs 拉取**：推模式（主动推送数据）由主题决定传递什么；拉模式（被动拉取）由观察者自行获取所需数据。本实现采用推模式。

## 基本实现

Subject 维护观察者列表并批量通知，Observer 定义更新接口。

```python
from abc import ABC, abstractmethod

class Observer(ABC):
    @abstractmethod
    def update(self, message: str):
        pass

class Subject:
    def __init__(self):
        self._observers: list[Observer] = []

    def attach(self, obs: Observer):
        if obs not in self._observers:
            self._observers.append(obs)

    def detach(self, obs: Observer):
        self._observers.remove(obs)

    def notify(self, message: str):
        for obs in self._observers:
            obs.update(message)
```

## 回调式实现

用 `Callable` 替代 Observer 接口，更轻量，适合 Python 特有的函数一等公民特性。

```python
class EventManager:
    def __init__(self):
        self._callbacks: dict[str, list[Callable]] = {}

    def subscribe(self, event: str, cb: Callable):
        self._callbacks.setdefault(event, []).append(cb)

    def unsubscribe(self, event: str, cb: Callable):
        if event in self._callbacks:
            self._callbacks[event].remove(cb)

    def emit(self, event: str, data=None):
        for cb in self._callbacks.get(event, []):
            cb(data)
```

## 弱引用观察者

防止观察者被遗忘时导致内存泄漏。

```python
import weakref

class WeakObserver:
    def __init__(self, cb: Callable):
        self._ref = weakref.ref(cb)

    def update(self, message: str):
        cb = self._ref()
        if cb:
            cb(message)
```

## 异步通知

避免通知阻塞主线程。

```python
import asyncio

class AsyncSubject:
    def __init__(self):
        self._observers: list = []

    async def notify(self, message: str):
        tasks = [asyncio.create_task(obs.update(message))
                 for obs in self._observers]
        await asyncio.gather(*tasks)
```

## 观察者 vs 回调

| | 观察者模式 | 回调 |
|---|---|---|
| 接口抽象 | 有统一接口 | 直接传函数 |
| 管理方式 | Subject 统一管理生命周期 | 手动管理 |
| 适用场景 | 多对象、多事件 | 简单一对一时 |
