# 01-对象模型与变量

> 前置：[01-语言定位与执行模型](../00-概览/01-语言定位与执行模型.md)（"一切皆对象"的出处） · 后续：[02-内建数据结构](02-内建数据结构.md)、[07-面向对象](07-面向对象.md)、[01-内存管理与垃圾回收](../03-运行时与性能/01-内存管理与垃圾回收.md)

Python 的变量不是盒子，是名字。这条定律是全库地基：赋值从不拷贝对象，只绑定引用；函数传参、容器存元素、属性挂值，走的全是同一条引用绑定路径。上一篇陈述的"一切皆对象"在本篇落成可操作的规则。

## 本质

- 一切数据都是堆上的 `PyObject`：头部含引用计数与类型指针（CPython 中即 `ob_refcnt` 与 `ob_type`），实际数据跟在头部之后。引用计数的生死语义见 [01-内存管理与垃圾回收](../03-运行时与性能/01-内存管理与垃圾回收.md)。
- 赋值 `b = a` 只是把名字 `b` 绑到 `a` 所指的对象。`id()` 返回对象身份的抽象（CPython 实现即地址），`is` 比较身份，`==` 走 `__eq__` 比较值——三者各司其职，不可互换。
- 变量、属性、模块成员、函数参数是四种"名字"，共享同一套绑定语义；差异只在命名空间机制（见 [05-函数](05-函数.md)、[10-模块与导入系统](10-模块与导入系统.md)）。

## 机制

### 可变性：类型的首要分类轴

不可变：`int` / `float` / `complex` / `bool` / `str` / `bytes` / `tuple` / `frozenset` / `None`。可变：`list` / `dict` / `set` / `bytearray` / 绝大多数自定义对象。

| 后果 | 不可变对象 | 可变对象 |
|---|---|---|
| 别名修改可见性 | 安全：任何"修改"都产生新对象，旧别名不受影响 | 危险：原地修改对所有别名可见 |
| 可作 dict 键 / set 元素 | 可以（前提：递归地不含可变元素） | 不可以 |
| 作函数默认参数 | 安全 | 陷阱（默认值在 def 时求值一次，见 [05-函数](05-函数.md)） |

`+=` 在两类对象上行为分叉：`list += x` 调用 `__iadd__` 原地扩展（名字不变、id 不变），而 `tuple += x` 只能抛 `TypeError`。`str +=` 的"追加"是 CPython 编译器优化（内部缓冲），语义上每次产生新串——循环拼接不可依赖它，应使用 `''.join`（见 [03-字符串与格式化](03-字符串与格式化.md)）。

### 拷贝：浅与深

- `b = a`：不拷贝，纯绑定。
- `a.copy()` / `a[:]` / `copy.copy(a)`：浅拷贝——新容器，元素仍是旧引用；嵌套的可变元素照样共享。
- `copy.deepcopy(a)`：递归拷贝，处理循环引用（内部 memo 记录已拷对象）。

经典事故：`rows = [[0] * 3] * 3` 造出三个指向同一内层 list 的"行"——外层 `*` 复制的是引用（承接 `list` 的指针数组本质，见 [02-内建数据结构](02-内建数据结构.md)）。

### 小对象缓存与驻留

CPython 缓存小整数（`[-5, 256]`）并驻留部分 identifier 形态的字符串——`a = 256; b = 256; a is b` 碰巧为 `True`，但 `257` 处可能为 `False`。约束：这是实现优化而非语言承诺；语义上**用 `==` 比值，`is` 仅用于 `None` 与单例判别**。

### 相等与哈希的契约（预埋）

若 `a == b` 为真，则 `hash(a) == hash(b)` 必须成立。自定义类只覆盖 `__eq__` 不覆盖 `__hash__` 时，后者被置为 `None`（对象立即不可哈希）——这是初学自定义 dict 键失效的头号原因。协议细节见 [07-面向对象](07-面向对象.md)，dict/set 为何依赖此契约见 [02-内建数据结构](02-内建数据结构.md)。

### 真值与 None

`bool(x)` 依次尝试 `__bool__` → `__len__` → 恒真；空容器为假。`None` 是单例，判空必须 `x is None`（`==` 可能被 `__eq__` 劫持）。真值协议接管控制流的位置见 [04-控制流程与表达式](04-控制流程与表达式.md)。

## 连接

| 对比 | 判据 |
|---|---|
| `is` vs `==` | 身份（同一对象）vs 相等（`__eq__` 语义）；`is` 只给 `None`/单例用 |
| 不拷贝 / 浅拷贝 / 深拷贝 | 需要独立容器且元素全不可变 → 浅拷贝足够；嵌套含可变 → `deepcopy` 或重建 |
| 引用语义 vs 值语义 | Python 一律引用语义（对照 C++ 拷贝构造、Java 仅基本类型值语义）；跨进程/序列化边界上引用网被切断——见 [03-序列化与配置格式](../02-IO与工程实践/03-序列化与配置格式.md) |

**延伸**：对象头如何决定内存开销、引用计数何时失灵见 [01-内存管理与垃圾回收](../03-运行时与性能/01-内存管理与垃圾回收.md)；协议（`__eq__`/`__bool__`/`__len__`）如何由类定义接管见 [07-面向对象](07-面向对象.md)。

## 示例

```python
a = [1, 2, 3]
b = a            # 绑定，不拷贝
c = a.copy()     # 浅拷贝：新容器
b.append(4)      # 通过 b 原地修改
print(a, c)      # [1, 2, 3, 4] [1, 2, 3] —— a 变了，c 不变
print(a is b, a is c, a == c)  # True False False（c 与 a 相等但不同一）

import copy
m = [[0] * 3] * 3
m[0][0] = 9
print(m)                    # [[9, 0, 0], [9, 0, 0], [9, 0, 0]] —— 三行同一对象
m2 = copy.deepcopy(m)
```

```python
# 相等与哈希契约：只覆盖 __eq__ 的类失去可哈希性
class Point:
    def __init__(self, x, y):
        self.x, self.y = x, y
    def __eq__(self, other):
        return (self.x, self.y) == (other.x, other.y)

p = Point(1, 2)
try:
    {p: "value"}            # TypeError: unhashable type: 'Point'
except TypeError as e:
    print(e)                # 修复：补 __hash__ = lambda self: hash((self.x, self.y))
```
