# 05-函数

> 前置：[01-对象模型与变量](01-对象模型与变量.md)（名字绑定）、[04-控制流程与表达式](04-控制流程与表达式.md)（作用域初见） · 后续：[07-面向对象](07-面向对象.md)（方法=类属性里的函数、`__call__`）、[11-类型提示](11-类型提示.md)（签名标注）、[03-结构型模式](../05-设计模式/03-结构型模式.md)（装饰器模式）

函数是 Python 里代码复用的最小单元，也是"一切皆对象"最直接的受益者：函数可以被赋值、传递、包装、返回——装饰器、回调、依赖注入、策略选择，全是这条性质的推论。本篇按"参数 → 作用域与闭包 → 装饰器"递进，装饰器收尾是因为它恰好是前两者的合成题。

## 本质

- `def` 是**可执行语句**：执行到它才创建函数对象并绑定名字——因此可以条件定义、可以在函数内定义（嵌套）。
- 函数对象携带三样东西：代码对象（字节码与常量）、`__globals__`（定义处的全局命名空间）、闭包单元（捕获的自由变量）。调用即"新帧 + 绑定参数 + 执行字节码"（帧与执行模型见 [01-语言定位与执行模型](../00-概览/01-语言定位与执行模型.md)）。
- 参数传递是**按对象传递**（call by object）：形参绑定实参所指对象——既非值拷贝也非引用拷贝，与赋值语义完全同构（承接 [01-对象模型与变量](01-对象模型与变量.md)）。

## 机制

### 参数模型的完整语法

```python
def f(pos_only, /, normal, *args, kw_only, **kwargs): ...
```

- `/` 左侧只能按位置传（避免参数名成为公共 API），`*` 右侧只能按关键字传（布尔开关类参数的纪律位——`connect(host, timeout=30)` 比 `connect(host, 30)` 可读）。
- 默认值在 `def` 执行时**求值一次**：可变默认值成为跨调用共享的隐式状态（承接 [01-对象模型与变量](01-对象模型与变量.md) 的可变性后果）。修正惯用法：`def f(x, cache=None): cache = cache if cache is not None else {}`。
- 解包传参：`f(*args, **kwargs)` 与定义侧对称；"转发所有参数"的包装器（装饰器）靠这一对成立。

### 作用域与闭包

- LEGB 查找（Local → Enclosing → Global → Builtin）；**赋值即局部**——函数内任何地方给名字赋值，该名字在整个函数体都是局部的，想改外层需 `global` / `nonlocal` 声明。
- 闭包捕获的是**变量（cell），不是值**：晚绑定是推论——循环里建 `lambda i: i * 2` 收集的函数共享同一个 `i`，调用时才取值，全是最末值。修正：默认参数冻结（`lambda i=i: ...`）或 `functools.partial`。
- 判据：需要"函数 + 少量捕获状态"时闭包合适；状态变多、需要自文档时升级为类（`__call__`，见 [07-面向对象](07-面向对象.md)）或 dataclass。

### 装饰器：语法糖与两层结构

`@deco` 等价 `func = deco(func)`——装饰器是"接函数、返回可调用"的高阶函数。叠加顺序自下而上应用（最靠近 def 的先包），调用时外层先执行。

```python
import functools

def log_calls(func):                       # 基础形：无参装饰器
    @functools.wraps(func)                 # 保住 __name__/doc/签名（反射与文档工具依赖）
    def wrapper(*args, **kwargs):
        print(f"→ {func.__name__}")
        return func(*args, **kwargs)
    return wrapper

def retry(times):                          # 参数化形：三层（参数 → 函数 → 包装）
    def deco(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            for attempt in range(times):
                try:
                    return func(*args, **kwargs)
                except Exception:
                    if attempt == times - 1:
                        raise               # 重试耗尽：继续抛（异常语义见 08）
        return wrapper
    return deco
```

约束：忘记 `functools.wraps` 不会坏功能，但 `__name__` 变 `wrapper`、`inspect.signature` 失真——测试与文档工具链（见 [01-pytest基础](../04-测试与质量/01-pytest基础.md)）会看到错的东西。装饰器模式在 GoF 语境里的位置见 [03-结构型模式](../05-设计模式/03-结构型模式.md)。

### functools：值得常备的四个件

| 工具 | 语义 | 典型场景 |
|---|---|---|
| `partial(f, x=1)` | 预绑定参数，返回新可调用 | 固定配置的回调、多进程任务（可 pickle，见 [03-并发与异步](../03-运行时与性能/03-并发与异步.md)） |
| `cache` / `lru_cache(maxsize)` | 按参数记忆化 | 纯函数加速（参数须可哈希）；递归改写 |
| `singledispatch` | 按首参类型分派 | 替代 if/elif isinstance 链（开闭原则的最廉价实现） |
| `reduce` | 折叠 | 少用；`sum`/`max`/`"".join` 已覆盖多数折叠 |

`lambda` 的纪律位：单表达式、无名、即刻传递（`key=`、`defaultdict` 工厂）；需要名字、语句或复用时必须 `def`。

## 示例

```python
# 闭包晚绑定与两种修正
fs_bad = [lambda: i for i in range(3)]
fs_fix = [lambda i=i: i for i in range(3)]        # 默认参数在每次创建时求值
from functools import partial
fs_fix2 = [partial(lambda v: v, i) for i in range(3)]
print([f() for f in fs_bad], [f() for f in fs_fix])   # [2, 2, 2] [0, 1, 2]

# lru_cache：纯函数记忆化（参数必须可哈希）
from functools import lru_cache

@lru_cache(maxsize=None)
def fib(n):
    return n if n < 2 else fib(n - 1) + fib(n - 2)
print(fib(200))    # 无缓存时这是宇宙级等待
```
