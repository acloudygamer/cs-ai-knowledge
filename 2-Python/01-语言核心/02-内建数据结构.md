# 02-内建数据结构

> 前置：[01-对象模型与变量](01-对象模型与变量.md)（容器存的是引用，不是值） · 后续：[04-控制流程与表达式](04-控制流程与表达式.md)（推导式构建）、[06-迭代器与生成器](06-迭代器与生成器.md)（流式替代）、[1-数据结构与算法](../../1-数据结构与算法/README.md)（算法基础）

承接对象模型：容器里存的是 `PyObject*`，所以"两个列表共享同一元素""拷贝容器不拷贝元素"都是引用语义的推论。本篇给五种内建容器一个统一决策框架——按**查询模式**选型，而不是按熟悉度选型。

## 本质

| 容器 | 底层结构 | 语义定位 |
|---|---|---|
| `list` | 动态数组（指针数组 + 超额分配） | 按位置组织的序列 |
| `tuple` | 定长数组 | 不可变记录（结构体的退化形态） |
| `dict` | 开放寻址哈希表 | 按键语义的映射 |
| `set` / `frozenset` | 无值化的哈希表 | 成员归属与集合运算 |
| `collections.deque` | 双向链表状的分块数组 | 两端操作 |

选型主轴：按下标/顺序访问 → `list`；按键语义访问 → `dict`；成员测试、去重、交并差 → `set`；固定异构字段包 → `tuple`（更好用的替代是 dataclass，见 [07-面向对象](07-面向对象.md)）。

## 机制

### 复杂度对比表（选型的定量依据）

| 操作 | list | dict | set | deque |
|---|---|---|---|---|
| 按下标访问 `c[i]` | $O(1)$ | —— | —— | $O(n)$ |
| 尾部 append / pop | 均摊 $O(1)$ | —— | —— | $O(1)$（两端） |
| 头部插入 / 删除 | $O(n)$ | —— | —— | $O(1)$ |
| `x in c` | $O(n)$ | 期望 $O(1)$ | 期望 $O(1)$ | $O(n)$ |
| 按键读写 `c[k]` | —— | 期望 $O(1)$ | —— | —— |

"期望"依赖哈希均匀假设，最坏退化为 $O(n)$；字符串键的哈希默认随机化（`PYTHONHASHSEED`）就是防哈希碰撞攻击。`list` 的 append 均摊 $O(1)$ 来自超额分配：容量按约 1.125 倍几何增长，总拷贝代价被摊平。算法与摊还分析的原理见 [1-数据结构与算法](../../1-数据结构与算法/README.md)。

### 哈希契约如何决定 dict/set 的一切怪癖

- 键必须可哈希且"相等即同键"：`1`、`1.0`、`True` 三者 `==` 相等，在 dict 里**是同一个键**（`{1: 'a', True: 'b'}` 只剩一项）——数值类型哈希值按值对齐是规范行为。
- 可变对象作键是逻辑错误：原地修改等于把键挪出哈希槽位，从此查不到（dict 不阻止你，只在查找时失败）。
- dict 保插入序（3.7+ 语言保证，非实现细节）；视图 `keys()` / `items()` 是动态投影不是快照，迭代期间增删键抛 `RuntimeError: dictionary changed size during iteration`（安全失败设计）。

### list 的数组本质与代价

- 连续存的是指针：缓存友好，但每次元素访问是"数组取指针 + 指针解引用"两次访存——这是 `array.array` 与 NumPy ndarray（数据连续、无指针层）在数值场景碾压 list 的结构原因（见 [05-数据分析与机器学习](../06-应用领域/05-数据分析与机器学习.md)）。
- `list.sort` 是 Timsort：稳定、自适应（对部分有序输入接近线性）——稳定性意味着排序后相等元素的相对顺序保持，这是"多级排序"惯用法（先按次键排、再按主键排）成立的前提。
- 切片是浅拷贝（承接 [01-对象模型与变量](01-对象模型与变量.md)）；`lst * n` 复制的是引用，嵌套结构必踩 `[[0]*3]*3` 坑。

### collections 与 heapq：标准库补位

| 工具 | 补的位 | 典型场景 |
|---|---|---|
| `collections.deque` | 双端队列（list 头部操作 $O(n)$ 的补位） | 滑动窗口、BFS、LIFO/FIFO 队列 |
| `collections.Counter` | 计数 dict | 词频、Top-K（`most_common`） |
| `collections.defaultdict` | 缺键默认值工厂 | 分组汇总（`defaultdict(list)`） |
| `heapq` | 堆（模块函数操作 list，不是类型） | Top-K、优先队列、Dijkstra |
| `array.array` | 紧凑同质数值数组 | 大量数值且无需对象语义时 |

### tuple 的双重身份

不可变序列（可切片、可迭代）与定长异构记录（`(x, y)` 当坐标、`(code, msg)` 当返回对）是两种不同用法；后者应升级为 `NamedTuple` 或 dataclass 获得字段名与类型标注（见 [07-面向对象](07-面向对象.md)、[11-类型提示](11-类型提示.md)）。陷阱：单元素必须写 `(x,)`。

## 连接

| 查询/使用模式 | 选择 |
|---|---|
| 顺序遍历 + 按下标 | list（构建用推导式，见 [04-控制流程与表达式](04-控制流程与表达式.md)） |
| 键 → 值映射、缓存、索引 | dict |
| 去重、成员测试、集合代数 | set（需要可哈希的冻结版本用 frozenset 作 dict 键） |
| 流式处理大数据（放不下内存） | 不选容器，选生成器管道（见 [06-迭代器与生成器](06-迭代器与生成器.md)） |
| 跨进程/网络传输 | 容器需序列化边界转换（见 [03-序列化与配置格式](../02-IO与工程实践/03-序列化与配置格式.md)） |

**延伸**：树、图、跳表等无内建类型——工程上要么用 dict/set 组合表达（邻接表即 `defaultdict(set)`），要么用第三方库；算法视角的对照见 [1-数据结构与算法](../../1-数据结构与算法/README.md)。并发场景下容器的线程安全边界见 [03-并发与异步](../03-运行时与性能/03-并发与异步.md)。

## 示例

```python
# dict 键等价性：1 == 1.0 == True，三者是同一个键
d = {1: "int"}
d[True] = "bool"     # 覆盖了 d[1]！
d[1.0] = "float"     # 再次覆盖
print(d)             # {1: 'float'}

# defaultdict + Counter：分组与计数的惯用法
from collections import Counter, defaultdict
words = ["go", "python", "go", "rust", "python", "go"]
by_lang = defaultdict(list)
for w in words:
    by_lang[w].append(len(w))
print(Counter(words).most_common(1))   # [('go', 3)]
```

```python
# 超额分配可见：容量阶梯式增长，append 仍均摊 O(1)
import sys
grow, size = [], sys.getsizeof([])
for i in range(100):
    grow.append(i)
    if sys.getsizeof(grow) != size:
        size = sys.getsizeof(grow)
        print(f"len={i:>3}  bytes={size}")   # 容量按几何级数跳变，而非线性
```
