# 04-控制流程与表达式

> 前置：[01-对象模型与变量](01-对象模型与变量.md)（真值协议）、[02-内建数据结构](02-内建数据结构.md)（被遍历与被构建的对象） · 后续：[05-函数](05-函数.md)（作用域与闭包）、[06-迭代器与生成器](06-迭代器与生成器.md)（for 的底层协议）、[08-错误与异常](08-错误与异常.md)（异常也是控制流）

本篇把"语句"一次讲完：分支（if / match）、循环（for / while / else）、以及两类表达式级控制力——推导式与海象运算符。线索是两条：**for 不关心被遍历者的类型**（协议化，通往生成器），**match 不是 switch**（结构化解构，通往模式思维）。

## 本质

- `for` 是协议语法糖：循环体等价于 `it = iter(seq)` 后反复 `next(it)` 直到 `StopIteration`——被遍历者只需提供 `__iter__`（或退化的 `__getitem__`）。协议全貌见 [06-迭代器与生成器](06-迭代器与生成器.md)。
- `match` 是**结构模式匹配**：按结构拆解并绑定名字，不是按值跳转的 switch。`case` 写的是"形状模板"，捕获即绑定变量——这是它与 `if/elif` 链的本质差异。
- 推导式是"声明式构建容器"：`[f(x) for x in xs if p(x)]` 的读序是 for → if → f，声明"要什么"而非"怎么造"。

## 机制

### 真值、短路与链式比较

- 真值协议：`bool(x)` 依次尝试 `__bool__` → `__len__`（承接 [01-对象模型与变量](01-对象模型与变量.md)）。
- `and` / `or` 返回**操作数本身**而非布尔值：`x or default` 是默认值惯用法，但当 `0` / `""` / `[]` 是合法值时静默出错——判空必须 `if x is None`，不要 `if not x` 混用两种语义。
- 链式比较 `a < b < c` 是真实的数学语义（等价 `a < b and b < c`，且 `b` 只求值一次），不是 C 的 `(a<b)<c`。

### match：模式是形状模板

```python
match command:
    case [action, *args]:            # 序列模式：定长头 + 收集尾
        run(action, args)
    case {"op": "move", "dx": dx}:   # 映射模式：按键取值（多余键忽略）
        move(dx)
    case Point(x=0, y=y):            # 类模式：按属性名解构
        print("on y-axis", y)
    case [x, y] | (x, y):            # 或模式：多形状合一
        print("pair", x, y)
    case _:                          # 通配：永远匹配
        raise ValueError(command)
```

- 捕获即绑定：`args`、`dx`、`y` 在 case 体内直接可用；字面量（`"move"`、`0`）不绑定。
- 守卫：`case [x, y] if x == y:`——模式管形状，守卫管语义，分工明确。
- 约束与后果：无穷尽检查（漏写分支不报错，`_` 兜底是自律）；匹配顺序即优先级，最具体的模式必须放最前。
- 对比 `if/elif`：match 的价值在**嵌套结构的深度解构**（一条 case 拆三层 JSON 形状）；纯标量分发用 dict 更快也更短。

### for / while 的完整形态

- `for ... else`：`else` 在循环**未被 break 打断**时执行——搜索失败兜底的惯用法（"找到就 break，没找到走 else"）。
- `range` 是惰性对象不是 list（见 [06-迭代器与生成器](06-迭代器与生成器.md)）；`enumerate(start=)`、`zip(strict=)`（3.10+，长度不等直接报错，防静默截断）是遍历的纪律件。
- 循环变量不新开作用域：循环后仍可见；推导式则有自己的作用域（下节）。

### 推导式与海象运算符

- 四种推导式共用一套语法位置：`list`（`[...]`）、`set`（`{...}`）、`dict`（`{k: v ...}`）、生成器（`(...)`，惰性，见 [06-迭代器与生成器](06-迭代器与生成器.md)）。
- 作用域：推导式是隐式函数作用域，内部变量不泄漏（Py3 语义；唯一例外是被遍历的最外层 iterable 在 Python 3 里也不泄漏）。
- 纪律：嵌套超过两层、或需要提前 break 的场合，退回显式循环——推导式的可读性收益在扁平短小。
- 海象 `:=`：表达式内赋值。两大正当场景——`while chunk := f.read(8192):`（读-判-用一体）与推导式内"过滤即使用"：`[y for x in data if (y := parse(x)) is not None]`。滥用（为省一行而嵌进复杂表达式）直接降低可读性。

### 表达式与语句的分界

`match`、推导式、`:=` 的共同方向：把"造值"从语句挤压进表达式。边界纪律——带副作用的表达式（`list.sort()` 返回 None、`:=` 滥用）是可读性负债；表达式应该造值，语句负责做事。

## 连接

| 想做 | 用 | 不用 |
|---|---|---|
| 标量分发（状态码 → 动作） | dict 映射 | if/elif 链、match |
| 深度解构（嵌套 dict/list 按形状取值） | match | 手写多层 `[]` 与 `in` 判断 |
| 边遍历边构建容器 | 推导式 | append 循环（初学者惯性） |
| 大数据流式过滤 | 生成器表达式（见 [06-迭代器与生成器](06-迭代器与生成器.md)） | 列表推导（全量物化） |
| 搜索 + 未找到兜底 | for/else | 标志位变量 |

**延伸**：循环体里的异常把控制流拐向哪、finally 与 return 谁赢，见 [08-错误与异常](08-错误与异常.md)；异常组 `except*` 与并发任务的结构化收尾见 [03-并发与异步](../03-运行时与性能/03-并发与异步.md)。

## 示例

```python
# for/else + 海象 + strict zip：三个纪律件合用
def find_first_duplicate(pairs):
    seen = set()
    for i, (a, b) in enumerate(pairs):   # 解构 + 计数
        if a in seen or b in seen:
            return i
        seen |= {a, b}
    else:
        return -1                          # 未 break 才到这里

print(find_first_duplicate([(1, 2), (3, 4), (4, 5)]))   # 2
```

```python
# match 解析"形状异构"的消息（嵌套解构是它的主场）
def handle(msg):
    match msg:
        case {"type": "error", "detail": {"code": code, "msg": m}}:
            return f"[{code}] {m}"
        case {"type": "batch", "items": [*items]} if len(items) <= 10:
            return "; ".join(handle(i) for i in items)
        case _:
            return "unrecognized"
```
