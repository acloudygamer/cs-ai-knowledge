# 03-字符串与格式化

> 前置：[01-对象模型与变量](01-对象模型与变量.md)（不可变性）、[02-内建数据结构](02-内建数据结构.md)（序列操作） · 后续：[02-正则与文本处理](../02-IO与工程实践/02-正则与文本处理.md)、[01-文件与路径](../02-IO与工程实践/01-文件与路径.md)（编码落地处）、[05-版本演进](../03-运行时与性能/05-版本演进.md)（t-string）

字符串是 Python 里最常用的"不可变对象"与最常用的序列，两条线都承接前两篇；同时它是人机边界上一切数据的通用载体——文件、网络、配置、日志，全是 str 进出的世界（见 [02-IO与工程实践](../02-IO与工程实践/README.md)）。本篇只讲语言层：编码模型与格式化体系。

## 本质

- `str` 是 **Unicode 码点序列**，不是字节序列：`len()` 数的是码点，`[i]` 取的是码点字符；与外部世界交换必须显式 `encode` / `decode`，字节侧的类型是 `bytes`。
- 不可变（承接 [01-对象模型与变量](01-对象模型与变量.md)）：一切"修改"方法都返回新串；循环拼接用 `''.join(parts)`（先把各部分收进 list，再一次分配）。
- 格式化四代同堂，但工程默认只有一个答案：f-string（快、可读、表达式内联）；其余各有明确的历史定位与残余场景。

## 机制

### str 与 bytes 的边界

```text
"héllo" ──encode('utf-8')──▶ b'h\xc3\xa9llo'      str → bytes：出进程（写文件/网络）
b'h\xc3\xa9llo' ──decode('utf-8')──▶ "héllo"      bytes → str：进进程
```

- UTF-8 是事实默认，但**只是 I/O 层约定**：`open()` 读文件必须显式 `encoding="utf-8"`（Windows 默认 locale 编码是历史陷阱），见 [01-文件与路径](../02-IO与工程实践/01-文件与路径.md)。
- 错误处理策略：`errors="strict" | "replace" | "ignore" | "surrogateescape"`——最后一者能无损往返"不合法字节"，用于文件名等不可控输入。
- 码点 ≠ 字形：组合字符、emoji 的码点数不等于视觉字符数（`len("👨‍👩‍👧‍👦")` 结果是码点数而非 1）；需要字形边界用 `unicodedata` 或第三方。

### f-string：完整语法与常见盲区

```text
{ 表达式 ! 转换 : 格式说明 }
```

- 转换：`!r`（repr，日志与调试首选）、`!s`、`!a`。
- 格式说明高频集：`>10` / `<10` / `^10`（宽度对齐）、`0>6`（补零）、`,.2f`（千分位+两位小数）、`.1%`（百分比）、`x` / `#x`（十六进制）、日期指令 `:%Y-%m-%d`（等价 strftime，日期体系见 [04-日期与时间](../02-IO与工程实践/04-日期与时间.md)）。
- 自文档调试：`f"{x=}"` 输出 `x=3.14`——断点打印与日志一行完成。
- 嵌套：`f"{value:{width}.2f}"`——宽度与精度可以来自变量（替换字段可以整体嵌套）。
- （Python 3.12 增量，PEP 701）f-string 内可复用同类引号、写多行表达式、用反斜杠——历史上三者的转义体操就此废除。

### 格式化四代对比

| 方式 | 形态 | 定位 |
|---|---|---|
| f-string | `f"{x:.2f}"` | 默认答案：编译期解析、运行时最快、表达式直取局部变量 |
| `str.format` | `"{x:.2f}".format(x=x)` | 模板与数据分离的场景（模板存成字符串/配置） |
| `%` 格式化 | `"%.2f" % x` | 遗留代码与 logging 的惰性格式化 `log.info("x=%s", x)`（见 [07-日志与调试](../02-IO与工程实践/07-日志与调试.md)） |
| `string.Template` | `Template("$name").substitute(d)` | 模板来自**不可信用户**时唯一安全选择（不执行表达式） |

安全约束：f-string 会求值任意表达式——绝不能拿用户输入拼模板；这是注入类缺陷的结构性来源，Web 场景见 [01-Web开发总览](../06-应用领域/01-Web开发总览.md)。

（Python 3.14 增量）t-string（PEP 750）：返回 `Template` 对象而非现成字符串，把"插值"与"渲染策略"解耦——库拿到字段后自行决定转义（HTML、shell、SQL），是结构化插值的方向标，见 [05-版本演进](../03-运行时与性能/05-版本演进.md)。

### str 方法：值得记住的非常用件

- `partition` / `rpartition`：切一刀返回三段，比 `split` 更适合"定界符只出现一次"的解析。
- `strip` / `lstrip` / `rstrip`：参数是**字符集合**不是子串（`"path/".rstrip("/")` 的正确理解）。
- `removeprefix` / `removesuffix`（3.9+）：语义正确的"去掉固定前后缀"（`startswith` + 切片的替代品）。
- `split(maxsplit=1)` 与 `splitlines()`：分行解析的精细控制。
- `str.maketrans` + `translate`：批量字符映射，比链式 `replace` 高效且可组合。

## 示例

```python
from datetime import date

x, width = 3.14159, 12
print(f"{x:.2f}")            # 3.14
print(f"{x:>{width}}")       # 右对齐到宽度 12（嵌套字段）
print(f"{x=:.3f}")           # x=3.142（自文档调试）
print(f"{1234567:,}")        # 1,234,567
print(f"{0.842:.1%}")        # 84.2%
print(f"{date(2026, 8, 24):%Y-%m-%d}")
```

```python
# 编解码边界与错误策略
raw = "héllo".encode("utf-8")             # b'h\xc3\xa9llo'
safe = raw.decode("utf-8", errors="replace")
raw[1:].decode("utf-8", errors="surrogateescape")   # 断在多字节序列中间也能无损往返

# join 与 += 的差别：语义上新串每次都造，join 一次成型
parts = []
for i in range(5):
    parts.append(f"row{i}")
table = "\n".join(parts)
```
