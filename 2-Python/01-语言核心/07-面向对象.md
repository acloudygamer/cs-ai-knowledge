# 07-面向对象

> 前置：[01-对象模型与变量](01-对象模型与变量.md)（对象与引用）、[05-函数](05-函数.md)（方法的本体）、[06-迭代器与生成器](06-迭代器与生成器.md)（协议初见） · 后续：[09-上下文管理器](09-上下文管理器.md)、[11-类型提示](11-类型提示.md)（Protocol/TypedDict）、[01-Python视角下的设计模式](../05-设计模式/01-Python视角下的设计模式.md)

Python 的面向对象没有访问修饰符、没有接口关键字、没有构造函数重载——它把 OOP 拆成了两件事：**属性查找规则**（含 MRO）与**协议（dunder）**。前者决定"名字找到谁"，后者决定"语法糖调谁"。抓住这两条，剩下的（dataclass、property、classmethod）都是糖上之糖。

## 本质

- `class` 语句可执行：跑一遍类体（就是个命名空间）、创建**类对象**（类型），再绑定类名。类对象是"能生产实例的可调用对象"：`Point(3, 4)` 调用 `type.__call__` → `__new__`（造实例）+ `__init__`（填状态）。
- 属性查找即协议：`obj.attr` 与 `obj.method()` 没有本质区别，都是"沿查找链取属性"——方法只是恰好可调用的类属性（调用时实例作为首参传入，见 [05-函数](05-函数.md)）。
- 鸭子类型的正式化：语法糖（`for`/`with`/`in`/`==`/`len`）从不检查类型，只找协议方法——类的工作是**实现协议**，而非继承某个基类。

## 机制

### 属性查找链（含描述符一瞥）

查找 `obj.x`：类型上的**数据描述符**（定义 `__get__` + `__set__`，如 property）→ 实例 `__dict__` → 类型 MRO 上的普通属性/非数据描述符（如函数）。推论：property 拦截同名实例属性（连赋值都拦）；方法存在类上而非实例上（实例只存状态）——这也是"所有实例共享一份方法、各存一份字段"的内存结构（见 [01-内存管理与垃圾回收](../03-运行时与性能/01-内存管理与垃圾回收.md)）。

### MRO 与 super()：线性化而非"父类"

多继承下方法按 **MRO**（C3 线性化：保持各父类相对顺序且子类先于父类的唯一序列，`cls.__mro__` 可查）线性查找。`super()` 不是"父类"，是 **MRO 上的下一个类**——协作用（cooperative）多继承的正确姿势：各 mixin 都用 `super().__init__()` 把调用传下去，让 MRO 决定整条链。约束与后果：跳过 `super()` 的类会截断链条（后续 mixin 拿不到初始化）；`__init_subclass__` 钩子常能替代 metaclass 做注册与校验。

### 协议速查表（语法糖 → 方法）

| 语法 | 协议方法 | 已在哪篇展开 |
|---|---|---|
| `x == y` / `hash(x)` | `__eq__` / `__hash__`（相等即哈希相等的契约） | [01-对象模型与变量](01-对象模型与变量.md) |
| `bool(x)` | `__bool__` → `__len__` | [04-控制流程与表达式](04-控制流程与表达式.md) |
| `for x in obj` | `__iter__` / `__next__` | [06-迭代器与生成器](06-迭代器与生成器.md) |
| `with obj:` | `__enter__` / `__exit__` | [09-上下文管理器](09-上下文管理器.md) |
| `x in obj` | `__contains__`（缺省退化为迭代） | 本篇 |
| `obj(k=v)` | `__call__`（对象当函数用） | [05-函数](05-函数.md) |
| `repr(x)` / `str(x)` | `__repr__`（无歧义、给开发者）/ `__str__`（可读、给用户） | 本篇 |
| `x < y` | `__lt__` 等 + `functools.total_ordering` 补全 | 本篇 |

### 封装：约定、 mangling 与 property

- `_name` 是约定（IDE/人遵守，语言不拦）；`__name` 触发名称改写（`_ClassName__name`），目的是**避免子类覆写冲突**而非私有性——外部仍可访问。
- `@property`：把方法暴露成属性。正当用途是"字段语义不变、实现演进"（直接访问改成计算属性不破坏调用方）；滥用（副作用藏在属性访问里）是可读性陷阱。只定义 getter 即只读。

### classmethod 与备选构造

`@classmethod` 的首参是类本身——**备选构造函数**的标准形态（`dict.fromkeys`、`datetime.fromtimestamp` 都是）；`@staticmethod` 是"恰好住在类里的普通函数"，多数时候应该是模块级函数。工厂方法与继承配合的设计权衡见 [02-创建型模式](../05-设计模式/02-创建型模式.md)。

### dataclass：记录类的默认答案

`@dataclass` 自动生成 `__init__` / `__repr__` / `__eq__`；`field(default_factory=list)` 处理可变默认值（承接 [05-函数](05-函数.md) 的默认值陷阱）；`frozen=True` 生成不可变实例（可哈希、可作 dict 键——契约回到 [01-对象模型与变量](01-对象模型与变量.md)）；`slots=True` 省内存（机制见 [01-内存管理与垃圾回收](../03-运行时与性能/01-内存管理与垃圾回收.md)）；`__post_init__` 做派生字段与校验。与 `NamedTuple`（tuple 底座、真不可变）的选择：需要解包与轻量记录用后者，需要方法与演进用前者。

### 抽象的两种形态：ABC 与 Protocol

- `abc.ABC` + `@abstractmethod`：名义类型（nominal）——子类必须显式继承，未实现抽象方法时实例化报错（构造期失败，早于运行时调用失败）。
- `typing.Protocol`：结构类型（structural）——不继承、只看形状，静态检查器据此匹配（见 [11-类型提示](11-类型提示.md)）。这是鸭子类型的静态化，与语言的运行时哲学同构。
- 判据：库的对外扩展点用 Protocol（用户类型无需 import 你的基类）；闭集框架内部用 ABC（强制契约 + 共享实现）。

### metaclass：知道边界即可

类对象的类型是 `type`；`class Foo(metaclass=Meta)` 把"造类"这一步交给 Meta。90% 的历史用途（注册子类、参数校验）已被 `__init_subclass__` 覆盖；真正需要改类创建语义的库（ORM、序列化框架）才碰 metaclass——业务代码出现 metaclass 几乎总是过度设计。

## 连接

| 想做 | 用 | 不用 |
|---|---|---|
| 数据记录（字段+相等+打印） | `@dataclass` | 手写 `__init__`/`__repr__` |
| 固定轻量记录、要解包 | `NamedTuple` / tuple | dict（键拼写错误静默通过） |
| 接口约定（开方式） | `Protocol` | ABC（强迫继承） |
| 组合出复用 | mixin（协作 super 链）或组合 | 深继承树（查找不透明） |
| 计算属性/校验 | `@property` | getter/setter 方法对（非 Python 风格） |

**延伸**：协议思想在类型系统的对应物（Protocol/TypedDict）见 [11-类型提示](11-类型提示.md)；"让半数 GoF 模式消失"的正是本篇的函数一等性与鸭子类型——见 [01-Python视角下的设计模式](../05-设计模式/01-Python视角下的设计模式.md)。

## 示例

```python
from dataclasses import dataclass, field
from functools import total_ordering

@total_ordering                      # 只写 __eq__ + __lt__，补全其余比较
@dataclass(frozen=True, slots=True)  # 不可变 + 省内存（无实例 __dict__）
class Version:
    major: int
    minor: int = 0
    tags: frozenset = field(default=frozenset)   # 可变默认值必须 default_factory

    def __lt__(self, other):
        return (self.major, self.minor) < (other.major, other.minor)

print(Version(3, 12) < Version(3, 14))   # True
# {Version(3, 12): "stable"} 可行：frozen + 全不可变字段 → 可哈希
```

```python
# 协作式多继承：super() 沿 MRO 传递，mixin 不截断链
class LoggerMixin:
    def __init__(self, **kw):
        super().__init__(**kw)          # 传给 MRO 下一家
        self.log = []
    def note(self, msg): self.log.append(msg)

class TimeoutMixin:
    def __init__(self, **kw):
        super().__init__(**kw)
        self.timeout = kw.pop("timeout", 30)

class Service(LoggerMixin, TimeoutMixin):   # MRO: Service → Logger → Timeout → object
    def __init__(self, name):
        super().__init__()                # 沿链跑完所有 __init__
        self.name = name

s = Service("api"); s.note("started")
print(s.timeout, s.log)                   # 30 ['started']
```
