# 数据库操作

数据库操作是程序与关系型数据库之间的数据持久化交互，通过 SQL 语句实现 CRUD（创建、读取、更新、删除）操作。

## 核心机制

Python 的 `sqlite3` 模块直接内嵌 SQLite 数据库，无需独立服务器进程，通过文件锁实现并发安全。SQLAlchemy 是 ORM（对象关系映射）层，将 Python 对象操作翻译为 SQL 语句。事务（Transaction）是一组原子化操作的集合，commit 确认变更、rollback 撤销变更。参数化查询 `?` 占位符防止 SQL 注入攻击。WAL（Write-Ahead Logging）模式将写操作先记录到日志再写入数据库，减少锁竞争提高并发性能。

## 定义断言

> 数据库是持久化的结构化数据集合，数据库操作本质是程序通过 SQL 与数据库引擎交互，实现数据的持久化与查询，其核心挑战是事务原子性、并发安全与查询效率。

## sqlite3 基础

### 参考样例

```python
import sqlite3

conn = sqlite3.connect("app.db")
cursor = conn.cursor()
cursor.execute("SELECT * FROM users WHERE id = ?", (1,))
row = cursor.fetchone()
```

## SQLAlchemy ORM

### 参考样例

```python
from sqlalchemy import create_engine
from sqlalchemy.orm import sessionmaker

engine = create_engine("sqlite:///app.db")
Session = sessionmaker(bind=engine)
session = Session()
```

## CRUD 操作

### 参考样例

```python
user = User(name="Alice", email="alice@example.com")
session.add(user)
session.commit()
```

## 事务与回滚

### 参考样例

```python
try:
    cursor.execute("UPDATE accounts SET balance = ? WHERE id = ?", (new_balance, account_id))
    conn.commit()
except Exception:
    conn.rollback()
    raise
```

## 常见问题

| 问题 | 解决方案 |
|------|----------|
| SQL 注入 | 参数化查询 |
| 并发写入冲突 | WAL 模式 |
| 连接泄漏 | 上下文管理器 |
| 大数据量查询 | 使用 `yield_per()` 流式处理 |
