# 日志记录

## logging 模块基础

### 日志级别

```python
import logging

# 级别：DEBUG < INFO < WARNING < ERROR < CRITICAL
logging.debug("调试信息")   # 开发时查看细节
logging.info("重要操作")    # 正常业务流程
logging.warning("警告")     # 潜在问题
logging.error("错误")       # 错误但能继续
logging.critical("严重")    # 程序无法继续
```

### 基础配置

```python
import logging

# 方式1：basicConfig（简单场景）
logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s - %(name)s - %(levelname)s - %(message)s",
    datefmt="%Y-%m-%d %H:%M:%S"
)

# 方式2：Logger 对象（推荐）
logger = logging.getLogger(__name__)
logger.setLevel(logging.DEBUG)

# 控制台处理器
console_handler = logging.StreamHandler()
console_handler.setLevel(logging.INFO)
formatter = logging.Formatter(
    "%(asctime)s - %(name)s - %(levelname)s - %(message)s"
)
console_handler.setFormatter(formatter)
logger.addHandler(console_handler)

# 文件处理器
file_handler = logging.FileHandler("app.log", encoding="utf-8")
file_handler.setLevel(logging.DEBUG)
file_handler.setFormatter(formatter)
logger.addHandler(file_handler)
```

### 日志器层级

```python
# 根日志器
logging.basicConfig(level=logging.INFO)

# 模块日志器（继承根日志器配置）
logger = logging.getLogger(__name__)  # 推荐：每个模块用自己的日志器

# 子日志器自动继承父日志器配置
api_logger = logging.getLogger("app.api")      # 继承 app 日志器
db_logger = logging.getLogger("app.database")  # 继承 app 日志器
```

## 配置文件方式

### dictConfig（YAML 格式）

```yaml
# logging_config.yaml
version: 1
disable_existing_loggers: false

formatters:
  detailed:
    format: "%(asctime)s - %(name)s - %(levelname)s - %(message)s"
  simple:
    format: "%(levelname)s - %(message)s"

handlers:
  console:
    class: logging.StreamHandler
    level: INFO
    formatter: simple
    stream: ext://sys.stdout
  file:
    class: logging.handlers.RotatingFileHandler
    level: DEBUG
    formatter: detailed
    filename: app.log
    maxBytes: 10485760  # 10MB
    backupCount: 3

loggers:
  app:
    level: DEBUG
    handlers: [console, file]
    propagate: false  # 不传播到根日志器

root:
  level: INFO
  handlers: [console]
```

```python
import logging.config
import yaml

with open("logging_config.yaml") as f:
    config = yaml.safe_load(f)
    logging.config.dictConfig(config)

logger = logging.getLogger("app")
```

## 结构化日志

### JSON 格式日志

```python
import logging
import json
from datetime import datetime

class JSONFormatter(logging.Formatter):
    def format(self, record):
        log_obj = {
            "timestamp": datetime.utcnow().isoformat(),
            "level": record.levelname,
            "logger": record.name,
            "message": record.getMessage(),
            "module": record.module,
            "function": record.funcName,
            "line": record.lineno
        }
        if record.exc_info:
            log_obj["exception"] = self.formatException(record.exc_info)
        if hasattr(record, "user_id"):
            log_obj["user_id"] = record.user_id
        if hasattr(record, "request_id"):
            log_obj["request_id"] = record.request_id
        return json.dumps(log_obj)

# 使用
handler = logging.StreamHandler()
handler.setFormatter(JSONFormatter())
logger = logging.getLogger("app")
logger.addHandler(handler)
logger.info("User logged in", extra={"user_id": 123, "request_id": "abc"})
```

## 最佳实践

### 业务日志模式

```python
import logging
from typing import Optional
from contextvars import ContextVar

# 请求上下文（用于链路追踪）
request_id_var: ContextVar[Optional[str]] = ContextVar("request_id", default=None)

class ContextLogger:
    def __init__(self, name: str):
        self.logger = logging.getLogger(name)

    def _log(self, level: str, msg: str, **kwargs):
        extra = {"request_id": request_id_var.get()}
        getattr(self.logger, level)(msg, extra=extra, **kwargs)

    def info(self, msg: str, **kwargs):
        self._log("info", msg, **kwargs)

    def error(self, msg: str, **kwargs):
        self._log("error", msg, **kwargs)

# 使用
logger = ContextLogger("app.payment")
request_id_var.set("req-123")
logger.info("Payment processed", amount=100.00, currency="USD")
```

### 异常日志

```python
import logging
import traceback

logger = logging.getLogger(__name__)

# 方式1：记录异常信息
try:
    risky_operation()
except Exception:
    logger.exception("操作失败")  # 自动包含堆栈跟踪

# 方式2：自定义异常链
try:
    load_config()
except FileNotFoundError as e:
    raise ConfigError("配置文件不存在") from e

# 方式3：只记录关键异常
try:
    db.query()
except ConnectionError as e:
    logger.error(f"数据库连接失败: {e}", exc_info=False)  # 避免敏感信息泄露
```

### 性能日志

```python
import logging
import time
from functools import wraps

logger = logging.getLogger(__name__)

def log_performance(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        result = func(*args, **kwargs)
        elapsed = (time.perf_counter() - start) * 1000
        logger.info(f"{func.__name__} 执行耗时: {elapsed:.2f}ms")
        return result
    return wrapper

@log_performance
def slow_query():
    pass
```

## 常见问题

| 问题 | 解决方案 |
|------|----------|
| 日志重复输出 | 检查日志器层级 `propagate` 设置 |
| 中文乱码 | 指定 `encoding="utf-8"` |
| 日志文件过大 | 使用 `RotatingFileHandler` 或 `TimedRotatingFileHandler` |
| 生产环境调试 | 使用 `LEVEL=DEBUG` 环境变量动态调整 |
| 敏感信息泄露 | 使用日志过滤器过滤敏感字段 |
