# 模块与包

## import 基础

### 参考样例

```python
# 导入整个模块
import math
print(math.pi)

# 导入特定内容
from math import pi, sqrt

# 别名
import numpy as np
from pandas import DataFrame as DF

# 相对导入（包内使用）
from . import sibling_module
from ..parent import ParentModule
```

## 模块结构

### 参考样例

```python
# my_module.py
"""模块文档字符串"""

MODULE_VERSION = "1.0.0"

def greet(name: str) -> str:
    return f"Hello, {name}!"

class MyClass:
    pass

# 模块级执行（作为脚本时）
if __name__ == "__main__":
    print(greet("World"))
```

## __init__.py

### 参考样例

```python
# 控制导出内容
__all__ = ["ClassA", "function_b"]

# 包级别初始化
import logging
logging.basicConfig(level=logging.INFO)

# 简化导入（子模块提升到包级别）
from .submodule import (
    useful_class as Class,
    useful_func as func,
)
```

## __main__.py

### 参考样例

```python
# __main__.py - 包的可执行入口
def main():
    import argparse
    parser = argparse.ArgumentParser()
    parser.add_argument("name")
    args = parser.parse_args()
    print(f"Hello, {args.name}!")

if __name__ == "__main__":
    main()
```

## 模块搜索路径

### 参考样例

```python
import sys

# 查看搜索路径
print(sys.path)

# 添加自定义路径
sys.path.insert(0, "/path/to/my/modules")
```

## importlib 动态导入

### 参考样例

```python
import importlib

# 动态导入
module_name = "math"
math = importlib.import_module(module_name)

# 重新加载模块
import my_module
importlib.reload(my_module)
```

## 常见陷阱

### 参考样例

```python
# 陷阱1：循环导入
# 解决：延迟导入、在函数内导入、使用 __init__.py 重构

# 陷阱2：模块级可变默认值
# default_items = []  # 所有导入共享同一列表
# 解决：使用 None，在函数内初始化

# 陷阱3：相对导入位置错误
# from . import module  # 在包内可以
# import module          # 在包外可以
# 但不能混用
```
