# 模块与包

模块与包是 Python 代码组织的单元，模块是单个 `.py` 文件，包是包含 `__init__.py` 的目录，通过 import 系统实现命名空间隔离和代码复用。

## 核心机制

`import` 语句触发模块加载：先查找模块文件（sys.path 顺序），再执行模块顶层代码，最后将模块对象绑定到当前命名空间。模块只初始化一次，后续 import 直接返回已缓存的模块对象。`__all__` 列表控制 `from module import *` 的导出内容。相对导入 `from .submodule import x` 依赖包的层级关系，包内才能使用。`__name__ == "__main__"` 判断模块是直接运行还是被导入。虚拟环境通过修改 sys.path 将项目本地包优先于系统包。

## 定义断言

> 模块是 Python 代码执行和命名空间隔离的基本单位，包是通过目录层级组织模块的命名空间容器，import 机制是模块间依赖关系的声明式引用。

## 数据流

<pre>
import 语句
    |
    v
sys.path 查找
    |
    v
模块已加载? --是--> 返回缓存模块
    |
    否
    v
执行模块顶层代码
    |
    v
缓存并绑定到命名空间
</pre>

## import 基础

### 参考样例

```python
import math
from math import pi
import numpy as np
```

## 模块结构

### 参考样例

```python
MODULE_VERSION = "1.0.0"

def greet(name: str) -> str:
    return f"Hello, {name}!"

if __name__ == "__main__":
    print(greet("World"))
```

## __init__.py

### 参考样例

```python
__all__ = ["ClassA", "function_b"]
from .submodule import useful_class as Class
```

## 动态导入

### 参考样例

```python
import importlib
math = importlib.import_module("math")
```

## 常见陷阱

| 陷阱 | 解决方案 |
|------|----------|
| 循环导入 | 延迟导入、在函数内导入 |
| 模块级可变默认值 | 使用 None，在函数内初始化 |
| 相对导入位置错误 | 确保在包内使用 `.` 相对导入 |
