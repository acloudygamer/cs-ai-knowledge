# 虚拟环境与包管理

## 解决什么问题

不同项目依赖不同版本的同一包，虚拟环境实现项目间依赖隔离；包管理器解决依赖安装、升级、卸载问题。

## 核心概念

- 虚拟环境隔离项目依赖，避免版本冲突
- `uv` 是新一代包管理器（Rust 编写），速度极快
- `venv` 是 Python 内置虚拟环境，轻量简单
- `poetry`/`pipenv` 提供依赖锁定和项目管理功能
- `pyproject.toml` 是现代 Python 包标准配置格式

## 怎么用

## 虚拟环境

### uv（推荐）

`uv` 是新一代 Python 包管理器，速度极快（用 Rust 编写），支持虚拟环境和包管理：

```bash
# 安装 uv（Linux/macOS/Windows）
curl -LsSf https://astral.sh/uv/install.sh | sh

# 或通过 pip
pip install uv

# 创建虚拟环境
uv venv myenv

# 激活（Windows）
myenv\Scripts\activate

# 激活（Linux/macOS）
source myenv/bin/activate

# 安装依赖
uv pip install requests
uv pip install pytest --dev

# 从 pyproject.toml 安装
uv pip install -e .

# 同步依赖
uv pip sync

# 导出 requirements.txt
uv pip freeze > requirements.txt

# 运行脚本（自动使用虚拟环境）
uv run python script.py
```

### venv（内置）

```bash
# 创建虚拟环境
python -m venv myenv

# Windows
myenv\Scripts\activate

# Linux/macOS
source myenv/bin/activate

# 退出
deactivate
```

### poetry

```bash
# 安装
pip install poetry

# 创建项目
poetry new myproject
cd myproject

# 安装依赖
poetry install

# 激活虚拟环境
poetry shell

# 添加依赖
poetry add requests
poetry add --dev pytest

# 更新依赖
poetry update

# 导出 requirements.txt
poetry export -f requirements.txt --output requirements.txt
```

### pipenv

```bash
# 安装
pip install pipenv

# 创建环境并安装依赖
pipenv install requests

# 激活
pipenv shell

# 安装开发依赖
pipenv install --dev pytest

# 锁定并安装
pipenv lock && pipenv install --deploy

# requirements.txt 导出
pipenv lock -r > requirements.txt
```

## pip 基础

```bash
# 安装包
pip install requests
pip install requests==2.28.0
pip install "requests>=2.28.0,<3.0.0"

# 升级
pip install --upgrade requests

# 卸载
pip uninstall requests

# 查看已安装
pip list
pip list --outdated

# 冻结依赖
pip freeze > requirements.txt

# 安装本地包
pip install -e .
pip install -e ../mypackage

# 从 requirements 安装
pip install -r requirements.txt
```

## pip 镜像源

```bash
# 临时使用
pip install requests -i https://pypi.tuna.tsinghua.edu.cn/simple

# 永久配置
# Windows: %USERPROFILE%\pip\pip.ini
# Linux/macOS: ~/.pip/pip.conf

# 清华镜像

trusted-host = pypi.tuna.tsinghua.edu.cn

# 阿里云镜像
[global]
index-url = https://mirrors.aliyun.com/pypi/simple/
trusted-host = mirrors.aliyun.com
```

## pyproject.toml

```toml
[project]
name = "mypackage"
version = "0.1.0"
description = "A sample package"
authors = [{name = "Alice", email = "alice@example.com"}]
dependencies = [
    "requests>=2.28.0",
    "click>=8.0.0",
]

[project.optional-dependencies]
dev = [
    "pytest>=7.0.0",
    "black>=23.0.0",
    "mypy>=1.0.0",
]
lint = ["flake8>=6.0.0"]

[build-system]
requires = ["setuptools>=45", "wheel"]
build-backend = "setuptools.build_meta"
```

## setup.py

```python
from setuptools import setup, find_packages

setup(
    name="mypackage",
    version="0.1.0",
    packages=find_packages(),
    install_requires=[
        "requests>=2.28.0",
    ],
    extras_require={
        "dev": ["pytest>=7.0.0"],
    },
    python_requires=">=3.8",
    author="Alice",
    author_email="alice@example.com",
    description="A sample package",
    long_description=open("README.md").read(),
    long_description_content_type="text/markdown",
    url="https://github.com/user/mypackage",
    classifiers=[
        "Programming Language :: Python :: 3",
        "License :: OSI Approved :: MIT License",
        "Operating System :: OS Independent",
    ],
)
```

## pipx（全局应用）

```bash
# 安装 pipx
pip install pipx
pipx ensurepath

# 安装全局工具
pipx install black
pipx install pytest
pipx install httpie

# 运行
pipx run black .

# 升级
pipx upgrade black
pipx upgrade-all
```

## uv（现代全能工具）

`uv` 还可以替代 pip、pip-tools、pipx、poetry 等：

```bash
# 管理 Python 版本
uv python install 3.12 3.13 3.14
uv python list

# 快速运行（无需手动创建环境）
uv run --with pandas python script.py

# 管理全局工具（类似 pipx）
uv tool install black
uv tool run black .

# 锁定依赖
uv pip compile requirements.in -o requirements.txt
```

## 多版本 Python

```bash
# 使用 pyenv 管理 Python 版本
pyenv install 3.12.0
pyenv install 3.13.0
pyenv install 3.14.0

# 设置全局版本
pyenv global 3.14.0

# 设置本地版本（项目目录）
pyenv local 3.14.0

# 创建特定版本的虚拟环境
python3.14 -m venv myenv

# 查看版本
python --version
pyenv versions
```

### uv 管理 Python 版本（推荐）

```bash
# 安装多个 Python 版本
uv python install 3.12 3.13 3.14

# 查看已安装版本
uv python list

# 指定版本创建虚拟环境
uv venv --python 3.13 myenv

# 运行特定版本
uv run --python 3.14 python script.py
```

## 常见问题

```bash
# 1. pip 安装失败
pip install --upgrade pip
pip install --upgrade setuptools wheel

# 2. SSL 错误（macOS）
pip install --trusted-host pypi.org --trusted-host files.pythonhosted.org <package>

# 3. 权限错误
pip install --user <package>
# 或使用虚拟环境

# 4. 清理缓存
pip cache purge

# 5. 查看包信息
pip show requests
pip show -f requests

# 6. 安装太慢？使用 uv（推荐）
uv pip install requests  # 比 pip 快 10-100 倍
```
