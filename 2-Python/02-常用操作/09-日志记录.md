# 日志记录

日志记录是程序运行时的事件追踪机制，通过结构化输出记录运行时状态，支持问题诊断、性能分析和审计。

## 核心机制

`logging` 模块实现日志的层级传播：Logger（产生日志）→ Handler（输出目的地）→ Formatter（格式化）。日志级别（DEBUG < INFO < WARNING < ERROR < CRITICAL）控制日志详细程度。`propagate` 属性控制日志是否向上传播到父 Logger。日志轮转（RotatingFileHandler）在文件达到指定大小或时间后自动创建新文件，避免单文件过大。结构化日志（JSON 格式）便于日志聚合系统（如 ELK）解析和分析。

## 定义断言

> 日志是程序运行时产生的带时间戳的事件记录，日志记录本质是通过日志级别过滤和格式化输出实现运行时状态的可观测性。

## 数据流

<pre>
Logger (产生)           Handler (输出)         Formatter (格式化)
    |                      |                      |
    | logger.info("msg")   |                      |
    | [检查级别]           |                      |
    |--------------------->|                      |
    |                      | [Filter]            |
    |                      |-------------------->|
    |                      |     formatted msg   |
    |                      |<--------------------|
    |                      | [输出到终端/文件]    |
</pre>

## logging 基础

### 参考样例

```python
import logging

logger = logging.getLogger(__name__)
logger.setLevel(logging.DEBUG)
logger.info("重要操作")
```

## 结构化日志

### 参考样例

```python
class JSONFormatter(logging.Formatter):
    def format(self, record):
        return json.dumps({
            "timestamp": record.created,
            "level": record.levelname,
            "message": record.getMessage()
        })
```

## loguru

### 参考样例

```python
from loguru import logger

logger.add("app_{time}.log", rotation="500 MB")
logger.info("Hello, {}!", "World")
```

## 常见问题

| 问题 | 解决方案 |
|------|----------|
| 日志重复输出 | 检查 `propagate` 设置 |
| 中文乱码 | 指定 `encoding="utf-8"` |
| 日志文件过大 | 使用 RotatingFileHandler |
| 敏感信息泄露 | 日志过滤器过滤字段 |
