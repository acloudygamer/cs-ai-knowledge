# 文件操作

文件操作是 Python 程序与文件系统交互的基础，通过操作系统抽象层实现用户态进程与持久化存储之间的数据交换。

## 核心机制

`open()` 是 Python 文件操作的基础函数，调用操作系统内核的 `open()` 系统调用返回文件描述符。`with` 语句通过 `__enter__`/`__exit__` 协议确保资源正确释放，避免文件描述符泄漏。`pathlib.Path` 是 Python 3.4+ 引入的面向对象路径 API，将路径作为对象而非字符串处理，自动适配不同操作系统的路径分隔符规则。流式读取通过缓冲区机制避免大文件一次性加载导致的内存峰值。

## 定义断言

> 文件是进程视角下可按字节序访问的持久化存储抽象，文件操作本质是用户态缓冲区与内核页缓存之间的数据搬移。

## 数据流

<pre>
进程用户态                内核                    磁盘
   |                     |                      |
   |  open()              |                      |
   |--------------------->|                      |
   |  [返回 fd]            |                      |
   |                      |                      |
   |  read(buf, n)        |                      |
   |--------------------─>| [页缓存查找]          |
   |                      |--------->            |
   |                      | [命中] <--------     |
   |<====================>|                      |
   |  [返回数据]           |                      |
</pre>

## open / with

### 参考样例

```python
with open("file.txt", "r", encoding="utf-8") as f:
    content = f.read()
```

## pathlib

### 参考样例

```python
from pathlib import Path

p = Path(".") / "data" / "file.txt"
content = p.read_text(encoding="utf-8")
Path("output").mkdir(parents=True, exist_ok=True)
```

## CSV 操作

### 参考样例

```python
import csv

with open("data.csv", "r", newline="", encoding="utf-8") as f:
    reader = csv.DictReader(f)
    for row in reader:
        print(row["name"], row["email"])
```

## pickle（对象序列化）

### 参考样例

```python
import pickle

data = {"name": "Alice", "scores": [90, 85, 88]}
with open("data.pkl", "wb") as f:
    pickle.dump(data, f)
```

安全注意：永远不反序列化不可信来源，可能执行恶意代码。

## 临时文件

### 参考样例

```python
import tempfile

with tempfile.TemporaryDirectory() as tmpdir:
    temp_file = Path(tmpdir) / "output.txt"
    temp_file.write_text("Data")
```

## 文件锁定

### 参考样例

```python
import fcntl  # Unix only

def lock_file(path: Path):
    with open(path, "r+") as f:
        fcntl.flock(f.fileno(), fcntl.LOCK_EX)
        yield f
        fcntl.flock(f.fileno(), fcntl.LOCK_UN)
```

Windows 跨平台锁定推荐使用 `portalocker` 库。

## 文件批量操作

### 参考样例

```python
import shutil
from pathlib import Path

shutil.copy2("file.txt", "backup.txt")
shutil.move("old.txt", "new.txt")
```

## 常见问题

| 问题 | 解决方案 |
|------|----------|
| 中文路径乱码 | 使用 `encoding="utf-8"` |
| 大文件读取慢 | 使用 `mmap` 内存映射 |
| 跨平台路径 | 使用 `pathlib.Path` 自动处理 |
