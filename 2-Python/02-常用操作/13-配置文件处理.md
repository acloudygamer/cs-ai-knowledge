# 配置文件处理

配置文件处理是程序读取和解析外部配置文件以调整运行时行为的机制，实现配置与代码的分离。

## 核心机制

`tomllib` 是 Python 3.11+ 内置的 TOML 解析库，无需第三方依赖。TOML（Tom's Obvious, Minimal Language）设计目标是人类可读、明确无歧义，适合作为项目配置文件。YAML 通过缩进表达层级结构，比 JSON 更适合配置文件但解析稍慢。`configparser` 处理 INI 格式，适合 Windows 环境。分层配置加载允许默认配置被环境配置覆盖，再被环境变量覆盖，实现不同环境的差异化配置。

## 定义断言

> 配置文件是程序启动时读取的外部数据，用于将运行时参数与代码分离，支持不同环境的差异化配置。

## TOML

### 参考样例

```python
import tomllib

with open("config.toml", "rb") as f:
    config = tomllib.load(f)
print(config["database"]["host"])
```

## YAML

### 参考样例

```python
import yaml

with open("config.yaml") as f:
    config = yaml.safe_load(f)
```

## 环境变量覆盖

### 参考样例

```python
import os

if "DB_HOST" in os.environ:
    config["database"]["host"] = os.environ["DB_HOST"]
```

## JSON vs TOML vs YAML 对比

| 特性 | JSON | TOML | YAML |
|------|------|------|------|
| Python 内置 | 3.0+ | 3.11+ | 需安装 |
| 注释支持 | 否 | 是 | 是 |
| 人类可读性 | 一般 | 优秀 | 优秀 |

## 常见问题

| 问题 | 解决方案 |
|------|----------|
| 敏感信息泄露 | 使用环境变量而非硬编码 |
| 多环境配置 | 分层配置加载机制 |
| 配置文件格式错误 | 使用 `tomllib.load()` 捕获解析异常 |
