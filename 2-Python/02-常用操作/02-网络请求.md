# 网络请求

网络请求是 Python 程序作为 HTTP/HTTPS 客户端与远程服务器通信的过程，本质是通过 TCP socket 发送协议报文并接收响应。

## 核心机制

`requests` 库封装了 socket 层面的通信细节，提供了直观的 API。HTTP 是无状态协议，请求-响应模型基于 TCP 可靠连接。连接复用通过 Session 对象实现，避免重复 TCP 握手开销。超时机制防止无限等待，硬超时强制关闭连接、软超时触发异常。指数退避重试在网络不稳定时通过逐步增加间隔来避免惊群效应。

## 定义断言

> 网络请求是客户端向服务器发送符合 HTTP 协议的报文并接收响应的过程，其核心挑战在于不可靠网络下的超时、重试与连接管理。

## 数学模型

指数退避重试间隔计算：
$$T_{delay} = T_{base} \times 2^{attempt}$$

硬上限通常设为 60 秒，防止间隔过长。

## requests

### 参考样例

```python
import requests

response = requests.get("https://api.example.com/users")
response.raise_for_status()
data = response.json()
```

## httpx（异步支持）

### 参考样例

```python
import httpx

async def fetch_all(urls):
    async with httpx.AsyncClient() as client:
        tasks = [client.get(url) for url in urls]
        return await asyncio.gather(*tasks)
```

## 超时配置

### 参考样例

```python
timeout = httpx.Timeout(connect=5.0, read=30.0)
```

## 重试策略

### 参考样例

```python
from httpx import Retry

retry_strategy = Retry(
    total=3,
    backoff_factor=0.5,
    status_forcelist=[500, 502, 503, 504]
)
```

## WebSocket

### 参考样例

```python
import websockets

async def websocket_client():
    async with websockets.connect("ws://localhost:8765") as ws:
        await ws.send("Hello")
        response = await ws.recv()
```

## 常见问题

| 问题 | 解决方案 |
|------|----------|
| SSL 证书错误 | `verify=False`（测试环境） |
| 代理设置 | `proxies={"http": "http://proxy:8080"}` |
| 重定向过多 | `allow_redirects=False` |
