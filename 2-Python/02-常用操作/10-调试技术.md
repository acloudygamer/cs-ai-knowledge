# 调试技术

调试技术是定位和修复程序错误的方法论，通过中断执行、检查状态、逐步执行等手段理解程序行为。

## 核心机制

`pdb` 是 Python 内置调试器，基于文本交互式控制台实现断点设置、单步执行、变量检查。`breakpoint()` 是 Python 3.7+ 引入的便捷断点函数，默认调用 `pdb.set_trace()`，可通过 `PYTHONBREAKPOINT` 环境变量切换调试器实现。IDE 调试器（如 VS Code）通过 pydevd 协议实现图形化断点、单步、变量查看，比 pdb 更直观。日志调试在难以复现的 bug 场景下优于断点，因可在生产环境开启。profiler 通过采样或插桩统计函数调用频率和耗时，定位性能热点。

## 定义断言

> 调试是在程序执行过程中通过中断、检查、步进来观察程序状态的方法，其本质是通过降低问题空间来定位错误源头。

## pdb 常用命令

| 命令 | 简写 | 说明 |
|------|------|------|
| `continue` | `c` | 继续执行到断点 |
| `next` | `n` | 执行下一行 |
| `step` | `s` | 进入函数 |
| `break` | `b` | 设置断点 |
| `print` | `p` | 打印变量 |
| `where` | `w` | 查看调用栈 |

## breakpoint()

### 参考样例

```python
def process_data(data):
    breakpoint()
    return [x * 2 for x in data]
```

## 堆栈跟踪

### 参考样例

```python
import traceback

traceback.print_stack()
```

## 常见问题

| 问题 | 解决方案 |
|------|----------|
| 多线程调试困难 | 使用日志定位 |
| 难以复现的 bug | 添加详细日志 |
| 内存泄漏 | `tracemalloc` 或 `objgraph` |
| 性能问题 | `cProfile` 或 `line_profiler` |
