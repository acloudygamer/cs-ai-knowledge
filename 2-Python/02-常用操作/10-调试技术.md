# 调试技术

## pdb（内置调试器）

### 启动方式

```python
# 方式1：在代码中插入断点
import pdb
def buggy_function(x):
    result = x * 2
    pdb.set_trace()  # 程序在此暂停
    return result / 0

# 方式2：命令行启动
# python -m pdb script.py

# 方式3：事后调试
python script.py
# 崩溃后输入: python -m pdb script.py
```

### 常用命令

| 命令 | 简写 | 说明 |
|------|------|------|
| `continue` | `c` | 继续执行直到断点 |
| `next` | `n` | 执行下一行（不进入函数） |
| `step` | `s` | 执行下一行（进入函数） |
| `until` | `u` | 执行到指定行 |
| `break` | `b` | 设置断点 |
| `delete` | `d` | 删除断点 |
| `list` | `l` | 查看当前代码 |
| `print` | `p` | 打印变量值 |
| `pp` | - | 格式化打印 |
| `args` | `a` | 打印函数参数 |
| `where` | `w` | 查看调用栈 |
| `up` | `u` | 跳到上层栈帧 |
| `down` | `do` | 跳到下层栈帧 |
| `quit` | `q` | 退出调试器 |

### 实用示例

```python
import pdb

def calculate_total(items, discount=0):
    pdb.set_trace()
    total = sum(item["price"] * item["quantity"] for item in items)
    if discount > 0:
        total = total * (1 - discount)
    return total

# 调试时常用命令:
# (Pdb) p items        # 查看 items 变量
# (Pdb) pp locals()    # 打印所有局部变量
# (Pdb) b 5            # 在第5行设置断点
# (Pdb) condition 1 x > 100  # 条件断点
# (Pdb) interact      # 启动交互式解释器
```

## breakpoint()（Python 3.7+）

```python
# breakpoint() 默认调用 pdb
def process_data(data):
    breakpoint()  # 程序在此暂停，进入 pdb
    return [x * 2 for x in data]

# 通过环境变量配置调试器
# PYTHONBREAKPOINT=0 禁用断点
# PYTHONBREAKPOINT=pdb.set_trace
# PYTHONBREAKPOINT=ipdb.set_trace  # 使用 ipdb
```

    logger.debug(f"Input: {data}")

### 堆栈跟踪

```python
import traceback
import sys

# 打印当前堆栈
traceback.print_stack()

# 获取堆栈信息
stack = traceback.extract_stack()
for frame in stack[:-1]:  # 排除当前帧
    print(f"{frame.filename}:{frame.lineno} in {frame.name}")

# 全局异常处理器
def global_exception_handler(exc_type, exc_value, exc_traceback):
    if issubclass(exc_type, KeyboardInterrupt):
        sys.__excepthook__(exc_type, exc_value, exc_traceback)
        return
    print("Unhandled exception:")
    traceback.print_exception(exc_type, exc_value, exc_traceback)

sys.excepthook = global_exception_handler
```

## 类型检查辅助

### mypy 静态检查

```bash
pip install mypy
mypy script.py --strict
```

```python
# 在调试时添加类型注解帮助理解
def process_items(items: list[int]) -> dict[str, int]:
    result: dict[str, int] = {}
    for i, item in enumerate(items):
        result[f"item_{i}"] = item  # mypy 会检查类型
    return result
```

###运行时类型检查

```python
from typing import get_type_hints, get_origin, get_args

def validate_types(func):
    hints = get_type_hints(func)
    def wrapper(*args, **kwargs):
        # 验证逻辑（调试用）
        return func(*args, **kwargs)
    return wrapper
```

## 常见问题

| 问题 | 解决方案 |
|------|----------|
| 多线程调试困难 | 使用 `breakpoint()` + `PYTHONBREAKPOINT=0` 禁用断点 |
| 难以复现的 bug | 添加详细日志记录关键路径 |
| 内存泄漏 | 使用 `tracemalloc` 或 `objgraph` |
| 性能问题 | 使用 `cProfile` 或 `line_profiler` |
| 并发 bug | 使用 `threading.current_thread().name` 辅助定位 |
