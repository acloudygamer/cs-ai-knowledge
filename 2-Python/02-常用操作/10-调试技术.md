# 调试技术

## pdb（内置调试器）

### 启动方式

### 参考样例

```python
# 方式1：在代码中插入断点
import pdb
def buggy_function(x):
    result = x * 2
    pdb.set_trace()  # 程序在此暂停
    return result / 0

# 方式2：命令行启动
# python -m pdb script.py
```

### 常用命令

| 命令 | 简写 | 说明 |
|------|------|------|
| `continue` | `c` | 继续执行直到断点 |
| `next` | `n` | 执行下一行（不进入函数） |
| `step` | `s` | 执行下一行（进入函数） |
| `break` | `b` | 设置断点 |
| `delete` | `d` | 删除断点 |
| `print` | `p` | 打印变量值 |
| `where` | `w` | 查看调用栈 |
| `quit` | `q` | 退出调试器 |

### 实用示例

```python
def calculate_total(items, discount=0):
    pdb.set_trace()
    total = sum(item["price"] * item["quantity"] for item in items)
    if discount > 0:
        total = total * (1 - discount)
    return total
```

## breakpoint()（Python 3.7+）

### 参考样例

```python
def process_data(data):
    breakpoint()  # 程序在此暂停，进入 pdb
    return [x * 2 for x in data]

# 通过环境变量配置调试器
# PYTHONBREAKPOINT=0 禁用断点
# PYTHONBREAKPOINT=ipdb.set_trace
```

## 常见调试技术

### 打印调试

### 参考样例

```python
# 快速查看变量
print(f"DEBUG: x={x}, y={y}")

# 使用 assert
assert x > 0, f"x 必须为正数，实际值: {x}"

# 条件打印
import logging
logging.debug(f"Processing: {data}")
```

### 堆栈跟踪

### 参考样例

```python
import traceback

# 打印当前堆栈
traceback.print_stack()

# 全局异常处理器
def global_exception_handler(exc_type, exc_value, exc_traceback):
    print("Unhandled exception:")
    traceback.print_exception(exc_type, exc_value, exc_traceback)
```

## 常见问题

| 问题 | 解决方案 |
|------|----------|
| 多线程调试困难 | 使用日志记录辅助定位 |
| 难以复现的 bug | 添加详细日志记录关键路径 |
| 内存泄漏 | 使用 `tracemalloc` 或 `objgraph` |
| 性能问题 | 使用 `cProfile` 或 `line_profiler` |
