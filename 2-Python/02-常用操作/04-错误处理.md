# 错误处理

程序运行时会遇到各种错误（用户输入、网络、文件等），需要捕获并合理处理，提供有意义的错误信息。

## 核心机制

`try/except` 捕获异常，`finally` 清理资源。异常链 `raise ... from e` 保留原始异常上下文。自定义异常应继承合适的基类。断言用于检查"不应该发生"的程序错误。

## try/except/finally

### 参考样例

```python
# 基本结构
try:
    result = 10 / 0
except ZeroDivisionError as e:
    print(f"不能除零: {e}")
except Exception as e:
    print(f"其他错误: {e}")
finally:
    print("总是执行")

# 捕获多个异常
try:
    int("hello")
except (ValueError, TypeError) as e:
    print(f"转换错误: {e}")
```

## 异常链

Python 3 支持异常链，可以在重新抛出异常时保留原始异常的上下文。

### 参考样例

```python
# 显式异常链（raise ... from）
try:
    int("not_a_number")
except ValueError as e:
    raise RuntimeError("转换失败") from e

# 获取原始异常
try:
    int("not_a_number")
except ValueError as e:
    try:
        raise RuntimeError("转换失败") from e
    except RuntimeError as re:
        print(f"原始异常: {re.__cause__}")

# 压制异常链
try:
    int("not_a_number")
except ValueError:
    raise RuntimeError("转换失败") from None
```

## 自定义异常

### 参考样例

```python
# 自定义异常基类
class AppError(Exception):
    def __init__(self, message, code=None):
        self.message = message
        self.code = code
        super().__init__(message)

# 具体异常类
class ValidationError(AppError):
    def __init__(self, field, message):
        self.field = field
        super().__init__(f"{field}: {message}")

class NotFoundError(AppError):
    pass

# 使用自定义异常
def validate_age(age):
    if age < 0:
        raise ValidationError("age", "年龄不能为负数")
    if age > 150:
        raise ValidationError("age", "年龄超出合理范围")
    return True

# 异常转译
def load_config(path):
    try:
        with open(path) as f:
            return json.load(f)
    except FileNotFoundError as e:
        raise ConfigError(f"配置文件不存在: {path}") from e
    except json.JSONDecodeError as e:
        raise ConfigError(f"配置文件格式错误: {e.msg}") from e
```

## 断言 assert

断言用于开发时检查不应该发生的情况。

### 参考样例

```python
def divide(a, b):
    assert b != 0, "除数不能为零"
    return a / b

# 断言 vs 异常
# - 断言：检查"不应该发生"的错误（程序 bug）
# - 异常：检查"可能发生"的错误（用户输入、网络等）
```

## warnings 模块

### 参考样例

```python
import warnings

# 警告类别
warnings.warn("这是一个警告")
warnings.warn("过期函数", DeprecationWarning)

# 过滤警告
warnings.filterwarnings("ignore", category=DeprecationWarning)
warnings.filterwarnings("error", category=RuntimeWarning)

# 上下文管理器控制警告
with warnings.catch_warnings():
    warnings.simplefilter("ignore")
    old_function()
```

## traceback 模块

### 参考样例

```python
import traceback

# 打印异常堆栈
try:
    1 / 0
except Exception:
    traceback.print_exc()

# 获取异常字符串
try:
    1 / 0
except Exception:
    error_str = traceback.format_exc()
```

## 异常处理最佳实践

### 参考样例

```python
# 1. 宽泛捕获 vs 精确捕获
try:
    process()
except Exception as e:
    logger.error(e)

# 2. 异常不应该用于控制流
# 正确：使用边界检查
for i in range(min(len(items), 1000000)):
    result = items[i]

# 3. 清理资源使用 finally 或上下文管理器
with open("data.txt") as file:
    process(file)

# 4. 保留异常上下文
try:
    int("not_a_number")
except ValueError as e:
    raise RuntimeError("转换失败") from e

# 5. 自定义异常应该继承自合适的基类
# Exception
#   ├── RuntimeError
#   │   └── TimeoutError
#   └── ValueError
#       └── ValidationError
```
