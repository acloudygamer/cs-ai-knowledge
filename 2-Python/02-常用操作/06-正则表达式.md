# 正则表达式

正则表达式是基于有限状态机理论的文本模式匹配工具，通过正则语法描述字符串的特征进行查找、提取、替换操作。

## 核心机制

正则引擎基于 NFA（非确定有限自动机），从左到右扫描字符串，尝试匹配每个位置。`match` 只检查字符串开头，`search` 查找第一个匹配。量词默认贪婪，会尽可能多地匹配字符，加 `?` 变为非贪婪。分组 `()` 既用于捕获子串，也影响优先顺序。零宽断言匹配字符之间的位置，不消耗字符。编译后的 Pattern 对象缓存正则解析结果，重复使用同一模式时更高效。

## 定义断言

> 正则表达式是基于正则语法描述字符串特征的模式，其中量词控制匹配次数，分组影响捕获范围，断言匹配位置而非字符。

## 数据流

<pre>
文本          正则引擎               匹配结果
  |              |                     |
  | a b c d e   |                     |
  | +-----------+                     |
  | [逐位置尝试] |                     |
  |             | [a-z]+ 匹配 "abc"]  |
  |             |-------------------->|
  |             |                     | ['abc']
</pre>

## re 模块基础

### 参考样例

```python
import re

re.findall(r'\d+', 'a1b2c3')
re.search(r'\d+', 'abc123def')
```

## 量词

### 参考样例

```python
re.findall(r'a*', 'aaaa')
re.findall(r'<.*?>', '<a><b>')
```

## 分组与捕获

### 参考样例

```python
match = re.search(r'(\d{4})-(\d{2})', '2024-06')
match.groups()
```

## 零宽断言

### 参考样例

```python
re.findall(r'\w+(?=\.)', 'hello.world')
```

## 编译与标志

### 参考样例

```python
pattern = re.compile(r'\d+')
pattern.findall('a1b2c3')
```

## 常见陷阱

| 陷阱 | 解决方案 |
|------|----------|
| 贪婪导致过度匹配 | 使用非贪婪 `*?` `+?` |
| re.match 误用 | 需要全文匹配用 `^...$` |
| 重复编译 | 编译后复用 Pattern 对象 |
| `.` 不匹配换行 | 使用 `re.DOTALL` 或 `[\s\S]` |
