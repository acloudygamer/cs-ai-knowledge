# 正则表达式

需要从文本中提取、匹配、替换复杂模式的场景，如验证输入、解析日志、提取数据等。

## 核心机制

`re.match` 从开头匹配，`re.search` 查找第一个匹配，`re.findall` 查找所有。量词：`*`（0或多个）、`+`（1或多个）、`?`（0或1个）、`{n,m}`（n到m个）。分组 `()` 用于捕获，`(?:...)` 非捕获分组。零宽断言 `(?=...)` `(?<=...)` 匹配位置不消耗字符。

## re 模块基础

### 参考样例

```python
import re

# match - 从字符串开头匹配
result = re.match(r'\d+', '123abc')
print(result.group())  # '123'

# search - 查找第一个匹配
result = re.search(r'\d+', 'abc123def')

# findall - 返回所有匹配列表
result = re.findall(r'\d+', 'a1b2c3')

# finditer - 返回迭代器（省内存）
for match in re.finditer(r'\d+', 'a1b2c3'):
    print(match.group(), match.start())
```

## 常用元字符

### 参考样例

```python
# . 任意字符（除换行）
re.findall(r'a.c', 'abc adc a1c')

# \d 数字
re.findall(r'\d{4}', 'a1234b')

# \w 单词字符（字母、数字、下划线）
re.findall(r'\w+', 'hello_world!')

# ^ $ 开头结尾
re.match(r'^abc', 'abcdef')
re.search(r'abc$', 'defabc')

# [] 字符集
re.findall(r'[aeiou]', 'hello')

# | 或
re.findall(r'cat|dog', 'I have a cat and a dog')
```

## 量词

### 参考样例

```python
# * 0或多个（贪婪）
re.findall(r'a*', 'aaaa')

# + 1或多个
re.findall(r'a+', 'aab')

# ? 0或1个
re.findall(r'colou?r', 'color colour')

# {n} 精确n个
re.findall(r'\d{4}', '2024-01-01')

# {n,m} 非贪婪
re.findall(r'<.*?>', '<a><b>')
```

## 分组与捕获

### 参考样例

```python
import re

# () 捕获分组
match = re.search(r'(\d{4})-(\d{2})-(\d{2})', '2024-06-15')
print(match.group(1))  # 2024
print(match.groups())   # ('2024', '06', '15')

# 命名分组 (?P<name>...)
match = re.search(r'(?P<year>\d{4})-(?P<month>\d{2})', '2024-06-15')
print(match.groupdict())  # {'year': '2024', 'month': '06'}

# 非捕获分组 (?:...)
re.findall(r'(?:ab)+', 'ababab')

# \1 引用分组
re.search(r'(\w+)\s+\1', 'the the')
```

## 零宽断言

### 参考样例

```python
# (?=...) 正前瞻（后面是什么，但不消耗）
re.findall(r'\w+(?=\.)', 'hello.world.csv')

# (?!...) 负前瞻（后面不是什么）
re.findall(r'\d+(?!\.)', '123abc 456')

# (?<=...) 正后顾（前面是什么，不消耗）
re.findall(r'(?<=\$)\d+', '$100 $200')

# (?<!...) 负后顾（前面不是什么）
re.findall(r'(?<!\$)\d+', '$100 200')
```

## 编译与标志

### 参考样例

```python
import re

# 编译（重复使用同一模式时更高效）
pattern = re.compile(r'\d+')
pattern.findall('a1b2c3')

# 常用标志
re.IGNORECASE  # i - 忽略大小写
re.MULTILINE   # m - ^ $ 匹配每行
re.DOTALL      # s - . 匹配换行
re.VERBOSE     # x - 允许注释和空白
```

## 替换与分割

### 参考样例

```python
import re

# sub - 替换
text = '2024-06-15'
result = re.sub(r'-', '/', text)

# 使用分组替换
text = 'John: 30, Jane: 25'
result = re.sub(r'(\w+): (\d+)', r'\2 - \1', text)

# 回调函数替换
def upperize(match):
    return match.group(1).upper()
re.sub(r'(hello)', upperize, 'say hello world')

# split - 分割
re.split(r'[,;]', 'a,b;c,d')
```

## 常用模式速查

### 参考样例

```python
import re

# 邮箱
email = r'^[\w.-]+@[\w.-]+\.\w+$'

# URL
url = r'https?://[\w.-]+(?:/[\w./-]*)?'

# IP 地址
ip = r'\b(?:\d{1,3}\.){3}\d{1,3}\b'

# 手机号（中国）
phone = r'1[3-9]\d{9}'

# 密码（8位，含数字字母）
password = r'^(?=.*\d)(?=.*[a-zA-Z])[\w]{8,}$'
```

## Match 对象

### 参考样例

```python
import re

match = re.search(r'(\w+)\s+(\d+)', 'hello 123')

# group / groups
match.group()    # 'hello 123'（整体）
match.group(1)   # 'hello'
match.groups()   # ('hello', '123')

# span / start / end
match.span()    # (0, 9)
match.start()   # 0
match.end()     # 9
```

## 常见陷阱

### 参考样例

```python
import re

# 陷阱1：贪婪匹配导致意外
re.findall(r'<.*?>', '<a><b>')  # ['<a>', '<b>']（非贪婪）

# 陷阱2：re.match 只匹配开头
re.search(r'\d+', 'abc123')  # Match（从任意位置）

# 陷阱3：编译 vs 非编译（重复使用同一模式）
compiled = re.compile(pattern)
for _ in range(1000):
    compiled.search(text)

# 陷阱4：.\n 不匹配换行
re.findall(r'a.*b', 'a\nb', re.DOTALL)
```
