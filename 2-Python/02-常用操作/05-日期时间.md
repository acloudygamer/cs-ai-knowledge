# 日期时间处理

日期时间处理是程序对时间点的表示、时间段的计算、时区的转换，以及时间与字符串之间的相互转换。

## 核心机制

Python 的 `datetime` 模块区分 naive（无时区信息）和 aware（有时区信息）两种 datetime 对象。naive 对象不包含时区，aware 对象通过 `tzinfo` 接口携带时区信息。`timedelta` 表示时间差，可跨日期计算但不支持月份/年份直接运算（因月份年份长度不固定）。`timestamp()` 将 aware datetime 转为 Unix 纪元秒数，`fromtimestamp()` 做逆运算。时区处理推荐使用 `zoneinfo` 模块（Python 3.9+），基于 IANA 时区数据库。

## 定义断言

> datetime 对象是时间轴上某个点的表示，timedelta 是两点之间的时间间隔，时区是相对于 UTC 的偏移量。

## 数据流

<pre>
datetime(naive)          datetime(aware)
     |                        |
     | timestamp()            | astimezone()
     v                        v
 Unix 秒数              另一时区的 datetime
     |                        |
     | fromtimestamp()        |
     v                        v
</pre>

## datetime 模块

### 参考样例

```python
from datetime import datetime
import zoneinfo

now = datetime.now(zoneinfo.UTC)
dt = datetime(2024, 6, 15, 14, 30)
```

## timedelta

### 参考样例

```python
from datetime import timedelta

delta = timedelta(days=7, hours=12)
total_seconds = delta.total_seconds()
```

## 时区处理

### 参考样例

```python
from datetime import timezone
import zoneinfo

tokyo = zoneinfo.ZoneInfo("Asia/Tokyo")
dt_tokyo = dt_utc.astimezone(tokyo)
```

## 字符串解析

### 参考样例

```python
dt = datetime.strptime("2024-06-15", "%Y-%m-%d")
dt_iso = datetime.fromisoformat("2024-06-15T14:30:00+08:00")
```

## 常见陷阱

| 陷阱 | 解决方案 |
|------|----------|
| naive vs aware 混淆 | 存储和传输用 aware，避免混合运算 |
| timedelta 不支持月份 | 使用 `dateutil.relativedelta` |
| 时区转换丢失 | 确保输入输出都是 aware datetime |
