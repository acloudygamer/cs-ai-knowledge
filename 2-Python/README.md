# 2-Python

> **版本基准**：Python 3.12 stable / 3.14 latest（详见 [versions.json](versions.json)）。3.13/3.14 特性在各篇行内以"增量"标注；版本变化的集中视图见 [05-版本演进](03-运行时与性能/05-版本演进.md)。

本库不是 API 手册，是一条**逻辑主线上的知识网络**：每篇开头承接上一篇、正文交叉链接相关概念——回答"为什么这样设计"多过"语法是什么"。读者定位：已会 Python 的专业开发者。
