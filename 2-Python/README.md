# Python

最适合入门的人工智能语言，简洁易读的语法让它成为全球最受欢迎的编程语言之一。

## 核心特点

- **简洁易读** - 缩进语法，代码即文档
- **动态类型** - 无需声明，灵活高效
- **生态丰富** - 「自带电池」，百万级第三方库
- **跨平台** - Windows / macOS / Linux 一处编写多处运行
- **AI 首选** - TensorFlow、PyTorch 等主流框架原生支持

## 适用场景

`Web开发` `数据分析` `机器学习` `自动化脚本` `网络爬虫` `AI应用`

## 学习路线

**推荐学习顺序：**

1. **基础入门**（2-3周）- 语法基础、数据结构、控制流程
2. **函数与模块**（1-2周）- 函数定义、模块导入、文件操作
3. **面向对象**（1-2周）- 类与对象、继承、特殊方法
4. **项目实践**（持续）- 选择方向深入：数据分析、Web开发、自动化

**核心习惯**：每天写代码、不懂查文档、多读他人代码、不怕踩坑
