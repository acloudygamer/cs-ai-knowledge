# 代码格式化工具

现代 Python 项目使用统一的代码格式化工具，确保代码风格一致，减少 code review 中的格式争议。

## 工具对比

| 工具 | 功能 | 速度 | 配置复杂度 |
|------|------|------|-----------|
| **Black** | 格式化 | 快 | 极简 |
| **isort** | 导入排序 | 很快 | 简单 |
| **Ruff** | 格式化+检查 | 极快 | 中等 |
| ** yapf** | 格式化 | 中等 | 灵活 |

## Black

Black 是 Python 最流行的代码格式化工具，遵循 "enforced formatting" 理念，几乎不需要配置。核心特性：零配置、稳定格式、高速、不兼容风格。

### 安装

### 参考样例

```bash
pip install black
# 或使用 uv
uv pip install black
```

`black myfile.py` 格式化文件，`--check` 检查格式，`--diff` 查看差异。

### 基本用法

```bash
# 格式化单个文件
black myfile.py

# 格式化整个目录
black src/

# 检查是否需要格式化（不修改）
black --check myfile.py

# 查看将要做的修改
black --diff myfile.py

# 格式化 stdin
cat myfile.py | black -
```

### 配置

在 `pyproject.toml` 中配置：

```toml
[tool.black]
line-length = 88          # 默认 88，与 Black 风格指南一致
target-version = ["py314"]  # 目标 Python 版本
include = '\.pyi?$'       # 匹配的文件
exclude = '''
/(
    \.git
  | \.venv
  | \.tox
  | build
  | dist
)/
'''
```

### 与其他工具集成

```bash
# 与 isort 一起使用
pip install black isort
isort myfile.py && black myfile.py

# pre-commit 集成
# .pre-commit-config.yaml
repos:
  - repo: https://github.com/psf/black
    rev: 24.1.1
    hooks:
      - id: black
        language_version: python3.14
```

### 输出示例

格式化前：

```python
# 不规范的代码
x={"a":1,"b":2,"c":3}
def foo(  a,b,c  ):
    return   a+b+c

class   MyClass :
    def __init__(self,  x,y  ):
        self.x=x
        self.y=y
```

格式化后：

```python
# Black 格式化后
x = {"a": 1, "b": 2, "c": 3}


def foo(a, b, c):
    return a + b + c


class MyClass:
    def __init__(self, x, y):
        self.x = x
        self.y = y
```

## isort

isort 负责对 Python 文件中的导入语句进行排序，使导入顺序清晰一致。核心特性：智能分组排序、与 Black 兼容、自动修复。

### 安装

### 参考样例

```bash
# 格式化导入
isort myfile.py

# 检查模式
isort --check-only myfile.py
isort --check-only --diff myfile.py

# 显示差异
isort --diff myfile.py

# 递归处理
isort src/

# 合并多个配置
isort --profile black myfile.py
```

### 配置

```toml
# pyproject.toml
[tool.isort]
profile = "black"          # 与 Black 兼容
line_length = 88
multi_line_output = 3      # 多行导入样式
include_trailing_comma = true
force_grid_wrap = 0
use_parentheses = true
ensure_newline_before_comments = true

# 导入分组顺序
sections = [
    "FUTURE",
    "STDLIB",
    "THIRDPARTY",
    "FIRSTPARTY",
    "LOCALTHIRDPARTY",
]

# 自定义导入顺序
known_firstparty = ["mymodule"]
known_thirdparty = ["django", "flask"]

# 不排序的导入
force_sort_within_sections = true
lexicographical = false
```

### 导入样式示例

**格式化前：**

```python
import os
from django.conf import settings
import sys
from mymodule import utils
from typing import Dict, List
import numpy as np
from .local import something
import pandas
```

**格式化后：**

```python
from __future__ import annotations

import sys
from typing import Dict, List

import numpy as np
import pandas
from django.conf import settings

from mymodule import utils

from .local import something
```

### 高级用法

```bash
# 强制所有 first-party 导入在 third-party 之前
isort --force-sort-within-sections

# 只显示汇总信息
isort --quiet

# 排除特定目录
isort --filter-files

# 导入类型注解特殊处理
isort --lines-after-imports=2
```

## Ruff

Ruff 是用 Rust 编写的极快 Python linter，替代 flake8、isort、pyupgrade。核心特性：极速、替代多个工具、500+ 规则、自动修复。

### 安装

### 参考样例

```bash
# 检查代码
ruff check src/

# 检查并显示错误代码位置
ruff check src/ --show-fixes

# 自动修复
ruff check src/ --fix

# 指定规则
ruff check src/ --select=E,F --ignore=E501
```

### 配置

```toml
# pyproject.toml
[tool.ruff]
line-length = 88
target-version = "py314"

# 选择要启用的规则
select = [
    "E",     # pycodestyle errors
    "W",     # pycodestyle warnings
    "F",     # pyflakes
    "I",     # isort
    "B",     # flake8-bugbear
    "C4",    # flake8-comprehensions
    "UP",    # pyupgrade
]
ignore = [
    "E501",  # line too long (handled by formatter)
    "B008",  # do not perform function calls in argument defaults
]

[tool.ruff.per-file-ignores]
"__init__.py" = ["F401"]

[tool.ruff.isort]
known-first-party = ["mymodule"]
```

### 常用规则

```python
# E - pycodestyle 错误
E501  # 行太长
E713  # 使用 `in` 而不是 `not in`

# F - pyflakes
F401  # 未使用的导入
F811  # 重定义的名称
F841  # 未使用的变量

# B - bugbear
B008  # 默认参数中的函数调用
B009  # getattr 的不安全使用
B010  # setattr 的不安全使用

# UP - pyupgrade
UP007  # 使用 `X | Y` 代替 `Union[X, Y]`
UP008  # 使用 `super()` 而不是 `super(__class__, self)`

# I - isort
I001  # 缺少导入
I005  # 导入顺序不正确
```

### 使用 as formatter

Ruff 从 0.1.0 开始支持格式化（alpha 阶段）：

```toml
# pyproject.toml
[tool.ruff]
formatter = "black"

# 或使用 ruff 自己的格式化
[tool.ruff.format]
quote-style = "double"
indent-style = "space"
line-ending = "auto"
```

```bash
# 格式化代码
ruff format src/

# 检查格式
ruff format --check src/
```

## 组合使用

### 推荐的开发工作流

```bash
# 1. 开发时：自动格式化
black src/
isort src/

# 2. CI/CD：检查
ruff check src/

# 3. pre-commit：提交前检查
```

### pre-commit 配置

```yaml
# .pre-commit-config.yaml
repos:
  - repo: https://github.com/pre-commit/pre-commit-hooks
    rev: v4.5.0
    hooks:
      - id: trailing-whitespace
      - id: end-of-file-fixer
      - id: check-yaml
      - id: check-added-large-files

  - repo: https://github.com/psf/black
    rev: 24.1.1
    hooks:
      - id: black
        language_version: python3.14

  - repo: https://github.com/pycqa/isort
    rev: 5.13.2
    hooks:
      - id: isort
        args: ["--profile", "black"]

  - repo: https://github.com/astral-sh/ruff-pre-commit
    rev: v0.1.14
    hooks:
      - id: ruff
        args: [--fix]
      - id: ruff-format
```

### Makefile 集成

```makefile
.PHONY: format lint clean test

format:
	black src/
	isort src/

lint:
	ruff check src/
	mypy src/

check:
	black --check src/
	isort --check-only src/
	ruff check src/

clean:
	rm -rf .pytest_cache
	rm -rf __pycache__
	find . -type d -name __pycache__ -exec rm -rf {} +
	find . -type f -name "*.pyc" -delete

test:
	pytest tests/ --cov=src/
```

## EditorConfig

补充说明：使用 EditorConfig 确保编辑器设置一致。

```ini
# .editorconfig
root = true

[*]
indent_style = space
indent_size = 4
end_of_line = lf
charset = utf-8
trim_trailing_whitespace = true
insert_final_newline = true

[*.py]
indent_size = 4
max_line_length = 88

[*.{yml,yaml,json,toml}]
indent_size = 2

[*.md]
trim_trailing_whitespace = false
```
