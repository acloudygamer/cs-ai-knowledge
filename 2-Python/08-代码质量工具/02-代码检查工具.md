# 代码检查工具

代码检查工具帮助发现代码中的错误、漏洞和风格问题，是保障代码质量的重要工具。

## 工具概览

| 工具 | 用途 | 速度 | 复杂度 |
|------|------|------|--------|
| **Ruff** | Linting | 极快 | 简单 |
| **Mypy** | 类型检查 | 中等 | 中等 |
| **Pylint** | 全面检查 | 慢 | 复杂 |
| **Pyright** | 类型检查 | 快 | 简单 |

## Ruff (Linting)

Ruff 是用 Rust 重新实现的 Python linter，作为多个传统工具的极快替代品。

### 规则体系

```toml
# pyproject.toml
[tool.ruff]
line-length = 88
target-version = "py311"

# 规则分组
select = [
    # 错误 (pycodestyle)
    "E",
    # 警告 (pycodestyle)
    "W",
    # pyflakes
    "F",
    # isort 兼容
    "I",
    # flake8-bugbear
    "B",
    # flake8-comprehensions
    "C4",
    # pyupgrade
    "UP",
    # flake8-return
    "RUF",  # Ruff 特有规则
]

ignore = [
    "E501",  # 行太长由 formatter 处理
    "B008",  # 默认参数中调用函数（有时是有意的）
]
```

### 常用规则详解

```python
# F 规则 (pyflakes)
import os  # F401: 未使用的导入

def foo():
    x = 1  # F841: 未使用的变量

# E 规则 (pycodestyle)
if x==1:  # E225: 运算符周围需要空格
    pass

# B 规则 (bugbear)
x = getattr(obj, "attr", [])  # B009: 不安全的 getattr

# UP 规则 (pyupgrade)
from typing import Optional, List  # UP007: 使用 Union[X, Y] | X | Y
```

### 修复能力

```bash
# 自动修复所有可修复规则
ruff check --fix src/

# 只修复特定类型
ruff check --fix --select=F src/

# 安全修复 vs 不安全修复
ruff check --fix --unsafe-fixes src/

# 显示修复统计
ruff check --fix --show-fixes src/
```

### 与其他工具对比

```bash
# Ruff vs Flake8
# Flake8: ~2.5s
# Ruff: ~0.01s

time flake8 src/
time ruff check src/
```

## Mypy

Mypy 是 Python 官方维护的静态类型检查器，实现 PEP 484 类型注解。

### 安装和基本用法

```bash
pip install mypy

# 检查代码
mypy src/

# 显示详细错误
mypy --pretty src/

# 检查所有 Python 文件
mypy .
```

### 配置

```toml
# pyproject.toml
[tool.mypy]
python_version = "3.11"
warn_return_any = true
warn_unused_configs = true
disallow_untyped_defs = true
disallow_incomplete_defs = true
check_untyped_defs = true
strict_optional = true
warn_redundant_casts = true
warn_unused_ignores = true
show_error_codes = true
show_column_numbers = true
pretty = true
```

### 类型注解示例

```python
from typing import Optional, List, Dict, Union, Callable, TypeVar

T = TypeVar("T")


# 函数类型注解
def greet(name: str) -> str:
    return f"Hello, {name}"


# 可选参数
def find_user(user_id: int, include_inactive: bool = False) -> Optional[dict]:
    ...


# 复杂类型
def process_items(
    items: List[int],
    processor: Callable[[int], str],
    options: Optional[Dict[str, Union[str, int]]] = None
) -> Dict[str, str]:
    ...


# 泛型
def first_of(items: List[T]) -> Optional[T]:
    return items[0] if items else None


# 协议（Protocol）
from typing import Protocol


class Readable(Protocol):
    def read(self) -> str:
        ...


def read_all(source: Readable) -> str:
    return source.read()


# TypeAlias
Vector = List[float]
Matrix = List[Vector]
```

### 严格模式

```python
# strict=True 配置下的代码
from typing import Optional


def bad_example(x: Optional[int]) -> int:
    # Error: argument "x" to "len" has type "int | None"
    # Need to check for None first
    return len([x])  # Still error if x could be None


def good_example(x: Optional[int]) -> int:
    if x is None:
        return 0
    return x + 1


# 全面注解
def typed_example(items: list[int]) -> dict[str, int]:
    result: dict[str, int] = {}
    for i, item in enumerate(items):
        result[f"item_{i}"] = item * 2
    return result
```

### mypy 配置示例

```toml
[tool.mypy]
python_version = "3.11"
strict = true
mypy_path = "src"

# 第三方库类型
[[tool.mypy.overrides]]
module = ["pandas.*"]
ignore_missing_imports = true

[[tool.mypy.overrides]]
module = ["numpy.*"]
ignore_missing_imports = true

[[tool.mypy.overrides]]
module = ["django.*"]
ignore_missing_imports = true
```

## Pylint

Pylint 是最全面的 Python 代码检查器，提供详细的代码分析。

### 安装和用法

```bash
pip install pylint

# 检查模块
pylint mymodule

# 检查包
pylint mypackage

# 检查文件
pylint src/

# 输出评分
pylint --output-format=text:لال

# 生成报告
pylint --generate-rcfile > .pylintrc
```

### 配置

```toml
# pyproject.toml
[tool.pylint]
max-line-length = 88
indent-string = "    "
disable = [
    "C0111",  # missing-docstring
    "C0103",  # invalid-name
    "R0903",  # too-few-public-methods
]
enable = [
    "use-maxsplitarg",
    "use-set-literal",
]
```

### 常用消息

```
# Convention (C) - 风格违反
C0111: Missing docstring
C0103: Invalid name

# Refactor (R) - 需要重构
R0913: Too many arguments
R0914: Too many local variables

# Warning (W) - 潜在问题
W0511: TODO/FIXME comment
W0612: Unused variable

# Error (E) - 严重问题
E1101: Instance has no 'member'
E0401: Unable to import
```

## Pyright

Pyright 是微软开发的快速 Python 类型检查器，集成在 Pylance (VS Code) 中。

### 安装和用法

```bash
npm install -g pyright  # 全局安装
# 或
pip install pyright

# 检查
pyright src/

# 监视模式
pyright --watch src/

# 输出 JSON
pyright --outputjson src/
```

### 配置

```json
// pyproject.toml
[tool.pyright]
pythonVersion = "3.11"
typeCheckingMode = "basic"  # off, basic, strict
reportMissingImports = true
reportMissingTypeStubs = false
reportGeneralTypeIssues = true
reportUnusedImport = true
reportUnusedVariable = true
pythonPlatform = "Darwin"
include = ["src"]
exclude = ["**/__pycache__"]
```

## CI/CD 集成

### GitHub Actions

```yaml
# .github/workflows/python-lint.yml
name: Python Lint

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  lint:
    runs-on: ubuntu-latest
    strategy:
      matrix:
        python-version: ["3.10", "3.11", "3.12", "3.14"]

    steps:
      - uses: actions/checkout@v4

      - name: Set up Python ${{ matrix.python-version }}
        uses: actions/setup-python@v5
        with:
          python-version: ${{ matrix.python-version }}

      - name: Install dependencies
        run: |
          python -m pip install --upgrade pip
          pip install ruff mypy
          pip install -e .  # 安装项目本身

      - name: Run ruff
        run: |
          ruff check src/

      - name: Run mypy
        run: |
          mypy src/ --ignore-missing-imports
```

### pre-commit 完整配置

```yaml
# .pre-commit-config.yaml
repos:
  # 基础检查
  - repo: https://github.com/pre-commit/pre-commit-hooks
    rev: v4.5.0
    hooks:
      - id: trailing-whitespace
      - id: end-of-file-fixer
      - id: check-yaml
      - id: check-added-large-files
      - id: check-toml
      - id: check-merge-conflict

  # 格式化
  - repo: https://github.com/psf/black
    rev: 24.1.1
    hooks:
      - id: black
        language_version: python3.11

  - repo: https://github.com/pycqa/isort
    rev: 5.13.2
    hooks:
      - id: isort
        args: ["--profile", "black"]

  # Linting
  - repo: https://github.com/astral-sh/ruff-pre-commit
    rev: v0.1.14
    hooks:
      - id: ruff
        args: [--fix, --exit-non-zero-on-fix]
      - id: ruff-format

  # 类型检查
  - repo: https://github.com/pre-commit/mirrors-mypy
    rev: v1.8.0
    hooks:
      - id: mypy
        additional_dependencies: [types-all]
```

## 实践建议

### 渐进式采用

```bash
# 第一步：先格式化
pip install black isort
black src/
isort src/

# 第二步：添加 ruff 检查（宽容模式）
pip install ruff
ruff check src/ --select=E,F --ignore=E501,F401

# 第三步：逐步启用更多规则
ruff check src/ --select=E,F,W,I,B,UP

# 第四步：启用严格模式
ruff check src/ --select=ALL --ignore=E501

# 第五步：添加 mypy 类型检查
pip install mypy
mypy src/ --ignore-missing-imports
```

### 常见问题解决

```bash
# Q: 第三方库没有类型注解？
# A: 安装类型存根或忽略
pip install types-requests types-redis
# 或
# pyproject.toml
[tool.mypy]
ignore_missing_imports = true

# Q: 与现有代码冲突？
# A: 逐步迁移，使用 # noqa 注释
import os  # noqa: F401

# Q: 误报太多？
# A: 配置忽略特定规则或文件
[tool.ruff]
ignore = ["E501", "B008"]

[tool.ruff.per-file-ignores]
"tests/*" = ["F401", "B008"]
"__init__.py" = ["F401"]
```

| 工具 | 1000 文件耗时 | 相对速度 |
|------|--------------|---------|
| Ruff | ~0.1s | 1x |
| flake8 | ~30s | 300x |
| Pylint | ~120s | 1200x |
| Mypy | ~45s | 450x |
