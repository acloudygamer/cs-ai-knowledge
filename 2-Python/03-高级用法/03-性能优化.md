# 性能优化

Python 程序性能不足时，需要定位热点代码并进行针对性优化，避免过早优化和错误优化。

## 核心机制

`cProfile` 是标准库性能分析器，定位热点函数。生成器代替列表可避免内存峰值。`__slots__` 限制实例属性可减少内存占用。Python 3.14 通过 Faster CPython 实现平均 5-10% 提速（3.11 相比 3.10 快 25%）。

## cProfile

### 参考样例

```python
# 命令行分析
# python -m cProfile -s cumulative my_script.py

import cProfile
import pstats

profiler = cProfile.Profile()
profiler.enable()
# 被分析的代码
profiler.disable()
stats = pstats.Stats(profiler)
stats.sort_stats('cumulative')
stats.print_stats(10)
```

## 列表 vs 生成器

### 参考样例

```python
import time

# 列表（立即计算，占内存）
squares = [x**2 for x in range(10**7)]

# 生成器（惰性求值，省内存）
gen = (x**2 for x in range(10**7))
total = sum(gen)
```

## __slots__ 优化内存

### 参考样例

```python
import sys

class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

class PointSlotted:
    __slots__ = ('x', 'y')
    def __init__(self, x, y):
        self.x = x
        self.y = y

p = Point(1, 2)
p2 = PointSlotted(1, 2)
print(sys.getsizeof(p))   # 约 48 bytes
print(sys.getsizeof(p2))  # 约 40 bytes
```

## 常用性能优化模式

### 参考样例

```python
# 避免全局变量查找
def fast_sum():
    total = 0
    local_total = total
    for i in range(1000000):
        local_total += i
    return local_total

# 字符串拼接优化
parts = [str(i) for i in range(10000)]
result = ''.join(parts)
```

## 热点代码识别技巧

### 参考样例

```python
import time

# 简单计时
start = time.perf_counter()
hot_code()
print(f"Time: {time.perf_counter() - start:.3f}s")

# 上下文管理器
from contextlib import contextmanager

@contextmanager
def timer(name):
    start = time.perf_counter()
    yield
    print(f"{name}: {time.perf_counter() - start:.3f}s")

with timer("Data processing"):
    process_data()
```
