# 性能优化

性能优化的核心是**定位真正的热点**（而非直觉认为的热点），然后针对性优化。优化前必须测量，优化后必须验证，避免过早优化和优化错误路径。Python 3.14 通过 Faster CPython 实现平均 5-10% 提速（3.11 相比 3.10 快 25%）。

## 热点定位原理

`cProfile` 使用 `cumulative` 排序能定位真正热点：它显示每个函数自身时间（tottime）加上它调用的子函数时间（cumtime）。一个调用次数少但每次调用链很深的函数，其 cumtime 可能远大于 tottime——这正是 cumulative 排序的价值。

```
tottime：函数自身执行时间（不含子调用）
cumtime：函数自身 + 所有子调用时间
ncalls：调用次数
```

若 cumtime 大但 tottime 小，说明函数自身不慢而是调用的子函数慢；若 tottime 大，说明函数自身就是热点。

## cProfile

### 参考样例

```python
# 命令行分析
# python -m cProfile -s cumulative my_script.py

import cProfile
import pstats

profiler = cProfile.Profile()
profiler.enable()
# 被分析的代码
profiler.disable()
stats = pstats.Stats(profiler)
stats.sort_stats('cumulative')
stats.print_stats(10)
```

## 列表 vs 生成器内存模型

列表是**立即求值**：创建时即在内存中构建完整数组，元素立即计算完毕。生成器是**惰性求值**：只在迭代时按需计算每次 yields，内存中只保存生成器对象和当前迭代状态。

```
列表: [x**2 for x in range(10**7)]
       ↓
       内存分配 10**7 个整数 ≈ 80MB

生成器: (x**2 for x in range(10**7))
       ↓
       内存只占生成器对象 ≈ 几百字节
       每次迭代只计算一个值
```

列表适合：需要多次遍历、数据量可放入内存、需随机访问。生成器适合：超大数据集、只需遍历一次、内存敏感场景。

### 参考样例

```python
import time

# 列表（立即计算，占内存）
squares = [x**2 for x in range(10**7)]

# 生成器（惰性求值，省内存）
gen = (x**2 for x in range(10**7))
total = sum(gen)
```

## __slots__ 优化内存

### 参考样例

```python
import sys

class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

class PointSlotted:
    __slots__ = ('x', 'y')
    def __init__(self, x, y):
        self.x = x
        self.y = y

p = Point(1, 2)
p2 = PointSlotted(1, 2)
print(sys.getsizeof(p))   # 约 48 bytes
print(sys.getsizeof(p2))  # 约 40 bytes
```

## 常用性能优化模式

### 参考样例

```python
# 避免全局变量查找
def fast_sum():
    total = 0
    local_total = total
    for i in range(1000000):
        local_total += i
    return local_total

# 字符串拼接优化
parts = [str(i) for i in range(10000)]
result = ''.join(parts)
```

## 热点代码识别技巧

### 参考样例

```python
import time

# 简单计时
start = time.perf_counter()
hot_code()
print(f"Time: {time.perf_counter() - start:.3f}s")

# 上下文管理器
from contextlib import contextmanager

@contextmanager
def timer(name):
    start = time.perf_counter()
    yield
    print(f"{name}: {time.perf_counter() - start:.3f}s")

with timer("Data processing"):
    process_data()
```
