# 内存管理

## 引用计数

Python 使用引用计数作为主要垃圾回收机制。对象创建时引用计数为1，每次引用加1，删除引用减1，当计数为0时立即回收。

### 参考样例

```python
import sys

# 引用计数
a = [1, 2, 3]
b = a
print(sys.getrefcount(a))  # 3

del b
del a
```

### 参考样例

```python
import gc

# 手动触发垃圾回收
gc.collect()

# 禁用自动回收
gc.disable()
gc.enable()
```

### 零成本异常（Python 3.11+）

Python 3.11 重写了异常处理，通过"零成本异常"机制提升性能。异常不再捕获时产生额外开销，只有真正抛出异常时才付出代价。

### 参考样例

```python
# Python 3.11：try 块几乎零开销
def new_style():
    try:
        return data['key']
    except KeyError:
        return 'default'
```

## 弱引用

弱引用允许引用对象而不增加其引用计数，对缓存场景很有用。

### 参考样例

```python
import weakref

class Cache:
    def __init__(self):
        self._cache = {}

    def get(self, key):
        ref = self._cache.get(key)
        return ref() if ref else None

    def set(self, key, value):
        self._cache[key] = weakref.ref(value)

# 对象在无强引用时可以被回收
obj = {'data': [1, 2, 3]}
ref = weakref.ref(obj)
del obj
```

## __slots__ 内存优化

`__slots__` 限制实例只能拥有指定的属性，减少内存开销。

### 参考样例

```python
import sys

class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

class PointSlotted:
    __slots__ = ('x', 'y')
    def __init__(self, x, y):
        self.x = x
        self.y = y

p = Point(1, 2)
p2 = PointSlotted(1, 2)
print(sys.getsizeof(p))   # 约 48 bytes
print(sys.getsizeof(p2))  # 约 40 bytes
```
