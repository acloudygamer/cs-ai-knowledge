# 内存管理

Python 内存管理的核心是**引用计数**——每个对象维护一个计数器，记录当前引用数量，当计数归零时对象立即被回收。引用计数是 Python 区别于其他垃圾回收语言（如 Java）的主要特征：它不需要"Stop-the-World"暂停，回收延迟是确定性的。

## 引用计数机制

```
对象创建 → refcount = 1
引用赋值给变量 → refcount +1
del 变量 / 变量赋新值 → refcount -1
refcount = 0 → 立即调用 __del__，释放内存
```

**为何需要分代回收配合引用计数**：引用计数无法处理循环引用（A 引用 B，B 引用 A，但无外部引用）。Python 的分代回收器（gc）专门解决循环引用——它定期扫描可能存在循环引用的对象集合（主要是容器类型），将存活对象移出"死亡"候选。

### 数据流

```
创建对象 → refcount = 1 → 无引用 → refcount=0 → 立即回收
                ↓
           有循环引用 → gc 标记 → 下一代扫描 → 仍无外部引用 → 回收
```

## 垃圾回收

### 参考样例


## Python 3.14 内存管理改进

Python 3.14 继续改进内存管理，包括自由线程模式和垃圾回收的完善。

> Python 3.11 的 Faster CPython 项目对垃圾回收进行了多项优化（零成本异常、回收器优化），3.14 在此基础上继续完善。

### 自由线程模式（Python 3.13+）

Python 3.13 引入了自由线程模式（PEP 703），Python 3.14 继续完善此功能。

自由线程模式的核心改变是**移除 GIL**（全局解释器锁）。GIL 保证同一时刻只有一个线程执行 Python 字节码，这是 Python 实现线程安全的简化机制，但代价是 CPU 密集型任务无法真正并行。自由线程模式用细粒度锁替代 GIL，允许多线程真正并行执行。

### 零成本异常（Python 3.11+）

Python 3.11 重写了异常处理，通过"零成本异常"机制提升性能。异常不再捕获时产生额外开销，只有真正抛出异常时才付出代价。

传统异常机制在 try 块入口插入检查代码，即使未发生异常也有开销。零成本异常将检查推迟到异常真正发生时——若无异常，try 块几乎零开销。

### 参考样例

```python
# Python 3.11：try 块几乎零开销
def new_style():
    try:
        return data['key']
    except KeyError:
        return 'default'
```

## 弱引用

弱引用是**不增加引用计数**的引用。普通引用（强引用）会保持对象存活，弱引用允许查询对象是否仍存在（返回对象或 None），对象无强引用时立即返回 None。

**缓存场景**：缓存应避免阻止对象被回收，否则缓存会持续增长导致内存泄漏。弱引用缓存只在对象仍被使用时有效，对象无其他引用时自动失效。

### 参考样例

```python
import weakref

class Cache:
    def __init__(self):
        self._cache = {}

    def get(self, key):
        ref = self._cache.get(key)
        return ref() if ref else None

    def set(self, key, value):
        self._cache[key] = weakref.ref(value)

# 对象在无强引用时可以被回收
obj = {'data': [1, 2, 3]}
ref = weakref.ref(obj)
del obj
```

## __slots__ 内存优化

`__slots__` 限制实例只能拥有指定的属性，代价是实例不能动态添加新属性。原理：正常类实例用 `__dict__` 存储属性（dict 额外开销），`__slots__` 将属性存储在固定大小的数组中，消除 `__dict__` 开销。

### 参考样例

```python
import sys

class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

class PointSlotted:
    __slots__ = ('x', 'y')
    def __init__(self, x, y):
        self.x = x
        self.y = y

p = Point(1, 2)
p2 = PointSlotted(1, 2)
print(sys.getsizeof(p))   # 约 48 bytes
print(sys.getsizeof(p2))  # 约 40 bytes
```
