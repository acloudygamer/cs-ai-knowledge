# 装饰器与元编程

装饰器是可调用对象，用于修改函数或类的行为。元编程则是程序在运行时操作自身结构的能力。

## 解决什么问题

需要在不修改原函数/类代码的情况下，给其添加通用功能（日志、缓存、权限检查、计时等），或动态创建和修改类。

## 核心概念

- 装饰器本质是接受 callable 并返回 callable 的函数
- `@decorator` 语法只是语法糖，等价于 `f = decorator(f)`
- `functools.wraps` 用于保留原函数的 `__name__`、`__doc__` 等元信息
- 类也能作为装饰器，通过 `__call__` 方法实现
- `type()` 可在运行时动态创建类，实现元编程

## 怎么用

### 基础装饰器

```python
import functools
import time

# 日志装饰器
def log_calls(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        print(f"Calling {func.__name__}")
        result = func(*args, **kwargs)
        print(f"{func.__name__} returned {result}")
        return result
    return wrapper

# 计时装饰器
def timer(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        result = func(*args, **kwargs)
        elapsed = time.perf_counter() - start
        print(f"{func.__name__} took {elapsed:.4f}s")
        return result
    return wrapper

@timer
@log_calls
def fibonacci(n):
    if n < 2:
        return n
    return fibonacci(n-1) + fibonacci(n-2)
```

### 带参数的装饰器

```python
# 重试装饰器
def retry(max_attempts=3, delay=1):
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            for attempt in range(max_attempts):
                try:
                    return func(*args, **kwargs)
                except Exception as e:
                    if attempt == max_attempts - 1:
                        raise
                    print(f"Attempt {attempt+1} failed, retrying...")
                    time.sleep(delay)
        return wrapper
    return decorator

@retry(max_attempts=3, delay=2)
def fetch_data(url):
    return requests.get(url)
```

### functools 缓存

```python
from functools import lru_cache

@lru_cache(maxsize=128)
def expensive_computation(n):
    """自动缓存最近使用的 maxsize 个结果"""
    return n ** 2

expensive_computation.cache_clear()
print(expensive_computation.cache_info())  # CacheInfo(hits=0, misses=0, ...)
```

### 类装饰器

```python
# 类装饰器：自动注册方法
class RouteRegistry:
    _routes = {}

    def __init__(self, path):
        self.path = path

    def __call__(self, func):
        RouteRegistry._routes[self.path] = func
        return func

@RouteRegistry("/home")
def home():
    return "Home Page"

print(RouteRegistry._routes)
# {'/home': <function home>}
```

### 动态类创建

```python
# type 动态创建类
MyClass = type('MyClass', (object,), {
    'x': 10,
    'greet': lambda self: f"Hello, {self.x}"
})

# 等价于
class MyClass:
    x = 10
    def greet(self):
        return f"Hello, {self.x}"

# 常见用法：动态类创建
def create_model(class_name, fields):
    return type(class_name, (object,), fields)

User = create_model('User', {
    'id': 0,
    'name': '',
})
user = User(1, "Alice")
```

## 装饰器 vs 元编程

| 特性 | 装饰器 | 元编程 (type) |
|------|--------|--------------|
| 用途 | 修改函数/类行为 | 动态创建类 |
| 语法 | `@decorator` | `type('Class', (), {})` |
| 时机 | 定义时应用 | 运行时创建 |
| 复杂度 | 较低 | 较高 |

装饰器适合为现有函数/类添加功能，元编程适合根据数据动态生成类结构。
