# 内存管理

## 引用计数

```python
import sys

# 引用计数
a = [1, 2, 3]        # 引用计数 +1
b = a                # 引用计数 +1
print(sys.getrefcount(a))  # 3（包含临时引用）

del b                # 引用计数 -1
del a                # 引用计数 -1，列表被回收

# 循环引用问题
class Node:
    def __init__(self, value):
        self.value = value
        self.next = None

# 创建循环引用
node1 = Node(1)
node2 = Node(2)
node1.next = node2
node2.next = node1

# 需要 gc.collect() 才能回收
```

## 垃圾回收

```python
import gc

# 手动触发垃圾回收
gc.collect()

# 禁用自动回收
gc.disable()
gc.enable()

# 查看回收对象
print(gc.get_stats())

# 调试
gc.set_debug(gc.DEBUG_STATS)
gc.get_referrers(obj)      # 找出谁引用了对象
gc.get_referents(obj)      # 找出对象引用了什么
```

## Python 3.14 内存管理改进 (<latest> 版本新增)

Python 3.14 在内存管理方面继续改进，包括自由线程模式（free-threaded）的持续优化和垃圾回收的完善。

> Python 3.11 的 Faster CPython 项目对垃圾回收进行了多项优化（零成本异常、回收器优化），3.14 在此基础上继续完善。

### 自由线程模式（Python 3.13+）

Python 3.13 引入了自由线程模式（PEP 703），Python 3.14 继续完善此功能：

```python
# 自由线程模式允许多线程真正并行执行
# 启用方式：python -X gil=0 或使用 free-threaded 构建

# 在自由线程模式下：
# - 每个线程有独立的 GIL
# - 多线程可以真正并行执行
# - 需要注意线程安全的数据访问
```

### 零成本异常（Python 3.11+）

Python 3.11 重写了异常处理，通过"零成本异常"机制提升性能。异常不再捕获时产生额外开销，只有真正抛出异常时才付出代价。

```python
# Python 3.10 及之前：try 块有轻微性能开销
def old_style():
    try:
        x = data.get('key')
        if x is None:
            raise KeyError('key')
    except KeyError:
        return 'default'

# Python 3.11：try 块几乎零开销
def new_style():
    try:
        return data['key']
    except KeyError:
        return 'default'
```

### 垃圾回收器优化

Python 3.11 对分代垃圾回收器进行了优化：

```python
import gc

# Python 3.11 新增：获取回收器配置
print(gc.get_threshold())  # (700, 10, 10) - 三代阈值

# Python 3.11 新增：设置分代回收参数
gc.set_threshold(500, 10, 10)  # 调整触发频率

# 查看各代对象数量
print(gc.get_count())  # 各代自上次回收后的对象增量

# 强制在特定代回收
gc.collect(generation=0)  # 只回收年轻一代（最频繁）
gc.collect(generation=1)  # 回收中一代
gc.collect(generation=2)  # 回收所有代
```

### 循环引用检测

循环引用是垃圾回收的难点，Python 通过标记-清除算法处理：

```python
import gc
import sys

# 创建循环引用
class Node:
    __slots__ = ('value', 'next')  # 减少每个对象的内存开销
    def __init__(self, value):
        self.value = value
        self.next = None

node1 = Node(1)
node2 = Node(2)
node1.next = node2
node2.next = node1  # 循环引用

# 在 Python 3.10+，可以通过以下方式观察回收
del node1
del node2
gc.collect()  # 手动触发回收

# 调试循环引用泄漏
gc.set_debug(gc.DEBUG_LEAK)  # 追踪泄漏对象
gc.collect()
print(gc.garbage)  # 查看无法回收的对象
```

### gc 模块常用函数速查

```python
import gc

# 基础操作
gc.collect()              # 手动触发完整垃圾回收
gc.enable()                # 启用自动回收（默认）
gc.disable()               # 禁用自动回收

# 查询操作
gc.get_count()            # 返回每代自上次回收后的对象计数 (count0, count1, count2)
gc.get_threshold()        # 返回触发各代回收的阈值 (threshold0, threshold1, threshold2)
gc.get_stats()            # 返回回收统计信息字典列表
gc.get_referrers(obj)     # 返回直接引用 obj 的对象（调试用）
gc.get_referents(*objs)   # 返回 objs 直接引用的对象

# 调试标志
gc.set_debug(flags)        # 设置调试标志
gc.DEBUG_STATS            # 打印回收统计
gc.DEBUG_LEAK              # 追踪无法回收的对象
gc.DEBUG_OBJECTS           # 追踪回收的对象
gc.DEBUG_SAVEALL           # 保存所有 unreachable 对象到 gc.garbage

# 手动管理对象（高级）
gc.freeze()                # 冻结所有未回收对象，不再扫描（Python 3.11+）
gc.unfreeze()              # 解冻，开始扫描
gc.get_freeze_count()      # 获取冻结对象数量

# 追踪特定对象
gc.callbacks.append(my_callback)  # 注册回收前后回调
# 回调函数签名: callback(phase, info)
# phase: 'start' 或 'stop'
# info: 包含统计信息的字典
```

### __slots__ 内存优化

`__slots__` 限制实例只能拥有指定的属性，减少内存开销。详细用法见「性能优化」章节的 `__slots__` 最佳实践。

```python
# 普通类 vs __slots__ 类内存对比
import sys

class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

class PointSlotted:
    __slots__ = ('x', 'y')
    def __init__(self, x, y):
        self.x = x
        self.y = y

p = Point(1, 2)
p2 = PointSlotted(1, 2)

print(sys.getsizeof(p))   # 约 48 bytes
print(sys.getsizeof(p2))  # 约 40 bytes（更小）
```

### 弱引用

弱引用允许引用对象而不增加其引用计数，对缓存场景很有用：

```python
import weakref

class Cache:
    def __init__(self):
        self._cache = {}

    def get(self, key):
        ref = self._cache.get(key)
        return ref() if ref else None

    def set(self, key, value):
        self._cache[key] = weakref.ref(value)

# 对象在无强引用时可以被回收
import gc
obj = {'data': [1, 2, 3]}
ref = weakref.ref(obj)
print(ref() is obj)  # True
del obj
gc.collect()
print(ref() is None)  # True，对象已被回收
```
