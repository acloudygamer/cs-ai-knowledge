# 打包与分发

## 项目结构

```
mypackage/
├── pyproject.toml           # 现代包配置
├── README.md
├── LICENSE
├── src/
│   └── mypackage/
│       ├── __init__.py
│       ├── main.py
│       └── utils.py
└── tests/
    ├── __init__.py
    └── test_main.py
```

## pyproject.toml

```toml
[build-system]
requires = ["setuptools>=45", "wheel", "setuptools_scm>=6.2"]
build-backend = "setuptools.build_meta"

[project]
name = "mypackage"
version = "0.1.0"
description = "A sample package"
readme = "README.md"
requires-python = ">=3.8"
license = {text = "MIT"}
authors = [
    {name = "Alice", email = "alice@example.com"}
]
keywords = ["sample", "tutorial"]
classifiers = [
    "Programming Language :: Python :: 3",
    "License :: OSI Approved :: MIT License",
]

dependencies = [
    "requests>=2.28.0",
    "click>=8.0.0",
]

[project.optional-dependencies]
dev = [
    "pytest>=7.0.0",
    "black>=23.0.0",
    "mypy>=1.0.0",
    "ruff>=0.1.0",
]
docs = [
    "sphinx>=6.0.0",
    "sphinx-rtd-theme>=1.0.0",
]

[project.urls]
Homepage = "https://github.com/user/mypackage"
Documentation = "https://mypackage.readthedocs.io"
Repository = "https://github.com/user/mypackage"

[tool.setuptools.packages.find]
where = ["src"]

[tool.black]
line-length = 88
target-version = ['py38', 'py39', 'py310', 'py311']

[tool.ruff]
line-length = 88
select = ["E", "F", "I", "N", "W"]
ignore = ["E501"]
```

## MANIFEST.in

```in
include README.md LICENSE
recursive-include src *.py
recursive-exclude tests *
global-exclude __pycache__
global-exclude *.py[co]
```

## 构建分发包

```bash
# 安装构建工具
pip install build

# 构建源码包和 wheel
python -m build

# 输出
# dist/
#   mypackage-0.1.0.tar.gz
#   mypackage-0.1.0-py3-none-any.whl
```

## 上传到 PyPI

```bash
# 安装上传工具
pip install twine

# 上传到 PyPI（生产环境）
twine upload dist/*

# 上传到 TestPyPI（测试环境）
twine upload --repository testpypi dist/*

# 或使用 Poetry 直接发布
poetry publish
poetry publish --build
```

## setup.cfg

```ini

    requests>=2.28.0

[options.packages.find]

[options.extras_require]
dev =
    pytest>=7.0.0
    black>=23.0.0

[flake8]
max-line-length = 88
extend-ignore = E203
```

## namespace packages

```python
# 在 pyproject.toml
[tool.setuptools.packages.find]
where = ["src"]
namespaces = false

# 常规包（非 namespace）
# src/mypackage/__init__.py 必须存在且非空
```

## entry_points 控制台脚本

```toml
[project.scripts]
myapp = "mypackage.cli:main"
mytool = "mypackage.tools:main"

# Windows: myapp.exe
# Linux/macOS: myapp
```

```python
# mypackage/cli.py
import click

@click.group()
def main():
    """My application CLI"""
    pass

@main.command()
def init():
    """Initialize the project"""
    click.echo("Initialized!")

if __name__ == "__main__":
    main()
```

## 测试打包

```bash
# 本地安装测试
pip install -e ".[dev]"
pip install -e .

# 构建并安装
python -m pip install dist/*.whl --force-reinstall

# 检查安装内容
pip show mypackage
python -c "import mypackage; print(mypackage.__version__)"
```

## 多平台 wheel

```bash
# 安装 wheel 扩展
pip install wheel

# 纯 Python wheel（跨平台）
python -m build --wheel

# 源码包
python -m build --sdist
```

## Conda 包（可选）

```yaml

package:
  name: mypackage
  version: "0.1.0"

source:
  path: .

build:
  number: 0
  script: python -m pip install . -vv

requirements:
  host:
    - python
    - pip
  run:
    - python
    - requests

test:
  imports:
    - mypackage

about:
  home: https://github.com/user/mypackage
  license: MIT
```
