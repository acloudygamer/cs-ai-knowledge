# 并发与异步

并发是同时管理多个 I/O 操作（网络请求、文件读写）的状态，异步是避免线程阻塞而让出控制权的协作机制。Python 并发围绕 GIL（全局解释器锁）设计：I/O 密集型任务在等待期间释放 GIL，适合用线程；CPU 密集型任务需要真正并行，适合用进程或自由线程模式。

## 并发模型选择原理

```
I/O 密集型 → GIL 在 I/O 等待时释放 → threading 多线程有效
CPU 密集型 → GIL 全程持有 → threading 无效 → multiprocessing 或自由线程
```

`threading` 共享进程内存空间，线程间通信零成本，但需要锁保护共享数据，死锁风险高。`multiprocessing` 进程独立 GIL 实现真正并行，但进程间通信（IPC）需要序列化/反序列化，开销远大于线程共享内存。`asyncio` 是单线程协作式调度，事件循环驱动协程切换，避免线程创建/切换开销，适合高并发网络服务。

`TaskGroup`（Python 3.11+）相比 `asyncio.gather` 提供更安全的异常聚合和细粒度取消。

## threading / multiprocessing

### 参考样例

```python
import threading
import multiprocessing
from concurrent.futures import ThreadPoolExecutor, ProcessPoolExecutor

# threading（I/O密集型）
def fetch_url(url):
    import requests
    return requests.get(url).status_code

with ThreadPoolExecutor(max_workers=10) as executor:
    urls = ["http://example.com"] * 100
    results = list(executor.map(fetch_url, urls))

# 线程同步
lock = threading.Lock()
counter = 0

def increment():
    global counter
    with lock:
        counter += 1

# multiprocessing（CPU密集型）
def cpu_task(n):
    return sum(i*i for i in range(n))

if __name__ == "__main__":
    with ProcessPoolExecutor(max_workers=4) as executor:
        results = list(executor.map(cpu_task, [10**6]*8))
```

## asyncio

### 参考样例

```python
import asyncio

# 基础协程
async def fetch(url):
    import aiohttp
    async with aiohttp.ClientSession() as session:
        async with session.get(url) as response:
            return await response.json()

# 运行协程
async def main():
    result = await fetch("https://api.example.com/data")

asyncio.run(main())

# 并发执行多个任务
async def main():
    import aiohttp
    urls = ["http://example.com"] * 10
    async with aiohttp.ClientSession() as session:
        tasks = [fetch(url) for url in urls]
        results = await asyncio.gather(*tasks)

# asyncio.TaskGroup（Python 3.11+）
async def main():
    async with asyncio.TaskGroup() as tg:
        task1 = tg.create_task(fetch("url1"))
        task2 = tg.create_task(fetch("url2"))
    results = [task1.result(), task2.result()]
```

## TaskGroup vs asyncio.gather

| 特性 | TaskGroup | asyncio.gather |
|------|-----------|----------------|
| 异常处理 | 取消所有任务，抛出 ExceptionGroup | 抛出第一个异常，其余任务继续 |
| 结果获取 | 通过 task.result() | 直接返回结果列表 |
| 细粒度控制 | 可单独取消某个任务 | 只能全部取消 |

### 参考样例

```python
# gather：任一任务异常立即抛出
async def main():
    try:
        results = await asyncio.gather(fetch("url1"), fetch("url2"))
    except Exception as e:
        print(f"某个任务失败: {e}")

# TaskGroup：所有任务在同一个 scope
async def main():
    try:
        async with asyncio.TaskGroup() as tg:
            tg.create_task(fetch("url1"))
            tg.create_task(fetch("url2"))
    except* ExceptionGroup as eg:
        print(f"异常组: {eg}")
```

## 超时处理

### 参考样例

```python
# asyncio.wait_for：超时后取消任务
async def main():
    try:
        result = await asyncio.wait_for(long_task(), timeout=3.0)
    except asyncio.TimeoutError:
        print("任务超时被取消")

# asyncio.timeout（Python 3.11+）
async def main():
    try:
        async with asyncio.timeout(3.0):
            result = await long_task()
    except asyncio.TimeoutError:
        print("超时")
```

## 常见陷阱

### 参考样例

```python
# 陷阱1：忘记 await
async def main():
    task = asyncio.create_task(fetch("url"))  # 错误：任务从未执行
    await task

# 陷阱2：阻塞事件循环
async def main():
    await asyncio.sleep(1)  # 正确：使用 asyncio.sleep
    # time.sleep(1)  # 不要这样做！

# 陷阱3：资源泄露
async def main():
    async with aiohttp.ClientSession() as session:  # 正确：使用 async with
        await session.get("url")
```
