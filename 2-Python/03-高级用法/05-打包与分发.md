# 打包与分发

Python 项目通过标准化打包格式实现分发。`pyproject.toml` 是现代 Python 包的配置标准，支持 setuptools、Poetry、Hatch 等构建后端。源码包（sdist）和 wheel 是两种主要分发格式。

## 项目结构

### 参考样例

```
mypackage/
├── pyproject.toml           # 现代包配置
├── README.md
├── LICENSE
├── src/
│   └── mypackage/
│       ├── __init__.py
│       ├── main.py
│       └── utils.py
└── tests/
    ├── __init__.py
    └── test_main.py
```

## pyproject.toml

`pyproject.toml` 定义构建系统、依赖、元数据。`[build-system]` 指定构建工具，`[project]` 定义包元数据和依赖。

### 参考样例

```toml
[build-system]
requires = ["setuptools>=45", "wheel", "setuptools_scm>=6.2"]
build-backend = "setuptools.build_meta"

[project]
name = "mypackage"
version = "0.1.0"
description = "A sample package"
readme = "README.md"
requires-python = ">=3.8"
license = {text = "MIT"}
authors = [
    {name = "Alice", email = "alice@example.com"}
]
keywords = ["sample", "tutorial"]
classifiers = [
    "Programming Language :: Python :: 3",
    "License :: OSI Approved :: MIT License",
]

dependencies = [
    "requests>=2.28.0",
    "click>=8.0.0",
]

[project.optional-dependencies]
dev = [
    "pytest>=7.0.0",
    "black>=23.0.0",
    "mypy>=1.0.0",
    "ruff>=0.1.0",
]
docs = [
    "sphinx>=6.0.0",
    "sphinx-rtd-theme>=1.0.0",
]

[project.urls]
Homepage = "https://github.com/user/mypackage"
Documentation = "https://mypackage.readthedocs.io"
Repository = "https://github.com/user/mypackage"

[tool.setuptools.packages.find]
where = ["src"]

[tool.black]
line-length = 88
target-version = ['py312', 'py313', 'py314']

[tool.ruff]
line-length = 88
select = ["E", "F", "I", "N", "W"]
ignore = ["E501"]
```

`MANIFEST.in` 指定构建时包含的非 Python 文件（README、LICENSE、数据文件等）。

### 参考样例

```in
include README.md LICENSE
recursive-include src *.py
recursive-exclude tests *
global-exclude __pycache__
global-exclude *.py[co]
```

## 构建分发包

```bash
# 安装构建工具
pip install build

# 构建源码包和 wheel
python -m build

# 输出
# dist/
#   mypackage-0.1.0.tar.gz
#   mypackage-0.1.0-py3-none-any.whl
```

`python -m build` 构建源码包（tar.gz）和 wheel（.whl）。wheel 是预编译格式，安装更快。

### 参考样例

```bash
# 安装上传工具
pip install twine

# 上传到 PyPI（生产环境）
twine upload dist/*

# 上传到 TestPyPI（测试环境）
twine upload --repository testpypi dist/*

# 或使用 Poetry 直接发布
poetry publish
poetry publish --build
```

`twine` 是上传包到 PyPI 的标准工具。支持正式 PyPI 和 TestPyPI 测试环境。Poetry 也内置发布功能。

### 参考样例

```bash
[metadata]
name = mypackage
version = attr: mypackage.__version__
description = A sample package
long_description = file: README.md
long_description_content_type = text/markdown
author = Alice
author_email = alice@example.com
license = MIT
url = https://github.com/user/mypackage

[options]
packages = find:
python_requires = >=3.8
install_requires =
    requests>=2.28.0
    click>=8.0.0

[options.packages.find]
where = src

[options.extras_require]
dev =
    pytest>=7.0.0
    black>=23.0.0

[flake8]
max-line-length = 88
extend-ignore = E203
```

`setup.cfg` 是传统的包配置文件格式，现在推荐使用 `pyproject.toml`。

### 参考样例

```ini
# mypackage/__init__.py
__version__ = "0.1.0"

# 或使用 setuptools_scm 自动管理
# __version__ = "0.1.0.dev5+g1234567"
```

版本管理两种方式：手动在 `__init__.py` 中定义 `__version__`，或使用 `setuptools_scm` 自动从 git tag 读取。

### 参考样例

```python
# 在 pyproject.toml
[tool.setuptools.packages.find]
where = ["src"]
namespaces = false

# 常规包（非 namespace）
# src/mypackage/__init__.py 必须存在且非空
```

Namespace packages 允许多个包共享同一命名空间前缀，适合大型项目拆分。

### 参考样例

```python
[project.scripts]
myapp = "mypackage.cli:main"
mytool = "mypackage.tools:main"

# Windows: myapp.exe
# Linux/macOS: myapp
```

```python
# mypackage/cli.py
import click

@click.group()
def main():
    """My application CLI"""
    pass

@main.command()
def init():
    """Initialize the project"""
    click.echo("Initialized!")

if __name__ == "__main__":
    main()
```

`entry_points` 在 `[project.scripts]` 中定义命令行脚本，构建后自动生成可执行文件（Windows .exe 或 Linux/macOS 原生程序）。

### 参考样例

```toml
# pyproject.toml
[tool.setuptools.package-data]
mypackage = "data/*.json", "templates/*.html"
```

```
src/mypackage/
├── __init__.py
├── data/
│   └── config.json
└── templates/
    └── base.html
```

`[tool.setuptools.package-data]` 配置包含在包中的数据文件（JSON 模板、配置文件等），放在包目录下的 data 或 templates 目录。

### 参考样例

```toml
# 本地安装测试
pip install -e ".[dev]"
pip install -e .

# 构建并安装
python -m pip install dist/*.whl --force-reinstall

# 检查安装内容
pip show mypackage
python -c "import mypackage; print(mypackage.__version__)"
```

本地安装测试使用 `pip install -e .`（可编辑模式）或直接安装 wheel。`pip show` 验证安装，`python -c "import ..."` 测试导入。

### 参考样例

```bash
# 安装 wheel 扩展
pip install wheel

# 纯 Python wheel（跨平台）
python -m build --wheel

# 源码包
python -m build --sdist
```

Pure Python wheel（`py3-none-any.whl`）跨平台通用。源码包（sdist）需要构建过程。特定平台 wheel（如 .cp312-cp312-linux_x86_64.whl）包含预编译扩展。

### 参考样例

```bash
# recipe/meta.yaml
package:
  name: mypackage
  version: "0.1.0"

source:
  path: .

build:
  number: 0
  script: python -m pip install . -vv

requirements:
  host:
    - python
    - pip
  run:
    - python
    - requests

test:
  imports:
    - mypackage

about:
  home: https://github.com/user/mypackage
  license: MIT
```
