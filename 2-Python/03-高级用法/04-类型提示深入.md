# 类型提示深入

类型提示是 Python 渐进类型系统的核心工具，在运行时提供静态检查和 IDE 自动补全支持，在编译/分析时捕获类型错误。`typing` 模块提供了泛型、协议、文字类型等高级类型工具，使类型系统能够表达复杂约束。

## 类型系统本质

Python 类型提示是**注解**而非**强制约束**——类型检查器（mypy、pyright）基于注解推断错误，但运行时不强制类型。类型提示的核心价值在于将"契约"显式化，使代码意图可被工具验证。

```
类型检查器 ← (类型注解) ← 代码 ← (类型注解) → 运行时
```

`Any` 是类型系统的"黑洞"——任何类型都与 `Any` 双向兼容，压制类型检查。

## TypeVar 泛型变量

`TypeVar` 将类型参数化，使函数/类能对多种类型操作而不失静态检查能力。约束 `TypeVar` 到特定类型时，检查器拒绝其他类型的实参。

### 机制

```python
T = TypeVar('T')
```

`TypeVar` 本质是一个符号，在泛型调用时被具体类型替换。`list[T]` 的检查器在 `list[int]` 调用时将 `T` 绑定为 `int`，若约束为 `int | float` 则两者均可。

### 参考样例

```python
from typing import TypeVar

T = TypeVar('T')

def first(lst: list[T]) -> T | None:
    return lst[0] if lst else None

first([1, 2, 3])       # T=int，推理返回 int | None
first(['a', 'b'])       # T=str，推理返回 str | None

OrderedT = TypeVar('OrderedT', int, float, str)
```

## Protocol 结构子类型

Protocol 是 PEP 544 引入的结构子类型（"鸭子类型+静态检查"）——若类拥有 Protocol 声明的方法，则无论继承关系如何，均视为该 Protocol 的子类型。这解决了继承层次难以表达"行为集合"的问题。

### 机制

```python
@runtime_checkable
class Closable(Protocol):
    def close(self) -> None: ...
```

`runtime_checkable` 装饰器使 Protocol 支持 `isinstance` 运行时检查。结构子类型的关键在于**方法签名匹配**，而非类型名或继承链。

### 参考样例

```python
from typing import Protocol, runtime_checkable

@runtime_checkable
class Closable(Protocol):
    def close(self) -> None: ...

class Resource:
    def close(self) -> None: ...

r = Resource()
isinstance(r, Closable)  # True
```

## Literal 文字类型

`Literal` 将类型收窄到特定常量值，用于表达枚举语义而不引入额外运行时开销。

### 参考样例

```python
from typing import Literal

def handle_mode(mode: Literal["read", "write"]) -> None:
    pass

handle_mode("read")    # OK
handle_mode("append")  # TypeError
```

## TypedDict

`TypedDict` 为字典字面量提供类型声明，约束键名和值类型，但**不**提供运行时强制——类型检查器在字面量赋值时检查键，运行时仍是普通 dict。

### 参考样例

```python
from typing import TypedDict, NotRequired

class User(TypedDict):
    name: str
    age: int

user: User = {"Name": "Alice", "age": 30}  # "Name" vs "name" 检查器报错

class Config(TypedDict, total=False):
    debug: bool
    log_level: str
```

`total=False` 使所有键变为 `NotRequired`，等价于显式 `Required[...]=False`。

## NewType

`NewType` 创建"语义类型"——`UserId` 和 `OrderId` 都是 `int`，但类型检查器视其为不同类型，防止意外混用。

### 机制

```python
UserId = NewType('UserId', int)
```

NewType 本质是编译器提示：检查器将 `UserId(123)` 视为 `int`，但拒绝直接将 `OrderId(123)` 传给需要 `UserId` 的函数。运行时 `NewType` 是 identity 函数，零开销。

### 参考样例

```python
from typing import NewType

UserId = NewType('UserId', int)
OrderId = NewType('OrderId', int)

def get_user(user_id: UserId) -> str:
    return f"User {user_id}"

uid = UserId(123)
get_user(uid)           # OK
get_user(OrderId(123))  # TypeError
```

## Callable

`Callable[[ArgTypes], ReturnType]` 表达"可调用对象"的签名约束。`Callable[..., R]` 表示任意参数。

### 参考样例

```python
from typing import Callable

def apply(func: Callable[[int], int], x: int) -> int:
    return func(x)

def with_retry(func: Callable[..., int], retries: int) -> int:
    for _ in range(retries):
        try:
            return func()
        except:
            pass
    raise RuntimeError("All retries failed")
```

## Union 和 Optional

`Union[A, B]` 表达"或"类型，`Optional[X]` 等价于 `Union[X, None]`。Python 3.10+ 支持 `X | Y` 语法，无需导入。

### 参考样例

```python
from typing import Union, Optional

def greet(name: Optional[str]) -> str:
    return f"Hello, {name or 'stranger'}!"

def process(x: int | str) -> int | str:
    return x
```

## 常见陷阱

### 参考样例

```python
# Mutable 容器默认值：默认可变对象在所有调用间共享
class W:
    def __init__(self, items: list[int] | None = None):
        self.items = items or []

# 泛型容器：Python 3.9+ 直接用 list[int]，不再需要 List[int]
```
