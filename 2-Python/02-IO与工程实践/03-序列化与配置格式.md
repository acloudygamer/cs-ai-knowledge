# 03-序列化与配置格式

> 前置：[01-文件与路径](01-文件与路径.md)（读写落点）、[11-类型提示](../01-语言核心/11-类型提示.md)（TypedDict/pydantic 边界） · 后续：[05-网络请求](05-网络请求.md)（JSON API）、[06-数据库操作](06-数据库操作.md)（另一条持久化路线）、[08-CLI应用](08-CLI应用.md)（配置与 CLI 的分工）

数据离开进程的那一刻就要选格式。本篇统一回答三组问题：**交换格式**（JSON，跨语言契约）、**配置格式**（TOML/INI/YAML/env，人写机器读）、**Python 专用**（pickle，仅限可信数据）。选型表先行，机制与坑随后。

## 本质

| 格式 | 定位 | 标准库 | 关键约束 |
|---|---|---|---|
| JSON | 跨语言数据交换的通用语 | `json` | 仅 null/bool/number/string/list/dict；键必须是字符串 |
| TOML | 人写的配置（pyproject 采纳后成为配置正统） | `tomllib`（3.11+，只读） | 类型丰富（日期、多行字符串）；写需 `tomli-w` |
| INI | 遗留配置 | `configparser` | 全是字符串，类型自己转 |
| YAML | 复杂配置/数据混写 | 无（PyYAML） | 表达力最强、坑也最多（隐式类型转换、缩进敏感） |
| env / `.env` | 部署期注入 | `os.environ` | 只能平面字符串 KV；密钥的标准去处 |
| pickle | Python 对象的原生序列化 | `pickle` | **反序列化即执行任意代码**——绝不可用于不可信输入 |

判据：机器 ↔ 机器选 JSON；人 ↔ 机器的配置选 TOML；密钥永远走环境变量/密管服务而不是任何入库文件。

## 机制

### JSON：标准库的四个旋钮

```python
import json
s = json.dumps(obj, ensure_ascii=False, indent=2)   # 中文直出（默认 \uXXXX 转义）
obj = json.loads(s)                                  # 解析
json.dump(obj, fh, ...);  obj = json.load(fh)        # 文件流版本
```

类型边界的坑（承接 [01-对象模型与变量](../01-语言核心/01-对象模型与变量.md) 的类型系统）：

- 不认识的类型抛 `TypeError`：`set`、`datetime`、dataclass 都不在 JSON 世界——用 `default=` 钩子教它（`default=str` 是兜底惯用法），回来用 `object_hook=` 逆转。
- `float('nan')`/`Infinity` 是**非法 JSON** 但 Python 默认写出（`allow_nan=False` 打开严格模式——对外 API 应开）。
- 顶层不是 dict/list 的字符串（如 `"3"`）能过解析——边界处必须校验形状。

### 边界的类型化：两条路线

入口把无类型 dict 变成有类型对象，才能让 [11-类型提示](../01-语言核心/11-类型提示.md) 的安全网生效：

- 轻量：`TypedDict` + 手动校验（小项目/内部边界）；
- 工程：`pydantic.BaseModel`——`model_validate_json` 一步完成解析+校验+类型化，错误信息结构化（FastAPI 的请求处理即此机制，见 [02-FastAPI](../06-应用领域/02-FastAPI.md)）。

### TOML：配置的当代正解

```python
import tomllib                                  # 3.11+，只读
with open("app.toml", "rb") as f:               # 注意：tomllib 要二进制模式
    cfg = tomllib.load(f)
```

写配置的场景极少（配置是人改的）；确需程序生成用 `tomli-w`。`.toml` 能直接表达布尔、日期、数组、嵌套表——`configparser` 里"取出来全是 str 再手转"的一代麻烦就此终结。

### configparser 与 YAML 的存量知识

- `configparser`：节（`[section]`）+ 平面 KV；`getint`/`getboolean` 手转类型；INI 遗留系统才碰。
- YAML（PyYAML）：`yaml.safe_load` 是纪律底线——`yaml.load` 不带 Loader 可执行任意对象构造（pickle 同级的安全洞）；"挪威问题"（`no` → `False`）提醒它的隐式类型转换不可掉以轻心。

### pickle：能力与红线

- 能力：任意 Python 对象图（含自定义类实例、递归结构），`pickle.dumps/loads`；多进程传任务的事实标准（见 [03-并发与异步](../03-运行时与性能/03-并发与异步.md)）。
- 红线：**loads 即代码执行**（恶意 pickle 可构造 `__reduce__` 调任意函数）——只用于自家可信进程间；缓存（`functools.cache` 落盘）与 `shelve` 都是它的变体，同一红线。
- 跨版本/跨解释器脆弱：类定义变了旧 pickle 可能解不开——持久化正式方案应是数据库或版本化格式，pickle 只做短期缓存。

### 环境变量与配置分层

运行期配置的三层来源（优先级从低到高）：文件默认值 → 环境变量 → 命令行参数（[08-CLI应用](08-CLI应用.md)）。`os.environ["KEY"]` 读取即用；`.env` 文件仅限本地开发（`python-dotenv` 加载），并确保它在 `.gitignore` 里——密钥入库是事故级错误。

## 示例

```python
import json, tomllib
from dataclasses import dataclass, field
from datetime import datetime

@dataclass
class Job:
    id: int
    tags: list[str] = field(default_factory=list)
    created: datetime = field(default_factory=datetime.now)

def encode(obj):                                  # 自定义类型的 JSON 出口
    if isinstance(obj, (set, frozenset)):
        return sorted(obj)
    if isinstance(obj, datetime):
        return obj.isoformat()
    if hasattr(obj, "__dataclass_fields__"):
        return obj.__dict__
    raise TypeError(type(obj))

blob = json.dumps(Job(7, {"a", "b"}), default=encode)
print(blob)                                       # {"id": 7, "tags": ["a", "b"], ...}

with open("pyproject.toml", "rb") as f:           # TOML 只读加载
    meta = tomllib.load(f)["project"]
```
