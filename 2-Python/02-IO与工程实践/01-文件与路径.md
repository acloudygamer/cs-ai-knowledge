# 01-文件与路径

> 前置：[03-字符串与格式化](../01-语言核心/03-字符串与格式化.md)（编码边界）、[09-上下文管理器](../01-语言核心/09-上下文管理器.md)（with 语义） · 后续：[03-序列化与配置格式](03-序列化与配置格式.md)、[06-数据库操作](06-数据库操作.md)（文件型数据库）、[04-CI-CD集成](../04-测试与质量/07-CI-CD集成.md)（产物归档）

文件是 Python 与外界交换状态的最基本通道。两件事值得专门讲：**路径**（pathlib 已让 os.path 退居遗留）与**读写语义**（模式、编码、缓冲、惰性）。编码问题承接字符串篇的 str/bytes 边界——这里是它落地出事故的地方。

## 本质

- `pathlib.Path` 把路径建模为对象：`/` 运算符拼接、属性访问取部件、方法完成常见动作（`read_text` / `exists` / `glob`）。路径对象不可变、跨平台（Windows 上 `\` 与 `/` 自动归一）。
- `open(path, mode, encoding)` 返回文件对象：文本模式做隐式编解码（str 世界与 bytes 世界的官方渡口，见 [03-字符串与格式化](../01-语言核心/03-字符串与格式化.md)），二进制模式原样给字节。

## 机制

### 模式速查与两个易错件

| 模式 | 语义 | 语义陷阱 |
|---|---|---|
| `r` / `w` / `a` | 读 / 清空写 / 追加写 | `w` 打开即清空——即使你一行都没写 |
| `x` | 排他创建写 | 已存在抛 `FileExistsError`：临时文件防覆盖的正解 |
| `b` / `t` | 二进制 / 文本（默认） | 文本模式追加 `encoding=` 是纪律，不写就吃平台默认（Windows 是 locale 编码） |
| `+` | 读写并存 | 混合读写需 `seek()` 管理位置，易错少用 |

### 逐行读：惰性是默认

文件对象本身可迭代（协议见 [06-迭代器与生成器](../01-语言核心/06-迭代器与生成器.md)）：`for line in f` 每次驻留一行，大文件 $O(1)$ 内存。对照：`f.read()` 全量入内存、`f.readlines()` 物化列表——只在确需随机访问时用。`line.rstrip("\n")` 而非 `strip()`（后者会顺手吃掉行尾语义空白）。

### pathlib 的动作件

```python
from pathlib import Path
root = Path("data")
cfg = root / "conf" / "app.toml"        # / 运算符拼接
cfg.parent.name                          # 'conf'
cfg.suffix                               # '.toml'
for p in sorted(root.rglob("*.log")):    # 递归 glob：惰性迭代器
    ...
cfg.read_text(encoding="utf-8")          # 小文件一步到位（内部仍是 open+close）
cfg.write_text(s, encoding="utf-8")      # 注意：覆盖写，无追加形态
```

新旧对照：`os.path.join` / `glob.glob` / `shutil` 的函数式组合能表达同样的东西，但新代码一律 pathlib；`os` 里仍不可替代的是进程级操作（`os.chdir`、`os.environ`）。

### 原子写与临时文件

`write_text` 的"打开-写-关闭"在写到一半时崩溃会留下残缺文件。原子写惯用法：**写临时文件 + `os.replace`**（同文件系统内 rename 是原子的）：

```python
tmp = path.with_suffix(".tmp")
tmp.write_text(data, encoding="utf-8")
os.replace(tmp, path)                    # 崩溃窗口内旧文件始终完好
```

`tempfile` 模块管临时资源：`TemporaryDirectory()` 是上下文管理器（自动清理，见 [09-上下文管理器](../01-语言核心/09-上下文管理器.md)），测试里的 `tmp_path` fixture 即它的化身（见 [02-Fixture](../04-测试与质量/02-Fixture.md)）。

### 目录树与批量操作

- `Path.walk()`（3.12+，自顶向下，可在回调里剪枝 `dirs[:] = [...]`）；旧代码的 `os.walk` 同义。
- 复制/移动/删除整树是 `shutil` 的领地：`copy2`（保元数据）/ `move` / `rmtree`。约束与后果：`rmtree` 无回收站、不问确认——路径参数必须是字面量或严格校验值，绝不拼接用户输入。

### newline 与跨平台

文本模式默认 universal newlines（读时 `\r\n`/`\r` → `\n`，写时按平台）。`newline=""` 关掉转换——处理 CSV、解析既有格式时必须用它（否则 `\r\n` 残留污染字段，见 [08-CLI应用](08-CLI应用.md) 的管道场景）。

## 示例

```python
import os
from pathlib import Path

def count_words(path: Path) -> int:
    total = 0
    with path.open(encoding="utf-8") as f:     # with 保证关闭（异常也关）
        for line in f:                          # 惰性：一行驻留
            total += len(line.split())
    return total

def atomic_write(path: Path, data: str) -> None:
    tmp = path.with_suffix(".tmp")
    tmp.write_text(data, encoding="utf-8")
    os.replace(tmp, path)                       # 原子替换

log_dir = Path("logs")
for day_file in sorted(log_dir.glob("2026-08-*.log")):
    print(day_file.name, count_words(day_file))
```
