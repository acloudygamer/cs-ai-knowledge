# 测试覆盖率

衡量测试对代码的覆盖程度。

## 安装与使用

```bash
# 安装
pip install pytest-cov

# 运行覆盖率
pytest --cov=mypackage tests/
pytest --cov=mypackage --cov-report=html tests/

# 生成 HTML 报告
pytest --cov=mypackage --cov-report=html tests/
# 报告位置：htmlcov/index.html

# 终端覆盖率报告
pytest --cov=mypackage --cov-report=term-missing tests/
```

## 覆盖率指标

| 指标 | 说明 |
|------|------|
| statements | 语句覆盖率 |
| branches | 分支覆盖率 |
| functions | 函数覆盖率 |
| lines | 行覆盖率 |

```bash
# 查看所有指标
pytest --cov=mypackage --cov-report=term-missing --cov-report=show-missing tests/

# 指定最低覆盖率
pytest --cov=mypackage --cov-fail-under=80 tests/
```

## 覆盖率配置

```toml
# pyproject.toml
[tool.coverage.run]
source = ["mypackage"]
omit = [
    "*/tests/*",
    "*/migrations/*",
    "*/__pycache__/*",
]
branch = true

[tool.coverage.report]
precision = 2
show_missing = true
skip_covered = false
exclude_lines = [
    "pragma: no cover",
    "def __repr__",
    "raise AssertionError",
    "raise NotImplementedError",
    "if __name__ == .__main__.:",
    "if TYPE_CHECKING:",
]

[tool.coverage.html]
directory = "htmlcov"
```

## 排除代码

```python
# 排除特定行
if False:  # pragma: no cover
    code_that_will_never_run()

def _private_helper():  # pragma: no cover
    """Not meant to be called directly"""
    pass

# 排除分支
if something:  # pragma: no cover
    do_something()
else:
    do_other()  # pragma: no cover
```

## 模块级别覆盖率

```bash
# 只测试特定模块
pytest --cov=mypackage.submodule tests/

# 多模块
pytest --cov=mypackage --cov=mypackage.utils tests/

# 输出到文件
pytest --cov=mypackage --cov-report=xml --cov-report=html tests/
```

## 增量覆盖率

```bash
# 比较两次运行的覆盖率差异
pytest --cov=mypackage --cov-branch --cov-report=term-missing tests/

# 使用 coverage diff
coverage diff -m --compare-mode=incremental
```

## 常见问题

```bash
# 1. 第三方库覆盖率
# 只测试自己的代码
pytest --cov=mypackage --cov-report=term tests/

# 排除外部代码
pytest --cov=mypackage --cov-report=term \
    --omit="*/site-packages/*" tests/

# 2. 异步代码覆盖率
import pytest
pytest --cov=mypackage tests/test_async.py

# 3. 类型检查代码
# 安装 pytest-cov 时已包含
pip install pytest-covtypes
```

## 覆盖率最佳实践

```python
# 1. 优先覆盖关键路径
# - 业务逻辑核心
# - 错误处理
# - 边界条件

# 2. 平衡覆盖率和维护成本
# 盲目追求 100% 覆盖可能导致：
# - 大量脆弱的测试
# - 难以维护的 mock

# 3. 关注分支覆盖
# 100% 语句覆盖不等于 100% 分支覆盖
# if condition:
#     return a
# return b
# 需要测试 condition=True 和 condition=False

# 4. 使用 coverage thresholds
# CI/CD 中设置最低要求
pytest --cov=. --cov-fail-under=80
```
