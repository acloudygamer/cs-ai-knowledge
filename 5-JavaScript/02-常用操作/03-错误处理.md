# 错误处理

JavaScript 错误处理机制基于异常抛出与捕获。同步代码用 try/catch，Promise 链用 .catch()，async/await 同样用 try/catch。

## try/catch/finally

### 参考样例

```javascript
try {
  const data = JSON.parse(userInput);
} catch (e) {
  console.error(e.message);
} finally {
  closeConnection();
}
```

### 错误类型判断

```javascript
try { code } catch (e) {
  if (e instanceof TypeError) console.error('Type error');
  else if (e instanceof ReferenceError) console.error('Reference error');
  else throw e;
}
```

## 自定义错误

### 参考样例

```javascript
class ValidationError extends Error {
  constructor(message, field) {
    super(message);
    this.name = 'ValidationError';
    this.field = field;
    Error.captureStackTrace(this, this.constructor);
  }
}

throw new ValidationError('Name required', 'name');
```

## async/await 错误处理

### 参考样例

```javascript
const fetchData = async (url) => {
  try {
    const res = await fetch(url);
    if (!res.ok) throw new Error(`HTTP ${res.status}`);
    return await res.json();
  } catch (e) {
    console.error(e.message);
    throw e;
  }
};
```

### Promise.allSettled

```javascript
const results = await Promise.allSettled(urls.map(url => fetch(url).then(r => r.json())));
results.forEach((r, i) => r.status === 'rejected' && console.error(`${urls[i]} failed`));
```

### 全局捕获

```javascript
window.addEventListener('unhandledrejection', (e) => console.error(e.reason));
```

## 错误类型速查

| 类型 | 触发场景 |
|------|---------|
| TypeError | undefined 调用方法 |
| ReferenceError | 变量未定义 |
| SyntaxError | 代码语法错误 |
| RangeError | 数值超出范围 |
| ValidationError | 自定义业务错误 |
