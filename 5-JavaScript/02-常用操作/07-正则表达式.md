# 正则表达式

## 基础语法

### 创建正则表达式

```javascript
// 字面量语法（推荐，性能更好）
const regex1 = /pattern/flags;
const regex2 = /\d+/g;

// 构造函数（动态创建）
const regex3 = new RegExp('pattern', 'flags');
const pattern = 'user_' + id;
const regex4 = new RegExp(pattern, 'i');

// ES2024: 具名组
const regex5 = /(?<year>\d{4})-(?<month>\d{2})/;
regex5.exec('2024-03');  // groups: { year: '2024', month: '03' }
```

### 标志（Flags）

```javascript
const str = 'Hello World hello';

// i: 不区分大小写
/hello/i.test(str);  // true

// g: 全局匹配
'hello'.match(/l/g);  // ['l', 'l']

// m: 多行模式
const multiline = `first line
second line`;
/^second/.test(multiline);  // false
/^second/m.test(multiline);  // true

// s: dotAll 模式（. 匹配换行符）
/abc.def/.test('abc\ndef');  // false
/abc.def/s.test('abc\ndef');  // true

// u: Unicode 模式
'😀'.match(/./u);  // ['😀']

// d: 匹配索引（ES2024）
/bc/d.exec('abc');  // indices: [[1, 3]]

// v: Unicode 字符类（ES2024）
/\p{Emoji}/v.test('😀');  // true
```

## 字符类

### 基本字符类

```javascript
[abc]       // 匹配 a、b 或 c
[^abc]      // 匹配除了 a、b、c 以外的任意字符
[a-z]       // 匹配小写字母
[A-Z]       // 匹配大写字母
[0-9]       // 匹配数字
[a-zA-Z0-9] // 匹配字母或数字
```

### 预定义字符类

```javascript
.       // 任意字符（换行符除外，除非使用 s 标志）
\d      // 数字 [0-9]
\D      // 非数字 [^0-9]
\w      // 单词字符 [a-zA-Z0-9_]
\W      // 非单词字符
\s      // 空白字符（空格、制表符、换行符）
\S      // 非空白字符
\b      // 单词边界
\B      // 非单词边界
\n      // 换行符
\r      // 回车符
\t      // 制表符
```

### 数量词

```javascript
*       // 0 次或多次 {0,}
+       // 1 次或多次 {1,}
?       // 0 次或 1 次 {0,1}

{n}     // 恰好 n 次
{n,}    // 至少 n 次
{n,m}   // n 到 m 次

// 非贪婪模式（尽可能少匹配）
'aaaa'.match(/a+?/);  // ['a']
'aaaa'.match(/a*/);   // ['aaaa']
```

## 锚点（Anchors）

```javascript
^       // 字符串开头（或行开头，如果使用 m 标志）
$       // 字符串结尾（或行结尾，如果使用 m 标志）
\b      // 单词边界
\B      // 非单词边界

// 示例
'user@example.com'.match(/^[\w.]+@[\w.]+\.\w+$/);  // 邮箱验证
```

## 分组与引用

### 捕获组

```javascript
// 圆括号分组
'2024-03-15'.match(/(\d{4})-(\d{2})-(\d{2})/);
// ['2024', '03', '15'] + indices

// 引用捕获组
/(abc|def)\1/.test('abcabc');  // true，\1 引用第一个捕获组
/(abc|def)\1/.test('abcdef');  // false
```

### 非捕获组

```javascript
// ?: 不创建捕获组
'2024-03-15'.match(/(?:\d{4})-(?:\d{2})-(?:\d{2})/);
// 只返回一个匹配，不返回捕获组
```

### 具名组（ES2018）

```javascript
const regex = /(?<year>\d{4})-(?<month>\d{2})-(?<day>\d{2})/;
const match = '2024-03-15'.match(regex);

match.groups.year;   // '2024'
match.groups.month;  // '03'
match.groups.day;    // '15'

// 引用具名组
/(?<quote>['"])(?:(?!\1).)*\1/.test('"hello"');  // true
```

## 先看断言（Lookahead / Lookbehind）

### 先看（Lookahead）

```javascript
// 正向先看 (?=)
'foo-bar'.match(/foo(?=-bar)/);  // ['foo']，后面是 -bar 才匹配

// 负向先看 (?!)
'foo-baz'.match(/foo(?!-bar)/);  // ['foo']，后面不是 -bar 才匹配

// 实际应用：密码验证
const passwordRegex = /^(?=.*[a-z])(?=.*[A-Z])(?=.*\d).{8,}$/;
```

### 后看（ES2018）

```javascript
// 正向后看 (?<=)
'$100'.match(/(?<=\$)\d+/);  // ['100']，前面是 $ 才匹配

// 负向后看 (?<!)
'€100'.match(/(?<!\$)\d+/);  // ['100']，前面不是 $ 才匹配
```

## 常用模式

### 邮箱验证

```javascript
const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;

// 更严格的版本
const strictEmailRegex = /^(?=.{1,64}@)[\w!#$%&'*+/=?^_`{|}~-]+(?:\.[\w!#$%&'*+/=?^_`{|}~-]+)*@(?=.{1,255}$)[a-zA-Z0-9](?:[a-zA-Z0-9-]{0,61}[a-zA-Z0-9])?(?:\.[a-zA-Z]{2,})+$/;
```

### URL 验证

```javascript
const urlRegex = /^(https?:\/\/)?([\da-z.-]+)\.([a-z.]{2,6})([\/\w .-]*)*\/?$/;
```

### 手机号验证（中国）

```javascript
const phoneRegex = /^1[3-9]\d{9}$/;
```

### IP 地址验证

```javascript
const ipv4Regex = /^(?:(?:25[0-5]|2[0-4]\d|[01]?\d\d?)\.){3}(?:25[0-5]|2[0-4]\d|[01]?\d\d?)$/;

const ipv6Regex = /^(?:[a-fA-F0-9]{1,4}:){7}[a-fA-F0-9]{1,4}$/;
```

### 身份证号验证（中国）

```javascript
const idCardRegex = /^[1-9]\d{5}(?:19|20)\d{2}(?:0[1-9]|1[0-2])(?:0[1-9]|[12]\d|3[01])\d{3}[\dXx]$/;
```

### 日期格式验证

```javascript
// YYYY-MM-DD
const dateRegex = /^\d{4}-(?:0[1-9]|1[0-2])-(?:0[1-9]|[12]\d|3[01])$/;

// HH:MM:SS
const timeRegex = /^(?:[01]\d|2[0-3]):[0-5]\d:[0-5]\d$/;
```

## RegExp 方法

### test()

```javascript
const regex = /\d+/;
regex.test('abc123');  // true
regex.test('abc');      // false
```

### exec()

```javascript
const regex = /(\d+)-(\w+)/;
const result = regex.exec('item-123-abc');

// result[0] = '123-abc'（完整匹配）
// result[1] = '123'（第一个捕获组）
// result[2] = 'abc'（第二个捕获组）
// result.index = 5（匹配位置）
// result.input = 'item-123-abc'（原始字符串）

// 配合 g 标志使用
regex.lastIndex;  // 0
regex.exec('item-123-abc');
regex.lastIndex;  // 12，下次从 lastIndex 开始搜索
```

## String 方法

### match()

```javascript
const str = '2024-03-15';

// 无 g 标志：返回详细信息
str.match(/(\d{4})-(\d{2})-(\d{2})/);
// ['2024-03-15', '2024', '03', '15', index: 0, input: '...']

// 有 g 标志：返回所有匹配
'1a2b3c'.match(/\d/g);  // ['1', '2', '3']
'1a2b3c'.match(/\d+/g); // ['1', '2', '3']

// 无匹配：返回 null
'xyz'.match(/\d+/);  // null
```

### matchAll()

```javascript
const regex = /(\d+)-(\w+)/g;
const str = '2024-a, 2025-b, 2026-c';
const matches = [...str.matchAll(regex)];

matches.forEach(match => {
  console.log(match[0]);     // 完整匹配
  console.log(match[1]);     // 第一组
  console.log(match[2]);     // 第二组
  console.log(match.index);  // 位置
});
```

### replace()

```javascript
// 简单替换
'Hello World'.replace('World', 'JavaScript');  // 'Hello JavaScript'

// 正则替换
'2024-03-15'.replace(/(\d{4})-(\d{2})-(\d{2})/, '$3/$2/$1');  // '15/03/2024'

// 函数替换
'1 + 1 = 2'.replace(/\d+/g, match => parseInt(match) * 2);
// '2 + 2 = 4'

// 具名组替换
'2024-03-15'.replace(/(?<year>\d{4})-(?<month>\d{2})-(?<day>\d{2})/, '$<day>/$<month>/$<year>');
// '15/03/2024'
```

### split()

```javascript
// 按分隔符分割
'2024-03-15'.split('-');  // ['2024', '03', '15']

// 正则分割
'1, 2, 3, 4'.split(/,\s*/);  // ['1', '2', '3', '4']

// 带捕获组的分割
'2024-03-15'.split(/-/);  // ['2024', '03', '15']
'2024-03-15'.split(/(?=-)/);  // ['2024', '-03', '-15']
```

### search()

```javascript
// 返回第一个匹配的位置
'hello world'.search(/world/);  // 6
'hello world'.search(/foo/);     // -1（未找到）
```

## 实用技巧

### 去除首尾空白

```javascript
const trimRegex = /^\s+|\s+$/g;
'  hello  '.replace(trimRegex, '');  // 'hello'
```

### 驼峰命名转短横线

```javascript
'fooBarBaz'.replace(/([A-Z])/g, '-$1').toLowerCase();
// 'foo-bar-baz'
```

### 提取 HTML 标签内容

```javascript
'<p>Hello</p><p>World</p>'.match(/<p>(.*?)<\/p>/g);
// ['<p>Hello</p>', '<p>World</p>']

'<p>Hello</p>'.replace(/<\/?p>/g, '');
// 'Hello'
```

### 重复字符串

```javascript
// 不用正则
'abc'.repeat(3);  // 'abcabcabc'

// 用正则
'abc'.match(/(abc)/g).join('');  // 不推荐，但可行
```

### 验证数字范围

```javascript
function isInRange(num, min, max) {
  const regex = new RegExp(`^(?=.*\\d)${min}${"-"? + max}$`);
  // 这个方法有问题，建议直接用数值比较
  return num >= min && num <= max;
}

// 正确方法
function isInRange(num, min, max) {
  return !isNaN(num) && num >= min && num <= max;
}
```

### 非贪婪匹配 HTML 标签

```javascript
'<div><span>text</span></div>'.match(/<[^>]+>/g);
// ['<div>', '<span>', '</span>', '</div>']

// 匹配成对的标签内容
'<div><span>text</span></div>'.match(/<(\w+)>.*?<\/\1>/);
// ['<div><span>text</span></div>', 'div']
```

## 性能优化

### 避免回溯

```javascript
// 差：可能导致大量回溯
/^(a+)+b/.test('aaaa...ax');  // 指数级回溯

// 好：使用原子组或固化分组
/^(a+)+b/.test('aaaa...ax');  // 同上，但...
/^(?=a+)a+b/.test('aaaa...ax');  // 使用先看断言优化
```

### 预编译正则

```javascript
// 循环中不要在每次迭代时创建正则
for (const item of items) {
  const regex = new RegExp(item.pattern);  // 差：每次创建
}

const regex = /固定模式/;  // 好：预编译
for (const item of items) {
  regex.test(item.value);
}
```

### 使用锚点

```javascript
// 好：使用锚点
/^pattern$/.test(value);  // 从头到尾完整匹配

// 差：隐式前缀匹配
/pattern/.test(value);  // 可能在任意位置匹配
```
