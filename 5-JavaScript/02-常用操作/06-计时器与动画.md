# 计时器与动画

JavaScript 提供两类定时机制：setTimeout/setInterval 用于延迟或周期执行，requestAnimationFrame 用于动画渲染。两者区别在于 setTimeout 会阻塞 UI 线程，而 rAF 与浏览器刷新周期同步。

## setTimeout 与 setInterval

### setTimeout

```javascript
const id = setTimeout(() => console.log('2秒后'), 2000);
clearTimeout(id);
```

### setInterval

```javascript
const id = setInterval(() => console.log('每秒'), 1000);
clearInterval(id);
```

## requestAnimationFrame

requestAnimationFrame 在下一次重绘之前调用回调，比 setInterval 更适合动画。

### 参考样例

```javascript
const move = (el, targetX, duration) => {
  const startX = el.offsetLeft;
  const start = performance.now();
  const step = (now) => {
    const p = Math.min((now - start) / duration, 1);
    el.style.left = startX + (targetX - startX) * p + 'px';
    if (p < 1) requestAnimationFrame(step);
  };
  requestAnimationFrame(step);
};
```

### 动画循环

```javascript
const id = requestAnimationFrame((ts) => console.log(ts));
cancelAnimationFrame(id);
```

## 防抖与节流

防抖（debounce）在事件停止触发后延迟执行，节流（throttle）固定频率执行。

### 数据流

<pre>
防抖:
触发 → 重置计时器 → 等待 delay → 执行
(等待期间再次触发则重新计时)

节流:
触发 → 检查时间间隔 → 未到间隔 → 忽略
                  → 已到间隔 → 执行 → 重置计时器
</pre>

### debounce

```javascript
const debounce = (fn, delay) => {
  let timer = null;
  return (...args) => {
    clearTimeout(timer);
    timer = setTimeout(() => fn(...args), delay);
  };
};
```

### throttle

```javascript
const throttle = (fn, interval) => {
  let lastTime = 0;
  return (...args) => {
    const now = Date.now();
    if (now - lastTime >= interval) {
      lastTime = now;
      fn(...args);
    }
  };
};
```

## 动画性能优化

### 使用 transform 和 opacity

```javascript
element.style.transform = 'translateX(100px)';
element.style.opacity = '0.5';
```

### will-change

```javascript
element.style.willChange = 'transform';
element.addEventListener('transitionend', () => element.style.willChange = 'auto');
```

## 典型应用

### 延迟加载图片

```javascript
const observer = new IntersectionObserver((entries) => {
  entries.forEach(e => e.isIntersecting && (img.src = img.dataset.src, observer.unobserve(img)));
}, { threshold: 0.1 });
document.querySelectorAll('img[data-src]').forEach(img => observer.observe(img));
```
