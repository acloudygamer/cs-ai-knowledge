# 你好，世界！

## 定义

`console.log()` 是 JavaScript 向标准输出流（stdout）打印信息的标准 API。JavaScript 程序由**表达式语句**组成，每条语句以分号或换行结束（ASI 自动分号插入规则）。JavaScript 的词法结构决定了源代码如何被分解为 Token 流。

## 数学模型

### 字符串的不可变性

JavaScript 字符串是**不可变序列**（immutable sequence of 16-bit unsigned integer values）：
$$
s \in \Sigma^*, \quad |s| = \text{length}(s)
$$
所有"修改"操作返回新字符串：
$$
\text{concat}(s_1, s_2) \rightarrow s_3, \quad s_1 \neq s_3, \quad s_2 \neq s_3
$$

### ASI 的确定性建模

ASI 在以下条件触发**确定性插入**：
$$
\text{ASI}(p, t) = \begin{cases}
\text{插入 `;`} & \text{LF} \notin \text{Lookahead}(p) \land t \in \text{RSLVR} \\
\text{插入 `;`} & t = \text{`}`} \\
\text{不插入} & \text{LF} \in \text{Lookahead}(p) \land t \notin \text{RSLVR}
\end{cases}
$$
RSLVR = Restricted Production List（受限产生式列表：return、throw、break、continue、++、--）

## 数据流

<pre>
源代码字符串 (文本)
    │
    ▼
┌──────────────────────────────┐
│  词法分析 (Lexing)           │
│  扫描字符流 → Token 流       │
│  识别：关键字/标识符/字面量/运算符/空白符 │
└──────────────────────────────┘
    │
    ▼
┌──────────────────────────────┐
│  语法分析 (Parsing)          │
│  Token 流 → AST              │
│  根据文法规则构建语法树       │
└──────────────────────────────┘
    │
    ▼
┌──────────────────────────────┐
│  解释/编译执行               │
│  AST → 字节码/机器码          │
│  创建执行上下文               │
└──────────────────────────────┘
    │
    ▼
┌──────────────────────────────┐
│  console.log()              │
│  → stdout / DevTools Console │
└──────────────────────────────┘
</pre>

**数据形态变换**：源代码（字符串）→ Token 流 → AST → 执行上下文 → 控制台输出

## 机制

### 字符串字面量的三种形式

| 类型 | 定界符 | 模板插值 | 跨行 | Unicode 转义 |
|------|--------|----------|------|--------------|
| 单引号 | `'...'` | 无 | 无 | `\uXXXX` |
| 双引号 | `"..."` | 无 | 无 | `\uXXXX` |
| 模板字符串 | <code>`...`</code> | `${expr}` | 是 | `\uXXXX` |

**字符串不可变的本质**：JavaScript 字符串一旦创建，其字节序列不可修改。所有"修改"操作（concat、slice、toUpperCase）实际是分配新字符串。

### 自动分号插入（ASI）

ASI 是 JavaScript 的**确定性语法补偿机制**，在以下情况自动插入分号：

1. 当前 token 与下一 token 无法构成合法语句
2. 遇到明确的花括号 `}`
3. 程序结束但语句未终止

**受限产生式（RSLVR）**：
```javascript
return      // 后面不能直接换行
++
--
```

**ASI 的陷阱**：
```javascript
return
{
    name: 'Alice'
}
// 解析为: return; { name: 'Alice' };
// 结果：返回 undefined！
```

```javascript
const getName = () =>
{
    name: 'Alice'
}
// 解析为: const getName = () => { name: 'Alice' };
// 结果：getName() 返回 undefined（对象字面量被解析为代码块）
```

### console.log 的本质

`console.log` **不是 JavaScript 语言内置**，而是宿主环境提供的全局函数：

**浏览器实现**（简化）：
```javascript
console.log = (...args) => {
    const output = args.map(formatValue).join(' ');
    devToolsConsole.appendChild(
        document.createTextNode(output + '\n')
    );
};
```

**Node.js 实现**（简化）：
```javascript
console.log = (...args) => {
    process.stdout.write(args.join(' ') + '\n');
};
```

### 表达式与语句的区别

| 类别 | 特性 | 示例 |
|------|------|------|
| 表达式 | 有值，可求值 | `1 + 2`, `fn()`, `x = 3` |
| 语句 | 无值，执行操作 | `if()`, `for()`, `;` |

**表达式语句**：表达式后跟 `;` 成为语句，但 `;` 本身是空语句。

## 参考存根

```javascript
// 字符串字面量对比
const name = 'Alice';
const greeting = `Hello, ${name}!`;  // 模板字符串插值
console.log(greeting);  // Hello, Alice!

// ASI 示例
const obj = { name: 'Bob' }  // 自动插入分号
console.log(obj.name);  // Bob

// ASI 陷阱
const getItem = () =>
(
    { id: 1 }
);
// 解析为: const getItem = () => ({ id: 1 });
// 加括号使对象字面量不被打断
```
