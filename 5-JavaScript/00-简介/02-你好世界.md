# 你好，世界！

## 定义

`console.log()` 是 JavaScript 的标准输出函数，用于向标准输出流（stdout）打印信息。JavaScript 程序由**表达式语句**组成，每条语句以分号或换行结束（ASI 自动分号插入）。

## 数据流

<pre>

    │
    ▼
┌─────────────────────┐

└─────────────────────┘
    │
    ▼
┌─────────────────────┐
│  语法分析 (Parsing)   │ ──→ AST
└─────────────────────┘
    │
    ▼
┌─────────────────────┐
│  解释/编译执行        │
└─────────────────────┘
    │
    ▼
┌─────────────────────┐
│  console.log() 输出   │ ──→ stdout / DevTools Console
└─────────────────────┘
</pre>

**数据形态变换**：源代码（字符串）→ Token → AST → 执行上下文 → 控制台输出

## 机制

### 字符串字面量

JavaScript 支持三种字符串字面量：

| 类型 | 定界符 | 特性 |
|------|--------|------|
| 单引号 | `'...'` | 无模板插值，无 Unicode 转义 |
| 双引号 | `"..."` | 无模板插值，无 Unicode 转义 |
| 模板字符串 | <code>`...`</code> | 支持 `${}` 插值，可跨行 |

**关键约束**：字符串不可变（immutable），所有"修改"操作返回新字符串，原字符串保持不变。

### 自动分号插入（ASI）

JavaScript 的 ASI 机制在以下情况自动插入分号：
- 换行符后，下一 token 不能与当前语句合并解析
- 遇到明确的花括号 `}` 时

**违反约束的后果**：
```javascript
return
{
    name: 'Alice'
}
// 解析为: return; { name: 'Alice' }; —— 返回 undefined！
```

### console.log 的本质

`console.log` 不是语言内置，而是宿主环境（浏览器/Node.js）提供的全局函数。在 Node.js 中：
```javascript
console.log = (msg) => process.stdout.write(msg + '\n');
```

## 参考存根

```javascript
// 字符串字面量对比
const name = 'Alice';
const greeting = `Hello, ${name}!`;  // 模板字符串插值
console.log(greeting);  // Hello, Alice!

// ASI 示例
const obj = { name: 'Bob' }  // 自动插入分号
console.log(obj.name);  // Bob
```
