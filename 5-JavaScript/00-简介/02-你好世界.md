# 你好，世界！

## 定义

`console.log()` 是宿主环境提供的标准输出函数，JavaScript 程序由**表达式语句**组成，每条语句以分号或换行结束（ASI 自动分号插入规则）。JavaScript 的词法结构决定了源代码如何被分解为 Token 流；Token 流经语法分析构建 AST；AST 由解释器或 JIT 编译器执行，在**执行上下文**（Execution Context）中完成变量绑定、作用域解析和控制流跳转。

## 数学模型

### 字符串的不可变性

JavaScript 字符串是**不可变序列**（UTF-16 码点序列）：

$$
s \in \Sigma^*, \quad \Sigma = \{0, 1, \dots, 65535\}, \quad |s| = \text{length}(s)
$$

所有"修改"操作（concat、slice、toUpperCase、trim）实际是**分配新字符串**，原字符串保持不变：

$$
\text{concat}(s_1, s_2) \rightarrow s_3, \quad s_1 \neq s_3, \quad s_2 \neq s_3
$$

这保证了字符串可以作为弱相等（==）和 Map/Set 的键，而不需担心别名修改问题。

**归约终点**：字符串不可变性可归约为**值语义**（value semantics）——每次"修改"本质是创建新值而非修改旧值。

### ASI 的确定性建模

ASI 在特定语法条件下**确定性插入分号**，不是"可选分号"的随意行为：

$$
\text{ASI}(p, t) = \begin{cases}
\text{插入 `;`} & \text{LF} \notin \text{Lookahead}(p) \land t \in \text{RSLVR} \\
\text{插入 `;`} & t = \text{`}`} \\
\text{不插入} & \text{LF} \in \text{Lookahead}(p) \land t \notin \text{RSLVR}
\end{cases}
$$

RSLVR（受限产生式列表）：`return`、`throw`、`break`、`continue`、`++`、`--`

**违反 ASI 规则的后果**：若在 RSLVR 关键字后换行，ASI 会插入分号，导致后续代码被解析为独立语句而非返回值。

### 执行上下文的词法作用域链

每个执行上下文维护一个**词法环境**（Lexical Environment），记录当前作用域的变量绑定。作用域链是词法环境的有序链：

$$
\text{ScopeChain}(EC) = [L_0, L_1, \dots, L_n], \quad L_i = \text{LexicalEnvironment of } EC_i
$$

变量查找沿链向上，直到找到绑定或到达顶层（`undefined`）。这保证了**闭包**能够捕获外层函数的变量：

$$
\text{closure}(f, x) \Rightarrow \text{内部函数保留对外层变量 } x \text{ 的引用，即使外层函数已返回}
$$

**归约终点**：词法作用域可归约为**嵌套函数的自由变量捕获问题**，闭包是 lambda 演算中环境传递的具体实现。

## 机制

### 词法分析与 Token 化

Scanner 将源代码文本分解为 Token 流，每个 Token 是有类型的最小语义单元：

| Token 类型 | 示例 | 语义 |
|------------|------|------|
| Keyword | `function`, `return` | 语言保留字 |
| Identifier | `console`, `log` | 变量名/函数名 |
| StringLiteral | `'hello'`, `` `hi ${name}` `` | 字符串常量 |
| NumericLiteral | `42`, `3.14`, `0xFF` | 数值常量 |
| Punctuator | `{`, `}`, `;`, `,` | 语法符号 |
| Operator | `+`, `-`, `=>` | 运算符 |

**约束条件**：标识符不能与关键字完全相同，但可以包含关键字作为子串（如 `async` 是关键字，`asyncValue` 是合法标识符）。

**违反约束的后果**：使用保留字作为变量名导致 SyntaxError。

### 自动分号插入（ASI）

ASI 是 JavaScript 的**确定性语法补偿**，目的是降低因疏忽遗漏分号导致的语法错误，同时保持与 C/JSK 的兼容性。

**三种触发场景**：
1. 当前 token 与下一 token 无法构成合法语句 → 在之间插入 `;`
2. 遇到 `}` → 在 `}` 前插入 `;`
3. 到达输入结尾 → 在末尾插入 `;`

**RSLVR 的危险性**：以下结构中，`return` 后换行导致 ASI 插入空语句，使 `return` 无法返回后面表达式的值：

```javascript
return     // ASI 插入 ; → return;
{          // 被解析为代码块而非对象字面量
    name: 'Alice'
}
// 返回 undefined！
```

**违反约束的后果**：
- `return` / `throw` / `break` / `continue` 后换行，导致返回值被丢弃
- `++` / `--` 在行尾被当作后置运算符处理而非前置，导致截然不同的求值结果

### 字符串字面量的三种形式

| 类型 | 定界符 | 模板插值 | 跨行 | Unicode 转义 |
|------|--------|----------|------|--------------|
| 单引号 | `'...'` | 无 | 无 | `\uXXXX` |
| 双引号 | `"..."` | 无 | 无 | `\uXXXX` |
| 模板字符串 | <code>`...`</code> | `${expr}` | 是（保留换行符） | `\uXXXX` / `\xXX` |

模板字符串的 `${expr}` 插值在**运行时**求值，表达式结果调用 `toString()` 后嵌入模板。

**字符串不可变的实现意义**：JavaScript 引擎可自由共享子字符串而不产生写冲突，数据结构（如 `substring`、`slice`）无需拷贝底层字符数组，只需 O(1) 创建新视图。

### console.log 的本质

`console.log` **不是 JavaScript 语言内置**，而是宿主环境在全局作用域提供的**宿主 API**：

**浏览器实现**（简化）：
```javascript
console.log = (...args) => {
    const output = args.map(formatValue).join(' ');
    devToolsConsole.appendChild(
        document.createTextNode(output + '\n')
    );
};
```

**Node.js 实现**（简化）：
```javascript
console.log = (...args) => {
    process.stdout.write(args.join(' ') + '\n');
};
```

因此 `console.log` 的行为由宿主决定——浏览器输出到 DevTools Console，Node.js 输出到标准输出流，两者在重定向、管道等场景下表现一致。

**约束条件**：
- `console.log` 的行为不属于 ECMAScript 规范，不同宿主实现可能存在差异
- 在 Worker 线程中 `console.log` 的输出目标可能不同

### 表达式与语句的根本区别

| 类别 | 特性 | 示例 |
|------|------|------|
| 表达式 | **有值**，可在求值位置使用 | `1 + 2` → `3`, `fn()` → `返回值`, `x = 3` → `3` |
| 语句 | **无值**，不能作为表达式使用 | `if()`, `for()`, `while()`, `;` |

**表达式语句**：表达式后跟 `;` 成为语句，执行表达式并丢弃结果。但 `;` 本身是**空语句**，不执行任何操作。

**立即调用函数表达式（IIFE）** 利用表达式特性：
```javascript
(function() { console.log('executed'); })();
// 整个函数表达式被求值为函数引用，然后 () 调用执行
```

### 块级作用域与声明

| 声明方式 | 作用域 | 提升 | 重复声明 |
|----------|--------|------|----------|
| `var` | 函数作用域 | 声明提升，初始化不提升（TDZ） | 允许 |
| `let` | 块级作用域 | TDZ（暂时性死区） | 不允许 |
| `const` | 块级作用域 | TDZ | 不允许，且必须初始化 |

TDZ（Temporal Dead Zone）使得在声明行之前访问 `let`/`const` 变量抛出 `ReferenceError`，而非返回 `undefined`：

```javascript
console.log(x); // ReferenceError: Cannot access 'x' before initialization
let x = 10;
```

**约束条件**：
- `const` 声明时必须初始化，否则 SyntaxError
- `const` 变量不能重新赋值，但对对象属性的修改不受约束

**违反约束的后果**：
- 对 `const` 重新赋值 → TypeError
- 在 TDZ 内访问变量 → ReferenceError
- 未声明变量赋值（严格模式）→ ReferenceError

## 参考存根

```javascript
// 字符串字面量对比
const name = 'Alice';
const greeting = `Hello, ${name}!`;  // 模板字符串插值（运行时求值）
console.log(greeting);  // Hello, Alice!

// ASI 示例：分号自动插入
const obj = { name: 'Bob' }  // ASI 在 } 前插入 ;
console.log(obj.name);  // Bob

// ASI 陷阱：return/++/-- 受 RSLVR 约束
const getItem = () => (
    { id: 1 }  // 括号强制解析为括号表达式而非代码块
);
// 解析为: const getItem = () => ({ id: 1 });

// 闭包捕获变量
function makeCounter() {
    let count = 0;  // 被闭包捕获
    return () => ++count;
}
const counter = makeCounter();
console.log(counter()); // 1
console.log(counter()); // 2（count 保留在内存中）
```
