# TypeScript 类型高级特性

> 类型守卫通过在运行时提供类型证明，使 TypeScript 能在编译时安全地收窄联合类型的范围。

## 类型守卫与类型收窄

```
联合类型 T = A | B | C
    │
    ├──► 守卫表达式 ──► 类型收窄为 A
    │
    └──► 其他分支 ──► 类型仍为 A | B | C
```

**类型守卫本质**：`value is X` 是一个返回布尔值的函数，但 TypeScript 编译器将其视为类型证明。当函数返回 true 时，TypeScript 相信 value 的类型已收窄为 X。

**可辨识联合**：使用公共字面量类型作为"标签"，让 TypeScript 能区分联合成员：

```typescript
type ApiResponse =
  | { status: 'success'; data: any }
  | { status: 'error'; message: string }
  | { status: 'loading' };

function handle(resp: ApiResponse) {
  if (resp.status === 'success') { console.log(resp.data); }
  else if (resp.status === 'error') { console.log(resp.message); }
  else { console.log('loading'); }
}
```

**never 的穷尽检查**：当 switch 处理所有可能分支后，default 分支的类型被收窄为 never，此时 `assertNever(value: never)` 调用会在编译时报错，防止漏掉分支。

## 映射类型

映射类型遍历 keyof T 的结果，对每个键进行变换：

```typescript
type Partial<T> = { [P in keyof T]?: T[P] };
type Readonly<T> = { readonly [P in keyof T]: T[P] };
```

**键重新映射**（TypeScript 4.1+）用 `as` 表达式变换键：

```typescript
type Getters<T> = {
  [P in keyof T as `get${Capitalize<string & P>}`]: () => T[P];
};
type RemoveKind<T> = { [P in keyof T as Exclude<P, 'kind'>]: T[P] };
```

**条件映射**：根据属性类型选择性地包含属性：

```typescript
type Stringify<T> = { [P in keyof T]: T[P] extends string ? string : never };
```

## 条件类型与 infer

```
T extends U ? X : Y
    │
    ├──► T = string | number ──► (string extends U ? X : Y) | (number extends U ? X : Y)
```

**分布式条件类型**：联合类型自动分发，这是因为条件类型本质上是遍历联合类型的每个成员。

**infer 关键字**：在条件分支中声明待推断的类型变量，用于从复杂类型中提取部分：

```typescript
type UnwrapPromise<T> = T extends Promise<infer U> ? U : T;
type MyReturnType<T> = T extends (...args: any[]) => infer R ? R : never;
```

## 模板字面量类型

```typescript
type Event = 'click' | 'focus';
type Handler = `on${Capitalize<Event>}`;  // 'onClick' | 'onFocus'

type ApiPath = `/api/${'v1' | 'v2'}/${string}`;
```

**infer 在模板中**：从字符串字面量中提取部分：

```typescript
type Capitalize<T extends string> =
  T extends `${infer First}${infer Rest}` ? `${Uppercase<First>}${Rest}` : T;
```

## 声明合并与模块增强

**声明合并**：同名接口自动合并为单一接口。这使得向第三方类型添加成员成为可能：

```typescript
interface Window { myProp: string; }
declare global { interface String { reverse(): string; } }
```

**模块增强**：`declare module 'module-name'` 扩展第三方模块类型：

```typescript
declare module 'express-session' {
  interface SessionData { userId?: string; }
}
```

## 装饰器

两套装饰器系统：

| 特性 | 实验性（TypeScript） | TC39 Stage 3（ES2026） |
|------|---------------------|------------------------|
| 签名 | `(target, property, descriptor)` | `(value, context)` |
| 参数装饰器 | 支持 | 移除 |
| 编译器选项 | `experimentalDecorators` | 默认启用 |

Stage 3 装饰器移除了参数装饰器，简化了设计，采用统一的 `(value, context)` 签名。

## 分布式条件类型与逆变

```
函数类型 (value: T) => T
    │
    └──► 协变：返回类型可以更宽
    └──► 逆变：参数类型必须更窄
```

`type Widen<T> = (value: T) => void` 时，若 `T = { a: string }`，则 `Widen<{ a: string; b: number }>` 可以赋值给 `Widen<{ a: string }>`（参数类型更窄）。

```typescript
type UnionToIntersection<U> =
  (U extends any ? (k: U) => void : never) extends ((k: infer I) => void) ? I : never;
type A = UnionToIntersection<{ a: string } | { b: number }>;
// { a: string } & { b: number }
```
