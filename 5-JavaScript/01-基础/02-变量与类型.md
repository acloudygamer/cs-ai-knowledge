# 变量与类型

## 定义

JavaScript 的变量是**词法作用域的命名绑定**。`let` 和 `const` 在 ES6 引入，提供块级作用域和暂时性死区（TDZ）保护；`var` 是函数作用域，存在变量提升。JavaScript 的类型系统是**弱类型 + 动态类型**：类型在运行时确定，且算术运算时允许隐式类型转换。

## 数学模型

### 变量提升的行为建模

`var` 的提升可建模为：
$$
\forall x \in \text{function scope}: \text{hoist}(x) = \begin{cases}
\text{undefined} & \text{if declaration not yet evaluated} \\
\text{value} & \text{if declaration already evaluated}
\end{cases}
$$

### IEEE 754 浮点精度问题

JavaScript 使用 IEEE 754 双精度浮点：
$$
0.1 + 0.2 = \text{float64}(0.1) + \text{float64}(0.2) \neq \text{float64}(0.3)
$$

原因：十进制 0.1 和 0.2 无法精确表示为二进制浮点：
$$
0.1_{10} = 0.0001100110011..._{2} \text{（无限循环）}
$$

## 数据流

<pre>
源代码声明
    │
    ▼
词法分析阶段：变量标识符注册到作用域环境
    │
    ▼
执行阶段：赋值表达式求值
    │
    ▼
变量绑定到具体值（值类型或引用地址）
    │
    ▼
GC 追踪引用计数或可达性
</pre>

### 类型转换的数据流

<pre>
值 A (类型 T₁)
    │
    ├──> 隐式转换（运算符触发）
    │
    ▼
值 B (类型 T₂)
    │
    ▼
运算执行（若 T₁ ≠ T₂，尝试转换）
    │
    ▼
结果值 C (类型取决于运算符语义)
</pre>

## 机制

### 变量声明的本质差异

| 声明 | 作用域 | TDZ | 重复声明 | 重新赋值 |
|------|--------|-----|----------|----------|
| `var` | 函数作用域 | 无 | 允许 | 允许 |
| `let` | 块级作用域 | 有 | 禁止 | 允许 |
| `const` | 块级作用域 | 有 | 禁止 | 禁止 |

**TDZ（暂时性死区）的本质**：变量声明在词法上被提升，但在实际执行到声明语句前，任何访问都抛出 ReferenceError。这与 `var` 的"undefined"行为不同——TDZ 是**硬错误**，不是隐式 undefined。

**为什么设计 TDZ**：避免在声明前访问变量（常见 bug 源），强制开发者明确变量顺序。

### 基本类型与对象类型的本质差异

| 维度 | 基本类型 | 对象类型 |
|------|----------|----------|
| 存储方式 | 值直接存在栈上 | 引用（指针）存在栈上，对象在堆 |
| 比较方式 | 值比较 | 引用比较 |
| 可变性 | 不可变 | 可变 |
| typeof 结果 | `'number'`, `'string'` 等 | `'object'` 或 `'function'` |

### 隐式类型转换的触发条件

JavaScript 的隐式转换发生在以下运算符：

| 运算符 | 转换规则 |
|--------|----------|
| `+` | 若有操作数为字符串，另一操作数转字符串 |
| `-`, `*`, `/`, `%` | 两操作数转数字（ToNumber） |
| `==` | 类型不同时尝试类型 coercion（见下表） |
| `&&`, `\|\|` | 返回原值（非布尔） |

**`==` 的类型转换规则**：
```
ToPrimitive(A) == ToPrimitive(B)
  → 若有一方是对象，调用 valueOf() 或 toString()
  → 若类型相同，比较值
  → null == undefined（特殊）
  → number vs string，string 转 number
  → boolean vs non-boolean，boolean 转 number
```

### Symbol 的本质

Symbol 是**唯一的、不可枚举的属性键**：
```javascript
const s1 = Symbol('desc');
const s2 = Symbol('desc');
s1 === s2  // false——即使描述相同，也是不同的 Symbol
```

Symbol 用于创建私有属性（外部无法通过 `for...in` 或 `Object.keys()` 枚举）。

### BigInt 的本质

BigInt 是 ES2020 引入的任意精度整数类型：
```javascript
const big = 123456789012345678901234567890n;
big + 1n  // 123456789012345678901234567891n
```

**约束**：BigInt 与 Number 混合运算是硬错误，必须显式转换。

### 类型守卫的本质

类型守卫是**运行时类型 narrowing**机制：

```javascript
function process(value) {
    if (typeof value === 'string') {
        // value 在此分支被 narrowing 为 string
    }
}
```

**narrowing 的数学本质**：在条件分支内，类型系统（静态 TypeScript）或引擎（动态 JS）将联合类型缩小为子类型。

## 参考存根

```javascript
// var 提升演示
console.log(hoisted);  // undefined（不是 ReferenceError）
var hoisted = 'hello';

// let TDZ 演示
// console.log(tdz);  // ReferenceError
let tdz = 'hello';

// 浮点精度问题
0.1 + 0.2 === 0.3  // false
Number.EPSILON      // 2^-52，可用于比较

// Symbol 唯一性
const s1 = Symbol('key');
const s2 = Symbol('key');
const obj = { [s1]: 'value1', [s2]: 'value2' };
Object.keys(obj).length  // 0——Symbol 属性不可枚举
```
