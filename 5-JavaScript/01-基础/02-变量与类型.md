# 变量与类型

JavaScript 的变量与类型系统经历了从 var 的函数作用域到 let/const 的块级作用域的演进。类型系统采用弱类型+动态类型组合，7种基本类型与对象类型构成了完整的类型层次。

## let / const / var

`var` 是函数作用域，存在变量提升（hoisting），同一函数内可重复声明。`let` 引入块级作用域和暂时性死区（TDZ），同一作用域内不可重复声明。`const` 具有 `let` 的全部特性，同时要求声明时初始化，且对绑定的引用不可变（但对象属性仍可修改）。

### 参考样例

```javascript
var name = 'Alice';          // 函数作用域
let age = 25;                // 块级作用域
const PI = 3.14159;          // 常量，不可重新赋值

// var 变量提升
console.log(hoisted);       // undefined（不是错误）
var hoisted = 'I am hoisted';

// let 暂时性死区
// console.log(tdz);         // ReferenceError
let tdz = 'temporal dead zone';
```

## 基本类型（7种）

JavaScript 的基本类型包括：`number`（整数、浮点、Infinity、NaN）、`string`、`boolean`、`null`（主动赋值，typeof 返回 'object' 是历史 bug）、`undefined`（未定义）、`symbol`（唯一标识）、`bigint`（大整数，超出 Number 安全范围时使用）。

## 对象类型

对象类型包括：`Object`（键值对集合）、`Array`（有序列表）、`Function`（函数对象）、以及 `Date`、`RegExp`、`Map`、`Set`、`WeakMap`、`WeakSet` 等内置对象。

## 类型判断

`typeof` 返回类型字符串，但 `typeof null === 'object'` 是历史 bug。`instanceof` 检查原型链。`Object.prototype.toString.call()` 可精确检测所有类型。`Array.isArray()` 是检查数组的标准方式。

### 参考样例

```javascript
typeof 123           // 'number'
typeof 'str'        // 'string'
typeof true         // 'boolean'
typeof undefined    // 'undefined'
typeof null         // 'object'（历史bug）
typeof {}            // 'object'
typeof []            // 'object'
typeof function(){}  // 'function'

// 精确判断
Object.prototype.toString.call(123)     // '[object Number]'
Object.prototype.toString.call([])       // '[object Array]'
Object.prototype.toString.call(null)    // '[object Null]'

// Array 检查
Array.isArray([])                       // true
[] instanceof Array                      // true
```

## 类型转换

### 强制类型转换

字符串转换：`String()`、`toString()`、`+ ''`。数字转换：`Number()`、`parseInt()`、`parseFloat()`、`+`。浮点精度问题（0.1 + 0.2 !== 0.3）需用整数运算或 decimal.js 解决。布尔转换：`Boolean()` 或 `!!`。

BigInt 转换：`BigInt()` 构造函数。

### 参考样例

```javascript
// 字符串转换
String(123)              // '123'
(123).toString()         // '123'
123 + ''                  // '123'

// 数字转换
Number('123')            // 123
parseInt('123px', 10)    // 123（解析整数）
parseFloat('3.14')        // 3.14
+'123'                    // 123（一元加号）

// 浮点精度问题
0.1 + 0.2                // 0.30000000000000004
// 解决方案：使用整数运算后除法，或使用 decimal.js

// 布尔转换
Boolean(1)               // true
Boolean('')              // false
Boolean('0')             // true
!!1                       // true（双重取反）

// BigInt 转换
BigInt(123)              // 123n
BigInt('123')            // 123n
```

### 隐式类型转换

字符串拼接时 `+` 将数字转为字符串。数学运算时 `-`、`*`、`/` 将字符串转为数字。逻辑运算时非空字符串为真，0、''、null 为假。相等性比较优先使用严格相等 `===`，避免宽松相等 `==` 的类型转换陷阱。

### 参考样例

```javascript
// 字符串拼接
'5' + 3                  // '53'（数字被转为字符串）

// 数学运算
'6' - 1                  // 5（字符串转为数字）
'6' * '2'                // 12

// 逻辑运算
!!'hello'               // true（非空字符串为真）
!!0                      // false
!!''                    // false
!!null                  // false

// 相等性比较
1 == '1'                 // true（宽松相等，类型转换）
1 === '1'               // false（严格相等，不转换）
```

## 类型守卫

类型守卫是在运行时检查类型、在条件分支中缩小变量类型范围的技术。常见形式包括 `typeof` 类型守卫、`instanceof` 类型守卫、`in` 类型守卫和自定义类型守卫函数。

### typeof 类型守卫

`typeof` 对基本类型的判断准确，可用于 string/number/boolean/function/undefined 的类型缩小。

### 参考样例

```javascript
function process(value) {
  if (typeof value === 'string') {
    // value 在这里被推断为 string
    return value.toUpperCase();
  }
  if (typeof value === 'number') {
    // value 在这里被推断为 number
    return value.toFixed(2);
  }
  // value 在这里是 unknown
}
```

### instanceof 类型守卫

`instanceof` 检查原型链，适用于类实例的类型判断。

### 参考样例

```javascript
class Dog {
  bark() { console.log('Woof!'); }
}

class Cat {
  meow() { console.log('Meow!'); }
}

function speak(animal) {
  if (animal instanceof Dog) {
    animal.bark();   // TypeScript 推断为 Dog
  }
  if (animal instanceof Cat) {
    animal.meow();  // TypeScript 推断为 Cat
  }
}
```

### in 类型守卫

`in` 操作符检查对象是否包含某属性，返回 true 时 TypeScript 可缩小类型范围。

### 参考样例

```javascript
function play(instrument) {
  if ('play' in instrument) {
    instrument.play();  // instrument 有 play 方法
  }
}
```

### 自定义类型守卫

返回布尔值的函数可用于类型检查，结合条件分支实现类型缩小。

### 参考样例

```javascript
// JavaScript 类型守卫函数
function isString(value) {
  return typeof value === 'string';
}

function isNumber(value) {
  return typeof value === 'number';
}

function isArray(value) {
  return Array.isArray(value);
}

// 使用类型守卫缩小类型范围
function process(value) {
  if (isString(value)) {
    console.log(value.toUpperCase());
  } else if (isNumber(value)) {
    console.log(value.toFixed(2));
  }
}
```
