# 类与模块

ES6 class 语法是原型继承的语法糖，本质上是构造函数+原型方法的组合。类不可提升（与函数声明不同），支持继承（extends）、super 调用、静态方法、私有字段（#前缀）。

## Class（类）

### 基本语法

class 声明定义构造函数与原型方法。constructor 是实例初始化方法。getter/setter 通过 get/set 关键字定义。static 关键字定义类方法而非实例方法。

### 参考样例

```javascript
// 类声明（不可提升）
class Person {
  // 构造函数
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }

  // 实例方法
  greet() {
    return `Hello, I am ${this.name}`;
  }

  // getter
  get info() {
    return `${this.name}, ${this.age} years old`;
  }

  // static 方法（类方法，非实例方法）
  static create(name, age) {
    return new Person(name, age);
  }
}

const p = new Person('Alice', 30);
p.greet();          // 'Hello, I am Alice'
Person.create('Bob', 25);  // static factory method
```

### 继承

extends 建立子类与父类的原型链。constructor 内必须先调用 super() 才能使用 this。方法重写时可通过 super.method() 调用父类实现。

### 参考样例

```javascript
class Animal {
  constructor(name) {
    this.name = name;
  }

  speak() {
    console.log(`${this.name} makes a noise`);
  }
}

class Dog extends Animal {
  constructor(name, breed) {
    super(name);  // 调用父类构造函数
    this.breed = breed;
  }

  // 重写父类方法
  speak() {
    super.speak();  // 调用父类方法
    console.log(`${this.name} barks`);
  }
}

const dog = new Dog('Rex', 'German Shepherd');
dog.speak();
// 'Rex makes a noise'
// 'Rex barks'
```

### 私有字段

ES2022 引入的 `#` 前缀私有字段，类外部无法访问。`in` 操作符可检测对象是否持有某私有字段。

### 参考样例

```javascript
class BankAccount {
  // 私有字段（#开头）
  #balance = 0;
  #id;

  constructor(id) {
    this.#id = id;
  }

  // 公开方法访问私有字段
  deposit(amount) {
    if (amount <= 0) throw new Error('Invalid amount');
    this.#balance += amount;
  }

  withdraw(amount) {
    if (amount > this.#balance) throw new Error('Insufficient funds');
    this.#balance -= amount;
  }

  getBalance() {
    return this.#balance;
  }
}

const account = new BankAccount('ACC001');
account.deposit(1000);
account.withdraw(300);
// account.#balance  // SyntaxError: Private field

// 私有字段检测
class MyClass {
  #privateField = 42;
  hasPrivateField() {
    return #privateField in this;
  }
}
```

### 静态字段

static 关键字定义的字段属于类本身而非实例，所有实例共享同一静态字段。

### 参考样例

```javascript
class Config {
  static DEFAULT_TIMEOUT = 5000;
  static MAX_RETRIES = 3;

  constructor(apiKey) {
    this.apiKey = apiKey;
  }
}

console.log(Config.DEFAULT_TIMEOUT);  // 5000
```
