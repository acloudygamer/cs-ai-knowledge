# 类与模块

ES6 class 语法是原型继承的语法糖：通过构造函数分配实例、通过原型链串联方法。class 声明在词法上被提升但受 TDZ 约束（声明前访问抛出 ReferenceError），这一点与函数声明不同。类支持继承（extends）、super 调用、静态方法、私有字段（#前缀）。

## Class（类）

### 本质

class 是构造函数的另一种写法。`new Person()` 的执行流程是：先以 Person 为构造函数创建空对象，再用该对象作为 this 调用 constructor。实例方法定义在 Person.prototype 上，属性定义在 constructor 内部。

### 类声明的提升

类声明在代码解析阶段被提升，但存在 TDZ（暂时性死区），在 `class` 声明语句执行前访问会抛出 ReferenceError。这与 `var` 声明函数不同——函数声明在声明前调用会返回 undefined 而非报错。

### 参考样例

```javascript
// TDZ：声明前访问类会抛出 ReferenceError
// const p = new Person('Bob'); // ReferenceError
class Person {
  constructor(name) {
    this.name = name;
  }
  greet() {
    return `Hello, ${this.name}`;
  }
}
const p = new Person('Alice');
```

### getter / setter / static

getter/setter 通过 `get`/`set` 关键字定义，在访问或赋值属性时拦截。static 关键字定义类方法而非实例方法，所有实例共享。

### 参考样例

```javascript
class Person {
  static create(name) { return new Person(name); }
  get info() { return `${this.name}`; }
}
```

## 继承（extends）

### 本质

`extends` 建立子类与父类的原型链：子类 prototype 的 `[[Prototype]]` 指向父类 prototype。`super()` 调用父类构造函数，将父类构造逻辑注入子类实例。

### 参考样例

```javascript
class Animal {
  constructor(name) { this.name = name; }
  speak() { return `${this.name} makes a noise`; }
}
class Dog extends Animal {
  constructor(name, breed) {
    super(name);
    this.breed = breed;
  }
  speak() { return super.speak() + ` and barks`; }
}
```

## 私有字段（#）

### 本质

`#` 前缀私有字段在编译阶段强制实施封装，类外部任何访问方式均抛出 SyntaxError。`in` 操作符可在外部检测对象是否持有某私有字段。

### 参考样例

```javascript
class BankAccount {
  #balance = 0;
  deposit(amount) {
    this.#balance += amount;
  }
}
```

## 模块

### 本质

ES6 module 是编译时静态分析的导出-导入契约。`import` 和 `export` 必须出现在模块顶层，不能在条件分支中动态导入。导入绑定是对模块导出值的只读引用（只读绑定 live binding）。

### 参考样例

```javascript
// lib.js
export const PI = 3.14;
export default function foo() {}

// main.js
import PI from './lib.js';
import { PI as pi } from './lib.js';
```

### 与 CommonJS 的差异

| 特性 | ESM | CommonJS |
|------|-----|----------|
| 加载方式 | 异步 | 同步 |
| 导入绑定 | 只读引用 | 值拷贝 |
| 顶层层级 | 模块级 | 函数级 |
| `this` | undefined | module.exports |
