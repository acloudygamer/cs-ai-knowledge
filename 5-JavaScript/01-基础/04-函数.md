# 函数

## 定义

JavaScript 函数是 **first-class object**（一等公民），可作为值传递、作为参数、作为返回值。函数有两种本质形态：**普通函数**通过 `function` 关键字声明，拥有独立的 `this` 绑定和 `arguments` 对象；**箭头函数**是 ES6 引入的词法 `this` 绑定语法，本质是 `function` 的语法糖，但 `this` 指向定义时外层作用域的 `this`。

## 数学模型

### 函数提升的数学描述

函数声明在词法分析阶段被提升，其值初始化为整个函数体：
$$
\forall f \in \text{function declarations}: \text{hoist}(f) = \lambda x.\text{body}(f)
$$

函数表达式的变量提升与 `var` 一致：
$$
\text{var } g = \text{function}(x) \{ \text{body} \}
$$
提升后 `g = undefined`，函数体在执行到赋值语句时才绑定。

### 闭包的数学模型

闭包是函数与其**词法环境**的组合：
$$
\text{closure}(f, E) = \lambda x. \text{body}(f) \text{ with free variables resolved in } E
$$

闭包捕获的变量是**引用绑定**（非值拷贝），这意味着：
```javascript
for (var i = 0; i < 3; i++) {
    setTimeout(() => console.log(i), 0);  // 输出 3, 3, 3
}
```

原因：`var i` 是函数作用域，闭包捕获的是 `i` 的引用，而非当时的值。循环结束后 `i = 3`，所有回调执行时读取的都是 `3`。

## 数据流

### 普通函数调用

<pre>
函数调用表达式
    │
    ▼
创建调用上下文（Execution Context）
    │
    ├──> 确定 this 绑定
    │
    ▼
参数求值（按顺序压入作用域）
    │
    ▼
执行函数体
    │
    ▼
返回值（若无可返回值，返回 undefined）
    │
    ▼
销毁调用上下文（保留闭包变量）
</pre>

### 箭头函数的词法 this 解析

<pre>
箭头函数定义
    │
    ▼
捕获外层作用域的 this（静态确定，不在调用时计算）
    │
    ▼
箭头函数对象创建
    │
    ▼
调用时：this 已经是确定的值，不再重新绑定
</pre>

## 机制

### 函数声明 vs 函数表达式的提升差异

| 类型 | 提升行为 | 提升后值 | 调用时机 |
|------|----------|----------|----------|
| 函数声明 | 完全提升（函数体整体） | 整个函数 | 声明前可调用 |
| 函数表达式 | 变量提升（var） | undefined | 赋值后可用 |
| 箭头函数表达式 | 随变量提升 | undefined | 赋值后可用 |

### 闭包的内存模型

闭包的本质是**堆上分配的函数对象 + 词法环境记录**：
- 普通函数：栈上创建，函数结束时栈帧销毁
- 闭包函数：堆上分配，即使外层函数返回，闭包仍持有对词法环境的引用

**违反约束的后果**：闭包导致的内存泄漏：
```javascript
function leaky() {
    const large = new Array(1000000);
    const big = new Array(1000000);
    return () => large;  // 只引用 large，但 big 无法被 GC
}
```

### this 绑定的四种模式

| 模式 | this 指向 | 示例 |
|------|-----------|------|
| 默认绑定 | 全局对象（严格模式为 undefined） | `fn()` |
| 隐式绑定 | 调用者对象 | `obj.method()` |
| 显式绑定 | bind/call/apply 第一个参数 | `fn.call(obj)` |
| new 绑定 | 新创建的对象 | `new Fn()` |

**箭头函数的 this 不可被修改**：箭头函数的 this 是词法绑定，`call()`/`bind()`/`apply()` 无法改变。

### bind 的实现原理

`Function.prototype.bind` 的简化实现：
```javascript
Function.prototype.bind = function(thisArg, ...fixedArgs) {
    const fn = this;
    return function(...args) {
        return fn.apply(thisArg, [...fixedArgs, ...args]);
    };
};
```

## 参考存根

```javascript
// 闭包计数器
function createCounter() {
    let count = 0;  // 私有变量
    return () => ++count;
}
const counter = createCounter();
console.log(counter());  // 1
console.log(counter());  // 2

// var 循环问题与 let 解决
for (var i = 0; i < 3; i++) {
    setTimeout(() => console.log(i), 0);  // 3, 3, 3
}
for (let j = 0; j < 3; j++) {
    setTimeout(() => console.log(j), 0);  // 0, 1, 2（let 块级作用域）
}

// this 绑定演示
const obj = {
    name: 'Alice',
    regular() { return this.name; },
    arrow: () => this.name  // this === 全局（不是 obj）
};
```
