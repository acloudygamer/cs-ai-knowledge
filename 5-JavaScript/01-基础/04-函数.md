# 函数

## 定义

JavaScript 函数是 **first-class object**（一等公民），可作为值传递、作为参数、作为返回值。函数有两种本质形态：**普通函数**通过 `function` 关键字声明，拥有独立的 `this` 绑定和 `arguments` 对象；**箭头函数**是 ES6 引入的词法 `this` 绑定语法，本质是 `function` 的语法糖，但 `this` 指向定义时外层作用域的 `this`。

## 数学模型

### 函数声明提升的数学描述

函数声明在词法分析阶段被提升，其值初始化为整个函数体：
$$
\forall f \in \text{function declarations}: \quad \text{hoist}(f) = \lambda x.\text{body}(f)
$$

函数表达式的变量提升与 `var` 一致：
$$
\text{var } g = \text{function}(x) \{ \text{body} \}
$$
提升后 $g = \text{undefined}$，函数体在执行到赋值语句时才绑定。

### 闭包的数学模型

闭包是函数与其**词法环境**的组合：
$$
\text{closure}(f, E) = \lambda x. \text{body}(f) \quad \text{with free variables resolved in } E
$$

闭包捕获的变量是**引用绑定**（非值拷贝）：
```javascript
for (var i = 0; i < 3; i++) {
    setTimeout(() => console.log(i), 0);  // 输出 3, 3, 3
}
```

原因：`var i` 是函数作用域，闭包捕获的是 `i` 的引用，而非当时的值。循环结束后 $i = 3$，所有回调执行时读取的都是 `3`。

### this 绑定的四象限模型

| 模式 | 条件 | this 指向 |
|------|------|----------|
| 默认绑定 | 严格模式 `fn()` | undefined |
| 隐式绑定 | `obj.method()` | obj |
| 显式绑定 | `fn.call(obj)` / `fn.apply(obj)` / `fn.bind(obj)()` | 第一个参数 |
| new 绑定 | `new Fn()` | 新创建的对象 |

## 数据流

### 普通函数调用

<pre>
函数调用表达式 func(args)
    │
    ▼
创建调用上下文（Execution Context）
    │
    ├──> 确定 this 绑定（根据调用方式）
    │
    ├──> 创建词法环境（作用域链）
    │
    ▼
参数求值（按顺序压入作用域）
    │
    ▼
执行函数体
    │
    ▼
返回值（若无可返回值，返回 undefined）
    │
    ▼
销毁调用上下文（保留闭包变量）
</pre>

### 箭头函数的词法 this 解析

<pre>
箭头函数定义
    │
    ▼
捕获外层作用域的 this（静态确定，不在调用时计算）
    │
    ▼
箭头函数对象创建（[[ThisMode]]: lexical）
    │
    ▼
调用时：this 已经是确定的值，不再重新绑定
</pre>

## 机制

### 函数声明 vs 函数表达式的提升差异

| 类型 | 提升行为 | 提升后值 | 调用时机 |
|------|----------|----------|----------|
| 函数声明 | 完全提升（函数体整体） | 整个函数 | 声明前可调用 |
| 函数表达式 | 变量提升（var） | undefined | 赋值后可用 |
| 箭头函数表达式 | 随变量提升 | undefined | 赋值后可用 |

**函数声明为何可以提升**：这是 JavaScript 的历史特性，函数声明被视为类似于 `var fn = function() {...}` 的两阶段操作，但在解析时就完成了赋值。

### 闭包的内存模型

闭包的本质是**堆上分配的函数对象 + 词法环境记录**：
- 普通函数：栈上创建，函数结束时栈帧销毁
- 闭包函数：堆上分配，即使外层函数返回，闭包仍持有对词法环境的引用

**闭包导致内存泄漏的本质**：
```javascript
function leaky() {
    const large = new Array(1000000);
    const big = new Array(1000000);
    return () => large;  // 只引用 large，但 big 无法被 GC
}
```
原因：闭包捕获整个词法环境，而非单个变量。只要闭包存在，整个环境都保留。

### 箭头函数的 this 不可变性

箭头函数的 `this` 是**词法绑定**，`call()`/`bind()`/`apply()` 无法改变：
```javascript
const obj = {
    value: 42,
    arrow: () => this.value,  // this === 全局对象（不是 obj）
    regular() { return this.value; }
};
```

**为什么箭头函数不能 new**：箭头函数没有 `[[Construct]]` 内部方法，不能作为构造函数。

### bind 的实现原理

`Function.prototype.bind` 返回一个新函数，其 `this` 被绑定到指定值：
```javascript
Function.prototype.bind = function(thisArg, ...fixedArgs) {
    const fn = this;  // 保存原函数
    return function(...args) {
        // 合并固定参数和新参数
        return fn.apply(thisArg, [...fixedArgs, ...args]);
    };
};
```

### arguments 对象的本质

`arguments` 是类数组对象，存储所有传入的参数：
- 在箭头函数中，`arguments` 指向外层函数的 `arguments`
- ES6+ 推荐使用 rest 参数 `...args` 替代

## 参考存根

```javascript
// 闭包计数器（私有变量）
function createCounter() {
    let count = 0;  // 私有变量，闭包持有引用
    return () => ++count;
}
const counter = createCounter();
console.log(counter());  // 1
console.log(counter());  // 2

// var 循环问题与 let 解决
for (var i = 0; i < 3; i++) {
    setTimeout(() => console.log(i), 0);  // 3, 3, 3
    // 原因：var 是函数作用域，所有回调共享同一个 i
}
for (let j = 0; j < 3; j++) {
    setTimeout(() => console.log(j), 0);  // 0, 1, 2
    // 原因：let 是块级作用域，每次循环创建新 j
}

// this 绑定演示
const obj = {
    name: 'Alice',
    regular() { return this.name; },
    arrow: () => this.name
};
console.log(obj.regular());  // 'Alice'（隐式绑定）
const fn = obj.regular;
console.log(fn());          // undefined（默认绑定，严格模式）
console.log(fn.call(obj));  // 'Alice'（显式绑定）

// bind 柯里化
function add(a, b) { return a + b; }
const add10 = add.bind(null, 10);
console.log(add10(5));  // 15
```
