# 函数

JavaScript 函数是 first-class object，可作为参数、返回值、赋值给变量。函数声明在 var 作用域内提升，但函数表达式不提升。箭头函数是 ES6 引入的词法 this 绑定语法，与普通函数在 this 绑定、arguments、super、new.target 方面存在本质差异。

## 函数声明 / 函数表达式 / 箭头函数

函数声明是独立的语句，可提升；函数表达式作为赋值表达式的一部分，不提升；箭头函数是匿名函数表达式，this 指向定义时外层上下文。

### 参考样例

```javascript
// 函数声明（可提升）
function greet(name) {
  return `Hello, ${name}`;
}

// 函数表达式（不可提升）
const greet = function(name) {
  return `Hello, ${name}`;
};

// 箭头函数
const greet = (name) => `Hello, ${name}`;

// 多行箭头函数需要 return
const add = (a, b) => {
  const sum = a + b;
  return sum;
};
```

## 默认参数 / rest参数

默认参数在调用时未传值或传 undefined 时使用默认值。rest 参数（`...`）将剩余参数收集为数组。展开运算符 `...` 可展开数组或对象。

### 参考样例

```javascript
// 默认参数
function greet(name = 'World') {
  return `Hello, ${name}`;
}

// rest参数（收集剩余参数为数组）
function sum(...numbers) {
  return numbers.reduce((a, b) => a + b, 0);
}
sum(1, 2, 3, 4);  // 10

// 展开运算符
const arr1 = [1, 2, 3];
const arr2 = [...arr1, 4, 5];  // [1, 2, 3, 4, 5]
```

## 闭包

闭包是函数与其词法作用域外部变量的组合。函数能访问其创建时所在的词法作用域中的变量，即使该函数在作用域外部执行。经典面试题中 var 的函数作用域导致循环中 setTimeout 引用同一变量，而 let 的块级作用域为每次迭代创建独立绑定。

### 参考样例

```javascript
// 闭包：函数能访问其词法作用域外部的变量
function createCounter() {
  let count = 0;  // 私有变量
  return function() {
    count++;
    return count;
  };
}

const counter = createCounter();
console.log(counter());  // 1
console.log(counter());  // 2
console.log(counter());  // 3

// 经典面试题
for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 100);  // 输出 3, 3, 3（var 是函数作用域）
}

// 解决：使用 let（块级作用域）或闭包
for (let i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 100);  // 输出 0, 1, 2
}
```

## this 绑定

普通函数的 this 在运行时动态绑定，指向调用者对象。箭头函数的 this 在定义时静态绑定，指向外层词法作用域的 this。`bind()` 可硬绑定 this，`call()`/`apply()` 可临时绑定。

### 参考样例

```javascript
const obj = {
  name: 'Alice',
  // 普通函数：this 指向 obj
  greet: function() {
    return `Hello, ${this.name}`;
  },
  // 箭头函数：this 指向外层（全局）
  greetArrow: () => {
    return `Hello, ${this.name}`;  // this !== obj
  }
};

// 手动绑定 this
const boundGreet = obj.greet.bind(obj);
boundGreet();  // 'Hello, Alice'

// 构造函数
function Person(name) {
  this.name = name;
}
const p = new Person('Bob');  // this 指向新对象
```
