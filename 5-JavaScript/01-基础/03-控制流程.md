# 控制流程

## 定义

控制流程是程序执行路径的描述机制。JavaScript 提供**条件分支**（if/else、switch）、**循环**（for、while、do-while）、**迭代**（for...of、for...in）三种基本结构。这些结构的本质是**状态机的条件转移**，由跳转指令或循环计数器控制执行流。

## 数学模型

### for 循环的执行次数建模

```javascript
for (init; condition; update) { body }
```

执行次数 $N$ 由 condition 决定：
$$
N = \min\{n \in \mathbb{N} \mid \text{condition}(\text{init} + n \cdot \Delta_{\text{update}}) = \text{false}\}
$$

其中 $\Delta_{\text{update}}$ 是 update 的增量。若 condition 永为 true，则 $N = \infty$（死循环）。

### for...of 的迭代协议

迭代器的本质是有限状态自动机：
$$
M = (Q, \Sigma, \delta, q_0, F)
$$
- $Q$：状态集 $\{ \text{active}, \text{exhausted} \}$
- $\Sigma$：输入（next() 调用）
- $\delta$：状态转移
- $q_0$：初始状态
- $F$：终结状态集 $\{\text{exhausted}\}$

迭代终止条件：
$$
\text{done} = \begin{cases}
\text{true} & \text{当所有元素已产出} \\
\text{false} & \text{当仍有元素未产出}
\end{cases}
$$

## 数据流

### if/else 的条件求值

<pre>
condition 表达式
    │
    ▼
求值结果（truthy/falsy）
    │
    ├── true ──→ if 分支执行
    │
    └── false ──→ else if / else 分支执行
</pre>

**falsy 值**：`false`, `0`, `''`, `null`, `undefined`, `NaN`
**truthy 值**：除 falsy 外的所有值，包括 `[]`, `{}`, `'0'`

### for...of 的迭代消费

<pre>
可迭代对象 (Array/Map/Set/String/NodeList/...)
    │
    ▼
调用 Symbol.iterator → 迭代器对象
    │
    ▼
迭代器.next() → { value, done }
    │
    ├── done=false ──→ body 执行，使用 value
    │
    └── done=true ──→ 迭代终止
</pre>

### switch 的跳转表

<pre>
switch (expr)
    │
    ▼
求值 expr
    │
    ▼
查找匹配 case（严格相等 ===）
    │
    ├── 匹配成功 ──→ 执行 case 后的语句
    │
    │               (若无 break，继续执行下一个 case)
    │
    └── 无匹配 ──→ 执行 default（若有）
</pre>

## 机制

### if/else vs switch 的本质差异

| 维度 | if/else | switch |
|------|---------|--------|
| 比较方式 | 任意布尔表达式 | 严格相等 `===` |
| 短路行为 | 条件求值短路 | 隐式贯穿（fall-through） |
| 适用场景 | 范围判断、多条件组合 | 离散值匹配 |
| 求值次数 | 最坏情况需判断所有条件 | 一次查找 |

**switch 的 fall-through 本质**：switch 语句没有隐式的 break 时，执行会**继续进入下一个 case**。这是 C 语言的特性，JavaScript 继承之。这既是特性也是 bug 源。

### for vs while vs do-while 的执行模型

| 结构 | 条件判定时机 | 最小执行次数 |
|------|--------------|--------------|
| for | 循环入口前 | 0（条件不满足则不执行） |
| while | 循环入口前 | 0（条件不满足则不执行） |
| do-while | 循环出口后 | 1（保证至少执行一次） |

**do-while 保证至少执行一次**：适合先执行后判断的场景（如用户输入验证）。

### for...in 的 enumerable 语义

`for...in` 遍历对象的**所有可枚举属性**（含继承属性），返回属性键（string）而非值：
```javascript
const arr = ['a', 'b', 'c'];
arr.customProp = 'd';
for (const key in arr) {
    console.log(key);  // '0', '1', '2', 'customProp'
}
```

**数组使用 `for...in` 是误用**——索引是字符串而非数字，且会遍历自定义属性。应使用 `for...of`。

### for...of 的 value 语义

`for...of` 调用对象的 `Symbol.iterator`，获取迭代器，逐个产出值：
```javascript
const arr = [10, 20, 30];
for (const val of arr) {
    console.log(val);  // 10, 20, 30
}
```

**内置可迭代对象**：Array, String, Map, Set, NodeList, DOMTokenList, arguments, 生成器。

## 对比参照

| 迭代方式 | 遍历目标 | 返回值类型 | 继承属性 | 迭代协议 |
|----------|----------|------------|----------|----------|
| for...in | 对象 | 属性键（string） | 含 | 无 |
| for...of | 可迭代对象 | 元素值 | 不含 | Iterator Protocol |
| forEach | 数组 | undefined | 不含 | 无（回调） |

## 参考存根

```javascript
// switch fall-through（需显式 break）
switch (type) {
    case 'A':
        handleA();
        break;
    case 'B':
        handleA();  // 故意贯穿，A 和 B 共用逻辑
    case 'C':
        handleAC();  // A、B、C 共用
        break;
    default:
        handleDefault();
}

// for...of 迭代 Map
const map = new Map([['a', 1], ['b', 2]]);
for (const [key, value] of map) {
    console.log(key, value);  // a 1, b 2
}

// for...in vs for...of
const arr = [1, 2, 3];
for (const i in arr) { console.log(typeof i); }  // string: '0', '1', '2'
for (const v of arr) { console.log(typeof v); }  // number: 1, 2, 3

// while vs do-while
let count = 5;
while (count < 5) {
    console.log('while:', count);  // 不执行
}
do {
    console.log('do-while:', count);  // 执行一次
} while (count < 5);
```
