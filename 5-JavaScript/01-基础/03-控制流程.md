# 控制流程

## 定义

控制流程是程序执行路径的描述机制。JavaScript 提供**条件分支**（if/else、switch）、**循环**（for、while、do-while）、**迭代**（for...of、for...in）三种基本结构。这些结构的本质是**状态机的条件转移**，由跳转指令或循环计数器控制执行流。

## 数学模型

### for 循环的执行次数建模

```javascript
for (init; condition; update) { body }
```

执行次数 $N$ 由 condition 决定：
$$
N = \min\{n \mid \text{condition}(init + n \cdot update) = \text{false}\}
$$

若 condition 永为 true，则 $N = \infty$（死循环）。

### for...of 的迭代协议

迭代器的本质是状态机：
$$
\text{next}(): \{value: T, done: bool\}
$$

迭代终止条件：
$$
\text{done} = \begin{cases}
\text{true} & \text{当所有元素已产出} \\
\text{false} & \text{当仍有元素未产出}
\end{cases}
$$

## 数据流

### if/else 的条件求值

<pre>
condition 表达式
    │
    ▼
求值结果（truthy/falsy）
    │
    ├── true ──→ if 分支执行
    │
    └── false ──→ else if / else 分支执行
</pre>

### for...of 的迭代消费

<pre>
可迭代对象 (Array/Map/Set/String)
    │
    ▼
调用 Symbol.iterator → 迭代器
    │
    ▼
迭代器.next() → { value, done }
    │
    ├── done=false ──→ body 执行，使用 value
    │
    └── done=true ──→ 迭代终止
</pre>

## 机制

### if/else vs switch 的本质差异

| 维度 | if/else | switch |
|------|---------|--------|
| 比较方式 | 任意布尔表达式 | 严格相等 `===` |
| 短路行为 | 条件求值短路 | 隐式贯穿（fall-through） |
| 适用场景 | 范围判断、多条件组合 | 离散值匹配 |

**switch 的 fall-through 本质**：switch 语句没有隐式的 break 时，执行会**继续进入下一个 case**，这既是特性也是 bug 源。

### for vs while vs do-while 的执行模型

| 结构 | 何时判定条件 | 最小执行次数 |
|------|--------------|--------------|
| for | 循环前 | 0 |
| while | 循环前 | 0 |
| do-while | 循环后 | 1 |

**do-while 保证至少执行一次**：条件判定在循环体之后，适合先执行后判断的场景（如用户输入验证）。

### for...in 的 enumerable 语义

`for...in` 遍历对象的**所有可枚举属性**（含继承属性），返回属性键而非值：
```javascript
const arr = ['a', 'b', 'c'];
arr.customProp = 'd';
for (const key in arr) {
    console.log(key);  // '0', '1', '2', 'customProp'
}
```

数组使用 `for...in` 是**误用**——应使用 `for...of`。

### for...of 的 value 语义

`for...of` 调用对象的 `Symbol.iterator`，获取迭代器，逐个产出值：
```javascript
const arr = [10, 20, 30];
for (const val of arr) {
    console.log(val);  // 10, 20, 30
}
```

## 对比参照

| 迭代方式 | 遍历目标 | 返回值类型 | 继承属性 |
|----------|----------|------------|----------|
| for...in | 对象 | 属性键（string） | 含 |
| for...of | 可迭代对象 | 元素值 | 不含 |
| forEach | 数组 | undefined | 不含（回调） |

## 参考存根

```javascript
// switch fall-through（需显式 break）
switch (type) {
    case 'A':
        handleA();
        break;
    case 'B':
        handleA();  // 故意贯穿
    case 'C':
        handleAC();  // A 和 C 共用
        break;
    default:
        handleDefault();
}

// for...of 迭代 Map
const map = new Map([['a', 1], ['b', 2]]);
for (const [key, value] of map) {
    console.log(key, value);
}

// for...in vs for...of
const arr = [1, 2, 3];
for (const i in arr) { console.log(i); }     // '0', '1', '2'（字符串索引）
for (const v of arr) { console.log(v); }     // 1, 2, 3（实际值）
```
