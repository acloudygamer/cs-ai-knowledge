# ES2023 到 ES2026 新特性

## ES2023 新特性

### Array findLast / findLastIndex

```javascript
const users = [
  { name: 'Alice', active: true },
  { name: 'Bob', active: false },
  { name: 'Charlie', active: true }
];

// findLast：从后往前查找
users.findLast(u => u.active);  // { name: 'Charlie', active: true }

// findLastIndex：返回索引
users.findLastIndex(u => u.active);  // 2
users.findLastIndex(u => u.name === 'Bob');  // 1
```

### Array toSorted / toReversed / toSpliced

```javascript
const arr = [3, 1, 4, 1, 5];

// toSorted：返回排序后的新数组（不修改原数组）
arr.toSorted();  // [1, 1, 3, 4, 5]
arr;  // [3, 1, 4, 1, 5]（原数组不变）

// toReversed：返回反转后的新数组
arr.toReversed();  // [5, 1, 4, 1, 3]

// toSpliced：返回替换后的新数组
arr.toSpliced(1, 2, 9, 8);  // [3, 9, 8, 5]
```

### Hashbang 语法

```javascript
#!/usr/bin/env node
// 将被当作单行注释解析，无视后面的路径
// 这是 ES2023 标准化之前就存在的非官方特性

console.log('Hello');
```

### Symbol.prototype.description

```javascript
const sym = Symbol('my description');

sym.description;  // 'my description'
Symbol.prototype.description;  // Symbol.prototype 的 description 为 undefined
```

## ES2024 新特性

### Array grouping（正式加入）

```javascript
const inventory = [
  { name: 'asparagus', type: 'vegetables' },
  { name: 'bananas', type: 'fruit' },
  { name: 'goat', type: 'meat' },
  { name: 'cabbage', type: 'vegetables' }
];

// Object.groupBy
const grouped = Object.groupBy(inventory, item => item.type);
// {
//   vegetables: [{ name: 'asparagus', ... }, { name: 'cabbage', ... }],
//   fruit: [{ name: 'bananas', ... }],
//   meat: [{ name: 'goat', ... }]
// }

// Map.groupBy
const groupedMap = Map.groupBy(inventory, item => item.type);
// Map { 'vegetables' => [...], 'fruit' => [...], 'meat' => [...] }
```

### Promise.withResolvers

```javascript
// 更简洁的 Promise 创建方式
function fetchWithTimeout(url, timeout) {
  const controller = new AbortController();
  const timeoutId = setTimeout(() => controller.abort(), timeout);

  const promise = fetch(url, { signal: controller.signal })
    .finally(() => clearTimeout(timeoutId));

  return { promise, signal: controller.signal };
}

// 或者手动控制 resolve/reject
function delay(ms) {
  const { promise, resolve, reject } = Promise.withResolvers();

  setTimeout(resolve, ms);
  return promise;
}
```

### 管道操作符（Pipeline Operator）- Stage 2

```javascript
// |> 管道操作符（尚未完全标准化，部分环境可用）

// 当前写法
const result = Math.sqrt(Math.pow(x, 2) + Math.pow(y, 2));

// 使用管道操作符（需要实验性支持）
const result = x
  |> (x => Math.pow(x, 2))
  |> (x => Math.pow(_, 2) + Math.pow(y, 2))
  |> Math.sqrt;

// 或使用占位符
const result = x
  |> Math.pow(_, 2)
  |> (_ => _ + Math.pow(y, 2))
  |> Math.sqrt;
```

### 导入属性（Import Attributes）

```javascript
// 静态导入属性
import jsonData from './data.json' with { type: 'json' };
import wasm from './module.wasm' with { type: 'webassembly' };

// 动态导入属性
const module = await import('./module.js', {
  with: { type: 'module' }
});
```

### 便捷的正则表达式标志

```javascript
// v 标志：Unicode 字符类
/\p{Emoji}/v.test('😀');  // true

// 区分大小写的 Unicode 属性转义
/\p{Script=Hiragana}+/u.test('ひらがな');  // true

// --dotAll 标志让 . 匹配换行符
const multiline = /abc.*def/s.test('abc\ndef');  // true
```

### ArrayBuffer Transfer

```javascript
// 可转移的 ArrayBuffer
const buffer = new ArrayBuffer(8);

const transferred = buffer.transfer();
// buffer 已被清空，无法再使用
// transferred 是一个新的 ArrayBuffer，内容相同
```

## ES2026 新特性（Node26+）

### 装饰器（Decorators）- 正式加入

```javascript
// 装饰器在 ES2026 正式加入标准
// Node.js 26+ 原生支持

@sealed
class BugReport {
  @readonly
  title = 'Untitled';

  @logging
  print() {
    console.log(this.title);
  }
}

function sealed(constructor) {
  Object.seal(constructor);
  Object.seal(constructor.prototype);
}

function readonly(target, name, descriptor) {
  descriptor.writable = false;
  return descriptor;
}

function logging(target, name, descriptor) {
  const original = descriptor.value;
  descriptor.value = function(...args) {
    console.log(`Calling ${name}`);
    return original.apply(this, args);
  };
  return descriptor;
}
```

### 管道操作符 - 正式加入

```javascript
// 管道操作符在 ES2026 正式加入
// 使用占位符 _ 表示前一个值

const result = value
  |> transform1
  |> (x => transform2(x, extraArg))
  |> obj.method
  |> await asyncOp
  |> (x => x.toUpperCase());
```

### String.dedent（Stage 2）

```javascript
// 模板字符串去缩进（Stage 2）
const html = String.dedent`
  <div>
    <p>Hello</p>
  </div>
`;
// '<div>\n  <p>Hello</p>\n</div>'
```

## 兼容性检查

```javascript
// 检查是否支持某个特性
const supportsFindLast = typeof Array.prototype.findLast === 'function';
const supportsGroupBy = typeof Object.groupBy === 'function';
const supportsPipeline = (1 |> (x => x + 1)) === 2;
const supportsDecorators = (() => {
  try {
    eval('class C { @(() => {}) m() {} }');
    return true;
  } catch {
    return false;
  }
})();

// 使用 @pika/pack 或 esm.sh 获取兼容包
// 或使用 core-js 填充
import 'core-js/actual/array/group-by';
```
