# 异步编程基础

JavaScript 是单线程语言，通过事件循环（Event Loop）实现非阻塞异步操作。调用栈（Call Stack）执行同步代码，任务队列（Task Queue）存放待执行的异步回调，微任务队列（Microtask Queue）优先于宏任务执行。

## 同步与异步

同步执行阻塞后续代码，异步执行不等待结果就继续后续代码。异步操作完成后通过回调、Promise 或 async/await 通知结果。

### 参考样例

```javascript
console.log('1');
console.log('2');
console.log('3');
// 输出顺序：1, 2, 3（同步阻塞）
```

```javascript
console.log('1');
setTimeout(() => console.log('2'), 0);
console.log('3');
// 输出顺序：1, 3, 2（异步非阻塞）
```

## 回调函数

回调是异步编程的基础模式。嵌套回调导致回调地狱，代码深度增加且错误处理困难。

### 参考样例

```javascript
// 基础回调
setTimeout(() => {
  console.log('Delayed');
}, 1000);

// 嵌套回调（回调地狱）
fetchUser(userId, (err, user) => {
  if (err) return handleError(err);
  fetchPosts(user.id, (err, posts) => {
    if (err) return handleError(err);
    fetchComments(posts[0].id, (err, comments) => {
      if (err) return handleError(err);
      displayComments(comments);
    });
  });
});
```

## Promise

Promise 是 ES6 引入的异步编程解决方案，代表未来某个时刻会完成的操作。状态机：pending → fulfilled 或 pending → rejected。链式调用避免回调嵌套。

### 创建 Promise

Promise 构造函数接收执行器函数，传入 resolve 和 reject 两个回调。

### 参考样例

```javascript
// 基本创建
const promise = new Promise((resolve, reject) => {
  // 异步操作
  setTimeout(() => {
    const success = true;
    if (success) {
      resolve('Result data');
    } else {
      reject(new Error('Failed reason'));
    }
  }, 1000);
});

// 使用
promise
  .then(data => console.log(data))
  .catch(err => console.error(err))
  .finally(() => console.log('Completed'));
```

### Promise 静态方法

`Promise.all` 全部成功才成功，一个失败则整体失败。`Promise.allSettled` 全部完成才返回，不抛出一失败就中断。`Promise.race` 返回最快完成的结果。`Promise.any` 返回最快成功的结果，全部失败才失败。

### 参考样例

```javascript
// Promise.all - 所有都成功才成功，一个失败则整体失败
const [users, posts] = await Promise.all([
  fetch('/api/users').then(r => r.json()),
  fetch('/api/posts').then(r => r.json())
]);

// Promise.allSettled - 全部完成，不管成功失败
const results = await Promise.allSettled([
  fetch('/api/users'),
  fetch('/api/posts')
]);

results.forEach((result, index) => {
  if (result.status === 'fulfilled') {
    console.log(`Request ${index} succeeded:`, result.value);
  } else {
    console.log(`Request ${index} failed:`, result.reason);
  }
});

// Promise.race - 返回最快完成的结果
const result = await Promise.race([
  fetch('/api/fast').then(r => r.json()),
  new Promise((_, reject) =>
    setTimeout(() => reject(new Error('Timeout')), 5000)
  )
]);

// Promise.any - 返回最快成功的结果，全部失败才失败
const result = await Promise.any([
  fetch('/api/primary'),
  fetch('/api/backup')
]);
```

### Promise 链式调用

`.then()` 返回新的 Promise，支持链式调用。前一个 `.then()` 的返回值作为下一个的输入。

### 参考样例

```javascript
fetch('/api/user')
  .then(response => response.json())
  .then(user => fetch(`/api/posts/${user.id}`))
  .then(response => response.json())
  .then(posts => console.log(posts))
  .catch(err => console.error(err));
```

## async/await

async/await 是 ES2017 引入的 Promise 语法糖，让异步代码看起来像同步代码。async 函数自动返回 Promise。await 暂停函数执行，等待 Promise resolve。

### 基础用法

### 参考样例

```javascript
// async 函数自动返回 Promise
async function fetchUser(id) {
  const response = await fetch(`/api/users/${id}`);
  return await response.json();
}

// 调用
const user = await fetchUser(123);
console.log(user);

// 错误处理
async function fetchUserSafe(id) {
  try {
    const response = await fetch(`/api/users/${id}`);
    if (!response.ok) {
      throw new Error(`HTTP error: ${response.status}`);
    }
    return await response.json();
  } catch (error) {
    console.error('Failed to fetch user:', error);
    throw error;
  }
}
```

### async/await 并行

顺序 await 会阻塞，并行使用 `Promise.all` 可同时触发多个异步操作。

### 参考样例

```javascript
// 顺序执行（慢）
const user = await fetchUser(1);
const posts = await fetchPosts(1);

// 并行执行（快）
const [user, posts] = await Promise.all([
  fetchUser(1),
  fetchPosts(1)
]);
```

### 常见错误

忘记 await 会导致返回 Promise 而非实际数据。循环中顺序 await 应改为 `Promise.all` 并行。

### 参考样例

```javascript
// 错误：忘记 await
async function mistake() {
  const data = fetch('/api/data');  // 返回 Promise，不是数据
  console.log(data);  // Promise 对象
}

// 正确
async function correct() {
  const data = await fetch('/api/data');
  console.log(data);
}

// 错误：循环中顺序 await（应该并行）
async function wrongLoop(urls) {
  const results = [];
  for (const url of urls) {
    const data = await fetch(url);  // 每次都等待
    results.push(data);
  }
}

// 正确：循环中并行
async function correctLoop(urls) {
  const results = await Promise.all(
    urls.map(url => fetch(url))
  );
}

// 错误：try/catch 吞掉所有错误
async function swallow() {
  try {
    const data = await fetch('/api/data');
    return data;
  } catch (e) {
    // 静默失败，不知道发生了什么
  }
}
```

## 事件循环（Event Loop）

事件循环是 JavaScript 异步编程的核心机制。调用栈执行同步代码，异步操作完成后宏任务进入 Task Queue，微任务进入 Microtask Queue。当前调用栈清空后，优先执行全部微任务，再执行一个宏任务。

### 调用栈与任务队列

```javascript
console.log('1');

setTimeout(() => {
  console.log('2');
}, 0);

Promise.resolve().then(() => {
  console.log('3');
});

console.log('4');

// 输出：1, 4, 3, 2
// 原因：setTimeout 是宏任务，Promise.then 是微任务
// 微任务在当前调用栈完成后立即执行，优先于宏任务
```

### 宏任务与微任务

| 类型 | 示例 |
|------|------|
| 宏任务（Macro Task） | setTimeout, setInterval, I/O, UI rendering |
| 微任务（Micro Task） | Promise.then, MutationObserver, queueMicrotask |

### 执行顺序

```javascript
// 完整示例
console.log('1');                      // 同步

setTimeout(() => console.log('2'), 0); // 宏任务

Promise.resolve()
  .then(() => console.log('3'));       // 微任务

setTimeout(() => {
  console.log('4');                    // 宏任务
  Promise.resolve()
    .then(() => console.log('5'));     // 微任务（嵌套）
}, 0);

console.log('6');                      // 同步

// 输出：1, 6, 3, 2, 4, 5
```

### async/await 与事件循环

`await` 使函数暂停，等待 Promise resolve 后将后续代码作为微任务入队。

### 参考样例

```javascript
async function example() {
  console.log('1');

  await Promise.resolve();  // 暂停函数执行，让出线程
  console.log('2');

  setTimeout(() => console.log('3'), 0);

  await new Promise(resolve => setTimeout(resolve, 0));
  console.log('4');
}

example();
console.log('5');

// 输出：1, 5, 2, 3, 4
// 解释：
// 1. 同步代码立即执行：1, 5
// 2. await 让出线程，example 函数暂停
// 3. Promise.resolve().then 执行：2
// 4. setTimeout 回调加入宏任务队列：3
// 5. 第二个 setTimeout 到期，resolve 执行
// 6. console.log(4) 执行
```

## 常见异步模式

### 顺序执行

逐个等待任务完成，适合有依赖关系的任务链。

### 参考样例

```javascript
async function sequential(tasks) {
  const results = [];
  for (const task of tasks) {
    results.push(await task());
  }
  return results;
}
```

### 并行执行（全部成功）

使用 `Promise.all` 并行执行，全部成功才返回。

### 参考样例

```javascript
async function parallel(tasks) {
  return Promise.all(tasks.map(task => task()));
}
```

### 并行执行（容忍部分失败）

使用 `Promise.allSettled` 获取所有结果，包含成功和失败信息。

### 参考样例

```javascript
async function parallelSettled(tasks) {
  const results = await Promise.allSettled(tasks.map(task => task()));
  const succeeded = results
    .filter(r => r.status === 'fulfilled')
    .map(r => r.value);
  const failed = results
    .filter(r => r.status === 'rejected')
    .map(r => r.reason);
  return { succeeded, failed };
}
```

### 限流并发

限制同时执行的任务数量，避免资源耗尽。

### 参考样例

```javascript
async function limitedParallel(tasks, limit = 5) {
  const results = [];
  const executing = [];

  for (const task of tasks) {
    const promise = task().then(result => {
      results.push(result);
    });

    executing.push(promise);

    if (executing.length >= limit) {
      await Promise.race(executing);
      executing.splice(
        executing.findIndex(p => p === promise),
        1
      );
    }
  }

  return Promise.all(executing).then(() => results);
}
```

### 错误重试

指数退避策略重试失败操作。

### 参考样例

```javascript
async function retry(fn, maxAttempts = 3, delay = 1000) {
  for (let attempt = 1; attempt <= maxAttempts; attempt++) {
    try {
      return await fn();
    } catch (error) {
      if (attempt === maxAttempts) throw error;

      const backoff = delay * 2 ** (attempt - 1);
      await new Promise(r => setTimeout(r, backoff));
    }
  }
}

// 使用
const data = await retry(() => fetch('/api/data').then(r => r.json()));
```

## async/await 与 Promise 对比

| 场景 | async/await | Promise.then |
|------|-------------|--------------|
| 顺序依赖 | `await a(); await b();` | `a().then(() => b())` |
| 并行 | `await Promise.all([a(), b()])` | `Promise.all([a(), b()])` |
| 错误处理 | try/catch | .catch() |
| 调试 | 支持断点 | 链式难以调试 |
| 条件分支 | 清晰直观 | 需嵌套 .then |
| 返回值 | 直接返回 | 需在 .then 中处理 |

## 最佳实践

### 参考样例

```javascript
// 1. 优先使用 async/await
async function fetchData() {
  try {
    const response = await fetch('/api/data');
    const data = await response.json();
    return data;
  } catch (error) {
    console.error('Fetch failed:', error);
    throw error;
  }
}

// 2. 避免不必要的 await
async function process() {
  const [a, b] = await Promise.all([doA(), doB()]);  // 好：并行
  // 不要写成：
  // const a = await doA();
  // const b = await doB();  // 差：串行
}

// 3. 并行和顺序要分明
async function getDashboardData() {
  // 并行：这些数据互不依赖
  const [user, notifications, settings] = await Promise.all([
    fetchUser(),
    fetchNotifications(),
    fetchSettings()
  ]);

  // 顺序：这些需要前一步的结果
  const posts = await fetchPosts(user.id);
  const recommended = await fetchRecommended(posts[0].category);

  return { user, notifications, settings, posts, recommended };
}

// 4. 及时释放资源
async function processLargeFile(file) {
  const reader = file.stream().getReader();

  try {
    while (true) {
      const { done, value } = await reader.read();
      if (done) break;
      await processChunk(value);
    }
  } finally {
    reader.releaseLock();  // 确保释放
  }
}
```
