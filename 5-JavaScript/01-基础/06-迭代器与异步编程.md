# 迭代器与异步编程

迭代器是实现 `next()` 方法的状态机对象，通过 `{value, done}` 结构实现惰性求值；生成器是 `function*` 的暂停-恢复执行模型，yield 指令在当前位置挂起并传递值。异步编程基于事件循环的单线程调度模型：调用栈执行同步代码，微任务（Promise.then）优先于宏任务（setTimeout）执行。两者结合形成 Promise/async-await 的非阻塞异步模式。

---

## 迭代器协议

### 本质

迭代器对象通过 `next()` 方法控制状态，每次调用返回 `{ value: any, done: boolean }`。`done: true` 表示迭代结束。迭代器不包含数据源，状态由调用方维护——这与生成器的内联状态不同。

### 参考样例

```javascript
const iterator = {
  data: ['a', 'b'],
  index: 0,
  next() {
    if (this.index < this.data.length) {
      return { value: this.data[this.index++], done: false };
    }
    return { value: undefined, done: true };
  }
};
```

### 可迭代对象

对象实现 `Symbol.iterator` 方法返回迭代器即可迭代。内置可迭代对象：Array、String、Map、Set、arguments、NodeList。展开运算符和 `for...of` 消费可迭代对象。

### 参考样例

```javascript
const myCollection = {
  items: [1, 2, 3],
  [Symbol.iterator]() {
    let index = 0;
    return { next: () => index < this.items.length
      ? { value: this.items[index++], done: false }
      : { value: undefined, done: true } };
  }
};
```

## 生成器（function*）

### 本质

`function*` 定义生成器函数，调用返回迭代器而非执行函数体。每次 `next()` 从上一个 yield 位置执行到下一个 yield 或 return。`yield` 表达式本身的值由上一次 `next(value)` 传入决定。

### 参考样例

```javascript
function* numberGenerator() {
  yield 1; yield 2; yield 3;
}
const gen = numberGenerator();
gen.next();        // { value: 1, done: false }
gen.next('hello'); // { value: 2, done: false }
```

### yield* 委托

`yield*` 将控制委托给另一个可迭代对象，逐个产出其元素。

### 参考样例

```javascript
function* gen1() { yield 'a'; yield 'b'; }
function* gen2() { yield '1'; yield* gen1(); yield '2'; }
```

### 生成器方法

`return()` 提前终止，`throw()` 向生成器注入错误。

## 异步迭代器

### async 生成器

`async function*` 定义异步生成器，`next()` 返回 Promise。`for await...of` 在每次循环中等待 Promise resolve。

### 参考样例

```javascript
async function* fetchPages(urls) {
  for (const url of urls) {
    yield await fetch(url).then(r => r.json());
  }
}
```

## 事件循环

### 执行模型

<pre>
调用栈 → 清空 → 微任务队列（全部） → 宏任务队列（取一个）→ 循环
</pre>

调用栈执行同步代码。Promise.then/queueMicrotask 入微任务队列。setTimeout/setInterval 入宏任务队列。当前调用栈清空后，**全部**微任务先执行，再取**一个**宏任务执行，然后重复。

### 微任务与宏任务

| 类型 | 来源 |
|------|------|
| 微任务 | Promise.then, queueMicrotask, MutationObserver |
| 宏任务 | setTimeout, setInterval, I/O, UI rendering |

### 参考样例

```javascript
console.log('1');
setTimeout(() => console.log('2'), 0);
Promise.resolve().then(() => console.log('3'));
console.log('4');
// 输出：1, 4, 3, 2
```

## Promise

### 本质

Promise 是异步操作的状态容器：pending → fulfilled 或 pending → rejected。状态一旦迁移不可逆。`.then()` 返回新 Promise，支持链式调用避免回调嵌套。

### 参考样例

```javascript
new Promise((resolve, reject) => {
  setTimeout(() => resolve('data'), 100);
}).then(data => console.log(data));
```

### Promise 静态方法

`Promise.all`：全部成功才成功，一个失败整体失败。`Promise.allSettled`：全部完成才返回，不因单个失败中断。`Promise.race`：返回最快完成的结果。`Promise.any`：返回最快成功的结果，全部失败才失败。

### 参考样例

```javascript
await Promise.all([fetch('/api/users'), fetch('/api/posts')]);
await Promise.allSettled([fetch('/a'), fetch('/b')]);
```

## async/await

### 本质

async 函数自动返回 Promise。`await` 暂停当前 async 函数执行，等待 Promise resolve 后将后续代码作为微任务入队。`await` 本身不阻塞事件循环——它让出线程去执行其他任务。

### 参考样例

```javascript
async function fetchUser(id) {
  const res = await fetch(`/api/users/${id}`);
  return res.json();
}
```

### 常见错误

忘记 await 返回 Promise 而非数据。循环中顺序 await 应改为 `Promise.all` 并行。

```javascript
// 错误
const data = fetch('/api/data'); // Promise

// 正确
const data = await fetch('/api/data');
```

## 惰性求值与管道

### 生成器的暂停特性

生成器按需产生值，避免一次性加载全部数据到内存。多个生成器串联形成数据处理管道，实现惰性计算图。

### 参考样例

```javascript
function* map(iterable, fn) {
  for (const item of iterable) { yield fn(item); }
}
function* filter(iterable, fn) {
  for (const item of iterable) { if (fn(item)) yield item; }
}
const result = map(filter([1,2,3,4], n => n % 2 === 0), n => n * 2);
```

### 状态机

生成器的暂停-恢复特性天然适合实现状态机。

```javascript
function* toggle() {
  let state = 'off';
  while (true) {
    state = state === 'off' ? 'on' : 'off';
    yield state;
  }
}
```
