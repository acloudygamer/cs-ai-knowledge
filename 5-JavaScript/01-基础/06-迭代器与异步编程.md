# 迭代器与异步编程

## 定义

迭代器是实现 `next()` 方法的状态机对象，通过 `{value, done}` 结构实现惰性求值。生成器是 `function*` 的暂停-恢复执行模型，yield 指令在当前位置挂起并传递值。异步编程基于事件循环的单线程调度模型：调用栈执行同步代码，微任务（Promise.then）优先于宏任务（setTimeout）执行。

## 数学模型

### 迭代器的状态机模型

迭代器可建模为有限状态自动机：
$$
M = (Q, \Sigma, \delta, q_0, F)
$$
- $Q$：状态集（未结束、已结束）
- $\Sigma$：输入（next() 调用）
- $\delta$：状态转移函数
- $q_0$：初始状态
- $F$：终结状态集（done: true）

### 事件循环的执行优先级

令 $t$ 为任意时刻，事件循环的调度序列：
$$
\text{schedule}(t) = \begin{cases}
\text{微任务队列（全部）} & \text{调用栈为空时} \\
\text{一个宏任务} & \text{微任务队列清空后} \\
\text{渲染（浏览器）} & \text{宏任务之间（若需要）}
\end{cases}
$$

### Promise 的状态机

Promise 是有限状态机：
$$
\text{Promise} \in \{\text{pending}, \text{fulfilled}, \text{rejected}\}
$$
$$
\delta: \text{pending} \rightarrow \text{fulfilled} \mid \text{rejected}
$$
状态迁移**不可逆**（单向）。

## 数据流

### 迭代器的数据消费

<pre>
可迭代对象 [Symbol.iterator]()
    │
    ▼
返回迭代器（持有内部状态）
    │
    ▼
迭代器.next() → { value, done }
    │
    ├── done=false ──→ 消费 value
    │
    └── done=true ──→ 迭代结束
</pre>

### 生成器的暂停-恢复

<pre>
调用生成器函数
    │
    ▼
返回迭代器（未执行函数体）
    │
    ▼
迭代器.next() ──→ 执行到 yield，暂停
    │
    ▼
yield value 作为 { value, done: false }
    │
    ▼
下次 .next(arg) ──→ arg 作为 yield 表达式的值，恢复执行
</pre>

### 事件循环的完整调度

<pre>
┌─────────────────────────────────────────────────────┐
│  调用栈 (Call Stack)                                │
│  执行同步代码                                        │
└─────────────────────┬───────────────────────────────┘
                      │ 清空
                      ▼
┌─────────────────────────────────────────────────────┐
│  微任务队列 (Microtask Queue)                      │
│  Promise.then / queueMicrotask / MutationObserver  │
│  全部执行完再继续                                    │
└─────────────────────┬───────────────────────────────┘
                      │ 清空
                      ▼
┌─────────────────────────────────────────────────────┐
│  宏任务队列 (Macrotask Queue)                      │
│  setTimeout / setInterval / I/O / UI Rendering     │
│  每次取一个执行                                      │
└─────────────────────┬───────────────────────────────┘
                      │ 循环
                      └───────────────────────────────
</pre>

### async/await 的执行流程

<pre>
async 函数
    │
    ▼
自动包装为 Promise
    │
    ▼
await 表达式
    │
    ▼
暂停函数执行（不阻塞事件循环）
    │
    ▼
将后续代码注册为微任务
    │
    ▼
Promise resolve 后，微任务恢复执行
</pre>

## 机制

### 迭代器协议 vs 可迭代协议

| 协议 | 要求 | 消费者 |
|------|------|--------|
| 迭代器协议 | 实现 `next()` | `for...of`、`...` 展开 |
| 可迭代协议 | 实现 `Symbol.iterator` | `for...of`、`Array.from` |

### 生成器的暂停语义

`yield` 是**协程级别的让出**：
- `yield` 暂停生成器，将控制权返回给调用者
- `next(value)` 恢复执行，`value` 作为 `yield` 表达式的值

**关键约束**：生成器是**单线程协作**的，调用者必须显式调用 `.next()` 才能推进。

### Promise 的链式调用原理

`.then()` 返回**新 Promise**，而非同一个 Promise：
```javascript
p.then(f).then(g)
// 等价于：
new Promise((resolve, reject) => {
    p.then(
        v => resolve(f(v)),  // f 的返回值决定新 Promise 的状态
        reject
    );
}).then(g);
```

### async/await 的本质

`async function` 是**生成器 + Promise + 状态机**的语法糖：
```javascript
// 源代码
async function fetchData() {
    const data = await promise;
    return data;
}

// 简化翻译
function fetchData() {
    return new Promise((resolve, reject) => {
        // 初始执行
        try {
            const gen = function*() {
                const data = yield promise;
                return data;
            }();
            // 后续恢复执行逻辑...
        } catch (e) { reject(e); }
    });
}
```

### for await...of 的语义

`for await...of` 遍历**异步可迭代对象**：
```javascript
for await (const item of asyncIterator) {
    // 每次循环等待 Promise resolve
}
```

## 对比参照

| 异步模式 | 阻塞行为 | 错误处理 | 可组合性 |
|----------|----------|----------|----------|
| 回调 | 阻塞调用者线程 | 分散在每一层 | 嵌套（回调地狱） |
| Promise | 非阻塞（链式） | `.catch()` 集中 | `.then()` 链 |
| async/await | 非阻塞（同步写法） | try/catch | for/await 循环 |

## 参考存根

```javascript
// 自定义迭代器
function range(start, end) {
    return {
        [Symbol.iterator]() { return this; },
        next() {
            return start < end
                ? { value: start++, done: false }
                : { value: undefined, done: true };
        }
    };
}

// 生成器惰性求值
function* fibonacci() {
    let [a, b] = [0, 1];
    while (true) {
        yield a;
        [a, b] = [b, a + b];
    }
}

// Promise 链式调用
fetch('/api/user')
    .then(r => r.json())
    .then(user => fetch(`/api/posts/${user.id}`))
    .then(r => r.json())
    .catch(err => console.error(err));

// 事件循环演示
console.log('1');
setTimeout(() => console.log('3'), 0);
Promise.resolve().then(() => console.log('2'));
// 输出：1, 2, 3（微任务先于宏任务）
```
