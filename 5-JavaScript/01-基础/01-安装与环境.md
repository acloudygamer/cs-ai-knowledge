# 安装与环境

## Node.js / npm / npx / nvm

- **Node.js**: JavaScript 运行时，基于 V8 引擎，用于服务器端开发
- **npm**: 包管理器，`npm install <package>` 安装依赖
- **npx**: 运行包命令，`npx create-react-app` 直接执行包而无需全局安装
- **nvm**: Node 版本管理器，可以安装和切换多个 Node.js 版本

### nvm 安装和使用

```bash
# 安装 nvm（Linux/Mac）
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash

# Windows 安装 nvm-windows
# 下载: https://github.com/coreybutler/nvm-windows/releases

# 常用命令
nvm install 26           # 安装 Node.js 26
nvm install 28           # 安装 Node.js 28（最新 LTS）
nvm use 26               # 切换到 Node.js 26
nvm list                 # 列出已安装的版本
nvm alias default 28     # 设置默认版本
```

### npm 常用命令

```bash
# 初始化项目
npm init -y              # 创建 package.json
npm init -y --scope=@myorg  # 初始化组织包

# 安装依赖
npm install lodash        # 安装到 dependencies
npm install --save-dev jest  # 安装到 devDependencies
npm install -g typescript  # 全局安装

# 运行脚本
npm run dev              # 运行 dev 脚本
npm run build            # 运行 build 脚本

# 包管理
npm list                 # 查看已安装的包
npm outdated             # 查看有更新的包
npm update               # 更新所有包
npm uninstall lodash      # 卸载包

# 清理缓存
npm cache clean --force
```

## 浏览器开发工具

### Chrome DevTools 常用功能

1. **Elements 面板**: 检查和修改 DOM 元素、CSS 样式
2. **Console 面板**: 执行 JavaScript 代码、查看日志
3. **Sources 面板**: 断点调试、查看源码
4. **Network 面板**: 监控网络请求、分析性能
5. **Performance 面板**: 记录和分析页面性能
6. **Application 面板**: 查看 LocalStorage、SessionStorage、Cookie

### 常用快捷键

```javascript
// 在 Console 中测试
console.log('Hello');           // 普通日志
console.error('Error');        // 错误日志
console.warn('Warning');       // 警告日志
console.table([1, 2, 3]);     // 表格形式显示

// 断点调试
debugger;  // 在代码中添加断点
```

## 项目结构最佳实践

### 推荐的目录结构

```
my-project/
├── src/
│   ├── index.js          # 入口文件
│   ├── App.js            # 主组件
│   ├── components/       # 组件目录
│   ├── utils/            # 工具函数
│   └── styles/           # 样式文件
├── public/               # 静态资源
├── tests/                # 测试文件
├── node_modules/         # 依赖
├── package.json
├── .gitignore
├── .eslintrc.json        # ESLint 配置
└── .prettierrc.json      # Prettier 配置
```

## 常见问题排查

### 1. npm 安装失败

```bash
# 清理缓存
npm cache clean --force

# 删除 node_modules 重新安装
rm -rf node_modules
rm package-lock.json
npm install

# 使用淘宝镜像（国内加速）
npm install --registry=https://registry.npmmirror.com
```

### 2. Node.js 版本不兼容

```bash
# 检查 Node.js 版本
node -v

# 检查 npm 版本
npm -v

# 使用 nvm 切换版本
nvm use 26
```

### 3. 权限问题（Linux/Mac）

```bash
# 如果遇到 EACCES 错误
sudo chown -R $(whoami) ~/.npm
# 或者
mkdir ~/.npm-global
npm config set prefix '~/.npm-global'
```
