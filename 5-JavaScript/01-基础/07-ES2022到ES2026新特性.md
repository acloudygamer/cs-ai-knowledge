# ES2022 到 ES2026 新特性

## 定义

ECMAScript 从 2016 年起每年发布一个新版本（ES2016、ES2017...ES2026）。每个版本在语言规范层面新增语法、内置对象或方法。Node.js 作为 JavaScript 运行时，按版本逐步实现这些特性。

> **版本说明**：本文涵盖 ES2022~ES2026 各版本特性。常规特性不标注版本；`<latest>` 标注表示该特性为 Node.js 26+ 前沿新增（Stage 3 提案，尚未纳入 ES 正式版本）。

## 数学模型

### Top-level await 的模块求值

Top-level await 使模块在顶层等待异步操作：
$$
\text{模块} \xrightarrow{\text{await}} \text{暂停加载} \xrightarrow{\text{Promise resolve}} \text{继续执行}
$$

这改变了 ESM 的加载顺序：使用 top-level await 的模块变成**异步模块**，依赖它的模块必须等待。

### Iterator Helpers 的惰性组合

Iterator Helpers（ES2025）提供链式操作，返回新迭代器而非数组：
$$
\text{Iterator} \xrightarrow{\text{map}} \text{Iterator} \xrightarrow{\text{filter}} \text{Iterator} \xrightarrow{\text{take}} \text{Iterator}
$$

每次 `.next()` 调用时才惰性求值，内存效率远高于立即求值的数组方法。

## 数据流

### 装饰器（Stage 3 提案）的求值顺序

<pre>
装饰器表达式求值（从内到外）
    │
    ▼
装饰器函数调用（从外到内，栈展开顺序）
    │
    ▼
返回装饰后的类/方法/字段
    │
    ▼
原始定义被替换
</pre>

### using 声明的资源管理

<pre>
using conn = new Resource();
    │
    ▼
进入作用域时获取资源
    │
    ▼
退出作用域时调用 Symbol.dispose
    │
    ▼
资源释放（逆序，类栈）
</pre>

## 机制

### ES2022 特性

#### Top-level await

**本质**：将 async 函数的 await 能力提升到模块顶层。

**约束**：
- 只能在 ESM 模块顶层使用（`.mjs` 或 `package.json` 的 `"type": "module"`）
- 使用 top-level await 的模块会阻塞依赖它的模块加载

**违反后果**：CJS 模块中使用 top-level await 是语法错误。

#### 私有类字段 `#`

**本质**：编译时强制的访问控制，通过 `[[PrivateMap]]` 实现。

**约束**：
- 必须在类体内声明时使用 `#` 前缀
- 外部任何访问方式（包括反射）都抛出 SyntaxError

#### `.at()` 方法

**本质**：支持负索引的数组/字符串访问。
```javascript
[1, 2, 3].at(-1)  // 3（倒数第一个）
```

**约束**：负索引只支持 -1 到 -(length)，超出返回 undefined。

### ES2023 特性

#### `findLast` / `findLastIndex`

**本质**：从数组末尾反向查找，避免 `arr[arr.length - 1]` 的边缘情况。

#### 数组不可变方法

`toSorted`、`toReversed`、`toSpliced`、`with` 返回**新数组**，不修改原数组。

**为什么需要**：避免函数副作用，提升不可变性认知。

### ES2024 特性

#### `Object.groupBy` / `Map.groupBy`

**本质**：按条件函数对数组分组，返回普通对象或 Map。

**数学模型**：
$$
\text{groupBy}(arr, f) = \{ k \rightarrow [a \in arr \mid f(a) = k] \}
$$

#### Promise.withResolvers

**本质**：将 resolve/reject 提取到外部作用域，适用于需要将 Promise 控制权传递给其他函数的场景。

### ES2025 特性

#### Iterator Helpers

**本质**：在迭代器本身上提供 `.map()`、`.filter()`、`.take()` 等方法，返回新迭代器。

**数据流**：
```javascript
range(0, Infinity)  // 惰性
    .filter(x => x % 2 === 0)  // 惰性过滤
    .take(5)  // 限制数量
    .toArray()  // 终止操作，触发求值
```

#### `Promise.try`

**本质**：统一处理同步和异步函数，无需区分 `try/catch` 或 `.catch()`。

### <latest> Stage 3 装饰器

**本质**：TC39 Stage 3 装饰器语法，与旧版 TypeScript 实验性装饰器不兼容。

**装饰器类型**：
- `class`：装饰器类本身
- `method`：装饰器方法
- `accessor`：装饰自动存取器
- `field`：装饰器类字段

**关键约束**：Stage 3 装饰器不可在同一个类中混用旧版 TypeScript 装饰器。

### <latest> `using` 声明

**本质**：RAII 模式的语法支持，与 `Symbol.dispose` 配合实现资源管理。

**约束**：
- `using` 声明不可重新赋值
- 退出作用域时按逆序调用 `Symbol.dispose`
- `await using` 用于异步资源（调用 `Symbol.asyncDispose`）

### <latest> Temporal API

**本质**：不可变、时区感知的日期时间 API。

**相比 Date 的改进**：
- Date 可变，Temporal 不可变
- Date 时区处理混乱，Temporal 提供明确的时区模型
- Temporal 支持 Date-only、Time-only、YearMonth 等细分类型

## 参考存根

```javascript
// Top-level await
const data = await fetch('/api/data').then(r => r.json());
export { data };

// Iterator Helpers（ES2025）
function* range(start, end) {
    for (let i = start; i < end; i++) yield i;
}
const result = range(0, 10)
    .filter(x => x % 2 === 0)
    .map(x => x * x)
    .take(3)
    .toArray();  // [0, 4, 16]

// using 声明（Stage 3 提案 <latest>）
class DatabaseConnection {
    [Symbol.dispose]() {
        console.log('连接已关闭');
    }
}
{
    using conn = new DatabaseConnection();
    console.log('使用连接');
}  // 自动调用 Symbol.dispose

// Temporal API（Stage 3 提案 <latest>）
const now = Temporal.Now.instant();
const date = Temporal.Now.plainDateISO();
```
