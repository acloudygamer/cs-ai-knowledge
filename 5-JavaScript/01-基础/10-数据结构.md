# JavaScript 数据结构

## 概述

JavaScript 固有（Built-in）的数据结构包括：
- 原始类型（Primitive Types）
- Object 类型（包含 Array、Map、Set、WeakMap、WeakSet 等）
- 结构化类型（Typed Arrays、ArrayBuffer、DataView）

---

## 原始类型（Primitive Types）

### 七种原始类型

```javascript
// 1. undefined
typeof undefined;  // 'undefined'

// 2. null
typeof null;  // 'object'（历史 bug）
null === null;  // true

// 3. Boolean
typeof true;  // 'boolean'
typeof false;  // 'boolean'

// 4. Number
typeof 42;  // 'number'
typeof 3.14;  // 'number'
typeof NaN;  // 'number'
typeof Infinity;  // 'number'

// 5. BigInt
typeof 9007199254740991n;  // 'bigint'
typeof BigInt(42);  // 'bigint'

// 6. String
typeof 'hello';  // 'string'
typeof '';  // 'string'

// 7. Symbol
typeof Symbol('id');  // 'symbol'
```

### 原始类型的包装对象

```javascript
// 原始类型会被临时包装为对象
'hello'.length;  // 5
(42).toString();  // '42'

// 包装对象与原始类型不相等
new String('hello') === 'hello';  // false

// 使用 valueOf 还原
new String('hello').valueOf() === 'hello';  // true
```

## Object 类型

### 通用对象操作

```javascript
const obj = { a: 1, b: 2 };

// 拷贝
const copy = { ...obj };
const deepCopy = structuredClone(obj);

// 合并
const merged = { ...obj, c: 3 };

// 冻结
Object.freeze(obj);  // 不可修改
Object.isFrozen(obj);  // true

// 密封
Object.seal(obj);  // 不可添加/删除属性，但可修改

// 获取属性描述符
Object.getOwnPropertyDescriptor(obj, 'a');
// { value: 1, writable: true, enumerable: true, configurable: true }
```

### 属性特性

```javascript
const obj = {};

// 数据属性
Object.defineProperty(obj, 'name', {
  value: 'Alice',
  writable: false,      // 不可重写
  enumerable: false,    // 不可枚举
  configurable: false   // 不可删除或重新定义
});

// 访问器属性
let _temp = 'initial';
Object.defineProperty(obj, 'computed', {
  get() { return _temp.toUpperCase(); },
  set(v) { _temp = v; }
});

// 获取所有属性描述符
Object.getOwnPropertyDescriptors(obj);
```

## Array（数组）

### 创建与初始化

```javascript
// 数组字面量
const arr = [1, 2, 3];
const sparse = [1, , 3];  // 稀疏数组
const mixed = [1, 'two', true, null];

// 构造函数
new Array(3);        // [empty × 3]
new Array(1, 2, 3);  // [1, 2, 3]
Array.of(1, 2, 3);  // [1, 2, 3]

// Array.from
Array.from('hello');  // ['h', 'e', 'l', 'l', 'o']
Array.from({ length: 3 }, (_, i) => i);  // [0, 1, 2]
```

### 常用方法

```javascript
const arr = [1, 2, 3, 4, 5];

// 遍历
arr.forEach((v, i) => console.log(i, v));
arr.map(v => v * 2);        // [2, 4, 6, 8, 10]
arr.filter(v => v % 2);      // [1, 3, 5]
arr.reduce((sum, v) => sum + v, 0);  // 15

// 查找
arr.find(v => v > 3);       // 4
arr.findIndex(v => v > 3);   // 3
arr.includes(3);             // true
arr.indexOf(3);              // 2

// 修改
arr.push(6);      // 末尾添加
arr.pop();        // 末尾删除
arr.unshift(0);   // 头部添加
arr.shift();      // 头部删除
arr.splice(1, 1, 9);  // 删除并插入

// 排序
[3, 1, 2].sort((a, b) => a - b);  // [1, 2, 3]

// 扁平化
[[1, 2], [3, [4, 5]]].flat(2);  // [1, 2, 3, 4, 5]
[1, 2].concat([3, 4]);  // [1, 2, 3, 4]
[...arr, 6];  // 展开操作符
```

### 迭代协议

```javascript
const arr = [1, 2, 3];

// iterable protocol
const iter = arr[Symbol.iterator]();
iter.next();  // { value: 1, done: false }
iter.next();  // { value: 2, done: false }
iter.next();  // { value: 3, done: false }
iter.next();  // { value: undefined, done: true }

// for...of
for (const v of arr) {
  console.log(v);
}

// 解构
const [first, ...rest] = arr;  // first=1, rest=[2, 3]
```

## Typed Arrays（类型化数组）

### 类型对照表

| 类型 | 大小 | 说明 |
|------|------|------|
| Int8Array | 1 byte | 有符号 8 位整数 |
| Uint8Array | 1 byte | 无符号 8 位整数 |
| Uint8ClampedArray | 1 byte | 无符号 8 位整数（截断） |
| Int16Array | 2 bytes | 有符号 16 位整数 |
| Uint16Array | 2 bytes | 无符号 16 位整数 |
| Int32Array | 4 bytes | 有符号 32 位整数 |
| Uint32Array | 4 bytes | 无符号 32 位整数 |
| Float32Array | 4 bytes | 32 位浮点数 |
| Float64Array | 8 bytes | 64 位浮点数 |
| BigInt64Array | 8 bytes | 有符号 64 位整数 |
| BigUint64Array | 8 bytes | 无符号 64 位整数 |

### 基本用法

```javascript
// 创建
const int8 = new Int8Array([1, 2, 3]);
const buffer = new ArrayBuffer(16);
const view = new Int32Array(buffer);

// 读写
int8[0] = 127;
int8[1] = -128;
int8[2] = 255;  // 自动截断为 -1

// 视图
const int32 = new Int32Array(buffer);
int32[0] = 1000000;
int32[1] = 2000000;
```

### DataView

```javascript
const buffer = new ArrayBuffer(24);
const view = new DataView(buffer);

// 写入不同类型
view.setInt8(0, 127);
view.setFloat64(8, 3.14159);

// 按需读取
view.getInt8(0);      // 127
view.getFloat64(8);   // 3.14159
```

## 队列与栈

### 队列（Queue）

```javascript
// 使用 Array 模拟队列
const queue = [];

// 入队
queue.push('first');
queue.push('second');

// 出队（FIFO）
queue.shift();  // 'first'

// 优化：使用指针
class CircularQueue {
  constructor(capacity) {
    this.items = new Array(capacity);
    this.capacity = capacity;
    this.front = 0;
    this.rear = 0;
    this.size = 0;
  }

  enqueue(item) {
    if (this.size === this.capacity) throw new Error('Full');
    this.items[this.rear] = item;
    this.rear = (this.rear + 1) % this.capacity;
    this.size++;
  }

  dequeue() {
    if (this.size === 0) throw new Error('Empty');
    const item = this.items[this.front];
    this.front = (this.front + 1) % this.capacity;
    this.size--;
    return item;
  }
}
```

### 栈（Stack）

```javascript
// 使用 Array 模拟栈
const stack = [];

// 压栈
stack.push('first');
stack.push('second');

// 出栈（LIFO）
stack.pop();  // 'second'
stack.pop();  // 'first'
```

### 双端队列（Deque）

```javascript
const deque = [];

// 前端操作
deque.unshift('last');  // 前端入队
deque.shift();          // 前端出队

// 后端操作
deque.push('first');     // 后端入队
deque.pop();            // 后端出队
```

## 链表（Linked List）

### 单向链表

```javascript
class ListNode {
  constructor(val) {
    this.val = val;
    this.next = null;
  }
}

class LinkedList {
  constructor() {
    this.head = null;
    this.size = 0;
  }

  append(val) {
    const node = new ListNode(val);
    if (!this.head) {
      this.head = node;
    } else {
      let curr = this.head;
      while (curr.next) curr = curr.next;
      curr.next = node;
    }
    this.size++;
  }

  prepend(val) {
    const node = new ListNode(val);
    node.next = this.head;
    this.head = node;
    this.size++;
  }

  remove(val) {
    if (!this.head) return;
    if (this.head.val === val) {
      this.head = this.head.next;
      this.size--;
      return;
    }
    let curr = this.head;
    while (curr.next && curr.next.val !== val) {
      curr = curr.next;
    }
    if (curr.next) {
      curr.next = curr.next.next;
      this.size--;
    }
  }
}
```

## 树（Tree）

### 二叉树节点

```javascript
class TreeNode {
  constructor(val) {
    this.val = val;
    this.left = null;
    this.right = null;
  }
}

// 二叉搜索树
class BST {
  constructor() {
    this.root = null;
  }

  insert(val) {
    const node = new TreeNode(val);
    if (!this.root) {
      this.root = node;
      return;
    }
    let curr = this.root;
    while (true) {
      if (val < curr.val) {
        if (!curr.left) { curr.left = node; break; }
        curr = curr.left;
      } else {
        if (!curr.right) { curr.right = node; break; }
        curr = curr.right;
      }
    }
  }

  search(val) {
    let curr = this.root;
    while (curr) {
      if (val === curr.val) return curr;
      curr = val < curr.val ? curr.left : curr.right;
    }
    return null;
  }
}
```

## 图（Graph）

### 邻接表表示

```javascript
class Graph {
  constructor() {
    this.adjacencyList = new Map();
  }

  addVertex(v) {
    if (!this.adjacencyList.has(v)) {
      this.adjacencyList.set(v, []);
    }
  }

  addEdge(v1, v2, directed = false) {
    if (!this.adjacencyList.has(v1)) this.addVertex(v1);
    if (!this.adjacencyList.has(v2)) this.addVertex(v2);
    this.adjacencyList.get(v1).push(v2);
    if (!directed) {
      this.adjacencyList.get(v2).push(v1);
    }
  }

  bfs(start) {
    const visited = new Set();
    const queue = [start];
    const result = [];

    while (queue.length) {
      const v = queue.shift();
      if (visited.has(v)) continue;
      visited.add(v);
      result.push(v);
      for (const neighbor of this.adjacencyList.get(v) || []) {
        if (!visited.has(neighbor)) queue.push(neighbor);
      }
    }
    return result;
  }

  dfs(start, visited = new Set()) {
    visited.add(start);
    const result = [start];
    for (const neighbor of this.adjacencyList.get(start) || []) {
      if (!visited.has(neighbor)) {
        result.push(...this.dfs(neighbor, visited));
      }
    }
    return result;
  }
}
```

## 堆（Heap）

```javascript
class MinHeap {
  constructor() {
    this.heap = [];
  }

  getParent(i) { return Math.floor((i - 1) / 2); }
  getLeft(i) { return 2 * i + 1; }
  getRight(i) { return 2 * i + 2; }

  swap(i, j) {
    [this.heap[i], this.heap[j]] = [this.heap[j], this.heap[i]];
  }

  push(val) {
    this.heap.push(val);
    this.bubbleUp(this.heap.length - 1);
  }

  bubbleUp(i) {
    while (i > 0 && this.heap[i] < this.heap[this.getParent(i)]) {
      this.swap(i, this.getParent(i));
      i = this.getParent(i);
    }
  }

  extractMin() {
    if (this.heap.length === 0) return null;
    if (this.heap.length === 1) return this.heap.pop();

    const min = this.heap[0];
    this.heap[0] = this.heap.pop();
    this.bubbleDown(0);
    return min;
  }

  bubbleDown(i) {
    while (this.getLeft(i) < this.heap.length) {
      let smallest = this.getLeft(i);
      const right = this.getRight(i);
      if (right < this.heap.length && this.heap[right] < this.heap[smallest]) {
        smallest = right;
      }
      if (this.heap[i] <= this.heap[smallest]) break;
      this.swap(i, smallest);
      i = smallest;
    }
  }
}
```

## 数据结构对比

| 数据结构 | 查找 | 插入 | 删除 | 有序 |
|----------|------|------|------|------|
| Array | O(1) | O(n) | O(n) | 是 |
| Set | O(1) | O(1) | O(1) | 否 |
| Map | O(1) | O(1) | O(1) | 插入顺序 |
| LinkedList | O(n) | O(1) | O(1) | 是 |
| BST | O(log n) | O(log n) | O(log n) | 是 |
| HashMap | O(1) | O(1) | O(1) | 否 |
| Heap | - | O(log n) | O(log n) | 是（最值） |
