# ES2022 到 ES2026 新特性

## 定义

ECMAScript 从 2016 年起每年发布一个新版本（ES2016、ES2017...ES2026）。每个版本在语言规范层面新增语法、内置对象或方法。Node.js 作为 JavaScript 运行时，按版本逐步实现这些特性。

> **版本说明**：本文涵盖 ES2022~ES2026 各版本特性。`stable`（Node24+ES2024）之前的内容不标注版本；`<Node26+ES2026>` 标注表示该特性为前沿增量，`<Stage 3>` 标注表示该特性处于 TC39 Stage 3 阶段。

## 数学模型

### Top-level await 的模块求值

Top-level await 使模块在顶层等待异步操作：
$$
\text{Module} \xrightarrow{\text{await}} \text{暂停加载} \xrightarrow{\text{Promise resolve}} \text{继续执行}
$$

这改变了 ESM 的加载顺序：使用 top-level await 的模块变成**异步模块**，依赖它的模块必须等待其完成加载。

**约束条件**：Top-level await 只能在 ESM 模块顶层使用，且只在模块顶层上下文可用。

**违反约束的后果**：在 CommonJS 模块或函数内部使用 top-level await 抛出 SyntaxError。

### Iterator Helpers 的惰性组合

Iterator Helpers（ES2025）提供链式操作，返回新迭代器而非数组：
$$
\text{Iterator} \xrightarrow{\text{map}(f)} \text{Iterator'} \xrightarrow{\text{filter}(p)} \text{Iterator''} \xrightarrow{\text{take}(n)} \text{Iterator'''}
$$

每次 `.next()` 调用时才惰性求值，内存效率远高于立即求值的数组方法。

**约束条件**：Iterator Helpers 返回的是迭代器而非数组，需要显式调用 `.toArray()` 或其他终止操作才能获取结果。

### Object.groupBy 的数学定义

$$
\text{Object.groupBy}(arr, f) = \{ k \rightarrow [a \in arr \mid f(a) = k] \}
$$

分组函数 $f$ 的返回值作为键，相同键的元素归为同一组。

## 机制

### ES2022 特性

#### Top-level await

**本质**：将 async 函数的 await 能力提升到模块顶层。

**约束条件**：
- 只能在 ESM 模块顶层使用（`.mjs` 或 `package.json` 的 `"type": "module"`）
- 使用 top-level await 的模块会阻塞依赖它的模块加载

#### 私有类字段 `#`

**本质**：编译时强制的访问控制，通过 `[[PrivateMap]]` 实现。

**约束条件**：
- 必须在类体内声明时使用 `#` 前缀
- 外部任何访问方式（包括反射）都抛出 SyntaxError

**与 TypeScript private 的区别**：TypeScript `private` 是编译时检查，运行时不生效；`#` 是运行时也生效的真正私有。

#### `.at()` 方法

**本质**：支持负索引的数组/字符串访问。
```javascript
[1, 2, 3].at(-1)  // 3（倒数第一个）
[1, 2, 3].at(-2)  // 2（倒数第二个）
```

**约束条件**：负索引只支持 -1 到 -(length)，超出返回 undefined。

### ES2023 特性

#### `findLast` / `findLastIndex`

**本质**：从数组末尾反向查找，避免 `arr[arr.length - 1]` 的边缘情况。
```javascript
const arr = [1, 2, 3, 4, 5];
arr.findLast(x => x % 2 === 1);   // 5（最后一个奇数）
arr.findLastIndex(x => x % 2 === 1);  // 4
```

#### 数组不可变方法

`toSorted`、`toReversed`、`toSpliced`、`with` 返回**新数组**，不修改原数组。

**为什么需要**：避免函数副作用，提升不可变性认知，减少意外的数组修改。

### ES2024 特性

#### `Object.groupBy` / `Map.groupBy`

**本质**：按条件函数对数组分组，返回普通对象或 Map。
```javascript
Object.groupBy(['a', 'b', 'AB'], x => x.length);  // { 1: ['a', 'b'], 2: ['AB'] }
```

**约束条件**：分组函数返回值若为 `null` 或 `undefined`，元素归入 `null` 或 `undefined` 键下。

#### Promise.withResolvers

**本质**：将 resolve/reject 提取到外部作用域，适用于需要将 Promise 控制权传递给其他函数或模块的场景。
```javascript
const { promise, resolve, reject } = Promise.withResolvers();
```

### ES2025 特性

#### Iterator Helpers

**本质**：在迭代器本身上提供 `.map()`、`.filter()`、`.take()` 等方法，返回新迭代器。

```javascript
function* range(start, end) {
    for (let i = start; i < end; i++) yield i;
}
const result = range(0, Infinity)
    .filter(x => x % 2 === 0)  // 惰性过滤
    .take(5)                   // 限制数量
    .toArray();                 // 终止操作，触发求值
// result: [0, 2, 4, 6, 8]
```

**与数组方法的区别**：数组方法立即求值，Iterator Helpers 惰性求值。

**约束条件**：Iterator Helpers 返回的是惰性迭代器，必须有终止操作（`.toArray()`、`.forEach()` 等）才能触发完整求值。

#### `Promise.try`

**本质**：统一处理同步和异步函数，无需区分 `try/catch` 或 `.catch()`。
```javascript
Promise.try(() => synchronousOperation())
    .then(result => ...)
    .catch(error => ...);
```

### <Stage 3> 装饰器

**本质**：TC39 Stage 3 装饰器语法，与旧版 TypeScript 实验性装饰器不兼容。

**装饰器类型**：
- `class`：装饰器类本身
- `method`：装饰器方法
- `accessor`：装饰自动存取器
- `field`：装饰器类字段

**关键约束**：
- Stage 3 装饰器不可在同一个类中混用旧版 TypeScript 装饰器
- 装饰器是纯函数，接收目标元素返回替代元素（或 void 表示不修改）

**违反约束的后果**：混用旧版 TypeScript 装饰器与 Stage 3 装饰器导致语义冲突，行为未定义。

### <Stage 3> `using` 声明

**本质**：RAII 模式的语法支持，与 `Symbol.dispose` 配合实现资源管理。

**约束条件**：
- `using` 声明不可重新赋值
- 退出作用域时按逆序调用 `Symbol.dispose`
- `await using` 用于异步资源（调用 `Symbol.asyncDispose`）

```javascript
class DatabaseConnection {
    [Symbol.dispose]() {
        console.log('连接已关闭');
    }
}
{
    using conn = new DatabaseConnection();
    console.log('使用连接');
}  // 自动调用 Symbol.dispose
```

**违反约束的后果**：
- 退出作用域时若 `Symbol.dispose` 抛出异常，异常向上传播
- 循环引用时 `Symbol.dispose` 的逆序调用可能导致死锁（异步场景）

### <Stage 3> Temporal API

**本质**：不可变、时区感知的日期时间 API。

**相比 Date 的改进**：
- Date 可变，Temporal 不可变
- Date 时区处理混乱，Temporal 提供明确的时区模型
- Temporal 支持 Date-only、Time-only、YearMonth 等细分类型

**约束条件**：Temporal 是 Stage 3 提案，API 可能在正式纳入前发生变化。

### <Stage 3> Error.isError

**本质**：提供可靠的错误身份检测，替代 `instanceof Error` 在跨Realm（如 iframe、Worker）场景下的失效问题。
```javascript
Error.isError(obj) === true  // 仅对真正的 Error 对象返回 true
```

### <Node26+ES2026> Array.fromAsync

`Array.fromAsync` 从异步可迭代对象创建数组：
$$
\text{Array.fromAsync}(asyncIter) \rightarrow \text{Promise}<T[]>
$$

适用于将异步数据流（如 `ReadableStream`）转换为数组：
```javascript
const lines = await Array.fromAsync(readableStream);
```

## 参考存根

```javascript
// Top-level await
const data = await fetch('/api/data').then(r => r.json());
export { data };

// Iterator Helpers（ES2025）
function* range(start, end) {
    for (let i = start; i < end; i++) yield i;
}
const result = range(0, 10)
    .filter(x => x % 2 === 0)
    .map(x => x * x)
    .take(3)
    .toArray();  // [0, 4, 16]

// 私有字段
class Counter {
    #count = 0;
    increment() { this.#count++; }
    getCount() { return this.#count; }
}

// using 声明（Stage 3 提案）
class DatabaseConnection {
    [Symbol.dispose]() {
        console.log('连接已关闭');
    }
}
{
    using conn = new DatabaseConnection();
    console.log('使用连接');
}

// Temporal API（Stage 3 提案）
const now = Temporal.Now.instant();
const date = Temporal.Now.plainDateISO();
console.log(now.toString());
console.log(date.toString());
```
