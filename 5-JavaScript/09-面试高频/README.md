## 面试体系

JavaScript 面试可分为四个层级，由浅入深：

```
第一层：语言基础（var/let/const、类型系统、函数基础）
第二层：核心概念（作用域链、闭包、this、原型链）
第三层：异步编程（Promise、async/await、事件循环）
第四层：手写实现（封装常用 API，证明理解深度）
```

## 面试技巧

### 原理类问题

回答结构：
1. **核心概念**：一句话定义（让面试官知道你理解本质）
2. **原理机制**：底层如何实现（V8 引擎、浏览器事件循环等）
3. **举例说明**：用一个代码示例验证你的理解
4. **应用场景**：实际开发中的使用场景或注意事项

示例问题："什么是闭包？"
```
闭包是指函数能够访问其词法作用域之外的变量。
当一个内部函数引用了外部函数的变量，即使外部函数已经执行完毕，
这些变量依然会被保留。

应用场景：防抖、节流、函数柯里化、模块化私有变量。
注意事项：过多闭包会导致内存泄漏。
```

### 实现类问题

回答结构：
1. **需求分析**：明确输入输出和边界条件
2. **思路拆解**：分步骤描述解决思路
3. **代码实现**：先实现核心逻辑，再处理边界情况
4. **测试验证**：运行几个测试用例确认正确性

示例问题："手写一个防抖函数"
```javascript
function debounce(fn, delay) {
  let timer = null;
  return function(...args) {
    clearTimeout(timer);
    timer = setTimeout(() => {
      fn.apply(this, args);
    }, delay);
  };
}
```

### 优化类问题

回答结构：
1. **问题定位**：说出性能瓶颈在哪里（重排重绘、内存泄漏、循环效率等）
2. **原因分析**：为什么会出现这个问题
3. **解决方案**：提供具体优化手段（节流防抖、懒加载、虚拟滚动等）
4. **效果对比**：优化前后的性能数据对比

## 常见考点

| 类别 | 核心考点 | 掌握程度 |
|------|---------|---------|
| **基础** | var/let/const 区别、类型判断、隐式转换 | 必须掌握 |
| **作用域** | 作用域链、词法环境、闭包 | 必须掌握 |
| **this** | 四种绑定规则、箭头函数 this | 必须掌握 |
| **原型** | 原型链、instanceof、构造函数 | 必须掌握 |
| **异步** | Promise 状态、async/await、事件循环、微任务/宏任务 | 必须掌握 |
| **手写** | 防抖节流、call/apply/bind、new、Promise、数组方法 | 高频考察 |
| **框架** | 响应式原理、虚拟 DOM、Hooks 原理 | 进阶必备 |

## 面试准备检查清单

### 第一轮（电话面/笔试）
- [ ] 能够手写 var/let/const 区别
- [ ] 能够解释 typeof 与 instanceof 底层原理
- [ ] 能够画出原型链
- [ ] 能够实现简易的防抖和节流

### 第二轮（技术面）
- [ ] 能够完整解释 JavaScript 事件循环机制
- [ ] 能够手写 Promise.all / Promise.race
- [ ] 能够解释 async/await 与 Promise 的关系
- [ ] 能够分析闭包的实际应用场景和内存影响

### 第三轮（技术终面/HR面）
- [ ] 能够从原理层面解释 this 的四种绑定方式
- [ ] 能够对比 ES Module 与 CommonJS
- [ ] 能够在实际项目中给出性能优化方案
- [ ] 能够讨论 JavaScript 引擎（V8）的工作原理

## 高频手写题分类

### 第一类：数组操作
- 手写 map / filter / reduce
- 数组扁平化（递归 / flat / reduce）
- 数组去重（Set / indexOf / includes）

### 第二类：函数增强
- 防抖（debounce）
- 节流（throttle）
- 柯里化（curry）
- 偏函数（partial）

### 第三类：对象操作
- 手写 new 操作符
- 手写 Object.create
- 手写 instanceof
- 深拷贝（JSON / 递归）

### 第四类：异步编程
- 手写 Promise（基本结构、all、race）
- 手写 async/await 原理
- 实现红黑树交换
