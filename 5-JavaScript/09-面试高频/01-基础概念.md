# JavaScript 基础概念面试题

## 数据类型

### Q: var、let、const 的区别？

| 特性 | var | let | const |
|------|-----|-----|-------|
| 作用域 | 函数作用域 | 块级作用域 | 块级作用域 |
| 变量提升 | 是（undefined） | 是（TDZ） | 是（TDZ） |
| 重复声明 | 可以 | 不可以 | 不可以 |
| 初始值 | 可选 | 可选 | 必须 |
| 重新赋值 | 可以 | 可以 | 不可以 |

```javascript
// var 变量提升示例
console.log(hoisted);  // undefined（不是报错）
var hoisted = 'I am hoisted';

// let 暂时性死区
// console.log(tdz);  // ReferenceError
let tdz = 'temporal dead zone';
```

### Q: 基本类型和引用类型的区别？

- **基本类型**：number、string、boolean、null、undefined、symbol、bigint
  - 存储在栈（stack）中
  - 按值访问，值不可变
  - 比较时比较值

- **引用类型**：Object、Array、Function 等
  - 存储在堆（heap）中，栈中存引用地址
  - 按引用访问，引用可变
  - 比较时比较引用地址

```javascript
// 基本类型
let a = 10;
let b = a;
b = 20;
console.log(a);  // 10（a 不受影响）

// 引用类型
let obj1 = { name: 'Alice' };
let obj2 = obj1;
obj2.name = 'Bob';
console.log(obj1.name);  // 'Bob'（obj1 也变了）
```

### Q: typeof 返回值有哪些？有什么陷阱？

```javascript
typeof 123           // 'number'
typeof 'str'        // 'string'
typeof true        // 'boolean'
typeof undefined    // 'undefined'
typeof null         // 'object'（历史 bug，typeof 检测不到 null）
typeof {}            // 'object'
typeof []            // 'object'（数组不是独立类型）
typeof function(){}  // 'function'
typeof Symbol()     // 'symbol'
typeof 10n          // 'bigint'

// 精确判断数组
Array.isArray([]);                        // true
Object.prototype.toString.call([]);       // '[object Array]'
```

## 作用域与闭包

### Q: 什么是闭包？有什么应用场景？

**闭包**：函数能访问其词法作用域外部的变量，即使外部函数已返回。

```javascript
// 经典闭包：私有变量
function createCounter() {
  let count = 0;
  return {
    increment: () => ++count,
    decrement: () => --count,
    getCount: () => count
  };
}

const counter = createCounter();
counter.increment();
counter.increment();
console.log(counter.getCount());  // 2

// 应用场景：
// 1. 数据私有化
// 2. 函数工厂
// 3. 模块模式
// 4. 缓存计算结果
```

### Q: for 循环中的 var 和 let 有什么区别？

```javascript
// var 是函数作用域，整个循环共用一个 i
for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 100);  // 输出 3, 3, 3
}

// let 是块级作用域，每次循环都有独立的 i
for (let i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 100);  // 输出 0, 1, 2
}

// 解决 var 问题的方式
for (var i = 0; i < 3; i++) {
  setTimeout((i) => console.log(i), 100, i);  // 输出 0, 1, 2
}

// 或者用闭包
for (var i = 0; i < 3; i++) {
  ((j) => setTimeout(() => console.log(j), 100))(i);
}
```

### Q: 什么是暂时性死区（TDZ）？

```javascript
// let/const 在声明前访问会报 ReferenceError
// 这块区域就叫暂时性死区

// console.log(x);  // ReferenceError
let x = 10;

// typeof 在暂时性死区也会报错（特殊情况）
// console.log(typeof y);  // ReferenceError
let y;
```

## this 指向

### Q: this 的指向规则？

| 调用方式 | this 指向 |
|----------|-----------|
| 普通函数调用 | window/undefined（严格模式） |
| 对象方法调用 | 该对象 |
| 箭头函数 | 定义时的外层 this |
| 构造函数 | 新建的对象 |
| call/apply/bind | 绑定的对象 |

```javascript
// 普通函数：指向调用者
function greet() { console.log(this.name); }
const obj = { name: 'Alice' };
greet.call(obj);  // 'Alice'

// 箭头函数：指向定义时的 this
const obj2 = {
  name: 'Bob',
  greet: () => console.log(this.name)
};
obj2.greet();  // undefined（外层不是对象）
```

### Q: 如何改变 this 指向？

```javascript
function greet(message) {
  console.log(`${message}, ${this.name}`);
}

const person = { name: 'Alice' };

// call: 立即调用，参数逐一传入
greet.call(person, 'Hello');  // 'Hello, Alice'

// apply: 立即调用，参数数组传入
greet.apply(person, ['Hi']);  // 'Hi, Alice'

// bind: 返回新函数，不立即调用
const bound = greet.bind(person, 'Hey');
bound();  // 'Hey, Alice'
```

## 原型与继承

### Q: 原型链是什么？

```javascript
// 每个对象都有原型（__proto__）
// 原型也有自己的原型，形成链式结构

const arr = [1, 2, 3];
// arr.__proto__ === Array.prototype
// arr.__proto__.__proto__ === Object.prototype
// arr.__proto__.__proto__.__proto__ === null

// instanceof 原理：沿着原型链查找
console.log(arr instanceof Array);  // true
console.log(arr instanceof Object);  // true
```

### Q: ES6 class 和原型继承的区别？

```javascript
// ES5 原型继承
function Animal(name) {
  this.name = name;
}
Animal.prototype.speak = function() {
  console.log(`${this.name} makes a noise`);
};

function Dog(name, breed) {
  Animal.call(this, name);
  this.breed = breed;
}
Dog.prototype = Object.create(Animal.prototype);
Dog.prototype.constructor = Dog;

// ES6 class
class Animal {
  constructor(name) { this.name = name; }
  speak() { console.log(`${this.name} makes a noise`); }
}

class Dog extends Animal {
  constructor(name, breed) {
    super(name);
    this.breed = breed;
  }
  speak() {
    super.speak();
    console.log(`${this.name} barks`);
  }
}
```

## 事件循环

### Q: 解释 JavaScript 事件循环？

```javascript
// 执行顺序
// 1. 同步代码（调用栈）
// 2. 微任务（Microtasks）：Promise.then, async/await, queueMicrotask
// 3. 宏任务（Macrotasks）：setTimeout, setInterval, I/O, UI rendering

console.log('1');

setTimeout(() => console.log('2'), 0);

Promise.resolve().then(() => console.log('3'));

console.log('4');
// 输出：1, 4, 3, 2
```

### Q: async/await 和 Promise 的区别？

```javascript
// Promise
function fetchData() {
  return fetch('/api/data')
    .then(r => r.json())
    .then(data => console.log(data));
}

// async/await（语法糖，更直观）
async function fetchData() {
  try {
    const response = await fetch('/api/data');
    const data = await response.json();
    console.log(data);
  } catch (error) {
    console.error(error);
  }
}

// async 函数始终返回 Promise
// await 暂停函数执行，等待 Promise resolve
```
