# 模块化

## 模块化概述

模块化是将代码拆分为独立、可复用单元的做法，每个模块有自己的作用域、接口和依赖关系。

### 模块化方案演进

```
全局函数/变量 → IIFE → CommonJS → AMD → UMD → ES Modules
```

---

## ES Modules（ESM）

### 基本语法

```javascript
// 导出
// 命名导出
export const PI = 3.14159;
export function add(a, b) { return a + b; };

// 默认导出
export default class Calculator { };

// 批量导出
const A = 1, B = 2;
export { A, B };

// 导出时重命名
export { A as a, B as b };

// as
export { A as a, B as b };
```

### 导入

```javascript
// 默认导入
import Calculator from './Calculator.js';
import myCalc from './Calculator.js';

// 命名导入
import { add, PI } from './math.js';

// 导入时重命名
import { add as sum } from './math.js';

// 命名空间导入
import * as math from './math.js';
math.add(1, 2);
math.PI;

// 组合导入
import Calculator, { add } from './Calculator.js';

// 仅执行（不导入绑定）
import './side-effects.js';
```

### 动态导入

```javascript
// 按需加载
const module = await import('./module.js');

// 条件加载
if (condition) {
  const { feature } = await import('./feature.js');
}

// 懒加载
const routes = {
  home: () => import('./routes/Home.js'),
  about: () => import('./routes/About.js')
};

const Home = await routes.home();
```

### 模块作用域

```javascript
// module-a.js
const privateVar = 'private';  // 不导出，模块私有
export const publicVar = 'public';

// module-b.js
import { publicVar } from './module-a.js';
console.log(publicVar);  // 'public'
// console.log(privateVar);  // ReferenceError
```

## CommonJS（CJS）

### 导出

```javascript
// 导出单个
module.exports = function() { };

// 导出多个
module.exports.add = (a, b) => a + b;
module.exports.PI = 3.14159;

// exports 简写
exports.name = 'Calculator';
exports.calculate = function() { };
```

### 导入

```javascript
const myModule = require('./myModule');
const { add, PI } = require('./math');

// 条件导入
const fs = process.env.NODE_ENV === 'production'
  ? require('./production')
  : require('./development');
```

### 循环依赖

```javascript
// a.js
exports.loaded = false;
const b = require('./b');
exports.loaded = true;

// b.js
const a = require('./a');
console.log(a.loaded);  // false（a 还未完成加载）

// 解决方案：延迟访问
setTimeout(() => {
  console.log(a.loaded);  // true
}, 0);
```

## AMD（Asynchronous Module Definition）

```javascript
define(['./dependency1', './dependency2'], function(dep1, dep2) {
  // 异步加载依赖
  return {
    doSomething: function() {
      return dep1.get() + dep2.get();
    }
  };
});

// 简化 CommonJS 转换
define(function(require, exports, module) {
  const dep1 = require('./dependency1');
  const dep2 = require('./dependency2');

  module.exports = {
    doSomething: function() {
      return dep1.get() + dep2.get();
    }
  };
});
```

## UMD（Universal Module Definition）

```javascript
(function(root, factory) {
  // 检测环境
  if (typeof define === 'function' && define.amd) {
    // AMD
    define(['dependency'], factory);
  } else if (typeof module === 'object' && module.exports) {
    // CommonJS
    module.exports = factory(require('dependency'));
  } else {
    // 全局变量
    root.MyModule = factory(root.Dependency);
  }
}(this, function(dependency) {
  return {
    // 模块实现
    doSomething: function() {
      return dependency.get();
    }
  };
}));
```

## 模块打包

### Webpack/Rollup 打包

```javascript
// 入口文件
// src/index.js
import { add } from './math.js';
import { multiply } from './math.js';
import './styles.css';

console.log(add(1, 2));

// 打包后，所有模块会被合并到单个文件
// 依赖关系会被妥善处理
```

### Tree Shaking

```javascript
// math.js
export function add(a, b) { return a + b; }
export function subtract(a, b) { return a - b; }
export function multiply(a, b) { return a * b; }

// 只导入使用的
import { add } from './math.js';  // subtract 和 multiply 会被移除
```

### Code Splitting

```javascript
// 静态导入（全部打包）
import('./module').then(module => {
  module.doSomething();
});

// 动态导入（代码分割）
// Webpack 会创建单独的 chunk
```

## 模块设计原则

### 单一职责

```javascript
// 差：多个功能
export function formatDate() { /* */ }
export function validateEmail() { /* */ }
export function sendEmail() { /* */ }

// 好：按职责分离
export { formatDate } from './date.js';
export { validateEmail, sendEmail } from './email.js';
```

### 显式依赖

```javascript
// 好：清楚列出依赖
import { EventEmitter } from 'events';
import { config } from './config.js';

class UserService extends EventEmitter {
  constructor() {
    super();
    this.config = config;
  }
}
```

###  barrel 模式

```javascript
// src/utils/index.js（barrel）
export { add } from './add.js';
export { subtract } from './subtract.js';
export { multiply } from './multiply.js';

// 消费者
import { add, multiply } from './utils/index.js';
// 无需知道具体文件
```

### 循环依赖处理

```javascript
// 避免循环依赖
// a.js
import { bMethod } from './b.js';
export function aMethod() {
  return bMethod() + 1;
}

// b.js
import { aMethod } from './a.js';
export function bMethod() {
  // 避免在模块加载时调用 aMethod
  return 42;
}

// 更好：使用事件解耦
// eventBus.js
import { EventEmitter } from 'events';
export default new EventEmitter();

// a.js
import eventBus from './eventBus.js';
eventBus.on('ready', () => { /* */ });

// b.js
import eventBus from './eventBus.js';
eventBus.emit('ready');
```

## TypeScript 模块

### 导出

```typescript
// 命名导出
export const PI = 3.14159;
export function add(a: number, b: number): number { return a + b; }

// 接口导出
export interface User {
  id: string;
  name: string;
}

// 类型导出
export type UserId = string | number;

// 默认导出
export default class Calculator { }
```

### 导入

```typescript
import Calculator, { add, PI } from './Calculator.js';
import type { User } from './types.js';

// 类型导入（不编译为 JS）
import type { User } from './types.js';
```

### 命名空间（旧）

```typescript
// math.ts
export namespace MathUtils {
  export function add(a: number, b: number): number {
    return a + b;
  }
}

// 使用
import { MathUtils } from './math.js';
MathUtils.add(1, 2);
```

## 模块化最佳实践

### 目录结构

```
src/
├── utils/
│   ├── index.js       # barrel 导出
│   ├── format.js      # 格式化工具
│   ├── validate.js   # 验证工具
│   └── parse.js      # 解析工具
├── services/
│   ├── api.js        # API 服务
│   ├── storage.js    # 存储服务
│   └── auth.js       # 认证服务
└── components/
    ├── Button.js
    └── Modal.js
```

### 循环依赖检测
