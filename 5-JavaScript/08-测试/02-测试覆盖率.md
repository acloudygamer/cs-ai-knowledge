# 测试覆盖率

## 简介

测试覆盖率衡量测试对代码的覆盖程度，是评估测试质量的重要指标。

### 覆盖率指标

| 指标 | 含义 |
|------|------|
| Statements | 语句覆盖率 - 执行到的语句比例 |
| Branches | 分支覆盖率 - if/switch 等分支覆盖比例 |
| Functions | 函数覆盖率 - 调用到的函数比例 |
| Lines | 行覆盖率 - 代码行数覆盖比例 |

## Jest 覆盖率配置

### 基本配置

```javascript
// jest.config.js
module.exports = {
  collectCoverage: true,

  // 覆盖的文件
  collectCoverageFrom: [
    'src/**/*.js',
    '!src/**/*.test.js',
    '!src/**/*.spec.js',
    '!src/**/index.js'
  ],

  // 覆盖率输出
  coverageDirectory: 'coverage',

  // 报告格式
  coverageReporters: ['text', 'lcov', 'html', 'clover'],

  // 覆盖阈值（强制要求）
  coverageThreshold: {
    global: {
      branches: 80,
      functions: 80,
      lines: 80,
      statements: 80
    }
  }
};
```

### 命令行选项

```bash
# 启用覆盖率
jest --coverage

# 指定报告格式
jest --coverage --coverageReporters=text --coverageReporters=lcov

# 输出目录
jest --coverage --coverageDirectory=coverage-report

# 阈值检查
jest --coverage --coverageThreshold='{"global":{"branches":80,"functions":80,"lines":80}}'
```

## 提高覆盖率

### 识别未覆盖代码

```javascript
// coverage/lcov-report/index.html 中高亮显示未覆盖的代码

// 示例：calculator.js
function calculate(a, b, operation) {
  if (operation === 'add') {     // 分支 1
    return a + b;
  } else if (operation === 'sub') {  // 分支 2
    return a - b;
  } else if (operation === 'mul') {  // 分支 3（未覆盖）
    return a * b;
  } else {
    return 0;  // 分支 4（未覆盖）
  }
}

// 测试需要补充：
test('multiplication', () => {
  expect(calculate(2, 3, 'mul')).toBe(6);
});

test('unknown operation', () => {
  expect(calculate(1, 1, 'div')).toBe(0);
});
```

### 边界条件

```javascript
// 边界测试覆盖
function divide(a, b) {
  if (b === 0) {
    throw new Error('Division by zero');
  }
  return a / b;
}

// 需要测试的场景：
test('divides positive numbers', () => {
  expect(divide(6, 2)).toBe(3);
});

test('divides negative numbers', () => {
  expect(divide(-6, 2)).toBe(-3);
});

test('divides by zero throws', () => {
  expect(() => divide(1, 0)).toThrow('Division by zero');
});
```

### 错误处理

```javascript
function parseJSON(str) {
  try {
    return JSON.parse(str);
  } catch (e) {
    return null;
  }
}

// 测试成功路径
test('parses valid JSON', () => {
  expect(parseJSON('{"a":1}')).toEqual({ a: 1 });
});

// 测试错误路径
test('returns null for invalid JSON', () => {
  expect(parseJSON('invalid')).toBeNull();
});
```

## 覆盖率最佳实践

### 避免无意义覆盖率

```javascript
// 差：为提高覆盖率而测试无关代码
test('getter returns name', () => {
  const user = new User('Alice');
  expect(user.name).toBe('Alice');
});

// 好：测试真实场景
test('creates user with name', () => {
  const user = new User('Alice');
  expect(user.name).toBe('Alice');
});
```

### 测试边界条件

```javascript
// 空值、null、undefined
test('handles null input', () => {
  expect(process(null)).toBeDefined();
});

test('handles undefined input', () => {
  expect(process(undefined)).toBeDefined();
});

test('handles empty string', () => {
  expect(process('')).toBe('');
});
```

### Mock 外部依赖

```javascript
// 不 mock，导致覆盖率不准确
test('fetches user', async () => {
  const user = await fetchUser(1);  // 可能失败或耗时
  expect(user.name).toBe('Alice');
});

// 正确 mock
jest.mock('./api');
test('fetches user', async () => {
  api.fetchUser.mockResolvedValue({ id: 1, name: 'Alice' });
  const user = await fetchUser(1);
  expect(user.name).toBe('Alice');
});
```

### 条件语句覆盖

```javascript
// 测试每个分支
if (x > 0 && y > 0) {  // 需要测试：
  // x>0, y>0 为真
  // x>0, y>0 为假

  // 其他情况
}
```

### 循环覆盖

```javascript
// 测试循环的 0次、1次、多次
const arr = [1, 2, 3];

// 0次
process([]);

// 1次
process([1]);

// 多次
process(arr);
```

## 集成测试覆盖率

### 覆盖率陷阱

```javascript
// 路由测试
app.get('/users/:id', async (req, res) => {
  const user = await User.findById(req.params.id);
  if (!user) {
    return res.status(404).json({ error: 'Not found' });
  }
  res.json(user);
});

// 补充 404 测试
test('returns 404 for non-existent user', async () => {
  User.findById.mockResolvedValue(null);
  const res = await request(app).get('/users/999');
  expect(res.status).toBe(404);
});
```

## 覆盖率报告集成

### CI/CD 集成

```yaml
# .github/workflows/test.yml
name: Test

on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-node@v3
        with:
          node-version: '26'
      - run: npm ci
      - run: npm test -- --coverage
      - uses: codecov/codecov-action@v3
        with:
          files: ./coverage/lcov.info
          fail_ci_if_error: true
```

### SonarQube 集成

```bash
# jest-sonar-reporter
npm install --save-dev jest-sonar-reporter

# jest.config.js
module.exports = {
  reporters: [
    'default',
    ['jest-sonar-reporter', {
      outputDirectory: 'coverage',
      outputName: 'sonar-report.xml'
    }]
  ]
};
```

## 阈值配置

### 强制阈值

```javascript
// jest.config.js
module.exports = {
  coverageThreshold: {
    // 全局阈值
    global: {
      branches: 80,
      functions: 80,
      lines: 80,
      statements: 80
    },

    // 每个文件阈值
    './src/utils/': {
      branches: 90,
      functions: 100,
      lines: 90,
      statements: 90
    }
  }
};
```

### 警告 vs 失败

```javascript
// 仅警告
coverageThreshold: {
  global: {
    branches: 50  // 低于 50% 仅警告，不失败
  }
}

// 失败构建
coverageThreshold: {
  global: {
    branches: 80  // 低于 80% 失败
  }
}
```

## 覆盖率工具

### Istanbul

Jest 内置的覆盖率工具，基于 Istanbul。

```bash
# 单独使用
npx istanbul cover test.js
npx istanbul report  # 生成报告
```

### c8（V8 内置）

```bash
# 安装
npm install --save-dev c8

# 运行
npx c8 npm test

# 报告
npx c8 report
```

### nyc（Istanbul CLI）

```bash
# 安装
npm install --save-dev nyc

# 配置 .nycrc
{
  "reporter": ["text", "lcov"],
  "include": ["src/**/*.js"],
  "exclude": ["**/*.test.js"]
}

# 运行
npx nyc npm test
```
