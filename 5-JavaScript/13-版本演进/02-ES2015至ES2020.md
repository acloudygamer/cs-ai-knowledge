# ES2015 至 ES2020

> 前置：[01-演进脉络与 TC39 流程](./01-演进脉络与TC39流程.md) · 后续：[03-ES2021 至 ES2026](./03-ES2021至ES2026.md)

> **版本基准**：Node 24 stable / Node 26 latest。本篇示例实测环境：Node v24.13.1（V8 13.6），Windows x64（特性探测脚本实测，全部可用）。

## 本质

这段时期的形状是**一次大跃进加五年小步**。

| | 特征 |
|---|---|
| **ES2015（ES6）** | 一次补足十余年欠账，新增内容超过此前所有版本之和 |
| **ES2016 起** | 每年一版，每版少量特性——TC39 有意把大改动拆成小步 |

**ES2015 之所以这么大，是有历史原因的**：上一轮大改（ES4）在 2008 年前后因委员会分歧被放弃，语言停滞多年，欠账积累到 ES2015 一次性还清。这条经验直接催生了现在的"每年一版"机制——**大爆炸式改版的风险太高**。

## 机制

### ES2015：一次性补齐的四组能力

**一、语法糖（写起来更短）**

| 特性 | 作用 |
|---|---|
| 箭头函数 | 简短函数 + 词法 `this`（见 [02-对象模型与运行时/03](../02-对象模型与运行时/03-this与调用约定.md)） |
| `let` / `const` | 块级作用域 + TDZ（见 [01-语言核心/02-绑定与类型](../01-语言核心/02-绑定与类型.md)） |
| 模板字符串 | 字符串插值与多行 |
| 解构 | 从数组/对象提取值 |
| 默认参数、剩余参数、展开 | 参数与数组的批量处理 |
| 简写属性与方法 | `{ x, f() {} }` |

**二、模块**：`import` / `export` 进入语言（此前只有 CommonJS 等第三方方案）。这是 ES2015 影响最深远的一项——它让"静态可分析的依赖结构"成为可能，tree-shaking 才有立足点（见 [09-工程化/03-打包与转译](../09-工程化/03-打包与转译.md)）。

**三、类的语法封装**：`class` / `extends` / `super`（见 [01-语言核心/05-对象与类](../01-语言核心/05-对象与类.md)）。注意它**没有改变原型继承的本质**，只是让写法接近基于类的语言。

**四、新的抽象**：

| 特性 | 补上了什么 |
|---|---|
| `Promise` | 异步的可组合值（见 [04-异步与并发/02](../04-异步与并发/02-回调到Promise.md)） |
| `Map` / `Set` | 真正的键值映射与唯一值集合（见 [03-标准库/03](../03-标准库/03-Object与Map-Set.md)） |
| `Symbol` | 不冲突的属性键 |
| 迭代协议 + 生成器 | 统一的遍历接口（见 [02-对象模型与运行时/05](../02-对象模型与运行时/05-迭代协议与生成器.md)） |
| `Proxy` / `Reflect` | 拦截对象操作（见 [02-对象模型与运行时/04](../02-对象模型与运行时/04-属性描述符与元编程.md)） |
| 类型化数组 / `ArrayBuffer` | 二进制数据处理 |

**这四组的共同点是：它们让大量"用已有能力手工模拟"的模式溶解**（见 [12-设计模式/01-设计模式总览](../12-设计模式/01-设计模式总览.md) 的溶解表）。

### ES2016–ES2017：小步与异步的收口

| 版本 | 特性 | 意义 |
|---|---|---|
| ES2016 | 指数运算符 `**`、`Array.prototype.includes` | 两个小补丁 |
| ES2017 | **`async` / `await`**、`Object.entries` / `values`、字符串补齐、尾逗号 | `async` / `await` 是这一段最重要的特性 |

`async` / `await` 的意义是把 Promise 的链式写法还原成同步的形状（见 [04-异步与并发/03](../04-异步与并发/03-async-await与异步模式.md)）——**能力没变，可读性与错误处理统一了**。它两年后才进入规范，而引擎早已实现，是"引擎领先规范"的早期实例。

### ES2018：异步迭代与对象展开

| 特性 | 作用 |
|---|---|
| **异步迭代**（`for await...of`、`Symbol.asyncIterator`） | 让异步数据源也能用统一的遍历语法 |
| 对象展开 / 剩余属性 | `{...a, ...b}`，此前的展开只支持数组 |
| 正则命名捕获组 | `(?<name>…)` |
| 正则 `s` 标志 | `.` 也匹配换行 |
| `Promise.prototype.finally` | 无论成败都执行的清理 |

### ES2019：数组与对象的便利方法

| 特性 | 作用 |
|---|---|
| `Array.prototype.flat` / `flatMap` | 展平 |
| `Object.fromEntries` | `Object.entries` 的逆操作 |
| 可选 `catch` 绑定 | `catch {}` |
| `trimStart` / `trimEnd` | 补齐 |
| `Symbol.prototype.description` | 读取符号的描述 |

### ES2020：三个"少写代码"的特性

| 特性 | 作用 |
|---|---|
| **可选链 `?.`** | 深层访问不必层层判空 |
| **空值合并 `??`** | 只在 `null` / `undefined` 时取默认值（`||` 会把 `0` 和 `""` 也替换掉，见 [01-语言核心/03](../01-语言核心/03-控制流程.md)） |
| `BigInt` | 任意精度整数（见 [03-标准库/01](../03-标准库/01-字符串与数字.md)） |
| **动态 `import()`** | 运行时按需加载（见 [11-前端框架与状态管理/05](../11-前端框架与状态管理/05-路由与SSR.md)） |
| `globalThis` | 跨宿主统一的全局对象 |
| `Promise.allSettled` | 等全部敲定，不因一个失败而放弃 |
| `import.meta` | 模块自身的元信息 |

`?.` 与 `??` 是这一段**使用频率最高**的两个特性——它们把"防御性判空"从一长串 `&&` 变成一次表达式。

## 连接：版本与核心贡献

| 版本 | 最重要的特性 | 解决的核心问题 |
|---|---|---|
| ES2015 | 模块、类、Promise、迭代协议、`let`/`const` | 补齐十年欠账 |
| ES2016 | 指数运算符、`includes` | 小补丁 |
| ES2017 | `async` / `await` | 异步的可读性 |
| ES2018 | 异步迭代、对象展开 | 异步遍历、对象合并 |
| ES2019 | `flat` / `flatMap`、`fromEntries` | 数据变换 |
| ES2020 | `?.`、`??`、`BigInt`、动态 `import()` | 少写判空代码、按需加载 |

**全部在 Node 24 实测可用**（见 [03-ES2021 至 ES2026](./03-ES2021至ES2026.md) 的支持矩阵）。

## 边界

- **`class` 没有改变原型继承**：它只是语法封装（见 [01-语言核心/05](../01-语言核心/05-对象与类.md)）。
- **ES2015 的特性需要转译才能跑在老环境**：`let`、箭头函数、模块都会降级。
- **`async` / `await` 的引擎实现早于规范批准**：不要用规范版本判断可用性。
- **`?.` 不能替代数据校验**：它只是让访问不抛错，不代表数据形状正确（见 [08-TypeScript/01](../08-TypeScript/01-类型系统基础.md)）。
- **`??` 与 `||` 语义不同**：默认值场景优先 `??`。
- **动态 `import()` 是异步的**：加载失败需要处理。
