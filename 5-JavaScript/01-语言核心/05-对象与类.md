# 对象与类

> 前置：[04-函数](./04-函数.md) · 后续：[06-模块](./06-模块.md)

> **版本基准**：Node 24 stable / Node 26 latest。本篇示例实测环境：Node v24.13.1（V8 13.6），Windows x64。

## 本质

**对象**是属性的无序集合——每个属性是"键 → 值"的关联，值可以是任意类型（含函数）。对象还额外持有一个指向另一个对象（或 `null`）的隐藏链接，称为**原型**。属性查找先在自己身上找，找不到就沿这条链接向上找，直到 `null`。这条链的机制见 [01-原型链与继承](../02-对象模型与运行时/01-原型链与继承.md)。

**类**（`class`）不是另一个概念，而是**对"用构造函数 + 原型链实现继承"这套手工写法的语法封装**。这一点可以直接观察：

```console
$ node -e 'class C{} console.log(typeof C, C.prototype.constructor === C)'
function true
```

`class C {}` 定义出来的 `C` 是一个函数，方法挂在 `C.prototype` 上，实例通过原型链接读到这些方法。所以 JavaScript 的继承始终是**原型继承**，`class` 只是让它写起来像基于类的语言——理解这条，才能解释后面每一个"奇怪"的行为（方法不在实例上、`this` 是动态的、方法可被借用）。

## 机制

### 对象字面量：三种语法机制

字面量 `{…}` 不只是"键加值"的罗列，有三种机制让它能当构建工具用：

```console
$ node -e 'const k="na"+"me"; const o={ [k]:1, m(){return 2}, get g(){return 3}, ...{extra:4} }; console.log(o.name, o.m(), o.g, o.extra)'
1 2 3 4
```

- **计算键名** `[表达式]`：键由表达式求值得出——键可以来自变量，而不是只能写字面量。
- **方法/访问器简写** `m(){}`、`get g(){}`：方法直接成为属性值；访问器定义"读取时求值"的属性（描述符机制见 [04-属性描述符与元编程](../02-对象模型与运行时/04-属性描述符与元编程.md)）。
- **展开 `...`**：把另一个对象的自有可枚举属性逐键拷贝进来，后写的覆盖先写的——合并配置的惯用形态。

属性还可以用**简写键值**（`{ x }` 等价于 `{ x: x }`）。删除与查询归 `delete`、`in`、`Object.keys` 一族（见 [03-标准库/03-Object 与 Map/Set](../03-标准库/03-Object与Map-Set.md)）。

### 类声明的三条硬约束

| 行为 | 规则 | 原因 |
|---|---|---|
| 提升 | **不提升**，声明前访问抛 `ReferenceError` | 类绑定处于 TDZ |
| 内部模式 | 类体**恒为严格模式**，不随文件模式改变 | 规范规定，避免 `this` 静默指向全局 |
| 调用方式 | 必须 `new`，裸调用抛 `TypeError` | 没有 `new` 就没有 `this` 绑定 |

```console
$ node -e 'try { new C() } catch(e){ console.log(e.constructor.name + ": " + e.message) } class C{}'
ReferenceError: Cannot access 'C' before initialization
```

严格模式的效果可测——把方法取出来裸调用，`this` 是 `undefined` 而不是全局对象：

```console
$ node -e 'class S{ m(){ return String(this) } } const m = S.prototype.m; console.log(m())'
undefined
```

（对比：CommonJS 里普通函数的裸调用会把 `this` 绑到全局对象。）

### 实例字段：全部在构造器体之前初始化

字段声明的**书写位置**不影响初始化时机——所有实例字段按书写顺序初始化，**全部发生在构造器体执行之前**：

```console
$ node -e 'class G{ x = console.log("字段 x"); constructor(){ console.log("构造器体") } y = console.log("字段 y") } new G()'
字段 x
字段 y
构造器体
```

即使 `y` 写在构造器后面，它也在构造器体之前初始化完。这条规则解释了为什么构造器里能读到所有字段。

### 私有字段 `#`

以 `#` 开头的字段是**真正的私有**——不是命名约定，是运行时强制：

```console
$ node -e 'class P{ #v = 1; get v(){ return this.#v } } const p = new P(); console.log(p.v, Object.keys(p).length)'
1 0
```

`#v` 不出现在 `Object.keys` 里，外部访问 `p.#v` 是语法错误（不是运行时错误——解析阶段就拒绝）。这是 2022 年才进入规范的能力；在此之前，私有状态只能靠 [04-函数](./04-函数.md) 里的闭包实现。

方法与访问器同样可以私有——`#m()`、`get #x()` 遵循同一套规则，外部一律不可达：

```console
$ node -e 'class P{ #v=41; #inc(){ this.#v++ } get v(){ this.#inc(); return this.#v } } const p=new P(); console.log(p.v)'
42
```

### `static` 与继承：两条独立的原型链

`static` 成员挂在**类本身**上，而不是 `prototype` 上。类继承时，两条链同时建立：

```console
$ node -e 'class Base{ static id = "base"; static who(){ return this.name } } class Sub extends Base{} console.log(Sub.id, Sub.who(), Object.getPrototypeOf(Sub) === Base)'
base Sub true
```

- **实例链**：`Sub.prototype` 的原型是 `Base.prototype`——实例能找到父类的方法。
- **构造器链**：`Sub` 的原型是 `Base`——子类能找到父类的静态成员。

`Sub.who()` 返回 `"Sub"` 而非 `"Base"`，因为 `static` 方法里的 `this` 是**调用它的那个类**。两条链的完整构造见 [01-原型链与继承](../02-对象模型与运行时/01-原型链与继承.md)。

### `static {}` 静态初始化块

静态字段的初始化器只能写一行表达式。需要多步初始化（读配置、填注册表、字段间互相依赖）时，用静态初始化块——它在**类求值时执行一次**，且能访问类的私有静态成员：

```console
$ node -e 'class C{ static #count=0; static { C.#count = 41; C.#count++ } static get count(){ return C.#count } } console.log(C.count)'
42
```

块内的 `this` 是类本身。这是 ES2022 与私有字段同批进入规范的能力——两者常在同一处出现：私有静态字段的复杂初始化，只有块内够得着。

### `extends` 与 `super`

`super` 有两个用途，指向两个不同的对象：

- `super(...)`（构造器内）：调用父类构造器。子类构造器在调用它之前**不能访问 `this`**——因为 `this` 正是由父类构造器创建的。
- `super.method()`（方法内）：从**父类原型**上取方法并调用，`this` 仍是当前实例。

## 连接：`class` 与等价的构造函数写法

| | `class` 写法 | 等价的手工写法 |
|---|---|---|
| 定义 | `class C { m(){} }` | `function C(){}; C.prototype.m = function(){}` |
| 严格模式 | 恒为严格 | 随所在文件 |
| 提升 | TDZ，不提升 | 函数声明提升 |
| 裸调用 | 抛 `TypeError` | `this` 指向全局（非严格）或 `undefined`（严格） |
| 实例字段 | `x = 1` | 构造器里 `this.x = 1` |
| 私有 | `#x` | 闭包变量或 WeakMap |

两列在行为上等价，`class` 赢在把易错的部分（严格模式、`new` 检查、原型方法不可枚举）变成默认。

## 边界

- **`class` 不等于静态语言里的类**：方法定义在原型上、`this` 动态绑定、方法可被取出借用、类型检查仍然缺席（见 [7-TypeScript](../../7-TypeScript/)）。
- **`class` 不是唯一建对象的方式**：对象字面量 `{a: 1}` 与 `Object.create` 仍常用，尤其在不需要继承时——大多数 JavaScript 代码用组合而非继承。
- **私有字段是运行时机制，不是编译期**：`#v` 在引擎内部有独立的槽位，不经过原型链。需要跨实例共享私有状态时用闭包或 [04-属性描述符与元编程](../02-对象模型与运行时/04-属性描述符与元编程.md) 里的 `WeakMap`。
