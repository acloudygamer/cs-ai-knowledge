# 包管理深入

## npm

### package.json

```json
{
  "name": "my-package",
  "version": "1.0.0",
  "description": "A sample package",
  "main": "dist/index.js",
  "module": "dist/index.mjs",
  "types": "dist/index.d.ts",
  "exports": {
    ".": {
      "import": "./dist/index.mjs",
      "require": "./dist/index.js",
      "types": "./dist/index.d.ts"
    }
  },
  "sideEffects": false,
  "scripts": {
    "dev": "node dev.js",
    "build": "tsc",
    "test": "jest",
    "lint": "eslint src"
  },
  "keywords": ["utils", "helper"],
  "author": "Author Name",
  "license": "MIT",
  "repository": {
    "type": "git",
    "url": "git+https://github.com/user/repo.git"
  },
  "dependencies": {
    "lodash": "^4.17.21"
  },
  "devDependencies": {
    "typescript": "^5.0.0",
    "jest": "^29.0.0"
  },
  "peerDependencies": {
    "react": ">=17.0.0"
  },
  "optionalDependencies": {
    "fsevents": "^2.3.0"
  },
  "engines": {
    "node": ">=26.0.0",
    "npm": ">=10.0.0"
  },
  "files": [
    "dist",
    "README.md"
  ]
}
```

### 依赖版本

```json
{
  "dependencies": {
    "exact": "1.0.0",      // 精确版本
    "range": "^1.0.0",    // 兼容版本 (>=1.0.0 <2.0.0)
    "tilde": "~1.0.0",    // 补丁版本 (>=1.0.0 <1.1.0)
    "latest": "*",        // 最新版本
    "git": "git+https://github.com/user/repo.git#v1.0.0",
    "workspace": "workspace:*"
  }
}
```

### 常用命令

```bash
# 安装
npm install                    # 安装所有依赖
npm install lodash             # 安装到 dependencies
npm install -D jest            # 安装到 devDependencies
npm install -g typescript      # 全局安装
npm install --save-optional    # 安装到 optionalDependencies
npm install --legacy-peer-deps  # 忽略 peer deps 冲突

# 更新
npm update                     # 更新所有
npm update lodash              # 更新单个包
npm outdated                   # 检查过期

# 删除
npm uninstall lodash
npm uninstall -g typescript

# 查看
npm list                       # 列出已安装
npm list --depth=0             # 只显示顶层
npm list lodash                # 查看特定包
npm info lodash                # 查看包信息

# 发布
npm publish                    # 发布到 npm
npm publish --access public    # 发布公开包
npm deprecate lodash@1.0.0 "Deprecated"  # 弃用
```

### npm scripts

```bash
# 预置脚本
npm run prebuild   # build 之前自动运行
npm run postbuild  # build 之后自动运行

# 传递参数
npm run test -- --coverage  # 传递 --coverage 给 jest

# 环境变量
npm run greet      # echo $npm_config_msg (通过 --msg=hello 设置)
```

### npm 配置

```bash
# 查看配置
npm config list
npm config get registry

# 设置
npm config set registry https://registry.npmmirror.com
npm config set package-lock true

# .npmrc 文件
# 项目级: .npmrc
# 用户级: ~/.npmrc
# 全局: $(npm root -g)/../npmrc（Unix）或 npm_prefix/etc/npmrc（Windows）

# 常用配置
registry=https://registry.npmjs.org/
save-exact=true
engine-strict=true
```

## yarn

### 特点

- 离线缓存（本地 .yarn/cache）
- 并行安装
- 确定性依赖（yarn.lock）
- 简洁输出

### 常用命令

```bash
# 安装
yarn                         # 安装所有依赖
yarn add lodash               # 添加到 dependencies
yarn add -D jest              # 添加到 devDependencies
yarn add --optional           # optionalDependencies
yarn global add typescript    # 全局安装

# 更新
yarn up                       # 更新所有
yarn up lodash                # 更新单个包
yarn up -i                     # 交互式更新

# 删除
yarn remove lodash
yarn remove global typescript

# 查看
yarn list
yarn list --depth=0
yarn info lodash

# 锁定版本
yarn import                   # 从 package-lock.json 导入
yarn install --frozen-lockfile  # 强制使用 yarn.lock
```

### yarn workspaces

```json
// 根目录 package.json
{
  "name": "my-monorepo",
  "private": true,
  "workspaces": [
    "packages/*"
  ]
}
```

```bash
# 在根目录运行，会自动安装所有 workspace 的依赖
yarn install

# 工作目录
yarn workspace @my/package dev    # 在特定包运行脚本
yarn workspace @my/package add react
```

### yarn 配置

```yaml
# .yarnrc.yml
nodeLinker: node-modules    # 或 pnp (Plug'n'Play)
registry: https://registry.yarnpkg.com
savePrefix: "^"             # 版本前缀
```

## pnpm

### 特点

- 快速（复用已下载包）
- 节省磁盘空间（硬链接）
- 严格的依赖管理
- 支持 monorepo

### 常用命令

```bash
# 安装
pnpm install                 # 安装所有依赖
pnpm add lodash              # 添加到 dependencies
pnpm add -D jest             # devDependencies
pnpm add -g typescript       # 全局安装

# 更新
pnpm up                      # 更新所有
pnpm up lodash               # 更新单个包
pnpm up --latest             # 更新到最新版本

# 删除
pnpm remove lodash
pnpm remove -g typescript

# 查看
pnpm list
pnpm list --depth=0
pnpm outdated

# 其他
pnpm import                  # 从 yarn.lock 或 package-lock.json 导入
pnpm rebuild                 # 重新构建 native 模块
pnpm store prune            # 清理 store
pnpm store status           # 查看 store 状态
```

### pnpm workspace

```yaml
# pnpm-workspace.yaml
packages:
  - 'packages/*'
```

```bash
# 安装所有 workspace 依赖
pnpm install

# 在特定包运行
pnpm --filter @my/package dev

# 从 workspace 依赖
pnpm --filter @my/package add @my/utils
```

### 符号链接结构

```
node_modules/
├── .pnpm/
│   ├── lodash@4.17.21/
│   │   └── node_modules/lodash
│   └── express@4.18.2/
│       └── node_modules/express
└── lodash -> .pnpm/lodash@4.17.21/node_modules/lodash
```

## 依赖管理最佳实践

### 锁文件管理

```bash
# 始终提交 lock 文件
git add package-lock.json  # npm
git add yarn.lock          # yarn
git add pnpm-lock.yaml     # pnpm

# CI/CD 中使用 lock 文件
npm ci                     # 从 lock 文件安装（更快更安全）
yarn install --frozen-lockfile
pnpm install --frozen-lockfile
```

### 生产环境安全

```bash
# 审计
npm audit                   # 检查漏洞
npm audit fix               # 自动修复
npm audit --audit-level=high  # 高危才报告

# 仅安装生产依赖
npm ci --omit=dev
NODE_ENV=production npm ci

# 更新安全补丁
npm update --depth=5       # 安全更新
```

### 依赖分析

```bash
# 可视化依赖树
npm list --depth=2
npm ls --depth=2

# 找出重复依赖
npm ls lodash
deptree                     # 第三方工具

# 找出未使用的依赖
depcheck                    # 检查未使用的依赖
```

## Node.js 模块解析

### 模块路径规则

```javascript
// 1. 内置模块
const fs = require('fs');           // fs 模块

// 2. 文件模块（相对路径）
const utils = require('./utils');   // ./utils.js
const app = require('../app');     // ../app.js
const component = require('./components/Button');

// 3. 文件模块（绝对路径）
const config = require('/etc/config');

// 4. node_modules
const express = require('express');  // 查找 node_modules/express

// 解析顺序
// 1. 内置模块
// 2. 文件模块（相对/绝对路径）
// 3. node_modules（向上查找）
```

### require vs import

```javascript
// CommonJS
const fs = require('fs');
module.exports = { readFile };

// ESM
import fs from 'fs';
export { readFile };
```

### 条件导出

```javascript
// package.json
{
  "exports": {
    ".": {
      "types": "./dist/index.d.ts",
      "import": {
        "node": "./dist/index.mjs",
        "default": "./dist/index.mjs"
      },
      "require": {
        "node": "./dist/index.cjs",
        "default": "./dist/index.js"
      },
      "default": "./dist/index.js"
    },
    "./utils": "./dist/utils.js",
    "./package.json": "./package.json"
  }
}
```

## 私有包管理

### npmrc 配置

```ini
# .npmrc
@mycompany:registry=https://npm.pkg.github.com
//npm.pkg.github.com/:_authToken=${GITHUB_TOKEN}
```

### .npmrc 多镜像

```ini
# .npmrc
registry=https://registry.npmmirror.com
@myorg:registry=https://npm.mycompany.com
```

### verdaccio（私有 npm）

```yaml
# docker-compose.yml
version: '3'
services:
  verdaccio:
    image: verdaccio/verdaccio
    ports:
      - "4873:4873"
    volumes:
      - ./verdaccio:/verdaccio
```

```bash
# 启动
docker-compose up -d

# 配置 npm
npm config set registry http://localhost:4873

# 登录
npm adduser --registry http://localhost:4873

# 发布
npm publish --registry http://localhost:4873
```

## 常见问题

### 1. 删除 node_modules

```bash
# npm
rm -rf node_modules
npm install

# yarn
rm -rf node_modules
yarn install

# pnpm
rm -rf node_modules
pnpm install

# 一键删除
rm -rf node_modules package-lock.json && npm install
```

### 2. 清理缓存

```bash
npm cache clean --force
yarn cache clean
pnpm store prune
```

### 3. 修复损坏的安装

```bash
# 删除 lock 文件和 node_modules
rm -rf node_modules package-lock.json
npm install
```

### 4. 处理 peer dependencies 警告

```bash
# 安装匹配的 peer 版本
npm install peer@^1.0.0

# 或忽略警告
npm install --legacy-peer-deps
```

## 工具对比

| 特性 | npm | yarn | pnpm |
|------|-----|------|------|
| 安装速度 | 慢 | 中等 | 快 |
| 磁盘空间 | 大 | 中等 | 小 |
| lock 文件 | package-lock.json | yarn.lock | pnpm-lock.yaml |
| monorepo | 需 workspaces | workspaces | workspaces |
| 离线安装 | 不支持 | 支持 | 支持 |
| node_modules | 扁平 | 扁平 | 非扁平 |
