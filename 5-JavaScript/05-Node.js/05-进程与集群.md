# 进程与集群

## 进程的本质

进程是**资源分配的最小单位**：每个进程拥有独立的内存空间、文件描述符、CPU 上下文。Node.js 单进程利用事件循环在单线程中处理并发，但 CPU 密集型任务会阻塞事件循环。

## 子进程与 IPC

子进程诞生的本质是**操作系统进程树**：spawn/fork/exec 创建子进程，通过 pipe 或 IPC 通道实现父子通信。fork 复制父进程内存（写时复制），exec 用新程序替换子进程镜像。

```javascript
const { fork } = require('child_process');
const child = fork('./worker.js');
child.send({ cmd: 'compute', data: 42 });
child.on('message', (m) => console.log('result:', m));
```

## 集群的本质

集群的本质是**水平扩展**：多个进程监听同一端口，操作系统负载均衡器（SO_REUSEPORT）将请求分发到不同 worker，充分利用多核 CPU。

```javascript
const cluster = require('cluster');
if (cluster.isMaster) {
  cluster.fork();
  cluster.fork();
} else {
  http.createServer((req, res) => res.end('ok')).listen(3000);
}
```

## 流的本质

流的本质是**数据分块处理**：不必将整个文件/请求加载到内存，通过 pipe 连接读写阶段，实现背压控制和内存效率最大化。

```javascript
const { pipeline } = require('stream/promises');
const fs = require('fs');
pipeline(
  fs.createReadStream('bigfile.txt'),
  new Transform({ transform: (c, _, cb) => cb(null, c.toString().toUpperCase()) }),
  fs.createWriteStream('out.txt'),
  () => {}
);
```
