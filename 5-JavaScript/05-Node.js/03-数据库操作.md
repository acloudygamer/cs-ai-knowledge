# Node.js 数据库操作

## 数据库本质

**数据库是持久化数据的索引结构**：SQL 数据库以 B+ 树组织磁盘数据，保证范围查询和事务的 ACID 特性；NoSQL 数据库以 LSM 树（写优化）或文档模型（灵活 Schema）实现不同的读写权衡。

<pre>
SQL: B+ Tree ──────────▶ 磁盘页 ──▶ 索引覆盖
     (读优化)             随机 I/O

NoSQL (LSM): MemTable ──▶ WAL ──▶ SSTable
   (写优化)              顺序写
</pre>

## SQL 数据库连接

连接池的本质是**有限资源的复用**：预先建立 N 个连接，请求借出、用完归还，避免频繁创建/销毁连接的开销，同时限制最大并发数保护数据库。

```javascript
const { Pool } = require('pg');
const pool = new Pool({ max: 20, host: 'localhost' });
const { rows } = await pool.query('SELECT * FROM users WHERE id = $1', [id]);
await pool.end();
```

## MongoDB 文档模型

MongoDB 的本质是**无 Schema 的 BSON 文档集合**：文档自行包含完整结构，通过 MMAPv1/WiredTiger 引擎映射到磁盘，支持嵌套文档减少 JOIN 操作。

```javascript
const { MongoClient } = require('mongodb');
const client = new MongoClient('mongodb://localhost:27017');
const db = client.db('mydb');
await db.collection('users').insertOne({ name: 'Alice', email: 'a@b.com' });
```

## Redis 数据结构

Redis 的本质是**内存中的持久化字典**：每种数据结构（string/hash/list/set/zset）都有对应的编码实现（int/embstr/hashtable/ziplist/quicklist），在内存效率和操作复杂度间动态选择。

```javascript
const { createClient } = require('redis');
const client = createClient();
await client.set('key', 'value');
await client.hSet('user:1', { name: 'Alice' });
await client.lPush('queue', 'job1');
```

## 分布式锁

分布式锁的本质是**外部协调者的原子性承诺**：利用 Redis SET NX EX 原子操作获取锁，Lua 脚本保证释放锁时的值校验，防止误删他人持有的锁。

```javascript
const lockKey = `lock:${resourceId}`;
const lockValue = Date.now().toString();
await client.set(lockKey, lockValue, { NX: true, EX: 10 });
```
