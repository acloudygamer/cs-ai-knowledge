# Node.js 包管理

## npm（Node Package Manager）

### 基础命令

```bash
# 初始化项目
npm init
npm init -y  # 跳过问答，自动生成 package.json

# 安装包
npm install lodash              # 安装到生产依赖
npm install --save-dev jest    # 安装到开发依赖
npm install -D jest             # 同上，简写
npm install                      # 安装所有依赖

# 全局安装
npm install -g typescript

# 安装特定版本
npm install lodash@4.17.21
npm install lodash@">=4.0.0"

# 更新
npm update lodash
npm update                        # 更新所有

# 卸载
npm uninstall lodash
npm remove lodash

# 查看
npm list                          # 列出已安装包
npm list --depth=0                 # 只显示顶层
npm list lodash                    # 查看特定包
npm outdated                       # 查看过期包
```

### package.json

```json
{
  "name": "my-project",
  "version": "1.0.0",
  "description": "A project",
  "main": "index.js",
  "type": "module",
  "scripts": {
    "start": "node index.js",
    "dev": "nodemon index.js",
    "test": "jest",
    "build": "tsc",
    "lint": "eslint src",
    "prettier": "prettier --write src"
  },
  "keywords": ["node", "javascript"],
  "author": "Your Name",
  "license": "MIT",
  "dependencies": {
    "express": "^4.18.2",
    "lodash": "~4.17.21"
  },
  "devDependencies": {
    "jest": "^29.0.0",
    "nodemon": "^3.0.0"
  },
  "engines": {
    "node": ">=18.0.0",
    "npm": ">=9.0.0"
  }
}
```

### 版本规则

```json
{
  "dependencies": {
    "lodash": "4.17.21",      // 精确版本
    "express": "^4.18.2",     // ^ 允许次版本和补丁更新
    "chai": "~4.3.7",         // ~ 只允许补丁更新
    "prettier": ">=2.0.0",    // 最小版本
    "typescript": "*",        // 任意版本
    "dayjs": "2.x"            // x 占位符
  }
}
```

## Yarn

### 基础命令

```bash
# 安装
npm install -g yarn

# 初始化
yarn init

# 安装依赖
yarn add lodash                 # 生产依赖
yarn add --dev jest            # 开发依赖
yarn add -D jest
yarn install                    # 安装所有

# 更新
yarn upgrade lodash
yarn upgrade                    # 更新所有

# 移除
yarn remove lodash

# 脚本
yarn start
yarn test

# 包信息
yarn info lodash
yarn why lodash
```

### Yarn.lock

```bash
# Yarn 使用 yarn.lock 锁定版本
# 安装后生成/更新
yarn install

# 验证
yarn check
```

    "packages/*"
  ]

## pnpm

### 基础命令

```bash

# 安装依赖

pnpm add -D jest
pnpm install

pnpm update lodash

```

### 特性

```bash
# 更快（复用已下载的包）
# 更节省空间（硬链接）

# 单独运行脚本
pnpm --filter @scope/package run build
```

## npm 配置

### .npmrc 文件

```ini
# 项目级 .npmrc
registry=https://registry.npmjs.org/
save-exact=true
engine-strict=true

# 或用户级 ~/.npmrc
prefix=~/.npm-global
```

### npm config

```bash
# 查看配置
npm config list
npm config get registry

# 设置配置
npm config set registry https://registry.npmjs.org/
npm config set save-exact true

# 删除配置
npm config delete registry
```

### .nvmrc

```bash
# 指定 Node 版本
echo "18.16.0" > .nvmrc
nvm use
```

## 依赖管理

### 生产 vs 开发依赖

```bash
# 生产依赖（运行时需要）
npm install express
# dependencies: { "express": "^4.18.2" }

# 开发依赖（构建/测试时需要）
npm install --save-dev webpack
# devDependencies: { "webpack": "^5.0.0" }

# 区分环境安装
NODE_ENV=production npm install
# 生产环境下，devDependencies 不会被安装
```

### peerDependencies

```json
{
  "peerDependencies": {
    "react": ">=17.0.0",
    "react-dom": ">=17.0.0"
  }
}
```

### optionalDependencies

```json
{
  "optionalDependencies": {
    "fsevents": "^1.0.0"
  }
}
```

## 发布包

### 登录

```bash
npm login
npm adduser
```

### 发布

```bash
# 发布到 npm
npm publish

# 指定标签
npm publish --tag beta

# 私有包
npm publish --access restricted

# 更新版本
npm version patch      # 1.0.0 -> 1.0.1
npm version minor      # 1.0.0 -> 1.1.0
npm version major      # 1.0.0 -> 2.0.0
```

### 撤销发布

```bash
# 撤销（24小时内）
npm unpublish <package>@<version>
npm unpublish --force

# 弃用
npm deprecate <package>@<version> "Use <other-package> instead"
```

## 依赖安全

### npm audit

```bash
# 检查漏洞
npm audit

# 详细输出
npm audit --audit-level=high

# 自动修复
npm audit fix

# 强制修复
npm audit fix --force
```

### Snyk

```bash
# 安装
npm install -g snyk

# 认证
snyk auth

# 检查
snyk test
snyk test --file=package.json

# 修复
snyk protect
snyk fix
```

### GitHub Actions 集成

```yaml
# .github/workflows/security.yml
name: Security

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  security:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-node@v3
        with:
          node-version: '18'
      - run: npm ci
      - run: npm audit --audit-level=high
```
