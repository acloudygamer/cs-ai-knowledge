## 策略模式

### 定义

**策略模式是一种将一系列可互换算法封装为同一接口并由调用方选择使用的结构。**

### 数据流

<pre>
client ──setStrategy(strategy)──▶ ShoppingCart
                                        │
                                   cart.checkout()
                                        │
                                   strategy.pay(total)
</pre>

### 机制

将"使用哪个算法"的责任交给客户端（调用方），而不是在类内部 hardcode。策略类实现统一接口，客户端在运行时切换算法。优于 if/switch 分支在于：新增策略只需新增类，无需修改现有代码，符合开闭原则。

### 代码

```javascript
class PaymentStrategy {
  pay(amount) { throw Error('not implemented'); }
}
class CreditCardPayment extends PaymentStrategy {
  pay(amount) { return { success: true, method: 'credit_card' }; }
}
class PayPalPayment extends PaymentStrategy {
  pay(amount) { return { success: true, method: 'paypal' }; }
}
```

```javascript
class ShoppingCart {
  constructor() { this.items = []; this.strategy = null; }
  addItem(item) { this.items.push(item); }
  setStrategy(strategy) { this.strategy = strategy; }
  getTotal() { return this.items.reduce((s, i) => s + i.price, 0); }
  checkout() { return this.strategy.pay(this.getTotal()); }
}
```

```javascript
class Validator {
  constructor() { this.rules = new Map(); }
  addRule(field, rule) { this.rules.set(field, rule); return this; }
  validate(data) {
    const errors = [];
    for (const [field, rule] of this.rules) {
      if (!rule.validate(data[field])) errors.push({ field });
    }
    return { valid: errors.length === 0, errors };
  }
}
```

## 观察者模式

### 定义

**观察者模式是一种在对象状态变化时自动通知依赖对象列表的结构。**

### 数据流

<pre>
Subject.setState(newState)
         │
    observers.forEach
         │
    ┌────┴────┐
    ▼         ▼
 Observer   Observer
  .update()  .update()
</pre>

### 机制

Subject 维护 observers 列表，状态变更时遍历通知。核心价值是松耦合：Subject 无需知道观察者具体是谁，只负责"有变化就通知"。常用于事件系统、响应式数据流、消息推送等场景。

### 代码

```javascript
class Subject {
  constructor() { this.observers = new Set(); this.state = null; }
  attach(o) { this.observers.add(o); }
  detach(o) { this.observers.delete(o); }
  notify() { this.observers.forEach(o => o.update(this.state)); }
  setState(s) { this.state = s; this.notify(); }
}
```

```javascript
class Observer {
  update(state) { throw Error('not implemented'); }
}
class NewsChannel extends Observer {
  constructor(name) { super(); this.name = name; }
  update(news) { return `${this.name} received: ${news}`; }
}
```

```javascript
class EventEmitter {
  constructor() { this.events = new Map(); }
  on(event, listener) {
    if (!this.events.has(event)) this.events.set(event, new Set());
    this.events.get(event).add(listener);
  }
  emit(event, ...args) {
    this.events.get(event)?.forEach(l => l(...args));
  }
}
```

## 命令模式

### 定义

**命令模式是一种将请求封装为对象从而支持参数化、队列化或撤销操作的结构。**

### 数据流

<pre>
client ──execute(cmd)──▶ Invoker
                              │
                         cmd.execute()
                              │
                         Receiver.action()
</pre>

### 机制

每个 Command 实现 execute/undo 接口，Invoker 持有命令历史队列。调用方与接收方解耦，命令可以序列化后排队、日志记录、撤销/重做。MacroCommand 组合多个命令实现批操作。

### 代码

```javascript
class Command {
  execute() { throw Error('not implemented'); }
  undo() { throw Error('not implemented'); }
}
```

```javascript
class LightOnCommand extends Command {
  constructor(light) { super(); this.light = light; }
  execute() { return this.light.on(); }
  undo() { return this.light.off(); }
}
```

```javascript
class RemoteControl {
  constructor() { this.history = []; this.undone = []; }
  execute(cmd) { this.history.push(cmd); this.undone = []; return cmd.execute(); }
  undo() { const cmd = this.history.pop(); if (cmd) { this.undone.push(cmd); cmd.undo(); } }
  redo() { const cmd = this.undone.pop(); if (cmd) { this.history.push(cmd); cmd.execute(); } }
}
```

```javascript
class MacroCommand extends Command {
  constructor(commands) { super(); this.commands = commands; }
  execute() { this.commands.forEach(c => c.execute()); }
  undo() { [...this.commands].reverse().forEach(c => c.undo()); }
}
```
