## 单例模式

### 定义

**单例模式是一种保证类仅有一个实例的结构。**

### 数据流

<pre>
client ──new──▶ Singleton.constructor
                  │
                  ├─instance?──yes──▶ return instance
                  │
                  └─no──────────────▶ create instance → store → return
</pre>

### 机制

构造函数通过检查静态属性 `instance` 实现实例唯一性：首次构造时创建实例并缓存，后续构造直接返回缓存值。懒汉式延迟到首次使用时创建，饿汉式在类加载时就创建。闭包变体利用函数作用域隐藏实例变量，通过返回的 getter 函数访问，实现真正的私有化。

### 代码

```javascript
class Singleton {
  constructor() {
    if (Singleton.instance) return Singleton.instance;
    this.data = [];
    Singleton.instance = this;
  }
}
```

```javascript
class LazySingleton {
  constructor() {
    if (LazySingleton.instance) return LazySingleton.instance;
    this.data = [];
    LazySingleton.instance = this;
  }
}
```

## 工厂模式

### 定义

**工厂模式是一种将"创建哪个类"的选择权从调用方转移给子类的结构。**

### 数据流

<pre>
client ──type──▶ createUser(type)
                    │
         ┌──────────┼──────────┐
         ▼          ▼          ▼
       Admin      Guest      User
</pre>

### 机制

简单工厂用条件判断集中创建逻辑，调用方无需知道具体类名，但新增类型必须修改工厂。工厂方法将创建逻辑抽象为接口，子类决定实例化哪个具体类——调用方依赖接口而非实现，符合开闭原则。抽象工厂更进一步，将相关对象簇的创建组合成一个接口，确保产品族的配套性。

### 代码

```javascript
class User {}
class Admin extends User {}
class Guest extends User {}

function createUser(type) {
  if (type === 'admin') return new Admin();
  if (type === 'guest') return new Guest();
  return new User();
}
```

```javascript
class Dialog {
  createButton() { throw Error('not implemented'); }
  render() { return this.createButton(); }
}
class WindowsDialog extends Dialog {
  createButton() { return new WindowsButton(); }
}
class MacDialog extends Dialog {
  createButton() { return new MacButton(); }
}
```

## 建造者模式

### 定义

**建造者模式是一种将复杂对象的构建过程分解为独立步骤的结构。**

### 数据流

<pre>
client ──new──▶ Director.construct(builder)
                       │
                  builder.step1()
                       │
                  builder.step2()
                       │
                  builder.getResult()
                       │
                       ▼
                    Product
</pre>

### 机制

将"如何构建"（步骤顺序）与"构建什么"（具体逻辑）分离。Director 定义步骤顺序但不涉及具体构建细节，不同 Builder 实现同一接口可产出不同表示。流式 API 变体将 `this` 作为返回值使调用链式化，适合可选参数多的场景。

### 代码

```javascript
class Director {
  construct(builder) {
    builder.step1();
    builder.step2();
    return builder.getResult();
  }
}
```

```javascript
class CarBuilder {
  constructor() { this.car = {}; }
  step1() { this.car.body = 'sedan'; }
  step2() { this.car.engine = 'v6'; }
  getResult() { return this.car; }
}
```

```javascript
class QueryBuilder {
  constructor() { this.q = { select: [], from: '', where: [] }; }
  select(...f) { this.q.select.push(...f); return this; }
  from(t) { this.q.from = t; return this; }
  where(f, op, v) { this.q.where.push({ f, op }); this.q.params.push(v); return this; }
}
```
