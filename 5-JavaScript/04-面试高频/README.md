## 面试技巧

### 原理类问题

1. 先说出核心概念（一句话定义）
2. 再举例说明
3. 最后补充应用场景或注意事项

### 实现类问题

1. 先分析需求（输入输出）
2. 考虑边界情况
3. 写代码（先实现核心逻辑）
4. 测试用例验证

### 优化类问题

1. 说明问题所在（性能/内存）
2. 分析原因
3. 提供解决方案
4. 对比优化前后

## 常见考点

- **基础**：var/let/const、类型判断、作用域、闭包、this、原型链
- **异步**：Promise 状态、async/await、事件循环、微任务/宏任务
- **手写**：防抖节流、call/apply/bind、new、Promise、数组方法
- **框架**：响应式原理、虚拟 DOM、diff 算法、Hooks 原理
