# 计算机基础版本规则

执行任务前，先读取 versions.json 获取版本信息，结合以下规则判断是否标注。

## 环境版本

- Windows 11
- Ubuntu 24.04
- WSL 2.6
- PowerShell 7.6.0
- GNU Bash 5.2.21 (WSL)
- GNU Bash 5.2.37 (MINGW64)

## 标注判断

| 场景 | 是否标注 | 标注方式 |
|------|----------|----------|
| 内容涉及特定 shell 版本差异 | 是 | 标注具体 shell 版本 |
| 内容涉及 Windows/Linux 平台差异 | 是 | 标注 OS 版本 |
| 内容涉及 WSL 特有行为 | 是 | 标注 WSL 版本 |
| 通用概念（如 TCP/IP 协议） | 否 | 不标注环境 |

## 示例

### 需要标注
- Windows 终端的 ANSI 转义序列支持 (Windows 11)
- systemd 服务管理命令 (Ubuntu 24.04)
- WSL2 文件系统共享机制 (WSL 2.6)
- `$PSVersionTable` 仅 PowerShell 7.6.0 支持

### 不需要标注
- TCP/IP 五层模型
- 算法复杂度分析
- 通用数据结构和编程概念
