# 基准测试与性能

## 基准测试（Benchmark）

基准测试用于测量代码性能，发现性能瓶颈。

### 基本格式

```go
func BenchmarkFunction(b *testing.B) {
    // 重复执行 b.N 次
    for i := 0; i < b.N; i++ {
        // 被测试的代码
    }
}
```

### 运行基准测试

```bash
# 运行所有基准测试
go test -bench=.

# 运行指定基准测试
go test -bench=BenchmarkFunction

# 基准测试详细输出
go test -bench=. -benchmem

# 调整运行时间
go test -bench=. -benchtime=5s

# 运行多次取平均值
go test -bench=. -count=3
```

### 输出解读

```
BenchmarkStringConcat-8    1000000    1234 ns/op    512 B/op    8 allocs/op
```

| 列 | 含义 |
|----|------|
| `BenchmarkStringConcat-8` | 函数名，-8 表示 GOMAXPROCS = 8 |
| `1000000` | 运行次数（b.N） |
| `1234 ns/op` | 每次操作耗时 |
| `512 B/op` | 每次操作内存分配 |
| `8 allocs/op` | 每次操作分配次数 |

## 字符串拼接对比

```go
// 1. + 拼接
func BenchmarkStringConcat(b *testing.B) {
    for i := 0; i < b.N; i++ {
        s := ""
        for j := 0; j < 100; j++ {
            s += "hello"
        }
    }
}

// 2. strings.Builder
func BenchmarkBuilder(b *testing.B) {
    for i := 0; i < b.N; i++ {
        var builder strings.Builder
        for j := 0; j < 100; j++ {
            builder.WriteString("hello")
        }
        builder.String()
    }
}

// 3. bytes.Buffer
func BenchmarkBuffer(b *testing.B) {
    for i := 0; i < b.N; i++ {
        var buf bytes.Buffer
        for j := 0; j < 100; j++ {
            buf.WriteString("hello")
        }
        buf.String()
    }
}
```

### 典型结果

```
BenchmarkStringConcat-8      50000     31234 ns/op     524288 B/op     100 allocs/op
BenchmarkBuilder-8         500000      2345 ns/op        4096 B/op       1 allocs/op
BenchmarkBuffer-8          500000      2512 ns/op        4096 B/op       1 allocs/op
```

结论：`+` 拼接在大循环中极慢，Builder/Buffer 快 10 倍以上。

## 切片操作对比

```go
// 预分配 vs 动态追加
func BenchmarkSlicePrealloc(b *testing.B) {
    for i := 0; i < b.N; i++ {
        s := make([]int, 0, 1000)
        for j := 0; j < 1000; j++ {
            s = append(s, j)
        }
    }
}

func BenchmarkSliceDynamic(b *testing.B) {
    for i := 0; i < b.N; i++ {
        var s []int
        for j := 0; j < 1000; j++ {
            s = append(s, j)
        }
    }
}

// 遍历方式
func BenchmarkSliceIndex(b *testing.B) {
    s := make([]int, 10000)
    for i := 0; i < len(s); i++ {
        s[i] = i
    }
    b.ResetTimer()
    var sum int
    for i := 0; i < b.N; i++ {
        for i := 0; i < len(s); i++ {
            sum += s[i]
        }
    }
}

func BenchmarkSliceRange(b *testing.B) {
    s := make([]int, 10000)
    for i := 0; i < len(s); i++ {
        s[i] = i
    }
    b.ResetTimer()
    var sum int
    for i := 0; i < b.N; i++ {
        for _, v := range s {
            sum += v
        }
    }
}
```

## Map 操作对比

```go
// sync.Map vs Mutex + map
func BenchmarkSyncMap(b *testing.B) {
    var m sync.Map
    for i := 0; i < 1000; i++ {
        m.Store(i, i)
    }
    b.ResetTimer()
    for i := 0; i < b.N; i++ {
        m.Range(func(k, v any) bool {
            return true
        })
    }
}

func BenchmarkMutexMap(b *testing.B) {
    var mu sync.Mutex
    m := make(map[int]int)
    for i := 0; i < 1000; i++ {
        m[i] = i
    }
    b.ResetTimer()
    for i := 0; i < b.N; i++ {
        mu.Lock()
        for k, v := range m {
            _ = k + v
        }
        mu.Unlock()
    }
}
```

## 并发基准测试

```go
func BenchmarkParallel(b *testing.B) {
    // 告诉系统启用 parallel 测试
    b.RunParallel(func(pb *testing.PB) {
        counter := 0
        for pb.Next() {
            counter++
        }
    })
}

// 使用 Loop 简化循环（Go 1.24+）
func BenchmarkLoop(b *testing.B) {
    var sum int64
    b.Loop()
    for i := range 1000 {
        sum += int64(i)
    }
}
```

运行并行基准测试：

```bash
# 使用多个 CPU
go test -bench=. -parallel=4

# 限制 CPU 数
GOMAXPROCS=2 go test -bench=.
```

## 性能测试最佳实践

```go
// 1. 防止编译器优化
func BenchmarkXor(b *testing.B) {
    // 使用 blackhole 函数防止优化
    result := 0
    for i := 0; i < b.N; i++ {
        result ^= i
    }
    // 防止 result 被优化掉
    fmt.Fprint(io.Discard, result)
}

// 更好的方式：使用 testing.B
func BenchmarkXorBetter(b *testing.B) {
    result := 0
    for i := 0; i < b.N; i++ {
        result ^= i
    }
    b.ReportMetric(float64(result), "xor-result") // 报告结果
}

// 2. 重置计时器，排除初始化时间
func BenchmarkInit(b *testing.B) {
    setup := make([]int, 10000)  // 初始化，不计入时间
    b.ResetTimer()
    for i := 0; i < b.N; i++ {
        process(setup)
    }
}

// 3. 正确比较
// 差：每次分配新对象
func BenchmarkBad(b *testing.B) {
    for i := 0; i < b.N; i++ {
        buf := bytes.NewBuffer(make([]byte, 0, 1024))
        // ...
    }
}

// 好：复用对象
func BenchmarkGood(b *testing.B) {
    buf := bytes.NewBuffer(make([]byte, 0, 1024))
    for i := 0; i < b.N; i++ {
        buf.Reset()
        // ...
    }
}
```

## 回归测试

```bash
# 保存基准测试结果
go test -bench=. -benchmem > baseline.txt

# 修改代码后再次运行
go test -bench=. -benchmem > current.txt

# 对比
diff baseline.txt current.txt
```

## 压力测试（Stress Testing）

Go 没有内置压力测试，但可以用 `policeman` 或自己实现：

```go
func TestConcurrentAccess(t *testing.T) {
    const numGoroutines = 1000
    const numOps = 100

    var wg sync.WaitGroup
    wg.Add(numGoroutines)

    for i := 0; i < numGoroutines; i++ {
        go func() {
            defer wg.Done()
            for j := 0; j < numOps; j++ {
                // 并发操作
            }
        }()
    }

    wg.Wait()
}
```
