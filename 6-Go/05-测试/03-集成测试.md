# 集成测试

## 集成测试 vs 单元测试

| 维度 | 单元测试 | 集成测试 |
|------|----------|----------|
| 范围 | 独立函数/方法 | 多个组件协作 |
| 依赖 | Mock 外部依赖 | 真实依赖（DB、HTTP） |
| 速度 | 快（毫秒级） | 慢（可能秒级） |
| 位置 | `*_test.go` | 单独目录或 tag |

## HTTP Handler 测试

### 使用 net/http/httptest

```go
import (
    "net/http"
    "net/http/httptest"
    "testing"
)

func TestHealthHandler(t *testing.T) {
    req := httptest.NewRequest(http.MethodGet, "/health", nil)
    rec := httptest.NewRecorder()

    HealthHandler(rec, req)

    if rec.Code != http.StatusOK {
        t.Errorf("expected status 200, got %d", rec.Code)
    }

    if rec.Body.String() != `{"status":"ok"}` {
        t.Errorf("unexpected body: %s", rec.Body.String())
    }
}
```

### 测试 JSON API

```go
func TestCreateUser(t *testing.T) {
    // 准备请求
    body := `{"name":"tom","email":"tom@example.com"}`
    req := httptest.NewRequest(
        http.MethodPost,
        "/users",
        strings.NewReader(body),
    )
    req.Header.Set("Content-Type", "application/json")
    rec := httptest.NewRecorder()

    // 执行
    CreateUserHandler(rec, req)

    // 验证
    if rec.Code != http.StatusCreated {
        t.Errorf("expected 201, got %d: %s", rec.Code, rec.Body.String())
    }

    var resp UserResponse
    if err := json.Unmarshal(rec.Body.Bytes(), &resp); err != nil {
        t.Fatalf("invalid JSON: %v", err)
    }

    if resp.Name != "tom" {
        t.Errorf("expected name 'tom', got '%s'", resp.Name)
    }
}
```

### 测试中间件

```go
func TestAuthMiddleware(t *testing.T) {
    gin.SetMode(gin.TestMode)
    r := gin.New()
    r.Use(AuthMiddleware())
    r.GET("/protected", func(c *gin.Context) {
        c.JSON(200, gin.H{"user": c.GetString("userID")})
    })

    t.Run("无 token", func(t *testing.T) {
        req := httptest.NewRequest(http.MethodGet, "/protected", nil)
        rec := httptest.NewRecorder()
        r.ServeHTTP(rec, req)

        if rec.Code != http.StatusUnauthorized {
            t.Errorf("expected 401, got %d", rec.Code)
        }
    })

    t.Run("有效 token", func(t *testing.T) {
        req := httptest.NewRequest(http.MethodGet, "/protected", nil)
        req.Header.Set("Authorization", "Bearer valid-token")
        rec := httptest.NewRecorder()
        r.ServeHTTP(rec, req)

        if rec.Code != http.StatusOK {
            t.Errorf("expected 200, got %d", rec.Code)
        }
    })
}
```

## 数据库集成测试

### 测试数据库设置

```go
import (
    "database/sql"
    _ "github.com/go-sql-driver/mysql"
)

func setupTestDB(t *testing.T) *sql.DB {
    // 使用测试数据库
    db, err := sql.Open("mysql", "root:test@/testdb?parseTime=true")
    if err != nil {
        t.Fatalf("failed to connect: %v", err)
    }

    // 运行迁移
    _, err = db.Exec(`
        CREATE TABLE IF NOT EXISTS users (
            id INT AUTO_INCREMENT PRIMARY KEY,
            name VARCHAR(255) NOT NULL,
            email VARCHAR(255) UNIQUE
        )
    `)
    if err != nil {
        t.Fatalf("failed to migrate: %v", err)
    }

    return db
}

func cleanupTestDB(t *testing.T, db *sql.DB) {
    db.Exec("DROP TABLE IF EXISTS users")
    db.Close()
}
```

### 使用事务隔离

```go
func TestUserRepository(t *testing.T) {
    db := setupTestDB(t)
    defer cleanupTestDB(t, db)

    repo := NewUserRepository(db)

    t.Run("Create and Get", func(t *testing.T) {
        // 每个测试用独立事务
        tx, err := db.Begin()
        if err != nil {
            t.Fatal(err)
        }
        defer tx.Rollback()

        user := &User{Name: "Tom", Email: "tom@example.com"}
        if err := repo.WithTx(tx).Create(user); err != nil {
            t.Fatalf("create failed: %v", err)
        }

        fetched, err := repo.WithTx(tx).GetByID(user.ID)
        if err != nil {
            t.Fatalf("get failed: %v", err)
        }

        if fetched.Name != "Tom" {
            t.Errorf("expected Tom, got %s", fetched.Name)
        }
    })
}
```

### 使用 go-sqlmock

```go
import (
    "database/sql"
    "testing"
    "github.com/DATA-DOG/go-sqlmock"
)

func TestUserRepo(t *testing.T) {
    db, mock, err := sqlmock.New()
    if err != nil {
        t.Fatalf("failed to create mock: %v", err)
    }
    defer db.Close()

    repo := NewUserRepository(db)

    t.Run("Create User", func(t *testing.T) {
        mock.ExpectExec("INSERT INTO users").
            WithArgs("Tom", "tom@example.com").
            WillReturnResult(sqlmock.NewResult(1, 1))

        err := repo.Create(&User{Name: "Tom", Email: "tom@example.com"})
        if err != nil {
            t.Errorf("unexpected error: %v", err)
        }

        if err := mock.ExpectationsWereMet(); err != nil {
            t.Errorf("unfulfilled expectations: %v", err)
        }
    })
}
```

## HTTP 客户端集成测试

### 使用 httptest.NewServer

```go
func TestExternalAPI(t *testing.T) {
    // 创建测试服务器
    ts := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        if r.URL.Path != "/api/data" {
            t.Errorf("unexpected path: %s", r.URL.Path)
        }
        w.Header().Set("Content-Type", "application/json")
        w.Write([]byte(`{"result":"ok"}`))
    }))
    defer ts.Close()

    // 客户端指向测试服务器
    client := NewClient(ts.URL)

    result, err := client.FetchData()
    if err != nil {
        t.Fatalf("fetch failed: %v", err)
    }

    if result != "ok" {
        t.Errorf("expected ok, got %s", result)
    }
}
```

## 网络延迟和超时测试

```go
func TestTimeoutHandling(t *testing.T) {
    ts := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        time.Sleep(200 * time.Millisecond)
        w.Write([]byte("done"))
    }))
    defer ts.Close()

    client := NewClient(ts.URL)

    t.Run("超时返回错误", func(t *testing.T) {
        ctx, cancel := context.WithTimeout(context.Background(), 100*time.Millisecond)
        defer cancel()

        _, err := client.FetchWithContext(ctx)
        if err == nil {
            t.Error("expected timeout error")
        }
    })
}
```

## 测试建议

1. **分层测试**：单元测试覆盖核心逻辑，集成测试覆盖组件协作
2. **测试真实场景**：模拟网络波动、数据库故障等
3. **独立可重复**：每个测试可以独立运行，不依赖执行顺序
4. **快速反馈**：CI 中分离快测试和慢测试
5. **失败排错**：详细的日志和错误信息
