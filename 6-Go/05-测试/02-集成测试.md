# 集成测试

**集成测试是通过真实依赖验证多个组件协作正确性的机制。**

## 本质

单元测试用 Mock 隔离依赖，集成测试则使用真实依赖（数据库、HTTP 服务）验证组件间交互的正确性。Go 标准库提供 `net/http/httptest` 模拟 HTTP 端点，通过 build tags 区分单元测试和集成测试。

## 机制

### HTTP Handler 测试

`httptest.NewRecorder()` 捕获 Handler 响应而非发起真实网络请求。`httptest.NewRequest()` 构造测试请求。

```
请求 → httptest.NewRequest → Handler → httptest.NewRecorder → 验证 response
```

### 事务隔离

集成测试中每个测试使用独立事务，测试完成后回滚，保证测试间互不污染数据库状态。

```
begin → 测试操作 → rollback →下一测试
```

### Testcontainers

`testcontainers-go` 启动真实 Docker 容器运行数据库等依赖，测试在真实环境中执行，代价是速度慢（秒级 vs 毫秒级）。

```go
pgContainer, _ := postgres.Run(ctx, "postgres:15-alpine")
defer pgContainer.Terminate(ctx)
connStr, _ := pgContainer.ConnectionString(ctx)
```

## 验证标准

- 使用 `httptest.NewServer` 模拟外部 HTTP 依赖
- 每个测试使用独立事务或独立数据库
- 慢测试通过 build tags 标记，在 CI 中分离执行
