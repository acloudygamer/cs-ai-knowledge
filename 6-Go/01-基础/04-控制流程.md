# 控制流程

Go 的控制流程设计遵循极简原则：只有一种循环语法 `for`，`switch` 不需要 `break`（默认 break，可贯穿）。这种设计消除了 C 系语言中常见的漏写 break 导致的行为错误。

## if/else

`if` 条件必须是布尔值，不支持隐式转型。条件前可包含短语句（初始化）。

### 参考样例

```go
if age := 30; age >= 18 {
    fmt.Println("成年")
} else {
    fmt.Println("未成年")
}

// 条件表达式前可以有短语句（初始化）
if err := doSomething(); err != nil {
    fmt.Println(err)
}
```

## switch

Go 的 switch 不需要 break（默认自动 break），除非使用 `fallthrough` 贯穿。可以没有变量，等同于 if-else 链。

### 参考样例

```go
lang := "go"
switch lang {
case "go":
    fmt.Println("Golang")
case "py":
    fmt.Println("Python")
default:
    fmt.Println("Unknown")
}

// 一个 case 可以匹配多个值
switch n {
case 1, 3, 5:
    fmt.Println("奇数")
}

// switch 后面不加变量，等同于 if-else
age := 25
switch {
case age < 18:
    fmt.Println("未成年")
case age < 30:
    fmt.Println("青年")
}
```

## for 循环（Go 只有这一种循环）

`for` 是 Go 唯一的循环语法，涵盖标准 for、死循环和 for range。

### 参考样例

```go
// 标准形式
for i := 0; i < 10; i++ {
    fmt.Println(i)
}

// 省略初始和结束语句
i := 0
for i < 10 {
    i++
}

// 省略所有 — 死循环
for {
    // 会无限循环，需要 break 或 return 退出
}

// for range
nums := []int{1, 2, 3, 4, 5}
for i, v := range nums {
    fmt.Printf("索引:%d, 值:%d\n", i, v)
}

// for range 整数（Go 1.22+）
for i := range 10 {
    fmt.Println(i)  // 0, 1, 2, ..., 9
}

// 遍历 map
m := map[string]int{"go": 30, "py": 25}
for k, v := range m {
    fmt.Printf("key:%s, value:%d\n", k, v)
}

// 遍历字符串（得到 rune）
str := "Hello世界"
for i, r := range str {
    fmt.Printf("位置:%d, 字符:%c\n", i, r)
}
```

## for range 循环变量作用域（Go 1.22 修复）

Go 1.22 修复了经典的循环变量作用域 bug：之前版本中 for range 的循环变量是共享的，现在每次迭代创建新变量。

### 参考样例

```go
// Go 1.21 之前（bug）：所有 goroutine 共享同一个 i
var funcs []func()
for i := 0; i < 3; i++ {
    funcs = append(funcs, func() { fmt.Println(i) })
}
for _, f := range funcs {
    f()  // 输出: 3, 3, 3（错误）
}

// Go 1.22：每次循环 i 是新变量
for i := 0; i < 3; i++ {
    funcs = append(funcs, func() { fmt.Println(i) })
}
for _, f := range funcs {
    f()  // 输出: 0, 1, 2（正确）
}
```
