# 控制流程

## 本质断言

Go 的控制流程设计遵循极简原则：只有一种循环语法 `for`，`switch` 不需要 `break`（默认 break，可贯穿）。这种设计通过**语法约束**消除了 C 系语言中常见的漏写 break 导致的行为错误，同时通过 for range 提供对容器类型的统一遍历抽象。

## 数学模型

### for 循环的复杂度

标准 for 循环：
$$T(n) = O(1) + n \times O(\text{body})$$

for range 循环（切片/数组）：
$$T(n) = O(1) + n \times O(1) = O(n)$$

for range 循环（map）：
$$T(n) = O(n) \text{（遍历顺序不确定）}$$

for range 循环（channel）：
$$T(n) = O(\text{元素数}) \text{ 或 } O(\infty) \text{（阻塞）}$$

### switch 的模式匹配复杂度

switch 表达式求值 + case 匹配：
$$T(\text{switch}) = O(\text{expr}) + O(\text{matched\_case})$$

Go 1.21+ 的编译器优化：若 case 为常量且可排序，使用二分查找，复杂度降为 $O(\log n)$。

### for range 整数循环的语义

Go 1.22+ 的 `for i := range n` 等价于：

```go
for i := 0; i < n; i++ { /* body */ }
```

这是 `for i := range [n]int{}[:]` 的语法糖，底层仍是数组遍历。

**形式化语义**：整数 range 展开为：

```go
// 编译器展开（Go 1.22+）
for i := 0; i < n; i++ {
    i := i  // 每次迭代创建新变量，避免闭包陷阱
    /* body */
}
```

**约束条件**：
- 遍历范围 $[0, n)$，不包含 $n$
- 若 $n < 0$，循环体不执行（空区间）
- $n$ 必须是整数类型（int），不接受浮点数

## 对比参照

### 控制流原语的对比表

| 维度 | for（标准） | for range | switch | if | 死循环 |
|------|-------------|-----------|--------|-----|--------|
| **适用场景** | 精确计数/自定义步进 | 遍历容器/通道 | 多值匹配/条件分支 | 单一条件判断 | 事件循环/长期运行 |
| **终止条件** | 布尔表达式为 false | 容器耗尽/通道关闭 | 首个匹配 case + break | else 分支执行 | 永不（需 break/goto/panic） |
| **循环变量** | 手动管理 | 自动声明新变量（Go 1.22+） | 无 | 无 | 无 |
| **贯穿语义** | 不适用 | 不适用 | 默认不贯穿（需 fallthrough） | 不适用 | 不适用 |
| **默认 break** | 需要显式 | 需要显式（channel 除外） | 自动 | 自动 | 不适用 |
| **复杂度** | $O(n)$ 或 $O(\text{body})$ | $O(n)$（map 除外） | $O(1)$~ $O(\log n)$ | $O(1)$ | $O(\infty)$ |

**for range 遍历语义的数学约束**：

| 容器类型 | 索引/键的数据形态 | 值的数据形态 | 遍历复杂度 | 顺序确定性 |
|----------|------------------|-------------|-----------|-----------|
| 数组 `[n]T` | `int`（0 到 n-1） | `T`（副本） | $O(n)$ | 确定性（索引顺序） |
| 切片 `[]T` | `int`（0 到 len-1） | `T`（副本） | $O(n)$ | 确定性（索引顺序） |
| map `map[K]V` | `K`（键类型） | `V`（副本） | $O(n)$ | 伪随机（哈希桶随机起始） |
| string | `int`（字节索引） | `rune`（Unicode 码点） | $O(n)$ | 确定性（字节顺序） |
| channel `chan T` | 无索引 | `T`（接收值） | 阻塞直到关闭 | 不适用（串行） |

## 机制

### 为什么 Go 不需要 break（默认）

Go 的 switch 的**默认 break** 语义消除了 C 系语言的常见 bug：

```c
// C: 漏写 break 导致贯穿（常见 bug）
switch (x) {
    case 1: doOne();  // 没有 break！
    case 2: doTwo(); break;
}
```

```go
// Go: 默认不贯穿，必须显式 fallthrough
switch x {
case 1: doOne()      // 不会贯穿到 case 2
case 2: doTwo()
}
```

这使得代码意图更清晰——fallthrough 是显式的，需要开发者明确声明。

### 为什么 Go 1.22 修复循环变量作用域

Go 1.21 及之前，for range 的循环变量是**共享的**：

```go
// Go 1.21 及之前（bug）
for i := range 3 {
    go func() { fmt.Println(i) }()
}
// 输出: 3, 3, 3  ← i 是共享变量
```

Go 1.22 修复后，每次迭代的 `i` 是**新变量**：

```go
// Go 1.22+（正确）
for i := range 3 {
    go func() { fmt.Println(i) }()
}
// 输出: 0, 1, 2  ← 每次迭代 i 是独立的
```

**形式化语义**：`for range` 现在等价于：

```go
for i := 0; i < 3; i++ {
    i := i  // Go 1.22+: 每次迭代创建新变量
    go func() { fmt.Println(i) }()
}
```

### 为什么 map 遍历顺序不确定

map 的哈希表实现导致遍历顺序**伪随机**：
- 哈希桶按哈希值排序，而非插入顺序
- 每次遍历从随机桶开始
- 这防止了程序对遍历顺序产生依赖

若需要有序遍历，必须使用**切片**存储键并排序。

### 为什么 channel range 会阻塞

`for v := range ch` 等价于：

```go
for {
    v, ok := <-ch
    if !ok { break }
    // 使用 v
}
```

当 channel 关闭且无数据时，`ok = false`，循环退出。

## if / else

条件必须是布尔值，不支持隐式转型。条件前可包含短语句（初始化）。

```go
if age := 30; age >= 18 {
    fmt.Println("成年")
} else {
    fmt.Println("未成年")
}
```

## switch

Go 的 switch 不需要 break（默认自动 break），除非使用 `fallthrough` 贯穿。

<pre>
switch 匹配流程:
  ┌─────────────────────────────┐
  │  case "go":  fmt.Println()  │
  │       ↓                    │
  │  自动 break (不继续匹配)    │
  └─────────────────────────────┘

fallthrough 贯穿:
  ┌─────────────────────────────┐
  │  case 1:                    │
  │       ↓ fallthrough         │
  │  case 2:  ← 继续执行       │
  └─────────────────────────────┘
</pre>

```go
lang := "go"
switch lang {
case "go":   fmt.Println("Golang")
case "py":   fmt.Println("Python")
default:     fmt.Println("Unknown")
}

switch {
case age < 18:  fmt.Println("未成年")
case age < 30:  fmt.Println("青年")
}
```

## for 循环

`for` 是 Go 唯一的循环语法，涵盖标准 for、死循环和 for range。

```go
for i := 0; i < 10; i++ { fmt.Println(i) }
for i < 10 { i++ }                      // 省略初始和结束
for { /* 死循环 */ }                     // 省略所有
```

## for range

for range 遍历切片、数组、map、字符串（得到 rune）。

```go
nums := []int{1, 2, 3}
for i, v := range nums { fmt.Println(i, v) }

m := map[string]int{"go": 30}
for k, v := range m { fmt.Println(k, v) }

str := "Hello世界"
for i, r := range str { fmt.Println(i, r) }
```

## for range 整数（Go 1.22+）

Go 1.22 起支持整数 range，直接遍历 0 到 n-1。

```go
for i := range 10 { fmt.Println(i) }   // 0-9
```

## 循环变量作用域修复（Go 1.22）

Go 1.22 修复了 for range 的经典 bug：之前版本循环变量共享，现在每次迭代创建新变量。

<pre>
Go 1.21 之前（bug）:
  for i := range 3 {
      go func() { fmt.Println(i) }()    // 所有goroutine共享 i
  }
  输出: 3, 3, 3

Go 1.22+（正确）:
  for i := range 3 {
      go func() { fmt.Println(i) }()    // 每次迭代 i 是新变量
  }
  输出: 0, 1, 2
</pre>

```go
for i := 0; i < 3; i++ {
    funcs = append(funcs, func() { fmt.Println(i) })
}
```
