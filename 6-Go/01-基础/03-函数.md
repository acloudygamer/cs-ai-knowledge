# 函数

Go 函数的独特价值在于多返回值机制——特别是 `(result, error)` 模式，使错误处理成为函数签名的显式组成部分而非异常机制。defer 关键字实现 LIFO 语义的资源清理，闭包则允许函数捕获并持久化外部变量状态。

## 多返回值

函数可返回多个值，error 作为最后一个返回值是 Go 的惯用约定。

```go
func divide(a, b int) (int, error) {
    if b == 0 { return 0, errors.New("div by zero") }
    return a / b, nil
}
result, err := divide(10, 2)
```

## 命名返回值

返回值作为命名变量在函数体中使用，return 省略变量名。

```go
func split(sum int) (x, y int) {
    x = sum * 4 / 9
    y = sum - x
    return
}
```

## 可变参数

`...T` 语法使函数接受同类型任意数量的参数，内部作为切片处理。

```go
func sum(nums ...int) int {
    total := 0
    for _, n := range nums { total += n }
    return total
}
sum(1, 2, 3)
```

传切片给可变参数需解包：

```go
vals := []int{1, 2, 3}
sum(vals...)
```

## 闭包

闭包是捕获了外部作用域变量的函数，变量状态在闭包调用间持久化。

<pre>
闭包捕获外部变量:
  sum := 0
  ┌─────────────────────┐
  │ func(x int) int    │
  │   sum += x         │────┼──→ 捕获 sum（持久化）
  │   return sum       │
  └─────────────────────┘
</pre>

```go
func adder() func(int) int {
    sum := 0
    return func(x int) int {
        sum += x
        return sum
    }
}
pos := adder()
pos(1)                       // 1
pos(2)                       // 3
```

## defer 延迟执行

defer 在函数退出前按 LIFO（后进先出）顺序执行。

<pre>
函数退出顺序:
  defer "3"  (最后定义)
  defer "2"
  defer "1"  (最先定义)
  输出: 3 → 2 → 1
</pre>

```go
defer fmt.Println("1")
defer fmt.Println("2")
defer fmt.Println("3")
// 输出: 3 2 1
```

defer 常用场景：文件关闭、锁解锁、连接关闭。

```go
file, _ := os.Open("test.txt")
defer file.Close()
mu.Lock()
defer mu.Unlock()
```

## 函数作为值

函数是一等公民，可作为参数、返回值和变量值。

```go
apply := func(fn func(int) int, x int) int {
    return fn(x)
}
apply(func(x int) int { return x * 2 }, 5)  // 10
```

## 函数式选项模式

用函数配置结构体，支持可选参数和默认值。

```go
type Option func(*Server)
func WithPort(port int) Option {
    return func(s *Server) { s.port = port }
}
func NewServer(opts ...Option) *Server {
    s := &Server{port: 8080}
    for _, opt := range opts { opt(s) }
    return s
}
server := NewServer(WithPort(9090))
```

## 错误处理约定

Go 约定返回 error 而非 panic，错误作为最后一个返回值。

```go
func DoSomething() error { return nil }
func Process() (Result, error) { return Result{}, nil }
```
