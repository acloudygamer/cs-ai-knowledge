# 面向对象

## 定义

Go 没有类（class），但通过结构体（struct）、方法（method）和接口（interface）提供了完整的面向对象编程能力。Go 的 OOP 哲学是：**组合优于继承**、**接口优于继承**、**Duck Typing 隐式实现**。

Go 的 OOP 本质上是**基于组合的消息传递**——对象是行为的集合而非数据的容器，类型间关系通过接口契约而非继承树确定。

## 数学模型

### 接口实现的静态分发

Go 的接口实现是**静态分发**的：编译器在编译时完成接口与实现类型的匹配检查，无需运行时类型查询。

设接口 $I$ 定义方法集 $M_I = \{m_1, m_2, \ldots, m_k\}$，类型 $T$ 的方法集为 $M_T$。若 $M_I \subseteq M_T$，则 $T$ 隐式实现 $I$。这是**子集关系判定**，而非继承层次结构的运行时调度。

$$\text{Implements}(T, I) \iff M_I \subseteq M_T$$

**方法集包含关系的判定算法**（编译时）：

```
function Contains(T_method_set, I_method_set):
    for each method m in I_method_set:
        if m not in T_method_set:
            return false
        if m has different signature in T:
            return false
    return true
```

### 接口的内存表示

非空接口（`interface{}`/`any`）在内存中表示为**两个指针的结构体**（iface）：

```
┌─────────────────────────────────────────────────────────────┐
│ iface 结构（16 字节，64位系统）                             │
├──────────────────────┬──────────────────────────────────────┤
│ tab *itab            │  data *unsafe.Pointer                │
│ (指向方法表)          │  (指向具体值的副本)                 │
└──────────────────────┴──────────────────────────────────────┘
```

空接口（`interface{}`/`any`）表示为两个 nil 或数据的指针。

**itab 结构**（src/runtime/runtime2.go）：

```go
type itab struct {
    inter *interfacetype  // 接口类型
    _type *_type          // 具体类型
    hash  uint32          // 具体类型的哈希（快速类型断言）
    fun   [1]uintptr      // 方法指针数组（变长）
}
```

### 指针接收者的方法集扩展

对于类型 `T` 和指针 `*T`：

$$M_T \subseteq M_{*T}$$

指针接收者方法集包含值接收者方法集（但反之不成立）。这允许 `*T` 方法修改对象，而 `T` 方法只能读取副本。

**形式化证明**：
- 值接收者方法 `(p T) Method()` 不修改 `p`，可作用于副本
- 指针接收者方法 `(p *T) Method()` 可能修改 `*p`，需要 `p` 指向原对象
- 任何能调用 `T.Method()` 的地方，也能调用 `(*T).Method()`（编译器自动转换）

**归约终点**：Go 的 OOP 可归约为**方法集合的包含关系**：
- 接口是方法集的抽象
- 结构体是数据字段的聚合
- 组合是嵌入式字段的方法提升
- Duck Typing 是编译器对子集关系的静态验证

## 机制

### 组合 vs 继承的本质差异

**继承**建立 **is-a** 关系：子类 is a 超类，继承链是编译时绑定的静态契约。

Go 放弃继承的原因：
1. **钻石问题**：多重继承的语言需要虚继承解决二义性，Go 放弃继承彻底规避此问题
2. **脆弱基类**：子类依赖父类实现细节，父类变化可能破坏子类
3. **静态耦合**：继承是编译时绑定，无法在运行时替换组件

**组合**建立 **has-a** 关系：对象包含其他对象，通过委托实现行为复用。

组合的优势：
- **运行时替换**：组件可在运行时替换（接口多态）
- **松耦合**：对象间通过接口通信，不依赖具体类型
- **显式委托**：方法调用明确，无隐式继承链

**方法提升**是组合的特殊形式：匿名嵌入字段的方法可直接调用，等价于继承的方法访问，但方法集在编译时静态确定，不存在运行时虚表查找。

### Duck Typing 的编译时验证

其他语言的 Duck Typing（如 Python）是**运行时动态验证**。Go 的 Duck Typing 是**编译时静态检查**——任何类型只要实现了接口的所有方法，无需任何声明即满足接口。

**松耦合架构的数学基础**：
- 接口定义者无需知道实现者
- 实现者无需声明实现
- 第三方库可以定义新接口，现有类型无需修改即可满足

这产生了**插件架构**的可能性：同一接口可有无数实现，运行时装载。

### 指针接收者 vs 值接收者的语义

- **值接收者**：`func (p Point) Distance()` 接收结构的副本，不修改原对象
- **指针接收者**：`func (p *Point) Scale()` 接收指向原对象的指针，可修改原对象

Go 编译器自动在两者间转换：
- 调用值接收者方法时，指针会自动解引用
- 调用指针接收者方法时，值会自动取地址（前提是值是可寻址的）

**约束**：若方法需要修改对象状态，必须用指针接收者；否则两者皆可。习惯上始终使用指针接收者，除非明确需要副本语义。

### 空接口的危险性

`interface{}`（Go 1.18+ 为 `any`）可以承载任意类型，丧失类型安全：

```go
var i interface{} = "hello"
s := i.(string)  // 安全，但 i 可能是任何类型
n, ok := i.(int)  // ok=false，不 panic
```

当代码中出现 `interface{}` 时，失去了编译时类型检查的保护。

**替代方案**：Go 1.18+ 引入泛型后，许多 `interface{}` 用法可用 `any` 约束的泛型替代，在编译时保留类型信息。

### 接口组合 vs 结构体组合

**接口组合**（嵌入接口）：

```go
type Reader interface {
    Read(p []byte) (n int, err error)
}

type Closer interface {
    Close() error
}

type ReadCloser interface {
    Reader  // 嵌入接口方法集
    Closer
}
```

接口组合是方法集的并集：
$$M_{\text{ReadCloser}} = M_{\text{Reader}} \cup M_{\text{Closer}}$$

**结构体组合**（嵌入结构体）：

```go
type ReadCloser struct {
    Reader
    Closer
}
```

结构体组合是方法提升：编译器为每个嵌入接口方法生成包装方法。

## 对比参照

| 属性 | Go struct+interface | 传统类继承 (Java/C++) |
|------|---------------------|----------------------|
| 类型关系 | 接口契约（静态检查） | 类继承树（编译+运行时） |
| 多态分发 | 编译时静态 | 运行时虚表查找 |
| 方法扩展 | 组合+提升 | 继承+重写 |
| 耦合度 | 低（接口解耦） | 高（继承链紧耦合） |
| 空值安全 | nil receiver 安全 | 需要 try-catch 或 Optional |
| 组合 vs 继承 | 优先组合 | 继承优先 |

## 参考存根

```go
// 接口定义（仅声明方法集）
type Shape interface {
    Area() float64
    Perimeter() float64
}

// 值接收者方法（不修改）
func (r Rectangle) Area() float64 { return r.Width * r.Height }

// 指针接收者方法（可修改）
func (r *Rectangle) Scale(factor float64) {
    r.Width *= factor
    r.Height *= factor
}

// 组合：匿名嵌入
type Dog struct {
    Animal              // 匿名嵌入 → 方法提升
    Breed string
}

func (d *Dog) Bark() { fmt.Println("Woof!") }

// iface 结构（src/runtime/runtime2.go）
type iface struct {
    tab  *itab
    data unsafe.Pointer
}

type itab struct {
    inter *interfacetype
    _type *_type
    hash  uint32
    fun   [1]uintptr  // 变长数组
}

// 空接口（any）的内存表示
type eface struct {
    _type *unsafe.Pointer
    data  unsafe.Pointer
}
```
