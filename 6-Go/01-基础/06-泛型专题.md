# 泛型专题

## 定义

Go 1.18 引入泛型，允许编写可复用且类型安全的代码，无需类型断言或反射。泛型特别适合数据结构（栈、队列、树）和算法实现（排序、搜索）。

泛型的本质是**参数化多态**：类型参数在编译时实例化为具体类型，消除了运行时类型断言的开销，同时保留编译时类型检查。

## 数学模型

设泛型函数 $F[T]$，其中 $T$ 是类型参数。调用 $F[int]$ 时，编译器生成 $F$ 的int实例化版本。实例化过程是**单态化**（monomorphization）：每个唯一类型组合生成独立代码副本。

**时间复杂度影响**：
- 泛型实例化：$O(1)$，编译时展开，无运行时开销
- 相比反射：`reflect.TypeOf` 每次调用 $O(1)$ 但涉及大量接口转换和分配

**空间复杂度**：
- 泛型代码膨胀：每种类型组合生成独立机器码。若泛型函数使用 10 种类型参数组合，则代码体积约为手写 10 份的等价物
- 相比接口+反射：接口只存储一种机器码，通过运行时类型断言分发

**归约终点**：泛型可归约为**编译时类型展开**，本质是语法糖——编译器生成具体类型的代码副本，而非运行时类型信息系统。

## 机制

### 类型约束的本质

`any` 约束表示无限制，任何类型都满足。`comparable` 约束要求类型支持 `==` 和 `!=`，用于需要相等性判断的场景。

类型约束通过**并集语法**组合类型：

```go
type Number interface{ int | int64 | float32 | float64 }
```

这里 `int | int64 | float32 | float64` 是**联合类型**，表示"可以是这些类型中的任意一种"。编译器在实例化时检查实际类型是否属于这个联合。

**约束的数学本质**：类型约束是类型参数的**定义域**。若 $T$ 被约束为 `Number`，则 $T \in \{int, int64, float32, float64\}$。

### 泛型函数类型推断

编译器在调用点推断类型实参：

```go
func Sum[T any](a, b []T) []T

// 编译器推断 T = int
result := Sum(a, b)  // a, b 是 []int
```

推断基于**函数参数的类型**。若无法推断（如无参数），则必须显式指定类型实参。

### 泛型方法的方法集

泛型结构体的方法可以有自己的类型参数，但方法集本身不因泛型参数而变化：

```go
type Container[T any] struct{ items []T }

// Map 是 Container[T] 的方法，U 是方法的类型参数
func (c *Container[T]) Map[U any](f func(T) U) *Container[U]
```

这里 `Map` 的类型参数 `U` 与 `Container` 的类型参数 `T` 无关，各自独立实例化。

### 自引用泛型的约束

链表等自引用结构需要接口作为中介：

```go
type LinkedList[T any] interface {
    Value() T
    Next() LinkedList[T]
}
```

`LinkedList[T]` 在定义中引用自身，必须通过接口间接定义，否则类型表达式无解。这是**递归类型约束**的数学结构。

### 泛型与接口的能力边界

| 场景 | 泛型 | 接口 |
|------|------|------|
| 类型分发 | 编译时静态 | 运行时动态 |
| 异构类型集合 | 不可（同一集合元素类型必须相同） | 可（同一集合可放不同类型） |
| 插件架构 | 不适合 | 适合（接口的运行时多态） |
| 性能 | 最优（无装箱） | 需要接口装箱，有少量开销 |

**关键约束**：泛型要求**编译时确定类型**，适合同质类型的数据结构和算法；接口适合需要运行时多态的插件架构。

## 参考存根

```go
// 泛型类型约束
type Ordered interface {
    ~int | ~int8 | ~int16 | ~int32 | ~int64 |
    ~uint | ~uint8 | ~uint16 | ~uint32 | ~uint64 |
    ~float32 | ~float64 | ~string
}

// 泛型最值函数
func Min[T Ordered](a, b T) T {
    if a < b {
        return a
    }
    return b
}

// 泛型栈
type Stack[T any] struct{ items []T }
func (s *Stack[T]) Push(item T) { s.items = append(s.items, item) }
func (s *Stack[T]) Pop() T {
    item := s.items[len(s.items)-1]
    s.items = s.items[:len(s.items)-1]
    return item
}

// 泛型 Filter-Map-Reduce
func Map[T, U any](s []T, f func(T) U) []U {
    result := make([]U, len(s))
    for i, v := range s {
        result[i] = f(v)
    }
    return result
}

func Filter[T any](s []T, pred func(T) bool) []T {
    result := make([]T, 0)
    for _, v := range s {
        if pred(v) {
            result = append(result, v)
        }
    }
    return result
}

func Reduce[T, U any](s []T, init U, f func(U, T) U) U {
    result := init
    for _, v := range s {
        result = f(result, v)
    }
    return result
}
```
