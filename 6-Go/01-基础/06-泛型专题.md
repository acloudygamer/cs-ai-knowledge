# 泛型专题

Go 1.18 引入泛型，允许编写可复用且类型安全的代码，无需类型断言或反射。泛型特别适合数据结构（栈、队列、树）和算法实现（排序、搜索）。

## 泛型函数

类型参数通过方括号声明，编译器在编译时推断具体类型。

```go
func Sum[T any](a, b []T) []T {
    result := make([]T, len(a))
    for i := range a { result[i] = a[i] + b[i] }
    return result
}
```

## 类型约束

`any` 表示无约束，`comparable` 支持 `==` 和 `!=`，`cmp.Ordered`（Go 1.21+）支持比较运算。

```go
import "cmp"
func Min[T cmp.Ordered](a, b T) T {
    if a < b { return a }
    return b
}

type Number interface{ int | int64 | float32 | float64 }
func Sum[N Number](nums []N) N {
    var total N
    for _, n := range nums { total += n }
    return total
}
```

## 泛型类型别名（Go 1.24+）

类型别名可以像定义的类型一样被参数化。

```go
type List[T any] = []T
type MapPair[K, V any] = map[K]V
nums := List[int]{1, 2, 3}
pairs := MapPair[string, int]{"a": 1}
```

## 泛型结构体

泛型结构体的方法可使用泛型类型参数。

```go
type Stack[T any] struct{ items []T }
func (s *Stack[T]) Push(item T) { s.items = append(s.items, item) }
func (s *Stack[T]) Pop() T {
    item := s.items[len(s.items)-1]
    s.items = s.items[:len(s.items)-1]
    return item
}

stack := &Stack[int]{}
stack.Push(1); stack.Push(2)
stack.Pop()                         // 2
```

## 泛型接口

接口中可以使用类型参数定义泛型方法。

```go
type Adder[T any] interface {
    Add(T) T
}
func Double[T any](a Adder[T], value T) T {
    return a.Add(value)
}
```

## 泛型方法

泛型结构体的方法可定义独立的类型参数。

```go
type Container[T any] struct{ items []T }
func (c *Container[T]) Map[U any](f func(T) U) *Container[U] {
    result := &Container[U]{items: make([]U, len(c.items))}
    for i, item := range c.items { result.items[i] = f(item) }
    return result
}
```

## 泛型集合操作

Filter、Map、Reduce 是泛型的经典应用场景。

```go
func Filter[T any](s []T, pred func(T) bool) []T {
    result := make([]T, 0)
    for _, v := range s { if pred(v) { result = append(result, v) } }
    return result
}

func Map[T, U any](s []T, f func(T) U) []U {
    result := make([]U, len(s))
    for i, v := range s { result[i] = f(v) }
    return result
}

func Reduce[T, U any](s []T, init U, f func(U, T) U) U {
    result := init
    for _, v := range s { result = f(result, v) }
    return result
}
```

链式调用示例：

```go
numbers := []int{1, 2, 3, 4, 5, 6}
Map(Filter(numbers, func(n int) bool { return n%2 == 0 }),
    func(n int) int { return n * n })
// [4, 16, 36]
```

## 联合类型约束

通过 `|` 连接多个类型，实现或的约束。

```go
type Number interface{ int | int64 | float32 | float64 }
type Stringable interface{ string | []byte }
type Printable interface{ comparable; fmt.Stringer }
```

## 自引用泛型（Go 1.24+）

类型参数可以引用它所约束的泛型类型本身，用于定义递归泛型结构（如链表）。

```go
type LinkedList[T any] interface {
    Value() T
    Next() LinkedList[T]
}
```

## 泛型与接口对比

| 场景 | 泛型 | 接口 |
|------|------|------|
| 类型安全 | 编译时检查 | 运行时断言 |
| 性能 | 无装箱开销 | 有装箱开销 |
| 插件式架构 | 接口 | 接口 |

## 什么时候用泛型

- 类型逻辑相同，只是类型不同（切片、映射、通道）
- 数据结构（栈、队列、树）
- 算法实现（排序、搜索）
- 避免重复代码

## 什么时候不用泛型

- 只有几种具体类型，手写更清晰
- 涉及类型特定操作（无法约束）
- 简单包装已有函数
