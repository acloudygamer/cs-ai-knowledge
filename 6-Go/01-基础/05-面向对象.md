# 面向对象

Go 没有类（class），但通过结构体（struct）、方法（method）和接口（interface）提供了完整的面向对象编程能力。Go 的 OOP 哲学是：**组合优于继承**、**接口优于继承**、**Duck Typing 隐式实现**。

## struct（结构体）

struct 是 Go 中定义自定义类型的主要方式，通过字段组合表示复杂数据结构。

```go
type Person struct {
    Name string
    Age  int
}
p := Person{Name: "Alice", Age: 30}
p := Person{}                        // 零值初始化
p := new(Person)                     // 返回 *Person
```

## 方法接收者

值接收者不修改对象，指针接收者可以修改。Go 自动在值和指针间转换以匹配接收者类型。

```go
type Point struct{ X, Y float64 }
func (p Point) Distance() float64 {
    return math.Sqrt(p.X*p.X + p.Y*p.Y)
}
func (p *Point) Scale(factor float64) {
    p.X *= factor; p.Y *= factor
}
```

## 接口

接口定义了方法集合，仅声明不实现。任何类型实现了接口的所有方法，就隐式实现了该接口——无需显式声明。

<pre>
┌────────────────────────────────────┐
│  interface                         │
│  Area() float64                    │
│  Perimeter() float64               │
└────────────────────────────────────┘
         ↑ 隐式实现
┌────────────────────────────────────┐
│  Rectangle{Width, Height}         │
│  func (r Rectangle) Area()        │
│  func (r Rectangle) Perimeter()   │
└────────────────────────────────────┘
</pre>

```go
type Shape interface {
    Area() float64
    Perimeter() float64
}
type Rectangle struct{ Width, Height float64 }
func (r Rectangle) Area() float64 { return r.Width * r.Height }
var s Shape = Rectangle{3, 4}
```

## Duck Typing

Go 采用 Duck Typing：只要对象实现了接口的方法，就可以使用接口类型，而无需显式声明。

```go
type Writer interface {
    Write([]byte) (int, error)
}
type StringWriter struct{ content strings.Builder }
func (w *StringWriter) Write(p []byte) (int, error) {
    w.content.Write(p)
    return len(p), nil
}
var w Writer = &StringWriter{}
w.Write([]byte("hello"))
```

## 常用标准库接口

| 接口 | 方法 | 用途 |
|------|------|------|
| `error` | `Error() string` | 错误表示 |
| `io.Reader` | `Read(p []byte) (n int, err error)` | 读取数据 |
| `io.Writer` | `Write(p []byte) (n int, err error)` | 写入数据 |
| `fmt.Stringer` | `String() string` | 字符串表示 |

## 接口类型断言

```go
var s Shape = Rectangle{3, 4}
r, ok := s.(Rectangle)               // comma-ok 语法
switch v := s.(type) {               // type switch
case Rectangle: fmt.Println(v.Width)
}
```

## 封装

Go 通过包级可见性实现封装。小写字母开头的标识符仅包内可见。

```go
package counter
type counter struct{ count int }
func New() *counter { return &counter{} }
func (c *counter) Increment() { c.count++ }
func (c *counter) Value() int { return c.count }
```

## 组合 vs 继承

Go 偏好组合而非继承。Go 通过嵌入（匿名字段）实现组合，替代传统继承。

<pre>
┌─────────────────────────────────────────┐
│  Animal struct                          │
│    Name: string                         │
│    Eat()                               │
└─────────────────────────────────────────┘
           │
           │ 嵌入
           ▼
┌─────────────────────────────────────────┐
│  Dog struct                            │
│    Animal (匿名嵌入)                    │
│    Breed: string                        │
│    Bark()                               │
└─────────────────────────────────────────┘
  d.Eat()  → 继承自 Animal
  d.Bark() → Dog 自有方法
</pre>

```go
type Animal struct{ Name string }
func (a *Animal) Eat() { fmt.Printf("%s eating\n", a.Name) }

type Dog struct {
    Animal                         // 匿名嵌入（组合）
    Breed string
}
func (d *Dog) Bark() { fmt.Println("Woof!") }

d := Dog{Animal: Animal{Name: "Buddy"}, Breed: "Labrador"}
d.Eat()                               // 继承自 Animal
d.Bark()                              // Dog 自有方法
```

## 多态

接口是 Go 中实现多态的主要方式。同一接口的不同实现可以共存于同一切片中。

```go
type Speaker interface{ Speak() string }
type Dog struct{}
func (d Dog) Speak() string { return "Woof!" }
type Cat struct{}
func (c Cat) Speak() string { return "Meow!" }

func MakeSpeak(s Speaker) { fmt.Println(s.Speak()) }
MakeSpeak(Dog{})                              // Woof!
MakeSpeak(Cat{})                              // Meow!
```

## 构造函数

Go 没有构造函数，通过工厂函数模拟。

```go
type Config struct{ host string; port int }
func NewConfig(host string, port int) *Config {
    return &Config{host: host, port: port}
}
```

## 接口最佳实践

1. **小接口优先** - io.Reader、io.Writer 是典范
2. **接受接口，返回结构体** - 函数参数用接口，返回值用具体类型
3. **避免空接口滥用** - 空接口丧失类型安全
4. **接口组合** - 将小接口组合成大接口
