# 安装与环境

Go 是 Go 语言的开发环境核心——通过 GOPATH（废弃）与 Workspace（Go 1.18+）两种模式管理源代码布局，go mod 管理依赖版本。

## Go Workspace 模式（Go 1.18+）

Workspace 模式是 Go 推荐的源代码组织方式，通过 go.work 文件在开发机器上同时管理多个模块。

<pre>
┌─────────────────────────────────────────┐
│            go.work                      │
│  go 1.24                                │
│  use ./module1                          │
│  use ./module2                          │
└─────────────────────────────────────────┘
         │
    ┌────┴────┐
    ▼         ▼
┌────────┐ ┌────────┐
│module1 │ │module2 │
└────────┘ └────────┘
</pre>

### 核心命令

| 命令 | 作用 |
|------|------|
| `go work init` | 创建 workspace |
| `go work use ./module` | 添加模块 |
| `go work sync` | 同步依赖 |

### go.work 文件结构

```
go 1.24.0

use (
    ./module1
    ./module2
)
```

## 模块管理（go mod）

go.mod 是 Go 项目的依赖清单，go get 动态添加版本，go mod tidy 自动整理。

### 核心命令

```
go mod init module_name     # 初始化项目
go mod tidy                # 整理依赖
go get package@version     # 添加依赖
go mod download            # 下载依赖
go mod verify             # 验证完整性
```

### go.mod 文件结构

```
module github.com/user/project

go 1.24.0

require (
    github.com/gin-gonic/gin v1.9.1
)
```

### 替换依赖（本地调试用）

```
go mod edit -replace github.com/pkg/errors=../local/pkg/errors
```

### 私有模块配置

```
GOPRIVATE=github.com/company/*
GOPROXY=https://proxy.golang.org,direct
```

## 环境变量

| 变量 | 说明 | 默认值 |
|------|------|--------|
| GOROOT | Go 安装目录 | 自动检测 |
| GOPATH | 工作区目录 | $HOME/go |
| GOPROXY | 依赖代理 | proxy.golang.org |
| GO111MODULE | 模块模式 | auto |
| GOCACHE | 缓存目录 | $HOME/go-build |

## 常用命令速查

```
go run main.go            # 运行
go build -o app .         # 编译
go test -v ./...          # 测试
go test -race ./...       # 竞态检测
go test -bench=.          # 基准测试
go test -cover ./...      # 覆盖率
go fmt ./...              # 格式化
go vet ./...              # 静态分析
go env GOROOT             # 查看环境变量
```

## 测试标志

```
-v          # 详细输出
-run        # 运行指定测试
-cover      # 显示覆盖率
-race       # 竞态检测
-bench=.    # 基准测试
-benchmem   # 内存统计
-short      # 跳过慢测试
```

## IDE 配置

### VS Code + Go 扩展

安装官方 Go 扩展后，在 `.vscode/settings.json` 配置：

```json
{
    "go.useLanguageServer": true,
    "go.lintTool": "golangci-lint",
    "go.formatTool": "gofmt",
    "go.testFlags": ["-v", "-race"]
}
```

### GoLand

- File → Settings → Go → Go Modules：启用 proxy
- File → Settings → Go → Testing：启用 race detector
- Ctrl+Shift+R：运行测试
- Ctrl+Shift+T：跳转测试/实现

## 常见问题

### 1. module not found

```
export GO111MODULE=on
go mod tidy
```

### 2. 依赖下载失败

```
export GOPROXY=https://goproxy.cn,direct
```

### 3. 加速编译

```
go build -p 4 .           # -p 指定并行数
go generate ./...          # 预生成代码
```
