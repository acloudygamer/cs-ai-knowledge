# 安装与环境

## 安装方式

### macOS
```bash
brew install go
# 或使用官方安装包
```

### Windows
```bash
# 方式1: winget
winget install golang

# 方式2: 官方安装包
# 下载 https://go.dev/dl/
```

### Linux
```bash
# Ubuntu/Debian
sudo apt install golang-go

# 或使用官方 tar.gz 包
wget https://go.dev/dl/go1.26.0.linux-amd64.tar.gz
sudo tar -C /usr/local -xzf go1.26.0.linux-amd64.tar.gz
export PATH=$PATH:/usr/local/go/bin
```

### 验证安装
```bash
go version  # go version go1.26.0 darwin/arm64
go env GOVERSION
```

## Go Workspace 模式（Go 1.18+）

### GOPATH vs Workspace

**GOPATH 模式（已废弃）**：
```bash
export GOPATH=$HOME/go
export PATH=$PATH:$GOPATH/bin
```

**Workspace 模式（推荐，Go 1.18+）**：
```bash
# 创建 workspace
mkdir myworkspace
cd myworkspace
go work init

# 添加模块到 workspace
go work use ./module1
go work use ./module2
```

### go.work 文件结构
```go
go 1.22.0

use (
    ./module1
    ./module2
)
```

## 模块管理（go mod）

### 初始化与基础命令
```bash
go mod init module_name      # 初始化项目，创建 go.mod
go mod tidy                   # 整理依赖（添加缺失，移除无用）
go get package@version        # 添加指定版本依赖
go get package@latest         # 添加最新版本依赖
go mod download               # 下载依赖到本地缓存
go mod verify                # 验证依赖完整性
go list -m all                # 列出所有依赖及版本
```

### go.mod 文件结构
```
module github.com/user/project

go 1.22.0

require (
    github.com/gin-gonic/gin v1.9.1
    github.com/go-sql-driver/mysql v1.7.1
)
```

### 替换依赖（用于本地调试）
```bash
go mod edit -replace github.com/pkg/errors=../local/pkg/errors
```

### 私有模块
```bash
# 设置 GOPRIVATE 环境变量
export GOPRIVATE=github.com/company/*
export GOPROXY=https://proxy.golang.org,direct
```

## 测试标志

### 常用测试标志
```bash
go test -v ./...              # 详细输出
go test -run TestName         # 运行指定测试
go test -cover ./...          # 显示覆盖率
go test -coverprofile=cover.out ./...  # 输出覆盖率文件
go test -race ./...           # 竞态检测
go test -bench=.              # 运行基准测试
go test -benchmem             # 显示内存分配统计
go test -cpuprofile=cpu.out   # CPU profiling
go test -memprofile=mem.out    # 内存 profiling
go test -trace=trace.out      # 执行追踪
```

### 测试输出分析
```bash
# 查看覆盖率报告
go tool cover -html=cover.out

# 查看 CPU profile
go tool pprof cpu.out
(pprof) web  # 在浏览器中打开
```

### 跳过慢测试
```bash
go test -short ./...          # 跳过耗时测试
go test -run 'Test[^Slow]'    # 正则匹配要运行的测试
```

## IDE 配置

### VS Code + Go 扩展

安装扩展：
- **Go**（官方扩展，作者：Go Team at Google）

推荐设置（`.vscode/settings.json`）：
```json
{
    "go.useLanguageServer": true,
    "go.languageServerExperimentalFeatures": {
        "diagnostics": true,
        "goDocs": true
    },
    "go.lintTool": "golangci-lint",
    "go.lintOnSave": "package",
    "go.formatTool": "gofmt",
    "go.testFlags": ["-v", "-race"],
    "filesaveago": true
}
```

常用命令：
- `Cmd+Shift+P` → **Go: Install/Update Tools** 安装工具
- `Cmd+Shift+P` → **Go: Test Package** 运行测试
- `Cmd+Shift+P` → **Go: Generate Unit Tests** 生成测试

### GoLand

推荐配置：
- **File → Settings → Go → Go Modules**：启用 proxy
- **File → Settings → Go → Testing**：默认启用 race detector
- **File → Settings → Go → Linter**：启用 golangci-lint

快捷键：
- `Ctrl+Shift+R` — 运行测试
- `Ctrl+Shift+T` — 跳转测试/实现
- `Alt+Enter` — 意图操作

## 常用命令速查

```bash
# 运行与编译
go run main.go                 # 直接运行
go build -o app .             # 编译为可执行文件
go build -buildmode=c-shared . # 编译为 C 共享库（用于 CGO）
go build -ldflags="-s -w" .   # 去除调试信息，减小体积

# 测试
go test -v ./...               # 详细测试
go test -race ./...            # 竞态检测
go test -bench=. -benchmem     # 基准测试 + 内存统计
go test -cover ./...           # 覆盖率

# 代码质量
go fmt ./...                   # 格式化
go vet ./...                   # 静态分析
golangci-lint run              # 综合 lint（需安装）
go mod tidy                    # 整理依赖

# 文档与工具
go doc fmt                     # 查看包文档
go list -m json                # 列出模块信息
go version                     # 查看 Go 版本

# 环境
go env GOROOT                 # Go 安装路径
go env GOPATH                 # 工作区路径
go env GOMODCACHE             # 依赖缓存路径
go env GO111MODULE            # 模块模式开关
```

## 环境变量

### 重要环境变量

| 变量 | 说明 | 默认值 |
|------|------|--------|
| GOROOT | Go 安装目录 | 自动检测 |
| GOPATH | 工作区目录 | $HOME/go |
| GOPROXY | 依赖代理 | https://proxy.golang.org,direct |
| GO111MODULE | 模块模式 | auto |
| GOCACHE | 缓存目录 | $HOME/go-build |
| GOGC | GC 目标百分比 | 100 |
| GOMEMLIMIT | 内存限制 | 无 |

### 永久设置（Linux/macOS）
```bash
# ~/.bashrc 或 ~/.zshrc
export GOROOT=/usr/local/go
export PATH=$PATH:$GOROOT/bin
export GOPATH=$HOME/go
export GOPROXY=https://proxy.golang.org,direct
export GO111MODULE=on
```

### Windows (PowerShell)
```powershell
# $PROFILE
$env:GOROOT = "C:\Program Files\Go"
$env:PATH += ";$env:GOROOT\bin"
$env:GOPATH = "$HOME\go"
$env:GO111MODULE = "on"
```

## 常见问题

### 1. go: module not found
```bash
# 确保在模块目录下，或启用 GO111MODULE
export GO111MODULE=on
go mod tidy
```

### 2. 编译速度慢
```bash
# 使用 -p 指定并行编译
go build -p 4 .

# 使用 go:generate 预生成代码
go generate ./...
```

### 3. 依赖下载失败
```bash
# 更换代理
export GOPROXY=https://goproxy.cn,direct
# 或使用七牛云的代理
export GOPROXY=https://goproxy.io,direct
```
