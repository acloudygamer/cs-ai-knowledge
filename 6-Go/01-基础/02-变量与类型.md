# 变量与类型

Go 的类型系统是静态的——编译时确定所有类型——但通过类型推导，变量声明可以简洁。核心设计原则：值类型（int、struct）直接存储，引用类型（slice、map、channel、pointer）存储引用且零值为 nil。

## 值类型 vs 引用类型

值类型直接存储数据，引用类型存储数据的内存地址。这是 Go 内存分配策略的基础。

<pre>
┌──────────────────────────────────────────────┐
│  值类型 (int, struct)                         │
│  ┌────────┐                                  │
│  │  int   │  → 栈或堆（逃逸分析决定）          │
│  └────────┘                                  │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│  引用类型 (slice, map, channel, pointer)      │
│  ┌────────┐      ┌──────────────┐           │
│  │ pointer│ ────→│ 实际数据(堆)  │           │
│  └────────┘      └──────────────┘           │
│  零值: nil                                   │
└──────────────────────────────────────────────┘
</pre>

## 声明方式

```go
var name string = "go"         // 显式声明
var name = "go"               // 类型推导
name := "go"                  // 短声明（函数内）
const Pi = 3.14159            // 常量
```

## 基本类型

| 类型 | 说明 |
|------|------|
| `int` / `int64` | 整数，平台相关 |
| `float32` / `float64` | 浮点数 |
| `bool` | 布尔值 |
| `string` | 字符串，不可变 |
| `byte` | uint8 别名 |
| `rune` | int32 别名，Unicode 码点 |

## 数组 vs 切片

数组是固定长度值类型，切片是动态长度的引用类型。切片底层指向数组，append 触发扩容时重新分配内存。

<pre>
数组: [5]int{1,2,3,4,5}  →  栈上的连续内存
切片: []int{1,2,3}        →  栈上的SliceHeader + 堆上的底层数组
                              ┌────────────┐
SliceHeader: ────────────────→│ 1 2 3 ...  │
┌──────────┬──────────┬───────┴────────────┘
│ ptr      │ len=3   │ cap=3
└──────────┴──────────┴───────┘
</pre>

```go
arr := [5]int{1, 2, 3, 4, 5}
s := []int{1, 2, 3}
s = append(s, 4)
s = append(s, 5)
```

## 指针

指针存储变量的内存地址。`&` 取地址，`*` 解引用。指针本身是值类型，但指向的数据通过逃逸分析决定分配位置。

```go
x := 10
p := &x
*p = 20
func addOne(n *int) { *n++ }
```

## 指针接收者

值接收者不修改对象，指针接收者可以修改。Go 自动在值和指针间转换以匹配接收者类型。

```go
type Counter struct{ value int }
func (c *Counter) Increment() { c.value++ }
func (c Counter) Get() int  { return c.value }
```

## 切片/Map/Channel 无需指针

切片/Map/Channel 本身就是引用类型，不需要指针。局部变量通过逃逸分析自动决定分配到栈还是堆。

```go
s := []int{1, 2, 3}
s = append(s, 4)
```

## 类型别名 vs 自定义类型

`=` 创建类型别名，完全等价于原类型。无 `=` 的自定义类型是独立类型，有类型安全保护。

```go
type ID = int                 // 别名
type UserID int               // 独立类型
type OrderID int
// getUser(UserID(1))         // OK
// getUser(OrderID(1))        // 编译错误
```

## 类型转换（显式）

Go 不支持隐式类型转换，必须显式转换。

```go
i := 42
f := float64(i)
s := string(runeValue)
```

## 类型断言

类型断言从接口值提取具体类型，使用 comma-ok 语法安全检查。

```go
var i interface{} = "hello"
s, ok := i.(string)         // 安全断言
n, ok := i.(int)            // ok=false，不panic
```

## 类型 switch

```go
switch val := v.(type) {
case string:  fmt.Println("string:", val)
case int:    fmt.Println("int:", val)
default:     fmt.Println("unknown")
}
```
