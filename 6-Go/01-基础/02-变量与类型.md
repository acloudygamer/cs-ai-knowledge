# 变量与类型

## 定义

Go 的类型系统是**静态编译时确定的**，通过类型推导简化声明，零值机制保证内存安全。核心设计：值类型（int、struct）直接存储数据，引用类型（slice、map、channel、pointer）存储数据的地址。逃逸分析决定变量分配在栈还是堆——栈分配满足 $O(1)$ 分配/释放，堆分配需要 GC 介入（$O(n)$ 扫描）。

## 数学模型

### 逃逸分析的约束条件

Go 通过**逃逸分析**决定变量的分配位置：

$$\text{Escape}(var) = \begin{cases} \text{stack} & \text{如果 } \text{lifetime}(var) \leq \text{function\_return} \\ \text{heap} & \text{如果 } \text{lifetime}(var) > \text{function\_return} \end{cases}$$

**逃逸触发条件（满足任一即 heap 分配）**：

- 变量被 channel 引用（跨协程通信需要堆生命周期）
- 变量被 slice 引用且长度编译期未知（append 可能导致重新分配）
- 变量被 return 语句返回（调用者生命周期 > 被调者）
- 变量被闭包捕获且超出创建作用域（闭包生命周期不确定）

**数学意义**：栈分配满足 $O(1)$ 分配/释放，堆分配需要 GC 介入，扫描复杂度 $O(n)$（n = 堆上存活对象数）。

### 切片的扩容公式

切片扩容策略（Go 1.21+）：

$$\text{newCap} = \begin{cases} 2 \times \text{oldCap} & \text{if } \text{oldCap} < 256 \\ 1.25 \times \text{oldCap} + 48 & \text{if } \text{oldCap} \geq 256 \end{cases}$$

实际实现更复杂，需考虑：
- 内存对齐（按 8 字节对齐）
- 溢出检测（cap > maxSliceCap 时限制）
- 最小 cap（至少是 oldCap + 1）

### 指针的代数语义

Go 指针满足**代数不变式**：

$$\forall p: *T, \exists a: T, \text{使得 } *p = a \text{ 且 } \&a \text{ 是有效地址}$$

**约束**：Go 不支持指针算术运算，保证内存安全。这将指针类型归约为**确界安全的引用**，而非 C 的裸指针。

## 机制

### 值类型 vs 引用类型的本质差异

**值类型**赋值的深拷贝语义：
- 赋值时复制整个数据结构
- 修改副本不影响原值
- 适合小型独立数据（int、float、struct）

**引用类型**赋值的浅拷贝语义：
- 赋值时复制引用（指针），不复制数据
- 所有引用共享同一底层数据
- 适合大型数据或需要共享的数据

**所有权模型**：值类型传递时转移数据所有权，引用类型传递时共享所有权（借用）。

### 为什么 slice 的 len 和 cap 分开设计

`len` 和 `cap` 分离提供**边界检查的科学依据**：

- `len` = 可读写元素数，`s[i]` 访问要求 $i < \text{len}$，越界触发 panic
- `cap` = 可扩展上限，`append` 时检查 $\text{len} + 1 \leq \text{cap}$，否则扩容

**数学约束**：
- `s[i:j]` 切片操作要求 $0 \leq i \leq j \leq \text{cap}$
- `s[i:j:k]` 切片操作要求 $0 \leq i \leq j \leq k \leq \text{cap}$

### 为什么 string 是不可变的

string 不可变的设计出于三个约束：

1. **并发安全约束**：不可变数据无需加锁，可安全共享
2. **复用约束**：相同内容的字符串可共享底层字节数组（interning）
3. **安全约束**：避免字符串被意外修改导致哈希值变化

**违反约束的代价**：频繁修改字符串会产生大量临时对象，应使用 `strings.Builder`（减少复制）或 `[]byte`（原地修改）。

### 类型别名 vs 自定义类型

`type ID = int`（类型别名）：
- 完全等价，可隐式互换
- 用于语义强调，不提供类型安全

`type ID int`（自定义类型）：
- 独立的类型，不能隐式互换
- 提供类型安全保护，防止误用

**数学本质**：类型别名是等价关系（$\equiv$），自定义类型是不相交并集（$\cup$）中的独立成员。

## 对比参照

| 属性 | 值类型 | 引用类型 |
|------|--------|----------|
| 内存位置 | 栈或堆（逃逸分析决定） | 堆（堆上数据）+ 栈（引用本身） |
| 赋值语义 | 深拷贝（复制数据） | 浅拷贝（复制引用） |
| 修改影响 | 修改副本不影响原值 | 修改影响所有引用 |
| 零值 | 各类型的零值（0, "", nil） | nil（空引用） |
| 典型类型 | int, float, bool, struct, array | slice, map, channel, pointer, interface |
