# 变量与类型

## 本质断言

Go 的类型系统是静态的——编译时确定所有类型，通过类型推导简化声明，零值机制保证内存安全。核心设计：值类型（int、struct）直接存储数据，引用类型（slice、map、channel、pointer）存储数据的地址，逃逸分析决定栈/堆分配。

## 数学模型

### 逃逸分析的约束条件

Go 通过**逃逸分析**决定变量的分配位置：

$$\text{Escape}(var) = \begin{cases} \text{stack} & \text{如果 } \text{lifetime}(var) \leq \text{function\_return} \\ \text{heap} & \text{如果 } \text{lifetime}(var) > \text{function\_return} \end{cases}$$

**逃逸条件**：
- 变量被 channel 引用
- 变量被 slice 引用且长度编译期未知
- 变量被返回（return value）
- 变量被闭包捕获且超出作用域

**数学意义**：栈分配满足 $O(1)$ 分配/释放，堆分配需要 GC 介入（$O(n)$ 扫描）。

### 切片的扩容公式

切片扩容策略（Go 1.21+）：

$$\text{newCap} = \begin{cases} 2 \times \text{oldCap} & \text{if } \text{oldCap} < 256 \\ 1.25 \times \text{oldCap} + 48 & \text{if } \text{oldCap} \geq 256 \end{cases}$$

但实际实现更复杂，考虑内存对齐和溢出检测。

### 指针的代数语义

Go 指针满足**代数不变式**：

$$\forall p: *T, \exists a: T, \text{使得 } *p = a \text{ 且 } \&a \text{ 是有效地址}$$

指针运算受限（不支持指针算术），保证了内存安全。

## 机制

### 为什么值类型和引用类型的设计重要

值类型赋值的**深拷贝**语义：
- 修改 y 不影响 x
- 适合小型独立数据（int、struct）

引用类型赋值的**浅拷贝**语义：
- 修改底层数据，所有引用都可见
- 适合大型数据或需要共享的数据

这使得内存管理的**所有权**清晰：值类型传递时转移所有权，引用类型传递时共享所有权。

### 为什么 slice 的 len 和 cap 分开

slice 的 `len` 和 `cap` 分离提供了**边界检查**的依据：

- `len` = 可读写元素数，超过触发 panic
- `cap` = 可扩展上限，append 时检查是否需要扩容

这使得：
- `s[i]` 访问（$i < len$）是安全的
- `s[i:j]` 切片（$j \leq cap$）不会触发扩容

### 为什么 string 是不可变的

string 不可变的设计：
- **安全**：避免字符串被意外修改
- **并发安全**：无需加锁
- **复用**：相同内容的字符串可以共享底层字节数组

但频繁修改字符串仍有效率问题——应使用 `strings.Builder` 或 `[]byte`。

### 为什么需要类型别名和自定义类型

`type ID = int`（别名）：
- 完全等价，可互换
- 用于语义强调（如 `type UserID int`）

`type ID int`（自定义类型）：
- 独立的类型，不能隐式互换
- 提供类型安全保护

## 值类型 vs 引用类型

值类型直接存储数据，引用类型存储数据的内存地址。这是 Go 内存分配策略的基础。

<pre>
┌──────────────────────────────────────────────┐
│  值类型 (int, struct)                         │
│  ┌────────┐                                  │
│  │  int   │  → 栈或堆（逃逸分析决定）          │
│  └────────┘                                  │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│  引用类型 (slice, map, channel, pointer)      │
│  ┌────────┐      ┌──────────────┐           │
│  │ pointer│ ────→│ 实际数据(堆)  │           │
│  └────────┘      └──────────────┘           │
│  零值: nil                                   │
└──────────────────────────────────────────────┘
</pre>

```go
var name string = "go"         // 显式声明
var name = "go"               // 类型推导
name := "go"                  // 短声明（函数内）
const Pi = 3.14159            // 常量
```

## 基本类型

| 类型 | 说明 |
|------|------|
| `int` / `int64` | 整数，平台相关 |
| `float32` / `float64` | 浮点数 |
| `bool` | 布尔值 |
| `string` | 字符串，不可变 |
| `byte` | uint8 别名 |
| `rune` | int32 别名，Unicode 码点 |

## 数组 vs 切片

数组是固定长度值类型，切片是动态长度的引用类型。切片底层指向数组，append 触发扩容时重新分配内存。

<pre>
数组: [5]int{1,2,3,4,5}  →  栈上的连续内存
切片: []int{1,2,3}        →  栈上的SliceHeader + 堆上的底层数组
                              ┌────────────┐
SliceHeader: ────────────────→│ 1 2 3 ...  │
┌──────────┬──────────┬───────┴────────────┘
│ ptr      │ len=3   │ cap=3
└──────────┴──────────┴───────┘
</pre>

```go
arr := [5]int{1, 2, 3, 4, 5}
s := []int{1, 2, 3}
s = append(s, 4)
s = append(s, 5)
```

## 指针

指针存储变量的内存地址。`&` 取地址，`*` 解引用。指针本身是值类型，但指向的数据通过逃逸分析决定分配位置。

```go
x := 10
p := &x
*p = 20
func addOne(n *int) { *n++ }
```

## 指针接收者

值接收者不修改对象，指针接收者可以修改。Go 自动在值和指针间转换以匹配接收者类型。

```go
type Counter struct{ value int }
func (c *Counter) Increment() { c.value++ }
func (c Counter) Get() int  { return c.value }
```

## 切片/Map/Channel 无需指针

切片/Map/Channel 本身就是引用类型，不需要指针。局部变量通过逃逸分析自动决定分配到栈还是堆。

```go
s := []int{1, 2, 3}
s = append(s, 4)
```

## 类型别名 vs 自定义类型

`=` 创建类型别名，完全等价于原类型。无 `=` 的自定义类型是独立类型，有类型安全保护。

```go
type ID = int                 // 别名
type UserID int               // 独立类型
type OrderID int
// getUser(UserID(1))         // OK
// getUser(OrderID(1))        // 编译错误
```

## 类型转换（显式）

Go 不支持隐式类型转换，必须显式转换。

```go
i := 42
f := float64(i)
s := string(runeValue)
```

## 类型断言

类型断言从接口值提取具体类型，使用 comma-ok 语法安全检查。

```go
var i interface{} = "hello"
s, ok := i.(string)         // 安全断言
n, ok := i.(int)            // ok=false，不panic
```

## 类型 switch

```go
switch val := v.(type) {
case string:  fmt.Println("string:", val)
case int:    fmt.Println("int:", val)
default:     fmt.Println("unknown")
}
```
