# 变量与类型

Go 的类型系统是静态的——编译时确定所有类型——但通过类型推导，变量声明可以简洁。核心设计原则：值类型（int、struct）直接存储，引用类型（slice、map、channel、pointer）存储引用且零值为 nil。

## 声明方式

Go 提供多种变量声明方式，从显式到隐式。

### 参考样例

```go
// var 声明，可指定类型
var name string = "go"
var age int = 30

// 类型推导
var name = "go"        // string
var age = 30           // int

// 短声明（函数内）
name := "go"           // 只能用在函数内
age := 30

// 多变量
var (
    name = "go"
    age  = 30
)

// 常量
const Pi = 3.14159
```

## 基本类型

Go 提供明确大小的基本类型，避免隐式类型转换。

| 类型 | 说明 |
|------|------|
| `int` / `int64` | 整数，平台相关 |
| `float32` / `float64` | 浮点数，推荐 float64 |
| `bool` | 布尔值 true/false |
| `string` | 字符串，不可变 |
| `byte` | uint8 的别名 |
| `rune` | int32 的别名，代表 Unicode 码点 |

## 数组 vs 切片

数组是固定长度值类型，切片是动态长度的引用类型。切片底层指向数组，append 可能触发扩容。

### 参考样例

```go
// 数组：固定长度，值类型
arr := [5]int{1, 2, 3, 4, 5}

// 切片：动态数组，引用类型
s := []int{1, 2, 3}
s = append(s, 4)
s = append(s, 5...)

// make 创建切片和 map
s := make([]int, 0, 10)  // len=0, cap=10
m := make(map[string]int)
m["go"] = 30
```

## 类型转换（显式）

Go 不支持隐式类型转换，必须显式转换。

### 参考样例

```go
i := 42
f := float64(i)    // int -> float64
b := byte(i)       // int -> byte
runeValue := 'A'
s := string(runeValue)  // runeValue -> string
```

## 指针

指针存储变量的内存地址。`&` 取地址，`*` 解引用。指针本身是值类型，但指向的数据可能是堆（逃逸分析决定）。

### 参考样例

```go
// 基本指针
x := 10
p := &x            // p 是 *int，指向 x
fmt.Println(*p)   // 解引用：10

// 修改原值
*p = 20            // x 现在是 20

// 指针函数参数（修改原始值）
func addOne(n *int) {
    *n++
}
num := 5
addOne(&num)
fmt.Println(num)   // 6

// new 创建指针
p := new(int)      // *int，值为 0
*p = 100
```

## 指针接收者（方法）

值接收者方法不修改对象，指针接收者方法可修改对象。Go 自动在值和指针间转换以匹配接收者类型。

### 参考样例

```go
type Counter struct{ value int }

func (c *Counter) Increment() {
    c.value++
}

func (c Counter) Get() int {
    return c.value
}

c := Counter{}
c.Increment()  // 自动转换为 (&c).Increment()
fmt.Println(c.Get())
```

## 指针陷阱

切片/Map/Channel 本身就是引用类型，不需要指针。局部变量通过逃逸分析决定分配到栈还是堆。

### 参考样例

```go
// 1. 切片/映射本身就是引用类型，不需要指针
s := []int{1, 2, 3}
s = append(s, 4)   // 不需要 &s

// 2. 局部变量逃逸分析
// Go 会自动决定变量是否需要分配到堆
func getPointer() *int {
    x := 10           // 编译器会将其分配到堆上
    return &x         // 安全，x 逃逸到堆
}

// 3. nil 指针检查
var p *int
if p != nil {
    fmt.Println(*p)
}
```

## 类型别名

`=` 创建类型别名，完全等价于原类型。自定义类型（无 `=`）创建新类型，有类型安全保护。

### 参考样例

```go
// 类型别名（编译时有效）
type ID = int        // = 表示别名，完全等价

// 自定义类型（类型安全）
type UserID int      // 新的独立类型
type OrderID int

func getUser(id UserID) {}
func getOrder(id OrderID) {}

// UserID 和 OrderID 是不同类型，编译器会阻止混用
uid := UserID(1)
oid := OrderID(1)
// getUser(oid)       // 编译错误：类型不匹配
getUser(uid)          // OK
```

## 自定义类型（类型定义）

基于基本类型、结构体或其他类型定义新类型，可添加方法。

### 参考样例

```go
// 1. 基于基本类型
type Age int
type Name string

// 2. 基于结构体
type Person struct {
    Name string
    Age  Age
}

// 3. 类型方法
type Meter float64

func (m Meter) ToFeet() float64 {
    return float64(m) * 3.28084
}

// 4. Stringer 接口（fmt 打印）
type Status int

const (
    Active  Status = iota
    Inactive
)

func (s Status) String() string {
    return [...]string{"Active", "Inactive"}[s]
}

// 5. 自定义错误
type MyError struct {
    Msg string
    Code int
}

func (e MyError) Error() string {
    return fmt.Sprintf("[%d] %s", e.Code, e.Msg)
}
```

## 类型断言与类型查询

类型断言从接口值提取具体类型，类型 switch 批量检查类型。

### 参考样例

```go
// 类型断言（接口类型）
var i interface{} = "hello"

s, ok := i.(string)     // 安全断言
fmt.Println(s, ok)     // hello true

n, ok := i.(int)        // ok = false，不会 panic
fmt.Println(n, ok)     // 0 false

// 类型 switch
func inspect(v interface{}) {
    switch val := v.(type) {
    case string:
        fmt.Println("string:", val)
    case int:
        fmt.Println("int:", val)
    case []int:
        fmt.Println("slice of int, len:", len(val))
    default:
        fmt.Println("unknown type")
    }
}
```

## 底层类型与类型层级

具有相同底层类型的类型之间必须显式转换。

### 参考样例

```go
// 相同底层类型可以直接转换
type A int
type B int

var a A = 10
var b B = 20
sum := int(a) + int(b)   // 必须显式转换

// 指针类型转换
type IntPtr *int   // 合法：定义了一个新的指针类型 IntPtr，不是别名
```
