# 面向对象

Go 没有类（class），但通过结构体（struct）、方法（method）和接口（interface）提供了完整的面向对象编程能力。Go 的 OOP 风格强调组合优于继承、接口优于继承、Duck Typing。

## struct（结构体）

struct 是 Go 中定义自定义类型的主要方式，相当于其他语言的 class。

### 基本定义

```go
type Person struct {
    Name string
    Age  int
}

// 创建实例
p := Person{Name: "Alice", Age: 30}
p := Person{}  // 零值初始化
p := new(Person)  // 返回 *Person
```

### 结构体标签（Tag）

结构体标签用于元数据，常用于 JSON 序列化、ORM 映射等。

```go
type Person struct {
    Name string `json:"name" db:"name"`
    Age  int    `json:"age" db:"age"`
}

// 读取标签
field, _ := reflect.TypeOf(Person{}).FieldByName("Name")
fmt.Println(field.Tag.Get("json"))  // name
```

### 嵌套结构体（组合）

Go 没有继承，但通过嵌套结构体实现组合。

```go
type Address struct {
    City    string
    Country string
}

type Person struct {
    Name    string
    Address        // 匿名嵌套，相当于组合
}

// 访问嵌套字段
p := Person{Name: "Bob", Address: Address{City: "Beijing", Country: "China"}}
fmt.Println(p.City)      // 直接访问，Go 自动深度查找
fmt.Println(p.Address.City)  // 显式访问
```

### 有标签的结构体

```go
type User struct {
    ID   int    `json:"id"`
    Name string `json:"name"`
}
```

## 方法（Method）

方法是绑定到特定类型的函数。

### 值接收者 vs 指针接收者

```go
type Point struct {
    X, Y float64
}

// 值接收者 - 不修改原对象
func (p Point) Distance() float64 {
    return math.Sqrt(p.X*p.X + p.Y*p.Y)
}

// 指针接收者 - 可以修改原对象
func (p *Point) Scale(factor float64) {
    p.X *= factor
    p.Y *= factor
}

p := Point{3, 4}
fmt.Println(p.Distance())  // 5
p.Scale(2)
fmt.Println(p.X, p.Y)      // 6 8
```

### 方法惯例

- 如果方法需要修改对象，必须用指针接收者
- 如果方法涉及 nil 指针可能性，用指针接收者更安全
- 一致性：同一类型的值方法和指针方法要配对使用
- Go 允许用值调用指针接收者方法（自动取地址），反之亦然

```go
p := Point{3, 4}
p.Scale(2)  // OK，Go 自动转换为 (&p).Scale(2)
```

### 何时用值接收者

- 方法不修改调用者
- 结构体很小（拷贝成本低）
- 需要避免并发问题（不可变数据）

```go
// 不可变结构体
type Circle struct {
    Radius float64
}

func (c Circle) Area() float64 {
    return math.Pi * c.Radius * c.Radius
}
```

## 接口（Interface）

接口定义了方法集合，仅声明不实现。

### 基本用法

```go
type Shape interface {
    Area() float64
    Perimeter() float64
}

type Rectangle struct {
    Width, Height float64
}

func (r Rectangle) Area() float64 {
    return r.Width * r.Height
}

func (r Rectangle) Perimeter() float64 {
    return 2 * (r.Width + r.Height)
}

// 任何实现了 Shape 所有方法的类型都是 Shape
var s Shape = Rectangle{Width: 3, Height: 4}
fmt.Println(s.Area())  // 12
```

### 空接口

空接口 `any`（Go 1.18+）或 `interface{}` 可以存储任意类型。

```go
var i any = 42
i = "hello"
i = []int{1, 2, 3}

fmt.Printf("value: %v, type: %T\n", i, i)
// 输出: value: [1 2 3], type: []int
```

### 接口类型断言

```go
var s Shape = Rectangle{3, 4}

// 断言（不安全）
r := s.(Rectangle)

// comma-ok 语法（安全）
r, ok := s.(Rectangle)
if ok {
    fmt.Println(r.Width)
}

// switch 类型断言
switch v := s.(type) {
case Rectangle:
    fmt.Println("矩形:", v.Width, v.Height)
case Circle:
    fmt.Println("圆形:", v.Radius)
default:
    fmt.Println("未知类型")
}
```

### 接口组合

```go
type Reader interface {
    Read(p []byte) (n int, err error)
}

type Closer interface {
    Close() error
}

// 组合接口
type ReadCloser interface {
    Reader
    Closer
}
```

## Duck Typing（动态类型）

Go 采用 Duck Typing：只要对象实现了接口的方法，就可以使用接口类型，而无需显式声明。

### 隐式实现

Go 没有 `implements` 关键字。只要类型定义了接口要求的方法，就自动实现了该接口。

```go
type Writer interface {
    Write([]byte) (int, error)
}

// StringWriter 隐式实现了 Writer
type StringWriter struct {
    content strings.Builder
}

func (w *StringWriter) Write(p []byte) (int, error) {
    w.content.Write(p)
    return len(p), nil
}

// 可以直接赋值给接口
var w Writer = &StringWriter{}
w.Write([]byte("hello"))
```

### 常用标准库接口

| 接口 | 方法 | 用途 |
|------|------|------|
| `error` | `Error() string` | 错误表示 |
| `io.Reader` | `Read(p []byte) (n int, err error)` | 读取数据 |
| `io.Writer` | `Write(p []byte) (n int, err error)` | 写入数据 |
| `io.Closer` | `Close() error` | 关闭资源 |
| `fmt.Stringer` | `String() string` | 字符串表示 |

### sort.Interface 示例

```go
type IntSlice []int

func (s IntSlice) Len() int           { return len(s) }
func (s IntSlice) Less(i, j int) bool { return s[i] < s[j] }
func (s IntSlice) Swap(i, j int)      { s[i], s[j] = s[j], s[i] }

sort.Sort(IntSlice{3, 1, 4, 1, 5})
```

## 封装（Encapsulation）

Go 通过包级可见性实现封装。小写字母开头的标识符仅包内可见。

```go
package counter

type counter struct {  // 仅包内可见
    count int
}

func New() *counter {
    return &counter{}
}

func (c *counter) Increment() {  // 公开方法
    c.count++
}

func (c *counter) Value() int {  // 公开方法
    return c.count
}
```

### getter/setter 惯例

Go 通常直接访问字段而非 getter/setter。但如果需要，可以这样：

```go
type User struct {
    name string  // 私有
}

func (u *User) Name() string {  // getter
    return u.name
}

func (u *User) SetName(name string) {  // setter
    if name == "" {
        return
    }
    u.name = name
}
```

## 组合 vs 继承

Go 偏好组合而非继承。这是一种更灵活的设计方式。

### 继承的问题（其他语言）

```go
// 其他语言的继承
class Animal {
    void eat();
}
class Dog extends Animal {
    void bark();
}
```

### Go 的组合方式

```go
type Animal struct {
    Name string
}

func (a *Animal) Eat() {
    fmt.Printf("%s is eating\n", a.Name)
}

type Dog struct {
    Animal           // 组合（匿名字段）
    Breed string
}

func (d *Dog) Bark() {
    fmt.Println("Woof!")
}

d := Dog{
    Animal: Animal{Name: "Buddy"},
    Breed:  "Labrador",
}
d.Eat()   // 继承自 Animal
d.Bark()  // Dog 自有方法
```

### 委托（Delegation）

显式委托，组合但非嵌入：

```go
type Logger struct{}

func (l *Logger) Log(msg string) {
    fmt.Println("LOG:", msg)
}

type Service struct {
    logger *Logger  // 显式依赖
}

func (s *Service) DoSomething() {
    s.logger.Log("doing something")
}
```

## 多态（Polymorphism）

接口是 Go 中实现多态的主要方式。

### 函数参数使用接口

```go
type Speaker interface {
    Speak() string
}

type Dog struct{}
func (d Dog) Speak() string { return "Woof!" }

type Cat struct{}
func (c Cat) Speak() string { return "Meow!" }

func MakeSpeak(s Speaker) {
    fmt.Println(s.Speak())
}

MakeSpeak(Dog{})  // Woof!
MakeSpeak(Cat{})  // Meow!
```

### 切片接口类型

```go
shapes := []Shape{
    Rectangle{Width: 3, Height: 4},
    Circle{Radius: 5},
    Triangle{Base: 6, Height: 8},
}

for _, s := range shapes {
    fmt.Printf("Area: %.2f\n", s.Area())
}
```

### nil 接口

接口可以持有 nil 值，但调用 nil 方法会 panic。检查接口是否为 nil 很重要。

```go
var s Speaker
if s != nil {
    fmt.Println(s.Speak())
}
// 安全：s 为 nil 时不调用
```

## 构造函数

Go 没有构造函数，但可以通过工厂函数模拟。

```go
type Config struct {
    host string
    port int
}

// 导出工厂函数
func NewConfig(host string, port int) *Config {
    return &Config{
        host: host,
        port: port,
    }
}

// 私有构造函数（强制使用工厂）
func newDefaultConfig() *Config {
    return &Config{host: "localhost", port: 8080}
}
```

## 接口最佳实践

1. **小接口优先** - 接口应该小而专注，如 `io.Reader`、`io.Writer`
2. **接受接口，返回结构体** - 函数参数用接口，返回值用具体类型
3. **避免空接口滥用** - 空接口丧失类型安全，尽量用具体接口
4. **接口组合** - 将小接口组合成大接口
5. **duck typing 是契约** - 接口定义了契约，实现者必须满足所有方法

```go
// 好的接口设计
type ReadWriteCloser interface {
    Reader
    Writer
    Closer
}

// 不好的设计（太大）
type Everything interface {
    Read(p []byte) (n int, err error)
    Write(p []byte) (n int, err error)
    Close() error
    Seek(offset int64, whence int) (int64, error)
    // ... 更多方法
}
```
