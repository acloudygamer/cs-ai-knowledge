# Go 应用场景

## 本质断言

Go 以其高并发支持和静态编译特性，成为云原生基础设施和微服务的首选语言。

## 为什么 Go 适合云原生

### 设计匹配

<pre>
云原生需求          Go 设计选择
─────────────────────────────────
秒级启动        →   静态编译 + 最小运行时
十万并发        →   goroutine + GMP 调度
快速部署        →   单文件，无依赖
可扩展性        →   接口组合，模块解耦
可观测性        →   标准库 net/http/expvar
</pre>

## 微服务

### 为什么 Go 适合微服务

1. **启动快** — 毫秒级，适合容器快速扩缩容
2. **内存省** — goroutine 栈初始仅 2KB，远小于 OS 线程
3. **部署简** — 单二进制，镜像体积小
4. **强并发** — 自然处理高并发请求

### 框架对比

| 框架 | 特点 | 适用场景 |
|------|------|----------|
| Gin | 性能最高，API 简洁 | API 服务 |

| Fiber | Express 风格，上手快 | 快速开发 |

## CLI 工具

### 为什么 CLI 工具偏好 Go

- **跨平台编译** — `GOOS=linux GOARCH=amd64 go build`
- **单文件部署** — 无运行时依赖，用户机器无需安装 Go
- **启动快** — 毫秒级，适合脚本化调用
