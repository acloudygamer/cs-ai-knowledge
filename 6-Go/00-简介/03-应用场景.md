# Go 应用场景

## 云原生与容器化

Go 是云原生时代的首选语言，许多改变行业格局的项目都基于 Go 开发：

| 项目 | 用途 |
|------|------|
| Kubernetes | 容器编排平台，自动化部署、扩缩容 |
| Docker | 容器化技术，程序及其依赖打包 |
| Prometheus | 云原生监控系统 |
| Grafana | 可观测性数据可视化 |
| etcd | 分布式键值存储 |
| Terraform | 基础设施即代码 |
| Vault | 密钥管理与密封 |

### 云原生技术栈

```
容器层：Docker containerd
编排层：Kubernetes
服务网格：Istio、Linkerd
监控：Prometheus + Grafana
日志：Loki、ELK
追踪：Jaeger、Zipkin
```

## 微服务架构

Go 的高并发、低内存占用特性使其非常适合构建微服务：

- 启动快速，响应延迟低
- 易于部署为单个二进制文件
- 内置 HTTP/JSON 序列化支持
- 活跃的微服务框架生态（Gin、Echo、Fiber）

### 微服务框架对比

| 框架 | 特点 | 适用场景 |
|------|------|----------|
| Gin | 性能最高，API 简洁 | API 服务 |
| Echo | 功能丰富，中间件完善 | Web 应用 |
| Fiber | Express 风格，上手快 | 快速开发 |
| go-kit | 微服务工具箱 | 分布式系统 |

## 网络编程

Go 的标准库 net/http 让网络编程变得极其简单：

```go
http.HandleFunc("/", func(w http.ResponseWriter, r *http.Request) {
    fmt.Fprintf(w, "Hello, Go!")
})
http.ListenAndServe(":8080", nil)
```

### 网络库选择

| 场景 | 推荐库 |
|------|--------|
| HTTP 服务 | net/http、Gin |
| TCP/UDP | net 包 |
| WebSocket | gorilla/websocket |
| gRPC | google.golang.org/grpc |
| HTTP 客户端 | net/http、fasthttp |

## CLI 工具开发

许多流行的命令行工具由 Go 编写：

- Hugo — 静态网站生成器
- Terraform — 基础设施即代码
- Pulumi — 云基础设施编程
- gh — GitHub CLI
- caddy — Web 服务器
- vegeta — 负载测试工具
- hey — HTTP 负载生成

### CLI 生态

| 功能 | 库 |
|------|---|
| 命令行解析 | Cobra、Click |
| 配置管理 | Viper |
| 交互提示 | survey |
| 进度条 | progressbar |
| 表格输出 | tablewriter |

## DevOps 与脚本

Go 的跨平台编译和静态链接特性，使其成为编写跨平台 DevOps 工具的理想选择：

- **批量处理脚本** — 替代 Bash，跨平台运行
- **运维工具** — 部署脚本、监控采集
- **数据处理** — ETL、报表生成
- **网络工具** — 代理、端口扫描

### DevOps 常用工具

```bash
# 跨平台编译
GOOS=linux GOARCH=amd64 go build -o myapp

# 使用 goreleaser 发布
goreleaser release --snapshot --skip-publish
```
