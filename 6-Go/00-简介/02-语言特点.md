# Go 语言特点

## 静态类型，动态简洁

Go 是静态类型语言，但写起来像动态语言。变量声明简洁，类型推导让你无需处处标注类型，却仍能享受类型安全的好处。

```go
// 类型推导：无需声明类型
name := "Go语言"     // string（根据字面量推导）
age := 15            // int（整数默认是 int）
version := 1.22     // float64（浮点默认是 float64）
```

## 原生并发：goroutine

goroutine 是 Go 最强大的特性。你可以轻松创建数万个并发任务，而系统开销几乎为零：

```go
// 关键字 go 启动一个 goroutine
go func() {
    fmt.Println("我正在并发执行")
}()

// 带名字的函数
go doWork()
```

### goroutine 调度

goroutine 由 Go 运行时（Runtime）调度，而非操作系统：

- **MPG 模型**：M（Machine/OS线程）、P（Processor/上下文）、G（ Goroutine）
- **工作窃取**：空闲 P 从其他 P 偷取任务
- **GMP 数量**：默认等于 CPU 核心数

## channel：协程间的通信桥梁

channel 让协程之间的数据传递变得安全简单，无需锁机制即可实现并发通信：

```go
// 创建无缓冲 channel
ch := make(chan string)

// 发送数据（阻塞直到有人接收）
go func() { ch <- "数据" }()

// 接收数据
msg := <-ch
fmt.Println(msg)

// 带缓冲的 channel
ch := make(chan int, 10)
```

### channel 方向

```go
// 只发送
func sender(ch chan<- int) { ch <- 1 }

// 只接收
func receiver(ch <-chan int) { <-ch }

// 双向（函数参数中常用单向）
func process(in <-chan int, out chan<- int) {
    for n := range in {
        out <- n * 2
    }
}
```

## 其他显著特点

- **编译极快** — 整个项目秒级编译，媲美增量编译的脚本语言
- **垃圾回收** — 自动内存管理，告别手动内存分配
- **组合优于继承** — 用结构体嵌套和接口组合替代传统继承
- **标准库丰富** — net/http、encoding/json、os 等开箱即用
- **部署简单** — 编译成单个可执行文件，无依赖

## 设计哲学

Go 偏好显式而非隐式，简洁而非复杂。正如 Rob Pike 所说："Go 的设计就是让程序员少做蠢事。"

### 核心原则

1. **简单** — 减少关键字，只保留必要特性
2. **可读** — 代码即文档，注释辅助理解
3. **显式** — 明确错误处理，拒绝隐藏行为
4. **组合** — 小单元组合成大系统

### 争议与取舍

| 特性 | 舍弃原因 |
|------|----------|
| 类继承 | 组合更灵活，避免菱形继承 |
| 异常 | 错误作为返回值，显式处理更安全 |
| 泛型（早期） | 保持语法简洁（1.18 已加入） |
| 断言 | 避免运行时类型转换的隐患 |
