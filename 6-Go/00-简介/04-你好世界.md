# 你好，世界！

## 本质断言

Go 程序以 `package main` 声明入口包，`func main()` 定义程序执行起点，静态编译为单一可执行文件。

## 程序结构

### 分步执行流

<pre>
1. 加载阶段
   └─ 编译器定位 package main
2. 编译阶段
   └─ 静态编译，链接依赖，生成单一二进制
3. 启动阶段
   └─ 操作系统加载二进制 → 启动 runtime → 调用 main()
4. 运行阶段
   └─ 按序执行 main() 中的语句
5. 退出阶段
   └─ main() 返回 → 进程退出
</pre>

## 机制解释

### 为什么 Go 强制格式化

Go 使用 gofmt 强制统一代码风格，消除无意义的格式争论。代码风格不是个人偏好，而是协作的基础。强制格式化让团队协作更顺畅。

### 为什么 Go 选择静态编译

Go 编译产物是单一可执行文件，部署时无需关心目标机器是否安装了运行时。这使得 Docker 镜像可以极小（~5MB），部署流程极简。

### 为什么入口必须是 package main

Go 以包为编译单元，`package main` 告诉编译器这个包需要生成可执行文件。main 包的存在使得项目结构和入口点清晰可辨。

## 参考代码

```go
package main

import "fmt"

func main() {
    fmt.Println("你好，世界！")
}
```

运行：

```bash
go run hello.go
# 输出：你好，世界！
```
