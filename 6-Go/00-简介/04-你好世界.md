# 你好，世界！

Go 程序以 `package main` 声明入口包，`func main()` 定义程序入口点。import 导入依赖，`fmt.Println` 向控制台输出。Go 强制格式化（gofmt）和单一可执行文件输出。

## 代码结构

### `package main`

每个 Go 文件都属于一个包（package）。`package main` 是特殊包名，表示这是一个可执行程序入口。Go 编译器会把 `package main` 的文件编译成可执行文件。

### `import "fmt"`

`import` 关键字用于导入其他包。`fmt` 是 Go 标准库中的格式化 I/O 包，提供了 `Println`、`Printf` 等打印函数。

### `func main()`

`func` 是定义函数的关键字。`main` 是特殊函数名——它是程序执行的起点。当运行程序时，Go 会自动调用 `main` 函数。一个程序只能有一个 `main` 函数，而且必须放在 `package main` 的文件中。

### `fmt.Println`

`fmt.Println` 调用 fmt 包的 Println 函数，在控制台打印一行文字并换行。

### 参考样例

```go
package main

import "fmt"

func main() {
    fmt.Println("你好，世界！")
}
```

运行：

```bash
go run hello.go
# 输出：你好，世界！
```

## 扩展练习

修改代码，输出其他内容。

### 参考样例

```go
package main

import "fmt"

func main() {
    name := "Go语言"
    fmt.Println("欢迎学习", name)
    fmt.Println("版本：", 1.24)
}
```
