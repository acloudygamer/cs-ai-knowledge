# Go 学习路线

## 本质断言

Go 学习路径是从**语法基础**到**并发范式**再到**工程实践**的渐进过程——核心挑战在于理解 goroutine/channel 的并发模型和 interface 的组合设计。

## 数学模型

### goroutine 调度的学习曲线

学习 goroutine 的认知负担可建模为：

$$C_{goroutine} = C_{sequential} + C_{concurrency} + C_{deadlock}$$

- $C_{sequential}$：顺序编程基础（已有）
- $C_{concurrency}$：并发正确性（channel、sync）
- $C_{deadlock}$：死锁/活锁检测

理解 goroutine 后，$C_{goroutine} < C_{thread\_pool}$，因为 channel 提供了**线性推理**的并发方式。

### 知识图谱的度中心性

Go 知识图谱中，度中心性最高的节点：
- goroutine（连接 channel、sync、context）
- interface（连接类型系统、mock、插件）
- defer（连接控制流、资源管理、panic）

掌握这三个概念可解锁 70% 的 Go 核心知识。

## 机制

### 为什么 goroutine 是 Go 最核心的概念

goroutine 是 Go **设计哲学**的集中体现：
- 启动成本极低（2KB 栈 vs 1MB 线程）
- 调度在用户态完成（无内核陷入）
- 与 channel 配合实现无锁并发

理解 goroutine 后，再理解 channel——channel 是 goroutine 之间的**同步协议**，而非队列。

### 为什么 interface 是 Go 的组合基础

Go 的 interface 是**隐式实现**的：

```go
type Reader interface {
    Read(p []byte) (n int, err error)
}
// 任何实现了 Read 方法的类型都满足 Reader
// 无需显式声明 implements
```

这使得：
- **Mock 测试**：用 mock 对象实现接口，注入依赖
- **插件系统**：运行时加载实现相同接口的插件
- **解耦**：调用方只需知道接口，无需知道实现

### 为什么 defer 是资源管理的核心

defer 的**栈帧绑定**语义：
- defer 在函数入口注册，退出时按 LIFO 顺序执行
- 即使 panic，defer 仍然执行
- 适合资源清理（文件关闭、锁解锁、连接关闭）

## 学习阶段规划

### 第一阶段：入门（1-2周）

- 掌握基础语法：变量、数据类型、控制流程
- 理解函数的多返回值和错误处理
- 学会使用标准库（fmt、os、net/http）
- 能够编写简单的命令行程序

**里程碑**：完成一个 Todo 命令行应用

### 第二阶段：进阶（2-4周）

- **goroutine 与 channel** — Go 并发的核心，深入理解 CSP 模型
- 理解接口与组合设计
- 掌握 defer/panic/recover 机制
- 学习常用标准库（io、bufio、encoding/*）

**里程碑**：完成一个并发爬虫程序

### 第三阶段：实战（持续）

- 参与开源项目或构建自己的应用
- 学习常用框架（Gin、Echo）
- 了解 Go 最佳实践和性能调优
- 掌握调试和性能分析工具

**里程碑**：完成一个 Web API 服务

## 重点深入：goroutine 与 channel

这是 Go 区别于其他语言的核心，也是面试中最常考察的内容：

### 核心概念

| 概念 | 说明 |
|------|------|
| goroutine | 轻量级线程，由 Go 运行时管理 |
| channel | 协程间通信的管道，有缓冲/无缓冲之分 |
| select | 多路复用，同时等待多个 channel |
| context | 取消信号和超时控制 |

### 学习路径

1. 基础：goroutine 创建和基本使用
2. 进阶：channel 通信模式
3. 高级：select、context、sync 包
4. 实战：并发安全、竞态检测

## 实践建议

### 学习方法

1. **每天写代码** — Go 是实践性很强的语言，看十遍不如写一遍
2. **从读源码开始** — 阅读 Go 标准库源码是提升最快的方式之一
3. **参与社区** — GitHub、Go Forum、公众号都是好去处
4. **构建项目** — 学到一定程度后，尝试用 Go 重写你熟悉的工具

### 必做练习

- [ ] 实现一个 echo 服务器
- [ ] 实现一个并发文件下载器
- [ ] 实现一个简易的内存缓存
- [ ] 实现一个 HTTP 中间件
- [ ] 阅读一个开源项目源码

### 避坑指南

| 误区 | 正确做法 |
|------|----------|
| 忽略错误处理 | 始终检查并处理错误 |
| 过度使用 mutex | 优先使用 channel |
| 全局变量共享 | 用 context 传递请求级数据 |
| 忽略 GC 调优 | 了解 GC 工作原理 |
| 滥用 interface{} | 保持类型安全 |
