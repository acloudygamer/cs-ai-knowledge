# Go 学习路线

## 学习阶段规划

### 第一阶段：入门（1-2周）

- 掌握基础语法：变量、数据类型、控制流程
- 理解函数的多返回值和错误处理
- 学会使用标准库（fmt、os、net/http）
- 能够编写简单的命令行程序

**里程碑**：完成一个 Todo 命令行应用

### 第二阶段：进阶（2-4周）

- **goroutine 与 channel** — Go 并发的核心，深入理解 CSP 模型
- 理解接口与组合设计
- 掌握 defer/panic/recover 机制
- 学习常用标准库（io、bufio、encoding/*）

**里程碑**：完成一个并发爬虫程序

### 第三阶段：实战（持续）

- 参与开源项目或构建自己的应用
- 学习常用框架（Gin、Echo）
- 了解 Go 最佳实践和性能调优
- 掌握调试和性能分析工具

**里程碑**：完成一个 Web API 服务

## 重点深入：goroutine 与 channel

这是 Go 区别于其他语言的核心，也是面试中最常考察的内容：

### 核心概念

| 概念 | 说明 |
|------|------|
| goroutine | 轻量级线程，由 Go 运行时管理 |
| channel | 协程间通信的管道，有缓冲/无缓冲之分 |
| select | 多路复用，同时等待多个 channel |
| context | 取消信号和超时控制 |

### 学习路径

1. 基础：goroutine 创建和基本使用
2. 进阶：channel 通信模式
3. 高级：select、context、sync 包
4. 实战：并发安全、竞态检测

## 实践建议

### 学习方法

1. **每天写代码** — Go 是实践性很强的语言，看十遍不如写一遍
2. **从读源码开始** — 阅读 Go 标准库源码是提升最快的方式之一
3. **参与社区** — GitHub、Go Forum、公众号都是好去处
4. **构建项目** — 学到一定程度后，尝试用 Go 重写你熟悉的工具

### 必做练习

- [ ] 实现一个 echo 服务器
- [ ] 实现一个并发文件下载器
- [ ] 实现一个简易的内存缓存
- [ ] 实现一个 HTTP 中间件
- [ ] 阅读一个开源项目源码

### 避坑指南

| 误区 | 正确做法 |
|------|----------|
| 忽略错误处理 | 始终检查并处理错误 |
| 过度使用 mutex | 优先使用 channel |
| 全局变量共享 | 用 context 传递请求级数据 |
| 忽略 GC 调优 | 了解 GC 工作原理 |
| 滥用 interface{} | 保持类型安全 |
