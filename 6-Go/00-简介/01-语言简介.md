# Go 语言简介

## 本质断言

Go 是 Google 设计的一种追求简洁性、高效性与原生并发友好的系统编程语言。

## 设计哲学

Go 遵循"Less is more"——通过削减关键字和特性，降低复杂性，让协作更简单。

### 设计目标

1. **简洁性** — 减少关键字，语法清晰，抛弃不必要的复杂性
2. **高效性** — 编译速度如 C，执行效率接近 C/C++
3. **并发友好** — 原生协程支持，让并发编程变得轻而易举

## 核心机制

### 为什么 Go 选择组合优于继承

继承带来紧耦合和菱形继承问题。Go 通过结构体嵌套和接口组合，让类型之间的关系显式且可预测。组合使得系统各部分可以独立测试和替换。

### 为什么 Go 选择错误作为返回值

Go 强制显式错误处理，避免异常隐藏控制流。函数返回 `(result, error)`，调用者必须处理每个错误，这使得错误路径和正常路径同等清晰。

### 为什么 Go 没有泛型（早期）

早期 Go 故意放弃泛型以保持语法简洁、编译速度极快。泛型在 Go 1.18 引入，代价是复杂度增加，但仍是可选特性。

## 创始人

- **Rob Pike** — 贝尔实验室老兵，Unix 和 Plan 9 贡献者
- **Robert Griesemer** — Go 运行时和编译器核心设计者
- **Ken Thompson** — Unix 之父，B/C 语言先驱，1983 年图灵奖得主

## 发展历程

| 年份 | 版本 | 里程碑 |
|------|------|--------|
| 2009 | Go (pre-1.0) | 正式开源发布 |
| 2012 | Go 1.0 | 首个稳定版本 |
| 2015 | Go 1.5 | 编译器自举，GC 改进 |
| 2016 | Go 1.7 | Context 包加入标准库 |
| 2018 | Go 1.11 | Go Modules 引入 |
| 2022 | Go 1.18 | 泛型正式发布 |
| 2023 | Go 1.21 | 内置 min/max/clear，slog 日志，**for range 支持整数** |
| 2024 | Go 1.22 | for range 循环变量作用域修复 |
| 2024 | Go 1.23 | iter 包（迭代器）|
| 2026 | Go 1.24 | Swiss Table、weak 包、泛型类型别名 |
