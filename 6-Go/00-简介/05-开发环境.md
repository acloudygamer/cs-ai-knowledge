# Go 开发环境

## 安装 Go

### 官网下载安装

访问 [go.dev/dl/](https://go.dev/dl/) 下载对应平台的安装包：

- **Windows** — 下载 `.msi` 安装包，双击运行即可
- **macOS** — 下载 `.pkg` 安装包或使用 Homebrew：`brew install go`
- **Linux** — 下载 `.tar.gz` 压缩包，解压到 `/usr/local/go`

### 版本验证

安装完成后，打开终端/命令提示符，验证安装：

```bash
go version
# 输出：go version go1.24.0 darwin/arm64
```

### 环境变量说明

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `GOPATH` | 工作区路径（Go 1.11+ 不必需） | `~/go` |
| `GOROOT` | Go 安装目录 | 自动检测 |
| `PATH` | 包含 `bin` 目录 | 自动配置 |

## Go Modules

### 创建项目

Go 1.11+ 推荐使用 Go Modules 管理依赖：

```bash
# 初始化模块
go mod init github.com/username/projectname

# 示例
go mod init myapp
```

这会在当前目录生成 `go.mod` 文件：

```
module myapp

go 1.24
```

### 常用命令

```bash
# 下载依赖
go mod tidy

# 升级依赖
go get package@version

# 查看依赖
go list -m all

# 镜像配置
go env -w GOPROXY=https://goproxy.cn,direct
```

## 开发工具

### VS Code + Go 扩展

推荐插件：

| 插件 | 功能 |
|------|------|
| Go | 官方插件，语法高亮/智能提示/调试 |
| Go Outliner | 大纲视图，快速导航 |
| Todo Tree | TODO 注释追踪 |

配置 `settings.json`：

```json
{
    "go.useLanguageServer": true,
    "go.alternateTools": {},
    "go.formatTool": "gofmt"
}
```

### GoLand

JetBrains 出品，专业的 Go IDE：

- 智能代码补全
- 强大的重构工具
- 内置调试器和测试工具
- 支持 Go Modules

### Vim/Neovim

使用 `gopls`（Go Language Server）：

```vim
" .vimrc 配置示例
Plug 'neovim/nvim-lspconfig'
Plug 'williamboman/nvim-lsp-installer'

lua << EOF
require('lspconfig').gopls.setup({
    settings = {
        gopls = {
            analyses = { unusedparams = true },
            staticcheck = true,
        }
    }
})
EOF
```

## 常用命令

### 编译运行

```bash
# 运行单个文件
go run hello.go

# 编译为可执行文件
go build -o myapp hello.go

# 编译并运行
go build -o myapp && ./myapp
```

### 测试

```bash
# 运行测试
go test ./...

# 带详细输出
go test -v ./...

# 覆盖率
go test -cover ./...
```

### 代码质量

```bash
# 格式化代码
go fmt ./...

# 静态分析
go vet ./...

# 依赖检查
go mod verify
```

### 文档查看

```bash
# 查看包文档
go doc fmt

# 本地文档服务器
godoc -http=:6060
# 访问 http://localhost:6060
```

## IDE 配置检查

安装完 Go 扩展后，VS Code 会提示安装必要工具：

```
go install -v github.com/mdempsky/gocode
go install -v github.com/stamblerre/gocode
go install -v github.com/rogpeppe/godef
go install -v github.com/go-delve/delve/cmd/dlv
```

或一键安装所有工具：

```bash
go install golang.org/x/tools/...@latest
```

## 常见问题

### Windows PowerShell 找不到 go

检查 PATH 环境变量是否包含 `C:\Go\bin`。

### macOS 提示权限错误

使用 `sudo` 或修改 `/usr/local` 的权限。

### 下载依赖慢

配置国内镜像：

```bash
go env -w GOPROXY=https://goproxy.cn,direct
```

### go mod init 失败

确保在正确的工作目录，且没有中文路径。
