# 开发环境

> 完整配置详见 [安装与环境](../01-基础/01-安装与环境.md)

## 快速参考

| 项目 | 命令/工具 |
|------|----------|
| 安装验证 | `go version` |
| IDE | VS Code + Go 扩展 / GoLand |
| 国内代理 | `go env -w GOPROXY=https://goproxy.cn,direct` |
| 格式化 | `go fmt ./...` |
| 运行 | `go run main.go` |

## 第一个项目

```bash
mkdir hello && cd hello
go mod init github.com/username/hello
```

```go
package main

import "fmt"

func main() {
    fmt.Println("Hello, Go!")
}
```

```bash
go run main.go   # 运行
go build .       # 编译
```
