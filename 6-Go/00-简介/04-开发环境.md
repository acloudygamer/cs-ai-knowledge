# 开发环境

> 完整配置详见 [安装与环境](../01-基础/01-安装与环境.md)

## 安装 Go

```bash
# macOS
brew install go

# Windows
winget install Go.Go

# Linux（官方包）
wget https://go.dev/dl/go1.26.0.linux-amd64.tar.gz
sudo tar -C /usr/local -xzf go1.26.0.linux-amd64.tar.gz
export PATH=$PATH:/usr/local/go/bin

# 验证
go version  # go version go1.26.0 ...
```

## 第一个项目

```bash
mkdir hello && cd hello
go mod init github.com/username/hello
```

```go
// main.go
package main

import "fmt"

func main() {
    fmt.Println("Hello, Go!")
}
```

```bash
go run main.go   # 运行
go build .       # 编译
```
