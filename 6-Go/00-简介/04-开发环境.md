# 开发环境

## 安装 Go

### 官网下载

从 [go.dev/dl](https://go.dev/dl) 下载安装包：

```bash
# macOS / Linux
tar -C /usr/local -xzf go1.26.0.linux-amd64.tar.gz
export PATH=$PATH:/usr/local/go/bin

# Windows
# 下载 .msi 安装包，一键安装
```

### 包管理器

```bash
# macOS
brew install go

# Ubuntu / Debian
sudo apt update && sudo apt install golang-go

# Windows (winget)
winget install Go.Go
```

### 版本管理（推荐）

使用 Go 版本管理器管理多个版本：

```bash
# 安装
go install golang.org/dl@latest

# 安装特定版本
go install go1.24.0@latest
go install go1.26.0@latest

# 切换版本
go1.24.0 download  # 首次使用需要下载
go1.24.0 version   # 验证
go1.26.0 version
```

### 验证安装

```bash
go version
# go version go1.26.0 linux/amd64
```

## GOPATH 与模块

### GOPATH 模式（Go < 1.16）

```bash
export GOPATH=$HOME/go
export PATH=$PATH:$GOPATH/bin
```

### Go Modules 模式（Go >= 1.16）

Go 1.16+ 默认启用模块模式：

```bash
# 创建项目（自动生成 go.mod）
mkdir myproject && cd myproject
go mod init github.com/username/myproject

# 添加依赖
go get github.com/gin-gonic/gin

# 整理依赖
go mod tidy

# 查看依赖
go mod graph
```

### 环境变量

```bash
# 查看所有变量
go env

# 常用变量
go env GOROOT    # Go 安装路径
go env GOPATH     # 工作空间路径
go env GOMODCACHE # 模块缓存路径
go env GOVERSION  # 当前版本
go env GOPROXY    # 代理地址

# 设置代理（国内推荐）
go env -w GOPROXY=https://goproxy.cn,direct
go env -w GOSUMDB=off
```

## IDE 与编辑器

### VS Code（推荐）

安装扩展：

```
Go (golang.go)
```

配置：

```json
{
    "go.formatTool": "gofmt",
    "go.lintTool": "golangci-lint",
    "go.useLanguageServer": true,
    "editor.formatOnSave": true,
    "[go]": {
        "editor.defaultFormatting": "gofmt",
        "editor.codeActionsOnSave": {
            "source.organizeImports": "explicit"

    }
```

## 常用工具

### go install 安装工具

```bash
# 代码格式化
go install mvdan.cc/gofmt@latest

# 代码检查
go install github.com/golangci/golangci-lint/cmd/golangci-lint@latest

# 协议缓冲
go install google.golang.org/protobuf/cmd/protoc-gen-go@latest
go install google.golang.org/grpc/cmd/protoc-gen-go-grpc@latest

# Mock 生成
go install go.uber.org/mock/mockgen@latest

# 文档生成
go install github.com/dave/docmd@latest
```

### golangci-lint（推荐）

Go 1.26+ 推荐使用 golangci-lint：

```bash
# 安装
go install github.com/golangci/golangci-lint/cmd/golangci-lint@latest

# 运行
golangci-lint run ./...

# 配置文件 .golangci.yml
linters:
  enable:
    - errcheck
    - gosimple
    - govet
    - staticcheck
    - unused
```

### go fix（Go 1.26+）

Go 1.26 重写的现代化工具：

```bash
# 自动更新代码到现代 Go
go fix ./...

# 仅检查
go fix -c ./...
```

## 快速上手

### 创建第一个项目

```bash
# 1. 创建项目目录
mkdir hello && cd hello

# 2. 初始化模块
go mod init github.com/username/hello

# 3. 创建主文件
cat > main.go << 'EOF'
package main

import "fmt"

func main() {
    fmt.Println("Hello, Go!")
}
EOF

# 4. 运行
go run main.go

# 5. 编译
go build -o hello .
./hello
```

### 项目结构

标准项目布局：

```
myproject/
├── cmd/
│   └── myapp/
│       └── main.go       # 入口
├── internal/
│   ├── api/              # API 逻辑
│   └── pkg/              # 内部包
├── pkg/                  # 对外暴露的包
├── go.mod
└── go.sum
```

## 常见问题

### Windows 下 PATH 配置

```powershell
# PowerShell 永久设置
[Environment]::SetEnvironmentVariable(
    "Path",
    $env:Path + ";C:\Program Files\Go\bin",
    "User"
)
```

### 代理问题

```bash
# 设置中国镜像
go env -w GOPROXY=https://goproxy.cn,direct
go env -w GOSUMDB=off

# 或阿里云
go env -w GOPROXY=https://mirrors.aliyun.com/goproxy,direct
```

### 模块版本冲突

```bash
# 查看依赖版本
go list -m all

# 降级依赖
go get github.com/pkg/errors@v0.9.1

# 清理缓存
go clean -modcache
```

### WSL2 下 Go 环境

```bash
# WSL2 中安装
wsl -d Ubuntu
sudo apt install golang-go

# Windows Go 与 WSL2 Go 共存
# 在 WSL2 中使用 /mnt/c/Program Files/Go/bin/go.exe
# 或在 WSL2 中单独安装 Go
```
