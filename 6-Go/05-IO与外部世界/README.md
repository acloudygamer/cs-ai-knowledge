# 05-IO与外部世界

文件、网络、HTTP、数据库、日志、API 设计——进程边界之外的一切。前置：[01-语言核心](../01-语言核心/)、[02-标准库](../02-标准库/)（io 接口族）、[04-并发](../04-并发/)（context 取消）。

Go 的 I/O 全部收束到 `io.Reader`/`io.Writer` 两个接口上：文件、TCP 连接、HTTP body、压缩流都是同一对接口的实现，因此可以互相套接。这条是本节所有 API 能组合的原因。
