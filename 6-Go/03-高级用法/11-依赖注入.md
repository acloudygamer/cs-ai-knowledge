# 依赖注入

**依赖注入是通过外部注入依赖而非内部创建，提高可测试性和可维护性——Go 中惯用构造函数参数注入，框架层提供 Wire（编译时）和 fx（运行时）两种自动化方案。**

## 手动注入

**通过构造函数传递依赖，零框架开销，适合中小型项目。**

```
App → NewUserService(db, logger)
            ↓
      UserService → Repository → Database
                   ↘ Logger
```

### 接口注入

```go
type Logger interface { Log(string) }
type Database interface { Query(string) }

type Service struct{ db Database; logger Logger }
func NewService(db Database, logger Logger) *Service
```

### 简单容器

```go
type Container map[string]any
func (c Container) Get(name string) any { return c[name] }

c := Container{"db": NewDB()}
c.Get("db").(Database)
```

## Wire（编译时 DI）

**Wire 通过代码生成在编译时解析依赖图，零运行时开销——适合追求性能的项目。**

```
wire.gen.go（生成文件）：
  func InitializeService() *Service {
      return &Service{
          db:     NewDB(),
          logger: NewLogger(),
      }
  }
```

### Provider Set

```go
var LoggerSet = wire.NewSet(NewLogger, wire.Bind(new(Logger), new(*StdLogger)))
var DBSet = wire.NewSet(NewMySQL, wire.Bind(new(Database), new(*MySQL)))

func InitApp() (*App, error) {
    panic(wire.Build(LoggerSet, DBSet, NewUserService))
}
```

```bash
wire  # 生成 wire_gen.go
```

## fx（运行时 DI）

**fx 在运行时通过反射构建依赖图，支持生命周期管理和模块化——适合大型应用。**

```
fx.New(
    fx.Provide(NewLogger, NewDB),
    fx.Invoke(startServer),
).Run()
       ↓
  自动解析依赖顺序
  调用 NewLogger → NewDB → NewServer
  OnStart/OnStop 钩子自动注册
```

### 生命周期钩子

```go
fx.Invoke(func(lc fx.Lifecycle, s *Server) {
    lc.Append(fx.Hook{
        OnStart: func(ctx context.Context) error { return s.Start() },
        OnStop:  func(ctx context.Context) error { return s.Stop() },
    })
})
```

### 模块化

```go
var DatabaseModule = fx.Module("db", fx.Provide(NewDB, NewUserRepo))
var LoggerModule = fx.Module("log", fx.Provide(NewZapLogger))

fx.New(DatabaseModule, LoggerModule, fx.Invoke(startServer))
```

## 框架对比

| 特性 | 手动 | Wire | fx |
|------|------|------|-----|
| 运行时开销 | 无 | 无 | 有（反射） |
| 循环检测 | 手动 | 自动 | 自动 |
| 生命周期 | 手动 | 手动 | 内置 |
| 延迟加载 | 支持 | 否 | 支持 |

## 常见陷阱

```
循环依赖：  A→B→A  → 用接口解耦
初始化顺序：wire/fx 自动解析，但 init() 应避免
内存泄漏：  持有不需要的依赖引用
```
