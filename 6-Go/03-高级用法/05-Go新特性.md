# Go 新特性

Go 每个版本都带来了实用的新特性。这里介绍 Go 1.21 到 Go 1.26 的重要更新。

---

## Go 1.21 新特性

### 内置 min/max 函数

```go
// 内置 min/max（无需 import）
fmt.Println(min(1, 2, 3))   // 1
fmt.Println(max(1, 2, 3))   // 3

// 任意可比较类型
fmt.Println(min("apple", "banana")) // apple
```

### 内置 clear 函数

```go
// 清空切片
s := []int{1, 2, 3}
clear(s)  // s 变成 []（元素变零值）
fmt.Println(s) // []

// 清空 map
m := map[string]int{"a": 1, "b": 2}
clear(m)  // m 变成空 map
fmt.Println(m) // map[]
```

### 结构化日志（log/slog）

```go
import "log/slog"

logger := slog.New(slog.NewJSONHandler(os.Stdout))
logger.Info("hello", "key", "value", "count", 42)

logger2 := slog.New(slog.NewTextHandler(os.Stdout, &slog.HandlerOptions{
    Level: slog.LevelDebug,
}))
```

### cmp.Or 排序辅助

```go
import "cmp"

func getName(name *string) string {
    return cmp.Or(name, "unnamed")  // nil 或空字符串时返回默认值
}
```

### slices 包增强

```go
import "slices"

// Clone（Go 1.21 新增）
orig := []int{1, 2, 3}
dup := slices.Clone(orig)

// Contains（Go 1.21 新增）
slices.Contains([]int{1, 2, 3}, 2)     // true
slices.ContainsFunc([]int{1, 2, 3}, func(n int) bool { return n > 2 }) // true

```

### maps 包增强

```go
import "maps"

m1 := map[string]int{"a": 1, "b": 2}
m2 := map[string]int{"b": 3, "c": 4}

copied := maps.Clone(m1)           // 克隆
maps.Copy(m1, m2)                   // 合并：将 m2 的键值对复制到 m1（无返回值）
equal := maps.Equal(m1, m2)         // 相等比较
equalFunc := maps.EqualFunc(m1, m2, func(v1, v2 int) bool { return v1 == v2 })
```

### cmp 包

```go
import "cmp"

type Point struct{ X, Y int }

points := []Point{{1, 2}, {3, 4}, {1, 0}}
slices.SortFunc(points, func(a, b Point) int {
    return cmp.Compare(a.X, b.X)
})
```

## Go 1.22 新特性

### for range 循环变量作用域修复

Go 1.22 修复了经典的循环变量作用域 bug。

```go
// Go 1.21 之前（bug）：所有 goroutine 共享同一个 i
var funcs []func()
for i := 0; i < 3; i++ {
    funcs = append(funcs, func() { fmt.Println(i) })
}
for _, f := range funcs {
    f()  // 输出: 3, 3, 3（错误）
}

// Go 1.22：每次循环 i 是新变量
for i := 0; i < 3; i++ {
    funcs = append(funcs, func() { fmt.Println(i) })
}
for _, f := range funcs {
    f()  // 输出: 0, 1, 2（正确）
}
```

### for range 支持整数

```go
// Go 1.22 开始支持
for i := range 10 {
    fmt.Println(i)  // 0, 1, 2, ..., 9
}

// 倒序（配合 slices.Backward）
for i := range 10 {
    fmt.Println(9 - i)
}
```

### math/rand/v2

```go
import "math/rand/v2"

// 新 API
r := rand.New(rand.NewSource(42))
fmt.Println(r.IntN(100))  // 0-99 的随机数
fmt.Println(r.Float64())  // 0.0-1.0 随机浮点数

// 丢弃随机字节
r.Read(make([]byte, 10))
```

## Go 1.23 新特性

### iter 包（迭代器）

```go
import "iter"

nums := []int{1, 2, 3, 4, 5}

// Seq 和 Seq2
seq := iter.Seq[int](func(yield func(int) bool) {
    for _, n := range nums {
        if !yield(n) {
            return
        }
    }
})

for v := range seq {
    fmt.Println(v)
}

// 双向迭代器
seq2 := iter.Seq2[int, string](func(yield func(int, string) bool) {
    for i, v := range nums {
        if !yield(i, fmt.Sprintf("val:%d", v)) {
            return
        }
    }
})

for i, s := range seq2 {
    fmt.Printf("%d: %s\n", i, s)
}
```

### slices.Backward

```go
nums := []int{1, 2, 3, 4, 5}

for i := range slices.Backward(nums) {
    fmt.Println(nums[i])  // 5, 4, 3, 2, 1
}
```

### slices.Chunk

```go
nums := []int{1, 2, 3, 4, 5, 6, 7}
chunks := slices.Chunk(nums, 2)
// [[1, 2], [3, 4], [5, 6], [7]]
```

### unique 包（值内化）

```go
import "unique"

type Point struct{ X, Y int }

// unique.Make 对相等的值返回同一 Handle（指针相等），用于节省内存
p1 := unique.Make(Point{1, 2})
p2 := unique.Make(Point{1, 2})
p3 := unique.Make(Point{1, 3})

fmt.Println(p1 == p2)  // true（相同值返回相同 Handle）
fmt.Println(p1 == p3)  // false
```

### context.AfterFunc

```go
import "context"

ctx, cancel := context.WithCancel(context.Background())
defer cancel()

// AfterFunc 返回 stop 函数；调用 stop() 可阻止 f 执行
stop := context.AfterFunc(ctx, func() {
    fmt.Println("执行清理")
})
_ = stop

cancel()  // 触发清理函数
```

### errors.Join 支持错误解包

```go
import "errors"

err1 := errors.New("error 1")
err2 := errors.New("error 2")
joined := errors.Join(err1, err2)

// errors.Join 内部实现 Unwrap() []error，不是 Unwrap() error
// 因此 errors.Unwrap(joined) 返回 nil（需用 errors.Is/As 遍历）
fmt.Println(errors.Unwrap(joined)) // nil（join error 不支持单值 Unwrap）

// Is 和 As 遍历整个错误链
fmt.Println(errors.Is(joined, err1)) // true
fmt.Println(errors.Is(joined, err2)) // true
```

## Go 1.24 新特性

### 泛型类型别名

Go 1.24 完全支持泛型类型别名，类型别名可以像定义的类型一样被参数化。

```go
// 类型别名可以参数化
type List[T any] = []T

// 泛型别名
type MapPair[K, V any] = map[K]V

// 使用
nums := List[int]{1, 2, 3}
pairs := MapPair[string, int]{"a": 1, "b": 2}

// 约束别名
type OrderedList[T comparable] = []T
```

### weak 包（弱指针）

弱指针不阻止垃圾回收，用于构建缓存等内存敏感结构。

```go
import "weak"

type Node struct {
    Value int
    next  *Node
}

obj := &Node{Value: 42}
ptr := weak.Make(obj)

// Value 返回对象，如果已被 GC 回收则返回 nil
if v := ptr.Value(); v != nil {
    fmt.Println(v.Value)
}
```

### Swiss Table（map 引擎升级）

Go 1.24 引入 Swiss Table 实现，CPU 开销降低 2-3%。

```go
// 无需修改代码，map 内部自动使用 Swiss Table
m := make(map[string]int)
for i := range 1000 {
    m[fmt.Sprintf("key%d", i)] = i
}
```

可通过 `GOEXPERIMENT=noswissmap` 禁用。

### runtime.AddCleanup（改进的终结器）

比 `SetFinalizer` 更灵活高效：

- 支持每个对象多个 cleanup
- 支持循环引用不会泄漏
- 不延迟对象释放

```go
import "runtime"

obj := &MyResource{}
runtime.AddCleanup(obj, func() {
    fmt.Println("清理资源")
})
```

### os.Root（安全文件系统访问）

限制文件系统访问在指定目录内。

```go
import "os"

// 打开一个受限的根目录
root, err := os.OpenRoot("/tmp/sandbox")
if err != nil {
    log.Fatal(err)
}

// Open 无法访问 /tmp/sandbox 之外的路径
f, err := root.Open("file.txt")  // 只能访问 /tmp/sandbox/file.txt
```

### testing.B.Loop（基准测试改进）

```go
import "testing"

func BenchmarkFast(b *testing.B) {
    for b.Loop() {  // 替换 for range b.N
        // 基准测试代码
    }
}
```

优点：精确执行次数，防止编译器优化循环体。

## Go 1.26 新特性

### 扩展的 new 函数

`new` 不再只接受类型，现在可以接受表达式。

```go
type Person struct {
    Name string `json:"name"`
    Age  *int   `json:"age"`
}

func personJSON(name string, born time.Time) ([]byte, error) {
    return json.Marshal(Person{
        Name: name,
        Age:  new(yearsSince(born)),  // new 接受表达式
    })
}

// 等价于
tmp := yearsSince(born)
p := Person{Name: name, Age: &tmp}
```

```go
type Adder[A Adder[A]] interface {

func (a IntAdder) Add(b IntAdder) IntAdder { return a + b }
```

### crypto/hpke

混合公钥加密，实现 RFC 9180。用于混合加密场景，结合传统公钥加密与后量子算法。

```go
import "crypto/hpke"

// 密钥交换示例（发送方）
func encryptMessage(recipientPublicKey []byte, plaintext []byte) ([]byte, error) {
    // 创建发送方上下文
    ctx, err := hpke.NewSender(
        recipientPublicKey,
        hpke.KDFArg{
            Hash: hpke.KDFHashSHA256,
            Info: []byte("my-app-encryption"),
        },
    )
    if err != nil {
        return nil, err
    }
    defer ctx.Cleanup()

    // 生成共享密钥
    enc, sharedSecret, err := ctx.SeparateEncapper()
    if err != nil {
        return nil, err
    }

    // 使用共享密钥加密
    ciphertext, err := ctx.Seal(plaintext, sharedSecret)
    if err != nil {
        return nil, err
    }

    return append(enc, ciphertext...), nil
}

// 接收方解密
func decryptMessage(recipientPrivateKey, encapsulatedKey, ciphertext []byte) ([]byte, error) {
    ctx, err := hpke.NewRecipient(
        recipientPrivateKey,
        hpke.KDFArg{
            Hash: hpke.KDFHashSHA256,
            Info: []byte("my-app-encryption"),
        },
    )
    if err != nil {
        return nil, err
    }
    defer ctx.Cleanup()

    // 解封共享密钥
    sharedSecret, err := ctx.SeparateDecapper(encapsulatedKey)
    if err != nil {
        return nil, err
    }

    // 解密
    return ctx.Open(ciphertext, sharedSecret)
}
```

### errors.AsType

```go
import "errors"

// 定义自定义错误
type ValidationError struct {
    Field   string
    Message string
}

func (e *ValidationError) Error() string {
    return fmt.Sprintf("%s: %s", e.Field, e.Message)
}

// 旧写法 (Go 1.20)
var ve *ValidationError
if errors.As(err, &ve) {
    fmt.Println(ve.Field, ve.Message)
}

// 新写法 (Go 1.26) - 类型安全
if err := errors.AsType[ValidationError](err); err != nil {
    fmt.Println(err.Field, err.Message)
}
```

## 新特性代码示例

### 使用 iter.Seq 实现懒加载

```go
import "iter"
import "slices"

func LazyFilter(seq iter.Seq[int], pred func(int) bool) iter.Seq[int] {
    return func(yield func(int) bool) {
        for v := range seq {
            if pred(v) && !yield(v) {
                return
            }
        }
    }
}

nums := slices.Values([]int{1, 2, 3, 4, 5})
filtered := LazyFilter(nums, func(n int) bool { return n%2 == 0 })

for v := range filtered {
    fmt.Println(v)  // 2, 4
}
```

### 使用 testing/synctest 测试并发

```go
import "testing/synctest"

func TestConcurrent(t *testing.T) {

            time.Sleep(time.Second)  // 虚拟时间，立即完成
```

### 扩展的 new 函数（Go 1.26）

```go
// 计算函数返回指针
func yearsSince(t time.Time) int {
    return int(time.Since(t).Hours() / 24 / 365)
}

func personAge(born time.Time) *int {
    return new(yearsSince(born))  // new 接受表达式，避免临时变量
}

// 等价于
func personAge(born time.Time) *int {
    tmp := yearsSince(born)
    return &tmp
}
```
