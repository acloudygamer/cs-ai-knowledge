# Go 新特性

Go 每个版本都带来了实用的新特性。以下按版本组织，标注稳定版与前沿版分界。

---

## Go 1.21 新特性

### 内置 min/max 函数

内置函数，无需 import，直接比较可排序类型。

### 参考样例

```go
fmt.Println(min(1, 2, 3))   // 1
fmt.Println(max(1, 2, 3))   // 3
fmt.Println(min("apple", "banana")) // apple
```

### 内置 clear 函数

清空切片或 map 元素为零值。

### 参考样例

```go
// 清空切片
s := []int{1, 2, 3}
clear(s)  // s 变成 []（元素变零值）

// 清空 map
m := map[string]int{"a": 1, "b": 2}
clear(m)  // m 变成空 map
```

### 结构化日志（log/slog）

标准库内置结构化日志，支持 JSON/Text 两种格式。

### 参考样例

```go
import "log/slog"

logger := slog.New(slog.NewJSONHandler(os.Stdout))
logger.Info("hello", "key", "value", "count", 42)

logger2 := slog.New(slog.NewTextHandler(os.Stdout, &slog.HandlerOptions{
    Level: slog.LevelDebug,
}))
```

### cmp.Or 排序辅助

nil 或空值时返回默认值。

### 参考样例

```go
import "cmp"

func getName(name *string) string {
    return cmp.Or(name, "unnamed")
}
```

### slices 包增强

新增 Clone、Contains、IndexFunc 等工具函数。

### 参考样例

```go
import "slices"

orig := []int{1, 2, 3}
dup := slices.Clone(orig)
slices.Contains([]int{1, 2, 3}, 2)     // true
slices.ContainsFunc([]int{1, 2, 3}, func(n int) bool { return n > 2 }) // true
idx := slices.IndexFunc([]int{1, 2, 3}, func(n int) bool { return n > 1 }) // 1
```

### maps 包增强

### 参考样例

```go
import "maps"

m1 := map[string]int{"a": 1, "b": 2}
m2 := map[string]int{"b": 3, "c": 4}
copied := maps.Clone(m1)
maps.Copy(m1, m2)                   // 合并：将 m2 的键值对复制到 m1
equal := maps.Equal(m1, m2)
equalFunc := maps.EqualFunc(m1, m2, func(v1, v2 int) bool { return v1 == v2 })
```

### cmp 包

### 参考样例

```go
import "cmp"

type Point struct{ X, Y int }
points := []Point{{1, 2}, {3, 4}, {1, 0}}
slices.SortFunc(points, func(a, b Point) int {
    return cmp.Compare(a.X, b.X)
})
```

## Go 1.22 新特性

### for range 循环变量作用域修复

Go 1.22 修复了经典的循环变量作用域 bug：每次循环迭代创建新变量，而非共享。

### 参考样例

```go
// Go 1.21 之前（bug）：所有 goroutine 共享同一个 i
var funcs []func()
for i := 0; i < 3; i++ {
    funcs = append(funcs, func() { fmt.Println(i) })
}
for _, f := range funcs {
    f()  // 输出: 3, 3, 3（错误）
}

// Go 1.22：每次循环 i 是新变量
for i := 0; i < 3; i++ {
    funcs = append(funcs, func() { fmt.Println(i) })
}
for _, f := range funcs {
    f()  // 输出: 0, 1, 2（正确）
}
```

### for range 支持整数

### 参考样例

```go
// Go 1.22 开始支持
for i := range 10 {
    fmt.Println(i)  // 0, 1, 2, ..., 9
}
```

### math/rand/v2

重写的随机数 API。

### 参考样例

```go
import "math/rand/v2"

r := rand.New(rand.NewSource(42))
fmt.Println(r.IntN(100))  // 0-99 的随机数
fmt.Println(r.Float64())  // 0.0-1.0 随机浮点数
r.Read(make([]byte, 10))
```

## Go 1.23 新特性

### iter 包（迭代器）

新增 iter.Seq 和 iter.Seq2 接口，支持自定义迭代器。

### 参考样例

```go
import "iter"

nums := []int{1, 2, 3, 4, 5}

// Seq
seq := iter.Seq[int](func(yield func(int) bool) {
    for _, n := range nums {
        if !yield(n) {
            return
        }
    }
})
for v := range seq {
    fmt.Println(v)
}

// Seq2（双向迭代器）
seq2 := iter.Seq2[int, string](func(yield func(int, string) bool) {
    for i, v := range nums {
        if !yield(i, fmt.Sprintf("val:%d", v)) {
            return
        }
    }
})
for i, s := range seq2 {
    fmt.Printf("%d: %s\n", i, s)
}
```

### slices.Backward

逆序迭代。

### 参考样例

```go
for i := range slices.Backward(nums) {
    fmt.Println(nums[i])  // 5, 4, 3, 2, 1
}
```

### slices.Chunk

将切片分块。

### 参考样例

```go
nums := []int{1, 2, 3, 4, 5, 6, 7}
chunks := slices.Chunk(nums, 2)
// [[1, 2], [3, 4], [5, 6], [7]]
```

### unique 包（值内化）

相同值返回同一 Handle（指针相等），用于节省内存。

### 参考样例

```go
import "unique"

type Point struct{ X, Y int }
p1 := unique.Make(Point{1, 2})
p2 := unique.Make(Point{1, 2})
p3 := unique.Make(Point{1, 3})
fmt.Println(p1 == p2)  // true（相同值返回相同 Handle）
fmt.Println(p1 == p3)  // false
```

### context.AfterFunc

在 context 取消时执行函数。

### 参考样例

```go
import "context"

ctx, cancel := context.WithCancel(context.Background())
defer cancel()

stop := context.AfterFunc(ctx, func() {
    fmt.Println("执行清理")
})
cancel()  // 触发清理函数
```

### errors.Join 支持错误解包

### 参考样例

```go
import "errors"

err1 := errors.New("error 1")
err2 := errors.New("error 2")
joined := errors.Join(err1, err2)

fmt.Println(errors.Unwrap(joined)) // nil（join error 不支持单值 Unwrap）
fmt.Println(errors.Is(joined, err1)) // true
fmt.Println(errors.Is(joined, err2)) // true
```

## Go 1.24 新特性

### 泛型类型别名

类型别名可以参数化，像泛型类型一样使用。

### 参考样例

```go
type List[T any] = []T
type MapPair[K, V any] = map[K]V
type OrderedList[T comparable] = []T

nums := List[int]{1, 2, 3}
pairs := MapPair[string, int]{"a": 1, "b": 2}
```

### weak 包（弱指针）

弱指针不阻止垃圾回收，用于构建缓存等内存敏感结构。

### 参考样例

```go
import "weak"

type Node struct {
    Value int
    next  *Node
}
obj := &Node{Value: 42}
ptr := weak.Make(obj)
if v := ptr.Value(); v != nil {
    fmt.Println(v.Value)
}
```

### Swiss Table（map 引擎升级）

Go 1.24 引入 Swiss Table 实现，CPU 开销降低 2-3%，无需改写代码。

### 参考样例

```go
// 无需修改代码，map 内部自动使用 Swiss Table
m := make(map[string]int)
for i := range 1000 {
    m[fmt.Sprintf("key%d", i)] = i
}
// 可通过 GOEXPERIMENT=noswissmap 禁用
```

### runtime.AddCleanup（改进的终结器）

比 `SetFinalizer` 更灵活：支持每个对象多个 cleanup，支持循环引用，不延迟对象释放。

### 参考样例

```go
import "runtime"

obj := &MyResource{}
runtime.AddCleanup(obj, func() {
    fmt.Println("清理资源")
})
```

### os.Root（安全文件系统访问）

限制文件系统访问在指定目录内。

### 参考样例

```go
import "os"

root, err := os.OpenRoot("/tmp/sandbox")
if err != nil {
    log.Fatal(err)
}
f, err := root.Open("file.txt")  // 只能访问 /tmp/sandbox/file.txt
```

### testing.B.Loop（基准测试改进）

### 参考样例

```go
import "testing"

func BenchmarkFast(b *testing.B) {
    for b.Loop() {  // 替换 for range b.N
        // 基准测试代码
    }
}
```

### 新增 crypto 包

### 参考样例

```go
// ML-KEM-768（后量子密钥交换）
import "crypto/mlkem"
// HKDF（HMAC 密钥派生）
import "crypto/hkdf"
// PBKDF2（密码学密钥派生）
import "crypto/pbkdf2"
```

### strings.Lines 和 bytes.Lines（按行迭代）

### 参考样例

```go
import "strings"
import "bytes"

text := "line1\nline2\nline3"
for line := range strings.Lines(text) {
    fmt.Println(line)
}
data := []byte("hello\nworld")
for line := range bytes.Lines(data) {
    fmt.Println(string(line))

```

### encoding/json omitzero 标签

`omitzero` 只省略零值，保留空切片和空映射。

### 参考样例

```go

    Time    time.Time `json:"time,omitempty,omitzero"`

}
```

## Go 1.25 新特性 (<latest> 版本新增)

> **机制演进说明**
> - **Go 1.24 及以前**：GC 由运行时固定算法控制
> - **Go 1.25 变革**：实验性 Green Tea GC，GC 开销减少 10-40%

### Green Tea GC（实验性）

自适应垃圾回收器，根据负载动态调整。

### 参考样例

```bash

```

### Container-Aware GOMAXPROCS (<latest> 版本新增)

运行时自动感知 cgroup CPU 限制并调整。

### 参考样例

```go
import "runtime"

runtime.SetDefaultGOMAXPROCS(0)  // 自动调整至 cgroup 限制
```

### Trace Flight Recorder (<latest> 版本新增)

快照运行时 trace 数据。

### 参考样例

```go

fr.WriteTo(os.Stdout, 0)
```

### testing/synctest（正式版）

虚拟化时间，用于测试并发代码。Go 1.23 实验，Go 1.25 GA。

## Go 1.26 新特性 (<latest> 版本新增)

### 扩展的 new 函数

`new` 不再只接受类型，现在可以接受表达式。

### 参考样例

```go
type Person struct {
    Name string `json:"name"`
    Age  *int   `json:"age"`
}

func personJSON(name string, born time.Time) ([]byte, error) {
    return json.Marshal(Person{
        Name: name,
        Age:  new(yearsSince(born)),  // new 接受表达式
    })
}
```

### 自引用泛型 (<latest> 版本新增)

类型参数可以引用它所约束的泛型类型本身。

### 参考样例

```go
type Adder[A Adder[A]] interface {
    Add(A) A
}

type IntAdder int

func (a IntAdder) Add(b IntAdder) IntAdder { return a + b }
```

### Green Tea GC（默认启用）(<latest> 版本新增)

Go 1.26 默认启用，GC 开销减少 10-40%。

### 参考样例

```bash

```

### crypto/hpke（RFC 9180）(<latest> 版本新增)

混合公钥加密，结合传统公钥与后量子算法。

### 参考样例

```go
import "crypto/hpke"

// 发送方
ctx, err := hpke.NewSender(recipientPublicKey, hpke.KDFArg{
    Hash: hpke.KDFHashSHA256,
    Info: []byte("my-app-encryption"),
})
enc, sharedSecret, err := ctx.SeparateEncapper()
ciphertext, err := ctx.Seal(plaintext, sharedSecret)
return append(enc, ciphertext...), nil

// 接收方
ctx, err := hpke.NewRecipient(recipientPrivateKey, hpke.KDFArg{
    Hash: hpke.KDFHashSHA256,
    Info: []byte("my-app-encryption"),
})
sharedSecret, err := ctx.SeparateDecapper(encapsulatedKey)
return ctx.Open(ciphertext, sharedSecret)
```

### errors.AsType（泛型错误解包）(<latest> 版本新增)

泛型、类型安全的错误解包，替代 `errors.As`。

### 参考样例

```go
import "errors"

type ValidationError struct {
    Field   string
    Message string
}
func (e *ValidationError) Error() string {
    return fmt.Sprintf("%s: %s", e.Field, e.Message)
}

// 旧写法 (Go 1.20)
var ve *ValidationError
if errors.As(err, &ve) { fmt.Println(ve.Field, ve.Message) }

// 新写法 (Go 1.26)
if err := errors.AsType[ValidationError](err); err != nil {
    fmt.Println(err.Field, err.Message)
}
```

| `slices` | `Clone`, `Compare`, `Contains`, `IndexFunc` | `Concat` | `Chunk`, `Backward` | - | - | - |
| `bytes` | - | - | - | `Lines` | - | `Buffer.Peek` |
| `strings` | - | - | - | `Lines` | - | - |
| `maps` | `Clone`, `Copy`, `Equal` | - | `Collect`, `Insert` | - | - | - |
| `cmp` | `Ordered`, `Or` | - | - | - | - | - |
| `log/slog` | 新增结构化日志 | - | - | - | - | - |
| `math/rand` | - | v2 子模块 | - | - | - | - |
| `unique` | - | - | `Make` | - | - | - |
| `context` | - | - | `AfterFunc` | - | - | - |
| `iter` | - | - | 新增 | 增强 | - | - |
| `weak` | - | - | - | 新增 | - | - |
| `runtime` | - | - | - | `AddCleanup` | - | - |
| `os` | - | - | - | `Root` | - | - |
| `testing` | - | - | - | `B.Loop` | `synctest` GA | - |
