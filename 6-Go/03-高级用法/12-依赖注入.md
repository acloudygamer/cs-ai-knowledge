# 依赖注入

依赖注入（DI）是一种设计模式，通过外部注入而非内部创建依赖，提高代码的可测试性和可维护性。Go 中有多种实现方式，从手动注入到自动化框架。

---

## 手动依赖注入

最简单的 DI 方式是手动注入依赖，适合小型项目。

### 基础结构

```go
package main

import "fmt"

// 定义接口
type Logger interface {
    Log(msg string)
}

type StderrLogger struct{}

func (l *StderrLogger) Log(msg string) {
    fmt.Println("ERROR:", msg)
}

type UserService struct {
    logger Logger  // 依赖注入
}

func NewUserService(logger Logger) *UserService {
    return &UserService{logger: logger}
}

func (s *UserService) Create(name string) {
    s.logger.Log("creating user: " + name)
}
```

### 构造函数注入

```go
type Database interface {
    Query(sql string) ([]string, error)
}

type MySQL struct {
    connectionString string
}

func NewMySQL(connStr string) *MySQL {
    return &MySQL{connectionString: connStr}
}

func (db *MySQL) Query(sql string) ([]string, error) {
    // 实现 Query
    return nil, nil
}

type UserRepository struct {
    db     Database  // 依赖接口而非具体实现
    logger Logger
}

func NewUserRepository(db Database, logger Logger) *UserRepository {
    return &UserRepository{db: db, logger: logger}
}
```

### 全局注册表（简单容器）

```go
import "sync"

type Container struct {
    services map[string]any
    mu       sync.RWMutex
}

func NewContainer() *Container {
    return &Container{services: make(map[string]any)}
}

func (c *Container) Register(name string, service any) {
    c.mu.Lock()
    defer c.mu.Unlock()
    c.services[name] = service
}

func (c *Container) Get(name string) (any, bool) {
    c.mu.RLock()
    defer c.mu.RUnlock()
    service, ok := c.services[name]
    return service, ok
}

// 使用
func main() {
    container := NewContainer()

    container.Register("logger", &StderrLogger{})
    container.Register("db", NewMySQL("localhost:3306"))

    // 获取依赖
    logger, _ := container.Get("logger")
    logger.(Logger).Log("application started")
}
```

## Google Wire

Wire 是 Google 开发的编译时依赖注入框架。

### 安装

```bash
go install github.com/google/wire/cmd/wire@latest
```

### 基本用法

```go
// wire.go
//go:build wireinject

package main

import "github.com/google/wire"

func InitializeEventBus(logger Logger) EventBus {
    wire.Build(NewEventBus, NewLogger)
    return nil
}
```

### 生成代码

```bash
wire
```

生成的文件包含完整的依赖图解析逻辑。

### Provider Set

```go
// provider.go
package main

// LoggerProvider 是 provider set
var LoggerProvider = wire.NewSet(
    NewLogger,
    wire.Bind(new(Logger), new(*StdLogger)),
)

// DatabaseProvider
var DatabaseProvider = wire.NewSet(
    NewMySQL,
    wire.Bind(new(Database), new(*MySQL)),
)

// AppProvider 组合多个 set
var AppProvider = wire.NewSet(
    LoggerProvider,
    DatabaseProvider,
    NewUserService,
    NewOrderService,
)

func InitializeApp() (*App, error) {
    panic(wire.Build(AppProvider))
}
```

### 结构体注入

```go
type AppConfig struct {
    Database *MySQL
    Logger   *StdLogger
    Redis    *Redis
}

var ConfigProvider = wire.NewSet(
    NewMySQL,
    NewStdLogger,
    NewRedis,
)

func InitializeConfig() (*AppConfig, error) {
    panic(wire.Build(ConfigProvider))
}
```

### 绑定接口

```go
// 绑定接口到具体实现
var LoggerSet = wire.NewSet(
    NewStdLogger,
    wire.Bind(new(Logger), new(*StdLogger)),
)

// 绑定值
var ConfigSet = wire.NewSet(
    wire.Value(AppConfig{
        Timeout: 30 * time.Second,
    }),
)
```

## fx（Uber 的 DI 框架）

fx 是 Uber 开发的运行时依赖注入框架。

### 安装

```bash
go get go.uber.org/fx
```

### 基础用法

```go
import (
    "go.uber.org/fx"
    "go.uber.org/zap"
)

func main() {
    fx.New(
        fx.Provide(
            NewLogger,
            NewUserService,
            NewConfig,
        ),
        fx.Invoke(startServer),
    ).Run()
}
```

### 提供依赖

```go
// NewLogger 创建 logger
func NewLogger() *zap.Logger {
    logger, _ := zap.NewProduction()
    return logger
}

// NewConfig 解析配置
func NewConfig() (*Config, error) {
    return &Config{Port: 8080}, nil
}

// NewUserService 注入依赖
func NewUserService(logger *zap.Logger, db *sql.DB) *UserService {
    return &UserService{
        logger: logger,
        db:     db,
    }
}
```

### 生命周期钩子

```go
func main() {
    fx.New(
        fx.Provide(NewServer),
        fx.Invoke(func(lc fx.Lifecycle, server *Server) {
            lc.Append(fx.Hook{
                OnStart: func(ctx context.Context) error {
                    return server.Start()
                },
                OnStop: func(ctx context.Context) error {
                    return server.Stop()
                },
            })
        }),
    ).Run()
}
```

### 模块化

```go
// database 模块
var DatabaseModule = fx.Module("database",
    fx.Provide(NewDB),
    fx.Provide(NewUserRepository),
)

// logger 模块
var LoggerModule = fx.Module("logger",
    fx.Provide(NewZapLogger),
)

// 组合模块
func main() {
    fx.New(
        DatabaseModule,
        LoggerModule,
        fx.Invoke(startServer),
    ).Run()
}
```

## 第三方库对比

| 特性 | 手动 | google/wire | uber/fx |
|------|------|-------------|---------|
| 运行时开销 | 无 | 无 | 有 |
| 配置复杂度 | 低 | 中 | 高 |
| 延迟加载 | 支持 | 否 | 支持 |
| 循环检测 | 手动 | 是 | 是 |
| 生命周期 | 手动 | 手动 | 内置 |

## 测试中的依赖注入

### Mock 接口

```go
type MockLogger struct {
    logs []string
}

func (m *MockLogger) Log(msg string) {
    m.logs = append(m.logs, msg)
}

// 测试
func TestUserService(t *testing.T) {
    mockLogger := &MockLogger{}
    service := NewUserService(mockLogger)

    service.Create("Alice")

    if len(mockLogger.logs) != 1 {
        t.Errorf("expected 1 log, got %d", len(mockLogger.logs))
    }
}
```

### 注入点测试

```go
import "go.uber.org/fx"

func TestWithFx(t *testing.T) {
    var svc *UserService
    app := fx.New(
        fx.Provide(
            &MockConfig{Timeout: 100 * time.Millisecond},
            fx.Annotate(
                NewUserService,
                fx.ParamTags(`optional:"true"`),
            ),
        ),
        fx.Populate(&svc),
    )

    // 执行测试
    app.Err()
}
```

## 最佳实践

### 1. 依赖接口而非具体实现

```go
// 好：依赖接口
type UserService struct {
    repository UserRepository  // 接口
    logger     Logger          // 接口
}

// 差：依赖具体类型
type BadService struct {
    repo *MySQLRepository  // 具体类型
}
```

### 2. 避免全局状态

```go
// 差：全局变量
var globalLogger *Logger

// 好：通过参数传递
func NewService(logger Logger) *Service {
    return &Service{logger: logger}
}
```

### 3. 单一职责

```go
// 好：每个结构体职责单一
type UserService struct {
    userRepo  UserRepository
    orderRepo OrderRepository  // 不是 UserService 的职责
}

// 好：拆分
type OrderService struct {
    orderRepo OrderRepository
}
```

### 4. 构造函数清晰

```go
// 好：明确的构造函数
func NewUserService(cfg Config, repo UserRepo, logger Logger) (*UserService, error) {
    if cfg.Timeout <= 0 {
        return nil, errors.New("timeout must be positive")
    }
    return &UserService{...}, nil
}
```

### 5. 可选依赖

```go
type Service struct {
    logger Logger  // 可选
}

// 使用选项模式
type ServiceOption func(*Service)

func WithLogger(logger Logger) ServiceOption {
    return func(s *Service) {
        s.logger = logger
    }
}

func NewService(opts ...ServiceOption) *Service {
    s := &Service{}
    for _, opt := range opts {
        opt(s)
    }
    return s
}

// 使用
svc := NewService(WithLogger(logger))
```

## 常见陷阱

### 循环依赖

```go
// 错误：循环依赖
type A struct{ b *B }
type B struct{ a *A }

// 解决方案：重构设计或使用接口解耦
type Handler interface {
    Handle()
}

type A struct{ h Handler }
type B struct{ h Handler }
```

### 初始化顺序

```go
// wire 或 fx 自动解析依赖顺序
// 但需要注意：
// 1. 避免在 init() 中创建依赖
// 2. 使用 lazy initialization 解决循环问题

type LazyService struct {
    once  sync.Once
    inner *InnerService
}

func (s *LazyService) Get() *InnerService {
    s.once.Do(func() {
        s.inner = NewInnerService()
    })
    return s.inner
}
```

### 内存泄漏

```go
// 差：持有不需要的引用
type Cache struct {
    items map[string]any
}

// 好：及时清理
func (c *Cache) Clear() {
    c.items = make(map[string]any)
}
```
