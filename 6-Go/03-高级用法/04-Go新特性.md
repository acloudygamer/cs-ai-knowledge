# Go 新特性

**定义**：Go 每个版本都带来了实用的新特性。Go 1.21 ~ 1.24 是稳定版主力，Go 1.25 ~ 1.26 包含前沿特性（标注 `<latest>`）。

## 版本模型与生命周期

### 数学模型

**版本号语义**：Go 采用语义化版本（SemVer）：
$$Major.Minor.Patch$$

- Major：破坏性变更（Go 2.0 未发布，当前始终为 1）
- Minor：新功能（向后兼容）
- Patch：错误修复

**版本支持周期**：
- 当前稳定版：约 2 年
- 安全修复：当前稳定版 + 前一个 Minor 版本

## Go 1.21 新特性（stable）

### 内置 min/max/clear 函数

### 定义
内置函数无需 import，直接比较可排序类型——编译器内联，无函数调用开销。

### 数学模型

**内联优化**：编译器将 `min(a, b)` 直接替换为条件指令（如 `cmp + cmov`），无函数调用开销：
$$T_{min}(a, b) = O(1)$$
而非普通函数调用的 $O(1) + O(\text{call overhead})$。

### 参考存根

```go
fmt.Println(min(1, 2, 3))   // 1
fmt.Println(max(1, 2, 3))   // 3

s := []int{1, 2, 3}
clear(s)  // 元素变零值 []

m := map[string]int{"a": 1, "b": 2}
clear(m)  // 变成空 map
```

### 结构化日志 log/slog

### 定义
标准库内置结构化日志，支持 JSON/Text 两种格式，替代第三方日志库。

### 数据流

<pre>
slog 日志输出路径：

LogRecord{
    Time, Level, Message, Attrs...
}
    │
    ├─→ JSONHandler → json.Marshal → io.Writer
    └─→ TextHandler → 格式化字符串 → io.Writer
</pre>

### 参考存根

```go
logger := slog.New(slog.NewJSONHandler(os.Stdout))
logger.Info("hello", "key", "value", "count", 42)
```

### slices/maps/cmp 包增强

```go
orig := []int{1, 2, 3}
dup := slices.Clone(orig)
slices.Contains([]int{1, 2, 3}, 2)  // true

m1 := map[string]int{"a": 1, "b": 2}
m2 := map[string]int{"b": 3, "c": 4}
maps.Copy(m1, m2)
```

## Go 1.22 新特性（stable）

### for range 循环变量作用域修复

### 定义
Go 1.22 修复了经典 bug：每次循环迭代创建新变量，而非共享同一个变量地址。

### 数学模型

**旧行为（Go 1.21 之前）**：
$$i_{shared} = \text{单一变量，所有 goroutine 共享同一地址}$$

**新行为（Go 1.22+）**：
$$i_n = \text{第 n 次迭代的独立变量}$$

### 数据流

<pre>
Go 1.21 之前（bug）：
  for i := 0; i < 3; i++ {
      go func() { fmt.Println(i) }()
  }
  i 在每次迭代中被覆盖
  goroutine 读取时 i 已变为 3

Go 1.22（修复）：
  for i := 0; i < 3; i++ {
      go func() { fmt.Println(i) }()
  }
  每次迭代 i 是独立变量
  goroutine 读取时各自获得 0, 1, 2
</pre>

### 参考存根

```go
for i := range 10 {
    fmt.Println(i)  // 0, 1, 2, ..., 9
}
```

### math/rand/v2

```go
r := rand.New(rand.NewSource(42))
fmt.Println(r.IntN(100))
fmt.Println(r.Float64())
```

## Go 1.23 新特性（stable）

### iter 包（迭代器）

### 定义
iter.Seq 和 iter.Seq2 接口支持自定义迭代器，yield 模式替代闭包。

### 数学模型

**迭代器接口**：
```go
type Seq[T any] func(yield func(T) bool)
type Seq2[K, V any] func(yield func(K, V) bool)
```

**yield 语义**：yield 函数返回 true 继续迭代，返回 false 提前终止。

### 参考存根

```go
seq := iter.Seq[int](func(yield func(int) bool) {
    for _, n := range nums {
        if !yield(n) {
            return
        }
    }
})
for v := range seq {
    fmt.Println(v)
}

seq2 := iter.Seq2[int, string](func(yield func(int, string) bool) {
    for i, v := range nums {
        if !yield(i, fmt.Sprintf("val:%d", v)) {
            return
        }
    }
})
```

### slices.Backward / slices.Chunk

```go
for i := range slices.Backward(nums) {
    fmt.Println(nums[i])  // 5, 4, 3, 2, 1
}

chunks := slices.Chunk(nums, 2)  // [[1, 2], [3, 4], [5, 6], [7]]
```

### unique 包（值内化）

### 定义
相同值返回同一 Handle（指针相等），用于节省内存。

### 数学模型

**值内化（Value Interning）**：
$$\forall x, y: x = y \Rightarrow unique.Make(x) = unique.Make(y)$$

通过维护字符串到指针的映射实现。

### 参考存根

```go
p1 := unique.Make(Point{1, 2})
p2 := unique.Make(Point{1, 2})
fmt.Println(p1 == p2)  // true
```

## Go 1.24 新特性（stable）

### 泛型类型别名

```go
type List[T any] = []T
type MapPair[K, V any] = map[K]V

nums := List[int]{1, 2, 3}
pairs := MapPair[string, int]{"a": 1, "b": 2}
```

### weak 包（弱指针）

### 定义
弱指针不阻止 GC，用于构建缓存等内存敏感结构。

### 数学模型

**弱引用语义**：
- 强引用阻止 GC（普通指针）
- 弱引用不阻止 GC
- GC 后弱引用返回 nil 或对象（取决于是否还有强引用）

### 参考存根

```go
obj := &Node{Value: 42}
ptr := weak.Make(obj)
if v := ptr.Value(); v != nil {
    fmt.Println(v.Value)
}
// obj = nil 后，GC 可能回收节点
// ptr.Value() 将返回 nil
```

### Swiss Table（map 引擎升级）

### 定义
Go 1.24 引入 Swiss Table 实现，CPU 开销降低 2-3%，无需改写代码。

### 数学模型

**Swiss Table 原理**：
- 传统 Go map：链表解决冲突（最坏 O(n)）
- Swiss Table：开放地址法 + robin hood hashing
- 查找复杂度：$O(1)$ 均摊，$O(\log n)$ 最坏

### runtime.AddCleanup（改进的终结器）

```go
obj := &MyResource{}
runtime.AddCleanup(obj, func() {
    fmt.Println("清理资源")
})
```

### os.Root（安全文件系统访问）

```go
root, _ := os.OpenRoot("/tmp/sandbox")
f, _ := root.Open("file.txt")  // 只能访问 /tmp/sandbox/file.txt
```

## Go 1.25 新特性（<latest>）

### Green Tea GC（实验性）

### 定义
自适应垃圾回收器，根据负载动态调整，GC 开销减少 10-40%。

### 数学模型

**自适应策略**：根据对象生命周期分布动态调整标记/清扫策略：
- 短生命周期对象多的负载：更频繁的清扫
- 长生命周期对象多的负载：更保守的标记

### 参考存根

```bash
GOEXPERIMENT=greenteagc go build ./...
```

### Container-Aware GOMAXPROCS

```go
runtime.SetDefaultGOMAXPROCS(0)  // 自动调整至 cgroup 限制
```

### testing/synctest（GA）

### 定义
虚拟化时间，用于测试并发代码。

### 数学模型

**虚拟时间语义**：`b.Sleep(time.Hour)` 在虚拟时间中立即执行，不等待实际时间流逝。

### 参考存根

```go
synctest.Test(func(b *synctest.B) {
    b.Sleep(time.Hour)  // 立即执行
})
synctest.Wait()
```

## 包变化总结

| 包 | Go 1.21 | Go 1.22 | Go 1.23 | Go 1.24 | Go 1.25 | Go 1.26 |
|----|--------|---------|---------|---------|---------|---------|
| 内置 | `min`, `max`, `clear` | `for range` 整数 | - | - | - | `new` 支持表达式 |
| `slices` | `Clone`, `Contains` | `Concat` | `Chunk`, `Backward` | - | - | - |
| `bytes` | - | - | - | `Lines` | - | `Buffer.Peek` |
| `maps` | `Clone`, `Copy`, `Equal` | - | `Collect`, `Insert` | - | - | - |
| `iter` | - | - | 新增 | 增强 | - | - |
| `weak` | - | - | - | 新增 | - | - |
| `testing` | - | - | - | `B.Loop` | `synctest` GA | - |
| `crypto` | - | - | - | `mlkem`, `hkdf` | - | `hpke` |
