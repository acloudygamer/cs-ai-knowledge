# 性能优化

## 性能测试基础

### 基准测试（Benchmark）

```go
import "testing"

func BenchmarkStringConcat(b *testing.B) {
    for i := 0; i < b.N; i++ {
        var s string
        for j := 0; j < 100; j++ {
            s += "hello"
        }
    }
}

func BenchmarkBuilderConcat(b *testing.B) {
    for i := 0; i < b.N; i++ {
        var builder strings.Builder
        for j := 0; j < 100; j++ {
            builder.WriteString("hello")
        }
        builder.String()
    }
}

func BenchmarkBufferConcat(b *testing.B) {
    for i := 0; i < b.N; i++ {
        var buf bytes.Buffer
        for j := 0; j < 100; j++ {
            buf.WriteString("hello")
        }
        buf.String()
    }
}
```

### 运行基准测试

```bash
# 运行所有基准测试
go test -bench=.

# 运行指定基准测试
go test -bench=BenchmarkStringConcat

# 显示内存分配
go test -bench=. -benchmem

# 统计分配次数和大小
go test -bench=. -benchmem -memprofilerate=1

# 运行指定时间
go test -bench=. -benchtime=5s

# 调整 GOMAXPROCS
go test -bench=. -benchmem -parallel=4
```

## Race Detector

### 使用竞态检测

```bash
# 运行测试时启用
go test -race ./...

# 运行程序时启用
go run -race main.go

# 构建时启用
go build -race ./...
```

### 竞态示例

```go
package main

import (
    "fmt"
    "sync"
)

var counter int

func main() {
    var wg sync.WaitGroup
    for i := 0; i < 1000; i++ {
        wg.Add(1)
        go func() {
            counter++  // 竞态条件！
            wg.Done()
        }()
    }
    wg.Wait()
    fmt.Println(counter)  // 可能不是 1000
}
```

### 修复竞态

```go
// 方法1: sync.Mutex
var (
    counter int
    mu      sync.Mutex
)

func increment() {
    mu.Lock()
    counter++
    mu.Unlock()
}

// 方法2: sync/atomic
var counter atomic.Int64

func increment() {
    counter.Add(1)
}

// 方法3: channel
func worker(ch chan int) {
    ch <- 1  // 序列化访问
}
```

## 切片操作优化

### 预分配容量

```go
// 不预分配：多次扩容
func withoutPrealloc() []int {
    var s []int
    for i := 0; i < 1000; i++ {
        s = append(s, i)
    }
    return s
}

// 预分配：一次分配
func withPrealloc() []int {
    s := make([]int, 0, 1000)  // 预分配 1000 容量
    for i := 0; i < 1000; i++ {
        s = append(s, i)
    }
    return s
}
```

### 切片是引用

```go
// 函数内修改会影响原切片
func modify(s []int) {
    s[0] = 100  // 会修改原切片
}

// 如果需要扩展切片，返回新切片
func extend(s []int) []int {
    return append(s, 4)
}
```

### 高效拷贝

```go
// 使用 copy 而非遍历
src := []int{1, 2, 3}
dst := make([]int, len(src))
copy(dst, src)

// 克隆切片
clone := append([]int(nil), src...)

// 拷贝部分
copy(dst[:2], src[:2])
```

## 字符串拼接优化

### 方法对比

```go
// 方法1: + 拼接（少量拼接）
result := "a" + "b" + "c"

// 方法2: fmt.Sprintf（最慢，调试用）
result := fmt.Sprintf("%s%s%s", s1, s2, s3)

// 方法3: strings.Builder（推荐）
var builder strings.Builder
for i := 0; i < 1000; i++ {
    builder.WriteString("hello")
}
result := builder.String()

// 方法4: bytes.Buffer
var buf bytes.Buffer
for i := 0; i < 1000; i++ {
    buf.WriteString("hello")
}
result := buf.String()

// 方法5: strings.Join（数组拼接）
parts := []string{"hello", "world", "foo"}
result := strings.Join(parts, ", ")
```

### strings.Builder 原理

```go
// 预分配
var builder strings.Builder
builder.Grow(10000)  // 预分配，减少扩容

// 避免频繁 Reset
builder.Reset()  // 清空内容，复用内存
```

## 反射优化

### 反射开销

```go
// 反射比直接调用慢 10-100 倍

// 慢
v := reflect.ValueOf(x)
v.FieldByName("Name").Interface()

// 快
x.Name  // 直接访问
```

### 替代方案

```go
// 1. 泛型（Go 1.18+）
func Map[T, U any](s []T, fn func(T) U) []U { ... }

// 2. 接口
type Stringer interface {
    String() string
}

// 3. 代码生成（最高效）
//go:generate stringer -type Status
type Status int

// 4. map 缓存反射结果
var typeCache = sync.Map{}

func getFieldIndex(t reflect.Type, name string) int {
    if cached, ok := typeCache.Load(t); ok {
        return cached.(map[string]int)[name]
    }

    fields := make(map[string]int)
    for i := 0; i < t.NumField(); i++ {
        fields[t.Field(i).Name] = i
    }
    typeCache.Store(t, fields)
    return fields[name]
}
```

## 并发优化

### Goroutine 池

```go
type Pool struct {
    work  chan func()
    sem   chan struct{}
}

func NewPool(size int) *Pool {
    p := &Pool{
        work: make(chan func()),
        sem:  make(chan struct{}, size),
    }
    for i := 0; i < size; i++ {
        go p.worker()
    }
    return p
}

func (p *Pool) worker() {
    for f := range p.work {
        f()
    }
}

func (p *Pool) Submit(f func()) {
    p.work <- f
}

// 使用
pool := NewPool(100)
pool.Submit(func() { fmt.Println("task") })
```

### 高效 Channel 使用

```go
// 避免泄露
ch := make(chan int, 10)
defer close(ch)

// 使用 select 超时
select {
case v := <-ch:
    fmt.Println(v)
case <-time.After(5 * time.Second):
    fmt.Println("timeout")
}

// 关闭信号
done := make(chan struct{})
go func() {
    for {
        select {
        case <-done:
            return
        default:
            // 工作
        }
    }
}()
close(done)
```

## I/O 优化

### bufio 缓冲

```go
// 使用 bufio 减少系统调用
f, _ := os.Open("large.txt")
defer f.Close()

reader := bufio.NewReader(f)
for {
    line, _, err := reader.ReadLine()
    if err != nil {
        break
    }
    // 处理行
}

// 写入
file, _ := os.Create("output.txt")
defer file.Close()

writer := bufio.NewWriter(file)
for _, s := range lines {
    fmt.Fprintln(writer, s)
}
writer.Flush()
```

### 并发文件读取

```go
func readFiles(files []string) ([]string, error) {
    results := make([]string, len(files))
    var wg sync.WaitGroup
    var mu sync.Mutex

    for i, file := range files {
        wg.Add(1)
        go func(i int, file string) {
            defer wg.Done()
            data, err := os.ReadFile(file)
            if err == nil {
                mu.Lock()
                results[i] = string(data)
                mu.Unlock()
            }
        }(i, file)
    }
    wg.Wait()
    return results, nil
}
```

## 常见性能问题

| 问题 | 症状 | 解决方案 |
|------|------|----------|
| 内存泄漏 | 内存持续增长 | pprof heap, 检查全局变量、channel |
| GC 压力 | 延迟周期性增加 | 减少分配, sync.Pool, GOGC |
| 竞态条件 | 数据不一致 | -race, mutex/atomic |
| 锁竞争 | 并发性能差 | 减小锁粒度, lock-free 结构 |
| 过多 Goroutine | 内存占用高 | worker pool, semaphore |
| 频繁字符串拼接 | CPU 高, 内存碎片 | strings.Builder |
| 反射滥用 | 性能差 | 泛型, 接口, 代码生成 |
