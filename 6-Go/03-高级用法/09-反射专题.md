# 反射专题

**反射是 Go 在运行时检查和操作对象的能力——通过 `reflect` 包，程序可以动态获取类型、调用方法、修改变量值。反射开销较大（比直接操作慢 10-100 倍），应避免在热路径使用。**

## reflect.Type 与 reflect.Value

**reflect.TypeOf 获取类型信息，reflect.ValueOf 获取值信息——两者分别对应编译时和运行时视角。**

### 参考样例

```go
t := reflect.TypeOf(42)
fmt.Println(t.Name())      // int
fmt.Println(t.Kind())     // int

v := reflect.ValueOf(42)
fmt.Println(v.Type())      // int
fmt.Println(v.Kind())     // int
```

### Kind vs Type

```
Type 是类型名（User、int、[]byte）
Kind 是类型的种类（struct、int、slice）

type User struct{ Name string }
t.Kind()  // struct
t.Name()  // User
```

## 结构体操作

### 读取字段标签

```go
type User struct {
    Name string `json:"name" validate:"required"`
    Age  int    `json:"age"`
}

t := reflect.TypeOf(User{})
field, _ := t.FieldByName("Name")
fmt.Println(field.Tag.Get("json"))      // name
fmt.Println(field.Tag.Get("validate")) // required
```

### 动态设置字段值

```go
u := User{Name: "Alice", Age: 30}
v := reflect.ValueOf(&u).Elem()

nameField := v.FieldByName("Name")
if nameField.CanSet() {
    nameField.SetString("Bob")
}
```

## 动态方法调用

### 调用函数

```go
add := reflect.ValueOf(add)
args := []reflect.Value{reflect.ValueOf(10), reflect.ValueOf(20)}
result := add.Call(args)
fmt.Println(result[0].Int())  // 30
```

### 调用方法

```go
u := User{Name: "Alice", Age: 30}
vp := reflect.ValueOf(&u)

greetMethod := vp.MethodByName("Greet")
result := greetMethod.Call(nil)
```

## 接口与类型断言

**反射可以检查类型是否实现了某个接口。**

```go
writerType := reflect.TypeOf((*io.Writer)(nil)).Elem()
fmt.Println(reflect.PtrTo(t).Implements(writerType))  // true
```

## 反射最佳实践

### 性能优化优先级

1. **泛型**（Go 1.18+）——编译时确定，无反射开销
2. **接口**——静态类型检查
3. **代码生成**（如 `stringer`）——零反射
4. **map 缓存反射结果**——减少重复反射

### 缓存反射结果

```go
var typeCache = sync.Map{}

func getFieldIndex(t reflect.Type, name string) int {
    if cached, ok := typeCache.Load(t); ok {
        return cached.(map[string]int)[name]
    }
    fields := make(map[string]int)
    for i := 0; i < t.NumField(); i++ {
        fields[t.Field(i).Name] = i
    }
    typeCache.Store(t, fields)
    return fields[name]
}
```

### 安全反射

```go
func safeSet(v reflect.Value, val interface{}) bool {
    if !v.CanSet() {
        return false
    }
    if !v.Type().AssignableTo(reflect.TypeOf(val)) {
        return false
    }
    v.Set(reflect.ValueOf(val))
    return true
}
```

## 常见错误

```
ValueOf 返回的是副本，无法修改
  v := reflect.ValueOf(x)
  v.SetInt(20)  // panic: unaddressable value

正确做法：使用指针
  v := reflect.ValueOf(&x).Elem()
  v.SetInt(20)  // x = 20
```

## 反射使用场景

| 场景 | 推荐方案 | 原因 |
|------|----------|------|
| JSON 编组 | encoding/json | 内部使用反射，已优化 |
| ORM 映射 | 代码生成 | 避免运行时反射开销 |
| 依赖注入 | 反射/代码生成 | 框架内部使用 |
| 测试框架 | 反射 | 动态调用是测试的核心 |
| RPC 框架 | 代码生成 | 性能和类型安全 |
