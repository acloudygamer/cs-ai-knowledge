# 内存管理

## 逃逸分析（escape analysis）

### 基本概念

```go
// 编译时分析变量是否会逃逸到堆上
// go build -gcflags="-m" 可查看逃逸分析结果
// go build -gcflags="-m -m" 更详细信息

func returnSlice() []int {
    s := []int{1, 2, 3}  // 可能在栈上（小且固定）
    return s
}

func returnSliceLarge() []int {
    s := make([]int, 1000000)  // 大切片会逃逸到堆
    return s
}

var global *int
func leakToHeap() {
    i := 42
    global = &i  // i 逃逸到堆（生命周期超出函数）
}
```

### 逃逸分析示例

```bash
$ go build -gcflags="-m" main.go
# command-line-arguments
./main.go:7:2: make([]int, 1000000) escapes to heap
./main.go:12:6: &i escapes to heap
./main.go:11:13: moved to heap: i
```

### 常见逃逸场景

```go
// 1. 指针逃逸
func foo() *int {
    i := 10
    return &i  // i 逃逸到堆
}

// 2. 接口逃逸
func interfaceEscape() {
    var i interface{} = 42
    fmt.Println(i)  // i 逃逸到堆（接口装箱）
}

// 3. 切片增长
func sliceGrowth() []int {
    s := make([]int, 0)
    for i := 0; i < 100; i++ {
        s = append(s, i)  // 如果切片增长，会逃逸
    }
    return s
}

// 4. 调用未知函数
func callUnknown(fn func() *int) {
    result := fn()  // result 可能逃逸
    _ = result
}
```

### 避免逃逸的技巧

```go
// 预分配容量避免多次分配
func avoidEscape() {
    s := make([]int, 0, 100)  // 预分配，避免 append 时逃逸
    for i := 0; i < 50; i++ {
        s = append(s, i)
    }
}

// 使用栈本地切片（传指针）
func processSlice(s *[]int) {
    *s = append(*s, 1)  // 切片本身不逃逸
}
```

## 垃圾回收（GC）

### GC 工作原理

Go 使用**三色标记并发 GC**，目标是暂停时间 < 100ms。

```
标记阶段:
1. 初始：所有对象白色
2. Root 扫描：堆外对象（全局变量、栈）标记为灰色
3. 标记：灰色对象引用的对象变为灰色，原对象变黑色
4. 最终：所有可达对象为黑色，不可达为白色
5. 清扫：删除白色对象
```

### GC 阶段

```
GC 周期：
┌─────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐
│  Sweep  │ → │  Mark   │ → │  Mark  │ → │  Sweep  │
│ (清扫)  │   │ (准备)  │   │ (并发)  │   │ (并发)  │
└─────────┘   └─────────┘   └─────────┘   └─────────┘
     ↑                                     │
     └─────────────────────────────────────┘
```

| 阶段 | 说明 | STW |
|------|------|-----|
| Mark Start | 停止 Goroutine，准备标记 | 是（~10-100us） |
| Mark | 并发标记可达对象 | 否 |
| Mark Termination | 完成标记，清理 | 是（~10-100us） |
| Sweep | 并发清扫未使用对象 | 否 |

### GC 调优参数

```go
import "runtime/debug"

// 设置 GC 目标百分比（默认 100）
// GOGC=100 表示：当内存增长到上次 GC 后的 2 倍时触发 GC
// GOGC=200 表示：当内存增长到 3 倍时触发
debug.SetGCPercent(100)

// 获取当前设置
percent := debug.SetGCPercent(-1)  // -1 表示查询当前值

// 强制执行 GC
runtime.GC()

// 手动触发并发 GC
debug.FreeOSMemory()  // 释放内存到操作系统
```

### 环境变量

| 变量 | 说明 | 默认值 |
|------|------|--------|
| GOGC | GC 目标百分比 | 100 |
| GOMEMLIMIT | 内存硬限制（字节） | 无 |
| GOMAXPROCS | GC 并行度 | CPU 核数 |
| GCHEAP | 启用 GC 调试 | 0 |

### GC 性能影响

```bash
# 高 GC 压力场景
GOGC=50   # 更频繁 GC，更少内存
GOGC=200  # 更少 GC，更多内存

# 延迟敏感场景
GOGC=100 + GOMAXPROCS=4

# 内存敏感场景
GOMEMLIMIT=8GB
```

## 内存分配

### 栈 vs 堆

| 特性 | 栈 | 堆 |
|------|-----|-----|
| 分配速度 | 极快（移动栈指针） | 较慢（需要分配算法） |
| 释放 | 自动（函数返回） | GC 管理 |
| 大小 | 较小（KB 级） | 较大（GB 级） |
| 内存布局 | 连续 | 可能碎片化 |

### 分配策略

```go
// 小对象（< 32KB）：先尝试栈，逃逸到堆
// 大对象（>= 32KB）：直接堆分配

// 栈分配（编译期确定）
func stackAlloc() {
    arr := [64]int{}  // 小数组，栈上分配
}

// 堆分配（运行时确定）
func heapAlloc() {
    slice := make([]int, 10000)  // 大切片，堆上分配
}
```

### 减少分配技巧

```go
// 1. 对象池 sync.Pool
var bufferPool = sync.Pool{
    New: func() any {
        return &bytes.Buffer{}
    },
}

func getBuffer() *bytes.Buffer {
    buf := bufferPool.Get().(*bytes.Buffer)
    buf.Reset()  // 重置，复用内存
    return buf
}

func putBuffer(buf *bytes.Buffer) {
    bufferPool.Put(buf)
}

// 2. 预分配容量
s := make([]int, 0, 100)  // 预分配，避免多次扩容

// 3. 字符串拼接优化
var builder strings.Builder
builder.Grow(1000)  // 预分配，避免多次分配
```

### 内存分配器原理

```
TCMalloc（Go 使用）:

┌─────────────────────────────────────┐
│          大小分类（size class）      │
├─────────────────────────────────────┤
│ < 32KB:     span（页面组）          │
│ >= 32KB:   直接从堆分配              │
└─────────────────────────────────────┘

每个 P（Processor）有本地分配缓存:
┌──────┬──────┬──────┐
│mcache│mcache│mcache│  ← 减少锁竞争
│(P0)  │(P1)  │(P)   │
└──────┴──────┴──────┘
         ↓
    ┌─────────┐
    │  mcentral│  ← 每 size class 一个
    └─────────┘
         ↓
    ┌─────────┐
    │   mheap │  ← 全局堆
    └─────────┘
```

## 内存分析（pprof）

### CPU Profiling

```bash
# 方式1: go test
go test -cpuprofile=cpu.out ./...
go tool pprof cpu.out

# 方式2: net/http/pprof
import _ "net/http/pprof"

func main() {
    go func() {
        log.Println(http.ListenAndServe("localhost:6060", nil))
    }()
}
```

```bash
# 查看 CPU profile
go tool pprof http://localhost:6060/debug/pprof/profile?seconds=10

# 在浏览器查看
(pprof) web  # 需要 Graphviz

# 查看 top 10
(pprof) top -10
```

### 内存 Profiling

```bash
# 堆内存
go tool pprof http://localhost:6060/debug/pprof/heap

# 查看 allocations（分配采样）
go tool pprof http://localhost:6060/debug/pprof/allocs

# 查看 goroutine
go tool pprof http://localhost:6060/debug/pprof/goroutine
```

### pprof 分析命令

```bash
# 常用命令
(pprof) top                    # 显示占用最多的函数
(pprof) top -cum               # 累计显示
(pprof) list funcName          # 查看函数源码及耗时
(pprof) web                    # 生成 SVG（需 Graphviz）
(pprof) go tool pprof -http=:8080 cpu.out  # Web 界面

# 导出数据
(pprof) raw                    # 原始数据
(pprof) callgrind.out          # 导出为 callgrind 格式
```

### 代码中使用 pprof

```go
import (
    "runtime/pprof"
    "os"
)

func writeProfile() {
    // CPU Profile
    f, _ := os.Create("cpu.prof")
    pprof.StartCPUProfile(f)
    defer pprof.StopCPUProfile()

    // ... 执行要分析的代码 ...

    // 内存 Profile
    f2, _ := os.Create("mem.prof")
    pprof.WriteHeapProfile(f2)
    f2.Close()
}
```

### 常见内存问题


## 内存监控

### runtime MemStats

```go
import "runtime"

func printMemStats() {
    var m runtime.MemStats
    runtime.ReadMemStats(&m)

    fmt.Printf("Alloc:      %v KB\n", m.Alloc/1024)
    fmt.Printf("TotalAlloc: %v KB\n", m.TotalAlloc/1024)
    fmt.Printf("Sys:        %v KB\n", m.Sys/1024)
    fmt.Printf("Lookups:    %v\n", m.Lookups)
    fmt.Printf("Mallocs:    %v\n", m.Mallocs)
    fmt.Printf("Frees:      %v\n", m.Frees)

    fmt.Printf("HeapAlloc:  %v KB\n", m.HeapAlloc/1024)
    fmt.Printf("HeapSys:    %v KB\n", m.HeapSys/1024)
    fmt.Printf("HeapIdle:   %v KB\n", m.HeapIdle/1024)
    fmt.Printf("HeapInuse:  %v KB\n", m.HeapInuse/1024)
    fmt.Printf("HeapReleased: %v KB\n", m.HeapReleased/1024)

    fmt.Printf("StackInuse: %v KB\n", m.StackInuse/1024)
    fmt.Printf("StackSys:   %v KB\n", m.StackSys/1024)
}
```

### 定期输出

```go
func monitorMemory(ctx context.Context, interval time.Duration) {
    ticker := time.NewTicker(interval)
    defer ticker.Stop()

    var m runtime.MemStats
    for {
        select {
        case <-ctx.Done():
            return
        case <-ticker.C:
            runtime.ReadMemStats(&m)
            fmt.Printf("[%s] Alloc=%vKB HeapInuse=%vKB NumGC=%d\n",
                time.Now().Format("15:04:05"),
                m.Alloc/1024,
                m.HeapInuse/1024,
                m.NumGC,
            )
        }
    }
}
```

