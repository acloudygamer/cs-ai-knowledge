# 插件系统

**Go 插件通过 `plugin` 包加载 `.so` 共享对象，实现运行时动态加载——但受限于 Linux/macOS 且需与主程序 Go 版本一致，实际生产使用较少。**

## 插件机制

**Go 插件编译为 `.so` 文件，通过 `plugin.Open()` 加载、`Lookup()` 查找符号、本质是 ELF（Linux）/ Mach-O（macOS）共享库。**

```
构建：  go build -buildmode=plugin -o plugin.so plugin.go
加载：  p := plugin.Open("plugin.so")
查找：  sym := p.Lookup("SymbolName")
使用：  fn := sym.(func(string) string)
```

### 插件接口

```go
// 主程序定义接口
type Plugin interface{ Name() string; Execute(ctx context.Context) error }

// 插件实现
var PluginImpl = &MyPlugin{}
func Register() (Plugin, error) { return PluginImpl, nil }
```

### 插件管理器

```go
type Manager struct{ plugins map[string]Plugin }
func (m *Manager) Load(path string) error {
    p, _ := plugin.Open(path)
    sym, _ := p.Lookup("Register")
    fn := sym.(func() (Plugin, error))
    plug, _ := fn()
    m.plugins[plug.Name()] = plug
    return nil
}
```

## 热加载

**热加载通过定时检测文件修改时间（mtime）实现插件更新——需先 Unload 再 Load。**

```
文件 mtime 变化 → Unload(name) → Load(new_path)
```

## 隔离与安全

```
资源限制：  syscall.Setrlimit(RLIMIT_AS, 100MB)
错误隔离：  defer recover() 防止插件 panic 影响主程序
签名验证：  加载前校验插件签名
```

## 限制

| 限制 | 说明 |
|------|------|
| 仅 Linux/macOS | Windows 不支持 |
| Go 版本必须一致 | 主程序和插件 |
| 编译标签必须一致 | 构建时指定 |
| 无真正卸载 | 只能替换，无法卸载 |

## 常见替代

| 场景 | 替代方案 |
|------|----------|
| 配置热更新 | JSON/YAML 重载 |
| 算法可插拔 | 接口 + 工厂注册 |
| 业务扩展 | 微服务 RPC |
