# Go

**运行时编译进产物的静态类型语言**——没有虚拟机进程，goroutine 调度器、垃圾回收器、内存分配器都在 `runtime` 包里，跟着你的二进制一起发布。`go build` 的产物是一个静态链接的可执行文件，这是"部署零依赖"这个卖点的物理来源。

版本口径：**stable = latest = Go 1.27**（见 [versions.json](../versions.json)）。

- **无 LTS，只维护最近两个次版本**。Go 每 6 个月发一个次版本（2 月、8 月），官方支持窗口是"当前版本加前一个"（原文：supported until there are two newer major releases）。本次写作时 go.dev/dl 上只有 go1.27.1 与 go1.26.8——**Go 1.25 的支持随 1.27 的发布终止**，故本库对 Go 只设单档口径，不设 stable/latest 双档。
- **Go 1 兼容性承诺**：Go 1.0 之后没有破坏性语言变更。这是本节 [10-版本演进](./10-版本演进/) 能按"增量"写法组织的前提，也是 `go.mod` 里 `go 1.x` 指令只升不降的原因。
- **实测环境**：go1.27.1 windows/amd64。文中所有 `$ go run` 代码块的回显均在此环境实测。

### 骨架的五条依据

**一、运行时是库，不是进程。** 这是 Go 与本库其它语言最大的结构差异，也是 [03-运行时与内存](./03-运行时与内存/) 独立成目录且排在语言核心之后的原因。

| | 语言规范 | 运行时 | 类库 |
|---|---|---|---|
| Python | 语法 | CPython（外部进程） | 标准库 |
| Java | JLS | JVM（外部进程） | Java SE |
| JavaScript | ECMA-262 | V8 / 浏览器 / Node（外部宿主） | Web API 与 Node 标准库（两套） |
| **Go** | **Go Spec** | **`runtime` 包（链接进产物）** | **标准库（一套）** |

后果是具体的：`GOMAXPROCS` 是进程内变量而非启动参数，GC 调优靠 `GOGC` 环境变量而非 JVM 启动标志，goroutine 栈由 `runtime` 按需伸缩而非操作系统分配。Java 的 [03-JVM与运行时](../4-Java/03-JVM与运行时/) 讲"程序跑在谁上面"，这里讲"程序里那一半你自己没写的东西"。

**二、并发是语言原语，不是库。** `go`、`chan`、`select` 是关键字，channel 有类型、能进函数签名。因此 [04-并发](./04-并发/) 与 [01-语言核心](./01-语言核心/) 并列，而不像 Java 的 [04-并发编程](../4-Java/04-并发编程/) 那样是"一个库的用法"。同时它与 [03-运行时与内存](./03-运行时与内存/) 分工明确：03 讲调度器**怎么实现**，04 讲并发**怎么写**。

**三、工具链是一个二进制。** `go build`、`go test`、`go fmt`、`go vet`、`go mod`、`go doc` 全是同一个可执行文件的子命令。对照 Java 的 [06-构建与工程](../4-Java/06-构建与工程/)（Maven/Gradle 两个独立外部工具）与 JavaScript 的 [09-工程化](../5-JavaScript/09-工程化/)（npm + 打包器 + 转译器 + 检查器四层），[06-工程与工具链](./06-工程与工具链/) 需要单独讲的东西只剩两样：`go.mod` 的依赖语义，和产物如何构建发布。

**四、标准库是生产级的，生态是加法。** `net/http`、`database/sql`、`encoding/json`、`log/slog` 直接能写生产服务。因此 [08-生态与框架](./08-生态与框架/) 的定位与 Java 的 [08-生态与框架](../4-Java/08-生态与框架/) 相反：那边没有 Spring 写不了企业服务，这边框架解决的是"少写样板"。

**五、错误是值，不是控制流。** 没有异常，`error` 是一个接口，`panic/recover` 是另一套机制。这条影响每一层 API 的形状——从 `os.Open` 到 `http.Handler` 都返回 `error`——因此 [错误处理](./01-语言核心/10-错误处理.md) 在语言核心内与接口、泛型并列，而不是像 Java 那样放在语言核心末尾的异常一节。
