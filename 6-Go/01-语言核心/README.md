# 01-语言核心

Go 规范本体：类型与变量、内置容器、控制流、函数与方法、结构体与接口、泛型、错误、包与可见性。前置：[00-概览](../00-概览/)——本篇的语言设计取舍都回应它在 00 建立的约束。

Go 没有类、没有继承、没有异常。接口是隐式实现的，错误是值，并发原语是关键字。这四条决定了本篇的每一节。
