# 控制流程

> 前置：[03-切片与映射](./03-切片与映射.md) · 后续：[05-函数](./05-函数.md)

> **版本基准**：Go 1.27（stable = latest）。本篇示例实测环境：go1.27.1 windows/amd64。

## 本质

Go 的控制流关键字只有 **四个**：`if`、`for`、`switch`、`goto`（`select` 是并发专用，见 [04-并发/02](../04-并发/02-channel与select.md)）。

**约束的由来**：Go 砍掉了 C 的 `while`、`do-while`、三元运算符 `?:`，也砍掉了 `switch` 的隐式贯穿（fallthrough）。判据是**"同一个语义只保留一种写法"**：

| C 里有的 | Go 里的替代 | 为什么砍 |
|---|---|---|
| `while (c)` | `for c { }` | 与 `for` 同义，两套语法学一遍用一遍 |
| `do { } while (c)` | `for { ...; if !c { break } }` | 使用频率极低 |
| `a ? b : c` | `if` 语句 | 嵌套后难读；Go 要求显式 |
| `switch` 隐式贯穿 | 显式 `fallthrough` | 漏写 `break` 是 C 的经典 bug |
| `for (;;)` | `for { }` | 同上 |

**代价**：`x := a ? b : c` 这种紧凑写法在 Go 里要写四行。收益是**读代码时控制流的形状唯一**——看到 `for` 就知道是循环，不需要先判断它是 `for` 还是 `while`。

## 机制

### `for` 的四种形态

```console
$ go run .
三段式: 10
while 形态: 3
死循环 + break: 3
```

```go
for i := 0; i < 5; i++ { }   // 三段式：初始化; 条件; 后置
for n < 3 { n++ }             // 只有条件 —— C 的 while
for { c++; if c == 3 { break } }  // 无条件 —— 死循环
for i := range 3 { }          // range 形态（下节）
```

三种形态共用 `for` 一个关键字，**三段之间用分号分隔但不需要括号**——Go 的 `if`/`for`/`switch` 条件都不加括号，这是强制的：`for (i < 5)` 会编译报错。

### `range`：四种不同的迭代语义

`range` 是 Go 唯一的迭代语法糖，但它对**不同被迭代对象有完全不同的语义**：

| 被迭代对象 | 第一个值 | 第二个值 |
|---|---|---|
| `slice` / `array` | 索引 | 元素副本 |
| `string` | **字节偏移** | **rune** |
| `map` | 键 | 值 |
| `channel` | — | 接收到的值 |
| `int`（Go 1.22） | — | 0..n-1 |
| `func`（Go 1.23 迭代器） | — | 每次 `yield` 的值 |

```console
$ go run .
len()=8  RuneCountInString=4
按 byte 索引: 0:0x47 1:0x6f 2:0xe8 3:0xaf 4:0xad 5:0xe8 6:0xa8 7:0x80 
for range  : 0:G(0x47) 1:o(0x6f) 2:语(0x8bed) 5:言(0x8a00) 
s[2] = 0xe8（半个汉字）
string(s[2:5]) = "语"（完整汉字）
```

**字符串的 `range` 按 rune 迭代，索引是字节偏移**——这是最容易出错的一处。`"Go语言"` 的 `len()` 是 8 字节，`utf8.RuneCountInString` 是 4 个字符。`range` 给出的索引是 `0, 1, 2, 5`（不是 `0,1,2,3`），因为 `语` 占 3 字节、`言` 占 3 字节。

`s[2]` 拿到的是 `0xe8`——一个 UTF-8 三字节序列的首字节，单独看没有意义。**按字节索引遍历多字节字符串得到的是垃圾**，要取字符用 `range` 或 `[]rune(s)`（[02-标准库/01](../02-标准库/01-字符串与字节.md) 给了完整的字符串处理）。

```console
$ go run .
range over int: 0 1 2 
range over func: 3 2 1 
range over channel: 1 2 
```

**`range over int`**（Go 1.22）是 `for i := 0; i < n; i++` 的简写。**`range over func`**（Go 1.23）让自定义类型可迭代——被 range 的函数签名是 `func(yield func(T) bool)`，`yield` 返回 `false` 表示调用方要提前退出（`break`）。这是 Go 的迭代器协议，`slices`/`maps` 包的 `Keys`/`Values`/`All` 都返回这种函数。

**`range over channel`** 一直收到 channel 被 `close` 为止——这是 `for` + `<-ch` 的简写，但**必须有人关闭**，否则永久阻塞。

### `switch`：不贯穿，且可以没有表达式

```console
$ go run .
switch true: 小于 10
switch: 周末
switch: case 1（不会 fallthrough 到 2）
```

三处与 C 不同：

**一、默认不贯穿。** 每个 `case` 执行完自动结束，要贯穿必须显式写 `fallthrough`（且只能贯穿到下一个 case，不能带条件）。C 里"漏写 `break`"这类 bug 在 Go 里不存在。

**二、`case` 可以列多个值**：`case time.Saturday, time.Sunday:`。

**三、表达式可省略**，写成 `switch { case cond1: ... }`——等价于 `switch true`，也就是 C 的 `if/else if` 链。配合 `switch x := f(); { ... }` 还能带初始化语句。

**约束**：`switch` 的 case 是**按顺序求值**的，第一个匹配的胜出。因此条件之间有重叠时顺序有意义（上面 `x < 3` 写在 `x < 10` 前面）。

### `if` 带初始化语句

```console
$ go run .
if 初始化语句: v = 42 （v 的作用域仅限 if/else）
```

```go
if v := compute(); v > 10 { ... }
```

`v` 的作用域**仅限这个 `if` 及其 `else` 分支**，出了 `if` 就不可见。这个形态在 Go 里极其常见，因为错误处理需要它：

```go
if err := doSomething(); err != nil {
	return err        // err 不泄漏到函数其余部分
}
```

**约束**：`else` 必须与 `}` 同行（`} else {`），因为 Go 的分号插入规则会在 `}` 后自动加分号（[01-安装与第一个程序](./01-安装与第一个程序.md) 提到的自动分号插入）。换行写 `}\nelse {` 是语法错误。

### 标签：跳出多层

```console
$ go run .
带标签 break（只到 i=2）: (0,0) (0,1) (1,0) (1,1) (2,0) (2,1) 
带标签 continue: 0 2 
```

`break` 和 `continue` 默认只作用于**最内层**循环。要跳出外层，给外层循环贴标签：

```go
outer:
	for i := 0; i < 3; i++ {
		for j := 0; j < 3; j++ {
			if j == 2 { continue outer }   // 跳到外层下一轮
		}
	}
```

`continue outer` 的效果是"放弃内层循环剩余部分，从外层下一轮继续"——上面输出到 `(2,1)` 后内层 `j==2` 触发 `continue outer`，外层 `i` 变成 3 结束。

**约束**：标签必须紧贴被标记的语句（中间不能有空行），且**标签名与变量名共享命名空间**——`outer` 不能再当变量名用。标签用得越多，控制流越难跟，Go 社区倾向**把嵌套循环抽成函数 + `return`**。

### `goto`：存在但罕用

`goto` 只能跳到**同一个函数内**的标签，且**不能跳过变量声明**。标准库里有少量使用（跳出深层嵌套、错误清理），业务代码里几乎不用——`defer` 与函数抽取覆盖了它的所有正当用途。

**与其它语言对照**：

| | 循环关键字 | switch 贯穿 | 条件括号 |
|---|---|---|---|
| C/C++/Java | `for` / `while` / `do-while` | 默认贯穿 | 必需 |
| Python | `for` / `while` | 无 switch（用 `if/elif`） | 无 |
| **Go** | **只有 `for`** | **默认不贯穿** | **禁止** |

Go 与 Python 在"只有一种循环"这点上一致，但 Python 的 `for` 是"遍历可迭代对象"、`while` 是"条件循环"，Go 把两者合并进同一个关键字。**Python 的 `for` 只做 `range` 形态，Go 的 `for` 三种形态都做**——这是 Go 用语法糖换关键字数量的典型手法。
