# 07-测试与质量

测试约定、单元测试与 mock、集成测试、模糊测试与基准测试。前置：[01-语言核心](../01-语言核心/)、[06-工程与工具链](../06-工程与工具链/)（`go test` 属于同一个二进制）。

Go 把测试做成了语言的约定而不是框架：`_test.go` 文件、`func TestXxx(t *testing.T)` 签名、`go test` 子命令。不需要引入 JUnit 或 Jest 就能开始，因此本节的篇幅花在**测试怎么写才有信息量**上，而不是工具怎么装。
