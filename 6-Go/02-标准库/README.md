# 02-标准库

语言之外、进程之内：字符串与字节、io 与缓冲、时间、正则、序列化。前置：[01-语言核心](../01-语言核心/)——本节所有 API 的形状都由接口（`io.Reader`/`io.Writer`）、错误值、切片与映射这三样决定。
