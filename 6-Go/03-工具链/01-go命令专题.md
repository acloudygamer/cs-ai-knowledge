## go env

### 查看环境变量

```bash
# 查看所有环境变量
go env

# 查看特定变量
go env GOROOT
go env GOPATH
go env GOVERSION
go env GOMODCACHE
go env GO111MODULE
```

### 修改环境变量

```bash
# 临时设置（当前命令）
GOGC=200 go run main.go

# 永久设置
go env -w GOGC=200
go env -w GO111MODULE=on

# 查看可写变量
go env -w
```

### 常用环境变量

| 变量 | 说明 | 默认值 |
|------|------|--------|
| GOROOT | Go 安装目录 | 自动检测 |
| GOPATH | 工作目录 | $HOME/go |
| GOMODCACHE | 模块缓存 | $GOPATH/pkg/mod |
| GO111MODULE | 模块模式 | auto |
| GOPROXY | 代理地址 | https://proxy.golang.org,direct |
| GONOPROXY | 不走代理的模块 | - |
| GOSUMDB | 校验数据库 | sum.golang.org |
| CGO_ENABLED | 是否启用 CGO | 1 |

## go build

### 编译命令

```bash
# 编译当前目录
go build .

# 编译为指定输出
go build -o myapp .

# 编译指定文件
go build -o myapp main.go

# 交叉编译
GOOS=linux GOARCH=amd64 go build -o app .
GOOS=windows GOARCH=amd64 go build -o app.exe .
GOOS=darwin GOARCH=arm64 go build -o app .

# 去除调试信息
go build -ldflags="-s -w" .

# 设置版本信息
go build -ldflags="-X main.Version=1.0.0" .
```

### 编译模式

```bash
# 可执行文件（默认）
go build -buildmode=exe .

# 静态编译（禁用 CGO）
CGO_ENABLED=0 go build -ldflags="-linkmode=external" .

# 共享库
go build -buildmode=c-shared .

# 插件
go build -buildmode=plugin .
```

### 常用标志

| 标志 | 说明 |
|------|------|
| -o | 输出文件名 |
| -gcflags | 传递给编译器的标志 |
| -ldflags | 传递给链接器的标志 |
| -tags | 构建标签 |
| -mod | 模块模式（readonly/vendor/mod） |

## go test

### 基本用法

```bash
# 运行所有测试
go test ./...

# 详细输出
go test -v ./...

# 显示覆盖率
go test -cover ./...

# 生成覆盖率报告
go test -coverprofile=coverage.out ./...
go tool cover -html=coverage.out

# 基准测试
go test -bench=. -benchmem ./...

# 竞态检测
go test -race ./...
```

### 测试过滤

```bash
# 运行匹配的测试
go test -run TestName ./...
go test -run '^TestFoo$' ./...

# 跳过某些测试
go test -run 'Test[^Slow]' ./...
go test -short ./...  # 跳过耗时测试

# 基准测试过滤
go test -bench 'Benchmark.*' ./...
```

### Profiling

```bash
# CPU Profile
go test -cpuprofile=cpu.out ./...
go tool pprof cpu.out

# 内存 Profile
go test -memprofile=mem.out -memprofilerate=1 ./...

# 阻塞 Profile
go test -blockprofile=block.out ./...

# Trace
go test -trace=trace.out ./...
go tool trace trace.out
```

### 测试覆盖

```bash
# 查看覆盖率
go test -cover ./...

# 查看详细覆盖率
go test -coverprofile=cover.out ./...
go tool cover -func=cover.out

# 按包查看
go tool cover -html=cover.out
```

## go vet

### 静态分析

```bash
# 检查所有包
go vet ./...

# 详细输出
go vet -v ./...

# 使用指定检查器
go vet -atomic ./...
go vet -printf ./...
go vet -shadow ./...  # 需要 golang.org/x/tools/go/analysis/cmd/shadow

# 严格模式
go vet -strict ./...
```

### 常用检查

```go
// go vet 能发现的问题：

// 1. 错误未检查
f, _ := os.Open("file")  // vet 会警告

// 2. 格式化字符串错误
fmt.Printf("%s", 123)  // vet 会警告

// 3. 不可达的代码
return
fmt.Println("unreachable")  // vet 会警告

// 4. 错误的 mutex 使用
var mu sync.Mutex
mu.Lock()  // vet 会警告：unkeyed literals
```

### vet 与 CI

```bash
# 在 CI 中运行
go vet ./...
if [ $? -ne 0 ]; then
    echo "Vet failed"
    exit 1
fi

# 使用 golangci-lint（更全面）
golangci-lint run ./...
```

## go fmt

### 格式化代码

```bash
# 格式化当前目录
go fmt ./...

# 仅显示需要格式化的内容
go fmt -n ./...

# 使用 gofmt
gofmt -w ./...
gofmt -w -l ./...  # 仅列出需要格式化的文件
gofmt -w -r 'a[3:5] -> a[3:5:5]' ./...  # 修复切片表达式
```

### 格式化规则

```go
// gofmt 自动处理：

// 1. 缩进和空白
if true {
    x := 1  // 缩进统一为 Tab
}

// 2. 注释对齐
var x int // comment  // 保持对齐

// 3. 换行规则
fmt.Println(a, b, c, d, e, f, g)  // 超过行长自动换行

// 4. 切片表达式
a[0:5]  // 改为 a[0:5:5]（完整形式）
```

### 编辑器集成

```json
// VS Code settings.json
{
    "go.formatTool": "gofmt",
    "editor.formatOnSave": true
}
```

## go mod

### 模块管理

```bash
# 初始化
go mod init module_name

# 整理依赖
go mod tidy

# 下载依赖
go mod download

# 验证依赖
go mod verify

# 列出依赖
go list -m all
go mod graph  # 显示依赖图

# 替换依赖
go mod edit -replace=old=../local/path
go mod edit -dropreplace=old
```

### go.mod 文件

```go
module github.com/user/project

go 1.22.0

require (
    github.com/gin-gonic/gin v1.9.1
    github.com/go-sql-driver/mysql v1.7.1
)

require (
    golang.org/x/net v0.17.0 // indirect
)

replace (
    github.com/pkg/errors => github.com/独家/errors v0.9.0
)
```

### 私有模块

```bash
# 设置私有模块
export GOPRIVATE=github.com/company/*
export GONOSUMDB=github.com/company/*
export GOPROXY=https://proxy.golang.org,direct

# 或在 go.mod 中配置
go mod edit -go=1.22
go mod edit -C private=github.com/company
```

## go work

## 常用命令组合

### 开发流程

```bash
# 1. 创建项目
go mod init github.com/user/project

# 2. 编写代码...

# 3. 格式化
go fmt ./...

# 4. 检查
go vet ./...

# 5. 测试
go test -v -race ./...

# 6. 编译
go build -o app .
```

### CI/CD

```bash
# 多平台构建
for GOOS in linux darwin windows; do
    for GOARCH in amd64 arm64; do
        CGO_ENABLED=0 go build -ldflags="-s -w" -o app-$GOOS-$GOARCH .
    done
done

# 运行测试与覆盖率
go test -race -coverprofile=coverage.out ./...
go tool cover -html=coverage.out -o coverage.html
```

### 依赖更新

```bash
# 查看可更新版本
go list -m -u all

# 更新到最新
go get -u ./...

# 更新到指定版本
go get github.com/gin-gonic/gin@v1.10.0

# 清理未使用的依赖
go mod tidy
```
