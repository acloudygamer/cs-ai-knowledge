# 代码质量工具

## golangci-lint

Go 最流行的综合 lint 工具，整合了 70+ 种 linter。

### 安装

```bash
# macOS
brew install golangci-lint

# Linux/macOS
curl -sSfL https://raw.githubusercontent.com/golangci/golangci-lint/master/install.sh | sh -s -- -b $(go env GOPATH)/bin

# Windows
scoop install golangci-lint

# Go 安装
go install github.com/golangci/golangci-lint/cmd/golangci-lint@latest
```

### 基本用法

```bash
# 运行所有 linter
golangci-lint run ./...

# 指定目录
golangci-lint run ./internal/...

# 输出详细信息
golangci-lint run -v ./...

# 固定问题（用于 CI）
golangci-lint run ./... > issues.txt

# 自动修复
golangci-lint run ./... --fix
```

### 配置文件

```yaml
# .golangci.yml
linter-settings:
  govet:
    check-shadowing: true
  golint:
    min-confidence: 0
  gocyclo:
    min-complexity: 15
  maligned:
    suggest-new: true
  dupl:
    threshold: 100
  goconst:
    min-len: 2
    min-occurrences: 2
  misspell:
    locale: US
  lll:
    line-length: 120

linters:
  enable:
    - gofmt
    - golint
    - staticcheck
    - gosimple
    - govet
    - errcheck
    - ineffassign
    - typecheck
    - unused
    - goimports
    - misspell
    - revive
    - unconvert
    - unparam
    - prealloc

linters-settings:
  revive:
    rules:
      - name: var-naming
        severity: warning
      - name: error-return
        severity: error

run:
  timeout: 5m
  tests: true
  skip-dirs:
    - vendor
    - generated
  skip-files:
    - ".*_test.go"
```

### 集成到 CI

```yaml
# .github/workflows/lint.yml
name: Lint
on: [push, pull_request]
jobs:
  golangci:
    name: lint
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-go@v5
        with:
          go-version: '1.22'
      - name: golangci-lint
        uses: golangci/golangci-lint-action@v4
        with:
          version: latest
```

## staticcheck

静态分析工具，提供更深入的代码检查。

### 安装

```bash
go install honnef.co/go/tools/cmd/staticcheck@latest
```

### 常用检查

```bash
# 运行
staticcheck ./...

# 检查特定问题
staticcheck -f text ./...  # 文本输出
staticcheck -f json ./...  # JSON 输出

# 启用额外检查
staticcheck -enable-all ./...
```

### 常用规则

```go
// S1000: 简化 if-else
if bytes.HasPrefix(p, []byte("...")) {
    return true
}
return false
// 应改为 bytes.HasPrefix(p, []byte("..."))

// S1005: 不必要的赋值
for k, v := range m {
    m[k] = v  // 不必要
}

// S1012: time.Since() 优于 time.Now().Sub()
start := time.Now()
doSomething()
elapsed := time.Since(start)  // 优于 time.Now().Sub(start)

// S1025: fmt.Sprintf 无用
fmt.Sprintf("error: %s", err.Error())  // 改为 fmt.Errorf
```

## errcheck

检查未处理的错误。

### 安装

```bash
go install github.com/kisielk/errcheck@latest
```

### 使用

```bash
# 检查所有错误
errcheck ./...

# 检查特定包
errcheck github.com/user/project/...

# 检查特定模式
errcheck -abspath ./...

# 忽略特定函数
errcheck -ignore='os\.(Remove|Getenv)' ./...
```

## goimports

自动管理 import 语句。

### 安装

```bash
go install golang.org/x/tools/cmd/goimports@latest
```

### 使用

```bash
# 格式化并添加/删除 import
goimports -w .

# 仅检查
goimports -l .

# 替换 gofmt
gofmt -w . && goimports -w .
```

### 与 gofmt 的区别

```go
// gofmt 只格式化
// goimports 额外：
// 1. 添加缺失的 import
// 2. 删除未使用的 import
// 3. 按字母排序 import
```

## gorename

重命名标识符（变量、函数、类型等）。

```bash

```

### 使用

```bash

# 重命名变量（在包内）

# 交互模式
gorename -d
```

## revive

Go 官方推荐的 linter，golangci-lint 的内置 linter 之一。

### 安装

```bash
go install github.com/mgechev/revive@latest
```

### 配置

```toml
# revive.toml
[rule.enable-all-rules]

[rule.var-naming]
  severity = "warning"

[rule.error-return]
  severity = "error"

[rule.error-strings]
  severity = "error"

[rule.exported]
  severity = "warning"

[rule.receiver-naming]
  severity = "warning"

[rule.indent-error-flow]
  severity = "warning"
```

### 使用

```bash
revive ./...
revive -config revive.toml ./...
```

## 工具组合

### Makefile 示例

```makefile
.PHONY: lint test vet fmt

lint:
	golangci-lint run ./...

vet:
	go vet ./...

fmt:
	go fmt ./...
	goimports -w .

test:
	go test -race -coverprofile=coverage.out ./...
	go tool cover -html=coverage.out -o coverage.html

check: lint vet fmt test
```

### CI Pipeline

```yaml
name: CI
on: [push, pull_request]
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-go@v5
        with:
          go-version: '1.22'
      - run: go mod download
      - run: go vet ./...
      - run: golangci-lint run
      - run: go test -race -coverprofile=coverage.out ./...
      - uses: codecov/codecov-action@v4
        with:
          file: ./coverage.out
```

## IDE 集成

### VS Code

```json
{
    "go.lintTool": "golangci-lint",
    "go.lintOnSave": "package",
    "go.formatTool": "goimports",
    "go.diagnosticToolkit": "staticcheck"
}
```

### GoLand

1. **Settings → Go → Linters** → 启用 golangci-lint
2. **Settings → Go → Tools** → 配置 goimports

### 配置顺序

```
golint → staticcheck → govet → errcheck → goimports → gofmt
```

## 常见问题

### 1. golangci-lint 内存不足

```bash
golangci-lint run --no-config --disable-all \
  -E gofmt,Ebodyclose,errcheck,gosimple,govet,ineffassign \
  -S staticcheck ./...
```

### 2. 误报处理

```yaml
# .golangci.yml
issues:
  exclude-use-default: false
  max-issues-per-linter: 0
  max-same-issues: 0

  # 排除特定文件
  exclude-rules:
    - path: "_test.go"
      linters:
        - errcheck
    - path: "vendor/"
      linters:
        - govet
```

### 3. 性能优化

```bash
# 使用缓存
golangci-lint cache on
golangci-lint cache status

# 并行
golangci-lint run --jobs=4 ./...
```
