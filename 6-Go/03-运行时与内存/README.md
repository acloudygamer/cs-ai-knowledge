# 03-运行时与内存

调度器、分配器、垃圾回收、反射、unsafe、CGO、性能剖析。前置：[01-语言核心](../01-语言核心/)。

本目录的切分依据是 Go 区别于本库其它语言的一条结构事实：**运行时不是外部进程，是链接进每个二进制的库**。Java 的 [03-JVM与运行时](../../4-Java/03-JVM与运行时/) 讲"程序跑在谁上面"；这里讲"程序里那一半你自己没写的东西"——`GOMAXPROCS` 是进程内变量，GC 参数是环境变量，goroutine 栈归 `runtime` 管。
