# 日期时间

**定义**：`time.Time` 是 Go 的时间点类型，内部存储为 UTC 纳秒时间戳（自 0001-01-01 00:00:00 起），与时区无关；格式化/解析是输入输出转换，与内部存储分离。

## Layout 参考时间的机制

### 定义断言
Go 的时间格式化使用**参考时间**（Reference Time）：`Mon Jan 2 15:04:05 MST 2006`，而非像其他语言使用格式字符串（如 `%Y-%m-%d`）。这不是随意选择，而是因为这串字符的每一个组件（Mon、Jan、2、15、04、05、MST、2006）**恰好对应数字 1-7 在该位置唯一可识别**。

### 机制解释
格式化是"用参考时间的形状填充你的格式字符串"：`now.Format("2006-01-02")` 意思是"用参考时间的 2006 填充第一部分、01 填充第二部分、02 填充第三部分"。这是 Go 设计者 Rob Pike 的"偷懒式"设计——复用已存在的字符串解析逻辑，无需新语法。

### 参考存 stub

```go
now.Format("2006-01-02 15:04:05")
time.Parse("2006-01-02", "2024-01-15")
```

## 时区处理

### 定义断言
Go 的时区处理基于 IANA 时区数据库（tzdata），`time.LoadLocation` 从系统或 `$GOROOT/lib/time` 加载。容器环境中务必确保 tzdata 已安装，否则 `LoadLocation` 返回 UTC。

### 数据流（时间存储与展示）

<pre>
存储：time.Now().Unix() ──→ int64 UTC 时间戳（时区无关）
展示：t.In(time.Local) ──→ 转换为本地时区时间点
      t.In(time.FixedZone("CST", 8*60*60)) ──→ 固定偏移量
</pre>

### 存储格式选择

| 存储格式 | 适用场景 | 优势 |
|---------|---------|------|
| UTC 时间戳（int64） | 内部存储、跨时区交换 | 精确、无时区歧义 |
| RFC3339 字符串 | API 响应、日志 | 人类可读、含时区 |
| 本地时间字符串 | 仅展示用 | 无需时区转换 |

### 参考存 stub

```go
// 推荐：存储 UTC，展示时转换
ts := time.Now().UTC().Unix()
t := time.Unix(ts, 0).In(time.Local)
```

## 常见陷阱

### 闰秒（Leap Second）
`time` 包正确处理闰秒（通过定时器补偿），但 Go 不自动处理闰秒切换对 `time.Now()` 的影响——这是内核职责。

### 夏令时（Daylight Saving）
跨夏令时边界的时间计算（如 2024-03-10 02:30 + 24h）会产生非直观结果：`time.AddDate(0, 0, 1)` 在夏令时切换日可能得到 03:30。解决方案：使用绝对时间戳计算，再转换回本地时间。
