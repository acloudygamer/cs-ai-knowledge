# 日期时间

Go 的 `time` 包提供了完整的时间处理功能，包括时间点、时间段、时区和格式化。

## 基础概念

- **Time** - 时间点，包含日期和时间
- **Duration** - 时间段，如 5 秒、2 小时
- **Location** - 时区信息
- **Month/Weekday** - 月份和星期枚举

```go
import "time"
```

---

## 获取当前时间

```go
now := time.Now()  // 当前本地时间
utc := time.Now().UTC()  // 当前 UTC 时间

fmt.Println(now)   // 2024-01-15 10:30:45.123456 +0800 CST
fmt.Println(utc)   // 2024-01-15 02:30:45.123456 UTC
```

### 时间戳

```go
now := time.Now()

timestamp := now.Unix()       // 秒时间戳
nano := now.UnixNano()        // 纳秒时间戳
milli := now.UnixMilli()      // 毫秒时间戳 (Go 1.20+)

// 时间戳转 Time
t := time.Unix(timestamp, 0)
t := time.UnixMilli(milli)
t := time.UnixNano(nano)
```

## Duration（时间段）

Duration 表示两个时间点之间的间隔。

```go
d := 5 * time.Second
d := 10 * time.Minute
d := 2 * time.Hour
d := 24 * time.Hour
d := 7 * 24 * time.Hour  // 一周

// 解析字符串
d, err := time.ParseDuration("5s")     // 5 秒
d, err := time.ParseDuration("2h30m")  // 2 小时 30 分钟
```

### Duration 方法

```go
d := 2*time.Hour + 30*time.Minute

fmt.Println(d.Hours())   // 2.5
fmt.Println(d.Minutes()) // 150
fmt.Println(d.Seconds()) // 9000
fmt.Println(d.String())  // 2h30m0s
```

### 时间计算

```go
now := time.Now()

// 加减
future := now.Add(1 * time.Hour)
past := now.Add(-30 * time.Minute)

// 时间差
d := future.Sub(now)  // 返回 Duration

// 提前/推迟
tomorrow := now.AddDate(0, 0, 1)  // 明天
nextMonth := now.AddDate(0, 1, 0)  // 下个月
nextYear := now.AddDate(1, 0, 0)   // 明年
```

## 时间格式化

Go 使用独特的参考时间格式：`Mon Jan 2 15:04:05 MST 2006`

### 常用格式

```go
now := time.Now()

fmt.Println(now.Format("2006-01-02"))           // 2024-01-15
fmt.Println(now.Format("15:04:05"))             // 10:30:45
fmt.Println(now.Format("2006-01-02 15:04:05"))  // 2024-01-15 10:30:45
fmt.Println(now.Format("2006/01/02"))           // 2024/01/15
fmt.Println(now.Format("15:04"))               // 10:30
```

### 格式参考

| 格式 | 含义 | 示例 |
|------|------|------|
| `2006` | 四位年份 | 2024 |
| `06` | 两位年份 | 24 |
| `01` | 月份 | 01-12 |
| `Jan` | 月份名称 | January |
| `02` | 日期 | 01-31 |
| `15` | 24 小时制 | 00-23 |
| `03` | 12 小时制 | 01-12 |
| `04` | 分钟 | 00-59 |
| `05` | 秒 | 00-59 |
| `MST` | 时区名 | CST |
| `Z07` | 时区偏移 | +0800 |

### 解析时间字符串

```go
// 解析
t, err := time.Parse("2006-01-02", "2024-01-15")
t, err := time.Parse("2006-01-02 15:04:05", "2024-01-15 10:30:45")

// 解析并指定时区
loc, _ := time.LoadLocation("America/New_York")
t, err := time.ParseInLocation("2006-01-02", "2024-01-15", loc)
```

## 时区处理

### LoadLocation

```go
// 加载时区
loc, err := time.LoadLocation("America/New_York")
loc, err := time.LoadLocation("Europe/London")
loc, err := time.LoadLocation("Asia/Shanghai")

// 使用本地时区
now := time.Now()
nowAsia := now.In(loc)
```

### 常用时区

```go
// UTC
time.UTC()

// 本地时区
time.Local  // 自动使用系统时区

// 固定偏移量
time.FixedZone("CST", 8*60*60)  // UTC+8
```

### 时间戳与时区

```go
// UTC 时间戳
timestamp := time.Now().Unix()

// 转换为指定时区
t := time.Unix(timestamp, 0).In(time.FixedZone("CST", 8*60*60))
fmt.Println(t.Format("2006-01-02 15:04:05"))
```

## 日期组件

```go
now := time.Now()

year := now.Year()       // 2024
month := now.Month()     // January
day := now.Day()         // 15
weekday := now.Weekday() // Monday

fmt.Printf("%d年%02d月%02d日 %s\n", year, month, day, weekday)
// 2024年01月15日 Monday

// 星期几（数值）
fmt.Println(now.Weekday().String())  // Monday
```

## 定时器

### time.Sleep

```go
// 阻塞指定时间
time.Sleep(5 * time.Second)
time.Sleep(100 * time.Millisecond)
```

### time.Timer

```go
timer := time.NewTimer(2 * time.Second)

<-timer.C  // 等待 timer 触发
fmt.Println("Timer fired!")

// 重置 timer
timer.Reset(5 * time.Second)
```

### time.Ticker（周期执行）

```go
ticker := time.NewTicker(1 * time.Second)
defer ticker.Stop()

for i := 0; i < 5; i++ {
    <-ticker.C
    fmt.Println("Tick:", i+1)
}
```

### for + Ticker

```go
ticker := time.NewTicker(500 * time.Millisecond)
done := make(chan bool)

go func() {
    for {
        select {
        case <-done:
            return
        case t := <-ticker.C:
            fmt.Println("Tick at", t)
        }
    }
}()

time.Sleep(2 * time.Second)
ticker.Stop()
done <- true
```

## 性能相关

### 避免在循环中格式化

```go
// 不好：每次迭代都分配新的 layout 字符串
for _, t := range times {
    s := t.Format("2006-01-02 15:04:05")
    // ...
}

// 好：复用 layout 变量
const layout = "2006-01-02 15:04:05"
for _, t := range times {
    s := t.Format(layout)
    // ...
}
```

### 解析优化

```go
// 预编译解析格式
const dateLayout = "2006-01-02"

func parseDate(s string) (time.Time, error) {
    return time.ParseInLocation(dateLayout, s, time.Local)
}
```

## 实际示例

### 计时器（函数执行时间）

```go
func measureTime() {
    start := time.Now()
    defer fmt.Printf("耗时: %v\n", time.Since(start))

    // 模拟耗时操作
    time.Sleep(100 * time.Millisecond)
}
```

### 限流器

```go
func rateLimiter(requests int, duration time.Duration) {
    ticker := time.NewTicker(duration)
    defer ticker.Stop()

    for i := 0; i < requests; i++ {
        <-ticker.C
        fmt.Printf("处理请求 %d\n", i+1)
    }
}

rateLimiter(5, 200*time.Millisecond)
```

### 优雅关闭（超时控制）

```go
func withTimeout(f func(), timeout time.Duration) error {
    done := make(chan struct{})
    errCh := make(chan error, 1)

    go func() {
        f()
        close(done)
    }()

    select {
    case <-done:
        return nil
    case <-time.After(timeout):
        return fmt.Errorf("timeout after %v", timeout)
    }
}
```

### 日期边界计算

```go
func startOfDay(t time.Time) time.Time {
    return time.Date(t.Year(), t.Month(), t.Day(), 0, 0, 0, 0, t.Location())
}

func endOfDay(t time.Time) time.Time {
    return time.Date(t.Year(), t.Month(), t.Day(), 23, 59, 59, 999999999, t.Location())
}

func startOfMonth(t time.Time) time.Time {
    return time.Date(t.Year(), t.Month(), 1, 0, 0, 0, 0, t.Location())
}

func daysInMonth(t time.Time) int {
    return time.Date(t.Year(), t.Month()+1, 0, 0, 0, 0, 0, t.Location()).Day()
}
```

### 相对时间（人类可读格式）

```go
func relativeTime(t time.Time) string {
    now := time.Now()
    diff := now.Sub(t)

    switch {
    case diff < time.Minute:
        return "刚刚"
    case diff < time.Hour:
        return fmt.Sprintf("%d 分钟前", int(diff.Minutes()))
    case diff < 24*time.Hour:
        return fmt.Sprintf("%d 小时前", int(diff.Hours()))
    case diff < 7*24*time.Hour:
        return fmt.Sprintf("%d 天前", int(diff.Hours()/24))
    default:
        return t.Format("2006-01-02")
    }
}
```

## 时间比较

```go
t1 := time.Now()
t2 := t1.Add(1 * time.Hour)

// 比较
t1.Before(t2)   // true
t2.After(t1)    // true

// IsZero 检查
var zeroTime time.Time
fmt.Println(zeroTime.IsZero())  // true
```

## 与数据库时间交互

### 存储为时间戳

```go
now := time.Now()

// 写入数据库
timestamp := now.Unix()
db.Exec("INSERT INTO events (created_at) VALUES (?)", timestamp)

// 从数据库读取
var ts int64
db.QueryRow("SELECT created_at FROM events WHERE id = ?", id).Scan(&ts)
t := time.Unix(ts, 0)
```

### 存储为 ISO 格式

```go
now := time.Now()

// 写入
isoStr := now.Format(time.RFC3339)
db.Exec("INSERT INTO events (created_at) VALUES (?)", isoStr)

// 读取
var isoStr string
db.QueryRow("SELECT created_at FROM events WHERE id = ?", id).Scan(&isoStr)
t, _ := time.Parse(time.RFC3339, isoStr)
```

## 常见错误

### 时区不一致

```go
// 错误：本地时区和服务器时区可能不同
t, _ := time.Parse("2006-01-02", "2024-01-15")

// 正确：明确指定时区
t, _ := time.ParseInLocation("2006-01-02", "2024-01-15", time.Local)

// 最佳：存储 UTC，转换到本地显示
t := time.Now().UTC()
t.Local()  // 显示时转换
```

### 时间戳溢出

```go
// 32 位系统 int 最大值为 2147483647（2038 年问题）
// Go 的 int 在 64 位系统是 64 位，无此问题

// 明确使用 int64
timestamp := time.Now().Unix()  // 返回 int64
```

### 闰秒和夏令时

Go 的 `time` 包正确处理闰秒，但不自动处理夏令时切换（需要正确加载时区数据）。
