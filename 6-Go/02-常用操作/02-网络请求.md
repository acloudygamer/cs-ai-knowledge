# 网络请求

**定义**：网络请求是客户端通过协议（HTTP/1.1、HTTP/2、gRPC）向服务端发起的数据交换，Go 标准库 `net/http` 提供基础实现，第三方库在其上提供更高层抽象。

## net/http（标准库）

### 定义断言
`http.Client` 是 HTTP 请求的原子执行单元，内部维护连接池（默认 100 个目标主机，每个主机 2 个空闲连接），连接复用通过 Transport 层的空闲连接队列实现，无需手动管理生命周期。

### 数据流（HTTP/1.1 keep-alive 连接复用）

<pre>
请求1 ──┐
请求2 ──┼──→ TCP连接(keep-alive) ──→ Server
请求3 ──┘     ↑ 连接池复用
         新请求时从池取空闲连接
         无需三次握手
</pre>

### 机制解释
`http.Get` 内部创建默认 Client（`http.DefaultClient`），其 Transport 包含 `MaxIdleConnsPerHost: 2`。当响应体读取完毕后（`io.Copy` 或 `resp.Body.Close()`），连接进入空闲队列可供复用。若空闲队列满，连接被关闭。若请求需要代理、TLS、或自定义 Transport，需创建自定义 Client。

### 版本基准
Go 1.24+ 默认启用 HTTP/2（当服务器支持时），无需额外配置。`http.Transport` 的 `ForceAttemptHTTP2` 在 Go 1.26 中默认为 true。

### 参考存 stub

```go
resp, _ := http.Get("https://example.com")
io.Copy(os.Stdout, resp.Body)
```

## 第三方库：fasthttp vs Gin

### 定义断言
`fasthttp` 是基于用户空间网络（无 epoll/kqueue 依赖）的单连接多请求复用库，适合高并发短连接场景；Gin 是基于 `net/http` 的 HTTP 框架，提供路由、中间件、请求绑定等 Web 开发基础设施。

### 机制对比

| 维度 | net/http | fasthttp | Gin |
|------|----------|----------|-----|
| 连接模型 | 内核 TCP | 用户态 reuseport | 基于 net/http |
| 内存分配 | 每次请求 new | 对象池复用 | 基于 net/http |
| HTTP/2 | 原生支持 | 不支持 | 通过 net/http 支持 |
| 中间件 | 无 | 无 | 原生支持 |
| 路由 | 线性扫描 | 基数树 | 基数树 |

### fasthttp 参考存 stub

```go
fasthttp.ListenAndServe(":8080",
    func(ctx *fasthttp.RequestCtx) { ctx.WriteString("ok") })
```

### Gin 参考存 stub

```go
r := gin.Default()
r.GET("/ping", func(c *gin.Context) { c.JSON(200, gin.H{"msg": "pong"}) })
r.Run(":8080")
```

## 连接池调优

### 定义断言
HTTP 连接池的核心参数是 `MaxIdleConnsPerHost`——它决定了单台目标服务器的复用连接数上限。设置过低导致频繁建联开销，设置过高则占用过多文件描述符。

### 数学模型
建连延迟公式：$T_{conn} = T_{DNS} + T_{TCP\_handshake} + T_{TLS\_handshake}$（典型值：10-100ms）。若并发 1000 QPS 且 `MaxIdleConnsPerHost=2`，则每秒新建 998 连接，额外开销 $998 \times T_{conn}$。

### 参考存 stub

```go
tr := &http.Transport{
    MaxIdleConnsPerHost: 100,
    IdleConnTimeout: 90 * time.Second,
}
client := &http.Client{Transport: tr}
```

## 请求体读取次数

### 定义断言
`resp.Body` 是一次性流，一旦读取完毕就必须重新发起请求才能再次获取。多次读取需使用 `io.TeeReader` 或自行 `ReadAll` 缓存。

### 参考存 stub

```go
data, _ := io.ReadAll(resp.Body)
// 之后 resp.Body 不可再读，data 可重复使用
```
