# 日志系统

Go 日志系统从简单的 log 包发展到结构化日志，Go 1.21 引入了内置的 slog。本专题深入讲解标准库日志和主流第三方库。

---

## log 标准库

```go
import "log"

// 基本用法
log.Print("message")           // 打印到 stderr
log.Printf("name: %s", name)   // 格式化打印
log.Println("message")         // 换行打印

// 严重错误
log.Fatal("message")  // 打印后 os.Exit(1)
log.Fatalf("error: %v", err)

// 严重错误 + stack trace
log.Panic("message")  // 打印后 panic
```

### 自定义 logger

```go
import (
    "log"
    "os"
)

logger := log.New(os.Stdout, "INFO: ", log.Ldate|log.Ltime|log.Lshortfile)
logger.Println("custom logger")
```

## log/slog 结构化日志（Go 1.21+）

slog 是 Go 内置的结构化日志库，支持 JSON 和文本格式。

### 基础用法

```go
import (
    "context"
    "errors"
    "log/slog"
    "os"
)

func basicSlog() {
    // JSON 格式（生产环境推荐）
    jsonHandler := slog.NewJSONHandler(os.Stdout, &slog.HandlerOptions{
        Level: slog.LevelInfo,
    })
    logger := slog.New(jsonHandler)
    slog.SetDefault(logger)

    // 属性日志
    logger.Info("server started", "port", 8080, "host", "localhost")

    // Debug 级别（默认不输出）
    logger.Debug("debug info", "key", "value")

    // 带错误的日志
    logger.Error("request failed", "err", errors.New("connection refused"))

    // 带级别的日志
    logger.Log(context.Background(), slog.LevelWarn, "low memory")
}
```

### TextHandler（开发环境友好）

```go
func textHandler() {
    handler := slog.NewTextHandler(os.Stdout, &slog.HandlerOptions{
        Level:     slog.LevelDebug,
        AddSource: true,  // 显示文件名和行号
    })
    logger := slog.New(handler)
    slog.SetDefault(logger)

    logger.Info("configuration loaded",
        "port", 8080,
        "debug", true,
        "timeout", time.Second * 30,
    )
}
```

输出示例：
```
time=2024-01-15T10:30:00Z level=INFO msg="configuration loaded" port=8080 debug=true timeout=30s
```

### 分层日志级别

```go
func levelExample() {
    handler := slog.NewJSONHandler(os.Stdout, &slog.HandlerOptions{
        Level: slog.LevelDebug,
    })
    logger := slog.New(handler)

    // 各级别日志
    logger.Debug("debug message", "count", 1)
    logger.Info("info message", "count", 2)
    logger.Warn("warn message", "count", 3)
    logger.Error("error message", "err", errors.New("sample error"))
}
```

### 日志分组（LogValue）

```go
func groupExample() {
    logger := slog.New(slog.NewJSONHandler(os.Stdout, nil))

    logger.Info("request completed",
        "method", "GET",
        "path", "/api/users",
        "duration_ms", 150,
        "request", slog.Group(
            "id", 12345,
            "ip", "192.168.1.1",
        ),
        "response", slog.Group(
            "status", 200,
            "size", 1024,
        ),
    )
}
```

### 自定义属性（LogValuer）

```go
type SensitiveValue struct{ value string }

func (s SensitiveValue) LogValue() slog.Value {
    return slog.StringValue("***")  // 日志中隐藏敏感值
}

func customValueExample() {
    logger := slog.New(slog.NewJSONHandler(os.Stdout, nil))

    apiKey := SensitiveValue{"secret-key-12345"}
    logger.Info("api call", "api_key", apiKey)
    // 输出: {"time":"...","msg":"api call","api_key":"***"}
}
```

### Context 集成

```go
import "context"

func contextExample(ctx context.Context) {
    logger := slog.FromContext(ctx)
    if logger == nil {
        logger = slog.Default()
    }

    // 从 context 获取的 logger 已包含 context 中的值
    logger.Info("processing request", "trace_id", ctx.Value("trace_id"))
}
```

## 第三方日志库对比

| 特性 | slog | zap | zerolog | logrus |
|------|------|-----|---------|--------|
| 性能 | 高 | 极高 | 极高 | 低 |
| 结构化 | 原生 | 原生 | 原生 | 字段 |
| 零分配 | 部分 | 是 | 是 | 否 |
| 第三方集成 | 好 | 优秀 | 优秀 | 优秀 |
| 生态 | 内置 | 大 | 中 | 大 |

### zap（高性能）

```go
import (
    "go.uber.org/zap"
)

func zapExample() {
    // 生产配置（JSON 格式，高性能）
    logger, _ := zap.NewProduction()
    defer logger.Sync()

    logger.Info("zap logger",
        zap.String("app", "myapp"),
        zap.Int("port", 8080),
        zap.Duration("timeout", time.Second),
    )

    // 开发配置（人类可读格式）
    devLogger, _ := zap.NewDevelopment()
    defer devLogger.Sync()

    devLogger.Sugar().Infow("sugar logger",
        "key1", "value1",
        "count", 42,
    )
}
```

### zerolog（零分配）

```go
import (
    "github.com/rs/zerolog"
)

func zerologExample() {
    logger := zerolog.New(os.Stdout).With().Timestamp().Logger()

    logger.Info().
        Str("name", "app").
        Int("port", 8080).
        Dur("timeout", time.Second).
        Msg("server started")

    // 便捷方法
    zerolog.SetGlobalLevel(zerolog.InfoLevel)
    zerolog.Info().Str("name", "app").Msg("message")
}
```

### logrus（生态丰富）

```go
import (
    "github.com/sirupsen/logrus"
)

func logrusExample() {
    logger := logrus.New()

    // 格式设置
    logger.SetFormatter(&logrus.JSONFormatter{
        TimestampFormat: "2006-01-02 15:04:05",
    })
    logger.SetOutput(os.Stdout)
    logger.SetLevel(logrus.InfoLevel)

    // 字段方式
    logger.WithFields(logrus.Fields{
        "app":  "myapp",
        "port": 8080,
    }).Info("server started")

    // 链式调用
    logger.WithError(errors.New("db error")).Fatal("connection failed")
}
```

## 日志库选型建议

### 生产环境

```go
// 推荐：slog（Go 1.21+）或 zap
import "log/slog"

func productionLogger() *slog.Logger {
    return slog.New(slog.NewJSONHandler(os.Stdout, &slog.HandlerOptions{
        Level:     slog.LevelInfo,
        AddSource: false,
    }))
}
```

### 开发环境

```go
// 推荐：slog text 格式或 zerolog
func developmentLogger() *slog.Logger {
    return slog.New(slog.NewTextHandler(os.Stdout, &slog.HandlerOptions{
        Level:     slog.LevelDebug,
        AddSource: true,
    }))
}
```

### 高性能场景

```go
// 推荐：zap 或 zerolog
import "go.uber.org/zap"

func highPerformanceLogger() *zap.Logger {
    config := zap.NewProductionConfig()
    config.EncoderConfig.TimeKey = "timestamp"
    config.EncoderConfig.EncodeTime = zap.ISO8601TimeEncoder

    logger, _ := config.Build()
    return logger
}
```

## 日志最佳实践

### 1. 使用接口便于替换

```go
type Logger interface {
    Debug(msg string, args ...any)
    Info(msg string, args ...any)
    Warn(msg string, args ...any)
    Error(msg string, args ...any)
}

type slogLogger struct {
    *slog.Logger
}

func (l *slogLogger) Debug(msg string, args ...any) {
    l.Logger.Debug(msg, args...)
}

func (l *slogLogger) Info(msg string, args ...any) {
    l.Logger.Info(msg, args...)
}
```

### 2. 避免敏感信息日志

```go
type Sensitive string

func (s Sensitive) LogValue() slog.Value {
    return slog.StringValue("***REDACTED***")
}

logger.Info("user data",
    "password", Sensitive(password),  // 不会打印真实密码
)
```

### 3. 结构化错误日志

```go
import "log/slog"

func logError(logger *slog.Logger, err error, ctx ...any) {
    logger.Error("operation failed",
        append(ctx, "err", err)...,
    )
}
```

### 4. context 传递日志器

```go
import "context"

type contextKey string

const loggerKey contextKey = "logger"

func withLogger(ctx context.Context, logger *slog.Logger) context.Context {
    return context.WithValue(ctx, loggerKey, logger)
}

func fromContext(ctx context.Context) *slog.Logger {
    if logger, ok := ctx.Value(loggerKey).(*slog.Logger); ok {
        return logger
    }
    return slog.Default()
}
```

### 5. 日志级别使用场景

| 级别 | 场景 |
|------|------|
| Debug | 开发调试，详细执行路径 |
| Info | 正常运行，关键操作 |
| Warn | 异常但可恢复，潜在问题 |
| Error | 错误，需要关注但不会崩溃 |
| Fatal | 严重错误，程序即将终止 |

## 迁移指南

### log 到 slog

```go
// Before: log
log.Printf("request: method=%s path=%s", method, path)
log.Printf("response: status=%d duration=%v", status, duration)

// After: slog
slog.Info("request completed",
    "method", method,
    "path", path,
    "status", status,
    "duration_ms", duration.Milliseconds(),
)
```

### 使用 slog.ReplaceGlobals

```go
import "log/slog"

func init() {
    slog.SetDefault(slog.New(slog.NewJSONHandler(os.Stdout, &slog.HandlerOptions{
        Level: slog.LevelInfo,
    })))
}
```
