# 文件操作

**定义**：文件操作是通过 OS 系统调用实现字节序列的持久化读写，Go 将其封装为 `os` 包与 `bufio` 缓冲层，前者处理原子系统调用，后者通过减少系统调用次数提升吞吐。

## os（基础操作）

### 定义断言
`os.ReadFile`/`os.WriteFile` 是 Go 1.16+ 推荐的原子文件操作，适用于 < 1GB 文件；超过此阈值或需要流式处理时应切换 `bufio`。

### 数据流（读取）

<pre>
应用程序 → os.ReadFile → 内核页缓存 → 磁盘
                 ↑
           整文件一次性读取
           适用于小文件（<100MB）
</pre>

### 机制解释
`ReadFile` 内部调用 `os.Open` + `io.ReadAll`，无中间缓冲层，每次调用产生 1 次 open + 1 次 read 系统调用。`WriteFile` 类似，原子性由内核保证（rename 系统调用实现写入原子性）。

### 参考存根

```go
data, _ := os.ReadFile("file.txt")
os.WriteFile("out.txt", data, 0644)
```

## bufio（缓冲 I/O）

### 定义断言
`bufio` 通过在用户空间维护读写缓冲区，将 N 次小粒度系统调用合并为 1 次大粒度系统调用，显著降低上下文切换开销。

### 数据流（读取）

<pre>
磁盘 ──read(4KB)──→ 内核页缓存 ──read(4KB)──→ bufio.Reader 缓冲区
                              ↑                        ↓
                         减少 syscall           应用多次 Scan()/Read()
                         次数（N→1）
</pre>

### 机制解释
`bufio.Reader` 初始化时分配默认 4KB 缓冲区。当应用调用 `Scan()` 时，若缓冲区已耗尽，才触发新的 `read(4KB)` 系统调用。关键指标：对于 100MB 文件，裸 `os.Open`+`Read` 产生 ~25600 次系统调用，`bufio.Reader` 将其降至 <100 次。

### 参考存 stub

```go
scanner := bufio.NewScanner(file)
for scanner.Scan() { _ = scanner.Text() }
```

## 写操作原子性

### 定义断言
`os.WriteFile` 的原子性由内核 rename 系统调用保证——先写临时文件，flush 后 rename 到目标路径，避免写入过半文件被读者看到。

### 参考存 stub

```go
tmp, _ := os.CreateTemp("", "write-*")
tmp.Write(data)
os.Rename(tmp.Name(), target)
```

## 场景选择决策树

```
文件大小 < 100MB 且一次性读写?
├─ 是 → os.ReadFile / os.WriteFile
└─ 否 → 需要流式处理?
       ├─ 是 → bufio.Reader / bufio.Writer
       └─ 否 → mmap 或分片处理
```
