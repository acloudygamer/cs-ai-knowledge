# 正则表达式

**定义**：正则表达式是通过 RE2 语法（Go 标准库 `regexp` 唯一支持）描述字符串匹配模式的有限状态自动机，其核心特性是**线性时间复杂度**——匹配过程无需回溯。

## RE2 核心约束

### 定义断言
RE2 是"确定型有限状态自动机"子集，不支持回溯（backtracking）和环视断言（lookahead/lookbehind）。这保证了 $O(n)$ 时间复杂度和 $O(1)$ 空间复杂度，其中 n 为输入字符串长度。

### 数学模型
正则匹配复杂度：$T(n) = O(n)$，空间 $S(n) = O(1)$（编译后的程序大小与输入无关）。相比 PCRE 等支持回溯的正则引擎（最坏情况 $O(2^n)$），RE2 保证无指数级最坏情况。

### 回溯陷阱示意

<pre>
模式 `(a+)+b` 在输入 "aaaa...a"（无尾随 b）：
├─ 传统正则：尝试所有 a 分组方式指数级爆炸
└─ RE2：线性扫描，无回溯，行为确定
</pre>

## 编译与复用

### 定义断言
`regexp.MustCompile` 在包初始化时执行一次，将正则字符串编译为内部状态机，之后每次 `MatchString` 调用无需重新编译。重复编译同一正则是大常见性能错误。

### 参考存 stub

```go
var emailRegex = regexp.MustCompile(`^[a-z]+@[a-z]+\.[a-z]+$`)
emailRegex.MatchString("a@b.c")
```

## 捕获组机制

### 定义断言
捕获组是圆括号 `(expr)` 创建的子匹配，其编号规则：整体匹配为 0，组 1-N 按左括号出现顺序编号。命名分组（`(?P<name>expr)`）是编号分组的别名，底层仍为编号。

### 参考存 stub

```go
re := regexp.MustCompile(`(?P<year>\d{4})-(?P<month>\d{2})`)
m := re.FindStringSubmatch("2024-01")
m[re.SubexpIndex("year")] // "2024"
```

## lookbehind 替代方案

### 定义断言
RE2 不支持 `(?<=prefix)` 环视。若需要"前缀匹配后取后缀"语义，使用 `strings.HasPrefix` + 字符串切片比正则更高效。

### 参考存 stub

```go
// 不支持：(?<=prefix)suffix
// 替代：
if strings.HasPrefix(s, "prefix") { s = s[6:]; /* 继续处理 */ }
```

## 性能最佳实践

1. **预编译**：`MustCompile` 包级变量，避免循环内编译
2. **具体化分支**：`a{2,5}` 优于 `a*`，避免可选分支爆炸
3. **锚定开头**：`^pattern` 让状态机从起始位置开始
4. **避免分组捕获**：非捕获 `(?:...)` 优于捕获 `(...)`
