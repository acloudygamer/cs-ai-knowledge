# 命令行工具

**定义**：命令行工具是程序通过 `flag`（标准库）解析用户输入的参数并执行业务逻辑的交互模式，核心问题是**参数验证**和**子命令树管理**（cobra）。

## flag 解析机制

### 定义断言
`flag.Parse()` 在调用时扫描 `os.Args[1:]`，将字符串形式的参数转换为对应类型的值并存入已注册变量。它必须在所有 flag 注册完成后调用，且只能调用一次。

### 数据流

<pre>
os.Args: ["./app", "-port", "8080", "-v", "arg1"]
              ↓
flag.Parser 扫描：遇到 -port 查找同名 Flag
              ↓
找到则尝试将 "8080" 转换为 int 并存储
              ↓
遇到非 - 开头的 "arg1" → 存入位置参数 []string
</pre>

### 自定义类型 flag
实现 `flag.Value` 接口（`Set(string) error` + `String() string`）可将任意类型接入 flag 系统。

### 参考存 stub

```go
var ip net.IP
flag.Var(&ipVal{&ip}, "server", "server IP")
flag.Parse()
```

## os/exec 安全

### 定义断言
`exec.Command` 的参数是**列表形式**（`exec.Command("ls", "-la")`），而非 shell 字符串（`exec.Command("ls -la")`）。后者会将整个字符串传给 shell，导致 shell 注入攻击。

### 参考存 stub

```go
// 安全：参数分开
exec.Command("ls", "-la", filename)

// 不安全：shell 注入风险
exec.Command("sh", "-c", "ls -la "+filename)
```

## cobra 命令树结构

### 定义断言
Cobra 命令树是**前缀树（Trie）**：每个 `Command` 可有 `Run` 或 `RunE` 回调和子命令 `AddCommand`。执行 `myapp serve api --port 8080` 时，前缀树从根向下匹配 `serve` → `api` → 到达目标命令。

### 数据流

<pre>
输入：myapp serve api --port 8080
匹配：root → serve（注册为子命令）→ api（注册为 serve 子命令）
执行：api.RunE(ctx, args=[--port, 8080])
</pre>

## flag vs cobra 选择

| 场景 | 推荐 |
|------|------|
| 单脚本工具、无子命令 | `flag` |
| 需要子命令树（git-like） | `cobra` |
| 复合场景 | `flag` 处理叶命令参数 + `cobra` 组织命令树 |
