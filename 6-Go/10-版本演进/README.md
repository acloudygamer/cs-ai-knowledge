# 10-版本演进

Go 1.0 → Go 1.27 的编年主线与提案流程，收官对照。前置：全部目录——本篇引用的每个特性都在前文有定义。

Go 的版本节奏与本库其它语言都不同：**每 6 个月一个次版本，没有 LTS，官方只维护最近两个**。这决定了版本口径只有一档（见总 [README](../README.md)），也决定了"向后兼容承诺"这条约束在本篇的分量——Go 1 兼容性承诺是这条节奏能持续十五年的前提。
