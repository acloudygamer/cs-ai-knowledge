# 06-工程与工具链

`go` 命令、模块与依赖、代码质量、项目布局、构建与发布。前置：[01-语言核心](../01-语言核心/)（包与可见性）。

本节比 Java 的 [06-构建与工程](../../4-Java/06-构建与工程/)（Maven/Gradle 是两个独立外部工具）、JavaScript 的 [09-工程化](../../5-JavaScript/09-工程化/)（npm + 打包器 + 转译器 + 检查器四层）都薄，依据是同一结构事实：**Go 的工具链是一个二进制**。`go build`、`go test`、`go fmt`、`go vet`、`go mod` 全是同一个可执行文件的不同子命令，没有外部构建系统需要学。剩下需要单独讲的只有两样：`go.mod` 的依赖语义，和产物如何构建与发布。
