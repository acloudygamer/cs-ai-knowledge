# CS/AI 知识库

多语言编程知识体系，覆盖计算机基础与 5 大编程语言。

## 概念文档宪法（记忆钩子）

每个 `.md` 文件必须遵循以下骨架编写：

| 章节 | 要求 |
|------|------|
| **定义** | 一句断言，直指本质 |
| **数学模型** | 若有计算/复杂度/概率，必须给出 LaTeX |
| **数据流** | ASCII 图或分步列表，标记数据形态变换 |
| **机制** | 为什么这样设计、约束条件、违规后果 |
| **参考存根** | 仅当需证明可实现性时出现，≤20 行，无错误处理 |

> **对比参照**：在"数据流"或"机制"章节中，通过链接引用相关概念文档：
> `[进程与线程](../02-系统软件层/03-进程与线程.md) | [并行与并发](../01-计算机体系/03-并行与并发.md)`
>
> 对比性概念（如进程/线程/协程）必须使用对比表格，对齐三列：
> **调度权 | 内存模型 | 数据交换代价**
