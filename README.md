# CS/AI 知识库

多语言编程知识体系，覆盖计算机基础与 5 大编程语言。

## 概念文档宪法（记忆钩子）

详见 [prompts/constitution.md](prompts/constitution.md)：

| 章节 | 要求 |
|------|------|
| **定义** | 一句断言，可延伸为段落式本质说明；避免空洞的"是一种...的技术" |
| **数学模型** | 必须存在；涉及计算/复杂度必须给 LaTeX，涉及概率给分布假设；归约终点：量化优先，量化困难时给出精确概念描述 |
| **数据流** | ASCII 图（用 `<pre>` 包裹）或分步列表，标记数据形态变换和所有权流转；与数学模型并列 |
| **对比参照** | 仅当存在易混淆概念时出现；三列对比表格：内存模型、调度权、数据交换代价 |
| **机制** | 为什么这样设计、约束条件、违反后果；不描述 API，不描述用法 |
| **参考存根** | 仅当需证明可实现性时出现；≤20 行，无错误处理、无日志、无注释 |
