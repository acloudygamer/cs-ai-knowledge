## 默认写法（先记这两条，可避开绝大多数死法）

- **行内**：两端各留一个半角空格、内侧紧贴定界符——`值为 $x+y$ 个`。中文/全角标点紧贴 `$` 必死。例外：`**$…$ …**` 加粗紧贴公式合法（strong 容器不杀公式，API 实测加粗与公式同时生效）；此时**禁止**在开 `**` 后补空格——空格会破坏 `**` 的 flanking 规则、杀死加粗（math_fix.py 已内置此例外）。
- **块级**：`$$` 独占段落——前后各留空行、块内无空行；或干脆整段一行 `$$…$$`。

这两条是默认前提，后面各站不再重复检查；其余条款是例外场景的手段，遇到才查。

## 管线地图

```
.md 源码
  → 第 1 站 块结构   决定公式候选能不能形成（$$ 块在此成形或夭折）
  → 第 2 站 行内解析 决定文本层损失（反斜杠被吃一层、标记配成元素）
  → 第 3 站 消毒     决定标签的三种命运（剥除/保留/补全）
  → 第 4 站 数学提取 生死判定（行内三道判据、块级段落纯净度）
  → 第 5 站 送达     块级公式的二次序列化（内容在此被改写）
  → 第 6 站 渲染     MathJax 排版（不判定，只排版）
```

公式死亡时先定位死在哪一站，再查该站条款。

## 第 1 站 · 块结构：候选能不能形成

解析器逐行扫描、只看行首，把文档切成块。**`$$` 数学块不存在**——它就是一个"整段内容恰为 `$$…$$`"的普通段落，能不能活全看段落纯不纯。

### 1.1 公式进不去的块

- **代码块**（≥4 空格缩进 / 围栏）：`$` 是普通字符，死——公式别写进代码块。
- **HTML 块**（行首 `<div>` 等块级标签开启）：**必死，无例外**——不跑行内解析，候选从未形成。手写块级标签排版时，公式一律放在标签之外。
- 表格、列表、引用：只写行内公式（见 1.3）。

### 1.2 `$$` 块 = 段落，保持纯净

- **独占段落**：`$$` 前空行、`$$` 后空行、块内无空行。前后缺空行 → 段落并入，多行块死、单行退化。
- **退化**：`$$` 与文字同行，或单行 `$$…$$` 落进脏上下文——照常提取，但包成 `js-inline-math` 且保留 `$$`。**别用"公式还在"判断成功，看 class。**
- **空行隔不断段落间的联系**：即使前后空行都留好，前文的状态仍会波及本段——未闭合的手写标签会跨段污染（第 3 站双补），同段内的配对可跨过 `$$` 定界符毁块。公式无故死亡时，先往前后段落找原因，别只盯着本段。

### 1.3 特殊容器：表格、列表、引用里只写行内公式

`$$` 块只放正文段落。表格、列表、引用里需要公式一律用行内 `$…$`——`$$` 在那些位置不会正常 display（单元格内退化、列表内静默失效、引用内有懒延续死法），不值得研究写法。

唯一要记住的容器条款：**表格单元格内的行内公式禁止裸 `|`**——行先把格切开，公式右半连同闭 `$` 被丢弃；一律写 `\|`（送达为裸 `|`）。

## 第 2 站 · 行内解析：转义被吃一层、标记配成元素

### 2.1 反斜杠消耗一层（内容损失在此定型，后面救不回来）

- TeX 需要的 `\`+ASCII 标点**一律双写**：`\%`→`\\%`、`\{`→`\\{`、`\_`→`\\_`、`\,`→`\\,`（`\;` `\!` `\:` `\.` 同命中）、`\&`→`\\&`、`\#`→`\\#`；或把字符移出公式（`$M_1 = 10$%`）。单写就被吃一层——`%` 变 TeX 注释符、`\text{}` 内裸 `_` 语法错、字面 `{` 变分组符。
- 行内公式内禁止 `\\`（行中塌成 `\`）；行尾孤 `\` 被硬换行吃掉。

### 2.2 emphasis 配对：元素在此生成

- 成对 `*`/`_`→`<em>`、`**`/`__`→`<strong>`、`~~`→`<del>`——生成的元素送第 4 站判生死。
- `_` 两侧是字母/数字时（`x_i`、`M_1`）永不配对，无需转义；`*` 无此豁免。
- `\\_` 修复的 `_` 仍是活配对候选：同段禁止其他边界位的 `_`（`_foo`、`foo_`、`$_{j}$`），否则配上对判死。
- 代码 span→`<code>`、链接→`<a>`、图片→`<img>`、手写标签透传——这些元素同样进第 4 站判定。

## 第 3 站 · HTML 生成与消毒：标签的三种命运

行内解析的产物序列化成 HTML 后过白名单消毒。手写标签有三种命运：

- **剥除**（`u`、`cite`、`abbr`、自定义标签）：标签消失、文本保留，视同没写——内部公式按裸段落判定。
- **保留**（`em`、`b`、`i`、`strong`、`span` 等常用标签）：原样进第 4 站，按容器死活表判定。
- **未闭合补全**：`<em>`/`<b>`/`<i>` 双补——段尾补闭合并重开同名元素，把后续所有块包到文末：`<em>`/`<b>` 之后公式全死，`<i>` 之后照活。**手写标签必须闭合**，这是跨段污染的来源。

另外：`&` `<` `>` 在 HTML 中以实体存在（`&amp;` `&lt;` `&gt;`），浏览器解码后读者看到的仍是原字符；行内公式被包装时多转一次（双层），后果见第 6 站。

## 第 4 站 · 数学提取：生死判定（闭源，全部按实测）

### 4.1 行内 `$…$` 三道判据（按序）

1. **容器跳过**：公式整体落进 `em`/`b`/`a`/`code` 子树 → 跳过（死）。
2. **连续文本节点**：任何**真实生成**的元素，边界落进 `$…$` 内部 → 死（成对标记、手写标签、链接、图片、`<br>` 同死；被剥除的标签不生成元素、无害）。
3. **杀手子串**：内容含 `select` 或 `begin` 子串 → 死（词内也算、大小写不敏感；`\begin{aligned}`、`\text{beginning}` 都中——进块级写）。

### 4.2 容器死活表（与样式语义无关，按元素名）

| 死（提取被跳过） | 活（安全容器） |
|---|---|
| `em`（`*`/`_` 斜体）、`b`（手写 `<b>`）、`a`（链接文字）、`code`（代码 span） | `strong`（`**` 加粗）、`del`（`~~`）、`i`（手写 `<i>`）、`span`、`sub`、`sup` 等 |

### 4.3 块级 `$$…$$` 判据

- 段落纯净且不含 `a`/`b`/`code`（含有则**整块提取失败**，`$$` 原样残留）→ `js-display-math`。
- 含 `<img>` → 图片整体丢弃、块照常 display（内容只剩空白）。
- 其余元素（em/strong/del 等）容忍，带进第 5 站序列化。

## 第 5 站 · 送达：块级公式的二次序列化

块级与行内的本质差异：行内遇元素切断即死，块级**带着元素序列化回文本**——公式活，但内容被改写：

- `<em>` → `_…_`：内容逐字保留；但成对 `*` 同化为 `_`——`a*b*c` → `a_b_c`，**乘号一律 `\cdot`**。
- `<strong>`/`<del>`/`<i>` 等 → 标记整对丢弃、文本保留：`a **b** c` → `a b c`；配对的 `__` 会把中间内容一并卷走——**块内禁止 `**` `__` `~~`**。
- 行尾 `\\` → `\\`（aligned 可靠）。
- **配对空行**：定界符独占行的块内 em 配上对 → 送达首尾多出空行——**对 MathJax 排版无影响**（2026-09-01 网页实测）；整段一行 `$$…$$` 配上对也字节级往返。要规避空行就把块写成单行。

## 第 6 站 · 前端渲染（MathJax）

- MathJax 读 `<math-renderer>` 的 textContent 排版，不做任何提取判定。
- 行内双层实体前端再解码一次：`<` `>` 渲染正常（2026-09-01 网页实测）；`&` 解码后是 TeX 对齐符、行内必炸——行内 `&` 写 `\\&`（送达 `\&`，渲染字面 &，2026-09-01 网页实测）或进块级。

## 排查路径（公式没显示时）

1. 找 `<math-renderer>`：**没有** → 死在第 1/2/4 站：先查是否偏离了默认写法（行内空格、块级独占段落），再查容器（斜体/链接/code/手写 `<b>`/`<em>`），再往回找未闭合手写标签，最后查块结构（HTML 块/列表）。
2. 有，但 class 是 `js-inline-math` 而你写的块级 → 退化（`$$` 与文字同行或落脏上下文）。
3. 有且 display，但显示异常 → 内容层：转义没双写、乘号写成 `*`、配对空行。

## 兜底（GitHub 专属写法，换渲染器即退化，可迁移性差）

- **行内**：`` $`x+y`$ ``——行内代码 span 外套两个 `$`：代码 span 内 Markdown 不做转义与配对，TeX 源原样穿过前两站；服务端认这个形态，提取后去掉反引号，送达为 `$x+y$`。
- **块级**：```` ```math ```` 围栏——按 display 提取（内容包成 `$$…$$`），**内容逐字原样送达**（2026-09-01 实测：`\%` `\_` `\{` `\,` 单写原样、`*` `_` 不配对、`>` `&` `<` 直通、aligned 行尾 `\\` 正常、杀手子串免疫）——转义密集的复杂公式在这里可以完全不用双写。
