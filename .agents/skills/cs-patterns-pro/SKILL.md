# CS Patterns Pro

## 计算机基础核心概念

### 1. 硬件与系统

**CPU**：
- 指令执行：取指 → 译码 → 执行 → 访存 → 写回
- 寄存器：PC（程序计数器）、IR（指令寄存器）、通用寄存器
- 流水线：超流水线、指令级并行

**内存**：
- 层次结构：寄存器 → L1/L2/L3 cache → 主存 → 磁盘
- 局部性原理：时间局部性、空间局部性
- 虚拟内存：页表、TLB、交换分区

**并发**：
- 进程 vs 线程：进程是资源分配单位，线程是调度单位
- 同步原语：互斥锁、信号量、条件变量
- 死锁条件：互斥、占有并等待、非抢占、循环等待

### 2. 操作系统

**内核**：
- 系统调用：用户态和内核态切换
- 进程调度：FCFS、SJF、RR、优先级

**文件系统**：
- inode 结构
- 目录项和硬链接/软链接

### 3. 网络

**OSI 七层**：
- 物理层 → 数据链路层 → 网络层 → 传输层 → 会话层 → 表示层 → 应用层

**TCP/UDP**：
- TCP：三次握手、四次挥手、流量控制、拥塞控制
- UDP：无连接、不可靠但高效

### 4. 编程原理

**编译/解释**：
- 编译型：源码 → 目标代码 → 链接 → 可执行文件
- 解释型：源码 → 解释器 → 逐行执行
- 混合：Java（字节码+JIT）

## 常见错误

1. 混淆进程和线程
2. 死锁四个条件记错
3. TCP/UDP 特点混淆
4. 缓存和主存速度数量级错误
