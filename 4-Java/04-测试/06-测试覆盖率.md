# 测试覆盖率

## JaCoCo 概述

JaCoCo (Java Code Coverage) 是 Java 标准的覆盖率工具，支持行覆盖、分支覆盖、方法覆盖等多种度量维度。

### Maven 配置

```xml
<plugin>
    <groupId>org.jacoco</groupId>
    <artifactId>jacoco-maven-plugin</artifactId>
    <version>0.8.11</version>
    <executions>
        <execution>
            <id>prepare-agent</id>
            <goals>
                <goal>prepare-agent</goal>
            </goals>
        </execution>
        <execution>
            <id>report</id>
            <phase>test</phase>
            <goals>
                <goal>report</goal>
            </goals>
        </execution>
        <execution>
            <id>check</id>
            <phase>verify</phase>
            <goals>
                <goal>check</goal>
            </goals>
            <configuration>
                <rules>
                    <rule>
                        <element>BUNDLE</element>
                        <limits>
                            <limit>
                                <counter>LINE</counter>
                                <value>COVEREDRATIO</value>
                                <minimum>0.80</minimum>
                            </limit>
                            <limit>
                                <counter>BRANCH</counter>
                                <value>COVEREDRATIO</value>
                                <minimum>0.70</minimum>
                            </limit>
                        </limits>
                    </rule>
                </rules>
            </configuration>
        </execution>
    </executions>
</plugin>
```

### Gradle 配置

```groovy
plugins {
    id 'jacoco'
}

jacoco {
    toolVersion = '0.8.11'
}

jacocoTestReport {
    reports {
        html.required = true
        xml.required = true
        csv.required = true
    }
}

jacocoTestCoverageVerification {
    rules {
        rule {
            element = 'bundle'
            limit {
                counter = 'LINE'
                value = 'COVEREDRATIO'
                minimum = 0.80
            }
        }
    }
}
```

## 覆盖率类型

### Counter 类型

| Counter | 说明 |
|---------|------|
| LINE | 行覆盖 |
| BRANCH | 分支覆盖（if/while/for/switch） |
| CLASS | 类覆盖 |
| METHOD | 方法覆盖 |
| INSTRUCTION | JVM 指令覆盖 |
| COMPLEXITY | 圈复杂度覆盖 |

### 覆盖比率

| Value | 说明 |
|-------|------|
| TOTALTOTAL | 总数 |
| COVERED | 已覆盖 |
| MISSED | 未覆盖 |
| COVEREDRATIO | 覆盖率（COVERED / TOTALTOTAL） |

## 分支覆盖率

### 分支覆盖示例

分支覆盖率衡量条件分支的覆盖程度。

```java
public boolean isValid(int age) {
    if (age < 0 || age > 150) {  // 2 个分支
        return false;
    }
    return age >= 18;
}
```

### 100% 分支覆盖

每个分支都需要至少一次 true 和一次 false 的测试用例。

```java
@Test
void testIsValid() {
    assertFalse(isValid(-1));  // age < 0
    assertFalse(isValid(151)); // age > 150
    assertFalse(isValid(10));  // age < 18
    assertTrue(isValid(25));  // age >= 18
}
```

### 分支覆盖与条件覆盖

BRANCH 覆盖每个 boolean 表达式结果的组合；CONDITION 覆盖每个条件的 true/false。

## 覆盖率指标

### 关键指标

```
Line Coverage = (Covered Lines / Total Lines) × 100%
Branch Coverage = (Covered Branches / Total Branches) × 100%
```

### 常见标准

| 级别 | 行覆盖率 | 分支覆盖率 |
|------|----------|------------|
| 最低 | 50% | 40% |
| 良好 | 70% | 60% |
| 优秀 | 80% | 70% |
| 严格 | 90% | 80% |

## 常见问题

### 私有方法覆盖

JaCoCo 可以覆盖私有方法，使用反射调用。

```java
@TestVisibleForTesting
void testPrivateMethod() throws Exception {
    Method method = MyClass.class.getDeclaredMethod("privateMethod");
    method.setAccessible(true);
    // 调用测试
}
```

### Lombok 问题

Lombok 生成的方法可从覆盖率中排除。

```xml
<exclude>
    <exclude>**/domain/*.class</exclude>
</exclude>
```

### 枚举覆盖

枚举需要测试所有值。

```java
@ParameterizedTest
@EnumSource(UserRole.class)
void testAllRoles(UserRole role) {
    User user = new User();
    user.setRole(role);
    assertEquals(role, user.getRole());
}
```

## SonarQube 质量门禁

### Maven 配置

```xml
<plugin>
    <groupId>org.sonarsource.scanner.maven</groupId>
    <artifactId>sonar-maven-plugin</artifactId>
    <configuration>
        <properties>
            <sonar.java.coveragePlugin>jacoco</sonar.java.coveragePlugin>
            <sonar.jacoco.reportPaths>${project.build.directory}/jacoco.exec</sonar.jacoco.reportPaths>
        </properties>
    </configuration>
</plugin>
```

## 最佳实践

### 不要追求 100%

覆盖率不是终极目标，关注关键业务逻辑、边界条件、异常处理路径。覆盖率可帮助发现死代码。

### 增量提升

逐步补充测试，查看 JaCoCo 报告找到未覆盖的方法。

### 关注分支覆盖

分支覆盖率低意味着存在未测试的条件分支。
