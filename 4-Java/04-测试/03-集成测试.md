# 集成测试

## 概述

集成测试验证多个组件协同工作的正确性，范围从单元测试的类级别到系统级别的部分或全部组件。

### 测试金字塔

```
        /\
       /  \      E2E (少量)
      /----\     集成测试 (适量)
     /      \    单元测试 (大量)
    /--------\
```

## Spring Boot 集成测试

### @SpringBootTest

```java
@SpringBootTest
class UserServiceIntegrationTest {

    @Autowired
    private UserService userService;

    @Autowired
    private UserRepository userRepository;

    @Test
    void testFullWorkflow() {
        // 真实 Spring 上下文
        User user = userService.createUser("Alice", "alice@example.com");
        assertNotNull(user.getId());

        User found = userRepository.findById(user.getId());
        assertEquals("Alice", found.getName());
    }
}
```

### @WebMvcTest 只测 Controller

```java
@WebMvcTest(UserController.class)
class UserControllerTest {

    @Autowired
    private MockMvc mockMvc;

    @MockBean
    private UserService userService;

    @Test
    void testGetUser() throws Exception {
        when(userService.findById(1L))
            .thenReturn(new User(1L, "Alice"));

        mockMvc.get("/users/1")
            .andExpect(status().isOk())
            .andExpect(jsonPath("$.name").value("Alice"));
    }
}
```

### @DataJpaTest 只测 JPA

```java
@DataJpaTest
class UserRepositoryTest {

    @Autowired
    private UserRepository userRepository;

    @Autowired
    private TestEntityManager entityManager;

    @Test
    void testFindByEmail() {
        User user = new User("Alice", "alice@example.com");
        entityManager.persist(user);
        entityManager.flush();

        User found = userRepository.findByEmail("alice@example.com");

        assertNotNull(found);
        assertEquals("Alice", found.getName());
    }
}
```

### @JsonTest 只测 JSON 序列化

```java
@JsonTest
class UserJsonTest {

    @Autowired
    private JacksonTester<User> json;

    @Test
    void testSerialize() throws IOException {
        User user = new User(1L, "Alice", "alice@example.com");

        JsonContent<User> result = json.write(user);

        assertThat(result).hasJsonPathStringValue("$.name");
        assertThat(result).extractingJsonPathStringValue("$.name")
            .isEqualTo("Alice");
    }
}
```

### @RestClientTest REST 客户端测试

```java
@RestClientTest(RestTemplate.class)
class RestClientTest {

    @Autowired
    private RestTemplate restTemplate;

    @MockServer
    private MockRestServiceServer mockServer;

    @Test
    void testGet() {
        mockServer.expect(requestTo("/api/user/1"))
            .andRespond(withSuccess("{\"name\":\"Alice\"}", MediaType.JSON));

        User user = restTemplate.getForObject("/api/user/1", User.class);

        assertEquals("Alice", user.getName());
    }
}
```

## MockMvc 详解

### 基本操作

```java
@Autowired
private MockMvc mockMvc;

@Test
void testGet() throws Exception {
    mockMvc.get("/users/1")
        .andExpect(status().isOk())
        .andExpect(content().contentType(MediaType.APPLICATION_JSON))
        .andExpect(jsonPath("$.name").value("Alice"));
}

@Test
void testPost() throws Exception {
    mockMvc.post("/users")
        .contentType(MediaType.APPLICATION_JSON)
        .content("{\"name\":\"Alice\",\"email\":\"alice@example.com\"}"))
        .andExpect(status().isCreated())
        .andExpect(header().exists("Location"));
}
```

### 请求构建

```java
@Test
void testComplexRequest() throws Exception {
    mockMvc.perform(
        get("/users")
            .param("page", "0")
            .param("size", "10")
            .param("sort", "name,desc")
            .header("Authorization", "Bearer token")
            .cookie(new Cookie("session", "abc123"))
            .contentType(MediaType.APPLICATION_JSON)
    )
    .andExpect(status().isOk());
}
```

### 文件上传

```java
@Test
void testFileUpload() throws Exception {
    MockMultipartFile file = new MockMultipartFile(
        "file",
        "test.txt",
        MediaType.TEXT_PLAIN_VALUE,
        "Hello World".getBytes()
    );

    mockMvc.perform(multipart("/upload").file(file))
        .andExpect(status().isOk());
}
```

### JSON 比较

```java
@Test
void testJsonContent() throws Exception {
    mockMvc.get("/users/1")
        .andExpect(status().isOk())
        .andExpect(jsonPath("$.name").value("Alice"))
        .andExpect(jsonPath("$.email").value("alice@example.com"))
        .andExpect(jsonPath("$.friends", hasSize(3)))
        .andExpect(jsonPath("$.friends[0].name").value("Bob"));
}
```

### 事务管理

```java
@SpringBootTest
@Transactional // 自动回滚
class TransactionalTest {

    @Test
    void test1() {
        // 数据变更会自动回滚
        userRepository.save(new User("Alice"));
    }

    @Test
    void test2() {
        // test1 的变更已回滚，看不到 test1 的数据
        List<User> users = userRepository.findAll();
        assertTrue(users.isEmpty());
    }
}
```

### 不回滚特定测试

```java
    }
```
```java
}
```

## REST Assured

### 添加依赖

```xml
<dependency>
    <groupId>io.rest-assured</groupId>
    <artifactId>rest-assured</artifactId>
    <version>5.3.0</version>
    <scope>test</scope>
</dependency>
<dependency>
    <groupId>io.rest-assured</groupId>
    <artifactId>spring-mock-mvc</artifactId>
    <version>5.3.0</version>
    <scope>test</scope>
</dependency>
```

### 基本用法

```java
@SpringBootTest
class RestAssuredTest {

    @Test
    void testGetUser() {
        given()
            .port(8080)
        .when()
            .get("/users/1")
        .then()
            .statusCode(200)
            .body("name", equalTo("Alice"))
            .body("email", equalTo("alice@example.com"));
    }
}
```

### JSON 验证

```java
@Test
void testJsonResponse() {
    given()
        .port(8080)
        .when()
        .get("/users/1")
        .then()
            .statusCode(200)
            .contentType(ContentType.JSON)
            .body("id", greaterThan(0))
            .body("name", notNullValue())
            .body("friends", hasSize(greaterThanOrEqualTo(0)));
}
```

### 复杂请求

```java
@Test
void testComplexRequest() {
    given()
        .port(8080)
        .contentType(ContentType.JSON)
        .header("Authorization", "Bearer token")
        .queryParam("page", 0)
        .queryParam("size", 10)
        .body("{\"name\":\"Alice\",\"email\":\"alice@example.com\"}")
    .when()
        .post("/users")
    .then()
        .statusCode(201)

```

## 异步测试

### CompletableFuture

```java
@Test
void testAsync() {
    CompletableFuture<String> future = asyncService.getData();

    String result = future.join();

    assertEquals("data", result);
}

// 带超时
@Test
void testAsyncWithTimeout() {
    CompletableFuture<String> future = asyncService.getData();

    assertTimeout(Duration.ofSeconds(5), () ->
        assertEquals("data", future.join())
    );
}
```

### @Async 测试

```java
@Test
void testAsyncMethod() {
    asyncService.asyncMethod();

    await().atMost(Duration.ofSeconds(5))
           .untilAsserted(() ->
               verify(repository).save(any())
           );
}
```

## 集成测试最佳实践

### 测试隔离

```java
@SpringBootTest
@DirtiesContext(classMode = BEFORE_EACH_TEST_METHOD)
class IsolatedTest {
    // 每个测试前重建 Spring 上下文
}

@DirtiesContext(classMode = AFTER_CLASS)
class CleanupTest {
    // 测试类结束后清理
}
```

### 配置文件分离

```
src/
├── main/
│   └── resources/application.yml
└── test/
    └── resources/
        ├── application-test.yml
        └── application-integration.yml
```
