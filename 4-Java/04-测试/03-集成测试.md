# 集成测试

## 概述

集成测试验证多个组件协同工作的正确性，范围从单元测试的类级别到系统级别的部分或全部组件。

### 测试金字塔

```
        /\
       /  \      E2E (少量)
      /----\     集成测试 (适量)
     /      \    单元测试 (大量)
    /--------\
```

## Spring Boot 集成测试

### @SpringBootTest

@SpringBootTest 启动完整 Spring 上下文，适用于需要完整 Spring 功能的集成测试。

```java
@SpringBootTest
class UserServiceIntegrationTest {

    @Autowired
    private UserService userService;

    @Autowired
    private UserRepository userRepository;

    @Test
    void testFullWorkflow() {
        User user = userService.createUser("Alice", "alice@example.com");
        assertNotNull(user.getId());

        User found = userRepository.findById(user.getId());
        assertEquals("Alice", found.getName());
    }
}
```

### @WebMvcTest 只测 Controller

@WebMvcTest 只启动 MVC 层，适合 Controller 层测试，使用 MockMvc 进行请求模拟。

```java
@WebMvcTest(UserController.class)
class UserControllerTest {

    @Autowired
    private MockMvc mockMvc;

    @MockBean
    private UserService userService;

    @Test
    void testGetUser() throws Exception {
        when(userService.findById(1L))
            .thenReturn(new User(1L, "Alice"));

        mockMvc.get("/users/1")
            .andExpect(status().isOk())
            .andExpect(jsonPath("$.name").value("Alice"));
    }
}
```

### @DataJpaTest 只测 JPA

@DataJpaTest 只启动 JPA 相关组件，使用内存数据库进行 Repository 层测试。

```java
@DataJpaTest
class UserRepositoryTest {

    @Autowired
    private UserRepository userRepository;

    @Autowired
    private TestEntityManager entityManager;

    @Test
    void testFindByEmail() {
        User user = new User("Alice", "alice@example.com");
        entityManager.persist(user);
        entityManager.flush();

        User found = userRepository.findByEmail("alice@example.com");

        assertNotNull(found);
        assertEquals("Alice", found.getName());
    }
}
```

### @JsonTest 只测 JSON 序列化

@JsonTest 只启动 JSON 处理相关组件，用于测试 JSON 序列化/反序列化。

```java
@JsonTest
class UserJsonTest {

    @Autowired
    private JacksonTester<User> json;

    @Test
    void testSerialize() throws IOException {
        User user = new User(1L, "Alice", "alice@example.com");

        JsonContent<User> result = json.write(user);

        assertThat(result).hasJsonPathStringValue("$.name");
        assertThat(result).extractingJsonPathStringValue("$.name")
            .isEqualTo("Alice");
    }
}
```

## MockMvc 详解

### 基本操作

MockMvc 提供链式 API 构建请求，andExpect() 添加断言。

```java
@Autowired
private MockMvc mockMvc;

@Test
void testGet() throws Exception {
    mockMvc.get("/users/1")
        .andExpect(status().isOk())
        .andExpect(content().contentType(MediaType.APPLICATION_JSON))
        .andExpect(jsonPath("$.name").value("Alice"));
}

@Test
void testPost() throws Exception {
    mockMvc.post("/users")
        .contentType(MediaType.APPLICATION_JSON)
        .content("{\"name\":\"Alice\",\"email\":\"alice@example.com\"}")
        .andExpect(status().isCreated())
        .andExpect(header().exists("Location"));
}
```

### 请求构建

MockMvc 支持复杂的请求构建，包括参数、头、Cookie 等。

```java
@Test
void testComplexRequest() throws Exception {
    mockMvc.perform(
        get("/users")
            .param("page", "0")
            .param("size", "10")
            .param("sort", "name,desc")
            .header("Authorization", "Bearer token")
            .cookie(new Cookie("session", "abc123"))
            .contentType(MediaType.APPLICATION_JSON)
    )
    .andExpect(status().isOk());
}
```

### 文件上传

使用 MockMultipartFile 模拟文件上传请求。

```java
@Test
void testFileUpload() throws Exception {
    MockMultipartFile file = new MockMultipartFile(
        "file",
        "test.txt",
        MediaType.TEXT_PLAIN_VALUE,
        "Hello World".getBytes()
    );

    mockMvc.perform(multipart("/upload").file(file))
        .andExpect(status().isOk());
}
```

## TestContainers

### PostgreSQL 测试

TestContainers 启动真实数据库容器，支持动态属性注入。

```java
@Testcontainers
class PostgreSQLTest {

    @Container
    static PostgreSQLContainer<?> postgres = new PostgreSQLContainer<>("postgres:15")
        .withDatabaseName("testdb")
        .withUsername("test")
        .withPassword("test");

    @DynamicPropertySource
    static void properties(DynamicPropertyRegistry registry) {
        registry.add("spring.datasource.url", postgres::getJdbcUrl);
        registry.add("spring.datasource.username", postgres::getUsername);
        registry.add("spring.datasource.password", postgres::getPassword);
    }

    @Test
    void testDatabase() {
        // 使用真实 PostgreSQL
    }
}
```

### 多容器

一个测试可以启动多个容器。

```java
@Testcontainers
class MultiContainerTest {

    @Container
    static PostgreSQLContainer<?> postgres = new PostgreSQLContainer<>("postgres:15");

    @Container
    static GenericContainer<?> redis = new GenericContainer<>("redis:7")
        .withExposedPorts(6379);

    @DynamicPropertySource
    static void properties(DynamicPropertyRegistry registry) {
        registry.add("spring.datasource.url", postgres::getJdbcUrl);
        registry.add("spring.redis.host", redis::getHost);
        registry.add("spring.redis.port", redis::getFirstMappedPort);
    }
}
```

## 数据库测试

### H2 内存数据库

H2 内存数据库适合快速测试，配置简单。

```properties
# application-test.properties
spring.datasource.url=jdbc:h2:mem:testdb
spring.datasource.driver-class-name=org.h2.Driver
spring.jpa.hibernate.ddl-auto=create-drop
```

### 事务管理

@SpringBootTest 默认启用事务，测试结束后自动回滚。

```java
@SpringBootTest
@Transactional
class TransactionalTest {

    @Test
    void test1() {
        userRepository.save(new User("Alice"));
    }

    @Test
    void test2() {
        List<User> users = userRepository.findAll();
        assertTrue(users.isEmpty());  // test1 的变更已回滚
    }
}
```

### @Rollback(false) 不回滚

@Rollback(false) 标记特定测试不回滚。

```java
@SpringBootTest
@Transactional
class RollbackTest {

    @Test
    @Rollback(false)
    void testNoRollback() {
        userRepository.save(new User("Alice"));
    }
}
```

### @Sql 初始化数据

@Sql 在测试前执行 SQL 脚本初始化数据。

```java
@Sql({"/data/user-test.sql"})
@Test
void testWithSqlFile() {
    // 使用 /resources/data/user-test.sql 初始化数据
}
```

## REST Assured

### 基本用法

REST Assured 提供 BDD 风格的 HTTP 测试 API。

```java
@SpringBootTest
class RestAssuredTest {

    @Test
    void testGetUser() {
        given()
            .port(8080)
        .when()
            .get("/users/1")
        .then()
            .statusCode(200)
            .body("name", equalTo("Alice"))
            .body("email", equalTo("alice@example.com"));
    }
}
```

### JSON 验证

REST Assured 支持丰富的 JSON 响应验证。

```java
@Test
void testJsonResponse() {
    given()
        .port(8080)
    .when()
        .get("/users/1")
    .then()
        .statusCode(200)
        .contentType(ContentType.JSON)
        .body("id", greaterThan(0))
        .body("friends", hasSize(greaterThanOrEqualTo(0)));
}
```

## 异步测试

### CompletableFuture

```java
@Test
void testAsync() {
    CompletableFuture<String> future = asyncService.getData();
    String result = future.join();
    assertEquals("data", result);
}

@Test
void testAsyncWithTimeout() {
    CompletableFuture<String> future = asyncService.getData();
    assertTimeout(Duration.ofSeconds(5), () ->
        assertEquals("data", future.join())
    );
}
```

## 集成测试最佳实践

### 测试隔离

@DirtiesContext 确保测试间上下文隔离。

```java
@SpringBootTest
@DirtiesContext(classMode = BEFORE_EACH_TEST_METHOD)
class IsolatedTest {
    // 每个测试前重建 Spring 上下文
}
```

### 配置文件分离

使用独立测试配置文件。

```
src/
├── main/
│   └── resources/application.yml
└── test/
    └── resources/
        ├── application-test.yml
        └── application-integration.yml
```
