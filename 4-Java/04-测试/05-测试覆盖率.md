# 测试覆盖率

## JaCoCo 概述

JaCoCo (Java Code Coverage) 是 Java 标准的覆盖率工具，支持行覆盖、分支覆盖、方法覆盖等。

### Maven 配置

```xml
<plugin>
    <groupId>org.jacoco</groupId>
    <artifactId>jacoco-maven-plugin</artifactId>
    <version>0.8.11</version>
    <executions>
        <execution>
            <id>prepare-agent</id>
            <goals>
                <goal>prepare-agent</goal>
            </goals>
        </execution>
        <execution>
            <id>report</id>
            <phase>test</phase>
            <goals>
                <goal>report</goal>
            </goals>
        </execution>
        <execution>
            <id>check</id>
            <phase>verify</phase>
            <goals>
                <goal>check</goal>
            </goals>
            <configuration>
                <rules>
                    <rule>
                        <element>BUNDLE</element>
                        <limits>
                            <limit>
                                <counter>LINE</counter>
                                <value>COVEREDRATIO</value>
                                <minimum>0.80</minimum>
                            </limit>
                            <limit>
                                <counter>BRANCH</counter>
                                <value>COVEREDRATIO</value>
                                <minimum>0.70</minimum>
                            </limit>
                        </limits>
                    </rule>
                </rules>
            </configuration>
        </execution>
    </executions>
</plugin>
```

### Gradle 配置

```groovy
plugins {
    id 'jacoco'
}

jacoco {
    toolVersion = '0.8.11'
}

jacocoTestReport {
    reports {
        html.required = true
        xml.required = true
        csv.required = true
    }
}

jacocoTestCoverageVerification {
    rules {
        rule {
            element = 'bundle'
            limit {
                counter = 'LINE'
                value = 'COVEREDRATIO'
                minimum = 0.80
            }
            limit {
                counter = 'BRANCH'
                value = 'COVEREDRATIO'
                minimum = 0.70
            }
        }
    }
}
```

## 覆盖率类型

### Counter 类型

| Counter | 说明 |
|---------|------|
| LINE | 行覆盖 |
| BRANCH | 分支覆盖（if/while/for/switch） |
| CLASS | 类覆盖 |
| METHOD | 方法覆盖 |
| INSTRUCTION | JVM 指令覆盖 |
| COMPLEXITY | 圈复杂度覆盖 |

### 覆盖比率

| Value | 说明 |
|-------|------|
| TOTALTOTAL | 总数 |
| COVERED | 已覆盖 |
| MISSED | 未覆盖 |
| COVEREDRATIO | 覆盖率（COVERED / TOTALTOTAL） |

## 分支覆盖率

### 分支覆盖示例

```java
public boolean isValid(int age) {
    if (age < 0 || age > 150) {  // 2 个分支
        return false;
    }
    return age >= 18;
}
```

### 100% 分支覆盖需要

```java
@Test
void testIsValid() {
    assertFalse(isValid(-1));  // age < 0
    assertFalse(isValid(151)); // age > 150
    assertFalse(isValid(10));  // age < 18
    assertTrue(isValid(25));  // age >= 18
}
```

### 分支覆盖与条件覆盖

```java
// BRANCH 覆盖：每个 boolean 表达式结果的组合
// CONDITION 覆盖：每个条件的 true/false

if (a && b) { ... }

// 条件覆盖：a=true, a=false; b=true, b=false
// 分支覆盖：(true,true), (true,false), (false,xxx)
```

## 覆盖率指标

### 关键指标

```
Line Coverage = (Covered Lines / Total Lines) × 100%
Branch Coverage = (Covered Branches / Total Branches) × 100%
```

### 常见标准

| 级别 | 行覆盖率 | 分支覆盖率 |
|------|----------|------------|
| 最低 | 50% | 40% |
| 良好 | 70% | 60% |
| 优秀 | 80% | 70% |
| 严格 | 90% | 80% |

## 常见问题

### 私有方法覆盖

```java
// JaCoCo 可以覆盖私有方法
// 使用反射或 @TestVisibleForTesting
@TestVisibleForTesting
void testPrivateMethod() throws Exception {
    Method method = MyClass.class.getDeclaredMethod("privateMethod");
    method.setAccessible(true);
    // 调用测试
}
```

### Lombok 问题

```xml
<!-- 排除 Lombok 生成的方法 -->
<configuration>
    <exclude>
        <exclude>**/domain/*.class</exclude>
    </exclude>
</configuration>
```

### 枚举覆盖

```java
// 枚举需要测试所有值
@ParameterizedTest
@EnumSource(UserRole.class)
void testAllRoles(UserRole role) {
    User user = new User();
    user.setRole(role);
    assertEquals(role, user.getRole());
}
```

### 异常覆盖

```java
// 测试每个 catch 分支
@Test
void testExceptionPath() {
    try {
        service.methodThatThrows();
        fail("应该抛出异常");
    } catch (ExpectedException e) {
        assertEquals("error", e.getCode());
    }
}
```

## SonarQube 质量门禁

### Maven

```xml
<plugin>
    <groupId>org.sonarsource.scanner.maven</groupId>
    <artifactId>sonar-maven-plugin</artifactId>

            <sonar.java.coveragePlugin>jacoco</sonar.java.coveragePlugin>
            <sonar.jacoco.reportPaths>${project.build.directory}/jacoco.exec</sonar.jacoco.reportPaths>

</plugin>
```

## 最佳实践

### 不要追求 100%

- 关注关键业务逻辑
- 关注边界条件
- 关注异常处理路径
- 避免死代码（通过覆盖率发现）

### 增量提升

```bash
# 查看未覆盖行
mvn jacoco:report
# 打开 target/site/jacoco/index.html 找到未覆盖的方法
# 逐步补充测试
```

### 关注分支覆盖

```java
// 低分支覆盖率示例
if (condition1 && condition2) {  // 4 种组合
    doSomething();
}

// 只测试 true, true 是不够的
```
