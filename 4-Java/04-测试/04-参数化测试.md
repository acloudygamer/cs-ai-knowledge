# 参数化测试

## JUnit 5 参数化测试

### 启用参数化测试

参数化测试允许使用不同参数多次运行同一测试，需要添加 junit-jupiter-params 依赖：

```xml
<dependency>
    <groupId>org.junit.jupiter</groupId>
    <artifactId>junit-jupiter-params</artifactId>
    <version>5.10.0</version>
    <scope>test</scope>
</dependency>
```

## @ValueSource

### 基础用法

@ValueSource 提供简单数组参数，支持 int、long、String、double 等类型。

```java
@ParameterizedTest
@ValueSource(ints = {1, 2, 3, 4, 5})
void testIsPositive(int number) {
    assertTrue(number > 0);
}

@ParameterizedTest
@ValueSource(strings = {"hello", "world", "test"})
void testIsNotBlank(String input) {
    assertNotNull(input);
    assertFalse(input.isBlank());
}
```

### 支持的类型

@ValueSource 支持 int、long、double、String 数组类型。

```java
@ValueSource(ints = {1, 2, 3})
@ValueSource(longs = {1L, 2L, 3L})
@ValueSource(strings = {"a", "b", "c"})
@ValueSource(doubles = {1.0, 2.0, 3.0})
```

## @NullSource 和 @EmptySource

### 组合用法

@NullSource 提供 null 值；@EmptySource 提供空值；@NullAndEmptySource 组合两者。

```java
@ParameterizedTest
@NullSource
void testNull(String input) {
    assertNull(input);
}

@ParameterizedTest
@EmptySource
void testEmpty(String input) {
    assertTrue(input.isEmpty());
}

@ParameterizedTest
@NullAndEmptySource
void testNullOrEmpty(String input) {
    assertTrue(input == null || input.isEmpty());
}
```

## @CsvSource

### 逗号分隔值

@CsvSource 使用逗号分隔多参数，每行对应一次测试执行。

```java
@ParameterizedTest
@CsvSource({
    "1, 2, 3",
    "0, 0, 0",
    "-1, -2, -3"
})
void testAdd(int a, int b, int expected) {
    assertEquals(expected, calculator.add(a, b));
}
```

### 自定义分隔符

delimiter 参数自定义分隔符。

```java
@ParameterizedTest
@CsvSource(value = {
    "Alice: 30: alice@example.com",
    "Bob: 25: bob@example.com"
}, delimiter = ':')
void testUser(String name, int age, String email) {
    User user = new User(name, age, email);
    assertNotNull(user.getName());
}
```

## @CsvFileSource

### 外部 CSV 文件

@CsvFileSource 从外部 CSV 文件读取参数。

```java
@ParameterizedTest
@CsvFileSource(resources = "/data/calculator.csv")
void testFromCsvFile(int a, int b, int expected) {
    assertEquals(expected, calculator.add(a, b));
}
```

### CSV 文件格式

```csv
a,b,expected
1,2,3
0,0,0
-1,-2,-3
```

## @MethodSource

### 静态工厂方法

@MethodSource 引用静态工厂方法提供参数，支持复杂对象和多参数。

```java
@ParameterizedTest
@MethodSource("provideStringsForIsBlank")
void testIsBlank(String input, boolean expected) {
    assertEquals(expected, input.isBlank());
}

static Stream<Arguments> provideStringsForIsBlank() {
    return Stream.of(
        Arguments.of("   ", true),
        Arguments.of("hello", false),
        Arguments.of("", true)
    );
}
```

### 基本类型方法

IntStream、List 等都可以作为参数源。

```java
@ParameterizedTest
@MethodSource("intRange")
void testIntRange(int number) {
    assertTrue(number >= 0 && number < 100);
}

static IntStream intRange() {
    return IntStream.range(0, 100);
}
```

### 外部类方法

使用完整类名引用外部类的工厂方法。

```java
class TestDataProvider {
    static Stream<Arguments> userData() {
        return Stream.of(
            Arguments.of("Alice", 30),
            Arguments.of("Bob", 25)
        );
    }
}

@ParameterizedTest
@MethodSource("com.example.TestDataProvider#userData")
void testUser(String name, int age) {
    // ...
}
```

## @ArgumentsSource

### 自定义 ArgumentsProvider

实现 ArgumentsProvider 接口创建自定义参数源。

```java
public class CustomArgumentsProvider implements ArgumentsProvider {
    @Override
    public Stream<? extends Arguments> provideArguments(ExtensionContext context) {
        return Stream.of(
            Arguments.of("hello", 5),
            Arguments.of("world", 5)
        );
    }
}

@ParameterizedTest
@ArgumentsSource(CustomArgumentsProvider.class)
void test(String input, int expectedLength) {
    assertEquals(expectedLength, input.length());
}
```

## 多个参数源

多个参数源组合，测试次数为所有源参数数量的笛卡尔积。

```java
@ParameterizedTest
@NullSource
@ValueSource(strings = {"hello", "world"})
void testMultiple(String input) {
    // 运行 3 次：null, "hello", "world"
}
```

## 参数转换

### 自动转换

JUnit 5 自动转换常见类型如 LocalDate、Enum 等。

```java
@ParameterizedTest
@ValueSource(strings = {"2024-01-01", "2024-12-31"})
void testDate(LocalDate date) {
    assertNotNull(date);
}
```

### 自定义 Converter

通过 @ConvertWith 使用自定义参数转换器。

```java
public class UserConverter extends SimpleArgumentConverter {
    @Override
    public Object convert(Object input, Type targetType) {
        if (input instanceof String && targetType == User.class) {
            String[] parts = ((String) input).split(":");
            return new User(parts[0], Integer.parseInt(parts[1]));
        }
        throw new IllegalArgumentException();
    }
}

@ParameterizedTest
@CsvSource({"Alice: 30", "Bob: 25"})
void testUser(@ConvertWith(UserConverter.class) User user) {
    assertNotNull(user.getName());
}
```

## DisplayName 自定义

### 自定义测试名称

使用 name 属性自定义每个测试变体的显示名称。

```java
@ParameterizedTest(name = "[{index}] {0} + 0 = {0}")
@ValueSource(ints = {1, 2, 3})
void testAddWithName(int number) {
    assertEquals(number, calculator.add(number, 0));
}
```

## 常用场景

### 边界值测试

```java
@ParameterizedTest
@ValueSource(ints = {Integer.MIN_VALUE, -1, 0, 1, Integer.MAX_VALUE})
void testBoundary(int value) {
    // 边界值测试
}
```

### 等价类划分

```java
@ParameterizedTest
@CsvSource({
    "alice@example.com, true",
    "bob@test.org, true",
    "invalid, false",
    "@test.com, false"
})
void testEmailValidation(String email, boolean expected) {
    assertEquals(expected, validator.isValid(email));
}
```

## 常见问题

### 空值和 null

```java
@ParameterizedTest
@NullSource
@EmptySource
@ValueSource(strings = {"hello"})
void testWithNullEmptyAndValue(String input) {
    // 处理所有情况
}
```

### 性能考虑

参数化测试默认串行执行，通过 @Execution(ExecutionMode.CONCURRENT) 可改为并行。

```java
@Execution(ExecutionMode.CONCURRENT)
@ParameterizedTest
@ValueSource(ints = {1, 2, 3, 4, 5})
void testParallel(int value) {
    // 并行执行
}
```
