# 责任链模式

## 定义

责任链模式是一种通过将请求沿着处理者链传递，直到某个处理者处理它，从而解除请求发送者与接收者之间耦合的行为型设计模式。

## 数学模型

### 链的可达性分析

设处理者链 $H = (h_1, h_2, \ldots, h_n)$，请求 $r$ 的处理结果：

$$\text{handle}(r, h_i) = \begin{cases} \text{处理成功} & \text{if } h_i.\text{canHandle}(r) \\ \text{传递给} \ h_{i+1} & \text{if } \neg h_i.\text{canHandle}(r) \end{cases}$$

若所有处理者都不能处理，请求最终被 **拒绝** 或 **到达链尾**。

**最坏情况时间复杂度**：$O(n)$，其中 $n$ 是链长度。

### Servlet Filter 链的数学结构

Servlet Filter 链可建模为 **函数组合**：

```java
filterChain.doFilter(request, response) =
    F1.doFilter(request, response,
        F2.doFilter(request, response,
            ...
                Fn.doFilter(request, response, servlet.service())...))
```

展开后形成嵌套调用：
$$F_1 \circ F_2 \circ \cdots \circ F_n \circ S$$

其中 $F_i$ 为第 $i$ 个 Filter，$S$ 为 Servlet。

## 机制

### 处理决策的两种模式

| 模式 | 语义 | 适用场景 |
|------|------|---------|
| **选择性传递** | 处理者判断能否处理，能则处理，不能则传递 | 审批流程、权限校验 |
| **全部处理** | 每个处理者都执行自己的逻辑，然后传递 | 日志记录、性能监控 |

**选择性传递**的终止条件：
1. 处理者判断自己能够处理
2. 到达链尾
3. 处理者显式决定停止传递

### Servlet Filter 的责任链

Servlet Filter 是责任链模式的企业级应用：

```
请求 → Filter1.doFilter() → Filter2.doFilter() → Servlet.service()
                                        ↑                    │
                                        └────────────────────┘
                                          响应沿链返回
```

```java
public interface Filter {
    void doFilter(ServletRequest req, ServletResponse res, FilterChain chain);
}

public interface FilterChain {
    void doFilter(ServletRequest req, ServletResponse res);
}
```

每个 Filter 调用 `chain.doFilter()` 将请求传递给下一个 Filter，最终到达 Servlet。

### Spring Security 的 Filter Chain

Spring Security 使用 **代理模式** 实现责任链：
```
SecurityFilterChain
    │
    ├─ WebAsyncManagerIntegrationFilter
    ├─ SecurityContextPersistenceFilter
    ├─ HeaderWriterFilter
    ├─ CorsFilter
    ├─ LogoutFilter
    ├─ UsernamePasswordAuthenticationFilter
    ├─ RequestCacheAwareFilter
    ├─ SecurityContextHolderAwareRequestFilter
    ├─ AnonymousAuthenticationFilter
    ├─ SessionManagementFilter
    ├─ ExceptionTranslationFilter
    └─ FilterSecurityInterceptor ← 最终授权检查
```

每个 Filter 只关注自己的职责，通过 `filterChain.doFilter()` 传递请求。

### Filter 链的顺序敏感性

Filter 的执行顺序影响最终结果：

```java
// 认证 Filter 在日志 Filter 之前
// 认证结果可被日志记录

// 但若日志 Filter 在前：
// 日志无法记录认证结果（认证尚未执行）
```

**Spring Security 的 Filter 排序**：通过 `Order` 或 `SecurityFilterChain` 配置固定顺序。

### 中途终止传递的实现

处理者可以选择 **不调用** `chain.doFilter()`，从而终止传递：

```java
public class AuthFilter implements Filter {
    public void doFilter(ServletRequest req, ServletResponse res, FilterChain chain) {
        if (isAuthenticated((HttpServletRequest) req)) {
            chain.doFilter(req, res); // 认证通过，继续传递
        } else {
            ((HttpServletResponse) res).sendError(401); // 终止，不传递
        }
    }
}
```

**终止的数学语义**：
$$\text{handle}(r, h_i) = \begin{cases} \text{处理并终止} & \text{if } h_i.\text{handle}(r) \\ \text{传递给} \ h_{i+1} & \text{otherwise} \end{cases}$$

## 参考存根

```java
// 展示责任链的两种实现
abstract class Handler {
    private Handler next;

    public Handler setNext(Handler next) {
        this.next = next;
        return next; // 便于链式构建
    }

    public final void handle(Request request) {
        if (canHandle(request)) {
            doHandle(request);
        } else if (next != null) {
            next.handle(request);
        } else {
            System.out.println("No handler can process: " + request);
        }
    }

    protected abstract boolean canHandle(Request request);
    protected abstract void doHandle(Request request);
}

class Request {
    public String type;
    public Object data;
    public Request(String type, Object data) {
        this.type = type;
        this.data = data;
    }
}

// 使用链式构建
Handler auth = new AuthHandler();
Handler log = new LoggingHandler();
Handler validate = new ValidationHandler();

log.setNext(validate).setNext(auth);

// 或使用 List 动态组合
class HandlerChain {
    private List<Handler> handlers = new ArrayList<>();

    public void add(Handler h) { handlers.add(h); }

    public void handle(Request r) {
        for (Handler h : handlers) {
            if (h.canHandle(r)) {
                h.doHandle(r);
                break;
            }
        }
    }
}
```
