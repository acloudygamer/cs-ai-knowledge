# 单例模式

## 概述

单例模式确保一个类只有一个实例，并提供全局访问点。

### 核心原则

- 构造函数私有化
- 类内部创建唯一实例
- 提供静态方法获取实例

## 饿汉式

### 静态常量

```java
public class Singleton {
    private static final Singleton INSTANCE = new Singleton();

    private Singleton() { }

    public static Singleton getInstance() {
        return INSTANCE;
    }
}
```

**优点**: 线程安全，JVM 保证
**缺点**: 类加载时就创建，可能浪费资源

### 静态代码块

```java
public class Singleton {
    private static final Singleton INSTANCE;

    static {
        INSTANCE = new Singleton();
    }

    private Singleton() { }

    public static Singleton getInstance() {
        return INSTANCE;
    }
}
```

## 懒汉式

### 线程不安全

```java
public class Singleton {
    private static Singleton instance;

    private Singleton() { }

    public static Singleton getInstance() {
        if (instance == null) {
            instance = new Singleton();
        }
        return instance;
    }
}
```

**优点**: 延迟加载
**缺点**: 线程不安全

### 线程安全（同步方法）

```java
public class Singleton {
    private static Singleton instance;

    private Singleton() { }

    public synchronized static Singleton getInstance() {
        if (instance == null) {
            instance = new Singleton();
        }
        return instance;
    }
}
```

**缺点**: 每次调用都需要同步，性能开销大

### 线程安全（双重检查）

```java
public class Singleton {
    private static volatile Singleton instance;

    private Singleton() { }

    public static Singleton getInstance() {
        if (instance == null) {                    // 第一次检查
            synchronized (Singleton.class) {
                if (instance == null) {           // 第二次检查
                    instance = new Singleton();
                }
            }
        }
        return instance;
    }
}
```

**优点**: 延迟加载 + 线程安全 + 高性能
**关键**: `volatile` 防止指令重排

### 指令重排问题

```java
instance = new Singleton();
// 实际执行（可能被重排）：
// 1. 分配内存
// 2. 调用构造器
// 3. instance 指向内存

// volatile 防止：
// 2 和 3 不能重排
```

## 静态内部类

```java
public class Singleton {
    private Singleton() { }

    private static class Holder {
        private static final Singleton INSTANCE = new Singleton();
    }

    public static Singleton getInstance() {
        return Holder.INSTANCE;
    }
}
```

**优点**: JVM 保证线程安全 + 延迟加载

## 枚举单例

```java
public enum Singleton {
    INSTANCE;

    public void method() {
        // ...
    }
}

// 使用
Singleton.INSTANCE.method();
```

**优点**:
- 线程安全（JVM 保证）
- 防止反射攻击
- 防止反序列化创建新实例
- 简洁

**缺点**:
- 延迟加载依赖于类加载时机（但实际影响很小，因为类加载本身是惰性的）
- 不能继承其他类（枚举不能 extends）
- 对于需要延迟初始化且有复杂初始化逻辑的场景，不如静态内部类灵活

## 序列化问题

### 普通单例序列化问题

```java
// 反序列化可能创建新实例
Singleton s1 = Singleton.getInstance();
Singleton s2 = (Singleton) serializedClone(s1);
assert s1 != s2; // true！
```

### 解决方案

```java
public class Singleton implements Serializable {
    private static final Singleton INSTANCE = new Singleton();

    private Singleton() { }

    public static Singleton getInstance() {
        return INSTANCE;
    }

    // 防止反序列化创建新实例
    private Object readResolve() {
        return INSTANCE;
    }
}
```

## 反射攻击防护

### 问题

```java
Constructor<Singleton> c = Singleton.class.getDeclaredConstructor();
c.setAccessible(true);
Singleton s = c.newInstance(); // 创建了新实例！
```

### 防护方式

```java
public class Singleton {
    private static volatile Singleton instance;

    private Singleton() {
        if (instance != null) {
            throw new RuntimeException("Use getInstance()");
        }
    }

    public static Singleton getInstance() {
        if (instance == null) {
            synchronized (Singleton.class) {
                if (instance == null) {
                    instance = new Singleton();
                }
            }
        }
        return instance;
    }
}
```

## Spring 中的单例

### 默认作用域

```java
@Service
public class UserService {
    // Spring 默认是单例
    // 整个应用只有一个实例
}
```

### 单例 vs 原型

```java
@Service
@Scope("singleton")  // 默认
public class SingletonBean { }

@Service
@Scope("prototype")
public class PrototypeBean { }
```

### 请求级单例

```java
@RequestScope
public class RequestScopedBean {
    // 每个请求一个实例
}

@SessionScope
public class SessionScopedBean {
    // 每个会话一个实例
}
```

## 最佳实践

### 推荐写法

```java
// 1. 枚举（大多数情况）
public enum Singleton {
    INSTANCE;
}

// 2. 双重检查（需要延迟加载）
public class Singleton {
    private static volatile Singleton instance;

    private Singleton() { }

    public static Singleton getInstance() {
        if (instance == null) {
            synchronized (Singleton.class) {
                if (instance == null) {
                    instance = new Singleton();
                }
            }
        }
        return instance;
    }
}

// 3. 静态内部类（需要延迟加载）
public class Singleton {
    private Singleton() { }

    private static class Holder {
        static final Singleton INSTANCE = new Singleton();
    }

    public static Singleton getInstance() {
        return Holder.INSTANCE;
    }
}
```

### 适用场景

- 日志对象
- 配置管理器
- 连接池
- 缓存管理器
- 业务服务 Bean（Spring 默认）

### 不适用场景

- 有状态对象（可能导致线程安全问题）
- 需要多实例的场景
- 频繁创建销毁的对象
