# 单例模式

## 概述

单例模式确保一个类只有一个实例，并提供全局访问点。

核心原则：
- 构造函数私有化
- 类内部创建唯一实例
- 提供静态方法获取实例

## 饿汉式

类加载时就创建实例，JVM 保证线程安全。缺点是可能浪费资源（即使不使用也会创建）。

### 参考样例

```java
// 静态常量
public class Singleton {
    private static final Singleton INSTANCE = new Singleton();

    private Singleton() { }

    public static Singleton getInstance() {
        return INSTANCE;
    }
}
```

```java
// 静态代码块
public class Singleton {
    private static final Singleton INSTANCE;

    static {
        INSTANCE = new Singleton();
    }

    private Singleton() { }

    public static Singleton getInstance() {
        return INSTANCE;
    }
}
```

## 懒汉式

延迟加载，但需要处理线程安全问题。

### 参考样例

```java
// 线程不安全
public class Singleton {
    private static Singleton instance;

    private Singleton() { }

    public static Singleton getInstance() {
        if (instance == null) {
            instance = new Singleton();
        }
        return instance;
    }
}
```

```java
// 线程安全（同步方法）- 每次调用都需要同步，性能开销大
public class Singleton {
    private static Singleton instance;

    private Singleton() { }

    public synchronized static Singleton getInstance() {
        if (instance == null) {
            instance = new Singleton();
        }
        return instance;
    }
}
```

```java
// 线程安全（双重检查）
public class Singleton {
    private static volatile Singleton instance;

    private Singleton() { }

    public static Singleton getInstance() {
        if (instance == null) {
            synchronized (Singleton.class) {
                if (instance == null) {
                    instance = new Singleton();
                }
            }
        }
        return instance;
    }
}
```

```java
// 指令重排问题
instance = new Singleton();
// 实际执行（可能被重排）：
// 1. 分配内存
// 2. 调用构造器
// 3. instance 指向内存
// volatile 防止：2 和 3 不能重排
```

## 静态内部类

JVM 保证线程安全 + 延迟加载。利用类加载机制，只有调用 getInstance 时才会加载内部类。

### 参考样例

```java
public class Singleton {
    private Singleton() { }

    private static class Holder {
        private static final Singleton INSTANCE = new Singleton();
    }

    public static Singleton getInstance() {
        return Holder.INSTANCE;
    }
}
```

## 枚举单例

线程安全（JVM 保证），防止反射攻击和反序列化创建新实例。简洁，是大多数情况下的推荐写法。

### 参考样例

```java
public enum Singleton {
    INSTANCE;

    public void method() {
        // ...
    }
}
```

## 序列化问题

普通单例反序列化会创建新实例。解决方案是实现 `readResolve()` 方法返回单例实例。

### 参考样例

```java
public class Singleton implements Serializable {
    private static final Singleton INSTANCE = new Singleton();

    private Singleton() { }

    public static Singleton getInstance() {
        return INSTANCE;
    }

    private Object readResolve() {
        return INSTANCE;
    }
}
```

## 反射攻击防护

通过在构造器中检查实例是否为 null 来防止反射创建新实例。

### 参考样例

```java
public class Singleton {
    private static volatile Singleton instance;

    private Singleton() {
        if (instance != null) {
            throw new RuntimeException("Use getInstance()");
        }
    }

    public static Singleton getInstance() {
        if (instance == null) {
            synchronized (Singleton.class) {
                if (instance == null) {
                    instance = new Singleton();
                }
            }
        }
        return instance;
    }
}
```

## Spring 中的单例

Spring 默认作用域是单例，整个应用只有一个实例。可以通过 `@Scope` 注解修改。

### 参考样例

```java
@Service
public class UserService { }  // Spring 默认单例

@Service
@Scope("prototype")
public class PrototypeBean { }  // 每次获取新实例

@RequestScope
public class RequestScopedBean { }  // 每个请求一个实例

@SessionScope
public class SessionScopedBean { }  // 每个会话一个实例
```

## 最佳实践

### 推荐写法

```java
// 1. 枚举（大多数情况）
public enum Singleton {
    INSTANCE;
}

// 2. 双重检查（需要延迟加载）
public class Singleton {
    private static volatile Singleton instance;

    private Singleton() { }

    public static Singleton getInstance() {
        if (instance == null) {
            synchronized (Singleton.class) {
                if (instance == null) {
                    instance = new Singleton();
                }
            }
        }
        return instance;
    }
}

// 3. 静态内部类（需要延迟加载）
public class Singleton {
    private Singleton() { }

    private static class Holder {
        static final Singleton INSTANCE = new Singleton();
    }

    public static Singleton getInstance() {
        return Holder.INSTANCE;
    }
}
```

### 适用场景

- 日志对象
- 配置管理器
- 连接池
- 缓存管理器
- 业务服务 Bean（Spring 默认）

### 不适用场景

- 有状态对象（可能导致线程安全问题）
- 需要多实例的场景
- 频繁创建销毁的对象
