# 适配器模式

## 定义

适配器模式是一种将一个类的接口转换成客户端期望的另一个接口，使原本接口不兼容的类可以合作的 structural 设计模式。其本质是**接口转换**——在两个不兼容的接口之间建立桥梁，而不改变原有类的实现。

## 数学模型

### 接口兼容性的图论

设适配器 $A$ 连接**Adaptee**（已有接口 $I_A$）和**Target**（期望接口 $I_T$）：

$$A: I_A \rightarrow I_T$$

适配器的本质是**异构图中的边**，将不兼容的顶点连接起来。

```
不兼容的接口图
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    Client (期望 I_T)
         │
         │ "我希望这样调用"
         ▼
    ┌─────────┐        ┌─────────┐
    │ Target  │        │ Adaptee │
    │ 接口    │        │ 接口    │
    └────┬────┘        └────┬────┘
         │                  │
         │    适配器 A       │
         └────────┬─────────┘
                  │
                  ▼
            "我来转换调用"
```

### 转换函数的形式化

适配器实现转换函数 $f: I_T \rightarrow I_A$ 和反向函数 $f^{-1}: I_A \rightarrow I_T$（双向适配器）：

```java
// 单向适配器
class Adapter implements Target {  // 实现期望接口
    private final Adaptee adaptee;  // 持有被适配对象

    public void targetMethod() {  // 实现 Target 方法
        adaptee.adapteeMethod();   // 转换调用
    }
}
```

### 类适配器的多继承约束

类适配器使用**继承**实现：

```java
// 类适配器（继承）
class Adapter extends Adaptee implements Target { ... }
```

**Java 不支持多继承**，因此类适配器无法在 `extends Adaptee` 的同时 `implements Target`（若 Adaptee 是类而非接口）。

**解决方案**：只能适配 Adaptee 是**接口**的情况，不能适配 Adaptee 是**类**的情况。

## 机制

### 类适配器 vs 对象适配器

| 维度 | 类适配器 | 对象适配器 |
|------|---------|----------|
| 实现方式 | 继承 | 组合 |
| 能访问的方法 | Adaptee 所有方法（public）+ 子类可访问 | 只能通过引用调用 |
| 多继承 | 需要（Java 不支持） | 不需要 |
| 灵活性 | 低（编译时绑定，无法动态替换 Adaptee） | 高（运行时可替换 Adaptee） |
| Adapter 数量 | 需为每个 Adaptee 创建 Adapter | 一个 Adapter 类适配所有 Adaptee 子类 |

**GoF 推荐对象适配器**，因为：
1. Java 不支持多继承
2. 对象适配器可以使用 Adaptee 的子类（里氏替换原则）

### 适配器 vs 装饰器 vs 代理

| 模式 | 目的 | 接口关系 | 新增行为 |
|------|------|---------|---------|
| **适配器** | 让不兼容变得兼容 | 转换接口 | 无（只做转换） |
| **装饰器** | 增强对象功能 | 保持接口 | 有（增加功能） |
| **代理** | 控制对对象的访问 | 保持接口 | 有（控制访问） |

**关键区别**：
- 适配器：**改变**接口以适配不兼容双方
- 装饰器：保持接口，**增加**功能
- 代理：保持接口，**控制**访问

### 接口适配器（默认适配器模式）

当接口有大量方法但只需实现少数时，提供空实现适配器：

```java
// 原接口有很多方法
interface Callback {
    void onStart();
    void onProgress(int percent);
    void onComplete();
    void onError(Exception e);
    void onCancel();
    // ... 更多方法
}

// 提供空实现适配器
abstract class CallbackAdapter implements Callback {
    public void onStart() {}
    public void onProgress(int percent) {}
    public void onComplete() {}
    public void onError(Exception e) {}
    public void onCancel() {}
}

// 用户只需重写关心的方法
Callback callback = new CallbackAdapter() {
    public void onComplete() {
        System.out.println("Done!");
    }
};
```

**Java 17 简化**：使用 `default` 方法直接在接口中提供空实现（Java 8+）：
```java
interface Callback {
    default void onStart() {}
    default void onProgress(int percent) {}
    default void onComplete() { System.out.println("Done!"); }
    default void onError(Exception e) {}
    default void onCancel() {}
}
```

### 双向适配器的对称性

双向适配器同时实现两个方向，允许双向转换：

```java
class TwoWayAdapter implements Target, Adaptee {
    private final Original original;  // 组合

    // Target → Original
    public void targetMethod() {
        original.originalMethod();
    }

    // Original → Target
    public void originalMethod() {
        // 做转换后调用 Target
    }
}
```

**约束**：双向适配器必须同时可见两个接口的源代码，灵活性受限。

## 参考存根

```java
// 对象适配器：把旧接口适配到新接口
interface Target {
    void request();
}

class Adaptee {
    public void specificRequest() {
        System.out.println("Adaptee's specific request");
    }
}

class Adapter implements Target {
    private final Adaptee adaptee;

    public Adapter(Adaptee adaptee) {
        this.adaptee = adaptee;
    }

    public void request() {
        // 适配逻辑：转换接口
        adaptee.specificRequest();
    }
}

// 使用
Target target = new Adapter(new Adaptee());
target.request();

// 列表适配器：把数组适配成 List
interface List<T> {
    T get(int index);
    int size();
    boolean isEmpty();
}

class ArrayToListAdapter<T> implements List<T> {
    private final T[] array;

    @SuppressWarnings("unchecked")
    public ArrayToListAdapter(T[] array) {
        this.array = array;
    }

    public T get(int index) {
        Objects.checkIndex(index, array.length);
        return array[index];
    }

    public int size() {
        return array.length;
    }

    public boolean isEmpty() {
        return array.length == 0;
    }
}

// 使用
String[] arr = {"a", "b", "c"};
List<String> list = new ArrayToListAdapter<>(arr);
list.get(0);  // "a"
list.size();   // 3

// 双向适配器示例
interface LegacyParser {
    String parseOldFormat(String input);
}

interface ModernParser {
    String parseNewFormat(String input);
}

class BiDirectionalAdapter implements LegacyParser, ModernParser {
    private final ModernParser modernParser;
    private final LegacyParser legacyParser;

    public BiDirectionalAdapter(ModernParser modernParser, LegacyParser legacyParser) {
        this.modernParser = modernParser;
        this.legacyParser = legacyParser;
    }

    // LegacyParser → ModernParser
    public String parseOldFormat(String input) {
        String converted = convertOldToNew(input);
        return modernParser.parseNewFormat(converted);
    }

    // ModernParser → LegacyParser
    public String parseNewFormat(String input) {
        String converted = convertNewToOld(input);
        return legacyParser.parseOldFormat(converted);
    }

    private String convertOldToNew(String input) { return input; }  // 简化
    private String convertNewToOld(String input) { return input; }  // 简化
}
```
