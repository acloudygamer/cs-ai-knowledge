# 适配器模式

## 概述

适配器模式将一个类的接口转换成客户端期望的另一个接口，使原本接口不兼容的类可以合作。

### 类型

| 类型 | 说明 |
|------|------|
| 类适配器 | 通过继承实现 |
| 对象适配器 | 通过组合实现 |
| 接口适配器 | 通过抽象类实现 |

### 结构

```
Client (客户端)
    |
    v
Target (目标接口)
    |
    +-- Adapter (适配器)
          |
          v
    Adaptee (被适配者)
```

## 类适配器

### 目标接口

```java
public interface Target {
    void request();
}
```

### 被适配者

```java
public class Adaptee {
    public void specificRequest() {
        System.out.println("Adaptee's specific request");
    }
}
```

### 适配器

```java
public class ClassAdapter extends Adaptee implements Target {
    @Override
    public void request() {
        specificRequest();
    }
}
```

### 使用

```java
Target target = new ClassAdapter();
target.request();
```

## 对象适配器

### 适配器

```java
public class ObjectAdapter implements Target {
    private final Adaptee adaptee;

    public ObjectAdapter(Adaptee adaptee) {
        this.adaptee = adaptee;
    }

    @Override
    public void request() {
        adaptee.specificRequest();
    }
}
```

### 使用

```java
Target target = new ObjectAdapter(new Adaptee());
target.request();
```

## 接口适配器

### 场景

接口方法过多，但只想使用其中几个。

### 接口

```java
public interface AdvancedInterface {
    void method1();
    void method2();
    void method3();
    void method4();
}
```

### 抽象适配器

```java
public abstract class AbstractAdapter implements AdvancedInterface {
    @Override
    public void method1() { }

    @Override
    public void method2() { }

    @Override
    public void method3() { }

    @Override
    public void method4() { }
}
```

### 具体实现

```java
public class ConcreteAdapter extends AbstractAdapter {
    @Override
    public void method2() {
        System.out.println("method2 implemented");
    }

    @Override
    public void method4() {
        System.out.println("method4 implemented");
    }
}
```

## 双向适配器

### 双向接口

```java
public interface MediaPlayer {
    void play(String filename);
}

public interface AdvancedMediaPlayer {
    void playVlc(String filename);
    void playMp4(String filename);
}
```

### 具体播放器

```java
public class VlcPlayer implements AdvancedMediaPlayer {
    @Override
    public void playVlc(String filename) {
        System.out.println("Playing VLC: " + filename);
    }

    @Override
    public void playMp4(String filename) { }
}

public class Mp4Player implements AdvancedMediaPlayer {
    @Override
    public void playVlc(String filename) { }

    @Override
    public void playMp4(String filename) {
        System.out.println("Playing MP4: " + filename);
    }
}
```

### 双向适配器

```java
public class MediaAdapter implements MediaPlayer {
    private AdvancedMediaPlayer advancedPlayer;
    private String filename;

    public MediaAdapter(String filename) {
        this.filename = filename;
        if (filename.endsWith(".vlc")) {
            advancedPlayer = new VlcPlayer();
        } else if (filename.endsWith(".mp4")) {
            advancedPlayer = new Mp4Player();
        }
    }

    @Override
    public void play(String filename) {
        if (filename.endsWith(".vlc")) {
            advancedPlayer.playVlc(filename);
        } else if (filename.endsWith(".mp4")) {
            advancedPlayer.playMp4(filename);
        }
    }
}
```

## Spring 适配器

### HandlerAdapter

```java
public interface HandlerAdapter {
    boolean supports(Object handler);
    ModelAndView handle(HttpServletRequest request,
                         HttpServletResponse response,
                         Object handler) throws Exception;
}

@RequestMapping("/users")
public class UserController {
    @RequestMapping("/list")
    public ModelAndView list() {
        return new ModelAndView("user/list");
    }
}

// DispatcherServlet 使用 HandlerAdapter
HandlerAdapter adapter = new RequestMappingHandlerAdapter();
if (adapter.supports(handler)) {
    adapter.handle(request, response, handler);
}
```

## 数据适配器

### 转换接口

```java
public interface DataConverter<S, T> {
    T convert(S source);
}
```

### 对象转换适配器

```java
public class UserDto {
    private String name;
    private String email;
    private int age;
    // getters, setters
}

public class UserEntity {
    private Long id;
    private String fullName;
    private String emailAddress;
    private int userAge;
    // getters, setters
}

public class UserConverter implements DataConverter<UserDto, UserEntity> {
    @Override
    public UserEntity convert(UserDto source) {
        UserEntity entity = new UserEntity();
        entity.setFullName(source.getName());
        entity.setEmailAddress(source.getEmail());
        entity.setUserAge(source.getAge());
        return entity;
    }
}
```

## REST API 适配器

### 外部 API 适配器

```java
public interface ExternalUserClient {
    ExternalUser getUser(String id);
    List<ExternalUser> getAllUsers();
}

public class RestTemplateUserAdapter implements ExternalUserClient {
    private final RestTemplate restTemplate;

    @Override
    public ExternalUser getUser(String id) {
        return restTemplate.getForObject("/users/{id}", ExternalUser.class, id);
    }

    @Override
    public List<ExternalUser> getAllUsers() {
        return Arrays.asList(
            restTemplate.getForObject("/users", ExternalUser[].class)
        );
    }
}
```

## 适配器 vs 装饰器 vs 代理

| 模式 | 目的 | 接口变化 | 关系 |
|------|------|----------|------|
| 适配器 | 接口转换 | 转换接口 | 包装一个类 |
| 装饰器 | 增强功能 | 保持接口 | 包装一个类 |
| 代理 | 控制访问 | 保持接口 | 持有对象引用 |

### 简单区分

- **适配器**: 让不兼容的变得兼容
- **装饰器**: 让功能变得更强
- **代理**: 控制对对象的访问

## 最佳实践

### 何时使用

- 现有类的接口与系统需求不匹配
- 需要使用若干个已经存在的子类，但不方便继承每个子类添加功能
- 需要统一接口，但有多个版本

### 适配器 vs 门面模式

| 适配器 | 门面模式 |
|--------|----------|
| 转换接口 | 简化接口 |
| 客户端可能感知 | 对客户端隐藏复杂性 |
| 一对一 | 多对一 |

### 注意事项

```java
// 避免：过度适配
public class OverAdaptedService implements
    ServiceA, ServiceB, ServiceC, ServiceD {
    // 违背单一职责
}

// 推荐：职责分离
public class ServiceAAdapter implements ServiceA { }
public class ServiceBAdapter implements ServiceB { }
```

### 对象组合 vs 继承

```java
// 对象适配器（推荐）：更灵活
public class Adapter implements Target {
    private final Adaptee adaptee; // 组合
}

// 类适配器：需要多继承支持
public class Adapter extends Adaptee implements Target { // 多继承
}
```
