# 装饰器模式

## 定义

装饰器模式是一种动态地给对象添加额外职责，通过在对象外包裹装饰器类来增强对象行为，比继承更灵活的 structural 设计模式。

## 数学模型

### 类爆炸的组合数学

设可选功能集合 $F = \{f_1, f_2, \ldots, f_n\}$，每种功能可以开启或关闭：

$$\text{组合数} = 2^n$$

若用继承实现，每种组合需要一个类：
$$|\text{ClassFamily}| = 2^n$$

当 $n=5$ 时，需要 32 个类；$n=10$ 时，需要 1024 个类。

装饰器模式将组合从 **编译时** 移到 **运行时**，只需 $n+1$ 个类（1 个基础类 + $n$ 个装饰器）。

## 机制

### 装饰器的委托机制

装饰器持有被装饰对象的引用（组合而非继承）：
```java
public class Decorator implements Component {
    protected Component wrapped; // 持有被装饰对象

    public Decorator(Component wrapped) {
        this.wrapped = wrapped;
    }

    public String operation() {
        return wrapped.operation(); // 委托给被装饰对象
    }
}

public class LoggingDecorator extends Decorator {
    public LoggingDecorator(Component wrapped) {
        super(wrapped);
    }

    public String operation() {
        System.out.println("Before operation");
        String result = super.operation(); // 调用被装饰对象
        System.out.println("After operation");
        return result;
    }
}
```

**委托链的数学结构**：形成 **责任链（Chain of Responsibility）**：
$$R = D_1 \circ D_2 \circ \cdots \circ D_n \circ B$$
其中 $D_i$ 是装饰器，$B$ 是基础对象。

### 装饰器 vs 代理

| 维度 | 装饰器 | 代理 |
|------|--------|------|
| **意图** | 动态增强功能 | 控制对对象的访问 |
| **接口关系** | 实现相同接口 | 实现相同接口 |
| **组合方式** | 可无限嵌套 | 通常单一代理 |
| **增强时机** | 运行时 | 编译时或运行时 |

装饰器的核心是 **功能增强的组合**，代理的核心是 **访问控制**。

### Java I/O 库的装饰器模式

Java I/O 类库是装饰器模式的经典应用：

```
BufferedInputStream
    └─ FilterInputStream
            └─ InputStream

FileInputStream (被装饰对象)
DataInputStream (装饰器)
BufferedInputStream (装饰器，可嵌套)
GZIPInputStream (装饰器，可嵌套)
```

这允许任意组合：
```java
// 缓冲 + 压缩 + 文件
InputStream in = new BufferedInputStream(
    new GZIPInputStream(
        new FileInputStream("data.gz")
    )
);
```

## 参考存根

```java
// 咖啡订单的装饰器实现
interface Coffee {
    String getDescription();
    double getCost();
}

class SimpleCoffee implements Coffee {
    public String getDescription() { return "Coffee"; }
    public double getCost() { return 2.0; }
}

abstract class CoffeeDecorator implements Coffee {
    protected Coffee decorated;
    public CoffeeDecorator(Coffee coffee) { this.decorated = coffee; }
}

class MilkDecorator extends CoffeeDecorator {
    public MilkDecorator(Coffee coffee) { super(coffee); }
    public String getDescription() {
        return decorated.getDescription() + ", Milk";
    }
    public double getCost() {
        return decorated.getCost() + 0.5;
    }
}

class SugarDecorator extends CoffeeDecorator {
    public SugarDecorator(Coffee coffee) { super(coffee); }
    public String getDescription() {
        return decorated.getDescription() + ", Sugar";
    }
    public double getCost() {
        return decorated.getCost() + 0.2;
    }
}

// 使用
Coffee coffee = new SugarDecorator(
    new MilkDecorator(
        new SimpleCoffee()
    )
);
// 描述：Coffee, Milk, Sugar
// 费用：2.0 + 0.5 + 0.2 = 2.7
```
