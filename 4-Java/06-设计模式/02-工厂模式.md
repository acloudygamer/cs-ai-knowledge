# 工厂模式

## 定义

工厂模式是一种将对象创建逻辑封装到专用类型中，使客户端代码无需了解具体类实现细节的创建型设计模式。

## 数学模型

### 开闭原则的形式化

开闭原则（Open-Closed Principle）：软件实体应对扩展开放，对修改关闭。

设软件实体 $M$（模块/类），扩展操作 $ext$，修改操作 $mod$：
$$\forall ext: M \rightarrow M' \quad \nexists mod: M \rightarrow M''$$

即：扩展 $M$ 后得到 $M'$，不应通过修改 $M$ 本身，而应通过添加新代码实现。

**工厂模式的 OCP 分析**：

若使用简单工厂，新增产品 $P_{new}$ 需要修改工厂类 $F$：
$$F \xrightarrow{mod} F'$$

若使用工厂方法，新增产品 $P_{new}$ 只需新增工厂 $F_{new}$：
$$F_{new} \xrightarrow{ext} \text{FactoryFamily}$$

简单工厂违反 OCP，工厂方法符合 OCP。

### 抽象工厂的产品族兼容性

产品族 $\{P_i\}$ 内各产品必须相互兼容。设产品族 $A$（Windows 风格）和产品族 $B$（Mac 风格）：
$$A = \{Button_A, TextField_A\}$$
$$B = \{Button_B, TextField_B\}$$

抽象工厂保证：同一工厂创建的产品来自同一族。
$$Factory_A.createButton() \in A, \quad Factory_A.createTextField() \in A$$

<pre>
工厂模式对象创建流程
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

简单工厂:
    Client → Factory.create("ConcreteA") → ConcreteA 实例

工厂方法:
    Client → Factory.create() → 子类实现
                          │
                          ▼
                     FactoryA → ConcreteA
                     FactoryB → ConcreteB

抽象工厂:
    Client → Factory.createButton() + Factory.createTextField()
                          │
                          ▼
                    FactoryA → ButtonA + TextFieldA（风格一致）
                    FactoryB → ButtonB + TextFieldB（风格一致）
</pre>

## 机制

### 简单工厂的耦合问题

简单工厂的问题：工厂类与产品类型耦合。违反 OCP 的原因是产品创建逻辑与产品类型数量绑定在同一位置。

```
ProductFamily = {ConcreteProduct1, ConcreteProduct2, ..., ConcreteProductN}
每当 |ProductFamily| 变化时，Factory 必须修改
```

### 工厂方法的扩展性

工厂方法定义创建产品的抽象接口：
```java
interface ProductFactory {
    Product create();
}

class ConcreteFactory implements ProductFactory {
    public Product create() {
        return new ConcreteProduct();
    }
}
```

**扩展时不需要修改现有代码**——只需添加新的工厂子类。这是 **对扩展开放，对修改关闭** 的体现。

### Lambda 工厂的函数式表达

当工厂接口只有一个方法时，可用 `Supplier<T>` 替代：
```java
Map<String, Supplier<Product>> factory = Map.of(
    "A", () -> new ConcreteProductA(),
    "B", () -> new ConcreteProductB()
);

Product p = factory.get(type).get();
```

**数学本质**：工厂从 **类型→对象** 的映射变为 **字符串→工厂函数** 的映射，消除了工厂接口的语法开销。

## 参考存根

```java
// 抽象工厂示例：数据库访问
interface ConnectionFactory {
    Connection createConnection();
    Statement createStatement();
}

class MySQLFactory implements ConnectionFactory {
    public Connection createConnection() {
        return new MySQLConnection();
    }
    public Statement createStatement() {
        return new MySQLStatement();
    }
}

class OracleFactory implements ConnectionFactory {
    public Connection createConnection() {
        return new OracleConnection();
    }
    public Statement createStatement() {
        return new OracleStatement();
    }
}

// 使用
ConnectionFactory factory = new MySQLFactory();
Connection conn = factory.createConnection(); // 始终返回同族产品
Statement stmt = factory.createStatement();
```
