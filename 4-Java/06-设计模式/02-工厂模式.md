# 工厂模式

## 概述

工厂模式将对象创建封装起来，客户端不需要知道具体类的创建细节。

### 类型

| 类型 | 特点 |
|------|------|
| 简单工厂 | 一个工厂创建多种产品 |
| 工厂方法 | 子类决定创建哪个产品 |
| 抽象工厂 | 创建产品族 |

## 简单工厂

### 传统写法

```java
public class ProductFactory {

    public static Product create(String type) {
        return switch (type) {
            case "A" -> new ConcreteProductA();
            case "B" -> new ConcreteProductB();
            default -> throw new IllegalArgumentException("Unknown type: " + type);
        };
    }
}

// 使用
Product product = ProductFactory.create("A");
```

### 改进：静态方法

```java
public class ProductFactory {

    private ProductFactory() { } // 防止实例化

    public static Product createA() {
        return new ConcreteProductA();
    }

    public static Product createB() {
        return new ConcreteProductB();
    }
}
```

**优点**: 简单直观
**缺点**: 违反开闭原则（新增产品需修改工厂）

## 工厂方法模式

### 产品接口

```java
public interface Product {
    void operation();
}
```

### 具体产品

```java
public class ConcreteProductA implements Product {
    @Override
    public void operation() {
        System.out.println("Product A operation");
    }
}

public class ConcreteProductB implements Product {
    @Override
    public void operation() {
        System.out.println("Product B operation");
    }
}
```

### 工厂接口

```java
public interface Factory {
    Product create();
}
```

### 具体工厂

```java
public class FactoryA implements Factory {
    @Override
    public Product create() {
        return new ConcreteProductA();
    }
}

public class FactoryB implements Factory {
    @Override
    public Product create() {
        return new ConcreteProductB();
    }
}
```

### 使用

```java
Factory factory = new FactoryA();
Product product = factory.create();
product.operation();
```

**优点**: 符合开闭原则
**缺点**: 类数量增加

## 抽象工厂模式

### 产品族

```java
// 抽象产品族
public interface Button { void paint(); }
public interface TextField { void paint(); }

// Windows 产品族
public class WindowsButton implements Button {
    @Override
    public void paint() { System.out.println("Windows Button"); }
}

public class WindowsTextField implements TextField {
    @Override
    public void paint() { System.out.println("Windows TextField"); }
}

// Mac 产品族
public class MacButton implements Button {
    @Override
    public void paint() { System.out.println("Mac Button"); }
}

public class MacTextField implements TextField {
    @Override
    public void paint() { System.out.println("Mac TextField"); }
}
```

### 抽象工厂

```java
public interface GUIFactory {
    Button createButton();
    TextField createTextField();
}
```

### 具体工厂

```java
public class WindowsFactory implements GUIFactory {
    @Override
    public Button createButton() {
        return new WindowsButton();
    }

    @Override
    public TextField createTextField() {
        return new WindowsTextField();
    }
}

public class MacFactory implements GUIFactory {
    @Override
    public Button createButton() {
        return new MacButton();
    }

    @Override
    public TextField createTextField() {
        return new MacTextField();
    }
}
```

### 使用

```java
public class Application {
    private final Button button;
    private final TextField textField;

    public Application(GUIFactory factory) {
        button = factory.createButton();
        textField = factory.createTextField();
    }

    public void paint() {
        button.paint();
        textField.paint();
    }
}

// 创建应用
GUIFactory factory = new WindowsFactory();
Application app = new Application(factory);
app.paint();
```

## 反射工厂

### 配置文件

```properties
# config.properties
product.com.example.ProductA=com.example.ConcreteProductA
product.com.example.ProductB=com.example.ConcreteProductB
```

### 反射工厂

```java
public class ReflectiveFactory {

    private static final Map<String, Class<?>> PRODUCT_MAP = new HashMap<>();

    static {
        PRODUCT_MAP.put("A", ConcreteProductA.class);
        PRODUCT_MAP.put("B", ConcreteProductB.class);
    }

    public static Product create(String type) {
        Class<?> clazz = PRODUCT_MAP.get(type);
        if (clazz == null) {
            throw new IllegalArgumentException("Unknown type: " + type);
        }
        try {
            return (Product) clazz.getDeclaredConstructor().newInstance();
        } catch (Exception e) {
            throw new RuntimeException("Failed to create product", e);
        }
    }
}
```

## Spring 工厂

### @Component + @Qualifier

```java
@Component
public class ProductA implements Product {
    @Override
    public void operation() { }
}

@Component
public class ProductB implements Product {
    @Override
    public void operation() { }
}

@Service
public class ProductService {
    private final Product product;

    @Autowired
    public ProductService(@Qualifier("productA") Product product) {
        this.product = product;
    }
}
```

### @Configuration + @Bean

```java
@Configuration
public class FactoryConfig {

    @Bean
    public Product productA() {
        return new ConcreteProductA();
    }

    @Bean
    public Product productB() {
        return new ConcreteProductB();
    }
}
```

### FactoryBean

```java
public class ProductFactoryBean implements FactoryBean<Product> {

    @Override
    public Product getObject() {
        return new ConcreteProductA();
    }

    @Override
    public Class<?> getObjectType() {
        return Product.class;
    }

    @Override
    public boolean isSingleton() {
        return true;
    }
}

@Configuration
public class Config {
    @Bean
    public ProductFactoryBean productFactoryBean() {
        return new ProductFactoryBean();
    }
}
```

## lambda 工厂

### 使用 Lambda

```java
public class LambdaFactory {

    private static final Map<String, Supplier<Product>> PRODUCT_SUPPLIERS = Map.of(
        "A", ConcreteProductA::new,
        "B", ConcreteProductB::new
    );

    public static Product create(String type) {
        Supplier<Product> supplier = PRODUCT_SUPPLIERS.get(type);
        if (supplier == null) {
            throw new IllegalArgumentException("Unknown type: " + type);
        }
        return supplier.get();
    }
}
```

### Spring 中的 Lambda

```java
@Configuration
public class Config {

    @Bean
    @Qualifier("productA")
    public Product productA() {
        return () -> System.out.println("Product A");
    }
}
```

## 最佳实践

### 工厂 vs 构造函数

```java
// 构造函数的问题
new ArrayList(); // 创建列表
new ArrayList(capacity); // 创建有初始容量的列表
// 名称相同，参数不同，客户端可能混淆

// 工厂方法的优势
List.newArrayList();        // 创建空列表
List.newArrayListWithCapacity(10); // 创建有初始容量的列表
List.newArrayListFromCollection(c); // 从已有集合创建
```

### 选择建议

| 场景 | 推荐模式 |
|------|----------|
| 产品类型少，稳定 | 简单工厂 |
| 需要扩展，符合开闭原则 | 工厂方法 |
| 产品族（多个相关产品） | 抽象工厂 |
| 需要延迟加载 | 工厂方法/反射 |

### 避免过度工程

```java
// 过度工程
interface ProductFactory<T extends Product> { ... }

// 适当简单化
class SimpleProductFactory {
    public Product create(String type) { ... }
}
```
