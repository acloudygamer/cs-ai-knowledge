# 策略模式

## 定义

策略模式是一种将一系列算法封装为独立类，使它们可以相互替换，让算法独立于使用它的客户端变化的行为型设计模式。

## 数学模型

### 条件分支的复杂度增长

设业务有 $n$ 种可替换算法。若用 `if-else` 实现：
$$C_{\text{if-else}}(n) = O(n) \quad \text{（判断次数）}$$

每次新增算法必须修改已有代码，违反 OCP。

若用策略模式：
$$C_{\text{strategy}}(n) = O(1) \quad \text{（选择开销）}$$

选择逻辑从 $O(n)$ 降为 $O(1)$，但新增策略类需要新增代码文件。

### 策略组合的代数结构

策略接口构成 **幺半群（Monoid）**：
- **结合律**：$S_1 \circ (S_2 \circ S_3) = (S_1 \circ S_2) \circ S_3$
- **单位元**：空策略（什么都不做）

这在需要组合多个策略的场景（如 Servlet Filter）中尤为重要。

策略模式执行流程

    │
    └─▶ strategy.execute()
             │
             ├─▶ StrategyA (算法 A)
             ├─▶ StrategyB (算法 B)
             └─▶ StrategyC (算法 C)

    context.execute()  // 执行算法 B
</pre>

## 机制

### 策略与状态模式的本质区别

**策略模式**：客户端**外部**决定使用哪个策略，策略之间**互相独立**，可任意替换。

**状态模式**：状态**内部**决定下一个状态，状态之间**有转换关系**，按序切换。

```
状态模式的状态转换：
StateA → StateB（StateA 自己决定转换到 StateB）
StateB → StateC（StateB 自己决定转换到 StateC）

策略模式的策略选择：
Context → StrategyA（由 Context 或客户端决定）
Context → StrategyB（策略之间无转换关系）
```

### Lambda 对策略模式的简化

当策略接口只有一个方法时：
```java
// 策略接口
interface ValidationStrategy<T> {
    boolean validate(T value);
}

// 策略实现
ValidationStrategy<String> emailValidator =
    email -> email.contains("@");

ValidationStrategy<String> lengthValidator =
    email -> email.length() <= 50;

// 使用
List<String> emails = List.of("a@b.com", "invalid");
emails.stream()
    .filter(emailValidator::validate)
    .forEach(System.out::println);
```

**函数式表达**：Lambda 表达式将策略从**类**降级为**函数对象**，减少了语法开销。

## 参考存根

```java
// 支付策略示例
interface PaymentStrategy {
    PaymentResult pay(Order order);
}

class CreditCardPayment implements PaymentStrategy {
    public PaymentResult pay(Order order) {
        // 信用卡支付逻辑
        return new PaymentResult(true, "paid-by-card");
    }
}

class PayPalPayment implements PaymentStrategy {
    public PaymentResult pay(Order order) {
        // PayPal 支付逻辑
        return new PaymentResult(true, "paid-by-paypal");
    }
}

class CryptoPayment implements PaymentStrategy {
    public PaymentResult pay(Order order) {
        // 加密货币支付逻辑
        return new PaymentResult(true, "paid-by-crypto");
    }
}

class PaymentContext {
    private PaymentStrategy strategy;

    public PaymentContext(PaymentStrategy strategy) {
        this.strategy = strategy;
    }

    public void setStrategy(PaymentStrategy strategy) {
        this.strategy = strategy;
    }

    public PaymentResult checkout(Order order) {
        return strategy.pay(order);
    }
}

// 使用
PaymentContext ctx = new PaymentContext(new CreditCardPayment());
ctx.checkout(order);

// 运行时切换策略
ctx.setStrategy(new PayPalPayment());
ctx.checkout(order);
```
