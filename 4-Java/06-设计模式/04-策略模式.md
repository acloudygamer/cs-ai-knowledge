# 策略模式

## 概述

策略模式定义一系列算法，将每个算法封装起来，使它们可以互换。

### 核心思想

- 将可变的算法封装为独立类
- 上下文持有策略引用
- 算法可以自由切换

### 结构

```
Context (上下文)
    |
    v
Strategy (策略接口)
    |
    +---> ConcreteStrategyA
    +---> ConcreteStrategyB
    +---> ConcreteStrategyC
```

## 传统实现

### 策略接口

```java
public interface PaymentStrategy {
    void pay(double amount);
}
```

### 具体策略

```java
public class CreditCardPayment implements PaymentStrategy {
    private final String cardNumber;

    public CreditCardPayment(String cardNumber) {

    @Override

    }
}

public class CryptoPayment implements PaymentStrategy {
    private final String walletAddress;

    public CryptoPayment(String walletAddress) {
        this.walletAddress = walletAddress;

    @Override
```

### 上下文

```java
public class ShoppingCart {
    private final List<Item> items = new ArrayList<>();
    private PaymentStrategy paymentStrategy;

    public void setPaymentStrategy(PaymentStrategy strategy) {
        this.paymentStrategy = strategy;
    }

    public void addItem(Item item) {
        items.add(item);
    }

    public double getTotal() {
        return items.stream().mapToDouble(Item::getPrice).sum();
    }

    public void checkout() {
        if (paymentStrategy == null) {
            throw new IllegalStateException("Please select payment method");
        }
        paymentStrategy.pay(getTotal());
    }
}
```

### 使用

```java
ShoppingCart cart = new ShoppingCart();
cart.addItem(new Item("Book", 29.99));
cart.addItem(new Item("Coffee", 4.99));

cart.setPaymentStrategy(new CreditCardPayment("1234-5678-9012"));
cart.checkout();

cart.setPaymentStrategy(new PayPalPayment("user@email.com"));
cart.checkout();
```

## Lambda 实现

### 函数式策略

```java
@FunctionalInterface
public interface ValidationStrategy {
    boolean execute(String input);
}

// 使用
public class Validator {
    private final ValidationStrategy strategy;

    public Validator(ValidationStrategy strategy) {
        this.strategy = strategy;
    }

    public boolean validate(String input) {
        return strategy.execute(input);
    }
}

// Lambda 实现
Validator emailValidator = new Validator(s -> s.contains("@"));
Validator lengthValidator = new Validator(s -> s.length() > 5);

emailValidator.validate("user@example.com"); // true
lengthValidator.validate("hello"); // true
```

## 策略选择器

### 策略工厂

```java
public class PaymentStrategyFactory {
    private static final Map<String, PaymentStrategy> STRATEGIES = Map.of(
        "credit", new CreditCardPayment("default"),
        "paypal", new PayPalPayment("default@paypal.com"),
        "crypto", new CryptoPayment("defaultWallet")
    );

    public static PaymentStrategy get(String type) {
        PaymentStrategy strategy = STRATEGIES.get(type.toLowerCase());
        if (strategy == null) {
            throw new IllegalArgumentException("Unknown payment type: " + type);
        }
        return strategy;
    }
}

// 使用
ShoppingCart cart = new ShoppingCart();
cart.setPaymentStrategy(PaymentStrategyFactory.get("credit"));
```

### 带参数的工厂

```java
public class PaymentStrategyFactory {

    public static PaymentStrategy createPayPal(String email) {
        return new PayPalPayment(email);
    }

    public static PaymentStrategy createCrypto(String wallet) {
        return new CryptoPayment(wallet);
    }
}
```

## Comparator 作为策略

### 内置策略

```java
List<User> users = List.of(
    new User("Alice", 30),
    new User("Bob", 25),
    new User("Charlie", 35)
);

// 按年龄排序
users.stream()
    .sorted(Comparator.comparingInt(User::getAge))
    .collect(Collectors.toList());

// 按姓名排序
users.stream()
    .sorted(Comparator.comparing(User::getName))
    .collect(Collectors.toList());

// 组合策略
users.stream()
    .sorted(
        Comparator.comparing(User::getName)
            .thenComparingInt(User::getAge)
    )
    .collect(Collectors.toList());

// 降序
users.stream()
    .sorted(Comparator.comparingInt(User::getAge).reversed())
    .collect(Collectors.toList());
```

### 自定义 Comparator

```java
Comparator<User> byNameLength = (u1, u2) ->
    Integer.compare(u1.getName().length(), u2.getName().length());

Comparator<User> byNameAlpha = Comparator.comparing(User::getName);

// 组合
users.stream()
    .sorted(byNameLength.thenComparing(byNameAlpha))
    .collect(Collectors.toList());
```

## Spring 中的策略模式

### @Autowired + List

```java
@Service
public class DiscountService {
    private final List<DiscountStrategy> strategies;

    @Autowired
    public DiscountService(List<DiscountStrategy> strategies) {
        this.strategies = strategies;
    }

    public double applyDiscount(double amount, String customerType) {
        return strategies.stream()
            .filter(s -> s.supports(customerType))
            .findFirst()
            .map(s -> s.apply(amount))
            .orElse(amount);
    }
}

@Component
public class VipDiscount implements DiscountStrategy {
    @Override
    public boolean supports(String customerType) {
        return "VIP".equals(customerType);
    }

    @Override
    public double apply(double amount) {
        return amount * 0.8; // 8折
    }
}

@Component
public class StudentDiscount implements DiscountStrategy {
    @Override
    public boolean supports(String customerType) {
        return "STUDENT".equals(customerType);
    }

    @Override
    public double apply(double amount) {
        return amount * 0.9; // 9折
    }
}
```

### Strategy 接口

```java

    boolean supports(String customerType);
    double apply(double amount);
```

## 注解驱动策略

### 自定义注解

```java
@Target(ElementType.TYPE)
@Retention(RetentionPolicy.RUNTIME)
public @interface DiscountType {
    String value();
}

@Component
@DiscountType("VIP")
public class VipDiscountStrategy implements DiscountStrategy {
    @Override
    public boolean supports(String customerType) {
        return "VIP".equals(customerType);
    }

    @Override
    public double apply(double amount) {
        return amount * 0.8;
    }
}
```

### 策略注册表

```java
@Service
public class DiscountRegistry {
    private final Map<String, DiscountStrategy> strategies = new HashMap<>();

    @Autowired
    public DiscountRegistry(List<DiscountStrategy> strategyList) {
        strategyList.forEach(s -> {
            if (s.getClass().isAnnotationPresent(DiscountType.class)) {
                String type = s.getClass()
                    .getAnnotation(DiscountType.class).value();
                strategies.put(type, s);
            }
        });
    }

    public DiscountStrategy getStrategy(String type) {
        return strategies.get(type);
    }
}
```

## 常见应用场景

### 排序算法

```java
public class Sorter<T> {
    private final Comparator<T> comparator;

    public Sorter(Comparator<T> comparator) {
        this.comparator = comparator;
    }

    public List<T> sort(List<T> list) {
        List<T> sorted = new ArrayList<>(list);
        sorted.sort(comparator);
        return sorted;
    }
}

// 使用
Sorter<Integer> ascSorter = new Sorter<>(Integer::compareTo);
Sorter<Integer> descSorter = new Sorter<>(Comparator.reverseOrder());
```

```java
public class Validator<T> {

// 使用
```

## 策略模式 vs 状态模式

### 区别

| 特征 | 策略模式 | 状态模式 |
|------|----------|----------|
| 意图 | 算法互换 | 状态转换 |
| 数量 | 固定 | 可变 |
| 切换 | 客户端决定 | 自动切换 |
| 依赖 | 聚合 | 聚合 |

### 状态模式示例

```java
// 状态模式：状态决定行为
public class Order {
    private OrderState state;

    public void proceed() {
        state.proceed(this); // 自动切换到下一个状态
    }
}

interface OrderState {
    void proceed(Order order);
    void cancel(Order order);
}
```

## 最佳实践

### 何时使用

- 多种算法/算法变体
- 需要动态选择算法
- 算法可以独立于客户端变化
- 避免大量条件语句

### 优点

- 符合开闭原则
- 消除条件语句
- 算法可复用
- 单元测试容易（每个策略独立测试）

### 缺点

- 增加类和对象数量
- 客户端需要了解策略差异
- 策略间可能产生通信开销
