# 观察者模式

## 概述

观察者模式定义对象间的一对多依赖关系，当一个对象状态改变时，所有依赖它的对象都会收到通知。

### 别名

- 发布-订阅模式（Publish-Subscribe）
- 模型-视图模式（Model-View）

### 结构

```
Subject (主题/被观察者)
    |
    +-- observers: List<Observer>
    |
    +-- attach(Observer)
    +-- detach(Observer)
    +-- notify()

Observer (观察者接口)
    |
    +-- update(Subject)

ConcreteObserverA <|-- Observer
ConcreteObserverB <|-- Observer
```

## 传统实现

### 观察者接口

```java
public interface Observer {
    void update(String message);
}
```

### 具体观察者

```java
public class EmailObserver implements Observer {
    private final String email;

    public EmailObserver(String email) {
        this.email = email;
    }

    @Override
    public void update(String message) {
        System.out.println("Email to " + email + ": " + message);
    }
}

public class SmsObserver implements Observer {
    private final String phone;

    public SmsObserver(String phone) {
        this.phone = phone;
    }

    @Override
    public void update(String message) {
        System.out.println("SMS to " + phone + ": " + message);
    }
}
```

### 主题接口

```java
public interface Subject {
    void attach(Observer observer);
    void detach(Observer observer);
    void notifyObservers();
}
```

### 具体主题

```java
public class NewsPublisher implements Subject {
    private final List<Observer> observers = new ArrayList<>();
    private String latestNews;

    @Override
    public void attach(Observer observer) {
        observers.add(observer);
    }

    @Override
    public void detach(Observer observer) {
        observers.remove(observer);
    }

    @Override
    public void notifyObservers() {
        for (Observer observer : observers) {
            observer.update(latestNews);
        }
    }

    public void setNews(String news) {
        this.latestNews = news;
        notifyObservers();
    }
}
```

### 使用

```java
NewsPublisher publisher = new NewsPublisher();

publisher.attach(new EmailObserver("user1@example.com"));
publisher.attach(new SmsObserver("123-456-7890"));
publisher.attach(new EmailObserver("user2@example.com"));

publisher.setNews("Breaking: Java 21 released!");
// 输出:
// Email to user1@example.com: Breaking: Java 21 released!
// SMS to 123-456-7890: Breaking: Java 21 released!
// Email to user2@example.com: Breaking: Java 21 released!
```

### PropertyChangeSupport

```java
public class NewsAgency {
    private final PropertyChangeSupport support = new PropertyChangeSupport(this);
    private String news;

    public void addObserver(PropertyChangeListener listener) {
        support.addPropertyChangeListener(listener);
    }

    public void removeObserver(PropertyChangeListener listener) {
        support.removePropertyChangeListener(listener);
    }

    public void setNews(String news) {
        String oldNews = this.news;
        this.news = news;
        support.firePropertyChange("news", oldNews, news);
    }
}

// 使用
NewsAgency agency = new NewsAgency();
agency.addObserver(evt ->
    System.out.println("Received: " + evt.getNewValue())
);
```

## Lambda 简化

### 简单场景

```java
public class Subject {
    private final List<Consumer<String>> observers = new ArrayList<>();

    public void observe(Consumer<String> observer) {
        observers.add(observer);
    }

    public void unobserve(Consumer<String> observer) {
        observers.remove(observer);
    }

    public void notify(String message) {
        observers.forEach(o -> o.accept(message));
    }
}

// 使用
Subject subject = new Subject();

subject.observe(msg -> System.out.println("Observer 1: " + msg));
subject.observe(msg -> System.out.println("Observer 2: " + msg));

subject.notify("Hello!");
```

### 带状态的观察者

```java
public class Observer<T> {
    private final Consumer<T> action;
    private T lastValue;
    private boolean initialized = false;

    public Observer(Consumer<T> action) {
        this.action = action;
    }

    public void update(T newValue) {
        if (!initialized || !lastValue.equals(newValue)) {
            lastValue = newValue;
            initialized = true;
            action.accept(newValue);
        }
    }
}
```

## RxJava 响应式

### Observable

```java
Observable<String> observable = Observable.create(emitter -> {
    emitter.onNext("Hello");
    emitter.onNext("World");
    emitter.onComplete();
});

observable.subscribe(
    item -> System.out.println("Received: " + item),
    error -> error.printStackTrace(),
    () -> System.out.println("Completed")
);
```

### Subject 作为通道

```java
// PublishSubject - 只发送订阅后的事件
PublishSubject<String> subject = PublishSubject.create();
subject.subscribe(msg -> System.out.println("A: " + msg));
subject.onNext("Hello");
subject.subscribe(msg -> System.out.println("B: " + msg));
subject.onNext("World");

// 输出:
// A: Hello
// A: World
// B: World

// ReplaySubject - 发送所有历史事件
ReplaySubject<String> replaySubject = ReplaySubject.create();
replaySubject.onNext("Hello");
replaySubject.subscribe(msg -> System.out.println("A: " + msg));
replaySubject.onNext("World");

// 输出:
// A: Hello
// A: World

// BehaviorSubject - 发送最新和后续事件
BehaviorSubject<String> behaviorSubject = BehaviorSubject.createDefault("Default");
behaviorSubject.subscribe(msg -> System.out.println("A: " + msg));
behaviorSubject.onNext("Hello");
behaviorSubject.subscribe(msg -> System.out.println("B: " + msg));

// 输出:
// A: Default
// A: Hello
// B: Hello
```

## 最佳实践

### 线程安全

```java
public class ThreadSafeSubject {
    private final List<Observer> observers = new CopyOnWriteArrayList<>();
    private final ExecutorService executor = Executors.newCachedThreadPool();

    public void addObserver(Observer observer) {
        observers.add(observer);
    }

    public void removeObserver(Observer observer) {
        observers.remove(observer);
    }

    public void notifyObservers(String message) {
        for (Observer observer : observers) {
            executor.submit(() -> observer.update(message));
        }
    }
}
```

### 弱引用观察者

```java
public class WeakSubject {
    private final Set<WeakReference<Observer>> observers =
        Collections.newSetFromMap(new WeakHashMap<>());

    public void subscribe(Observer observer) {
        observers.add(new WeakReference<>(observer));
    }

    public void notifyObservers(String message) {
        observers.removeIf(ref -> ref.get() == null);
        observers.forEach(ref -> {
            Observer observer = ref.get();
            if (observer != null) {
                observer.update(message);
            }
        });
    }
}
```

### 订阅管理

```java
public class Subscribable {
    private final CopyOnWriteArrayList<Subscription> subscriptions = new CopyOnWriteArrayList<>();

    public Subscription subscribe(Observer observer) {
        observers.add(observer);
        return () -> observers.remove(observer);
    }

    public void unsubscribe(Subscription subscription) {
        subscription.cancel();
    }

    public void notifyObservers(String message) {
        observers.forEach(o -> o.update(message));
    }

    @FunctionalInterface
    public interface Subscription {
        void cancel();
    }
}

// 使用
Subscription sub = subscribable.subscribe(msg -> System.out.println(msg));
// 稍后取消订阅
sub.cancel();
```

### 避免内存泄漏

```java
public class SelfUnsubscribingSubject {
    private final List<Observer> observers = new ArrayList<>();
    private final List<Observer> toRemove = new ArrayList<>();

    public void addObserver(Observer observer) {
        observers.add(observer);
    }

    public void notifyObservers(String message) {
        for (Observer observer : observers) {
            try {
                observer.update(message);
            } catch (Exception e) {
                toRemove.add(observer);
            }
        }
        observers.removeAll(toRemove);
        toRemove.clear();
    }
}
```
