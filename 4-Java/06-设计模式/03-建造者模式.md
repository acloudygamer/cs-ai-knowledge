# 建造者模式

## 概述

建造者模式将复杂对象的构建与表示分离，相同的构建过程可以创建不同的表示。

### 适用场景

- 构造参数过多（超过 4 个）
- 参数可选性强
- 对象创建步骤固定但可配置
- 不可变对象创建

## 传统建造者

### 产品类

```java
public class User {
    private final String firstName;  // 必填
    private final String lastName;   // 必填
    private final int age;          // 可选
    private final String phone;     // 可选
    private final String address;   // 可选

    private User(Builder builder) {
        this.firstName = builder.firstName;
        this.lastName = builder.lastName;
        this.age = builder.age;
        this.phone = builder.phone;
        this.address = builder.address;
    }
}
```

### 建造者

```java
public class User {
    // ... 字段和构造函数 ...

    public static class Builder {
        // 必填字段
        private final String firstName;
        private final String lastName;

        // 可选字段，使用默认值
        private int age = 0;
        private String phone = "";
        private String address = "";

        public Builder(String firstName, String lastName) {
            this.firstName = firstName;
            this.lastName = lastName;
        }

        public Builder age(int age) {
            this.age = age;
            return this;
        }

        public Builder phone(String phone) {
            this.phone = phone;
            return this;
        }

        public Builder address(String address) {
            this.address = address;
            return this;
        }

        public User build() {
            return new User(this);
        }
    }
}
```

### 使用

```java
User user = new User.Builder("John", "Doe")
    .age(30)
    .phone("123-456-7890")
    .address("123 Main St")
    .build();
```

## 链式调用

### Fluent Interface

```java
public class Query {
    private String table;
    private List<String> columns = new ArrayList<>();
    private String where;
    private String orderBy;
    private int limit;

    public static Query builder() {
        return new Query();
    }

    public Query from(String table) {
        this.table = table;
        return this;
    }

    public Query select(String... columns) {
        this.columns.addAll(Arrays.asList(columns));
        return this;
    }

    public Query where(String condition) {
        this.where = condition;
        return this;
    }

    public Query orderBy(String column) {
        this.orderBy = column;
        return this;
    }

    public Query limit(int n) {
        this.limit = n;
        return this;
    }

    public String build() {
        StringBuilder sb = new StringBuilder();
        sb.append("SELECT ");
        sb.append(columns.isEmpty() ? "*" : String.join(", ", columns));
        sb.append(" FROM ").append(table);
        if (where != null) sb.append(" WHERE ").append(where);
        if (orderBy != null) sb.append(" ORDER BY ").append(orderBy);
        if (limit > 0) sb.append(" LIMIT ").append(limit);
        return sb.toString();
    }
}
```

### 使用

```java
String sql = Query.builder()
    .select("id", "name", "email")
    .from("users")
    .where("age > 18")
    .orderBy("name")
    .limit(10)
    .build();

// SELECT id, name, email FROM users WHERE age > 18 ORDER BY name LIMIT 10
```

## 验证与约束

### build() 验证

```java
public class User {
    private final String firstName;
    private final String lastName;
    private final int age;

    public static class Builder {
        private final String firstName;
        private final String lastName;
        private int age = 0;

        public Builder(String firstName, String lastName) {
            if (firstName == null || firstName.isBlank()) {
                throw new IllegalArgumentException("firstName is required");
            }
            if (lastName == null || lastName.isBlank()) {
                throw new IllegalArgumentException("lastName is required");
            }
            this.firstName = firstName;
            this.lastName = lastName;
        }

        public Builder age(int age) {
            if (age < 0 || age > 150) {
                throw new IllegalArgumentException("Invalid age");
            }
            this.age = age;
            return this;
        }

        public User build() {
            return new User(this);
        }
    }
}
```

### 自定义验证器

```java
public User build() {
    if (email != null && !email.contains("@")) {
        throw new IllegalStateException("Invalid email: " + email);
    }
    return new User(this);
}
```

## 复杂对象构建

### 嵌套建造者

```java
public class Order {
    private final String orderId;
    private final Customer customer;
    private final List<OrderItem> items;
    private final Address shippingAddress;

    public static class Builder {
        private final String orderId;
        private Customer.Builder customerBuilder;
        private List<OrderItem> items = new ArrayList<>();
        private Address.Builder addressBuilder;

        public Builder(String orderId) {
            this.orderId = orderId;
        }

        public Builder customer(String firstName, String lastName) {
            this.customerBuilder = new Customer.Builder(firstName, lastName);
            return this;
        }

        public Builder address(String street, String city) {
            this.addressBuilder = new Address.Builder(street, city);
            return this;
        }

        public Builder addItem(String productName, int quantity) {
            this.items.add(new OrderItem(productName, quantity));
            return this;
        }

        public Order build() {
            Customer customer = customerBuilder.build();
            Address address = addressBuilder.build();
            return new Order(this, customer, address);
        }
    }
}
```

### 使用

```java
Order order = new Order.Builder("ORD-001")
    .customer("John", "Doe")
    .address("123 Main St", "New York")
    .addItem("Widget", 2)
    .addItem("Gadget", 1)
    .build();
```

## 复制构建

### with 方法

```java
@Builder
public class User {
    private final String firstName;
    private final String lastName;
    private final int age;

    public User with(String firstName, String lastName, int age) {
        return new User(firstName, lastName, age);
    }

    // 更实用的方式
    public User withAge(int newAge) {
        return User.builder()
            .firstName(this.firstName)
            .lastName(this.lastName)
            .age(newAge)
            .build();
    }
}
```

## Lombok 高级用法

### 自定义Setter

```java
@Builder
public class User {
    @Builder.Default
    private String name = "Anonymous";

    private String email;
    private int age;
}
```

### toBuilder

```java
@Builder(toBuilder = true)
public class User {
    private String name;
    private int age;
}

// 使用 toBuilder
User user = User.builder()
    .name("John")
    .age(30)
    .build();

User modified = user.toBuilder()
    .age(31)
    .build();
```

### Singular

```java
@Builder
public class User {
    private String name;

    @Singular
    private List<String> hobbies;
}

// 使用
User user = User.builder()
    .name("John")
    .hobby("Reading")  // 不是 hobbies
    .hobby("Gaming")
    .build();
```

## 建造者 vs 构造函数

### 参数少时

```java
// 构造函数 OK
new User("John", "Doe");

// 建造者过于繁琐
User.builder().firstName("John").lastName("Doe").build();
```

### 参数多时

```java
// 构造函数参数顺序难记
new User("John", "Doe", 30, "123-456", "address", true, false, ...);

// 建造者清晰
User.builder()
    .firstName("John")
    .lastName("Doe")
    .age(30)
    .phone("123-456")
    .address("address")
    .active(true)
    .verified(false)
    .build();
```

## 最佳实践

| 场景 | 建议 |
|------|------|
| 参数 <= 3 | 构造函数足够 |
| 参数 4-6 | 考虑建造者 |
| 参数 > 6 | 强烈推荐建造者 |
| 不可变对象 | 建造者必须 |
| 可选参数多 | 建造者必须 |

### 命名规范

```java
// Lombok 风格
User.builder().firstName("John").lastName("Doe").build();

// 传统风格
new User.Builder("John", "Doe").build();

// Fluent 风格
Query.builder().from("users").build();
```
