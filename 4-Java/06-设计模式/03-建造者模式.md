# 建造者模式

## 定义

建造者模式是一种将复杂对象的构建过程与其表示分离，使相同的构建过程可以创建不同表示的对象创建型设计模式。

## 数学模型

### 参数空间的分解

设复杂对象 $O$ 有 $n$ 个构造参数 $P = \{p_1, p_2, \ldots, p_n\}$，参数空间大小为 $|P|$。

**问题**：若直接通过构造函数创建，需要 $|P|!$ 种构造函数重载（telescoping constructor）。

**解决**：将参数空间分解为必填子集 $R \subset P$ 和可选子集 $O = P \setminus R$：
$$P = R \cup O, \quad R \cap O = \varnothing$$

必填参数在 Builder 构造时传入，可选参数通过方法链设置：
$$\text{Builder}(R) \xrightarrow{O_1} \text{Builder} \xrightarrow{O_2} \cdots \xrightarrow{O_k} \text{build()}$$

### build() 的约束验证

build() 方法执行参数验证，确保对象处于有效状态。设约束函数 $C: P \rightarrow \{\text{true}, \text{false}\}$：

$$\forall p \in P: C(p) = \text{true} \iff O \text{ 是有效对象}$$

若验证失败，抛出 `IllegalStateException`——这是 **防御性编程** 的体现。

<pre>
User.builder() 创建流程

User.builder()
    │
    ├─ new UserBuilder("John", "Doe") ← 必填参数，构造时验证
    │
    ├─ .age(30)  → builder.age = 30
    ├─ .email("a@b.com") → builder.email = "a@b.com"
    └─ .build()
           │
           ├─ 验证：age >= 0, email matches regex
           ├─ new User(builder)  ← 构造函数
           └─ 返回不可变 User
</pre>

## 机制

### 链式调用的接口设计

每个 setter 方法返回 `this`：
```java
public class UserBuilder {
    private String firstName;
    private String lastName;

    public UserBuilder firstName(String firstName) {
        this.firstName = firstName;
        return this; // 返回 this 实现链式调用
    }

    public UserBuilder lastName(String lastName) {
        this.lastName = lastName;
        return this;
    }

    public User build() {
        return new User(this);
    }
}
```

**方法链（Method Chaining）** 的本质是 **流畅接口（Fluent Interface）**，通过返回 `this` 实现调用链。

### 不可变对象的构建

Builder 模式允许创建 **不可变对象**：
```java
public final class User {
    private final String firstName;
    private final String lastName;
    private final int age;

    private User(Builder builder) {
        this.firstName = builder.firstName;
        this.lastName = builder.lastName;
        this.age = builder.age;
    }
}
```

对象在 `build()` 时才创建，一旦创建，所有字段不可变——`final` 修饰符保证这一点。

### Lombok @Builder 的编译器处理

Lombok 在编译时自动生成 `UserBuilder` 类：
```java
@Builder
public class User {
    private final String firstName;
    private final String lastName;
    private final int age;
}
```

编译后等价于手写的 Builder 类。这本质上是 **编译时元编程（Compile-time Metaprogramming）**。

## 参考存根

```java
// 展示必填/可选分离的 Builder 实现
public class HttpRequest {
    private final String url;          // 必填
    private final String method;       // 必填
    private final Map<String, String> headers; // 可选
    private final String body;         // 可选
    private final Duration timeout;   // 可选

    private HttpRequest(Builder builder) {
        this.url = builder.url;
        this.method = builder.method;
        this.headers = Collections.unmodifiableMap(builder.headers);
        this.body = builder.body;
        this.timeout = builder.timeout;
    }

    public static Builder builder(String url, String method) {
        return new Builder(url, method);
    }

    public static class Builder {
        private final String url;
        private final String method;
        private Map<String, String> headers = new HashMap<>();
        private String body;
        private Duration timeout = Duration.ofSeconds(30);

        Builder(String url, String method) {
            Objects.requireNonNull(url);
            Objects.requireNonNull(method);
            this.url = url;
            this.method = method;
        }

        public Builder header(String key, String value) {
            this.headers.put(key, value);
            return this;
        }

        public Builder body(String body) {
            this.body = body;
            return this;
        }

        public Builder timeout(Duration timeout) {
            this.timeout = timeout;
            return this;
        }

        public HttpRequest build() {
            return new HttpRequest(this);
        }
    }
}

// 使用
HttpRequest req = HttpRequest.builder("https://api.example.com", "POST")
    .header("Content-Type", "application/json")
    .body("{\"name\":\"Alice\"}")
    .timeout(Duration.ofSeconds(5))
    .build();
```
