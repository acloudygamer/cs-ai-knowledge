# 建造者模式

## 定义

建造者模式是一种将复杂对象的构建过程与其表示分离，使相同的构建过程可以创建不同表示的对象创建型设计模式。其本质是**参数空间的正交分解**——将必填参数与可选参数分离，通过链式调用组合可选参数的取值空间。

## 数学模型

### 参数空间的分解

设复杂对象 $O$ 有 $n$ 个构造参数 $P = \{p_1, p_2, \ldots, p_n\}$，参数空间大小为 $|P|$。

**问题**：若直接通过构造函数创建，需要枚举所有参数组合：

$$\text{构造函数变体数} = \sum_{k=0}^{n} \binom{n}{k} = 2^n$$

当 $n=10$ 时，需要 1024 种构造函数变体——这称为**构造函数膨胀（Constructor Telescoping）**。

**解决**：将参数空间分解为必填子集 $R \subset P$ 和可选子集 $O = P \setminus R$：
$$P = R \cup O, \quad R \cap O = \varnothing$$

必填参数在 Builder 构造时传入，可选参数通过方法链设置：
$$\text{Builder}(R) \xrightarrow{o_1} \text{Builder} \xrightarrow{o_2} \cdots \xrightarrow{o_k} \text{build()}$$

### build() 的约束验证

`build()` 方法执行参数验证，确保对象处于有效状态。设约束函数 $C: P \rightarrow \{\text{true}, \text{false}\}$：

$$\forall p \in P: C(p) = \text{true} \iff O \text{ 是有效对象}$$

若验证失败，抛出 `IllegalStateException`——这是**防御性编程**的体现。

**典型约束**：
- 数值范围：`age >= 0`
- 格式校验：`email.matches("^[\\w.-]+@[\\w.-]+\\.[a-zA-Z]{2,}$")`
- 互斥条件：若设置了 `shippingAddress`，则 `digitalDelivery` 必须为 false

### 链式调用的组合数学

设可选参数集合 $O = \{o_1, o_2, \ldots, o_k\}$，每个可选参数可设置或不设置：

$$\text{可构建对象数} = 2^k$$

例如，3 个可选参数可构建 $2^3 = 8$ 种不同配置的对象。

**Java 17 增强**：使用 `Objects.requireNonNullElse` 简化空值处理：
```java
public Builder email(String email) {
    this.email = Objects.requireNonNullElse(email, "default@example.com");
    return this;
}
```

## 机制

### 链式调用的接口设计

每个 setter 方法返回 `this`，实现方法链：

```java
public class UserBuilder {
    private String firstName;
    private String lastName;

    public UserBuilder firstName(String firstName) {
        this.firstName = firstName;
        return this;  // 返回 this 实现链式调用
    }

    public UserBuilder lastName(String lastName) {
        this.lastName = lastName;
        return this;
    }

    public User build() {
        return new User(this);
    }
}
```

**方法链（Method Chaining）**的本质是**流畅接口（Fluent Interface）**，通过返回 `this` 实现调用链，使代码更具可读性。

### 不可变对象的构建

Builder 模式允许创建**不可变对象**：

```java
public final class User {
    private final String firstName;  // final 字段
    private final String lastName;
    private final int age;

    private User(Builder builder) {  // private 构造函数
        this.firstName = builder.firstName;  // 复制而非引用
        this.lastName = builder.lastName;
        this.age = builder.age;
    }
}
```

**不可变性的三层保障**：
1. **字段 final**：构造后不可修改
2. **无 setter**：外部无法修改字段
3. **类 final**：防止子类破坏不变量

### Lombok @Builder 的编译器处理

Lombok 在编译时自动生成 `UserBuilder` 类：

```java
@Builder
public class User {
    private final String firstName;
    private final String lastName;
    private final int age;
}
```

编译后等价于手写的 Builder 类。这是**编译时元编程（Compile-time Metaprogramming）**。

**@Builder 的隐式行为**：
- 生成 `UserBuilder` 类
- 生成 `UserBuilder(String firstName, String lastName, int age)` 构造函数（所有参数）
- 生成 `UserBuilder.firstName(String)` 等链式方法
- 生成 `UserBuilder.build()` 方法

### 嵌套对象的 Builder 模式

当对象包含嵌套对象时，嵌套 Builder 委托构建子对象：

```java
public class Order {
    private final Customer customer;  // 嵌套对象
    private final List<Item> items;

    public static class Builder {
        private Customer.Builder customerBuilder = new Customer.Builder();
        private List<Item> items = new ArrayList<>();

        public Builder customer(Customer.Builder builder) {
            this.customerBuilder = builder;
            return this;
        }

        public Builder addItem(Item item) {
            this.items.add(item);
            return this;
        }

        public Order build() {
            return new Order(customerBuilder.build(), List.copyOf(items));
        }
    }
}
```

### Java 17 文本块与建造者模式

对于包含大段文本的对象（如 SQL、JSON），可结合文本块简化：

```java
public class SqlQuery {
    private final String sql;
    private final Map<String, Object> params;

    public static class Builder {
        private String sql;
        private Map<String, Object> params = new HashMap<>();

        public Builder sql(String sql) {
            this.sql = sql;  // 可使用 """ 文本块
            return this;
        }

        public Builder param(String key, Object value) {
            this.params.put(key, value);
            return this;
        }

        public SqlQuery build() {
            return new SqlQuery(this);
        }
    }
}

// 使用
SqlQuery query = SqlQuery.builder("""
    SELECT * FROM users WHERE id = :id
    """)
    .param("id", 1)
    .build();
```

## 参考存根

```java
// 必填/可选分离的完整 Builder 实现（Java 17）
public class HttpRequest {
    private final String url;           // 必填
    private final String method;       // 必填
    private final Map<String, String> headers;  // 可选
    private final String body;          // 可选
    private final Duration timeout;    // 可选

    private HttpRequest(Builder builder) {
        this.url = builder.url;
        this.method = builder.method;
        this.headers = Collections.unmodifiableMap(builder.headers);
        this.body = builder.body;
        this.timeout = builder.timeout;
    }

    public static Builder builder(String url, String method) {
        return new Builder(url, method);
    }

    public static class Builder {
        private final String url;
        private final String method;
        private Map<String, String> headers = new HashMap<>();
        private String body;
        private Duration timeout = Duration.ofSeconds(30);

        Builder(String url, String method) {
            this.url = Objects.requireNonNull(url);
            this.method = Objects.requireNonNull(method);
        }

        public Builder header(String key, String value) {
            this.headers.put(key, value);
            return this;
        }

        public Builder body(String body) {
            this.body = body;
            return this;
        }

        public Builder timeout(Duration timeout) {
            this.timeout = Objects.requireNonNull(timeout);
            return this;
        }

        public HttpRequest build() {
            return new HttpRequest(this);
        }
    }
}

// 使用
HttpRequest req = HttpRequest.builder("https://api.example.com", "POST")
    .header("Content-Type", "application/json")
    .header("Authorization", "Bearer token")
    .body("""
        {"name":"Alice"}
        """)
    .timeout(Duration.ofSeconds(5))
    .build();
```
