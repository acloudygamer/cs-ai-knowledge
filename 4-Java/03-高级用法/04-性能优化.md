# 性能优化

## JVM 调优参数

### 堆内存设置

```bash
# 初始堆大小和最大堆大小
-Xms2g          # 初始堆大小为 2GB
-Xmx2g          # 最大堆大小为 2GB
-Xms256m -Xmx256m  # 最小化配置

# 推荐：将 -Xms 和 -Xmx 设置为相同值，避免动态调整带来的开销
-Xms4g -Xmx4g
```

### 新生代/老年代比例

```bash
# NewRatio=2 表示 老年代:新生代 = 2:1
-XX:NewRatio=2

# 也可以直接设置新生代大小
-Xmn512m        # 设置新生代为 512MB
```

### 垃圾收集器选择

```bash
# G1 收集器（推荐用于大堆应用）
-XX:+UseG1GC
-XX:MaxGCPauseMillis=200    # 最大 GC 停顿时间目标

# ZGC（低延迟，大堆）
-XX:+UseZGC
-XX:+ZGenerational   # ZGC 分代支持

# Shenandoah
-XX:+UseShenandoahGC

# 串行 GC（单线程，适用于小内存）
-XX:+UseSerialGC

# 并行 GC（吞吐量优先）
-XX:+UseParallelGC
```

### 其他常用参数

```bash
# 元空间大小
-XX:MetaspaceSize=256m
-XX:MaxMetaspaceSize=512m

# 线程堆栈大小
-Xss1m           # 1MB 线程堆栈

# GC 日志
-Xlog:gc*:file=gc.log:time,uptime
-XX:+PrintGCDetails
-XX:+PrintGCDateStamps

# OOM 时导出堆转储
-XX:+HeapDumpOnOutOfMemoryError
-XX:HeapDumpPath=/var/log/java/
```

## 代码层面优化

### 减少对象创建

```java
// 错误：在循环中创建对象
for (int i = 0; i < 1000; i++) {
    String s = new String("hello");  // 每次循环创建新对象
}

// 正确：将不变对象提到循环外
String s = "hello";
for (int i = 0; i < 1000; i++) {
    // 使用 s
}

// 正确：使用 StringBuilder
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 1000; i++) {
    sb.append("hello");
}
String result = sb.toString();
```

### 避免自动装箱/拆箱

```java
// 错误：大量自动装箱
List<Integer> list = new ArrayList<>();
for (int i = 0; i < 10000; i++) {
    list.add(i);  // int -> Integer 自动装箱
}

// 正确：使用基本类型集合（Java 10+ 支持）
IntList list = new IntArrayList();
for (int i = 0; i < 10000; i++) {
    list.add(i);  // 无装箱
}

// 或者使用 Stream 的 mapToInt
int sum = list.stream().mapToInt(Integer::intValue).sum();
```

### 合理使用集合

```java
// 预分配容量，减少扩容开销
ArrayList<String> list = new ArrayList<>(1000);  // 预分配 1000 容量

// HashMap 预分配
HashMap<String, Object> map = new HashMap<>(expectedSize * 2);

// 使用 EnumSet/EnumMap 处理枚举键
enum Color { RED, GREEN, BLUE }
EnumMap<Color, String> enumMap = new EnumMap<>(Color.class);
```

### String 优化

```java
// StringBuilder 拼接（避免 String 频繁拼接）
StringBuilder sb = new StringBuilder();
for (String item : items) {
    sb.append(item).append(",");
}
String result = sb.toString();

// StringJoiner（Java 8+）
String result = String.join(",", items);

// 字符串字面量使用
String s1 = "hello";          // 推荐：使用字符串池
String s2 = new String("hello");  // 不推荐：每次创建新对象

// 字符串 intern
String s1 = new String("hello");
String s2 = s1.intern();     // s2 指向字符串池中的 "hello"
```

### 避免反射调用

```java
// 反射调用开销大
Method method = clazz.getMethod("methodName");
method.invoke(target, args);  // 反射调用

// 正确：使用方法引用
Function<T, R> function = target::methodName;  // 更快

// 或者使用 Map 缓存方法引用
private static final Map<String, Function<T, R>> HANDLERS = Map.of(
    "action1", MyClass::handleAction1,
    "action2", MyClass::handleAction2
);
```

## 并发优化

### 使用线程池

```java
// 推荐：使用 ThreadPoolExecutor 而非直接 new Thread
ExecutorService executor = new ThreadPoolExecutor(
    corePoolSize,          // 核心线程数
    maxPoolSize,           // 最大线程数
    keepAliveTime,        // 空闲线程存活时间
    TimeUnit.SECONDS,
    new LinkedBlockingQueue<>(queueSize),  // 任务队列
    Executors.defaultThreadFactory(),
    new ThreadPoolExecutor.CallerRunsPolicy()  // 拒绝策略
);

// 常用线程池创建
ExecutorService fixedPool = Executors.newFixedThreadPool(4);
ExecutorService cachedPool = Executors.newCachedThreadPool();
ScheduledExecutorService scheduledPool = Executors.newScheduledThreadPool(2);
```

### 减少锁竞争

```java
// 错误：锁粒度过大
synchronized (this) {
    count++;
    list.add(item);
    map.put(key, value);
}

// 正确：分离锁
synchronized (countLock) {
    count++;
}
synchronized (listLock) {
    list.add(item);
}
synchronized (mapLock) {
    map.put(key, value);
}

// 更好的方式：使用 ConcurrentHashMap
ConcurrentHashMap<String, Object> map = new ConcurrentHashMap<>();
map.put(key, value);  // 内部分段锁
```

### 使用 volatile 和原子类

```java
// volatile: 可见性，但不保证原子性
private volatile boolean running = true;

// 原子类：保证原子性
private AtomicInteger count = new AtomicInteger(0);
count.incrementAndGet();  // 线程安全

// LongAdder（高并发下比 AtomicLong 性能更好）
private LongAdder sum = new LongAdder();
sum.add(1);
```

## 内存优化

### 减少内存占用

```java
// 使用基本类型数组而非包装类型集合
int[] intArray = new int[1000];  // 比 Integer[] 更省内存

// 及时清理大对象引用
List<byte[]> buffer = new ArrayList<>();
try {
    buffer.add(new byte[1024 * 1024]);
} finally {
    buffer.clear();  // 及时清理
}

// 使用软引用/弱引用
SoftReference<byte[]> ref = new SoftReference<>(data);
WeakReference<Object> weakRef = new WeakReference<>(object);
```

### 对象池

```java
// 复用昂贵对象
import org.apache.commons.pool2.ObjectPool;
import org.apache.commons.pool2.impl.GenericObjectPool;

// 使用 ThreadLocal 复用线程局部对象
ThreadLocal<SimpleDateFormat> dateFormat =
    ThreadLocal.withInitial(() -> new SimpleDateFormat("yyyy-MM-dd"));
```

## 数据库优化（JDBC）

```java
// 使用批量操作
String sql = "INSERT INTO users (name, email) VALUES (?, ?)";
try (PreparedStatement ps = connection.prepareStatement(sql)) {
    for (User user : users) {
        ps.setString(1, user.getName());
        ps.setString(2, user.getEmail());
        ps.addBatch();  // 添加到批处理
    }
    ps.executeBatch();  // 一次性执行
}

// 使用连接池
HikariCPConfig config = new HikariCPConfig();
config.setJdbcUrl("jdbc:mysql://localhost:3306/mydb");
config.setMaximumPoolSize(20);
config.setMinimumIdle(5);
config.setConnectionTimeout(30000);
HikariDataSource ds = new HikariDataSource(config);
```
