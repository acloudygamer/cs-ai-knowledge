# 安全编码实践

## 概述

安全编码是防止常见安全漏洞的关键实践。本章涵盖 Java 开发中最重要的安全问题及解决方案。

### OWASP Top 10（Web 安全）

```
1. 注入（SQL Injection）
2. 失效的身份认证
3. 敏感数据泄露
4. XML 外部实体（XXE）
5. 失效的访问控制
6. 安全配置错误
7. 跨站脚本（XSS）
8. 跨站请求伪造（CSRF）
9. 使用已知漏洞的组件
10. 不足的日志记录
```

## SQL 注入

### 问题代码

```java
// 危险：直接拼接 SQL
String query = "SELECT * FROM users WHERE name = '" + username + "'";
Statement stmt = connection.createStatement();
ResultSet rs = stmt.executeQuery(query);  // 可能被注入
```

### 解决方案 1：PreparedStatement

```java
// 使用参数化查询
String query = "SELECT * FROM users WHERE name = ?";
PreparedStatement ps = connection.prepareStatement(query);
ps.setString(1, username);
ResultSet rs = ps.executeQuery();
```

### 解决方案 2：JPA

```java
// JPA 参数化查询
@Query("SELECT u FROM User u WHERE u.username = :username")
Optional<User> findByUsername(@Param("username") String username);
```

### 解决方案 3：MyBatis

```xml
<!-- 使用参数 #{} 而非 ${} -->
<select id="findByUsername" resultMap="UserResultMap">
    SELECT * FROM users WHERE username = #{username}
</select>

<!-- 危险：使用 ${} 直接拼接 -->
<!-- SELECT * FROM users WHERE username = '${username}' -->
```

## XSS（跨站脚本攻击）

### 问题代码

```java
// 危险：直接输出用户输入
response.getWriter().write("<div>" + userInput + "</div>");
```

### 解决方案 1：输出编码

```java
// HTML 编码
import org.owasp.encoder.Encode;

String safeOutput = Encode.forHtml(userInput);

```

### 解决方案 2：Spring Security

```java
@Configuration
@EnableWebSecurity
public class SecurityConfig {
    
    @Bean
    public SecurityFilterChain filterChain(HttpSecurity http) throws Exception {
        http
            .csrf(csrf -> csrf
                .csrfTokenRepository(CookieCsrfTokenRepository.withHttpOnlyFalse())
            )
            .headers(headers -> headers
                .contentSecurityPolicy(csp -> csp
                    .policyDirectives("script-src 'self'")
                )
            );
        
        return http.build();
    }
}
```


## CSRF（跨站请求伪造）

### 问题

```
攻击者网页：
<form action="https://bank.com/transfer">
    <input name="to" value="hacker"/>
    <input name="amount" value="10000"/>
</form>
<script>document.forms[0].submit();</script>
```

### 解决方案 1：CSRF Token

```java
@Configuration
@EnableWebSecurity
public class SecurityConfig {
    
    @Bean
    public SecurityFilterChain filterChain(HttpSecurity http) throws Exception {
        http
            .csrf(csrf -> csrf
                .csrfTokenRepository(CookieCsrfTokenRepository.withHttpOnlyFalse())
                .ignoringRequestMatchers("/api/public/**")  // 公共 API 禁用
            );
        
        return http.build();
    }
}
```

```html
<!-- 表单提交包含 CSRF Token -->
<form method="POST" action="/api/user">
    <input type="hidden" name="_csrf" value="${_csrf.token}"/>
    <!-- 其他字段 -->
</form>
```

### 解决方案 2：SameSite Cookie

```java
// Spring Boot 2.6+
server:
  servlet:
    session:
      cookie:
        same-site: strict  # 严格模式
        # same-site: lax   # 宽松模式
```

## 敏感数据处理

### 密码存储

```java
// 错误：明文存储
user.setPassword(password);

// 错误：MD5/SHA-1（已破解）
user.setPassword(hash(password));

// 正确：BCrypt
@Service
public class PasswordService {
    
    @Autowired
    private PasswordEncoder passwordEncoder;
    
    public void encodePassword(User user) {
        user.setPassword(passwordEncoder.encode(user.getPassword()));
    }
    
    public boolean matches(String rawPassword, String encodedPassword) {
        return passwordEncoder.matches(rawPassword, encodedPassword);
    }
}

@Configuration
@EnableWebSecurity
public class SecurityConfig {
    
    @Bean
    public PasswordEncoder passwordEncoder() {
        // BCrypt（推荐）
        return new BCryptPasswordEncoder();
        
        // Argon2（更安全但需要额外库）
        // return Argon2PasswordEncoder.defaultsForSpringSecurity_v5_8();
        
        // SCrypt
        // return SCryptPasswordEncoder.defaultsForSpringSecurity_v5_8();
    }
}
```

### 敏感数据加密

```java
// 使用 AES 加密敏感数据
@Service
public class EncryptionService {
    
    private static final String ALGORITHM = "AES/GCM/NoPadding";
    private static final int GCM_TAG_LENGTH = 128;
    private static final int GCM_IV_LENGTH = 12;
    
    @Value("${encryption.key}")
    private byte[] secretKey;  // 32 字节密钥
    
    public String encrypt(String plaintext) {
        byte[] iv = new byte[GCM_IV_LENGTH];
        new SecureRandom().nextBytes(iv);
        
        Cipher cipher = Cipher.getInstance(ALGORITHM);
        GCMParameterSpec parameterSpec = new GCMParameterSpec(GCM_TAG_LENGTH, iv);
        cipher.init(Cipher.ENCRYPT_MODE, new SecretKeySpec(secretKey, "AES"), parameterSpec);
        
        byte[] ciphertext = cipher.doFinal(plaintext.getBytes(StandardCharsets.UTF_8));
        
        // 拼接 IV + 密文
        byte[] encrypted = ByteBuffer.allocate(iv.length + ciphertext.length)
            .put(iv)
            .put(ciphertext)
            .array();
        
        return Base64.getEncoder().encodeToString(encrypted);
    }
    
    public String decrypt(String encrypted) {
        byte[] decoded = Base64.getDecoder().decode(encrypted);
        
        ByteBuffer buffer = ByteBuffer.wrap(decoded);
        byte[] iv = new byte[GCM_IV_LENGTH];
        buffer.get(iv);
        byte[] ciphertext = new byte[buffer.remaining()];
        buffer.get(ciphertext);
        
        Cipher cipher = Cipher.getInstance(ALGORITHM);
        GCMParameterSpec parameterSpec = new GCMParameterSpec(GCM_TAG_LENGTH, iv);
        cipher.init(Cipher.DECRYPT_MODE, new SecretKeySpec(secretKey, "AES"), parameterSpec);
        
        return new String(cipher.doFinal(ciphertext), StandardCharsets.UTF_8);
    }
}
```

### 日志脱敏

```java
// 敏感信息脱敏工具
public class DataMaskingUtils {
    
    public static String maskEmail(String email) {
        if (email == null) return null;
        int atIndex = email.indexOf('@');
        if (atIndex <= 2) return "***" + email.substring(atIndex);
        return email.substring(0, 2) + "***" + email.substring(atIndex);
    }
    
    public static String maskPhone(String phone) {
        if (phone == null || phone.length() < 7) return "***";
        return phone.substring(0, 3) + "****" + phone.substring(phone.length() - 4);
    }
    
    public static String maskIdCard(String idCard) {
        if (idCard == null || idCard.length() < 10) return "***";
        return idCard.substring(0, 4) + "**********" + idCard.substring(idCard.length() - 4);
    }
    
    public static String maskBankCard(String cardNumber) {
        if (cardNumber == null || cardNumber.length() < 8) return "***";
        return cardNumber.substring(0, 4) + " **** **** " + 
               cardNumber.substring(cardNumber.length() - 4);
    }
}

// 日志使用
@Slf4j
public class UserService {
    
    public void logUserLogin(String username, String email) {
        log.info("User login: username={}, email={}", 
            username, 
            DataMaskingUtils.maskEmail(email));
    }
}
```

## 输入验证

### Bean Validation

```java
@Entity
public class User {
    
    @NotBlank(message = "用户名不能为空")
    @Size(min = 3, max = 20, message = "用户名长度必须在 3-20 之间")
    @Pattern(regexp = "^[a-zA-Z][a-zA-Z0-9_]*$", message = "用户名必须以字母开头")
    private String username;
    
    @NotBlank(message = "邮箱不能为空")
    @Email(message = "邮箱格式不正确")
    private String email;
    
    @NotBlank(message = "密码不能为空")
    @Size(min = 8, message = "密码长度至少 8 位")
    @Pattern(regexp = "^(?=.*[A-Za-z])(?=.*\\d)[A-Za-z\\d]{8,}$", 
             message = "密码必须包含字母和数字")
    private String password;
    
    @Pattern(regexp = "^1[3-9]\\d{9}$", message = "手机号格式不正确")
    private String phone;
}
```

### 自定义验证器

```java
// 自定义注解
@Target({ElementType.FIELD, ElementType.PARAMETER})
@Retention(RetentionPolicy.RUNTIME)
@Constraint(validatedBy = StrongPasswordValidator.class)
@Documented
public @interface StrongPassword {
    String message() default "密码强度不足";
    Class<?>[] groups() default {};
    Class<? extends Payload>[] payload() default {};
}

public class StrongPasswordValidator implements 
        ConstraintValidator<StrongPassword, String> {
    
    @Override
    public boolean isValid(String value, ConstraintValidatorContext context) {
        if (value == null) return true;  // 使用 @NotNull 检查
        
        // 至少 8 字符，包含大小写字母和数字
        boolean hasUpper = false, hasLower = false, hasDigit = false;
        
        for (char c : value.toCharArray()) {
            if (Character.isUpperCase(c)) hasUpper = true;
            else if (Character.isLowerCase(c)) hasLower = true;
            else if (Character.isDigit(c)) hasDigit = true;
            
            if (hasUpper && hasLower && hasDigit) break;
        }
        
        return hasUpper && hasLower && hasDigit && value.length() >= 8;
    }
}
```

## XXE（XML 外部实体）

### 问题代码

```java
// 危险：未安全配置的 XML 解析
DocumentBuilderFactory dbf = DocumentBuilderFactory.newInstance();
DocumentBuilder builder = dbf.newDocumentBuilder();
Document doc = builder.parse(new FileInputStream(xmlFile));
```

### 解决方案

```java
// 安全配置 XML 解析器
DocumentBuilderFactory dbf = DocumentBuilderFactory.newInstance();
dbf.setFeature(XMLConstants.FEATURE_SECURE_PROCESSING, true);
dbf.setFeature("http://apache.org/xml/features/disallow-doctype-decl", true);
dbf.setFeature("http://xml.org/sax/features/external-general-entities", false);
dbf.setFeature("http://xml.org/sax/features/external-parameter-entities", false);
dbf.setFeature("http://apache.org/xml/features/nonvalidating/load-external-dtd", false);
dbf.setNamespaceAware(true);

// XXE 攻击示例（被阻止）：
// <?xml version="1.0"?>
// <!DOCTYPE foo [<!ENTITY xxe SYSTEM "file:///etc/passwd">]>
// <foo>&xxe;</foo>
```

## 安全配置

### Spring Security 最佳配置

```java
@Configuration
@EnableWebSecurity
public class SecurityConfig {
    
    @Bean
    public SecurityFilterChain filterChain(HttpSecurity http) throws Exception {
        http
            // 禁用 iframe（防止点击劫持）
            .headers(headers -> headers
                .frameOptions(frame -> frame.deny())
            )
            
            // CSRF（仅表单提交启用）
            .csrf(csrf -> csrf
                .csrfTokenRepository(CookieCsrfTokenRepository.withHttpOnlyFalse())
                .ignoringRequestMatchers("/api/public/**", "/api/health")
            )
            
            // 会话管理
            .sessionManagement(session -> session
                .sessionCreationPolicy(SessionCreationPolicy.IF_REQUIRED)
                .sessionFixation().migrateSession()
                .maximumSessions(1)
                .maxSessionsPreventsLogin(false)
            )
            
            // 安全头
            .headers(headers -> headers
                .contentTypeOptions().and()
                .xssProtection().and()
                .cacheControl().and()
                .httpStrictTransportSecurity(hsts -> hsts
                    .includeSubDomains(true)
                    .maxAgeInSeconds(31536000)
                )
            )
            
            // 认证规则
            .authorizeHttpRequests(auth -> auth
                .requestMatchers("/api/public/**", "/api/health").permitAll()
                .requestMatchers("/admin/**").hasRole("ADMIN")
                .anyRequest().authenticated()
            )
            
            // 错误处理
            .exceptionHandling(ex -> ex
                .authenticationEntryPoint((request, response, authException) -> {
                    response.sendError(HttpServletResponse.SC_UNAUTHORIZED);
                })
                .accessDeniedHandler((request, response, accessDeniedException) -> {
                    response.sendError(HttpServletResponse.SC_FORBIDDEN);
                })
            );
        
        return http.build();
    }
}
```

### CORS 配置

```java
@Configuration
@EnableWebSecurity
public class SecurityConfig {
    
    @Bean
    public CorsConfigurationSource corsConfigurationSource() {
        CorsConfiguration config = new CorsConfiguration();
        config.setAllowedOrigins(Arrays.asList("https://example.com"));
        config.setAllowedMethods(Arrays.asList("GET", "POST", "PUT", "DELETE"));
        config.setAllowedHeaders(Arrays.asList("*"));
        config.setAllowCredentials(true);
        config.setMaxAge(3600L);
        
        // 响应头控制
        config.setExposedHeaders(Arrays.asList("Authorization", "X-Request-Id"));
        
        UrlBasedCorsConfigurationSource source = 
            new UrlBasedCorsConfigurationSource();
        source.registerCorsConfiguration("/api/**", config);
        return source;
    }
}
```

## 日志与监控

### 安全日志

```java
@Slf4j
@Service
public class SecurityAuditService {
    
    public void logLoginSuccess(String username, String ip) {
        log.info("SECURITY AUDIT: Login success - user: {}, ip: {}, time: {}",
            username, ip, LocalDateTime.now());
    }
    
    public void logLoginFailure(String username, String ip, String reason) {
        log.warn("SECURITY AUDIT: Login failure - user: {}, ip: {}, reason: {}, time: {}",
            username, ip, reason, LocalDateTime.now());
    }
    
    public void logAccessDenied(String username, String resource, String action) {
        log.warn("SECURITY AUDIT: Access denied - user: {}, resource: {}, action: {}, time: {}",
            username, resource, action, LocalDateTime.now());
    }
    
    public void logSensitiveOperation(String username, String operation, Object details) {
        // 记录敏感操作（删除、修改权限等）
        log.info("SECURITY AUDIT: Sensitive operation - user: {}, operation: {}, details: {}",
            username, operation, details);
    }
}
```

### 异常处理不泄露信息

```java
// 错误：泄露内部信息
catch (SQLException e) {
```
