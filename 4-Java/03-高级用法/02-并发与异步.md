# 并发与异步

## 概述

Java 并发体系：

```
Thread / Runnable          # 基础
ExecutorService            # 线程池
CompletableFuture          # 异步编程
Virtual Threads (Loom)     # 轻量级线程 (Java 21+)
Concurrent Collections      # 并发集合
Synchronizers              # 同步器
```

## 线程基础

### 创建线程

```java
// 方式 1: 继承 Thread
class MyThread extends Thread {
    @Override
    public void run() {
        System.out.println("Thread running");
    }
}
new MyThread().start();

// 方式 2: 实现 Runnable（推荐）
Thread thread = new Thread(() -> {
    System.out.println("Runnable running");
});
thread.start();

// 方式 3: 使用 Thread.ofPlatform() (Java 21+)
Thread.ofPlatform().start(() -> System.out.println("Platform thread"));

// Thread 属性
thread.setName("MyThread");
thread.setDaemon(true);  // 守护线程（不影响 JVM 退出）
thread.setPriority(Thread.MAX_PRIORITY);  // 优先级
```

### 线程状态

```
NEW → RUNNABLE → BLOCKED/WAITING → TERMINATED
  ↓       ↓           ↓
 创建    就绪/运行    阻塞/等待
```

| 状态 | 说明 |
|------|------|
| `NEW` | 创建但未启动 |
| `RUNNABLE` | 可运行（可能正在运行）|
| `BLOCKED` | 等待获取锁 |
| `WAITING` | 无限期等待 |
| `TIMED_WAITING` | 有限期等待 |
| `TERMINATED` | 已终止 |

### 线程同步

```java
// synchronized 代码块
public class Counter {
    private int count = 0;

    public void increment() {
        synchronized (this) {
            count++;
        }
    }

    // synchronized 方法（锁住 this）
    public synchronized void decrement() {
        count--;
    }

    // 静态 synchronized 方法（锁住类对象）
    public static synchronized void reset() {
        // 锁住 Counter.class
    }
}
```

## ExecutorService

### 线程池类型

```java
import java.util.concurrent.*;

// 固定大小线程池
ExecutorService fixed = Executors.newFixedThreadPool(4);

// 单线程池（保证顺序）
ExecutorService single = Executors.newSingleThreadExecutor();

// 缓存线程池（按需创建）
ExecutorService cached = Executors.newCachedThreadPool();

// 调度线程池（定时任务）
ScheduledExecutorService scheduled = Executors.newScheduledThreadPool(2);
```

### 提交任务

```java
ExecutorService executor = Executors.newFixedThreadPool(4);

try {
    // 提交 Runnable（无返回值）
    executor.submit(() -> System.out.println("Task 1"));

    // 提交 Callable（有返回值）
    Future<Integer> future = executor.submit(() -> {
        Thread.sleep(1000);
        return 42;
    });

    // 阻塞获取结果
    Integer result = future.get();  // 抛出 InterruptedException, ExecutionException

    // 带超时获取
    Integer resultWithTimeout = future.get(2, TimeUnit.SECONDS);

    // 判断是否完成
    if (future.isDone()) {
        System.out.println("Completed: " + future.get());
    }

    // 取消任务
    future.cancel(true);  // mayInterruptIfRunning

} finally {
    executor.shutdown();  // 拒绝新任务，等待现有任务完成
    // executor.shutdownNow();  // 尝试取消所有任务
}
```

### 批量提交

```java
List<Callable<Integer>> tasks = List.of(
    () -> compute(1),
    () -> compute(2),
    () -> compute(3)
);

// invokeAll: 等待所有任务完成
List<Future<Integer>> futures = executor.invokeAll(tasks);

// invokeAny: 返回第一个完成的结果
Integer first = executor.invokeAny(tasks);
```

## CompletableFuture

### 创建

```java
// 手动完成
CompletableFuture<String> future = new CompletableFuture<>();
future.complete("Result");  // 完成并设置结果

// from Supplier
CompletableFuture<String> supply = CompletableFuture.supplyAsync(() -> {
    // 异步执行
    return "Hello";
});

// from Runnable
CompletableFuture<Void> run = CompletableFuture.runAsync(() -> {
    System.out.println("Running async");
});
```

### 链式操作

```java
CompletableFuture<String> future = CompletableFuture
    .supplyAsync(() -> "Hello")           // 异步生成 "Hello"
    .thenApply(s -> s + " World")          // 转换 "Hello World"
    .thenApply(String::toUpperCase)       // "HELLO WORLD"
    .thenApply(s -> s + "!");             // "HELLO WORLD!"

// 异常处理
CompletableFuture<String> future = CompletableFuture
    .supplyAsync(() -> riskyOperation())
    .exceptionally(ex -> {
        System.err.println("Error: " + ex.getMessage());
        return "Default";
    })
    .thenApply(s -> s + "!");
```

### 组合

```java
// thenCombine: 合并两个 CompletableFuture
CompletableFuture<String> combined = CompletableFuture
    .supplyAsync(() -> "Hello")
    .thenCombine(
        CompletableFuture.supplyAsync(() -> " World"),
        (s1, s2) -> s1 + s2
    );  // "Hello World"

// thenCompose: 扁平化（用于返回 CompletableFuture 的情况）
CompletableFuture<User> userFuture = getUserId()
    .thenCompose(this::fetchUser);  // 返回 User，不是 CompletableFuture<User>

// allOf: 等待所有完成
CompletableFuture.allOf(
    fetchUser(id1),
    fetchUser(id2),
    fetchUser(id3)
).join();  // 阻塞直到全部完成

// anyOf: 任意一个完成
CompletableFuture<Object> any = CompletableFuture.anyOf(f1, f2, f3);
```

### 实际应用

```java
// 并行 HTTP 请求
List<Long> userIds = List.of(1L, 2L, 3L);

List<CompletableFuture<User>> futures = userIds.stream()
    .map(id -> CompletableFuture.supplyAsync(() -> fetchUser(id)))
    .toList();

// 等待所有请求完成
List<User> users = futures.stream()
    .map(CompletableFuture::join)
    .toList();

// 超时处理
CompletableFuture<String> withTimeout = CompletableFuture
    .supplyAsync(() -> slowOperation())
    .orTimeout(5, TimeUnit.SECONDS)
    .exceptionally(ex -> "Timeout or error: " + ex.getMessage());
```

## Virtual Threads (Java 21+)

轻量级线程，显著降低线程创建成本。

### 基础用法

```java
// 创建虚拟线程
Thread virtualThread = Thread.ofVirtual().start(() -> {
    System.out.println("Running in virtual thread");
});

// 使用 VirtualThreadPerTaskExecutor
try (ExecutorService executor = Executors.newVirtualThreadPerTaskExecutor()) {
    Future<String> future = executor.submit(() -> "Hello");
    System.out.println(future.get());
}

// 虚拟线程工厂
ThreadFactory factory = Thread.ofVirtual().factory();
ExecutorService executor = Executors.newThreadPerTaskExecutor(factory);
```

### 虚拟线程 vs 平台线程

| 特性 | 平台线程 | 虚拟线程 |
|------|---------|---------|
| 创建成本 | 高（OS 线程）| 低（JVM 管理）|
| 数量 | 数百 | 数百万 |
| 阻塞 | 阻塞 OS 线程 | 挂起虚拟线程，释放载体 |
| 适用场景 | 计算密集型 | IO 密集型 |
| 堆栈 | 固定大小（通常 1MB）| 按需增长/收缩 |

### 虚拟线程挂起机制

```java
// 虚拟线程遇到阻塞操作（如 sleep、Lock.lock()、BlockingQueue.take()）时会自动挂起
// 释放底层载体线程，让其他虚拟线程继续执行

Thread.ofVirtual().start(() -> {
    try {
        // 这个操作会让虚拟线程挂起，不会阻塞载体线程
        Thread.sleep(Duration.ofSeconds(5));
    } catch (InterruptedException e) {
        Thread.currentThread().interrupt();
    }
});
```

### 虚拟线程最佳实践

```java
// 推荐：用于 IO 密集型任务
try (var executor = Executors.newVirtualThreadPerTaskExecutor()) {
    List<Future<String>> futures = IntStream.range(0, 10_000)
        .mapToObj(i -> executor.submit(() -> fetchUrl(i)))
        .toList();

    futures.forEach(f -> {
        try {
            f.get();
        } catch (ExecutionException e) {
            System.err.println("Error: " + e.getMessage());
        }
    });
}

// 适合场景：HTTP 请求、数据库查询、文件 IO
try (var executor = Executors.newVirtualThreadPerTaskExecutor()) {
    List<CompletableFuture<User>> futures = userIds.stream()
        .map(id -> CompletableFuture.supplyAsync(
            () -> userClient.getUser(id), executor))
        .toList();
    
    List<User> users = futures.stream()
        .map(CompletableFuture::join)
        .toList();
}

// 禁止：虚拟线程不要池化（虚拟线程本身就是轻量的）
// Executors.newFixedThreadPool() 不适合虚拟线程
//Executors.newVirtualThreadPerTaskExecutor() 已自动处理

// 禁止：ThreadLocal 过度使用
// 虚拟线程数量巨大，可能导致内存问题
// 解决方案：使用 ScopedValue（Java 21 新特性）
```

## Structured Concurrency（结构化并发，Java 21+）

将多个并发任务视为单一工作单元，简化错误处理和取消。

### 基本用法

```java
// 旧方式：手动管理多个 Future
public List<User> getUsers(List<Long> ids) throws ExecutionException, InterruptedException {
    ExecutorService executor = Executors.newVirtualThreadPerTaskExecutor();
    try {
        List<Future<User>> futures = ids.stream()
            .map(id -> executor.submit(() -> fetchUser(id)))
            .toList();
        
        List<User> users = new ArrayList<>();
        for (Future<User> future : futures) {
            users.add(future.get());  // 需要单独处理异常
        }
        return users;
    } finally {
        executor.shutdown();
    }
}

// 新方式：StructuredTaskScope
public List<User> getUsers(List<Long> ids) throws InterruptedException, ExecutionException {
    try (var scope = new StructuredTaskScope.ShutdownOnSuccess<List<User>>()) {
        ids.forEach(id -> 
            scope.fork(() -> fetchUser(id)));
        
        return scope.join().orElseThrow();  // 等待所有任务完成
    }
}
```

### StructuredTaskScope 用法

```java
// ShutdownOnSuccess：任意一个成功即返回
try (var scope = new StructuredTaskScope.ShutdownOnSuccess<String>() {
    @Override
    protected String complete(Object result) {
        // 第一个成功结果返回
        return super.complete(result);
    }
}) {
    scope.fork(() -> callServiceA());
    scope.fork(() -> callServiceB());
    
    scope.join();
    
    String result = scope.resultNow();  // 获取结果
}

// ShutdownOnFailure：全部失败才结束
try (var scope = new StructuredTaskScope.ShutdownOnFailure()) {
    List<Future<String>> futures = List.of(
        scope.fork(() -> callServiceA()),
        scope.fork(() -> callServiceB())
    );
    
    scope.join();  // 等待所有任务完成
    
    // 处理结果
    List<String> results = futures.stream()
        .map(StructuredTaskScope.Subtask::get)
        .toList();
    
    // 如果有失败，抛出异常
    scope.throwIfFailed();
}
```

### 实际应用

```java
@Service
public class OrderService {
    
    public OrderDetails getOrderDetails(Long orderId) throws InterruptedException {
        try (var scope = new StructuredTaskScope.ShutdownOnFailure()) {
            
            Future<Order> orderFuture = scope.fork(() -> orderRepository.findById(orderId));
            Future<User> userFuture = scope.fork(() -> userClient.getUser(orderId));
            Future<List<Item>> itemsFuture = scope.fork(() -> itemClient.getItems(orderId));
            
            scope.join();  // 等待所有任务
            
            Order order = orderFuture.resultNow();
            User user = userFuture.resultNow();
            List<Item> items = itemsFuture.resultNow();
            
            return new OrderDetails(order, user, items);
        }
    }
}
```

## Scoped Values（Java 21+）

替代 ThreadLocal 的线程作用域变量，虚拟线程友好。

### ThreadLocal 问题

```java
// ThreadLocal 在虚拟线程中有问题：
// 1. 虚拟线程数量巨大，ThreadLocal 实例过多
// 2. 每个虚拟线程都有自己的副本，内存占用高

// 场景：传递用户上下文
public class UserContext {
    static final ThreadLocal<String> CURRENT_USER = new ThreadLocal<>();
}

// 虚拟线程中
Thread.ofVirtual().start(() -> {
    UserContext.CURRENT_USER.set("alice");
    // 每个虚拟线程都有独立副本
});
```

### ScopedValue 用法

```java
// 定义 ScopedValue（不可变）
public class UserContext {
    static final ScopedValue<String> CURRENT_USER = ScopedValue.newInstance();
    
    // 在 Scope 中设置值
    public static <T> T withUser(String user, Supplier<T> action) {
        return ScopedValue.where(CURRENT_USER, user).get(action);
    }
}

// 使用
public void handleRequest(HttpRequest request) {
    String user = extractUser(request);
    
    // 只能在 ScopedValue.where 块内访问
    ScopedValue.where(UserContext.CURRENT_USER, user)
        .run(() -> processRequest());
}

private void processRequest() {
    // 继承父作用域的值
    String user = UserContext.CURRENT_USER.get();  // "alice"
    
    // 虚拟线程中调用
    Thread.ofVirtual().start(() -> {
        String u = UserContext.CURRENT_USER.get();  // 也是 "alice"（继承）
    });
}
```

### 虚拟线程 + ScopedValue

```java
try (var executor = Executors.newVirtualThreadPerTaskExecutor()) {
    ScopedValue<String> requestId = ScopedValue.newInstance();
    
    executor.submit(() -> 
        ScopedValue.where(requestId, "req-123")
            .run(() -> handleRequest()));
}

// 与 StructuredTaskScope 结合
try (var scope = new StructuredTaskScope.ShutdownOnFailure()) {
    ScopedValue.where(CURRENT_USER, user)
        .run(() -> {
            scope.fork(() -> fetchData());
            scope.fork(() -> fetchMoreData());
        });
    
    scope.join();
}
```

## Concurrent Collections

### 常用并发集合

```java
import java.util.concurrent.*;

// ConcurrentHashMap（推荐替代 HashMap）
ConcurrentHashMap<String, Integer> map = new ConcurrentHashMap<>();
map.put("a", 1);
map.putIfAbsent("b", 2);  // 仅当不存在时插入
map.computeIfAbsent("c", k -> compute(k));  // 原子计算

// ConcurrentLinkedQueue（无界）
ConcurrentLinkedQueue<String> queue = new ConcurrentLinkedQueue<>();
queue.offer("a");
String head = queue.poll();

// BlockingQueue（阻塞队列）
BlockingQueue<String> blockingQueue = new LinkedBlockingQueue<>(100);

// ArrayBlockingQueue（有界，FIFO）
// LinkedBlockingQueue（可选有界）
// PriorityBlockingQueue（优先级）

// CopyOnWriteArrayList（读多写少）
CopyOnWriteArrayList<String> list = new CopyOnWriteArrayList<>();
```

### 生产者-消费者模式

```java
BlockingQueue<Integer> queue = new LinkedBlockingQueue<>(10);

// 生产者
Thread producer = new Thread(() -> {
    for (int i = 0; i < 100; i++) {
        try {
            queue.put(i);  // 队列满时阻塞
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }
    }
});

// 消费者
Thread consumer = new Thread(() -> {
    while (true) {
        try {
            Integer value = queue.take();  // 队列空时阻塞
            process(value);
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            break;
        }
    }
});

producer.start();
consumer.start();
```

## Synchronizers

### CountDownLatch

等待一组操作完成。

```java
CountDownLatch latch = new CountDownLatch(3);

new Thread(() -> {
    doTask1();
    latch.countDown();
}).start();

new Thread(() -> {
    doTask2();
    latch.countDown();
}).start();

new Thread(() -> {
    doTask3();
    latch.countDown();
}).start();

latch.await();  // 等待计数归零
System.out.println("All tasks completed");
```

### Semaphore

控制并发访问资源的数量。

```java
Semaphore semaphore = new Semaphore(3);  // 3 个许可

for (int i = 0; i < 10; i++) {
    new Thread(() -> {
        try {
            semaphore.acquire();  // 获取许可
            accessResource();
        } finally {
            semaphore.release();  // 释放许可
        }
    }).start();
}
```

### CyclicBarrier

让线程相互等待，直到所有线程都到达某个点。

```java
CyclicBarrier barrier = new CyclicBarrier(3, () -> {
    System.out.println("All threads reached barrier, continuing...");
});

for (int i = 0; i < 3; i++) {
    new Thread(() -> {
        doTask();
        barrier.await();  // 等待其他线程
    }).start();
}
```

### Phaser

更灵活的屏障，支持动态注册。

```java
Phaser phaser = new Phaser(3);  // 3 个参与方

for (int i = 0; i < 3; i++) {
    new Thread(() -> {
        doPhase1();
        phaser.arriveAndAwaitAdvance();  // 等待所有方到达

        doPhase2();
        phaser.arriveAndAwaitAdvance();

        doPhase3();
        phaser.arriveAndDeregister();  // 完成并注销
    }).start();
}
```

## 原子类

## ThreadLocal

线程本地变量，每个线程有独立的副本。

```java
// 基本用法
ThreadLocal<String> threadLocal = new ThreadLocal<>();
```

## 最佳实践

```java
// 1. 优先使用线程池而不是创建新线程
ExecutorService executor = Executors.newFixedThreadPool(4);
executor.submit(task);

// 2. 异步编程用 CompletableFuture
CompletableFuture.supplyAsync(() -> doStuff(), executor);

// 3. 虚拟线程用于 IO 密集型
try (var executor = Executors.newVirtualThreadPerTaskExecutor()) {
    // IO 操作
}

// 4. 优先使用并发集合而不是 synchronized 集合
ConcurrentHashMap<> map = new ConcurrentHashMap<>();
// 而不是 Collections.synchronizedMap(new HashMap<>());

// 5. 使用原子类而不是锁（简单场景）
AtomicInteger counter = new AtomicInteger(0);
counter.incrementAndGet();

// 6. 避免 synchronized(this)
class MyService {
    private final Object lock = new Object();  // 更好
}
```
