# 注解、反射与动态代理

> Java 没有装饰器（Decorator）模式，类似的横切关注点分离通过注解、反射和动态代理实现。

## 注解（Annotations）

元数据，不直接影响程序运行
- 内置注解：`@Override`、`@Deprecated`、`@FunctionalInterface` 等
- 元注解：`@Retention`、`@Target`、`@Inherited` 等

### 内置注解

| 注解 | 说明 |
|------|------|
| @Override | 标记重写父类方法 |
| @Deprecated | 标记已废弃 |
| @FunctionalInterface | 标记函数式接口 |
| @SafeVarargs | 标记安全可变参数 |
| @SuppressWarnings | 压制警告 |

### 元注解

| 元注解 | 说明 |
|--------|------|
| @Retention | 注解保留阶段（SOURCE/CLASS/RUNTIME） |
| @Target | 注解可使用的位置 |
| @Documented | 包含在 Javadoc 中 |
| @Inherited | 子类继承父类的注解 |
| @Repeatable | 注解可重复使用 |

### 常用注解示例

```java
// 自定义注解
@Retention(RetentionPolicy.RUNTIME)
@Target({ElementType.TYPE, ElementType.METHOD})
@interface Documentation {
    String value() default "";
    String author() default "unknown";
}

// 重复注解（Java 8+）
@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.TYPE)
@Repeatable(Validations.class)
@interface Validation {
    String rule();
}

@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.TYPE)
@interface Validations {
    Validation[] value();
}

// 使用重复注解
@Validation(rule = "notnull")
@Validation(rule = "email")
public class UserForm {
    // ...
}
```

## 反射（Reflection）

运行时检查和操作类、方法和属性
- 获取 Class 对象、调用方法、访问字段
- 框架底层大量使用（Spring、Hibernate）

### 获取 Class 对象

```java
// 三种方式获取 Class
Class<?> c1 = String.class;           // 方式1：类字面量
Class<?> c2 = "hello".getClass();     // 方式2：实例.getClass()
Class<?> c3 = Class.forName("java.lang.String");  // 方式3：完全限定名

// 基本类型也有 Class
Class<?> intClass = int.class;
Class<?> longClass = long.class;
```

### 反射操作

```java
// 获取类信息
Class<?> clazz = Class.forName("com.example.Person");
String name = clazz.getName();        // 完全限定名
String simpleName = clazz.getSimpleName();  // 简单名
Package pkg = clazz.getPackage();     // 包信息

// 获取父类/接口
Class<?> superclass = clazz.getSuperclass();
Class<?>[] interfaces = clazz.getInterfaces();

// 获取构造器
Constructor<?>[] constructors = clazz.getConstructors();
Constructor<?> ctor = clazz.getConstructor(String.class, int.class);
Object instance = ctor.newInstance("Alice", 30);

// 获取方法
Method[] methods = clazz.getMethods();  // 包括继承的
Method[] declared = clazz.getDeclaredMethods();  // 仅本类
Method method = clazz.getMethod("setName", String.class);
method.invoke(instance, "Bob");

// 获取字段
Field[] fields = clazz.getDeclaredFields();
Field field = clazz.getDeclaredField("name");
field.setAccessible(true);  // 访问私有字段
Object value = field.get(instance);
field.set(instance, "NewName");
```

### 反射与泛型

```java
// 获取泛型参数（Type）
class Container<T> {
    T value;
}

Class<?> clazz = Container.class;
TypeVariable<?>[] typeParams = clazz.getTypeParameters();
System.out.println(typeParams[0].getName());  // T

// 获取字段的泛型类型
Field field = MyClass.class.getDeclaredField("map");
Type type = field.getGenericType();
if (type instanceof ParameterizedType) {
    ParameterizedType pt = (ParameterizedType) type;
    Type[] args = pt.getActualTypeArguments();
    System.out.println(args[0]);  // String
    System.out.println(args[1]);  // Integer
}
```

## 动态代理

`Proxy` 类在运行时创建代理对象
- AOP（面向切面编程）的基础
- Spring AOP、MyBatis 映射器都用到了动态代理

### JDK 动态代理

```java
import java.lang.reflect.*;

// 接口
interface UserService {
    void addUser(String name);
    void deleteUser(int id);
}

// 实现类
class UserServiceImpl implements UserService {
    public void addUser(String name) {
        System.out.println("添加用户: " + name);
    }

    public void deleteUser(int id) {
        System.out.println("删除用户: " + id);
    }
}

// InvocationHandler
class LoggingProxy implements InvocationHandler {
    private final Object target;

    public LoggingProxy(Object target) {
        this.target = target;
    }

    @Override
    public Object invoke(Object proxy, Method method, Object[] args) throws Throwable {
        String methodName = method.getName();
        System.out.println("调用方法前: " + methodName);
        try {
            Object result = method.invoke(target, args);
            System.out.println("调用方法后: " + methodName);
            return result;
        } catch (InvocationTargetException e) {
            System.out.println("方法异常: " + methodName);
            throw e.getCause();
        }
    }
}

// 创建代理对象
UserService proxy = (UserService) Proxy.newProxyInstance(
    UserService.class.getClassLoader(),
    new Class[]{UserService.class},
    new LoggingProxy(new UserServiceImpl())
);
proxy.addUser("Alice");  // 被代理
```

### CGLIB 动态代理

```java
// CGLIB 不需要接口，直接代理类
import net.sf.cglib.proxy.*;

// 被代理的类
class UserService {
    public void addUser(String name) {
        System.out.println("添加用户: " + name);
    }
}

// MethodInterceptor
class TimingInterceptor implements MethodInterceptor {
    @Override
    public Object intercept(Object obj, Method method, Object[] args,
                            MethodProxy proxy) throws Throwable {
        long start = System.nanoTime();
        Object result = proxy.invokeSuper(obj, args);  // 调用原始方法
        long end = System.nanoTime();
        System.out.println(method.getName() + " 耗时: " + (end - start) + "ns");
        return result;
    }
}

// 创建代理
Enhancer enhancer = new Enhancer();
enhancer.setSuperclass(UserService.class);
enhancer.setCallback(new TimingInterceptor());
UserService proxy = (UserService) enhancer.create();
proxy.addUser("Bob");
```

### JDK 代理 vs CGLIB

| 特性 | JDK 动态代理 | CGLIB |
|------|-------------|-------|
| 原理 | 反射，生成字节码 | 继承，生成子类 |
| 依赖 | jdk.proxy, jdk.reflect | cglib, asm |
| 性能 | 稍慢 | 更快 |
| 限制 | 必须有接口 | 不能代理 final 类/final 方法 |

## 注解处理器（APT）

编译时处理注解，生成代码或文档。

### 注解处理器配置

```xml
<!-- pom.xml 中配置注解处理器 -->
<dependencies>
    <dependency>
        <groupId>org.projectlombok</groupId>
        <artifactId>lombok</artifactId>
        <version>1.18.30</version>
        <scope>provided</scope>
    </dependency>
</dependencies>

<!-- maven-compiler-plugin 配置 -->
<plugin>
    <groupId>org.apache.maven.plugins</groupId>
    <artifactId>maven-compiler-plugin</artifactId>
    <configuration>
        <annotationProcessorPaths>
            <path>
                <groupId>org.projectlombok</groupId>
                <artifactId>lombok</artifactId>
                <version>1.18.30</version>
            </path>
        </annotationProcessorPaths>
    </configuration>
</plugin>
```

### 自定义注解处理器

```java
// 1. 定义注解
@Retention(RetentionPolicy.SOURCE)  // 仅编译时保留
@Target(ElementType.CLASS)
public @interface Builder {
    String prefix() default "";
}

// 2. 创建处理器
@SupportedAnnotationTypes("com.example.Builder")
@SupportedSourceVersion(SourceVersion.RELEASE_17)
public class BuilderProcessor extends AbstractProcessor {

    @Override
    public boolean process(Set<? extends TypeElement> annotations,
                          RoundEnvironment roundEnv) {
        for (Element element : roundEnv.getElementsAnnotatedWith(Builder.class)) {
            // 检查是否是类
            if (element.getKind() != ElementKind.CLASS) {
                processingEnv.getMessager().printMessage(
                    Diagnostic.Kind.ERROR, "@Builder 仅能用于类");
                return true;
            }

            TypeElement typeElement = (TypeElement) element;
            Builder annotation = typeElement.getAnnotation(Builder.class);
            String prefix = annotation.prefix();

            // 生成代码（通常写入新文件）
            generateBuilder(typeElement, prefix);
        }
        return true;
    }

    private void generateBuilder(TypeElement type, String prefix) {
        String className = type.getSimpleName() + "Builder";
        StringBuilder code = new StringBuilder();
        code.append("public class ").append(className).append(" {\n");
        // ... 生成 builder 代码
        // 写入文件
        try {
            JavaFileObject builderFile = processingEnv.getFiler()
                .createSourceFile(type.getQualifiedName() + "Builder");
            Writer writer = builderFile.openWriter();
            writer.write(code.toString());
            writer.close();
        } catch (IOException e) {
            // 处理异常
        }
    }
}
```

### Lombok 原理

Lombok 使用注解处理器在编译时修改 AST：

```java
// Lombok 常用注解
@Data                   // 生成 getter/setter/equals/hashCode/toString
@Getter/@Setter         // 生成 getter/setter
@NoArgsConstructor      // 生成无参构造
@AllArgsConstructor     // 生成全参构造
@Builder                // 生成 builder 模式
@Slf4j                  // 生成 log 字段
@Slf4j
public class User {
    @Getter @Setter private String name;
    @Getter private int age;
}
```

### 编译时生成文件结构

```
编译前                          编译后（生成）
User.java ──────────→ javac ──────────→ User.class
@Data                              UserGetter.class  (生成)
@Builder                           UserBuilder.class (生成)
```

## 反射与动态代理最佳实践

### 性能考虑

```java
// 反射调用优化
Method method = clazz.getMethod("doSomething");
method.setAccessible(true);  // 跳过安全检查，提升性能

// 缓存 Method 对象
private static final Method DO_SOMETHING;
static {
    try {
        DO_SOMETHING = MyClass.class.getDeclaredMethod("doSomething");
        DO_SOMETHING.setAccessible(true);
    } catch (NoSuchMethodException e) {
        throw new RuntimeException(e);
    }
}

// 使用 MethodHandle（Java 7+，更高性能）
MethodHandle handle = MethodHandles.lookup()
    .findVirtual(MyClass.class, "doSomething", MethodType.methodType(void.class));
handle.invokeExact(instance);
```

### 安全考虑

```java
// 反射访问私有成员前检查权限
if (!field.isAccessible()) {
    // 可能抛出 SecurityException
    field.setAccessible(true);
}

// 使用 SecurityManager 限制反射
System.setSecurityManager(new SecurityManager());
```
