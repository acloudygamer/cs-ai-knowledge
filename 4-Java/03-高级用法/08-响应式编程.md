# 响应式编程

## 概述

响应式编程是一种异步数据流编程范式，核心概念是「发布-订阅」模式。

### 核心优势

- **非阻塞**：不占用线程等待 IO
- **背压支持**：消费者控制数据流速
- **声明式**：用操作符表达转换逻辑
- **组合性**：易于组合复杂逻辑

## Java 响应式生态

### 响应式库对比

| 库 | 描述 | 背压 |

## 参考样例

```java
// 冷发布者 vs 热发布者
Flux<Integer> coldFlux = Flux.range(1, 3);
coldFlux.subscribe(i -> System.out.println("A: " + i));
coldFlux.subscribe(i -> System.out.println("B: " + i));

Sinks.Many<Integer> hotSink = Sinks.many().multicast().onBackpressureBuffer();
hotSink.asFlux().subscribe(i -> System.out.println("A: " + i));
hotSink.emitNext(1, Sinks.EmitFailureHandler.FAIL_FAST);
```

```java
// WebFlux 控制器
@GetMapping("/users/{id}")
public Mono<ResponseEntity<User>> getUser(@PathVariable Long id) {
    return userService.findById(id)
        .map(ResponseEntity::ok)
        .defaultIfEmpty(ResponseEntity.notFound().build());
}
```

```java
// 错误处理
Mono<User> user = fetchUser(id)
    .retry(3)
    .onErrorReturn(defaultUser)
    .onErrorResume(ex -> fetchFromCache(id));
```

```java
// 并行执行多个请求
Mono<User> user = userService.findById(id)
    .flatMap(u -> Flux.zip(
        Mono.just(u),
        orderService.findByUserId(u.getId()).collectList()
    ).map(t -> { t.getT1().setOrders(t.getT2()); return t.getT1(); }));
```

```java
// 避免阻塞操作
Flux.range(1, 100)
    .publishOn(Schedulers.boundedElastic())
    .map(i -> blockingOperation());
```

```java
// 性能考虑
Flux.range(1, 1000)
    .flatMap(i -> process(i), 10)  // 最多 10 个并发
    .limitRate(100);
```
