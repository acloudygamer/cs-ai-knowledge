# 响应式编程

> 响应式编程的本质是"异步数据流编程"——将数据视为时间轴上的事件序列，通过声明式操作符描述转换逻辑，而非命令式的循环和回调。

## 核心概念

### 发布-订阅模型

**响应式编程以发布-订阅为核心：发布者（Publisher）产生数据，订阅者（Subscriber）消费数据，两者之间通过信号（signal）协调——onNext传送数据，onError报告错误，onComplete表示结束。**

<pre>
Publisher ──onNext(datum)──> Subscriber
    │
    ├───onError(error)──> Subscriber（终止）
    └───onComplete()──> Subscriber（终止）
</pre>

### 冷发布者 vs 热发布者

**冷发布者（Cold）：** 每个订阅者独立获取完整数据序列，订阅前不产生数据，如Flux.just(1,2,3)。
**热发布者（Hot）：** 数据共享给所有订阅者，订阅后才开始产生数据，如Sinks.Many。

```java
Flux<Integer> cold = Flux.range(1, 3);
cold.subscribe(i -> System.out.println("A: " + i));
cold.subscribe(i -> System.out.println("B: " + i));
```

```java
Sinks.Many<Integer> hot = Sinks.many().multicast().onBackpressureBuffer();
hot.asFlux().subscribe(i -> System.out.println("A: " + i));
hot.emitNext(1, Sinks.EmitFailureHandler.FAIL_FAST);
```

### 背压（Backpressure）

**背压是消费者控制数据流速的机制——当消费者处理速度慢于生产者时，消费者通知生产者减慢速度，而非无限制积压导致OOM。**

实现方式：request(n)告诉发布者消费者一次只能处理n个元素。

## Mono与Flux

**Mono表示0-1个元素（用于单值或空值），Flux表示0-N个元素（用于流）。两者都是Publisher的实现。**

### Mono（0-1个元素）

```java
Mono<String> mono = Mono.just("hello");
Mono<User> userMono = Mono.just(userId)
    .flatMap(this::fetchUser)
    .map(User::toDTO)
    .onErrorReturn(defaultUser)
    .switchIfEmpty(Mono.just(defaultUser));
```

### Flux（0-N个元素）

```java
Flux<Integer> flux = Flux.just(1, 2, 3);
Flux<String> flux1 = Flux.fromIterable(users)
    .map(User::getName)
    .filter(name -> name.startsWith("A"));
```

## 操作符

### 创建类

```java
Mono.just(value)
Mono.empty()
Flux.range(1, 10)
Flux.interval(Duration.ofSeconds(1))
```

### 转换类

```java
flux.map(String::toUpperCase)
flux.flatMap(concurrentOperation)
flux.scan((a, b) -> a + b)
```

### 过滤类

```java
flux.filter(s -> s.length() > 1)
flux.distinct()
flux.take(5)
```

### 组合类

```java
Flux.merge(flux1, flux2)
Flux.zip(flux1, flux2)
Mono.zip(mono1, mono2)
```

## 调度器

**调度器决定操作在哪个线程执行——默认在订阅线程，通过publishOn/subscribeOn切换。**

```java
Mono.just("hello")
    .publishOn(Schedulers.boundedElastic())
    .map(this::heavyOperation);
```

## 错误处理

```java
Mono<User> user = fetchUser(id)
    .retry(3)
    .onErrorReturn(defaultUser)
    .onErrorResume(ex -> fetchFromCache(id));
```

## WebFlux控制器

```java
@GetMapping("/users/{id}")
public Mono<ResponseEntity<User>> getUser(@PathVariable Long id) {
    return userService.findById(id)
        .map(ResponseEntity::ok)
        .defaultIfEmpty(ResponseEntity.notFound().build());
}
```

## 性能考虑

```java
Flux.range(1, 1000)
    .flatMap(i -> process(i), 10)
    .limitRate(100);
```

```java
Flux.range(1, 100)
    .publishOn(Schedulers.boundedElastic())
    .map(i -> blockingOperation());
```
