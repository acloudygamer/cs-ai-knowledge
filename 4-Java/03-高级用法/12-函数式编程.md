# 函数式编程

## 概述

函数式编程（Functional Programming）是一种编程范式，强调使用纯函数、不可变数据和表达式求值。与命令式编程不同，函数式编程将计算视为数学函数的求值，避免副作用。

```
命令式编程:
"如何做" - 一步步告诉计算机执行什么操作

函数式编程:
"做什么" - 描述要计算什么，而不是如何计算
```

## 核心概念

### 纯函数（Pure Functions）

```java
// 纯函数：相同输入，总是产生相同输出，没有副作用
public class PureFunctions {

    // 纯函数
    public int add(int a, int b) {
        return a + b;  // 不修改任何外部状态
    }

    // 非纯函数（副作用）
    public int addToGlobal(int a) {
        globalCounter += a;  // 修改了外部状态
        return globalCounter;
    }

    // 非纯函数（依赖外部状态）
    private int factor = 10;
    public int multiply(int a) {
        return a * factor;  // 依赖外部可变状态
    }

    // 非纯函数（I/O 操作）
    public String readFile(String path) {
        return Files.readString(Path.of(path));  // I/O 副作用
    }
}
```

### 一等公民（First-Class Functions）

在 Java 中，函数是一等公民，可以：
- 作为参数传递
- 作为返回值
- 赋值给变量

```java
public class FirstClassFunctions {

    // 函数作为参数
    public List<Integer> filter(List<Integer> numbers, Predicate<Integer> predicate) {
        List<Integer> result = new ArrayList<>();
        for (int n : numbers) {
            if (predicate.test(n)) {
                result.add(n);
            }
        }
        return result;
    }

    // 使用
    List<Integer> evens = filter(List.of(1, 2, 3, 4, 5), n -> n % 2 == 0);

    // 函数作为返回值
    public Function<String, String> createFormatter(String type) {
        return switch (type) {
            case "upper" -> String::toUpperCase;
            case "lower" -> String::toLowerCase;
            case "trim" -> String::trim;
            default -> s -> s;
        };
    }

    // 赋值给变量
    Function<Integer, Integer> square = x -> x * x;
    Function<Integer, Integer> doubleValue = x -> x * 2;

    // 组合
    Function<Integer, Integer> composed = square.andThen(doubleValue);
    int result = composed.apply(3);  // (3 * 3) * 2 = 18
}
```

## 高阶函数

高阶函数是接收函数作为参数或返回函数的函数。

### 常用高阶函数

```java
public class HigherOrderFunctions {

    // map: 转换每个元素
    public <T, R> List<R> map(List<T> input, Function<T, R> mapper) {
        List<R> result = new ArrayList<>();
        for (T item : input) {
            result.add(mapper.apply(item));
        }
        return result;
    }

    // filter: 按条件过滤
    public <T> List<T> filter(List<T> input, Predicate<T> predicate) {
        List<T> result = new ArrayList<>();
        for (T item : input) {
            if (predicate.test(item)) {
                result.add(item);
            }
        }
        return result;
    }

    // flatMap: 扁平化映射
    public <T, R> List<R> flatMap(List<T> input, Function<T, List<R>> mapper) {
        List<R> result = new ArrayList<>();
        for (T item : input) {
            result.addAll(mapper.apply(item));
        }
        return result;
    }

    // reduce: 归约
    public <T> T reduce(List<T> input, T identity, BinaryOperator<T> accumulator) {
        T result = identity;
        for (T item : input) {
            result = accumulator.apply(result, item);
        }
        return result;
    }

    // fold: 带初始值的归约
    public <T, R> R fold(List<T> input, R initial, BiFunction<R, T, R> folder) {
        R result = initial;
        for (T item : input) {
            result = folder.apply(result, item);
        }
        return result;
    }
}
```

## 函数组合

### 基本组合

```java
public class FunctionComposition {

    public void examples() {
        Function<Integer, Integer> square = x -> x * x;
        Function<Integer, Integer> addOne = x -> x + 1;
        Function<Integer, Integer> doubler = x -> x * 2;

        // andThen: 先执行当前函数，再执行参数函数
        Function<Integer, Integer> squareThenAddOne = square.andThen(addOne);
        // squareThenAddOne.apply(3) = addOne(square(3)) = 10

        // compose: 先执行参数函数，再执行当前函数
        Function<Integer, Integer> addOneThenSquare = square.compose(addOne);
        // addOneThenSquare.apply(3) = square(addOne(3)) = 16

        // 组合多个函数
        Function<Integer, Integer> complex = square.andThen(addOne).andThen(doubler);
        // complex.apply(3) = doubler(addOne(square(3))) = 20
    }
}
```

### Predicate 组合

```java
public class PredicateComposition {

    public void examples() {
        Predicate<String> isLong = s -> s.length() > 10;
        Predicate<String> hasUpper = s -> s.chars().anyMatch(Character::isUpperCase);
        Predicate<String> hasLower = s -> s.chars().anyMatch(Character::isLowerCase);

        // and: 两者都满足
        Predicate<String> longWithUpper = isLong.and(hasUpper);

        // or: 满足任一即可
        Predicate<String> longOrUpper = isLong.or(hasUpper);

        // negate: 取反
        Predicate<String> notLong = isLong.negate();

        // isEqual: 判断相等
        Predicate<String> isHello = Predicate.isEqual("hello");

        // 组合使用
        Predicate<String> valid = isLong.and(hasUpper).and(hasLower);

        // 使用
        boolean result = valid.test("HelloWorld");  // true
    }
}
```

### 自定义组合器

```java
public class CustomCombinators {

    // 管道操作符
    public static <T> T pipe(T value, Function<T, T>... functions) {
        T result = value;
        for (Function<T, T> f : functions) {
            result = f.apply(result);
        }
        return result;
    }

    // 条件应用
    public static <T> Function<T, T> when(boolean condition, Function<T, T> function) {
        return condition ? function : Function.identity();
    }

    // 示例
    public void usage() {
        String result = pipe(
            "hello",
            s -> s.toUpperCase(),      // HELLO
            s -> s + " WORLD",         // HELLO WORLD
            s -> s.substring(0, 5)    // HELLO
        );

        // 条件转换
        Function<String, String> formatter = pipe(
            "input",
            when(true, String::toUpperCase),   // 应用（条件为真）
            when(false, s -> s + "!")          // 不应用（条件为假）
        );
    }
}
```

## 柯里化（Currying）

将多参数函数转换为一系列单参数函数。

### 基本柯里化

```java
public class Currying {

    // 普通函数：两参数
    public int add(int a, int b) {
        return a + b;
    }

    // 柯里化版本
    public Function<Integer, Integer> curriedAdd(int a) {
        return b -> a + b;
    }

    public void examples() {
        // 使用普通函数
        int result1 = add(3, 5);  // 8

        // 使用柯里化函数
        Function<Integer, Integer> addTo3 = curriedAdd(3);
        int result2 = addTo3.apply(5);  // 8

        // 部分应用
        Function<Integer, Integer> addTo10 = curriedAdd(10);
        int result3 = addTo10.apply(5);  // 15
    }
}
```

### 多参数柯里化

```java
public class MultiParamCurrying {

    // 三参数普通函数
    public int calculate(int a, int b, int c) {
        return (a + b) * c;
    }

    // 三参数柯里化
    public Function<Integer, Function<Integer, Function<Integer, Integer>>>
            curriedCalculate(int a) {
        return b -> c -> (a + b) * c;
    }

    public void examples() {
        // 完整调用
        Function<Integer, Function<Integer, Function<Integer, Integer>>> curried =
            curriedCalculate(10);

        Function<Integer, Function<Integer, Integer>> add5ThenMultiply =
            curried.apply(5);

        Function<Integer, Integer> multiplyBy3 =
            add5ThenMultiply.apply(3);

        int result = multiplyBy3.apply(2);  // (10 + 5) * 2 = 30

        // 或链式调用
        int result2 = curried.apply(10)
                             .apply(5)
                             .apply(3);  // (10 + 5) * 3 = 45
    }
}
```

### 实际应用

```java

    }
```

## 偏函数应用（Partial Application）

固定函数的部分参数，得到一个参数更少的函数。

### 基本偏函数

```java
public class PartialApplication {

    // 普通函数
    public int multiply(int a, int b, int c) {
        return a * b * c;
    }

    // 偏函数：固定第一个参数
    public Function<Integer, Function<Integer, Integer>> partialMultiply(int a) {

        // 使用 Java 内置
        Function<Integer, Integer> multiplyBy2And3Alt =
            partialMultiply(2).apply(3);

        int result2 = multiplyBy2And3Alt.apply(4);  // 24
    }
}
```

## Functor 与 Monad

### Functor

Functor 是可以映射的结构：如果你有一个容器 F<A> 和一个函数 A -> B，你可以得到 F<B>。

```java
public interface Functor<T> {

    <R> Functor<R> map(Function<T, R> mapper);

    // Optional 作为 Functor
    static class OptionalFunctor implements Functor<Object> {
        private final Optional<?> value;

        public <R> Optional<R> map(Function<Object, R> mapper) {
            return value.map(mapper);
        }
    }

    // Stream 作为 Functor
    static class StreamFunctor<T> implements Functor<T> {
        private final Stream<T> stream;

        public <R> Stream<R> map(Function<T, R> mapper) {
            return stream.map(mapper);
        }
    }
}
```

### Monad

Monad 是可以"扁平化"的 Functor：如果你有一个函数 A -> F<B> 和一个 F<A>，你可以得到 F<B>。

```java
public interface Monad<T> {

    // pure: 将值放入容器
    static <T> Monad<T> of(T value);

    // flatMap (bind/chain): 映射后扁平化
    <R> Monad<R> flatMap(Function<T, Monad<R>> mapper);

    // 示例：Optional Monad
    static class OptionalMonad<T> {
        private final Optional<T> value;

        public static <T> OptionalMonad<T> of(T value) {
            return new OptionalMonad<>(Optional.ofNullable(value));
        }

        public <R> OptionalMonad<R> flatMap(Function<T, OptionalMonad<R>> mapper) {
            return value.map(mapper)
                        .orElseGet(() -> new OptionalMonad<>(Optional.empty()));
        }

        public <R> OptionalMonad<R> map(Function<T, R> mapper) {
            return flatMap(mapper.andThen(OptionalMonad::of));
        }
    }
}
```

### 实际 Monad 示例

```java
public class RealMonads {

    // 1. Optional Monad - 链式空值检查
    public void optionalMonad() {
        record User(Long id, String name, Address address) {}
        record Address(String city, String zip) {}

        Optional<User> user = findUser(1L);

        // 链式空值检查
        Optional<String> city = user
            .flatMap(u -> Optional.ofNullable(u.address()))
            .flatMap(a -> Optional.ofNullable(a.city()));

        // 使用 map（自动处理空值）
        Optional<String> zip = user
            .map(u -> u.address())
            .map(a -> a.zip());
    }

    // 2. Stream Monad - 惰性求值和组合
    public void streamMonad() {
        List<List<Integer>> nested = List.of(
            List.of(1, 2),
            List.of(3, 4)
        );

        // flatMap 扁平化
        List<Integer> flat = nested.stream()
            .flatMap(List::stream)  // flatMap: Stream<Stream<A>> -> Stream<A>
            .toList();  // [1, 2, 3, 4]
    }

    // 3. CompletableFuture Monad - 异步组合
    public void completableFutureMonad() {
        CompletableFuture<User> userFuture = fetchUser(1L);

        // flatMap 用于异步链
        CompletableFuture<Order> orderFuture = userFuture
            .thenCompose(user -> fetchOrder(user.id()));  // thenCompose = flatMap

        // 完整的异步链
        CompletableFuture<String> result = fetchUser(1L)
            .thenCompose(user -> fetchOrder(user.id()))
            .thenCompose(order -> fetchItems(order.id()))
            .thenApply(items -> items.size() + " items");
    }

    // 4. Result Monad (模拟)
    public void resultMonad() {
        // 类似 Optional，但处理异常
        Result<User> user = Result.of(() -> findUser(1L));

        Result<String> city = user
            .map(u -> u.address())
            .map(a -> a.city());

        // flatMap 处理可能失败的操作
        Result<Order> order = user
            .flatMap(u -> Result.of(() -> fetchOrder(u.id())));
    }
}
```

## 闭包（Closures）

闭包是捕获了外部作用域变量的函数。

```java
public class Closures {

    // 闭包：函数 + 引用的环境
    public Function<Integer, Integer> createMultiplier(int factor) {
        // factor 被闭包捕获
        return x -> x * factor;
    }

    public void closureExample() {
        Function<Integer, Integer> doubler = createMultiplier(2);
        Function<Integer, Integer> triple = createMultiplier(3);

        System.out.println(doubler.apply(5));  // 10
        System.out.println(triple.apply(5));  // 15
    }

    // 闭包修改变量（需要 final 或 effectively final）
    public Runnable createCounter() {
        int[] count = new int[1];  // 数组作为"可变容器"

        return () -> {
            count[0]++;
            System.out.println("Count: " + count[0]);
        };
    }

    public void counterExample() {
        Runnable counter = createCounter();
        counter.run();  // Count: 1
        counter.run();  // Count: 2
        counter.run();  // Count: 3
    }

    // 闭包与并行
    public void closureInParallel() {
        List<Integer> numbers = List.of(1, 2, 3, 4, 5);

        // 错误：共享可变变量
        int[] sum = new int[1];
        numbers.forEach(n -> sum[0] += n);  // 不好！

        // 正确：使用 reduce
        int correctSum = numbers.stream()
            .reduce(0, Integer::sum);
    }
}
```

## 递归（Recursion）

### 尾递归优化

```java
public class Recursion {

    // 普通递归（可能有栈溢出风险）
    public long factorial(int n) {
        if (n <= 1) return 1;
        return n * factorial(n - 1);
    }

    // 尾递归版本
    public long tailFactorial(int n) {
        return tailFactorialHelper(n, 1);
    }

    private long tailFactorialHelper(int n, long accumulator) {
        if (n <= 1) return accumulator;
        return tailFactorialHelper(n - 1, n * accumulator);
    }

    // 使用 Stream 替代递归
    public long streamFactorial(int n) {
        return LongStream.rangeClosed(1, n)
            .reduce(1, (a, b) -> a * b);
    }

    // 互递归
    public boolean isEven(int n) {
        if (n == 0) return true;
        return isOdd(n - 1);
    }

    public boolean isOdd(int n) {
        if (n == 0) return false;
        return isEven(n - 1);
    }
}
```

## Point-Free 编程

Point-Free 风格：不显式使用参数变量。

```java
public class PointFree {

    // Point-Full（有参数）
    public List<Integer> processPointFull(List<Integer> numbers) {
        return numbers.stream()
            .filter(n -> n > 0)
            .map(n -> n * 2)
            .collect(Collectors.toList());
    }

    // Point-Free（无参数）
    public List<Integer> processPointFree(List<Integer> numbers) {
        return numbers.stream()
            .filter(n -> n > 0)
            .map(multiplyBy(2))
            .toList();
    }

    // 辅助函数
    public IntUnaryOperator multiplyBy(int factor) {
        return x -> x * factor;
    }

    // 组合多个操作
    public Function<List<Integer>, List<Integer>> pipeline =
        pipeline(
            ((Predicate<Integer>) n -> n > 0)::test,
            PointFree::multiplyBy2,
            List::stream,
            Collectors::toList
        );

    public static <T> Function<T, T> pipeline(Function<T, T>... ops) {
        return t -> {
            T result = t;
            for (Function<T, T> op : ops) {
                result = op.apply(result);
            }
            return result;
        };
    }
}
```

## 命令式 vs 函数式对比

```java
public class ImperativeVsFunctional {

    // 场景：统计满足条件的元素

    // 命令式风格
    public int countEvensImperative(List<Integer> numbers) {
        int count = 0;
        for (int n : numbers) {
            if (n % 2 == 0) {
                count++;
            }
        }
        return count;
    }

    // 函数式风格
    public long countEvensFunctional(List<Integer> numbers) {
        return numbers.stream()
            .filter(n -> n % 2 == 0)
            .count();
    }

    // 场景：转换并过滤

    // 命令式
    public List<String> transformImperative(List<User> users) {
        List<String> result = new ArrayList<>();
        for (User user : users) {
            if (user.getAge() >= 18) {
                result.add(user.getName().toUpperCase());
            }
        }
        return result;
    }

    // 函数式
    public List<String> transformFunctional(List<User> users) {
        return users.stream()
            .filter(u -> u.getAge() >= 18)
            .map(User::getName)
            .map(String::toUpperCase)
            .toList();
    }

    // 场景：分组统计

    // 命令式
    public Map<String, Integer> groupByImperative(List<Product> products) {
        Map<String, Integer> totals = new HashMap<>();
        for (Product p : products) {
            totals.merge(p.category(), p.price(), Integer::sum);
        }
        return totals;
    }

    // 函数式
    public Map<String, Integer> groupByFunctional(List<Product> products) {
        return products.stream()
            .collect(Collectors.groupingBy(
                Product::category,
                Collectors.summingInt(Product::price)
            ));
    }
}
```

## 最佳实践

### 函数式设计原则

```
1. 优先使用不可变数据
   - 使用 record 或 final 类
   - 集合用 List.of(), Map.of() 等

2. 纯函数优先
   - 避免修改外部状态
   - 避免 I/O 副作用

3. 组合优于继承
   - 使用函数组合而非继承层次

4. 延迟求值
   - 使用 Stream 的惰性求值
   - 考虑 Supplier 延迟执行

5. 避免过度函数式
   - 简单场景用简单代码
   - 不要为了函数式而函数式
```

### 反模式

```java
public class AntiPatterns {

    // 反模式 1：过度嵌套
    public void overNested() {
        // 避免
        result.map(a -> a.getB())
              .map(b -> b.getC())
              .map(c -> c.getD())
              .map(d -> d.getValue())
              .orElse("default");

        // 更好的方式：提取方法
        result.flatMap(this::extractValue)
              .orElse("default");
    }

    // 反模式 2：链式副作用
    public void sideEffectChain() {
        // 避免：forEach 中的副作用
        users.stream()
            .forEach(u -> {
                u.setProcessed(true);  // 修改外部状态
                logger.info("Processed: " + u.getName());  // 副作用
                notify(u);  // 更多副作用
            });

        // 更好：明确分离
        List<User> processed = users.stream()
            .peek(u -> u.setProcessed(true))  // peek 用于调试
            .toList();

        processed.forEach(u -> {
            logger.info("Processed: " + u.getName());
            notify(u);
        });
    }

    // 反模式 3：内存泄漏（闭包捕获大对象）
    public Runnable createLeakingClosure() {
        List<String> hugeList = loadHugeData();  // 大对象

        return () -> {
            // hugeList 被闭包捕获，无法被 GC
            process(hugeList);
        };
    }

    // 正确：只捕获需要的数据
    public Runnable createNonLeakingClosure() {
        String summary = loadHugeData().stream()
            .reduce("", (a, b) -> a + b);

        return () -> processSummary(summary);
    }
}
```

## 总结

```
函数式编程核心概念:
- 纯函数：相同输入，相同输出，无副作用
- 不可变性：数据创建后不可修改
- 一等公民：函数可以作为参数和返回值
- 高阶函数：接收或返回函数的函数
- 柯里化：将多参数函数转为单参数链
- 偏函数：固定部分参数
- Functor：可映射的结构
- Monad：可flatMap的结构

Java 函数式工具:
- Lambda 表达式
- 方法引用
- Stream API
- Function/Predicate/Consumer 接口
- Optional
- CompletableFuture
```
