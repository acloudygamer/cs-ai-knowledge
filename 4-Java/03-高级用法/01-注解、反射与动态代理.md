# 注解、反射与动态代理

> 注解是Java的元数据机制，反射是运行时操作自身的能力，动态代理是运行时生成代理对象的手段。三者共同构成Java的横切关注点分离体系，替代其他语言中的装饰器模式。

## 注解（Annotations）

**注解是一类特殊的接口，其本身不直接影响程序运行，而是为编译器、工具或运行时提供元数据。**

### 内置注解

| 注解 | 说明 |
|------|------|
| @Override | 标记重写父类方法，编译器验证签名匹配 |
| @Deprecated | 标记已废弃，编译器产生警告 |
| @FunctionalInterface | 标记函数式接口，编译器验证单抽象方法 |
| @SafeVarargs | 标记安全可变参数，抑制堆污染警告 |
| @SuppressWarnings | 压制指定类型的编译器警告 |

### 元注解

| 元注解 | 说明 |
|--------|------|
| @Retention | 保留阶段：SOURCE（仅源码）→ CLASS（编译期）→ RUNTIME（运行时） |
| @Target | 标注位置：TYPE/METHOD/FIELD/PARAMETER/CONSTRUCTOR等 |
| @Documented | javadoc文档包含此注解 |
| @Inherited | 子类继承父类的此注解 |
| @Repeatable | 允许在同一位置重复使用此注解 |

**为什么需要@Retention？** 注解的生命周期决定了它能为谁服务。SOURCE级供IDE和静态分析工具使用；CLASS级供字节码操作工具（如ASM）使用；RUNTIME级供反射API在运行时读取。

<pre>
用户代码 → [编译] → CLASS文件(含注解) → [类加载] → JVM运行时
              ↑                    ↑
          工具读取              反射读取
</pre>

### 自定义注解

```java
@Retention(RetentionPolicy.RUNTIME)
@Target({ElementType.TYPE, ElementType.METHOD})
@interface Documentation {
    String value() default "";
    String author() default "unknown";
}
```

```java
@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.TYPE)
@Repeatable(Validations.class)
@interface Validation {
    String rule();
}
```

## 反射（Reflection）

**反射是程序在运行时检查和操作自身结构（类、方法、属性、构造函数）的能力，其代价是跳过编译期安全检查，显著慢于直接调用。**

框架（Spring、Hibernate）依赖反射实现依赖注入、ORM映射、动态代理。代价是绕过编译期类型安全，性能低于直接调用（通常 2-100倍）。

<pre>
Class对象 ─┬─> getDeclaredMethods()  获取全部方法
           ├─> getDeclaredFields()   获取全部属性
           ├─> getDeclaredConstructors() 获取全部构造函数
           └─> getAnnotation()       获取运行时注解
</pre>

### Class对象获取

```java
Class<?> c1 = String.class;
Class<?> c2 = "hello".getClass();
Class<?> c3 = Class.forName("java.lang.String");
```

### 反射调用

```java
Class<?> clazz = Class.forName("com.example.Person");
Constructor<?> ctor = clazz.getConstructor(String.class, int.class);
Object instance = ctor.newInstance("Alice", 30);
Method method = clazz.getMethod("setName", String.class);
method.invoke(instance, "Bob");
```

### 反射与泛型

泛型信息在编译后被擦除（类型擦除），但通过反射仍可获取泛型声明：

```java
Type genericType = field.getGenericType();
if (genericType instanceof ParameterizedType pt) {
    Type[] args = pt.getActualTypeArguments();
}
```

## 动态代理

**动态代理是在运行时创建代理对象的设计模式，其本质是字节码生成——JVM在内部拼装出实现了指定接口的类字节码，通过InvocationHandler将所有方法调用转发到用户定义的处理逻辑。**

这是AOP（面向切面编程）的底层支撑：切面逻辑集中管理，具体方法调用时由代理统一拦截并织入。

<pre>
调用方 ──proxy──> InvocationHandler.invoke() ──> 真实对象
                  ↑
             拦截在此添加
             前置/后置/异常通知
</pre>

### JDK动态代理

```java
UserService proxy = (UserService) Proxy.newProxyInstance(
    UserService.class.getClassLoader(),
    new Class[]{UserService.class},
    new LoggingProxy(new UserServiceImpl())
);
```

### CGLIB/ByteBuddy

```java
UserService proxy = new net.bytebuddy.ByteBuddy()
    .subclass(UserService.class)
    .method(net.bytebuddy.matcher.ElementMatchers.named("addUser"))
    .intercept(net.bytebuddy.implementation.MethodDelegation.to(new TimingInterceptor()))
    .make()
    .load(UserService.class.getClassLoader())
    .getLoaded()
    .getDeclaredConstructor()
    .newInstance();
```

## 注解处理器（APT）

**APT在编译期运行，遍历源代码中的注解及其宿主元素，生成新文件（通常是.java）——这是Lombok等工具实现自动代码生成的底层机制。**

## Lombok

**Lombok通过APT在编译期自动生成getter/setter/constructor/builder等样板代码，其代价是IDE需要插件支持，且编译产物与源码存在隐式差异。**

### 数据类注解

```java
@Getter @Setter
private Long id;
```

```java
@NoArgsConstructor
@AllArgsConstructor
@RequiredArgsConstructor
public class User {
    private Long id;
    private final String email;
}
```

```java
@Data
public class User {
    private Long id;
    private final String email;
}
```

```java
@Value
public class User {
    private Long id;
    private final String email;
}
```

```java
@Builder
public class User {
    private Long id;
    private final String email;
}
User user = User.builder().id(1L).email("alice@example.com").build();
```

### 通用方法注解

```java
@ToString
public class User {
    private Long id;
    @ToString.Exclude
    private String password;
}
```

```java
@EqualsAndHashCode(callSuper = true)
public class Admin extends User {
    private String role;
}
```

### 日志与空安全

```java
@Slf4j
public class UserService {
    public void createUser(User user) {
        log.info("Creating user: {}", user.getName());
    }
}
```

```java
public void createUser(@NonNull User user) {
    this.user = user;
}
```

```java
@Cleanup
InputStream is = new FileInputStream(path);
```

### 常见问题

| 特性 | @Data | @Value |
|------|-------|--------|
| 字段可变性 | 可变 | 不可变（final） |
| 生成setter | 是 | 否 |
| 生成全参构造 | 否 | 是 |
| 适合场景 | DTO、可变对象 | 不可变数据、值对象 |

## 反射性能优化

```java
private static final Method DO_SOMETHING;
static {
    DO_SOMETHING = MyClass.class.getDeclaredMethod("doSomething");
    DO_SOMETHING.setAccessible(true);
}
```

```java
MethodHandle handle = MethodHandles.lookup()
    .findVirtual(MyClass.class, "doSomething", MethodType.methodType(void.class));
handle.invokeExact(instance);
```
