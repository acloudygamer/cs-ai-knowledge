# 注解、反射与动态代理

> Java 没有装饰器（Decorator）模式，类似的横切关注点分离通过注解、反射和动态代理实现。

## 注解（Annotations）

元数据，不直接影响程序运行。

### 内置注解

| 注解 | 说明 |
|------|------|
| @Override | 标记重写父类方法 |
| @Deprecated | 标记已废弃 |
| @FunctionalInterface | 标记函数式接口 |
| @SafeVarargs | 标记安全可变参数 |
| @SuppressWarnings | 压制警告 |

### 元注解

| 元注解 | 说明 |
|--------|------|
| @Retention | 注解保留阶段（SOURCE/CLASS/RUNTIME） |
| @Target | 注解可使用的位置 |
| @Documented | 包含在 Javadoc 中 |
| @Inherited | 子类继承父类的注解 |
| @Repeatable | 注解可重复使用 |

## 参考样例

```java
// 自定义注解
@Retention(RetentionPolicy.RUNTIME)
@Target({ElementType.TYPE, ElementType.METHOD})
@interface Documentation {
    String value() default "";
    String author() default "unknown";
}

// 重复注解
@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.TYPE)
@Repeatable(Validations.class)
@interface Validation {
    String rule();
}
```

```java
// 反射操作
Class<?> clazz = Class.forName("com.example.Person");
Constructor<?> ctor = clazz.getConstructor(String.class, int.class);
```

```java
// CGLIB ByteBuddy
UserService proxy = new net.bytebuddy.ByteBuddy()
    .subclass(UserService.class)
    .method(net.bytebuddy.matcher.ElementMatchers.named("addUser"))
    .intercept(net.bytebuddy.implementation.MethodDelegation.to(new TimingInterceptor()))
    .make()
    .load(UserService.class.getClassLoader())
    .getLoaded()
    .getDeclaredConstructor()
    .newInstance();
```

## Lombok

Lombok 是一个 Java 库，通过注解自动生成样板代码（boilerplate），显著减少 getter/setter/构造函数等重复代码。

### 添加依赖

```xml
<!-- Maven -->
<dependency>
    <groupId>org.projectlombok</groupId>
    <artifactId>lombok</artifactId>
    <version>1.18.30</version>
    <scope>provided</scope>
</dependency>
```

### 数据类注解

**@Getter / @Setter**：为字段生成 getter 和 setter 方法。

```java
@Getter @Setter
private Long id;
```

**@NoArgsConstructor / @AllArgsConstructor / @RequiredArgsConstructor**：
- @NoArgsConstructor：生成无参构造
- @AllArgsConstructor：生成全参构造
- @RequiredArgsConstructor：只包含 final 和 @NonNull 字段的构造

```java
@NoArgsConstructor
@AllArgsConstructor
@RequiredArgsConstructor
public class User {
    private Long id;
    private final String email;  // 包含在 RequiredArgsConstructor 中
}
```

**@Data**：组合注解，包含 @Getter @Setter @RequiredArgsConstructor @ToString @EqualsAndHashCode。

```java
@Data
public class User {
    private Long id;
    private final String email;
}
```

**@Value**：不可变数据类，所有字段变为 final，不生成 setter。

```java
@Value
public class User {
    private Long id;
    private final String email;
}
```

**@Builder**：生成建造者模式的构造方式。

```java
@Builder
public class User {
    private Long id;
    private final String email;
}

User user = User.builder()
    .id(1L)
    .email("alice@example.com")
    .build();
```

### 通用方法注解

**@ToString**：生成 toString 方法，可使用 @ToString.Exclude 排除字段。

```java
@ToString
public class User {
    private Long id;
    @ToString.Exclude  // 排除字段
    private String password;
}
```

**@EqualsAndHashCode**：生成 equals 和 hashCode 方法。

```java
@EqualsAndHashCode(callSuper = true)
public class Admin extends User {
    private String role;
}
```

### 日志注解

```java
@Slf4j  // 自动生成 private static final org.slf4j.Logger log
public class UserService {
    public void createUser(User user) {
        log.info("Creating user: {}", user.getName());
    }
}
```

### 空安全与资源

**@NonNull**：在参数上生成 null 检查。

```java
public void createUser(@NonNull User user) {
    // 相当于：if (user == null) throw new NullPointerException("user");
}
```

**@Cleanup**：自动调用 close 方法。

```java
@Cleanup
InputStream is = new FileInputStream(path);
```

### 常见问题

| 特性 | @Data | @Value |
|------|-------|--------|
| 字段可变性 | 可变 | 不可变（final）|
| 生成 setter | 是 | 否 |
| 生成全参构造 | 否 | 是 |
| 适合场景 | DTO、可变对象 | 不可变数据、值对象 |

```java
// 反射调用优化
private static final Method DO_SOMETHING;
static {
    DO_SOMETHING = MyClass.class.getDeclaredMethod("doSomething");
    DO_SOMETHING.setAccessible(true);
}

// 使用 MethodHandle（更高性能）
MethodHandle handle = MethodHandles.lookup()
    .findVirtual(MyClass.class, "doSomething", MethodType.methodType(void.class));
handle.invokeExact(instance);
```
