# 参数化测试

## 定义

参数化测试通过**同一测试逻辑遍历多组参数**，实现数据驱动的测试执行。其数学本质是笛卡尔积：

$$
T_{\text{executed}} = \bigcup_{i=1}^{n} \{\text{test logic} \times p_i\}
$$

其中 $p_i$ 是第 $i$ 组参数。同一测试逻辑被实例化 $n$ 次，每次使用不同参数。 是第 $i$ 组参数。同一测试逻辑被实例化 $n$ 次，每次使用不同参数。 组参数。同一测试逻辑被实例化 $n$ 次，每次使用不同参数。 次，每次使用不同参数。

**参数化的价值**：将"相同逻辑，不同数据"的测试模式从 N 个独立测试方法压缩为 1 个参数化测试方法，大幅减少代码重复。

**执行模型**：参数化测试不是"一个测试执行多次"，而是"每个参数组合实例化一个独立的测试实例"。每个实例有独立的显示名、执行状态、失败报告。

### 边界值注入的数学原因

`Integer.MIN_VALUE`、`-1`、`0`、`1`、`Integer.MAX_VALUE`是整数类型的缺陷高发边界：

| 边界值 | 潜在问题 |
|--------|----------|
| `Integer.MAX_VALUE + 1` | 整数溢出（变成负数） |
| `Integer.MIN_VALUE - 1` | 整数下溢（变成正数） |
| `-0.0 vs 0.0` | 浮点零的符号差异 |
| `NaN` | 非数值比较（NaN != NaN） |

**边界值缺陷的分布**：假设缺陷分布在边界 $\epsilon$ -邻域内，则边界值测试的期望发现率远高于内部值测试。-邻域内，则边界值测试的期望发现率远高于内部值测试。

## 深度：组合测试的数学

### 全因子组合的穷举性

 $N$ 个布尔参数的全因子组合测试覆盖所有 $2^N$ 种可能输入组合，提供**完备性保证**： 个布尔参数的全因子组合测试覆盖所有 $2^N$ 种可能输入组合，提供**完备性保证**： 种可能输入组合，提供**完备性保证**：

$$
\forall (b_1, b_2, \ldots, b_N) \in \{0, 1\}^N: \exists t \in T_{\text{full}}: \text{test}(t) = (b_1, b_2, \ldots, b_N)
$$

### 成对组合的最优性

成对组合测试的覆盖表生成是一个**组合优化问题**：

**目标**：用最少的测试用例覆盖所有 2 元组合。

**数学表达**：
$$
\forall i < j, \forall v_i \in V_i, \forall v_j \in V_j: \exists t \in T_{\text{pairwise}}: t[i] = v_i \land t[j] = v_j
$$

**充分性**：研究表明，80%以上的缺陷可由成对组合触发——这是经验数据，不是数学证明。

### 正交表与覆盖表

正交表 $L_N(v^k)$ 是覆盖表的一种特例，要求每个参数每个值出现相同次数： 是覆盖表的一种特例，要求每个参数每个值出现相同次数：

$$
\forall j \in \{1, \ldots, k\}, \forall a, b \in V: |\{ r \mid \text{row}(r)[j] = a \}| = |\{ r \mid \text{row}(r)[j] = b \}|
$$

正交表的性质允许更均衡的参数值分布。

### 组合测试的复杂度下界

对于 $CA(N; t, k, v)$ ，有信息论下界： ，有信息论下界：

$$
N \geq \frac{\log(v^{{k \choose t} \cdot t!})}{\log(v)} = {{k \choose t} \cdot t! \over \log_2 v}
$$

这给出了覆盖表大小的理论极限。

## 参考存根

```java
// 笛卡尔积执行的最小化演示
import java.util.Arrays;
import java.util.List;
import java.util.stream.Collectors;

public class CartesianProduct {
    public static void main(String[] args) {
        List<Integer> nums = Arrays.asList(1, 2);
        List<String> letters = Arrays.asList("a", "b");

        // 笛卡尔积：2 × 2 = 4 种组合
        List<String> combinations = nums.stream()
            .flatMap(n -> letters.stream().map(l -> n + l))
            .collect(Collectors.toList());

        System.out.println("组合: " + combinations);
        // 输出: [1a, 1b, 2a, 2b]
    }
}
```
