# 正则表达式

## 概述

正则表达式是用于匹配字符串模式的工具，Java 通过 `java.util.regex` 包提供支持。

## 基本语法

### 元字符

| 元字符 | 说明 | 示例 |
|--------|------|------|
| `.` | 任意单个字符 | `a.c` 匹配 "abc" |
| `\d` | 数字 [0-9] | `\d+` 匹配 "123" |
| `\D` | 非数字 | `\D+` 匹配 "abc" |
| `\w` | 单词字符 [a-zA-Z0-9_] | `\w+` 匹配 "hello_1" |
| `\W` | 非单词字符 | `\W` 匹配 "@" |
| `\s` | 空白字符 | `\s+` 匹配空格 |
| `\S` | 非空白字符 | `\S+` 匹配非空格 |

### 字符类

```java
[abc]       // a、b 或 c
[^abc]      // 除 a、b、c 外的任意字符
[a-z]       // a 到 z
[a-zA-Z]    // a-z 或 A-Z
[0-9]       // 0-9
```

### 量词

| 量词 | 说明 |
|------|------|
| `*` | 0 次或多次 |
| `+` | 1 次或多次 |
| `?` | 0 次或 1 次 |
| `{n}` | 恰好 n 次 |
| `{n,}` | 至少 n 次 |
| `{n,m}` | n 到 m 次 |

### 边界匹配

```java
^       // 字符串开始
$       // 字符串结束
\b      // 单词边界
\B      // 非单词边界
```

### 分组与捕获

```java
(...)       // 捕获组
(?:...)     // 非捕获组
(?<name>...) // 命名捕获组
\1          // 引用第 1 个捕获组
```

## Java API

### Pattern 和 Matcher

```java
import java.util.regex.*;

String text = "Hello, my email is test@example.com and phone: 123-456-7890";

// 1. 编译正则表达式
Pattern pattern = Pattern.compile("\\w+@[a-zA-Z]+\\.[a-zA-Z]+");

// 2. 创建 Matcher
Matcher matcher = pattern.matcher(text);

// 3. 查找匹配
while (matcher.find()) {
    System.out.println("Found: " + matcher.group());
    System.out.println("Start: " + matcher.start());
    System.out.println("End: " + matcher.end());
}
```

### 常用方法

```java
// matches() - 整个字符串匹配
boolean isMatch = Pattern.matches("\\d+", "123");  // true

// split() - 按正则分割
String[] parts = "a,b;c d".split("[,;\\s]+");  // ["a", "b", "c", "d"]

// replaceAll() - 替换所有
String result = "abc123def".replaceAll("\\d+", "#");  // "abc#def"

// replaceFirst() - 替换第一个
String result = "abc123def123".replaceFirst("\\d+", "#");  // "abc#def123"
```

### 捕获组示例

```java
// 提取日期中的年、月、日
String date = "2024-04-13";
Pattern p = Pattern.compile("(\\d{4})-(\\d{2})-(\\d{2})");
Matcher m = p.matcher(date);

if (m.matches()) {
    System.out.println("Year: " + m.group(1));   // 2024
    System.out.println("Month: " + m.group(2));  // 04
    System.out.println("Day: " + m.group(3));    // 13
}

// 命名捕获组
Pattern p = Pattern.compile("(?<year>\\d{4})-(?<month>\\d{2})-(?<day>\\d{2})");
Matcher m = p.matcher(date);

if (m.matches()) {
    System.out.println(m.group("year"));   // 2024
    System.out.println(m.group("month"));  // 04
    System.out.println(m.group("day"));    // 13
}
```

## 常见场景

### 邮箱验证

```java
public static boolean isValidEmail(String email) {
    String regex = "^[A-Za-z0-9+_.-]+@[A-Za-z0-9.-]+\\.[A-Za-z]{2,}$";
    return Pattern.matches(regex, email);
}

// 测试
System.out.println(isValidEmail("test@example.com"));  // true
System.out.println(isValidEmail("invalid@"));          // false
```

### 手机号验证

```java
// 中国手机号（简单验证）
public static boolean isValidPhone(String phone) {
    String regex = "^1[3-9]\\d{9}$";
    return Pattern.matches(regex, phone);
}

// 国际手机号
public static boolean isValidInternationalPhone(String phone) {
    String regex = "^\\+?[1-9]\\d{1,14}$";
    return Pattern.matches(regex, phone);
}
```

### URL 提取

```java
String text = "Visit https://example.com/path?query=1 and http://test.org";
Pattern p = Pattern.compile("https?://[\\w.-]+(?:/[\\w./?%&=-]*)?");
Matcher m = p.matcher(text);

while (m.find()) {
    System.out.println(m.group());
}
// https://example.com/path?query=1
// http://test.org
```

### HTML 标签内容提取

```java
String html = "<h1>Title</h1><p>Paragraph</p>";
Pattern p = Pattern.compile("<(\\w+)[^>]*>([^<]+)</\\1>");
Matcher m = p.matcher(html);

while (m.find()) {
    System.out.println("Tag: " + m.group(1) + ", Content: " + m.group(2));
}
// Tag: h1, Content: Title
// Tag: p, Content: Paragraph
```

### 密码强度验证

```java
public static boolean isStrongPassword(String password) {
    // 至少8位，包含大写、小写、数字、特殊字符
    String regex = "^(?=.*[a-z])(?=.*[A-Z])(?=.*\\d)(?=.*[@$!%*?&])[A-Za-z\\d@$!%*?&]{8,}$";
    return Pattern.matches(regex, password);
}
```

## 常用正则模式

### 数字相关

```java
"^\\d+$"                    // 整数
"^-?\\d+$"                  // 整数（含负号）
"^\\d*\\.\\d+$"            // 正小数
"^-?\\d*\\.\\d+$"          // 小数（含负号）
"^\\d{1,3}(,\\d{3})*$"     // 千分位格式：1,234,567
```

### 字符串相关

```java
"^[a-zA-Z]+$"              // 纯字母
"^[a-zA-Z0-9]+$"           // 字母数字
"^\\S+$"                   // 无空白字符
".*"                       // 任意字符（贪婪）
".*?"                      // 任意字符（非贪婪）
```

### 时间日期相关

```java
"^\\d{4}-\\d{2}-\\d{2}$"           // 日期：YYYY-MM-DD
"^\\d{2}:\\d{2}:\\d{2}$"           // 时间：HH:mm:ss
"^\\d{4}-\\d{2}-\\d{2} \\d{2}:\\d{2}:\\d{2}$"  // 日期时间
```

### 身份信息

```java
"^\\d{17}[\\dXx]$"                 // 18位身份证
"^\\d{15}$"                        // 15位身份证
```

## 性能优化

### 预编译

```java
// 每次调用都编译（不推荐）
public boolean validate(String input) {
    return input.matches("\\d{6}");
}

// 预编译（推荐）
private static final Pattern PATTERN = Pattern.compile("\\d{6}");

public boolean validate(String input) {
    return PATTERN.matcher(input).matches();
}
```

### 非贪婪匹配

```java
String html = "<div>content</div><div>more</div>";

// 贪婪：匹配到最后一个 </div>
Pattern greedy = Pattern.compile("<div>.*</div>");

// 非贪婪：匹配到第一个 </div>
Pattern nonGreedy = Pattern.compile("<div>.*?</div>");
```

### 避免回溯

```java
// 问题：\\.\\.\\.  在输入过长时会导致回溯
Pattern problem = Pattern.compile("(a+)+b");

// 解决：明确范围
Pattern fixed = Pattern.compile("a{1,20}b");
```
