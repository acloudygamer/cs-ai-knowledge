# 日期时间

## 旧版 API（Date/Calendar）

Java 8 之前使用 `Date` 和 `Calendar`，存在线程安全和设计问题。

```java
import java.util.Date;
import java.util.Calendar;
import java.text.SimpleDateFormat;

// Date（遗留类，大部分方法已废弃）
Date date = new Date();
System.out.println(date.toString());  // Thu Apr 13 10:30:00 CST 2024

// SimpleDateFormat（线程不安全）
SimpleDateFormat sdf = new SimpleDateFormat("yyyy-MM-dd HH:mm:ss");
String formatted = sdf.format(date);

// Calendar（复杂且线程不安全）
Calendar cal = Calendar.getInstance();
cal.set(2024, Calendar.APRIL, 13);  // 月份从 0 开始
int year = cal.get(Calendar.YEAR);
int month = cal.get(Calendar.MONTH) + 1;
```

## Java 8+ 日期时间 API

Java 8 引入全新 API，位于 `java.time` 包，线程安全且设计良好。

### 核心类

| 类 | 说明 |
|----|------|
| Instant | 时间戳（UTC） |
| LocalDate | 日期（年-月-日） |
| LocalTime | 时间（时:分:秒） |
| LocalDateTime | 日期时间 |
| ZonedDateTime | 带时区的日期时间 |
| Duration | 时间段（秒/纳秒） |
| Period | 日期间隔（年/月/日） |
| ZoneId | 时区 ID |

### LocalDate（日期）

```java
import java.time.*;

LocalDate today = LocalDate.now();  // 当前日期
System.out.println(today);  // 2024-04-13

// 从指定值创建
LocalDate date = LocalDate.of(2024, 4, 13);
LocalDate date2 = LocalDate.parse("2024-04-13");

// 获取属性
int year = date.getYear();           // 2024
int month = date.getMonthValue();     // 4
int day = date.getDayOfMonth();       // 13
DayOfWeek dow = date.getDayOfWeek();  // SATURDAY

// 计算
LocalDate nextWeek = today.plusWeeks(1);
LocalDate lastMonth = today.minusMonths(1);
LocalDate firstDayOfMonth = today.withDayOfMonth(1);

// 比较
boolean isAfter = date1.isAfter(date2);
boolean isBefore = date1.isBefore(date2);
```

### LocalTime（时间）

```java
LocalTime now = LocalTime.now();  // 当前时间
System.out.println(now);  // 10:30:45.123456

// 从指定值创建
LocalTime time = LocalTime.of(14, 30, 0);
LocalTime time2 = LocalTime.parse("14:30:00");

// 获取属性
int hour = time.getHour();      // 14
int minute = time.getMinute();  // 30
int second = time.getSecond();  // 0

// 计算
LocalTime later = time.plusHours(2);
LocalTime earlier = time.minusMinutes(30);
```

### LocalDateTime（日期时间）

```java
LocalDateTime now = LocalDateTime.now();
LocalDateTime dt = LocalDateTime.of(2024, 4, 13, 14, 30);

// 转换为 LocalDate/LocalTime
LocalDate date = dt.toLocalDate();
LocalTime time = dt.toLocalTime();

// 格式化
DateTimeFormatter formatter = DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss");
String formatted = dt.format(formatter);  // 2024-04-13 14:30:00

// 解析
LocalDateTime parsed = LocalDateTime.parse("2024-04-13 14:30:00", formatter);
```

### Instant（时间戳）

```java
Instant instant = Instant.now();  // 当前 UTC 时间戳
System.out.println(instant);  // 2024-04-13T02:30:45.123456Z

// 与 Date 互转
Date date = Date.from(instant);
Instant instant2 = date.toInstant();

// Epoch 秒/毫秒
long seconds = instant.getEpochSecond();       // 秒
long millis = instant.toEpochMilli();          // 毫秒

// 从 Epoch 创建
Instant fromEpoch = Instant.ofEpochSecond(1713000000);
```

### Duration 和 Period

```java
// Duration：时间长度（用于 LocalTime/Instant）
LocalTime start = LocalTime.of(10, 0);
LocalTime end = LocalTime.of(12, 30);

Duration duration = Duration.between(start, end);
System.out.println(duration);  // PT2H30M (2小时30分钟)

long hours = duration.toHours();      // 2
long minutes = duration.toMinutes();  // 150

// 创建 Duration
Duration d1 = Duration.ofHours(2);
Duration d2 = Duration.parse("PT2H30M");

// Period：日期间隔（用于 LocalDate）
LocalDate from = LocalDate.of(2024, 1, 1);
LocalDate to = LocalDate.of(2024, 4, 13);

Period period = Period.between(from, to);
System.out.println(period);  // P3M12D (3个月12天)

int months = period.getMonths();  // 3
int days = period.getDays();      // 12
```

### ZonedDateTime（带时区）

```java
// 当前时区的日期时间
ZonedDateTime zonedNow = ZonedDateTime.now();
System.out.println(zonedNow);  // 2024-04-13T10:30:45+08:00[Asia/Shanghai]

// 指定时区
ZonedDateTime tokyo = ZonedDateTime.now(ZoneId.of("Asia/Tokyo"));
ZonedDateTime utc = ZonedDateTime.now(ZoneId.of("UTC"));

// 带时区的时间戳
Instant instant = zonedNow.toInstant();

// 时区转换
ZonedDateTime converted = instant.atZone(ZoneId.of("Europe/London"));

// 格式化带时区
DateTimeFormatter formatter = DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss Z");
System.out.println(zonedNow.format(formatter));  // 2024-04-13 10:30:45 +0800
```

## 格式化与解析

### DateTimeFormatter

```java
import java.time.format.*;

// 预定义格式
String result1 = LocalDate.now().format(DateTimeFormatter.ISO_DATE);
String result2 = LocalDateTime.now().format(DateTimeFormatter.ISO_DATE_TIME);

// 自定义格式
DateTimeFormatter f1 = DateTimeFormatter.ofPattern("yyyy-MM-dd");
DateTimeFormatter f2 = DateTimeFormatter.ofPattern("yyyy年MM月dd日 HH:mm:ss");
DateTimeFormatter f3 = DateTimeFormatter.ofPattern("EEEE", Locale.CHINESE);  // 星期几

// 本地化格式
DateTimeFormatter localized = DateTimeFormatter.ofLocalizedDate(FormatStyle.FULL);
String result = LocalDate.now().format(localized);  // 2024年4月13日 星期六
```

### 常用格式模式

| 模式 | 说明 | 示例 |
|------|------|------|
| yyyy | 4位年份 | 2024 |
| MM | 2位月份 | 04 |
| dd | 2位日期 | 13 |
| HH | 2位小时(24h) | 14 |
| hh | 2位小时(12h) | 02 |
| mm | 2位分钟 | 30 |
| ss | 2位秒 | 45 |
| a | AM/PM | 下午 |
| EEEE | 星期几 | 星期六 |
| Z | 时区偏移 | +0800 |

## 时区处理

```java
// 获取所有可用时区
Set<String> zones = ZoneId.getAvailableZoneIds();
zones.stream().filter(z -> z.contains("Asia")).forEach(System.out::println);

// 转换示例：北京时间转纽约时间
LocalDateTime beijingTime = LocalDateTime.of(2024, 4, 13, 20, 0);
ZonedDateTime beijing = beijingTime.atZone(ZoneId.of("Asia/Shanghai"));
ZonedDateTime newYork = beijing.withZoneSameInstant(ZoneId.of("America/New_York"));

System.out.println(beijing);   // 2024-04-13T20:00+08:00[Asia/Shanghai]
System.out.println(newYork);   // 2024-04-13T08:00-04:00[America/New_York]
```

## 与旧版 API 互转

```java
// Date -> LocalDateTime
Date date = new Date();
Instant instant = date.toInstant();
LocalDateTime ldt = LocalDateTime.ofInstant(instant, ZoneId.systemDefault());

// LocalDateTime -> Date
LocalDateTime ldt2 = LocalDateTime.now();
Instant instant2 = ldt2.atZone(ZoneId.systemDefault()).toInstant();
Date date2 = Date.from(instant2);

// Calendar -> ZonedDateTime
Calendar calendar = Calendar.getInstance();
ZonedDateTime zdt = calendar.toInstant().atZone(ZoneId.systemDefault());
```

## 常见操作示例

### 计算年龄

```java
public static int calculateAge(LocalDate birthDate) {
    return Period.between(birthDate, LocalDate.now()).getYears();
}

// 使用
int age = calculateAge(LocalDate.of(1990, 5, 15));
```

### 判断是否工作日

```java
public static boolean isWeekday(LocalDate date) {
    DayOfWeek dow = date.getDayOfWeek();
    return dow != DayOfWeek.SATURDAY && dow != DayOfWeek.SUNDAY;
}

// 使用
System.out.println(isWeekday(LocalDate.of(2024, 4, 13)));  // true (Saturday)
// 注意：这里返回 false，因为 4/13 是周六
```

### 日期范围迭代

```java
// 遍历日期范围
LocalDate start = LocalDate.of(2024, 4, 1);
LocalDate end = LocalDate.of(2024, 4, 10);

List<LocalDate> dates = start.datesUntil(end.plusDays(1))
    .collect(Collectors.toList());
dates.forEach(System.out::println);
```

### 季度计算

```java
public static int getQuarter(LocalDate date) {
    return (date.getMonthValue() - 1) / 3 + 1;
}

public static LocalDate getQuarterStart(int year, int quarter) {
    int startMonth = (quarter - 1) * 3 + 1;
    return LocalDate.of(year, startMonth, 1);
}
```

## 线程安全

```java
// 旧版 SimpleDateFormat（线程不安全）
SimpleDateFormat sdf = new SimpleDateFormat("yyyy-MM-dd");
// 不要共享实例！

// 新版 DateTimeFormatter（线程安全）
DateTimeFormatter formatter = DateTimeFormatter.ofPattern("yyyy-MM-dd");
// 可以安全地共享和重用
LocalDate date = LocalDate.parse("2024-04-13", formatter);
```

## 常用工具

### 生日倒计时

```java
public static long daysUntilBirthday(LocalDate birthday) {
    LocalDate today = LocalDate.now();
    LocalDate nextBirthday = birthday.withYear(today.getYear());

    if (nextBirthday.isBefore(today) || nextBirthday.isEqual(today)) {
        nextBirthday = nextBirthday.plusYears(1);
    }

    return Period.between(today, nextBirthday).getDays();
}
```

### 时间戳格式化

```java
public static String formatTimestamp(Instant instant) {
    DateTimeFormatter formatter = DateTimeFormatter
        .ofPattern("yyyy-MM-dd HH:mm:ss")
        .withZone(ZoneId.systemDefault());
    return formatter.format(instant);
}
```
