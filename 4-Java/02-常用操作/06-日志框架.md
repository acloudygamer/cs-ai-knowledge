# 日志框架

> **本质断言**：SLF4J 作为门面模式（Facade Pattern），将日志调用与日志实现解耦，使应用代码可以在编译期绑定具体实现（Logback/Log4j2），避免运行时才发现日志框架冲突。

## 门面模式设计

<pre>
应用代码 (调用 SLF4J API)
        │
        ▼
   SLF4J API  (接口层，不实现日志逻辑)
        │
   SLF4J-to-Logback 桥接器 (jcl-over-slf4j.jar)
        │
   Logback 实现 (ch.qos.logback.classic.Logger)
        │
        ▼
   Appender (ConsoleAppender/FileAppender...)
</pre>

**为什么使用门面而非直接用实现**：直接使用 Logback 会导致代码与实现强耦合，若后续需要切换到 Log4j2 或 JUL（Java Util Logging），需修改所有源码。SLF4J 将"日志在哪里"（实现）与"如何记录"（API）分离。

## 日志级别与过滤器链

<pre>
Logger 配置: DEBUG
        │
        ▼ 消息: log.debug("user={}", name)
        │
  LevelFilter: DEBUG >= DEBUG ? PASS : DENY  → PASS
        │
   MatcherFilter: 检查 MDC/ThreadLocal → PASS
        │
      Appender: 写文件/控制台
</pre>

日志框架在记录前执行过滤器链，每层可以修改日志事件（添加上下文、替换内容）或决定是否放行。`${}` 占位符延迟到评估阶段才拼接，避免字符串拼接开销。

## Logback vs Log4j2 架构差异

Logback 使用 SLF4J 原生 API，不需桥接器，性能差异主要在于：
- Logback 的 `ILoggerFactory` 返回的 `Logger` 直接持有 Appender 引用，无额外间接层
- Log4j2 使用 `LSLAY`（Log4j Servlet API）异步架构，在单独线程处理日志写入

## 参考样例

```java
// 基本用法（≤20行）
public class UserService {
    private static final Logger log = LoggerFactory.getLogger(UserService.class);
    public void createUser(String name) {
        log.info("Creating user: {}", name);
    }
}
```

```java
// 异常日志处理
try { /* 操作 */ }
catch (IOException e) { log.error("Failed to read: {}", path, e); }
```

```java
// 避免日志级别判断开销
if (log.isDebugEnabled())
    log.debug("Processing: {}", expensiveComputation());
```

```xml
<!-- logback.xml 配置 -->
<configuration>
    <appender name="CONSOLE" class="ch.qos.logback.core.ConsoleAppender">
        <encoder>
            <pattern>%d{HH:mm:ss} %-5level %logger{36} - %msg%n</pattern>
        </encoder>
    </appender>
    <root level="INFO"><appender-ref ref="CONSOLE"/></root>
    <logger name="com.example" level="DEBUG"/>
</configuration>
```

```yaml
# Spring Boot 配置
logging:
  level:
    root: INFO
    com.example: DEBUG
  file:
    name: logs/application.log
    max-size: 10MB
    max-history: 30
```

```java
// 敏感信息处理
log.info("User login: username={}, password=***", username);
```

```xml
<!-- Log4j2 替换 Logback -->
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-web</artifactId>
    <exclusions><exclusion>
        <groupId>ch.qos.logback</groupId>
        <artifactId>logback-classic</artifactId>
    </exclusion></exclusions>
</dependency>
<dependency>
    <groupId>org.apache.logging.log4j</groupId>
    <artifactId>log4j-slf4j2-impl</artifactId>
</dependency>
```
