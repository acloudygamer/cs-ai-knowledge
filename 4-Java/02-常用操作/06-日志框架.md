# 日志框架

## 概述

Java 日志框架生态系统：

- **Commons Logging** - Apache 通用日志接口
- **SLF4J** (Simple Logging Facade for Java) - 日志门面（接口）
- **Logback** - SLF4J 的默认实现（Logback  native implementation）
- **Log4j** - 早期主流实现（已被 Log4j2 取代）
- **Log4j2** - Apache 新一代日志框架

最佳实践：**SLF4J 作为日志门面 + Logback 作为实现**

## SLF4J + Logback 快速上手

### 添加依赖

```xml
<!-- Maven -->
<dependency>
    <groupId>org.slf4j</groupId>
    <artifactId>slf4j-api</artifactId>
    <version>2.0.9</version>
</dependency>

<!-- Logback 实现 -->
<dependency>
    <groupId>ch.qos.logback</groupId>
    <artifactId>logback-classic</artifactId>
    <version>1.4.14</version>
</dependency>
```

Spring Boot 默认已包含 Logback，无需额外添加依赖。

## 基本用法

```java
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

public class UserService {

    // 获取 Logger，通常用类的全限定名
    private static final Logger log = LoggerFactory.getLogger(UserService.class);

    public void createUser(String name) {
        log.info("Creating user: {}", name);  // {} 是占位符

        try {
            // 业务逻辑
            log.debug("User created successfully: {}", name);
        } catch (Exception e) {
            log.error("Failed to create user: {}", name, e);  // 异常会自动打印堆栈
        }
    }
}
```

### 占位符 vs 字符串拼接

```java
// 推荐：使用占位符
log.info("User {} logged in at {}", username, timestamp);

// 不推荐：字符串拼接（即使日志级别关闭也会执行拼接）
log.info("User " + username + " logged in at " + timestamp);
```

### 日志级别

| 级别 | 用途 | 示例 |
|------|------|------|
| `TRACE` | 最详细，追踪调试 | 方法入口/出口、变量值 |
| `DEBUG` | 开发调试信息 | 业务逻辑中间状态 |
| `INFO` | 正常业务流程 | "用户登录成功"、"订单已创建" |
| `WARN` | 潜在问题 | "配置缺失，使用默认值" |
| `ERROR` | 错误，但能继续运行 | "数据库连接失败"、"文件读取失败" |
| `FATAL` | 严重错误，程序终止 | "JVM 内存耗尽" |

### 配置日志级别

```xml
<!-- logback.xml -->
<configuration>
    <!-- 控制台输出 -->
    <appender name="CONSOLE" class="ch.qos.logback.core.ConsoleAppender">
        <encoder>
            <pattern>%d{yyyy-MM-dd HH:mm:ss} [%thread] %-5level %logger{36} - %msg%n</pattern>
        </encoder>
    </appender>

    <!-- 文件输出 -->
    <appender name="FILE" class="ch.qos.logback.core.rolling.RollingFileAppender">
        <file>logs/application.log</file>
        <rollingPolicy class="ch.qos.logback.core.rolling.TimeBasedRollingPolicy">
            <fileNamePattern>logs/application-%d{yyyy-MM-dd}.log</fileNamePattern>
            <maxHistory>30</maxHistory>
        </rollingPolicy>
        <encoder>
            <pattern>%d{yyyy-MM-dd HH:mm:ss} [%thread] %-5level %logger{36} - %msg%n</pattern>
        </encoder>
    </appender>

    <!-- 根日志级别 -->
    <root level="INFO">
        <appender-ref ref="CONSOLE"/>
        <appender-ref ref="FILE"/>
    </root>

    <!-- 指定包的日志级别 -->
    <logger name="com.example.service" level="DEBUG"/>
    <logger name="org.springframework" level="WARN"/>
</configuration>
```

### Spring Boot 配置（application.yml）

```yaml
logging:
  level:
    root: INFO
    com.example: DEBUG  # 指定包/类的日志级别
    org.springframework.web: WARN
    org.hibernate: WARN

  pattern:
    console: "%d{yyyy-MM-dd HH:mm:ss} [%thread] %-5level %logger{36} - %msg%n"
    file: "%d{yyyy-MM-dd HH:mm:ss} [%thread] %-5level %logger{36} - %msg%n"

  file:
    name: logs/application.log
    max-size: 10MB
    max-history: 30
```

## Log4j2 配置

### 添加依赖

```xml
<!-- Log4j2 需要排除 Logback -->
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-web</artifactId>
    <exclusions>
        <exclusion>
            <groupId>ch.qos.logback</groupId>
            <artifactId>logback-classic</artifactId>
        </exclusion>
    </exclusions>
</dependency>

<dependency>
    <groupId>org.apache.logging.log4j</groupId>
    <artifactId>log4j-slf4j2-impl</artifactId>
    <version>2.21.1</version>
</dependency>
```

### log4j2.xml 配置

```xml
<?xml version="1.0" encoding="UTF-8"?>
<Configuration>
    <Appenders>
        <Console name="CONSOLE">
            <PatternLayout pattern="%d{HH:mm:ss.SSS} [%t] %-5level %logger{36} - %msg%n"/>
        </Console>
        <File name="FILE" fileName="logs/application.log">
            <PatternLayout pattern="%d{yyyy-MM-dd HH:mm:ss} [%t] %-5level %logger{36} - %msg%n"/>
        </File>
    </Appenders>
    <Loggers>
        <Root level="info">
            <AppenderRef ref="CONSOLE"/>
            <AppenderRef ref="FILE"/>
        </Root>
    </Loggers>
</Configuration>
```

## 最佳实践

### 1. 使用 SLF4J 而不是具体的日志实现

```java
// 推荐：使用 SLF4J 接口
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

// 不推荐：直接使用 Logback 或 Log4j2
// import ch.qos.logback.classic.Logger;
```

### 2. 异常日志正确处理

```java
// 推荐：异常作为最后一个参数
try {
    // 操作
} catch (IOException e) {
    log.error("Failed to read file: {}", path, e);
}

// 不推荐：字符串拼接
// log.error("Failed to read file: " + path + ": " + e);
```

### 3. 避免在日志中执行复杂计算

```java
// 推荐：先判断日志级别
if (log.isDebugEnabled()) {
    log.debug("Processing items: {}", expensiveComputation());
}

// 不推荐：即使 DEBUG 关闭也执行
// log.debug("Processing items: {}", expensiveComputation());
```

### 4. 日志格式建议

```xml
<!-- 推荐格式 -->
<pattern>%d{yyyy-MM-dd HH:mm:ss.SSS} [%thread] %-5level %logger{36} - %msg%n</pattern>

<!-- 输出示例 -->
2024-01-15 10:30:45.123 [http-nio-8080-exec-1] INFO  c.e.s.UserService - User logged in: alice
```

### 5. 敏感信息处理

```java
// 不要记录密码、token、身份证等敏感信息
log.info("User login: username={}, password=***", username);

// 或者使用自定义的脱敏工具
log.info("User login: {}", maskSensitive(userData));
```

## 日志门面桥接

当项目中存在多个日志框架时，使用桥接器统一：

```
commons-logging → SLF4J（通过 jcl-over-slf4j）
Log4j → SLF4J（通过 log4j-to-slf4j）
Log4j2 → SLF4J（通过 log4j-to-slf4j）
Jul → SLF4J（通过 jul-to-slf4j）
```

```xml
<!-- 排除所有日志实现，添加桥接器和 SLF4J -->
<dependencies>
    <!-- 排除 Spring Boot 默认的 Logback -->
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-web</artifactId>
        <exclusions>
            <exclusion>
                <groupId>ch.qos.logback</groupId>
                <artifactId>logback-classic</artifactId>
            </exclusion>
        </exclusions>
    </dependency>

    <!-- 添加 SLF4J API -->
    <dependency>
        <groupId>org.slf4j</groupId>
        <artifactId>slf4j-api</artifactId>
    </dependency>

    <!-- 使用 Log4j2 作为实现 -->
    <dependency>
        <groupId>org.apache.logging.log4j</groupId>
        <artifactId>log4j-slf4j2-impl</artifactId>
    </dependency>
</dependencies>
```
