# 单元测试

## 概述

单元测试是针对程序最小单元（方法/类）的自动化测试，确保代码行为符合预期。

测试原则：
- **独立**：每个测试独立运行，不依赖其他测试
- **可重复**：测试结果稳定，可重复执行
- **快速**：毫秒级完成，便于频繁运行
- **自验证**：测试自动判断通过或失败

## JUnit 5 快速上手

### 添加依赖

```xml
<!-- Maven -->
<dependency>
    <groupId>org.junit.jupiter</groupId>
    <artifactId>junit-jupiter</artifactId>
    <version>5.10.0</version>
    <scope>test</scope>
</dependency>
```

Spring Boot 项目已包含 JUnit 5。

### 基本结构

```java
import org.junit.jupiter.api.*;

import static org.junit.jupiter.api.Assertions.*;

class CalculatorTest {

    private Calculator calculator;

    @BeforeEach      // 每个测试方法前执行
    void setUp() {
        calculator = new Calculator();
    }

    @AfterEach       // 每个测试方法后执行
    void tearDown() {
        calculator = null;
    }

    @Test
    void testAdd() {
        int result = calculator.add(2, 3);
        assertEquals(5, result);
    }

    @Test
    void testDivide() {
        assertThrows(ArithmeticException.class,
            () -> calculator.divide(1, 0));
    }
}
```

### 常用断言

```java
import static org.junit.jupiter.api.Assertions.*;

// 相等
assertEquals(expected, actual);
assertEquals(expected, actual, "提示信息"); // 失败时显示

// 布尔
assertTrue(condition);
assertFalse(condition);

// 空/非空
assertNull(object);
assertNotNull(object);

// 异常
assertThrows(Exception.class, () -> { /* code */ });
assertThrows(Exception.class, () -> { /* code */ }, "提示");

// 超时
assertTimeout(Duration.ofSeconds(1), () -> { /* code */ });

// 数组
assertArrayEquals(expectedArray, actualArray);

// 异常信息包含
assertThrows(IllegalArgumentException.class, () -> {
    throw new IllegalArgumentException("年龄不能为负");
}).getMessage().contains("年龄");

// 组断言（所有断言都会执行）
assertAll("用户信息",
    () -> assertEquals("Alice", user.getName()),
    () -> assertEquals(30, user.getAge()),
    () -> assertEquals("alice@example.com", user.getEmail())
);
```

## Mockito 模拟对象

### 添加依赖

```xml
<dependency>
    <groupId>org.mockito</groupId>
    <artifactId>mockito-junit-jupiter</artifactId>
    <version>5.7.0</version>
    <scope>test</scope>
</dependency>
```

Spring Boot 项目已包含 Mockito。

### 基本用法

```java
import org.junit.jupiter.api.Test;
import org.junit.jupiter.api.extension.ExtendWith;
import org.mockito.Mock;
import org.mockito.junit.jupiter.MockitoExtension;

import static org.mockito.Mockito.*;

@ExtendWith(MockitoExtension.class)
class UserServiceTest {

    @Mock
    private UserRepository userRepository;

    @Test
    void testFindById() {
        // 模拟行为：调用 findById(1) 返回 User 对象
        User expectedUser = new User(1L, "Alice", "alice@example.com");
        when(userRepository.findById(1L)).thenReturn(expectedUser);

        // 执行
        UserService service = new UserService(userRepository);
        User result = service.findById(1L);

        // 验证
        assertNotNull(result);
        assertEquals("Alice", result.getName());

        // 验证方法被调用
        verify(userRepository, times(1)).findById(1L);
    }
}
```

### 常用 Mockito 方法

```java
// 模拟返回值
when(mock.method()).thenReturn(value);
when(mock.method()).thenThrow(new Exception());
when(mock.method()).thenAnswer(inv -> {
    // 自定义行为
    return result;
});

// 多次调用返回不同值
when(mock.get()).thenReturn("first", "second", "third"); // 第三次及以后返回 "third"

// 精确匹配
when(mock.findById(eq(1L))).thenReturn(user);

// 任意参数
when(mock.findById(anyLong())).thenReturn(user);

// 验证调用次数
verify(mock, times(1)).method();    // 精确 1 次
verify(mock, atLeast(1)).method();  // 至少 1 次
verify(mock, atMost(3)).method();    // 最多 3 次
verify(mock, never()).method();      // 从未调用

// 顺序验证
InOrder inOrder = inOrder(mockA, mockB);
inOrder.verify(mockA).first();
inOrder.verify(mockB).second();

// 模拟 void 方法
doNothing().when(mock).setName(anyString());
doThrow(new Exception()).when(mock).delete(anyLong());

// 模拟对象创建
try (MockedConstruction<User> mocked = mockConstruction(User.class)) {
    User user = new User();
    // ...
}
```

### @Spy 部分模拟

```java
@Spy
private UserService userService; // 真实对象

@Test
void testWithSpy() {
    // 只模拟 getUserFromCache 方法
    doReturn(new User("Cached")).when(userService).getUserFromCache(anyString());

    // getUserFromCache 被模拟，其他方法真实调用
    User result = userService.findUser("Alice");
}
```

## 嵌套测试类

```java
@DisplayName("计算器测试")
class CalculatorTest {

    @Nested
    @DisplayName("加法测试")
    class AddTests {
        @Test
        void testPositiveNumbers() {
            assertEquals(5, new Calculator().add(2, 3));
        }

        @Test
        void testNegativeNumbers() {
            assertEquals(-1, new Calculator().add(-2, 1));
        }
    }

    @Nested
    @DisplayName("除法测试")
    class DivideTests {
        @Test
        void testNormalDivision() {
            assertEquals(2, new Calculator().divide(6, 3));
        }

        @Test
        void testDivisionByZero() {
            assertThrows(ArithmeticException.class,
                () -> new Calculator().divide(1, 0));
        }
    }
}
```

## 参数化测试

```java
import org.junit.jupiter.params.ParameterizedTest;
import org.junit.jupiter.params.provider.ValueSource;

@ParameterizedTest
@ValueSource(ints = {0, 1, 2, 10})
void testIsPositive(int number) {
    assertTrue(number > 0);
}

@ParameterizedTest
@CsvSource({
    "1, 2, 3",
    "0, 0, 0",
    "-1, -2, -3"
})
void testAdd(int a, int b, int expected) {
    assertEquals(expected, new Calculator().add(a, b));
}

@ParameterizedTest
@MethodSource("provideStringsForIsBlank")
void testIsBlank(String input, boolean expected) {
    assertEquals(expected, input.isBlank());
}

static Stream<Arguments> provideStringsForIsBlank() {
    return Stream.of(
        Arguments.of("   ", true),
        Arguments.of("hello", false),
        Arguments.of("", true)
    );
}
```

## Spring Boot 测试

### 集成测试

```java
import org.springframework.boot.test.context.SpringBootTest;
import org.springframework.test.web.servlet.MockMvc;
import org.springframework.beans.factory.annotation.Autowired;

@SpringBootTest
@AutoConfigureMockMvc
class UserControllerTest {

    @Autowired
    private MockMvc mockMvc;

    @Test
    void testGetUser() throws Exception {
        mockMvc.get("/users/1")
            .andExpect(status().isOk())
            .andExpect(jsonPath("$.name").value("Alice"));
    }
}
```

### Service 层测试（使用 @MockBean）

```java
@SpringBootTest
class UserServiceIntegrationTest {

    @Autowired
    private UserService userService;

    @MockBean
    private UserRepository userRepository;

    @Test
    void testFindById() {
        when(userRepository.findById(1L)).thenReturn(new User("Alice"));

        User result = userService.findById(1L);

        assertEquals("Alice", result.getName());
    }
}
```

### @DataJpaTest 数据库测试

```java
@DataJpaTest
class UserRepositoryTest {

    @Autowired
    private TestEntityManager entityManager;

    @Autowired
    private UserRepository userRepository;

    @Test
    void testFindByEmail() {
        User user = new User("Alice", "alice@example.com");
        entityManager.persist(user);
        entityManager.flush();

        User found = userRepository.findByEmail("alice@example.com");

        assertNotNull(found);
        assertEquals("Alice", found.getName());
    }
}
```

## 测试最佳实践

### AAA 模式

```java
@Test
void testAdd() {
    // Arrange - 准备测试数据
    Calculator calculator = new Calculator();

    // Act - 执行被测方法
    int result = calculator.add(2, 3);

    // Assert - 验证结果
    assertEquals(5, result);
}
```

### 测试命名

```java
// 推荐：方法_场景_预期结果
@Test
void add_twoPositiveNumbers_returnsSum() { }

@Test
void findById_existingId_returnsUser() { }

@Test
void findById_nonExistingId_throwsNotFoundException() { }
```

### 测试隔离

```java
// 每个测试使用独立数据，避免相互影响
private User createTestUser() {
    return User.builder()
        .name("TestUser_" + UUID.randomUUID())
        .email("test_" + UUID.randomUUID() + "@example.com")
        .build();
}
```

### 常见错误

```java
// 错误：使用 == 比较对象
assertTrue(user.getName() == "Alice"); // 字符串应用 equals()

// 正确
assertEquals("Alice", user.getName());

// 错误：在测试中打印结果代替断言
System.out.println(result); // 应该用 assertEquals

// 错误：测试过于庞大
// 一个测试只验证一个行为
```
