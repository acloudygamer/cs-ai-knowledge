# 网络编程

## 网络基础

### TCP vs UDP

| 特性 | TCP | UDP |
|------|-----|-----|
| 连接 | 面向连接 | 无连接 |
| 可靠性 | 可靠 | 不可靠 |
| 速度 | 较慢 | 较快 |
| 消息边界 | 无边界 | 有边界 |
| 适用场景 | 文件传输、Web、邮件 | DNS、视频流、游戏 |

### Socket 简介

Socket 是网络通信的端点，Java 通过 `java.net` 包提供支持。

## 参考样例

```java
// TCP 服务器
try (ServerSocket serverSocket = new ServerSocket(port)) {
    while (true) {
        Socket clientSocket = serverSocket.accept();
        new Thread(() -> handleClient(clientSocket)).start();
    }
}
```

```java
// TCP 客户端
try (Socket socket = new Socket(host, port);
     BufferedReader in = new BufferedReader(new InputStreamReader(socket.getInputStream()));
     PrintWriter out = new PrintWriter(socket.getOutputStream(), true)) {
    out.println(line);
    String response = in.readLine();
}
```

```java
// UDP 服务器
try (DatagramSocket socket = new DatagramSocket(port)) {
    while (true) {
        DatagramPacket packet = new DatagramPacket(buffer, buffer.length);
        socket.receive(packet);
        socket.send(responsePacket);
    }
}
```

```java
// URL 基本操作
URL url = new URL("https://example.com/path?query=1#section");
url.getProtocol();  // https
url.getHost();      // example.com
```

```java
// HttpURLConnection GET
HttpURLConnection conn = (HttpURLConnection) url.openConnection();
conn.setRequestMethod("GET");
conn.setConnectTimeout(5000);
int responseCode = conn.getResponseCode();
```

```java
// HttpURLConnection POST
conn.setRequestMethod("POST");
conn.setDoOutput(true);
conn.setRequestProperty("Content-Type", "application/json");
```

```java
// Java 11 HttpClient 同步 GET
HttpClient client = HttpClient.newHttpClient();
HttpRequest request = HttpRequest.newBuilder()
    .uri(URI.create("https://example.com"))
    .GET()
    .build();
HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
```

```java
// Java 11 HttpClient 异步 GET
client.sendAsync(request, HttpResponse.BodyHandlers.ofString())
    .thenApply(HttpResponse::body)
    .thenAccept(System.out::println)
    .join();
```

```java

InetAddress local = InetAddress.getLocalHost();

boolean reachable = InetAddress.getByName("8.8.8.8").isReachable(3000);
```

```java
// 检查端口是否可用
public static boolean isPortAvailable(int port) {
    try (ServerSocket socket = new ServerSocket(port)) {
        return true;
    } catch (IOException e) {
        return false;
    }
}
```

```java
// NIO ServerSocketChannel
ServerSocketChannel serverChannel = ServerSocketChannel.open();
serverChannel.socket().bind(new InetSocketAddress(8080));
serverChannel.configureBlocking(false);
Selector selector = Selector.open();
serverChannel.register(selector, SelectionKey.OP_ACCEPT);
```

```java
// 连接超时
Socket socket = new Socket();
socket.connect(new InetSocketAddress("example.com", 80), 5000);
```
