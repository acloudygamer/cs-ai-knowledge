# 正则表达式

> **本质断言**：Java 正则引擎基于非确定性有限自动机（NFA），通过回溯（backtracking）尝试所有可能的匹配路径，量词范围过宽或嵌套过深会导致指数级回溯（灾难性回溯）。

## NFA 回溯机制

<pre>
正则: a{1,3}a{1,3}a{1,3}   输入: aaaaaaaa (8个a)

尝试1: [a{1,3}][a{1,3}][a{1,3}][剩余1个a] 失败(无法填满第三个量词)
回溯2: [a{1,3}][a{1,3}][a{2,3}][剩余0个a] 失败
回溯3: [a{1,3}][a{1,3}][a{3,3}]  成功

指数级复杂度: 每个量词有(上限-下限+1)种分配可能
a{1,3}a{1,3} 对8个a: 3×3=9种分配尝试
</pre>

**为什么用 NFA 而非 DFA**：NFA 支持捕获组（capturing group）和反向引用（back-reference），这些功能在 DFA 中难以实现。性能换取功能。

## 灾难性回溯

<pre>
正则: (a+)+b   输入: aaaaaaaaaac

普通 NFA: 第一个 a+ 贪婪匹配全部8个a，然后发现没有b
逐个回退 a+，最后一个 a+ 退到0个时尝试b，失败
回溯次数 ≈ 2^n (指数级)

防御: 使用独占量词 (a+++) 或固化分组 使回溯不返回
</pre>

## Pattern.compile() 缓存

`Pattern` 内部缓存编译后的 NFA 状态机。对于同一正则表达式，多次调用 `matcher()` 不重新编译。`Matcher` 对象则持有输入字符串的引用和当前匹配状态，可重复使用。

```java
// 预编译（推荐用法）
private static final Pattern EMAIL = Pattern.compile(
    "[A-Za-z0-9+_.-]+@[A-Za-z0-9.-]+\\.[A-Za-z]{2,}");
public boolean isValid(String email) {
    return EMAIL.matcher(email).matches();
}
```

## 参考样例

```java
// 预编译（≤20行）
Pattern p = Pattern.compile("\\d{4}-\\d{2}-\\d{2}");
Matcher m = p.matcher("2024-04-13");
if (m.matches()) System.out.println(m.group(1));
```

```java
// 常用方法
boolean m = Pattern.matches("\\d+", "123");
String[] p = "a,b;c d".split("[,;\\s]+");
String r = "abc123def".replaceAll("\\d+", "#");
```

```java
// 捕获组
Pattern p = Pattern.compile("(\\d{4})-(\\d{2})");
Matcher m = p.matcher("2024-04");
if (m.matches()) System.out.println(m.group(1)); // 2024
```

```java
// 命名捕获组
Pattern p = Pattern.compile("(?<year>\\d{4})-(?<month>\\d{2})");
```

```java
// 非贪婪 vs 贪婪
Pattern greedy = Pattern.compile("<div>.*</div>");
Pattern nonGreedy = Pattern.compile("<div>.*?</div>");
```

```java
// 常用正则模式
"^\\d+$"               // 整数
"^\\d{4}-\\d{2}-\\d{2}$"  // 日期
"^1[3-9]\\d{9}$"       // 手机号
```
