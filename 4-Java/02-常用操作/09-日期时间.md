# 日期时间

> **本质断言**：`java.time`（JSR-310）是基于 Timeline 模型（国际原子时 TAI）的不可变类型设计，替代了 `Date`（可变、1900 年偏移、毫米精度）和 `Calendar`（可变、时区处理混乱）的所有使用场景。

## Date 的设计缺陷

```java
// Date 可变：多线程访问同一实例会相互干扰
Date now = new Date();
calendar.setTime(now);  // 副作用：now 被修改

// 1900 年偏移：年份从 1900 开始计算
new Date(2024 - 1900, 3, 25)  // 需传入 2024-1900=124

// 毫米精度问题：getHours()/getMinutes() 在 JDK 8+ 已废弃
date.getHours();  // 编译警告
```

## 不可变设计

<pre>
旧 API (Date/Calendar): 可变
Date d = new Date();
d.setYear(2024);  // d 本身被修改，多线程访问产生竞态条件

java.time: 不可变
LocalDate d = LocalDate.of(2024, 4, 13);
d.plusYears(1);   // 返回新实例，d 本身不变
// 无并发问题，无防御性拷贝开销
</pre>

## Timeline 模型与时区

<pre>
Instant: 自 1970-01-01T00:00:00Z（Unix Epoch）起的秒数/纳秒数
       物理时间线，全球统一，与时区无关

LocalDateTime: 人类视角时间，无时区信息
              2024-04-13T14:30:00（某时区的本地时间）

ZonedDateTime: LocalDateTime + ZoneId = 确定的物理时刻
              2024-04-13T14:30:00[Asia/Shanghai] → Instant

转换: Instant ⟷ ZonedDateTime ⟷ LocalDateTime
</pre>

`ZoneId` 代表 IANA 时区数据库中的时区标识（如 `Asia/Shanghai`），包含该时区相对于 UTC 的历史偏移规则（考虑夏令时）。

## Duration vs Period

| 类型 | 基于 | 适用场景 | 示例 |
|------|------|---------|------|
| Duration | 秒/纳秒 | 时间段（机器时间） | 30秒、2小时 |
| Period | 年/月/日 | 日历日期间隔 | 1年2个月3天 |

```java
Duration.between(start, end);  // "2小时30分"
Period.between(from, to);      // "1年2个月"
```

## 线程安全原理

`DateTimeFormatter` 是线程安全的，因为它不保存状态：解析时每次创建 `TemporalAccessor`，格式化时每次通过 `LocalDate/LocalDateTime` 的方法而非修改-formatter。

## 参考样例

```java
// LocalDate（≤20行）
LocalDate today = LocalDate.now();
LocalDate date = LocalDate.of(2024, 4, 13);
int year = date.getYear();
LocalDate next = today.plusWeeks(1);
```

```java
// LocalDateTime 格式化
LocalDateTime dt = LocalDateTime.now();
String s = dt.format(DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss"));
```

```java
// Instant
Instant i = Instant.now();
long millis = i.toEpochMilli();
```

```java
// ZonedDateTime 转换
ZonedDateTime beijing = LocalDateTime.of(2024, 4, 13, 20, 0)
    .atZone(ZoneId.of("Asia/Shanghai"));
ZonedDateTime london = beijing.withZoneSameInstant(ZoneId.of("Europe/London"));
```

```java
// 计算年龄
public int age(LocalDate birth) {
    return Period.between(birth, LocalDate.now()).getYears();
}
```

```java
// 判断工作日
public boolean isWeekday(LocalDate d) {
    DayOfWeek dow = d.getDayOfWeek();
    return dow != SATURDAY && dow != SUNDAY;
}
```
