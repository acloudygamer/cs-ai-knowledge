# 文件操作

> **本质断言**：Java I/O 是基于装饰器模式的字节流/字符流分层抽象，通过缓冲减少系统调用次数，NIO 则以 Channel 和 Buffer 实现零拷贝可能。

## I/O 体系概述

```
┌─────────────────────────────────────────────────────────┐
│                     InputStream                          │
│  (抽象基类，所有字节输入流的父类)                          │
└─────────────────────────────────────────────────────────┘
                           │
        ┌──────────────────┼──────────────────┐
        ▼                  ▼                  ▼
┌───────────────┐  ┌───────────────┐  ┌───────────────┐
│FileInputStream│  │BufferedInputSt.│  │ObjectInputSt. │
│ (节点流/原始) │  │ (装饰器/缓冲) │  │ (对象序列化)  │
└───────────────┘  └───────────────┘  └───────────────┘
```

<pre>
InputStream/OutputStream（字节流）
    ├── FileInputStream/FileOutputStream
    ├── BufferedInputStream/BufferedOutputStream
    └── ObjectInputStream/ObjectOutputStream（序列化）

Reader/Writer（字符流）
    ├── FileReader/FileWriter
    ├── BufferedReader/BufferedWriter
    └── InputStreamReader/OutputStreamWriter（字节→字符）
</pre>

## 装饰器模式

`BufferedInputStream` 包装 `FileInputStream` 时，不是继承而是组合：持有一个底层 `InputStream` 引用，在内部维护 8KB 缓冲区。每次 `read()` 先查缓冲区，缓冲区空时才触发真实 I/O。

<pre>
无缓冲：App → read() → [Syscall] → [Disk]    // 每次读1字节 = N次系统调用
有缓冲：App → read() → [Buffer] → [Syscall]   // 缓冲区满/空才Syscall
</pre>

**为什么减少系统调用能提升性能**：系统调用涉及用户态/内核态切换（context switch），每次切换约 1-5μs 开销。若读取 1MB 数据，无缓冲需 1M 次 `read()` syscall，有缓冲（8KB）只需约 125 次。

## File 类 vs Files 类

`File` 类直接封装操作系统文件描述符，操作的是"路径对象"而非真实文件内容；`Files` 类基于 NIO，使用 `Path` 接口，方法如 `readString()`/`writeString()` 会在内部复用 `FileChannel` 和 `ByteBuffer`。

## 内存映射文件原理

`FileChannel.map()` 将文件直接映射到堆外内存（`MappedByteBuffer`），省去从内核缓冲区到用户缓冲区的数据拷贝。映射后对内存的读写直接变成对文件的读写，由 OS 内存管理单元（MMU）处理换页。

<pre>
传统 I/O：  Disk → KernelBuffer → UserBuffer → App
内存映射：  Disk → KernelBuffer ↔ (mmap) ↔ AppMemory（直接访问）
</pre>

## 参考样例

```java
// Files 读取（≤20行）
String content = Files.readString(Path.of("file.txt"));
```

```java
// BufferedReader 逐行
try (BufferedReader reader = Files.newBufferedReader(Path.of("file.txt"))) {
    String line;
    while ((line = reader.readLine()) != null)
        System.out.println(line);
}
```

```java
// 对象序列化
try (ObjectOutputStream oos = new ObjectOutputStream(
        new FileOutputStream("object.dat"))) {
    oos.writeObject(new Person("Alice", 30));
}
```

```java
// FileChannel 复制
try (FileChannel in = FileChannel.open(Path.of("source.bin"));
     FileChannel out = FileChannel.open(Path.of("dest.bin"),
             StandardOpenOption.CREATE, StandardOpenOption.WRITE)) {
    in.transferTo(0, in.size(), out);
}
```

```java
// 内存映射
try (FileChannel ch = FileChannel.open(Path.of("large.bin"))) {
    MappedByteBuffer buf = ch.map(FileChannel.MapMode.READ_ONLY, 0, ch.size());
    byte b = buf.get();
}
```
