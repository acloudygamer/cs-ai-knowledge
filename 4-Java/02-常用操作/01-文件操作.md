# 文件操作

## I/O 体系概述

Java I/O 分两大体系：字节流和字符流。

```
InputStream/OutputStream（字节流）
    ├── FileInputStream/FileOutputStream
    ├── BufferedInputStream/BufferedOutputStream
    └── ObjectInputStream/ObjectOutputStream（序列化）

Reader/Writer（字符流）
    ├── FileReader/FileWriter
    ├── BufferedReader/BufferedWriter
    └── InputStreamReader/OutputStreamWriter（字节→字符）
```

## File 类

传统 API，操作文件和目录。

## Files 类（Java NIO）

现代 API，提供便捷方法。

## BufferedReader/BufferedWriter

高效字符流，减少 I/O 次数。无缓冲时每次 read()/write() 都触发系统调用，有缓冲时使用 8KB 缓冲区减少系统调用次数。

## 参考样例

```java
// File 类操作
File file = new File("path/to/file.txt");
File dir = new File("path/to/dir");

// 文件属性
file.exists();           // 是否存在
file.isFile();           // 是否是文件
file.isDirectory();      // 是否是目录
file.length();           // 文件大小（字节）
file.lastModified();     // 最后修改时间

// 路径操作
file.getName();          // 文件名
file.getParent();        // 父目录
file.getPath();          // 完整路径
file.getAbsolutePath();  // 绝对路径

// 创建/删除
file.createNewFile();    // 创建新文件
file.mkdir();            // 创建目录
file.mkdirs();           // 创建多级目录
file.delete();          // 删除文件/空目录
file.deleteOnExit();    // JVM 退出时删除

// 目录列表
String[] names = dir.list();
File[] files = dir.listFiles();
File[] files = dir.listFiles((d, name) -> name.endsWith(".txt"));
```

```java
// Files 类读取
String content = Files.readString(Path.of("file.txt"));
List<String> lines = Files.readAllLines(Path.of("file.txt"), StandardCharsets.UTF_8);
byte[] bytes = Files.readAllBytes(Path.of("file.bin"));

// BufferedReader 逐行读取
try (BufferedReader reader = Files.newBufferedReader(Path.of("file.txt"))) {
    String line;
    while ((line = reader.readLine()) != null) {
        System.out.println(line);
    }
}

// InputStream 读取
try (InputStream in = Files.newInputStream(Path.of("file.bin"))) {
    byte[] buffer = in.readAllBytes();
}
```

```java
// Files 类写入
Files.writeString(Path.of("output.txt"), "Hello, Java!");
List<String> lines = List.of("Line 1", "Line 2", "Line 3");
Files.write(Path.of("output.txt"), lines, StandardCharsets.UTF_8);
Files.write(Path.of("output.bin"), bytes);

// BufferedWriter 写入
try (BufferedWriter writer = Files.newBufferedWriter(Path.of("output.txt"))) {
    writer.write("Hello");
    writer.newLine();
    writer.write("Java");
}
```

```java
// 文件复制/移动
Files.copy(Path.of("source.txt"), Path.of("dest.txt"));
Files.copy(Path.of("source.txt"), Path.of("dest.txt"),
    StandardCopyOption.REPLACE_EXISTING,
    StandardCopyOption.COPY_ATTRIBUTES);

```

```java
// 目录操作
Files.createDirectory(Path.of("newDir"));
Files.createDirectories(Path.of("parent/child/grandchild"));

// 遍历目录（深度为1）
try (DirectoryStream<Path> stream = Files.newDirectoryStream(Path.of("dir"))) {
    for (Path entry : stream) {
        System.out.println(entry.getFileName());
    }
}

// Walk 文件树（递归）
Files.walk(Path.of("root"))
    .filter(Files::isRegularFile)
    .forEach(System.out::println);
```

```java
// 字节流操作
try (FileInputStream fis = new FileInputStream("file.bin")) {
    int byte;
    while ((byte = fis.read()) != -1) { }
    byte[] bytes = fis.readAllBytes();
}

try (FileOutputStream fos = new FileOutputStream("output.bin")) {
    fos.write(bytes);
    fos.write(0x41);
}
```

```java
// 对象序列化
try (ObjectOutputStream oos = new ObjectOutputStream(
        new FileOutputStream("object.dat"))) {
    oos.writeObject(new Person("Alice", 30));
}

try (ObjectInputStream ois = new ObjectInputStream(
        new FileInputStream("object.dat"))) {
    Person p1 = (Person) ois.readObject();
}

public class Person implements Serializable {
    private static final long serialVersionUID = 1L;
    private String name;
    private transient String password;  // 不序列化
}
```

```java
// FileChannel
try (FileChannel channel = FileChannel.open(Path.of("file.txt"))) {
    ByteBuffer buffer = ByteBuffer.allocate(1024);
    channel.read(buffer);
    buffer.flip();
    byte[] data = new byte[buffer.remaining()];
    buffer.get(data);
}

// 文件锁
try (FileChannel channel = FileChannel.open(Path.of("file.txt"));
     FileLock lock = channel.lock()) { }
```

```java
// 内存映射文件
try (FileChannel channel = FileChannel.open(Path.of("largefile.bin"))) {
    MappedByteBuffer buffer = channel.map(
        FileChannel.MapMode.READ_ONLY, 0, channel.size());
    byte b = buffer.get();
}
```

```java
// 复制大文件
Files.copy(Path.of("source.txt"), Path.of("dest.txt"));

// FileChannel 高性能复制
try (
    FileInputStream fis = new FileInputStream("source.bin");
    FileOutputStream fos = new FileOutputStream("dest.bin")
) {
    FileChannel in = fis.getChannel();
    FileChannel out = fos.getChannel();
    in.transferTo(0, in.size(), out);
}
```

```java
// 处理压缩文件
try (GZIPOutputStream gzout = new GZIPOutputStream(
        new FileOutputStream("file.txt.gz"))) {
    gzout.write("Content".getBytes());
}

try (ZipOutputStream zout = new ZipOutputStream(
        new FileOutputStream("archive.zip"))) {
    ZipEntry entry = new ZipEntry("file.txt");
    zout.putNextEntry(entry);
    zout.write("Content".getBytes());
    zout.closeEntry();
}
```
