# 文件操作

## I/O 体系概述

Java I/O 分两大体系：字节流和字符流。

```
InputStream/OutputStream（字节流）
    ├── FileInputStream/FileOutputStream
    ├── BufferedInputStream/BufferedOutputStream
    └── ObjectInputStream/ObjectOutputStream（序列化）

Reader/Writer（字符流）
    ├── FileReader/FileWriter
    ├── BufferedReader/BufferedWriter
    └── InputStreamReader/OutputStreamWriter（字节→字符）
```

## File 类

传统 API，操作文件和目录。

```java
// 创建 File 对象
File file = new File("path/to/file.txt");
File dir = new File("path/to/dir");

// 文件属性
file.exists();           // 是否存在
file.isFile();           // 是否是文件
file.isDirectory();      // 是否是目录
file.length();           // 文件大小（字节）
file.lastModified();     // 最后修改时间

// 路径操作
file.getName();          // 文件名
file.getParent();        // 父目录
file.getPath();          // 完整路径
file.getAbsolutePath();  // 绝对路径

// 创建/删除
file.createNewFile();    // 创建新文件
file.mkdir();            // 创建目录
file.mkdirs();           // 创建多级目录
file.delete();          // 删除文件/空目录
file.deleteOnExit();    // JVM 退出时删除

// 目录列表
String[] names = dir.list();           // 文件名数组
File[] files = dir.listFiles();        // File 对象数组
File[] files = dir.listFiles((d, name) -> name.endsWith(".txt")); // 过滤
```

## Files 类（Java NIO）

现代 API，提供便捷方法。

### 读取操作

```java
import java.nio.file.*;

// 读取整个文件（Java 11+）
String content = Files.readString(Path.of("file.txt"));

// 按行读取
List<String> lines = Files.readAllLines(Path.of("file.txt"), StandardCharsets.UTF_8);

// 读取为字节数组
byte[] bytes = Files.readAllBytes(Path.of("file.bin"));

// BufferedReader 逐行读取
try (BufferedReader reader = Files.newBufferedReader(Path.of("file.txt"))) {
    String line;
    while ((line = reader.readLine()) != null) {
        System.out.println(line);
    }
}

// InputStream 读取
try (InputStream in = Files.newInputStream(Path.of("file.bin"))) {
    byte[] buffer = in.readAllBytes();
}
```

### 写入操作

```java
// 写入字符串（Java 11+）
Files.writeString(Path.of("output.txt"), "Hello, Java!");

// 按行写入
List<String> lines = List.of("Line 1", "Line 2", "Line 3");
Files.write(Path.of("output.txt"), lines, StandardCharsets.UTF_8);

// 字节数组写入
Files.write(Path.of("output.bin"), bytes);

// BufferedWriter 写入
try (BufferedWriter writer = Files.newBufferedWriter(Path.of("output.txt"))) {
    writer.write("Hello");
    writer.newLine();
    writer.write("Java");
}
```

### 文件复制/移动

```java
// 复制
Files.copy(Path.of("source.txt"), Path.of("dest.txt"));
Files.copy(Path.of("source.txt"), Path.of("dest.txt"),
    StandardCopyOption.REPLACE_EXISTING,
    StandardCopyOption.COPY_ATTRIBUTES);

// 移动/重命名
Files.move(Path.of("source.txt"), Path.of("dest.txt"));
Files.move(Path.of("source.txt"), Path.of("dest.txt"),
    StandardCopyOption.REPLACE_EXISTING);
```

### 目录操作

```java
// 创建目录
Files.createDirectory(Path.of("newDir"));
Files.createDirectories(Path.of("parent/child/grandchild"));

// 遍历目录（深度为1）
try (DirectoryStream<Path> stream = Files.newDirectoryStream(Path.of("dir"))) {
    for (Path entry : stream) {
        System.out.println(entry.getFileName());
    }
}

// 遍历目录（带过滤器）
try (DirectoryStream<Path> stream = Files.newDirectoryStream(
        Path.of("dir"), "*.{java,xml}")) {
    for (Path entry : stream) {
        System.out.println(entry);
    }
}

// Walk 文件树（递归）
Files.walk(Path.of("root"))
    .filter(Files::isRegularFile)
    .forEach(System.out::println);
```

### 文件属性

```java
// 基本属性
Files.exists(path);
Files.isRegularFile(path);
Files.isDirectory(path);
Files.isSymbolicLink(path);
Files.size(path);
Files.getLastModifiedTime(path);

// 设置属性
Files.setLastModifiedTime(path, FileTime.fromMillis(System.currentTimeMillis()));

// Posix 属性（Unix-like 系统）
PosixFileAttributes attrs = Files.readAttributes(
    path, PosixFileAttributes.class);
System.out.println("Owner: " + attrs.owner().getName());
System.out.println("Permissions: " + attrs.permissions());
```

### Path 与 File 的转换

```java
// Path 是 Java NIO 的路径表示
Path path = Path.of("file.txt");
Path path = Paths.get("dir", "file.txt");  // 兼容写法

// File 与 Path 互转
File file = path.toFile();
Path path = file.toPath();
```

## BufferedReader/BufferedWriter

高效字符流，减少 I/O 次数。

```java
// BufferedReader 逐行读取
try (BufferedReader reader = new BufferedReader(new FileReader("file.txt"))) {
    String line;
    while ((line = reader.readLine()) != null) {
        System.out.println(line);
    }
}

// BufferedWriter 写入
try (BufferedWriter writer = new BufferedWriter(new FileWriter("output.txt"))) {
    writer.write("Hello");
    writer.newLine();
    writer.write("Java");
}

// 性能对比
// 无缓冲：每次 read()/write() 都触发系统调用
// 有缓冲：8KB 缓冲区，减少系统调用次数
```

## 字节流操作

### FileInputStream/FileOutputStream

```java
// 读取字节
try (FileInputStream fis = new FileInputStream("file.bin")) {
    int byte;
    while ((byte = fis.read()) != -1) {
        // 处理字节
    }
}

// 读取到字节数组
byte[] bytes = fis.readAllBytes();

// 写入字节
try (FileOutputStream fos = new FileOutputStream("output.bin")) {
    fos.write(bytes);
    fos.write(0x41);  // 写入单个字节
}
```

### BufferedInputStream/BufferedOutputStream

```java
// Buffered 包装
try (BufferedInputStream bis = new BufferedInputStream(
        new FileInputStream("file.bin"))) {
    byte[] buffer = bis.readAllBytes();
}

// BufferedOutputStream
try (BufferedOutputStream bos = new BufferedOutputStream(
        new FileOutputStream("output.bin"))) {
    bos.write(bytes);
}
```

## 对象序列化

### ObjectOutputStream/ObjectInputStream

```java
// 序列化（写入对象）
try (ObjectOutputStream oos = new ObjectOutputStream(
        new FileOutputStream("object.dat"))) {
    oos.writeObject(new Person("Alice", 30));
    oos.writeObject(new Person("Bob", 25));
}

// 反序列化（读取对象）
try (ObjectInputStream ois = new ObjectInputStream(
        new FileInputStream("object.dat"))) {
    Person p1 = (Person) ois.readObject();
    Person p2 = (Person) ois.readObject();
}

// 对象必须实现 Serializable
public class Person implements Serializable {
    private static final long serialVersionUID = 1L;
    private String name;
    private int age;

    // transient 字段不序列化
    private transient String password;
}
```

### SerialVersionUID

```java
public class Person implements Serializable {
    // 必须声明 serialVersionUID
    private static final long serialVersionUID = 1L;

    // 如果不声明，运行时自动生成
    // 类结构变化时 UID 会变，导致反序列化失败
}
```

## NIO Channels 与 Buffers

### FileChannel

```java
// 读取到 Buffer
try (FileChannel channel = FileChannel.open(Path.of("file.txt"))) {
    ByteBuffer buffer = ByteBuffer.allocate(1024);
    channel.read(buffer);
    buffer.flip();  // 切换读模式
    byte[] data = new byte[buffer.remaining()];
    buffer.get(data);
}

// 直接写入（零拷贝优化）
try (FileChannel channel = FileChannel.open(Path.of("output.txt"),
        StandardOpenOption.WRITE,
        StandardOpenOption.CREATE)) {
    ByteBuffer buffer = StandardCharsets.UTF_8.encode("Hello");
    channel.write(buffer);
}

// 文件锁
try (FileChannel channel = FileChannel.open(Path.of("file.txt"));
     FileLock lock = channel.lock()) {
    // 持有锁期间的操作
}
```

### MappedByteBuffer（内存映射文件）

```java
try (FileChannel channel = FileChannel.open(Path.of("largefile.bin"))) {
    // 将文件映射到内存，避免内核拷贝
    MappedByteBuffer buffer = channel.map(
        FileChannel.MapMode.READ_ONLY, 0, channel.size());

    // 直接读取
    byte b = buffer.get();
}
```

## 常见 I/O 模式

### 扫描文件内容

```java
// 方式1：Scanner
try (Scanner scanner = new Scanner(Path.of("file.txt"))) {
    while (scanner.hasNextLine()) {
        String line = scanner.nextLine();
        // 处理行
    }
}

// 方式2：Files.lines（流式处理，Java 8+）
try (Stream<String> lines = Files.lines(Path.of("file.txt"))) {
    lines.filter(line -> line.startsWith("ERROR"))
         .forEach(System.out::println);
}
```

### 复制大文件

```java
// 方式1：Files.copy（简单）
Files.copy(Path.of("source.txt"), Path.of("dest.txt"));

// 方式2：BufferedReader + BufferedWriter（可控）
try (
    BufferedReader reader = Files.newBufferedReader(Path.of("source.txt"));
    BufferedWriter writer = Files.newBufferedWriter(Path.of("dest.txt"))
) {
    String line;
    while ((line = reader.readLine()) != null) {
        writer.write(line);
        writer.newLine();
    }
}

// 方式3：FileChannel（高性能）
try (
    FileInputStream fis = new FileInputStream("source.bin");
    FileOutputStream fos = new FileOutputStream("dest.bin")
) {
    FileChannel in = fis.getChannel();
    FileChannel out = fos.getChannel();
    in.transferTo(0, in.size(), out);
}
```

### 处理压缩文件

```java
// GZIP 压缩
try (
    GZIPOutputStream gzout = new GZIPOutputStream(
        new FileOutputStream("file.txt.gz"))
) {
    gzout.write("Content".getBytes());
}

try (
    GZIPInputStream gzin = new GZIPInputStream(
        new FileInputStream("file.txt.gz"))
) {
    String content = new String(gzin.readAllBytes());
}

// ZIP 文件
try (ZipOutputStream zout = new ZipOutputStream(
        new FileOutputStream("archive.zip"))) {
    ZipEntry entry = new ZipEntry("file.txt");
    zout.putNextEntry(entry);
    zout.write("Content".getBytes());
    zout.closeEntry();
}
```

### 使用 PathMatcher

```java
// 匹配文件
PathMatcher matcher = FileSystems.getDefault()
    .getPathMatcher("glob:**/*.java");

Files.walk(Path.of("src"))
    .filter(Files::isRegularFile)
    .filter(matcher::matches)
    .forEach(System.out::println);

// glob 语法
// *.java      - 任意 java 文件
// **/*.java   - 任意深度的 java 文件
// {a,b}.java  - a.java 或 b.java
```
