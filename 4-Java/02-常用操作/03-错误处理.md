# 错误处理

## 异常体系

Java 所有异常继承自 `Throwable`，分为两大分支：Error（系统级错误，不应捕获）和 Exception（可处理异常）。

### 受检异常 vs 非受检异常

- **受检异常（Checked Exception）**：编译器强制要求处理或声明，调用者必须 catch 或 throws
- **非受检异常（Unchecked Exception）**：继承自 `RuntimeException`，不强制处理

### Java 异常处理的底层机制

异常处理使用 **异常表**（Exception Table）实现。

## try/catch/finally

### try-with-resources（Java 7+）

自动关闭实现 `AutoCloseable` 的资源，无需 finally 块。

### finally 与返回值

finally 中的 return 会覆盖 try/catch 中的 return，finally 中的异常会抑制 try/catch 中的异常。

## 异常抛出与自定义

### throw 与 throws

`throw` 抛出异常对象，`throws` 声明方法可能抛出的异常。

### 自定义异常

业务异常通常为非受检异常，包装异常用于保留原始异常信息。

### 异常链与原因

使用构造函数传递 cause 或使用 addSuppressed 保留被抑制的异常。

## 异常处理最佳实践

### 参考样例

```java
// 受检异常必须声明或捕获
public void readFile() throws IOException {
    FileReader reader = new FileReader("file.txt");
}

// 非受检异常可不处理
public void divide(int a, int b) {
    if (b == 0) {
        throw new ArithmeticException("除数不能为零");
    }
}
```

```java
// 多异常捕获
try {
} catch (IOException | SQLException e) {
    System.err.println("IO 或数据库错误: " + e.getMessage());
}
```

```java
// try-with-resources
try (BufferedReader reader = new BufferedReader(new FileReader("file.txt"))) {
    String line = reader.readLine();
} catch (IOException e) {
    System.err.println("IO 错误: " + e.getMessage());
}
```

```java
// 自定义异常
public class BusinessException extends RuntimeException {
    private final String code;

    public BusinessException(String message) {
        super(message);
        this.code = "BUSINESS_ERROR";
    }

    public BusinessException(String code, String message) {
        super(message);
        this.code = code;
    }

    public String getCode() { return code; }
}
```

```java
// 异常链
try {
} catch (IOException e) {
    throw new ServiceException("服务失败", e);
}

// 获取原因链
Throwable cause = e.getCause();
Throwable[] suppressed = e.getSuppressed();
```

```java
// 只捕获真正能处理的异常
try {
} catch (IOException e) {
    log.error("IO 错误", e);
    throw new ServiceException("无法读取文件", e);
}
```

```java
// 不要用异常控制业务逻辑 - 使用 Optional
Optional<User> user = userRepository.findById(id);
if (user.isPresent()) {
    // 处理用户
} else {
    // 处理找不到用户
}
```

```java
// 清理资源 - try-with-resources（推荐）
try (Connection conn = dataSource.getConnection()) {
    // 使用连接
}
```

```java
// 全局异常处理（Spring Boot）
@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(BusinessException.class)
    public ResponseEntity<ErrorResponse> handleBusiness(BusinessException e) {
        return ResponseEntity
            .status(HttpStatus.BAD_REQUEST)
            .body(new ErrorResponse(e.getCode(), e.getMessage()));
    }

    @ExceptionHandler(Exception.class)
    public ResponseEntity<ErrorResponse> handleGeneric(Exception e) {
        log.error("Unexpected error", e);
        return ResponseEntity
            .status(HttpStatus.INTERNAL_SERVER_ERROR)
            .body(new ErrorResponse("INTERNAL_ERROR", "系统错误"));
    }
}

public record ErrorResponse(String code, String message) {}
```

```java
// 参数验证
public void createOrder(String userId, List<Item> items) {
    Objects.requireNonNull(userId, "用户ID不能为空");
    Objects.requireNonNull(items, "订单项不能为空");

    if (items.isEmpty()) {
        throw new IllegalArgumentException("订单项不能为空");
    }
}
```

// 异常测试

public void testInvalidInput() {
    validator.validate(null);
}

@Test
public void testExceptionMessage() {
    IllegalArgumentException e = assertThrows(
        IllegalArgumentException.class,
        () -> validator.validate(null)
    );
    assertEquals("输入不能为空", e.getMessage());
}
