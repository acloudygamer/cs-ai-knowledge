# 网络请求

## 概述

Java中进行HTTP请求主要有两种方式：JDK自带的`HttpClient`（Java 11+）和第三方库`OkHttp`。两者都支持同步和异步请求。

## HttpClient（Java 11+）

现代HTTP客户端API，替代了旧的`HttpURLConnection`，支持HTTP/2。

### 发送GET请求

```java
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

HttpClient client = HttpClient.newHttpClient();

// 同步GET
HttpRequest request = HttpRequest.newBuilder()
    .uri(URI.create("https://api.example.com/data"))
    .header("Accept", "application/json")
    .GET()
    .build();

HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
System.out.println(response.statusCode());
System.out.println(response.body());
```

### 发送POST请求

```java
// POST JSON数据
String jsonBody = "{\"name\":\"Alice\",\"age\":30}";
HttpRequest postRequest = HttpRequest.newBuilder()
    .uri(URI.create("https://api.example.com/users"))
    .header("Content-Type", "application/json")
    .POST(HttpRequest.BodyPublishers.ofString(jsonBody))
    .build();

HttpResponse<String> postResponse = client.send(postRequest, HttpResponse.BodyHandlers.ofString());
```

### 异步请求

```java
// 异步GET
CompletableFuture<HttpResponse<String>> future =
    client.sendAsync(request, HttpResponse.BodyHandlers.ofString());

future.thenApply(HttpResponse::body)
      .thenAccept(System.out::println)
      .exceptionally(ex -> {
          System.err.println("请求失败: " + ex.getMessage());
          return null;
      });

// 异步POST
CompletableFuture<HttpResponse<String>> asyncPost =
    client.sendAsync(postRequest, HttpResponse.BodyHandlers.ofString());
```

### 设置超时

```java
HttpClient client = HttpClient.newBuilder()
    .connectTimeout(Duration.ofSeconds(10))
    .build();

HttpRequest request = HttpRequest.newBuilder()
    .uri(URI.create("https://api.example.com/slow"))
    .timeout(Duration.ofSeconds(30))  // 读取超时
    .GET()
    .build();
```

### 处理响应状态码

```java
HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());

switch (response.statusCode()) {
    case 200 -> System.out.println("成功: " + response.body());
    case 201 -> System.out.println("已创建");
    case 400 -> System.err.println("请求参数错误");
    case 401 -> System.err.println("未授权");
    case 404 -> System.err.println("资源不存在");
    case 500 -> System.err.println("服务器内部错误");
    default -> System.err.println("未知状态码: " + response.statusCode());
}
```

## OkHttp

第三方库，功能丰富，社区活跃，使用广泛。

### 引入依赖

```xml
<dependency>
    <groupId>com.squareup.okhttp3</groupId>
    <artifactId>okhttp</artifactId>
    <version>4.12.0</version>
</dependency>
```

### 同步请求

```java
import okhttp3.*;
import java.io.IOException;

OkHttpClient client = new OkHttpClient();

// GET请求
Request getRequest = new Request.Builder()
    .url("https://api.example.com/data")
    .addHeader("Accept", "application/json")
    .build();

try (Response response = client.newCall(getRequest).execute()) {
    if (response.isSuccessful()) {
        System.out.println(response.body().string());
    } else {
        System.err.println("请求失败: " + response.code());
    }
} catch (IOException e) {
    e.printStackTrace();
}

// POST请求（JSON）
MediaType JSON = MediaType.parse("application/json; charset=utf-8");
String jsonBody = "{\"name\":\"Alice\",\"age\":30}";

RequestBody body = RequestBody.create(jsonBody, JSON);
Request postRequest = new Request.Builder()
    .url("https://api.example.com/users")
    .post(body)
    .build();

try (Response response = client.newCall(postRequest).execute()) {
    System.out.println(response.body().string());
}
```

### 异步请求

```java
client.newCall(getRequest).enqueue(new Callback() {
    @Override
    public void onFailure(@NotNull Call call, @NotNull IOException e) {
        System.err.println("请求失败: " + e.getMessage());
    }

    @Override
    public void onResponse(@NotNull Call call, @NotNull Response response) throws IOException {
        try (response) {
            if (response.isSuccessful()) {
                System.out.println(response.body().string());
            }
        }
    }
});
```

### 表单提交

```java
// form-urlencoded表单
RequestBody formBody = new FormBody.Builder()
    .add("username", "alice")
    .add("password", "secret")
    .build();

Request formRequest = new Request.Builder()
    .url("https://api.example.com/login")
    .post(formBody)
    .build();

// Multipart上传文件
RequestBody multipartBody = new MultipartBody.Builder()
    .setType(MultipartBody.FORM)
    .addFormDataPart("file", "report.pdf",
        RequestBody.create(new File("report.pdf"), MediaType.parse("application/pdf")))
    .addFormDataPart("description", "Monthly Report")
    .build();

Request multipartRequest = new Request.Builder()
    .url("https://api.example.com/upload")
    .post(multipartBody)
    .build();
```

### 复用连接池

```java
// 共享连接池（推荐用于高并发场景）
ConnectionPool pool = new ConnectionPool(5, 5, TimeUnit.MINUTES);
OkHttpClient client = new OkHttpClient.Builder()
    .connectionPool(pool)
    .build();
```

## 对比选择

| 特性 | HttpClient | OkHttp |
|------|------------|--------|
| Java版本要求 | Java 11+ | Java 7+ |
| HTTP/2支持 | 原生支持 | 支持 |
| 连接池 | 需手动配置 | 内置 |
| 社区生态 | JDK标准 | 成熟活跃 |
| Spring集成 | RestTemplate底层 | WebClient可选 |

## 实际应用建议

### GET请求封装示例

```java
public String get(String url) throws Exception {
    HttpClient client = HttpClient.newHttpClient();
    HttpRequest request = HttpRequest.newBuilder()
        .uri(URI.create(url))
        .GET()
        .build();

    HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
    if (response.statusCode() != 200) {
        throw new RuntimeException("HTTP " + response.statusCode());
    }
    return response.body();
}
```

### POST请求封装示例

```java
public String post(String url, String jsonBody) throws Exception {
    HttpClient client = HttpClient.newHttpClient();
    HttpRequest request = HttpRequest.newBuilder()
        .uri(URI.create(url))
        .header("Content-Type", "application/json")
        .POST(HttpRequest.BodyPublishers.ofString(jsonBody))
        .build();

    HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
    return response.body();
}
```

### 处理网络异常

```java
try {
    HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
} catch (InterruptedException e) {
    Thread.currentThread().interrupt();
    throw new RuntimeException("请求被中断", e);
} catch (IOException e) {
    throw new RuntimeException("网络IO错误", e);
}
```
