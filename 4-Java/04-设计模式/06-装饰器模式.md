# 装饰器模式

## 概述

装饰器模式动态地给对象添加额外职责，比继承更灵活。

### 结构

```
Component (接口)
    |
    +-- ConcreteComponent
    |
    +-- Decorator (抽象装饰器)
          |
          +-- ConcreteDecoratorA
          +-- ConcreteDecoratorB
```

### 对比继承

| 继承 | 装饰器 |
|------|--------|
| 编译时静态 | 运行时动态 |
| 父类所有行为 | 按需包装 |
| 类爆炸 | 单一职责 |

## 传统实现

### 组件接口

```java
public interface Coffee {
    String getDescription();
    double getCost();
}
```

### 具体组件

```java
public class SimpleCoffee implements Coffee {
    @Override
    public String getDescription() {
        return "Simple Coffee";
    }

    @Override
    public double getCost() {
        return 2.0;
    }
}
```

### 抽象装饰器

```java
public abstract class CoffeeDecorator implements Coffee {
    protected final Coffee coffee;

    public CoffeeDecorator(Coffee coffee) {
        this.coffee = coffee;
    }

    @Override
    public String getDescription() {
        return coffee.getDescription();
    }

    @Override
    public double getCost() {
        return coffee.getCost();
    }
}
```

### 具体装饰器

```java
public class MilkDecorator extends CoffeeDecorator {
    public MilkDecorator(Coffee coffee) {
        super(coffee);
    }

    @Override
    public String getDescription() {
        return super.getDescription() + ", Milk";
    }

    @Override
    public double getCost() {
        return super.getCost() + 0.5;
    }
}

public class SugarDecorator extends CoffeeDecorator {
    public SugarDecorator(Coffee coffee) {
        super(coffee);
    }

    @Override
    public String getDescription() {
        return super.getDescription() + ", Sugar";
    }

    @Override
    public double getCost() {
        return super.getCost() + 0.2;
    }
}

public class WhipDecorator extends CoffeeDecorator {
    public WhipDecorator(Coffee coffee) {
        super(coffee);
    }

    @Override
    public String getDescription() {
        return super.getDescription() + ", Whip";
    }

    @Override
    public double getCost() {
        return super.getCost() + 0.7;
    }
}
```

### 使用

```java
Coffee coffee = new SimpleCoffee();
System.out.println(coffee.getDescription() + ": $" + coffee.getCost());
// Simple Coffee: $2.0

coffee = new MilkDecorator(coffee);
System.out.println(coffee.getDescription() + ": $" + coffee.getCost());
// Simple Coffee, Milk: $2.5

coffee = new SugarDecorator(coffee);
System.out.println(coffee.getDescription() + ": $" + coffee.getCost());
// Simple Coffee, Milk, Sugar: $2.7

coffee = new WhipDecorator(coffee);
System.out.println(coffee.getDescription() + ": $" + coffee.getCost());
// Simple Coffee, Milk, Sugar, Whip: $3.4
```

## Java I/O 装饰器

### I/O 类结构

```
InputStream (抽象组件)
    |
    +-- FileInputStream (具体组件)
    |
    +-- FilterInputStream (装饰器)
          |
          +-- BufferedInputStream (具体装饰器)
          +-- DataInputStream (具体装饰器)
```

### 使用

```java
// 基本文件读取
InputStream is = new FileInputStream("data.txt");

// 缓冲装饰
InputStream buffered = new BufferedInputStream(
    new FileInputStream("data.txt")
);

// 链式装饰
DataInputStream dis = new DataInputStream(
    new BufferedInputStream(
        new FileInputStream("data.txt")
    )
);

// 读取基本类型
int i = dis.readInt();
double d = dis.readDouble();
String s = dis.readUTF();
```

### 自定义装饰器

```java
public class UpperCaseInputStream extends FilterInputStream {
    public UpperCaseInputStream(InputStream in) {
        super(in);
    }

    @Override
    public int read() throws IOException {
        int c = super.read();
        return (c == -1 ? c : Character.toUpperCase((char) c));
    }

    @Override
    public int read(byte[] b, int off, int len) throws IOException {
        int result = super.read(b, off, len);
        for (int i = off; i < off + result; i++) {
            b[i] = (byte) Character.toUpperCase((char) b[i]);
        }
        return result;
    }
}

// 使用
InputStream is = new UpperCaseInputStream(
    new BufferedInputStream(
        new FileInputStream("data.txt")
    )
);
```

## 缓存装饰器

### 通用缓存装饰器

```java
public class CachedDataSource implements DataSource {
    private final DataSource original;
    private final Map<String, byte[]> cache = new ConcurrentHashMap<>();

    public CachedDataSource(DataSource original) {
        this.original = original;
    }

    @Override
    public byte[] read() {
        return cache.computeIfAbsent("data", k -> original.read());
    }

    @Override
    public void write(byte[] data) {
        cache.clear();
        original.write(data);
    }

    public void invalidate() {
        cache.clear();
    }
}
```

### 异步刷新装饰器

```java
public class AsyncWriteDecorator implements DataSource {
    private final DataSource original;
    private final ExecutorService executor = Executors.newSingleThreadExecutor();

    public AsyncWriteDecorator(DataSource original) {
        this.original = original;
    }

    @Override
    public byte[] read() {
        return original.read();
    }

    @Override
    public void write(byte[] data) {
        executor.submit(() -> original.write(data));
    }
}
```

## 日志装饰器

### 请求日志装饰器

```java
public class LoggingDataSource implements DataSource {
    private final DataSource original;
    private final Logger logger = Logger.getLogger(DataSource.class);

    public LoggingDataSource(DataSource original) {
        this.original = original;
    }

    @Override
    public byte[] read() {
        logger.info("Reading data...");
        long start = System.currentTimeMillis();
        byte[] data = original.read();
        logger.info("Read " + data.length + " bytes in " +
            (System.currentTimeMillis() - start) + "ms");
        return data;
    }

    @Override
    public void write(byte[] data) {
        logger.info("Writing " + data.length + " bytes...");
        long start = System.currentTimeMillis();
        original.write(data);
        logger.info("Write completed in " +
            (System.currentTimeMillis() - start) + "ms");
    }
}
```

## 装饰器 vs 代理模式

### 装饰器

- 透明包装（包装后的对象类型相同）
- 增强行为
- 可以嵌套多个装饰器

```java
// 装饰器
InputStream is = new BufferedInputStream(new FileInputStream("file"));
// is 仍然是 InputStream
```

### 代理模式

- 控制对原始对象的访问
- 不一定改变行为
- 通常持有原始对象的引用

```java
// 代理
Image image = new ImageProxy("large.jpg");
// image 是 Image 类型，但可能不会加载真实图片直到需要
```

## Java 装饰器注解

### @Decorator（CDI）

```java
public interface PricingService {
    double calculatePrice(double basePrice);
}

@Decorator
public class LoggingPricingDecorator implements PricingService {
    @Inject
    @Delegate
    private PricingService delegate;

    @Override
    public double calculatePrice(double basePrice) {
        System.out.println("Calculating price: " + basePrice);
        return delegate.calculatePrice(basePrice);
    }
}
```

## 函数式装饰器

### Chain of Responsibility

```java
@FunctionalInterface
public interface Handler<T, R> {
    R handle(T input);

    default Handler<T, R> andThen(Handler<T, R> after) {
        return t -> {
            R result = this.handle(t);
            return after.handle(result);
        };
    }
}

// 使用
Handler<String, String> pipeline =
    s -> s.toUpperCase()
        .andThen(s -> s + " - processed")
        .andThen(s -> "Result: " + s);

String result = pipeline.handle("hello"); // Result: HELLO - processed
```

### Decorator with Function

```java
public class DecoratedService<T> {
    private final Function<T, T> decorator;

    public DecoratedService(Function<T, T> decorator) {
        this.decorator = decorator;
    }

    public static <T> DecoratedService<T> of(Function<T, T> decorator) {
        return new DecoratedService<>(decorator);
    }

    public DecoratedService<T> andThen(Function<T, T> after) {
        return new DecoratedService<>(decorator.andThen(after));
    }

    public T process(T input) {
        return decorator.apply(input);
    }
}

// 使用
DecoratedService<String> service = DecoratedService.of(s -> s.trim())
    .andThen(s -> s.toLowerCase())
    .andThen(s -> "Processed: " + s);

String result = service.process("  HELLO  ");
// Processed: hello
```

## 最佳实践

### 组合多个装饰器

```java
// 创建顺序很重要
DataSource source = new FileDataSource("file.txt");
source = new CompressionDecorator(source);
source = new EncryptionDecorator(source);
source = new LoggingDecorator(source);
```

### 抽象到接口

```java
// 好的实践：装饰器实现相同接口
public class BufferedOutputStream extends FilterOutputStream {
    // ...
}

// 不好的实践：直接继承具体类
public class MyDataSource extends FileDataSource { // 紧耦合
    // ...
}
```

### 避免过度装饰

```java
// 过度
new LoggingDecorator(
    new CachingDecorator(
        new RetryDecorator(
            new TimeoutDecorator(
                new RealService()
            )
        )
    )
);

// 适度：使用配置或组合
public class ServicePipeline {
    private final List<ServiceDecorator> decorators;

    public ServicePipeline(Service service, List<ServiceDecorator> decorators) {
        this.decorators = decorators;
    }
}
```
