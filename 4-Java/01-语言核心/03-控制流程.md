# 控制流程

## 定义

Java 的控制流程语句（if/else、switch、for、while）本质上是**有穷状态自动机**（Finite State Machine, FSM）的语法结构化表示。编译器将控制流图（Control Flow Graph, CFG）转换为基本块，用于优化和异常处理。

从计算理论视角，控制流语句将程序划分为**基本块**（Basic Block），块内是顺序执行，块间通过跳转连接。这一表示是后续优化（死代码消除、公共子表达式消除、常量传播）的基础。

**基本块的数学定义**：基本块是程序中满足以下条件的最长连续指令序列：
1. 入口的第一个语句
2. 跳转目标
3. 跳转语句的下一条

设程序指令序列为 $I = (i_1, i_2, ..., i_n)$ ，基本块划分将 $I$ 划分为 $B_1, B_2, ..., B_k$ ，使得 $\bigcup_{j=1}^k B_j = I$ ，且 $B_j \cap B_l = \emptyset$ （ $j \neq l$ ）。 ，基本块划分将 $I$ 划分为 $B_1, B_2, ..., B_k$ ，使得 $\bigcup_{j=1}^k B_j = I$ ，且 $B_j \cap B_l = \emptyset$ （ $j \neq l$ ）。 划分为 $B_1, B_2, ..., B_k$ ，使得 $\bigcup_{j=1}^k B_j = I$ ，且 $B_j \cap B_l = \emptyset$ （ $j \neq l$ ）。 ，使得 $\bigcup_{j=1}^k B_j = I$ ，且 $B_j \cap B_l = \emptyset$ （ $j \neq l$ ）。 ，且 $B_j \cap B_l = \emptyset$ （ $j \neq l$ ）。 （ $j \neq l$ ）。 ）。

### 循环不变式与正确性证明

### 分支预测的熵模型

CPU 的**分支预测器**使用**分支历史表**（Branch History Table, BHT）和**模式历史表**（Pattern History Table, PHT）进行预测。

设分支行为序列为 $B = b_1, b_2, ..., b_n$ ，分支预测器维护状态机： ，分支预测器维护状态机：

| 状态 | 预测 | 实际 Taken | 下一状态 |
|------|------|------------|----------|
| strongly not taken (00) | N | N → 01, T → 10 | |
| weakly not taken (01) | N | N → 10, T → 00 | |
| weakly taken (10) | T | N → 00, T → 11 | |
| strongly taken (11) | T | N → 01, T → 10 | |

**预测准确率**：对于高度可预测的分支（如循环），准确率可达 95%+。对于随机分支，准确率接近 50%。

**流水线损失**：分支预测失败时，流水线需要清空并重新取指，损失 10-20 周期。

**分支预测的熵解释**：分支序列的信息熵 $H(B) = -\sum p_i \log_2 p_i$ 衡量了分支的不可预测程度。熵越低（ $p \to 0$ 或  $p \to 1$），分支越可预测；熵越高（  $p = 0.5$），分支越接近随机。 衡量了分支的不可预测程度。熵越低（ $p \to 0$ 或  $p \to 1$），分支越可预测；熵越高（  $p = 0.5$），分支越接近随机。 或  $p \to 1$ ），分支越可预测；熵越高（  $p = 0.5$），分支越接近随机。），分支越可预测；熵越高（  $p = 0.5$ ），分支越接近随机。），分支越接近随机。

## 机制

### if/else 的分支预测

CPU 的**分支预测器**尝试预测跳转方向。高度可预测的分支（如大多数 if/else）几乎无性能损失。

**性能约束**：
- 分支预测失败：流水线清空，10-20 周期损失
- 分支预测成功：几乎零成本

if/else 的 FSM 语义：
```
q0: 条件检查 ──true──> q_true（执行then）
                └──false──> q_false（执行else）
```

**归约终点**：条件分支是**二元选择自动机**，状态数仅为 2。编译器通过指令重排（Instruction Scheduling）将分支推向代码块尾部，减少预测失败的影响。

### for 循环 vs while 循环的等价性

所有 for 循环都可以改写为 while 循环：

```java
// for 循环
for (init; condition; update) {
    body;
}

// 等价于 while 循环
{
    init;
    while (condition) {
        body;
        update;
    }
}
```

**数学解释**：for 循环是 while 循环的**语法糖**，但 for 循环的 init/update 在同一作用域使变量声明更紧凑。

### break 和 continue 的跳转语义

- `break`：跳转到循环体之外的第一条语句（退出最近的外层循环或 switch）
- `continue`：跳转到循环体的末尾（开始下一次迭代）

**FSM 视角**：
- break： $q_{current} \rightarrow q_{exit}$ （终止状态转移） （终止状态转移）
- continue： $q_{current} \rightarrow q_{loop-start}$ （回到循环起始） （回到循环起始）

### labeled break/continue

带标签的 break/continue 可以跳出或继续外层嵌套循环：

```java
outer:
for (int i = 0; i < 10; i++) {
    for (int j = 0; j < 10; j++) {
        if (condition(i, j)) {
            break outer;  // 跳出外层循环
        }
    }
}
```

**约束**：标签必须正确定声明在被跳出的循环之前。错误的标签使用导致编译错误。

**finally 块的数学语义**：finally 块在控制流离开 try 块时**总是执行**，无论是以正常路径还是异常路径离开。这形成了一个**图的遍历顺序问题**——finally 必须在所有可能离开路径上被插入。

    int lo = 0, hi = arr.length - 1;
    // 循环不变式：arr[0..lo-1] < target, arr[hi+1..n-1] > target
