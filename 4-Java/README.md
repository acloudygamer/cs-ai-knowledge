# Java

**运行在 JVM 上的静态类型语言**——源代码编译为字节码，由虚拟机解释/即时编译执行。一次编译、到处运行的代价与收益都来自这个中间层。

版本口径：**stable = Java 21（LTS）/ latest = Java 25（LTS）**。
