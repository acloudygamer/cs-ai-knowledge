# 泛型

## 概述

泛型（Generics）是 Java 5 引入的特性，支持在编译时进行类型安全检查，避免强制类型转换。

核心优势：
- **类型安全**：编译时检查，减少 `ClassCastException`
- **代码复用**：编写可适用于多种类型的通用代码
- **消除强制转换**：代码更简洁清晰

## 类型参数命名约定

- `<E>` - Element（集合元素）
- `<K, V>` - Key, Value（键值对）
- `<T>` - Type（一般类型）
- `<N>` - Number（数字类型）
- `<R>` - Result（返回类型）
- `<S, U, V>` - 多类型参数

## 泛型类

### 参考样例

```java
public class Box<T> {
    private T content;

    public Box(T content) {
        this.content = content;
    }

    public T getContent() {
        return content;
    }

    public void setContent(T content) {
        this.content = content;
    }
}

// 使用
Box<String> stringBox = new Box<>("Hello");
String content = stringBox.getContent();
```

## 泛型方法

### 参考样例

```java
public class ArrayUtil {

    // 泛型方法
    public static <T> T findFirst(T[] array, Predicate<T> predicate) {
        for (T element : array) {
            if (predicate.test(element)) {
                return element;
            }
        }
        return null;
    }

    // 泛型方法（带边界）
    public static <T extends Comparable<T>> T findMax(T[] array) {
        if (array == null || array.length == 0) {
            return null;
        }
        T max = array[0];
        for (int i = 1; i < array.length; i++) {
            if (array[i].compareTo(max) > 0) {
                max = array[i];
            }
        }
        return max;
    }
}
```

## 有界类型参数

### 上界限定

`T extends Number` 表示 T 必须继承或实现 Number。可使用 `&` 分隔多个上界。

### 下界限定

`? super T` 表示 T 或 T 的父类型。写入安全，返回类型是 Object。

### 通配符对比

| 符号 | 含义 | 用途 |
|------|------|------|
| `<?>` | 无界通配符 | 只读操作，不知道具体类型 |
| `<? extends T>` | 上界限定 | 读取安全（返回 T） |
| `<? super T>` | 下界限定 | 写入安全（接受 T） |

### 参考样例

```java
// 上界限定
public class NumericBox<T extends Number> {
    private T value;

    public T getValue() {
        return value;
    }

    public double toDouble() {
        return value.doubleValue();
    }
}

// 多个上界（用 & 分隔）
public <T extends Comparable<T> & Serializable> void process(T item) {
    // T 必须实现 Comparable 和 Serializable
}
```

```java
// 下界限定
public class Container<T> {
    public void addNumbers(List<? super Integer> list) {
        list.add(1);
        list.add(2);
        // list.add(3.14);  // 编译错误
        Object obj = list.get(0);  // 返回类型是 Object
    }
}
```

```java
// PECS 原则（Producer Extends, Consumer Super）
// 生产者（读取数据）：用 extends
public double sumOfList(List<? extends Number> list) {
    double sum = 0;
    for (Number n : list) {
        sum += n.doubleValue();
    }
    return sum;
}

// 消费者（写入）：用 super
public void addNumbers(List<? super Integer> list) {
    list.add(1);
    list.add(2);
}

// 既读又写：不用通配符
public void copy(List<? super Integer> dest, List<? extends Integer> src) {
    for (Integer item : src) {
        dest.add(item);
    }
}
```

## 类型擦除

Java 泛型通过类型擦除实现：编译时进行类型检查，运行时移除泛型信息。T 被替换为 Object 或上界。

### 参考样例

```java
// 源代码
public class Box<T> {
    private T content;
    public T getContent() { return content; }
}

// 编译后（伪代码）
public class Box {
    private Object content;
    public Object getContent() { return content; }
}
```

### 类型擦除的影响

```java
// 不能创建泛型数组
E[] array = (E[]) new Object[10];

// 不能使用基本类型
Stack<Integer> intStack;  // 必须用包装类

// 不能 instanceof 泛型
if (obj instanceof List<String>) { }  // 编译错误
if (obj instanceof List<?>) { }  // 正确

// 不能重载（类型擦除后方法签名相同）
public void process(List<String> list) { }
public void process(List<?> list) { }  // 正确：不同签名
```

## 泛型与继承

Integer 是 Number 的子类型，但 `List<Integer>` 不是 `List<Number>` 的子类型。使用通配符实现协变和逆变。

### 参考样例

```java
// 协变
List<? extends Number> numList = new ArrayList<Integer>();

// 逆变
List<? super Integer> intList2 = new ArrayList<Number>();
```

## 泛型擦除与桥方法

### 参考样例

```java
public class Node<T> {
    private T data;
    public Node(T data) { this.data = data; }
    public T getData() { return data; }
    public void setData(T data) { this.data = data; }
}

public class StringNode extends Node<String> {
    public StringNode(String data) { super(data); }

    @Override
    public String getData() { return super.getData(); }

    // 编译器生成桥方法
    @Override
    public Object getData() {
        return this.getData();
    }
}
```

## 泛型约束

```java
// 不能实例化泛型类型
public <T> T createInstance(Class<T> clazz) {
    return clazz.newInstance();  // 正确
    // return new T();  // 编译错误
}

// 静态方法不能使用类泛型参数
public class GenericClass<T> {
    // private static T staticField;  // 编译错误
    public static <T> T createInstance() { }  // 正确
}

// 不能使用泛型创建异常
public class GenericException<T> extends Exception { }  // 编译错误
```

## 泛型最佳实践

### 参考样例

```java
// 1. 优先使用泛型集合
List<String> list = new ArrayList<>();
list.add("string");

// 2. 优先使用泛型方法
public <T> String convert(T value) {
    return Objects.toString(value);
}

// 3. Diamond 运算符（Java 7+）
List<String> list = new ArrayList<>();

// 4. 泛型和数组
@SafeVarargs
public static <T> void printAll(T... elements) {
    for (T element : elements) {
        System.out.println(element);
    }
}

// 5. 合理使用边界
public boolean isEmpty(List<?> list) { return list.isEmpty(); }
public double sum(List<? extends Number> list) { }
public void addNumbers(List<? super Integer> list) { }

// 6. 泛型和可变参数
@SafeVarargs
public static <T> List<T> listOf(T... elements) {
    return Arrays.asList(elements);
}
```

## 泛型与反射

### 参考样例

```java
public class GenericFactory<T> {
    private final Class<T> clazz;

    public GenericFactory(Class<T> clazz) {
        this.clazz = clazz;
    }

    public T create() throws Exception {
        return clazz.getDeclaredConstructor().newInstance();
    }

    public T create(Class<?>[] paramTypes, Object... args) throws Exception {
        return clazz.getDeclaredConstructor(paramTypes).newInstance(args);
    }
}
```
