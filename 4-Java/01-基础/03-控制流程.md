# 控制流程

## Switch 模式匹配

### 基础类型匹配

switch 模式匹配消除了强制类型转换的样板代码，类型检查与变量绑定在同一个表达式中完成。

### Guarded Patterns（带条件的模式）

带条件的模式匹配通过 when 子句实现额外的运行时检查，将条件从外部 if 迁移到模式内部。

### Record 模式匹配

嵌套 Record 解构允许在模式匹配中直接提取嵌套字段，实现类似解构赋值的能力。

### null 处理

Java 21 允许在 switch 中显式处理 null，null case 必须放在类型 case 之前。

### 参考样例

```java
// 模式匹配 switch
String describe = switch (obj) {
    case Integer i when i > 0 -> "正整数: " + i;
    case Integer i -> "非正整数: " + i;
    case String s -> "字符串: " + s;
    case null, default -> "其他类型";
};
```

```java
// when 子句实现条件匹配
sealed interface Shape permits Circle, Rectangle, Triangle {}
record Circle(double radius) implements Shape {}
record Rectangle(double width, double height) implements Shape {}
record Triangle(double base, double height) implements Shape {}

String describeArea(Shape s) {
    return switch (s) {
        case Circle c when c.radius() > 0 -> "半径为 " + c.radius() + " 的圆";
        case Rectangle r when r.width() == r.height() -> "边长为 " + r.width() + " 的正方形";
        case Rectangle r -> "宽 " + r.width() + " 高 " + r.height() + " 的矩形";
        case Triangle t -> "底 " + t.base() + " 高 " + t.height() + " 的三角形";
        case null -> "空形状";
    };
}
```

```java
// 解构 record 并同时匹配类型
sealed interface Node permits TreeNode, Leaf {}
record TreeNode(int value, Node left, Node right) implements Node {}
record Leaf(int value) implements Node {}

String eval(Node node) {
    return switch (node) {
        case TreeNode(int v, TreeNode l, TreeNode r) -> "子树: " + v + " (左右子节点)";
        case TreeNode(int v, TreeNode l, Leaf r) -> "子树: " + v + " (左右子节点)";
        case TreeNode(int v, Leaf l, Leaf r) -> "子树: " + v + " (两个叶子)";
        case TreeNode(int v, null, null) -> "单节点树: " + v;
        case Leaf(int v) -> "叶子: " + v;
        case null -> "空节点";
    };
}
```

```java
// null 处理
String result = switch (obj) {
    case null -> "是 null";
    case String s -> "字符串: " + s;
    case Integer i -> "整数: " + i;
    default -> "其他";
};

// 旧写法（Java 14-20）
String result = (obj == null) ? "是 null" : switch (obj) {
    case String s -> "字符串: " + s;
    default -> "其他";
};
```

```java
// 模式匹配最佳实践
// 1. 总要处理 null（避免 NPE）
sealed interface Response permits Success, Error {}
record Success(String data) implements Response {}
record Error(String message) implements Response {}

String handle(Response r) {
    return switch (r) {
        case Success(String data) -> "成功: " + data;
        case Error(String msg) -> "错误: " + msg;
        case null -> "响应为空";
    };
}

// 2. 使用 default 兜底
String classify(Object obj) {
    return switch (obj) {
        case Integer i -> "整数";
        case String s -> "字符串";
        case null -> "null";
        default -> "其他类型";
    };
}

// 3. 穷尽性检查
sealed interface Color permits Red, Green, Blue {}
record Red() implements Color {}
record Green() implements Color {}
record Blue() implements Color {}

String colorName(Color c) {
    return switch (c) {
        case Red r -> "红色";
        case Green g -> "绿色";
        case Blue b -> "蓝色";
    };
}
```

## break 和 continue

- `break`：跳出当前循环
- `continue`：跳过本次循环，继续下一次迭代

### 参考样例

```java
// break：跳出循环
for (int i = 0; i < 10; i++) {
    if (i == 5) {
        break;  // i 达到 5 时终止循环
    }
    System.out.println(i);
}

// continue：跳过本次迭代
for (int i = 0; i < 5; i++) {
    if (i == 2) {
        continue;  // 跳过 i == 2 的本次迭代
    }
    System.out.println(i);
}
```

## 循环

- `for`：标准循环
- `while`：先判断后执行
- `do-while`：先执行后判断（至少执行一次）
- **增强 for 循环（for-each）**：遍历数组和集合

### 参考样例

```java
// 普通 for 循环
for (int i = 0; i < 5; i++) {
    System.out.println(i);
}

// 增强 for 循环（遍历数组）
int[] numbers = {1, 2, 3, 4, 5};
for (int num : numbers) {
    System.out.println(num);
}

// 遍历集合
List<String> names = List.of("Alice", "Bob", "Charlie");
for (String name : names) {
    System.out.println(name);
}

// while 循环
int count = 0;
while (count < 5) {
    System.out.println(count++);
}

// do-while 循环
do {
    System.out.println("至少执行一次");
} while (false);
```
