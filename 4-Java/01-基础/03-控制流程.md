# 控制流程

## if/else 和 switch

- `switch` 支持 Java 14+ 的表达式形式（yield 返回值）
- switch 表达式支持匹配多个值（Java 21+）

```java
// if/else
if (score >= 90) {
    grade = "A";
} else if (score >= 80) {
    grade = "B";
} else {
    grade = "C";
}

// switch 表达式 (Java 14+)
String result = switch (day) {
    case MONDAY, FRIDAY, SUNDAY -> "6";
    case TUESDAY -> "7";
    case THURSDAY, SATURDAY -> "8";
    case WEDNESDAY -> "9";
    default -> "0";
};
```

## Switch 模式匹配（Java 21+）

### 基础类型匹配

```java
// Java 21+ 模式匹配 switch
String describe = switch (obj) {
    case Integer i when i > 0 -> "正整数: " + i;
    case Integer i -> "非正整数: " + i;
    case String s -> "字符串: " + s;
    case null, default -> "其他类型";
};
```

### Guarded Patterns（带条件的模式）

```java
// when 子句实现条件匹配
sealed interface Shape permits Circle, Rectangle, Triangle {}
record Circle(double radius) implements Shape {}
record Rectangle(double width, double height) implements Shape {}
record Triangle(double base, double height) implements Shape {}

String describeArea(Shape s) {
    return switch (s) {
        // Circle 且 radius > 0
        case Circle c when c.radius() > 0 ->
            "半径为 " + c.radius() + " 的圆";
        // Rectangle 且宽高相等
        case Rectangle r when r.width() == r.height() ->
            "边长为 " + r.width() + " 的正方形";
        case Rectangle r ->
            "宽 " + r.width() + " 高 " + r.height() + " 的矩形";
        case Triangle t ->
            "底 " + t.base() + " 高 " + t.height() + " 的三角形";
        case null -> "空形状";
    };
}
```

### Record 模式匹配

```java
// 解构 record 并同时匹配类型
sealed interface Node permits TreeNode, Leaf {}
record TreeNode(int value, Node left, Node right) implements Node {}
record Leaf(int value) implements Node {}

String eval(Node node) {
    return switch (node) {
        // 匹配 TreeNode 并解构
        case TreeNode(int v, TreeNode l, TreeNode r) ->
            "子树: " + v + " (左右子节点)";
        case TreeNode(int v, TreeNode l, Leaf r) ->
            "子树: " + v + " (左右子节点)";
        case TreeNode(int v, Leaf l, Leaf r) ->
            "子树: " + v + " (两个叶子)";
        case TreeNode(int v, null, null) ->
            "单节点树: " + v;
        case Leaf(int v) ->
            "叶子: " + v;
        case null -> "空节点";
    };
}
```

### null 处理

Java 21+ 允许在 switch 中显式处理 null：

```java
// null case 必须放在类型 case 之前
String result = switch (obj) {
    case null -> "是 null";
    case String s -> "字符串: " + s;
    case Integer i -> "整数: " + i;
    default -> "其他";
};

// 旧写法（Java 14-20）
String result = (obj == null) ? "是 null" : switch (obj) {
    case String s -> "字符串: " + s;
    default -> "其他";
};
```

### 模式匹配最佳实践

```java
// 1. 总要处理 null（避免 NPE）
sealed interface Response permits Success, Error {}
record Success(String data) implements Response {}
record Error(String message) implements Response {}

String handle(Response r) {
    return switch (r) {
        case Success(String data) -> "成功: " + data;
        case Error(String msg) -> "错误: " + msg;
        case null -> "响应为空";  // 必须处理
    };
}

// 2. 使用 default 兜底
String classify(Object obj) {
    return switch (obj) {
        case Integer i -> "整数";
        case String s -> "字符串";
        case null -> "null";
        default -> "其他类型";  // 显式 default
    };
}

// 3. 穷尽性检查
sealed interface Color permits Red, Green, Blue {}
record Red() implements Color {}
record Green() implements Color {}
record Blue() implements Color {}

// 编译器检查所有 case 都被处理
String colorName(Color c) {
    return switch (c) {
        case Red r -> "红色";
        case Green g -> "绿色";
        case Blue b -> "蓝色";
        // 不需要 default，编译器确保穷尽
    };
}
```

## break 和 continue

- `break`：跳出当前循环
- `continue`：跳过本次循环，继续下一次迭代

```java
// break：跳出循环
for (int i = 0; i < 10; i++) {
    if (i == 5) {
        break;  // i 达到 5 时终止循环
    }
    System.out.println(i);
}

// continue：跳过本次迭代
for (int i = 0; i < 5; i++) {
    if (i == 2) {
        continue;  // 跳过 i == 2 的本次迭代
    }
    System.out.println(i);
}
```

## 循环

- `for`：标准循环
- `while`：先判断后执行
- `do-while`：先执行后判断（至少执行一次）
- **增强 for 循环（for-each）**：遍历数组和集合

```java
// 普通 for 循环
for (int i = 0; i < 5; i++) {
    System.out.println(i);
}

// 增强 for 循环（遍历数组）
int[] numbers = {1, 2, 3, 4, 5};
for (int num : numbers) {
    System.out.println(num);
}

// 遍历集合
List<String> names = List.of("Alice", "Bob", "Charlie");
for (String name : names) {
    System.out.println(name);
}

// while 循环
int count = 0;
while (count < 5) {
    System.out.println(count++);
}

// do-while 循环
do {
    System.out.println("至少执行一次");
} while (false);
```
