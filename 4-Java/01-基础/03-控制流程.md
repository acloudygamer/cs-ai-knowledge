# 控制流程

## 定义

Java 的控制流程语句（if/else、switch、for、while）本质上是**有穷状态自动机**（Finite State Machine, FSM）的语法结构化表示。编译器将控制流图（Control Flow Graph, CFG）转换为基本块，用于优化和异常处理。

## 数学模型

### switch 的 FSM 形式化

switch 表达式可建模为五元组：

$$M = (Q, \Sigma, \delta, q_0, F)$$

- $Q$：状态集（case 分支 + 接受状态）
- $\Sigma = T \cup \{\text{null}\}$：输入符号集（类型标签或 null）
- $\delta: Q \times \Sigma \rightarrow Q$：转移函数
- $q_0$：初始状态（null 检查）
- $F$：接受状态集（各 case 分支）

**完备性条件**：对于所有 $q \in Q$ 和 $\sigma \in \Sigma$，$\delta(q, \sigma)$ 均有定义。

### sealed 接口的穷尽性检查

对于 sealed 接口，switch 表达式的穷尽性检查本质是**集合覆盖**。对于 sealed 接口：

$$U = \{ t \mid t \in \text{permits list} \}$$

switch 表达式必须覆盖 $U$ 的所有元素。编译器将检查建模为：

$$\bigcup_{i} P_i = U$$

其中 $P_i$ 是每个 case 的类型模式覆盖集合。若覆盖不完整，编译错误。

**复杂度**：设 sealed 类型的子类型数为 $n$，穷尽性检查需要验证所有子类型都被处理。Java 使用**完备分配检测**（complete assignment detection），在 $O(n)$ 时间内完成。

### 循环不变式与正确性证明

循环的正确性证明依赖于**循环不变式**（loop invariant）：在每次迭代开始前和结束后都为真的命题。

设循环条件为 $C$，循环体为 $B$，不变式为 $I$：

$$\frac{I \land C \xrightarrow{B} I}{(I) \land \neg C}$$

## 数据流

### switch 模式匹配的求值流程（Java 17 密封类）

<pre>
sealed interface Shape permits Circle, Rectangle {}
switch (shape) {
    case Circle c    -> computeCircleArea(c);
    case Rectangle r -> computeRectangleArea(r);
}
         │
         ▼
┌─────────────────────┐
│ q0: shape instanceof Circle? │──yes──→ c 绑定为 Circle
└─────────────────────┘
         │ no
         ▼
┌─────────────────────┐
│ q1: shape instanceof Rectangle? │──yes──→ r 绑定为 Rectangle
└─────────────────────┘
         │ no
         ▼
    编译错误（穷尽性检查）
</pre>

### 控制流图的 基本块结构

编译器将方法体划分为**基本块**（Basic Block）：
- 入口的第一个语句
- 跳转目标
- 跳转语句的下一条

<pre>
基本块 A                    基本块 B
+------------------+        +------------------+
| int x = f();     |        | if (x > 0) {    |
| if (x > 0) {     | ─────> |     // B1       |
+------------------+  false  +------------------+
         │ true                      │
         ▼                           ▼
+------------------+        +------------------+
|     // B1        |        |     // B2       |
+------------------+        +------------------+
</pre>

基本块之间通过**控制流边**连接，形成有向图。优化和异常处理都基于这个图结构。

## 机制

### if/else 的分支预测

CPU 的**分支预测器**尝试预测跳转方向。高度可预测的分支（如大多数 if/else）几乎无性能损失。

**性能约束**：
- 分支预测失败：流水线清空，10-20 周期损失
- 分支预测成功：几乎零成本

if/else 的 FSM 语义：
```
q0: 条件检查 ──true──> q_true（执行then）
                └──false──> q_false（执行else）
```

### for 循环 vs while 循环的等价性

所有 for 循环都可以改写为 while 循环：

```java
// for 循环
for (init; condition; update) {
    body;
}

// 等价于 while 循环
{
    init;
    while (condition) {
        body;
        update;
    }
}
```

**数学解释**：for 循环是 while 循环的**语法糖**，但 for 循环的 init/update 在同一作用域使变量声明更紧凑。

### break 和 continue 的跳转语义

- `break`：跳转到循环体之外的第一条语句（退出最近的外层循环或 switch）
- `continue`：跳转到循环体的末尾（开始下一次迭代）

**FSM 视角**：
- break：$q_{current} \rightarrow q_{exit}$（终止状态转移）
- continue：$q_{current} \rightarrow q_{loop-start}$（回到循环起始）

### labeled break/continue

带标签的 break/continue 可以跳出或继续外层嵌套循环：

```java
outer:
for (int i = 0; i < 10; i++) {
    for (int j = 0; j < 10; j++) {
        if (condition(i, j)) {
            break outer;  // 跳出外层循环
        }
    }
}
```

**约束**：标签必须正确定声明在被跳出的循环之前。错误的标签使用导致编译错误。

### 穷尽性检查的工程价值

| 场景 | 无穷尽检查 | 有穷尽检查 |
|------|-----------|-----------|
| 新增子类型 | 运行时 `MatchException` | 编译错误 |
| 代码重构 | 需人工检查所有 switch | 编译器强制验证 |
| 遗漏分支 | 静默执行 default 或 fallthrough | 编译失败 |

## sealed 接口与穷尽性示例（Java 17）

```java
sealed interface Shape permits Circle, Rectangle, Triangle {}

record Circle(double radius) implements Shape {}
record Rectangle(double width, double height) implements Shape {}
record Triangle(double base, double height) implements Shape {}

double area(Shape s) {
    return switch (s) {
        case Circle c    -> Math.PI * c.radius() * c.radius();
        case Rectangle r -> r.width() * r.height();
        case Triangle t  -> t.base() * t.height() / 2;
        // 无需 default：编译器确保穷尽
    };
}
```

## 参考存根

```java
// 循环不变式示例：查找数组中的元素
int binarySearch(int[] arr, int target) {
    int lo = 0, hi = arr.length - 1;
    // 循环不变式：arr[0..lo-1] < target, arr[hi+1..n-1] > target
    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;
        if (arr[mid] == target) {
            return mid;  // 找到目标
        } else if (arr[mid] < target) {
            lo = mid + 1;  // 维持不变式
        } else {
            hi = mid - 1;  // 维持不变式
        }
    }
    return -1;  // 未找到
}

// labeled break 示例
int[][] matrix = {{1, 2}, {3, 4}};
outer:
for (int i = 0; i < matrix.length; i++) {
    for (int j = 0; j < matrix[i].length; j++) {
        if (matrix[i][j] == 4) {
            System.out.println("Found at " + i + ", " + j);
            break outer;
        }
    }
}
```
