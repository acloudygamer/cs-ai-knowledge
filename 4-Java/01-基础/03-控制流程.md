# 控制流程

## Switch 模式匹配

Switch 模式匹配将类型检查与变量绑定在同一个表达式中完成，消除了强制类型转换的样板代码。

### null 处理

Java 21 允许在 switch 中显式处理 null，null case 必须放在类型 case 之前。

```java
String result = switch (obj) {
    case null -> "是 null";
    case String s -> "字符串: " + s;
    case Integer i -> "整数: " + i;
    default -> "其他";
};
```

### Guarded Patterns（带条件的模式）

通过 `when` 子句在模式匹配内部进行运行时检查，将条件从外部 if 迁移到模式内部。

```java
sealed interface Shape permits Circle, Rectangle {}
record Circle(double radius) implements Shape {}
record Rectangle(double width, double height) implements Shape {}

String describe(Shape s) {
    return switch (s) {
        case Circle c when c.radius() > 0 -> "正圆，半径 " + c.radius();
        case Rectangle r when r.width() == r.height() -> "正方形，边长 " + r.width();
        case Rectangle r -> "矩形";
        case null -> "空形状";
    };
}
```

### Record 模式匹配

嵌套 Record 解构允许在模式匹配中直接提取嵌套字段，实现类似解构赋值的能力。

```java
sealed interface Node permits TreeNode, Leaf {}
record TreeNode(int value, Node left, Node right) implements Node {}
record Leaf(int value) implements Node {}

String eval(Node node) {
    return switch (node) {
        case TreeNode(int v, TreeNode l, TreeNode r) -> "子树: " + v;
        case TreeNode(int v, null, null) -> "单节点: " + v;
        case Leaf(int v) -> "叶子: " + v;
        case null -> "空节点";
    };
}
```

### 穷尽性检查

Sealed 接口配合 switch 模式匹配，编译器验证所有可能情况都被处理。

```java
sealed interface Color permits Red, Green, Blue {}
record Red() implements Color {}
record Green() implements Color {}
record Blue() implements Color {}

String name(Color c) {
    return switch (c) {
        case Red r -> "红色";
        case Green g -> "绿色";
        case Blue b -> "蓝色";
    };
}
```

**为什么穷尽性检查重要：** 穷尽性检查在编译期确保没有遗漏任何可能类型，新增类型时未处理的 case 会导致编译错误，而非运行时 bug。

## break 和 continue

- `break`：跳出当前循环
- `continue`：跳过本次循环，继续下一次迭代

```java
for (int i = 0; i < 10; i++) {
    if (i == 5) break;
}
for (int i = 0; i < 5; i++) {
    if (i == 2) continue;
}
```

## 循环

- `for`：标准循环
- `while`：先判断后执行
- `do-while`：先执行后判断（至少执行一次）
- **增强 for 循环（for-each）**：遍历数组和集合

```java
int[] numbers = {1, 2, 3, 4, 5};
for (int num : numbers) {
    System.out.println(num);
}
List<String> names = List.of("Alice", "Bob");
for (String name : names) {
    System.out.println(name);
}
```
