# 安装与环境

## JDK 下载安装

### 推荐下载地址

- **Eclipse Temurin**（原 AdoptOpenJDK，推荐）: https://adoptium.net/
- **Oracle JDK**: https://www.oracle.com/java/technologies/downloads/
- **Amazon Corretto**: https://aws.amazon.com/corretto/
- **Microsoft Build of OpenJDK**: https://learn.microsoft.com/java/

### 环境变量配置

**Windows:**

```batch
setx JAVA_HOME "C:\Program Files\Eclipse Adoptium\jdk-21.0.2-hotspot"
setx PATH "%JAVA_HOME%\bin;%PATH%"
```

```bash
java -version
javac -version
```

**Linux/macOS:**

```bash
export JAVA_HOME=/usr/lib/jvm/temurin-21-jdk
export PATH=$JAVA_HOME/bin:$PATH
source ~/.bashrc
```

### Java 版本选择建议

| 场景 | 推荐版本 | 说明 |
|------|----------|------|
| 新项目 | Java 25 | 最新特性，简化入口/模块导入 |
| 企业维护 | Java 21 LTS | 虚拟线程，长期支持稳定版 |
| Android 开发 | Java 17 | Android Studio 最低要求 |
| 学习 | Java 21 或 25 | 包含所有现代特性 |

**为什么 LTS 版本适合企业：** LTS 版本提供 8 年以上支持周期，期间安全补丁和关键更新持续推送，无需频繁升级。虚拟线程（JEP 444）在 Java 21 LTS 中稳定，支持高并发低内存场景。

## IDE

### IntelliJ IDEA（推荐）

最流行的 Java IDE，代码理解能力最强。

**下载:** https://www.jetbrains.com/idea/download/

### VS Code

适合简单项目，通过 Extension Pack for Java 获得基础 Java 支持。

**扩展:**

```json
{
  "java.home": "/usr/lib/jvm/temurin-21-jdk",
  "java.configuration.runtimes": [
    {
      "name": "JavaSE-21",
      "path": "/usr/lib/jvm/temurin-21-jdk",
      "default": true
    }
  ]
}
```

### Eclipse

适合大型企业项目，完全免费开源。下载: https://www.eclipse.org/downloads/

## 构建工具

### Maven

使用 `pom.xml` 配置，依赖管理和项目生命周期成熟。

```
my-project/
├── src/main/java/
├── src/main/resources/
├── src/test/java/
├── target/
├── pom.xml
└── .mvn/
```

**pom.xml 示例:**

```xml
<project>
    <modelVersion>4.0.0</modelVersion>
    <groupId>com.example</groupId>
    <artifactId>my-project</artifactId>
    <version>1.0.0</version>
    <properties>
        <java.version>21</java.version>
    </properties>
    <dependencies>
        <dependency>
            <groupId>org.junit.jupiter</groupId>
            <artifactId>junit-jupiter</artifactId>
            <version>5.10.0</version>
            <scope>test</scope>
        </dependency>
    </dependencies>
</project>
```

**常用命令:**

```bash
mvn clean compile
mvn test
mvn package
mvn dependency:tree
```

### Gradle

使用 `build.gradle`，配置更简洁，支持 Kotlin DSL。

```groovy
plugins {
    id 'java'
}
group = 'com.example'
version = '1.0.0'
java {
    sourceCompatibility = '21'
}
repositories {
    mavenCentral()
}
dependencies {
    testImplementation 'org.junit.jupiter:junit-jupiter:5.10.0'
}
```

**常用命令:**

```bash
gradle build
gradle test
gradle run
gradle dependencies
```

## 常见问题排查

### java 命令找不到

```bash
echo $JAVA_HOME
echo $PATH
```

### Maven 编译报错 "Permission denied"

```bash
chmod +x /path/to/mvn
```

### Maven 下载依赖失败

删除本地仓库缓存强制重新下载，或配置镜像:

```xml
<mirror>
    <id>aliyun</id>
    <mirrorOf>central</mirrorOf>
    <url>https://maven.aliyun.com/repository/central</url>
</mirror>
```
