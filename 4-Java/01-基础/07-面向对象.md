# 面向对象

## 面向对象三要素

### 封装（Encapsulation）

将数据和对数据的操作打包在一起，隐藏内部细节，对外提供接口。

### 继承（Inheritance）

子类复用父类的属性和方法，并可扩展或覆盖。

### 多态（Polymorphism）

同一接口的不同实现，子类对象可替代父类对象。

## 类与对象

### 访问修饰符

| 修饰符 | 同类 | 同包 | 子类 | 其他包 |
|--------|------|------|------|--------|
| private | Yes | No | No | No |
| default | Yes | Yes | No | No |
| protected | Yes | Yes | Yes | No |
| public | Yes | Yes | Yes | Yes |

## this 和 super

`this` 引用当前对象，`super` 调用父类构造器或访问父类成员。

## static

`static` 修饰的成员属于类而非实例。限制：只能访问静态成员，不能使用 `this` 或 `super`，不能被重写但可以被隐藏。

## final

`final` 修饰类（不能继承）、方法（不能覆写）、字段（初始化后不能改变）或参数（不能修改）。

### 参考样例

```java
// 封装示例
public class BankAccount {
    private double balance;
    private final String accountId;

    public BankAccount(String accountId, double initialBalance) {
        this.accountId = accountId;
        this.balance = initialBalance;
    }

    public void deposit(double amount) {
        if (amount <= 0) {
            throw new IllegalArgumentException("存款金额必须为正");
        }
        balance += amount;
    }

    public void withdraw(double amount) {
        if (amount <= 0) {
            throw new IllegalArgumentException("取款金额必须为正");
        }
        if (amount > balance) {
            throw new IllegalStateException("余额不足");
        }
        balance -= amount;
    }

    public double getBalance() { return balance; }
    public String getAccountId() { return accountId; }
}
```

## 抽象类与接口

### 抽象类

不能实例化，可包含抽象方法（无实现）和具体方法。

### 接口

完全抽象，只能包含抽象方法、默认方法、静态方法、私有方法（Java 9+）。字段只能是 public static final。

### 抽象类 vs 接口

| 特性 | 抽象类 | 接口 |
|------|--------|------|
| 字段 | 无限制 | 只能是 public static final |
| 方法 | 无限制 | 抽象方法、默认方法、静态方法 |
| 构造器 | 有 | 无 |
| 多继承 | 不支持 | 支持（可多实现） |
| 目的 | "是..."关系 | "能..."能力 |

### 参考样例

```java
// 抽象类
public abstract class Shape {
    protected String color;

    public Shape(String color) {
        this.color = color;
    }

    public abstract double getArea();
    public abstract double getPerimeter();

    public String getColor() {
        return color;
    }
}

public class Circle extends Shape {
    private double radius;

    public Circle(String color, double radius) {
        super(color);
        this.radius = radius;
    }

    @Override
    public double getArea() {
        return Math.PI * radius * radius;
    }

    @Override
    public double getPerimeter() {
        return 2 * Math.PI * radius;
    }
}
```

## 内部类

### 成员内部类

可直接访问外部类所有成员，需通过外部类实例创建。

### 静态内部类

只能访问外部类静态成员，可直接创建实例。

### 局部内部类

定义在方法内部，可访问方法中的隐式 final 变量。

### 匿名内部类

没有名字的局部内部类，常用于事件监听和回调。

### 参考样例

```java
// 成员内部类
public class Outer {
    private int x = 10;

    public class Inner {
        public void display() {
            System.out.println("x = " + x);
        }
    }
}
Outer outer = new Outer();
Outer.Inner inner = outer.new Inner();
```

```java
// 静态内部类
public class Outer {
    private static int staticX = 10;

    public static class StaticInner {
        public void display() {
            System.out.println("staticX = " + staticX);
        }
    }
}
Outer.StaticInner inner = new Outer.StaticInner();
```

```java
// 局部内部类
public class Outer {
    public void method() {
        int localVar = 10;

        class LocalInner {
            public void display() {
                System.out.println("localVar = " + localVar);
            }
        }

        LocalInner inner = new LocalInner();
        inner.display();
    }
}
```

```java
// 匿名内部类
public interface HelloService {
    void sayHello();
}

HelloService service = new HelloService() {
    @Override
    public void sayHello() {
        System.out.println("Hello!");
    }
};
```

## 枚举类

### 参考样例

```java
// 简单枚举
public enum Day {
    MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY, SATURDAY, SUNDAY
}

// 带属性和方法
public enum Status {
    SUCCESS(200, "成功"),
    ERROR(500, "错误"),
    NOT_FOUND(404, "未找到");

    private final int code;
    private final String description;

    Status(int code, String description) {
        this.code = code;
        this.description = description;
    }

    public int getCode() { return code; }
    public String getDescription() { return description; }

    public static Status fromCode(int code) {
        for (Status s : values()) {
            if (s.code == code) return s;
        }
        throw new IllegalArgumentException("Unknown code: " + code);
    }
}
```
