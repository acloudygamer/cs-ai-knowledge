# 面向对象

## 面向对象三要素

**封装（Encapsulation）**将数据和对数据的操作打包在一起，隐藏内部细节，对外提供受控接口。

**继承（Inheritance）**允许子类复用父类的属性和方法，并可扩展或覆盖。

**多态（Polymorphism）**使同一接口的不同实现可以被替代：子类对象可替代父类对象，方法调用在运行时绑定到实际实现。

**为什么封装重要：** 隐藏实现细节使调用者无需了解内部复杂性和约束条件；修改内部实现不影响外部使用者；通过受控接口限制不当操作，保证对象一致性。

**为什么需要继承而非直接复制代码：** 继承建立 is-a 关系，子类天然具有父类的接口和行为；里氏替换原则保证子类实例可以在父类出现的地方正常工作；代码复用且类型关系明确。

**为什么多态优于条件判断：** 通过父类引用调用方法，实际执行的是运行时类型的实现，而非编译时类型的判断；新增子类无需修改已有代码，符合开闭原则。

## 类与对象

### 访问修饰符

| 修饰符 | 同类 | 同包 | 子类 | 其他包 |
|--------|------|------|------|--------|
| private | Yes | No | No | No |
| default | Yes | Yes | No | No |
| protected | Yes | Yes | Yes | No |
| public | Yes | Yes | Yes | Yes |

**为什么 protected 允许子类访问但不允许同包非子类访问：** protected 主要用于支持继承场景，子类可能在不同包中；同包访问用 default 修饰符即可实现。

## this 和 super

`this` 引用当前对象，`super` 调用父类构造器或访问父类成员。

## static

`static` 修饰的成员属于类而非实例。限制：只能访问静态成员，不能使用 `this` 或 `super`，不能被重写但可以被隐藏。

## final

`final` 修饰类（不能继承）、方法（不能覆写）、字段（初始化后不能改变）或参数（不能修改）。

## 抽象类与接口

### 抽象类

不能实例化，可包含抽象方法（无实现）和具体方法。用于"是..."关系。

### 接口

完全抽象，只能包含抽象方法、默认方法、静态方法、私有方法（Java 9+）。字段只能是 `public static final`。用于"能..."能力。

### 抽象类 vs 接口

| 特性 | 抽象类 | 接口 |
|------|--------|------|
| 字段 | 无限制 | 只能是 public static final |
| 方法 | 无限制 | 抽象/默认/静态/私有 |
| 构造器 | 有 | 无 |
| 多继承 | 不支持 | 支持（可多实现） |

**为什么 Java 8 引入默认方法：** 在接口中添加方法会导致所有实现类必须添加实现，破坏向后兼容。默认方法提供有默认实现的方法，实现类可以直接使用，无需重写。

**为什么接口字段必须是 static final：** 接口不参与实例化，没有实例状态；字段本质是常量，static 保证所有实例共享一份，final 保证不可修改。

```java
public abstract class Shape {
    protected String color;
    public Shape(String color) { this.color = color; }
    public abstract double getArea();
    public abstract double getPerimeter();
}

public class Circle extends Shape {
    private double radius;
    public Circle(String color, double radius) {
        super(color);
        this.radius = radius;
    }
    @Override
    public double getArea() { return Math.PI * radius * radius; }
    @Override
    public double getPerimeter() { return 2 * Math.PI * radius; }
}
```

```java
public interface Drawable {
    void draw();
    void resize(double factor);
    default void print() { System.out.println("Printing..."); }
    static Drawable create() { return new DefaultDrawable(); }
}

interface Flyable { void fly(); }
interface Swimmable { void swim(); }

class Duck implements Flyable, Swimmable {
    public void fly() { }
    public void swim() { }
}
```

## 内部类

### 成员内部类

可直接访问外部类所有成员，需通过外部类实例创建。

### 静态内部类

只能访问外部类静态成员，可直接创建实例。

### 局部内部类

定义在方法内部，可访问方法中的隐式 final 变量。

### 匿名内部类

没有名字的局部内部类，常用于事件监听和回调。

```java
public class Outer {
    private int x = 10;
    public class Inner {
        public void display() { System.out.println(x); }
    }
}
Outer outer = new Outer();
Outer.Inner inner = outer.new Inner();
```

```java
public class Outer {
    private static int staticX = 10;
    public static class StaticInner {
        public void display() { System.out.println(staticX); }
    }
}
Outer.StaticInner inner = new Outer.StaticInner();
```

```java
public interface HelloService {
    void sayHello();
}
HelloService service = new HelloService() {
    public void sayHello() { System.out.println("Hello!"); }
};
```

**为什么局部内部类访问方法参数必须 effectively final：** 局部内部类实例的生命周期可能超过方法执行时间，如果参数在方法返回后被修改，内部类中的引用会指向不确定的值。编译器强制要求参数不可变以避免此问题。

## 枚举类

枚举是固定数量常量的类，比整型常量更类型安全。

```java
public enum Status {
    SUCCESS(200, "成功"),
    ERROR(500, "错误"),
    NOT_FOUND(404, "未找到");
    private final int code;
    private final String description;
    Status(int code, String description) {
        this.code = code;
        this.description = description;
    }
    public int getCode() { return code; }
}
```
