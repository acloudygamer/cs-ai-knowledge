# 面向对象

## 面向对象三要素

### 封装（Encapsulation）

将数据和对数据的操作打包在一起，隐藏内部细节，对外提供接口。

```java
// 封装示例
public class BankAccount {
    // 私有字段，外部不能直接访问
    private double balance;
    private final String accountId;

    // 构造器
    public BankAccount(String accountId, double initialBalance) {
        this.accountId = accountId;
        this.balance = initialBalance;
    }

    // 公共方法，对外提供受控访问
    public void deposit(double amount) {
        if (amount <= 0) {
            throw new IllegalArgumentException("存款金额必须为正");
        }
        balance += amount;
    }

    public void withdraw(double amount) {
        if (amount <= 0) {
            throw new IllegalArgumentException("取款金额必须为正");
        }
        if (amount > balance) {
            throw new IllegalStateException("余额不足");
        }
        balance -= amount;
    }

    public double getBalance() {
        return balance;
    }

    public String getAccountId() {
        return accountId;
    }
}

// 使用
BankAccount account = new BankAccount("ACC001", 1000);
account.deposit(500);
account.withdraw(200);
System.out.println(account.getBalance());  // 1300
```

### 继承（Inheritance）

子类复用父类的属性和方法，并可扩展或覆盖。

```java
// 父类
public class Animal {
    protected String name;
    protected int age;

    public Animal(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public void eat() {
        System.out.println(name + " 正在吃东西");
    }

    public void speak() {
        System.out.println(name + " 发出声音");
    }
}

// 子类
public class Dog extends Animal {
    private String breed;

    public Dog(String name, int age, String breed) {
        super(name, age);  // 调用父类构造器
        this.breed = breed;
    }

    @Override  // 标记覆写
    public void speak() {
        System.out.println(name + " 汪汪叫");
    }

    public void fetch() {
        System.out.println(name + " 正在捡球");
    }
}

// 使用
Animal animal = new Dog("旺财", 3, "金毛");
animal.speak();  // 输出：旺财 汪汪叫
((Dog) animal).fetch();  // 向下转型后调用
```

### 多态（Polymorphism）

同一接口的不同实现，子类对象可替代父类对象。

```java
// 多态示例
public class Zoo {
    public static void main(String[] args) {
        // 父类引用指向子类对象
        Animal a1 = new Dog("旺财", 3, "金毛");
        Animal a2 = new Cat("咪咪", 2);

        // 同一接口，不同实现
        a1.speak();  // 汪汪叫
        a2.speak();  // 喵喵叫
    }
}
```

## 关键字

### this 和 super

```java
public class Person {
    private String name;

    public Person(String name) {
        this.name = name;  // this 引用当前对象
    }
}

public class Student extends Person {
    private int score;

    public Student(String name, int score) {
        super(name);  // super 调用父类构造器
        this.score = score;
    }

    public void display() {
        System.out.println("Name: " + super.name);  // 访问父类字段
    }
}
```

### static

```java
public class Counter {
    private int instanceCount;  // 实例字段
    private static int totalCount = 0;  // 静态字段（类变量）

    public Counter() {
        instanceCount++;
        totalCount++;
    }

    public static int getTotalCount() {  // 静态方法
        return totalCount;
    }

    // 静态初始化块
    static {
        System.out.println("Counter 类初始化");
    }
}

// 使用
Counter c1 = new Counter();
Counter c2 = new Counter();
System.out.println(Counter.getTotalCount());  // 2
```

### final

```java
// final 类：不能被继承
public final class String {
    // ...
}

// final 方法：不能被覆写
public class Parent {
    public final void method() {
        // 不能被子类覆写
    }
}

// final 字段：初始化后不能改变
public class Person {
    private final String id;  // 必须且只能赋值一次

    public Person(String id) {
        this.id = id;  // 构造器中赋值
    }
}

// final 参数
public void method(final int x) {
    // x 不能被修改
}
```

## 抽象类与接口

### 抽象类

```java
// 抽象类：不能实例化，可包含抽象方法
public abstract class Shape {
    protected String color;

    public Shape(String color) {
        this.color = color;
    }

    // 抽象方法：没有实现
    public abstract double getArea();
    public abstract double getPerimeter();

    // 具体方法
    public String getColor() {
        return color;
    }
}

public class Circle extends Shape {
    private double radius;

    public Circle(String color, double radius) {
        super(color);
        this.radius = radius;
    }

    @Override
    public double getArea() {
        return Math.PI * radius * radius;
    }

    @Override
    public double getPerimeter() {
        return 2 * Math.PI * radius;
    }
}
```

### 接口

```java
// 接口：完全抽象，只能包含抽象方法和常量
public interface Drawable {
    // 常量（隐式 public static final）
    String TYPE = "Shape";

    // 抽象方法
    void draw();
    void resize(double factor);
}

// 接口默认方法（Java 8+）
public interface Drawable {
    default void print() {
        System.out.println("Printing...");
    }
}

// 接口静态方法（Java 8+）
public interface Drawable {
    public static Drawable create() {
        return new DefaultDrawable();
    }
}

// 接口私有方法（Java 9+）
public interface Drawable {
    private void helper() {
        // 内部共享代码
    }
}
```

### 抽象类 vs 接口

| 特性 | 抽象类 | 接口 |
|------|--------|------|
| 字段 | 无限制 | 只能是 public static final |
| 方法 | 无限制 | 抽象方法、默认方法、静态方法 |
| 构造器 | 有 | 无 |
| 多继承 | 不支持 | 支持（可多实现） |
| 目的 | "是..."关系 | "能..."能力 |

```java
// 抽象类示例
abstract class Vehicle {
    abstract void start();
}

class Car extends Vehicle {
    @Override
    void start() {
        System.out.println("汽车启动");
    }
}

// 接口示例
interface Flyable {
    void fly();
}

interface Swimmable {
    void swim();
}

// 多实现
class Duck implements Flyable, Swimmable {
    @Override
    public void fly() {
        System.out.println("鸭子飞");
    }

    @Override
    public void swim() {
        System.out.println("鸭子游");
    }
}
```

## 内部类

### 成员内部类

```java
public class Outer {
    private int x = 10;

    // 成员内部类
    public class Inner {
        public void display() {
            System.out.println("x = " + x);  // 可访问外部类成员
        }
    }
}

// 使用
Outer outer = new Outer();
Outer.Inner inner = outer.new Inner();
inner.display();
```

### 静态内部类

```java
public class Outer {
    private static int staticX = 10;

    // 静态内部类
    public static class StaticInner {
        public void display() {
            // 只能访问外部类静态成员
            System.out.println("staticX = " + staticX);
        }
    }
}

// 使用
Outer.StaticInner inner = new Outer.StaticInner();
```

### 局部内部类

```java
public class Outer {

    }

```

## 密封类（Java 17+）

限制类的继承层次。

```java
// 密封类：精确控制哪些类可以继承
public sealed class Shape permits Circle, Rectangle, Triangle {
    // ...
}

// 允许的子类可以是 final、sealed 或 non-sealed
public final class Circle extends Shape { }  // 不能被继承
public sealed class Rectangle extends Shape permits Square { }  // 密封
public non-sealed class Triangle extends Shape { }  // 开放继承

// Square 继承自 sealed 的 Rectangle
public final class Square extends Rectangle { }
```

## 记录类（Java 16+）

简化不可变数据类的创建。

```java
// 传统写法
public class Point {
    private final int x;
    private final int y;

    public Point(int x, int y) {
        this.x = x;
        this.y = y;
    }

    public int getX() { return x; }
    public int getY() { return y; }

    @Override
    public boolean equals(Object o) {
        if (this == o) return true;
        if (o == null || getClass() != o.getClass()) return false;
        Point point = (Point) o;
        return x == point.x && y == point.y;
    }

    @Override
    public int hashCode() {
        return Objects.hash(x, y);
    }

    @Override
    public String toString() {
        return "Point[x=" + x + ", y=" + y + "]";
    }
}

// 记录类写法（自动生成 equals/hashCode/toString/构造器/访问器）
public record Point(int x, int y) {}

// 使用
Point p = new Point(1, 2);
System.out.println(p.x());  // 1 (访问器方法)
System.out.println(p);     // Point[x=1, y=2]
```

## 枚举类

```java
// 简单枚举
public enum Day {
    MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY, SATURDAY, SUNDAY
}

// 带属性和方法
public enum Status {
    SUCCESS(200, "成功"),
    ERROR(500, "错误"),
    NOT_FOUND(404, "未找到");

    private final int code;
    private final String description;

    Status(int code, String description) {
        this.code = code;
        this.description = description;
    }

    public int getCode() { return code; }
    public String getDescription() { return description; }

    public static Status fromCode(int code) {
        for (Status s : values()) {
            if (s.code == code) return s;
        }
        throw new IllegalArgumentException("Unknown code: " + code);
    }
}

// 使用
Status s = Status.SUCCESS;
System.out.println(s.getCode());  // 200
System.out.println(s.name());     // SUCCESS
```
