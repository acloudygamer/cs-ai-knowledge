# 函数

在 Java 中，"函数"被称为"方法"（Method）。Java 是一种纯面向对象的语言，所有方法都必须定义在类内部。

## 方法定义

方法由访问修饰符、返回类型、方法名和参数列表组成。

## 方法重载（Overload）

同一个类中，方法名相同但参数列表不同（参数个数、类型或顺序不同）。返回值类型不能作为重载的依据。当调用重载方法时，Java 按照以下顺序寻找匹配：精确匹配 → 自动类型转换匹配 → 自动装箱/拆箱匹配。

### 参考样例

```java
public class Calculator {

    // 重载：两个整数相加
    public int add(int a, int b) {
        return a + b;
    }

    // 重载：三个整数相加
    public int add(int a, int b, int c) {
        return a + b + c;
    }

    // 重载：两个浮点数相加
    public double add(double a, double b) {
        return a + b;
    }

    // 重载：字符串拼接
    public String add(String a, String b) {
        return a + b;
    }

    public static void main(String[] args) {
        Calculator calc = new Calculator();
        System.out.println(calc.add(1, 2));           // 输出: 3
        System.out.println(calc.add(1, 2, 3));        // 输出: 6
        System.out.println(calc.add(1.5, 2.5));       // 输出: 4.0
        System.out.println(calc.add("Hello", "World")); // 输出: HelloWorld
    }
}
```

```java
// 重载匹配规则
public class OverloadDemo {

    public void process(int num) {
        System.out.println("int: " + num);
    }

    public void process(double num) {
        System.out.println("double: " + num);
    }

    public void process(Integer num) {
        System.out.println("Integer: " + num);
    }

    public static void main(String[] args) {
        OverloadDemo demo = new OverloadDemo();
        demo.process(10);      // 输出: int: 10 (精确匹配)
        demo.process(10.5);     // 输出: double: 10.5 (精确匹配)
        demo.process(Integer.valueOf(10)); // 输出: Integer: 10
    }
}
```

## 可变参数（Varargs）

JDK 5 引入的特性，允许方法接受零个或多个参数。参数名是一个数组，可变参数必须是最后一个参数，每次调用会创建新数组。

### 参考样例

```java
public class StringUtils {

    // 连接多个字符串
    public static String join(String... strings) {
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < strings.length; i++) {
            if (i > 0) {
                sb.append(", ");
            }
            sb.append(strings[i]);
        }
        return sb.toString();
    }

    // 计算多个整数的最大值
    public static int max(int... numbers) {
        if (numbers == null || numbers.length == 0) {
            throw new IllegalArgumentException("At least one number is required");
        }
        int max = numbers[0];
        for (int i = 1; i < numbers.length; i++) {
            if (numbers[i] > max) {
                max = numbers[i];
            }
        }
        return max;
    }

    public static void main(String[] args) {
        System.out.println(join("Apple", "Banana", "Orange"));  // Apple, Banana, Orange
        System.out.println(max(3, 7, 2, 9, 5));  // 9
    }
}
```

```java
// 可变参数必须是最后一个参数
public void print(String prefix, int... numbers) { }  // 正确
// public void print(int... numbers, String prefix) { }  // 错误
```

## 方法引用（Method Reference）

JDK 8 引入，是 Lambda 表达式的一种简化写法。当 Lambda 表达式只是调用已有方法时，使用方法引用更简洁。

### 四种类型

| 类型 | 语法 | 示例 |
|------|------|------|
| 静态方法引用 | `类名::静态方法名` | `String::valueOf` |
| 实例方法引用（特定对象） | `对象::实例方法名` | `str::length` |
| 实例方法引用（任意对象） | `类名::实例方法名` | `String::toUpperCase` |
| 构造函数引用 | `类名::new` | `ArrayList::new` |

### 参考样例

```java
// 1. 静态方法引用
Function<String, Integer> parser = Integer::parseInt;
System.out.println(parser.apply("123"));  // 123

// 2. 实例方法引用（特定对象）
String str = "Hello";
Supplier<Integer> lengthSupplier = str::length;
System.out.println(lengthSupplier.get());  // 5

// 3. 实例方法引用（任意对象）
List<String> names = new ArrayList<>();
names.add("Alice");
names.add("Bob");
names.add("Charlie");
names.forEach(System.out::println);

// 字符串比较
Comparator<String> comparator = String::compareTo;

// 4. 构造函数引用
Supplier<List<String>> listSupplier = ArrayList::new;
List<String> newList = listSupplier.get();

// 带参数的构造函数
Function<Integer, String[]> arrayCreator = String[]::new;
String[] array = arrayCreator.apply(5);
```

```java
// 方法引用 vs Lambda
public class CompareDemo {

    public static int multiply(int a, int b) {
        return a * b;
    }

    public int divide(int a, int b) {
        return a / b;
    }

    public static void main(String[] args) {
        CompareDemo demo = new CompareDemo();

        // 静态方法引用
        BiFunction<Integer, Integer, Integer> multiply1 = (a, b) -> multiply(a, b);
        BiFunction<Integer, Integer, Integer> multiply2 = CompareDemo::multiply;

        // 实例方法引用（特定对象）
        BiFunction<Integer, Integer, Integer> divide1 = (a, b) -> demo.divide(a, b);
        BiFunction<Integer, Integer, Integer> divide2 = demo::divide;
    }
}
```

## 递归方法

方法调用自身的特性称为递归。常用于解决分治问题。必须有终止条件，否则会导致 StackOverflowError。

### 参考样例

```java
public class RecursionDemo {

    // 计算斐波那契数列
    public static long fibonacci(int n) {
        if ( n <= 1) {
            return n;
        }
        return fibonacci(n - 1) + fibonacci(n - 2);
    }

    // 计算阶乘
    public static long factorial(int n) {
        if ( n <= 1) {
            return 1;
        }
        return n * factorial(n - 1);
    }

    // 递归遍历目录
    public static void printDirectory(File dir, String indent) {
        File[] files = dir.listFiles();
        if (files != null) {
            for (File file : files) {
                System.out.println(indent + file.getName());
                if (file.isDirectory()) {
                    printDirectory(file, indent + "  ");
                }
            }
        }
    }
}
```

```java
// 使用记忆化提升性能
public class FibMemo {

    private static long[] memo = new long[100];

    public static long fibonacci(int n) {
        if ( n <= 1) {
            return n;
        }
        if (memo[n] != 0) {
            return memo[n];
        }
        memo[n] = fibonacci(n - 1) + fibonacci(n - 2);
        return memo[n];
    }

    public static void main(String[] args) {
        System.out.println(fibonacci(50));  // 快速返回
    }
}
```

## 静态方法

使用 `static` 关键字修饰的方法，不需要创建对象就可以调用。限制：只能访问静态成员，不能使用 `this` 或 `super`，不能被重写但可以被隐藏。

### 参考样例

```java
public class StaticMethodDemo {

    public static int add(int a, int b) {
        return a + b;
    }

    public static void main(String[] args) {
        int result = StaticMethodDemo.add(3, 5);
        System.out.println(result);  // 输出: 8
    }
}
```

```java
// 静态方法的限制
public class StaticRestrictions {

    private static int staticVar = 10;
    private int instanceVar = 20;

    public static void staticMethod() {
        System.out.println(staticVar);
        // System.out.println(instanceVar);  // 编译错误
    }
}
```

## 方法参数传递

Java 采用**值传递**（pass by value）。基本类型传递副本，引用类型传递引用副本（指向同一对象）。

### 参考样例

```java
public class PassByValueDemo {

    public static void main(String[] args) {
        // 基本类型 - 传递副本
        int num = 10;
        modifyPrimitive(num);
        System.out.println(num);  // 输出: 10（不变）

        // 引用类型 - 传递引用副本（指向同一对象）
        int[] arr = {1, 2, 3};
        modifyArray(arr);
        System.out.println(arr[0]);  // 输出: 100（改变了）
    }

    public static void modifyPrimitive(int n) {
        n = 20;
    }

    public static void modifyArray(int[] array) {
        array[0] = 100;
    }
}
```

```java
// 交换两个变量的值：由于值传递的特性，直接交换不会影响原变量
public class SwapDemo {

    public static void swap(int a, int b) {
        int temp = a;
        a = b;
        b = temp;
    }

    public static void main(String[] args) {
        int x = 10, y = 20;
        swap(x, y);
        System.out.println(x + ", " + y);  // 输出: 10, 20（未交换）
    }
}
```
