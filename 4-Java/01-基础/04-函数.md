# 函数

Java 中"函数"被称为"方法"（Method），因为 Java 是纯面向对象语言，所有方法都必须定义在类内部。

## 方法定义

方法由访问修饰符、返回类型、方法名和参数列表组成。

## 方法重载（Overload）

同一个类中，方法名相同但参数列表不同（参数个数、类型或顺序不同）。返回值类型不能作为重载依据。

**为什么 Java 按值传递但重载看参数列表：** 方法签名在编译时确定，包括方法名和参数类型，不包括返回类型。因此两个返回类型不同但参数相同的方法会编译冲突。

**重载匹配顺序：** 精确匹配 → 自动类型转换匹配 → 自动装箱/拆箱匹配。

```java
public class Calculator {
    public int add(int a, int b) { return a + b; }
    public int add(int a, int b, int c) { return a + b + c; }
    public double add(double a, double b) { return a + b; }
    public String add(String a, String b) { return a + b; }
}
```

```java
public class OverloadDemo {
    public void process(int num) { }
    public void process(double num) { }
    public void process(Integer num) { }
    process(10);    // int: 精确匹配
    process(10.5);  // double: 精确匹配
    process(Integer.valueOf(10)); // Integer
}
```

## 可变参数（Varargs）

JDK 5 引入，允许方法接受零个或多个参数。本质是数组，可变参数必须是最后一个参数。

```java
public static String join(String... strings) {
    StringBuilder sb = new StringBuilder();
    for (int i = 0; i < strings.length; i++) {
        if (i > 0) sb.append(", ");
        sb.append(strings[i]);
    }
    return sb.toString();
}
```

```java
public void print(String prefix, int... numbers) { }
```

## 方法引用（Method Reference）

JDK 8 引入，是 Lambda 表达式的简化写法。当 Lambda 表达式只是调用已有方法时，使用方法引用更简洁。

| 类型 | 语法 | 示例 |
|------|------|------|
| 静态方法引用 | `类名::静态方法名` | `String::valueOf` |
| 实例方法引用（特定对象） | `对象::实例方法名` | `str::length` |
| 实例方法引用（任意对象） | `类名::实例方法名` | `String::toUpperCase` |
| 构造函数引用 | `类名::new` | `ArrayList::new` |

```java
Function<String, Integer> parser = Integer::parseInt;
Supplier<Integer> len = "Hello"::length;
List<String> names = List.of("a", "b");
names.forEach(System.out::println);
Supplier<List<String>> listSupplier = ArrayList::new;
Function<Integer, String[]> arrayCreator = String[]::new;
```

**为什么方法引用比 Lambda 更高效：** 方法引用在字节码层面直接指向方法，而不是创建新的函数对象；JIT 编译器可以更容易地内联方法引用。

## 递归方法

方法调用自身。常用于解决分治问题。必须有终止条件，否则导致 StackOverflowError。

```java
public static long fibonacci(int n) {
    if (n <= 1) return n;
    return fibonacci(n - 1) + fibonacci(n - 2);
}
```

**为什么递归有栈溢出风险：** 每次递归调用在栈上分配新的栈帧，深度过大会耗尽栈空间。尾递归优化在 Java 中未实现，因此大深度递归应使用迭代或显式栈。

```java
public static long fibonacci(int n) {
    if (n <= 1) return n;
    long[] memo = new long[n + 1];
    for (int i = 2; i <= n; i++) {
        memo[i] = memo[i - 1] + memo[i - 2];
    }
    return memo[n];
}
```

## 静态方法

使用 `static` 关键字修饰，不需要创建对象即可调用。限制：只能访问静态成员，不能使用 `this` 或 `super`，不能被重写但可以被隐藏。

```java
public static int add(int a, int b) {
    return a + b;
}
StaticMethodDemo.add(3, 5);
```

```java
public class StaticRestrictions {
    private static int staticVar = 10;
    public static void staticMethod() {
        System.out.println(staticVar);
    }
}
```

## 方法参数传递

Java 采用**值传递**（pass by value）：基本类型传递副本，引用类型传递引用副本（指向同一对象）。

```java
public class PassByValueDemo {
    public static void modifyPrimitive(int n) {
        n = 20;
    }
    public static void modifyArray(int[] array) {
        array[0] = 100;
    }
    public static void main(String[] args) {
        int num = 10;
        modifyPrimitive(num);
        int[] arr = {1, 2, 3};
        modifyArray(arr);
    }
}
```

```java
public static void swap(int a, int b) {
    int temp = a;
    a = b;
    b = temp;
}
```

**为什么 swap 无法交换原变量：** 原始引用副本指向原变量，重新赋值只修改了局部副本，原引用不变。
