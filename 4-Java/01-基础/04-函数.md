# 函数

在 Java 中，"函数"被称为"方法"（Method）。Java 是一种纯面向对象的语言，所有方法都必须定义在类内部。

## 方法定义

```java
访问修饰符 返回类型 方法名(参数列表) {
    // 方法体
    return 返回值;
}
```

### 示例

```java
public class MathUtils {

    // 计算两个整数的和
    public int add(int a, int b) {
        return a + b;
    }

    // 计算阶乘（递归）
    public int factorial(int n) {
        if (n <= 1) {
            return 1;
        }
        return n * factorial(n - 1);
    }
}
```

## 方法重载（Overload）

同一个类中，方法名相同但参数列表不同（参数个数、类型或顺序不同）。返回值类型不能作为重载的依据。

### 为什么需要重载？

当功能相似但参数不同时，使用相同的方法名可以让代码更易读。例如 `println` 方法可以打印整数、字符串、布尔值等。

```java
public class Calculator {

    // 重载：两个整数相加
    public int add(int a, int b) {
        return a + b;
    }

    // 重载：三个整数相加
    public int add(int a, int b, int c) {
        return a + b + c;
    }

    // 重载：两个浮点数相加
    public double add(double a, double b) {
        return a + b;
    }

    // 重载：字符串拼接
    public String add(String a, String b) {
        return a + b;
    }

    public static void main(String[] args) {
        Calculator calc = new Calculator();
        System.out.println(calc.add(1, 2));           // 输出: 3
        System.out.println(calc.add(1, 2, 3));        // 输出: 6
        System.out.println(calc.add(1.5, 2.5));       // 输出: 4.0
        System.out.println(calc.add("Hello", "World")); // 输出: HelloWorld
    }
}
```

### 重载的匹配规则

当调用重载方法时，Java 按照以下顺序寻找匹配：

1. 精确匹配
2. 通过自动类型转换匹配
3. 通过自动装箱/拆箱匹配

```java
public class OverloadDemo {

    public void process(int num) {
        System.out.println("int: " + num);
    }

    public void process(double num) {
        System.out.println("double: " + num);
    }

    public void process(Integer num) {
        System.out.println("Integer: " + num);
    }

    public static void main(String[] args) {
        OverloadDemo demo = new OverloadDemo();
        demo.process(10);      // 输出: int: 10 (精确匹配)
        demo.process(10.5);     // 输出: double: 10.5 (精确匹配)
        demo.process(Integer.valueOf(10)); // 输出: Integer: 10
    }
}
```

## 可变参数（Varargs）

JDK 5 引入的特性，允许方法接受零个或多个参数。

### 基本语法

```java
public 返回类型 方法名(参数类型... 参数名) {
    // 参数名是一个数组
}
```

### 使用场景

当你需要处理不确定数量的同类参数时，可变参数非常有用。

```java
public class StringUtils {

    // 连接多个字符串
    public static String join(String... strings) {
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < strings.length; i++) {
            if (i > 0) {
                sb.append(", ");
            }
            sb.append(strings[i]);
        }
        return sb.toString();
    }

    // 计算多个整数的最大值
    public static int max(int... numbers) {
        if (numbers == null || numbers.length == 0) {
            throw new IllegalArgumentException("At least one number is required");
        }
        int max = numbers[0];
        for (int i = 1; i < numbers.length; i++) {
            if (numbers[i] > max) {
                max = numbers[i];
            }
        }
        return max;
    }

    public static void main(String[] args) {
        // 连接字符串
        System.out.println(join("Apple", "Banana", "Orange"));
        // 输出: Apple, Banana, Orange

        // 求最大值
        System.out.println(max(3, 7, 2, 9, 5));
        // 输出: 9
    }
}
```

### 可变参数的注意事项

1. **可变参数必须是最后一个参数**

```java
// 正确
public void print(String prefix, int... numbers) { }

// 错误 - 编译失败
public void print(int... numbers, String prefix) { }
```

2. **每次调用会创建新数组**

```java
public class VarargsDemo {

    // 可变参数实际上是一个数组
    public static void printAll(String... names) {
        System.out.println("参数个数: " + names.length);
        for (String name : names) {
            System.out.println(name);
        }
    }

    public static void main(String[] args) {
        printAll("Alice");                    // 1 个参数
        printAll("Bob", "Charlie");           // 2 个参数
        printAll("David", "Eve", "Frank");    // 3 个参数
    }
}
```

## 方法引用（Method Reference）

JDK 8 引入，是 Lambda 表达式的一种简化写法。当 Lambda 表达式只是调用已有方法时，使用方法引用更简洁。

### 四种类型

| 类型 | 语法 | 示例 |
|------|------|------|
| 静态方法引用 | `类名::静态方法名` | `String::valueOf` |
| 实例方法引用（特定对象） | `对象::实例方法名` | `str::length` |
| 实例方法引用（任意对象） | `类名::实例方法名` | `String::toUpperCase` |
| 构造函数引用 | `类名::new` | `ArrayList::new` |

### 代码示例

```java
import java.util.function.*;
import java.util.ArrayList;
import java.util.List;

public class MethodReferenceDemo {

    public static void main(String[] args) {

        // 1. 静态方法引用
        // Lambda: (s) -> Integer.parseInt(s)
        // 引用:   Integer::parseInt
        Function<String, Integer> parser = Integer::parseInt;
        System.out.println(parser.apply("123"));  // 输出: 123

        // 2. 实例方法引用（特定对象）
        String str = "Hello";
        // Lambda: () -> str.length()
        // 引用:   str::length
        Supplier<Integer> lengthSupplier = str::length;
        System.out.println(lengthSupplier.get());  // 输出: 5

        // 3. 实例方法引用（任意对象）
        // 常见于集合的 forEach
        List<String> names = new ArrayList<>();
        names.add("Alice");
        names.add("Bob");
        names.add("Charlie");

        // Lambda: (s) -> System.out.println(s)
        // 引用:   System.out::println
        names.forEach(System.out::println);

        // 另一个例子：字符串比较
        // Lambda: (s1, s2) -> s1.compareTo(s2)
        // 引用:   String::compareTo
        Comparator<String> comparator = String::compareTo;

        // 4. 构造函数引用
        // Lambda: () -> new ArrayList<>()
        // 引用:   ArrayList::new
        Supplier<List<String>> listSupplier = ArrayList::new;
        List<String> newList = listSupplier.get();

        // 带参数的构造函数
        Function<Integer, String[]> arrayCreator = String[]::new;
        String[] array = arrayCreator.apply(5);  // 创建长度为5的数组
    }
}
```

### 方法引用 vs Lambda 表达式

```java
import java.util.function.BiFunction;

public class CompareDemo {

    public static int multiply(int a, int b) {
        return a * b;
    }

    public int divide(int a, int b) {
        return a / b;
    }

    public static void main(String[] args) {
        CompareDemo demo = new CompareDemo();

        // 静态方法引用
        BiFunction<Integer, Integer, Integer> multiply1 = (a, b) -> multiply(a, b);
        BiFunction<Integer, Integer, Integer> multiply2 = CompareDemo::multiply;
        // 两者等价

        // 实例方法引用（特定对象）
        BiFunction<Integer, Integer, Integer> divide1 = (a, b) -> demo.divide(a, b);
        BiFunction<Integer, Integer, Integer> divide2 = demo::divide;
        // 两者等价
    }
}
```

### 实际应用场景

```java
import java.util.*;
import java.util.stream.Collectors;

public class RealWorldDemo {

    public static void main(String[] args) {
        List<Person> people = Arrays.asList(
            new Person("Alice", 30),
            new Person("Bob", 25),
            new Person("Charlie", 35)
        );

        // 按名字排序（实例方法引用）
        people.sort(Comparator.comparing(Person::getName));

        // 提取名字列表（方法引用）
        List<String> names = people.stream()
            .map(Person::getName)
            .collect(Collectors.toList());

        System.out.println(names);

        // 过滤并收集（方法引用）
        List<Person> adults = people.stream()
            .filter(Person::isAdult)
            .collect(Collectors.toList());
    }
}

class Person {
    private String name;
    private int age;

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public String getName() { return name; }
    public int getAge() { return age; }
    public boolean isAdult() { return age >= 18; }
}
```

## 递归方法

方法调用自身的特性称为递归。常用于解决分治问题。

```java
public class RecursionDemo {

    // 计算斐波那契数列
    public static long fibonacci(int n) {
        if (n <= 1) {
            return n;
        }
        return fibonacci(n - 1) + fibonacci(n - 2);
    }

    // 计算阶乘
    public static long factorial(int n) {
        if (n <= 1) {
            return 1;
        }
        return n * factorial(n - 1);
    }

    // 递归遍历目录
    public static void printDirectory(File dir, String indent) {
        File[] files = dir.listFiles();
        if (files != null) {
            for (File file : files) {
                System.out.println(indent + file.getName());
                if (file.isDirectory()) {
                    printDirectory(file, indent + "  ");
                }
            }
        }
    }

    public static void main(String[] args) {
        // 斐波那契数列: 0, 1, 1, 2, 3, 5, 8, 13, 21, ...
        for (int i = 0; i < 10; i++) {
            System.out.print(fibonacci(i) + " ");
        }
        System.out.println();

        // 阶乘: 5! = 120
        System.out.println("5! = " + factorial(5));

        // 递归遍历当前目录（示例）
        // printDirectory(new File("."), "");
    }
}
```

### 递归的注意事项

1. **必须有终止条件**：否则会导致 StackOverflowError
2. **考虑性能问题**：斐波那契的递归实现效率低下，因为有大量重复计算

```java
// 使用记忆化提升性能
public class FibMemo {

    private static long[] memo = new long[100];

    public static long fibonacci(int n) {
        if (n <= 1) {
            return n;
        }
        if (memo[n] != 0) {
            return memo[n];
        }
        memo[n] = fibonacci(n - 1) + fibonacci(n - 2);
        return memo[n];
    }

    public static void main(String[] args) {
        System.out.println(fibonacci(50));  // 快速返回
    }
}
```

## 静态方法

使用 `static` 关键字修饰的方法，不需要创建对象就可以调用。

```java
public class StaticMethodDemo {

    public static int add(int a, int b) {
        return a + b;
    }

    public static void main(String[] args) {
        // 直接通过类名调用
        int result = StaticMethodDemo.add(3, 5);
        System.out.println(result);  // 输出: 8
    }
}
```

### 静态方法的限制

1. 只能访问静态成员（静态变量、静态方法）
2. 不能使用 `this` 或 `super`
3. 不能被重写（override），但可以被隐藏

```java
public class StaticRestrictions {

    private static int staticVar = 10;
    private int instanceVar = 20;

    // 正确：访问静态变量
    public static void staticMethod() {
        System.out.println(staticVar);
        // System.out.println(instanceVar);  // 编译错误
    }
}
```

## 方法参数传递

Java 采用**值传递**（pass by value）。

```java
public class PassByValueDemo {

    public static void main(String[] args) {
        // 基本类型 - 传递副本
        int num = 10;
        modifyPrimitive(num);
        System.out.println(num);  // 输出: 10（不变）

        // 引用类型 - 传递引用副本（指向同一对象）
        int[] arr = {1, 2, 3};
        modifyArray(arr);
        System.out.println(arr[0]);  // 输出: 100（改变了）
    }

    public static void modifyPrimitive(int n) {
        n = 20;
    }

    public static void modifyArray(int[] array) {
        array[0] = 100;
    }
}
```

### 交换两个变量的值

由于值传递的特性，直接交换不会影响原变量：

```java
public class SwapDemo {

    public static void swap(int a, int b) {
        int temp = a;
        a = b;
        b = temp;
    }

    public static void main(String[] args) {
        int x = 10, y = 20;
        swap(x, y);
        System.out.println(x + ", " + y);  // 输出: 10, 20（未交换）
    }
}
```

如果要交换，需要使用包装类或自定义对象。
