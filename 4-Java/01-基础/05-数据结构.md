## ArrayList 内部实现

### 核心结构

ArrayList 底层使用**动态数组**（Object[] elementData），初始容量为 10，每次扩容 1.5 倍。

```java
// ArrayList 核心字段（简化）
public class ArrayList<E> {
    private static final int DEFAULT_CAPACITY = 10;
    private Object[] elementData;
    private int size;

    public ArrayList() {
        elementData = new Object[DEFAULT_CAPACITY];
    }

    public ArrayList(int initialCapacity) {
        if (initialCapacity > 0) {
            elementData = new Object[initialCapacity];
        }
    }

    // 扩容：grow() 方法
    private void grow(int minCapacity) {
        int oldCapacity = elementData.length;
        int newCapacity = oldCapacity + (oldCapacity >> 1);  // 1.5倍
        if (newCapacity - minCapacity < 0)
            newCapacity = minCapacity;
        elementData = Arrays.copyOf(elementData, newCapacity);
    }
}
```

### 关键操作时间复杂度

| 操作 | 时间复杂度 | 说明 |
|------|-----------|------|
| get(index) | O(1) | 数组直接索引 |
| add(E element) | O(1) amortized | 均摊O(1)，扩容时O(n) |
| add(index, E) | O(n) | 移动index后的所有元素 |
| remove(index) | O(n) | 移动index后的所有元素 |
| contains/contains | O(n) | 需遍历数组 |

### 线程安全版本

```java
// 方式1：Collections.synchronizedList
```

## LinkedList 内部实现

### 核心结构

LinkedList 是**双向链表**，每个节点包含 prev、item、next 三个引用。

```java
// 节点结构
private static class Node<E> {
    E item;
    Node<E> next;
    Node<E> prev;

    Node(Node<E> prev, E element, Node<E> next) {
        this.item = element;
        this.next = next;
        this.prev = prev;
    }
}

// LinkedList 核心字段
public class LinkedList<E> {
    private Node<E> first;
    private Node<E> last;
    private int size;

    // 头部插入
    private void linkFirst(E e) {
        Node<E> newNode = new Node<>(null, e, first);
        if (first == null) {
            last = newNode;
        } else {
            first.prev = newNode;
        }
        first = newNode;
        size++;
    }
}
```

### 关键操作时间复杂度

| 操作 | 时间复杂度 | 说明 |
|------|-----------|------|
| get(index) | O(n) | 需遍历链表 |
| add(E) | O(1) | 尾部插入 |
| remove(index) | O(n) | 需先定位 |
| addFirst/removeFirst | O(1) | 链表头部操作 |

### ArrayList vs LinkedList

| 场景 | ArrayList | LinkedList |
|------|-----------|------------|
| 随机访问 | O(1) | O(n) |
| 头部插入/删除 | O(n) | O(1) |
| 尾部插入/删除 | O(1) amortized | O(1) |
| 内存占用 | 连续，节省指针 | 每节点2个指针 |

## HashMap 内部实现（JDK 8+）

### 结构演进

- JDK 7：数组 + 链表（冲突用拉链法）
- JDK 8+：数组 + 链表 + 红黑树（链表长度 > 8 转为红黑树）

### 核心结构

```java
public class HashMap<K, V> {
    // 桶数组
    transient Node<K, V>[] table;

    // 节点结构
    static class Node<K, V> {
        final int hash;
        final K key;
        V value;
        Node<K, V> next;  // 链表next指针
    }

    // 树节点（JDK 8+）
    static final class TreeNode<K, V> {
        TreeNode<K, V> parent;
        TreeNode<K, V> left;
        TreeNode<K, V> right;
        TreeNode<K, V> prev;
        boolean red;  // 红黑树颜色
    }
}
```

### 红黑树特性

HashMap 使用红黑树保证最坏 O(log n) 的查找性能：

1. 每个节点非红即黑
2. 根节点是黑色
3. 叶节点（NIL）是黑色
4. 红节点的子节点必须是黑色
5. 从任一节点到其每个叶子的路径包含相同数量的黑色节点

### put 流程

```
put(key, value)
  ↓
1. 计算 hash = hash(key)
  ↓
2. 找到桶位置 i = (n-1) & hash
  ↓
3. 桶为空 → 直接插入
   桶不为空 →
     a. key相等 → 覆盖value
     b. 当前是TreeNode → 红黑树插入
     c. 当前是链表 → 遍历，尾插
        - 找到相同key → 覆盖
        - 未找到 → 插入尾部，若长度>8 → 转红黑树
  ↓
4. 检查是否扩容（size > threshold）
```

### 关键操作时间复杂度

| 操作 | 平均 | 最坏 |
|------|------|------|
| get | O(1) | O(log n)（红黑树） |
| put | O(1) | O(log n)（红黑树） |
| remove | O(1) | O(log n)（红黑树） |
| containsKey | O(1) | O(log n)（红黑树） |

### 扩容机制

```java
// 扩容因子 0.75（loadFactor）
// threshold = capacity * loadFactor

// 容量总是 2 的幂（方便取模）
// 扩容时容量翻倍，所有元素重新 hash（可优化）
newTab[(oldCapacity - 1) & hash]  // 旧桶位置
newTab[index + oldCapacity]        // 新桶位置（原hash高位为1时）
```

## 泛型

编译时类型安全检查。

```java
// 泛型类
class Box<T> {
    private T content;
    public T getContent() { return content; }
    public void setContent(T content) { this.content = content; }
}

// 泛型方法
public static <T> T findMax(List<T> list) {
    return list.stream().max(Comparator.naturalOrder()).orElse(null);
}

// 泛型限定
<T extends Comparable<T>>  // 上界限定
<? extends T>            // PECS（Producer Extends, Consumer Super）
<? super T>               // 逆变
```
