# 变量与类型

## 静态类型

Java是静态类型语言，变量类型在编译时确定，编译器会进行类型检查，可以提前发现类型错误，提高代码安全性和可读性。

## 基本类型（8种）

Java的基本类型分为4类：整型、浮点型、字符型、布尔型。

### 整型

| 类型 | 位数 | 范围 | 默认值 |
|------|------|------|--------|
| byte | 8bit | -128 ~ 127 | 0 |
| short | 16bit | -32,768 ~ 32,767 | 0 |
| int | 32bit | -2,147,483,648 ~ 2,147,483,647 | 0 |
| long | 64bit | -9,223,372,036,854,775,808 ~ 9,223,372,036,854,775,807 | 0L |

```java
byte b = 100;
short s = 1000;
int i = 100000;
long l = 100000L;  // 推荐使用L后缀，避免与int混淆
```

### 浮点型

| 类型 | 位数 | 范围 | 默认值 |
|------|------|------|--------|
| float | 32bit | ±3.4E+38（7位有效数字） | 0.0f |
| double | 64bit | ±1.8E+308（15位有效数字） | 0.0d |

```java
float f = 3.14f;    // 必须加f后缀
double d = 3.14;     // d后缀可选
double pi = Math.PI;
```

### 字符型

- `char`：16bit Unicode字符
- 范围：'\u0000' ~ '\uFFFF'

```java
char c1 = 'A';
char c2 = '中';
char c3 = '\u0041';  // Unicode编码
```

### 布尔型

- `boolean`：true / false
- JVM实现中通常使用1bit，但实际占用大小由JVM决定

```java
boolean flag = true;
boolean isValid = false;
```

## 引用类型

引用类型存储对象的地址（引用），而非对象本身。

### 类型分类

- **类（Class）**：自定义类、String等
- **接口（Interface）**
- **数组（Array）**
- **枚举（Enum）**
- **记录（Record）**（Java 16+，正式版）

```java
String str = "Hello";        // String类
int[] arr = {1, 2, 3};      // 数组
List<Integer> list = new ArrayList<>();  // 接口+实现类
```

### 内存模型

```
栈内存（Stack）          堆内存（Heap）
┌─────────────┐          ┌─────────────────┐
│ str ────────┼─────────→│ "Hello" 对象    │
│ arr ────────┼─────────→│ [1, 2, 3] 数组  │
└─────────────┘          └─────────────────┘
```

- **栈内存**：存放局部变量（方法参数、基本类型变量、引用变量）
- **堆内存**：存放所有new创建的对象和数组
- **字符串常量池**：存放字符串字面量

## 字符串

`String`是不可变对象，存储在字符串常量池中。

### 字符串创建方式

```java
// 字面量方式（优先使用）
String s1 = "Hello";

// new方式（每次创建新对象）
String s2 = new String("Hello");

// s1 == s2 为false，s1.equals(s2) 为true
```

### 常用操作

```java
String str = "Hello, World!";

// 长度
int len = str.length();

// 查找子串
int index = str.indexOf("World");    // 返回起始位置
boolean contains = str.contains("World");

// 截取
String sub = str.substring(0, 5);    // "Hello"

// 替换
String replaced = str.replace("World", "Java");

// 分割
String[] parts = "a,b,c".split(",");

// 转换
String upper = str.toUpperCase();
String lower = str.toLowerCase();
String trimmed = "  hi  ".trim();

// 拼接（推荐使用StringBuilder）
String joined = String.join("-", "a", "b", "c");  // "a-b-c"
```

## 自动装箱与拆箱

基本类型和包装类之间的自动转换。

### 装箱（Boxing）

基本类型 → 包装类

```java
Integer boxed = 10;          // 自动装箱
Integer boxed2 = Integer.valueOf(10);  // 手动装箱
```

### 拆箱（Unboxing）

包装类 → 基本类型

```java
int unboxed = boxed;         // 自动拆箱
int unboxed2 = boxed.intValue();  // 手动拆箱
```

### 注意事项

```java
// 装箱会产生对象，避免在循环中频繁操作
List<Integer> list = new ArrayList<>();
for (int i = 0; i < 1000; i++) {
    list.add(i);  // 每次add都会自动装箱
}

// 建议：使用基本类型集合或批量操作
IntStream.range(0, 1000).boxed().collect(Collectors.toList());
```

### 整数缓存

```java
Integer a = 127;
Integer b = 127;
System.out.println(a == b);    // true（缓存范围-128~127）

Integer c = 128;
Integer d = 128;
System.out.println(c == d);    // false（超出缓存范围）
```

## 类型转换

### 自动类型转换（隐式）

小范围 → 大范围，自动进行

```
byte → short → int → long → float → double
char → int
```

```java
int i = 100;
long l = i;      // 自动转换
double d = l;    // 自动转换
```

### 强制类型转换（显式）

大范围 → 小范围，需要cast

```java
double d = 3.14;
int i = (int) d;     // i = 3（小数部分丢失）
long l = 100;
int i2 = (int) l;    // 安全，不丢失数据
```

### 强制转换风险

```java
double d = 1e10;
int i = (int) d;     // 溢出！i变成一个负数
```

## 变量类型推断

Java 10+支持局部变量类型推断。

### var关键字（Java 10+）

```java
var message = "Hello";          // 推断为String
var numbers = new ArrayList<>(); // 推断为ArrayList<>
var stream = list.stream();      // 推断为Stream

// 注意：var不能用于全局变量、方法返回类型、构造函数参数
```

### 适用场景

```java
// 推荐使用var的场景
var result = someComplexMethodReturningGenericType();
var list = new ArrayList<Map<String, List<Object>>>();

// 不推荐使用var的场景
var x;              // 错误：必须初始化
var lambda = (a, b) -> a + b;  // 错误：无法推断
```

## 方法参数传递

Java总是按值传递。

### 基本类型参数

```java
void increment(int x) {
    x = x + 1;  // 只修改局部副本
}

int num = 10;
increment(num);
System.out.println(num);  // 仍然是10
```

### 引用类型参数

```java
void modify(StringBuilder sb) {
    sb.append(" World");   // 修改引用所指对象
}

StringBuilder sb = new StringBuilder("Hello");
modify(sb);
System.out.println(sb);  // "Hello World"

// 注意：如果在方法内重新赋值引用，不影响原变量
void reassign(StringBuilder sb) {
    sb = new StringBuilder("New");  // 只修改局部引用
}
reassign(sb);
System.out.println(sb);  // 仍然是"Hello"
```

## 关键字与保留字

Java有一些特殊意义的单词，不能用作标识符。

常见关键字：`abstract`, `assert`, `boolean`, `break`, `byte`, `case`, `catch`, `char`, `class`, `const`, `continue`, `default`, `do`, `double`, `else`, `enum`, `extends`, `final`, `finally`, `float`, `for`, `goto`, `if`, `implements`, `import`, `instanceof`, `int`, `interface`, `long`, `native`, `new`, `package`, `private`, `protected`, `public`, `return`, `short`, `static`, `strictfp`, `super`, `switch`, `synchronized`, `this`, `throw`, `throws`, `transient`, `try`, `void`, `volatile`, `while`

保留字（未被使用但保留）：`goto`, `const`
