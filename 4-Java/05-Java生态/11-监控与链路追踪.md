# 监控与链路追踪

## 概述

在微服务架构中，监控和链路追踪是运维的核心能力。监控关注系统指标（CPU、内存、请求延迟），链路追踪关注请求在分布式系统中的完整调用路径。两者结合实现全面的可观测性。

## Spring Boot Actuator

### Actuator 端点

Actuator 提供一组 HTTP 端点用于监控和管理应用。生产环境应限制暴露的端点，只开放 health、metrics 等必要端点。

| 端点 | 说明 |
|------|------|
| /actuator/health | 健康检查 |
| /actuator/info | 应用信息 |
| /actuator/metrics | 指标数据 |
| /actuator/prometheus | Prometheus 格式 |
| /actuator/loggers | 日志级别 |
| /actuator/threaddump | 线程转储 |
| /actuator/heapdump | 堆转储 |

### 基础配置

```yaml
management:
  endpoints:
    web:
      exposure:
        include: health,info,metrics,prometheus
      base-path: /actuator
  endpoint:
    health:

      enabled: true
```

### 自定义健康检查

HealthIndicator 接口允许自定义健康检查逻辑，聚合多个依赖的检查结果。

```java
@Component
public class CustomHealthIndicator implements HealthIndicator {

    @Autowired
    private DatabaseService databaseService;

    @Autowired
    private ExternalApiService externalApiService;

    @Override
    public Health health() {
        StringBuilder details = new StringBuilder();

        boolean dbHealthy = checkDatabase(details);
        boolean apiHealthy = checkExternalApi(details);

        if (dbHealthy && apiHealthy) {
            return Health.up()
                .withDetail("database", "connected")
                .withDetail("externalApi", "available")
                .build();
        } else {
            return Health.down()
                .withDetail("database", dbHealthy ? "ok" : "failed")
                .withDetail("externalApi", apiHealthy ? "ok" : "failed")
                .withDetail("details", details.toString())
                .build();
        }
    }

    private boolean checkDatabase(StringBuilder details) {
        try {
            databaseService.ping();
            return true;
        } catch (Exception e) {
            details.append("DB ping failed: ").append(e.getMessage());
            return false;
        }
    }

    private boolean checkExternalApi(StringBuilder details) {
        try {
            externalApiService.ping();
            return true;
        } catch (Exception e) {
            details.append("API ping failed: ").append(e.getMessage());
            return false;
        }
    }
}
```

### 自定义 Info 端点

InfoContributor 允许向 /actuator/info 端点贡献自定义信息。

```java
@Component
public class CustomInfoContributor implements InfoContributor {

    @Value("${build.version:1.0.0}")
    private String version;

    @Override
    public void contribute(Builder builder) {
        builder.withDetail("application", Map.of(
            "name", "user-service",
            "version", version,
            "environment", System.getProperty("spring.profiles.active", "dev")
        ));

        builder.withDetail("git", Map.of(
            "branch", getGitBranch(),
            "commit", getGitCommit()
        ));

        builder.withDetail("java", Map.of(
            "version", System.getProperty("java.version"),
            "vendor", System.getProperty("java.vendor")
        ));
    }

    private String getGitBranch() {
        try {
            return new String(
                Runtime.getRuntime().exec("git rev-parse --abbrev-ref HEAD")
                    .getInputStream().readAllBytes()
            ).trim();
        } catch (Exception e) {
            return "unknown";
        }
    }

    private String getGitCommit() {
        try {
            return new String(
                Runtime.getRuntime().exec("git rev-parse HEAD")
                    .getInputStream().readAllBytes()
            ).trim().substring(0, 7);
        } catch (Exception e) {
            return "unknown";
        }
    }
}
```

## Micrometer 指标

### 核心概念

Micrometer 是指标门面，支持多种监控系统（Prometheus、Datadog、InfluxDB等）。Meter 是指标的基础抽象，MeterRegistry 是指标的注册中心。

| Meter 类型 | 说明 |
|------------|------|
| Counter | 计数器，只增不减 |
| Gauge | 仪表，当前值 |
| Timer | 计时器，测量耗时 |
| LongTaskTimer | 长任务计时器 |
| DistributionSummary | 分布统计 |

### Counter 使用

Counter 用于记录事件发生次数，如请求数、订单数。

```java
@Service
public class OrderService {

    private final Counter orderCreatedCounter;
    private final Counter orderFailedCounter;
    private final Counter orderAmountCounter;

    public OrderService(MeterRegistry registry) {
        this.orderCreatedCounter = Counter.builder("orders.created")
            .description("Number of orders created")
            .tag("service", "order-service")
            .register(registry);

        this.orderFailedCounter = Counter.builder("orders.failed")
            .description("Number of failed orders")
            .tag("service", "order-service")
            .register(registry);

        this.orderAmountCounter = Counter.builder("orders.amount")
            .description("Total order amount in cents")
            .tag("service", "order-service")
            .register(registry);
    }

    public Order createOrder(OrderRequest request) {
        try {
            Order order = doCreateOrder(request);
            orderCreatedCounter.increment();
            orderAmountCounter.increment(request.getAmount().longValue());
            return order;
        } catch (Exception e) {
            orderFailedCounter.increment();
            throw e;
        }
    }
}
```

### Gauge 使用

Gauge 用于记录当前值，如缓存大小、队列长度。Gauge 只记录最新值，不做聚合。

```java
@Service
public class CacheMetricsService {

    private final AtomicLong cacheSize;
    private final AtomicLong cacheHits;
    private final AtomicLong cacheMisses;

    public CacheMetricsService(MeterRegistry registry) {
        this.cacheSize = new AtomicLong(0);
        this.cacheMisses = new AtomicLong(0);
        this.cacheHits = new AtomicLong(0);

        Gauge.builder("cache.size", cacheSize, AtomicLong::get)
            .description("Current cache size")
            .tag("cache", "user-cache")
            .register(registry);

        Gauge.builder("cache.hit_ratio", this, CacheMetricsService::calculateHitRatio)
            .description("Cache hit ratio")
            .tag("cache", "user-cache")
            .register(registry);
    }

    public void put(String key, Object value) {
        cacheSize.incrementAndGet();
    }

    public void remove(String key) {
        cacheSize.decrementAndGet();
    }

    private double calculateHitRatio() {
        long hits = cacheHits.get();
        long misses = cacheMisses.get();
        long total = hits + misses;
        return total > 0 ? (double) hits / total : 0.0;
    }
}
```

### Timer 使用

Timer 用于测量代码执行时间，自动记录次数、总耗时、最大耗时、百分位数。

```java
@Service
public class PaymentService {

    private final Timer paymentTimer;
    private final MeterRegistry registry;

    public PaymentService(MeterRegistry registry) {
        this.registry = registry;
        this.paymentTimer = Timer.builder("payment.process")
            .description("Payment processing time")
            .tag("service", "payment-service")
            .publishPercentiles(0.5, 0.95, 0.99)
            .publishPercentileHistogram()
            .register(registry);
    }

    public PaymentResult processPayment(PaymentRequest request) {
        return paymentTimer.record(() -> {
            try {
                return doProcessPayment(request);
            } catch (Exception e) {
                registry.counter("payment.errors")
                    .tag("type", e.getClass().getSimpleName())
                    .increment();
                throw e;
            }
        });
    }
}
```

## 链路追踪 - Micrometer Tracing

### 链路追踪概念

链路追踪记录请求在分布式系统中的完整调用路径。每个请求产生一个 Trace，多个 Span 组成 Trace。Span 表示一个操作单元，包含操作名、开始时间、持续时间、标签信息。

### 创建 Span

Tracer 创建 Span，SpanInScope 将 Span 绑定到当前线程。

```java
@Service
public class OrderWorkflowService {

    private final Tracer tracer;

    public OrderWorkflowService(Tracer tracer) {
        this.tracer = tracer;
    }

    public OrderResult processOrder(Long orderId) {
        Span span = tracer.nextSpan()
            .name("processOrder")
            .tag("order.id", orderId.toString())
            .start();

        try (Tracer.SpanInScope ignored = tracer.withSpan(span)) {
            // 验证订单
            span.event("validating order");
            validateOrder(orderId);

            // 检查库存
            span.event("checking inventory");
            boolean available = checkInventory(orderId);

            if (!available) {
                span.event("insufficient inventory");
                return OrderResult.insufficientInventory();
            }

            // 创建支付
            span.event("creating payment");
            Payment payment = createPayment(orderId);

            // 完成订单
            span.event("completing order");
            return completeOrder(orderId, payment);

        } catch (Exception e) {
            span.error(e);
            throw e;
        } finally {
            span.end();
        }
    }
}
```

### 异步追踪

异步操作需要手动传播 Span 上下文，确保新线程使用相同的 Trace。

```java
@Service
public class AsyncOrderProcessor {

    private final Tracer tracer;

    public AsyncOrderProcessor(Tracer tracer) {
        this.tracer = tracer;
    }

    @Async
    public CompletableFuture<Void> processOrderAsync(Long orderId) {
        Span span = tracer.nextSpan()
            .name("processOrderAsync")
            .tag("order.id", orderId.toString())
            .start();

        try (Tracer.SpanInScope ignored = tracer.withSpan(span)) {
            return CompletableFuture.runAsync(() -> {
                doProcessOrder(orderId);
            }).thenApply(result -> {
                span.event("order processed");
                return result;
            });
        } catch (Exception e) {
            span.error(e);
            throw e;
        } finally {
            span.end();
        }
    }
}
```

## OpenTelemetry

### 手动埋点

OpenTelemetry SDK 提供更底层的追踪 API，支持自定义属性和异常记录。

```java
@Service
public class UserService {

    private final Tracer tracer;
    private final OpenTelemetry openTelemetry;

    public UserService(OpenTelemetry openTelemetry) {
        this.tracer = openTelemetry.getTracer("user-service");
        this.openTelemetry = openTelemetry;
    }

    public User createUser(CreateUserRequest request) {
        Span span = tracer.spanBuilder("createUser")
            .setAttribute("user.email", request.getEmail())
            .setAttribute("user.type", request.getType().name())
            .startSpan();

        try (Scope scope = span.makeCurrent()) {
            // 验证邮箱唯一性
            if (userRepository.existsByEmail(request.getEmail())) {
                span.setAttribute("error", true);
                span.setAttribute("error.message", "Email already exists");
                throw new EmailAlreadyExistsException(request.getEmail());
            }

            User user = doCreateUser(request);

            span.setAttribute("user.id", user.getId());
            span.setStatus(StatusCode.OK);

            return user;
        } catch (Exception e) {
            span.recordException(e);
            span.setStatus(StatusCode.ERROR, e.getMessage());
            throw e;
        } finally {
            span.end();
        }
    }
}
```

## 自定义指标拦截器

### HTTP 请求指标

通过 HandlerInterceptor 拦截所有 HTTP 请求，自动记录请求时间、状态码等指标。

```java
@Component
public class MetricsInterceptor implements HandlerInterceptor {

    private final Timer requestTimer;
    private final Counter errorCounter;
    private final MeterRegistry registry;

    public MetricsInterceptor(MeterRegistry registry) {
        this.registry = registry;
        this.requestTimer = Timer.builder("http.server.requests")
            .tag("state", "success")
            .register(registry);
        this.errorCounter = Counter.builder("http.server.errors")
            .register(registry);
    }

    @Override
    public boolean preHandle(HttpServletRequest request,
                             HttpServletResponse response,
                             Object handler) {
        request.setAttribute("startTime", System.currentTimeMillis());
        return true;
    }

    @Override
    public void afterCompletion(HttpServletRequest request,
                               HttpServletResponse response,
                               Object handler,
                               Exception ex) {
        long duration = System.currentTimeMillis()
            - (Long) request.getAttribute("startTime");

        Timer.builder("http.server.requests")
            .tag("method", request.getMethod())
            .tag("uri", normalizeUri(request.getRequestURI()))
            .tag("status", String.valueOf(response.getStatus()))
            .tag("error", ex != null ? "true" : "false")
            .register(registry)
            .record(Duration.ofMillis(duration));

        if (ex != null) {
            errorCounter.increment();
        }
    }

    private String normalizeUri(String uri) {
        // 替换路径参数为占位符
        return uri.replaceAll("/\\d+", "/{id}");
    }
}
```

### 数据库查询指标

使用 AOP 拦截数据库操作，记录查询类型和执行时间。

```java
@Component
public class DatabaseMetricsInterceptor {

    private final MeterRegistry registry;
    private final Map<String, Timer> queryTimers = new ConcurrentHashMap<>();

    public DatabaseMetricsInterceptor(MeterRegistry registry) {
        this.registry = registry;
    }

    @Around("execution(* org.springframework.jdbc.core.JdbcTemplate.*(..))")
    public Object measureQuery(ProceedingJoinPoint joinPoint) throws Throwable {
        String methodName = joinPoint.getSignature().getName();
        String queryType = classifyQuery(methodName);

        Timer timer = queryTimers.computeIfAbsent(queryType, qt ->
            Timer.builder("db.query")
                .tag("type", qt)
                .register(registry)
        );

        return timer.record(() -> {
            try {
                return joinPoint.proceed();
            } catch (Exception e) {
                Counter.builder("db.errors")
                    .tag("type", queryType)
                    .tag("exception", e.getClass().getSimpleName())
                    .register(registry)
                    .increment();
                throw e;
            }
        });
    }

    private String classifyQuery(String methodName) {
        if (methodName.startsWith("query")) return "SELECT";
        if (methodName.startsWith("update") || methodName.startsWith("insert")) {
            return "WRITE";
        }
        if (methodName.startsWith("batch")) return "BATCH";
        return "OTHER";
    }
}
```

## 日志与追踪关联

### MDC 集成

通过 MDC（Mapped Diagnostic Context）将 TraceId/SpanId 注入日志上下文，实现日志与追踪的关联。

```java
@Component
public class TracingMdcFilter extends OncePerRequestFilter {

    private final Tracer tracer;

    public TracingMdcFilter(Tracer tracer) {
        this.tracer = tracer;
    }

    @Override
    protected void doFilterInternal(HttpServletRequest request,
                                   HttpServletResponse response,
                                   FilterChain filterChain)
            throws ServletException, IOException {

        Span currentSpan = tracer.currentSpan();
        if (currentSpan != null) {
            String traceId = currentSpan.context().traceId();
            String spanId = currentSpan.context().spanId();

            MDC.put("traceId", traceId);
            MDC.put("spanId", spanId);

            response.addHeader("X-Trace-Id", traceId);
            response.addHeader("X-Span-Id", spanId);
        }

        try {
            filterChain.doFilter(request, response);
        } finally {
            MDC.clear();
        }
    }
}
```

## 健康检查高级配置

```java
@Component
public class ReadinessHealthIndicator implements HealthIndicator {

    private final AtomicBoolean ready = new AtomicBoolean(false);

    @Autowired
    private List<DependencyCheck> dependencies;

    @Override
    public Health health() {
        if (!ready.get()) {
            return Health.down()
                .withDetail("reason", "Service not ready")
                .build();
        }

        List<String> failedDeps = checkDependencies();

        if (failedDeps.isEmpty()) {
            return Health.up()
                .withDetail("dependencies", "all healthy")
                .build();
        } else {
            return Health.down()
                .withDetail("failedDependencies", failedDeps)
                .build();
        }
    }

    private List<String> checkDependencies() {
        return dependencies.stream()
            .filter(dep -> !dep.isHealthy())
            .map(DependencyCheck::getName)
            .collect(Collectors.toList());
    }

    public void setReady(boolean ready) {
        this.ready.set(ready);
    }
}
```

### 关键指标

业务指标（用户登录、订单金额）与技术指标（CPU、内存）结合，形成完整的监控视图。

```java
@Service
public class BusinessMetrics {

    private final MeterRegistry registry;

    public BusinessMetrics(MeterRegistry registry) {
        this.registry = registry;
    }

    // 用户指标
    public void recordUserLogin(String method) {
        Counter.builder("users.logins")
            .tag("method", method)
            .register(registry)
            .increment();
    }

    public void recordUserRegistration(String source) {
        Counter.builder("users.registrations")
            .tag("source", source)
            .register(registry)
            .increment();
    }

    // 业务指标
    public void recordOrderValue(BigDecimal value, String currency) {
        registry.summary("order.value", "currency", currency)
            .record(value.doubleValue());
    }

    public void recordConversion(boolean converted) {
        Counter.builder("funnel.conversions")
            .tag("result", converted ? "success" : "dropped")
            .register(registry)
            .increment();

    // 容量指标
    public void recordQueueSize(int size) {
        Gauge.builder("queue.size", () -> size)
            .tag("queue", "order-queue")
            .register(registry);
    }

    public void recordConnectionPoolSize(int size, String poolName) {
        Gauge.builder("connection.pool.size", () -> size)
            .tag("pool", poolName)
            .register(registry);
    }
}
```
