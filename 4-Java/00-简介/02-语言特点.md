# Java 语言特点

## 1. 纯面向对象

Java是"纯正"的面向对象语言，所有代码都必须在类中定义（即使是`main`方法）。它不支持独立的函数、全局变量，必须通过类和对象来组织代码。

### 核心特性

- **封装**：将数据和操作封装在类中，通过访问修饰符控制可见性
- **继承**：支持类之间的继承关系，实现代码复用
- **多态**：同一接口的不同实现，如方法重写、接口实现

### 带来的好处

- 代码结构清晰，容易模块化
- 便于复用和维护
- 设计模式在Java世界里应用广泛，形成了成熟的最佳实践

### Java与C++对比

| 特性 | Java | C++ |
|------|------|-----|
| 多继承 | 不支持（用接口替代） | 支持 |
| 全局变量 | 不支持 | 支持 |
| 指针 | 不支持（安全的引用） | 支持 |
| 内存管理 | GC自动回收 | 手动管理 |

## 2. 平台无关

通过JVM实现真正的跨平台：

```
.java源文件 → javac编译 → .class字节码 → JVM执行 → 机器码
```

### 跨平台原理

- `.java`源文件通过`javac`编译成`.class`字节码
- `.class`文件在任何安装了JVM的平台上都能运行
- JVM负责将字节码转换为特定平台的机器码
- 虚拟机负责平台相关的细节处理

### "一次编写，到处运行"

```bash
# 在Windows上编译
javac Hello.java    # 生成Hello.class

# 在Linux/Mac上直接运行（无需重新编译）
java Hello
```

### JVM的作用

- **类加载器**（ClassLoader）：加载.class文件
- **字节码验证器**：确保字节码安全
- **解释器/ JIT编译器**：执行字节码
- **垃圾回收器**：自动内存管理

## 3. 自动内存管理

Java的**GC（Garbage Collection，垃圾回收）**机制会自动：
- 分配内存给新对象
- 识别不再使用的对象（不可达对象）
- 释放这些对象的内存

### 开发者无需手动管理

```java
// C++需要手动释放
void foo() {
    Object* obj = new Object();
    // 使用obj...
    delete obj;  // 忘记会导致内存泄漏
}

// Java自动回收
void foo() {
    Object obj = new Object();
    // 使用obj...
}  // obj离开作用域后，GC会自动回收
```

### 优点与缺点

**优点**：
- 大大减少内存泄漏和野指针问题
- 提高开发效率

**缺点**：
- GC会带来短暂停顿（Stop-The-World）
- 内存占用通常比手动管理高
- 调试内存问题较困难

### GC调优（进阶）

```java
// 设置GC策略
java -XX:+UseG1GC -Xmx2g -Xms2g MyApp

// 常见GC收集器
// - Serial GC：单线程，适合小内存
// - Parallel GC：多线程，适合吞吐量优先
// - CMS/G1：低停顿，适合响应时间优先
// - ZGC/Shenandoah：极低停顿
```

## 4. 健壮性与安全性

### 强类型检查

- 编译时严格检查类型错误
- 变量必须先声明后使用
- 类型转换必须显式进行

```java
int num = "hello";  // 编译错误：类型不兼容
```

### 异常处理

统一的异常机制代替传统的错误码：

```java
try {
    int result = divide(10, 0);
} catch (ArithmeticException e) {
    System.err.println("除数不能为零");
} finally {
    // 资源清理
}
```

### 安全管理器

- 可控制代码的访问权限
- 禁止读写本地文件
- 限制网络连接
- 沙箱安全机制

### 数组边界检查

```java
int[] arr = {1, 2, 3};
arr[5] = 10;  // 运行时抛出ArrayIndexOutOfBoundsException
```

## 5. 多线程支持

Java从诞生起就内置了多线程支持：

### 基础多线程

```java
// 继承Thread
class MyThread extends Thread {
    @Override
    public void run() {
        System.out.println("Running in thread");
    }
}

// 实现Runnable
class MyRunnable implements Runnable {
    @Override
    public void run() {
        System.out.println("Running in thread");
    }
}

// 使用
Thread t = new MyThread();
t.start();

Runnable r = new MyRunnable();
Thread t2 = new Thread(r);
t2.start();
```

### 同步机制

- `synchronized`关键字：内置锁
- `wait()/notify()`：等待通知机制
- `java.util.concurrent`：高级并发工具

```java
synchronized (lockObject) {
    // 原子操作
}

// java.util.concurrent包
import java.util.concurrent.locks.Lock;
import java.util.concurrent.locks.ReentrantLock;

Lock lock = new ReentrantLock();
lock.lock();
try {
    // 原子操作
} finally {
    lock.unlock();
}
```

### 现代Java特性（Java 17+）

Java 17+ 引入了虚拟线程（Virtual Threads）和结构化并发（Structured Concurrency），大幅简化高并发编程。详见：[虚拟线程深度](../03-高级用法/11-虚拟线程深度.md)
